第一章

&nbsp; &nbsp; 如果有一天，忽然有一個奇遇擺在你面前，只要你伸伸手，就能得到很多夢寐以求的東西……你會不會動心？

&nbsp; &nbsp; 當然，我們必須清楚的認識到，這世界上，任何東西，都是有代價的！-

&nbsp; &nbsp; 鬧鐘的聲音把我吵醒，我翻了個身，從休息室的小床上坐了起來。

&nbsp; &nbsp; 看了看時間，下午五點整。

&nbsp; &nbsp; 我扭開燈，掏出一枝香煙給自己點上，然後深深吸了一口，讓香煙的辛辣的氣味在肺里轉了個來回，這才真的完全清醒了過來。

&nbsp; &nbsp; 隨後我跳下地，在地上做了幾十個俯臥撐，听見自己全身的骨骼在運動中　　做響，然後略微收拾了一下自己的衣服，把掛在門前的黑色西裝穿上，用力揉了揉自己的臉，讓臉部肌肉松弛了一些，我走出了休息室。

&nbsp; &nbsp; 我的名字，叫陳陽，年紀是二十三歲，生活在這個南方的中等城市里。

&nbsp; &nbsp; 我現在工作的地方，是本市著名的“金壁輝煌”娛樂中心里面的夜總會，夜總會是什麼地方，相信很多人都有了解。在本市的同類娛樂場所中，這家娛樂中心也是高檔次的，而且以里面的小姐年輕漂亮服務熱情而聞名。

&nbsp; &nbsp; 我的頭餃，是主管。

&nbsp; &nbsp; 這名字听著挺氣派，其實工作內容並沒有那麼高雅。我的工作內容就是在客戶來夜總會消費的時候，和他們拉拉關系，喝喝酒，管理管理場子，相當于一個經理一樣。

&nbsp; &nbsp; 我走出休息室的時候，走廊里還沒有什麼人，不過一些服務員已經開始上班了，正在打掃走廊。因為我是主管，所以我才擁有一個小房間當休息室，而我的休息室隔壁就是小姐們的休息室。不過因為現在才下午五點，小姐沒都沒上班，所以現在這個時候，隔壁都是空著的。

&nbsp; &nbsp; 我走出門，就看見隔壁房間里走出一個艷麗的女人，我抬眼掃了她一眼，是瑪麗。

&nbsp; &nbsp; 瑪麗是英文名MARRY的諧音，她是夜總會里的一個資深人士。原本在幾年前曾經是本市幾個娛樂場所都很紅的小姐，現在年紀大了一點，開始整理手里的資源，拉攏了一批小妹，自己當起了媽咪。

&nbsp; &nbsp; 瑪麗在我們場子里算混得不錯，手下有二三十個小姐跟著她混飯吃。而且她入行多年，路子相當野，如果遇到人手不夠的時候，她一個電話就能調來十幾個小妹。不過可惜的是，一直以來，她手下都沒有能帶出一個真正的紅牌。

&nbsp; &nbsp; 所謂的紅牌，不是說只長相漂亮就可以。這年頭，當小姐也不是那麼容易混的。說句玩笑話，當名妓也不是一件簡單的活兒。身為一個紅牌，不但要漂亮，而且還要聰明，會來事兒，會看客人臉色。該風騷的時候風騷，該端架子的時候端著。

&nbsp; &nbsp; 一般能當紅牌的，都是那種能把男人勾引得神魂顛倒如痴如醉的女妖精。

&nbsp; &nbsp; 那種上來就脫了衣服往客人身上撲的小姐，一般只有沒見過女人的小花痴才喜歡。

&nbsp; &nbsp; 現在的男人，出來玩都玩成精了！

&nbsp; &nbsp; 憑心而論，瑪麗算是一個很風騷誘人的女人。她的五官很艷麗，身材圓潤，該翹的地方翹，該細的地方細，身上穿著的那件黑色小西裝，偏偏胸前前襟放得很開，故意露出了半截白色的蕾絲內衣，外加一條乳白色的乳溝，很誘人的一個熟女型艷女。

&nbsp; &nbsp; “小五哥~~”瑪麗看見我，立刻眼楮一亮，嬌笑著喊了我一聲，故意扭動著水蛇腰，款款向我走來，身子有意無意的貼著我，上半身干脆就掛在我的胳膊上，用甜得發膩得聲音在我耳邊笑︰“今晚你可要多照顧我啊，昨天死強那個家伙，硬是把我這組人排在最後，害的我手下小妹一晚上都沒活干呢。”

&nbsp; &nbsp; 說完，仿佛是故意一樣，把她一對爆乳在我手臂上摩擦了幾下。

&nbsp; &nbsp; 我臉上露出嘻笑的表情，故意在她翹臀上用力拍了一下，順手捏了一把，笑道︰“瑪麗姐，別耍我了？阿強敢駁你面子？昨晚我可看見了，就數你手下的小妹接的活兒最多。馬老板昨天不是還帶著麗麗出場了麼？”

&nbsp; &nbsp; 瑪麗對我飛了個媚眼，膩聲笑著︰“我不管了，今晚你可得給我排個好鐘！”說完又把柔軟香噴噴的身子往我胳膊上貼。

&nbsp; &nbsp; 很多人以為這種娛樂場所里，小姐都是夜總會里的。其實這種概念是錯誤的。

&nbsp; &nbsp; 夜總會自身是不養小姐的，小姐和媽咪都不拿夜總會一分錢薪水的。一般夜總會做生意，都會召來幾個媽咪，由媽咪帶來一幫小姐，每天在場子里給客人服務，小姐都是靠客人的小費養活。而媽咪的收入，則是靠拿小姐的提成，一般來說，客人給小姐多少小費，小姐都要上交媽咪一成。

&nbsp; &nbsp; 當然，也有混的比較好的小姐或者媽咪，認識了幾個熟客，客人通過她們在夜總會里預定的包間，那麼那天晚上客人的消費，小姐或者媽咪也能拿到一定比例的提成。

&nbsp; &nbsp; 比如瑪麗，她手下雖然沒有什麼紅牌小姐，但是因為人緣廣，手里攥著幾個大客戶，每個月這幾個大客戶都在夜總會里消費十來萬，那麼她拿到的提成就相當可觀了。

&nbsp; &nbsp; 不過坦率說，我現在干的這個活兒，她的確要好好巴結我。

&nbsp; &nbsp; 因為夜總會里的制度，一般客人來了，都是我們這種客戶主管負責接待，然後進了包間，我就會找和自己關系好的媽咪或者小姐進去給客人服務，權力基本上都在我手里。

&nbsp; &nbsp; 所以，混這里的媽咪和小姐，都很巴結我。就是希望我能多給他們介紹生意。

&nbsp; &nbsp; 還有很多小姐，為了能多賺錢，能在經理手下排個好位置，甚至願意主動送上門來讓經理佔便宜。

&nbsp; &nbsp; 根據我知道的，我們這個場子里，另外的那個主管阿強，至少這里的一小半小姐都被他上過了。

&nbsp; &nbsp; 不過我人比較和氣，很少打罵這些小姐，也從來不仗著自己的權利欺負人和佔小姐便宜，倒是人緣還不錯。

&nbsp; &nbsp; 瑪麗在嬌笑，我順勢把手攬在她柔軟的水蛇腰上，輕輕捏了一下，心中不禁贊嘆，靠，手感一流！

&nbsp; &nbsp; 這女人身材爆好，皮膚也白皙滑膩，尤其是腰上，更是沒有一絲墜肉。再加上夜總會里的規矩，當媽咪的都是穿著這種黑色的緊身小西裝，手里拿著一個小小的手袋（裝小費用的），這麼猛的一看，還真有點OL誘惑的味道。

&nbsp; &nbsp; 我不禁嘆息，瑪麗手下沒有紅牌小姐，那是因為她現在不肯下水了。如果她肯重操舊業，一定紅的。雖然她本身不算絕色，但是眉眼通挑，又會揣摩客人心理，又會哄人，難怪當年曾經紅過了。

&nbsp; &nbsp; “小五哥，現在時間還早，要不要我幫你松松骨呀？”說完，送了我一個媚眼，一雙眼楮里都仿佛要滴出水來了。我知道她是在耍我。一會兒就要開工了，就算想干什麼，現在也來不及了。用力在她臀部上扭了一下，笑道︰“好了，別逗我了，晚上我正好有幾個客人預定了包間，回頭我帶你進去吧，不過叫你手下小妹好好打扮一下，我這幾個客人眼楮可毒得很。”

&nbsp; &nbsp; 瑪麗立刻眉開眼笑，湊過來在我臉上波了一下，這才扭著水蛇腰進去補妝去了。

&nbsp; &nbsp; 金壁輝煌夜總會里，一共有四個主管。我是四個人中年紀最小的，可卻是在這里混的最長的。我十八歲就來這里混了，從端盤子的小弟開始干，然後從服務員干到接待，最後才混上了主管的位置。

&nbsp; &nbsp; 今晚和我一起當班的還有另外一個主管阿強。這小子比我大好幾歲，已經三十開外了。卻長著一張小白臉。一雙眼楮里總是冒淫光，好像總是欲求不滿的樣子。我走到後場餐廳的時候，這小子正和另外一個媽咪鳳姐打情罵俏。

&nbsp; &nbsp; 鳳姐是這里的頭號媽咪，她手下的小妹沒有瑪麗多，但是卻有兩個超級紅牌，都是我們這里的鎮場台柱子。絕對的美女。

&nbsp; &nbsp; 我坐了下來，和阿強鳳姐打了個招呼，鳳姐立刻笑眯眯的貼了過來，故意挨著我一屁股坐在我身邊。鳳姐的模樣和瑪麗完全兩個極端，瑪麗是那種風騷的熟女，身材火爆。而鳳姐則是小巧形的，不過一雙眼楮很媚，身上的風塵味沒有瑪麗那麼足，但是為人卻極精明，很有手段，不然也鎮不住手下那兩個超級紅牌小姐。

&nbsp; &nbsp; “小五，怎麼來這麼晚啊。”阿強笑著遞給我一枝香煙，露出一口潔白的牙齒。這家伙據說當年是在本市某個著名的鴨店里干過，年輕的時候也曾經風靡本市鴨界，不過現在年紀大了，拼不過那些小年輕了，才到我們這行混飯吃的。

&nbsp; &nbsp; 我一向不太喜歡這個家伙，因為原本憑他的本事是很難當主管的，據說也是靠女人上位的，傳說我們這家夜總會背後除了現在的老板還有一個股東是富婆，這家伙就是靠了那個富婆的關系才進來的。

&nbsp; &nbsp; 我一向總覺得凡是這種吃軟飯的男人都很欠扁，對他一向沒什麼好感。背地里我也知道，公司的很多人暗中都叫他“軟飯王”。

&nbsp; &nbsp; 我臉上保持淡淡的微笑，和他點了點頭，算是打了個招呼。

&nbsp; &nbsp; 鳳姐則干脆伸手摟住了我的脖子︰“小五哥，我听說今晚馬老板還要過來，他可是你的老客人了，今晚一定要多關照我呀。”

&nbsp; &nbsp; 我察覺到鳳姐摟我的時候，阿強眼楮好像閃過一絲不快的目光，立刻不動聲色假裝抽煙的動作，擺脫了鳳姐胳膊的糾纏。

&nbsp; &nbsp; 我不是怕阿強，只是覺得在這種地方，為了一個夜總會里當媽咪的女人莫名其妙得罪一個同事，沒有必要。

&nbsp; &nbsp; “鳳姐，你手下兩個台柱子放在那里，每天就等著數錢吧。”我笑眯眯的噴了口煙，然後叫了一份套餐。我察覺鳳姐的表情有些不自然，強笑著道︰“再怎麼樣也要你小五哥關照才行啊。”

&nbsp; &nbsp; 我聞言心中一動，難道是她手下那兩個紅牌出問題了？

&nbsp; &nbsp; 不過這都不關我的事情，我狼吞虎咽吃完了東西，把筷子一扔，和兩人打了個招呼，上樓沖澡去了。

&nbsp; &nbsp; 留下阿強和鳳姐兩人鬼鬼祟祟，也不知道商量什麼東西。

&nbsp; &nbsp; 這里人人都知道阿強和鳳姐兩人有關系……不是有一腿，而是有很多腿！基本上媽咪很少出面給主管獻身的，不過也有真的勾搭在一起。比如阿強和鳳姐，不過我心中猜測，這小子勾搭鳳姐，恐怕真正的目的是她手下的那兩個紅牌吧。

&nbsp; &nbsp; 紅牌小姐和普通小姐是完全不同的。比方說，普通小姐需要巴結我們，巴結媽咪。巴結了我們，因為我們一般會照顧關系好的小妹，帶他們進一些大客戶的包間。而巴結媽咪，則是為了給客人挑人的時候，站的位置考前一點。

&nbsp; &nbsp; 在這種場所玩過的朋友都知道，一般客人挑小姐的時候，都是讓小姐在包間里站成一排讓客人看。而和媽咪關系最好的小姐，都是站在最前面，最靠近客人的地方。至于那些不受寵的小姐，就只能站在靠近門邊上，甚至還會被別人擋住。

&nbsp; &nbsp; 這種情況下，就算你是天仙美女，客人都看不到你，你也絕對沒生意做的。

&nbsp; &nbsp; 而紅牌小姐，根本不用巴結人，她們自己就有不少熟悉的大客戶，每天晚上甚至不用和別人排隊去等客人挑，自己就有固定的老客戶來點名捧她場。反而是媽咪，都要對手下的這種紅牌小姐很客氣，因為紅牌小姐就是媽咪手下的生金蛋的母雞！一般來手，主管或許可以利用手里的權利佔佔普通小姐的便宜，但是紅牌小姐，是不用看主管臉色的。

&nbsp; &nbsp; 在我看來，我們這個場子里一共有四個紅牌小姐，其中有兩個更是超級紅牌，真真正正的絕色美女！其中一個還是著名藝術學學院畢業的！還在幾部影視劇里演過配角，只不過娛樂圈里競爭實在太激烈，而做這行來錢也快，就過來撈錢了。

&nbsp; &nbsp; 我上了樓去桑拿部洗了個澡，在熱水下沖了二十分鐘，才感覺全身的精力都恢復了。出來的時候，桑拿部的小弟過來恭恭敬敬的先喊了聲五哥，然後問我要不要找兩個小妹給我松松骨，按摩一下。

&nbsp; &nbsp; 我從來都不踫桑拿房里的小姐，原因是感覺她們很髒。

&nbsp; &nbsp; 我列個數字，大家就明白了。

&nbsp; &nbsp; 我們的這個娛樂中心，桑拿部里掛名的有三十個小姐，每天晚上這里接待的客人一般有一百多人，平均每個小姐每天晚上要接客三次以上！一個月下來就是九十次！半年就是五百四十次！一年下來……嘿嘿，您自己計算吧。

&nbsp; &nbsp; 當然，我也很少踫夜總會里的小姐。

&nbsp; &nbsp; 夜總會里的小姐，雖然一樣是出來撈錢的，不過大多很少出場陪客人上床。因為基本上她們不用出場，每個月也能掙到上萬的收入。

&nbsp; &nbsp; 我並不是說夜總會里的小姐就干淨。出來做這行的，沒有干淨的！這也是我在這里混時間舊了之後，就基本不踫場子里的小姐的原因。

&nbsp; &nbsp; 不過現在想想，這年頭，所謂的良家婦女就真的干淨麼？

&nbsp; &nbsp; 那些毛都沒長齊全的女中學生，大學生，成天到晚泡在網絡上，今天見一個網友，明天見一個網友，隔三叉五就和不同的網友去酒店開房間圈圈叉叉……單純從這種頻率上，和出來做的小姐相比，也干淨不了多少！

&nbsp; &nbsp; 這個小弟知道我的習慣，他說的找小妹給我松松骨頭，找的是那種真正的按摩技工小妹，不是小姐。這里畢竟是高檔場所，並不是每個客人來這里都是嫖的。也有專業的按摩技工。

&nbsp; &nbsp; 如果在往日，我是不拒絕洗完澡之後享受一下按摩，這里消費很高，光是洗個澡就要一百塊，而按摩技工的技術也真的很不錯，還有幾個是從南方沿海城市聘回來的，而且我在這里洗澡享受也不用我掏錢。不過看看時間來不及了，搖搖頭，讓他給我拿了瓶礦泉水，一口氣喝完，這才穿了衣服下樓。

&nbsp; &nbsp; 晚上七點鐘，準時開工。

&nbsp; &nbsp; 門口站了一排穿著高開叉旗袍的迎賓小姐，有客人走進就一起鞠躬，鶯鶯燕燕的一片嬌聲細語︰“老板好！”“大哥好！”“老板好……”

&nbsp; &nbsp; 站在門口的這幫迎賓都是包間里的服務員，也就是俗稱的公主。這種包間公主，只有在高檔的夜總會里才有，那種三流低檔次的場子里是沒有的。包間公主負責端茶倒酒，偶爾也會陪客人喝兩杯，玩兩把骰子，不過這種公主是不讓客人踫的，不能踫不能摸，但是服務絕對周到。往往客人消費完了，一般都會塞幾百塊小費給她們。可以說，她們是這里最干淨的人了。甚至很多小姐都常常開玩笑說，想回去當包間公主。

&nbsp; &nbsp; 她們累死累活陪客人喝酒，還要讓客人抱，讓客人摸，每天晚上坐一個台也就幾百塊。

&nbsp; &nbsp; 當然，也有長得漂亮的公主，干了一段時間，受不了金錢的誘惑，就干脆改行當小姐的。

&nbsp; &nbsp; “哎喲……”她很風騷的一笑，貼著我坐了下來，我的休息室里只有一張沙發床，兩人就這麼並肩坐在床上，她伏在我肩膀上，膩聲道︰“沒事就不能來找你說說話麼？”

&nbsp; &nbsp; 老實說，我今晚有些喝多了，順手就摟住她的腰，然後手就往下滑，她也不躲閃，水蛇腰在我懷里一扭一扭，卻仿佛是故意挑逗我一樣。

&nbsp; &nbsp; 瑪麗身手在我胸前劃了兩下，嘻嘻笑道︰“小五哥，別耍我了，誰不知道你是練過的。你身體這麼好，以後你老婆可有福氣了。”

&nbsp; &nbsp; 我撇撇嘴巴︰“老婆？我哪里來的老婆哦……”

&nbsp; &nbsp; 瑪麗的一雙眼楮都仿佛要滴出水來了，干脆整個人往我懷里一倒︰“好了，小五哥，大不了今晚……我去陪你？”

&nbsp; &nbsp; 我心里一動，反而生出幾分警覺來。

&nbsp; &nbsp; 今晚她這麼送上門來，難道是想巴結我？

&nbsp; &nbsp; 不過如果要巴結我，隨便派她手下一個小妹就是了，不用她親自出馬吧？

&nbsp; &nbsp; 我輕輕笑了一聲︰“妖精，你把我火逗上來了，就想不管了麼？”

&nbsp; &nbsp; 她眼中閃過一絲奇異的目光，回身把房門鎖了，然後扭著腰部走到我面前，輕輕蹲了下去，一雙細長的手靈巧的解開了我的拉鏈，然後抬頭媚笑，張開嘴巴……
