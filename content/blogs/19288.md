24句“草根”哲理<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


草根文化生於民間，長於民間，雖然沒有經過主流意識的疏導和規範，沒有經過文化精英的加工改造，充滿著鄉土氣息，但其涵蘊著豐富的生活共識和生活理念，越是這種來自民間、來自大眾、來自生活的東西，越是古樸，越是真實！下面和大家分享一下24句經典的“草根”哲理。

　1．記住該記住的，忘記該忘記的。改變能改變的，接受不能改變的。
&nbsp; &nbsp; 2．能沖刷一切的除了眼淚，就是時間，以時間來推移感情，時間越長，沖突越淡，仿佛不斷稀釋的茶。
&nbsp; &nbsp; 3．怨言是上天得至人類最大的供物，也是人類禱告中最真誠的部分。
&nbsp; &nbsp; 4．智慧的代價是矛盾。這是人生對人生觀開的玩笑。
&nbsp; &nbsp; 5．世上的女生總以為自己是驕傲的公主（除了少數極醜和少數極聰明的女生例外）
&nbsp; &nbsp; 6．如果敵人讓你生氣，那說明你還沒有勝他的把握。
&nbsp; &nbsp; 7．如果朋友讓你生氣，那說明你仍然在意他的友情。
&nbsp; &nbsp; 8．令狐沖說“有些事情本身我們無法控制，只好控制自己。”
&nbsp; &nbsp; 9．我不知道我現在做的哪些是對的，那些是錯的，而當我終於老死的時候我才知道這些。所以我現在所能做的就是盡力做好每一件事，然後等待著老死。
&nbsp; &nbsp; 10．也許有些人很可惡，有些人很卑鄙。而當我設身為他想象的時候，我才知道：他比我還可憐。所以請原諒所有你見過的人，好人或者壞人。
&nbsp; &nbsp; 11．魚對水說你看不到我的眼淚，因為我在水裏．水說我能感覺到你的眼淚，因為你在我心裏。
&nbsp; &nbsp; 12．快樂要有悲傷作陪，雨過應該就有天晴。如果雨後還是雨，如果憂傷之後還是憂傷．請讓我們從容面對這離別之後的離別。微笑地去尋找一個不可能出現的你！
&nbsp; &nbsp; 13．死亡教會人一切，如同考試之後公布的結果？？雖然恍然大悟，但為時晚矣！
&nbsp; &nbsp; 14．你出生的時候，你哭著，周圍的人笑著；你逝去的時候，你笑著，而周圍的人在哭！
&nbsp; &nbsp; 15．男人在結婚前覺得適合自己的女人很少，結婚後覺得適合自己的女人很多。
&nbsp; &nbsp; 16．於千萬人之中，遇見你所遇見的人；於千萬年之中，時間的無涯荒野裏，沒有早一步，也沒有晚一步，於千萬人之中，遇見你所遇見的人；於千萬年之中，時間的無涯荒野裏，沒有早一步，也沒有晚一步。
&nbsp; &nbsp; 17．每個人都有潛在的能量，只是很容易:被習慣所掩蓋，被時間所迷離,被惰性所消磨。
&nbsp; &nbsp; 18．人生短短幾十年，不要給自己留下了什麼遺憾，想笑就笑，想哭就哭，該愛的時候就去愛，無謂壓抑自己。
&nbsp; &nbsp; 19．《和平年代》裏的話：當幻想和現實面對時，總是很痛苦的。要嘛你被痛苦擊倒，要嘛你把痛苦踩在腳下。
&nbsp; &nbsp; 20．真正的愛情是不講究熱鬧不講究排場不講究繁華更不講究噱頭的。
&nbsp; &nbsp; 21．生命中，不斷地有人離開或進入。於是，看見的，看不見的；記住的，遺忘了。生命中，不斷地有得到和失落。於是，看不見的，看見了；遺忘的，記住了。然而，看不見的，是不是就等於不存在？記住的，是不是永遠不會消失？
&nbsp; &nbsp; 22．我們確實活得艱難，一要承受種種外部的壓力，更要面對自己內心的困惑。在苦苦掙紮中，如果有人向你投以理解的目光，你會感到一種生命的暖意，或許僅有短暫的一瞥，就足以使我感奮不已。
&nbsp; &nbsp; 23．我不去想是否能夠成功,既然選擇了遠方,便只顧風雨兼程；我不去想,身後會不會襲來寒風冷雨,既然目標是地平線,留給世界的只能是背影。
&nbsp; &nbsp; 24．後悔是一種耗費精神的情緒.後悔是比損失更大的損失,比錯誤更大的錯誤.所以不要後悔。
