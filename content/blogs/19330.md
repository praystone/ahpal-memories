十三種寂寞，你屬於哪一種 


1。獨自在街道上遊蕩，看著街道上熙熙攘攘的人群，那些歡笑著的臉孔


，那些都是不屬於你的， 你只是一個過客，什麼也帶不走，什麼也留不下


&nbsp;再怎樣的熱鬧，再怎樣的繁華，卻越發襯托你的形單影只 在人群中，


你默然抬起頭，卻找不到一張熟悉的面孔... ... 


&nbsp;


2。一個人蜷縮在床上，無法入睡，腦子裡想著莫名其妙的問題，


黑暗猶如一張巨大的蛛網把你包裹在內，厚厚的棉被裡，你感覺好冷


&nbsp;從枕頭下掏出手機，卻發現你不知道該打給誰，於是，無奈的又塞回枕頭中


&nbsp;你把頭縮進被子裡，輕輕的抱住自己的膝蓋，像一個孩子 把自己抱緊一點，


那麼，就不會冷了吧... ... 


&nbsp;


3。你恨一些人，一些事，甚至恨著這個世界 你總是在想，為什麼是你 


為什麼承受一切痛苦的都必須是你 你只想做一個普普通通的小孩子，


開心過完自己的童年，讀書，找工作，戀愛 ... ... 可是，這麼普通的一切，


對於你，卻如此的難 ... ... 你感覺背後似乎有一雙眼睛，帶著諷刺的笑意看著你 


然後，搖搖頭，走開了... ... 


&nbsp;


4。面對著電腦發呆，身邊的咖啡已經漸漸發涼，耳機裡綿延出悠揚的音樂聲，


此時，已是凌晨 你也不知道是什麼時候變成這樣的，像是一個穴居動物一般，


躲在自己的窩裡不想出來 什麼時候，開始害怕外面的陽光，討厭出門，


面對著門外的那些人，你覺得他們甚至沒有你那台冰冷的電腦親切 有時，虛擬世界


，確實要比現實世界美麗 ... ... 


&nbsp;


5。你靠在窗邊，透過濛濛細雨，靜靜的看著這個陌生的城市 你不知道要在這裡停留多久


，你不知道你會遇見什麼樣的人，不也不知道你會留下怎樣的回憶 ... ... 點一支煙，


煙霧繚繞中，你靜靜的咪上眼，享受這一刻的寂靜 過去的一切就讓他這樣過去吧，


從今開始，你要學會認識陌生的人，做陌生的事，過陌生的生活... ... 獨在異鄉為異客... ... 


&nbsp;


6。你習慣一個人學校的走道上手插口袋漫步徜徉，沒有目標，沒有終點，


你只是想這樣一步一步的走下去，走到自己筋疲力盡為止 你學會在這種


只屬於一個人的時間裡，獨自思考著解開一些問題，無論你的結論是對是錯，


都已經不重要了... ... 你看著那熱鬧的****場，嘴角，輕輕上揚著一絲微笑 夕陽下，


你的影子拉的好長 ... ... 


&nbsp;


7。你在夢裡看到她/他的離開，哭泣著從夢裡醒來 看著空蕩的房間，


你靜靜的走到洗臉台前 看著鏡子裡，自己蒼白而憔悴的臉 你一瞬間淚流滿面 ... ... 


&nbsp;


8。你清晨起床，家中空無一人，你給自己泡了一杯牛奶，


呵著暖暖的熱氣坐在陽台上的沙發裡，隨手翻開著旁邊厚厚的書籍 


冬日的陽光懶散而溫暖的照在你身上 周圍寂靜而安詳 不知不覺中，


你再次睡著，輕聲打著呼嚕，如同一隻懶貓 


&nbsp;


9。你一直沉醉在回憶裡，不願意醒來 你想起以前和朋友在一起的場面，


便會微微發笑 你想起以前的一些窘事，便會微微臉紅 你想起以前的一些無奈，


便會輕聲長嘆 你想起了她，便會死死的咬住下唇 你害怕... ...你會哭出聲來 ... ... 


&nbsp;


10。你在酒吧裡點一支啤酒，聽著震耳欲聾的音樂，看著舞池裡扭動著的人群，


你漫無表情 冰冷的啤酒從食道一直涼到胃裡，你輕聲的呻吟... ... 然後，隨著眩目的燈光，


腳輕輕的打著拍子 巴台上，你的背影像是一尊石像... ... 


&nbsp;


11。學會不再哭泣，學會不再透露自己的感情，他們說你冷血，


你卻只是在那裡微笑 你知道，沒有必要試圖讓別人了解你 知我者為我分憂，


不知我者謂我何求 眼淚解決不了任何問題，只會帶來吵鬧 很多的事情，


我們可以感動，卻不能流淚 因為一旦放任自己的感情，怕會讓自己泣不成聲 


12。參加一場聚會，喝很多酒，卻一直沒有醉倒 咪著一雙眼睛看這個世界，


光怪而陸離 告訴自己，你喜歡這種感覺 獨自去洗臉台，潑了點冷水在臉上，


然後看著鏡子一個人傻笑 醉後 ... ...世界好美... ... 


&nbsp;


13。默默的喜歡上她/他，卻不敢玷污這份感情，一直將它默默珍藏，


無論她/他多麼的驕橫，無論她/他多麼的不講道理，無論她/他讓你氣上多少次，


你都一直在讓著她/他 你明白你現在給不了她/他什麼，你明白現實比愛情殘酷，


你明白，等你能夠給她/他想要的東西時，你才配去愛她/他... ... 最後，


當你鼓起勇氣去找她/他，去尋覓每一個她/他可能在的角落，


想跟她/他說明白一切時，卻發現她/他的身邊，已經有了一個能夠讓她/他幸福的人 


不愛她/他的理由有很多，愛她/他的理由... ...已經不存在了... ...
