[轉]改造不好人緣為好人緣的方法 跟大家分享


1、懺悔自己過去所造損人利己的惡業。<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


2、從今天起，決不再做出妨礙別人的事情。


&nbsp;


3、不嫉妒別人。


&nbsp;


4、看見別人得到好的名譽和利益，心生歡喜。


&nbsp;


5、常願一切眾生都得到利益和好的人緣。


&nbsp;


6、勸導別人不要嫉妒他人。


&nbsp;


7、看見別人嫉妒，替他懺悔業障，並生憐湣心。


&nbsp;


8、看見別人名譽減損，設法幫助他。


&nbsp;


9、稱讚不嫉妒的人。


&nbsp;


10、宣揚不嫉妒的好處。


&nbsp;


11、時時關心別人，處處為別人著想。


&nbsp;


12、常做廣結善緣的好事情。


&nbsp;


13、盡心侍奉父母尊長。


&nbsp;


14、不說別人的過失。


&nbsp;


15、適時適地讚美別人的優點。


&nbsp;


16、不輕視或譏笑人緣不好的人。


&nbsp;


17、多做福利大眾的事業。


&nbsp;


18、常懷念佛菩薩的功德。
