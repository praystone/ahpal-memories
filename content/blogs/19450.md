1、懺悔自己過去身體、語言和心念上所造偷盜的罪業。<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


2、從今以後，決心不犯偷盜。


&nbsp;


3、看見別人從事偷盜時，設法加以勸導或阻止。


&nbsp;


4、看見偷盜的眾生，替他懺悔。


&nbsp;


5、常願一切眾生永遠不偷竊、不盜用別人的財物。


&nbsp;


6、看見別人不偷盜，加以稱讚。


&nbsp;


7、宣揚不偷盜的益處。


&nbsp;


8、看見別人獲得利益，不但不嫉妒而且生歡喜心。


&nbsp;


9、看見別人施捨財物生隨喜心。


&nbsp;


10、時常觀想自己在施捨。


&nbsp;


11、看見貧苦眾生，心生憐湣而不加以輕視或譏笑。


&nbsp;


12、看見富貴人家，勸他施捨，利益大眾。


&nbsp;


13、看見別人追求利益，不但不加留難，而且設法幫助他們達成願望。


&nbsp;


14、盡心幫助窮困的眾生。


&nbsp;


15、侍奉父母，不使老人家有所匱乏。


&nbsp;


16、常念‘地藏王菩薩’等佛菩薩的名號。
