好個總統rn&nbsp;


有一天總統不小心掉到水溝裡，恰巧有三個小孩經過


&nbsp;


總統對他們說：「如果你們救我起來，我就給你們每人一個願望」


&nbsp;


第一個小孩說他要一輛變速腳踏車


&nbsp;


第二個小孩就說他要一個棒球手套


&nbsp;


第三個小孩想了很久，說他要一台輪椅


&nbsp;


總統心裡覺得很奇怪，手腳好好的為什麼需要輪椅呢


&nbsp;


就問第三個小孩：「你為什麼要輪椅呢？」


&nbsp;


第三個小孩就說：「如果我爸知道我救你起來會把我的腿打斷。」


&nbsp;


&nbsp;


&nbsp;


&nbsp;


傻傻分不清楚


&nbsp;


有一個外國人來台灣學中文


&nbsp;


但他一直搞不清楚"鐵"跟"鋼"的差別。有一天他很晚才回到家


&nbsp;


結果樓下的門打不開，他只好大聲的往樓上喊


&nbsp;


"" 房 東 太 太 ， 妳&nbsp; 的 鋼 門 打 不 開 ""


&nbsp;


&nbsp;


&nbsp;


&nbsp;


大家一起來臭屁


&nbsp;


有一天，四個已經退休的老人一起打麻將


&nbsp;


打了幾圈，一個老人想去上廁所


&nbsp;


其他的三個於是就開始聊起來


&nbsp;


一個老人講到他的兒子俊明，就忍不住臭屁一下


&nbsp;


「我們家的俊明啊……在作珠寶生意，前一陣子不知道發了什麼瘋


&nbsp;


竟然送個大鑽戒給他朋友，真是受不了他啊……」


&nbsp;


另一個老人也不甘示弱的說：「我那個建國啊……在汽車公司裡當經理


&nbsp;


前一陣子也是送了一部凱迪拉克給他朋友！你說敗不敗家嘛！」


&nbsp;


第三個老人也說話啦：「我那個不成材的兒子志杰啊！在搞房地產


&nbsp;


現在經濟不景氣，前一陣子他竟然還送了一棟房子給他朋友！


&nbsp;


真搞不懂他在想什麼……」


&nbsp;


三個老人臭屁了半天，第四個老人上完廁所回來了


&nbsp;


他說：「你們在聊些什麼啊？」 


&nbsp;


「聊兒子啊…，對了，你的兒子家明最近怎樣啊？」其中一個老人問到


&nbsp;


只見第四個老人深深的嘆了一口氣…說著：


&nbsp;


「唉……我家那個家明……別提了…是個同性戀……，


&nbsp;


不過前陣子，不知道走了什麼狗屎運，有朋友送他鑽戒，又有人送凱迪拉克


&nbsp;


還有個人送了棟房子給他！你們說奇不奇怪啊……」
