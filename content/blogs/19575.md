&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 星期一：

&nbsp;

　　左眼跳，今天有事情要發生！

&nbsp;

　　右眼跳，平常事，不要緊。

&nbsp;

　　星期二：

&nbsp;

　　左眼跳，心情會很愉快。

&nbsp;

　　右眼跳，會發生不快的事。

&nbsp;

　　星期三：

&nbsp;

　　左眼跳，有人喜歡你！

&nbsp;

　　右眼跳，有事會讓你生氣。

&nbsp;

　　星期四：

&nbsp;

　　左眼跳，有想不到的事情發生。

&nbsp;

　　右眼跳，今天對任何事都不能插手。

&nbsp;

　　星期五：

&nbsp;

　　左眼跳，有人在想念你。

&nbsp;

　　右眼跳，將發生一件幸福的事。

&nbsp;

　　星期六：

&nbsp;

　　左眼跳，這幾天會暴露你的秘密。

&nbsp;

　　右眼跳，近期會得到禮物。

&nbsp;

　　星期日：

&nbsp;

　　左眼跳，會發生意想不到的事。

&nbsp;

　　右眼跳，有好運氣。

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;子時：23點一一01點前 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;左眼：意外之喜降臨，會有不錯好運，你的心髒要強一點，別興奮過了頭。 

&nbsp;

　　右眼：有人請你吃飯，可以省下一筆錢，但是這個人的目的不明，你要多多斟酌。

&nbsp;

　　丑時：01點一一03點前

&nbsp;

　　左眼：家中最近很麻煩，大小事困擾著，不知該怎麼辦，短期內一籌莫展。

&nbsp;

　　右眼：有人思念你，有可能是家中長輩，相互牽掛太久了，有空打電話關心一下吧。

&nbsp;

　　寅時：03點一一05點前

&nbsp;

　　左眼：會有朋友自遠方而來，狠狠吃你一頓！如果你並非別有所圖或手邊閒錢多，接到

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 朋友電話一定要裝忙。

&nbsp;

　　右眼：家人有機會得到意外之財，例如忽然中了獎，也有可能丟掉的錢又找回來了。

&nbsp;

　　卯時：05點一一07點前

&nbsp;

　　左眼：貴人貴客報到，讓你生命重現曙光，多留意忽然出現在你身邊；很久不見的朋

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 友。

　　&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 右眼：平安順利，不必太過擔心可能發生危險的狀況，吉人自有天相，安心睡覺吧。

&nbsp;

　　辰時：07點一一09點前

&nbsp;

　　左眼：人際關系會變好，許久不見的朋友再次相逢，可能捎來不錯的喜訊。

&nbsp;

　　右眼：錢財就這樣不知不覺地流失掉，花了許多冤枉錢。

&nbsp;

　　巳時：09點一一11點前

&nbsp;

　　左眼：會有好處可以撈，目前的你頗有利用價值，別人都會讓你三分。

&nbsp;

　　右眼：開車小心，提醒家人多注意平安，危險出現在四週。

&nbsp;

　　午時：11點一一13點前

&nbsp;

　　左眼：長期耕耘總算有了結果，你可以鬆一口氣，準備享受成果吧。

&nbsp;

　　右眼：意料之外的事情發生，還好機率不高，繼續保持警戒才好。

&nbsp;

　　未時：13點一一15點前

&nbsp;

　　左眼：你可能在打賭或玩麻將時輸了不少錢，別輸光了才來後悔。

&nbsp;

　　右眼：有好事發生，但屬于微不足道，你也不會很高興的那種小事。

&nbsp;

　　戌時：19點一一21點前

&nbsp;

　　左眼：有人指派工作給你，不要想太多，快點答應，其他的問題會自然會迎刃而解喔！

&nbsp;

　　右眼：得意忘形了嗎？小心小人隨時準備落井下石，你別太囂張。

&nbsp;

　　申時：15點一一17點前

&nbsp;

　　左眼：忽然想起什麼事情嗎？快點去做，當下想到的，最容易成功了。

&nbsp;

　　右眼：異性緣佳，你的貴人就是異性，他們對你，比同性寬容多了。

&nbsp;

　　酉時：17點一一19點前

&nbsp;

　　左眼：為人辛苦為人忙，好在有收獲，幫別人也是在幫自己。

&nbsp;

　　右眼：剛認識的朋友就可以熟得不得了，和他們多混熟點會很不錯。

&nbsp;

　　戌時：19點一一21點前

&nbsp;

　　左眼：有人指派工作給你，不要想太多，快點答應，其他的問題會自然會迎刃而解喔！

&nbsp;

　　右眼：得意忘形了嗎？小心小人隨時準備落井下石，你別太囂張。

&nbsp;

　　亥時：21點一一23點前

&nbsp;

　　左眼：享受合家團圓、多方肯定，再加把勁，你會做得更漂亮。

&nbsp;

　　右眼：提防官司糾紛，你要不口舌冒犯人，要不就是弄壞東西！

&nbsp;

　　子時：左有貴人，右有飲食。午時：左主飲食，右有兇事。

&nbsp;

　　丑時：左有憂人，右有人恩。未時：左主吉昌，右有中喜。

&nbsp;

　　寅時：左遠人來，右若事至。申時：左有女思，右有損財。

&nbsp;

&nbsp;

　　辰時：左遠客來，右主損害。戌時：左有客至，右主聚會。
