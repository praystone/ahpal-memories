&nbsp;

&nbsp;

&nbsp;

『等到我學業完成以後，我定要好好地放鬆自

&nbsp;

己。』 


&nbsp;

『等到我生意上了軌道以後，我定要出國旅行，

&nbsp;

到處遊玩，開開眼界。』 


&nbsp;

『等到我賺了錢以後，我定要好好地孝敬父母，

&nbsp;

讓他們過上好日子。』 


&nbsp;

『等到我買了房子以後，我就會停下忙碌的腳

&nbsp;

步，好好享受人生。』 


&nbsp;

『等到我孩子結了婚以後，我就可以安心打牌，

&nbsp;

毋需再顧慮那麼多。』 


等到‥‥‥等到‥‥‥我們總是這樣對自己說，


&nbsp;

也總是這樣把享受人生寄托在遙不可知的未來。


&nbsp;

似乎我們所有的生命，都消耗在等待上。 


&nbsp;

&nbsp;

曾有這麼兩個年青人，一位是中國人，另一位是

&nbsp;

美國人。


&nbsp;

他們同在某個大城市的一家公司上班，職位相

&nbsp;

同，薪金相同，


&nbsp;

然而所過的生活卻迵然不同。


&nbsp;

&nbsp;

那位美國人在他上班一年後，


&nbsp;

用所賺的薪金分期付款買了一套非常漂亮、舒適

&nbsp;

的房子，日子過得稱心如意；


&nbsp;

而另外那位中國人，卻是租住在一棟非常破舊的

&nbsp;

公寓裡，


&nbsp;

房子又黑又小又舊，彷彿稍微用力一點，整個房

&nbsp;

子就會倒塌似的。


&nbsp;

&nbsp;

那位中國人省吃儉用，他告訴自己，等到賺夠了

&nbsp;

錢，就一定要買棟漂亮的房子，


&nbsp;

讓自己住得舒服一點。


&nbsp;

&nbsp;

二十年後，他終於如願以嘗，


&nbsp;

在那位美國人所住的公寓裡買了一套與他一樣漂

&nbsp;

亮的房子，與美國人毗鄰而居。


&nbsp;

結果不幸的是，那位中國人住進新房子還不到一

&nbsp;

年，


&nbsp;

就因多年來營養不良、積勞成疾而撒手西歸。 


&nbsp;

&nbsp;

　　這就是中國人的悲哀，也是東方人與西方人

&nbsp;

&nbsp;

最大的區別。


&nbsp;

中國人顧慮太多，總是把生命用在等待上；


&nbsp;

&nbsp;

而西方人卻是秉持“把握現在，及時行樂”的人

&nbsp;

&nbsp;

生態度。


&nbsp;

&nbsp;

如果那位中國人也像那位美國同事一樣，


&nbsp;

&nbsp;

用分期付款的方法買一套房子，


&nbsp;

&nbsp;

那他不也是一樣可以在二十年前就讓自己過得舒

&nbsp;

&nbsp;

服一點了嗎？ 

人人都願意犧牲現在，去換取不可知的等待；


&nbsp;

&nbsp;

犧牲今生的辛苦錢，去換取來世的安逸。


&nbsp;

&nbsp;

其實我們毋須等到生活完美無瑕，也毋須等到一

&nbsp;

&nbsp;

切穩定下來，


&nbsp;

&nbsp;

想做什麼，現在就可以開始。每個人的生命都有

&nbsp;

&nbsp;

盡頭，


&nbsp;

許多人往往在生命即將結束時，才發現自己還有

&nbsp;

&nbsp;

很多事沒有做，這實在是一種遺憾。 
! 


&nbsp;

　　人生是一張單程車票，失去的便永遠不會再

&nbsp;

&nbsp;

擁有。


&nbsp;

&nbsp;

千萬別把美好的生命浪費在等待上，把握現在，

&nbsp;

&nbsp;

享受現在，才是最重要的。

&nbsp;

&nbsp;
