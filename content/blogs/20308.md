&nbsp;

岸邊閒情 一賞百姿景
古箏琵琶 弦音裊裊繞

&nbsp;

音繞聲響岸邊染 隨音起舞嘻戲情

&nbsp;



&nbsp;

一笑~眼賞雙雉鳴聲逗蝶舞

&nbsp;

&nbsp;



&nbsp;

二觀~雙鶴仰頸尋蟬縱 蟬兒靜俏藏枝中

&nbsp;

&nbsp;




三賞~蝶飛近賞雀姿態 雙彩並行風采豔


&nbsp;

&nbsp;

&nbsp; 

&nbsp;

慢水流中 小魚懶游游
江邊野雁 靜等覓食來
崖邊壁上 蟲險不知危
頂上雉鳥 伺伏瞬間擒

&nbsp;

&nbsp;

&nbsp;

&nbsp; 

&nbsp;

暖暖晴午日中下 貓兒興起玩耍心
雙眼溜溜望蝶轉 靜伏慢進撲蝶行
途中遇覓水中魚 好奇之心貓天性
不追蝶行停望觀 水中游魚何時停
靜觀貓兒心中疑 搖尾彈耳眨眨眼
蠢蠢欲動耐不住 前足前伸撥邊魚

&nbsp;

&nbsp;

&nbsp;

&nbsp;&nbsp; 

&nbsp;

天微略暗已傍晚 巢中鳥出尋覓食
銳眼尋得戲蟲影 自投嘴中不費力
嘴啣美味心歡喜 落枝速走回巢行

&nbsp;

&nbsp;

&nbsp; 

&nbsp;

月下晚涼意 江邊 荷花塘
朵朵盛開小荷花 花香隨風滿飄揚
月光照亮花叢間 晶瑩華麗撒晶亮
晶亮之美荷葉襯 葉下魚蝦也來賞
草魚悠閒自在游 羞蝦探探戲水弄
荷花魚蝦月光下 宛如一幅水墨畫
閒情一彈一賞景 爾添吟頌詩詞境
