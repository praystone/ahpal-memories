我喜歡看樹枝上那淡淡的嫩綠。它是春天的使者，它是清晨的開始，它是朝氣蓬勃先
&nbsp;
驅，它提醒你現在是雨後的潔淨與清新…… 　 
&nbsp; &nbsp;
&nbsp;
我追求淡淡的友誼。是朋友，卻不常常見面，偶爾電話中淡淡的一句：你好嗎？淡淡的
&nbsp;
問候此時就象發芽的思念一樣蔓延開來，牽掛將牢居你的心頭。俗話說：君子之交淡如
&nbsp;
水；友誼中的這個“淡”字又包含了多少的真誠與純潔呢！ 愛要淡淡的。詩人汪國真
&nbsp;
說：“愛，不要成為囚。不要為了你的遐意，便取締了別人的自由……少是愁多也是
&nbsp;
憂……”不是你的留也留不住，是你的跑也跑不了。朋友，記住：淡淡的愛才會有幸福
&nbsp;
到白頭。 我欣賞那種淡淡的微笑。它讓女人更溫柔嬌羞，它讓男人更成熟大度。它讓孩
&nbsp;
子更天真燦爛，它讓老人更慈祥寬厚。護士的微笑能減輕病人的疼痛，上級的微笑才覺
&nbsp;
得平易近人，鄰友見面淡淡的微笑才顯得親如家人…… 我喜歡淡淡的水。一杯冰開水足
&nbsp;
以解渴。茶呢，也要淡淡的，淡淡之中才品出它餘味的清香。喝咖啡不要加糖，淡淡的
&nbsp;
苦才是它原來的味道。 我還喜歡天空中那朵淡淡的雲，它將天空襯的更高更藍更寬闊；
&nbsp;
有時候真希望自己就是天空中那自在又瀟灑雲兒，朝迎旭日升、暮送夕陽下、身隨魂夢
&nbsp;
飛、來去無罣礙…… 
&nbsp; &nbsp;
&nbsp;
我喜歡淡淡的風。春風吻臉輕輕，秋風撫面溫柔，夏天的風送來涼爽，冬天的風帶來清
&nbsp;
涼。看，那搖曳的柳枝、那麥浪的翻滾、那浪花的跳躍，那是風在舞蹈。聽，耳邊還有
&nbsp;
風的聲響，可是遠方的你在輕聲的呼喚？偶爾蟄伏的思念也會來淡淡的敲開我記憶的閘
&nbsp;
門。沏一杯清茶，放一曲淡淡的音樂，一個人，就一個人，靜靜地，將自己包圍在沙發
&nbsp;
之中，融化在音樂裏，淡淡的回憶著模糊的往昔，翻開舊日的像冊、打開塵封的日記。
&nbsp;
回憶著從來不需要想起、永遠也不會忘記的你。這“淡淡”之中又引出多少的感慨萬
&nbsp;
分、多少的幽怨無奈啊。 　　
&nbsp; &nbsp;
&nbsp;
淡淡之中包含了很多很多，我喜歡淡淡的感覺—— 我還喜歡鄉村那縈繞著的、淡淡的
&nbsp;
炊煙我也喜歡從我身邊略過的淡淡的香水味道我更喜歡那種“紅了櫻桃、綠了芭蕉”的
&nbsp;
淡淡的鄉愁…… 是的，我喜歡淡淡的想你…
&nbsp;
