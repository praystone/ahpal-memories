不相同的人<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


不一樣的事


&nbsp;


以及不一樣亦不相同的物~


&nbsp;


都不應該只有一種公式


&nbsp;


所以當然不可以用自己的公式


&nbsp;


去套用別人


&nbsp;


這會讓人不舒服


&nbsp;


也會讓自己不開心


&nbsp;


妳會納悶別人為何想法與自己相差這麼多


&nbsp;


妳會覺得別人為何無法聽從自己的建議


&nbsp;


妳往往也會告訴自己 我都是為了她好


&nbsp;


請三思&nbsp; 【每個人都是獨特的】


&nbsp;


道理像是不會有人要求~烏龜站立~駝鳥會飛~公雞會下蛋~鴨子會生鵝蛋....


&nbsp;


所以請勿拿公式去套用別人的處理方式
