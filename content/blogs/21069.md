&nbsp;

&nbsp;

其實想要的很簡單，

&nbsp;

就，愛。

&nbsp;

不管怎麼樣，只想愛。

&nbsp;

&nbsp;

&nbsp;

希望能愛人，所以稱她為愛人。

&nbsp;

希望她愛你，你是她的愛人。

&nbsp;

&nbsp;

&nbsp;

但相遇，不簡單。

&nbsp;

可，我只不過是想

&nbsp;

愛。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

是不是真的，這麼難。
