&nbsp;

一個訊息比一個訊息讓人啞口無言

該如何去安慰一個人....停留很久卻說不出話

&nbsp;

明明是探望朋友時候才得知

至今也才幾天

&nbsp;

很不幸我又傳到讓人遺憾的訊息

我以為阿維已經準備開學

&nbsp;

明天就是開學日

為何人還在家裡

&nbsp;

詢問其原因

阿維說因為家裡有事情

&nbsp;

我想說應該是要照顧父親大人

頗為感動時

&nbsp;

就順問了明天是否要去醫院陪伴父親大人

過了一會

&nbsp;

&nbsp;

"他不在了"

這句話讓我想了好久，卻不知道開怎了回覆。

&nbsp;

停頓了！

&nbsp;

因為這句話，感覺都不對了。

原本只是要打聲招呼

&nbsp;

卻得知遺憾的訊息

讓人意外的不知道該如何安慰...

&nbsp;

相同的年紀

確有不相同的際遇

&nbsp;

為何讓人最不願意見到的 生病~&nbsp; 不在了~

這樣的分離和焦慮讓人飽受精神轟炸之苦

&nbsp;

往往都是留下了的

照顧在旁邊的

這些人辛苦~心疼~

&nbsp;

※千萬要為了關心尼的人保重自己的身體

※千萬不要讓關心妳的去承擔分離的苦楚

&nbsp;

&nbsp;

一人同樣20歲的年紀

在醫院陪伴父親大人

還要撥空下來看看婷有沒有需要幫忙

這樣的好人...去哪裡找呢？

&nbsp;

傷心的事情總是讓人刻骨銘心

使人沈思

每天千辛萬苦得來的快樂~試問它價值在哪裡?

一個訊息就可以使人心情降到最低點

在多的安慰還是需要時間去淡忘一切
