　　你是茶葉，


&nbsp;


　　那麼你地香郁，


&nbsp;


　　必須依賴我地無味。


&nbsp;




&nbsp;


　　讓你地乾枯柔柔的，


&nbsp;


　　在我裏面展開、舒散 ;


&nbsp;


　　讓我底浸潤，


&nbsp;


　　舒展你的容顏。


&nbsp;




&nbsp;


　　我必須熱，必須沸，


&nbsp;


　　彼此才能相容。


&nbsp;




&nbsp;


　　我們必須隱藏


&nbsp;


　　在水裏相覷，相親。


&nbsp;


　　一盞茶功夫，


&nbsp;


　　我倆才決定成一種顏色。


&nbsp;




&nbsp;


　　無論你怎麼浮沉，


&nbsp;


　　把持不定，


&nbsp;


　　你終將緩緩的，


&nbsp;


　　(噢，輕輕的)


&nbsp;


　　落下，攢聚，


&nbsp;


　　在我最深處。


&nbsp;




&nbsp;


　　那時候，


&nbsp;


　　你最苦地一滴淚，


&nbsp;


　　將是我最甘美的


&nbsp;


　　一口茶。
