七彩泡泡 



&nbsp;



親愛的



每個人都在追求幸福人生，每個人都在找尋成功捷徑。



你小時候一定玩過吹泡泡吧，我想你也一定玩過萬花筒。



隨風飛舞的七彩美麗泡泡，說穿了只是苦澀的肥皂水；



而花樣多變的萬花筒，打破了也不過是幾張破碎的小紙片。



一味追求光鮮活躍的現代e生活；



汲汲營營自我表現，為了社會普遍價值觀而讓自己忙碌不堪。



&nbsp;



你是否曾經靜下心來想過：



在繁華多樣的背後，會不會也像七彩泡泡和萬花筒般短暫而不真實？



&nbsp;



&nbsp;



■看的更遠 



&nbsp;



親愛的



想要確切的看清事物本質，事實上是有些困難的。



你一定到過海邊吧，站在岸邊看海面，



你只能憑藉著既有的認識去想像海潮底下的世界，



你會忽略了每個地方的海中都是不同的，景觀不同，魚類也不同。



就算是同一個地方，四時的變化也會完全的不同，



就連同一天的清晨與黃昏都會有很大的差別。



&nbsp;



我們容易犯的錯誤就是：太過相信自己。



如果我們可以在聽到不同的觀點時，



先不要急切的想要說服對方接受我們的看法，



讓心靈開個門使對方能夠進入，我們的心就會更寬廣的看到世界。



&nbsp;



&nbsp;



■無形的價值 



&nbsp;



親愛的，事物的價值你怎麼看？



記得去年五月，把後院的小小一塊地整理了一下，



之後去買的一包聖心小蕃茄的種子回來種。



還花了六百元買肥料和支撐蕃茄的木架，細心的澆水拔草，



三個多月後，終於收成了。



我懷著欣喜的心情，拿出我裝涼麵的竹製蔞子小心的摘下一顆顆



紅透的小蕃茄，用一種近乎呵護愛人的心情。



大約有兩、三斤吧，一方面一個人也吃不完，



一方面也想炫耀一下自己的成果，我拿去公司請大家吃。



沒想到非但沒有獲得讚賞與感謝，還被笑笨，花了那麼多錢和心力，



換來幾十元就能買到的蕃茄，而且還沒有外面賣的漂亮。



&nbsp;



其實我並不這麼認為，因為在澆水照顧蕃茄的過程中有著期待，



所以我獲得了許許多多的快樂，這些絕不是金錢所能換來的。



如果所以事物都要冠上金錢價值，那麼人生將會少掉很多的樂趣，



但願你在衡量的天平上，也能夠把無形的價值放重一些。



&nbsp;



&nbsp;



■一個人生活 



&nbsp;



親愛的，一個人生活其實也不錯。



一個人生活最有味道的地方，應該就是下班以後買一束花，



第二天早上在淡淡的花香中醒來的感覺吧？



這是日劇「一個人住」中花淵美步說的話。



創造生活樂趣可以有許許多多不同的方法，



只要你願意用心去生活，用心去經營自己的生命。



發現路旁不知名小花開了可以快樂....



在書店看到一段心有戚戚焉的文字可以快樂....



抬頭望見一朵雲飄過可以快樂……



快樂其實是無所不在的，就看你要不要罷了。



&nbsp;



就從現在起，把身旁的快樂統統找出來吧，



你將發現到，人生其實是充滿驚喜與樂趣的。



&nbsp;



&nbsp;



■相信自己 



&nbsp;



親愛的，你覺得自己處處不如人嗎 ？



腦袋沒有他人聰明，環境背景也不如人，帥氣美麗更是跟人沒得比。



陽明山花季開始了，許許多的多的賞花人絡繹於途，杜鵑、櫻花恣意的開放著。



如果你往裡面走遠一些，往大屯山、七星山的路上有許多菅芒，



三月的菅芒是孤單的，沒有人會多看它一眼，甚至可說是讓人厭棄的，



它銳利的葉子容易刺傷人。但菅芒仍守著小小的天空生長著。



但是時序更替，春天過去，夏天過去，秋天來了。



菅芒的白穗在風中搖曳，染白了整個秋季，許多人專程上山去感受那份唯美，



秋天，是屬於菅芒的季節。



&nbsp;



我們如果不是嬌豔的玫瑰，不是繽紛的杜鵑，



至少我們可以是菅芒，只要努力認真生活，



一樣可以可以有屬於自己的季節，一樣展露出迷人風采。



&nbsp;



&nbsp;



■幸與不幸 



&nbsp;



你喜歡巧克力，卻不喜歡它那麼甜；



你喜歡玫瑰，卻不喜歡它的多刺；



你喜歡帥哥美女，卻擔心被別人追走……



你總抱怨著美中不足，所以心中一直有遺憾。



&nbsp;



其實，反過頭來想想，如果巧克力不甜，能賦予戀愛的濃情蜜意嗎？



玫瑰如果沒刺，能表達愛情的酸甜苦辣嗎？



帥哥美女不是那麼多人追逐，你還會對他(她)有興趣嗎？



所有事物都有正反兩面，陰影的另一面必存在陽光燦爛。



&nbsp;



如此想來，幸與不幸，也是一體兩面，



就看你自己的認定跟面對方式了。



&nbsp;



&nbsp;



■抓泥鰍與蜜蜂 



&nbsp;



親愛的，你總說抓不住愛情、常常被愛情所傷。



你到田間抓過泥鰍嗎？你在花叢中抓過蜜蜂嗎？



小時候我常常跑到田裡抓泥鰍，弄得一身泥濘。



我們從田埂邊的爛泥中翻土找尋泥鰍，



看到泥鰍如果死命的用兩手緊緊想要抓住牠，



在用力的同時，全身包覆黏液的泥鰍馬上滑不溜丟的離手而去。



唯有在手掌中留下些空間，順勢將泥鰍移入袋中，才能抓到泥鰍。



&nbsp;



我們也喜歡在冬日的油菜花田裡徒手抓蜜蜂，



只要輕輕將手靠向停在花上的蜜蜂，



然後慢慢將手指聚攏圈圍出一個最大的範圍，蜜蜂是不會螯人的，



我們可以輕鬆的將蜜蜂放入準備好的塑膠袋中。



&nbsp;



我想愛情應該也跟抓泥鰍、抓蜜蜂一樣，



如果因為在乎、想要完全擁有，而讓對方沒有空間，



往往會成為溜走的泥鰍或螯人的蜜蜂。



&nbsp;



放開你緊握的手，給愛情一點喘息的空間吧！



&nbsp;



&nbsp;



■玫 瑰 



&nbsp;



親愛的，你怎樣比喻人生？



雖然我並不頂愛玫瑰的，但我喜歡用玫瑰比喻人生。



玫瑰豔麗、充滿浪漫的遐思，人生也是這樣，多姿多采而讓人憧憬；



玫瑰也多刺，像是人生中難以避免的挫折與阻逆。



你是看到玫瑰的美麗，還是扎人的刺？



只要你懂得欣賞玫瑰，像情人般賦予玫瑰美麗的名字，刺無形中就不存在了；



如果你只是在意硬刺的存在，你就沒有心思去欣賞它的美麗。



當然，你更不會聞到那隱隱約約、若無似有的花香了。



&nbsp;



不要讓偶爾的失意打敗，多多去欣賞人生過程中的美麗吧！



&nbsp;



&nbsp;



■距 離 



&nbsp;



親愛的，都會中，人與人距離近了，接觸頻繁了，



但是，彼此的心靈與關懷卻遠了。



甚至因為每個人帶著一張沒有表情的臉腳步匆匆，所以連面孔都模糊了。



你一定碰到在在電梯中與他人相距僅僅是短短的十公分距離，



卻尷尬的不知該將眼光落向何處？



&nbsp;



那麼，試試微笑如何？



就像是照鏡子，你除非先有微笑，不然鏡中絕不會回你笑臉。



如果將都會比喻是一個海洋，那麼每個人就是小島，



如果你不架起一座座的橋樑，而只願築起冷漠的高牆，



那麼就算是你擁有的這個小島的面積再大，



你依然走不出去外面的廣闊天空，也就失去了快樂的動力。



而微笑，就是建構小島與小島間最好橋樑的原料。



&nbsp;



&nbsp;



■寂寞不寂寞&nbsp; 



親愛的，寂寞是一種病，一種現代人普遍都罹患的流行病。



你是不是喜歡將日子排得滿滿的？



逛街購物、上山喝茶、唱KTV、吃喝一頓……



真的找不到人陪，你會一個人跑到PUB，讓一堆寂寞心情互相取暖；



你從不讓自己有空檔時間，你覺得這樣的日子才是充實而有樂趣的。



你讓日子像趕場般的沒有空閒，說穿了，你只是害怕獨處時的寂寞，



因為，你偶爾也會抱怨說每天都過得好累好累。



一個人獨處，真的是美好的時光，沒有喧囂，可以沖杯咖啡看看書，



可以聽聽音樂回想從前，可以好好看片DVD，可以與心靈來一場感性的對話……



你還可以打開窗，讓晚風進到屋內，幸運的話，月光也會探頭進來瞧瞧，



還有滿天星光不甘被冷落的拚命對你眨眼。



&nbsp;



一個人不一定就寂寞，寂寞不寂寞，寂寞可以很熱鬧。
