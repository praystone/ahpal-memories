雞蛋能吃嗎？!&nbsp;
莊嘉茵 / 文&nbsp;
&nbsp;
女兒將滿十歲，小學四年級，身材魁武，是學校游泳校隊。一年前某日遊完泳回家，一直甩著頭說耳中有水，單著腳跳來跳去，用了棉花棒后也沒改善。帶她去看醫生，說是有些中耳發炎，吃了幾天藥后，醫生說已經痊癒了，但是女兒開始習慣性的快速搖頭，慢慢變本加厲。&nbsp;
&nbsp;
我說你耳朵已經好了，不要再搖頭了，她只是無辜的看著我。一段時間后，除了搖頭，她開始下意識的常常一手捏著兩頰，嘟出嘴巴。我剛發現時，還笑著請她不要再作怪樣，漸漸的女兒簡直是無時不刻的捏著兩頰。看電視時，做功課時，隨時隨地的捏著嘴巴。 &nbsp;
&nbsp;
女兒自出生就容貌出眾，鼻高耳肥，個性大而化之，從小看到她的人都常驚呼：“好帥！”每每要向人說明她實在是女兒身。有一次到友人家中玩了一天，還一起吃飯。離開后這位前國防部長向夫人說，從沒看過長得這麼好看的的小男生！ &nbsp;
&nbsp;
連有一面之緣的地皎法師見到她就說；“這位查甫囝仔生得真莊嚴！”我說：“這位是查某囡仔！”法師連忙抬頭再看，笑笑說：“要轉男兒身沒轉過來！” &nbsp;
&nbsp;
這麼一位容貌端正的女兒，幾個月來每天從早到晚不是搖頭就是捏臉嘟嘴，看得我氣急攻心，見到她又以手捏臉，我就打她捏臉的手，漸漸地母女關系越來越緊張。 &nbsp;
&nbsp;
當我惡狠狠的打下她的手，她有時委屈的哭，讓我甚為懊悔，有時她就跟我怒目相向，后來就常常躲著我。我的先生修養甚好，見我生氣時就說：“女兒，不要作怪樣惹媽媽生氣！”幾個月不見改善后，先生也幾次打了她的手。 &nbsp;
&nbsp;
就這樣吵吵鬧鬧幾個月后，有一位不甚相熟的朋友突然來訪，她十多年來旅居國外，難得回臺。學佛近二十年來，即使居住國外，兩夫妻亦每日精進念佛誦經。三年前回臺時，見到初學佛法的先生與我法喜充滿的樣子，印象深刻。而她也跟我們分享她幾年前開始有神通的因緣。 &nbsp;
&nbsp;
這次回臺幾日，有一個下午的空閒，就想來看看我們，聽聽我們學佛的心得。不料她一見到女兒就說，這個孩子有一千多只雞的眾生圍繞在她的頭部，已經影響她的眼睛、鼻子、耳朵還有嘴巴，現在已深入到頭部，影響她的情緒與思考。 &nbsp;
&nbsp;
我聞言大驚，問：“她前世殺害的雞嗎？”“不是喔，是這一世。”“這一世哪來跟這麼多雞結怨哪！那怎麼辦呢？”“我們幫她辦一場超渡拔薦法會吧！早上先誦藥師經，下午辦一場普施。” &nbsp;
女兒鼻子過敏多年，整日用力擤鼻涕，尤其晨起最是嚴重。中西醫看遍，針灸插了滿臉的針，治療多時不見改善。中醫說過敏性鼻炎用力擤鼻子的結果，會影響到眼睛和耳朵。果然二年級就近視，每晚要戴著矯正隱形眼鏡睡覺，幾個月前的中耳炎開始搖頭甚至嘟嘴。雖然不懂為甚麼會跟一千多只雞結怨，但是朋友所說的影響確實是有的。 &nbsp;
&nbsp;
此時越想越覺應有可能，女兒短髮，快速的忽而向左忽而向右搖頭，頭髮飛揚，就像隻雞左顧右盼的模樣。捏臉亦嘟出尖尖的嘴，也常常發出ㄛ-----的怪叫聲。整日跳來跳去，活脫脫像一只鬥雞。&nbsp;
&nbsp;
想到這裡再無疑慮，而朋友說的超渡方法與我們在“能仁凈寺”參加的法會並無違背之處，趕緊請朋友安排時間在我們家舉辦法會。 &nbsp;
法會當日依著寺里舉辦法會的模樣，在家佈置了一個莊嚴的壇城：沉香、盆花、鮮果、熱騰騰的美食與各種供品。借來十多本藥師經和蒙山施食經本，請來我的婆婆、媽媽、妹妹與多位友人，在有神通的這位朋友的帶領下，禮佛誦經。 &nbsp;
&nbsp;
這位朋友誦經的專注與精確令人嘆為觀止，一部藥師經自頭至尾無一字漏失無一處停頓，眾人也聚精會神的跟著誦經。下午我們重新煮過新的供品，恭恭敬敬的照著施食的儀軌完成普施，朋友說舉辦過的家庭法會，以這次最為莊嚴。&nbsp;
&nbsp;
女兒放學回來時法會尚未結束，她也一起參加普施。待眾人離去后，先生也開車送婆婆媽媽回家，我累累的看著整個晚上依然還是搖著頭、捏著嘴的女兒半天，無力的問她：&nbsp;
“你在吃素以前有很喜歡吃雞肉嗎？”&nbsp;
“沒有啊！”&nbsp;
“你覺得我們家在吃素以前常常煮雞肉嗎？”&nbsp;
“我覺得我們家以前吃豬肉的機會比雞肉多！”&nbsp;
“你這幾個月來做著怪樣，有想到跟雞有關嗎？”&nbsp;
女兒搖搖頭說：“我在學校裡和同學講話的時候還會這樣呢！”&nbsp;
女兒說著將兩頰的肉吸入嘴裡咬住，尖著嘴巴還上下點頭。&nbsp;
“天啊！我怎麼沒看過？”&nbsp;
“我哪敢給媽媽看到啊！” &nbsp;
“唉！怎麼辦呢？你也素食快二年了，我們法會也辦了，你的問題也沒解決，哪來一千多只雞啊！”我不僅陷入沉思……..突然，腦中靈光一閃：“會不會是雞蛋！” &nbsp;
&nbsp;
婚前不闇廚藝的我，婚后亦無多少長進。在我生這大女兒時，婆婆在我生產當日就送來雞湯煨蛋，湯鍋只有六個蛋，沒有雞肉。“啊！六個蛋怎麼吃啊！” &nbsp;
&nbsp;
“生蛋要補蛋！在我們家鄉，產婦坐月子每天就是吃雞蛋！你看雞蛋多有營養，一只雞蛋就可以孵出一只雞！”之后婆婆每天都要我吃蛋，雖然我也請別人幫忙吃，但是一坐完月子，我的膽固醇就過高，不敢多吃蛋了。&nbsp;
而女兒一到書上說可以吃1/4蛋黃的時候，我就迫不及待的喂她。照著書上增加到全蛋，每天絲毫不敢怠慢。蒸全蛋時，要用溫的高湯或雞湯打入雞蛋再加些青菜，以保鮮膜包好再蒸。每天下班一進家門，就要問菲傭女兒蒸蛋吃了沒？ &nbsp;
&nbsp;
即使假日帶她出遊，也要帶一個白水煮蛋，當日一定讓她吃完。我對煮食非常沒信心，雖然自己對食物很不講究，但是對女兒的營養可不能馬虎，只要她一天吃進一個雞蛋，我就放下心了，其他再隨意補充一些食物即可。 &nbsp;
&nbsp;
如此到她快五歲時，先生與我接觸了佛法，雖然沒有馬上改為素食，但食物也漸漸清淡，對於女兒吃蛋就沒那麼緊逼盯人，但還是覺得幾天沒吃肉沒關系，幾天沒吃蛋要補充才安心。在戒除肉食后，一直沒辦法完全不吃蛋。 &nbsp;
&nbsp;
女兒七歲半時，不知情的上慧下深法師給我一卷訪談賴金聲居士的錄音帶。職業是醫院檢驗師的賴居士隨機四處買來盒裝一盒10個的雞蛋，以恒溫26度孵化。從一開始的孵出五只雞到漸有經驗后，每盒都可以孵出八只雞左右。 &nbsp;
&nbsp;
我聽后真覺得不可思議，一般貨架上的雞蛋，不都是生蛋雞下的蛋，養雞場裡應該沒有公雞才對，怎麼還能孵出雞來？師父提倡素食不遺餘力，我們亦僅遵教誨，惟獨對於吃蛋，還是存著疑問，覺得吃的只是“胚蛋”，沒有殺生問題。聽了錄音帶后，才毅然斷念再吃蛋。&nbsp;
之前擔心女兒們有很多含蛋的麵包糕餅不能吃會讓她們產生大煩惱，沒想到跟她們溝通后，她們就很自然的會去確定糕餅有無含蛋，不含蛋才吃，之前真是太小看她們了。 &nbsp;
&nbsp;
大女兒在吃素之前已有嚴重鼻子過敏的毛病，吃素之后較為好轉。而二女兒在一歲半時我們已接觸佛法，何況我對二女兒所花的心力確實不如老大，沒那樣窮兇極惡的盯著她吃蛋。 &nbsp;
&nbsp;
雖然西醫曾說二女兒也有過敏性鼻炎，但是也只有感冒時流流鼻涕，過后就好了。如果真的是因為吃雞蛋的業因，殺害了雞隻眾生，那大女兒這一世所吃的雞蛋說是二千個也不無可能。&nbsp;
“一定是吃雞蛋的緣故，女兒啊！你這輩子已經吃了一千多個雞蛋了！”“我吃了一千多個雞蛋哪！” &nbsp;
&nbsp;
“是啊！從你才幾個月大，媽媽就天天喂你吃雞蛋，即使出去玩也不放過，你記得你每天要吃蛋嗎？” &nbsp;
&nbsp;
女兒搖搖頭，她每天只顧玩，不記得這些。&nbsp;
“媽媽真懺悔，為了自己的孩子，去吃別人的孩子。傷害了這麼多眾生，讓你擔了這麼多罪業，還每天對你發火。媽媽現在對這些眾生懺悔，還要向你道歉！”女兒只是呆呆的看著我。 &nbsp;
&nbsp;
隔天女兒一覺醒來，頭也不搖了，也不去捏嘴了，所有的怪毛病一夕之間通通不見了。我看著她跑來跑去，沒向她提醒她的毛病怎麼都好了。 我心理真是百感交集。一場豐盛的法會，若對我們所傷害的眾生不起懺悔之心，只是想超渡她們的話，誦再多的經咒，供再多的供品都無太大意義。 &nbsp;
&nbsp;
寺里每月朝山的活動意義甚大，每一拜的懺悔文中，對我們所傷害的眾生懺悔，才能讓他們放下執著，隨著佛菩薩往生善處。而我們在日常生活中所遇到令我們憤怒的事，追根究底自己亦難辭其咎。 &nbsp;
&nbsp;
我想起在大女兒之前，曾有一次懷孕。雖然先生與我年齡已然不小，因為才結婚半年，對於這位不速之客不甚歡迎。不料在得知懷孕才3周，等於胎兒才7、8周大，半夜突然出血到醫院掛急診，還未見到醫生就到洗手間，毫無痛苦的產下一個完整的紫紅色的胚卵在馬桶裡，隨后又產下一個小小的胎盤。 &nbsp;
&nbsp;
出來后告訴先生，我已經流產了，生下一個大型的蛋。雖然如此，還是得上手術房，醫生說我先前果然已經排得很乾淨。出了手術房我就開始哭，雖然從未歡迎過這個孩子，流產卻讓我難過許久。&nbsp;
我想孩子應該是貪著父母的愛才會來。之后我們開始期望孩子再回轉，再過了半年才懷了這個大女兒。&nbsp;
&nbsp;
近日從電視新聞報導得知，為提高蛋雞之產蛋量，雞農定期幫母雞在脖子上打賀爾蒙，並注射公雞的精子進蛋雞的產道，一只公雞取得的精子可以分打到十只母雞身上，以刺激母雞不斷的下蛋，這是所有的養雞廠都普遍使用的方法，難怪盒裝雞蛋可以孵出小雞。 &nbsp;
&nbsp;
目前吃蛋奶素者，有人不相信市售盒裝雞蛋可以孵出小雞，有人相信可孵出雞仔，但說只要不去孵它就不會有血腥。所有動物的胎兒，原始都是一個卵泡。每一個雞蛋都是母雞的孩子，試問母雞會不會同意我們吃它的蛋？即使這個蛋可能孵不出小雞。 &nbsp;
&nbsp;
感謝佛菩薩讓我因此因緣有所領悟，更藉此告訴大眾，“雞蛋絕對不可以吃！～雞卵之食否，聚訟已久，然明理之人，決不以食為是。好食者，巧為辯論，實則自彰其愚。&nbsp;
&nbsp;
&nbsp;
&nbsp;
凡屬有知覺者，皆不宜食，雖無知覺，然有生機，如各種蛋，亦不宜食。牛奶食之無礙，然亦取彼脂膏，補我身體，亦宜勿食。”—《印光大師文鈔續編•卷上》頁81。復鮑衡士居士書。 &nbsp;
