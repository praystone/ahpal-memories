【原創】吃素、放生治好了我的憂鬱症和社交恐懼症<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp; &nbsp; 我今年30歲。我曾是個很憂鬱的人，而且極怕與人交往，見到人說不出話，也不敢看別人的眼睛（這在心理學上可能稱之為“社交恐懼症”）。這使我在中學，大學期間幾乎沒有什麼朋友，常常一個人獨來獨往；畢業工作後，在公司也沒什麼朋友，許多員工喜歡的公司聚餐，旅遊，對我來說，卻是一種煎熬，一種令我避之不及的事情。也因為不會與人溝通，工作中常常覺得很辛苦很壓抑，有一種四處碰壁的感覺。因此，我是辭了一家又一家，沒有一家能做長久的。那種痛苦，沒有經歷過的人，是很難體會到的。我多次情緒低落到，想自殺，但幸好，我聽說，在宗教中，說自殺是要下地獄的。就因為這個信念，使我守住了底線，再怎麼痛苦，都沒走出那一步。

&nbsp; &nbsp; 期間，我試過種種的方法，希望解除我的痛苦：看社交的書（比如卡耐基的書，還有象《心靈雞湯》等等），看心理醫生，學氣功，但這些基本沒什麼效果。應該說，卡耐基的書是不錯的了，但在我的頑症面前顯得根本無能為力。可是，我卻記住了書中的一句話，大意是，當你嘗試去幫助別人時，你會慚慚忘記甚至治癒你的痛苦。就因為相信這句話，我試著去做點力所能及的善事，比如，捐錢給災區，做義工等。當時，我是很積極的，有時是冒著中午的烈日去孤兒院。因為，我的痛苦讓我覺得，只要能治癒，我什麼都願意做。我希望通過做這些事情忘掉自己的痛苦，使自己變得快樂些。事實是，這些善事有時會暫時使我的心情好了一點點，但實在說，沒有治癒我的憂鬱和社交恐懼，長時間下來，我對自己的症狀有點絕望了，但我還是一邊痛苦一邊繼續做著。功不唐捐，這句話是千真萬確的。事情在2006年底有了轉機。

&nbsp; &nbsp; 我那時身體不太好，每天坐在辦公室裏，也沒幹什麼事，但一會兒就覺得人非常疲倦。我每天回到家，最常說的一句話就是“身心疲憊”。有一天，我聽說 ，多吃香蕉可以令人精神愉快，吃素食可以令人身體好精神好。於是，我當即就決定開始吃素食了。我那時是很乖的，不管什麼方法，只要說能夠解決我的問題，我就照做。這樣過了一段時間，精神確實是好了不少，不容易疲憊了。後來。為了“積福”，我又做過其他一些善事。轉眼到了2007年5，6月間，我為了實現自己的某個願望，又投機取巧地在網上捐錢做善事。這時，我在網上發現了“放生三年了”這篇文章。裏面的內容吸引了我（雖然我本人不炒股也不支持炒股）。然後，我用“放生”在網上搜索，看到了更多文章，紛紛說他們放生後的身心，環境的變化。我敏感地感覺到，我生命的轉機來了。

&nbsp; &nbsp; 於是，我決定開始放生。下班後，我去市場買了青蛙，在雨中為它們念了佛號（這是網上的文章教的），然後放到動物園裏。這是我的第一次放生。那天晚上，我的心情前所未有的好。於是，我決定，以後要一直放，一直放。然後，我幾乎每週末，都和另一位朋友提著水桶去放生，我們多數是放泥鰍，塘虱，生魚和鯽魚（其實，我想放更多種類的，但苦於對動物的生活習性不太瞭解，不敢隨便往江裏放）。我們象打遊擊一樣，有時在這裏放，有時在那裏放；有時在這檔買，有時在那檔買。因為，我們不想被人發現，以免這邊放完，那邊別人就來捕撈。我們的放生工具也有了改進,第一次用塑膠袋,發現一漏水根本沒辦法,很被動;後來就改用小水桶,桶蓋上打N個孔給動物透氣;再後來,一次水退潮,發現,原來平時江邊的水並非很深的,淺淺的水下就有很多石頭.這樣把魚倒下去,也不知魚會不會受傷,於是,我們又改進了一下,在桶上方和下方分別綁上一條繩子,提著上方的繩子,象打水一樣把桶放下江去,桶下降到接近江面時,把下方的繩子一提,水桶就倒過來,魚兒就掉下去了).有時，我上班心情不好，下班後，我就自己一個人去放，放完回來，心情也變好了。一般人，心情不好會選擇去旅遊，我心情不好就去放生。

&nbsp; &nbsp; 放生的效果真是不可思議。大約四個月後，我突然發現，我的憂鬱不知跑哪去了，我經常可以發自內心開心地笑了。而且，也不怕人了。雖然，我還是不擅長與人交際，但“不擅長”與“害怕”，已經是天淵之別了！！！

&nbsp; &nbsp; 我同時發現，工作也順手了不少。另外，人緣也慢慢變好了,一些以前不太找我玩的朋友，也開始來約我了。（不過，這時，我反而不太想出席了，因為，一去就要花錢。我嘗到了甜頭，更願意把錢省下來放生。）以前，我看到別人週末就會和一班朋友去玩，而自己總是一個人孤孤單單的，非常苦惱，現在卻沒有這種感覺了。

&nbsp; &nbsp; 現在，我放生很堅定，每週都去。而吃素，也是我要堅持一輩子的事情。

&nbsp; &nbsp; 至於吃素，放生為何會有這樣神奇的效果，我不太會說（我只會說，至少是，你給其他生命快樂和新生的機會，作為反作用力，你自己也得到快樂和新生），反正就是有。如果各位朋友有興趣，可以上網搜索一下“放生的功德”，歷代大師的話會更令您信服。

&nbsp; &nbsp; 我在此可以告訴大家，上面的話，句句是真，都是我的親身經歷。我在這裏寫出來，就是希望，我能夠走出憂鬱，大家也能夠走出憂鬱。如果您不信，就把它當故事看一看；但如果您試過種種的方法，還是解決不了您的問題（就象我以前一樣），不妨也可以試一試。吃素，放生，堅持上一年半載，您回頭看看，您是不是有了變化？

&nbsp; &nbsp; 如果有十個朋友看這篇文章，其中有一個人去實踐，並得到利益，那我就沒有白費功夫了。謝謝大家！
