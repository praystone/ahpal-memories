我本人不是在臺灣皈依的。
皈依多年，這是我第一次見到上師，我內心十分感動。

看到大家有那麼多機會能夠親近上師，我實在是無比的羡慕。

上師曾開示：「密咒是一切諸佛如來所有功德的體現。」

但我總是有些懷疑。

&nbsp;

像觀世音菩薩心咒：六字大明咒，區區六個咒字，

怎能總攝觀世音菩薩的一切功德？

&nbsp;

但是後來我有一個特殊的因緣，

使我對上師的開示，生起無比的信心。

現在我就把我的親身經歷與大家分享。 


我有一個小外甥，今年已是21歲。

大概在十年前，當時他還是十歲大的小男孩。

那時我正在外地讀書，過農曆春節時，我回家看我媽媽，

我隨身帶著「金剛經」與「普賢菩薩行願品」，

在家沒事時來讀經。

&nbsp;

有一天，我在讀「金剛經」，

這小男孩蠻怪的，就來坐在我旁邊，閉著眼睛聽。

我出聲的讀，我想讓這小孩聽聽金剛經，也許對他有點好處。

&nbsp;

讀完了一遍，他對我說：

「老舅，你剛才在讀經的時候，我發生了這麼一件事。

我的眼睛前有一道白光，

從遠而近，打著轉，一下子呼一聲，就鑽進我眼睛裏去了，

然後緊接著四，五道光團也都鑽進來，

突然我的眼前就好像電視螢幕一樣，一下子非常光亮清楚。」

&nbsp;

他說：「我就看到另外一個世界的情況。」

他說：「我看見了有一個佛，周圍圍繞著很多僧人在聽。」

&nbsp;

我當時蠻吃驚的，但我還是覺得是不是他想出來的，

胡謅的，我還不怎麼相信。 


然後我開始讀「普賢行願品」，在我讀完了一遍後，

他就告訴我：「老舅，你在讀這部經的時候，來了一個菩薩。

他說這菩薩蠻怪的，騎著一隻大白野豬，

這個野豬也挺怪的，雖然是個豬，但是它的腿上下一樣粗。」

&nbsp;

我說：「這個上下腿一樣粗的應該是大象。」

他說：「對好像是大象，它特別大。」

我說：「我再讀一遍，你再看看。」

接著我又讀完了一遍，

然後他說：「老舅，這回我看清楚了，真是一個大象。

　　　　　　這個大象的毛，我都能看的清楚。

　　　　　　並且這個大象很怪，一邊有三隻牙。」

&nbsp;

我這個十歲大的外甥，當時根本沒有接觸任何有關佛教的東西，

我們家裏頭其他人也不信佛，也沒有供奉佛像等等。

&nbsp;

我當時感到非常吃驚，

一個小孩不能想出一邊有三隻牙的六牙白象，

這六根牙白象微著圓滿的六波羅密。

&nbsp;

他接著說：

「你在讀經的時候，這個菩薩手中拿著一個小瓶，

　往你身上倒水，然後這些水都變成了光，把你身體都照亮了。

　那大白象也往你身上噴水，

　那些水到你身上，也都變成光，

　把你身上污穢的東西，都給洗淨了。」

&nbsp;

　這個事情發生後，讓我不得不信，

　原因是我覺得一個小孩，

　他沒有辦法編造出一個有六隻牙的象，

　因為在我們現實生活裏沒六隻牙的象。

&nbsp;

這個事情讓我很吃驚。當時我很喜歡念「楞嚴咒」，

這個咒很長，我就念後面那個心咒，我很喜歡念。

&nbsp;

有一天我在念這個楞嚴咒的時候，

我的外甥又跑過來跟我說：

「老舅，你在念這楞嚴咒的時候，我看見了這麼一幅景象。」

&nbsp;

他說：「你坐在中間，你的一左一右，站著兩個大天王，

　　　　個子非常的巨大，比你高的多，看起來非常有力量，

　　　　你的外邊站著四個人，這四個人我認得是四大天王。」

&nbsp;

我說：「你怎麼認得？」

他說：「這四個人手中分別拿著琵琶，寶劍還有傘等等。」

&nbsp;

他說：

「我看卡通片西遊記裏有這四大天王，

　　　　所以這四個人我認識。

　　　　然後在這四天王外面，還有好多的各色各樣天神，

　　　　身上的穿著都不一樣，有的上頭還沒穿衣服，

　　　　長得都很怪，

　　　　但是我覺得他們都挺好，好像是來保護你的。

&nbsp;

　　　　在這些天神的外面，還有一層，

　　　　這一層是無量無邊的，就像秋天稻田地裏的稻穗，

　　　　漫天金黃色，個個穿著整齊，宛若士兵，

　　　　手裏都拿著棒子及武器，

　　　　隨著你不斷念咒，越來越多，密度越來越大。

&nbsp;

　　　　除此之外，在你身後還站著一個菩薩，

　　　　這個菩薩非常高大，身上纏著蛇，臉是藍色的，

　　　　還長了好多疙瘩，

　　　　嘴裏的牙也是往上翹的，背後還冒著火。

&nbsp;

　　　　這個菩薩太高大了，我看就像山一樣地高，

　　　　長的非常醜非常的恐怖，

　　　　但是好像這所有的天神及士兵，都是他佈置的，

　　　　受他號令的。」 


這個事情更讓我吃驚，吃驚在那裏呢？



&nbsp; 

在「楞嚴經」裏，世尊宣說了楞嚴咒，並講述了該咒種種的功德。

&nbsp;

當時，經文裏記載，

有梵天及帝釋天，從座而起，誓言在未來世，

若有人受持的話，我們就要保護他，

做他的護法，令他去除障礙，一切所求如願。

&nbsp;

可能就是我小外甥，所看到在我左右這二位。

在梵天與帝釋天後，又有四大天王起身誓言，

我們也要保護這樣的修行者，令他去除障礙，一切所求如願，

這就是我小外甥所看到的四大天王。

&nbsp;

緊接著四大天王後，又有數不盡的山河神只，

也都紛紛站起誓言，我們也要保護這樣的修行者。

&nbsp;

最後是有八萬四千那由他俱只恒河沙金剛藏王菩薩，

暨其無量無邊的眷屬，一起在世尊前誓言，

我們也要保護這樣的修行者，

若是有人來搗亂的話，我們就用寶杵，

把他腦袋打的像微塵那樣錘碎。

&nbsp;

八萬四千那由他俱只恒河沙，

是個譬喻的數，意思是無量無邊，

一那由他是一萬億，一俱只是一百億，

再乘以恒河沙，

這是無量無邊的金剛藏王菩薩，要來護持這個咒語。

&nbsp;

我的小外甥，把這無量無邊的金剛藏王菩薩，

描述成秋天稻田地裏的稻穗，無量無邊閃耀的金黃光。 


這個事情給我很大的震憾。

我在想，我們這六道凡夫，貪嗔癡如此深重，沒有任何功德，

憑什麼我們在念咒時，

這麼多金剛，這麼多天神，這麼多神只還要來保護我們呢？

&nbsp;

我唯一的解釋是他們來護持這楞嚴咒。

&nbsp;

楞嚴經上說：

&nbsp;

「這楞嚴咒生出十方一切諸佛，

　十方諸佛因此咒得成無上正覺，

　十方諸佛因此咒得降伏一切諸魔外道，

　十方諸佛因此咒坐寶蓮花應微塵國，

　十方諸佛因此咒於微塵國轉大車輪，

　十方諸佛因此咒能於十方摩頂授記等等難以言盡的功德，

&nbsp;

　這楞嚴咒就是十方諸佛如來的心，

　有此咒的地方就是有佛，

　誰要念誦此咒，即能與佛相應，

　所以一切金剛護法就來保護他。」

&nbsp;

我是學科學的，一切講求實證，若是沒有親身經歷，

我對佛經及密咒的一切功德，不能夠起堅定的信心。

&nbsp;

但這事是出自一個十歲小孩的嘴裏，

他又沒有任何這方面的知識，

我相信沒有一個人能編得這樣一幅情景，

與經文上所載情形竟是如此地一致。

&nbsp;

此時我才堅定的相信，佛經所講的話，句句實言，

如「金剛經」

所言：「如來是實語者，如語者，不誑者，不異語者。」

&nbsp;

以前我讀經較注重義理，對於經上所載種種功德，

心想大概是世尊想要我們相信所編出種種的場面及故事，

來善意地引導我們去修，

心裏並不怎麼相信，

但經這小孩一講，我沒有辦法去否定這件事。

&nbsp;

我學科學的，我要否定這件事，

我必須找證據及理由來駁斥它，但我沒有辦法來駁斥。
