今天起把壓抑的愛說出來

&nbsp;

與妳相遇的季節

&nbsp;

記載學會坦承的春天

&nbsp;

擁有著快樂的今天

&nbsp;

會帶來同樣快樂的明天

&nbsp;

這樣的時光會持續下去

&nbsp;

我深信不疑

&nbsp;

哪怕今天有再多的無奈

&nbsp;

哪怕明天同樣會掉下淚

&nbsp;

或許未來的某一天

&nbsp;

可以回首思念這段回憶

&nbsp;

四季不斷自顧的獨自變換

&nbsp;

在這樣多變的季節裡

&nbsp;

我們生存在此時此刻

&nbsp;

到底該做些什麼

&nbsp;

珍惜彼此

&nbsp;

將愛全釋吧
