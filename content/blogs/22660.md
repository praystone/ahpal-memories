你有沒有一個屬於自己的『後台朋友』

&nbsp;



&nbsp;

這是一篇非常好的文章，因為我們都已社會化深了，

&nbsp;

所表現出來的都是想要別人羨慕的一面，不

&nbsp;

好的都只想沉默或暗自憂傷，夜深人靜時真的需要好好想想，


不論是最親密的配偶也好、知心朋友也罷！


你所交的朋友中是否有這種人呢？

&nbsp;

你有沒有一個屬於自己的『後台朋友』

&nbsp;



&nbsp;

莎士比亞說：「人生如舞台。」

&nbsp;

人有前台，也有後台。

&nbsp;




&nbsp;


前台，是粉墨登場的場所，費盡心思，化好了妝，穿好了衣服，

&nbsp;

準備好了台詞，端好了架式，調勻了呼吸，一步步踱出去，

&nbsp;

使出渾身解數；該唱的，唱得五音不亂；

&nbsp;

該說的，說得字正腔圓；

&nbsp;

該演的，演得淋漓盡致；

&nbsp;

於是博得滿堂彩，名利雙收，

&nbsp;

然後躊躇滿志而回。

&nbsp;


&nbsp;&lt;/ DIV&gt; 
然而，當他回到後台，脫下戲服，卸下妝彩，

&nbsp;

露出疲累而飢黃的臉部，

&nbsp;

後台有沒有一個朋友在等他，

&nbsp;

和他說一句真心話，道一聲辛苦了，

&nbsp;

或默默交換一個眼色，這個眼色，

&nbsp;

也許比前台的滿堂彩要受用、而且必要！


&nbsp;

人有沒有這樣的朋友，很重要。

&nbsp;

後台的朋友，是心靈的休息地。

&nbsp;

在他面前，

&nbsp;

不必化妝，

&nbsp;

不必穿戲服，

&nbsp;

不必做表情，

&nbsp;

不必端架子，

&nbsp;

可以說真心話，

&nbsp;

可以說洩氣話，

&nbsp;

可以說沒出息的話，

&nbsp;

可以讓他知道你很脆弱、很懦弱、很害怕。


&nbsp;

每次要走出前台時都很緊張、很厭惡，

&nbsp;

因為你確知後台朋友只會安慰你，

&nbsp;

不會恥笑你，不會奚落你。

&nbsp;

況且，在他面前你早已沒什麼形象可言了，

&nbsp;

也樂得繼續沒形象下去。


&nbsp;



&nbsp;

人生有一個地方，有一個人，

&nbsp;

在這人面前，

&nbsp;

可以不必有出息，

&nbsp;

可以不必有形象，

&nbsp;

可以暴露弱點，

&nbsp;

可以全身都是弱點，

&nbsp;

這是很大的解放。

&nbsp;


有此解放，人乃可以在解放一陣子之後，

&nbsp;

重拾勇氣，重披戲服再次化妝，

&nbsp;

端起架子，走到前台去扮演該扮演的角色，

&nbsp;

做一個人模人樣的人物，

&nbsp;

博得世俗的讚美，獲得功成名就的利益。


&nbsp;

話雖如此，後台朋友並非任何人隨處可以找到。

&nbsp;

親如夫婦，往往還不能成為「休息地」，

&nbsp;

這可視為人的弱點不堪披露。

&nbsp;

可見人無論生死，都很難找到「後台朋友」，

&nbsp;

因惜」，


&nbsp;
