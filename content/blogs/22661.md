&nbsp;

有如秋楓灑落散盡時

&nbsp;

如夢一般&nbsp; 與妳相遇的奇蹟

&nbsp;

彼此相愛 &nbsp;&nbsp;&nbsp; 

現在倆人一同克服著&nbsp;&nbsp; 心中的障礙

&nbsp;

就算轉世再生&nbsp;&nbsp; 也要在妳身旁&nbsp;

&nbsp;&nbsp;&nbsp; 

不斷守護著&nbsp;&nbsp; 無論是哭&nbsp; 是笑妳的表情

&nbsp;

感謝我倆的相遇

&nbsp;

因為愛而變得更堅強

&nbsp;

妳為我留下的記憶&nbsp; 即使歲月會流逝

&nbsp;

也會不失光彩的在我心裡

&nbsp;

這就是幸福&nbsp;&nbsp; 抱緊妳&nbsp;&nbsp; 能夠讓我忘卻煩憂

&nbsp;

一個遙遠的未來

&nbsp;

一個深切的情感

&nbsp;

妳我想必在更早以前

&nbsp;

已為了相遇許下愛的諾言

&nbsp;

屬於我們的明天

&nbsp;

屬於我們的愛戀

&nbsp;

編織一場幻想的夢

&nbsp;

讓不盡的幸福

&nbsp;

支持所有
