妻子、情人、紅顏知己


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


什麼是妻子？


&nbsp;


就是你願意把積蓄交給她保管的女人。


&nbsp;


&nbsp;


&nbsp;


什麼是情人？


&nbsp;


就是你偷偷摸摸地去和她約會


&nbsp;


又怕妻子撞見的女人。


&nbsp;


&nbsp;


什麼是紅顏知己？


&nbsp;


就是你能把有些秘密說給她聽


&nbsp;


卻不能說給妻子聽的女人。


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


妻子是一種約束，


&nbsp;


約束你不能隨便和別的女人交往；


&nbsp;


&nbsp;


&nbsp;


情人是一種補償，補償你想從妻子


&nbsp;


那得到卻又無法得到的激情；


&nbsp;


&nbsp;


紅顏知己就是一種點撥，點撥你心中的迷津。


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


妻子陪你過日子，


&nbsp;


情人陪你花鈔票，


&nbsp;


紅顏知己陪你聊聊天。


&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


妻子不能替代情人，因為她沒有情人有情調；


&nbsp;


情人不能代替妻子，因為她沒有妻子的親情；


&nbsp;


妻子和情人都代替不了紅顏知己，


&nbsp;


因為那是心靈的需要。


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


妻子是一個和你沒有一點血緣關係的女人，


&nbsp;


卻為你深夜不回家而牽腸掛肚；


&nbsp;


&nbsp;


&nbsp;


情人是一個和你沒有一點家庭關係的女人，


&nbsp;


卻能讓你盡情消魂；


&nbsp;


&nbsp;


&nbsp;


紅顏知己是一個還沒和你扯上關係的女人，


&nbsp;


卻能分擔你的快樂和憂愁。


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


妻子是一個家，


&nbsp;


是一個能給你浮躁的心


&nbsp;


帶來安撫的港灣；


&nbsp;


&nbsp;


&nbsp;


&nbsp;


情人是家的累贅，


&nbsp;


只是不到萬不得已你不想甩掉；


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


紅顏知己是家的點綴，


&nbsp;


沒有她你不會覺得寂寞，


&nbsp;


但你會覺得生活沒意思。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


妻子的關心像一杯白開水，


&nbsp;


有時會成為一種嘮叨，


&nbsp;


只是在生病時才成為一種溫馨；


&nbsp;


&nbsp;


&nbsp;


情人的關心就像在白開水裡加了一勺糖，


&nbsp;


慢慢地品上一個晚上還不滿足；


&nbsp;


&nbsp;


&nbsp;


&nbsp;


紅顏知己的關心就像工作到午夜


&nbsp;


喝一杯香甜的咖啡，越喝越提神。


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


妻子懷上你的孩子會深情地問你想要


&nbsp;


個男孩還是要個女孩，


&nbsp;


&nbsp;


&nbsp;


&nbsp;


情人懷上你的孩子會哭著來問你


&nbsp;


該怎麼辦怎麼辦啊？


&nbsp;


&nbsp;


&nbsp;


對於紅顏知己，你會把你情人懷孕


&nbsp;


的消息告訴她，


&nbsp;


並問她你該怎麼辦。


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


至於妻子，你會在她發現你的情人


&nbsp;


肚子大了的秘密後才告訴她：其實


，


我早就想告訴你了。


&nbsp;


然後拼命地向她解釋，並作可憐狀。


&nbsp;


&nbsp;


&nbsp;


妻子回了娘家一個星期不回來你也不想，


&nbsp;


&nbsp;


情人一天不見你就給她打電話：上哪去了？


&nbsp;


今晚我們到老地方喝杯咖啡好嗎？


&nbsp;


&nbsp;


心中有了苦悶，


&nbsp;


你最想找紅顏知己傾訴，


&nbsp;


告訴她你在妻子和情人之間疲於奔命，


&nbsp;


實在受不了了。


&nbsp;


&nbsp;




&nbsp;


&nbsp;


最讓男人受不了的是


&nbsp;


妻子的嘮叨，


&nbsp;


情人的眼淚，


&nbsp;


紅顏知己的誤解。


&nbsp;


&nbsp;




&nbsp;


妻子的嘮叨使男人的心亂上加亂，


&nbsp;


情人的眼淚讓男人已硬的心變得酥軟，


&nbsp;


紅顏知己的誤解把男人的心由懸崖推進深谷。


&nbsp;




&nbsp;


&nbsp;


&nbsp;


最好的妻子，就是男人能從她身上找到情人


&nbsp;


和紅顏知己兩種相互交織的感覺，


&nbsp;


只是這種感覺男人很難找到。


&nbsp;


&nbsp;


&nbsp;


最好的情人是在你和她的關係被妻子發現


&nbsp;


而主動退出又不提任何要求，


&nbsp;


只是情人很難做到這點。


&nbsp;


&nbsp;


&nbsp;


最好的紅顏知己是有一天她能成為情人，


&nbsp;


甚至妻子，


&nbsp;


只是這種想法很難實現。


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


如果有可能，


&nbsp;


男人都想把紅顏知己變成情人，


&nbsp;


如果再有可能，再把她變成妻子。


&nbsp;


只是變成妻子的紅顏知己


&nbsp;


就不再是知己了


&nbsp;
