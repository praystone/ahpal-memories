最近一直想做新的主頁風格，所以稍微研究了一下 CSS 語法，
但是爬了許多文都沒發現有人發表類似的文章，
所以總覺得對"進階"想設計主頁的人是一大門檻。

首先我這篇是針對"火狐"(Firefox)的使用者(因為IE比較麻煩= =")
且對CSS有基礎概念的人，要找主頁各地方的"選擇器"名稱，
所提供的一個方法，我目前都是用這個方法，
因為過去總是因為不了解想改的地方的"選擇器"四處求助，
也間接給其他 人添麻煩 = ="
所以在此發這篇文章，跟大家分享我的心得=^.^=
PS:之所以針對"火狐"(Firefox)是因為只有火狐才有這個功能 [0427 0026 補充]

原始碼當中的

&lt;div id="space_info"&gt;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp; 
ID 就是選擇器 這裡直接看就是 #space_info
ID 就是在開頭加 #&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
例如: &lt;div id="space_avatar"&gt; 可看做 #space_avatar (這是頭像的選擇器)

&lt;h3 class="feed_header"&gt;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
class 是在ID裡面的子選擇器 這裡直接看就是 .feed_header 
class 就是在開頭加&nbsp; .&nbsp; (點)&nbsp;&nbsp;&nbsp;&nbsp; 
例如:&lt;li class="dropmenu" id="ucappmenu" onclick="showMenu(this.id)"&gt;
&lt;a href="javascript:;"&gt;站內導航&lt;/a&gt;
可看做 .dropmenu (這是最上面的 "站內導航")
當然.......他裡面本身就有 id="ucappmenu" 所以用 #ucappmenu 也可以

接者來看

&lt;div id="space_info"&gt;
&lt;h3 class="feed_header"&gt;

&lt;a linkindex="35" href="cp.php?ac=profile" rnclass="r_option"&gt;完善資料&lt;/a&gt;

個人資料&lt;/h3&gt;

這一整段當中 class="r_option" 代表者 #space_info .r_option 
#space_info .r_option 是"完整資料"的選擇器(標題欄右邊的連結)
這裡之所以要在前面加一個 #space_info 是因為他是 #space_info 裡面的一個子選擇器，
假如不詳細定義 #space_info 的話，單單只有 .r_option 會被視為全部的標題欄右邊連結

到這裡你可以用下面這些做實驗即可了解，(我不附圖是要讓你們自己做實驗)

#space_info .r_option&nbsp; {visibility:hidden;}&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 這是隱藏標題欄右邊連結
.r_option&nbsp; {visibility:hidden;}&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 這是隱藏所有標題欄右邊的連結

再來看
&lt;h3 class="feed_header"&gt;

&lt;a linkindex="35" href="cp.php?ac=profile" rnclass="r_option"&gt;完善資料&lt;/a&gt;
這段當中還有一個值得注意的地方就是&lt;a ..........&lt;/a&gt;
這個意思是"完整資料"他是 .feed_header 當中的連結，也就是 #space_info .feed_header a
#space_info .feed_header a&nbsp;&nbsp; 這是個人資料標題欄當中的所有連結(就一個而已......汗")

所以 
#space_info .r_option 
也可以用
&nbsp;#space_info .feed_header a 
來代表

#space_info&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 就是整個"個人資料"欄整體
#space_info .feed_header&nbsp;&nbsp;&nbsp; 這個是個人資料的整個標題欄
#space_info .r_option&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 這個是個人資料標題欄右邊的"完整資料"
#space_info .feed_header a 這個也是個人資料標題欄右邊的"完整資料"

到這裡應該可以理解大部分的選擇器怎樣找了
接者在給你們一些語法去做實驗:

#space_feed {border-style:dotted;color:#006600}
這是在個人動態加邊框且將顏色設成綠色(邊框預設是黑色)，
及直屬這"選擇器"的文字改成綠色，
邊框右邊會不見是因為預設的欄位比較大，

所以右邊被擋住了，可以改成這樣 
#space_feed {border-style:dotted;color:#006600;width: 500px; height: px;}
就知道意思了

#space_feed div {border-style:dotted;color:#006600}
這就有點複雜了...這是指屬於 #space_feed 裡面的所有"物件"
不過既然是物件，就會有"選擇器"名稱(就是 .????? )，
所以這段只是要讓你們參考罷了，
下面這些給你們當成功課，記得要和原始檔做比較喔 =^.^=

#space_feed ul {border-style:dotted;color:#006600}


#space_feed li {border-style:dotted;color:#006600}

#space_feed a {border-style:dotted;color:#006600}

#space_feed img {border-style:dotted;color:#006600}
