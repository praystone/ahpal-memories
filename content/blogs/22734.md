&nbsp;


&nbsp;&nbsp;&nbsp; 這是我看到的一本小冊子，內中記錄了一個通靈人所看到的不同疾病患者的疾病來歷，希望能對大家觀察自己的病因有所幫助。這個人所看到的事實，是我們沒有天眼功夫的人所看不到的，但是許多有這個功能的人卻都能得出同樣的結論，那就是，疾病是因果迴圈的一種顯現與反映。貌似肉體的疾病卻能從另一個看不見的空間找到根本原因，這不能不說是一個奇跡，這個事實告訴我們，不要小看你身上的疾病，更不能輕視自己日常的行為。惡有惡報，善有善報，這條真理在疾病領域裏同樣適用。


&nbsp;


&nbsp;&nbsp;&nbsp; 敝人救世濟病以後得了經驗，驗出許多病患，大多與前世因果有關聯。前世所作所為皆成為今世的際遇，在冥冥之中都有天地神靈的控制。前世積德之人，今世必定安享幸福，今世不知再修福，神靈暗中削掉福祿。若是前世作惡多端，今世必定左右逢難，不如意之事時常臨身。若是今世常看聖書佛典，行之有恆，神靈會暗中削掉前世之罪行，而消災解怨，進而賜福招祥。


&nbsp;&nbsp;&nbsp;


&nbsp;&nbsp;&nbsp; 依敝人的經驗，前世做過何種罪過，今世應的何種病，敝人簡單的揭穿，請讀者大致明瞭。


&nbsp;


&nbsp;&nbsp;&nbsp; 患有長期心臟病之人，大都是前世殺人，殺畜生過多，或是做官辦案不清、誤殺善良、皆得今世心力不足，常有心腫，心跳、心氣呼喘之痛。心臟之穴脈在手的中指，敝人把脈到中指時，必有怨靈發出靈音叫著說：他前世殺我害我，我是靈冥旨前來討債，我要纏他三月、五年、十年不等，依前世所害對方之深淺，而定痛苦之日期是多少。（此脈道正說明了，靈魂的居所是心臟。如果心臟被怨靈或外來的靈體佔據，被佔據之人必然得心臟諸病，為什麼靈體都害怕外科醫生？就是因為外科醫生的手術刀，可以令附體靈體傷殘或失去討債的靈能，所以外科醫生的手術刀是非常辟邪的法器，如果是夜常作噩夢者，就可以將一把外科醫生的手術刀放在枕頭下麵，噩夢從此就可與你訣別了！）


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 患有長期風濕痛之人，大多前世棄妻拋子，另結新歡，或者前世欺辱弱者，逞強淩弱，此病痛者需鑄印善書雜誌。其功德回向給討債者，然後服下天賜藥方非常有效。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 患有長期胃腸病者，大多前世欠人銀兩不還，或是前世霸佔兄弟財產，或是搶人金銀、敝人把痛患之小指一看，必有怨靈大呼他前世欠多少銀兩，或是他前世霸佔我妻子、財產，我是領冥旨而來的。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 患有長期頭疼、頭癢、頭重之患者，敝人把到他的大拇指時，必有怨靈大呼他前世做官，辦案不清，害我入牢，或是他前世打我頭部，以至使我頭疼一輩子，今世我是來算帳的。也有的說，他前世是秀才，用刀筆害我入牢，我是領旨前來算帳的。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;患有長期肝病之人，大多是前世貪人便宜，占人物品，貪不義之財，設計貪財貪物致使人破產，生活陷入困境，今世皆得肝病。談到肝病奇觀真多，全是按照人的前世因果而定下的哪一條肝脈受阻，哪一條通脈無法迴圈而成肝癌，肝硬化，肝局部肝炎，遇到肝病之人，只要看到患者食指，必有其怨靈大呼救命：我是領冥旨而來，他欠我錢不還，或是種種被侵、被搶、被貪人之多少而定被貪人多少而定肝部病苦之輕重。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 患有腎臟病痛之患者，大都前世敗人名節，強姦好色之徒，或是殺妻納妾之輩，或是寵竊棄妻之人，依前世犯此罪惡之深淺而定病情。


&nbsp;


&nbsp;&nbsp; &nbsp;根據以上通靈者的陳述，我們可以悟出，人的食指是心臟生髮出來的脈道的延伸，“十指連心”就是說的這種情況。懂脈道學的人只要一把脈，就可以知道病在何處？而通靈者的把脈就更多了一層診斷的根據，那就是可以配合把脈，將諸病的病根徹查出來。五臟六腑的脈道均分佈在手掌及十指上，而人的靈魂的住所是在心臟裏，不管我們看到看不到，這些事實都存在！如果我們相信因果，相信善有善報，惡有惡報的真理，我們就能少患病，甚至通過善思維與善行而不患病&nbsp;，這該是多麼好的事情啊！


&nbsp;


&nbsp;&nbsp;&nbsp; 下面文章中的事實，也是這個通靈者親口講述的神奇經歷。從她講述的的真實故事中，我們應當明白，造成我們身體疾病與運氣下降的根本原因，差不多都與前來討債、算帳的隱靈有關。而只要我們多積德，多做善事，多念經，多將自己的善事功德回向給它們，長此以往，就能解開它們的怨恨，而讓陽光、自在、健康與平安重新回到我們的身邊！所以，回向是非常重要的解災程式，但願朋友們不要忘記，在自己享受幫助別人的愉悅時，還要將功德回向法界眾生，尤其是自己及家人的冤親債主啊！


&nbsp;


&nbsp;&nbsp;&nbsp; 許多靈魂的境界科學無法驗證，但敝人五年中發現的奇事不少。兩年前，有一個孕婦曾開了兩次刀，花了好多錢，過後還是處處疼痛，來到溪湖找醫生求診，在旅社住了五天錢將要花光，帶著失望的心情準備回家的時候，在旅社遇到一個跟我結識的好友，介紹他來我家，當時那孕婦心情沉重，我給她把脈時，發現她身上附著一個靈魂，那靈魂向我說：“她前世欠我三百銀元沒有還我！”我向那靈魂說：“冤冤相報，如此相纏也不是辦法，你們應該和解！”然後我向那患者說：“你前世欠人三百兩，今世做做善事。功德回向給那個靈魂，兩者都好。”她也答應了，從此以後，那個靈魂歡喜而去，孕婦也即時感到舒服，不再有身中不固定位置之疼痛發生了。


&nbsp;&nbsp;&nbsp;


&nbsp;&nbsp;&nbsp; 有一些男士患了長期風濕前來找我，我發現它們身上附有女人靈魂，經過把脈時，那人身上的靈魂會主動跟我說：“這個人前世破壞我的名聲，我非常不甘心，今特來找他算帳的！”我遇到這種病人很多，只需做些善事功德回向給討債者，有時是會不藥而愈的。多行善事可以解開冤孽苦病，這是千真萬確的。比如捐款救災，冬令助貧，助印善書等，都是善事。一善可以化解病魔的纏身。人若患有冤孽病最為難醫，都是前世不知修身所得結果，此種所謂長久病，非行善立德不可，若是遇到操勞過度所引起的病，可就會藥到病除的。


&nbsp;&nbsp;


&nbsp;&nbsp;&nbsp; 有一個孝婦來，我給她燙頭髮，我剛為她剪下第一刀時，聽到一個聲音從她的頭上發出來說：“小心一點。這個人是孝婦，我領天命，保佑她賺錢十年，我是福神。”我向孝婦說：“您平時非常孝順，您可連續賺錢十年！”那孝婦聽了非常驚奇，向我說：“你再說一遍好嗎？”我再強調說一遍，她說：“哎呀！您真靈，為什麼您全部都知道？我確實是每天都賺一千多元，因為我家種了幾棵芭樂，每天都采一擔，一挑出去賣，人人稱讚我的芭樂即甜又香，一下子就全部賣完了。真奇怪，今天摘完，想明天不多了，結果卻又是摘了一擔，每天都是一千多元的收入。”有人去請教她如何栽種，她說“自己也不知道”。善有善報，蒼天會疼愛孝順人是事實。實情文章不敢亂騙人。


&nbsp;&nbsp;&nbsp;


&nbsp;&nbsp;&nbsp; 最近有一女士，她是我家的常客，有一天，她來洗髮，帶著她孫子忙的昏頭轉向，前天看到那小孩身邊，有三位天兵護佑，哪知三位天兵向我打招呼，而自言道：“此人母親用這孩子的名義助印《地獄遊記》，祈求賜她兒子平安。”我恍然大悟，我直問那女士：“您的孫子最近比較乖嗎？”她說：“最近很乖！”我問她是不是有助印《地獄遊記》一書？婦人想了想說：“有的，她母親去辦的”。助印《地獄遊記》獲善報，真實不虛。


&nbsp;


&nbsp;&nbsp;&nbsp;佛說因果報應，真實不虛，有時敝人看到長久病患者來求問，我的眼睛打量病患者時，會聽到其人身上另一靈魂喊：“救命！救命！我是領冥旨前來討債的！”我運用靈力和討債者言談：“他是欠你什麼？”有的會說，是前世欠銀子不還，或是被殺，種種的遇害有時聽來真可怕，有時聽來真有趣兒。其怨靈每個所談的語氣皆不同，有的聽來有幽默感，有的談笑風生，現在我把所經過的略寫一些，讓讀者當故事看也好，或當因果實在報應也好。


&nbsp;


&nbsp;&nbsp;&nbsp; 有一位住在沙鹿的女士，患有全身瘙癢的病症，手一抓便有痕腫起。已有十個多月，吃藥打針均未見效。一天到台中，經朋友介紹來找我，她一進門，我就看到她身上有一條蛇，那蛇一直說：“我是領冥旨前來討債的！她前世吃我的肉，喝我的血，磨我的骨，我是一條有修養的蛇，我不敢吃小動物，平時只吃草、水，望以後能快投人身道，我的壽命未終，她看到我，即刻將我打死，然後將我的肉煮湯賣錢，拿我的骨磨粉去當藥賣，我非常不甘心，因此領一殿冥旨而來的！”我問那蛇要纏她多久，它說：“我領冥旨是一年八個月，使她花錢吃苦藥，吃到一年八個月，才往一殿交旨。”我又向它說：“冤冤相報，業業相纏，你們都痛苦，我叫她行善，將功德回向給你好不好？”它說：“那是求之不得啊！”我向病患說明前世因果病，需要行善補前世之過，過後，那病患打電話來道謝，言說她的因果病已經好了。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;有一個男孩六歲左右，家住田尾鄉，有一天他的父母帶他來找我，要求華佗仙翁賜藥方，我打量那小孩一下，身上有靈魂俯身，喊道：“救命！救命！我是領冥旨來的！他前世侵犯公款三萬元，上司誤會我偷，害我入牢，我死後非常不甘心，向二殿閻羅控告，陰司辦案無私，特賜我領冥旨前來算帳，要纏他三年整！”我說：“冤冤相報，兩者都苦，叫他行善，將功德回向給你好嗎？”它說：“那是再好不過的，真謝謝你，解開了我們之間的冤結。”其後我向孩子的父母說：“你的孩子正氣不通，鼻子常有病是不是？”他的父母說：“我的孩子鼻子時常不通，又時常流鼻血，中西藥方都無效。”我告訴他，用孩子名義助印善方，扣求蒼天賜方，解開前世冤孽病，其後，吃下藥方非常靈驗，果然藥到病除。


&nbsp;


&nbsp;&nbsp;&nbsp; 有一個彰化市人，她臉上都是黑點，今年20多歲。她從六歲出麻疹，以後臉上就長出黑斑，到現在整個臉部都是黑斑，到各處求醫都不見效，聽朋友介紹，來問有何藥方來治療，我打量她的身上，就有八個陰靈說：“救命！救命！我們是領冥旨而來的。她前世借了我們的錢，去做黑天暗地的生意，而且又沒有還錢，我們死後被閻羅整的好慘！說我們的錢借她去做犯法生意。”我說：“是什麼犯法生意？”它們說：“偷賣鴉片！”我說：“原來如此。那你們要纏她幾年？”它們答：“20年。”我說那叫她行善，其功德回向給你們好不好？”它們異口同聲地說：“求之不得！”那患者也發願，要行善補前世之過，現在她臉上的黑斑已漸漸褪化，比以前好看的多了，前世因果報應確實厲害！


&nbsp;&nbsp;&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;最近溪湖有一女士，帶著她女兒前來，叫我給她女兒看望，因她女兒今年已經28歲了，與人談婚嫁都談不成，有時將要談成又落空。我一看那小姐身上，有一陰靈說：“救命！救命!，我是領冥旨來的！她前世破壞我的因緣！”我問道：“那你纏她有多久？”它答：“已有四年了。”“那麼領旨要纏幾年？”它說“七年。”我說：“冤冤相報，實在兩者都不好，你暫時離開她，以後與人訂婚，叫她助印善書，以其功德回向給你好嗎？”那怨靈歡喜離去。不到一個月，那小姐已經訂婚了。想來真可怕，那陰靈附身，可造成血液迴圈不通，而發生身體內部各線路故障，故障原因查出以後，對症下藥。效果大都是百分之百的靈驗。&nbsp;


&nbsp;


附：凡是惡疾都是鬼在後面支配著（宣化上人）





凡是惡疾，如瘧疾、癌症等，皆由鬼在裏面支配著，令人體內五臟錯位，四大不調，都是業障鬼在作怪。因為人夙世有業障，時間到了鬼就來討債。也因為這個人的陽氣不足，陰盛陽衰，故鬼能得其便。你若能常常無煩惱，智慧現前，鬼便無隙可乘。一旦生了欲念，無明，鬼便容易鑽進來.


&nbsp;


以此類推，八萬四千個疾病，皆有前因後果。甚至蚊子咬你一口，蜜蜂蟄你一下，及其人世所遭遇的一切，都是因果互為經緯。人若明白這個道理，則一點錯事也不敢做，一做錯就要受報應。尤其是修六度萬行者，更要腳踏實地，絲毫不能行虛偽。所謂「因地不真，果招紆曲」。到果地的時候，則有很多麻煩。
因此，諸位要「隨緣消舊業，更莫造新殃。」不能有少許放逸的行為。大家要隨時隨地提高警覺。不去害人，只去利益人，便什麼毛病也不會發生，鬼也找不著你。

&nbsp;
