&nbsp;

和妳相遇是個奇蹟,不知是所謂的緣分..

&nbsp;

還是命中注定..腦海裡有許許多多的問號

&nbsp;

但疑問的卻不是對妳的感受,

&nbsp;

而是謎樣的未來

&nbsp;

一切太過珍貴&nbsp; 如果不是妳

&nbsp;

愛情怎會如此充滿色彩

&nbsp;

記得史賓賽書裡曾說,每個人生下來都有屬於自己的 禮物，

&nbsp;

那是世界上最獨一無二的。

&nbsp;

但是這份禮物，要靠自己去尋找…

&nbsp;

我是否能喜悅的說&nbsp; 我找到了呢

&nbsp;

在這所有事物都有著缺陷的世界裡

&nbsp;

對我而言妳卻是如此完美

&nbsp;

一點點的笑容

&nbsp;

一點點的依賴

&nbsp;

這些是無價的

&nbsp;

即便無法猜測未來而感不安

&nbsp;

妳我心中有數

&nbsp;

所許下的約定

&nbsp;

將會隨著時光轉換更顯清晰

&nbsp;

會記得彼此對嗎?

&nbsp;

不會忘記對方的

&nbsp;

只要我們都記得

&nbsp;

親吻彼此的感動

&nbsp;

哪怕輕閉雙眼時

&nbsp;

我們也能記住彼此

&nbsp;

愛妳永遠

&nbsp;
