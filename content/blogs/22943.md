藥師咒水不間斷強力加持法<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


首先，準備一大罐的保特瓶礦泉水。若有佛堂者將其供在藥師佛像前，若能點燈懸幡更好。礦泉水的下方放置念藥師咒的念佛機，24小時播放藥師咒，以咒音的不可思議聲波不間斷的加持礦泉水。


&nbsp;


每次取出不需太多，若1500毫升的水，可分次取出，但最後必須剩母水，不可全部取盡；之後再加入新買的水混入即可。


&nbsp;


每天念行者也念藥師咒加持，另外在每次取出服用前，再由行者念108遍（時間允許可念更多遍），加持之後，祈求藥師佛慈悲加持此水。


&nbsp;


另外也可參加藥師法會，會後若有結緣藥師咒水也可以混入此瓶水中。


&nbsp;


此法的特殊有以下幾點：


&nbsp;


（1）全天候加持：24小時播放藥師咒加持，若以我的念佛機藥師咒念誦速度而言，20秒念1遍；等於一分鐘念3遍，一小時念180遍，一天就有4320遍的藥師咒加持；若一個月就有129600遍的藥師咒加持，一年1555200遍加持。這是以念佛機咒音聲波加持的部分。（若有速度更快的念佛機就可以更多遍。可以自己找適合的檔案請念佛機廠商製作）


&nbsp;


（2）行者親自加持：行者每天都持108遍（或更多），這樣一個月這瓶水就有3240遍親自加持的效果。


&nbsp;


（3）再次加強效果：要飲用前必須再念108遍，再特別稟告藥師佛這水是為了何人何事祈求，之後就可以使用咒水，如此便能自利利他。


&nbsp;


（4）總匯加持：若參加法會結緣或有任何加持過的藥師咒水也可以加入此水中。

開示集：


&nbsp;


◎如果每日持誦藥師咒，一切諸佛菩薩與總攝一切諸佛大威勢力的金剛手菩薩、四大天王和其他護法將會一直保護並引導我們。我們的一切惡業都會淨除，迅速地息除疾病及魑魅傷害。


&nbsp;


◎因為眾生的心更墮落，一切也都更加墮落。食物和藥物的力量減退，甚至咒語的力量也削弱了。所以現在修本尊法，都必須比以前持更多的咒。


&nbsp;


不過，基於藥師諸佛往昔許諾的力量，實際上藥師咒在濁世反而更有威力。這是很有必要持誦藥師咒的理由之一。


&nbsp;


◎藥師諸佛往昔曾經許諾，濁世眾生所發的願，必定要成功。每一尊藥師佛都發過許多願，要紓解眾生的種種困境。


&nbsp;


◎眾生甚至只要聽到藥師佛的聖號或咒語，便不會墮惡趣。藥師佛法門具有強大的威力，帶來現前及究竟的成功。


&nbsp;


◎修藥師法及持藥師咒，可除病離苦。


&nbsp;


◎藥師咒具有強大的威力，不僅限於療愈疾病，也能夠淨化生者和亡者的業障。如果能夠本著菩提心，在臨終者或動物耳邊，持誦藥師佛的聖號和咒語，最好不過了，因為那將使他們不墮惡趣。


&nbsp;


◎如果亡者已經聽不見了，可以持藥師佛咒，然後直接在他們身上吹氣或者先在滑石粉、香水上吹氣，然後把粉末、香水塗抹在他們身上。


&nbsp;


◎修藥師法甚至能夠淨化亡者，把他們從苦難中救脫出來。


&nbsp;


◎持藥師佛的咒語，然後在所吃的肉上面，或死屍、死者的骨頭上面吹氣，都很有利益，可以淨除亡者的業障，使他們得以往生淨土或上界。


&nbsp;


◎如果你是肉食者，應當利益你所吃的被宰殺的動物。在吃肉之前，應當持誦這個強力的淨障咒，而且猛力地回向，使那些動物即刻脫離惡趣，往生淨土或上界，永不再墮惡趣。


&nbsp;


◎即使動物或人已經死了幾百年甚至上千年之久，心識還在惡趣，如果持誦藥師佛咒之後，在他們的骨頭上吹氣，照樣可以把心識遷移到淨土或上界。


&nbsp;


◎持誦藥師佛咒語之後，也可以吹氣在水上、沙上或滑石粉上，再灑在死亡的動物或人的骨頭或皮膚上。這麼做至少可以縮短亡者在惡趣受苦的時間。


&nbsp;


◎修藥師法不但對重病的人很有效，還會帶來事業、修行或者其他事行的成功。
