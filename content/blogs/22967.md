&nbsp;

我的愛&nbsp;&nbsp; 

&nbsp;

想看著妳的神情

&nbsp;

誘惑著我的心

&nbsp;

此刻妳在哪裡

&nbsp;

我要飛向妳心裡

&nbsp;

請將我帶到妳身旁

&nbsp;

我的愛是妳

&nbsp;

我的全部都給妳

&nbsp;

我的愛&nbsp; 請帶動我

&nbsp;

讓我飛向妳心裡

&nbsp;

思念&nbsp; 讓我無法呼吸

&nbsp;

我想給你我的一切

&nbsp;

此刻妳在哪裡

&nbsp;

我的愛&nbsp; 無論何時都在我心裡

&nbsp;

我之所以開心&nbsp; 全都是因為妳

&nbsp;

將妳擁入懷裡

&nbsp;

大聲說愛妳

&nbsp;
