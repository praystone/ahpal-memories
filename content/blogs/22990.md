簡易的設置法


既然要自行設置主頁風格，

那我在這裡提供一些設置主頁的小技巧，給大家參考，


關于注釋


CSS中的注釋非常重要。在剛開始創建CSS樣式時，應保持隨手注釋的習慣。

我習慣使用&nbsp; /* 注釋內容 */&nbsp; 的格式來寫注釋，

範例:
/*主頁的所有顯示時間的數字或文字*/
#space_page .gray {color:#fff; }
之所以要這樣做，主要是讓自己知道這段語法是甚麼東西，
當然...你也可以不設...就怕你看不懂而已...

設置背景


要如何應用CSS控制部落格背景？background-color&nbsp; 背景顏色
設置方
法&nbsp;&nbsp;&nbsp;&nbsp; 選擇器 { background-color: 顏色代碼 }
例：
/*rn主頁背景變成黃色*/
body { background-color: yellow}

background-image&nbsp; 背景圖片
設置方法&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 選擇器 { background-image: rnurll(圖片網址) }
例 : 
/*主頁
背景圖片*/
body { background-image: rnurl(attachment/201004/4/13918_1270365614wC5c.gif) }

到這里，在使用背景圖片時，一定經常碰到一些圖片因為太小，
而產生種種如圖片的重復出現而破壞了整個頁面的
美感，
想換成其它圖片又不合適之類的麻煩情況吧。不過現在好了，
大家只要用了以下的幾個CSS裡控制圖片方法，那麼你以後就不會再有此類
的麻煩事發生了。

background-repeat&nbsp;rn 圖片是否重復顯示 
body {background-image: rnurl(網址);background-repeat: 設定值;}
可以設置的值:
repeat&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 背景圖案在
 x- 及 y-方向重複
x-repeat&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 背景圖案在 x-方向重複
y-repeat&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
背景圖案在 y-方向重複
no-repeat&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 背景圖案不重複
範例:
/*主頁背景圖向下無限重複*/
body {
background-image: rnurl(attachment/201004/4/13918_1270365614wC5c.gif);
background-repeat: x-repeat;
}
background-position 指定圖片的位置
body {
background-image:rn url(網址);
background-repeat: no-repeat;
background-position: 設定值 ;
}
可
設定的值:
background-position: center center
第一個字為 [top,center,bottom]rn 中三選一，而第二個字由 [left,center,right] 中三選一。
background-position: 50% 50%
第
一個百分比為 x-軸的百分比，第二個為 y-軸的百分比。
background-position: 500px 500px
第一個數
目為 x-軸的位置，第二個數目為 y-軸的位置。

範例:

body {
background-image: rnurl(attachment/201004/4/13918_1270365614wC5c.gif);
background-repeat:rn no-repeat;background-position:100px 200px;
}
background-attachment 控制圖片是否滾動
