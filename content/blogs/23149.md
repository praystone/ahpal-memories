&nbsp;

以前提到結婚，想到「天長地久」；現在提到結婚，想到「能撐多久」。

&nbsp;

當初會結婚，說是「看上眼」；後來會離婚，說是「看走眼」。

&nbsp;

婚前，愛情是神話；婚後，愛情是笑話。

&nbsp;

男人花錢，是為了讓女人高興；女人花錢，是因為男人讓她不高興。

&nbsp;

嫁入「豪門」，要懂得理財；嫁入「寒門」，要懂得生財。

&nbsp;

以前的人，視婚姻生活為「一輩子」；現代的人，視婚姻生活為「一陣子」。

&nbsp;

婚前，男人在餐廳等女人；婚後，女人在客廳等男人。

&nbsp;

婚前，男人經常找女人「討論」；婚後，男人只告訴女人「結論」。

&nbsp;

婚前，男人對她悄悄講話；婚後，男人對她大聲講話。

&nbsp;

戀愛時，情話綿綿；結婚後，謊話連連。

&nbsp;

戀愛時的男人，喜歡「毛手毛腳」；結婚後的男人，變成「沒手沒腳」。

&nbsp;

婚前，情侶做什麼都是「浪漫」；婚後，夫妻做什麼都是「浪費」。

&nbsp;

想結婚，是自己已能獨立；想離婚，是子女已經獨立。

&nbsp;

婚前的男人，大都很幽默；婚後的男人，大都很沉默。

&nbsp;

女人的記性，吵架時最好；男人的耐性，結婚後最差。

&nbsp;

戀愛時，一見面就「親嘴」；結婚後，一見面就「鬥嘴」。

&nbsp;

婚前，男人常給女人「空白支票」；婚後，男人常給女人「空頭支票」。

&nbsp;

戀愛時，生活「妙不可言」；結婚後，日子「苦不堪言」。

&nbsp;

婚前，男人天天盯著女人；婚後，女人天天盯著男人。

&nbsp;

熱戀時，總相許下輩子再結良緣；結婚後，懷疑上輩子造作孽緣。

&nbsp;

大男人，會「作威作福」；好男人，會「作牛作馬」。

&nbsp;

婚前，「謊話」都是「情話」；婚後，「情話」都是「廢話」。

&nbsp;

婚前，靠近一點；婚後，閃開一點。

&nbsp;

婚前，沒話找話說；婚後，有話也不說。

&nbsp;

成功對男人的定義是指能賺很多的錢，成功對女人的定義是指能花很多錢。

&nbsp;

男人有錢就變壞，女人變壞就有錢。

&nbsp;

男人沒有女人，耳根清淨；女人沒有男人，居家乾淨。

&nbsp;

男人「入錯行」，上班會很痛苦；女人「嫁錯郎」，下班會很痛苦。

&nbsp;

好女人，養壞男人的胃口；壞女人，吊足男人的胃口。

&nbsp;

婚前，男人像傳令兵；婚後，男人像指揮官。

&nbsp;

失戀不見得是世界末日：你的心也許會"泣血"，但你的荷包卻可以不再"失血"。

&nbsp;

婚前媽媽擔心；婚後老婆擔心。

&nbsp;

婚前叫做孩子；婚後稱為大人。

&nbsp;

婚前天下的都是機會；婚後機會都是天下的。

&nbsp;

婚前叫做性行為；婚後叫做履行義務。

&nbsp;

婚前觸目皆美女；婚後觸目皆驚心。

&nbsp;

婚前眾女友互相往來；婚後她們老死不相往來。

&nbsp;

婚前他們計劃將來；婚後她們數落過去。

&nbsp;

婚前他棄暗投明；婚後他陽奉陰違。

&nbsp;

婚前他忠心耿耿；婚後他處變不驚。

&nbsp;

婚前吃飯他出錢；婚後吃飯他沒錢。

&nbsp;

婚前在床上他勢如破竹；婚後他只能炒箭筍。

&nbsp;

婚前他倆愛看雙響炮；婚後他們就是雙響炮。

&nbsp;

婚前他說她像清蒸鱈魚；婚後她說他像鱈魚香絲。

&nbsp;

婚前他倆山盟海誓；婚後他們約法三章。

&nbsp;

婚前他倆花前月下；婚後他卻花錢消災。

&nbsp;

婚前他討好丈母娘；婚後他埋怨丈母娘。

&nbsp;

婚前他陪她散步；婚後她逮他逛街。

&nbsp;

婚前她怕他會變心；婚後她怕身材變形。

&nbsp;

婚前他們戀戀風塵；婚後他們玫瑰戰爭。

&nbsp;

婚前他練御女神功；婚後他練葵花寶典。

&nbsp;

婚前她的怒色叫嬌嗔；婚後則是河東獅子吼。

&nbsp;

婚前他長篇大論；婚後她滔滔不絕。

&nbsp;

婚前他有點老花眼；婚後他決心要近視眼。

&nbsp;

婚前他拈花惹草叫外向；婚後他拈花惹草叫外遇。
