一直習慣到同一家去吃麵．．．．．
&nbsp;
一直習慣　只點著同樣的牛肉湯麵　．．．　
&nbsp;
即使只是醬油湯麵，一點牛肉味都沒有
&nbsp;
還是每次去並點著同樣的麵．　從不在意他好不好吃．
&nbsp;

&nbsp;
直到同事看到我每次都點著同樣的麵．想說也點來吃吃看．
&nbsp;
&nbsp;
嗯！　此麵可是被嫌棄到不行．
&nbsp;
&nbsp;
今天又去同家吃麵，同事提醒　怎麼還不換．&nbsp;

被這麼一說，我才想著　來換個口味吧．

&nbsp;
才驚覺，我以把很多事都公式化了．
&nbsp;
什麼時間做什麼事，早以被制定好的．
&nbsp;
到那家店吃飯，也都固定點同樣的餐點．　從不去想我今天想吃什麼．
&nbsp;
&nbsp;
上班也一樣，當有新的狀況來時，會想辦法解決．
&nbsp;
當解決辦法試出來時，就會自動把事情公式化
&nbsp;
久了！　又是一種習慣處理方式．
&nbsp;
&nbsp;
&nbsp;
唉！　要一直這麼生活下去嗎？
&nbsp;
覺得自己以經懶的動腦了．懶的去轉變了．
&nbsp;
