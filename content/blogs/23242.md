關懷人間的藥師佛 

&nbsp;




&nbsp;


&nbsp;

具足一切安樂

佛教開示淨土法門，告訴我們大千世界中有許許多多佛土，但特別提倡兩處：一是在我們這個世界以西，稱西方極樂淨土；一是在我們這個世界以東，稱東方琉璃淨土。

&nbsp;

&nbsp;

&nbsp;

西方淨土的教主阿彌陀佛，在因地發了四十八大願，令眾生來世往生極樂；而東方淨土的藥師如來，在因地發了十二大願，更為重視人生的現世快樂。藥師佛的本願是十分特殊的，注重現實利益，藥師琉璃淨土雖是天國的淨化，但是藥師佛重在成就其名號功德，主要是以名號攝化眾生，而並非以淨土攝導眾生。

&nbsp;

&nbsp;

藥師佛的十二願是立足有情的現世安樂，進而引導眾生趣入究竟的解脫，出世而不離世間。藥師法門是立足有情的現生安樂，進而引導眾生趣入究竟的解脫。所以在佛教徒中自然形成這樣一種觀念：往生西方念阿彌陀佛，消災延壽念藥師如來。


&nbsp;

西方淨土的弘揚，一向為教界所重視，相關典籍可謂汗牛充棟；而東方藥師法門卻鮮少有人提倡，這方面的著述更寥寥無幾。這一現象也使得社會對佛教產生了諸多誤會，認為信佛但求來世快樂而不重視現世的人生，甚至認為佛教乃逃避現實的宗教。

&nbsp;

&nbsp;

近代佛教領袖太虛大師為改變人們這種錯誤認識，曾大力提倡人間佛教，並親自講解過《藥師經》，認為可以依藥師法門創建人間淨土。所以說，藥師法門的弘揚是很有現實意義的。


&nbsp;

修習藥師法門得到人世間所需要的一切。消災免難、除病延壽、具足福德，是人們現前所希望的；遠離惡道、往生淨土，則是人們對未來的願望。因此，在藥師法門中，無論是現世樂還是來世樂，乃至涅槃究竟樂全都具足。尤其是對現世樂的強調，可以改變人們認為佛教但重來世的錯誤看法。

&nbsp;

&nbsp;

&nbsp;

如果我們學習藥師如來的十二大願，並努力地依教奉行，人間淨土是一定能實現的，因此在現代社會宏揚藥師法門有特別重大的意義，也是佛教徒義不容辭的責任。


&nbsp;

&nbsp;

祈禱藥師佛得福報的實例


從前在天竺國有一位貧窮的男子，平日靠乞討食物賴以維生。然而其所乞討的人家都不願意施捨給他。
一見到他就趕緊關起門來，因此人們都戲稱他為「閉門」；因為生活中這樣的境遇，他經常感到憂傷悲悽。


&nbsp;

&nbsp;

每每在難過的時候，他都會去一間供奉藥師佛的寺廟中參拜，繞著藥師佛像誦唸佛號，並至心懇切的懺悔，發願斷食五日。一日在睡夢中，從佛像中出現了一個身相莊嚴光明的人，對他說：「你往昔的業力已經因為你的誠心懺悔而消滅，不久你將會生活富饒。你不妨回去探訪你雙親的故居。」


&nbsp;

夢醒之後，他依著夢中指引回到了父母的舊宅，那裡的屋舍及城牆都已毀塌，唯有一根樑木沒有頹壞，上面寫著要求他兩日之後在此掘地，屆時將會發現一筆金錢，那是他父母生前的積蓄收入，善加運用這些積蓄，一年之內將會得到富貴。


&nbsp;

&nbsp;

這位貧窮的男子因為至心懇求藥師佛而改變了自己貧窮的生活，成為一個富有的人。


&nbsp;

&nbsp;

藥師如來在因地修菩薩行時，曾發十二大願，其中有一悲願便是令一切眾生的生活所需物資皆不缺乏。


&nbsp;

&nbsp;

因此，若我們能以恭敬心，供養藥師如來，或稱念藥師佛聖號，即能遠離一切貧窮過著富足、豐裕及安樂的生活。



隨喜法施功德

佛教提倡布施，在財施、法施和無畏施中，又以法施的功德最大。法施，就是把佛法的道理介紹給別人知道，使眾生能夠了解生死的由來、死後的歸趨、解脫煩惱的方法、真正幸福快樂的境界等。而「流通佛法資訊」正是法施的方式之一。


&nbsp;

隨喜的功德也是非常大的。法華經「隨喜功德品」說：如來滅後，若有人因聽經而發菩提心，隨緣、隨處、隨力為人演說。聽聞者，又輾轉為人演說，此人所得功德，大過於以一切資具布施四百萬億阿僧祇世界的六道眾生，又使他們修道證果的功德。


&nbsp;

為什麼隨喜功德有這麼大呢？因為，一個人聞法而發歡喜心，是一個人的功德。由於他的發心，隨緣、隨處、隨喜地為人演說；這些聽聞者，又繼續輾轉不斷地對與他們有緣的人演說，令聞者皆發菩提心，信樂佛道。因為眾生無盡，隨喜發心的願行亦無窮盡，所以這分隨喜的功德就如一燈傳千燈，燈燈相傳，光光相照，永遠不會斷絕。 


&nbsp;

古代流通佛法的方式，大部分是抄經、到中古時代印刷發達，印經的意義就如同佛經講的抄經流通是一樣的。到了目前的網路時代，在網路上介紹佛法，轉貼流通佛法資訊，就如同印經抄經的功德一般。


&nbsp;

在此網路時代，隨喜介紹轉貼佛法網站也是流通佛法的一種方式。就如同佛累世勤苦修行，已經將所有修行功德灌注於佛號，只要有人發心持誦就能得到累劫修行之功德。前人辛苦出資出力建立網站，有緣見網站者，只需發心隨喜舉手之勞的流通轉貼，即是一種法施最容易的方式。 


歡迎多多轉寄流通本訊息，功德無量！

歡迎護持流通本資訊，人身稍縱即逝，若來此世間不能做出對自他有利益的事，那麼等於是空來一趟，未來世只能隨業流轉。若能在佛法中造些許的功德，地藏菩薩承諾將救度此人不墮入三惡道。故能夠大量的轉寄此訊息，甚至只是一念隨喜，將是帶給自己與他人、今生與來世幸福、快樂的緣起。
