&nbsp;rn神奇的白鐵線圈療法-日本醫學大師發明的能量花&nbsp;&nbsp;


贈送鐵線圈 歡迎索取&nbsp;請寫體驗心得&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


將白鐵線做成鐵線圈 如一朵花 &nbsp;是能量花




將做好的鐵線圈擺在透氣膠帶上約八個左右 看患處痛的範圍 &nbsp;有的只需三四個就好 撕下來貼在患處&nbsp; 







法薰禪苑 推廣白鐵線圈的因緣及實例分享


經由熟識的法師推薦說白鐵線圈可以治病，並且教我怎麼做，當時存著半信半疑的心，認為沒有任何後遺症，也沒有侵入性；而且白鐵線也很便宜不用花很多的費用，就特別去大賣場買24號白鐵線來做，試著在痠痛處貼貼看；真的很神奇，過了幾小時後，患處就不痛了。覺得此簡單療法可以改善身上的病苦，乃開始大力推廣，遇有人哪裡痠哪裡痛就為他們貼上做好的白鐵線圈，並教大家自己製作白鐵線圈為家人服務。大家的反應也都覺得不可思議，一個小小的白鐵線圈竟然能發揮它的大作用力，可解除或舒緩身上的痠痛。


&nbsp;


當然久病要花更多的時間才能改善，若小毛病就能馬上見效。若是大毛病還是要找醫生醫治喔！下面有幾則實例與大家分享：


&nbsp;


&nbsp;&nbsp; ※鼻涕倒流 精神不佳 約二個小時後獲得改善&nbsp; 


&nbsp;有一位法師感冒後引起鼻涕倒流且精神狀況不佳，用白鐵線圈為他貼在鼻子兩側的凹陷處（迎香穴）以及印堂處，經過二小時後，不再流鼻涕了，鼻子很通暢舒服，整個精神也恢復了，這位法師說真的好神奇喔！


&nbsp;


※婆婆身體疼痛 不再吃止痛藥


陳太太的婆婆手痛常常要吃止痛藥，孝順的媳婦為她貼上白鐵線圈後舒緩了她的痛處。以後只要哪裡痛，她的婆婆都會自己去貼白鐵線，而且也停止吃止痛藥了，這是令她婆婆最高興的事。


&nbsp;


※鐵線圈也能讓膿瘡消失


謝先生說他脖子長了一顆膿瘡，他也用白鐵線圈去貼，結果膿瘡就消失了。 謝 先生的小狗生病，半夜呻吟吵得讓家人無法入睡， 謝 先生體驗到白鐵線圈的好處，也為小狗在患處貼上白鐵線圈，減輕了小狗的痛苦，哀嚎聲就漸漸減少。


&nbsp;


※車禍引起腰酸背痛&nbsp; 無法久坐跪拜 竟然能全程參加法會的跪拜


溫師姐因車禍引起腰痠背痛，無法久坐及跪拜。有一次參加寺裡的法會，因為腰部及膝蓋有貼上白鐵線圈讓她能全程參加整個法會到結束，更神奇的是她還能起來跪拜禮佛。溫師姐也做了好多白鐵線圈與她的兩個媳婦分享，媳婦也願意接受婆婆的好意推薦，貼在患處之後也都有改善。 


&nbsp;


&nbsp; ※惱人的膝蓋痠痛 &nbsp;終於有對治的方法


葉師姐膝蓋痠痛無法跪拜禮佛，也因為在膝蓋處貼了白鐵線圈，就感覺不痛好像把痛處拔掉一樣，讓她非常高興，不用再擔心參加共修時無法跪拜。有時膝蓋會在痛，只要貼一貼就好了。


&nbsp;


※脖子緊、手麻也得到改善


有一位師姐脖子緊及手麻，在脖子兩側及手腕處貼上白鐵線圈，也都有改善。


&nbsp;


※減輕尾椎疼痛


有一位先生說他曾摔傷，引起尾椎疼痛，做了好幾次復健，尾椎依然沒有改善，我用八個白鐵線圈黏在透氣膠帶上讓他自己貼在患處，大約過了半小時後，他說尾椎痛有減輕。 


&nbsp;


※腳踝扭傷&nbsp;&nbsp; 不藥而癒


智師父對於白鐵線圈的神奇療效，深信不疑。有一次下午走路不慎右腳踝扭傷，左脖子也拉傷，本以為是小事一樁不已理會，結果二三個小時後，腳踝腫起來無法走路，左脖子也緊緊的，智師父馬上把做好的鐵線圈，在腳踝腫的前後左右共貼了三條，左脖子也貼一條。（每條各七八個鐵線圈），到隔天就已不藥而癒，神奇吧。


智師父的右手手腕，抄經時手腕會痛，乃在手腕處貼了一圈的白鐵線圈，解除了痠痛感，可以專心的抄經。


&nbsp;&nbsp;&nbsp;&nbsp; 


※鐵線圈太多 能量太強會失眠


智師父有一次在手三里及足三里處以及受傷的腳踝為了保健也貼了一條，結果能量太強，循環太快全身熱起來，晚上也無法入睡，把腳踝那一條白鐵線圈扯下來之後，就能安然入睡。


記得晚上不要貼太多喔，否則會讓您精神超好導致失眠喔！在晚上使用白鐵線圈時適量就好。


&nbsp;


※鐵齒族終於相信鐵線圈的功效


手指頭忽然疼痛及腳撞傷&nbsp; 貼鐵線圈治好了


清師姐，剛開始介紹她使用白鐵線圈時，可能是使用的數量不夠，加上工作都是粗活，所以她的腰部沒有改善，很多師兄姐都說白鐵線圈真的有效，她總是帶著懷疑的眼光。有一次她的食指頭忽然痛起來，她馬上貼上使用過的白鐵線圈，隔了一夜就好了，清師姐這次肯相信了，說真的有效耶。


&nbsp;


有一次清師姐出外工作，腳膝蓋被東西撞傷有瘀腫，清師姐回家後趕快貼白鐵線圈，隔天也退瘀消腫了。


&nbsp;


清師姐的同修也因為勞動過度手臂會痛，他跟清師姐說等你貼有效了，我再來貼；結果他同修現在工作回來，就會趕快貼上白鐵線圈，來舒緩手臂過勞的疼痛。


&nbsp;


&nbsp;&nbsp; ※貼湧泉穴讓自己好安眠


竹師姐晚上有時會睡不好，無法一夜安眠，問我要貼哪裡讓自己好睡一點，我用了三個鐵線圈幫她貼在腳底湧泉穴，三天後告訴我說，貼在腳底一直沒掉，到昨天才拿下來，真的每夜好睡，一覺到天亮。


&nbsp;


※ 消腳腫 減輕膝蓋痛


元師父，雙腳腫，膝蓋痛，走路很吃力，我用鐵線圈各三個幫他貼湧泉穴及太衝穴，並在膝蓋兩邊的膝眼處貼了兩條鐵線圈，元師父說他隔天就消腫了，走路也比較有力。現在元師父寺裡的人眾也都大力在推廣神奇的鐵線圈療法。


&nbsp;


※治感冒喉嚨痛


若覺得快要感冒，有點喉嚨痛趕快在喉嚨的地方貼上白鐵線圈，能解除喉嚨痛。或是脖子找找看那地方有微痛，不要遲疑，貼了鐵線圈之後，能很快消除不適感。


&nbsp;


※鼻炎及頭痛


珍師姐鼻子過敏已很久了，且頭又常痛，教她用兩個鐵線圈貼在鼻子迎香穴及太陽穴，但她已病很久了，所以他她說有貼就舒服，要是停止不貼鼻子還是不通，頭還是痛，但總比吃要好多了。常貼的人就是要克服皮膚過敏的毛病，常貼的人的經驗是：洗澡時撤下來，讓皮膚休息幾個鐘頭，或是休息一晚再貼，並重新換新的透氣膠帶。


&nbsp;


願意相信肯貼的人，都會豎起大拇指說：讚。因為生病的時候求人不如求己。自己DIY可省掉很多時間及金錢，也不會有什麼副作用。唯一的缺點就是貼久了皮膚會過敏。


&nbsp;


※ 神奇的能量花


有一為師兄對磁場很敏感，我跟他介紹白鐵線圈的功效，他放在手中，有感覺有一股能量在三個圈圈裡面轉向中間，然後能量往上面衝。有一個師兄說白鐵線圈是一朵能量花。


&nbsp;


※法會中師姐們都自己當治療師


禪苑一年只舉行一次的梁皇法會，常常要跪及拜，而且時間是一星期，往年大家都會拜的很累，而且也會腰酸背痛，腳也無力更無法好好的跪誦。因為梁皇是一部大懺，經文有時很長要跪很久，裡面的佛號也很多，要不斷的拜。剛好在推廣白鐵線圈都教他們自己做，很多同修都會自己DIY，聽他們說，要來參加法會時，在大腿外面兩側各貼一條，腰酸時也貼，今年清明前的粱皇法會，蓮友們都說拜得很輕鬆，而且法喜充滿。


&nbsp;


以上都是我親自採訪的見證報告，白鐵線圈神奇的療效說不完，要自己去親身體驗，你就會發現它的神奇功效。反正哪裡有不適就貼哪裡，很簡單，心動不如馬上行動，趕快貼貼看吧！

&nbsp;在推廣白鐵線圈期間，遇到黃先生，送給我一本青春出版社出版的「磁場療法」，一翻書上內容，才知白鐵線圈的療法，原來是出自這本書。這本書的作者是日本人-藤本憲幸，是日本醫學大師─村上晉一先生所發明的迅速有效、戰勝疾病及疼痛的療法。書內一個單元就是在介紹「矯正混亂的磁場—鋼絲圈療法」，書內有詳細說明製作鋼絲圈的作法及日本人使用鋼絲圈的見證報告。有興趣想要知道詳細內容的請自己向青春出版社購買。&nbsp;（註：日本的鋼絲，就是台灣的白鐵線24號） &nbsp;

「磁場療法」是一本有版權的書，而且是日本的體驗，我想出版一本國內使用者的體驗報告，以及製作白鐵線圈的方法，和一些穴道的貼法。讓大家能自己DIY，讓更多的人能受惠，因此要徵求使用者的體驗報告，只要願意寫體驗心得的會贈送白鐵線圈一包，約可貼痠痛處三個地方。請用透氣膠帶貼，如上圖的貼法，然後撕下來貼在患處，若怕皮膚過敏，最好白天貼，晚上洗澡時就要拆下來，等隔天在新換膠布後再貼上。若皮膚好的人，可以一直貼著，洗澡也不用拆下來。白鐵線圈可以重複使用，若有改善，勿隨便丟棄，可留著以後哪兒痠痛時可再拿來貼。皮膚易過敏的，可買防過敏或嬰兒用的透氣膠帶。
