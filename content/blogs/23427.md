&nbsp;

曾經多麼堅強的防禦&nbsp;&nbsp; 不能再讓傷痛侵襲

&nbsp;

也會心甘情願的為那個人&nbsp;&nbsp; 卸下全身的重甲

&nbsp;

只是在心底深處為這個人&nbsp;&nbsp; 留了一個小小的空間

&nbsp;

這是多麼艱辛的空間&nbsp;&nbsp; 有煩惱&nbsp;&nbsp; 有憂愁 &nbsp; 有彷徨&nbsp;&nbsp; 有失落

&nbsp;

難道感情是一個雙刃劍&nbsp;&nbsp; 愛也痛不愛也痛

&nbsp;


&nbsp; 
也許愛的規則&nbsp;&nbsp; 從未真正懂過


&nbsp;

想找個藉口騙自己&nbsp;&nbsp; 我擁有你的愛

&nbsp;

我無力挽留愛的夢痕

&nbsp;

卻讓它縈繞心頭&nbsp;&nbsp; 糾纏不休

&nbsp;

我告訴自己不准哭&nbsp;&nbsp;&nbsp; 不准再掉淚

&nbsp;

就這麼讓它儲藏這份 &nbsp; 今生擁有的思念與回憶

&nbsp;


&nbsp; 
刻骨的溫柔&nbsp;&nbsp;&nbsp; 演唱者~郭&nbsp;&nbsp; 燕
