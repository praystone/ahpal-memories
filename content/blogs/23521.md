在信箱中看到此篇


哈佛管理世界中看到這樣一篇小文。 
&nbsp; 
一：沉穩 
&nbsp; &nbsp; &nbsp;（1）不要隨便顯露你的情緒。 我會顯露
&nbsp; &nbsp; &nbsp;（2）不要逢人就訴說你的困難和遭遇。 我會到處說
&nbsp; &nbsp; &nbsp;（3）在徵詢別人的意見之前，自己先思考，但不要先講。 我腦袋中沒有思考細胞
&nbsp; &nbsp; &nbsp;（4）不要一有機會就嘮叨你的不滿。 訴說牢騷是我的強項
&nbsp; &nbsp; &nbsp;（5）重要的決定儘量有別人商量，最好隔一天再發佈。通常朝令夕改我也常發生 
&nbsp; &nbsp; &nbsp;（6）講話不要有任何的慌張，走路也是。走路常撞東撞西算慌張嗎?


&nbsp; 
二：細心 
&nbsp; &nbsp; &nbsp;（1）對身邊發生的事情，常思考它們的因果關係。 
&nbsp; &nbsp; &nbsp;（2）對做不到位的執行問題，要發掘它們的根本癥結。 
&nbsp; &nbsp; &nbsp;（3）對習以為常的做事方法，要有改進或優化的建議。 
&nbsp; &nbsp; &nbsp;（4）做什麼事情都要養成有條不紊和井然有序的習慣。 
&nbsp; &nbsp; &nbsp;（5）經常去找幾個別人看不出來的毛病或弊端。 
&nbsp; &nbsp; &nbsp;（6）自己要隨時隨地對有所不足的地方補位。 
&nbsp; 
&nbsp;三：膽識 
&nbsp; &nbsp; &nbsp;（1）不要常用缺乏自信的詞句 
&nbsp; &nbsp; &nbsp;（2）不要常常反悔，輕易推翻已經決定的事。 
&nbsp; &nbsp; &nbsp;（3）在眾人爭執不休時，不要沒有主見。 
&nbsp; &nbsp; &nbsp;（4）整體氛圍低落時，你要樂觀、陽光。 
&nbsp; &nbsp; &nbsp;（5）做任何事情都要用心，因為有人在看著你。 
&nbsp; &nbsp; &nbsp;（6）事情不順的時候，歇口氣，重新尋找突破口，就結束也要乾淨俐落。 
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 更別提以上六項~~根本沒一樣可以達到
四：大度 
&nbsp; &nbsp; &nbsp;（1）不要刻意把有可能是夥伴的人變成對手。 
&nbsp; &nbsp; &nbsp;（2）對別人的小過失、小錯誤不要斤斤計較。 
&nbsp; &nbsp; &nbsp;（3）在金錢上要大方，學習三施（財施、法施、無畏施） 
&nbsp; &nbsp; &nbsp;（4）不要有權力的傲慢和知識的偏見。 
&nbsp; &nbsp; &nbsp;（5）任何成果和成就都應和別人分享。 
&nbsp; &nbsp; &nbsp;（6）必須有人犧牲或奉獻的時候，自己走在前面。 
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 哈這些我倒是還不錯
五：誠信 
&nbsp; &nbsp; &nbsp;（1）做不到的事情不要說，說了就努力做到。 
&nbsp; &nbsp; &nbsp;（2）虛的口號或標語不要常掛嘴上。 
&nbsp; &nbsp; &nbsp;（3）針對客戶提出的“不誠信”問題，拿出改善的方法。 
&nbsp; &nbsp; &nbsp;（4）停止一切“不道德”的手段。 
&nbsp; &nbsp; &nbsp;（5）耍弄小聰明，要不得！ 
&nbsp; &nbsp; &nbsp;（6）計算一下產品或服務的誠信代價，那就是品牌成本。 
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 越來越難懂了
六：擔當 
&nbsp; &nbsp; &nbsp;（1）檢討任何過失的時候，先從自身或自己人開始反省。 &nbsp; &nbsp; 
&nbsp; &nbsp; &nbsp;（2）事項結束後，先審查過錯，再列述功勞。 
&nbsp; &nbsp; &nbsp;（3）認錯從上級開始，表功從下級啟動 
&nbsp; &nbsp; &nbsp;（4）著手一個計畫，先將權責界定清楚，而且分配得當。 
&nbsp; &nbsp; &nbsp;（5）對“怕事”的人或組織要挑明瞭說。
