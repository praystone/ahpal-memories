【潘朵拉之盒】之ㄧ<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


他將那一只盒子擺在辦公桌上，思緒陷落在遙遠的記憶之中。


&nbsp;


16歲那一年，有一個女孩的身影，闖入了他的心中。她的長相已經被歲月沖刷的有點兒模糊了，只記得她有著白皙的皮膚，有著甜美的笑容，有著銀鈴般的聲音，有著文靜典雅的外表，還有一種獨特的感覺，那是一種，彷彿永遠在咫尺之外的感覺，離他遠遠的，怎麼也捉摸不定的感覺。


&nbsp;


盒子裡收藏著的，就是他與她認識之後所有的信件往來。


&nbsp;


36歲的他已經歷經過許多風浪，天底下似乎已經沒有甚麼他不敢去碰觸的事情，生與死，苦與痛，新與舊，來與去，那些在人生中該經歷的，他幾乎都差不多經歷過了。客戶、案子、朋友、員工、家人，他用盡每一分心力去經營一切，去看待一切。不管做甚麼事，他自認為他都比別人用心，也因為用心，所以，他覺得，再沒有甚麼可以箝制他，再沒有甚麼可以令他遲疑或是猶豫的事情了。


&nbsp;


唯獨對這只盒子，卻讓他，不敢輕易開啟。


&nbsp;


彷彿這是只潘朵拉之盒，掀開盒蓋，不知道盒子裡將會有甚麼東西跑出來，慾望？貪婪？還是邪惡？又或者，盒子其實早已經被開啟了，裡頭只剩下人們唯一被潘朵拉隱藏起來的希望？如果盒子裡是希望，那麼，他又該不該將它開啟？掀開盒蓋到底將會面臨甚麼？他所看到的，會是天堂，還是地獄？這些矛盾的思緒撕扯著他，讓他陷入一種前所未有的掙扎裡。


&nbsp;


這一陣子，他總是對盒子戀戀不忘，沒事就會將盒子捧到桌前，端詳，思索著，猶豫著該不該將盒子打開？好像連作夢都在思考著這件事，記得那是一個寒冷的夜晚，他作了一個詭異的夢境，他將盒子打開了，而盒子裡頭，竟然空無一物！他呆呆地看著空空如也的盒子，心底一種濃厚的失落感油然而生，好像一切的努力都白費了，好像精心雕琢的水晶突然摔落地面，眼看著碎裂片片，卻再也無能為力。她呢？記憶中的她到哪裡去了？為甚麼盒子裡會甚麼都沒有了？至少，也該有那一張，唯一的一張，她的照片吧？


&nbsp;


在眼淚即將落下時，他醒了。


&nbsp;


已經許久不曾有過想哭的感覺，自從最疼愛他的祖母過世之後，他的眼淚似乎找到了一個躲藏得十分安穩的地方，再也不曾輕易宣洩，而，在夢裡，他竟然會有這種想哭的情緒出現？於是，在那樣的一夜，他再也闔不上眼睛。隔天一早公事十分繁忙，他狠狠地把這個夢境用力地遠遠拋到九霄雲外。


&nbsp;


就這樣，他在各種不斷找來的藉口中，蓄意遺忘那只盒子。公司裡一堆大大小小的事情需要他的照料，需要他的決斷，需要他的協調，週遭的眾人已經養成了一種十分優良的習慣，凡是遇到不能解決的事情，找他就對了，找他，自然一切困難都應該解決。在他們眼中，他是萬能的，沒有甚麼事情無法解決。而他也習慣了去解決一切，在他的城堡裡，大到公司決策，小到幫兒子換尿布，都在他的掌控之中。


&nbsp;


在忙碌中，彷彿很容易就可以忘卻一些細微的心情。這些細微的心情已經習慣被壓抑、被隱藏，被封鎖在生活細節之外。


&nbsp;


一直到那一天，妻為了一些芝麻綠豆的小事惹得他心煩不已，他衝出門，不知不覺地驅車至公司，打開辦公室門的那一瞬間，他突然有一股衝動，這次，他決定要打開那只盒子。他將盒子搬了出來，不再讓自己猶豫，深呼吸一口氣，顫抖著手拿起美工刀，劃破封口。


&nbsp;


他感覺劃破封口的那一個動作，像是在切割自己的心臟。


&nbsp;


等到那熟悉卻又模糊的字跡跳躍出來時，他幾乎停止了呼吸。呆楞了許久，他才有勇氣將信件一封一封打開來閱讀。思緒墮入遙遠的記憶之中，回味著過去的種種，二十年了，漫長的二十年已經過去，她在他生命中刻劃下永恆不滅的痕跡。


&nbsp;


他花了一整夜的時間去沉緬在年輕歲月裡，他時而泛起微笑，時而緊緊皺眉，千百種複雜的情緒在他心中來來回回地流竄，那種感覺就像洗三溫暖一樣，一會兒極熱，一會兒卻又冰冷。在冷熱之中，他遺忘了自己的存在，遺忘了現實中所有的一切。


&nbsp;


翻著翻著，其中一紙信讓他暫時放下信件，回憶起當時的情景，記得那一次他們相約清晨去球場打球，而到了球場，他卻怎麼也找不到她。他找遍整個球場，望眼欲穿地，卻怎麼也找不到她的身影，他滿頭大汗找得好辛苦、好辛苦，他以為她失了約沒來，卻，在失望地放棄了之後才發現，她竟然就在他前方不遠處，手拿著羽毛球拍，早已經在那裡打球了。


&nbsp;


他一直不明白當時為了甚麼原因會看不見她，她就在眼前而已，他卻怎麼也找不到她？她近在咫尺之內，卻，彷彿遠在天邊。她一直給他這樣的感覺，彷彿很靠近，卻其實朦朧地幾乎不存在。


&nbsp;


他為自己當時的那一股傻勁而笑了起來，是的，現在的他已經不是當年的他了，如果再次與她相約，他想，他應該可以不會再犯下相同的錯誤了吧？他應該，不會再找不到她了吧？


&nbsp;


問題就在於，現在的她到哪裡去了？


&nbsp;&nbsp;


【潘朵拉之盒】之二


&nbsp;


生活在同一個城市裡，他竟從來沒能再遇見她。他們的最後一面是在大約十年前了，26歲的他們竟然會選擇在同年同月同日結婚，只不過新郎新娘不是對方。


&nbsp;


他常常為此感到無比的嘆息，失去幾年的聯絡之後，他們各自陷落在屬於自己的愛情裡，然後，竟然會不約而同地選擇在同一年的同一天舉行婚禮，理所當然地，他和她都無法參加對方的婚禮。他一直感到很遺憾，此生，竟然沒能親眼看見她披上白紗禮服的美麗模樣。


&nbsp;


結婚後，他們又再度失去了聯繫。就好像他們不存在同一個時空似地，偶爾陰錯陽差幾乎遇見了，卻又迅速無比地朝相反的方向離去。


&nbsp;


這十年來，他的生活面臨著許多考驗與掙扎。經過許多地努力與奮鬥，他好不容易終於創建了一家屬於自己的公司，好不容易買下了第一棟屬於自己的房子，好不容易讓全家人衣食高枕無憂。他手握某種程度的權限，關係著員工某程度的前途與未來，關係著父母妻兒某程度的經濟與依靠，而這些權限，是用他全部的心血換來。


&nbsp;


以前他總覺得她高高在上，遙不可及，現在的他，經過這許多的考驗與奮鬥，應該距離她近些了吧？他腦中竄進一個念頭，他十分渴望，能找到她。


&nbsp;


找到她，讓她分享這些成就，讓她感動這些努力。


&nbsp;


他開始翻箱倒篋追尋一切可以找到她的訊息，結婚時的聯絡地址已經變更，工作地點也不一樣了，他不放過任何蛛絲馬跡，終於找到她娘家的電話，沒想到那通電話有些陰錯陽差，接電話的是個小女孩，他以為，連這電話都變更了。


&nbsp;


這條路行不通，於是，他改成找她丈夫的行蹤。皇天不負苦心人，他終於找到了她的訊息，擁有了她的行動電話號碼。可是，看著電話，他還是十分遲疑，該不該打這通電話？接通之後該說些甚麼？她還會記得他嗎？她一直都是那麼飄忽而遙不可及，找到她之後，會不會又是同樣的感覺？


&nbsp;


他還是鼓起勇氣打了電話，電話那頭她的聲音依舊甜美，她笑得開心，直喊著他的名字：『宇軒？宇軒！是你啊！好久沒有你的消息了！最近好嗎？』她熱情的語調挑起了存在他心底小小的、某種程度的情懷。


&nbsp;


那一通電話聊了許久，彼此不只是互道寒喧而已，還聊起了許多心情、許多過往以及許多現況。電話掛上的那一刻，他心情顯得十分雀躍。


&nbsp;


他終於找到她，終於聽到了她的聲音，她不再給人那種飄忽不定的感覺，而是真真實實地存在著。那一個晚上，他的耳朵裡總是迴繞著她嬌甜的聲音，一遍又一遍地，帶給了他一個甜蜜的好夢。


&nbsp;


幾天後，他找了一個中午，約她共進午餐。初見到她的那一霎那，他有點兒驚訝，比起十年前她瘦多了！她不只是瘦，還顯得有些憔悴，原本圓潤的臉龐變成了消瘦的臉型，長長的直髮襯著黑色毛衣，更突顯了她的纖細瘦弱，只有那雙會閃耀出光芒的眼睛，仍舊與記憶中一樣閃亮動人。


&nbsp;


『妳怎麼瘦成這樣？妳丈夫虐待妳啊？怎麼瘦成這樣呢？』他不斷追問著，好像她的瘦弱十分不應該似的。她則是笑著回答：『許多人要靠減肥藥瘦下來呢！瘦有甚麼不好？至少，我不必跟別人一樣去擔心肥胖問題啊！』


&nbsp;


他心疼地看著她，這十年，她到底經歷過些甚麼？是甚麼原因，奪去了那圓潤的臉龐？他仔細地端詳著她，漫無邊際地猜測著種種可能發生的原因，但是，卻沒有再直接問她原因。


&nbsp;


有些事情，問了，不一定有真實的回答，就算有，也可能讓他無法接受。他不能忍受有一絲一毫的痛苦加諸在她身上，雖然明知道肯定有某些事情發生在她身上了，但是，他還沒有做好心理準備，他還不能接受。


&nbsp;


這算是自欺欺人嗎？是吧！有太多時候，如果不暫時欺騙自己的感覺，可能啥事也決斷不下了。
