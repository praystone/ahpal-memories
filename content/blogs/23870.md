放生治癒窩兒寒<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />rn這是發生在今年春天的事情。


&nbsp;


&nbsp;那時，我們一大家子十口人，有六人感冒。他們是：倆小外甥，侄兒，哥，我母親，還有我。特別是我，嗓子發炎，兼有咳嗽，說起話來也是沙啞的。見此情形，我嫂子說：“你們這是得了窩兒寒了。”


&nbsp;


小小感冒，我沒有當回事兒，心想過兩天就對了。誰知道，卻是一天比一天加重。我感覺此事不妙，應當去放生.


&nbsp;


&nbsp;&nbsp;&nbsp; 一兩天后，我進城邀蓮友放生，大概買了八九十元錢的魚。後來，覺得自己的狀況好很多，但仍有後遺症。我便買了兩元錢的蛇膽川貝液，以備服用。


&nbsp;


&nbsp;&nbsp;&nbsp; 緊接著，開始幹活。我的活兒是室外建築，天公不作美，偏偏下起了雨。遭了，我這感冒只怕是不得好了。幸虧雨小，略有淒風，病沒有復發。


&nbsp;


&nbsp;&nbsp;&nbsp; 第二天，仍去幹活。收工的時候，又下雨。我駕駛著拖拉機，在風雨中，一路高歌阿彌陀佛。雨越下越大，半路上，我停下來，向一家小商店討了個塑膠袋籠在頭上，繼續趕路，大約一個半小時，我回到家裏，早已是萬家燈火。


&nbsp;


&nbsp;&nbsp;&nbsp; 我無心晚課，脫了濕漉漉的衣服，忐忑不安的睡下，次日醒來，平安無事。


&nbsp;


&nbsp;&nbsp;&nbsp; 如果不是放生，在全家窩兒寒這種背景下，僅僅兩元錢的藥，病沒有好，又遭逢淒風苦雨，想要康復，那真是癡人說夢呢。


&nbsp;


&nbsp;&nbsp;&nbsp; 家人的病，也都好了。慈輝佛教基金會會長楊洪居士曾經說過：感冒也是怨親債主使然。由此，我深切體認到確實如此。


&nbsp;


&nbsp;&nbsp;&nbsp; 放生愈病，真是靈丹妙藥啊
