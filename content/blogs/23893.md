【潘朵拉之盒】之五<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


雖然藉著各種接觸，拉近了他和她之間的距離，可是那種彷彿隨時會失去她的感覺，並沒有因此而改變多少。他很清楚地知道，自己已經沉淪在愛戀之中了。不是不明白這份愛戀在社會道德之外，但是，現在的他並不想再顧慮那麼多了。


&nbsp;


從小他就被壓抑著，總有人告訴他該做甚麼，不該做甚麼。小時候要努力讀書，為了聯考最好所有的興趣都得放棄；當兵時要服從長官命命，不合理的要求是磨練，一聲命令下來，甚麼都得照做；結婚後要照顧好家庭，下班後除了回家，哪裡都不應該去；員工失戀了，工作效率差到極點，你不能炒他魷魚，只能拍拍他的肩膀，告訴他天涯何處無芳草，何必單戀一枝花；難搞的客戶刁鑽無理，像菜市場裡賣菜的小販，為一塊錢兩塊錢面紅耳赤地殺價，你只能笑著回答：『合作愉快！』


&nbsp;


他像是被困在象牙塔裡的玩偶，漸漸被塑造出一個別人期望的模樣，一個符合社會期望的模樣。他是個好老闆、好丈夫、好父親，甚至也是個好兒子。他有時候甚至會懷疑，自己並不為自己而活著，而是為了週遭的人活著。現在，他要為自己而活，為自己而感覺，為自己而快樂悲傷。


&nbsp;


並不是因此要拿甚麼作為代價，事業與家庭他同樣兼顧，甚至有她的存在，更讓他趨向穩定。只是，這一次，無論如何，無論該拿甚麼作為代價，他都願意犧牲。


&nbsp;


他對她的思念與日俱增，她的身影總不時地出現在腦海裡，苦澀的思念感覺像是無底黑洞，拉扯著他往無邊無際的深淵裡墮落下去。他其實是用一種喜悅的心情落入思念，有太多時候，他渴望能見到她，即使只是短短的幾秒鐘，都可以讓他感到無限的滿足。


&nbsp;


歲月早已慢慢讓他明白，細水長流的美麗。


&nbsp;


他開始想盡辦法去接她下班，就像在冥冥中排了時間表一樣，每天下午五點三十分，他總會排除萬難出現在她公司門口守候。即使只是送她回家的短短三十分鐘，他看著她的面容，和她說說話，他都覺得有一種充電的感覺，好像她已經變成了他的精神食糧，能看著她笑，真的比甚麼都令他感到快樂。


&nbsp;


他好喜歡她笑起來的模樣，很直接、很自然、很無拘無束，沒有一絲做作的味道。他也喜歡聽她說話，甜美的聲音彷彿可以將寒冷的冬意驅走。他更喜歡她偶爾頑皮淘氣的樣子，像個孩子似的，她天真浪漫的表情實在可以融化了他平時嚴肅的防衛，可以讓繁忙而緊張的工作壓力暫時消失。


&nbsp;


只要見到她，他可以將所有的世俗煩惱拋到九霄雲外。跟她在一起，他覺得有一種很輕鬆自在的感覺，很久沒有這麼開懷地笑過，很久沒有這麼自在地說話。


&nbsp;


她是他的天使，她是他的希望。


&nbsp;


這份希望不是形式上的名份，而是隱藏在心底一股無形的助力。當他終於忍不住思念的煎熬，當他終於緊緊握住她的手，他發現，她的手冰冷的像冰塊一般，彷彿從身體裡寒透而出，冷到讓人心疼。


&nbsp;


他總企圖使那雙小手溫暖，卻怎麼也徒勞無功。其實，他第一次握她的手的時候，他的內心是十分矛盾的。有著雀躍的心情，也有著擔憂的恐懼。即使將那雙手緊緊握住，他還是有著一種莫名的恐懼感，感覺她隨時會消失不見。


&nbsp;


二十年來，他不曾握過這雙手。


&nbsp;


一旦將那手緊緊握住，他在心底告訴自己，再也不輕易放開。冰冷的小手有著白皙的皮膚，有著二十年來隱藏的愛戀，還有著那種隨時會飛走的不安定感。


&nbsp;


有時候他甚至覺得，她可能在他面前，就這麼憑空消失了。這種若即若離的感覺困擾他，好像這一切都只是一場夢，隨時都會讓他自夢中醒來，隨時都會讓她消失的無影無蹤。這種奇怪的感覺有時候令他十分沮喪，他總努力說服自己，說服自己那只是庸人自擾，說服自己只因她曾經自他生命中消失，所以才會恐懼她再度消失。


&nbsp;


【潘朵拉之盒】之六


&nbsp;


她總是穿著一身黑，黑色毛衣、黑色外套，黑色鞋子，甚至連皮包都是黑色。雖然，黑色能襯托出她白皙肌膚，可是，卻也突顯了她的蒼白憔悴與纖細。


&nbsp;


而且，老穿著黑色，總是讓人有一種陰暗深沉的感覺。他問她為何老是一身黑，她卻意味深長地回答：『我喜歡黑色，因為，黑色是思念的顏色。』她的眼眸裡閃出獨特的光彩，彷彿眸子裡有著美麗的銀河閃爍。


&nbsp;


她很認真地說：『你知道嗎？有位作家在文章裡說，思念是有形狀的，像一條蜿蜒而上的階梯。他說思念有聲音，也有重量。我倒是覺得思念應該也有顏色，思念的顏色就是黑色。它就像是宇宙黑洞那樣的深黑色，會把人往裡面拉扯進去，無論怎麼你怎樣掙扎都沒有用。』


&nbsp;


他思索著，思索黑色與思念的相關性，覺得有些茫然不解，也有些異想天開。他以為，如果思念有顏色，那也應該是如彩虹的七彩絢麗才對。


&nbsp;


黑色，太深，也太沉。


&nbsp;


他輕輕親吻著她，試圖化解那一身的黑暗。他想看見她心中的思念彩虹，他想看見她的笑容與喜悅，他其實並不希望看見，她被思念的宇宙黑洞給揪扯進去，墜落在無邊無際的黑暗之中。


&nbsp;


但，即使他再怎麼努力，也無法避免某些時間與距離的空白所造成的宇宙黑洞。


&nbsp;


上海分公司必須他親自去督導，所以，他得暫時離開有著她的台北天空。雖然只是短短一個星期，對他與她來說卻像是經過了整整一個世紀那麼長久。沒有對方存在的天空瞬間變得灰暗朦朧，一顆心總是卡在喉嚨，忐忑不安。


&nbsp;


半夜裡，他做著惡夢，夢見她突然消失了。他在夢中急得如熱鍋上的螞蟻般，瘋狂地到處尋找她的蹤影。那種感覺就好像是失去了肉體，只剩下一縷幽魂，乘著風的翅膀，在海中、在山裡、在真實與虛擬的界線中摸索，在雲霧瀰漫的世界裡找尋她的蹤跡。


&nbsp;


在上海客戶邀約的飯局裡，他眼睛雖然盯著滿桌豐盛的佳餚，心裡卻想著她；在香港人山人海的街道上，耳邊鬧哄哄的吵雜裡，她甜美的聲音卻出現在腦海。


&nbsp;


她佔據了他的白天與黑夜，也奪去了他的心靈與感官。她的存在，已經變成了一種要命的習慣。


&nbsp;


這個時候他終於明瞭，思念的顏色的確是黑色，思念如宇宙黑洞般吞噬人心，思念是無論你如何苦苦掙扎，都掙脫不了的束縛。


&nbsp;


李宗盛唱的那首【鬼迷心竅】不斷迴繞著，他在心中來來回回地唱著，曾經以為人生就這樣了，平靜的心拒絕再有浪潮，斬了千次的情絲卻斷不了，百轉千折它將我圍繞。有人問我妳究竟是哪裡好，這麼多年我還忘不了，春風再美也比不上妳的笑，沒見過妳的人不會明瞭。是命運的安排也好，是妳存心的捉弄也好，然而這一切已不再重要，如果妳能重回我懷抱，我願意隨妳到天涯海角。


&nbsp;


她的出現的確像是讓他鬼迷了心竅，為了她，他真的十分甘願，去承受一切苦果。


&nbsp;


回到台灣的第一件事，他將她緊緊擁抱在懷裡，再也不願意輕易放開。那天剛好是情人節，也是潘朵拉盒子開啟的第一百天。一切的道德框架都失去效用，一切的社會倫理都被拋在腦後，經過二十年漫長的等待，經過一百天緊密地相知相依，他第一次真正佔據了她的身心。


&nbsp;


她的嬌羞，她的嫵媚，她的純真，都在漫長的等待與短暫的分離中真實地呈現出來。他又愛又憐地親吻著她全身每一吋肌膚，彷彿要將她的每一顆細胞都牢牢記熟。


&nbsp;


如果可以，他真的想給她，全世界。
