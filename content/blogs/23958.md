【潘朵拉之盒】之九<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


她的消失幾乎讓他達到崩潰的頂點，在夢境裡，那種墮入灰濛濛世界的感覺，無情而殘酷地來到了現實之中。


&nbsp;


但奇怪的是，如今真正面對的時候，他反而沒有像夢裡面一樣那麼無助的感覺，他再怎麼找不到她，最後的手段，最逼不得已的時候，總可以直接登堂入室到她家找她吧？


&nbsp;


當他決定不顧一切時，連自己都感到訝異，在商場上縱橫多年的冷靜與機智，都似乎暫時消失了。現在的他，像是16歲的年少輕狂，像是26歲的熱血澎湃，一點兒也不像36歲男人該有的矜持成熟。


&nbsp;


沒有人會明瞭她對他的重要性，這不只是一份感情的支持而已，她啟發了一個全新的世界，一個充滿希望的世界。他學會了如何跳脫自己去思考一些事情，而不是像以前那樣依循著某一種模式前進，他學會了怎樣去看待自己，去面對自己。


&nbsp;


這些，不只是狹隘的愛情而已。愛情烘托了這些，讓它們更加快速與真實。


&nbsp;


他徘徊在她家樓下，回想著她所帶給他的一切助益與激勵，期望等到下班時間可以遇見她的歸來，他想，無論如何她總會回家吧？就算她要搬家，他們分手才只一宿，也不至於那麼迅速吧？


&nbsp;


就這麼等著等著，等到霓虹開始閃爍，等到夜色慢慢降臨，卻，始終不見她的身影。直到對街出現了她丈夫至浩的身影，他的心開始有點兒慌亂，卻，深深吸一口氣，準備鼓足了勇氣面對，是的，無論如何，他非找到她不可。


&nbsp;


『嗨！好久不見』至浩見到他，有著小小的訝異。『好久沒聯絡，經過這兒，來探望你們。』他說了謊。


&nbsp;


進門的那一瞬間，他突然想起她總是提起進門玄關養著一缸魚，有著美麗的紅蓮燈，有著七彩的孔雀魚，還有著各種漂亮的水草舖設在水底。她總是十分雀躍地告訴他，家裡的魚又生了魚寶寶，小小孔雀在水草間玩著躲迷藏的遊戲，非常非常可愛。


&nbsp;


於是，他順口問道：『疑？魚缸呢？』


&nbsp;


『魚缸？』至浩臉上出現了十分訝異的神情，彷彿這一句話不應該問似的：『你怎麼知道以前這裡有魚缸？』兩個人對望一眼，呆楞在原地。


&nbsp;


『不是嗎？這裡不是應該有魚缸？』不知怎地，一股莫名的恐懼感侵襲而來，他全身的毛細孔都不由自主撐開。至浩望著他，不再言語。然後，拉著他，走進了客廳。走進客廳之後，那一幕景象，讓他驚得再說不出話來。


&nbsp;


他看見了，她的靈位。


&nbsp;


盤香燃燒著，一縷黑煙幽幽地舞動，詭譎的空氣裡，瀰漫著檀香的味道。怎麼可能？怎麼會有她的靈位出現？昨夜他還跟她在一起的，昨夜她還溫柔地依偎在他懷中，怎麼可能就這樣死了？這是一個玩笑嗎？她會跟他開這種生死的玩笑？他回頭望著至浩，說不出話來。


&nbsp;


『你來晚了，沒見到她最後一面，三個月前她就走了。』至浩臉上仍掩不住喪妻的悲慟。


&nbsp;


三個月前？不！這中間一定有甚麼不對！三個月前他開啟了她和他二十年前所有信件的潘朵拉盒，不久之後，她出現在他眼前，就像天使一樣帶給他無限希望，三個月前，他是透過至浩才得知她電話號碼的，不是嗎？


&nbsp;


『你沒跟我聯絡過啊！』至浩的回答讓他更吃驚：『這麼多年沒消息，我以為你移民到對岸去了。』


&nbsp;


他的心跳幾乎停頓，彷彿有人用力掐住他的心臟。


&nbsp;


『她走了以後，魚缸裡的魚幾乎都死光了，所以，前兩天，我把魚缸整理後送人了。』至浩沉痛地說。


&nbsp;


他呆楞在當場，無法思考。這一切都太過詭異，太過離奇。


&nbsp;


他就這麼呆立在那裡，腦海中她美麗的倩影不斷出現，她的話語一遍又一遍迴響著，這一切難道只是一場夢境？還是她放心不下他，所以死去之後靈魂出現在他面前？可是，那柔軟的膚觸，那浪漫的纏綿，是那麼真實貼切，那麼讓他悸動不已，那一切，難道，都只是他自己的幻覺？


&nbsp;


也不知道過了多久，至浩拍拍他肩膀：『她走得很匆忙，沒留下甚麼話，只說有只盒子要送給你，她說，你總有一天會來找她的，所以，我就一直擺著。』他將盒子遞到他手中。


&nbsp;


他低頭看著盒子，努力想讓自己鎮定下來，然後顫抖著雙手，冒著冷汗，開啟了盒子。


&nbsp;


盒子裡擺放著，一只小巧玲瓏的水晶盒。


&nbsp;


實心的水晶盒晶瑩剔透，閃爍著七彩的光芒，精緻的雕工條理分明，盒蓋上，一朵水晶玫瑰綻放著，栩栩如生。
