&nbsp;

可以相信嗎&nbsp; 在我的夢境裡

&nbsp;

妳是被施了魔咒的公主

&nbsp;

總是注視妳的我

&nbsp;

雖然有著阻礙

&nbsp;

但無論何時&nbsp;&nbsp; 有著一份勇氣

&nbsp;

相信能與妳更加靠近

&nbsp;

看見妳憂傷的站在遠處

&nbsp;

現在起就抓住我的手

&nbsp;

我們一同飛翔在空中

&nbsp;

就算飛翔也別感到驚怕

&nbsp;

眼前的世界&nbsp; 實在太珍貴了

&nbsp;

只要我們在一起

&nbsp;

穿越了心靈&nbsp; 越過了阻礙

&nbsp;

雖有著無數困難

&nbsp;

但你就在身旁

&nbsp;

賦予了我無盡勇氣

&nbsp;

克服了畏懼&nbsp; 遠離了憂傷

&nbsp;

這一切都太珍貴了&nbsp; 

&nbsp;

&nbsp;只因我們在一起
