我所期望的那一天&nbsp; 

&nbsp;

不知何時&nbsp; 從抓住的妳手中感受到了

&nbsp;

或許因為實在太模糊&nbsp; 所以無法坦承

&nbsp;

就連那份心也無法解釋

&nbsp;

妳懷抱著怎樣的心情呢

&nbsp;

就連謎樣的未來

&nbsp;

也都屬於我嗎

&nbsp;

我可能是存在的

&nbsp;

感激&nbsp;&nbsp;&nbsp; 因為我擁有了你

&nbsp;

現在&nbsp; 妳就是愛

&nbsp;

寶貝&nbsp; 只有妳

&nbsp;

如同我們相遇&nbsp;&nbsp; 

&nbsp;

我心動的唯一理由

&nbsp;

只有我那爲妳變換的情緒

&nbsp;

妳知道的

&nbsp;

告訴我 

&nbsp;

這是可以永遠的愛情

&nbsp;

是幸福的&nbsp;&nbsp; 深切&nbsp; 可以是永遠

&nbsp;

人群中尋找著

&nbsp;

我的愛&nbsp; 我正奔向妳

&nbsp;

不管身在何處

&nbsp;

我想妳&nbsp;&nbsp; 寶貝只有妳

&nbsp;

我知道&nbsp; 也相信

&nbsp;

妳懂的
