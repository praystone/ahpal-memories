&nbsp;

&nbsp;

&nbsp;

男人是上帝根據世界的需要而創造的 
女人是上帝根據男人的需要而創造的 

&nbsp;

男人愛上女人後， 他會做詩 
女人愛上男人後， 她會做夢 

&nbsp;

女人對男人往往會朝思暮想 
男人對女人往往會朝秦暮楚 

&nbsp;

女人的看家本領是撒嬌 
男人的拿手好戲是撒謊 

&nbsp;

女人的幸福在於：他真的愛我 
男人的幸福在於：她值得我愛 

&nbsp;

女人應該有豐滿的胸脯 
男人應該有豐滿的腰包 

&nbsp;

女人吻男人算是一種幸福 
男人吻女人算是一種口福 

&nbsp;

當女人走投無路的時候，她會和一個男人結婚 
當男人走投無路的時候，一個女人會和他離婚 

&nbsp;

聰明的女人會嫁給愛她的男人做老婆 
愚蠢的女人會嫁給她愛的男人做老婆 

&nbsp;

做情人的時候，女人會讓男人心疼 
做妻子的時候，女人會讓男人頭疼 

&nbsp;

少女習慣用眼神征服男人 
少婦習慣用眼淚征服男人 

&nbsp;

為女人發誓的男人是可笑的 
為女人發財的男人是可愛的 

&nbsp;

男人要是提出離婚，往往是他已經不喜歡她的妻子了 
女人要是提出離婚，往往是她丈夫已經不喜歡她了 

&nbsp;

女人堅持獨身，人們會認為她有毛病 
男人堅持獨身，人們會認為他有事業心 


&nbsp;

而實際情況是： 


女人堅持獨身是因為找不到好對象 
男人堅持獨身是因為找不到對象 

&nbsp;

女人習慣把賭注押在愛情上 
男人習慣把賭注押在婚姻上 


&nbsp;

女人能夠忍受不幸的婚姻，不能忍受不幸的愛情 
男人能夠忍受不幸的愛情，不能忍受不幸的婚姻 


一個憂鬱的女人背後必然有一段不幸的愛情 
一個憔悴的男人的背後必然有一樁不幸的婚姻 

&nbsp;

女人再婚是為了賭氣 
男人再婚是為了碰運氣 

&nbsp;

有價值的女人沒有價格 
有價格的女人沒有價值
