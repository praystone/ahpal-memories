&nbsp;

&nbsp;

現在起我們只談真心

&nbsp;

沒有什麼不可能的

&nbsp;

哪怕沒人能夠認同

&nbsp;

只要能夠一起&nbsp; 一切都好

&nbsp;

在這記憶中的點滴溫暖

&nbsp;

將會銘刻心中&nbsp; 成為深深的牽絆

&nbsp;

這世上總存在著奇蹟&nbsp; 

&nbsp;

這樣特別的事情

&nbsp;

又何必去解釋

&nbsp;

只要有愛就足夠了

&nbsp;

隨著時光漸漸淡去

&nbsp;

即使有著苦澀&nbsp; 我仍願意向前

&nbsp;

徜若有一天&nbsp; 妳遇見了傷痛

&nbsp;

無論何時這份思念伴妳身旁

&nbsp;

妳我都別憂傷

&nbsp;

快樂的讀著

&nbsp;

屬於我們的童話吧

&nbsp;
