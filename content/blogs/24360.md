值得珍惜的一切總是那般脆弱

&nbsp;

我們無法預知&nbsp; 只能默默守候

&nbsp;

遙遠的&nbsp; 遙遠的&nbsp;&nbsp; 世界中的一端

&nbsp;

我倆彼此相遇的這偶然

&nbsp;

稱作為奇蹟的這感覺

&nbsp;

只想對你說

&nbsp;

只是&nbsp; 總是無法明確傳遞

&nbsp;

過去&nbsp; 消極茫然的看待戀情

&nbsp;

現在&nbsp; 似乎也看見了光明

&nbsp;

一再一再的嘗試靠近

&nbsp;

累積了許多淚水及笑容

&nbsp;

我倆一同走過的這段

&nbsp;

只有它是難以忘卻的

&nbsp;

寒冷的時候讓我做妳的外套

&nbsp;

炎熱的時候讓我成為那陣涼風

&nbsp;

因為即便有著黑夜

&nbsp;

必定還有黎明

&nbsp;

春 夏 秋 冬 四季不斷轉換

&nbsp;

愛阿&nbsp; 愛阿&nbsp; 無數的期許

&nbsp;

讓情感自由奔放

&nbsp;

只想告訴妳

&nbsp;

我倆一同編織的童話

&nbsp;

永遠不會消失

&nbsp;

只想告訴妳一定會記得妳

&nbsp;

&nbsp;

&nbsp;
