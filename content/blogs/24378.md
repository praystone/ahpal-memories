&nbsp;

&nbsp;

無論是誰　都有一個不能實現的願望

&nbsp;

任性地強求答案　

&nbsp;

只為了不讓點燃的火苗熄滅

&nbsp;

突然聽到熟悉的旋律　

&nbsp;

在熙熙攘攘的人群中

&nbsp;

駐足不前　

&nbsp;

究竟是為了什麼？
　
沒有盡頭的夢想片段

&nbsp;

現在是否還繼續守護著？　

&nbsp;


 


是否還放在心裡？

&nbsp;

你曾寫給我文字　

&nbsp;

突然閃過了心頭

&nbsp;

因為想要見你　

&nbsp;

而就要決堤的淚水

&nbsp;

不管多麼努力

&nbsp;

伸手想要追求

&nbsp;

卻還是有得不到的東西　

&nbsp;

&nbsp;

我們可以一直就這樣　和你兩人一起

&nbsp;

注視著在遠方照映出如橘子般的夕陽吧?

&nbsp;

你那天真的眼神　還有不變的堅強

&nbsp;

希望能在這溫柔的風中一直感受著

&nbsp;

&nbsp;

不管是誰總有一天　都能得到幸福吧

&nbsp;

不要放開緊握的手　別忘了這樣的笑容

&nbsp;

無論是誰只要許下心願　就一定能再展翅飛翔

&nbsp;

不要任性地強求答案　別讓點燃的火苗熄滅

&nbsp;
