&nbsp;




禪 心 琉 璃








&nbsp;


&nbsp;




般若三昧經云： 佛是我心， 是我心見佛， 是我心作佛。


&nbsp;




有是如幻有，空是畢竟空， 空有俱不著，入大光明藏。


&nbsp;




一念心不生即如如佛。


&nbsp;




因言顯道，道顯遣言，言若不遣，因言障道。


&nbsp;




離一切心意識分別，無所取著，猶如虛空。


&nbsp;




知見立知，即無明本；知見無見，斯即涅槃。


&nbsp;




執相心著魔，離相心自在， 一切平等觀，無取亦無捨。


&nbsp;




禪是清淨一心， 不二之心是禪。


&nbsp;




禪是無對立的世界。


&nbsp;




見佛聞法，皆是自心分別， 不起見者，是名見佛。


&nbsp;


&nbsp;




不作聖心，名善境界；若作聖解，即受群邪。


&nbsp;


&nbsp;




若以色見我，以音聲求我， 是人行邪道，不能見如來。


&nbsp;


&nbsp;




應無所住而生其心。


&nbsp;


&nbsp;




吾有正法眼藏， 涅槃妙心，實相無相， 教外別傳，


今咐囑摩訶大迦葉。


&nbsp;


&nbsp;




見即是性，離性不可見，性即是見，離見無性；見性不二。


&nbsp;


&nbsp;




凡所有相,皆是虛妄
