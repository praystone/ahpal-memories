&nbsp;

「我是開玩笑啦」　一如往常

&nbsp;

惡作劇地　露出燦爛的笑容


無法對任何人言明　

&nbsp;

在漫長的夜裡獨自

&nbsp;

卸下睫毛上的睫毛膏

&nbsp;

輕輕落下的灰色淚水

&nbsp;

怎樣的思念&nbsp; 才能讓人不懂傷心

&nbsp;

在你的記憶中

&nbsp;

我是如何的一張面孔

&nbsp;

黑色的天空有散落的星光閃爍

&nbsp;

只盼望　

&nbsp;

你此刻在某處綻放幸福的笑容

&nbsp;

有限的　未來

&nbsp;

定會在留下的手心裡閃耀　現在的我願望著

&nbsp;

挺直背桿　

&nbsp;

繃緊穿著的高跟鞋　

&nbsp;

擺出與平常不同的姿態

&nbsp;

我在這裡佇立著　

&nbsp;

只有在空虛的心裡

&nbsp;

增加對你無暇的思念 

&nbsp;
