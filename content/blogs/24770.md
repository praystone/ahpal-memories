&nbsp;

告訴自己不是愛情

&nbsp;

只是錯覺

&nbsp;

雖然這樣對自己說

&nbsp;

我的心卻不由主的靠近妳

&nbsp;

倒退了一步

&nbsp;

暫停了一步

&nbsp;

越是如此&nbsp; 腦海裡妳的面容越是清晰

&nbsp;

是愛上了吧

&nbsp;

是期待了吧

&nbsp;

即使會受傷害

&nbsp;

我好像也無法遮掩

&nbsp;

原來愛是真摯的

&nbsp;

原來我的心正向著你

&nbsp;

守護著你

&nbsp;

終於明白

&nbsp;

妳那溫和的笑容

&nbsp;

妳那溫暖的話語

&nbsp;

滿滿的就是愛

&nbsp;

你也是愛我的嗎?

&nbsp;

你也期待著我嗎?

&nbsp;

有時淚水會使我們疲倦

&nbsp;

但我愛妳

&nbsp;

這就足夠了

&nbsp;

我愛妳

&nbsp;

有妳就夠了

&nbsp;
