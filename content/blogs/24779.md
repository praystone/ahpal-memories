&nbsp;

相傳過了鬼門關便上一條路叫黃泉路，路上盛開著只見花,不見葉的彼岸花。花葉

&nbsp;

生生兩不見,相念相惜永相失,

&nbsp;

路盡頭有一條河叫忘川河，河上有一座橋叫奈何橋。走過奈何橋有一個土台叫望鄉

&nbsp;

臺。望鄉臺邊有個亭子叫孟婆亭，

&nbsp;

有個叫孟婆的女人守候在那裡，給每個經過的路人遞上一碗孟婆湯。忘川河邊有一

&nbsp;

塊石頭叫三生石。喝下孟婆湯讓人忘了一切。

&nbsp;

三生石記載著前世今生來世。走過奈何橋，在望鄉臺上看最後一眼人間，喝杯忘川

&nbsp;

水煮今生

&nbsp;&nbsp;&nbsp; 

傳說人死先到鬼門關，出了鬼門關，途經黃泉路，來到忘川河邊，便是奈何橋。橋

&nbsp;

分三層，上層紅，中層玄黃，最下層乃黑色。

&nbsp;

愈下層愈加凶險無比，裡面盡是不得投胎的孤魂野鬼。生時行善事的走上層，善惡

&nbsp;

兼半的人走中層，行惡的人就走下層 


奈何橋上有孟婆，要過奈何橋，就要喝孟婆湯，不喝孟婆湯，就過不得奈何橋，過

&nbsp;

不得奈何橋，就不得投生轉世。

&nbsp;

凡是喝過孟婆湯的人就會忘卻今生今世所有的牽絆，了無牽掛地進入輪迴道開始了

&nbsp;

下一世的輪迴。


孟婆湯又稱忘情水或忘憂散，一喝便忘前世今生。一生愛恨情仇，一世浮沉得失，

&nbsp;

都隨這碗孟婆湯遺忘得乾乾淨淨。

&nbsp;

今生牽掛之人，今生痛恨之人，來生都形同陌路，相見不識。陽間的每個人在這裡

&nbsp;

都有自己的一只碗，碗裡的孟婆湯，其實就是活著的人一生所流的淚。

&nbsp;&nbsp;&nbsp; 

每個人活著的時候，都會落淚：因喜，因悲，因痛，因恨，因愁，因愛。孟婆將他

&nbsp;

們一滴一滴的淚收集起來，煎熬成湯，在他們離開人間，走上奈何橋頭的時候，

&nbsp;

讓他們喝下去，忘卻活著時的愛恨情愁，乾乾淨淨，重新進入六道，或為仙，或為

&nbsp;

人，或為畜。


不是每個人都會心甘情願地喝下孟婆湯。因為這一生，總會有愛過的人不想忘卻。

&nbsp;

孟婆會告訴他：你為她一生所流的淚都熬成了這碗湯，

&nbsp;

喝下它，就是喝下了你對她的愛。來的人眼中最後的一抹記憶便是他今生摯愛的

&nbsp;

人，喝下湯，眼裡的人影慢慢淡去，眸子如初生嬰兒般清徹。

&nbsp;&nbsp;&nbsp; 

為了來生再見今生最愛，你可以不喝孟婆湯，那便須跳入忘川河，等上千年才能投

&nbsp;

胎。千年之中，你或許會看到

&nbsp;

橋上走過今生最愛的人，但是言語不能相通，你看得見她，她看不見你。千年之

&nbsp;

中，你看見她走過一遍又一遍奈何橋，喝過一碗又一碗孟婆湯，

&nbsp;

你盼她不喝孟婆湯，又怕她受不得忘川河中千年煎熬之苦。

&nbsp;&nbsp;&nbsp; 

千年之後若心念不滅，還能記得前生事，便可重入人間，去尋前生最愛的人。&nbsp; 

&nbsp;&nbsp;&nbsp;

奈何橋邊有塊青石叫三生石，三生石記載著每個人的前世今生，石身上的字鮮紅如

&nbsp;

血，最上面刻著四個大字“早登彼岸”。

&nbsp;&nbsp;&nbsp;&nbsp; 

今生已知前生事 三生石上留姓氏 不知來生她是誰 飲湯便忘三生事。

&nbsp;&nbsp;&nbsp; 

世上有一種藥叫“龍蜒草”，它能使垂死之人不死，但卻不能活人。

&nbsp;&nbsp;&nbsp; 

傳說世上還有一種藥叫“孟婆湯”，它能使人還陽，但卻令人忘卻過去。

&nbsp;&nbsp;&nbsp; 

世上有一種草叫“斷腸草”，它會讓人恢復記憶，但它也可致命，一旦服之三天之

&nbsp;

內必會暴斃而亡。

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
奈何橋畔&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 等你千年
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
輕風裡看見&nbsp;&nbsp;&nbsp;&nbsp;你的淚如雨紛飛
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
