如果一個男人，把自己超過三分之一的總收入，用在了你身上，那麼姑且請相信，

&nbsp;

這個男人愛你。哪怕他在演戲。要考慮，他的實際收入。他要消費，他要儲蓄，他

&nbsp;

要應酬，能花三分之一收入在你身上，那就是真的。

&nbsp;&nbsp;&nbsp;

如果一個女人，把自己超過三分之一的時間，用在了你身上，那麼請姑且相信，這

&nbsp;

個女人愛你。哪怕，她在演戲，她還在和其他男人曖昧，她還在和其他男人玩選擇

&nbsp;

和被選擇的演戲，她還在掛，還在挑，還在選。

&nbsp;&nbsp;&nbsp; 

如果男人真心欺騙，如果女人真心演戲，那麼一切就是真的。女人不要說，你沒有

&nbsp;

遇到你想遇到的人，你想嫁的人，如果你的容貌身材姿色收入家庭條件出生沒有發

&nbsp;

生改變的話，按照常理和規律，你就應該和現在的人在一起。男人不要說，等我有

&nbsp;

了錢，等我成功了，等我有了權，如果你的相貌身材收入家庭姿色沒有發生根本轉

&nbsp;

變的話按照常理和規律，你就應該和現在的人在一起。你現在能遇到的，能交往

&nbsp;

的，就是你可以找到的人。所以，你不要想以後怎樣，以後是以後的事情。&nbsp; 

&nbsp;&nbsp;&nbsp; 

現在，就是現在。

&nbsp;&nbsp;&nbsp; 

沒有多少男人會泡女人了，這個年頭，男人負擔太重，活得太累。所以，即便一個

&nbsp;

是想泡你，他也是真心在泡你。如果真是為了性，為了身體，這個時代可以解決的

&nbsp;

途徑和方式很多，很直接迅速廉價。

&nbsp;&nbsp;&nbsp; 

沒有多少女人會真心在男人身上花時間了，甚至奉獻青春和身體，現在女人都功

&nbsp;

利，現實，如果你不是百萬千

&nbsp;

萬富翁，就別以為女人是想你的錢財。何況這個時代，女人想賺錢，途徑很多，方

&nbsp;

法很多，也很直接迅速快截。

&nbsp;&nbsp;&nbsp; 

所以，泡你的人，和陪你的人，都是在真心的逢場作戲，至少他們還相信愛情，還

&nbsp;

期待感情，還很純真，還很善良。

&nbsp;&nbsp;&nbsp; 

那些為你趕路，為你計劃，為你安排，為你消費，為你安排的男人，請你珍惜。也

&nbsp;

許他們並不富裕，但是甘願為你花費一周乃至數周的薪水，博取你一笑，和彼此的

&nbsp;

開心快樂，那麼他是愛你的，他是一個有道德的人，他演技高超。

&nbsp;&nbsp;&nbsp; 

那些為你化妝，為你精心準備服飾，為你推掉應酬約會，在黃金時間和重大節假日

&nbsp;

陪你的女人，請你珍惜。也許她們並不國色天香，品味非凡，氣質高雅，但是甘願

&nbsp;

在人生最寶貴的時間，一年最鄭重和值得紀念的日子，陪伴你，和你在一起，讓你

&nbsp;

不寂寞，讓彼此愉悅，相信感情和彼此溫暖，那麼她是愛你的，因為女人的青春最

&nbsp;

寶貴，一去不復返，她成功欺騙了你，欺騙了自己，喪失了機會。

&nbsp;&nbsp;&nbsp; 

也許，你不相信愛情，也許，你不能再愛，也許你覺得世界庸俗，也許，你覺得沒

&nbsp;

有什麼可以相信。那麼請相信一切都是真的。那個男人深夜裡給你發來短信和問

&nbsp;

候，再很多時間，牽掛著你，

&nbsp;

哪怕他在鶯鶯燕燕的包圍裡，只要他還記得你。

&nbsp;&nbsp;&nbsp; 

也許，你覺得這個世界物質，這個世界殘酷，這個世界沒有真愛，這個世界虛偽，

&nbsp;

這個人生虛幻，那麼請相信一切都是真的。那個女人為了你玩弄許多花樣，談論起

&nbsp;

自己很多男人追逐，很搶手，

&nbsp;

談論自己過去有很多有錢人垂涎，談論自己的家常生活，甚至只是需要一件嫁衣。

&nbsp;

哪怕，她還在左顧右盼，還在瞻前顧後，只要她還在哄你。

&nbsp;&nbsp;&nbsp;

那麼，請認真地逢場作戲。請善待那個真實欺騙你的人。請珍惜為你演戲的人。

&nbsp;

哪怕她的騙術拙劣，哪怕他的

&nbsp;

演戲低劣。請相信，他是真的。至少當時是真的，是因為他相信感情很好，愛情很

&nbsp;

美好。

&nbsp;&nbsp;&nbsp; 

至於以後，以後誰也不知道。也許他真的腰纏萬貫，在依紅偎翠時，仍然忘不了

&nbsp;

你，捨不得你，或者你是他的

&nbsp;

髮妻，你永遠是NO1，是第一位，是同患難的，是可以欺騙他一生的女人。也許你

&nbsp;

以後一文不名，窮困潦倒，眾生無望，但是有一個女人，會圍繞你身邊，不離不

&nbsp;

棄，因為你是她的丈夫，你永遠是歸宿，你演技高超，是可以和她一生做對手的那

&nbsp;

個人。

&nbsp;&nbsp;&nbsp; 

所以，欺騙是好的，只要彼此相信，心照不宣，就沒有問題。所以，演戲是好的，

&nbsp;

只要彼此投入。

&nbsp;&nbsp;&nbsp; 

人生不過百年，幕起幕落而已
