如果愛是盲目

&nbsp;

把我倆的愛釘上十字架

&nbsp;

無法掙脫

&nbsp;

無法抵抗

&nbsp;

一種色彩的愛

&nbsp;

無法自拔

&nbsp;

清楚的悸動

&nbsp;

從裡到外的感受

&nbsp;

當春風迎面吹來時

&nbsp;

伸手觸摸永恆

&nbsp;

答案就在那季節裡

&nbsp;

這是永遠嗎

&nbsp;

像水中的金魚

&nbsp;

難以別離

&nbsp;

我將明白

&nbsp;

沒有理由的愛戀

&nbsp;

如果愛是盲目

&nbsp;

就將我倆的愛釘上十字架上

&nbsp;

&nbsp;
