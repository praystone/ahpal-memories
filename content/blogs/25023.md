【轉貼】阿婆、叔公念觀世音菩薩 不可思議的真實感應

&nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;作者：思佳

說說真實的事吧，讓我們堅定此生學佛的信念！

&nbsp; &nbsp;&nbsp; &nbsp; 進入論壇後，找到了家的感覺，看到師兄們的感應事件，真心讚歎，此生我對諸佛菩薩也是感恩不盡，就我自己就有很多的感應，我想等有空了再梳理記憶把所有的都記敘下來，跟師兄們分享。

突然想先把啊婆的事寫下來，以前阿婆曾對我講過這些事，前陣子我也打長途電話過去征得她的同意，由她再詳細闡述，我記下來。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;阿婆是我在家鄉的蓮友，已受五戒，吃長齋，懂佛理，非常精進，學佛應該二十多三十年了，拜佛人都稱她為老菩薩，深受眾人的敬重，我也非常崇敬她！以下是她其中的兩件感應事件（阿婆口述，我寫）：

&nbsp; &nbsp;&nbsp; &nbsp;阿婆的丈夫是老海軍，以前出生入死打戰的，軍人出生的他不怎麼相信佛法，常常是家裡播放法師講經的牒時，法師在電視講，他就在下面胡亂反駁，但由於夫妻感情好，也並沒強烈反對阿婆拜佛。

十多年前的那件事發生後，叔公（阿婆的丈夫我尊稱他為叔公）就開始對佛法深信不疑，並也開始持誦大悲咒了。叔公身子一直不好，有心臟病、糖尿病、高血壓。十多年前，叔公突然心肌梗塞，非常嚴重，送到醫院時已經不省人事，醫生覺得很難救活，一定要家人簽好像是病危通知書才肯接手搶救。叔公一連好幾晚都不省人事，阿婆的女兒也很有善根，正當醫生、家人都束手無策時，她對阿婆說，既然醫生都沒辦法了，我們求他們也沒用，不如專心求佛菩薩吧，也許還有希望。於是，他們把觀世音菩薩的聖像掛在醫院掛輸液瓶的架子上，阿婆日夜不停地為叔公專心誦大悲咒，祈求觀世音菩薩大慈大悲救助丈夫。

叔公心臟病嚴重，醫生交代不能讓病人平躺著睡覺，所以在他的背部墊了個枕頭半躺著睡，那時的他也已經失去直覺了，連坐都不坐不了，半躺著不到一會，他就自動滑下平躺。阿婆整晚都沒睡，邊持大悲咒，邊看護他，他一滑下來，就把他拉高一些，如此整夜反復不斷。心裡非常地焦急、擔憂，越急越憂就越專心誦咒。

&nbsp; &nbsp;&nbsp; &nbsp; 突然半夜裡，叔公竟然奇跡地清醒並開口說話，口齒也清晰，要求阿婆扶起他整個坐直來，好像還要求要站起來。之前醫生還交代過，也不能讓他有大的動作，所以阿婆不肯。只見叔公這時神情嚴肅，猛地一用力竟自己坐直起來，鄭重其事地用手打了個手印（食指和中指伸直叉開），對著自己正前方好像想要夾什麼東西，口裡還大喊了一句：“制住你！”之後就靠在枕頭上安詳地睡去。啊婆不解，還以為是因為不肯扶他起來，他發脾氣罵她，當時阿婆也感到挺委屈的。

&nbsp; &nbsp;&nbsp;&nbsp;第二天，醫生就宣佈叔公已經脫離危險。後來叔公才說了那晚半夜的情形。他說他一直迷迷糊糊地毫無知覺，就在那時忽然在病房的正前方看到無比殊勝的勝境，群山連綿不斷，雲煙繚繞，每一個山頭站著一尊佛，每尊佛都閃爍著耀眼的金光，連綿不斷的山，無數的佛菩薩，金碧輝煌、非常美妙。他掙扎著坐起來看，實在太美了，他心中讚歎無比！可就在這時，突然旋過一股黑色的旋風，眼看就要破壞這一美妙的境界，叔公心裡此時湧起一個念頭：如此莊嚴的佛界怎能容你這妖風破壞，定要捍衛！一急就情不自禁地打了個手印，大喊一聲：“制住你！”，於是妖風就被夾走。之後，叔公感覺相當舒適，竟睡著了。

&nbsp; &nbsp;&nbsp; &nbsp; 在這之前，搶救的這段時間，叔公說他心臟一絞痛起來，好像整個心被人撕扯一樣，疼到差不多要暈過去。當時醫生為他打止痛針，好像是叫杜冷丁（阿婆用方言口述的，我直譯過來，不知道會不會打錯這藥名字），連打了四針都沒感覺，醫生不肯打第五針，醫生說再打，就算搶救過來也會癱瘓。疼痛難耐時，不知道為什麼，平時不信佛的他，竟然叫了一句：“觀世音菩薩救我”，就一句，馬上不痛了。

&nbsp; &nbsp;&nbsp; &nbsp; 還有更加不可思議的事，住院期間，唯獨叔公的病房，白天就從病房上方遠遠傳來人們念“南無觀世音菩薩”的聖號的聲音，阿婆和家人都跟著念，晚上就是“地藏菩薩”聖號。阿婆也納悶，十多年前哪有什麼念佛機，總以為有信佛的醫生在醫院最頂樓播放碟片。好幾次都尋聲去找，根本就找不到什麼，就是從天上遠遠飄下來的。奇怪的是，別病房的人都聽不到，就他們一家在叔公病房裡能聽到。

&nbsp; &nbsp;&nbsp; &nbsp; 出院時，醫院的主任告訴他們這是個奇跡，還指著輸液架子上掛著的觀音菩薩像說：“是她救了他的！”，聽說跟叔公一同入院同種病、病情比他輕的病人已經離世了。

&nbsp; &nbsp;&nbsp; &nbsp; 這是阿婆真實的事，今晚還得誦經，沒時間了，先說一件和師兄們分享。

（我和阿婆都是佛家皈依弟子，深深明白說妄語的果報，以上是真實的事件，希望對佛教仍然信心搖擺的師兄，能由此生起信心）南無大悲觀世音菩薩 ！

&nbsp; &nbsp;&nbsp; &nbsp; 阿婆的事還有，哪天還有空我再寫下來。
