&nbsp;

人～從一無所有的墜地，來到繽紛多彩的世界長大，融入環境

&nbsp;

多了欲望，多了追求，多了夢想，努力是為了實現目標，奮鬥是為了實現理想

&nbsp;

拼搏是為了更多的追求，不一樣的人，造就不一樣的生活

&nbsp;

生活的多彩來自每個人，不同的鍛造

&nbsp;

&nbsp;

尊嚴上～

&nbsp;

我們是一樣的，人格上我們也是平等


&nbsp;

經歷過許多的故事，看到太多的人生起伏

&nbsp;

安靜的面對各式各樣的人群


&nbsp;

再沒有不適，也沒有激動，更沒有無妄的自大

&nbsp;

看著比我生活好的人，沒有無故的羡慕

&nbsp;

看到生活不如我的人，也沒莫名的優越

&nbsp;

&nbsp;

平常心對待所有的事情～

&nbsp;

也是人生的一大筆財富，淡然的生存

&nbsp;

恬靜的佇立於世間，平穩實在的守著安穩的工作

&nbsp;

神情安祥的立足於自己營造的世界

&nbsp;

也是生存的方式，他人的生活沒必要去指手劃腳

&nbsp;

別人的世界，也沒有必要去流言蜚語

&nbsp;

過好自己，遵守生存的規則對已對人，都是一種尊重

&nbsp;

&nbsp;

人都是一樣～


&nbsp;

誰能沒有富貴，誰能沒有落魄

&nbsp;

誰又不是赤裸的來，誰又不是赤裸的去

&nbsp;

所有的繁華只在一轉眼，所有的落魄也是一瞬間

&nbsp;

大起的創造很簡單，大落的失去也很容易

&nbsp;

全都在瞬間的改變中

&nbsp;

&nbsp;

人的等值很簡單～

&nbsp;

簡單到一個詞：平等

&nbsp;

可是這簡單的詞，有人卻需要一生的時間來詮釋

&nbsp;

有的人，可能一生也無法理解

&nbsp;

看到暮暮蒼年的老人，我會靜靜的長時間的注視

&nbsp;

注視著已經被歲月渾濁了的眼睛

&nbsp;

這雙經過命運洗禮過後的眼睛

&nbsp;

渾濁過後有一種釋然，一種對經歷過後的釋然

&nbsp;

一種對人生探索過後的大徹大悟。
