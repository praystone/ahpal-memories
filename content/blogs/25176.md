夜裡的深吻&nbsp;&nbsp; 在秋日之聲的盡頭

&nbsp;

來自遠方的訊息令內心充滿感慨

&nbsp;

寂靜窗外是憂傷的荒野

&nbsp;

在不經意問起&nbsp; 這是個什麼樣的季節

&nbsp;

如在此道別&nbsp;&nbsp; 且許下諾言

&nbsp;

兩者如撕裂胸口般&nbsp;&nbsp; 

&nbsp;

故作堅強&nbsp; 迎接著季節轉變

&nbsp;

遠超過天長地久&nbsp; 我倆的愛戀

&nbsp;

雖不是最初&nbsp;&nbsp; 也不是最完全的

&nbsp;

但終將成了愛&nbsp;&nbsp; 倆人心中稱作最後的戀情

&nbsp;

真的如此認為

&nbsp;

總在難眠的夜晚&nbsp; 心裡反覆回味那句「明天見」

&nbsp;

被這如月有圓缺的缺陷愛戀&nbsp;&nbsp; 灌溉了千百回

&nbsp;

若是不自覺再次&nbsp;&nbsp; 走上這回頭路

&nbsp;

妳說 「如果想我就回來吧」

&nbsp;

那特有的語調 和傻氣.及熟悉的溫柔

&nbsp;

會使我熱淚盈框

&nbsp;

回首我仍認定是妳

&nbsp;

無法忘卻&nbsp; 妳就是我的深愛
