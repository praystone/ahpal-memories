&nbsp;

某報章精選了30件最開心的事，它們都是些生活瑣事，也許你平時不曾注意，可一經提醒就會覺得，世界瞬間變得如此美好。 

&nbsp;

&nbsp;

1、摸摸口袋，竟然發現裏面有錢。 

&nbsp;

2、成功趕上將要出發的汽車或火車。 

&nbsp;

3、別人為你按著電梯門的“開”鍵，等你進來。 

&nbsp;

4、電話響了，你拿起聽筒發現正是剛才在想的人。 

&nbsp;

5、請別人為你撓背，他一下子撓到了最癢的部位。 

&nbsp;

6、突然想起小時候最好的朋友的電話號碼。 

&nbsp;

7、你打算買的東西降價了。

&nbsp;

8、乾淨俐落地撕下有黏性的價格標簽。 

&nbsp;

9、衣服上弄了污漬，但輕鬆洗掉了。 

&nbsp;

10、把手指上的刺挑出來了。 

&nbsp;

11、傾聽烤肉在烤架上發出“咝咝”的聲音。 

&nbsp;

12、一下子將廢物扔進了垃圾箱，太準了。 

&nbsp;

13、想著今天是星期三，其實是星期五。 

&nbsp;

14、和朋友一起聊明星八卦。 

&nbsp;

15、把最後一塊圖案放進拼圖裏。 

&nbsp;

16、從洗衣機裏取出的兩隻襪子剛好是一雙。 

&nbsp;

17、完美地磕開一個雞蛋。 

&nbsp;

18、收到一封信，地址是手寫的。 

&nbsp;

19、清空電腦的回收站。 

&nbsp;

20、終於解開一個死結。 

&nbsp;

21、換了張乾淨的新床單。 

&nbsp;

22、坐飛機時，一大排座位就你一個人。 

&nbsp;

23、炎熱天氣喝下一杯冰水。 

&nbsp;

24、下雪後，第一個踩出腳印。 

&nbsp;

25、吃媽媽做的炒雞蛋。 

&nbsp;

26、開了半天車，一路都是綠燈。 

&nbsp;

27、需要擁抱的時候，得到一個溫暖的擁抱。 

&nbsp;

28、排隊時，你所在的隊伍最快了。 

&nbsp;

29、廣告時間換了頻道，返回來的時候節目恰好開始。 

&nbsp;

30、發現明年生日那天是星期六或星期天。

&nbsp;

&nbsp;

這些看似簡單的小細節卻能讓人擁有開心的元素.
