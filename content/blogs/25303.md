黎明前天空仍泛紫時

&nbsp;

在我倆相繫相依的心中

&nbsp;

萌芽的深情緩緩展開

&nbsp;

逐漸滿佈的曙光&nbsp; 沾染了妳容顏

&nbsp;

我們所共同擁有的事物

&nbsp;

在他稱作回憶前

&nbsp;

都要緊緊抱住&nbsp; 永不放手

&nbsp;

手牽著手傳來的暖意是如此溫柔

&nbsp;

輕擁著你&nbsp; 相互吸引

&nbsp;

偶然相遇的兩人預料般的相戀

&nbsp;

總因搖擺的思緒而感不定

&nbsp;

如多變的氣候覆蓋著思緒

&nbsp;

坦然迎對&nbsp;&nbsp;

&nbsp;

我倆刻劃的道路

&nbsp;

一定能通往天際

&nbsp;

直到那無邊界的盡頭&nbsp; 

&nbsp;

我對你的心永遠不變

&nbsp;

在一切化作回憶之前

&nbsp;

都要緊緊握住&nbsp; 永不鬆手

&nbsp;

&nbsp;
