&nbsp;

&nbsp;

從前年例行體檢.發現有顆大於2.3CM生存於我膽裡的石頭小姐.


&nbsp;

為了這不其而遇.我給它取名為綠石丹.

&nbsp;

本以為該聽從醫師指示如有發炎疼痛狀況需緊急開刀切除.


&nbsp;

為了不想讓自己變成一名(無膽的女人).我採納一位非常要好朋友的建議.

&nbsp;

實施我7天(99.10.25)排膽日生活~(膽結石食療法（雷久南博士）)

&nbsp;

第1~5天:早中晚外加宵夜須在飯前照實服用蘋果汁(我都喝現榨)正常飲食.


每天四杯.一杯約250CC.

&nbsp;

剛開使喝時沒什麼感覺.但越到後面每喝一次便會感到帳氣不適感.


&nbsp;

好友說:應該是綠石丹在軟化作用而引起的局部膨脹感.


&nbsp;

還跟我開玩笑說:喝了皮膚會更水潤唷~~嗯~發現有耶.皮膚更美囉&gt;&lt;

&nbsp;

第6天停止蘋果汁的飲用.不吃晚餐.在晚上1800及20:00這兩個時段需喝下瀉鹽水二百五十西西.

&nbsp;

本以為藥局有賣此鹽.跑了幾家才發現現禁止發售.於是拜託友人至天水街的化工原料公司購買.


&nbsp;

聽那家的老闆娘:許多排膽石之人都服用過此配方.效果都很顯著.


&nbsp;

回診也都發現膽石清除且不危害人體.免除開刀之痛.而且這偏方已流傳20多年了.

&nbsp;

說真的喝下這2杯鹽水真是不舒服.又苦又鹹.反胃感十足.我給它★★★★★~


&nbsp;

而且肚裡彷若在大戰.一直翻攪著.此時的我又餓又脹又痛.給它不是很開心..

&nbsp;

別以為這樣就結束囉.登登~好戲在後頭...

&nbsp;

喝完鹽水後.小歇片刻.重頭戲上場.

&nbsp;

在22:00還須喝下新鮮檸檬一至二個壓汁半杯.加入半杯橄欖油(約125CC).


混勻後空腹服下.


&nbsp;

服用後還需右側躺臥.在膽囊部位做局部的熱敷.特別是膽囊.膽管處.

&nbsp;

原以為喝鹽水已經粉不舒服了.沒想到檸檬汁加橄欖油更讓我痛斥.


&nbsp;

你想想一杯檸檬汁上浮現滿滿的油.那情景多壯觀.


&nbsp;

我望著那一杯.一直給自己心裡建設:妳可以的那沒什麼.至少免於開刀之苦.又加上好友的鼓勵.


&nbsp;

淺嚐一口..我的天啊~反胃感指數★★★★★★★★~


&nbsp;

很酸又很油..我一邊攪拌一邊慢慢吞食..直到見到杯底..好想哭喔我&gt;&lt;


&nbsp;

我給自己一個大大的擁抱~因我做到並完成整個療程~丹妳是最棒的^^


&nbsp;

喝完後馬上上床用電毯熱敷.心想才22:00.怎睡的著..沒想到想著想著就睏去呀.

&nbsp;

第七天不知是太早睡還是興奮5點多就起來了.隨即空腹喝下一大杯冷開水.等待綠石丹的到來.

&nbsp;

等時肚裡一直發出咕嚕咕嚕的聲響.好餓喔&gt;&lt;...

&nbsp;

等到7點多終於想恩恩了.趕緊跑到WC.很多~但我沒勇氣清洗恩恩所以以下省略..


&nbsp;

但發現許多暗綠色的東西.我想那應該就是了~


&nbsp;

這幾天找個時間會去醫院照個超音波看是否有減少與減輕~

&nbsp;

飲食習慣真的頗重要..希望亞寶的好友們日常多加注意.大家都健康.

&nbsp;

特地PO膽友所排出的結石..不要嚇到呢&gt;&lt;
