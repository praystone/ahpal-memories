養貓2年後，我搬了新家，買了1隻雪納瑞狗狗，取名莫妮卡。


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


莫妮卡眉毛、嘴巴及四肢的毛色是白色，其他則是黑色，據說黑色部份會慢慢變成銀色，好像有點那麼回事，因為每一次幫莫妮卡剪毛美容後，就發現牠好像黑顏色的部份有點不太一樣了。


&nbsp;


雪那瑞又別名老夫子狗，那長長的眉毛及鬍鬚是特色，許多絨毛玩具都會以雪納瑞作造型，因為牠們很有特色，這也是我喜歡雪納瑞的原因，雪納瑞其實是工作犬，當初是被培育來田裡抓老鼠的，牠們肌肉很結實，運動量比較大，得有足夠的空間讓牠們奔跑和運動，牠們也是一種很容易有遺傳性皮膚病的狗，所以如果沒有足夠的耐心和愛心，還是奉勸各位別養雪納瑞。


&nbsp;


幾個月後，我們又買了妮可，一樣是雪納瑞狗狗，這是為了讓莫妮卡有個伴，尤其我們上班的時候，狗兒獨自在家會很寂寞，妮可比莫妮卡更愛撒嬌，有時候我和女兒們抱抱，妮可會汪汪叫著擠到我們中間，十足表達她吃醋的意願。莫妮卡愛咬衣服和襪子，每次收衣服都得防著牠偷咬襪子去躲起來玩，妮可則是愛咬毛巾，2隻狗狗都粉調皮。


&nbsp;


莫妮卡和妮可剛來的時候都試圖跟貓咪玩，但是發現貓咪並不喜歡跟牠們玩，甚至還會甩牠們巴掌，就學聰明離貓咪遠一點，免得不小心被甩巴掌。有幾次莫妮卡窩在我身上撒嬌，貓咪也跳上來找我，莫妮卡就會定住不動，眼神偷偷喵著貓咪，彷彿告訴貓咪：我可沒招惹你喔，別甩我巴掌。


&nbsp;


由於雪納瑞造性特殊，所以剛開始我們都帶牠們去給美容師美容，每次要價約800元，2隻狗狗就要1600元，後來我買了電剪，上網搜尋寵物美容教學影片，開始自己幫牠們美容，才發現，呵，我手藝還不錯哩，電剪加上打薄剪，一切都可以搞定，每月的寵物美容費用，就輕鬆地省下來囉。


&nbsp;


不過一次幫2隻狗狗剪毛洗澡，會讓我腰酸背痛，所以我現在會錯開牠們美容的時間，因為牠們的毛髮捲曲，很容易打結，莫妮卡剪毛很乖，妮可就很不喜歡電剪接近頸部以上，所以每次幫妮可剪毛我都有點辛苦，因為牠會一直動來動去，得半哄半威嚇，才能順利剪完，


&nbsp;


說到遺傳性皮膚病，莫妮卡皮膚就真的比較不好，很容易就會有皮膚病，剛開始帶去給醫生看，又是打針又是吃藥的，後來我在網路上努力找資料，發現硫磺可以治療狗狗的皮膚病，就在寵物店買了一罐硫磺，狗狗洗完澡後毛髮半乾時，抹上硫磺，再用吹風機吹乾，幾次皮膚病就會好了，還挺有效的。


&nbsp;


狗狗很黏人，跟貓咪完全不同，幾乎是我走到哪，牠們就跟到哪，我洗碗的時候，牠們窩在我腳邊，我打電腦的時候，牠們躺在旁邊打盹，我一站起來，牠們會很快地立刻站起來走在我前面，我看電視的時候，莫妮卡躺在我身上，妮可窩在我腳邊，睡覺的時候更不用說了，每晚我都抱著莫妮卡睡覺，冬天到了，牠可是我的專屬暖爐，妮可還是選擇窩在我腳邊，把我的小腿肚當作牠的枕頭。


&nbsp;


平常時候2隻狗狗會玩得不亦樂乎，牠們喜歡互相追逐，然後互咬，莫妮卡會讓妮可，妮可則是有時候會玩得太過火，咬傷莫妮卡，我們只要發現妮可太興奮了，就會阻止牠，避免妮可玩的沒節制而去傷了莫妮卡。


&nbsp;


雪納瑞警戒心很夠，妳如果到我家，乖乖坐在沙發上聊天，牠們就不會叫，一旦你站起身，牠們就會警戒地大叫起來，目前我們用一種讓狗狗不要亂叫的方法，叫做「天譴」法，就是用鐵盒子裝銅板，當他們亂叫的時候，就搖動罐子，加上命令：「不可以」，牠們就會停止狂吠了，因為牠們很不喜歡那種聲音，雖然有點殘忍，但為防止他們亂吠擾亂鄰居，說真的，這招還真的不錯用。


&nbsp;


牠們還很貪吃，這種狗狗胃口很好，幾乎甚麼都吃，但是為了狗狗的健康，人類的食物還是不可以給狗狗吃，我們只讓牠們吃狗飼料，是皇家品牌雪納瑞專用的飼料，可以減少皮膚病的產生，另外，就是狗零食和狗餅乾，還有每天跟我一起分享水果，一碗滿滿的水果我和莫妮卡、妮可分著吃，牠們可是從我切好水果就開始等囉。


&nbsp;


愛貓，愛狗，牠們雖不會言語，但是就覺得牠們眼神中，總是訴說著許多心情，每次看到虐待動物的影片或照片，都會覺得很殘忍，都會不自禁詛咒那些虐待動物的人，牠們這麼可愛，那些人於心何忍啊？


&nbsp;


和大家分享我的寵物經，也希望大家都能愛護動物，希望盡一份微薄的力量，好減少虐待動物的事件發生。
