&nbsp;




誰是誰的誰,誰為誰哭泣 (網路小品)


&nbsp;

人活一世，短短幾個載。

&nbsp;

誰是誰的誰，終究都要灰飛煙滅。

&nbsp;

誰是誰的誰，終究都要隨風而逝。

&nbsp;

誰是誰的誰，終究是多情總被無情傷。

&nbsp;

誰是誰的誰，誰又在為誰哭泣。

&nbsp;

生活中，總是希望能再多一點快樂分給身邊的人，

&nbsp;

不管是朋友、同事、還是擦肩而過的路人。

&nbsp;

一個微笑總會給自己和別人帶去好心情。縱然心底有著說不出的憂傷。

&nbsp;

都說多愁的人容易老，我想這就是我總是健忘的原因吧。

&nbsp;

想的太多，太遠。要求太多，太高。

&nbsp;

總是在理想和現實中徘徊，不知所措.

&nbsp;

總是恍惚著過日子，一天又一天。

&nbsp;

也許，有天，我會憂患成疾。

&nbsp;

僅管，我已盡心、盡力的告訴自己要快樂，也竭盡全力的讓自己做到。



網路中，總象個孩子肆意的索取溫暖。我找到了自己想要的那種感覺。

&nbsp;

不要求什麼，只希望心靈安寧，釋放情感。

&nbsp;

不管生活與網路，與人相處，與人交流，必不可少。

&nbsp;

人要生存，必先學會處事。

&nbsp;

只是，在社會打滾十多年的自己，在為人處事上總是欠缺著應有的冷靜和包容。

&nbsp;

僅管自己已經給努力的去做，但離目標總還是相差甚遠。

&nbsp;

自己也深知，不可能做到讓每個人都滿意，但心底總是多了一分擔憂。

&nbsp;

也不知從何時起，我懼怕起了孤單。



某天，某時。心生不滿，管不住自己的衝動，前去理論。

&nbsp;

自是沒有好的言語相待。

&nbsp;

雖然最終微笑和解，但還是明白，只要有裂縫就不可能還原。

&nbsp;

覺得自己還是不夠大度，包容不了一些事情。遇事還是那般衝動，如同孩子。

&nbsp;

不知道，我這樣的孩子何時才能長大，才能懂事。　

&nbsp;

其實，誰是誰的誰？何必在乎，何必計較？能夠在茫茫網海相遇，相識，已是難得

&nbsp;

的緣份。

&nbsp;

再有緣份一起共事，更是難能可貴。自當好好珍惜都來不及，又怎能去計較。

&nbsp;

如果自己能再多一分容忍之心，多一分寬大之意，就可以免去許多不必要的小矛

&nbsp;

盾。何樂而不為？

&nbsp;

誰是誰的誰，說到底，誰也不是誰的誰，誰也不會永遠陪誰。

&nbsp;

又何必在意，何必將一些小事記於心？

&nbsp;

給別人快樂，就是給自己開心，給別人幫助，就是給自己積德。

&nbsp;

誰是誰的誰，不重要。

&nbsp;

能讓身邊的人都開心、快樂才重要。
