女孩終於鼓起勇氣對男孩說：「我們分手吧！」&nbsp;&nbsp;&nbsp;&nbsp; 


男孩問：「為什麼？」&nbsp;&nbsp;&nbsp;&nbsp; 
女孩說：「倦了，就不需要理由了」&nbsp;&nbsp;&nbsp;&nbsp; 


一個晚上...&nbsp;&nbsp;&nbsp;&nbsp; 


男孩只抽煙不說話、&nbsp;&nbsp; 


&nbsp;

女孩的心也越來越涼『連挽留都不會表達的情人 能給我什麼樣的快樂？』&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

過了許久 ... 


&nbsp;

女孩終忍不住說：「怎麼做你才能留下來？」&nbsp;&nbsp;&nbsp;&nbsp; 


女孩慢慢地說：&nbsp;&nbsp;&nbsp;&nbsp; 


「回答一個問題，如果你能答到我心裡就答案，我就留下來。&nbsp;&nbsp; 


「比如我非常喜歡懸崖上的一朵花，而你去摘的結果是百分之百的死亡，你會不會

摘給我？」&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

男孩想了想說：「明天早晨告訴你答案好嗎？」&nbsp;&nbsp;&nbsp;&nbsp; 


女孩的心頓時灰了下來. 


早晨醒來，男孩已經不在、&nbsp; 

&nbsp;

只有一張寫滿字的紙壓在溫熱的牛奶杯下，&nbsp;&nbsp; 


&nbsp;

第一行，就讓女孩的心涼透了：&nbsp;&nbsp; 


&nbsp;

「親愛的，我不會去摘 但請容許我陳述不去摘的理由 你只會用電腦打字 卻總把

&nbsp;

程式弄得一塌糊塗 然後對著鍵盤哭 我要留著手指給你整理程式 你出門總是忘記

&nbsp;

帶鑰匙 我要留著雙腳跑回來給你開門 酷愛旅遊的你 在自己的城市里都常常迷路 

&nbsp;

我要留著眼睛給你帶路 每月（好朋友）光臨時 你總是全身冰涼，還肚子疼 我要

&nbsp;

留著掌心溫暖你的小腹 你不愛出門 我擔心你會患上自閉症 我要留著嘴巴軀趕你

&nbsp;

的寂寞 你總是盯者電腦 眼睛給糟蹋得已不是太好了 我要好好活著 等你老了 給

&nbsp;

你修剪指甲 幫你拔掉讓你懊惱的白髮 拉著你的手 在海邊享受美好的陽光和柔軟

&nbsp;

的沙灘 告訴你一朵朵花的顏色 像你青春的臉… 所以 在我不能確定有人比我更愛

&nbsp;

你以前 我不想去摘那朵花…」&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

（女孩淚滴在紙上...形成晶瑩的花朵）&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

抹淨眼淚，女孩繼續往下看：&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

「親愛的 如果你已經看完了 答案還讓你滿意的話 請你開門吧 我正站在門外 手

&nbsp;

裡提著你最喜歡吃的鮮奶麵包…」&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

女孩拉開門


看見他的臉...&nbsp;&nbsp;&nbsp;&nbsp; 


緊張得像個孩子...&nbsp;&nbsp; 


只會把擰著麵包的手在她眼前晃. 


&nbsp;

我想這就是愛情或者生活、被幸福平靜的包圍時、&nbsp;&nbsp; 


一些平凡的愛意，總被渴望激情和浪漫的心忽略，&nbsp;&nbsp; 


&nbsp;

愛！在雙方引起的許多個微不足道的動作裡，&nbsp;&nbsp;&nbsp;&nbsp; 


從來就沒有固定的模式、&nbsp;&nbsp; 


&nbsp;

只有愛；&nbsp;&nbsp;&nbsp;&nbsp; 


可以是任何一中平淡無奇的形式 ，花朵、浪漫 、&nbsp;&nbsp;&nbsp;&nbsp; 


不過是浮在生活表面的淺淺點綴 ，&nbsp;&nbsp; 


在它們的下面才是我們真實的生活。
