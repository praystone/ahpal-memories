【軟體介紹】：

hromePlus 為 Google Chrome的「全套件加強版」！

ChromePlus 與 Chrome 一樣，都是以 Chromium 這個開放源碼專案為基礎而開發出來的瀏覽器，所以 ChromPlus 和 Chrome 是一樣核心的瀏覽器。差別在ChromPlus多了「滑鼠手勢」、連結「超級拖曳」、「雙擊關閉」分頁，還有可以用 IE 核心瀏覽在 Chrome 裏「以 IE 開啟網頁」的 IE Tab。
