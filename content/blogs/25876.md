&nbsp;

&nbsp;　　　　　 
　　　　&nbsp; &nbsp; 

　　　　 生命已到盡頭，孤獨、徬徨無助，感覺有如被判了死刑的犯

人


&nbsp;

　　　　　　　讓越來越愚鈍的思緒包圍著，氣虛如燈芯亦如絲

&nbsp;

　　　　　　　　　　　求生的意志鬥不過死神的招喚

&nbsp;



　　　　　　　　&nbsp; 你來到我的身邊，總以是虛幻假境不宜理睬

&nbsp;

　　　　　　　可是我真的累了很想借個依靠，來證明自己還活著

&nbsp;

　　　　　　　　　　　意志薄弱游走生死邊緣之際的我

&nbsp;

　　　　　　　　　　對於你勤於問候、安慰與鼓勵的話語

&nbsp;

　　　　　　　　　　　　　我迷惑了 我真的迷惑了





　　　　　　　　我不懂...我真的不懂...你的話語是愛情還是友誼


　　　　　　　　　　&nbsp;&nbsp; 或許是我故意陷在錯誤的泥沼之中

&nbsp;

　　　　　　　　&nbsp; 感情並非一場遊戲，我不該用玩的心理去面對

&nbsp;

　　　　　　　既然是玩的心理我就不該栽進去，讓將盡的生命複雜





　　　　　&nbsp; 你這不速之客，匆匆的來匆促的走，讓這不了情而不了了之


　　　　　　&nbsp; 如今是愛情還是友誼已不重要了，因為我確實是愛你的

&nbsp;

　　　我一天天的告訴自己，不要在去想你了，不要讓思念的痛在心裡糾纏著

&nbsp;

　　　　　　　　　　　　　　偏偏迷亂的心揮之不去





　　　　　　　　不是有這麼一句話：「人之將死、其言也善嗎？」


　　　　　　　為何我這將死的心，很壞很壞不聽話的讓自己愛得心碎


　　　　　　不是有這麼一句話：「不是路已走到盡頭，而是該轉彎了」


　　　　　　我乖乖的聽話，乖乖的轉彎了，可是碰到的還是路的盡頭


　　　　　　　　或許命中註定，我如小小流星，瞬間一閃即逝...
