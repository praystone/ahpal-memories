&nbsp;




不是每個擦肩而過的人都會相識，也不是每個相識的人都會讓人牽掛，


至少我們在今生，在那個地方,在一轉身的時候沒有錯過。

&nbsp;

在我們雙眼相望的時候，在眼中找到了愛的緣份。

&nbsp;

若大的球上能和你相遇真的不容易，感謝上天給了我們這次相識，相戀的緣份。

&nbsp;

別忘了，你的世界我曾經來過。
&nbsp;
曾經我也帶給你快樂，曾經我也帶給你幸福。

&nbsp;

曾經我也讓你焦灼和無奈，曾經我也讓你等待和期盼。

&nbsp;

也曾經我們都忘了自己，體會那心跳的感覺和纏綿的愛。

&nbsp;

不是每一段愛情都有美麗的回憶，也不是每段回憶都是那麼的刻骨銘心。

&nbsp;

我們即使不能相伴到老，我也會在這裡為你祝福,

&nbsp;

即使某天這一段感情再也無法繼續，

&nbsp;

相信你也會記得有一個人和你相依偎，

&nbsp;

有一個時常會惹你生氣的我。
&nbsp;
因為你已是我今生永遠無法割捨的牽掛。因為再多的東西也換不回擁有你的日子。

&nbsp;

也許你已經忘了你的那句‘我愛你’但我付出的依然是最真的心。

&nbsp;

如果你真的愛我，那我是幸福的。 

&nbsp;

就算和你走不到天涯，我的心依然為你牽掛。

&nbsp;

當你不開心的時候，我會陪你流淚。

&nbsp;

當你不快樂的時候，我就是你的開心果。

&nbsp;

當你孤獨的時候，我會陪伴你左右，你傷感的時候，我會和你一樣的憂鬱。

&nbsp;

當你夢見我的時候，那是我再想你了...
&nbsp;
有時候執著是一種負擔或者是一種傷害，放棄卻是一種美麗。

&nbsp;

當愛情不能完美，我寧願選擇無悔，不論來生多麼美麗，我無法失去今生對你的記憶！

&nbsp;

為什麼路的後面還是路，為什麼故事結束還有那麼多的假如。

&nbsp;

如果今生我們注定擦肩而過，那我深深地祝福你永遠快樂。

&nbsp;

然後收起有關於的你一切，期待來生與你相遇。

&nbsp;

淚水是我想你的滋味，我付出的心無力挽回，如果回憶是唯一的回信，我不會忘記我們曾經的美麗。

&nbsp;

淚已流下來，怎可讓它堆積成海。

&nbsp;

如果某天你我分手，我願做你眼裡的一滴淚，當你把我哭出來的時候，讓我在你的唇邊消失。
&nbsp;
鳥兒和魚兒相愛了。

&nbsp;

可是，它們活在兩個世界。於是，鳥兒傷心地飛向另一片海域，魚兒游向海底最深處。

&nbsp;

有天你航行累了，如果那時覺得我還是你可以信賴的港灣，

&nbsp;

如果那時我的港灣裡沒有航船，我會毫不猶豫歡迎你靠岸。 

&nbsp;

有些話只說一遍，即使我們分開了，我也會笑著活下去。

&nbsp;

其實離開你，比當初愛上你更需要勇氣.

&nbsp;

不想說再見，是因為我們要分別；不能說再見，是因為眼眶中有淚。

&nbsp;

緣聚緣散我們只能默然......

&nbsp;

也許生命中最美的就是這種沒有結果的感情，一切都來不及表達，


所有的，可能都因死亡或錯過而冰封。

&nbsp;

也許是緣份，我們都不願傷害最不願傷害的人，相信你，因為我愛你，讓我們彼此好好珍惜。

&nbsp;

每一份感情都很美，每一程相伴也都令人迷醉。
&nbsp;
是不能擁有的遺憾讓我們更感縫眷； 

&nbsp;

是夜半無眠的思念讓我們更覺留戀。 

&nbsp;

既然我們不能相伴，就讓我們笑著說再見，苦苦的追尋並不能讓生活更圓滿。 

&nbsp;

也許一點遺憾，一絲傷感， 會讓這份感情更值得懷念。

&nbsp;

不要求你給我太多，也不要求你的任何承諾和你的任何責任 。

&nbsp;

更不要求你能深深的記著我一輩子..

&nbsp;

只要你記著我們曾經的一切。 

&nbsp;

只想讓你偶爾的時候還會想起我，偶爾想起那個曾經深深愛過你的人，那個曾經為你流淚的人。

&nbsp;

請你一定要記得，你的世界我曾經來過。

&nbsp;

雖然我們不能並肩走下去，可我們也曾帶給彼此不少的歡樂。

&nbsp;

請記得一定要比我幸福！
