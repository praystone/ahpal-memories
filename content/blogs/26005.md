&nbsp;


一家知名企業登報應徵會計人員，廣告才登了二天，


應徵的履歷表就如雪片般的飛來


公司經過初步篩選，總計發出了三十封面試的通知書函。


&nbsp;


結果，經過面試而被錄用的女孩，才貌普通，


&nbsp;


表面上看起來，實在找不出有什麼特別過人之處，


&nbsp;


能擊敗其他二十九位對手，實在令人大感意外。


&nbsp;


公司中的幹部人員，都說她一定是被幸運之神給眷顧了，


&nbsp;


若是根據往例判斷，憑她的條件，根本不可能被錄用。


&nbsp;


幸運的她在公司任職二年後，


&nbsp;


總經理的專任秘書突然發生車禍，嚴重的傷勢在短期內無法復原，


&nbsp;


而工作必須立刻有人接手，


&nbsp;


但總經理的執拗脾氣和工作習慣，可不是隨便哪個人就能適應的，


&nbsp;


所以，欲爭取的人雖然多，卻是誰也沒有把握。


&nbsp;


沒想到，人事令發佈，雀屏中選的又是她，


&nbsp;


幸運的說法再次傳遍公司上下，真是羨煞了眾人。


&nbsp;


但幸運的事，還不僅止於此；


&nbsp;


由於公司與許多外國廠商進行策略連盟，


&nbsp;


經常會和外國公司的高級主管接觸，這其中有一名是華僑，


&nbsp;


中文講得很流利，他每次來台灣時最喜歡作的消遣，


&nbsp;


就是下西洋棋，剛巧公司中只有她會下西洋棋，


&nbsp;


於是，二人在棋海中漸漸滋生情愫，最後締結良緣，


&nbsp;


寫下了一則現代灰姑娘的故事。


&nbsp;


盛大的婚禮上，終於有人按捺不住的問她說：


&nbsp;


「ㄟ！能不能請妳稍為透露一下，妳怎麼能夠如此的幸運？」


&nbsp;


她緩緩地放下酒杯，


&nbsp;


用一個香吻取得新郎准她暫時離席的同意，


&nbsp;


然後將那些想知道答案的人


&nbsp;


帶到酒店的游泳池旁對她們說：


&nbsp;


「當初，要去公司應徵的那一天，我沒有睡過頭，


&nbsp;


我在公司的人員還沒有開始上班前就去公司門口等待了。


&nbsp;


我不知道公司擔任面試的主管是誰，


&nbsp;


但我想，我可以在面試之前和陸續到公司上班的所有員工們


&nbsp;


打聲親切的招呼，而這裡面一定也有主管人員在內，


&nbsp;


這樣，我便能讓他們建立起對我的好印象。


&nbsp;


當然，我問候的對象，也包含了妳們在內，


&nbsp;


也許妳們不記得了，或當時根本不在乎，


&nbsp;


因為，妳們對別人從來就不曾用心過。」


&nbsp;


大家沉默了一會兒，並試著用力回想當時的情景：


&nbsp;


「啊！是有這麼回事！不過，妳故意這麼做，


&nbsp;


不見得保證就會被錄取啊？我們覺得，


&nbsp;


還是幸運的成份多？」


&nbsp;


她嘴角微揚，輕哼了一聲，回答說：


&nbsp;


「我接到面試通知後，距離正式面試還有三天，


&nbsp;


我猜想，其他人大概只會抱持著等待的心情，


&nbsp;


但我卻利用這段時間，去查閱公司的資料，


&nbsp;


包括成立背景、經營團隊、產品走向、財務狀況、市場佈局


&nbsp;


以及歷史新聞等等，並作充份的瞭解，如此一來，


&nbsp;


當別人還在關心她自己的工作權益時，&nbsp;


&nbsp;


我已經作好了隨時可以上班的準備，


&nbsp;


自然能提高我被錄用的機會。


&nbsp;


至於，我為什麼能以最淺的資歷去接任秘書的職位，


&nbsp;


那是因為，我花了很多的心力，


&nbsp;


去觀察、紀錄公司中每一個重要人物的工作態度和工作流程。


&nbsp;


我知道前任秘書每天早上會替總經理泡一杯摩卡咖啡，


&nbsp;


加兩塊糖和一匙鮮奶油；到了下午三點，


&nbsp;


換成泡薰衣草茶，不加糖，但要放一片薄荷葉，


&nbsp;


而薰衣草茶包一定要是英國原裝進口的才行。


&nbsp;


如果總經理情緒不好，遞上一條冰毛巾是絕對不能稍有遲緩的。


&nbsp;


有幾次前任秘書忽然請假，


&nbsp;


在那幾天裡，這些事情是誰幫總經理做的，


&nbsp;


我想我不必再多說了吧！」


&nbsp;


聽到這裡，眾人才有點兒恍然大悟：


&nbsp;


「照這麼說來，妳有可能不是原來就會下西洋棋的，


&nbsp;


而是臨時填鴨學會的，對不對？」


&nbsp;


「妳們終於開竅了。


&nbsp;


&nbsp;當我老公第一次來台灣的時候，


&nbsp;


我注意到他閒時總是一個人在下西洋棋，


&nbsp;


引發了我好奇和學習的興趣。


&nbsp;


於是，當他第二次來台灣的時候，


&nbsp;


我已經將西洋棋學得很不錯了。


&nbsp;


在下過幾次棋之後，我們變成了好朋友，


&nbsp;


不過，當時的我，實在不敢對他存有任何男女感情的妄想，


&nbsp;


如果說，這整個過程中有屬於妳們所謂的幸運的部份，


&nbsp;


大概就是指他對我的愛了。


&nbsp;


但我也必須說，我的幸運來自於我的努力和我的用心，


&nbsp;


當我愈努力愈用心，也就愈幸運。」


&nbsp;


人經常會抱怨自己不夠幸運，


&nbsp;


卻從來不懂得去探討幸運發生的原因。


&nbsp;


其實，幸運是來自於一分注定，


&nbsp;


三分善良和六分的努力。


&nbsp;


注定的幸運，起因於前世所積累的福報，


&nbsp;


強求不得，所以不必妄想。


&nbsp;


努力得到的幸運，


&nbsp;


在其流得汗、用得心比別人多，付出多自然回報多。


&nbsp;


善良也能獲致幸運，是真的嗎？


&nbsp;


就讓我用生活中一段真實的小插曲來說明：


&nbsp;


有一天早晨，我到便利超商買報紙，結帳的時候，


&nbsp;


一名小學生排在我前面，我聽見他向店員小姐說：


&nbsp;


「麵包和紅茶請分開各打一張發票，謝謝！」


&nbsp;


我在他後面笑著說：


&nbsp;


「多拿一張發票，難道就比較容易中獎嗎？


&nbsp;


像我不訂報紙，每天用買的，


&nbsp;


為的就是一個月可以多三十張發票對獎，


&nbsp;


但從來連小獎也不曾對中過，運氣實在是有夠背的！」


&nbsp;


那名小學生轉頭對我說：


&nbsp;


「不會呀！我每個月最少都會對中兩百元，


&nbsp;


最高紀錄還對中過四萬元哩！」


&nbsp;


我開始對他的幸運感到好奇和羨慕，


&nbsp;


經由短暫的聊天，他告訴我說：


&nbsp;


「我媽媽每天早上都會給我二十元買早餐吃，


&nbsp;


媽媽賺錢很辛苦，而我爸爸很早以前就離開我們了。


&nbsp;


媽媽說，不吃早餐，頭腦會變笨，


&nbsp;


可是，我實在很想幫媽媽省錢。


&nbsp;


後來，我決定每天的早餐都到便利商店買，


&nbsp;


因為有發票可以拿，要是去一般的早餐店，


&nbsp;


錢花完了就什麼也沒有了。


&nbsp;


我想，如果我每個月都能對中獎金的話，


&nbsp;


不就可以替媽媽省錢了嗎！」


&nbsp;


啊！真是一個心地善良的好孩子，


&nbsp;


想得獎金的出發點完全不是為自己，


&nbsp;


難怪他會如此幸運了。


&nbsp;


終於，我明白了自己的運氣為什麼總是不好，


&nbsp;


原來是因為這個世界上有比我更需要幸運的人呀！


&nbsp;


如果幸運全給了我，那這名善良的孩子不就難以如願了嗎！


&nbsp;


可見，上天真是有眼睛的，唯有善良的人值得庇護。


&nbsp;


現在，每當我拿到發票的時候，


&nbsp;


總會情不自禁地紅著眼眶想起那名小學生，


&nbsp;


神奇的是，當我愈希望上天將幸運分送給真正有需要的人時，


&nbsp;


自己卻開始也中起小獎來了。


&nbsp;


假若這不是因為善良而招來的幸運，


&nbsp;


那又會是什麼呢？


&nbsp;


我們不該再抱怨自己不夠幸運了，


&nbsp;


回頭想一想，是不是自己的福報積得不夠？


&nbsp;


還是流得汗太少，用得心太淺


&nbsp;


努力與冀求的比例差太多了呢？


&nbsp;


或許，我們該學著更善良一點兒，


&nbsp;


更會替別人著想一點兒，當上天確認可以經由


&nbsp;


你的手去幫助更多苦難者的時候，幸運之神就會降臨了。


&nbsp;


才氣與愛情一樣，不是與生俱來的，


&nbsp;


是去追尋、努力、磨練、失而復得最後才能擁有的???


&nbsp;


『幸運是來自於一分注定，三分善良和六分的努力』
