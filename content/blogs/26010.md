看到有人問說，有沒有人，作過"夢中夢"或"預知夢"，我是沒有作過預知夢，但卻作過
一個終生難忘的"夢中夢"吧，這是一個非常長的故事，希望大家有心理準備。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
故事簡介：就是夢到自已在睡覺，而且被鬼壓床，但是在夢中發現一些不合理的事，於
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp; 是發現自已是在作夢，一有這個念頭的時侯，就會回到這個夢的起點，這時
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp; 仍然在夢中(但是卻以為自已已經醒了)，就這樣週而復始，一連作了七次循
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp; 環的夢。

所以這樣先簡介一下，希望能讓大家容易理解一點，總之所有發生的事，都是在夢中發生
，但本人卻一直醒不來。
---------------------------------------------------------------------------


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;時間發生在民國八十三年，我讀五專三年級的時侯，那時侯我讀的是基隆的一所商專，
大概有人知道是那一所學校了吧，學校名字我就不說出來了，而且學校的名字也不重要吧。
&nbsp; &nbsp; 
&nbsp; &nbsp; 基隆是一座山城，大部份的房子，就是沿著山腰，依山而建，所以常常出現，那種，前面
有窗戶可以看到山下，而後面是山壁，所以靠山壁那一側的房間，反而算是在地下室，因為
牆外面就是只有土而已了。

&nbsp; &nbsp;&nbsp;&nbsp;我先把房子的格間情況，先描述一下，那一幢五層樓的建築，房東蓋房子的時侯，就是打
算蓋來租學生的，所以地下室先有一個往下的樓梯，下到地下室之後，先左轉個九十度的彎，
向前走大約三米，再右轉個九十度的彎，然後就是一個長長的走道，在走道的二側，各有五
個房間，也就是一共有十個房間，再加上樓梯下的邊間，就一共有十一間房間，而走道右側
的房間是有窗戶的，而左邊的房間是靠山壁的那一邊，走道走到底，是一個大家共用的浴廁
，一邊是一整排的洗手槽，另一邊是隔成三間淋浴間跟三間廁所，說到這裏，是不是覺得真
的是非常標準的學生宿舍吧。

&nbsp; &nbsp; 那時侯我是住在左側房間的第二間，而我的同班同學金成伍，就住在左側的第三間房間，
說真的，我同學長的還真的很像金城武呢，所以大家可想而知，長的像金城武，而且還讀商
專，所以當然永遠都不缺女朋友囉，而我，唉~~，長的也不算差吧，但誰叫我跟金成伍是
好同學，所以目光的焦點，當然不容易落在我身上，好啦，廢話不多說，直接說故事。

&nbsp; &nbsp; 我的房間靠走道的那一邊是門(當然是廢話)，一開門進來之後，門邊是放一個小矮櫃，矮
櫃上是電視，我的房間沒有床，我是在地上舖地毯，然後在靠內側牆邊，靠著牆放一塊單人
床墊，在床墊頭部的地方，我放了一個那種有帶電燈的書櫃，電燈開關是用轉的那一種，在
我的床墊旁邊，放著一張和室桌，和室桌上有一盞那種二管直燈管的檯燈，在床尾的牆上，
有著一張三十吋的籃球之神喬登灌藍的海報，是我學長畢業後，就送給我了，所以我睡覺的
時侯，如果是背對著牆，側身睡的話，是看著門的方向的。

&nbsp; &nbsp; 各位看倌，可能在想，怎麼說個故事廢話那麼多，不是我廢話多，而是如果不把所有的環
境細節，說清楚的話，實在是不好繼續說下去。

&nbsp; &nbsp;……

&nbsp; &nbsp; 話說重頭，那時是五專三年級上學期，期中考的時侯，我們當然要發揮，五專生的特質囉，當然就是要大考大玩，小考小玩，不考還是繼續玩，所以我一、二年級，就當了一屁股了，不過已經升三年級了，當然就不一樣了，到了考試的前一天，還是要看書的嘛，所以那一天的晚上，就先排好了看書進度表，第二天要考三科，所以我就打算三一三一三，就是第一科，看三個鐘頭，然後休息睡一小時，再看第二科三個鐘頭，再睡一小時，再直接看到天亮，然後去考試，那時，我已經看完第二科的統計學了，準備要休息一下，已經四點鐘了，要用三個鐘頭把半個學期都沒看過的東西，硬塞進腦袋裏，還真是有點辛苦，還好我平常人緣還不錯，要借筆記影印，不是太困難的事。

&nbsp; &nbsp;&nbsp;&nbsp;四點鐘，我躺在我心愛的床上，側睡著，就是面對著門的那一邊，右側身體在下，左側身體朝著天花板，隱隱約約還聽到門外面，有學長還在看A片的聲音，有沒有搞錯啊，期中考還看什麼A片，不知不覺我就睡著了。

&nbsp; &nbsp; 睡著睡著，當然就作夢了喔。


(以下這一段，全是在夢中發生的事)
============================================================


&nbsp;&nbsp;&nbsp; 我就夢到自已正在睡覺，是用第一人稱的視點，就是自已側躺著，突然發現自已的身體怎麼動不了，還覺得自已的左側腰上，好像壓了一個什麼東西，我就把眼睛打開，向下瞄了一下，不瞄還好，一瞄嚇了我一身冷汗，在左側的腰上，壓了一團不知什麼東西，所以就像一團白霧。我想完了，被鬼壓了，趕緊把眼睛閉上，就開始唸佛號，什麼觀音大士、阿彌陀佛、耶穌基督、真主阿拉啊，反正誰來都沒關系，喬登來就沒關系，反正只要能來救我就可以了，本來身體是不會動的，突然發現身體好像鬆了一點，我的眼睛，還是不敢張開，就慢慢伸手向上，去摸我床頭書櫃的燈，當我摸到燈的開關的時侯，我就轉了一下，那種光的感覺，透過眼皮，我突然覺得我得救了，然後我就睜開眼睛，坐了起來，就要去開我和室桌上的檯燈，但我就覺得奇怪怎麼電線亂七八糟的，也不管，就要去開檯燈，但我一看檯燈的燈管時，就覺得奇怪，怎麼燈管不是直燈管，怎麼變成圓圓的燈泡了，唉啊…原來我在作夢，當我心中有這個念頭的時侯，突然就回到了，我原本側身睡覺的姿勢(但實際上還沒有醒喔，只是"夢中的"自已在側身睡覺)。

&nbsp; &nbsp; 這時侯，我就偷偷的把眼睛打開一點點，向下瞄了一下，我考…，那團白霧還在我的左側腰上，媽的，這是什麼情形，又不敢睜開眼睛，又開始念佛號，又開始覺得身體好像有一點鬆了，我又伸手向上去開我的電燈，燈光又透過我的眼皮，我又坐了起來，又去開和室桌上的檯燈，天啊，怎麼又是圓圓的燈泡，當我又發現，原來我是在作夢的時侯，我又回到了，我原本側身睡覺的姿勢(仍然沒有醒，還是在夢中)。

&nbsp; &nbsp; (各位看倌，看到這裡是不是有點火了，是想說我這個傢伙，是不是打算，就這樣一直把稿拖下去，最後不了了之，我沒有那麼過份啦，而且這是親身的經歷，所以就要照實寫著下來囉，大家多多包涵。大家有玩過紙雕嗎，就是那種，一面有圖案，另一面是黑的，有一點毛毛的感覺的那種紙雕，書局裏買的到，然後買一把筆刀，可以把圖案雕出來的那種。)

&nbsp; &nbsp; 我又是側身睡覺的姿勢，還是覺得身體不能動，不會吧，我應該醒了吧(仍然在夢中，但覺得自已已經醒了)，我都已經知道我是在作夢了啊，還是覺得左側腰上，有什麼東西壓著，我就把眼睛睜開，向下瞄了一眼，這次，我看清楚，不是一團白霧了，是一個看起來大約高三十公分，寬二十公分的紙雕娃娃，就像個影子的立體平面，壓在我的左腰上，然後，這時侯，她對我說了一句話："嘻、嘻、嘻，來玩啊"，我考，這時侯我都快精神崩潰了，我趕快把眼睛閉上，她還在繼續說話，什麼你看這是我的好朋友，它叫XX，我們一起來玩啊，這一類有的沒有的。
&nbsp; &nbsp;&nbsp;&nbsp;
&nbsp; &nbsp;&nbsp;&nbsp;我都快瘋掉了，還找我來玩，這時侯，我就在猶豫要不要去開床頭燈，想一想算了，就把眼睛張開一點，也不敢向下看，看到房門門下的縫有光線透進來，我就想先逃出房間好了，我就向門的方向爬過去，真是是用爬的喔，在我的手握住門把手的時侯，居然有光從門的把手發了出來，突然之間，我覺得我得救了，我把門打開，就去隔壁找我同學，我直接打開他的房門，要把我同學叫醒，他是用毛毯蓋著頭睡的，我就把他的毛毯拉開，我的同學他的臉，居然沒有五官，有沒有搞錯啊，這…是什麼情形，我想我大概看錯了，就再仔細重新仔細看了一下，呼……，是我眼花了，是我的同學成伍沒錯，我就把他叫醒，他一臉茫然的看著我，就說"在幹嘛啦，都幾點了，還不睡覺"，我就跟他說，我見鬼了，他就一付愛理不理的樣子，最後我就很生氣的說"媽的，自已的同學見鬼了"，你怎麼一點反應也沒有，最後我就很生氣的回我的房間，到了我房間門口，就覺得很奇怪，我房間怎麼會有這麼多的棉被在地上，我就把那些棉被往走廊丟，丟著丟著，我就突然驚覺到，對啊，我現在是在作夢啊，我房間沒有那麼多的棉被啊。

&nbsp; &nbsp;&nbsp; &nbsp; 我又回到了側身睡覺的姿勢，我又把眼睛打開向下瞄了一眼，天啊，還是那個紙雕娃娃，她又對我說了那句話："嘻、嘻、嘻，來玩啊"，冷汗流到都沒有汗了，我這次伸出左手，去摸它，我的手就從它的身上穿了過去，就好像穿過一個影子一樣，看的到卻摸不到，媽的，真的是鬼啊，我趕緊把眼睛閉上，接下來，我又用爬的去開我的房間門，又跑去隔壁房間，去找我的同學，這次，我還真的很怕，我把毛毯一拉開，又是那張沒有臉的同學，但還好，一拉開毛毯，是我的同學，成伍兄，但最後還是話不投機三句多，他還是一付不鳥我的樣子，我說好啦，不然陪我去上個廁所，總可以吧，說真的，一個大男人，還要找別人陪去上廁所，想想還真奇怪，穿過長長的走道，到了底端的公用浴廁，我就先把一間廁所的門打開，就站著要小便，廁所我說過了是有三個隔間的廁所，但我向下看了一眼，疑~~，這個馬桶怎麼怪怪的，好像歪歪的，然後我向右看了一下，疑~~，怎麼三間廁所，都打通連在一起了，有沒有搞錯啊，原來我根本就還沒有醒，當我又這個念頭的時侯，我又回到了側身睡覺的姿勢…。

&nbsp;

(到此為止，以上全是夢中發生的事)
============================================================

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;說到這裡，接下來的情節大同小異，反正就是那個討人厭的紙雕娃娃、開燈、開門、找同學，又連續再做了三次吧。&nbsp; &nbsp;&nbsp; &nbsp; 在夢中總是就會發現一件不合理的地方，然後發現自已在作夢，一次是因為發現走廊上怎麼多了一張沙發，一次是發現浴室多了一個大浴缸，一次是…我忘了，抱歉，畢竟是十多年前的事了。

&nbsp; &nbsp; 大家會好奇，我最後是怎麼醒的囉，過程也很平凡，就是我是側身睡覺的姿勢，最後一次，我的眼睛完全沒有張開，就直接伸手去摸我床頭書櫃的燈，當我摸到電燈開關的時侯，就把它轉開，當我眼皮感受到，那個溫暖的黃色燈光，穿過我的眼皮之後，我就立刻坐起來，第一件事，就是去看鬧鐘，發現時間是四點三十分，呼……，真是的鬆了一口氣，在半個小時之中，居然作了一個七層的夢中夢喔，我那時侯，本來一醒過來，就準備要把這個夢記錄下來，不過因為那時侯，只有一想到紙雕娃娃，就覺得很恐怖，就不知道該怎麼寫下去，不過我就立刻把我的隔壁間的同學金成伍，挖了起來，跟他說了我這個夢，所以雖然過了十多年了，這個夢，我還是記得非常的清楚喔，不過對紙雕娃娃的恐懼，似乎已不再覺得那麼恐怖了，也許是年紀比較大了吧。

&nbsp; &nbsp;&nbsp;&nbsp;打了一篇那麼長的文章，雖然是親身的經歷，不過要寫成文字，還真的不太容易呢，希望大家不要看到睡著喔。
