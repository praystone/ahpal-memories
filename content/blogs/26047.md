&nbsp;

&nbsp;

　　　　　　凌姊姊亞莉很高興能在亞寶認識您


&nbsp;

　　　　　　好友們都知道!姊的平易近人和藹可親的個性

&nbsp;

　　　　　　是很難得的好朋友呢!

&nbsp;



&nbsp;

　　　　　　能認識您!是我的幸運更是美好的緣份


&nbsp;

　　　　　　您對我的關懷照顧，讓我感受到您溫馨情誼



&nbsp;

　　　　　　這溫馨甜蜜的情誼常常滋潤亞莉的心

&nbsp;

　　　　　　對姊的情誼我會永遠珍惜著保存在心裡


&nbsp;



&nbsp;

&nbsp;

　　　　　　很榮幸在這特別時刻一同慶祝您生日快樂

&nbsp;

　　　　　　在姊的特別日子裡亞莉要跟您說:

&nbsp;

　　　　　　 







&nbsp;

　　　　　　　　　　緣份存在心裡是場浪漫的情境

&nbsp;

　　　　　　　　　　思念藏在心底是段芬芳的記憶

&nbsp;

　　　　　　　　　　友情放在心上是曲甜蜜的旋律




　　　　　　　　　　朋友記在心頭是份溫馨的美麗

&nbsp;

　　　　　　　　　　祝福的話語永遠說不完道不盡

&nbsp;

　　　　　　　　　　就是希望你永遠平安快樂幸福
