&nbsp;

&nbsp;

很喜歡擁抱

&nbsp;

喜歡與心愛的人深情相擁的感覺

&nbsp;

什麼也不說.什麼也不做.就只是靜靜地擁抱.久久不要分開

&nbsp;

似乎只有這樣.才能體會與心愛的人真正溶為一體的真實感.

&nbsp;

在那一刻.相信時間也會為我們停止的.
　　 
一直以來都覺得.擁抱.較之親吻更加真實.溫馨

&nbsp;

那個可以讓你依靠的胸膛一定是很溫暖的.肩膀也一定很堅實.

&nbsp;

不然為什麼大家在傷心哭泣的時候.總想找個肩膀來依靠呢.&nbsp;&nbsp; 
　&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
我想.其實更多地是想要一個擁抱吧. 
　　 
擁抱的時候.內心會溢滿一種叫甜蜜的情愫.

&nbsp;

擁抱的感覺是真實和安全的.因為擁抱是有溫度的.擁抱是有聲音的.
　　 
擁抱的含義有很多： 
　　　　
情侶間的擁抱.是幸福甜蜜的. 
　　　　
夫妻間的擁抱.是寬容理解的. 
　　　　
朋友間的擁抱.是貼心信任的. 
　　　　
吵架後的擁抱.代表妥協與原諒. 
　　　　
相逢後的擁抱.代表思念與激動. 
　　　　
離別前的擁抱.代表不捨與期待.
　　　&nbsp;
擁抱.是無聲的語言.

&nbsp;

擁抱.是最簡單的接受與認可. 
　　&nbsp;&nbsp;&nbsp; 
擁抱的時候.彼此是被需要的.

&nbsp;

被別人需要是時候.是一個人最有價值的時候. 
　　&nbsp;&nbsp; 
曾經在篇文章上看到一段話：當一個女人從背後抱著你的時候.請一定別再挪動腳步而請轉過身

&nbsp;

緊緊抱著自己的女人.

&nbsp;

因為.當一個女人願意從背後深情抱著你的時候.

&nbsp;

代表著她把自己的身心都交給了你.那擁抱裡，有著太多太多的愛. 
　　 
當一個男人從背後擁抱著自己的女人.兩人的感覺是溫馨和甜蜜的.

&nbsp;

當一個女人從背後擁抱著自己的男人.女人是無聲的祈求.而男人是心的復歸和寧靜. 
　　 
親愛的.你曾經說過.好想累的時候能抱著我.

&nbsp;

其實.我又何嘗不想呢.

&nbsp;

累的時候.好想你能在身邊.無需太多言語.只要一個擁抱.再苦再累都值得.
　　 
也好想.能夠在你累的時候.從身後環住你的腰.

&nbsp;

把臉輕輕靠在你的後背.靜靜地.無需語言.用心靈對話.傾聽彼此內心的聲音.
　　 
親愛的.不能守在你的身邊.不能在你傷心難過的時候給你安慰.

&nbsp;

不能在你累的時候給你擁抱.更看不到你.面對這麼多不可能時的無奈與心酸.
　&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
可是.我是可以體會你的心情的.因為.在你倍受思念痛苦的同時.我和你是一樣的.
　　&nbsp;
&nbsp;如有一天..

&nbsp;

請相信我.我會用我的雙臂.在你看到我的第一眼時擁你入懷. 
　　&nbsp;&nbsp; 
親愛的.好想好想你.好想好想累的時候能抱抱你. 

&nbsp;

請記得我們說過的永遠.
