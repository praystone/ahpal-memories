戒殺放生,念佛拜佛,重症轉輕,再世為人.


&nbsp;


無嗔居士真人真事


&nbsp;


無量壽經云：［若不往昔修福慧,於此正法不能聞.已曾供養諸如來,則能歡喜信此事.]菩薩承願再來,眾生隨業流轉,各人學佛因緣不同,有人善根,福德,因緣具足,一接觸正信佛法即心生歡喜,而後依教奉行,身受其益;有人則須經歷種種慘痛代價,甚至性命,才相信佛法,進而依教起修,而後受益.而無嗔居士就是屬於後者.她是在身罹重症,身心備受煎熬,醫學束手無策,而後依止佛法起死回生的真實事例.


&nbsp;


無嗔居士南投縣中興新村 人,未學佛前,性烈如火.民國八十一年底,因小便困難出血,經三所醫院診斷為膀胱惡性腫瘤;誘因排便漆黑,檢查出為胃出血,肝硬化.且因血壓過低,胃部出血,以致腫瘤無法進行手術,只能改以人工膀胱代用.醫師亦估算她的生命大約只剩下一個多月.原本一生順遂的她,突然遭受此等重大打擊,身心頓時陷入痛苦深淵中.


&nbsp;


幸而菩薩垂憫,同村中善知識張居士平時護持三寶,聽聞佛法,並常親近上圓下英老法師,當時恰好前來探望,看到了病入膏肓已無退路的她,便提議上山向老法師請益,或許還有轉機.無嗔居士在絕望當中遇此因緣非常高興,馬上一口答應,並期盼早日成行.


&nbsp;


上山前一天晚上（除夕夜）,無嗔居士睡覺時,突然做了一個夢,夢到一位長相凶惡的巫女在身後追打並大聲吆喝,居士乃從夢中驚醒,醒後如廁竟然排出大量污物.天將亮時,又朦朧入睡進入了另一個夢鄉,夢中看到自己置身在一間小茅蓬,旁邊砌有大石,兩旁竹木稀疏,鳥叫蟲鳴,自己則變成一位小女孩,耍玩遊戲,怡然自得.


&nbsp;


隔天（大年初一）,親友們把她半揹半扶上山見了老法師,初進茅蓬,一看四周景物,竟與前一天晚上夢境相似,居士心中倍感激動,在看到老法師法相莊嚴慈祥,淚水屆如決堤般地湧出,痛哭失聲,直說道：［您就是我的師父阿！］


&nbsp;


待心緒平靜後,無嗔居士詳述病情.老法師仔細聆聽後即以堅定口吻開示：［你累世殺業深重,如今業報現前,得此重症.但是只要誠心懺悔,戒殺放生,一定會有轉機！］當下便為她皈依,並且再三囑咐一定要拜佛,放生,戒殺,吃素.然而末法眾生障深慧薄,業習深重,此時無嗔居士竟又向師父央求說：［醫生說我營養不良,身體非常虛弱,是否可以只吃魚和蛋？］師父聽後,面色凜然,嚴肅告誡她說：［以已經吃了一身是毒,還要吃嗎？］


&nbsp;


一語驚醒夢中人,聽了法師一席話後,無嗔居士才知道人所以會身罹重病,壽命短促,多災多難,竟然都是過去無知殺害眾生,而今又大魚大肉,飲苦食毒,毫無仁慈心所致.居士當下深感懺悔,便發願邇後餘生,必定戒殺吃素永斷葷腥,並放生還債.


&nbsp;


返家後由於長期出血,身體羸弱,無嗔居士一直都未拜佛懺罪.直到大年初七,張居士再次來電詢問近況,才又再三鼓勵一定要禮佛,拜佛,向寃親債主求懺悔,並求佛菩薩加被,才能突破困厄,改變病況.所謂［志誠禮佛一拜,罪滅河沙.］人之真誠懺悔心最能感動天地與諸佛菩薩.經此提醒,鼓勵,居士即拖著虛脫的身體,抱著［寧可拜倒佛前,也不橫臥病榻］的意志與決心,強忍著痛苦,開始禮佛拜佛.


&nbsp;


當天家中無人,只有一位八歲胖兒子陪著她,小小年歲的他,知道拜佛的好處後,為了鼓舞母親,並求佛菩薩保佑媽媽,竟然要求和媽媽一起拜佛.無嗔居士屢拜屢跌,痛苦難當,經常不支倒地,但仍堅不放棄.母子二人就在淚水交融,相依相扶持的兩個多小時中完成了第一次的禮八十八佛.


&nbsp;


［至誠感通］,［虔誠必靈],隔日初八,居士如廁,竟排出大量黑便,此時居士心中暗驚：不知是否昨日拜佛過度以致胃又大量出血.直到翌日初九,如廁時排出正常黃便,才知道是罪業減輕,胃已停止出血.自從胃出血以來已六十多天,任何藥物幾乎都無法控制,最後竟因拜佛,吃素,放生而告痊癒.在真正蒙受佛法不可思議利益後,無嗔居士更加心中篤定,信願堅固.


&nbsp;


此後居士每天口常念佛,心常想佛,身常禮佛,並且大量放生.大錢隨著師父定期放,小錢隨緣自己放,心懷慈憫,愛生護生,未嘗中斷.如此經過四個月,當再回到醫院複診時,膀胱腫瘤竟然消失不見.醫院醫師都非常訝異,頻頻探詢原因.


&nbsp;


從參見師父,皈依三寶迄今,已過了八年.這段時間無嗔居士吃素,放生,念佛,拜佛從未間斷.幾經薰習,今非昔比,身體狀況－－除了胃部偶爾作痛外,腫瘤已消失,肝硬化亦已恢復正常.如今的她心終常懷慈憫,對任何大小生靈物命,皆愛護有加;並常以親身遭遇和奮鬥改變命運實例,勉勵鼓舞同樣患者.而身受其益者確已不在少數.


&nbsp;


這是一則真人真事,但願有緣閱讀到此篇文章者,尤其是命中犯有意外劫數,命運多舛,壽命不長或長期病苦纏身之人,甚至念佛人希望臨命終時,走得更清楚,更自在,更少病苦,都要深信發願：要常心存慈憫,真正戒除任何傷害大小重生之念頭與行為.並以真誠,平等,慈悲之心隨時對大小生靈物命救生,護生,放生,讓自己這股慈悲大愛之心遍滿天地宇宙.再配合健康素食－－常喝新鮮蔬菜果汁（去毒生新）,並以真正慚愧懺悔心,勇猛精進,天天念佛,拜佛.若再能擇定明師（非名師）,一門深入,長時聽經聞法,並融入落實在日常生活中,你會煩惱輕,智慧長,受益無窮.


&nbsp;


盡心盡力地去作,一切自有佛菩薩安排！無嗔居士不也是現身說法,為我們作了最好的見證嗎？

我的外公也是因膀胱癌去世,但是他不若本文無嗔居士那麼有善根福報,這個病症在幾年前就得到了,曾經治癒,但後來又復發,並且擴散到肺部跟大腸,我放一個念佛機在他耳邊想讓他聽,但是他因為重聽很嚴重所以聽不到,更枉論念佛.


&nbsp;


有一次我媽媽如同一般人,怕外公營養不良,所以煮魚湯給外公喝,結果當天晚上外公突然大出血,緊急送入加護病房,由於一般人對因果的無知,導致病人的色身增加了更多苦磨,我明知卻感到無能為力,因為我的話都不被家人們採信,後來我想以念經的方式幫外公消一點病業,結果他的寃親債主們很兇的罵我,叫我不要多管閒事,有的還要打我,人過去世所造的惡緣寃業真的很可怕.


&nbsp;
