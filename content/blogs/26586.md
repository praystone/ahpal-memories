&nbsp;

&nbsp;

哭的時候沒人哄，我學會了堅強


&nbsp;

怕的時候沒人陪，我學會了勇敢


&nbsp;

煩的時候沒人問，我學會了承受


&nbsp;

累的時候沒人可以依靠，我學會了自立..


&nbsp;

就這樣我找到了自己


&nbsp;

原來我很優秀，更可貴的是

&nbsp;

世界上


&nbsp;

我只有一個，只有一個我！


&nbsp;

漸漸地，我成熟了


&nbsp;

知道了人是被逼出來的


&nbsp;

只有壓力才有動力，因為沒有更大的不如意


&nbsp;

所以現在的不如意也是幸福的！


&nbsp;

想要成蝶的蛹就要破繭


&nbsp;

想要重生的鳳凰就要蘗磐


&nbsp;

就要堅強，即使獨自悲傷


&nbsp;

也不要去乞求憐憫


&nbsp;

在追求美好的同時不要失去自我，要始終做我自己


&nbsp;

只有自己才擁有自己全部的風格，誰也模仿不了，真實的你沒有盜版！


&nbsp;

相信自己可以撐起屬於自己的那片藍天~

&nbsp;

是馬就應去馳騁草原


&nbsp;

是鷹就該去翱翔天空

&nbsp;

而我只需要做好我自己！

&nbsp;

多疼疼自己，健康是一切的本錢


&nbsp;

不要過分去強求不屬於自己的東西


&nbsp;

因為那樣毫無意義，瀟灑的放下該放下的


&nbsp;

去活出自己的精彩！
