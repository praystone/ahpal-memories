認識<?xml:namespace prefix = st1 ns = "urn:schemas-microsoft-com:office:smarttags" />趙老師，是一個緣份。老師在fb上貼了一篇有關國文老師寫的文章，非常有趣，我念給同事聽，大家都笑翻了，於是我想分享文章給其它在fb上的好友，同事告訴我，你可以試試看加趙老師為好友啊，這樣就可以分享文章了，於是，我很冒昧地，第一次在fb上請求加一位陌生人為好友。


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


沒想到趙老師很欣然地接受了我的邀請，還捎來生日祝福，讓我感覺趙老師的親切與熱誠。過些天，由於老師開了一個關於教育的議題，我和趙老師的學生們聊了起來，老師的子弟們分布世界各地，都很有成就，也都很有自己的看法，聊著聊著，老師捎來訊息，原來老師怕他的學生講話太耿直，讓我生氣，捎來訊息安慰，這真是讓我感到又驚且喜，老師這麼貼心，這麼愛護一個算是陌生人的網友，真的是難得啊！


&nbsp;


和老師在私人訊息聊了一下，我便將部落格網址給了老師，老師來逛過，也留了言，於是我也有了老師的部落格網址，就認真的去閱讀了老師的部落格，看到了一張照片，是老師的兒子，長的很帥，穿著日式的衣服，理著平頭，眼神很深沉，看著照片，我竟然有了錯覺，以為老師的兒子出家了？


&nbsp;


我在和老師的私人訊息中，終於忍不住射手座的好奇心，冒昧地問老師：您的兒子出家了嗎？老師當晚並沒有回答這個問題，隔天一早我趕緊為自己的唐突向老師道歉，沒想到老師竟回答，她沒有生氣，只是一時不曉得怎麼回答我的問題。


&nbsp;


到這兒，我知道一定有什麼不對了，於是努力擠出空檔好好閱讀老師的文章，才發現，呵，我還真是耍了個超級大寶，那張照片其實是電影劇照，她的兒子就是劇中主角—張震。


&nbsp;


發現自己由於對演藝圈不熟而鬧出這樣的笑話，真是被自己打敗了，我趕緊跟老師說，原來我誤會了，真是不好意思！老師很親切地回答，正想約我喝杯咖啡聊聊她的兒子哩！


&nbsp;


我看過「臥虎藏龍」，也看過「詭絲」，也看過「赤壁」，但就是沒看過「吳清源」這部電影，沒想到這還是張震奪得第三屆大版電影節外語片最佳男主角的作品，呵！我真是耍寶，那麼有名的人，我竟然不知那是劇照，鬧了個大笑話。


&nbsp;


老師是那麼親切，那麼有智慧的一位長者，讓我很傾心，對老師有那麼獨特的崇敬，分析起來也許跟自家母親有關，母親個性耿直，從不理會人情世故，為此我的心經常受傷，所以我特別對開朗、有智慧又處事圓融的長者感到敬佩，在心理層面而言，這可能是種補償作用吧！


&nbsp;


昨天是老師生日，忙了一個早上的辦公，下午稍微有空，立刻找時間替老師製作了一張圖檔，除了寫作，我能送給老師的，也就只有圖檔了，稱不上什麼禮物，只是自己的一點小小心意，老師看到之後頗為高興，還問可不可以製作另一個兒子的照片，呵！看到老師喜歡，看到老師的學生們，那些年紀長我若干的大哥大姐們也很熱情，心裡就覺得很高興。


&nbsp;


這是一個偶然的緣分，也是一個欣然的緣分，很希望老師可以過得很開心，讓愛，持續下去。
