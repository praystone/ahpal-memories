&nbsp;

不期而至的你.在那個吐露芬芳的日子裡蹣跚而來.

&nbsp;

你的氣息帶著綿綿情意.穿越萬水千山.飛過蒼穹海際

&nbsp;

靜悄悄來到我身邊.喚醒沉睡的我。

&nbsp;

你把愛的陽光撒滿我的整個世界

&nbsp;

心靈深處那份塵封已久的情愫終於在你的呵護下甦醒

&nbsp;

終於走進了你的心裡.睡在了你的心上.再也不願醒來.

&nbsp;

一直以為自己已經把情感封存.

&nbsp;

可當你的溫暖撫過我的冰點.才發現自己手中仍緊握著情感的尾巴.

&nbsp;

我清楚地知道.我已經把你放進了心裡.而我.甜甜地睡在了你的心上.

&nbsp;

感謝讓我擁有了這場情到深處.無怨無悔的相遇.

&nbsp;

不是情非得已.而是真情流露.

&nbsp;

“真愛是過程，而不是目的”

&nbsp;

你可以放心地幸福著你的幸福.快樂著你的快樂.

&nbsp;

在你幸福的背後.有一個永遠想著你.念著你.

&nbsp;

不願傷害你.默默地祝福著你.

&nbsp;

就讓這個傻瓜永遠住在你心裡.睡在你心上.

&nbsp;

不要叫醒.就這樣.就這樣睡在你心上.不管今生還是來世…
　　　　　
Only dreaming
