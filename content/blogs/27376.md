&nbsp;

女人

&nbsp;

該做一本讓人忍不住讀下去的書

&nbsp;

而不是一眼看穿的花瓶 
&nbsp;

學著去理解去體諒

&nbsp;

學著去遺忘一些不愉快的事情

&nbsp;

學著放棄糾纏於雞毛蒜皮的小事

&nbsp;

學著忍耐淡然

&nbsp;

學著忽視表面的不安

&nbsp;

學著深信愛著的人

&nbsp;

人最大的幸福應該是自己給的

&nbsp;

尤其是女人

&nbsp;

生活從來都不乏色彩


只是有時候我們會被悲傷仇恨嫉妒蒙蔽了雙眼

&nbsp;

一頭扎進去不願意出來

&nbsp;

畫地為牢

&nbsp;

一遍又一遍地重複自己的悲傷

&nbsp;

其實女人不必如此

&nbsp;

不用委屈著自己的心情

&nbsp;

快樂永遠不缺少理由

&nbsp;

沒有誰必須是誰的太陽或月亮

&nbsp;

也沒有誰離開誰就會窒息而亡

&nbsp;

學著自己給自己製造快樂和幸福

&nbsp;

用自身的魅力去吸引著別人

&nbsp;

而不是死纏爛打地拖著某人

&nbsp;

女人

&nbsp;

該做一本讓人忍不住讀下去的書

&nbsp;

而不是一眼看穿的花瓶

&nbsp;
