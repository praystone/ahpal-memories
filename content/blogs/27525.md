WinASO Registry Optimizer 是一個 Windows 優化工具和進階登錄檔清理工具，它允許您以簡單的滑鼠按一下來安全的清理及修復登錄檔故障。通過修復陳舊訊息及調整 Windows 登錄檔參數，它對系統速度的提升是值得令人注意的。 WinASO Registry Optimizer特色與功能簡介： 登錄檔優化~清除二十項登錄檔陳年舊資料，以快速進行掃描，掃描完畢會提供報告，只需按下修復，就可清除陳舊資料。 私隱清理~當運行某些程式時，軟件會將部份私隱資料儲存在系統資料夾內，但這些資料不會在移除軟件時一併清除，用家只要利用WinASO就能把被留下的私隱資料澈底清除。 整理登錄表碎片~開啟軟件時，軟件會讀取登錄檔數據，如數據分散於硬碟內不同地方，軟件的開啟時間及運行速度都會被拖慢。WinASO會先分析登錄檔，然後將分散的數據重整備份，這樣軟件的運行速度就會加快。 啟動項目管理器~現時許多應用軟件在安裝時會加入開機常駐程式，讓電腦開機時自動執行，同時也會使電腦啟動速度大大減慢，其實這些軟件很多都不需要常駐，WinASO就可把所有開機時自動開啟的程式名稱與內容也一同列出來，用家就可移除無須常駐的程式，另電腦速度大大提升。 IE管理器~部份軟件安裝時一併將瀏覽器的首頁更改，並且加入其它功能。WinASO可以將瀏覽器的設定還原至預設選項，從而加快瀏覽器速度。 系統優化~WinASO能將登錄檔的參數調整：從而令電腦相應的速度加快，如關機、開啟瀏覽器等。 捷徑清理器~WinASO能搜尋系統卓面和其它位置的無效捷徑，刪除這些無效捷徑或不存在的檔案，可以釋放磁碟空間並提高系統性能。 系統工具~WinASO能幫用家啟動一些Windows內建工具，以前用家可能沒注意到它們的存在，它們都是非常有用。 還原~以上各種操作各全部都可以還原到未作任何改動前的模樣，用家只需在一開始使用WinASO時，先設置還原點就可。
