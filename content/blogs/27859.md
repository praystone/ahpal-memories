&nbsp;

誰能證明我

&nbsp;

我的心仍能如過往

&nbsp;

留下無法拭去的痕跡般

&nbsp;

當時&nbsp; 我們明白是夢也好

&nbsp;

即使悲傷&nbsp; 也不哭泣

&nbsp;

就算永遠無法相見

&nbsp;

回憶&nbsp; 如同在身旁

&nbsp;

劃下永遠的終點

&nbsp;

許下來生要幸福的誓言

&nbsp;

無盡傷悲

&nbsp;

珍貴的只有一個

&nbsp;

想要呵護的力量

&nbsp;

告訴我生存下去的動力

&nbsp;

如果只是苦痛&nbsp; 我願接受

&nbsp;

就算哀傷 也不哭泣

&nbsp;

即使已不在身邊

&nbsp;

想起回憶&nbsp; 就像回到過去

&nbsp;

葬下了永遠

&nbsp;

無盡傷悲
