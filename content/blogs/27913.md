夜空中星星描繪出的文字

&nbsp;

像在呈現著什麼

&nbsp;

深信著黑暗中

&nbsp;

在同樣的視線裡

&nbsp;

繪著M的字狀

&nbsp;

如同有你相伴似的

&nbsp;

閃耀著

&nbsp;

妳是我的&nbsp; 我愛你

&nbsp;

來世我們會再相見

&nbsp;

每當仰望天際 便會想起你

&nbsp;

妳的氣息

&nbsp;

至今仍然存在

&nbsp;

直到相見的那天

&nbsp;

我們會一直思念彼此

&nbsp;

深信會和你&nbsp; 再次依偎

&nbsp;

即使四季轉換

&nbsp;

妳永遠是我的愛

&nbsp;

向著夜空&nbsp; 輕聲訴說

&nbsp;

不是離別

&nbsp;

深信著

&nbsp;

不變的思念

&nbsp;

永遠存在著

&nbsp;

想你 想你 想你

&nbsp;
