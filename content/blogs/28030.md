&nbsp;




每個人都在走自己的歲月，內容都不會相同，有快樂、痛苦、辛酸和幸福，是平淡是酸甜苦辣，這就是生活。
&nbsp;&nbsp;&nbsp; 


你可以順其自然，平淡生活，也可以轟轟烈烈一生，總之都是自己的選擇，你的人生.

&nbsp;

人於人之間最難的是相處，這就是生活，有的人會讓生活充滿陽光，有的人生活確是風風雨雨，一切都無所謂那是你的生活要你自己去經營。
&nbsp;&nbsp;&nbsp; 

失敗過別難過，那是生命的本質，有失敗才有進步，明天你才會更充實，沒有什麼大不了，成功了也不要驕傲，說不清那一天你就會失落。有時我都覺得好累好累，但是那就是生活，你沒有選擇，生活，選擇讓自己開心吧！
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

無所謂，也沒什麼大不了。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

一路的彷徨，一路的依戀，他們都不會輕易寫下失望，他們努力在飛，即使翅膀沒了愛的重量，沒了愛的風，他們還是一路輕盈，只是眼睛會腫，為因那裡包涵不了太多的痛，夢永遠是夢，夢的天堂總是給人幻想，其實，又有什麼啊，愛不愛是你，何必失望呢。&nbsp;&nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

曾經兩個相愛的人，一方提出分手，另一方痛苦是肯定了。但是，不管有多痛，分手時，你都不要和曾經愛你的人和你愛的說狠話。

&nbsp;

你好好想想，這個世界上，能傷害到你的人，一定是你愛的人；能讓你受傷的人，一定是愛你的人。不然，他怎麼有機會在你心上刻下傷痕？他怎麼有資格讓你在情海浮沉？


&nbsp;

一段感情走到盡頭，你不要向他傾倒無情的口水來證明你被拋棄的痛苦和無辜。如果你真的從心底往外恨，那說明你根本不是真愛他，你只是習慣他整天圍著你轉罷了，他的角色不過是備胎而已。既然從你這裡得不到重視，人家選擇去為別的車服務，你有什麼不舍，有什麼不平衡？


&nbsp;

傷口，是愛的筆記，裡面記載的許多內容是需要你用一生來忘記的。能夠相伴一生的愛情，難道不值得珍惜嗎？

&nbsp;

痛苦是人生一筆重要的財富，不要輕易踐踏；曾經愛過你的人，前世一定和你有緣，不要語言虐待。如果他今生真的負你了，那是因為你前生負他，紅塵輪迴，無需計較。

&nbsp;&nbsp;&nbsp; 

&nbsp;

佛說：前世五百次的回眸，才換得今生的擦肩而過！所有的一切都有它出現的理由，不必為此而感到驚訝！


&nbsp;

緣分是世間男女情愛的開端，從不相識到相識相知，讓人覺得象是冥冥中的注定，美好而直扣心扉。因一個緣字，讓世間多少男女為之癲狂。

&nbsp;

但也有時有緣卻沒份，這種情況最讓人心傷。還有有份無緣的，無緣無份的。當然，有緣有分是最好的結局，諸君該珍惜。


&nbsp;

茫茫人海中兩人從相遇、相識、相知，或是相親相愛，這就是緣分！

&nbsp;

緣分無需等待，緣分是人爭取的、是人創造的。只有懂得努力創造緣分的人，才是最理智的。可是又有多少人，能在緣分來的時候，抓得住它、珍惜它呢！


&nbsp;

緣分是美麗的！緣分和愛情一樣，是個古老的話題，同時緣分也需要精心呵護的。

&nbsp;

緣分不是詩，但它比詩更美麗；緣分不是酒，但它比酒更香濃。

&nbsp;

愛是不分距離不分地域的，在緣分的天空裡，緣分並不是永遠都不會遠逝。珍惜你的緣分，善待你的愛情，莫等失去空遺恨.


&nbsp;

每個人心中都有自己喜歡的異性，人性的本能促使對自己喜歡的異性去追求，目的在於將兩顆陌生的心融匯在一起，這段追求的過程就是戀愛。


&nbsp;

戀愛是一杯對了牛奶的苦咖啡，很甜蜜，卻要承載相應的苦楚。戀愛是在星空下一起數星星，明知道沒有盡頭，但兩人卻樂此不疲。

&nbsp;

&nbsp;

曾昱嘉
