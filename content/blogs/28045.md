雖然以前已經決定好未來的方向

&nbsp;

但是聽了長輩的意見

&nbsp;

敝痕愣住了

&nbsp;

未來的路要怎麼走

&nbsp;

怎麼走 自己最清楚這個問題

&nbsp;

怎麼回答 敝痕最清楚該怎麼回答

&nbsp;

只是敝痕錯了

&nbsp;

果斷 比不上實踐

&nbsp;

決心比不上現實

&nbsp;

套一句以前家人喜歡對小孩子說的

&nbsp;

你什麼都不是，在你還不能賺錢養活自己以前是沒資格要求什麼

&nbsp;

是，敝痕什麼都不是

&nbsp;

做每一件事情沒辦法一心一意

&nbsp;

做每一件工作巴不得想找個理由逃避

&nbsp;

那麼，後來呢

&nbsp;

最終，什麼都不做，留給自己：殘酷到什麼都沒有

&nbsp;

敝拫覺得，好，即時內心那麼抗拒工作，那就慢慢培養，慢慢‧‧‧‧‧待續
