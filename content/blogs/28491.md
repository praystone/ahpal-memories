真情比酒濃

&nbsp;



&nbsp;

&nbsp;


很多人想像中的愛情必須是經典、激情、浪漫

&nbsp;

充滿誘惑且讓人感動

&nbsp;

還希望讓這份愛情永恆，能地老天荒

&nbsp;

但是，這畢竟僅僅是我們的一廂情願

&nbsp;

這種愛情像火柴燃燒

&nbsp;

剎那間放射出炫麗的光芒，能將兩顆心融化

&nbsp;

甚至有人願意用盡一生的激情去燃燒，

&nbsp;

只為了享受這短暫的幸福

&nbsp;

所有劃過的火柴都只是美麗的瞬間

&nbsp;

所有的心動都只能慢慢沈澱下來，它無法溫暖你的一生

&nbsp;

當它燃盡，那硝煙的清香會頃刻化為烏有

&nbsp;

留下的是無盡的失落

&nbsp;

&nbsp;

其實，所有的絢麗都是短暫的，它最終都會歸於平靜，

&nbsp;

我們總是不遺餘力地去追求愛情能夠地老天荒

&nbsp;

總是千方百計地去留住那所謂的幸福瞬間，

&nbsp;

卻不知道天有老的時候，地也有荒的時候，

&nbsp;

地老天荒只是一種美好的願望而已

&nbsp;

很多人都刻意去追求那種轟轟烈烈蕩氣回腸的愛情生活

&nbsp;

而他們完全沒有意識到身邊的生活本來就應該是平淡的

&nbsp;

&nbsp;

平淡的就是幸福的

&nbsp;

愛情帶給我們的幸福首先是心靈的幸福

&nbsp;

只要有一顆能感受幸福的心就能創造幸福

&nbsp;

不奢求過多的一生是幸福的一生，簡單真實的一生也是幸福的一生

&nbsp;

淡泊寧靜的一生同樣是幸福的一生，

&nbsp;

相愛是一種緣分，人海茫茫中遇見你

&nbsp;

在煙波浩瀚的歲月長河中我們能相逢，這本身就是上帝的恩賜

&nbsp;

&nbsp;

相愛是一種默契

&nbsp;

能和最適合自己最體貼最溫暖那個人相守是一種默契

&nbsp;

相愛是一種感覺

&nbsp;

須用兩顆心去體驗和感受才能體會出那跌宕起伏的美麗

&nbsp;

相愛也是一種付出

&nbsp;

是無怨無悔心甘情願無所索求的為心愛的人付出一切

&nbsp;

&nbsp;

愛情歸於平淡後的生活是樸實無華的

&nbsp;

像爐火，它能給你一生的溫暖，

&nbsp;

它沒有耀眼的光芒，沒有炙烈的火焰

&nbsp;

但它卻讓你心靜如水，讓你舒適，能陪著熬過無數個漫漫冬夜

&nbsp;

當你從寒冷中回到家裡，伸出冰冷的手，

&nbsp;

讓淡淡的爐火烤著，你的心也會溫暖起來

&nbsp;

所有的激情最終都會歸於一種平淡

&nbsp;

&nbsp;

我願守著這一爐暖融融的火度過溫馨而平淡的生活

&nbsp;

年年歲歲花相似，歲歲年年人不同

&nbsp;

守住屬於自己的一份平淡的生活，你就是一個幸福的人了

&nbsp;

一份喜歡，一份尊重，一份關心，一份體貼，一份纏綿，

&nbsp;

&nbsp; &nbsp;一份牽掛，一份理解，一份寬容，一份珍惜，一份依戀&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

如果你能擁有這樣簡單而豐濃的情思，

&nbsp;

那麼，人世間有一種愛就叫永遠，

&nbsp;

這份愛情能讓你的生命因此而光彩照人 


&nbsp;
