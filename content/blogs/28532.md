★愛的真諦★

&nbsp;



&nbsp;


愛，是內心的一種感受，

&nbsp;

&nbsp;可以不要太多的語言來表述。 


&nbsp;

相愛的兩個人，彼此之間的一個動作，


&nbsp;

一個眼神，對方都能心領神會。


&nbsp;

甚至一聲嘆息，一陣寂寞無語，對方都能知道你內心所想。


&nbsp;

那份相知的默契勝卻無法言表。


&nbsp;

相愛的兩個人，

&nbsp;

不會計較，誰付出的多，誰付出的少。


&nbsp;

即使是付出的很多很多，也是心甘情願。


&nbsp;

因為他內心唯一的願望，就是希望你幸福，你過得比他好。


&nbsp;

相愛的兩個人，會處處時時牽掛著你，


&nbsp;

一切替你著想，給他以父親般的關懷體貼。


&nbsp;

相愛的兩個人，可以拋棄俗世名利。


&nbsp;

即使粗茶淡飯也是甘甜如醴，也會相濡以沫的廝守。


真正相愛的兩個人，就是在對的時間裡遇到對的人，


&nbsp;

從此珍愛一生。


&nbsp;

愛，是一種彼此的理解與尊重。


&nbsp;

愛情需要寬容與理解，愛情需要信任。


&nbsp;

沒有理解寬容信任的愛情，豈不時空中樓閣，海市蜃樓。


&nbsp;

雖然百般幻化，美麗異常，

&nbsp;

但終究是鏡裡看花，水中望月。


&nbsp;

愛，不是等價交換，它沒有公平的籌碼。


&nbsp;

但它卻宛如一架天平，兩端的砝碼不等，便會傾斜，


&nbsp;

差得太大時，便會失去重心。


&nbsp;

愛，是美麗卻又易逝的花朵。有些人，

&nbsp;

一旦錯過就不再。

&nbsp;

可能便永遠的消失在茫茫的人海中，

&nbsp;

你們注定只是擦肩。


&nbsp;

那麼在我們們擁有的時候，

&nbsp;

為什麼不去珍惜？


&nbsp;

偏偏等到失去的時候，方知其寶貴呢？


&nbsp;

看來珍惜你所擁有的愛戀，在生活的瑣屑中，

&nbsp;

用心愛自己所愛。去呵護那多嬌豔的愛情之花。 


&nbsp;

才是愛的真諦！


&nbsp;
