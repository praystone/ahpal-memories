&nbsp;

十二星座愛情裡最強表現 

&nbsp;



&nbsp;


現實中的愛情不會如童話故事般美好，

&nbsp;

但人們仍然興高采烈的加入到追求的隊伍中，

&nbsp;

人們為愛傷心，難過，很多時候都是一開始想像太美，

&nbsp;

落到實處就不免失望，但即使明白希望越大，

&nbsp;

失望就越大這個道理，還是沒辦法做到不去期望……

&nbsp;

&nbsp;

白羊座～★

&nbsp;

行動力十足的白羊，是個特別講究氣氛的星座。

&nbsp;

他們總希望自己的提議能得到對方的積極回應，

&nbsp;

總希望對方能在自己下決定的時候熱烈支持。

&nbsp;

可每個人的思考角度都不相同，

&nbsp;

就算是再有默契的戀人，也不一定時時配合的天衣無縫。

&nbsp;

於是，白羊老覺得對方不夠理解自己，心有靈犀為什麼就這麼難。

&nbsp;

其實，戀人之間保持一點神秘感更新鮮，可以在分歧中共同進步。

&nbsp;

&nbsp;

金牛座～★

&nbsp;

愛情在金牛看來，是一定需要醞釀的，

&nbsp;

好比美酒，時間越長，香味也就越濃，

&nbsp;

交往的越久，了解也就越深，愛情才會長長久久的走下去。

&nbsp;

只是主觀上的認為不會如客觀上來的正確，

&nbsp;

金牛對待感情，總是處於慢半拍的狀態。

&nbsp;

自己熱情高漲，對方卻沒有激情，

&nbsp;

等到對方想要浪漫的時候，他們又缺乏心思。

&nbsp;

固執的等待同步，總懷疑是不是緣分錯了。

&nbsp;

感情本來就需要你進一點，

&nbsp;

我退一步才能達到和諧，一味倔強很容易錯過真愛。

&nbsp;

&nbsp;

雙子座～★

&nbsp;

給人感覺總是活潑開朗的雙子，其實內心是很容易寂寞的，

&nbsp;

難過的時候就一個人默默的承受，所以對愛非常的敏感。

&nbsp;

一方面渴望被關心，一方面又擔心受傷，

&nbsp;

在愛情的旅程中，總會莫名其妙的煩惱，害怕遠離，又討厭束縛，

&nbsp;

不免認為對方不能諒解自己的情緒，不能接受自己的想法。

&nbsp;

愛情最忌諱胡思亂想，

&nbsp;

雙子這般的杞人憂天，簡直是唯恐愛情不出狀況。

&nbsp;

&nbsp;

巨蟹座～★

&nbsp;

愛情才剛剛開始，巨蟹就會理所當然的把對方定位在親人的角色上。

&nbsp;

噓寒問暖不算，就連甜言蜜語也跟著變了味，

&nbsp;

帶著點提醒和順其自然的責怪。

&nbsp;

以自我為中心的觀念越來越強，只要對方沒向自己報備外出，

&nbsp;

就會很不安，認為沒被信任；

&nbsp;

不允許對方有任何隱私，應該如親人般坦誠相待。

&nbsp;

要知道成為親人之前，首先還是愛人，

&nbsp;

沒必要如此限制彼此，空間少了，感情也就容易淡。

&nbsp;

&nbsp;

獅子座～★

&nbsp;

性格外向的獅子，是不堪寂寞的星座。

&nbsp;

情緒越是壓制，爆發的時候就會越強烈。

&nbsp;

所以，一旦他們想要愛了，就會直接採取行動，

&nbsp;

也不會太顧及對方的感受，反而認為對方配合的不夠好。

&nbsp;

會常常認為對方在朋友面前沒給自己留足面子，

&nbsp;

會認為愛自己就不能分心給其他人。要知道愛情不是一個單獨的個體，

&nbsp;

一心一意也並不需要眼中只有對方來證明，

&nbsp;

愛的太過霸道，只會丟失原本的溫柔。

&nbsp;

&nbsp;

處女座～★

&nbsp;

處女做事周到細心不假，但情緒卻非常善變，

&nbsp;

忽冷忽熱的態度很容易讓戀人困惑，不知道自己究竟做錯了什麼。

&nbsp;

其實是處女把戀人看得太重，只想呈現完美的一面，

&nbsp;

把脆弱用遠離來偽裝，只是這樣往往適得其反，誤會，

&nbsp;

猜疑不斷出現。這時，處女就很委屈，

&nbsp;

認為自己做出了這麼大的犧牲，對方怎麼就不明白呢？

&nbsp;

愛人不是應該心照不宣嗎？

&nbsp;

可是情人間最重要的就是理解，如果只能同甘，

&nbsp;

不給共苦的機會，愛也就失去了完美的意義。

&nbsp;

&nbsp;

天秤座～★

&nbsp;

天秤一直都在尋找愛與被愛的和諧，

&nbsp;

也因為想太多，面面俱到而常常感到茫然若失，自尋煩惱。

&nbsp;

豐富的想像力，使天秤滿懷信心的迎接愛情的到來，

&nbsp;

卻總是被生活的瑣碎給影響，一會覺得只有自己一個人在努力，

&nbsp;

一會擔心投入這麼多的感情值不值得，

&nbsp;

對方總是不能在自己感到無助，空虛難耐的時候及時出現。

&nbsp;

戀人不是助手，不可能隨叫隨到，得失心太重，愛怎麼可能穩定。

&nbsp;

&nbsp;

天蠍座～★

&nbsp;

愛的真也愛的深，天蠍極端的個性，

&nbsp;

注定不是在愛情的世界享受深情的陶醉，

&nbsp;

就是被自我的固執給逼的傷痕累累。

&nbsp;

天蠍願意為對方付出很多，但絕不是不求回報，相反，

&nbsp;

他們潛意識裡非常在意對方的態度。

&nbsp;

對愛的熱情並不會隨時間而消退，

&nbsp;

而對方過了熱戀期就有可能不那麼投入了，

&nbsp;

天蠍對此會強烈不滿，甚至大動干戈。

&nbsp;

當愛已成習慣，說明離修成正果不遠，激情散去，平淡更應珍惜。

&nbsp;

&nbsp;

摩羯座～★

&nbsp;

對待生活很認真的摩羯，面對愛情也一樣細心，

&nbsp;

可以說是謹慎得有些過了，主要原因還是他們改不掉，

&nbsp;

也從未想過要改的現實主義。

&nbsp;

所以，會自然而然把麵包放上台面來說，

&nbsp;

所以會認為對方的想法幼稚，

&nbsp;

即使只是想偶爾浪漫一下；會認為約會沒有那麼重要，

&nbsp;

重要的是麵包夠不夠，香不香；還越來越覺得對方達不到自己的要求。

&nbsp;

愛情之所以為愛情，還是需要激情的，

&nbsp;

完全用現實看待，也就沒有意思了。

&nbsp;

&nbsp;

射手座～★

&nbsp;

射手是個很怕被束縛的星座，

&nbsp;

如果他們決定愛了，並不表示願意為愛放棄自由自在，

&nbsp;

而是這份愛讓射手感到快樂。

&nbsp;

只是興奮如興趣，永遠在最高點是不可能的，

&nbsp;

時間久了，射手難免抱怨，對方怎麼管的越來越寬，

&nbsp;

愛情也越來越不如一開始精彩，樂趣慢慢被金錢物質，

&nbsp;

柴米油鹽給消磨，考慮放棄的想法也越來越強烈。

&nbsp;

愛情不是遊戲，回歸生活才是重點，至少有美好的回憶。

&nbsp;

&nbsp;

水瓶座～★

&nbsp;

水瓶是個習慣私生活保密的星座，

&nbsp;

即使面對戀人，也不能碰觸這個底線。

&nbsp;

可情到濃時，總會忍不住想要了解更多，

&nbsp;

如人們的好奇心，越是不知道的就越是感興趣，

&nbsp;

不管水瓶自己有多能控制慾望，

&nbsp;

對方就不一定了，戀人間問長問短是常有的事。

&nbsp;

所以，水瓶不自在了，認為被愛情束縛了，沒有了秘密，

&nbsp;

連和朋友相處的時間也變少了。兩個人才是愛情，

&nbsp;

互相包容是應該的，把細問當作關心不就很好。

&nbsp;

&nbsp;

雙魚座～★

&nbsp;

每一次的戀愛，雙魚都全力以赴，

&nbsp;

只希望美夢能在愛情中得到實現，

&nbsp;

希望童話在現實中也展現一些片段。只不過，想像畢竟是想像，

&nbsp;

現實的愛情是需要物質做保障的。

&nbsp;

一開始還挺羅曼蒂克的，雙魚也就歡歡喜喜，可時間長了，

&nbsp;

怎麼可能總玩浪漫。

&nbsp;

於是，雙魚越來越失望，感嘆著俗氣，對方怎麼不是公主或王子。

&nbsp;

現實是不能放抗，就只能接受的生活，

&nbsp;

愛情一開始就不應該想像的太過精彩絕倫。
