★ 40顆心 ★ rn&nbsp;

真厲害，40顆心都沒重覆 


&nbsp;




&nbsp;


我心愛的豬皮：恕我冒昧之心，

&nbsp;

暢述我的傷心，妳的美麗使我驚心， 

&nbsp;

差點失去重心和垂心，我對妳一見傾心。


縱使嫦娥下凡我也不會動心，

&nbsp;

雖然妳是一片冰心，我也不會灰心，

&nbsp;

我已經下了最大的決心、耐心，

&nbsp;

再加上小心、細心、留心，絲毫不敢粗心。

&nbsp;

&nbsp;

捧著我最真摯的心，希望和妳永結同心，

&nbsp;

請妳放心，我不會對妳負心，

&nbsp;

加強妳的信心，希望妳不要多心。


天地良心，我對妳一定專心，


不會偷心，此生此世我絕不變心。


&nbsp;

星星知我心，我以一顆痴心，靜待妳的芳心，

&nbsp;

即使海洛裗磣琱都不會死心，


請妳別叫我痛心，在我的內心，妳是我的甜心。


請妳可憐我一番苦心，莫讓我寒心，使我秋霜寸心。


&nbsp;

這封信句句代表我的真心，

&nbsp;

希望能贏得妳的鐵心，感受到我的用心。 

&nbsp;

最後...祝福妳歡心
