猜 心

&nbsp;



&nbsp;


猜是賭，賭彼此的感情，

&nbsp;

猜對，贏了一把，

&nbsp;

猜錯，輸了一半，是要不回的一半。

&nbsp;

我們期待對方能知道自己內心的想法，

&nbsp;

於是總在選擇上要對方猜、總是在每個情況下要對方猜，

&nbsp;

我們不可能清楚對方的想法，

&nbsp;

當然對方也不可能懂得我們的真實感受，

&nbsp;

這是正常的，也是每對情侶的要學習的功課。

&nbsp;

&nbsp;

學習什麼？不是學習讀心術也不是學未卜先知，

&nbsp;

就只是學習尊重跟接納，尊重對方跟你相異的想法，

&nbsp;

接納跟你背道而馳的意見，兩個人會有兩套不同的心態跟作為，

&nbsp;

這才是正常的交往，而不是逼著彼此附和對方，

&nbsp;

更不該認為對方不能有不同的意見，

&nbsp;

若無法給彼此該有的自我空間，那是種悲哀。

&nbsp;

&nbsp;

猜測可以，但無論結果符不符合你意，給彼此一個擁抱吧，

&nbsp;

因為感情根本就不是拿來猜謎的，猜對只是僥倖，

&nbsp;

猜錯也只是彼此有各自的思維跟自我，沒什麼了不起的，

&nbsp;

如果感情沒有互相包容還有彼此珍惜，那麼猜測只是種自欺欺人的遊戲，

&nbsp;

到頭來，這段感情什麼也不是。

&nbsp;

&nbsp;

別再猜心，你無法百分百懂我，

&nbsp;

我也不可能，猜只是浪費感情存摺的差勁行為，

&nbsp;

彼此的互相學習卻是感情的基礎，

&nbsp;

學習去認識彼此也學著給彼此個人空間，

&nbsp;

無法猜到對方的想法不要緊，努力珍惜才是感情的長久之方，

&nbsp;

要是把感情當成猜謎遊戲，猜對就給獎勵，

&nbsp;

猜錯就認為對方不夠了解你，只是在玩弄你的情感罷了，

&nbsp;

而又有誰能忍受這種玩弄感情的手法呢？


&nbsp;

&nbsp;
