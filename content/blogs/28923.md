零亂的小屋，一個男人靠在床頭抽著煙，旁邊一個神情沮喪的女人趴在床上哭泣

&nbsp;

A女：你幹嗎強姦我？？你這個禽獸！！~
B男：因為我是禽獸所以我才強姦你，這麼笨的問題你也問。

&nbsp;

A女：嗚嗚~！你讓我以後怎麼辦？？
B男：我哪知道，我是強姦你的！又不是你男朋友。

&nbsp;

A女：我要懷孕了呢，你會負責麼。
B男：我操，你當我小白（白癡）啊~

&nbsp;

A女：嗚嗚~~嗚，嗚！
B男：別哭了，有什麼大不了的，好了，好了，頂多以後我常來看看你

&nbsp;

A女：真的嗎！！！你真會來看我麼？？真的來麼！你能來麼！
B男：靠~你當我強姦是假的啊，我說來就會來~

&nbsp;

A女：那你強姦我之後，難道就沒有內疚麼！
B男：哎，你還別說，你這一說我還真有點內疚!

&nbsp;

A女：那你要補償我！~~~
B男：（驚訝）怎麼補償？？？

&nbsp;

A女：你當我男朋友吧~~.
B男：汗~~~~~~（我今年30了，還沒個對象，今天就有了？？？？

&nbsp;

A女：同意麼？
B男：好，既然你這麼說了，我就勉為其難，答應你了！

&nbsp;

A女：你太好了，說完在B男的臉上親了一口！~ (幸福中……)
B男淚流滿面的說：強姦無罪~~~~~！！

&nbsp;

（從此他倆快快樂樂的生活著）^_^! ~ !!!

&nbsp;

刑警隊長對受害女子說：認出來了嗎？

&nbsp;

受害女子說：認出來了，就是正在看帖這小子。

&nbsp;

刑警隊長問受害女子：你能確定嗎？

&nbsp;

受害女子說：能確定

&nbsp;

副隊長悄悄對隊長說

不要先下結論，根據我的經驗，強*犯一般都是看完日誌不評論的。
