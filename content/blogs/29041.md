★預留人生的美好★

&nbsp;



&nbsp;


每天最享受的事，莫過於在緊湊的日常生活中，

&nbsp;

為自己勻出一份閒逸無擾的心靈時間。


當家人還沉睡夢鄉，天色猶是墨黑的清晨時分，

&nbsp;

我常就獨自由被窩悄然爬起，為自己倒杯熱水，

&nbsp;

不匆不忙地在窗邊靜坐一會兒，

&nbsp;

由高樓居處靜靜欣賞都會遠處那不曾寂滅的星點燈光。

&nbsp;

&nbsp;

在這個時刻，既不會有電話鈴聲劃破靜寂，

&nbsp;

也沒有什麼急迫待辦的事。

&nbsp;

可以想心事，可以寫日記，背首詩，或做做計劃……。

&nbsp;

一天初始的那份寧靜，怡適的氛圍，不費一分一毫，

&nbsp;

就已完完滿滿的蔓延，充溢在心間。

&nbsp;


&nbsp;

其實，人生每一個簡單經驗裡，

&nbsp;

都蘊藏著看不見的珍貴寶藏。

&nbsp;

只要靜心細想，就不難發現，最令人愉悅回味的時刻，

&nbsp;

常只是一些非常簡單的生活小事，用不上什麼巨額的花費。

&nbsp;

或是靜下來讀一本好書，或是赤足踏在沙灘上，

&nbsp;

感受潮湧、海風的氣味，

&nbsp;

或者帶寵物在沐著月光的小巷裡散一會兒步，

&nbsp;

或是與家人共賞一部好電影，在燈下聚餐歡談，

&nbsp;

彼此間交換一個會心的微笑，與久違的老友通次電話，

&nbsp;

或是運動後，身體充份舒展的舒暢之感……。

&nbsp;




&nbsp;

如果，

&nbsp;

生命中所有美妙的時刻都能不請自來，

&nbsp;

當然是最理想的。

&nbsp;

但也因現代人每日的生活都如此忙碌，

&nbsp;

不知不覺中，

&nbsp;

我們常讓這簡單的想望湮沒於浮生的喧囂、

&nbsp;

汲汲營營之中。

&nbsp;

&nbsp;

在匆忙、緊張的心境下，

&nbsp;

我們也常因急切的追逐夢想、欲望，

&nbsp;

而忘了靜心細賞人生與萬物之美，

&nbsp;

每每在事過境遷、人事不再的時候，

&nbsp;

才暗自謂嘆自己的不曾善用時間，珍惜把握。


&nbsp;

所以聰明的人必得為自己預留創造人生的美好時刻。

&nbsp;

若我們能為自己、為摯愛的人預留時間，

&nbsp;

每天奉獻自我，大愛在心，助人無悔，常懷感恩，

&nbsp;

而不僅是被動的等待賞心悅目的事自動發生，

&nbsp;

必能為自己的人生扉頁，增添許多豐富瑰麗的色澤，

&nbsp;

創造許多值得回憶的美麗印記。


&nbsp;
