★真愛不易★



&nbsp;


&nbsp;

一位即將出嫁的女孩，向母親提了一個問題： 

&nbsp;

〝媽媽，婚後我該怎麼把握愛情呢？〞 

&nbsp;

母親聽了女孩的問話，溫情地笑了笑， 


&nbsp;

然後慢慢地蹲下，從地上捧起一捧沙子。 

&nbsp;

&nbsp;

女孩發現那捧沙子在母親的手圓圓滿滿的，

&nbsp;

沒有流失，沒有撒落。 

&nbsp;

接著，母親用力將雙手握緊，沙子立刻從母親的指縫間泄落下來。 

&nbsp;

待母親再把手張開時，原來那捧沙子已經所剩無幾，

&nbsp;

其圓圓滿滿的形狀也早已被壓得扁扁的，毫無美感可言。

&nbsp;

&nbsp;

其實，那位母親是要告訴她的女兒： 


&nbsp;

愛情無需刻意去把握，越是想抓牢自己的愛情，反而越容易失去。 

&nbsp;

正如掬一把清沙，握得越緊，反而手中所剩越少，

&nbsp;

而那些從指縫中間漏掉的，

&nbsp;

全是自己太用力，太珍惜，太想留住的。 

&nbsp;

&nbsp;

像愛情不能抓緊一樣，人生中許多事情都一樣。 


&nbsp;

過猶不及，超過了那個度，就難有美感可言， 


&nbsp;

只能面對手中的餘沙惆悵與無奈了。 

&nbsp;

美滿的婚姻，雙方必須要有完全平等的感情， 


&nbsp;

必須不干涉雙方的自由， 


&nbsp;

必須保持雙方身心上的親密友誼，有相似的價值標準。 

&nbsp;

如果具備這些條件，


&nbsp;

我相信婚姻是男女之間最美好最重要的關係。 

&nbsp;

真愛是接納... 


&nbsp;

&nbsp;

真正的愛，是在能愛的時候；

&nbsp;

懂得珍惜，該珍惜時好好去愛。


&nbsp;
