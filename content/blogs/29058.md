修養與成功 : 你所給予的..都會回到你身上 !


修養與成功

&nbsp;

很棒的文章和大家分享

&nbsp;

有一個外國名人說過這樣一句話，

&nbsp;

大意是：促成一個人成功的因素，專業知識只佔15％，

&nbsp;

另外 85％是來自於他的修養、人際關係、處世能力、應變能力等等。

&nbsp;

我對此頗有感觸。

&nbsp;

我曾看到過這樣一個故事：

&nbsp;

一個畢業班的班主任帶著他的五十幾個學生到一個大集團公司參觀，

&nbsp;

由於該集團的老總是班主任的同學，因此老總親自接待，

&nbsp;

秘書和工作人員也非常客氣。

&nbsp;

秘書將同學們安排在一個有空調的大會議室坐定，

&nbsp;

工作人員給每個學生倒了一杯水，

&nbsp;

學生們坐在那裡非常坦然，沒有客氣，

&nbsp;

其中還有一個女同學問工作人員有沒有紅茶， 理由是她平時只喝紅茶。

&nbsp;

只有一個同學起身雙手接過工作人員遞過來的茶

&nbsp;

並客氣地說了聲： " 謝謝，您辛苦了！

&nbsp;

" 老總辦完事情急急忙忙趕過來連聲道歉：

&nbsp;

&nbsp;"對不起，對不起，讓你們久等了。 " 竟然沒有人應聲，

&nbsp;

還是老師和前面所說的那位同學帶頭鼓起了掌，但掌聲稀稀落落。

&nbsp;

老總開始講話，發現同學們端坐著，沒有人做記錄，

&nbsp;

於是轉過身對秘書說去領一些公司的筆記本和筆來，

&nbsp;

然後老總面帶笑容地雙手遞給每一個學生，

&nbsp;

遞著遞著老總的笑容沒有了，因為學生們都是伸長著一隻手臂去接，

&nbsp;

有的學生根本就不起身，更沒有人說聲： "謝謝！ "

&nbsp;

只有剛才那個同學畢恭畢敬地站起來雙手接過紙和筆，

&nbsp;

並連說兩聲：" 謝謝！謝謝！ " 

&nbsp;

畢業分配的時候，該同學接到了那個大公司的錄用通知書。

&nbsp;

其他同學非常不服氣：他的成績並沒有我好，憑什麼讓他去而不讓我去。

&nbsp;

老師一邊嘆氣一邊說： 我帶你們去參觀的真正目的是想給你們創造機會，

&nbsp;

可是你們都失去了，該公司點名要這位同學，我有什麼辦法呢？

&nbsp;

&nbsp;

** 你所給予的 .. 都會回到你身上 ** 不論你傷害誰，就長遠來看，!

&nbsp;

你都是傷害到你自己，或許你現在並沒有覺知，但它一定會繞回來。

&nbsp;

凡你對別人所做的，就是對自己做，這是歷來最偉大的教誨。

&nbsp;

不管你對別人做了什麼，那個真正接收的人，並不是別人，而是你自己；

&nbsp;

同理，當你給予他人，當你為別人付出，

&nbsp;

那個真正獲利的也不是別人，而是你。

&nbsp;

如果你對人冷淡，別人也會回以冷漠；

&nbsp;

如果你經常批評別人，你也會接收到許多的批評；

&nbsp;

如果你總是擺一張臭臉，沒錯，別人也不會給你好臉色。

&nbsp;

所有你所給予的，都會回到你身上。

&nbsp;

套句詩人奧登（ W.H.Auden）的話：「人受惡意之作弄，必作惡以回報。」

&nbsp;

如果你陷害別人，哪天你也會遭人陷害。

&nbsp;

同樣的道理，當你帶給別人歡樂，你就會得到歡樂_

&nbsp;

帶給別人祝福，你就會得到別人的祝福；

&nbsp;

如果你經常讚美別人，不久你也會聽到有人在讚美你，

&nbsp;

「你給別人的，其實是給自己的」，

&nbsp;

你讓他人經歷什麼，有一天你也將自己經歷；

&nbsp;

你怎麼對待你的父母，將來你的孩子也會怎麼對待你。

&nbsp;

我想許多人一定聽過，

&nbsp;

格林童話中有一則關於一位老人和兒子住在一起的故事。

&nbsp;

老人的耳力已經不行了，眼睛也看不見，

&nbsp;

顫抖的雙手經常把飯菜洒得滿地，碗也常打破， 

&nbsp;

兒子夫婦倆感到非常厭煩，給老爸爸一付木製碗筷，

&nbsp;

把他趕到廚房幽暗的角落，不准和大家一起用餐。

&nbsp;

有一天，兒子看到自己的兒子用刀片削木頭，他好奇的問孩子要做什麼。

&nbsp;

結果孩子回答：「我在替你準備將來要用的木碗、木筷。」

&nbsp;

從此以後，年老的父親又回到餐桌上吃飯，家人也都非常孝順他。

&nbsp;

* 農夫的哲理 *

&nbsp;

有一個農夫的玉米品種，每年都榮獲最佳產品獎，

&nbsp;

而他也總是將自己的冠軍種籽， 毫不吝惜地分贈給其他農友。

&nbsp;

有人問他為什麼這麼大方？他說：「我對別人好，其實是為自己好。

&nbsp;

風吹著花粉四處飛散，如果鄰家播種的是次等的種籽，

&nbsp;

在傳粉的過程中，自然會影響我的玉米品質。

&nbsp;

因此，我很樂意其他農友都播種同一優良品種。」

&nbsp;

他的話看似簡單卻深富哲理， 凡你對別人所做的，就是對自己所做的 。

&nbsp;

所以，凡事你希望自己得到的，你必須先讓別人得到。

&nbsp;

* 保證有效的秘方 * 

&nbsp;

就像那個農夫一樣，如果你想要得到冠軍的品種，就要給別人冠軍的種籽。

&nbsp;

你若想被愛，就要先去愛人；

&nbsp;

你期望被人關心，就要先去關心別人；

&nbsp;

你要想別人對你好，就要先對別人好。

&nbsp;

這是一個保證有效的秘方，可以適用在任何情況。

&nbsp;

如果你希望交到真心的朋友，你就必須對待朋友真心，

&nbsp;

然後你會發現朋友也開始對你真心；

&nbsp;

如果你希望快樂，那就去帶給別人快樂，

&nbsp;

不久你就會發現自己愈來愈快樂。明白了嗎？ 

&nbsp;

我們所能為自己做的最好的事情，就是去為他人多做點好事。

&nbsp;

己所欲，施於人。凡你想給予自己的經驗，就給予別人；

&nbsp;

想別人怎麼對你，就怎麼對待別人。

&nbsp;

**一生都要學習做人 **

&nbsp;

星雲大師有一位徒弟，大學畢業後，到夏威夷讀碩士，又到耶魯讀博士，

&nbsp;

花了好多年的時間，終於得到博士，非常歡喜。

&nbsp;

有一天他回來，

&nbsp;

對星雲說：「師父，我現在得到博士學位了，以後要再學習什麼呢？」

&nbsp;

&nbsp;星雲說：「學習做人。」學習做人是一輩子的事，沒有辦法畢業的。

&nbsp;

星雲覺得人生，不管是士農工商、各種人等，

&nbsp;

只要學習就有進步，今天要跟大家分享需要學習的事。

&nbsp;

第一、「學習認錯」。

&nbsp;

人常常不肯認錯，凡事都說是別人的錯，認為自己才是對的，

&nbsp;

其實不認錯就是一個錯。

&nbsp;

&nbsp;認錯的對象可以是父母、朋友、社會大眾、佛祖，

&nbsp;

甚至向兒女或是對我不好的人認錯， 自己不但不會少了什麼，

&nbsp;

反而顯得你有度量。學習認錯是美好的，是一個大修行。

&nbsp;

&nbsp;

第二、「學習柔和」。

&nbsp;

人的牙齒是硬的，舌頭是軟的，到了人生的最後階段牙齒都掉光了，

&nbsp;

舌頭卻不會掉，所以要柔軟，人生才能長久，硬反而吃虧。

&nbsp;

心地柔軟了，是修行最大的進步。

&nbsp;

一般形容執著的人說，你的心、你的性格很冷、很硬，像鋼鐵一樣。

&nbsp;

如果我們像禪門說的調息、調身、調心，慢慢調伏像野馬、

&nbsp;

像猴子的這顆心，令它柔軟，人生才能活得更快樂、更長久。

&nbsp;

第三、「學習生忍」。

&nbsp;

這世間就是忍一口氣，風平浪靜，退一步海闊天空；

&nbsp;

忍，萬事都能消除。忍就是會處理、會化解，

&nbsp;

用智慧、能力讓大事化小、小事化無。

&nbsp;

各位要生活、要生存、要生命，

&nbsp;

有了忍，可以認清世間的好壞、善惡、是非，甚至接受它。

&nbsp;

&nbsp;

第四、「學習溝通」。

&nbsp;

缺乏溝通，就會產生是非、爭執與誤會。

&nbsp;

現在中國大陸、香港和台灣，兩岸三地最重要的就是溝通，

&nbsp;

相互了解、相互體諒、相互幫助，大家都是龍兄虎弟，

&nbsp;

互相爭執、不溝通怎麼能和平呢？

&nbsp;

&nbsp;

第五、「學習放下」。

&nbsp;

人生像一只皮箱，需要用的時候提起，不用的時就把它放下，

&nbsp;

應放下的時候，卻不放下，就像拖著沉重的行李，無法自在。

&nbsp;

人生的歲月有限，認錯、尊重、包容才能讓人接受，放下才自在啊！

&nbsp;

&nbsp;

第六、「學習感動」。

&nbsp;

我們看到人家得好處，要歡喜；看到好人好事，要能感動。

&nbsp;

感動是一個愛心、菩薩心、菩提心，

&nbsp;

在我幾十年的歲月裡，有許多事情、語言感動了我，

&nbsp;

所以我也很努力的想辦法讓別人感動。

&nbsp;

&nbsp;

第七、「學習生存」。

&nbsp;

為了生存，我要維護身體健康，身體健康不但對自己有利，

&nbsp;

也讓朋友、家人放心，所以也是孝親的行為。

&nbsp;

** 心在哪裡，人就在那裡 **
