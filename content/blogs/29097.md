&nbsp;



★可以快樂，可以不在憂傷★

&nbsp;



&nbsp;

&nbsp;


當記憶和往事都成了一種負擔，


&nbsp;

當諾言變成了口中隨口說出的語言，


&nbsp;

當謊言變成了一種習慣，當傷害變成了一種常態，


&nbsp;

當悲傷變得怎麼也無法替代。 


&nbsp;

其實我們付出了那麼多，往往得到一個啼笑皆非的答案，


&nbsp;

誰能快樂，誰能悲傷，我只想一個人，


&nbsp;

不想多麼奪目，多麼美麗，多麼令人眼花繚亂，


&nbsp;

也許只需要在某個寂寞的夜晚裡，會隱隱約約的想到，


&nbsp;

可以快樂，可以不再憂傷。
&nbsp;
&nbsp;
人生，如流星一般，也許會有剎那間的絢麗，


&nbsp;

但，絢麗過後迎接的確是永恆的寂暗。


&nbsp;

有時總是為了一件自己曾經做過的事而思考良久，


&nbsp;

到頭來，卻發現自己做的事竟然毫無意義。


&nbsp;

不禁搖頭苦笑。“旁觀者清，當局者迷” 


&nbsp;

在自己用一個旁觀者的身份去看待自己曾經做過的事件，


&nbsp;

就會發現，原來自己什麼都不懂。
&nbsp;
&nbsp;
有時，抬頭仰望蔚藍的天空，

&nbsp;

總是有一種衝出禁錮的強烈衝動。

&nbsp;

待有一天如願以嘗時，卻發現，自己已經失去了好多、好多。

&nbsp;

但是，相信自己能夠憑著年少輕狂，心中的那股倔強，

&nbsp;

用盡全身氣力往前飛，卻不想，自己從此便走上了一條充滿錯誤的道路！

&nbsp;

在迷失方向，迷失自己的時候，陪伴著的只有孤寂與蒼涼。
&nbsp;
&nbsp;
風過，落葉飛卷。抱著自己那雙脆弱的翅膀，瑟瑟發抖，

&nbsp;

心中的委屈與孤單卻總也不說出口，

&nbsp;

因為總想著：“要變堅強，經歷這些風雨是必然的！

&nbsp;

”總是很天真的認為，只要伸出雙手就能擁抱全世界。


&nbsp;

當有人向自己伸出溫暖的雙手時，


&nbsp;

自己卻高傲的把頭一抬，拍著翅膀頭也不回的衝向藍天。


&nbsp;

當黑夜過去總會出現陽光。但是，我們必須戰勝黑暗中的孤寂，


&nbsp;

別被表面所迷惑，而做出衝動的決定。


&nbsp;

天沒變，地沒變，既然什麼都沒變，


&nbsp;

為何自己的內心與看法卻產生了動搖呢？
&nbsp;
&nbsp;
有一個知己，相交甚深，但無緣成為眷侶，


&nbsp;

只是偶爾在電話裡糾纏，說些不相干的事、不相干的人，


&nbsp;

心知肚明的感情，雲淡風清。
&nbsp;


有一個朋友，是親密搭檔，相互理解與信賴，


&nbsp;

而且惺惺相惜，業務與工作之餘，心生贊嘆，但無從表達。

&nbsp;

有一個網友，只通過電話，但心有靈犀，語言傳遞相知相解，


&nbsp;

在午夜相逢的快樂裡，卻只能思念，相聚在夢中。
&nbsp;


有一種愛，我們不能稱之為愛情。


&nbsp;

雖然有同樣的心動，同樣的懷想，


&nbsp;

同樣乍然相見的喜悅、依依不舍的眷戀，


&nbsp;

但塵世間總有一種約束，讓心思沉靜，


&nbsp;

讓感情不再漂泊，發乎情，只能止乎禮。


&nbsp;

但依然可以在陽光下享受難得的溫情，


&nbsp;

依然可以在午夜夢回時心生柔情，


&nbsp;

依然可以相信自己的完美與可愛……在這些溫柔的情愫裡，


&nbsp;

依然，可以感受被愛。
&nbsp;
&nbsp;
我們的世界，畢竟不僅僅有愛情。


&nbsp;

在歲月漫長的腳步裡，我們更多對水色山光的眷戀。


&nbsp;

紅玫瑰只有一朵，燃燒此生唯一的心情，


&nbsp;

而更多時候，空氣與水都是恩賜，讓我們享受生活。
&nbsp;
&nbsp;可以快樂，可以不再憂傷


&nbsp;

有一種真情，可以平靜的相忘於江湖。


&nbsp;

君子之交，亦或萍水相逢，都可以默默的愛，默默的理解，


&nbsp;

默默在心裡裝滿祝福，揮一揮手，讓春草連綿，落紅成陣。
&nbsp;


有很多愛，我們不能用世俗的方式承擔，


&nbsp;

也不過聚散隨緣，風雨由天，金風玉露，勝卻人間無數。
&nbsp;
&nbsp;
每當從夢中醒來，睜開眼睛的那一刻，


&nbsp;

為自己還能夠看見光明而感到慶興。


&nbsp;

也許長大了就會懂得存儲一些記憶了吧！


&nbsp;

我們其實可以快樂，可以不再憂傷……


&nbsp;

可是自己真正的做到了嗎?


&nbsp;
