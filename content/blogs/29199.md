人生領悟<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


自由意味著可以選擇：


活的有意義，或者死得有尊嚴；


&nbsp;


人生哪裡死結，想通了，不過就是：饑來餐，倦來眠；


&nbsp;


人生的舞臺沒有假裝這一說，每個人遲早都會真的變成他日常扮演的那個角色；


&nbsp;


面具戴久了，就會長到臉上，再想揭下來，除非傷筋動骨扒皮；


&nbsp;


工作時不為錢分心，錢反而會來的更快；


&nbsp;


婚姻中最折磨人的，並非衝突，而是厭倦；


&nbsp;


聰明人應當是快樂的，自以為聰明的人才常常感到煩惱；


&nbsp;


真君子是：以入世之態度做事，以處世之態度做人；


&nbsp;


安全須知：第一、提防好脾氣的人發火。第二、別和沒什麼東西可失去的人競爭；


&nbsp;


社交之所以累，是因為每個人都試圖表現出自己其實並不具備的品質；


&nbsp;


世界上唯一會隨著時光的流逝而越來越美好的東西就是回憶；


&nbsp;


動物只相信它看到的東西，人卻能看到他相信的東西：幸福和煩惱皆由此而來；


&nbsp;


真正的痛苦，沒有人能與你分擔。你只能把它從一個肩，換到你的另一個肩；


&nbsp;


令人筋疲力盡的並不是要做的事本身，而是事前事後患得患失的心態；


&nbsp;


令人沮喪的往往並非事實，而是比較；


&nbsp;


知識和財富的不同點之一就是：前者無論在哪里得到，都沒有什麼可恥的；


&nbsp;


要是經常往上看，你會長高，如果老是低著頭撿便宜，你就會駝背；


&nbsp;


許多人不斷犯錯誤的原因就是：覺得事後表示歉意比事前抵禦誘惑容易些；


&nbsp;


人生沒有如果，但有許多但是；


&nbsp;


懷舊……不是因為那個時代多麼好，而是那個時候，你年輕。
