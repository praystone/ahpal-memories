&nbsp;

隨份-就是認清自己的本份 

&nbsp;




&nbsp;


我們很多不快樂的原因,就是因為沒有認清自己的本份,


然後就會去期待一些我們不可能達到的目標,

&nbsp;

給自己帶來壓力, 形成問題.最後,變成煩惱跟痛苦.

&nbsp;

如果,我們能夠認清自己到底是什麼樣的一種人,

&nbsp;

我們就比較不會去做一些不適合自己做的事,就會更快樂一點. 

&nbsp;

&nbsp;


隨緣-就是認識你的外緣 


外面的環境,認識你自己的心態,

&nbsp;

也就是認清週遭的一切人,事,物. 

&nbsp;

有時後,同樣的話在不同的場合,講給不同的人聽,

&nbsp;

會造成完全不同的結果. 

&nbsp;

&nbsp;

我相信很多人都有這個經驗.所以,一個人,

&nbsp;

如果能夠認清自己,認清環境,也就是能夠隨份過日,

&nbsp;

能夠隨緣過生活,一定就會快樂! 

&nbsp;

快樂是一個人生命的泉源,如果我們不能保有一顆快樂的心,

&nbsp;

那就是我們身心老化的源頭

&nbsp;


有人問，分離的時候，


還是留下來的那個人比較痛苦？到底是離開的那個人比較痛苦， 

&nbsp;

應該說，愛得最深的那個人比較痛苦。 

&nbsp;

一雙情侶，其中一方要單獨出門，

&nbsp;

這種短暫的分離，

&nbsp;

必然是留下來的那個比離開的那個痛苦。 


在外面的那個人，忙著遊玩或忙著工作，多姿多采，

&nbsp;

留下來的那個人，卻要獨自面對孤獨。 

&nbsp;

那一刻， 他才知道原來自己多麼思念對方。 


&nbsp;

&nbsp;

機場常常是求婚的地方，女人從外面回來，

&nbsp;

來接機的男人想她想得瘋了，自投羅網說：我們結婚好嗎？


&nbsp;

誰說結了婚就不用分離？ 

&nbsp;

下一次，換了男人一個人出門，寂寞的是留下來的女人，

&nbsp;

&nbsp; 她擔心他有意外，更擔心他有豔遇。 

&nbsp;

&nbsp; 拋棄別人總比被人拋棄好過一點，所謂離別，總是一個走，一個留下，

&nbsp;

走的那個當然比不上留下的那一個痛苦。 

&nbsp;

&nbsp;

年深日久，

&nbsp;

留下來的那個發現自己原來可以忘記離開的那個人，

&nbsp;

那麼，他就不再痛苦；

&nbsp;

偏偏離開的那個發現自己仍然愛著從前那個人。 

&nbsp;

那一刻，他才知道，原來自己才是留下來的那個人。
