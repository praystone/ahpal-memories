幸運是來自於一分注定， 三分善良和六分的努力

某知名企業登報應徵會計人員，廣告才登了二天，

&nbsp;

應徵的履歷表就如雪片般的飛來。公司經過初步篩選，

&nbsp;

總計發出了三十封面試的通知書函。


結果，經過面試而被錄用的女孩，才貌普通，表面上看起來，

&nbsp;

實在找不出有什麼特別過人之處，能擊敗其他二十九位對手，

&nbsp;

實在令人大感意外。公司中的幹部人員，都說她一定是被幸運之神

&nbsp;

給眷顧了，若是根據往例判斷，憑她的條件，根本不可能被錄用。


幸運的她在公司任職二年後， 總經理的專任秘書突然發生車禍，

&nbsp;

嚴重的傷勢在短期內無法復原，而工作必須立刻有人接手，

&nbsp;

但總經理的執拗脾氣和工作習慣，可不是隨便哪個人就能適應的，

&nbsp;

所以，欲爭取的人雖然多，卻是誰也沒有把握。

&nbsp;


沒想到，人事令發佈，雀屏中選的又是她， 幸運的說法再次傳遍

&nbsp;

公司上下，真是羡煞了眾人。 但幸運的事，還不僅止於此；

&nbsp;

由於公司與許多外國廠商進行策略連盟，經常會和外國公司的高

&nbsp;

級主管接觸，這其中有一名是華僑，中文講得很流利，他每次來

&nbsp;

台灣時最喜歡作的消遣， 就是下西洋棋，剛巧公司中只有她會下

&nbsp;

西洋棋， 於是，二人在棋海中漸漸滋生情愫，最後締結良緣，

&nbsp;

寫下了一則現代灰姑娘的故事。

&nbsp;


盛大的婚禮上，終於有人按捺不住的問她說： 「ㄟ！能不能請妳

&nbsp;

稍為透露一下，妳怎麼能夠如此的幸運？」 她緩緩地放下酒杯，

&nbsp;

用一個香吻取得新郎准她暫時離席的同意，然後將那些想知道答

&nbsp;

案的人帶到酒店的游泳池旁對她們說： 「當初，要去公司應徵的

&nbsp;

那一天，我沒有睡過頭， 我在公司的人員還沒有開始上班前就去

&nbsp;

公司門口等待了。 我不知道公司擔任面試的主管是誰，但我想，

&nbsp;

我可以在面試之前和陸續到公司上班的所有員工們打聲親切的招呼，

&nbsp;

而這裡面一定也有主管人員在內， 這樣，我便能讓他們建立起對

&nbsp;

我的好印象。 當然，我問候的對象，也包含了妳們在內，

&nbsp;

也許妳們不記得了，或當時根本不在乎，因為，

&nbsp;

妳們對別人從來就不曾用心過。」


大家沉默了一會兒，並試著用力回想當時的情景：

&nbsp;

「啊！是有這麼回事！不過，妳故意這麼做，不見得保證就會被

&nbsp;

錄取啊？我們覺得， 還是幸運的成份多？」


她嘴角微揚，輕哼了一聲，回答說： 「我接到面試通知後，距離

&nbsp;

正式面試還有三天， 我猜想，其他人大概只會抱持著等待的心情，

&nbsp;

但我卻利用這段時間，去查閱公司的資料，包括成立背景、經營

&nbsp;

團隊、產品走向、財務狀況、市場佈局以及歷史新聞等等，並作

&nbsp;

充份的了解，如此一來，當別人還在關心她自己的工作權益時，

&nbsp;

我已經作好了隨時可以上班的準備，自然能提高我被錄用的機會。


至於，我為什麼能以最淺的資歷去接任秘書的職位，那是因為，

&nbsp;

我花了很多的心力，去觀察、紀錄公司中每一個重要人物的工作

&nbsp;

態度和工作流程。我知道前任秘書每天早上會替總經理泡一杯摩

&nbsp;

卡咖啡，加兩塊糖和一匙鮮奶油；到了下午三點，換成泡薰衣草茶，

&nbsp;

不加糖，但要放一片薄荷葉，而薰衣草茶包一定要是英國原裝進

&nbsp;

口的才行。


如果總經理情緒不好，遞上一條冰毛巾是絕對不能稍有遲緩的。

&nbsp;

有幾次前任秘書忽然請假，在那幾天裡，這些事情是誰幫總經理

&nbsp;

做的，我想我不必再多說了吧！」聽到這裡，眾人才有點兒恍然

&nbsp;

大悟：「照這麼說來，妳有可能不是原來就會下西洋棋的，

&nbsp;

而是臨時填鴨學會的，對不對？」


「妳們終於開竅了。 當我老公第一次來台灣的時候，我注意到他

&nbsp;

閒時總是一個人在下西洋棋， 引發了我好奇和學習的興趣。


於是，當他第二次來台灣的時候，我已經將西洋棋學得很不錯了。

&nbsp;

在下過幾次棋之後，我們變成了好朋友，不過，當時的我，實在

&nbsp;

不敢對他存有任何男女感情的妄想，如果說，這整個過程中有屬

&nbsp;

於妳們所謂的幸運的部份，大概就是指他對我的愛了。但我也必

&nbsp;

須說，我的幸運來自於我的努力和我的用心，當我愈努力愈用心，

&nbsp;

也就愈幸運。」


經常會抱怨自己不夠幸運， 卻從來不懂得去探討幸運發生的原因。

&nbsp;

其實，幸運是來自於一分注定，三分善良和六分的努力。注定的

&nbsp;

幸運，起因於前世所積累的福報，強求不得，所以不必妄想。

&nbsp;

努力得到的幸運，在其流得汗、用得心比別人多，

&nbsp;

付出多自然回報多。 善良也能獲致幸運，是真的嗎？


就讓我用生活中一段真實的小插曲來說明： 有一天早晨，我到便

&nbsp;

利超商買報紙，結帳的時候， 一名小學生排在我前面，我聽見他

&nbsp;

向店員 小姐說：「麵包和紅茶請分開各打一張發票，謝謝！」

&nbsp;

我在他後面笑著說：「多拿一張發票，難道就比較容易中獎嗎？

&nbsp;

像我不訂報紙，每天用買的， 為的就是一個月可以多三十張發

&nbsp;

票對獎，但從來連小獎也不曾對中過，運氣實在是有夠背的！」


那名小學生轉頭對我說：「不會呀！我每個月最少都會對中兩百元，

&nbsp;

最高紀錄還對中過四萬元哩！」我開始對他的幸運感到好奇和羡慕，

&nbsp;

經由短暫的聊天，他告訴我說：「我媽媽每天早上都會給我二十

&nbsp;

元買早餐吃，媽媽賺錢很辛苦，而我爸爸很早以前就離開我們了。

&nbsp;

媽媽說，不吃早餐，頭腦會變笨，可是，我實在很想幫媽媽省錢。

&nbsp;

後來，我決定每天的早餐都到便利商店買，因為有發票可以拿，

&nbsp;

要是去一般的早餐店，錢花完了就什麼也沒有了。我想，如果我

&nbsp;

每個月都能對中獎金的話，不就可以替媽媽省錢了嗎！」啊！

&nbsp;

真是一個心地善良的好孩子，想得獎金的出發點完全不是為自己，

&nbsp;

難怪他會如此幸運了。


終於，我明白了自己的運氣為什麼總是不好，原來是因為這個世

&nbsp;

界上有比我更需要幸運的人呀！如果幸運全給了我，那這名善良

&nbsp;

的孩子不就難以如願了嗎！可見，上天真是有眼睛的，唯有善良

&nbsp;

的人值得庇護。現在，每當我拿到發票的時候，總會情不自禁地

&nbsp;

紅著眼眶想起那名小學生，神奇的是，當我愈希望上天將幸運分

&nbsp;

送給真正有需要的人時，自己卻開始也中起小獎來了。


假若這不是因為善良而招來的幸運，那又會是什麼呢？我們不該

&nbsp;

再抱怨自己不夠幸運了，回頭想一想，是不是自己的福報積得不夠？

&nbsp;

還是流得汗太少，用得心太淺，努力與冀求的比例差太多了呢？

&nbsp;

或許，我們該學著更善良一點兒，更會替別人著想一點兒，當上

&nbsp;

天確認可以經由你的手去幫助更多苦難者的時候，幸運之神就會

&nbsp;

降臨了。才氣與愛情一樣，不是與生俱來的，是去追尋、努力、

&nbsp;

磨練、失而復得最後才能擁有的???
