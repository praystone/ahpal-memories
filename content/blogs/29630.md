最美的景色是好心情！


&nbsp;



&nbsp;


我們每個人都希望自己的生活過得豐富多彩，


不過，生活質量的高低，


在很大程度上取決於自己對生活的心情。



&nbsp;


&nbsp;


在活生生的生活面前，任何人都難免要打上許多無奈的結，


盡管你一千個一萬個不樂意，但它卻不依你的意志所轉移。


看不透這些，一味地浮躁，那只能平添自己的痛苦。　


就生活本身而言，它是不會自個兒變得輕鬆抑或沈重的，


挫折也不會因為你的祈禱或詛咒而改變軌道。


&nbsp;


&nbsp;


不過，你則有辦法改變你的心情改變你的感受。


如果不是硬要與自己過不去，就應當學會營造一份好心情。


可以這樣說，營造好心情永遠是創造完美人生的一大技法。


不僅遇上挫折、煩惱襲來時需要，


就是困於單調、陷入平淡時也需要，抑或更需要。


&nbsp;


&nbsp;


靜心思考一下，道理頗為簡單：



哪條路上沒坎坷？



誰家沒有一本難念的經？



統觀周圍，環顧左右，鮮活的例子不勝枚舉。



&nbsp;


&nbsp;


要錢有錢，要名有名，要尊重有尊重，


按理說是最幸福不過的了吧，


但為數不少的“大牌”明星怨嘆名氣


給他們背上了一副沈重的十字架，


欲罷不能，活得好累好苦；



&nbsp;


&nbsp;


許多“富豪”在享盡奢華的物質文明果實之余


自責“窮得只有錢，乏味沒勁”而可憐悲哀。



&nbsp;


如是說來，失敗者的心情是沈重的，


成功者又何嘗不是如此呢？



&nbsp;


失意者自然是煩惱不已的，


但得意者又何嘗沒有苦惱呢？



&nbsp;


&nbsp;


任何人如若不在心理上作些解脫，


用寬鬆、平和的心境去化解生活中的無奈，


那就只能永遠沈重、終生煩惱了！


&nbsp;


&nbsp;


面對紛繁的生活，尋找一種超越，尋找一種樂趣，


實質上是對生命的負責、對人生的善待。



&nbsp;


人類總是在不斷地試圖以各種方式詮釋人生的真諦。


其實，人生就是從左腳到右腳的距離，路就在腳下。



&nbsp;


&nbsp;


一個人從降臨人世起，到邁入社會大門，


就難免受到各種誘惑。色、利、名無不給人刺激。


因而，爭名於朝，爭利於市。


古往今來，在種種誘惑面前，


有人挺住了，有人卻倒下了。


營造一份好心情，就要能自覺地抗拒誘惑。


&nbsp;


&nbsp;


人生苦短。


許多人追求一生，勞碌一生，心高氣傲一生，


最後發現自己並沒有達到理想，於是抱恨終生。



實際上，人活世上一如月亮，圓則缺，盈則虧。



拼搏、努力後，倘若成功了，


我們需要擁有好的心情讓自己感到安慰；



&nbsp;


如果受挫、面對逆境，


我們更需要營造一份恬淡的心情，


來癒合自己的傷口，


去再一次面對生活的滄桑與坎坷，


尋找新的角度奮進。



&nbsp;


否則，不正視現實，只一味地知難而進，


逆勢而拼，到頭來受傷的還是你自己。



&nbsp;


於是，我說：


把握時機讓自己處於好的心情氛圍中，


你便愉悅、快樂、幸福！



&nbsp;


&nbsp;


最美的景色是好心情！


時常擁有好心情，


你便永遠擁有一片晴空，


永遠快活年輕！
