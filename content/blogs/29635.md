虎斑地鶇奇緣記<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


三月了，南半球已悄悄的入秋，一沒留神，早晚的涼意直沁入髓，初秋的南半球依然豐碩美麗，在紐西蘭更是日日晴天，天氣好到讓人覺得不真實，又覺得心慌，到底要如何把握？才不辜負這美好的秋之盛宴呢？


&nbsp;


季節一變，住家附近的眾鳥生態隨即不同，例如總是準時報到的虎斑地鶇，因其羽色像老虎的斑纹，或者更像豹纹而得名。這種鳥最喜歡在陰暗的林下與灌木叢里鑽來鑽去覓食，下地的時間相對於其他鳥來說，算是很長的。牠有時也出现於較開闊的草地，走走停停，找尋蚯蚓、昆蟲。


&nbsp;


即使是嘴角嫩黄的亞成鳥，牠找蚯蚓的本領也是一流！只見牠在地面上不斷淺啄探索，一旦確定地方隨即猛啄草地，碎泥與草葉齊飛，接著一條長長的蚯蚓就给扯出來啦——呵呵，看起來很容易嘛！也許牠聽的到蚯蚓的地下活動？


&nbsp;


虎斑地鶇在此地屬秋候鳥，秋天一到就會出現在住宅附近，牠膽子不小，只要你不去動他歪腦筋，即使經過牠身邊，牠也不太「鳥」你，自顧自找東西吃。


&nbsp;


前年秋初，一連下了幾天雨，我到後院打掃時發現一隻虎斑地鶇小雛鳥落地，（當時還不知道牠的名字）全身濕透在發抖，趕緊把牠救回來，找個鞋盒墊上柔軟紙巾，放了一個五燭光小燈泡，幫牠烘暖，大概是舒服了，一會兒就睡著了。


&nbsp;


我又到後院繼續整理東西，這時飛來一隻成鳥，就停在戶外餐桌上對著我叫，與我的距離約一公尺，我看牠跟屋裡的小鳥很像，心想會不會是鳥媽媽？回身拿了一點土司餵牠，牠吃完後繼續叫了一陣子就飛走了。


&nbsp;


天黑時小鳥睡醒了，開始小聲啼叫，八成是餓啦！可叫我到哪去找小蟲給牠吃啊？只好弄點土司小球和碎蛋黃給牠吃，大概是餓壞了，小傢伙來者不拒，通通吃下去，至少肯吃就能飽命，總算放心。


&nbsp;


第二天一早，小鳥睡醒了精神不錯又開始叫，我再餵牠吃一頓，果然有效，吃飽就睡。到了八點左右，我去後院曬衣服，昨天那隻成鳥又來了，因為牠一來就停在昨天桌上同一位置，對著我叫，所以我判斷是同一隻。


&nbsp;


正猜應該是鳥媽媽，就聽到屋裡傳來小鳥叫聲，鳥媽媽聽到後，忽然叫聲變急促，拍著翅膀在桌上跳，裡外呼應，可是小鳥還很虛弱，而戶外因昨夜大雨依舊潮濕，這時候放出去，小鳥不會飛、又在地上，對貓來說簡直就是到嘴肉，我是萬萬不能放的。


&nbsp;


母鳥繼續啼叫，大有不肯放手的架式，我進屋把鞋盒捧出來，放在桌上，母鳥跳在盒邊對小鳥叫了幾聲就跑了，正納悶哩！牠就回來了，一來一去不會超過三分鐘，牠嘴上叼了一條小小蚯蚓，餵給小鳥吃，接著又跑了，約莫同樣三分鐘，再次出現時又叼了一條小小蚯蚓來餵小鳥，就這樣來來回回四趟，最後第四趟就飛走了沒回來。我把鞋盒放回屋裡繼續用小燈讓小鳥保溫，這小傢伙一暖了又睡著了。


&nbsp;


到了快天黑時，母鳥又出現了，這回直接叼了三條蚯蚓來，我趕進屋把已經在叫的小鳥捧出來，就像早上一樣，母鳥餵食，餵完了又叫了幾聲飛走了。我再把小鳥拿進屋，依舊沒放牠。到了晚上再下一場大雨，心想好家在又留了一夜，不然小鳥絕對活不到明天。


&nbsp;


就這樣連續三天，早晚母鳥各來餵食一次，中間就由我餵碎蛋黃和土司，衍生出一種不可思議的默契。大概是蛋黃真營養，加上鳥媽媽餵「鮮肉」，才三天小鳥羽毛長了不少出來，不過還不能飛。我家阿SIR說這樣不是辦法，小鳥會錯過學飛期，於是他做了一個臨時鳥窩，趁母鳥沒來，把鳥窩固定在後院橘子樹的樹幹上，傍晚母鳥又來了，我當牠的面將小鳥放到人工鳥窩，母鳥一路跟著飛到橘子樹上，看著我放小鳥到窩裡，隨即跳進去餵食。


&nbsp;


至此是我能做的部分了，剩下就看牠們自己了。不過因那時我家狗狗還在，所以後院不會有貓來，小鳥在樹上算安全無虞。大約兩天後我就沒在看到這母子倆了。鳥窩還在樹上，不知道還有沒有別的鳥會來利用一下了。


&nbsp;


事情過後好幾天，我都還沒從「震驚」中恢復過來，那幾天我和這對母子之間的互動真是奇蹟，特別是母鳥，牠知道小鳥在我院子中「丟失」的，竟然會飛回來找小鳥，小鳥在屋裡也會回應媽媽的啼叫，（我家附近鳥可多了，啼叫聲沒斷過，但小鳥就是能分辨出媽媽的聲音）而最讓我驚訝的是，母鳥竟能體會我照顧小鳥的心意，知道我不會傷害小鳥，因而放心早晚來餵一次。


&nbsp;


後來查書才知到牠就是虎斑地鶇，一個奇妙的小生物。
