玄鳳鸚鵡帥哥記<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


昨天看到網友love提及，她有一隻寵物小鴿子叫做小乖，鴿如其名，十分溫馴可愛。這讓我回憶起多年前養的一隻玄鳳鸚鵡，聽話、貼心，讓我至今念念不忘。


&nbsp;


帥哥是我給那隻小鸚鵡取的名字，有一次我們經過鳥店，隨意進去逛逛後，「不小心」買下的。那時我們剛結婚，還沒有孩子，帥哥就成為我們的第一個孩子了。


&nbsp;


買回來時，帥哥還是一個毛沒長齊的小雛鳥，身上都是「毛管」，醜醜的，但是已經知道要黏人了，我們用熱水將飼料泡軟後，拿一隻吸管削去一角，舀起飼料餵牠，牠吃的可起勁兒了，又快又急，活像我餓牠三天三夜似的，每次都吃到素囊飽飽快漲破還不住嘴，都是我硬不給牠才停下來。


&nbsp;


因為我們是從小雛鳥養起，所以帥哥認定我們是牠爸爸媽媽，連晚上睡覺也要跟我睡，而且一定要睡在我枕頭邊才肯，我只好給牠做個小枕頭，放上幾層紙巾給牠「方便」用，就這樣天天跟我睡。一直到牠夠大了，有「自主意識」才停。


&nbsp;


自小在手中養大，帥哥跟我們親得不得了，任何事牠都要參一腳，我洗米做飯，牠堅持要停在我肩膀上，阿SIR寫文章，牠要站在筆筒上，或阿SIR肩膀上，最有趣的一點是，鳥類隨時會排泄的，但是帥哥卻從來不曾大大在我們肩膀上，牠會走到肩膀最邊邊，歪著屁股「噗」到地板上，雖然我要擦地板，但是牠這「貼心」小動作，讓我跟阿SIR感動死了。


&nbsp;


帥哥天性好奇，而且貪吃，日常生活理牠最愛兩樣東西，蚯蚓？小蟲？才不是，我家帥哥吃素，除飼料外，我只給牠吃蛋黃、水果，牠的毛漂亮極了。


帥哥愛喝咖啡和紅酒。不可思議喔！有一次阿SIR沖咖啡，牠正好停在他肩上，開水沖入咖啡泛起的香味，引的牠急急忙忙離開肩膀，從手臂上走過來，停在手上，對著咖啡叫個不停，拿一隻小匙裝了咖啡吹涼，帥哥就急忙衝過來喝，喝光了還要，餵了幾次我怕牠拉肚子就不給了，牠還一副很不爽的表情咧！


&nbsp;


另一次是吃完飯，我們一時興起喝點小酒，當紅酒入杯時，這個小酒鬼等不及，直接停在杯緣埋首入杯喝起來，一連喝了好幾口，我跟阿SIR呆在一旁，這這這….什麼跟什麼？結果牠當然喝醉了，東倒西歪，還把吃下去的飼料吐出來。後來又發生一次，我們一時忘記，當牠的面喝酒，牠又衝過來要喝，這回我就不給牠喝了。


&nbsp;


帥哥喜歡玩把戲，最愛的一招是我把手垂下，牠從袖口一路振翅而上爬到肩上站著，玩幾次牠都奉陪。我們用食指輕頂牠肚皮，牠就會站在你手指上。跟所有鳥類一樣，帥哥愛吃瓜子，阿SIR幫牠把殼咬破，然後將瓜子嚼碎放在舌尖，牠會在他舌尖上輕啄取食，


其實牠吃瓜子本事大的呢，又快又完整，可要我們一起吃，牠就非要我們咬給牠，再自舌尖取食，而不肯自己吃了。


&nbsp;


說到整理羽毛，帥哥非常愛護自己的羽毛，沒事就一根根咬住順毛，因為在我們手上玩久了，身上毛變髒，這時我們就幫牠洗澡，原本還想牠會害怕，那知牠愛死了蓮蓬頭對著牠正面沖下，若是調換水的方向，牠一定跟著轉，堅持迎面沖水。之後的吹乾過程更爆笑，吹風機的聲音大一點也嚇不到牠，非但如此，牠簡直是愛上吹風機，毛吹乾後關機，牠還會叫幾聲表示還要呢！


&nbsp;


帥哥有時會願意住籠子，夏天太熱牠會就著喝水罐子洗澡，但是不過癮啊！我拿噴水霧的罐子噴牠，牠愛到會自己將左右翅膀輪流張開，側過身來指定我要噴腋下，左左右右十幾趟才罷手，然後讓自然風晾乾。我也會在籠邊放塊蘋果給牠，愛極啦！


&nbsp;


帥哥會叫自己的名字，叫的可清楚了，籠子掛在屋簷乘涼時，牠最開心，這時就會叫：帥哥、帥哥。好幾次鄰居經過都會來問：「你家的鳥叫帥哥嗎？」


是的，牠是帥哥，我們永遠的最愛。
