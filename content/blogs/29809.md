&nbsp;


用心去感覺對方的感覺





&nbsp;



我常常想，人會有那麼多煩愁悲苦，



絕大部分原因是太過執著於 「我」，

&nbsp;

放不下的全是「我的」，丟不開的，也都捨不得一個「我」。

&nbsp;

我要、我希望、我得到、我委屈、我失去、

&nbsp;

我少了些什麼、我盼望﹔我要年輕、漂亮富有、舒適。

&nbsp;

而別人的一切，若是能符合我的要求，

&nbsp;

我就開心、就快樂﹔同樣的如果對方不能配合我的一切，

&nbsp;

那麼，就感受到冷落、受到傷害，轉化為憤怒、怨恨的情緒。


&nbsp;

我們常說和誰談的來，


&nbsp;

也常喜歡用氣味相投來形容朋友的契合。
&nbsp;
一對男女相識、相知、相愛的更高境界，是心心相印，


&nbsp;

是心有靈犀﹔人與人之間，


&nbsp;

最完美的層次，是思想上的相通，心靈能產生共鳴....


這一切的一切，之所以會發生、能達到，


&nbsp;

主要是建立在雙方面中間，有一座橋，


&nbsp;

能夠互通的橋﹔想搭起這座橋，第一個原則，


&nbsp;

就是要瞭解對方的感受，然後用心去感覺對方的感覺。


&nbsp;

因為，在實際生活中，感覺往往比道理、


&nbsp;

社會規範更重要，尤其對感情籤細、思維敏銳的人，


&nbsp;

感覺，是一種相當主觀的情緒。
&nbsp;
它不關是非，更不論對錯，它不能


&nbsp;

用很理性的邏輯來分析，也不適於硬性的規範，


&nbsp;

完全是一層直接的情緒反映，


&nbsp;

就是一個人的語言、動作所帶給一個人的感應。
&nbsp;
&nbsp;
&nbsp;
多用一點心，多加一份慧心，


&nbsp;

多注意一下別人的感覺，多觀察週遭人們的一切，


&nbsp;

在適當的時候，表達自己的關心、同情，


&nbsp;

這不僅僅是一種最高貴的品格，也是一份令人愉悅


&nbsp;

的體貼，一份令人難忘的溫柔。


&nbsp;

用心去感覺，感覺世間萬物，


&nbsp;

感覺人間小事，感覺甜美、溫馨的快樂，


&nbsp;

你會發現，我們居住的這個世界原是處處充滿愛。

&nbsp;

體貼是一種快樂體貼是一種


&nbsp;

非常高貴、細緻、接近完美的品質。


&nbsp;

一個時時能體貼別人的人，男性我們稱為君子、紳士﹔


&nbsp;

女性稱為溫婉可人或淑女，一個知道體貼別人的人，


&nbsp;

必然懷抱溫柔，必為性情中人，


&nbsp;

也一定是一個值得交往信賴的朋友。


懂得體貼的男人，


&nbsp;

一定是好丈夫、好情人、好長官、好領袖。


懂得體貼的女人，


&nbsp;

絕對是好妻子、好母親、好朋友，好的讓你時時想念的女人。


只是，這麼美好的一份情愫，一種人性品格，


&nbsp;

卻逐漸地，一點一滴地在我們社會中剝落消失。


&nbsp;
