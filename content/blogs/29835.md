走迷宮看個性 

&nbsp;

&nbsp;





走到終點時 , 請 記住自己的英文字母 , 再看下面的答案 ~!!!!!!!!&nbsp;
&nbsp;



終點為 A 的 人： 
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;
&nbsp;你屬于比較有個性的一類人，做事情富有冒險精神，討厭一成不變的事物。 
&nbsp;
你有自己的世界觀，並且不容易受! 到! 別人的左右，有些固執。 
&nbsp;
自己決定的事情可以不顧週圍人的反對堅持做下去。 
&nbsp; &nbsp; &nbsp;
你喜歡別人的認可，有時候身邊的人與! 你! 唱反調，反而是你前進和堅持己見的動力。 
&nbsp;
建議在一些大事的把握上，如果認為身邊的人的意見不可靠， 
&nbsp;
可以請教一下自己崇敬的長輩或老師，這將對你的決定有很關鍵的指導作用。 
&nbsp; &nbsp; &nbsp; &nbsp;
&nbsp;! 適合的職業：警察、教練、作家 

&nbsp;**********************************************************************************************
&nbsp; 
終點為 B 的 人： 

&nbsp;自信的你有時候也會猶豫不決，你屬于比較有靈性的一類人。 

&nbsp;你對週圍世界的事物有比較敏銳的洞察力，而且能夠辨別是非。 
&nbsp;
你的心情起伏呈正弦波動，有時時來運轉，則好運不斷，事事順心，心情也很愉快； 

&nbsp;而有時一旦倒霉起來則禍不單行，百事不順。 

&nbsp;其實這裡邊有許多是主觀的因素，需要冷靜地思考，便可以解決問題。 
&nbsp;
你的感情比較豐富，感情上的順利令為你在其他事情上也信心百倍， 
而感情上一旦出現了問 &nbsp;題，會對你的情緒有很大的影響。 
&nbsp;
建議不開心時千萬不要自己苦思冥想，非要尋找一個自己! 的! 答案， 
&nbsp;
而是應當找朋友聊聊天，與老同學聚一聚， 
&nbsp; &nbsp;
&nbsp;或者上街去買一些自己想要的東西，有時答案會在某一瞬間浮出水面。 

&nbsp;適合的職業：漫畫家、會計、導演、設計師。 

****************************************************************** 
&nbsp; 
終點為 C 的人： 
&nbsp;
直率的你往往有些不拘小節，或者說容易忽略一些細節， 
&nbsp;
對週圍事物的洞察並不是十分的敏銳和細致， 
&nbsp; &nbsp;
但總會把握大的方向，雖然在理想的路上會有一些坎坷，但總能! 夠! 沿著正確的方向前進。 
&nbsp;
週圍的朋友願意和你在一起，尤其是熟識的朋友，當他們遇到困難時會找你聊天談心， 

&nbsp;但是偶爾也會與朋友發生矛盾，不過最終總會煙消雲散。 

&nbsp;建議多觀察一下週圍的世界，做事情要更加細心，也許會有不錯的發現。 

&nbsp;適合的職業：領導、律師、指揮 

************************************************************* &nbsp;
&nbsp;
終點為 D 的 人： 

&nbsp;
&nbsp;你對生活的態度很坦誠，並不喜歡大風大浪，屬于穩中求進的一類人。 
&nbsp;
你並不喜歡無謂的刺激。在你認為模仿要比創新容易得多，省事得多， 
&nbsp;
所以經常會參考別人的東西。 
&nbsp;
&nbsp;你比較注! 重! 親情，認為親人是世界上獨一無二的、最重要的東西。 

&nbsp;你對生活的態度比較隨和，但常常會缺乏目標， 

&nbsp;建議經常給自己確定一些階段性的目標，你的感情和事業都會更加順利。 

&nbsp;適合的職業：醫生、教師、歌手、記者、工人 

********************************************************** &nbsp;

終點為 E 的人： 

&nbsp; &nbsp;你對身邊親人和朋友的依賴性比較強，如果沒有他們，你的生活將是無法想象的。! 
&nbsp;
你喜歡熟悉的事物，經常會對一些事物產生懷舊感， 

比如歌曲、電影的片斷、食物的某種味道等等， &nbsp; &nbsp; 
&nbsp;這些事物會勾起你對往日的回憶或者莫名的親切感。 
&nbsp;
你不是很喜歡身邊的世界源源不斷地變幻， 
你喜歡熟悉的東西，熟悉的環境，熟悉的街道。 
&nbsp;
往往你曾經很喜歡的東西你會冠以經典之名並難以忘懷。 
&nbsp;
往往當你在一個陌生的城市中時，會有些莫名的緊張。 
&nbsp; &nbsp; &nbsp;
建議你應該獨立的去闖蕩一番，如果條件不允許的話， 
也可以到網上以另一個自己的身份登陸，也許會有所收獲。
