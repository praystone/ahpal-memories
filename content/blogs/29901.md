: 請注意飯後活動
以前一直以為吃飽飯後再走動，會有助消化，結果事實不然，...
最近小熊在一篇報導中看到，報導內容是關於飯後不宜散步，看
了這篇報導，讓小熊覺得好驚訝，以前一直以為吃飽飯後再走動
，會有助消化，結果事實不然，所以就激發小熊去找了幾項關於
飯後的禁忌，提供給各位親愛的朋友參考：

&nbsp;

&nbsp;

&nbsp;

★不宜急於吸煙：據專家考証，飯後吸一支煙，中毒量大於平常
&nbsp;&nbsp;&nbsp; 吸十支煙的總和。

&nbsp;

&nbsp;

&nbsp;

★不宜馬上吃水果：飯後馬上吃水果，很容易形成脹氣，所以吃
&nbsp;&nbsp;&nbsp; 水果最好在飯後1至2小時，或在飯前1小時。

&nbsp;

&nbsp;

&nbsp;

★不宜立即喝茶：因為茶葉中含有大量的單寧酸，這種物質進入
&nbsp;&nbsp;&nbsp; 胃腸道後，能使食物中的蛋白質變成不易消化的凝固物質。

&nbsp;

&nbsp;

&nbsp;

★不宜放鬆褲帶：飯後將褲帶放鬆，容易發生腸扭轉，引起腸硬
&nbsp;&nbsp;&nbsp; 阻，還容易引起胃下垂。

&nbsp;

&nbsp;

&nbsp;

★不宜馬上洗澡：飯後洗澡，四肢、體表的血流量會增加，胃腸
&nbsp;&nbsp;&nbsp; 道的血流量相應減少，從而使腸胃的消化功能減弱。

&nbsp;

&nbsp;

&nbsp;

★不宜百步走：人們常說：飯後百步走，活到九十九? A其實不然
&amp;nb sp;&nbsp; 。“百步走會因運動量增加，而影響消化道對營養物質的消化吸收。

&nbsp;

&nbsp;

&nbsp;

★不宜立刻睡覺：飯後立即睡覺，食物不能很好地消化，久而久
&nbsp;&nbsp;&nbsp; 之就會誘發胃病、腸炎等。

&nbsp;

&nbsp;


&nbsp;



結論：吃完飯........
