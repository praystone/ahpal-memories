&nbsp;&nbsp;&nbsp; 



開往西安的火車上，一個很漂亮的列車乘務員，

&nbsp;

盯著一個民工摸樣的中年人，大聲說道 "查票 " 。

&nbsp;

中年人渾身上下一陣翻找，終於找到了，卻捏在手掌中。

&nbsp;

列車員朝他怪怪地笑了笑，說：『這是兒童票。』 

&nbsp;

中年人憋紅了臉，囁嚅著說：

&nbsp;

『兒童票不是跟殘疾人票價一樣嗎？』

&nbsp;

列車員打量了中年人一番，問道：『你是殘疾人？』

&nbsp;

『我是殘疾人 !』

&nbsp;

『那你把殘疾證給我看看。』

&nbsp;

中年人緊張起來，說：『我沒有殘疾證，買票的時候，

&nbsp;

售票員就向我要殘疾證，我沒辦法才買的兒童票。』

&nbsp;

列車員冷笑了一下： 沒有殘疾證，怎麼能證明你是殘疾人啊？

&nbsp;

中年人沒有做聲，只是輕輕地將鞋子脫下，

&nbsp;

又將褲腿挽了起來–他只有半個腳掌。

&nbsp;

列車員斜眼看了看，說：我要看的是證件！是殘聯蓋的鋼印！

&nbsp;

中年人一副苦瓜臉，解釋說：

&nbsp;

『我沒有當地戶口，人家不給辦理殘疾證。
&nbsp;&nbsp;&nbsp; 
而且我是在私人工地幹活，出了事之後老闆就跑了，

&nbsp;

我也沒錢到醫院做評定……』

&nbsp;

列車長聞訊趕來，詢問情況。

&nbsp;

中年人再一次向列車長說明，自己是一個殘疾人， 

&nbsp;

買了一張和殘疾人票一樣價格的票……

&nbsp;

列車長也問：你的殘疾證呢？ 

&nbsp;

中年人說他沒有殘疾證，接著就讓列車長看他的半個腳掌。

&nbsp;

列車長連看都沒看，

&nbsp;

他不耐煩地說：

&nbsp;

我們只認證不認人！有殘疾證就是殘疾人，

&nbsp;

有殘疾證才能享受殘疾人票的待遇。你趕快補票。

&nbsp;

中年人一下就慌了。他翻遍了全身的口袋和行李，

&nbsp;

只有幾塊錢，根本不夠補票的。

&nbsp;

他帶著哭腔對列車長說：我的腳掌被機器軋掉一半之後，

&nbsp;

就再也打不了工了，沒有錢，

&nbsp;

連老家也回不去了，這張半價票還是老鄉們湊錢給我買的呢？

&nbsp;

求您高抬貴手，放過我吧！

&nbsp;

列車長堅決地說：那不行。『』

&nbsp;

那個女列車員趁機對列車長說：讓他去車頭鏟煤吧，算做義務勞動。

&nbsp;

列車長想了想說：『好！』

&nbsp;

中年人對面的一個老先生看不慣了，

&nbsp;

他站起來盯著列車長的眼睛，說：『你是不是男人？』

&nbsp;

列車長不解地說：『這跟我是不是男人有什麼關係啊！』
&nbsp; 
『你就告訴我，你是不是男人！』
&nbsp; 
『我當然是男人。』
&nbsp; 
『你用什麼證明你是男人呢？把你的男人證拿出來給大家看看！』

&nbsp;

周圍的人一下笑起來。

&nbsp;

列車長愣了愣，說：『我一個大男人在這兒站著，難道還是假的不成？』

&nbsp;

老者搖了搖頭說：『我和你們一樣，只認證不認人，

&nbsp;

有男人證就是男人，沒男人證就不是男人。』

&nbsp;

列車長卡了殼，一時想不出什麼話來應對。

&nbsp;

那個女列車員站出來替列車長解圍，

&nbsp;

她對老者說：『我不是男人，你有什麼話，跟我說好了。』

&nbsp;

老者指著她的鼻子，說：『你根本就不是人！』

&nbsp;

列車員一下暴跳如雷，尖聲叫道：『你嘴巴乾淨點！你說 "我不是人是什麼 ?』

&nbsp;

老者一臉平靜狡黠地笑了笑，說：『你是人？那好，把你的人證拿出來……』

&nbsp;

四周的人再一次哄笑起來。

&nbsp;

只有一個人沒笑，他是那個只有半個腳掌的中年人，

&nbsp;

他定定地望著眼前的這一切，

&nbsp;

不知何時，眼睛流下淚水，不知道是委屈，是感激，還是仇恨。

&nbsp;

得饒人處且饒人，事實證明---墨守成規未必是可行的，

&nbsp;

畢竟『法律不外乎人情！』 
對吧！與您分享...........
