&nbsp;


在網路裡留言或回覆是一種友情


&nbsp;


是一種欣賞別人的善良


&nbsp;


大家來此的目的不盡相同


&nbsp;


在此流連忘返的原因卻是難捨這一份淡淡的，輕鬆的朋友之誼


&nbsp;


或許你只想要一縷春風，而留言的朋友卻給你整個春天


&nbsp;


熱情的問候、真誠的關懷、善解人意的體諒、獨道精闢的觀點


&nbsp;


語重心長的開導都是欣賞別人，真誠付出的一種友情


&nbsp;


看著自己喜歡的文章、論點、心思...被大家所喜愛，所認同


&nbsp;


這共享的快樂難以言表，是一種知音的情懷帶來的愉快，
&nbsp;&nbsp; 
&nbsp;讓人難以忘懷...


&nbsp;


&nbsp;


留言或回覆是朋友給你雪中送炭的溫暖，錦上添花的美事


&nbsp;


在手指與心靈的凝眸間盈盈淺笑，靈犀剔透


&nbsp;


有時候心想，因為無聊，


&nbsp;


因為每一位留言或回覆而熟悉起來的朋友


&nbsp;


其實不經意間已陪著你我走過一段人生的旅途


&nbsp;


其中的賞心樂事只有身臨其境的人方能體會的到


&nbsp;


或許有一天會心境轉換，物非人非


&nbsp;


但這種快樂心情，給予別人與自己陽光的感覺一定難以忘懷


&nbsp;


或許不是忘不了，而是不想忘，罷了


&nbsp;


&nbsp;


生活在鋼筋水泥的都市裡，人和人的交流變得越來越難


&nbsp;


甚至連談話都在臉上偽裝著清一色的微笑面具


&nbsp;


把自己的內心世界深深的隱藏起來


&nbsp;


也許是因為這個世界太現實了


&nbsp;


&nbsp;


在這個電磁波橫流的世界，人們也更敏感的保護著自己


&nbsp;


寧肯獨自去品味孤獨，也不願輕易表達心裡的熱情


&nbsp;


但是我們哪一個不希望有人來聽我們傾訴呢


&nbsp;


都想摘下生活給我們的這虛偽面具，表達心中最原本最真實的自我呢...


&nbsp;


而在這個用電纜和思維構築的網上空間裡


&nbsp;


我們或多或少都懷著這樣心情，來釋放自己，結交朋友


&nbsp;


那一篇篇文章，和那一篇篇留言


&nbsp;


心和心之間架起了一座座美麗的彩橋


&nbsp;


這裡就像是一個沒有拘束的世界


&nbsp;


每個人都可以相互傾聽，相互鼓勵，相互安慰嘻笑打鬧，


&nbsp;


無處不透露出脈脈溫情，本來世界就應該是這樣的吧


&nbsp;


每當手指輕輕的敲擊著鍵盤


&nbsp;


就像整個人沁浸在香茗的芬芳裡，有朋友真好....


&nbsp;


如果有人問我為什麼對這個虛幻的網路世界仍有眷戀


&nbsp;


我會告訴她，因為人是感情的動物


&nbsp;


因為彼此間仍存有一份互動的情誼


&nbsp;


如果在這裡沒有這份互動的情誼,你還會眷戀什麼.....


&nbsp;


有時心情不佳時，想過不再寫文章


&nbsp;


把心底的秘密隱藏起來，讓它成為歷史


&nbsp;


可是每每想起許多朋友不時的關切和問候，


&nbsp;


那煩惱也就跑了九霄雲外


&nbsp;


&nbsp;


留言或回覆是一種友情，寫文章是一種舒發和釋懷


&nbsp;


寫出你的心聲，道出你的友情


&nbsp;


讓我和妳們結了緣......


&nbsp;


拿起你的筆開起您的智慧和心窗，盡情的塗抹吧


&nbsp;


網路中最美麗的行為...


&nbsp;


您還等什麼....


&nbsp;


寫出你的心聲，道出你的友情，


&nbsp;


讓我們一起期待著春天的到來.....


&nbsp;


美好的春天...似乎就在妳打開心門的那一刻


&nbsp;


悄悄地到來!


&nbsp;


&nbsp;
