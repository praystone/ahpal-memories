雖然說夏季水果要多吃，但是依照中醫的看法，人有體質，水果也有水果的性質
，每一種水果的營養價值和藥用價值各不相同，一不留神，吃水果也會讓人不舒
服，但如果根據自己的體質選擇水果，那麼滋養的功效則會事半功倍！

體質分類是傳統中國醫學的獨特理論，也就是一般常聽到的寒、熱、虛、實。
“寒體質”的人體內產熱量較少，所以手足較冰涼，臉色比一般人蒼白，喜歡喝
熱飲，很少口渴，即使炎炎夏日，進入有空調的房間也會覺得不適，需要喝杯熱
茶或加件外套才會舒服。相反，“熱體質”的人產熱能量較多，臉色紅赤，容易
口渴舌燥，喜歡喝冷飲，夏天進入空調房間就倍感舒適。
體質虛是生命活動力衰退所造成，人的精神比較萎靡，心悸氣短；體質實則容易
發熱、腹脹、煩躁、呼吸氣粗，容易便秘。

水果屬性V.S身體體質
中醫認為食物進入體內會產生“寒、熱、溫、冷”的作用。因此，每種水果都有
它的“個性”。中醫強調均衡、陰陽調和，所以體質偏熱的人要多吃寒涼性的食
物，體質偏寒的人，自然多吃溫熱性的食物，吃水果的原則也一樣。
中醫認為，熱性水果指的是熱量密度高、糖分高的水果。這樣的水果吃下去，容易
上火，身體能量會增加。相反地，熱量密度低、富含纖維，但脂肪、糖分都很少的
水果，就屬於寒性，這樣的水果吃下去，纖維和水分會佔據腸胃空間，讓人吃不下
其他營養的食物，人吃多了就會越來越沒有能量、沒體力，也越來越怕冷、虛弱。

那麼各種體質該怎麼搭配水果呢？營養專家為你指點迷津：

1、桃子——含鐵量居水果之冠
&nbsp;&nbsp; &nbsp; &nbsp;民間有句俗話“桃子養人杏傷人”。因桃子富含多種維生素、礦物質及果酸，
&nbsp;&nbsp; &nbsp; &nbsp;其含鐵量居水果之冠。鐵是人體造血的主要原料，對身體健康相當有益。

2、杏子——止咳潤腸通便好
&nbsp;&nbsp; &nbsp; &nbsp;杏含有檸檬酸、蘋果酸、β胡蘿蔔素，主要用於止咳平喘、潤腸、通便。
&nbsp;&nbsp; &nbsp; &nbsp; 但是《本草綱目》記載“生食多，傷筋骨”。

3、西瓜——清熱解暑又利尿
&nbsp;&nbsp; &nbsp; &nbsp;我國民間有句諺語：夏日吃西瓜，藥物不用抓。說明夏季最適宜吃西瓜。
&nbsp;&nbsp; &nbsp; &nbsp;西瓜富含維生素A、B1、B2、C，葡萄糖、蔗糖、蘋果酸、谷氨酸和精氨酸等
&nbsp;&nbsp; &nbsp; ，有清熱解暑、利小便、降血壓的功效，對高熱口渴、暑熱多汗、腎炎尿少、
&nbsp;&nbsp; &nbsp; 高血壓等有一定的輔助療效。
&nbsp;&nbsp; &nbsp; 西瓜雖好，但中醫專家認為，西瓜屬寒性食物，易傷脾胃，所以脾胃虛寒、平
&nbsp;&nbsp; &nbsp; 常有慢性腸炎、胃炎及十二指腸潰瘍等或大便稀溏的人最好少吃。正常人也不
&nbsp;&nbsp; &nbsp; 宜食用過量，否則會損傷脾胃而引發消化不良或腹瀉。
&nbsp;&nbsp; &nbsp; 需要提醒的一點是，夏天感冒發燒的患者常常借助進食西瓜來補水、退燒，但
&nbsp;&nbsp; &nbsp; 是因為它屬於甘寒食物，不宜用於風寒感冒及感冒初期，特別是患有畏寒、無
&nbsp;&nbsp; &nbsp; 汗等症狀者不宜食用。

4、柑橘——檸檬烯有抗癌作用
&nbsp;&nbsp; &nbsp; &nbsp;柑橘果實能潤肺理氣，新鮮橘汁含多種肌酸、維生素，對人體新陳代謝有幫助
&nbsp;&nbsp; &nbsp; &nbsp;，具有美白效果，還兼具多種保健功效。橘瓤表面的白色絲絡，含維生素P，
&nbsp;&nbsp; &nbsp; &nbsp;能防治高血壓，具化痰功效。有一種著名的精油，叫檸檬烯精油，這些精油是
&nbsp;&nbsp; &nbsp; &nbsp;大多數橙橘類最主要的部分，目前研究指出檸檬烯具有抗癌作用。

5、木瓜——治療蛋白質消化障礙
&nbsp;&nbsp; &nbsp; &nbsp;木瓜不僅是一種美味的水果，還有醫療效果。木瓜中含有一種稱為番木瓜
&nbsp;&nbsp; &nbsp;（papain）的重要消化?，可將蛋白質類食物分解成可消化的狀態，可溶解
&nbsp;&nbsp; &nbsp; &nbsp;高達其本身35倍的瘦肉，這就是人們會以木瓜來治療蛋白質消化障礙的原因
&nbsp;&nbsp; &nbsp; &nbsp;。其在木瓜樹的葉部及尚未成熟的木瓜果皮中含量最多。

6、鳳梨——分解蛋白質消血塊
&nbsp;&nbsp; &nbsp; &nbsp;每100克鳳梨果實中所含的維生素C高達30毫克，並含有豐富的水分。它的果肉
&nbsp;&nbsp; &nbsp; &nbsp;中和木瓜一樣含有一種能分解蛋白質的酵素，因此它能柔軟肉質、消解血塊。

7、草莓——減少日曬疼痛
&nbsp;&nbsp; &nbsp; &nbsp;草莓富含維生素C、B、鈣、磷和鉀，今日仍在植物性藥品中佔有一席之地。
&nbsp;&nbsp; &nbsp; &nbsp;其葉部煮沸後可當做一種收斂劑，並能治療腹瀉、發燒、口內潰瘍及牙齦等疾病。

8、葡萄——抗氧化效果好
&nbsp;&nbsp; &nbsp; &nbsp;葡萄籽的抗氧化效果不僅是維生素C的20倍，更是維生素E的50倍。葡萄籽含有
&nbsp;&nbsp; &nbsp; &nbsp;大量的OPC抗氧化劑，OPC是一種強效類黃酮，主要存在於表皮與種子裏，紅
&nbsp;&nbsp; &nbsp; &nbsp;色葡萄籽尤其是OPC的有效來源，是增加人體內抗氧化活動的潛在關鍵，可保
&nbsp;&nbsp; &nbsp; &nbsp;護免疫氧化損傷，並延緩老化過程。

9、香蕉——抗憂鬱助睡眠
&nbsp;&nbsp; &nbsp; &nbsp;香蕉為人類最古老的水果之一，其營養價值相當高，是天然鉀的來源，同時還
&nbsp;&nbsp; &nbsp; &nbsp;含可以抑制引發高血壓、心血管疾病的鈉，它維持正常血壓和心臟功能，還富
&nbsp;&nbsp; &nbsp; &nbsp;有讓人遠離憂鬱的維生素B6及抗緊張的礦物質鎂，也是必須氨基酸———色氨
&nbsp;&nbsp; &nbsp; &nbsp;酸的來源。其和維生素B6、煙鹼酸及鎂一起作用，是人體製造血清素的主要原
&nbsp;&nbsp; &nbsp; &nbsp;料，具有抗憂鬱、鎮定、安眠之功效。

10、蘋果——降膽固醇預防膽結石
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;蘋果不僅含有蛋白質、脂肪、碳水化合物、多種維生素、礦物、蘋果酸等，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;還有一種寶貴的果膠成分。果膠是一種可溶性纖維素，能促進胃腸蠕動，調
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;理腸胃，並和膽固醇結合，幫助人體排出體外，達到降低膽固醇的目的。其
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;中果膠也會和膽囊中的膽固醇結合排出，可以稀釋膽汁，有預防膽結石的效果。
