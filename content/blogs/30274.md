這些食物的營養價值很高，但很多人卻都不喜歡吃：

1.大白菜
　　一杯剁碎的大白菜中只含有22卡路里的熱量，卻含有大量營養物質。大白菜
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;中含有蘿蔔硫素，可以增加體內酵素的含量。(酵素可以阻止破壞細胞的自由
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;基的產生並且可以防止癌症)研究發現，和其他任何植物化學物相比，蘿蔔硫
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;素促進酵素產生的能力是最高的。

2.甜菜
　　這種紅色的蔬菜含有大量葉酸和甜菜堿。這兩種化學物質共同作用可以降低
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;高半胱氨酸的水準，這是一種炎性混合物，可以損害動脈，增加心臟病患病
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;機率。而且甜菜中的自然色素--β花青?經實驗證明可以防止癌症。

3.石榴
　　石榴含有高濃度番茄紅素，比番茄和西瓜更能防止前列腺癌。而且，一杯石榴
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;中含有688毫克鉀，比香蕉中鉀的含量多63%。石榴中還含有大量纖維，每杯中
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;含有9克 。

4.萵筍
　　半杯熟萵筍中含有大量葉黃素和玉米黃質，每杯含有10毫克。這些叫做類胡蘿
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;蔔素的化學物可以防止視網膜老化，因為這些物質可以吸收損害眼睛的光線。

5.肉桂
　　肉桂有助於控制血糖，降低心臟病患病率。事實上，研究發現，2型糖尿病患
&nbsp;&nbsp; &nbsp; &nbsp; 者每天攝入1克 肉桂，一直持續6周，其血糖、血脂和不良膽固醇都會有顯著降低。

6.馬齒莧
　　馬齒莧中的歐米茄3含量最高，而且研究發現，馬齒莧中的褪黑激素(阻止癌細
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;胞產生的一種抗氧化劑)是其他任何水果和蔬菜的10倍。

7.石榴汁
　　研究發現，每天喝2盎司( 56克 )石榴汁，持續一年，收縮血壓可降低21%，流向
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;心臟的血流量會顯著改善。

8.枸杞
　　在所有的水果中，枸杞的抗氧化能力指數是最高的。而且研究發現，枸杞中的
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;糖分可以降低胰島素抵制，從而防止糖尿病。

9.梅乾
　　梅乾含有大量新綠原酸(neochlorogenic )和綠原酸(Chlorogenic acid)，這是兩種可以
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;抵抗自由基的化學物。這些自由基可以引起細胞的機構損壞，從而導致癌症。

10.黃瓜籽
　　黃瓜籽中含有大量鎂，研究發現，血液內鎂含量高的人早死的機率會降低40%。
