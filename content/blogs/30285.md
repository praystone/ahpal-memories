一輩子，最動聽的三句話

&nbsp;



&nbsp;

&nbsp;


愛你一生不變…

&nbsp;

相愛的人都希望對方說出這樣的一句話，

&nbsp;

但說出來的確非常容易，

&nbsp;

做出來就要用一生的精力去兌現。


&nbsp;

男人聽到這句話的時候更在乎女人對自己忠誠，

&nbsp;

女人聽到這句話的時候更希望男人疼愛自己一輩子。


&nbsp;

經常和一位好朋友的姥姥在一起聊天，

&nbsp;

老人家對待年輕人特別的熱情總是希望我們常常去看她，

&nbsp;

然後她就會把家裡好吃好喝的一下子

&nbsp;

全都找出來讓我們飽餐一頓。

&nbsp;

她說，她喜歡和年輕人在一起，喜歡年輕人身上的那股衝勁，

&nbsp;

更願意把自己的人生感悟和年青人一起分享！

&nbsp;

尤其是她對愛情的感慨，讓人感動也學到了許多

&nbsp;

那個年代的人的優點和單純的一面，

&nbsp;

尤其老人提到的女人一輩子最愛聽

&nbsp;

男人說的三句話更是令人感慨萬千！

&nbsp;

&nbsp;

第一句，我愛你

&nbsp;

當每個人青春年少的時候都希望對方說我愛你，

&nbsp;

喜歡聽這麼一句話，尤其是越來越開放的社會，

&nbsp;

年輕人更願意開放的表達自己的愛。

&nbsp;

說出來的愛雖然沒有做出來更加的真切和實在，

&nbsp;

但許多女孩子更願意聽到男人一遍又一遍的說出這句話來麻木自己。

&nbsp;

因為女人都喜歡做夢並且喜歡把自己愛的夢想表現在言語中，

&nbsp;

在這個階段的男孩子如果把我愛你多說幾遍，

&nbsp;

肯定戀愛就會成功也會更加招女孩子喜歡。

&nbsp;

&nbsp;

第二句，我疼你


伴隨著年齡的增長，

&nbsp;

最初的戀愛也變成了現現實的婚姻，

&nbsp;

當婚姻降臨在男人和女人身邊的時候，

&nbsp;

其實就是最平淡的日子，

&nbsp;

過日子不像最初的戀愛那麼讓人充滿無限幻想。

&nbsp;

而是要一日三餐油鹽醬醋鍋碗瓢盆的算計，

&nbsp;

所以在這個階段，更多的女人都越活越真實，

&nbsp;

不是把自己的愛情與生活寄托給神和上帝，

&nbsp;

但是更願意看到老公對自己實實在在的好。

&nbsp;

在生活中、學習中對自己倍加照顧、

&nbsp;

真心的疼愛自己，並且把自己真的放在心裡。

&nbsp;

&nbsp;

第三句，我扶你

&nbsp;

當婚姻過了銀婚，迎接金婚的時候，

&nbsp;

當兒女都成長為大人的時候，

&nbsp;

當看著對方悄悄老去的時候，

&nbsp;

更多的女人願意聽到男人說的一句話是我扶你！

&nbsp;

我扶你是一種最用心的愛，是一種最真的表達

&nbsp;

是老來伴的最親切行動。

&nbsp;

其實，在生活中更多的愛情的結果就是老來有個伴，

&nbsp;

讓自己最愛的人陪伴一生，永遠都守候在自己身旁，

&nbsp;

當你走不動的時候，我用車推你，

&nbsp;

當我走累的時候，你扶我前行，

&nbsp;

用最實際的行動詮釋出愛情的偉大和完美。

&nbsp;

當我們還年青的時候，

&nbsp;

也許我們還不能完美理解這三句話的真正含意～

&nbsp;

但伴隨著時間的推移，我們一天天老去的時候就會發現，

&nbsp;

其實，愛就是身邊對自己身邊愛的人，

&nbsp;

只是簡短的幾句話，她就會感覺到一生的幸福．
