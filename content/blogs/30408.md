渴望愛情 → 不知死活的傢伙.物色對象 → 你活得不耐煩了.結婚熱潮 → 爭先恐後的去使.相親 → 為自己的墓地看風水.愛慕 → 大限之期不遠矣.表白 → 自掘墳墓.拒絕 → 死裡逃生.談戀愛 → 這不是玩命是什麼.寫情書 → 為自己的墓地分期付款.婚友社 → 葬儀社招桃花→代表異性緣非常好.婚姻專家 → 公墓管理員結婚紀念日 → 清明掃墓節.閃電結婚 → 猝死先上車後補票 → 爽死.奉子之命結婚 → 怎麼死的都不知道對婚姻猶豫不決 → 生死一瞬間假結婚 → 裝死.求婚告白 →往生咒異國之戀 → 客死他鄉.冷戰 → 苟延殘喘分手 → 千鈞一髮.破鏡重圓 → 該來的還是要來求婚 → 教唆自殺.儲蓄結婚基金 → 投保壽險訂婚 → 一隻腳已經踏進了棺材.結婚 →雙雙殉情第三者 → 盜墓.移情別戀 → 遷墓草莓麵包 →衛生棉 .離婚 → 置之死地而後生訂婚宴客 → 追悼會.結婚宴客 → 超渡法會親朋好友 → 奔喪大隊.包紅包 → 慰問金小雨衣→ 保險套.公證結婚 → 由法院出具死亡證明集體結婚 → 集體自殺
