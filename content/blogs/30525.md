&nbsp;

 

愛情恰恰

&nbsp;



&nbsp;


有一天，康小明考試考的不好， 

&nbsp;

他回家之後很傷心的對他媽說：

&nbsp;

媽！我都考了那麼多次了，成績還是如此，

&nbsp;

我真的累了，我想喝農藥自殺。

&nbsp;

&nbsp;

此時，

&nbsp;

康小明的媽媽正在唱台語歌（愛情恰恰）的KTV，

&nbsp;

沒空理他，只見他媽媽唱著：

&nbsp;

「喝下去，喝下去，不要漏氣……」

&nbsp;

&nbsp;

頓時康小明內心有點傷感的又說：

&nbsp;

「媽！家裡沒有農藥

&nbsp;

那我不喝農藥了，我要選擇跳樓囉。」

&nbsp;

此時，他媽的又剛好唱到：

&nbsp;

「跳下去，跳下去，大家歡喜………」

&nbsp;

&nbsp;

康小明心想我媽媽怎會如此對待我呢？！

&nbsp;

康小明這時候火都上來了，非常生氣的說：

&nbsp;

「媽！我到底是不是你的兒子啊？！」

&nbsp;

只見康小明他媽媽又唱到：

&nbsp;

「不是！不是……不是……你！」

&nbsp;

&nbsp;

此時康小明已經氣到口吐白沫暈眩過去了…

&nbsp;

他媽媽竟然還樂在KTV信心滿滿的說：

&nbsp;

&nbsp;

「來賓！請掌聲鼓勵鼓勵………」
