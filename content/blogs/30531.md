潤喉茶
〔澎大海+蜂蜜〕
&nbsp;&nbsp;【作法】:將澎大海打碎放入保溫杯中，沖入開水後即可飲用，具潤喉、防止發炎、通便作用。

〔羅漢果〕
&nbsp;&nbsp; 【作法】: 將半粒或一粒打碎後，用紗布包成一小包，丟入保溫杯中沖泡後即可飲用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;屬甘味劑，可進行自由基清除。

〔甘草水〕
&nbsp;&nbsp;【作法】: 將甘草片放入保溫杯中沖泡後嗽口，對於發炎的喉嚨具有溫潤的幫助。

〔麥門冬+人參鬚〕
&nbsp;&nbsp; 【作法】: 將麥門冬與人參鬚放入保溫杯中沖泡後，即可飲用。可生津補氣。

〔菊花茶〕
&nbsp;&nbsp; 【作法】: 菊花十朵放入保溫杯中沖泡後加蓋密閉，略冷後即可飲用，喜喝冰涼者，可沖開水5分滿，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 加入冰塊即可。另可加適量之蜂蜜。清肝明目。

〔菊枸茶〕
&nbsp;&nbsp; &nbsp;【作法】:將枸杞子20粒和菊花10朵一起放入保溫杯中沖入熱開水即可。

氣血雙補安神粥
【材料】:酸棗仁一兩、茯神5錢、黨參一兩、五味子5錢、桂圓肉5錢、糯米半杯、冰糖適量。

【作法】: 1.酸棗仁洗淨，用毛巾吸乾，放於砧板上用刀背壓碎，後和茯神、黨參、五味子一併放入電鍋
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 之內鍋中加水六杯，外鍋加水半杯煮至開關跳起，紗布過濾取高濃汁。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;2.米洗淨泡於少量清水中一小時再加(1)之濃汁及桂圓肉煮至成粥，加適量冰糖即可食用。

【說明】:茯神：寄生於松樹，抱松樹根而生之茯苓，具鎮靜安神作用。茯神和茯苓相同，除補脾利水外，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;具有較強之鎮靜、&nbsp;安神作用，而配合五味子之斂肺滋腎，生津斂汗；一般發汗過多，身體疲 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 倦，元氣缺失時，則配合五味子和補氣之黨參相配伍，亦常用於神經衰弱，過度疲勞而失眠
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;，尤其是耳鳴、眩暈則可和酸棗仁相配合，亦可減輕症狀。&nbsp;

潤腸安神粥
【材料】:熟地黃1兩、里脊肉2兩、柏子仁5錢、酸棗仁2錢、香菇5朵、蓬來米半杯。

【作法】:1.熟地黃切細，加溫水一杯浸泡軟後，放入果汁機打碎均勻待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 2.柏子仁及酸棗仁洗淨，用毛巾吸乾，用粉碎機打成粉。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 3.香菇洗淨加少量水潤軟後，切絲，里脊肉切絲，加少量醬油、太白粉、香麻油拌均待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 4.米洗淨加入1之地黃均勻液加水6杯，煮成粥後加入(3)之香菇、肉絲攪拌加熱，至肉熟為度，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;再加入柏子仁、酸棗仁粉末拌勻，即為一道爽口的潤腸安神粥。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;5.此道藥膳對於易動悸、便秘、老年人亦可將熟地黃改用肉蓯蓉5錢、熟地黃5錢，作用如(1)相似。

【說明】:柏子仁味甘、性平，含有脂肪油，具有寧心安神，潤腸通便，止汗之寧心安神作用，尤其是血虛
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 不眠配合熟地黃更相得益彰。老人或產後虛弱體質者，為增加其補性，可酌加肉蓯蓉。
【注意】本藥膳具有通便安神，下痢者禁止使用。

補中益氣、增進食慾─山黨蓮子雞
【材料】:新鮮山藥半斤，黨參一兩，茯苓一兩，蓮子二兩（新鮮半斤），土雞一隻，枸杞三錢，豆苗適量。

【作法】:(1)山藥洗淨後，用不鏽鋼刀削去外皮，用鹽水略浸泡。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)將黨參和削去外皮的山藥，一起放入磁鍋中，加水4杯，再放入電鍋中，外鍋加水半杯，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 煮至開關跳起，略冷後，濾去渣，留汁。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(3)土雞去毛，除去內臟之脂肪，放入沸水中燙洗，取出，用冷水沖乾淨後，待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(4)蓮子最好是用新鮮者半斤洗淨，若乾蓮子則最好洗淨後，放入沸水中煮沸1分鐘，即刻撈放
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;入大碗中，加蓋悶10分鐘，即可軟化。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(5)將雞放入燉鍋中，依序加入切塊之山藥，茯苓，蓮子及(2)之湯汁，最好再加入適當之水，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;以淹蓋雞為度，加蓋放入電鍋中，外鍋加水一杯，煮至開關跳起，略冷，即可上桌食用，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 上桌前加入枸杞及豆苗，則為一道色香味俱全之補氣聖品。

【說明】:黨參，味甘，性微溫，具有補氣健胃之作用，其水煎液對兔子之紅血球及血色素均有提昇之
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 作用，因此具有造血功能，並有祛痰鎮咳及降壓之作用，與人參同具有補氣作用，然而其補
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 氣作用十分緩和，僅為人參之1/2～1/8，另外人參不適高血壓者使用，因此黨參較適宜，為
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 老少鹹宜之補氣材料。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;茯苓，補脾健胃，利水滲濕，具有利尿及提昇免疫之功能，為茵類之子實體含有豐富之多
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;糖體。山藥，補脾健胃，益肺腎，含有粘糖蛋白，多糖體；除具有滋養強壯外，尚能幫助
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 消化，補疲勞增加體力，止瀉，祛痰。蓮子性平，具有清心益腎，健脾止瀉，益腎固澀，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;為中藥中收斂性強壯藥。配合補中益氣之土雞，則成為一道增加食慾補脾健胃食膳，加入
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 紅色之枸杞，增添美味顏色外，尚有滋陰明目的效果。

妊娠惡阻茶
【材料】:(1)紫蘇梗2錢、陳皮1錢、縮砂1錢、適量果糖或冰糖。(2)新鮮金桔或鹽金桔5粒、紫蘇3片
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 、適量果糖或蜂蜜。

【作法】:(1)將紫蘇梗、縮砂和切細陳皮放入磁杯中加水八分滿，放入電鍋中，外加1/3杯水，煮至
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 開關跳起，加適量甜度之果糖即可飲用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)金桔切片及紫蘇切碎放入磁杯中加水八分滿，放入電鍋中同上法。

【說明】:紫蘇──具有行氣寬中，即調整腸胃功能，幫助消化，增強腸胃蠕動及胃液分泌，配合金桔
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 則止嘔效果佳。以上兩種茶劑適合妊娠中之嘔吐、胸部苦悶、噁心、下腹部痛之妊娠惡阻。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;☆ 若口味不佳缺乏食慾則（1）之茶劑更適宜，乃因縮砂可溫胃。

小兒健康點心
【材料】:山藥4兩、浮小麥3錢、薏仁3錢、神麴3錢、米半杯、冰糖適量。(成人可多加山渣2錢)

【作法】:(1)山藥洗淨去外皮，泡於檸檬水中。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)將浮小麥和神麴加水4杯放入電鍋內鍋中，外鍋加水半杯，煮至開關跳起。等其冷卻時
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 即可將渣濾除。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(3)米洗淨加水用果汁機打成乳狀物再加入薏仁。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(4)將(1)之汁倒入鍋中加水4杯，煮沸後緩緩加入米漿，拌勻煮至半透明，略悶後加入適量之
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;冰糖後再，將山藥磨成泥放入攪拌均勻即可食用，為幼兒最佳之點心、飲料。

【說明】浮小麥有收斂作用，尤其在出虛汗之改善。山藥之粘液物含有豐富之消化酵(Amylase)而有
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;幫助消化及止渴之作用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;而薏仁之利水消濕，可減少胃中及身體內之水分。米露不加糖亦可瘦身。若是成人想食用，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;可多加山渣2錢，可消脂消脹。

山藥養生元宵
【材料】:新鮮山藥一斤、蓮子4兩、桂圓肉20粒、地瓜粉適量、黨蔘1兩、紅棗20粒、檸檬半粒。

【作法】:(1)山藥洗淨削去外皮，浸於檸檬水中1分鐘即放入電鍋中，蒸熟透後取出，用不鏽鋼網壓成
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 泥狀後，加入適量之地瓜粉，揉搓成塊，用濕毛巾蓋好待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)紅棗洗淨，略為刀割後，加入黨蔘、山藥外皮和水4杯，放入電鍋之內鍋，外鍋加水半杯，
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 煮至開關跳起，用時去渣取汁。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (3)蓮子洗淨，放入煮沸之水中燙洗；即刻撈起再放入碗中，加蓋略悶5分鐘後，再加入(2)之湯
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 汁1杯，放入電鍋中，外鍋放半杯水煮至開關跳起後，取出蒸爛熟透之蓮子，用不鏽鋼網壓
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;泥後，再將切細之桂圓肉一起拌勻作成餡待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(4)山藥作成之塊，搓作成條，切塊壓平，再將上述蓮子桂圓餡包入，揉成大元宵。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(5)將黨蔘大棗去黨蔘之湯汁煮沸後加入作好的元宵，改用小火煮至元宵浮起即可食用。

【說明】:山藥，補脾健胃、益肺腎，山藥中所含之天然成分，經現代藥理研究發現含有消化酵素之
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 黏液，其含有之多糖體可降低血糖及提昇免疫黨蔘補氣，桂圓肉補血；加入紅棗的藥引子，可調和本食 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;膳之免疫補氣作用。

補氣養血精氣粥
【材料】:黃精1兩、枸杞半兩、生地黃半兩、麥門冬1兩、蓬來米1杯、尾冬骨（無油）4兩。

【作法】:(1)米洗淨，泡於清水中。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)黃精生地切成小片。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (3)冬去蕊（一般中藥店即可買到，若未去蕊，可先將麥冬洗淨，放置二十分鐘，使整顆
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 麥冬潤軟後，用刀切開除去中間之白蕊，一般中醫界以去蕊可除煩，因此麥冬一定要
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 用去蕊者）切成小塊待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(4)尾冬骨切小塊（買時即先請切塊）洗淨後，放入沸水中，燙洗以除去腥待用。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;(5)將洗淨(1)之米、(2)(3)(4)之材料加水六～八杯，放入電鍋中，外鍋中加水一杯，煮至
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;開關跳起，即可聞到十分香醇之精氣粥，食用前加入枸杞子拌勻，即可上桌食用。

【說明】:黃精味甘性平，具有補益、填精髓強筋骨之傳統療效；生地黃味甘性寒，具有補血，滋陰清
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 熱之效；麥冬味甘，具有滋陰生津，根據筆者之研究，麥冬水抽出液具有提昇造血功能力作
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 用；配合枸杞子之滋陰明目，補腎護肝；米之補中益氣。是一道適合作為早餐或點心之更年
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 期婦女的補氣血之清熱藥膳食譜。

清熱涼血──蓮藕汁
【材料】:藕節5段、適量蜂蜜

【作法】:(1)藕節洗淨、壓段後，將土洗淨後，放入果汁機中，搾汁去渣，再加入適量蜂蜜及冰開水
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ，放入冰箱中，冰涼飲用。

【說明】:藕節具有清熱涼血作用，一般在中藥店買到的是乾品，現在是『蓮藕』之季節，吃蓮藕常把
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 藕節去掉，因其纖維多而不好吃，卻不知到此乃是夏日最好的食物。藕節含有抗氧化之多酚
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 類成分，禁與金屬、鐵器相遇，會起化學反應而變黑色，因此切時最好用不鏽鋼刀具。藕節
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;是指蓮之地下莖藕之節部，具有收斂止血作用，新鮮者具有清熱涼血的作用，因心急、煩熱
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;易造成末梢之血管張而臉色紅嫩，另有些原本有胃不適或潰瘍、有胃出血傾向者，或咳嗽時
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;略有血絲，此時則宜選擇具有熱之新鮮藕節。涼血乃為中國醫學之名辭，以現代藥理學解釋
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ，乃降低血流量，減少血管壁之壓力，而達止血之效用。

水性體質瘦身藥膳
補中益氣瘦身粥──提升免疫冬瓜粥
【材料】:黃耆40公克、冬瓜子10公克、新鮮帶皮冬瓜300公克、枸杞子10公克、良質米1杯、冰糖適量。

【作法】:(1)將冬瓜洗淨，削去皮，取子，冬瓜切成小丁，待用，米洗淨泡於清水中。
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (2)黃耆及冬瓜子、冬瓜皮加水4杯，放入不鏽鋼鍋內鍋，於電鍋外鍋加水半杯，煮至開關跳起
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ，成粥後，再加入枸杞及適量冰糖調勻。放入燜燒鍋中，可當正餐亦可當點心。

【說明】:黃耆補氣，冬瓜及子利水滲濕，配合米之補中益氣。冬瓜子除利水外，近代藥理研究，尚發現
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 有生干擾素之作用，配合滋陰明目之枸杞，既美觀又增加口味。本食膳具有利尿補氣之健康瘦
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 身食膳。

風熱頭痛改善露
【材料】:白芷2錢、防風1錢、荊芥1錢、薄荷1錢、綠茶1錢、適量冰糖。

【作法】:白芷、防風、荊芥加水3杯，煮沸後改用小火煮3分鐘略為悶後，再煮沸一次後，加入薄荷
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 、綠茶後一煮沸即可熄火，加蓋悶至微濁即可茶飲，味道十分芳香，亦可加入少量冰糖調
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;至喜愛的甜味。

【說明】:本茶劑最適合感冒頭痛，特別是前額部分之疼痛或血虛之偏頭痛。白芷具有袪風解表、止痛
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;、消腫排膿作用，而其芳香成分具有刺激中樞神經興奮，因此亦為中醫感冒頭痛常用之主藥材之一。
