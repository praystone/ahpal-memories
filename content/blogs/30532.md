&nbsp;


&nbsp;


一位長髮美女,走進紐約的一間銀行


&nbsp;


並以她又圓又亮的眼睛,看著貸款人員說:


&nbsp;


我要去歐洲出差兩個星期,想要跟銀行借5000美元


&nbsp;


貸款人員無法置信,因為她的臉上始終掛著微笑,


&nbsp;


不像缺錢的女人!


&nbsp;


&nbsp;


但拉回現實,並跟她說銀行需要擔保品.


&nbsp;


隨後長髮美女坐到貸款人員的對面,


&nbsp;


並交出停在銀行外面的一輛賓士跑車的鑰匙!


&nbsp;


所有的手續都已完成,銀行也接受那輛車為擔保品後,


&nbsp;


一位行員,隨即將車子開到銀行的車庫停放.



兩個星期後,長髮美女回到了銀行.


&nbsp;


還了5000美元的借款,另外付了15.41的利息.


&nbsp;


&nbsp;


貸款人員困惑的看著長髮美女的臉蛋,


&nbsp;


並說:我們很高興跟妳做生意,而且這個交易又進行的非常完美.


&nbsp;


但我們有些困惑,妳離開時,我們對妳做了一些調查,


&nbsp;


發現妳原來是個~富豪!


&nbsp;


因此,非常困惑妳為什麼要借5000美元呢?


&nbsp;


&nbsp;


&nbsp;


長髮美女轉動著那雙大眼睛,


&nbsp;


回答他說:請你告訴我,


&nbsp;


在紐約還有哪裡能讓我的車停兩個星期,


&nbsp;


卻只要付15美元呢?


&nbsp;
