&nbsp; 你對愛情忠誠嗎 ! 


&nbsp;



&nbsp;

當你在公園裏散步時，看見一個長相不錯的異性，坐在長椅上沉思，

&nbsp;

你會認為他處在什麼樣的狀況下？

&nbsp;

&nbsp;


A.他在等人

&nbsp;

B.他正在煩惱一件很重要的事

&nbsp;

C.他看起來不受女人歡迎

&nbsp;

D.你並沒有特別注意他

&nbsp;

&nbsp;

&nbsp;

&nbsp;


&nbsp;

A. 他正在等人

&nbsp;

你的愛情忠誠度相當不錯，追究原始因素是：

&nbsp;

在有所行動前，你會先默默觀察別人的言行舉止是否值得信賴，

&nbsp;

所以，你不會將愛情託付給一個不值得愛的人。

&nbsp;

你不僅有忠誠度，也懂得掌握一個幸福婚姻，是個體貼又善解人意的人。

&nbsp;

&nbsp;

&nbsp;

B. 他正在煩惱一件很重要的事

&nbsp;

天性善良讓你的想法充滿同情心，基本上你是對愛情堅貞忠實的人，

&nbsp;

但卻難免會因為同情心與多情，而意外被捲進一些男女是非之中，

&nbsp;

當然也有可能使你不得不移情別戀。

&nbsp;

&nbsp;

&nbsp;

C. 他看起來不受女人歡迎

&nbsp;

你的答案中還有一絲防禦之心，但是卻深藏著來自潛意識裏的好奇心。

&nbsp;

你對其他各種類型的異性，仍充滿好奇，

&nbsp;

即使你很愛目前的情人，忠誠度也很高，

&nbsp;

但是當日子久了激情褪去後，剛好有個機會來臨，

&nbsp;

你不會放過出軌機會的。

&nbsp;

&nbsp;

&nbsp;

D. 你並沒有特別注意他

&nbsp;

你不易有任何外遇，對目前的情人相當滿足，

&nbsp;

除非你的情人與你之間的感情轉變，同時又剛好有條件不錯的異性追求，

&nbsp;

在較多的因素混合下才可能導致你外遇。

&nbsp;

不過，也因為你的個性堅貞、不易移情別戀，

&nbsp;

所以最好再確認一下你的他是個可靠、值得依靠的人。
