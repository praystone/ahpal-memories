孤独の月が 闇を刺す 

&nbsp;

深い時の底　眠りについては 

&nbsp;

何度も繰り返している 

&nbsp;

千の記憶辿る呪文　身に纏って 

&nbsp;

誰かを傷つけても 失うものは 

&nbsp;

この手にはないのに 

&nbsp;

誰かを待ち続ける　想いだけが 

&nbsp;

操られた迷路のように 

&nbsp;

永遠に終わらない 

&nbsp;

永彷徨う闇の旅へと 

&nbsp;

果てしない欲望よ 

&nbsp;

夢の続き 誘え... 


愚かな時代の　幕開け 

&nbsp;

瞬きの間　通りすぎてゆく 

&nbsp;

いつでも　搜し続けてる 

&nbsp;

かすかな足音に　耳を澄ましている 

&nbsp;

誰も行くことのない　何も見えない 

&nbsp;

この時代(とき)の果てさえ 

&nbsp;

誰かに出会うためと知っていたら 

&nbsp;

少しは楽しめるのだろう 

&nbsp;

永遠に絡み合う 

&nbsp;

がんじからめの自由を 

&nbsp;

断ち切って　手に入れた 

&nbsp;

幻と気づかずに... 

&nbsp;


孤獨之月 刺入黑暗中 

&nbsp;

深幽的時之盡頭 乃陷入沉眠只所 

&nbsp;

無數次 不停地重複 

&nbsp;

在千萬的記憶中追尋 是那詛咒纏身 

&nbsp;

就算去傷害什麼人 已失去的東西 

&nbsp;

也不會再次出現在手中 

&nbsp;

一直在等著那個人 只有這思念 

&nbsp;

就像那被操縱著的迷宮 

&nbsp;

向著永遠沒有終結的 

&nbsp;

彷徨的黑暗之旅 

&nbsp;

永無止境的欲望 

&nbsp;

向著夢的延續而引誘著 

&nbsp;

打開這愚蠢時代的序幕 

&nbsp;

眨眼之間 已經成為了過去 

&nbsp;

一直都在 為了繼續尋找那 

&nbsp;

微弱的腳步聲 而傾聽著 

&nbsp;

誰也沒有抵達過 什麼也看不到 

&nbsp;

即使是這時代的盡頭 

&nbsp;

要是能知道是為了和誰相遇 

&nbsp;

至少能夠稍微輕鬆些吧 

&nbsp;

永遠的纏繞著 

&nbsp;

緊緊綁縛著自由 

&nbsp;

斬斷它 得到它 

&nbsp;

卻沒有注意到那僅是幻像… 

&nbsp;
