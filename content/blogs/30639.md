&nbsp;

人生

&nbsp;

&nbsp;


&nbsp;人生有些失去是註定的，

&nbsp;

有些緣分是永遠不會有結果的，

&nbsp;

愛一個人不一定要擁有，但擁有了一個人就一定要珍惜，

&nbsp;

不要等到傷害的時候才去乞求原諒，

&nbsp;

不要等到失去的時候再去挽回。


多情人隱藏情感,遠遠要比無情人隱藏,冷酷困難的多，

&nbsp;

“隨遇而安”本身就已包含著忍耐、堅毅的精神在內,

&nbsp;

這實在是件很奇妙的事。


&nbsp;

一個人傷心的時候往往就會流淚，

&nbsp;

無論是什麼人，在夢中永遠比在清醒時更勇敢，更坦率，

&nbsp;

逃避不一定躲得過，面對不一定最難受，

&nbsp;

孤單不一定能長久，失去不一定不再有，

&nbsp;

轉身不一定最軟弱，懂得放棄的人會感到輕鬆，

&nbsp;

懂得遺忘的人會得到自由。


&nbsp;

生活中什麼也不用說，一聲“懂你”全代表了。

&nbsp;

珍惜這份“懂你”，珍惜懂你的人，

&nbsp;

即使有一天他（或她）不再懂你了，

&nbsp;

但曾有過的“懂你”依然是生命中的一份溫暖。

&nbsp;

自己把自己說服了，是一種立誌的勝利，

&nbsp;

自己被自己感動了，是一種心靈的升華，

&nbsp;

自己把自己理順了，是一種人生的成熟。


&nbsp;

有人把自己看做是生活的主角，

&nbsp;

有人把自己看做是生活的觀眾，

&nbsp;

而不屈服命運的人，卻把自己看做是生活的編導！


人生就是一天天日子連綴的彩衣：
&nbsp;&nbsp; 

平凡的、瑣碎的、苦惱的、歡樂的、

&nbsp;

失落的、希望的、悲傷的、拘謹的....
&nbsp;&nbsp; 
缺了哪一天，都不是完整的人生；
&nbsp;&nbsp; 
&nbsp;缺了哪一種滋味，都不是完整的人生。
&nbsp;&nbsp; 


&nbsp;

人生，是極平凡的，平淡的日子一定多於色彩紛繁的日子。
&nbsp;&nbsp; 
人生就像一棵樹，開出繽紛花朵的時候，是短暫的；
&nbsp;&nbsp; 
人生，就像一壺水。

&nbsp;

再清新芬芳的龍井茶或雀巢咖啡倒進這壺水裏，

&nbsp;

味道也被沖淡，難以再加如鹽一樣的結晶。
&nbsp;&nbsp; 

&nbsp;

平凡，不是平庸。平庸，

&nbsp;

是將本來可以燙平的衣服揉皺了；

&nbsp;

是將本來可以濾清的水攪渾了；

&nbsp;

是將本來可以唱得動聽的歌曲唱得走了調，五音不全......
&nbsp;&nbsp; 
平凡，就像泥土，即使災年，照樣長出莊稼；

&nbsp;

就像天空，即使有雷雨，照樣橫跨彩虹；就像溪水，

&nbsp;

即使很淺，照樣映出太陽和月亮.....

&nbsp;

平凡的，就是美好!


&nbsp;

人生場景的重復，並不是人生真正的重復。

&nbsp;

一切可以從頭再來，唯有人生是一次性的，

&nbsp;

可以回首瞻望，卻無法回走過去的路，

&nbsp;

就像流過去的河水，再流過來，也不再是曾經流過來的河水.
&nbsp;&nbsp; 

&nbsp;

我們看得太多的是人世紛憂和人生喧囂，

&nbsp;

看得太清的是生活蠅頭微利和日常瑣碎平庸，

&nbsp;

即便累得眼睛失去了敏感的神經，

&nbsp;

還是有很多很多看不見或看不清的東西。
&nbsp;&nbsp; 

&nbsp;

人生，磨難會多於幸福。

&nbsp;

人生就是由一個個磨難連接成，

&nbsp;

當最後連接成一個大的連環時，才會變成一個美麗的花環。
&nbsp;&nbsp; 


對於人生，享受不等於感受。

&nbsp;

感受可以包含享受。享受卻不包括感受，

&nbsp;

享受是現實主義的，但感受是浪漫主義的。


&nbsp;
