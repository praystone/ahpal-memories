你是耍賴情人嗎 ?

&nbsp;



&nbsp;

Q.對於自己的五官，你最滿意的是哪一處？


&nbsp;

&nbsp;

A 耳朵 


&nbsp;

B 眼睛


&nbsp;

C 嘴唇


&nbsp;

D 鼻子
&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;


解析


選擇A.耳朵的人

&nbsp;

你是個好奇心很重的人，大多時間你都是理性型的情人，

&nbsp;

不太會耍賴，有事彼此可以好好溝通。

&nbsp;

偶爾對情人耍賴，通常是因為你心情低落，

&nbsp;

希望以任性耍賴的方式引起情人的注意，

&nbsp;

目的是得到情人的疼愛，感受到情人對你的包容。

&nbsp;

&nbsp;

選擇B.眼睛的人

&nbsp;

聰明的你會耍賴，不過你很明白以柔克剛的藝術，

&nbsp;

所以當你耍賴時，會有技巧，

&nbsp;

大多是以言語或肢體等撒嬌方式耍賴，

&nbsp;

而不是以哭鬧或是吵架等令人厭惡的招術，

&nbsp;

因此情人會覺得又好氣又好笑，抵擋不住你的撒嬌功夫，

&nbsp;

最後會照著你的意願走，達到你的目的。

&nbsp;

&nbsp;

&nbsp;選擇C.嘴唇的人

&nbsp;

平 常你並不是耍賴情人，但當你犯錯時，

&nbsp;

你會硬拗，連瞎掰的理由也敢講出口，就是不想認錯，

&nbsp;

會變得很「番（台語：難纏）」，情人若是和你理論，

&nbsp;

你會以吵鬧或撒 嬌方式企圖混過去。

&nbsp;

情況若換成是情人犯錯，你則緊迫盯人，

&nbsp;

一定要對方向你道歉，衡量標準完全不一樣，

&nbsp;

是「嚴以律人，寬以待己」的代表人物。

&nbsp;

&nbsp;

選擇D.鼻子的人

&nbsp;

你是個很任性的人，非常自我中心，

&nbsp;

你向大家耍賴，逼別人屈服於你，讓你得到滿足感，

&nbsp;

身為你的情人，理所當然成為被你「凌虐」的頭號目標，

&nbsp;

事情一不如你意，你便使出耍賴招術，

&nbsp;

以冷戰不說話或是哭鬧等方法，折磨情人，

&nbsp;

或是給情人難看，直到情人勉為其難配合為止。
