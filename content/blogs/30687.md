虛擬的網絡里的感情〖轉貼〗<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


人都是有感情的，人的感情是豐富多彩、繽紛絢爛的。情感是一種說不清的東西，在情感的世界里沒有什麼是對什么是錯。


&nbsp;


在網絡里漫游久了的人，都能夠深深的體會到“網絡雖虛擬，但人的感情卻真實”，這句話的含義。



網絡中的相識是一種緣份，網絡中的愛情便成了穿越時空的愛戀。




&nbsp;


&nbsp;


&nbsp;


&nbsp;


不管空間的距離有多遙遠，屏幕上對面的距離永遠是那麼親近。


&nbsp;


也許有人說：“上網聊天的人，都不可能只有一個網友，當你和他聊得很開心的同時，他會和很多人也會聊得很好。”


&nbsp;


我覺得有一句俗語說的很好“親情有薄厚、友情有遠近”。


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


對待每一個人的感情不會完全一致的，遇到讓自已心儀的人時便會把這份情感淋灕地表達出來。在乎他的感受，關心他的生活。


&nbsp;


腦海里經常會出現他的模樣，回想說過的每句話，不經意間嘴角就會出現甜甜的笑容。心里面裝載著他的故事，慢慢的享受著他所帶來的幸福。


&nbsp;


網絡人生里的喜悅可以使人變的神采奕奕，網絡里的心酸同樣可以讓人心痛難過，這種情感是網絡之外的人無法體會到的。
