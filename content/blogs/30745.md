生氣會讓身體留下痕跡<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


愛生氣的人很難健康，更難長壽；但在日常生活中，人們免不了會有五種「最好別生」的氣：閒氣、怨氣、悶氣、賭氣和怒氣。中國「中醫科學院」院士程莘農教授說，要養生，關鍵就在「會生氣也要會散氣」，如果氣散不掉，很多疾病都會由此而發。


&nbsp;


很多人在一些益智遊戲或友誼比賽等活動中喜歡爭強好勝，常常因為一點小意見、小爭執、小動作或多說一句話，就爭得面紅耳赤，甚至氣得血壓升高。這就是人們常說的「生閒氣」。所謂「閒氣」，就是「為無關緊要的事情生氣」，其實，一個人健康與否，很大程度上跟心理狀態有關，心理狀態不好，而且沒氣找氣的人更愛生病。


&nbsp;


「怨氣」來源於一種怨恨的情緒。近年來常在媒體上看到一些報導，有些人會突然產生過激的行為，像是砸車、放火燒車等，這種行為通常就是一種情緒的發洩，也就是一股怨氣。


&nbsp;


「悶氣」則大多發生在夫妻之間，兩人一生氣就沒完沒了，相敬如「冰」，誰也不和對方說話，繃著臉，陰沉沉地總不見「晴天」。這種悶氣也是一種「冷暴力」，無形中會對人體進行傷害。衛生專家表示，夫妻間生悶氣最傷害身體。


&nbsp;


人們經常由於不滿意或受指責而「賭氣」。每個人大概都會有賭氣的時候，只是程度不同而已；曾經有新聞報導，有人由於不滿銀行排隊時間過長，就到提款機分1000次，每次領1元，領出1000元；殊不知，這種賭氣的結果，往往最受傷的是自己。


&nbsp;


對於性格急躁的人來說，很容易爆發「怒氣」。醫學專家指出，怒傷肝，憤怒使人肝氣不舒、胸悶、胸肋脹痛。這種氣如果不能加以控制，危害最大。


&nbsp;


人之所以會「生病」，最原始的一種根源就是「生氣」，這在中國古籍「黃帝內經」中就有說明。中醫學者指出，生一次氣毀一次健康，生氣導致的疾病與由風寒暑濕等外因導致的疾病不同，會直接損傷五臟功能，發病更加嚴重。長期生氣的人，會在身體上留下不同的痕跡。從外表看，脾氣火暴，經常處於發怒狀態的人，多數會禿頂。嚴重的還會使頭頂變尖；程度輕點的，則會在額頭兩側形成雙尖的M形微禿。美國「洛杉磯時報」也曾報導，愛生氣的人容易長色斑，而且腦細胞衰老明顯加快。從中醫角度分析，發脾氣時，氣會往上衝，造成頭頂發熱，導致脫髮；嚴重的暴怒，有時會造成肝內出血，如果血吐不出來，就會留在肝內，一段時間內形成血瘤。


&nbsp;


另外，生氣導致的肝熱也會影響到肺，肺熱一個嚴重的後果就是失眠，臨床醫學上曾經有人因為生氣而造成五天五夜無法成眠；而血氣較差的人，氣往下沉，形成腹部脹痛，會讓人誤以為是腸胃問題。如果生了氣散不出來，比如悶氣，往往會在胸腹形成中醫所謂「橫逆」的氣滯，很可能導致婦女乳腺小葉增生和乳癌，也可能造成十二指腸或胃潰瘍，嚴重的還會引發胃出血。


&nbsp;


愛生氣的人還容易罹癌，曾有一群癌症患者經過思考、討論後，親身見證「氣、急、累」正是他們患病的真正原因。


&nbsp;


人生氣時，氣流在體內是處於一種紊亂狀態，所以醫生建議現代人，要想養生，必須讓氣流保持和諧順暢。親愛的朋友，您正在生氣嗎？不管是閒氣、怨氣、悶氣、賭氣或怒氣，趕快停歇，去散散心吧！別讓生氣影響了您的身體健康，甚或導致「減壽」喔。
