&nbsp;

&nbsp;

 人世間最美的情

&nbsp;



&nbsp;

&nbsp;


不知什麼時候讀到過這樣一句話

&nbsp;

&nbsp; 世界上最遠的距離，不是我在天邊或海角，

&nbsp;

而是我就在你面前，你卻不知道我愛你

&nbsp;

&nbsp;

很多人常常會忽略身邊的人，忽略關心著你的人，
&nbsp;
而到最後，當你疲倦時才會發現，

&nbsp;

其實最愛你的人，就在你身邊，
&nbsp;
而你一直沒有發現，也沒有想著怎樣去好好珍惜。

&nbsp;

&nbsp;

大千世界裡，

&nbsp;

人們用各種各樣的方式來表達自己的愛，

&nbsp;

富有的人，會用金錢去滿足自己所愛的人的歡心，

&nbsp;

那麼貧窮的人呢?他們也許就能從很簡單的一個微笑，

&nbsp;

從一個關愛的眼神，從一件小小的事情，
&nbsp;
都會感悟到一些人生獨有的溫馨……

&nbsp;

&nbsp;

朋友們，無論你是貧是富，
&nbsp;
能得到一份真愛，你才算得上是最幸福的人，

&nbsp;

請拿出你的真心去愛，珍惜生命中你愛的和愛你的人。

&nbsp;

&nbsp;

不要奢望當時就能得到回報，
&nbsp;
要慢慢地等待自己真摯的愛能在對方心中生根發芽。

&nbsp;

開出世間最最美麗的花……
