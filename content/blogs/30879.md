&nbsp;


真正的愛情，不是一見鐘情，而是日久生情；

&nbsp;

真正的緣份，不是上天的安排，而是你的主動；

&nbsp;

真正的自卑，不是你不優秀，而是你把她想得太優秀；

&nbsp;

真正的關心，不是你認為好的就要求她改變，

&nbsp;

而是她的改變你是第一個發現的；

&nbsp;

真正的矛盾，不是她不理解你，而是你不會寬容她。
　　
　　我們一直覺得妥協一些、將就一些、容忍一些可以得到幸福。

&nbsp;

但當你的底線放得越低，你得到的就是更低的那個結果！不是嗎?
　　
不要因為寂寞愛錯人，更不要因為愛錯人而寂寞一生，

&nbsp;

嘗試信任才能得到幸福。

&nbsp;

緣分是本書，翻的不經意會錯過，讀得太認真會淚流。

&nbsp;

女人會記得讓她笑的男人，男人會記得讓他哭的女人，

&nbsp;

可是女人總是留在讓她哭的男人身邊，男人卻留在讓他笑的女人身邊。
　　
　　多少人在說，我會等你，等你回心轉意的那一天；我會等你，

&nbsp;

等你愿意和我在一起的那一天；我會等你，

&nbsp;

等你離開那個人來到我身邊的那一天；

&nbsp;

我會等你，

&nbsp;

等你……然而人們可曾知道，世上的愛情，沒有几份真的經得起等待！
　　
　　這個世界上最殘忍的一句話，不是對不起，也不是我恨你，

&nbsp;

而是，我們再也回不去。

&nbsp;

就是這樣再簡單不過的一句話，生生的將兩個原本親密的人隔為疏離。

&nbsp;

&nbsp;沒有經曆過的人，永遠都不會明白，那是怎樣的一種切膚之痛。
　　
　　最寶貴的東西不是你擁有的物質，而是陪伴在你身邊的人。

&nbsp;

不能強迫別人來愛自己，只能努力讓自己成為值得愛的人，

&nbsp;

其余的事情則靠緣分。
　　
　　愛總是會使我們有太多期許：希望長久，希望不會分別，希望占有和實現。

&nbsp;

而最終只是覺得有些許厭倦，不知道該往哪里去。

&nbsp;

愛情就是這樣，有些人會慢慢遺落在歲月的風塵里，

&nbsp;

哭過，笑過，吵過，鬧過，再戀戀不舍也都只是曾經。
　　
　　世界上最動人的情話，不是“我愛你”，而是在我需要的時候，

&nbsp;

你說“ I’ll be there ” 。
　　
　　每一個不敢再愛的女人，一定很深的愛過。

&nbsp;

看起來好象百毒不侵，其實早已百毒侵身。
　　
　　女人好比梨，外甜內酸。吃梨的人不知道梨的心是酸的，

&nbsp;

因為吃到最后就把心扔了，所以男人從來不懂女人的心。

&nbsp;

男人就好比洋蔥，想要看到男人的心就需要一層一層去剝！

&nbsp;

但在剝的過程中你會不斷流淚，剝到最后你才知道洋蔥是沒心的。
　　
　　愛情里最忌諱的是：兩人都幻想著彼此的未來，卻也總惦記著對方的過去。
　　
　　明明說著看開了，放下了，每次卻總是不自覺的想起那個給與溫暖的人。

&nbsp;

每每又總是在微笑沉醉時看到了現實，

&nbsp;

想到了傷痛，然后，冷的感覺再也暖和不起來了 。 

&nbsp;

如此反復，心，終于累了，現實就是這樣。

&nbsp;

我曾經醉過，卻又最終醒來，我正在行走，卻找不到方向。
　　
　　我想給你幸福，卻走不進你的世界 。

&nbsp;

我想用我的全世界來換取一張通往你的世界的入場券，

&nbsp;

不過，那只不過是我的一廂情愿而已。

&nbsp;

我的世界，你不在乎；你的世界，我被驅逐。

&nbsp;

我真的喜歡你，閉上眼，以為我能忘記，但流下的眼淚，卻沒有騙到自己。
　　
　　道歉並不總意味著你是錯的，而對方是正确的。

&nbsp;

有時它只是意味著相對自我而言，你更珍惜你們之間的關系。
　　
　　有些傷痕，划在手上，愈合后就成了往事；

&nbsp;

有些傷痕，划在心上，那怕划得很輕，也會留駐于心；

&nbsp;

有些人，近在咫尺，卻是一生無緣。

&nbsp;

生命中，似乎總有一種承受不住的痛。

&nbsp;

有些遺憾，注定了要背負一輩子；

&nbsp;

生命中，總有一些精美的情感瓷器在我們身邊跌碎，

&nbsp;

然而那裂痕卻留在了歲暮回首時的剎那。
　　
　　1一個人炫耀什麼，說明內心缺少什麼。

&nbsp;

一個人越在意的地方，就是最令他自卑的地方。
　　
　　2有些人越越想得到的，就越是裝作無所謂；越怕失去的，就越是裝作不在乎。
　　
　　3人越是得意的事情，越愛隱藏；越是痛苦的事情，越愛小題大作。

&nbsp;

4憎恨某人，優點被看成偽裝；喜歡某人，缺點也變得美好。
　　
　　有時候，同樣的一件事情，我們可以去安慰別人，卻說服不了自己。
　　
　　熱戀時愛情，可以什麼都不在乎。

&nbsp;

只要你要，只要我有，因為我愛你，所以我愿意。

&nbsp;

一旦感情平復了下來，心中就會出現接連不斷的計較，

&nbsp;

為什麼我付出的比你多；為什麼我什麼都可以給你，你卻要有所隱瞞，

&nbsp;

然后冷戰，爭吵，分手，和好，冷戰 ... 

&nbsp;

走得過的就是執子之手，走不過的就只能緬怀當初。
　　
　　在愛情沒開始以前，你永遠想象不出會那樣地愛一個人；

&nbsp;

在愛情沒結束以前，你永遠想象不出那樣的愛也會消失；

&nbsp;

在愛情被忘卻以前，你永遠想象不出那樣刻骨銘心的愛也會只留淡淡痕跡；

&nbsp;

在愛情重新開始以前，你永遠想象不出還能再一次找到那樣的愛情。
　　
　　有些人一直沒机會見，等有机會見了，卻又猶豫了。

&nbsp;

有些事一直沒机會做，等有机會了，卻不想再做了。

&nbsp;

有些話埋藏在心中好久，沒机會說，

&nbsp;

等有机會說的時候，卻說不出口了。

&nbsp;

有些愛一直沒机會愛，等有机會了，已經不愛了。

&nbsp;

有些話有很多机會說的，卻想著以后再說，要說的時候，卻已經沒机會了。
　　
　　也許你沒有貌，但你有才；也許你沒有才，但你溫柔；

&nbsp;

也許你沒有溫柔，

&nbsp;

但你....... 也許你什麼都沒有，但是也許，他/她正愛著你的平凡。
　　
　　時間會告訴你一切真相。

&nbsp;

有些事情，要等到你漸漸清醒了，才明白它是個錯誤；

&nbsp;

有些東西，要等到你真正放下了，才知道它的沉重。
　　
　　能牽手的時候，請別肩並肩；

&nbsp;

能擁抱的時候，請別手牽手。

&nbsp;

能相愛的時候，請別說分開；

&nbsp;

擁有了愛情，請別去碰曖昧。
　　
　　男人對女人的傷害，不一定是他愛上了別人，

&nbsp;

而是他在她有所期待的時候讓她失望，

&nbsp;

在她脆弱的時候沒有給她應有的安慰。
　　
　　世界沒有悲劇和喜劇之分，如果你能從悲劇中走出來，那就是喜劇；

&nbsp;

如果你沉緬于喜劇之中，那它就是悲劇。

&nbsp;

如果你只是等待，發生的事情只會是你變老了。

&nbsp;

人生的意義不在于拿一手好牌，而在于打好一手坏牌。
　　
　　如果彼此出現早一點，也許就不會和另一個人十指緊扣。

&nbsp;

又或者相遇的再晚一點，

&nbsp;

晚到兩個人在各自的愛情經曆中慢慢地學會了包容與體諒，善待和妥協，

&nbsp;

也許走到一起的時候，就不會那麼輕易的放棄，

&nbsp;

任性地轉身，放走了愛情。

&nbsp;

但時間不會回頭，愛情豈能“如果”？

&nbsp;
