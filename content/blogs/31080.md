&nbsp;&nbsp;&nbsp;&nbsp; 昨天和朋友去看你 看到你眼睛能稍微睜開了 看到你有點意識

&nbsp;

&nbsp;&nbsp;&nbsp; 叫你時 你有知道我們來看你 但眼角卻在流淚 不曉得是你

&nbsp;

&nbsp;&nbsp;&nbsp; 不知道自己怎麼會變成這樣 還是不想讓我們這些好朋友看到你

&nbsp;

&nbsp;&nbsp;&nbsp; 現在這模樣 我們看到你這樣 也只能努力的安慰你 叫你快點好起來

&nbsp;

&nbsp;&nbsp;&nbsp; 又加上現在請看護一天兩千多 負擔很大 伯父也說 要把你帶回家照顧

&nbsp;

&nbsp;&nbsp;&nbsp; 心裡真的很心酸啦 好好的一個人 瞬間變成這樣 讓人真的很不捨

&nbsp;

&nbsp;&nbsp;&nbsp; 多希望這不是真的 讓一切歸零好嗎 剛下班同事兼麻吉打電話來

&nbsp;

&nbsp;&nbsp;&nbsp; 說公司那邊已經在印募款單了&nbsp; 在加上一些朋友欠你的 會幫你追

&nbsp;

&nbsp;&nbsp;&nbsp; 回來 讓你的家人能有一筆照顧你的花費 我和麻吉已經說好了

&nbsp;

&nbsp;&nbsp;&nbsp; 會竭盡所能的幫你 一起陪伴你復健 走過這人生最大的低潮 也希望上天

&nbsp;
