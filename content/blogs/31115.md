人可以追求，可以選擇自己喜歡的生活方式，卻無法秉棄生活的本質。


&nbsp;



生活原本是一杯水，貧乏與富足、權貴與卑微等等，都不過是人根據自己的心態和能力為生活添加的調味。


&nbsp;



有人喜歡豐富刺激的生活，把它拌成多味醬。


&nbsp;



有人喜歡苦中作樂的生活，把它攪成咖啡。


&nbsp;



有人喜歡在生活中多加點蜜，把它和成糖水。


&nbsp;



有人喜歡把生活泡成茶，細品其中的甘香。


&nbsp;



還有人什麽也不加，只喜歡原汁原味的白開水。


&nbsp;



更有人不知不覺地把生活熬成苦藥，甚至是毒藥，親手把自己的生活埋葬。


&nbsp;



什麽樣的生活才是幸福的生活呢？其實，幸福只是一種心態。


&nbsp;



你感到幸福，生活便是幸福無比，你感到痛苦，生活便痛苦不堪。


&nbsp;



同是一片天，有人擡頭看見的是陰翳層層，


&nbsp;


有人卻可以透過雲層感受那無際的蔚藍。


&nbsp;



有人活著，不知道自己想要的是什麽。


&nbsp;



於是盲目地羨慕，盲目地追求，往往卻總是與幸福擦身而過。


&nbsp;



其實，每個人不論在任何處境下，只要端正自己的心態，學會把握、學會滿足、學會感恩，生活就會幸福。


&nbsp;



同時，幸福也不是可以用你能得到多少財物擁有多少名譽來衡量，社會的和諧、家庭的和睦、身體的健康才會讓人感到真正幸福。


&nbsp;



生活只是那一杯水，


&nbsp;


要靠自己慢慢去品味，


&nbsp;


細細去咀嚼，


&nbsp;


用心去欣賞，


&nbsp;


你才能發現，


&nbsp;


原來，最幸福的生活，


&nbsp;


就是在那如水的平淡中活出精彩
