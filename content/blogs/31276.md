夜是那麼不思議

&nbsp;

平穩了我那極為瘋狂的心

&nbsp;

黑夜真是無邊無際 

&nbsp;

月是那麼的寧靜柔和

&nbsp;

世間萬物都靜靜的沉睡

&nbsp;

月之光照耀在我身上

&nbsp;

已經離去得好遠好遠的

&nbsp;

時間與思念 

&nbsp;

卻在我的夢中出現

&nbsp;

那真實卻帶著虛幻的夢境

&nbsp;

似醒非醒&nbsp; 夢中夢

&nbsp;

鳴聲訴說著思念那女孩

&nbsp;

遠遠傳來的歌曲

&nbsp;

究竟是誰的歌聲

&nbsp;

微風輕撫著銀白秀髮的那身影

&nbsp;

竟是我等待多年的女孩

&nbsp;

推開那扇封閉已久的門

&nbsp;

那裡就是永遠嗎

&nbsp;

夢境隱藏了現實

&nbsp;

讓我看到夢想與妄想

&nbsp;

甦醒破滅了幻境

&nbsp;

就像楓樹上的枯葉逐漸飄落

&nbsp;

一一一一一一一一一一一一一一一一 一一一一一一一一一一一

&nbsp;

夜はそのように思いはからないのです

&nbsp;

私のそれではきわめて気違いのような心に安定になりました

&nbsp;

やみ夜は本当にはてしがありません 

&nbsp;

月はそんなにのが静かでやさしいです

&nbsp;

世の中の万物はすべて静かに熟睡します

&nbsp;

月の光は私の身で照らします

&nbsp;

すでに立ち去るのがとても遠くてとても遠かったですの

&nbsp;

時間と恋しい思い 

&nbsp;

私の夢の中で現れます

&nbsp;

それでは如実に幻の夢の世界を持っています

&nbsp;

目が覚めるようです目が覚めません 夢の中で夢

&nbsp;

鳴いて回が訴えてあの女の子を懐かしみます

&nbsp;

はるかに伝来する歌曲

&nbsp;

一体誰の歌声です

&nbsp;

そよ風は軽くなって銀白色の容姿端麗で有能のあの影をなでています

&nbsp;

つまり私は長年の女の子を待ちます

&nbsp;

あれを押し開けてすでに長い扉を密封します

&nbsp;

そこに永遠にですか

&nbsp;

夢の世界は現実に隠れました

&nbsp;

私に夢想と妄想を見させます

&nbsp;

蘇ります水泡に帰した幻の境地

&nbsp;

カエデの木の上の枯れている葉のようで次第に舞い落ちます

&nbsp;


&nbsp;

&nbsp;一一一一一一一一一一一一一一一一 一一一一一一一一一一一

&nbsp;

夜晚的寧靜 一杯濃郁的曼特寧咖啡 一根DUNHLL 這就是享受


&nbsp;


&nbsp;


狼的心得

&nbsp;

&nbsp;

這首詩其實是這兩天夜晚的心得與結論

&nbsp;

&nbsp;

人生真的如夢似幻&nbsp;&nbsp;&nbsp; 可以活多少年

&nbsp;

&nbsp;

老實說我不介意

&nbsp;

&nbsp;

只要我現在活的快樂就好

&nbsp;

&nbsp;

但是我卻對永恆這個名稱

&nbsp;

&nbsp;

產生了所謂的求知欲

&nbsp;

&nbsp;

在夢中或許是永恆的

&nbsp;

&nbsp;

旦現實中還是得活下去

&nbsp;

&nbsp;

這就是所謂的人生如戲吧

&nbsp;

&nbsp;

各位朋友們好好觀賞吧

&nbsp;

&nbsp;

這也是一個對我自己的挑戰
