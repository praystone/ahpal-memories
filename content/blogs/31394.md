&nbsp;為什麼男生要疼女生.............

&nbsp;&nbsp; &nbsp;因為...當女生很累耶...
&nbsp;&nbsp; 

1.吃要吃相　(細嚼慢嚥)
&nbsp;

&nbsp; 2.坐要坐相　(哪能像男生腳開開坐..穿裙子更麻煩)
&nbsp;

&nbsp; 3.不能說話太大聲　(否則被說像三八..八婆)
&nbsp;

&nbsp; 4.沒事被掀裙子..出門在外上廁所也不方便
&nbsp;&nbsp;

&nbsp;5.沒來由的胸部　(沒事還得駝著背..或被男生彈弄吊橋)


&nbsp;&nbsp;

&nbsp;6.不能趴著睡　(胸部會壓扁)
&nbsp;

&nbsp; 7.不能站太久　(會有蘿蔔腿)
&nbsp;

&nbsp; 8.不能坐太久...不能翹二郎腿　(屁股會變大)
&nbsp;&nbsp;

&nbsp;9.不能熬夜或夜玩　(會長痘痘..膚質變差)
&nbsp;&nbsp;

&nbsp;10.頭髮要美...腰要細...腋下要刮毛　(不是人幹的)


&nbsp;

&nbsp; 11.沒事還得學化妝跟打扮　(否則變成村姑)


&nbsp;

&nbsp;&nbsp; 12.終身的減肥作戰　(餓肚子..節食..折磨自己)


&nbsp;

&nbsp; 13還得買保養品　(怕太早老化被男人嫌)
&nbsp;

&nbsp; 14.還得防曬　(怕夏天一穿細肩帶變成雙層膚色)
&nbsp;

&nbsp; 15.為了漂亮還得穿魔術的Bra　(誰叫男人愛波大的辣妹)
&nbsp;

&nbsp; 16.出門穿尖頭靴逛街　(誰叫我們是女生!痛死了)
&nbsp;&nbsp;

&nbsp;17.花心被罵淫蕩　(男生卻被說很吃得開)
&nbsp;&nbsp;

&nbsp;18.深夜未歸好像吃了虧　(男生像賺到了)
&nbsp;

&nbsp; 19.還得面對生小孩　(生小孩疼痛指數直逼燒傷人體100%肌膚之程度!)
&nbsp;&nbsp; 

20還得苦哈哈討好婆婆...小姑　(女人間的戰爭..很累人)
&nbsp;&nbsp; 

21.年老色衰還得應付老公的外遇　(當黃臉婆已經夠倒霉的)
&nbsp;&nbsp;

&nbsp;所以ㄚ......當女生是很辛苦的唷！
