夏天到了，穿了一天的鞋和襪子上的臭味就變得更加明顯，和人交往時常常令人尷尬。其實，腳臭不僅影響情緒，有些人還因為腳臭背上了包袱，甚至產生了自卑感。&nbsp;
　　那麼，鞋為什麼會臭？
這是由於腳心多汗的緣故。腳心每平方釐米有620個左右汗腺。而身體其它部位同樣面積僅有143～339個，也就是說，手心、腳心比其它部位的汗腺多出數倍。當人們作用中增多、天氣悶熱、精神緊張、吃辛辣熱燙食物的時候，汗液就會大量分泌出來。
汗液裏除含水分、鹽分外，還含有乳酸及尿素。在多汗條件下，腳上的細菌大量繁殖並分解角質蛋白，加上汗液中的尿素、乳酸，這樣就會發出一種臭味。如果穿的又是捂得很嚴實的旅遊鞋、球鞋、皮鞋，空氣不流通，臭味就會越積越濃，一旦松松鞋帶，這種臭味就會撲面而來。

　　除鞋臭腳臭的幾個小竅門：

　　1、鞋子內放入生石灰小包（吃的雪米餅等食品裏面常有的乾燥劑）。

　　2、柚子皮撕成小碎片放入鞋子內。

　　3、將腳放在攝氏五十至六十度的熱水中多燙幾次，每次15分鐘，每日1至2次。

　　4、洗腳時，在水中加入米醋10至15毫升，調勻後，將雙腳放入浸泡15分鐘左右，每日一次，連續泡三至四
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 天，腳臭即可消失。

　　5、洗腳時，在熱水裏加50克白礬，浸泡10分鐘左右，可去除腳臭。

　　6、葛根15克，研成細末，加白酒15克，再加適量水，煎後洗腳，每日一次，連續一周後，可除去腳汗引起 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;的腳臭。

　　7、每晚臨睡前，用棉球或布頭蘸小許酒精，均勻地抹在剛脫下的膠、球鞋內，待第二天早晨乾燥後再穿。 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;如此堅持兩周後，鞋就不會發出臭味了。

　　8、取適量脫水明礬或乾石灰粉，用小布袋裝好，每晚臨睡前放置鞋內。

　　9、把幾粒樟腦丸壓成粉末，撒在洗乾淨的鞋內，在墊上一塊鞋墊，這樣穿時就不易臭腳了。樟腦丸不能直 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;接和腳接觸，裏面的樟腦丸只要隔周換一次就可以了。樟腦丸能起到很好的抑菌作用，能夠殺死因為潮 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;濕而繁殖的大量細菌，這樣就不會有臭味了。

　　10、新買回的膠、球鞋，在其海綿底上均勻地噴足白酒（直至海綿底不能吸收為止），待其晾乾後，穿起來 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;就不會產生臭味了（如是舊膠、球鞋，將其洗淨後亦可同法處理）。

　　11、將乾茶葉（泡過的也可）包放入鞋內可去除異味。

　　12、冬瓜皮：冬瓜皮有消暑、健脾、利濕之功效，可用於治療腎病、肺病、心臟病引起的水腫、腹脹、小便 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;不利等症狀。用冬瓜皮煎湯洗腳既治腳氣，又治腳臭，一舉兩得。

　　13、襪子也很容易有臭味，在洗襪子的水裏倒入少許白醋，泡一會兒，再用清水洗淨，這樣不但可以除去臭 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;味，還能起到殺菌的作用。

　　14、鞋櫃裏的臭味也很好解決。只要在鞋櫃中放入一塊香皂，就能輕松去除鞋櫃中的臭味了，開啟鞋櫃還有 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;好聞的香味呦
