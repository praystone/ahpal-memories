[感人故事]✪ 落淚的泡麵！
_____________________________


&nbsp;


 


他是個單親爸爸，獨自撫養一個七歲的小男孩。

&nbsp;

每當孩子和朋友玩耍受傷回來，

&nbsp;

他對過世妻子留下的缺憾，便感受尤深，

&nbsp;

心底不免傳來陣陣悲涼的低鳴。 

&nbsp;

&nbsp;

這是他留下孩子出差當天發生的事。

&nbsp;

因為要趕火車，沒時間陪孩子吃早餐，他便匆匆離開了家門。

&nbsp;

一路上擔心著孩子有沒有吃飯，會不會哭，心老是放不下。

&nbsp;

即使抵達了出差地點，也不時打電話回家。 

&nbsp;

可孩子總是很懂事地要他不要擔心。

&nbsp;

然而因為心里牽掛不安，便草草處理完事情，踏上歸途。

&nbsp;

回到家時孩子已經熟睡了，他這才松了一口氣。

&nbsp;

旅途上的疲憊，讓他全身無力。

&nbsp;

正準備就寢時，突然大吃一驚：

&nbsp;

棉被下麵，竟然有一碗打翻了的泡麵！ 


&nbsp;

「這孩子！」他在盛怒之下，

&nbsp;

朝熟睡中的兒子的屁股，一陣狠打。 


&nbsp;

「為什麼這麼不乖，惹爸爸生氣？

&nbsp;

你這樣調皮，把棉被弄？要給誰洗？」

&nbsp;

&nbsp;這是妻子過世之后，他第一次體罰孩子。 


&nbsp;

「我沒有......」

&nbsp;

孩子抽抽咽咽地辯解著：

&nbsp;

「我沒有調皮，這......這是給爸爸吃的晚餐。」 

&nbsp;

原來孩子為了配合爸爸回家的時間，

&nbsp;

特地泡了兩碗泡麵，一碗自己吃，另一碗給爸爸。

&nbsp;

可是因為怕爸爸那碗麵涼掉，所以放進了棉被底下保溫。 


&nbsp;

爸爸聽了，不發一語地緊緊抱住孩子。

&nbsp;

看著碗里剩下那一半已經泡漲的泡麵： 

&nbsp;

「啊 ！孩子，這是世上最...最美味的泡麵啊！」 


&nbsp;

孩子即使再年幼， 


&nbsp;

也有他們的尊嚴， 


&nbsp;

如果父母發現錯怪了孩子， 


&nbsp;

要勇敢向他們說： 


&nbsp;

「對不起！」。
