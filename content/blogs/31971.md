向二手農藥說「不」


&nbsp;


周妙妃 



在我果園南邊隔著鳳梨園有個叫阿義的農夫，是個大好人，也是我們的好鄰居。他最近剛把他那荒廢的農地整理了一下，除了本來的芒果，他又種下香蕉、芭樂、和菜豆。我出入都要經過他的果園，他天天都在忙著。菜豆苗剛種下，健康肥壯的，沒有瑕疵可挑，有天卻見他背著農藥桶噴灑，據他說是「預防蟲害」。│曾幾何時，毒藥成了預防針許多農夫都是如此按時噴藥，不管植株是否遭受蟲害。


過沒兩週，遠遠又見他背著農藥桶噴灑，我漫步跨過鳳梨園，想過去看個究竟，接近時迎著南風，接下了不少農藥飛沬。他的菜豆扭曲變形，不知患了什麼病蟲害。他說噴藥也無效，滿臉失望。又過了幾週，他帶了一大袋的收成來分享，說是放棄不管反倒長起來了。我沒勇氣問他收成是否拿到菜市場賣了。


我們收下了他的菜豆但不敢吃，拿到郊外野地掩埋了。那次迎風接下的農藥讓我不適數日，為了因應未來可能的農藥噴灑，我決定在果園南邊種排樹籬，希望能擋住二手農藥的波及。當然，我們將藉機給阿義洗腦，希望他能放棄農藥的施放。&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


澳洲的全國毒物協會（NTN, National Toxins Network Inc.）是個非營利的社團組織，著眼於減少汙染，保護環境等議題。最近針對遭受農藥噴灑波及受害的問題發行了一份小冊，內容告訴大家受到農藥噴灑的波及威脅時該怎麼辦；如何定義遭到波及；它如何發生；那些農藥對健康及環境有何危害；如何因應面對；等等。借花獻佛，希望大家也能正視二手農藥的危害情形。


「……澳洲遭受農藥噴灑波及的問題因農藥逐日增量施用及接近住宅區和水源地而日顯嚴重，政府並未制法增加對人民的保護。……人民、野生生物和環境受波及都會有不良的後果，農夫、他們的牲畜和作物更是首當其衝，有機農夫更可能因此失去認証資格。……目前各州對此問題都明顯地立法不足，受害者往往要面對模糊不一致的訴求過程，往往發現他們沒有保障、公理、正義或補償可言。」

農藥噴灑時該怎麼辦？……


1. 馬上離開現場，告知鄰居，立即就醫。關上門窗，關掉空調。


2. 如果皮膚被農藥（霧狀或粉屑）波及，立即全身沖洗冷水。（熱水將使毛細孔張開，吸收更多農藥）


3. 如果衣物受波及，脫掉後放密封袋內，必要時拿去檢驗。洗滌時應與其它衣物分開清洗。


4. 許多醫生並不清楚農藥中毒情形，可能認為你是感冒症狀。詳述過程，要求盡快做血液和尿液檢查。


5. 通知相關單位。


6. 詳細記錄事件過程。


7. 向相關單位要求測定空氣污染及殘餘。測定空氣可知道吸入量，有些農藥是氣體沒有殘餘物，有些僅殘留數日，所以要儘快測定。


8. 詳細記錄你接洽過的人、時間、日期、談話內容、照片、錄影等。


什麼是農藥﹖…… 


農業上用來殺死動植物的化學藥品，包括殺昆蟲劑、除草劑、殺黴菌劑、殺老鼠劑等等，用來：


1. 消滅、麻痺、驅離及抑止害蟲吃食植物或其它物品。


2. 消滅植物或改變其生理代謝功能。


3. 改變另一農業化學品的作用。


4. 吸引害蟲再予消滅之藥物。


在澳洲，農藥和畜牧醫藥署（APVMA, Australian pesticides and Veterinary Medicines Authority）負責州的農藥法規。負責農藥產品的評估和註冊登記，也負責標示農藥的安全使用辦法。農藥產品售出後，其使用的管制成為各州政府的職責。農藥產品的使用者除了必須遵循農藥的安全使用辦法，也必須遵循各州或當地的規定。譬如，須經過訓練課程，學會記錄，施用前須告知敏感地區如學校等等。工業團體也有使用農藥產品和設備的準則，通常由其自行監控。


&nbsp;


什麼是「農藥噴灑波及（pesticide spray drift）」的情況﹖……


目前澳洲各州還沒有一致的定義。只有南澳定義為「化學藥品的侵犯」，就是農牧業用的化學藥品被使用或拋棄，結果造成：


1. 噴灑區之外之土地、動物或植物己經或可能被污染。


2. 噴灑區內及噴灑區之外之人體健康和安全己經或可能受到傷害。


3. 噴灑區以內及噴灑區之外之環境己經或可能受到損害。


舉例如下：


1. 農藥噴灑四散開來或被污染的溢流出來的水造成農作物和牧草污染或損害。


2. 農藥噴灑波及了牧養的家畜。


3. 農藥噴灑四散後，被污染的溢流出來的水、或不當丟棄未用、或殘餘化學品造成的環境汙染。


4. 農藥噴灑後危及人體的健康，造成反胃、頭痛、呼吸道、皮膚、眼睛的刺痛。


澳洲農藥和畜牧醫藥署也定義了「農藥噴灑波及」如下：


1. 農藥噴灑波及是噴灑滴狀物「及其乾性的殘餘物」由噴嘴經空氣四散的物理性運動，在噴灑時或之後短期內「１個小時內」波及到了非噴灑區。


2. 它不包括這些農業化學藥品在噴灑後接下來的四散波及，如揮發、侵蝕地底，地表，以及地底水流的輸送，或風沙帶動等等情況。


但澳洲農藥和畜牧醫藥署的定義顯然不太週全，因為它把噴灑後的四散情況排除，忽視四散波及會持續幾個小時甚至幾天。農藥「溶於液體或油中」噴灑後蒸發或揮發成氣體更是件嚴重的問題，因為它沒有液狀或粉狀物的可見物，所以需要特別的偵測設備。噴灑後沾上農藥的土粒也可能隨風飄散，掉落到花園、室內、車輛等較廣泛的範圍。噴灑區下雨也會造成農藥四散。


澳洲農藥和畜牧醫藥署確認農藥四散危害是嚴重的問題，也宣佈將對二千八百種農藥做進一步危害評估（包括各種噴灑方式；不同環境，農地、森林、遊樂區│等等）。表示目前許多使用中的農藥都沒有仔細評估過四散危害的問題，也沒有管制的辦法。


農藥如何四散﹖


不管是空中或在地面噴灑，都可能波及四周，市區或郊外、工作場所、家中、學校、車內。四散情形可能持續幾個小時，甚至數日。依照標示噴灑並不保証沒有四散危害情形。有許多因素會影響該農藥是否四散及其波及的程度：例如風向與風速、農藥組成、噴灑器材及其尺寸、溫度和濕度、作物種類及高度、地形、噴灑的人等等。


&nbsp;


飄散的農藥有那些？


1. 有機磷酸鹽Organophosphates一類：抑制神經傳導，造成痙攣、抽搐、麻痺。對人和昆蟲的作用一樣，容易由皮膚吸收，為高毒性農藥。


2. 氨基甲酸鹽Carbamates一類：一樣影響神經糸統。產品有殺昆蟲劑、除草劑、殺黴菌劑。


3. 有機氯鹽Organochlorines一類：有許多產品因危害人體健康和環境而被禁用，如DDT和可氯丹（chlordane）。有許多是荷爾蒙干擾劑，例如安殺蕃（endosulfan），己有超過 60 個國家禁用。


4. Pyrethroids一類：是天然殺蟲劑除蟲菊（pyrethrin）的人工合成版。有些對神經糸統有毒性，有些可能是荷爾蒙干擾劑。


5. 除草劑（Herbicides）一類：有些僅對某類植物有毒性，有些會殺死所有植物。2,4-D、草脫淨（atrazine）、汰克草（dicamba）、巴拉刈（paraquat）、草甘瞵（glyphosate）等。

二手農藥會危害我們的健康│


我們對農藥的危害了解並不透徹（50年以上）。大部分農藥從未在人體實驗其安全性。澳洲農藥和畜牧醫藥署並不要求重大的毒性後果的研究報告，如對發育期神經系統的毒性、或內分泌系統的干擾等。多重農藥使用的危害也未評估。農藥中其它成分如溶解液等，可能有害，但也未評估或標示。


農藥可經由吸入，皮膚接觸，吃食等方式進入人體，造成短期急性及長期慢性的健康問題。急性中毒可在接觸幾分鐘至幾天內發生。應向醫生說明以獲得適當治療及報知相關單位。症狀可能是：眼、鼻、喉嚨、皮膚刺痛、呼吸困難、頭痛、胃痛、腹瀉、噁心、嘔吐、昏眩、顫抖、肌肉無力、視力模糊。長期慢性的健康問題可能是單次大量或為長期累積的結果。症狀可能是：腦癌和其它癌症、畸形、巴金森症、痴呆、白血症、肥胖、流產、不孕、氣喘、自體免疫疾病（類風濕性關節炎、紅斑性狼瘡、糖尿病、硬皮病）、過敏（花粉熱、食物過敏、濕疹）、自閉症、過動。


胎兒及嬰幼兒最脆弱，因為他們正快速成長和發育，比較無法代謝許多有毒化學物品。加上嬰幼兒較常在草地和地板遊玩，把手和物品放入口中，而接觸沾了農藥的灰塵和泥土。胎兒在母親子宮內，幼兒餵食母乳也可能接觸農藥。


&nbsp;


二手農藥會危害我們的環境│


它會危害環境、農作物和牲畜。農藥噴灑及噴灑後，會經由揮發、溢流、地表和地底水流、風沙等飄散。澳洲各州在河川，住家儲水塔測到農藥的例子很多。例如草脫淨（atrazine）和草滅淨（simazine），許多國家因其污染地下水正逐步禁用中。澳洲水源缺乏，保護地下水和收集的雨水不受污染極其重要，當然將跟進禁用。野生植被和動物也受到極大危害，但很少有相關的研究報告。新南威爾斯州北方的Bitou bush野生林正進行的監測顯示：農作區一再的大規模空中噴灑農藥對鄰近野生動植物危害極大。飄散過來的農藥如掉落在脆弱敏感的濕地和湖礁，將造成沿海自然生態受損，土地流失。當地野生樹林經多次噴灑後無法復原，


物種滅絕，各種昆蟲、爬蟲、小動物、及土壤中的微生物受到危害。


&nbsp;


我們如何因應﹖│


乾淨健康的環境，在國際法律上，己逐漸成為人民該有的權力。人民對會進入他們土地和飲水的化學品，尤其是有毒物質都有事先被告知的權力。堅持我們的立場，告訴我們的選舉人，寫訴求信等，將能決定我們和家人朋友的健康與未來。


最基本的，要有被知會的權利。維護我們被告知的權利：


1. 那種殺蟲劑，那類成份將被噴灑？必要時可向相關單位要求該殺蟲劑的施用規定資料。


2. 將用何種噴灑方式？


3. 何時將施放？


4. 用在那些地方？


5. 施放負責人及緊急電話？此時可以暫時避開，把晾曬衣物收起來，小孩的玩爽場所蓋起來，或離開現場以減少危險。


涉及法律時，了解相關的殺蟲劑規定，看是否符合維護人體健康和野生生物的福址。&nbsp;&nbsp;&nbsp; 


例如澳洲新南威爾斯州強制規定，有使用殺蟲劑的行業必須經過訓練，施放者每 5 年須補充訓練，有使用殺蟲劑的行業必須保存記錄。二○○七年開始，公家單位如市府，須制定通告計劃。住宅管理處和蟲害管制技師須知會公寓和大樓有關殺蟲劑的施放。二○○九年後，進一步強制知會敏感地區施放消息。


在澳洲可應用以保護自己的一般法律條文有：1. 住家有免於受到干擾的權利。2. 施放者不得對於可預期危害有所疏忽，例如沒有依照標籤指示噴灑。3. 非法持續地、故意地噴灑侵入波及私宅，尤其己經經過書面要求者（最好書寫，並有見証人）。


在澳洲關於農藥波及訴訟成功案例有：


1. 一九九七年，ICI製造商應對其農藥產品 Chlorfluazuron 污染牧牛造成的損害負責的案例。


2. 一九九九年，在新南威爾斯州，一件有關空中噴洒除草劑造成鄰近葡萄園受損的案例。


3. 一九八九年，在西澳，一件未依指示在刮風日噴洒organophosphate 殺蟲劑造成鄰居生病的案例。


4. 都市計劃可把預防或限制農藥波及列入考量。例如，二○○八年，南澳州規定某一葡萄園須種植緩衝區以防止灰塵、氣味、農藥，散至鄰近土地。


可以預期的是，遭受農藥噴灑波及受害的情形未來將逐漸受到重視。去年 11 月，英國 35 歲的Georgina Downs小姐控訴英國政府在殺蟲劑噴灑管制上未善盡保護人民的職責，在經過&nbsp; 8&nbsp; 年苦戰後獲得勝訴（二○○九年 5 月文章）的例子，對受害者就是一大鼓舞。Georgina Downs小姐在多年生病不適後，才發覺與住處旁的農田噴灑農藥有關。


這案例讓我想到一個志同道合的好朋友。她和家人搬到南部一個山明水秀的好地方，蓋了別墅，種菜、養鴨，又買了幾塊地，種有機米、有機地瓜、自製有機堆肥。我去拜訪她時，看到當地也有許多類似的別墅房舍，她對各家各戶如數家珍，他們都是熱愛大自然，喜好鄉野生活的人們。他們定期聚會、交換樹苗：種子、蔬果什麼的。


聽說她肝臟功能不佳，於是再度登門拜訪。到了她家泡茶聊天，窗外就是遼闊無礙的山野綠地，好友加好茶，人生夫復何求﹖我這好友還是如往常一樣精力旺盛，敘述著她各種田園的經歷。在她的形容下，活龍活現地，鴨子成了消滅惡勢力，拯救飢荒的英雄；半夜用手電筒抓蟲則成了孩童的暑假大探險。聊著聊著，她起身打開窗戶，說早上隔壁稻田噴藥所以關上了。我這才注意到朋友屋舍後緊臨著一塊稻田，就像在當地定居，追求鄉野生活的人們，她的屋舍可說是坐落於大片農田之中。當時我並不了解遭受農藥噴灑波及的受害情形，直到看了英國Georgina Downs小姐個人的親身經歷，才警覺到二手農藥的嚴重性。至於我這好友的肝臟功能是否跟隔壁稻田噴藥有關，實在很難確認，我只希望她能早日恢復健康！
