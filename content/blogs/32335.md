&nbsp;



&nbsp;

&nbsp;

&nbsp;

&nbsp;

到一個朋友家去做客，出了電梯，

見門口赫然掛了一塊小木牌，上書：


&nbsp;

「進門前，請脫去煩惱；回家時，帶快樂回來。」&nbsp;


&nbsp;

&nbsp;

進屋後，果見男女主人一團和氣，兩個孩子大方有禮，溫馨、和諧充盈著整個屋子。我自然詢問起那塊木牌，女主人笑著望向男主人：「你說。」男主人則溫柔地瞅向女主人：「還是你說，因為這是你的創意。」 


&nbsp;

最終，女主人輕緩地說開了：「有一回我回家，在電梯的鏡子裏看到了一張困倦、灰暗的臉，一雙緊擰的眉毛，煩惱的眼睛……把我自己嚇了一大跳。

&nbsp;

於是，我想，當孩子、丈夫面對這樣愁苦陰沈的面孔時，會有什麼感覺？


&nbsp;

假如我面對的也是這樣的面孔又會有什麼反應？


&nbsp;

接著我想到孩子在餐桌上的沈默、丈夫的冷淡……


&nbsp;

第二天我就寫了一塊方木牌釘在門上以提醒自己。


結果，提醒的不只是我而是一家人，奇蹟就這樣出現了。


而且，不僅是我們一家人，到我家的客人也都變得歡歡喜喜……」



&nbsp;



&nbsp;

&nbsp;

&nbsp;

&nbsp;

好有智慧、好可愛的女人。 


&nbsp;

天下的好與壞，幸與不幸，快樂與痛苦，常常是一體的兩面。

&nbsp;&nbsp;

&nbsp;

一念之間的轉換，就呈現出截然不同的世界。
