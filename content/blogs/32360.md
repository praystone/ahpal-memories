&nbsp;&nbsp; &nbsp; 黑胡椒醬
材料 &nbsp;奶油2 大匙、洋蔥末3 大匙、蒜末2 大匙、黑胡椒細粒3 大匙、鮮奶油
&nbsp;&nbsp; &nbsp; &nbsp;1 大匙、水1 又1/2 碗、鹽少許、麵粉水酌量、威士忌酒1 大匙
作法 &nbsp;1.先把奶油加熱融化，放入蒜末及洋蔥末爆香，再加黑胡椒粒一起拌炒
&nbsp;&nbsp; &nbsp; &nbsp;2.另將水、鮮奶油和鹽一起放入煮開，起鍋前以麵粉水芶芡，再加1 大
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;匙威士忌酒即可。
---------------------------------------------------------------------------- &nbsp; &nbsp;
&nbsp;&nbsp; 蒜味茄汁義大利麵醬
材料 &nbsp; 洋蔥1/4 個、蒜末1/2 大匙、橄欖油2 大匙、水煮蕃茄罐頭1 大匙 月
&nbsp;&nbsp; &nbsp; &nbsp; 桂葉1 片、白酒2 大匙、白胡椒少許
作法 &nbsp; 1.將材料備好，洋蔥切丁備用。
&nbsp;&nbsp; &nbsp; &nbsp; 2.先將橄欖油加熱，再放入洋蔥、蒜末爆香。
&nbsp;&nbsp; &nbsp; &nbsp; 3.把蕃茄罐內的汁與粒倒入，再把剩餘的材料加入煮沸，即完成
---------------------------------------------------------------------------- &nbsp;&nbsp;
&nbsp;&nbsp; 紅燴海鮮醬
材料 &nbsp;辣椒醬1 大匙、蕃茄汁2 大匙、水3 大匙、米酒1 大匙、香油1/2 大匙
&nbsp;&nbsp; &nbsp; &nbsp;薑末1 大匙、蔥末1 大匙
作法 &nbsp;取一小鍋子，將所有材料調勻放入，用小火煮沸即可。
&nbsp;&nbsp; &nbsp; &nbsp;燴海鮮時將材料切好汆燙後瀝乾，放入紅燴海鮮醬拌炒入味即可。什錦
&nbsp;&nbsp; &nbsp; &nbsp;海鮮或肉類沾醬或炒醬均可。
----------------------------------------------------------------------------&nbsp;
米醬
材料 &nbsp;在來米粉2 大匙、醬油3~4 大匙、糖2~3 大匙、水2 杯、鹽適量 甘草
&nbsp;&nbsp; &nbsp; &nbsp;粉少許
作法 &nbsp;將所有材料放入鍋中，調勻煮開放涼即可。
&nbsp;&nbsp; &nbsp; &nbsp;可用於燜粉肝、燙豬肝或是粽子沾醬B.B.Q.烤肉醬
材料 &nbsp;蕃茄醬2 大匙、法式芥茉醬1/2 大匙、海鮮醬1 大匙、黑醋1/2 大匙 橄
&nbsp;&nbsp; &nbsp; &nbsp;欖油1/2 大匙、辣椒醬1/3 大匙、洋蔥碎末1/4 杯、蒜末1 大匙 粗黑
&nbsp;&nbsp; &nbsp; &nbsp;胡椒1/2 小匙、鹽少許、糖少許
作法 &nbsp;將所有材料混合調勻即可。
----------------------------------------------------------------------------&nbsp;
麻醬麵醬
材料 &nbsp;芝麻醬2 大匙、醬油2 大匙、糖1 小匙、白醋1 大匙、香油1 大匙 冷
&nbsp;&nbsp; &nbsp; &nbsp;開水3～4 大匙、蒜泥1 大匙
作法 &nbsp;將所有材料調勻即可，視個人喜好，可加點黃瓜絲及紅蘿蔔絲當配料，
&nbsp;&nbsp; &nbsp; &nbsp;可用於擔仔麵、乾麵、滷肉飯淋醬，或是燙青菜淋醬。
----------------------------------------------------------------------------&nbsp;
鹽水雞沾醬
材料 &nbsp;鹽3 大匙、薑4～5 片、蔥3 支、米酒1/2 碗 陳皮、桂皮、八角共20元、水
作法 將材料全部放入鍋中熬煮即可
&nbsp;&nbsp; &nbsp; 這個佐料可以用來滷雞，也可以用來沾雞肉吃。換言之，這個配方可以當
&nbsp;&nbsp; &nbsp; 作滷汁，也可以當成是沾料
----------------------------------------------------------------------------&nbsp;
義大利麵醬
材料 &nbsp;絞肉1/2 斤、洋蔥(切成小丁)1/4 顆、蕃茄糊罐頭1 罐 紅蘿蔔丁(或蘿
&nbsp;&nbsp; &nbsp; &nbsp;蔔末)1 杯、橄欖油2 大匙、紅辣椒醬2 大匙 蒜末1 大匙、白胡椒粉1
&nbsp;&nbsp; &nbsp; &nbsp;小匙、糖1/2 杯、水1/2 杯
作法 &nbsp;1.熱鍋，將橄欖油入鍋微熱過，加入洋蔥末、紅蘿蔔丁和蒜末炒香
&nbsp;&nbsp; &nbsp; &nbsp;2.再加進絞肉爆炒，接著加入辣椒醬、白胡椒粉、豆蔻粉和糖一起炒過
&nbsp;&nbsp; &nbsp; &nbsp;3.最後放入蕃茄糊和1/2 杯水用小火熬煮約3~5 分鐘即可
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp;用於義大利麵、乾麵淋醬，或是白菜燉煮醬
----------------------------------------------------------------------------&nbsp;
蕃茄醬
材料 &nbsp; 熟蕃茄1 斤、橄欖油1/2 小匙、紫蘇(或西洋香菜末)1 小匙、糖1/2 小
&nbsp;&nbsp; &nbsp; &nbsp; 匙 胡椒粉少許、鹽少許
作法 1.將蕃茄放入滾水中川燙一下，撈起放入冷水中再取出剝皮。蕃茄切半，
&nbsp;&nbsp; &nbsp; &nbsp; 把蕃茄籽及汁擠出後剁碎。
&nbsp;&nbsp; &nbsp; 2.起油鍋，加入橄欖油、剁碎的蕃茄、紫蘇(或西洋香菜末)及糖一起攪拌
&nbsp;&nbsp; &nbsp; &nbsp; 均勻，煮至蕃茄熟透。以鹽及胡椒粉調味，放涼收入冰箱，食用時酌量
&nbsp;&nbsp; &nbsp; &nbsp; 取用即可。
----------------------------------------------------------------------------&nbsp;
咖哩蕃茄醬
材料 &nbsp;材料Ａ： 蕃茄醬2 大匙、咖哩粉1 大匙、水1 杯、鹽1 小匙、香油1/3
&nbsp;&nbsp; &nbsp; &nbsp;大匙 糖1/2 大匙 材料Ｂ：太白粉1/3 大匙、水1 大匙
作法 &nbsp;1.將水煮沸加入材料Ａ用小火煮至收乾約成半杯量。
&nbsp;&nbsp; &nbsp; &nbsp;2.加入材料Ｂ芶芡，不用太濃，適量即可。(不芶芡也可以)
&nbsp;&nbsp; &nbsp; &nbsp; 可用於肉類或蔬菜炒醬
----------------------------------------------------------------------------&nbsp;
橙汁排骨醬
材料 &nbsp; 柳橙1 個、蕃茄醬2 大匙、糖1 大匙、鹽1 小匙、水2 大匙
作法 1.柳橙1 個(或香吉士)洗淨瀝乾對切，再切成0.5 公分片狀。
&nbsp;&nbsp; &nbsp; 2.將柳橙片與其他材料一起煮沸後改小火煮到剩餘約2/3 杯即可熄火，
&nbsp;&nbsp; &nbsp; &nbsp; 將所有材料渣過濾掉，醬汁即可使用
----------------------------------------------------------------------------&nbsp;
廣東油雞淋醬
材料 &nbsp;醬油3 杯、麥芽糖3～4 大匙、冰糖3 大匙、米酒1/2 杯、鹽2 大匙 水
&nbsp;&nbsp; &nbsp; &nbsp;10 杯、香油1/2 杯
滷包：廣陳皮、桂皮、八角、甘草
作法 將所有材料放入鍋中用中火煮約20 分鐘，就是香噴噴的油雞滷汁含油量較少的沙律醬
材料 &nbsp; 水1 杯、白醋2 大匙、細砂糖3 大匙、玉米粉5 大匙、沙律油1.5 杯鹽1 小匙、全蛋2個
作法 1.將水，白醋，細沙糖，玉米粉混合拌勻
&nbsp;&nbsp; &nbsp; 2.用中火將此混合物煮至透明， 呈膠狀即可
&nbsp;&nbsp; &nbsp; 3.第(2)部分材料先混合扮拌勻備用
&nbsp;&nbsp; &nbsp; 4.第一部分 1.2.離火後， 馬上加入四分之一左右的第(2)部分材料， 迅速拌
&nbsp;&nbsp; &nbsp; &nbsp; 勻， 如此反覆共4 次加完拌勻， 即為乳白色沙律醬
&nbsp;&nbsp; &nbsp; &nbsp; 此醬為基礎，可自行在調味上做變化，譬如多加點醋或胡椒粉等糖和醋
&nbsp;&nbsp; &nbsp; &nbsp; 的量可視需要稍作調整
----------------------------------------------------------------------------&nbsp;
馬鈴薯沙律(一)
材料 &nbsp; 4 人份，馬鈴薯 4 個，蔥 4 根，洋香菜屑 2 大匙，檸檬汁 2 大匙蒜泥
&nbsp;&nbsp; &nbsp; &nbsp; 1 粒，鹽 1/2 小匙，胡椒 適量，橄欖油 6 大匙
作法 &nbsp; 1.馬鈴薯洗淨，連皮在滾水中煮至熟透（水面需蓋過馬鈴薯）。
&nbsp;&nbsp; &nbsp; &nbsp; 2.煮好後，瀝去水，待涼至不會燙手的程度。
&nbsp;&nbsp; &nbsp; &nbsp; 3.蔥留白色與淺綠色較不老的部位，切成蔥花。
&nbsp;&nbsp; &nbsp; &nbsp; 4.馬鈴薯去皮，切成約半公分左右的厚片，放入大碗中，加蔥花
&nbsp;&nbsp; &nbsp; &nbsp; 5.與洋香菜拌合。
&nbsp;&nbsp; &nbsp; &nbsp; 6.取另一小碗混合檸檬汁、蒜末與鹽，灑少許胡椒，緩緩加入橄欖
&nbsp;&nbsp; &nbsp; &nbsp; 7.油，需邊加邊攪拌。
&nbsp;&nbsp; &nbsp; &nbsp; 8.拌勻的油汁淋在馬鈴薯上，拌一拌，讓馬鈴薯均勻沾到油汁。
&nbsp;&nbsp; &nbsp; &nbsp; 9.嚐嚐味道，若不夠鹹，可灑少許鹽再拌。適合冷食。
----------------------------------------------------------------------------&nbsp;
蒜味烤肉醬
材料 &nbsp; 醬油2 大匙、蠔油2 大匙、冰糖或麥芽糖2 大匙、五香粉少許胡椒粉1/4
&nbsp;&nbsp; &nbsp; &nbsp; 小匙、水3 又1/2 杯、酒1 大匙、蒜頭12 顆
作法 1.鍋中放入2 大匙油，先將蒜頭放入油鍋中，炸至微黃時立即撈起
&nbsp;&nbsp; &nbsp; 2.另外準備一個鍋子，將所有調味料放入鍋中煮開，再加進炸好的
&nbsp;&nbsp; &nbsp; 3.蒜頭熬煮至濃稠，就是很好的蒜味烤肉醬
----------------------------------------------------------------------------&nbsp;
馬鈴薯沙律(二)
材料 &nbsp;馬鈴薯三百克，小黃瓜三分之一條，紅蘿蔔三分之一條，火腿兩片，蔥四
&nbsp;&nbsp; &nbsp; &nbsp;分之一個，醋少許，鹽適量，胡椒少許，沙律醬四大匙
作法 1.馬鈴薯切小塊加水煮八分鐘加紅蘿蔔塊煮熟(不要把馬鈴薯壓碎)
&nbsp;&nbsp; &nbsp; 2.（1）把水瀝乾放入碗中加入鹽、胡椒、沙律醬拌勻
&nbsp;&nbsp; &nbsp; 3.加入火腿丁、洋蔥丁、小黃瓜片拌勻
----------------------------------------------------------------------------&nbsp;
味噌烤肉醬
材料 &nbsp; 味噌(須挑選鹽份較低者)1 大匙、味霖(即日本酒醋)1 小匙、糖1 大匙水
&nbsp;&nbsp; &nbsp; 1 大匙、蒜末1 小匙、香菜末1 大匙、蔥花1 大匙
作法 1.將味噌，味霖，糖和水仔細調勻再加入蒜末
&nbsp;&nbsp; &nbsp; 2.灑上蔥花和香菜末即可
&nbsp;&nbsp; &nbsp; &nbsp; 如果還覺得不夠鹹的話可以加入適量的醬油.如果買不到味霖，可以用
&nbsp;&nbsp; &nbsp; &nbsp; 少許白醋代替
----------------------------------------------------------------------------&nbsp;
正宗日本天婦羅沾醬
材料 白蘿蔔、醬油
作法 白蘿蔔弄成泥，加醬油，拌勻即可
----------------------------------------------------------------------------&nbsp;
腐乳醬汁(雞排醃汁)
材料 紅腐乳60 克、料理米酒10CC、糖1 茶匙、味精1/2 茶匙、蠔油1 大
&nbsp;&nbsp; &nbsp; 匙 薑末5 克、小蘇打1/4 茶匙、水50CC、蒜末20 克
作法 將所有材料放入果汁機內打約30 秒盛碗即可
----------------------------------------------------------------------------&nbsp;
香檸醃汁(雞排醃汁配方)
材料 檸檬1 顆、糖1 茶匙、鹽1/4 茶匙、小蘇打1/4 茶匙、水30CC 料理
&nbsp;&nbsp; &nbsp; 米酒1 大匙
作法 將檸檬壓汁，再和其餘材料放入果汁機內，打約30 秒盛碗即可。
----------------------------------------------------------------------------&nbsp;
傳統雞排醃汁
材料 蔥末20 克、薑末10 克、蒜末40 克、五香粉1/4 茶匙、味精1 茶匙 醬
&nbsp;&nbsp; &nbsp; 油膏1 大匙、小蘇打1/4 茶匙、水50CC、料理米酒1 大匙
作法 將所有材料放入果汁機內打約30 秒盛碗，再放入雞排肉將其兩面均勻沾
&nbsp;&nbsp; &nbsp; 上醃汁，靜置約30 分鐘即可
----------------------------------------------------------------------------&nbsp;
梅子醬
材料 &nbsp; 紫蘇梅2 顆、砂糖1 大匙、素蠔油1 大匙、梅子汁2 大匙、水少許
作法 1.紫蘇梅洗淨、切細末。
&nbsp;&nbsp; &nbsp; 2.取一碗，放入其餘材料與水攪拌均勻。備用。
&nbsp;&nbsp; &nbsp; 3.熱鍋，倒入作法2 的醬汁以小火煮約3～5 分鐘至小滾即可熄火盛碗。
&nbsp;&nbsp; &nbsp; 4.將作法1 和作法3 一起混合拌勻即可。
----------------------------------------------------------------------------&nbsp;
蒜蓉醬
材料 &nbsp; 辣椒1 條、蒜頭1 顆、砂糖1 大匙、蠔油1 大匙、醬油膏2 大匙、水少許
作法 1.取一碗，砂糖、蠔油、 醬油膏與水一起攪拌均勻。
&nbsp;&nbsp; &nbsp; 2.熱鍋，倒入作法1 的醬汁以小火煮約3～5 分鐘至黏稠狀盛碗。
&nbsp;&nbsp; &nbsp; 3.辣椒、蒜頭洗淨切細末，再和作法2 的醬一起拌勻即可。
----------------------------------------------------------------------------&nbsp;
甜辣醬
材料 &nbsp; 蕃茄醬1/2 大匙、辣椒醬2 大匙、水少許、砂糖1 大匙
作法 1.取一碗，加入所有材料與水一起攪拌均勻。
&nbsp;&nbsp; &nbsp; 2.熱鍋，倒入作法1 的醬汁以小火煮約3～5 分鐘至黏稠狀即可。
----------------------------------------------------------------------------&nbsp;
炸醬麵醬
材料 &nbsp;蝦米3 兩、蝦皮4 兩、蒜頭2 兩、絞肉1 斤、豆干丁1/2 斤、甜麵醬1
&nbsp;&nbsp; &nbsp; &nbsp;罐 豆瓣醬1/3 小罐、蘿蔔乾4 兩、水1 又1/2 碗
作法 將蝦皮與蝦米混合，放入鍋中，配合蒜頭爆香，再加入水、絞肉、豆干丁、
&nbsp;&nbsp; &nbsp; 蘿蔔乾一起拌炒，最後加入甜麵醬及豆瓣醬炒勻，加水煮開後放涼裝瓶。
----------------------------------------------------------------------------&nbsp;
南瓜醬
材料 &nbsp;南瓜2 杯、高湯1 杯、牛奶1 杯、鹽少許、白胡椒粉少許、麵粉少許 奶
&nbsp;&nbsp; &nbsp; &nbsp;油1 大匙、洋蔥2 大匙
作法 1.將南瓜洗淨去皮與籽後切小塊，和高湯一起放入鍋中煮沸，改中火，再
&nbsp;&nbsp; &nbsp; &nbsp; 加入牛奶一起煮至熟透即可熄火備用。
&nbsp;&nbsp; &nbsp; 2.將奶油放入鍋中加熱溶解，放入洋蔥爆香後改小火，再倒入麵粉略炒
&nbsp;&nbsp; &nbsp; &nbsp; 後，盛起放入南瓜湯汁中繼續煮，如湯汁不夠可再加入少許牛奶或高湯。
&nbsp;&nbsp; &nbsp; 3.將湯汁煮至濃稠後加入鹽及白胡椒粉，攪拌均勻後，盛起倒入果汁機中
&nbsp;&nbsp; &nbsp; &nbsp; 攪打均勻即可使用。點心沾醬或油炸類食物沾醬均可
----------------------------------------------------------------------------&nbsp;
樹子辣醬
材料 &nbsp; 樹子1/3 杯、紅辣椒粉2 小匙、蒜泥1 大匙、香油1/2 大匙、水2 大匙
&nbsp;&nbsp; &nbsp; &nbsp; 蔥末1 大匙、紅蘿蔔末1 大匙
作法 1.樹子有粒狀及圓餅狀之分，如果是整塊，要先分開成小塊粒狀。
&nbsp;&nbsp; &nbsp; 2.再將所有材料拌勻用小火煮至味道均衡後即可使用蒸魚、蒸肉火鍋沾醬用
----------------------------------------------------------------------------&nbsp;
薄荷醬
材料 &nbsp;薄荷葉適量、水1/2 杯、糖少許、牛奶1/2 杯、奶油1 大匙、鹽少許 麵
&nbsp;&nbsp; &nbsp; &nbsp;粉適量、水適量、白胡椒粉適量
作法 1.將薄荷葉洗淨打成細末與水一起煮沸後將渣濾除後再用小火加熱。
&nbsp;&nbsp; &nbsp; 2.續在鍋中放入奶油、牛奶、鹽、糖、白胡椒粉等調煮拌勻。
&nbsp;&nbsp; &nbsp; 3.另外用小碗將麵粉與水拌勻，慢慢將麵粉水加入鍋中煮至濃稠狀即可熄
&nbsp;&nbsp; &nbsp; &nbsp; 火備用。可作為麵包條沾醬或羊排淋醬
----------------------------------------------------------------------------&nbsp;
豆乳泥辣醬
材料 &nbsp;豆腐乳1 塊、果糖1 又1/2 大匙、辣油1 大匙、水2/3 杯、醬油1/2
&nbsp;&nbsp; &nbsp; &nbsp;大匙 蒜泥1 大匙、蔥末1 大匙
作法 1.先將豆腐乳壓成泥狀備用。
&nbsp;&nbsp; &nbsp; 2.再與水融合後加入果糖、辣油、醬油等用小火煮沸。
