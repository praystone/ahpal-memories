&nbsp;


"等到有一天" 你或許沒有機會/作者：孫越



&nbsp;


在今天，我們的房子越來越大，但是家庭越來越小。


&nbsp;


生活越來越方便，但是時間卻越來越少。


&nbsp;


我們的學位越來越高，常識卻越來越少。


&nbsp;


知識越來越多，判斷力卻越來越差。


&nbsp;


我們有更多的專家，但是也有更多的問題。


&nbsp;


醫藥越來越好，但健康越來越少。


&nbsp;


我們花費太多，歡笑太少。


&nbsp;


車開得太快，火氣上來也更快。


&nbsp;


睡得太晚，閱讀太少，電視看得太多，而且禱告太少。


&nbsp;


我們所擁有的資產倍增，但是價值卻遞減。


&nbsp;


我們說得太多，但是愛心太少，且謊話連篇。


&nbsp;


我們學習如何經營生活，但沒有建造生命。


&nbsp;


我們在生命中加增歲月，卻沒有在歲月中增長生命。


&nbsp;


我們有越來越高的建築，但也有越來越低的 EQ。


&nbsp;


有更寬廣的高速公路，但有更狹窄的視野。


&nbsp;


我們花費得更多，但擁有的更少。


&nbsp;


我們買得更多，但享受得更少。


&nbsp;


我們可以登陸月球回來。但是卻無法拜訪對街的鄰居。


&nbsp;


我們可以征服外太空。但是卻無法掌控內心世界。


&nbsp;


我們可以分裂原子核，但是卻無法挪去心中的偏見。


&nbsp;


我們更多書寫，卻更少學習。


&nbsp;


更多計畫，卻更少成就。


&nbsp;


我們學會忙碌，但學不會等候。


&nbsp;


我們的收入更高了，但道德更低了。


&nbsp;


我們生產更多電腦，掌握更多資訊，


&nbsp;


複製更多拷貝，但我們的溝通卻更貧乏。


&nbsp;


我們的數量提高了，品質卻降低了


&nbsp;


這是快速食品充斥卻消化不良的時代。


&nbsp;


高大的身軀與低劣的性格並存的時代。


&nbsp;


更多休閒卻更少歡樂。


&nbsp;


更多食物卻更少營養。


&nbsp;


更多雙收入家庭，但更高的離婚率。


&nbsp;


更多千萬豪宅，但 卻更多破碎的家庭。


&nbsp;


我建議，在今天這樣的世代，


&nbsp;


你不要保留任何事情到特殊的場合才做，


&nbsp;


因為你活著的每一天都是特殊場合。


&nbsp;


勤加閱讀，追求知識，


&nbsp;


坐在你家的前廊上欣賞自然美景，


&nbsp;


無需汲汲營營於生活需要。


&nbsp;


多花時間與家人及好友在一起，


&nbsp;


享受喜歡的食物，


&nbsp;


到你喜愛的地方去遊覽。


&nbsp;


生命不只是為了存活，


&nbsp;


而是一連串愉快事件組成的的鏈條。


&nbsp;


將你的水晶高腳杯拿出來，


&nbsp;


不要將妳最好的香水存起來，


&nbsp;


任何時候你想要用的時候就用它吧。


&nbsp;


把「有一天」「將來的某一天」


&nbsp;


從你的字典中刪除。


&nbsp;


現在就去寫那一封


&nbsp;


你曾經想過要等到「有一天」才來寫的信。


&nbsp;


讓我們現在就告訴我們的家人我們多愛他們。


&nbsp;


不要將會帶給你歡笑及喜樂的任何事情拖延到未來。


&nbsp;


每一天，每一小時，每一分鐘都是特別的，


&nbsp;


而且你不知道那是否是你的最後一刻。


&nbsp;


如果你太忙以致於無法將這封信傳給你所愛的人，


&nbsp;


你告訴自己說，「等到有一天」我再傳。


&nbsp;


那　請你相信我&nbsp; "等到有一天" 你或許沒有機會傳了。


&nbsp;
