&nbsp;




&nbsp;


&nbsp;


生命的本質在於追求快樂，


而使得生命快樂的途徑有兩條︰
&nbsp;
第一，發現使你快樂的時光，增加它；
&nbsp;
&nbsp; 第二，發現使你不快樂的時光，減少它。
&nbsp;
擁有陽光心態的人不是沒有黑暗和悲傷的時候，
&nbsp;
只是他們追尋陽光的心靈不會被黑暗和悲傷遮蓋罷了。
&nbsp;
如果我們每天能夠“早上醒來，光彩在臉上，
&nbsp;
充滿笑容地迎接未來︰
&nbsp;
到了中午，光彩在腰上，挺直腰杆地活在當下；
&nbsp;
&nbsp; 到了晚上，光彩在腳上，腳踏實地地做好自己，”
&nbsp;
那麼，我們就享受了生命的精彩過程。
&nbsp;
&nbsp;


&nbsp;


生活就像一面鏡子，


你笑，它也笑；你哭，它也哭。

20歲時，我們在意別人對我們的想法；
&nbsp;
&nbsp; 40歲時，我們不理會別人對我們的想法；
&nbsp;
&nbsp;&nbsp; 60歲時，我們發現別人根本就沒有在意我們。
&nbsp;
陽光就是快樂，陽光就是幸福，
&nbsp;
陽光就是安詳，陽光就是富足。
&nbsp;
&nbsp;


&nbsp;


擁有美好的心情才能欣賞靚麗的風光，
&nbsp;
決定你生活是否快樂的不是頭頂直射的陽光，
&nbsp;
而是自己心中那一輪冉冉升起的朝陽。
&nbsp;
擁有陽光的心態，才能擁有美好的一切。
&nbsp;
&nbsp;


我擁有微笑….


有人說，他擁有金錢，
&nbsp;
但那只不過是物質的富足，不是精神的沃土。
&nbsp;


有人說，她擁有美貌，
&nbsp;
但那只不過是上天偶然的恩賜，誰能抵擋時間的輪回。
&nbsp;


有人說，他擁有權勢，
&nbsp;
但那只不過是瞬間的榮耀，過往雲煙何須自傲？
&nbsp;


我都不要，我不要利益的枷鎖，我不要浮華的絆擾，
&nbsp;


我只要一抹嘴角上彎的愜意，
&nbsp;
一抹清澈如泉的天真，一抹暖如冬日的陽光------微笑。
&nbsp;
&nbsp;


&nbsp;


是誰說微笑是世上最美的語言？
&nbsp;
失意時，給自己一個微笑，


希望便重振旗鼓，鬥志昂揚…..
&nbsp;
憂傷時，給自己一個微笑，
&nbsp;
就能吹散絕望的烏雲，看到遠方的光明….
&nbsp;
快樂時，也別忘了給自己一個微笑，
&nbsp;
讓春天在臉上讚揚樂觀，


綻放一曲青春歡樂的主旋律…
&nbsp;
這是多麼快樂的事啊，這是多麼幸福的事呀!
&nbsp;
&nbsp;


&nbsp;


我擁有微笑….
&nbsp;
是笑對困阻的微笑、是喜迎磨難的微笑、
&nbsp;
是激情飛揚的微笑、是融化堅冰的微笑。
&nbsp;
&nbsp;


&nbsp;


我擁有微笑….
&nbsp;
我就把微笑分享，讓朋友笑逐顏開、
&nbsp;
讓對手握手言和、讓誤會走投無路、讓真情一路撒播….
&nbsp;
金錢會流失，美貌會失去，權勢也終究化為烏有，
&nbsp;
惟獨微笑------這寶貴的財富，歷經風雨相伴如一。
&nbsp;
微笑的人是多麼幸運，笑出積極樂觀的態度，
&nbsp;
笑出勇敢熱情的人生，對著天空，
&nbsp;
&nbsp;


&nbsp;


我微笑著。
&nbsp;
擁有陽光的心態，才能擁有美好的一切。


&nbsp;
