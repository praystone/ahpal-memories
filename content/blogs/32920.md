1. 蔬菜類&nbsp;
　　（1）屬於寒性的鹼性食物有：蓴菜、馬齒菜、蕺菜（魚腥草）、蕹菜、番茄、佛手瓜、西葫蘆、
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 葫蘆瓜、瓠瓜、甜瓜（香瓜）、哈密瓜、西瓜、菜瓜、竹筍、海帶。

　　（2）屬於涼性的鹼性食物有：蓮藕、魔芋、慈菇、粉葛、甜菜（紫菜頭）、蘿蔔、苤藍、旱芹、
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 莧菜、茄子、萵苣（萵筍）、茭白、苦瓜、油菜、菠菜、蘑菇、生菜
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 、菜花、金針菇、冬瓜、黃瓜、絲瓜。
　　（3）屬於平性（陰性系列中屬於比陰陽比陽陰的一種）的鹼性食物有：百合、胡蘿蔔、大頭菜、
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 茼蒿、荊芥、白菜、甘藍、猴頭、黑木耳、薺菜、銀耳、番薯（紅薯）
&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 、馬鈴薯（土豆）、芋頭。
　　（4）屬於溫性的鹼性食物有：恰瑪古、山藥、洋蔥、薤白（野蒜）、香椿、韭菜、雪裏蕻、芫荽、甜椒、 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 南瓜、生薑、蔥。
　　（5）屬於熱性的鹼性食物有：大蒜、辣椒、胡椒。&nbsp;

2.食用藥材類&nbsp;
　　（1）屬於寒性的鹼性食物有：石斛、蘆根。
　　（2）屬於涼性的鹼性食物有：菊花、薄荷、地黃、白芍、西洋參、沙參、決明子。
　　（3）屬於平性（比陰陽，比陽陰）的鹼性食物有：黃精、天麻、黨參、茯苓、甘草。
　　（4）屬於溫性的鹼性食物有：何首烏、砂仁、冬蟲夏草、桂花、川芎、黃芪、人參、當歸、肉蓯蓉、杜 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;仲、白術。
　　（5）屬於熱性的鹼性食物有：肉桂。&nbsp;

3.水果類&nbsp;
　　（1）屬於寒性的鹼性食物有：獼猴桃、柿子、桑葚、無花果、甘蔗、香蕉、荸薺。
　　（2）屬於涼性的鹼性食物有：梨子、枇杷、柳丁、柑子、芒果、羅漢果、蘋果。
　　（3）屬於平性（陰性系列中屬於比陰陽比陽陰的一種）的鹼性食物有：葡萄、山楂、石榴、木瓜、龍眼 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; （桂圓）、檳榔、橘子、荔枝、檸檬。
　　（4）屬於熱性的鹼性食物有：桃子、櫻桃。

4.堅果類&nbsp;
　　（1）屬於平性（比陰陽，比陽陰）的鹼性食物有：大豆(黃豆)。
　　（2）屬於溫性的鹼性食物有：栗子、杏仁。

5.飲料類&nbsp;
　　（1）屬於涼性的鹼性食物有:茶葉
　　（2）屬於平性（比陰陽，比陽陰）的鹼性食物有：葡萄酒、豆漿、牛奶、蜂蜜。
　　（3）屬於溫性的鹼性食物有：咖啡。

6.製品類&nbsp;
　　（1）屬於寒性的鹼性食物有：食鹽。
　　（2）屬於溫性的鹼性食物有：食醋。
　　（3）屬於熱性的鹼性食物有：食堿。

7.十字花科類
　　（1）蘿蔔乾、紅蘿蔔、紅薯等。
　　 (2)強鹼：恰瑪古等。

常見的鹼性食物與酸性食物：
　1.強酸性食品：蛋黃、乳酪、白糖做的西點或柿子、烏魚子、柴魚等。&nbsp;
&nbsp;&nbsp; &nbsp;2.中酸性食品：火腿、培根、雞肉、鮪魚、豬肉、鰻魚、牛肉、麵包、小麥、奶油、馬肉等。&nbsp;
&nbsp;&nbsp; &nbsp;3.弱酸性食品：白米、落花生、啤酒、酒、油炸豆腐、海苔、文蛤、章魚,泥鰍。&nbsp;
&nbsp;&nbsp; &nbsp;4.弱鹼性食品：紅豆、蘿蔔、蘋果、甘藍菜、 洋蔥、豆腐等。&nbsp;
&nbsp;&nbsp; &nbsp;5.中鹼性食品：蘿蔔幹、大豆、紅蘿蔔、蕃茄、香蕉、橘子、番瓜、草莓、蛋白、梅幹、檸檬、菠菜等。&nbsp;
&nbsp;&nbsp; &nbsp;6 .強鹼性食品：恰瑪古、葡萄、茶葉、海帶芽、海帶，檸檬等。
