戒老錄<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


1.不要認為別人替你做是理所當然。因為“老”並非等於有權利要求別人“替你做事”。


&nbsp;


2.老人不是“頭銜”也不是“資格”。


&nbsp;


3.對親人也不要隨便說話，也需要保持儀態。


&nbsp;


4.不要將自己所遭遇的孤獨、貧困、病苦與別人相較，你並非最不幸的人。


&nbsp;


5.不要閒著沒事做就好管閒事，或論斷別人。


&nbsp;


6.要建立自己的生活方式，少論斷別人的行為或想改變他人。


&nbsp;


7.埋怨非但沒有一點好處，反而使自己更自怨自艾。


&nbsp;


8.要顯得明朗，即使心中並非如此。


&nbsp;


9.老人的自卑顯得庸俗，要盡力克服它。


&nbsp;


10.做不到的事要放棄，不要勉強。


&nbsp;


11.能做的事要自己做，不時的鍛鍊自己。


&nbsp;


12.要保重身體，但不必太寵。


&nbsp;


13.對下一代的將來，要保持某種程度的冷漠。


&nbsp;


14.切記，年青人定比我們忙。


&nbsp;


15.年青人不像老人那麼空，銘記此點與他們接觸會較順利。


&nbsp;


16.生活上的寂寞感是無法排解的。或許有人會幫你忙，但基本上只有自己才能解決。


&nbsp;


17.不要羡慕“年青”要尊重年青人。


&nbsp;


18.兒女不需要你擔心，只要默默關心。兒女使你擔心，那就要感謝。


&nbsp;


19.不要說謊。


&nbsp;


20.不要攻擊別人。


&nbsp;


21.不要因對方對老人態度不好，就指責對方。


&nbsp;


22.醫生對你態度不好，也不生氣。


&nbsp;


23.常與同年齡的老人來往，使自己的生活充實。


&nbsp;


24.退休是個定點，從此再出發，就是新生。當然要受教於別人。


&nbsp;


25.凡事不要以為自己是最正確，不妨先試想自己是錯誤的。


&nbsp;


26.要得到快樂，多少總要花錢。不用體力、不費心、不花錢是不能得到快樂的。


&nbsp;


27.要習慣一個人玩（過日子）。


&nbsp;


28.孫兒對老人漠不關心，也不必在意。


&nbsp;


29.要照顧孫兒，但別想回報。


&nbsp;


30.兒女並非養老的保險。如有這種想法要趕快放棄，以免成為功利的討厭的父母。


&nbsp;


31.守住自己的範圍，避免干涉別人的工作、交際。


&nbsp;


32.不要將自己與親戚朋友來往的成規加諸於年青一輩。


&nbsp;


33.需要幫忙時，還是找專職的，不要利用別人的好意。


&nbsp;


34.不要以為用金錢就能說動別人，也不要以為老人不會麻煩別人。


&nbsp;


35.要別人幫忙時，只要看結果，不要在乎過程。


&nbsp;


36.自己不能照顧就別養寵物，或種植物。


&nbsp;


37.不要固執。固執使人老化。


&nbsp;


38.稱讚別人時，僅止于對其本人。


&nbsp;


39.不要求位階、勳章、或加入特殊聲譽的團體。更不要想為自己立碑、鑄銅像。


&nbsp;


40.超過平均壽命，即使氣力與體力都夠也不要當候選人，或站上教壇。死亡的可能性太大，造成對選民、學生的不負責任。


&nbsp;


41.對名譽職位不要棧戀。自己定個期間，任期到了，即刻辭退。


&nbsp;


42.別人對你客氣，只是你看來夠“老”。對你無禮，是把你看成對等的人。


&nbsp;


43.對自己的健忘、身體的機能失靈不要找藉口。


&nbsp;


44.突然有性格上的改變，可能起因于疾病，要仔細檢查。


&nbsp;


45.努力學習用新機器。


&nbsp;


46.勿在交通人擁擠時出門。出門時手不要拿東西。


&nbsp;


47.對食物，要考慮自己的健康能力、範圍。


&nbsp;


48.用餐時要注重禮節。無禮的老人會討人厭。


&nbsp;


49.視力、聽力有問題及早就醫。不要以為“老人不會好”就放棄。


&nbsp;


50.小心口臭、體臭。老人有獨特的體味，善于利用香水。


&nbsp;


51.老人要保持整潔。這是對周圍的禮貌。


&nbsp;


52.上廁所要關門及上鎖。坐在椅子上，雙腳要靠緊。


&nbsp;


53.一輩子都要注重儀態。


&nbsp;


54.要捨得丟。廢紙、紙箱等老人有收著捨不得丟的傾向。


&nbsp;


55.不要什麼都要。（將不需要的東西都收集，是老化的徵候）


&nbsp;


56.只種植、照顧植物使腦退化。多讀書、用功與人溝通，能激盪腦、防止退化。


&nbsp;


57.不要誇耀自己的體力、氣力。能幫比自己衰弱的友人，是幸運。


&nbsp;


58.想當年”這種話題適可而止。


&nbsp;


59.不慌、不忙、不急。


&nbsp;


60.在外面要聚神。但心中要鎮定，認為即使有出錯，也定能解決。


&nbsp;


61.年青時就要鍛鍊腳力，要伸直背部，保持良好姿勢。


&nbsp;


62.運動是很必要的。老人都很空，每天要做適當的運動。


&nbsp;


63.找電話號碼、寄信、打電報等，這些日常生活的瑣事要自己做。


&nbsp;


64.如果會妨礙年青人，不要與他們同行。


&nbsp;


65.不要怕風雨，即使下了些雨，也不要取消出門的予定。不過老人容易跌倒，強風豪雨時不要外出。


&nbsp;


66.多旅行。沒有羈絆，要享受自由。


&nbsp;


67.搬家、大掃除與日常生活有變化時，老人不必幫忙，儘量避開。


&nbsp;


68.婚喪喜慶、探病等，到了某個時期就要避免。重要的是為病人迫切禱告。
