&nbsp;

&nbsp;

悲傷是過去式，生活是未來式

&nbsp;



&nbsp;

&nbsp;


任何人只要活著就必須面臨到傷痛的回憶，

&nbsp;

可能是傷害、苦難甚至失去的折磨，

&nbsp;

有人咬緊牙關，頭過身就過的忍耐，

&nbsp;

也有人跌跌撞撞、遍體連傷，但無論你如何度過難關的，

&nbsp;

你必須懂的將過往的悲痛放下，

&nbsp;

不需要再繼續背負著它走往以後的人生，

&nbsp;

或許它給傷害難免讓我們久久無法釋懷，

&nbsp;

可是你越放不下，它就越會影響你往後的生活方式，

&nbsp;

是好是壞很難說，但它讓你擔心、

&nbsp;

害怕甚至將自己封鎖起來卻是很有可能的事情。

&nbsp;

&nbsp;

過去的就讓它隨著時間過去，不要過去都已經受到折磨，

&nbsp;

當下還不願意放手，你哭 你悲 你痛 都無法改變

&nbsp;

已經發生的事實，

&nbsp;

或許情緒發洩完，但你情緒發洩完之後，

&nbsp;

你願意重新面對屬於自己的人生嗎？

&nbsp;

它給的傷害可能短暫可能永遠，是要看你的心態的，

&nbsp;

或許真的很悲痛、很難受，

&nbsp;

只是你沉溺在過去的悲痛當中，你知道嗎？

&nbsp;

珍惜你的人、關心你的人同樣也被過去的悲痛所綑綁。

&nbsp;

&nbsp;

負面的回憶，它給你傷口、給你折磨，

&nbsp;

讓你無法輕鬆的看待過去，但你呢？

&nbsp;

你是否才是讓自己背負著過去悲傷的罪魁禍首？

&nbsp;

既然已經是過去式就代表它已經是發生的事，

&nbsp;

你無法改變這件事情了，但你可以改變自己，

&nbsp;

看你要用一年、十年甚至一輩子的時間

&nbsp;

來回憶不愉快的過去，還是把悲傷的時間縮短，

&nbsp;

再次創造屬於自己往後生活上的種種幸福快樂，

&nbsp;

其實決定權在你手上，而你打算掌握了嗎？

&nbsp;

&nbsp;

不要已經飽受傷害了，

&nbsp;

自己還讓自己墮落在痛苦深淵當中，

&nbsp;

你越難過就越讓自己爬不出痛苦的深淵、

&nbsp;

你越負面就越讓自己的日子不快樂，

&nbsp;

面對它，能解決就解決，能面對就面對，

&nbsp;

若無法解決或面對那就告訴自己看開些吧！

&nbsp;

畢竟它不是你造成的，也不是你願意碰上的，

&nbsp;

而是環境給於的考驗跟折磨，

&nbsp;

不需要連自己往後的生活都賠進去，

&nbsp;

更不要連往後的幸福都遭受傷害，

&nbsp;

過去的惡夢就告訴自己請放開它不要再緊握。

&nbsp;

&nbsp;

人生苦短不要因為過去的惡夢

&nbsp;

讓往後的生活都籠罩在黑暗之中，

&nbsp;

它給的悲、給的痛、給的傷 、可能世界超級無敵讓人無法對抗，

&nbsp;

可是你認為把你的人生、

&nbsp;

精神甚至幸福通通花費在這身上值得嗎？

&nbsp;

我想並不值得吧！但你看看你，

&nbsp;

你難道沒發覺自己正在為過去的悲痛

&nbsp;

而浪費往後的生活時光嗎？

&nbsp;

把時間浪費在惡夢、傷痛之中，

&nbsp;

為過去的不愉快而浪費未來的美好時光，這你有發現嗎？

&nbsp;

&nbsp;

過去的不需要刻意忘記，也不需要浪費太多時間在它身上，

&nbsp;

好的回憶我們收留並且保存，壞的記憶我們記取教訓，

&nbsp;

然後讓它隨風而逝；可能我們無法改變過去，

&nbsp;

但也不要讓不好的過去影響未來，畢竟還有關心我們的人、

&nbsp;

還有珍惜我們的人 

&nbsp;

站在往後人生路途上的某處等著我們，

&nbsp;

若因為過去的惡夢 讓我們的路走偏、讓我們的人生變調，

&nbsp;

那我們還遇的上他們嗎？記得悲痛的教訓，

&nbsp;

但也該張開雙手迎向新的未來生活，

&nbsp;

因為還有美妙的未來在前方等我們擁有。


&nbsp;
