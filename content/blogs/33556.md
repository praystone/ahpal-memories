Q、你搬家的時候，一位好朋友想送你一幅以阿爾卑斯山為背景的畫給你，如果要你選擇，請問你會選擇下列四幅畫中的哪一幅？


&nbsp;


&nbsp;


A、海上的阿爾卑斯山


&nbsp;


B、被白雪覆蓋的阿爾卑斯山


&nbsp;


C、被山川所環繞的阿爾卑斯山


&nbsp;


D、從空中俯瞰的阿爾卑斯山&nbsp;


&nbsp;

&nbsp;


&nbsp;


&nbsp;


&nbsp;


A.


&nbsp;


你非常重視人際關係，喜歡照顧別人，對於他人的一舉一動非常注意。你很具有社交性格，朋友也很多，而個性很開放，在戀愛方面也是相當浪漫，容易與對方一見鍾情，很會營造羅曼蒂克的氣氛，讓戀情可以進行的很順利。


&nbsp;


&nbsp;


&nbsp;


B.


&nbsp;


你的個性保守，相當重視道德。阿爾卑斯山代表理想，而白雪則代表限制它的道德。因此這種類型的人很重視自己的想法，不勉強自己與他人交往，有頑固的一面。你能擁有一份可以發揮自己專長的工作，逐步完成自己的夢想。


&nbsp;


&nbsp;


&nbsp;


C.


&nbsp;


這種類型的人，是經歷過各種的苦難，煩憂而建立起屬於自己的人生觀，是越挫越勇的人。在與人交往方面算是相當順利的，因為大多會站在對方的立場體諒別人，很容易受他人信賴與親近，朋友都喜歡找你傾訴心中的煩惱。


&nbsp;


&nbsp;


&nbsp;


D.


&nbsp;


你是個支配慾很強的人，不喜歡接受他人的命令，喜歡受人奉承及指使他人，對新奇的事物也很有好奇心。在人際關係方面，你為人很好，因此交友廣闊，對周圍所發生的事件都抱持極高度的關心與參與，是一個很能幹的人。
