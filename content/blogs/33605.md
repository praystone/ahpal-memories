如同氧氣般的妳

&nbsp;

就像易碎的珍品 

&nbsp;

你用甜美侵蝕了我

&nbsp;

凍結的傷口

&nbsp;

因為妳逐漸裂開

&nbsp;

感覺對了 卻又無法擁有 戀愛的苦痛 

&nbsp;

刺痛了我

&nbsp;

如氧氣般的妳 只要吸食&nbsp; 便無法呼吸

&nbsp;

殘忍的愛情世界裡 令我窒息

&nbsp;

妳是 冷漠 無情的藥劑

&nbsp;

喝下後便靜靜跟隨妳

&nbsp;

冰冷的愛情 思念的苦痛

&nbsp;

還有你那清晰的真心

&nbsp;

將我帶上了盡頭

&nbsp;

無法呼吸

&nbsp;

漸漸窒息

&nbsp;

失去的悲傷 破裂的心臟 溢出我的淚水

&nbsp;

眼前的妳 已不再屬於我

&nbsp;

沒了妳&nbsp; 剩下狠毒的深情

&nbsp;

侵占了我的記憶

&nbsp;

&nbsp;
