去吧~我的愛 

&nbsp;

當你熟睡之後

&nbsp;

我已瞬間長大

&nbsp;

擁有過的 還是遺憾最多

&nbsp;

對不起

&nbsp;

欠你一句話

&nbsp;

就欠著吧

&nbsp;

你欠我的

&nbsp;

又何只一句話而已

&nbsp;

不討了

&nbsp;

總讓你牽掛

&nbsp;

安心去吧 我的愛

&nbsp;

這時節

&nbsp;

是為難我了

&nbsp;

沒勇氣去看你

&nbsp;

對不起&nbsp; 

&nbsp;

無法面對冰冷的罈

&nbsp;

自言自語

&nbsp;

永遠無回應

&nbsp;

請讓我浮出海面

&nbsp;

偶爾 透透氣

&nbsp;

就這樣而已 

&nbsp;

就這樣而已
