最后的旅行




&nbsp;


他是個搞設計的工程師，她是中學畢業班的班任老師，

&nbsp;

兩人都錯過了戀愛的最佳季節，后來經人介紹而相識。

&nbsp;

沒有驚天動地的過程，平平淡淡地相處，自自然然地結婚。

&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

婚后第三天，他就跑到單位加班，為了趕設計，

&nbsp;

他甚至可以徹夜拼命，連續幾天幾夜不回家。

&nbsp;

她忙于畢業班的管理，經常晚歸。為了各自的事業，

&nbsp;

他們就像兩個陀螺，在各自的軌道上高速旋轉著。

&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

送走了畢業班，清閑了的她開始重新審視自己的生活，審視自己的婚姻，

&nbsp;

她開始迷茫，不知道自己在他心里有多重，她似乎不記得他說過愛他。

&nbsp;

一天，她問他是不是愛她，他說當然愛，不然怎麼會結婚，

&nbsp;

她問他怎麼不說愛，他說不知道怎麼說。

&nbsp;

她拿出寫好的離婚協議，他愣了，說，那我們去旅遊吧，

&nbsp;

結婚的蜜月我都沒陪你，我虧欠你太多。

&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

他們去了奇峰異石的張家界。

&nbsp;

飄雨的天氣和他們陰郁的心情一樣，

&nbsp;

走在盤旋的山道上，她發現他總是走在外側，

&nbsp;

她問他為什麼，他說路太滑，他怕外側的柵欄不牢，怕她萬一不小心跌倒。

&nbsp;

她的心忽然感到了溫暖，回家就把那份離婚協議撕掉了。

&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

很多時候，愛是埋在心底的，尤其是婚姻進行中的愛，

&nbsp;

平平淡淡，說不出來，但是真實存在。
