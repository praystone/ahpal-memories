破碎的花瓶rn&nbsp;




他和她是大學同學，他來自偏遠的農村，她來自繁華的都市。


&nbsp;

他的父親是農民，她的父親是經理。

&nbsp;

除了這些，沒有人不說他們是天生的一對，在她家人的极力反對下，他們最終還是走到了一起。

&nbsp; &nbsp;&nbsp;&nbsp;

他是定向分配的考生，畢業只能回到預定的單位。

&nbsp;

她放棄了父親找好的單位，隨他回到他所在的縣城。

&nbsp;

他在局里做著小職員，她在中學教書，過著艱辛而又平靜的生活。

&nbsp;

在物欲橫流的今天，這樣的愛情不亞于好來塢的“經典”。

&nbsp; &nbsp;&nbsp;&nbsp;

那天，很冷。她拖著重感冒的身體，在學校給落課的學生補課，

&nbsp;

她給他打過電話，讓他早點回家做飯。可當她又累又餓地回到家時，他不在，

&nbsp;

屋子里冷鍋冷灶，沒有一絲人氣，她剛要起身做飯，他回來了。

&nbsp;

她問他去哪了，他說，因為她不能回來做飯，他就出去吃了。

&nbsp;

她很傷心，含著滿眶的淚水走進了臥室。

&nbsp;

她走過茶几時，裙角刮落了茶几上的花瓶，花瓶掉在地上，碎了。

&nbsp;

半年后，她離開了縣城，回到了繁華的都市。

&nbsp;

這便是婚姻，堅強而又脆弱。如同漂亮的花瓶，放在一個合適的位置，

&nbsp;

可以經受得住歲月的風化，但是只要輕輕一碰，掉在地上，就可能會變成無數的碎片。
