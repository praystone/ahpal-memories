&nbsp;


男人回味愛情

&nbsp;

&nbsp;


初相識：她真美，如同天使。

&nbsp;

&nbsp;

&nbsp;

戀愛時：她是世界上最好的姑娘，我一定要娶她！

&nbsp;

&nbsp;

結婚 1年：我的老婆還不錯，稱得上是賢內助，只不過有些小毛病，偶爾也耍耍脾氣

結婚5 年：她開始變得越來越俗不可耐，越來越蠻不講理。

&nbsp;

&nbsp;

結婚 10年：她是世界上最醜最不近人情最不講道理的女人，當初我怎麼會娶她？

&nbsp;

&nbsp;

結婚20 年：不計較那些缺點，除去脾氣太糟糕，她還勉強可以容忍。

&nbsp;

&nbsp;

結婚30 年：有時候她也挺明白事理，挺懂感情，挺會料理生活的。

&nbsp;

&nbsp;

結婚 40年：老伴真是不錯，持家有方，在外可獨擋一面，來世一定還要娶她。

&nbsp;

&nbsp;

她去世了：我真是說不出的難過，因為我失去了世界上最好的女人。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

女人回味愛情

&nbsp;

&nbsp;

初相識 ：又笨又呆，真是十足的傻小子！

&nbsp;

&nbsp;

戀愛時 ：他太老實了，不過還挺聽話，讓人可憐，我會嫁給他嗎？

&nbsp;

&nbsp;

結婚 1年：我的他還不錯，知書達理，又會體貼人，還有一點點魅力。

&nbsp;

&nbsp;

結婚5 年：才發現他聰明絕頂，才華橫溢，超凡脫俗，非同一般。

&nbsp;

&nbsp;

結婚 10年：他是世界上最好的人，真不知道如果沒有他，我該如何生活?

&nbsp;

結婚20 年：他可以稱道可以炫耀的地方真是越來越少了，充其量只能算是個男人

&nbsp;

&nbsp;

結婚30年 ：他的毛病越來越多，懶惰，愚訥，固執，無能。

&nbsp;

&nbsp;

&nbsp;

結婚 40年：整個又呆又笨的糟老頭，下輩子說啥也不能嫁他。

&nbsp;

&nbsp;

&nbsp;

他去世了：這個死老頭子，害了我一生，撇下我就走了！
