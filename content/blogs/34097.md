幾米說：愛情最好不要順其自然----網路文章分享

&nbsp;





&nbsp;


我們總是以為，我們會找到一個自己很愛很愛的人。&nbsp;


可是當我們回首，才發覺自己曾經多麼天真。&nbsp;


假如從來沒有開始，你怎麼知道自己會不會很愛很愛那個人呢？


&nbsp;









&nbsp;


其實，很愛很愛的感覺，


是要在一起經歷了許多事情之後才會發現的


&nbsp;









&nbsp;


茫茫人海可以找到一個心愛的人，這是多麼大的福氣，


或許沒有你想像那麼好，應該也不會糟糕到哪裡，


所以要知福惜福好好珍惜，多說關懷話，少說責備話。&nbsp;


&nbsp;









&nbsp;


如果你懂得珍惜，你會發現你獲得的越來越多，


如果你一昧追求，你會發現你失去的越來越快。&nbsp;


&nbsp;









&nbsp;


愛情合理就好，不要委屈將就，不要相信完美的愛情，


其實彼此有缺點，有一種純樸的可愛就足夠了。


&nbsp;









&nbsp;


我們擁有一隻鞋子的時候，才會明白失去另一隻鞋子的滋味，


消逝的戀情總是刻骨銘心的，珍惜或放下，都是生命中必經的過程。


&nbsp;









&nbsp;


相愛的時候需要真誠，爭執的時候需要溝通，


生氣的時候需要冷靜，愉快的時候需要分享，


指責的時候需要諒解，過日子的時候需要包容。


&nbsp;









&nbsp;


一個人的生命裡，擦肩而過的人有千千萬萬，


有幾個是知音？有幾個是深愛自己的人？


愛情再堅固，也無法承受忙碌的侵蝕，


你忙得天荒地亂，你忙得忘記關心，


你忙得身心疲憊，你忙得無所適從，


但是 ------ 愛情不能等你有空才珍惜。


&nbsp;









&nbsp;


女人不要說，你沒有遇到你想遇到的人，你想嫁的人，


如果你的容貌身材姿色收入家庭條件出生沒有發生改變的話，


按照常理和規律，你就應該和現在的人在一起。&nbsp;&nbsp;


&nbsp;


&nbsp;


男人不要說，等我有了錢，等我成功了，等我有了權，


如果你的相貌身材收入家庭姿色沒有發生根本轉變的話


按照常理和規律，你就應該和現在的人在一起。


&nbsp;


&nbsp;


你現在能遇到的，能交往的，就是你可以找到的人。&nbsp;


&nbsp;


&nbsp;


所以，你不要想以後怎樣，以後是以後的事情。&nbsp;&nbsp;


&nbsp;


&nbsp;


人生不過百年，幕起幕落而已。


&nbsp;
