★放開心情看人生★

&nbsp;



&nbsp;

&nbsp;


我們人生在世，


&nbsp;

似乎時時刻刻被一種無形的東西牽動著，


&nbsp;

那就是我們的心情。


&nbsp;

平時，我們閒聊時總是會關心地問：今天心情如何啊 ?

&nbsp;

雖然只是一句普通的問候語，


&nbsp;

不僅顯示我們對人生的關切，也道出了我們對人生的珍惜，


&nbsp;

更加說明了我們對人生的那份享受與關愛。

&nbsp;

&nbsp;

人生就是這樣，


&nbsp;

不管你是如何度過或是把持什麼態度，


&nbsp;

我們都會期待著自己～能夠擁有好心情，期待著自己～

&nbsp;

能夠享受幸福快樂的人生。

&nbsp;

我們對待人生的態度不盡相同的，

&nbsp;

日常中既有認真、愉悅，也有頹喪、苦悶，


&nbsp;

都會帶給我們不同的生活感受。

&nbsp;

&nbsp;

心情的好與壞～不全然可由自己來決定，


&nbsp;

我們時常會受到外在因素與客觀條件所影響，


&nbsp;

但是我們可以積極面對～

&nbsp;

勇於追求、探索，找出最適合自己的生活方式。

&nbsp;

&nbsp;

俗話說：


&nbsp;

好也是一天，壞也是一天，哭笑也是一天，


&nbsp;

那麼我們～何不選擇愉快地度過每一天呢？

&nbsp;

&nbsp;

放開心情～看人生，


&nbsp;

你將會看到另一番風情景致，這或許不是你所想像或預料到的；


&nbsp;

它會在平淡的生活中～慢慢顯現出來，


&nbsp;

它會讓你進而從中～感受到喜樂的心情。

&nbsp;

充實自己的生活～讓你的人生飛揚起來，

&nbsp;

展開你想像的翅膀～朝著你的夢想翱翔，


&nbsp;

&nbsp;你的人生～會變得更加自在，

&nbsp;

&nbsp; 你的心情～也會變得更加愉悅！


&nbsp;
