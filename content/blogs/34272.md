努力做一個內心強大的女子！

&nbsp;

&nbsp;

&nbsp;


&nbsp;


&nbsp;


&nbsp;

&nbsp;


1、 無論做什麼，記得是為自己而做，那就毫無怨言。


&nbsp;


&nbsp;


&nbsp;


2、 面對困境，也不要悲觀厭世。


&nbsp;


&nbsp;


&nbsp;


3、 人生沒有絕對的公平，但是相對公平的。



在一個天平秤上，你得到的越多，也必須比別人承受得更多。 


&nbsp;


&nbsp;


&nbsp;


4、 在人生的任何時候都不怕重頭再來，



每一個看似低的起點，


&nbsp;


都是通往更高峰的必經之路。


&nbsp;


&nbsp;


&nbsp;


5、讓自己更平和一點，更豁達一點，




　　對於身邊的過錯，讓自己更寬容一點。



&nbsp;


人人都有他的難處，何必強求於人。


&nbsp;


&nbsp;


&nbsp;


6、作為女孩子，首先要爭取經濟獨立，



然後才有資格談爭取什麼，


&nbsp;


15到25歲，爭取讀書以及旅遊機會，


&nbsp;


25到35歲，努力工作，積極進修，


&nbsp;


組織家庭，開始儲蓄，


&nbsp;


必需活潑樂觀，不厭其煩地工作…


&nbsp;


這雙手雖小，但屬於我，


&nbsp;


作出成績來，享受成果，不知多開心… 


&nbsp;


&nbsp;


&nbsp;


7、壞事總是不斷發生，可還是有很多辦法來解決困難。



永遠不要忘記學進修學問，拓闊胸襟。


&nbsp;


人生所有煩惱的會不多不少永遠追隨，


&nbsp;


只不過學識涵養可以使一個人


&nbsp;


更加理智冷靜地分析處理這些難題而已。 


&nbsp;


&nbsp;


&nbsp;


8、失去的東西，其實從來未曾真正地屬於你，



也不必惋惜，瀟灑一點。


&nbsp;


生活中無論有什麼閃失，統統是自己的錯，與人無尤，


&nbsp;


從錯處學習改過，精益求精，直至不犯同一錯誤，


&nbsp;


從不把過失推諉到他人肩膀上去，免得失去學乖的機會。


&nbsp;


&nbsp;


&nbsp;


9、浪漫是一種自我修養，是生活的格調。



不管自己已婚未婚，什麼年齡，


&nbsp;


總要保持有一種少女般浪漫情懷。


&nbsp;


&nbsp;


&nbsp;


10、生命的樂趣是要自己尋找的，



誰也沒有義務要為你做什麼，要討好你什麼。 


&nbsp;


愛情很美好，但是，生活永遠比愛情要長，


&nbsp;


而生活，是需要智慧。樂觀，陽光，凡事往好處想。


&nbsp;


&nbsp;


&nbsp;


11、對一個城市的留戀，其實只是留戀那裡的人和事，



更多的，是沉澱在那個城市裡自己最好的年華。


&nbsp;


不管在什麼地方，生活都有喜有悲，


&nbsp;


沒有必要羨慕別人增添自己的煩惱。


&nbsp;


&nbsp;


&nbsp;


12、法國有句諺語：愛人在身旁，處處是天堂。



幸福不是因為得到的多，而是計較的少。


&nbsp;


苦苦追求沒有得到的，不懂得珍惜擁有的，


&nbsp;


結果只是徒勞傷命。


&nbsp;


&nbsp;


13、《莊子》裡有句話叫做夏蟲不可語於冰,



意思是說對於夏天的蟲子，


&nbsp;


無論你怎樣與它談論冬天的冰雪，它也不會明白。


&nbsp;


同理，當我們總是責怪別人無法理解自己的時候，


&nbsp;


請靜下心，各人有各人的思維限制，


&nbsp;


思維不同，很難一致，


&nbsp;


所以，我們都是互相眼裡的夏蟲。


&nbsp;


對生活多一點耐心，信心與堅持。不要總是半途而廢。


&nbsp;


&nbsp;


&nbsp;


14、為了夢想努力拼搏，



回頭看，你會發現那些苦難，


&nbsp;


後來成為了你人生的財富。


&nbsp;


未來掌握在自己的手中。


&nbsp;


&nbsp;


&nbsp;


15、有得有失，才是人生，切忌忿忿不平。



做人最忌無休止地自怨自艾，招人討嫌。


&nbsp;


愛自己，就如同朝陽升起。


&nbsp;


&nbsp;


&nbsp;


16、人生短短數十載，最要緊是滿足自己，不是討好他人。



何必向不值得的人證明什麼，生活得更好，乃是為你自己……


&nbsp;


&nbsp;


&nbsp;


生活得更好，乃是為你自己……
