溝通原則十五條: 


&nbsp;&nbsp;&nbsp; 一.講出來

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
尤其是坦白的講出來你內心的感受.感情.痛苦.想法和期望,但絕對不是批評.責
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 備.抱怨.攻擊;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 二.不批評.不責備.不抱怨.不攻擊.不說教&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
批評.責備.抱怨.攻擊這些都是溝通的劊子手,只會使事情惡化;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 三.互相尊重

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
只有給予對方尊重才有溝通,若對方不尊重你時,你也要適當的請求對方的尊重,
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 否則很難溝通;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 四.絕不口出惡言

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 惡言傷人,就是所謂的 [ 禍從口出 ];

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 五.不說不該說的話

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
如果說了不該說的話,往往要花費極大的代價來彌補,正是所謂的
[ 一言既出.
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 駟馬難追 ] .[ 病從口入,禍從口出
]甚至於還可能造成無可彌補的終生遺憾
&nbsp;&nbsp;&nbsp;&nbsp; 
哩!所以溝通不能夠信口雌黃.口無遮攔;但是完全不說話,有時後也會變得更惡
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 劣。

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 六.情緒中不要溝通,尤其是不能夠做決定

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
情緒中的溝通常常無好話,既理不清,也講不明;尤其在情緒中,很容易衝動而失
&nbsp;&nbsp;&nbsp;&nbsp; 
去理性;如:吵的不可開交的夫妻.反目成仇的父母子女.對峙已久的上司下屬...
&nbsp;&nbsp;&nbsp;&nbsp; 
尤其是不能夠在情緒中做出情緒性.衝動性的[決定],這很容易讓事情不可挽回,
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 令人後悔!

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 七.理性的溝通,不理性不要溝通

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
不理性只有爭執的份,不會有結果,更不可能有好結果,所以,這種溝通無濟於事;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 八.覺知

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
不只是溝通才需要覺知,一切都需要......如果自己說錯了話.做錯了事,如不想
&nbsp;&nbsp;&nbsp;&nbsp; 
造成無可彌補的傷害時,最好的辦法是什麼???(我錯了),這就是一種覺知;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 九.承認我錯了

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
承認我錯了是溝通的消毒劑,可解凍.改善與轉化溝通的問題;就一句:我錯了!勾
&nbsp;&nbsp;&nbsp;&nbsp; 
銷了多少人的新仇舊恨,化解掉多少年打不開的死結,讓人豁然開朗,放下武器,
&nbsp;&nbsp;&nbsp;&nbsp; 
重新面對自己,開始重新思考人生,甚至於我是誰??在這浩瀚的宇宙洪流裡,人最
&nbsp;&nbsp;&nbsp;&nbsp; 
在意的就是[我],如果有人不尊重我.打壓我.欺負我或侮辱我時,即使是親如父
&nbsp;&nbsp;&nbsp;&nbsp; 
子,都可能反目成仇,偏淚一點的,離家出走還算什麼,死給你看的例子都屢見不
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 鮮哩!

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十.說對不起!!

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
說對不起,不代表我真的做了什麼天大的錯誤或傷天害理的事,而是一種軟化劑,
&nbsp;&nbsp;&nbsp;&nbsp; 
使事情終有[轉圜]的餘地,甚至於還可以創造[天堂];其實有時候你也真的是大
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 錯特錯,死不認錯就是一件大錯特錯的事;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十一.讓奇蹟發生

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
如今自己願意互相認錯,就是在替自己與家人創造了天堂與奇蹟;化不可能為可
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 能...

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十二.愛

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 一切都是愛,[愛是最偉大的治療師]..

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十三.等待轉機

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
如果沒有轉機,就要等待;急只會治絲益棼;當然,不要空等待,成果就會從天下掉
&nbsp;&nbsp;&nbsp;&nbsp; 
下來,還是要你自己去努力,但是努力並不一定會有結果,或捨本逐末;但若不努
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 力時,你將什麼都沒有;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十四.耐心

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 等待唯一不可少的是耐心,有志者事竟成...

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 十五.智慧

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 智慧使人不執著,而且福至心靈

&nbsp;

&nbsp;

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 心靈妙方:

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 
*找一個良辰吉時開始,不論發生什麼事,你都要[講出來].[表示意見].[跟他溝
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 通],如此一個星期,你會有意想不到的收穫.

&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; *
找一個良辰吉時開始,不論任何人到你面前,你都要[講出來].[表示意見].[跟
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 他溝通].[關懷他],如此一個星期,你將會有奇蹟出現.
