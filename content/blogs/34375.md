學會心情的改造，比什麼都重要

&nbsp;



&nbsp;


&nbsp;

在人生的每一個過程中

&nbsp;

&nbsp;我們不知道，也無法預料

&nbsp;

何時會發生什麼樣的事，會遇見什麼樣的人

&nbsp;

有的時候，被人誤解了

&nbsp;

有的時候，被人出賣了

&nbsp;

有的時候，被人中傷了

&nbsp;

&nbsp;

在當下，那種受傷的心情，確實很痛、很苦、很難平復

&nbsp;

很想極力的解釋清楚，很想把所有的事實、真相說出

&nbsp;

但是，就怕於事無補，

&nbsp;

越想，內心越酸、越苦心情不快樂，做事不專注，精神容易恍惚

&nbsp;

不但會影響工作的情緒和態度

&nbsp;

也會影響人與人之間的相處

&nbsp;

或許，應該學習適時將心情自我放逐

&nbsp;

就用修行的角度來看待所有的一切事物
 rn&nbsp;

越是迷惘，越是困頓、無助，就越該想辦法靜下心思

&nbsp;

事情過了，要趕快讓心情平復

&nbsp;

昨日的不愉快隨著星辰消逝

&nbsp;

今早歸零，將記憶抹除，一切從新開始

&nbsp;

給他人一個台階、一個退路！就當是為自己消業、造福

&nbsp;

不要心想：『我要報復』，覺得：『自己總是被欺負』

&nbsp;

『這樣的日子好苦，宛如世界末日』

&nbsp;

『忍耐』，對自己一定有好處

&nbsp;

&nbsp;

古人有言：『傻人有傻福…』這句話，很值得你我深思

&nbsp;

很多人，總是耳根子輕

&nbsp;

所以身邊常見許多補風捉影的事情

&nbsp;

聰明的人，看人、看事不一定用耳、用眼睛

&nbsp;

察言觀色最重要的是〝用心〞

&nbsp;

有些事，眼睛看到的不一定準，耳朵聽到的也未必是真

&nbsp;

有人專門做表面，也有人擅於蜜語讒言


但是………………

&nbsp;

話說得再多、再美，聽多了，就一點也不特別

&nbsp;

反而不如一份真實的感受來得貼切

&nbsp;

名利都是虛偽，唯有心善最美

&nbsp;

虛偽的心就像汽球表面又是何苦

&nbsp;

究竟人與人之間應如何相處

&nbsp;

有人說：『吃虧就是佔便宜』，凡事何妨退一步路

&nbsp;

爭得了一時，爭不了一世，未來還有很長的路!

&nbsp;

在一個團體，一個人有功

&nbsp;

有人羨慕、有人嫉妒，有人則是真心祝福

&nbsp;

因得失而〝嫉妒〞，為爭寵而〝爭功吃醋〞

&nbsp;

這樣的工作態度，這樣的人建立於此


&nbsp;

有時候，因為一件事...

&nbsp;

可以讓你認識、了解一個人更加深入

&nbsp;

雖然你的委曲久久難消除，雖然，你該受的待遇不若你的付出

&nbsp;

雖然，有那麼多的人給你安慰、為你祝福

&nbsp;

心裡還是覺得有些忍不住

&nbsp;

有那麼一點兒酸、有那麼一點兒苦

&nbsp;

但是，人生沒有永遠的快樂，也沒有永遠的苦

&nbsp;

心境的轉變，才能使你快速的遠離痛苦

&nbsp;

過去，沒遇過這樣的人，沒發生過這樣的事

&nbsp;

現在反省、檢討、學習，一點都不遲

&nbsp;

&nbsp;

反觀未來的人生態度

&nbsp;

是積極？是消極？牽動著你我的行事

&nbsp;

不管經歷什麼難事，都不要輕易的就服輸

&nbsp;

要不畏艱難和險阻，要有勇氣、毅力去克服

&nbsp;

不過份貪圖--不屬於自己的幸福

&nbsp;

更不要老是想著--需要別人的幫助

&nbsp;

凡事靠自己，遇事先好好想清楚，要徹底領悟
