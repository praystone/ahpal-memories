十二時辰養生歌<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


&nbsp;


子時睡得足，黑眼圈不露。


&nbsp;


丑時不睡晚，臉上不長斑。


&nbsp;


寅時睡得熟，面紅精氣足。


&nbsp;


卯時大腸蠕，排毒渣滓出。


&nbsp;


辰時吃早餐，營養身體安。


&nbsp;


巳時脾經旺，造血身體壯。


&nbsp;


午時一小憩，安神養精氣。


&nbsp;


未時分清濁，飲水降虛火。


&nbsp;


申時津液足，養陰身體舒。


&nbsp;


酉時腎藏精，納華元氣清。


&nbsp;


戌時護心臟，減壓心舒暢。


&nbsp;


亥時百脈通，養身養嬌容。
