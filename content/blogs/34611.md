生命中你看重什麼？


&nbsp;



&nbsp;


有一位父親存了很久的錢，

&nbsp;

終於買了一輛雪亮的新車，他非常寶貝這部車，

&nbsp;

每天都洗車打蠟，他五歲的兒子見父親這麼愛車，

&nbsp;

也非常興奮的幫爸爸一起洗。

&nbsp;

父親有這樣一個兒子，

&nbsp;

非常滿足，深覺這個兒子很體諒為父的心。

&nbsp;

&nbsp;

&nbsp;

有一天，這位父親很累，

&nbsp;

雖然車子因為淋了雨而顯得髒，

&nbsp;

但他實在太累了，心想，改天再洗車吧！

&nbsp;

五歲的兒子見父親這麼累，就興沖沖的要幫爸爸洗車，

&nbsp;

父親見他人小志氣大，心裡更加得意，便放手讓兒子洗。

&nbsp;

小兒子要洗車，卻找不到抹布，他走進廚房，

&nbsp;

立時便想到母親平常炒完菜洗鍋子時，

&nbsp;

都是用鋼刷使勁刷才刷乾淨的，

&nbsp;

所以既然沒有抹布，就用鋼刷吧！

&nbsp;

他拿起鋼刷用力的洗起車來，

&nbsp;

一遍又一遍，像刷鍋子一樣刷車。


&nbsp;

等他洗完之後，『哇！』他大哭失聲，

&nbsp;

車子怎麼都花了？這下慘了，他急忙跑去找父親，

&nbsp;

邊哭邊說：爸爸，對不起，爸爸，.你來看！

&nbsp;

父親疑惑地跟著兒子走到車旁，

&nbsp;

他也『哇』的一聲， 

&nbsp;

我的車！我的車！這位父親氣得走進房間，

&nbsp;

他十分生氣地跪在地上禱告，

&nbsp;

上帝呀，請你告訴我，我該怎麼做？

&nbsp;

那是我新買的車，一個月不到，

&nbsp;

就變成這樣，我該怎麼處罰我的孩子？

&nbsp;

他才禱告完，在他心裡忽然出現一個聲音，

&nbsp;

『世人都是看表面，而我卻是看內心！』突然間，

&nbsp;

他像是被點醒了。他走出房門，

&nbsp;

兒子正害怕地流著淚，動也不敢動。


&nbsp;

父親急忙把孩子擁在懷裡，

&nbsp;

並且說：

&nbsp;

『謝謝你幫爸爸洗車，爸爸愛你，勝過那部車子。』

&nbsp;

親愛的朋友，生命中你看重什麼？你懂得愛嗎？
