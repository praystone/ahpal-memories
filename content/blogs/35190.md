老師的一席話(很值得一讀)<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


&nbsp;


1、一個人，如果你不逼自己一把，你根本不知道自己有多優秀。


&nbsp;


2、賺錢是一種能力，花錢是一種水準，能力可以練，水準是輕易練不出來的。


&nbsp;


3、年輕人不可以太狂。


&nbsp;


4、一個人的知識，通過學習可以得到；一個人的成長，必須通過磨練。


&nbsp;


5、這個世界*很多，可以改變命運的書很少。


&nbsp;


6、這個世界上朋友很多，可以用一生託付的朋友很少。


&nbsp;


7、如果發現一個人，一個地方，一件事，一本書，可以改變你的命運。一定要想辦法跟他發生關係，否則，他就跟你沒關係。


&nbsp;


8、當一個人沒有成功的時候，裝也裝出成功的樣子。（因為裝的時候，他已經成為你性格的一部分）


&nbsp;


9、我們學習的目的，是為了使用，不是知識沒有用，而是你沒有使用，說明你沒有用。


&nbsp;


10、別人對你的態度，決定了你的命運。


&nbsp;


11、笑由心生。


&nbsp;


12、一個人出門的時候，口袋裡都裝的錢，裝錢的目的，就是為了花出去，那裡舒服就往那裡花。一個人讓別人舒服，他就是一個經營者；別人讓你舒服，他就是一個消費者。


&nbsp;


13、一個人，敢聽真話，需要勇氣；一個人敢說真話，需要魄力。


&nbsp;


14、因為你的存在，讓別人快樂起來，你叫朋友；因為你的存在，讓別人卓越起來，你是教練；因為你的存在，讓別人強大起來，你是領導。


&nbsp;


15、一件事情，對你傷害的程度與事情本生沒有任何關係，取決於你對這件事的態度。


&nbsp;


16、你，簡單了，你的世界就簡單了；你，簡單了，事情就簡單了。


&nbsp;


17、一件事，會幹了，好好幹；不會幹了，亂幹。幹的次數多了，自然會幹，但是，首先，你要幹。


&nbsp;


18、一個人，想要優秀，你必須要接受挑戰；一個人，你想要儘快優秀，就要去尋找挑戰。


&nbsp;


19、一個人想要創業，先要學會打工。


&nbsp;


20、世界上，成功的有兩種人，一種人是傻子，一種人是瘋子。傻子是會吃虧的人，瘋子是會行動的人。
