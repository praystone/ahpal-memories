學會在等待中釋懷‏





愛情中的等待，常教人無奈，

&nbsp;

等一個懂愛的人出現在生命轉彎的地方，

&nbsp;

短則耗掉三、五年，長則花去大半生。

&nbsp;

當那個人出現之後，也未必會珍惜分秒，約會的時候，

&nbsp;

還要珊珊遲來，教人引領企盼，把秋水望穿。

&nbsp;

長久等待，令人老得快，唯一能和歲月拔河的秘方，

&nbsp;

是學會在等待中釋懷。 

&nbsp;

是的，學會在等待中釋懷，實在太愛對方了，

&nbsp;

所以能夠忍受他的遲到，等得再久，

&nbsp;

或終於沒有等到，還是無怨無悔， 

&nbsp;

無怨無悔地等待，是愛情中很高尚的情操。

&nbsp;

從等待的情緒反應中，測量愛情的溫度大街上，

&nbsp;

手裡捧著報紙或雜誌，

&nbsp;

眼光卻不時瞟向人群裡搜尋對方熟悉的身影。

&nbsp;

心裡哼唱著：「愛情真偉大。 」

&nbsp;

這是戀愛初期約會苦等對方出現時的自然現象。 

&nbsp;

熱戀時候，還是願意癡癡地等待，

&nbsp;

不過在這個時候癡心會轉化成為焦慮表現出來。 

&nbsp;

心裡十分焦急，一股腦兒往壞處想：

&nbsp;

一定是出門前被電話絆住了呢？途中發生什麼事了呢？

&nbsp;

會不會出車禍呢？

&nbsp;

等到對方終於出現了，沒有責難，只是低聲地說：

&nbsp;

「好擔心啊！哦！沒關係，只要你平安到了就好。 」

&nbsp;

什麼時候會發現熱情減退了呢？ 

&nbsp;

很簡單，吻合以下情況的，很明顯是該分手了，

&nbsp;

當你等了二十分鐘，終於不想在浪費時間，

&nbsp;

轉身離去時，連留給他一張字條也覺得多餘。

&nbsp;

心想：「我自己逛街走走吧！」

&nbsp;

口德差一點的，暗罵一句：「讓他給車撞死算了。 」

&nbsp;

這種約會，十分多餘，雙方都不該赴約的，

&nbsp;

遲到或不來，都沒什麼影響，早該分手。 

&nbsp;

不論早到或遲來，「時間」只是藉口，

&nbsp;

用來幫不相愛的彼此脫罪，經典情歌中唱著：

&nbsp;

「有很多事，你不必問，有許多人，你不必等。 」

&nbsp;

&nbsp;

不適合的對象，平白辜負了等待的美麗與意義，

&nbsp;

在愛情驛站過盡千帆的人，應該都會對等待有所體會，

&nbsp;

愛情和愛人都一樣，沒有所謂的先來後到。 

&nbsp;

真正讓人有「相識太早」、或「相見恨晚」遺憾的，

&nbsp;

並不是時間遲早的問題。

&nbsp;

關鍵多半是出在「人」自己本身，

&nbsp;

不過是拿「時間」來做藉口而已。 

&nbsp;

時間，不論早到或遲來，

&nbsp;

都可以如膺重任地幫不相愛的彼此脫罪。 

&nbsp;

婚前遇見不喜歡的人主動示愛，婉拒對方的說辭是：

&nbsp;

「我還沒有準備好。」

&nbsp;

外遇戀情中，主動決定和對方 Say Good-bye的人，

&nbsp;

常語帶遺憾地說：「只恨相見太晚。 」 

&nbsp;

早到或遲來，只是不愛的藉口，真正能維持長久的愛，

&nbsp;

是學會在等待中釋懷。

&nbsp;

用平靜的心情繼續守候，

&nbsp;

或以敏銳的智慧判斷什麼時候該離開，

&nbsp;

不要擔太多不必要的心。

&nbsp;

以分秒之差，讓相愛的雙方錯身而過，甚或釀成悲劇，

&nbsp;

畢竟機率太低，除非是像「金玉盟」那樣的電影，

&nbsp;

現實生活中不容易發生。 

&nbsp;

也不必固執地守在那裡，

&nbsp;

因為心有未甘就不顧一切地等下去，

&nbsp;

因司機而罷工的脫班公車，

&nbsp;

不會只為了你老老實實等在那裡，

&nbsp;

就會乖乖地準時開過來。

&nbsp;

通往幸福終站的車班，不會只有一條路線，

&nbsp;

也許時候到了，你就得當機立斷，

&nbsp;

換個路口改搭另一條路線的車子，

&nbsp;

就算最後車子不來，你還是可以決定自己步行前往。 

&nbsp;

當你等了半天、或半輩子的人沒有出現，

&nbsp;

其實不用過於擔心，也不用為他焦慮。

&nbsp;

你該做的是：悠閒地喝杯咖啡，休息一下，

&nbsp;

把自己打點好，隨時保持從容不迫的鎮定，

&nbsp;

以便於以優雅的姿勢，和愛情相遇。 

&nbsp;

我想人應該在情感的路上多一點勇氣，

&nbsp;

喜歡就該讓對方知道， 不論對方接受與否，

&nbsp;

至少不會讓自己生命中留有遺憾， 

&nbsp;

說不定對方也喜歡你，只不過不敢表達罷了。 

&nbsp;

若有幸遇上彼此心怡的人，那就更應該好好把握與珍惜，

&nbsp;

不要被一些外在因素所影響，該好好面對自己的心，

&nbsp;

堅持當初的選擇，不要輕易放棄。
