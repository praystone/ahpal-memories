『老』是一項恩賜

 rn&nbsp;


&nbsp;


（文：E-mail）


老，其實是一項恩賜！


不怕！但是要注意活得健康快樂！


&nbsp;


&nbsp;


&nbsp;


我這輩子從來沒像現在這樣那麼滿意自己。


當然，我不是指身材。


有時候我的身材還真讓我氣餒，


皺紋、眼袋、臀部下垂。


&nbsp;


&nbsp;


&nbsp;


鏡中的「老人」常常把我打敗，


她看起來還真像我媽。


&nbsp;


&nbsp;


&nbsp;


但，這些已經很久沒有困擾我了。


&nbsp;


&nbsp;


&nbsp;


我絕不會只為了要讓自己頭髮少白一點，


或是肚子平坦一點，而拿我現在的生活來交換。


&nbsp;


&nbsp;


&nbsp;


我那些死黨真有趣、


我的生活太美妙、我的家庭好甜蜜。


&nbsp;


&nbsp;


&nbsp;


年紀越大，我對自己也越來越寬容，


不再那麼跟自己過不去；


我，跟自己做了朋友。


&nbsp;


&nbsp;


&nbsp;


我不再感到自責，


只因為多吃了一塊餅乾、早晨起床沒疊被、


或是買了一個看起來很酷可是


根本用不著的家飾品。


&nbsp;


&nbsp;


&nbsp;


我有足夠資格善待自己、縱容自己、


或是偶而地揮霍一下。


&nbsp;


&nbsp;


&nbsp;


這個伴隨年齡而來的特權，


太多人還沒來得及享用，就已經離開了人世。


&nbsp;


&nbsp;


&nbsp;


就算我現在看書或者玩電腦玩到清晨，


然後一覺睡到中午，又與人何干？



&nbsp; rn&nbsp;


&nbsp;


我可以跟著老歌自顧自地跳舞，


想起年輕時逝去的戀情而掉下淚來，


也不覺得難為情。


&nbsp;


&nbsp;


&nbsp;


我可以在臃腫的身軀上套件泳衣，


縱情戲水，


而不在意那些帥哥辣妹的憐憫眼神。


終有一天他們也會變老。


&nbsp;


&nbsp;


&nbsp;


我知道偶而我會記不住事情。


但是，生命中有些事還是忘了好。


&nbsp;


&nbsp;


&nbsp;


反正重要的事，我會記得。


&nbsp;


&nbsp;


&nbsp;


當然，這些年來我也曾多次心碎過。


&nbsp;


&nbsp;


&nbsp;


當你失去至愛、看到小朋友受虐、


或甚至看到某人的愛犬發生車禍，


怎麼可能不難過？


&nbsp;


&nbsp;


&nbsp;


但傷心難過卻正好讓我們鍛鍊心智、


變得堅強、懂得體諒和同情他人。


&nbsp;


&nbsp;


&nbsp;


從來沒有受傷過的心，


就像呆在無菌室中，


無法感受「不完美」的美好。


&nbsp;


&nbsp;


&nbsp;


我覺得自己還真幸運，


能活得老到足以讓頭髮變白，


讓笑容變成刻在臉上的皺紋。


太多人沒有這樣的機會。


&nbsp;


&nbsp;


&nbsp;


年紀越大，看待事物也越正面。


不那麼在意別人怎麼想、不再質疑自己、


甚至認清世間沒有絕對的對錯。


&nbsp;


&nbsp;


&nbsp;


總之，我還蠻喜歡變老的。


它讓我覺得隨心所欲、自由自在。


&nbsp;


&nbsp;


&nbsp;


終有一天我會離開人世，


但只要我活著，


我絕不悔恨過去，憂煩未來。


&nbsp;


&nbsp;


&nbsp;


還有，


只要我高興，我每天都會吃我的飯後甜點。
