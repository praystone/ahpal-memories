夢影


&nbsp;


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />




&nbsp;


&nbsp;


風吹過來的寒冷


已凍不了我疼痛的心


空氣中的呼吸參雜我的淚水


和你(妳)分手的心情難道錯了嗎


逞強地跟你(妳)提出分手的話語


感覺現在心情開始沈悶


無論在夢裡或是在呼吸時


在自己的身體肌膚裡


都充滿著你(妳)


&nbsp;


&nbsp;




&nbsp;


你(妳)在那裡 &nbsp;你(妳)在那裡


懂不懂我在思念著你(妳)


你(妳)在那裡&nbsp; 你(妳)在那裡


不管再怎麼去尋找


也無法挽回你(妳)


&nbsp;


你(妳)在那裡&nbsp; 你(妳)在那裡


對不起　對不起


我太幼稚了 &nbsp;太矛盾了


如果是現在的話


你(妳)可不可以能夠原諒我


&nbsp;


&nbsp;&nbsp;


&nbsp;


你(妳)在那裡&nbsp; 你(妳)在那裡


對不起 &nbsp;對不起


能夠遇見你(妳)真的很好


我真心誠意的希望你(妳)幸福


&nbsp;


相信嗎　相信嗎


我是如此地喜歡你(妳)


永遠都不會忘記


真的&nbsp; 真的


永遠都在我的心裡&nbsp; 腦海裡


&nbsp;




&nbsp;


&nbsp;


我記得


無論是你(妳)的臉 &nbsp;你(妳)的聲音


你(妳)的溫柔 &nbsp;你(妳)的體貼


我全部 &nbsp;全部都還記得


你(妳)在那裡　你(妳)在那裡


不管再怎麼尋找你(妳)


也無法挽回你(妳)


只有在夢裡才能再次夢見你(妳)


夢見你(妳)的影
