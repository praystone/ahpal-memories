&nbsp;

&nbsp;

一個男子很有錢，要娶媳婦，他有一位很窮的親戚，

&nbsp;

實在不願發帖給他，但於禮不合，所以還是發了張帖子， 

&nbsp;

上頭附註 :

&nbsp;

如果你來，表示你貪吃．

&nbsp;

如果不來，表示你小氣．


這位富翁便要看他來不來．


婚禮當天，看見這位窮親戚，窮親戚看到他，

&nbsp;

便將包禮的紅包給他，就進去吃大餐，富翁將禮打開，

&nbsp;

發現裡面只有一塊錢，還附了張紙條，寫道 :

&nbsp;

如果你收，表示你貪財．

&nbsp;

如果不收，表示你嫌少 ．

&nbsp;
