很多人感情不如意的真正根源！（照做會立杆見影！）<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


物件，物件，相對之象，就是對沖我；


&nbsp;


&nbsp; &nbsp;&nbsp;&nbsp;父母，長輩，上司是什麼呢？
父母生我，所以是生助我；長輩，上司，長生幼，也是生助我；


&nbsp;


&nbsp; &nbsp; 沒有父母師長生助你，對象來和你較量，你就要受欺負。
不知道大家相信嗎，所以想要姻緣好，第一個就是不要再抵觸頂撞父母師長，讓父母師長來生助你，這樣感情就欺負不了你。大家可以觀察下周圍是不是這個樣子？


&nbsp;


&nbsp; &nbsp; 你小時候言行割傷了父母師長的心，成長過程中就要被最心愛的人割傷心靈，承受情苦的煎熬。你越是高聲大氣，不耐煩，抵觸父母長輩，就越是遇到地獄般痛苦的感情。你對父母的每一分惡氣，惡話，都會由你最心愛的人百倍割傷還給你。直到盡，這個人就不會再折磨你了。沒有物件的，你自己所受的煎熬還夠頂撞父母了，對象也到來了。
&nbsp; &nbsp; 你想要貴，你就不能輕賤其他人；你想要富，你就不能生氣怨恨，不能言行讓其他人生氣怨恨；不順親長，考公務員沒份，工作又差又不順。你工作不順，問題百出，必定是因為你從小抵觸頂撞父母師長，現在都還沒有改；你受情苦煎熬，也必定是因為你從小抵觸頂撞父母師長，現在都還沒有改；在五行上父母師長是生助我的。孝順父母師長，不抵觸頂撞嗔恨父母師長，才能濟養自己，才能在姻緣，工作上順利——自己受生助，才能強大。


&nbsp;


&nbsp; &nbsp; 畢恭畢敬的對父母，讓父母高興喜悅，有一點好東西，都要拿來供養父母。說句大家不愛聽的話，不管一個人怎樣說自己的心地孝順，一個人不供養父母，他這個窮字非常大的寫在臉上。
大家可以觀察下是不是這個樣子？
&nbsp; &nbsp; 平時要拿出財物供養父母，不要抱那麼緊，不要找藉口說老婆孩子房子需要錢，你這個樣子，以後你老了，你孩子一樣不會供養你，連藉口都和你一樣，這叫：父形子肖。



&nbsp; &nbsp;&nbsp;&nbsp;中國人有句罵人的詞語——“賤骨頭”。這是因為一個人的貴賤，是受人尊敬，還是受人輕辱，是骨相決定的。抵觸頂撞父母，正是毀壞自己骨相的。我一般看到骨相不好的人，我都心裏對他說：回家不要抵觸頂撞父母了。
&nbsp; &nbsp; 這是古人說的“骨相定貴賤”。
&nbsp; &nbsp; 我們身上五臟之中，什麼對應骨呢？
&nbsp; &nbsp; 腎主骨（我們說骨氣骨氣，所以腎的神表達出來就是志向）。
&nbsp; &nbsp; 大家都知道，腎五行屬水，水的性質是什麼？——至柔。
&nbsp; &nbsp; 柔軟隨順眾生, 沒有尖銳的棱角去割傷他人。
&nbsp; &nbsp; 很多人身上都旋繞著戾氣, 有這個戾氣, 命運就不會通達，事與願違。戾得大事小事就是不順,別人來做就是順, 你來做就問題百出, 非常不順。並且戾氣是傷害身家性命的, 就像一把白刃, 不但會傷自己, 還會傷到至親, 乃至一切靠近自己的人. 

&nbsp; &nbsp; 大家知道怎樣消戾氣嗎? 

&nbsp; &nbsp; 戾就是逆. 逆的反義詞就是順. 所以要消掉戾氣, 必須要從順父母, 敬先賢, 尊上司, 敬長輩, 禮平輩開始。
&nbsp; &nbsp; 如果一個人不順親長, 他身上的戾氣, 永遠消不掉。
如果一個人肯真正順父母, 順上司, 順先賢長輩,他的戾氣就能很快滅除乾淨。沒有戾氣, 做事就沒有阻礙。
&nbsp; &nbsp; 自己以後也是要生baby的, 如果你的baby從小就抵觸頂撞嗔恨你, 耍脾氣不理睬你, 你難過不難過? 

&nbsp; &nbsp; 有這樣的baby, 自己的每一天都容易生嗔心, 煩躁, 心裏哪有順意呢? 如果不悔改, 繼續抵觸頂撞父母, 你生活中的各種工作，姻緣，辦事上的痛苦會一直持續. 還會有一個抵觸頂撞你, 高聲大氣吼著和你說話的baby, 他成長的三十年, 你會快樂嗎? 

&nbsp; &nbsp; 但是只要你從此柔順的對待父母, 好話哄著父母開心, 幽默一點, 柔軟一點, 高興一點, 那麼你將來的baby從小就很愛你, 每天都是你的開心果, 你看到baby都開開心心, 煩惱走光光。
