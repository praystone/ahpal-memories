『人』字只有兩撇<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />



一撇一捺&nbsp; 卻不好寫


&nbsp;


從書法角度講


&nbsp;


字的筆劃愈少&nbsp; 想寫好愈不容易


&nbsp;


從社會學角度講


&nbsp;


『人』字這兩筆&nbsp; 內涵豐富&nbsp; 哲理深邃&nbsp; 想寫好更難


&nbsp;


這兩筆有一筆沒寫好


&nbsp;


便不能稱之為&nbsp; 真正意義上完整的人生



一筆寫出生時那哇哇哭聲

一筆寫臨終時那欣慰的笑容





人生在世不過短短幾十年


&nbsp;



生時&nbsp; 自我的哭聲是向他人證明了我們生的艱辛


&nbsp;


&nbsp;


他人的笑&nbsp; 是迎接我們的到來




死時自我的笑是表白了平生了無憾事


&nbsp;


他人的哭&nbsp; 說明我們一生為他人奉獻過&nbsp; 付出過


&nbsp;


從而贏得了他人的不捨


&nbsp;




人生就是一個新陳代謝的過程　包括思想和身體



新的不斷滋生&nbsp; 舊的不斷淘汰&nbsp; 人只有不斷接受



吸納新生事物&nbsp; 才能推陳出新&nbsp; 健康成長


&nbsp;


&nbsp;



一筆寫前進&nbsp; 一筆寫後退




人生如登山&nbsp; 一步一步往山頂攀登



到了山頂&nbsp; 又一步一步往下退


&nbsp;


下山往往比上山還要難



百折不撓&nbsp; 不畏艱險&nbsp; 勇於攀登人固然可敬



而到了頂峰 不戀高位&nbsp; 急流勇退



能上能下 寵辱不驚的人 更難能可貴


&nbsp;



一筆寫快樂&nbsp; 一筆寫煩惱




快樂和煩惱是人生騰飛的兩翼



相伴而生&nbsp; 形影相隨



快樂和煩惱&nbsp; 幸福與痛苦&nbsp; 高興與憂傷



都是相比較而存在&nbsp; 相激勵而前進的



經過煩惱&nbsp; 痛苦和憂傷的洗禮



才感到人生的快樂和幸福



快樂和煩惱&nbsp; 是奔向人生的一對車輪



【哪裡有快樂&nbsp; 哪裡就有煩惱】


&nbsp;


&nbsp;


&nbsp;


&nbsp;



一筆寫順境&nbsp; 一筆寫逆境




順境是浪潮起時的喧嘩&nbsp; 逆境是浪潮落時的歎息



人生有順境&nbsp; 也有逆境&nbsp; 甚至逆境多於順境



面對困難和挫折&nbsp; 不能只是一味地抱怨 沉淪和絕望



逆境雖能影響&nbsp; 但不會控制你的命運



只有你對生存和生活的態度及表現


&nbsp;


才能決定你的成功或失敗


&nbsp;



一筆寫付出&nbsp; 一筆寫收穫




人總是活在得失之間&nbsp; 魚和熊掌不可兼得


&nbsp;


我們就要擁有那種『得不以喜&nbsp; 失不以憂』的情懷


&nbsp;


想想生命的可貴&nbsp; 你就會明白


&nbsp;


人生最美的是奮鬥的過程&nbsp; 計較得失只會自尋煩惱


&nbsp;



一筆寫道德&nbsp; 一筆寫才能




有的人仍活著&nbsp; 但它已經死了


&nbsp;


有的人死了&nbsp; 但他還在活著


&nbsp;


指的就是人之德&nbsp;&nbsp; 德才是人字的一撇一捺


&nbsp;


沒有【德】這一撇&nbsp; 不成其人


&nbsp;


沒有【才】那一捺&nbsp; 人難自立


&nbsp;



一筆寫權利&nbsp; 一筆寫責任




每個人都有做人的權利


&nbsp;


同時又肩負做人的責任


&nbsp;


沒有沒權利的責任&nbsp; 也沒有沒責任的權利


&nbsp;


放棄自己的權利的人


&nbsp;


專看別人的眼色行事&nbsp; 專為別人的喜惡而活


&nbsp;


就淪落為奴才


&nbsp;


不承擔責任&nbsp; 不履行義務的人


&nbsp;


只知道享受生活&nbsp; 不願意創造生活


&nbsp;


只盼人人為我&nbsp; 不願意我為人人


&nbsp;


坐享其成就墮落為寄生蟲


&nbsp;


人的雙肩


&nbsp;


就是一肩挑權利　一肩挑責任


&nbsp;


而走完人生旅途


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


一筆寫自己&nbsp; 一筆寫愛人




夫妻如同左右手&nbsp; 左手提東西累了


&nbsp;


不用開口&nbsp; 右手就為接過來


&nbsp;


右手受了傷&nbsp; 也不用呼喊或請求


&nbsp;


左手就會伸過來


&nbsp;


相濡以沫&nbsp; 你扶我牽&nbsp; 互幫互助


&nbsp;


夫妻又如一雙筷子&nbsp; 什麼時候都要齊心同力


&nbsp;


酸甜苦辣　一起品嚐　櫛風沐雨&nbsp; 共度人生


&nbsp;


夫妻正如『人』字


&nbsp;


一撇一捺&nbsp; 倆人合作&nbsp; 才能頂天立地


&nbsp;



一筆寫朋友&nbsp; 一筆寫對手




人是社會的人


&nbsp;


任何一個人都不能離開他人而獨立生存


&nbsp;


但每個人的成長都離不開朋友


&nbsp;


多個朋友多條路


&nbsp;


朋友是你在愁風苦雨中行走時&nbsp; 飄過來的一把傘


&nbsp;


朋友是你在黑暗中摸索前進時&nbsp; 遞過來的一支火把


&nbsp;


朋友是你在坎坷旅途中跌倒時&nbsp; 扶你一把的那個人




&nbsp;


人的成長離不開對手&nbsp; 有個對手不落後


&nbsp;


對手　是成功者的陪練


&nbsp;


體育場上的最高記錄往往就是在與對手較勁時創下的


&nbsp;


&nbsp;



一筆寫前半生　一筆寫後半生


&nbsp;




前半生長根、發芽、開花


&nbsp;


後半生結果、收穫、儲藏


&nbsp;


有的人前半生窮困潦倒　後半生飛黃騰達


&nbsp;


有的人前半生求索無路　後半生功成名就



有的人前半生燦爛輝煌　後半生暗淡無光



有的人前半生桂冠顯要　後半生晚節不保


&nbsp;


人生道路雖然漫長



但決定其“身後名”的人生歷程

往往是最後幾步


&nbsp;


無論過去多成功　多燦爛


&nbsp;


都不能代表未來


&nbsp;


只有不停地耕耘　不停地砥礪


&nbsp;


不停地鞭策　不停地學習


&nbsp;


才能把『人』字的後一筆寫得更加壯麗


&nbsp;


&nbsp;



一筆寫『真我』　一筆寫『假我』




『人』字兩筆


&nbsp;


一陰一陽


&nbsp;


一撇為真我之靈性


&nbsp;


一捺為假我之色身


&nbsp;


人生轉眼白頭


&nbsp;


這一生是為『真我』或『假我』而活


&nbsp;
