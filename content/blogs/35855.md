&nbsp;

人的一生有多少選擇

&nbsp;



&nbsp;

&nbsp;


人的一生

&nbsp;

選對老師，智慧一生；選對伴侶，幸福一生；選對環境，

&nbsp;

快樂一生；選對朋友，甜蜜一生；選對行業，成就一生。


&nbsp;

面 對..

&nbsp;

面對玫瑰，不必浪漫；面對美女，不必多看；

&nbsp;

面對朋友，粗茶淡飯；面對家庭，

&nbsp;

出力流汗；面對老婆，朝夕相伴。

&nbsp;

&nbsp;

人之相惜

&nbsp;

人之相惜惜於品，人之相敬敬於德，人之相交交於情，

&nbsp;

人之相擁擁於禮，人之相信信於誠，人之相伴伴於愛。

&nbsp;

&nbsp;

之 最

&nbsp;

健康是最佳的禮物，知足是最大的財富，

&nbsp;

善良是最好的品德，關心是最真摯的問候，

&nbsp;

牽掛是最無私的思念，祝福是最美好的話語！

&nbsp;

&nbsp;

路和樹

&nbsp;

愛人是路，朋友是樹；人生只有一條路，

&nbsp;

一條路上多棵樹；有錢的時候莫忘路，缺錢的時候靠靠樹；

&nbsp;

幸福的時候別迷路，休息的時候澆澆樹。

&nbsp;

&nbsp;

人 啊

&nbsp;

都說金錢是惡源，都想撈；都說美女是禍水，都想沾；

&nbsp;

都說高處不勝寒，都想爬；都說煙酒傷身體，都不捨；

&nbsp;

都說天堂最美好，都不去！

&nbsp;

&nbsp;

如何品味人生

&nbsp;

人生的確很累，看你如何品味，每天多尋歡樂，

&nbsp;

煩惱別去理會，短短數十寒暑，何不瀟灑面對，

&nbsp;

朋友經常聯繫，別管電話太費，

&nbsp;

閒時發個資訊，伴你開心開胃。

&nbsp;

&nbsp;

人 這一輩子

&nbsp;

人這一輩子，怎麼都是過，與其皺眉頭，不如偷著樂。

&nbsp;

冬天別嫌冷，夏天別嫌熱，

&nbsp;

有錢別裝窮，沒錢別擺闊，閒暇養養身，

&nbsp;

每日找找樂，苦辣酸甜都嘗過，才算沒白活！

&nbsp;

&nbsp;

福

&nbsp;

人生多有福，想開就知足。

&nbsp;

思量愚昧苦，聰明就是福。

&nbsp;

思量饑寒苦，飽暖就是福。思量勞累苦，清閒就是福。

&nbsp;

思量孤獨苦，友多就是福。福祿系於心，心正得大富！

&nbsp;

&nbsp;

生活中…

&nbsp;

生活中要用大海的胸懷面對，用科學的方法支配，

&nbsp;

用皇帝的禦膳養胃，用清新的空氣洗肺，

&nbsp;

用燦爛的陽光曬被，像懶貓一樣安睡。

&nbsp;

&nbsp;

平安就好

&nbsp;

錢多錢少，常有就好；人醜人俊，順眼就好；

&nbsp;

人老人少，健康就好；家窮家富，和氣就好；

&nbsp;

誰對誰錯，理解就好；人的一生，平安就好。

&nbsp;

&nbsp;

知 音

&nbsp;

茶——苦而後甘，令人回味；

&nbsp;

酒——綿而後勁，叫人道爽；

&nbsp;

泉——清而味淡，卻用一生來品出甜。

&nbsp;

一個知音，如茶、如酒、如泉，讓人受益一生。

&nbsp;

&nbsp;

會生活

&nbsp;

多歇歇別太累，到時吃按點睡。看上就買甭嫌貴，

&nbsp;

決不和環境來作對。得空與友聚聚會，

&nbsp;

既有清醒也有醉。能掙錢會消費，生活才算有滋味。

&nbsp;

&nbsp;

或……或

&nbsp;

或淡或雅，花總在綻放；或盈或缺，月總在天上；

&nbsp;

或高興或痛苦，日子總是在過；或期盼或失望，

&nbsp;

希望總在眼前；或見或不見，朋友永在心間。

&nbsp;

&nbsp;

忘卻塵世的累

&nbsp;

以粗茶淡飯養養胃，用清新空氣洗洗肺，

&nbsp;

讓燦爛陽光曬曬背，找群朋友喝個小醉，

&nbsp;

像貓咪那樣睡一睡，忘卻輾轉塵世的累。

&nbsp;

&nbsp;

情字了得

&nbsp;

世上最難斷的是感情，最難求的是愛情，

&nbsp;

最難還的是人情，最難得的是友情，最難分的是親情，

&nbsp;

最難找的是真情，最難受的是無情，

&nbsp;

最可愛的是你微笑的表情！

&nbsp;

&nbsp;

懂 得

&nbsp;

懂得喝酒的人，找到感覺；

&nbsp;

懂得知足的人，找到快樂；懂得放下的人，找到自由；

&nbsp;

懂得珍惜的人，找到幸福；懂得關懷的人，找到朋友。

&nbsp;

&nbsp;

養 氣

&nbsp;

多讀書養才氣，慎言行養清氣，

&nbsp;

重情義養人氣，能忍辱養志氣，溫處事養和氣，

&nbsp;

講責任養賢氣，系蒼生養底氣，淡名利養正氣，

&nbsp;

不媚俗養骨氣，敢作為養浩氣，會寬容養大氣。


&nbsp;

養生四要素

&nbsp;

善良是心理養生營養素，寬容是心理養生調節閥，

&nbsp;

樂觀是心理養生不老丹，淡泊是心理養生免疫劑。
