別用眼淚感動愛情〖轉貼〗<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


愛情是一種雙向性的情感交流， 
是兩情相悅， 
是一種靈魂與靈魂碰撞的火花。 


&nbsp;


如果兩個人相愛， 
是不需要刻意的改變自己去取悅對方的。 
如果他不喜歡你， 
你怎麼刻意的去追求也都是沒有用的。


&nbsp;


真的相互喜歡的話， 喜歡還來不及， 
用得著不顧一切的去取悅麼？ 


&nbsp;




&nbsp;


&nbsp;


就算你用真誠打動了他， 
這樣得到的感情未免有點兒勉強， 
他當初不那麼接受你， 
一定是你有些條件不那麼符合他心目中的要求。


&nbsp;


被你一時的行動所感動， 
可時間長了，如果他遇到心目中理想的人， 
就難保證他不變心了。 


&nbsp;


可經常有人這樣說：&nbsp;
“ 放棄他，我活不下去，我很愛他！” 
其實這樣的想法很可笑，&nbsp;
生活中，誰沒有了誰就不能活了呢？ 
沒有了誰地球就不能轉了呢？ 



除非你自己真的不想活了， 
否則誰也擋不了你生活的路。 
通常我們以為“唯一”的東西其實都不是真的， 
只是我們沒有用心的去尋找而已。 


&nbsp;


真正的愛情源於彼此發自內心的傾慕， 
建立在兩情相悅的基礎上。 



任何只顧瘋狂的去愛別人而不顧自己有否被愛， 
或著只顧索取而不知真心付出的人都不會有好的結局。


&nbsp;




&nbsp;


一個人一生中會遇到多少的有緣無份的呢愛你的，


你愛的，都一一擦肩而過，


可是這裡最讓你記憶最深的只有初戀，


體會到愛情初次的甜蜜 ，深深烙在心里。


&nbsp;




以至於以後的朋友條件都依TA而尋，


或許你的信箱裡現在還保存著當年的情書，


一字一句都讓你難以忘記 。


&nbsp;


沒有辦法繼續愛情的時候只能轉成親情 
現在再見到TA的時候，不會再有當時的衝動 ；
一種手心手背的感覺 。


&nbsp;


得到了的不珍惜得不到的是最好的人往往都是這樣，得到了的不珍惜 
追求一個人很久的時間未能得到感覺TA的神秘，


看不到他糗的時候，


心里永遠都是完美的形象所以備感珍惜，珍貴 ！


&nbsp;


得到的呢？ 
經過甜蜜的熱戀，


從完美的形象期過渡到平凡從陌生到熟悉，


甚至身上有幾顆痣都說長相守，


卻不能理解其含義愛情珍貴的不是熱戀，


而是能接受平淡的生活。 


&nbsp;


女人會愛男人百分百，


而男人卻總會留有空間的去愛；


當有一天男人對女人說：


你要留百分之三十愛自己；女人哭了，


因為這句話太晚了，早已付出百分百。 


&nbsp;


就算愛情沒了， 
生活也一樣在繼續， 
幸福永運在將來， 
可命運或許在你手中操控 。


&nbsp;


愛是種責任 ，而不是感覺； 
請不要輕易言愛！ 
承諾，對未來的諾言， 
那麼，請不要承諾； 
快樂與傷悲成正比。 


&nbsp;


每一個愛情都創造著一種神話，愛情就是神話一般的。
