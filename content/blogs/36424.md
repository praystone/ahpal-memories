心機指數 

熱鬧的年節剛過，在這個中國人一年一度的大日子裡，你認為最有年節象徵意義的會是以下那一種活動？ 
A貼春聯 


B拜年 


&nbsp;

C討紅包 


D團圓飯

‧ 選擇A的人 

你對於用計去設計別人，其實是有點不屑的，因為你覺得這不夠光 明磊落，你要依靠你的實力來取勝，而不想拿出見不得人的小動作， 
你有你的理想堅持，但是可不是人人都是如此想，因此你常常被敵手從後面放冷箭，因此亂箭穿心，卻又無可奈何，因為你耍不出報復手段。工於心計指數15％。 
&nbsp;

&nbsp;

&nbsp;

‧ 選擇B的人 

說起來你工於心計方法，其實有點不夠高明，因為你思慮的方式並不是粉切合實際，總是太天馬行空，實行可能性低，再加上你太過緊 張的毛病，若是勉強披掛上陣，說實在的，粉快就被其他人發現你的 心計所在，想要成功\達陣，困難度是粉高的啦。工於心計指數35％。 
&nbsp;

&nbsp;

&nbsp;

‧ 選擇C的人 

你是不是工於心計的人，這其實粉難定論，因為你的確有這樣的頭腦，可以去設計周密的計劃，但是問題是在於你不是粉能狠得下心腸，所以常常你是計劃在握，可是卻因為思慮太多，而無法行動；要不然就是推行到一半，就因為心太軟，而無法作到最後一步，給予最後 
一擊，所以工於心計指數只有50％。 
&nbsp;

&nbsp;

&nbsp;

‧ 選擇D的人 

你認為人際相處，就是需要雙方合作，但是當對方製造了溝通障礙 ， 你又會想辦法處理對方，你認為使用心計是不得已的作法，但是必要時，你也不惜使用計策，而且還要用得狠，命中要害，達到你的目地。不過因為你表面都是笑瞇瞇的，會讓別人覺得你是個有點可怕的懷柔份子。工於心計指數87％。

‧ 選擇Ａ的人 

你會在表面上看到的地方下功夫，不太注重其他小節，只要大體上覺得很整齊、還算得體，那就足夠了，其他的小物件就可以盡量往衣櫃、抽屜或床底下亂塞。所以基本上，剛與你接觸的人，都會認為你外表看起來乾乾淨淨的，好像是個生活嚴謹的人。等到相處一段時日，才會發現，你的家還是帶有一些「人味」。你的潔癖指數是７６％。 


&nbsp;

&nbsp;

‧ 選擇Ｂ的人 

你希望自己不管是在人前人後，都能表現出高雅的氣質。所以，你的眼中容不下自己犯一點過錯，只要看到哪兒沾上一點污漬，你的心中就會覺得很不舒服，一定要立刻除去。無論是衣著打扮，或是學校辦公室的座位附近，你都會詳加注意，隨時檢視有沒有變得紊亂，在這樣嚴苛的要求下，潔癖指數高９８％，把最高分送給你，應該沒有人會有任何異議。

&nbsp;

&nbsp;

&nbsp;

‧ 選擇Ｃ的人 
你偏好在活潑的環境中工作，那會使你的創意源源不絕迸現。因為要保持熱鬧的氣氛，你的生活周邊自然就會塞滿了東西，常常要拿出來賞玩、參考，或是做為刺激靈感之用。因此，你的環境會稍微亂了些，可是每一件物品都有其價值，每一種擺設方式也都有你自個兒的邏輯，所以在你看來，可說是擺放得恰如其份。這種亂中有序的潔癖 
指數可得６６％，算是常人標準了。 


&nbsp;

&nbsp;

‧ 選擇Ｄ的人 

你的審美觀與別人很不一樣，有自己獨到的看法。你不在乎其他人是怎麼想的，認為只要能夠讓自己過得舒適，任何安排都是最合宜的 。你注重個人的生活品質，選購的物品都很有質感，家中很少出現會破壞品味的「垃圾」，即使你的生活方式很另類，整體看來還是相潔淨，也很有個性，你的潔癖指數８３％。

流言殺傷力 
在旅遊風氣興盛，有空閒大家就會搭飛機出去走走。旅遊文學也 
隨著這股風潮開始熱了起來，玩夠了再寫文章來賺稿費，是挺不錯的計劃。你最嚮往到什麼樣的地方去生活一個月，為當地作傳世記錄？ 
Ａ文化古國 


Ｂ鄉村小鎮 


Ｃ現代都會 


&nbsp;

Ｄ原始叢林

‧ 選擇Ａ的人 

你雖然會受謠言影響，短時間陷入情緒不穩的狀態中，需要一個人獨處療傷。可是不消多久的時間，你就會自然痊癒，這一點小事情不會將你擊倒。因為生活有其他更重要的事情，會分散掉你的注意力，而那些沒有依據的謠言，也會隨著時間流逝。之於你來說，那些事情好像從沒發生過，如同船過水無痕。 


&nbsp;

&nbsp;

‧ 選擇Ｂ的人 

你討厭被別人誤解，若是有一天聽到與自己相關的不實傳聞，你會十分氣憤，將這件事掛在心上。但你的個性溫和，不愛與別人起衝突，你也不希望自己的解釋，反而讓事情越描越黑，所以多數時候，你會將一股怨氣吞下。心事悶得久了，可能會醞釀出一種殺傷力極強的酵素，漫漫銷蝕你對於其他人的信任。 
&nbsp;

&nbsp;

&nbsp;

‧ 選擇Ｃ的人 

你能夠在各種環境中適應得很好，因為不管遇到的問題多麼棘手，你都能處之泰然，找到適當的方法來應付。說你具有流言免疫力，一點也不為過。看遍了各種光怪陸離的現象，要嚇唬你還挺不容易的，因為你老早就已經練就了金鋼不壞之身。那些有趣的八卦謠言，都只是你茶餘飯後的談笑題材。 
&nbsp;

&nbsp;

&nbsp;

‧ 選擇Ｄ的人 

你是個以自我為中心的人，凡事只要自己確認做得沒錯，問心無愧，你就不會在意別人怎麼說。甚至於對一些有心混淆視聽的人，你相當看不順眼，除了不予理會之外，有時還故意在對方面前大搖大擺的，絲毫不受讒言影響。你相信清者自清，濁者自濁，謠言總有澄清的 一天，根本不必擔心那麼多。
