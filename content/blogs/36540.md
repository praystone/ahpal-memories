我，每天早上起床之後，就去浴室洗臉，刷牙。


在牆壁上掛著一條別人的毛巾，，。 我覺得，為什麼這條毛巾，每天早上看到都是濕濕的呢???


&nbsp;


今天的疑問是從這裡開始的。就是，從這條濕毛巾就可以看到日本人跟台灣人的洗臉方式的習慣差異。


&nbsp;


&nbsp;


我剛開始跟公公婆婆一起同居的時候，我一直覺得莫名其妙，他們早上又沒有洗澡，他們的毛巾怎


&nbsp;


麼濕答答的掛在那裏?


&nbsp;


我問我先生說;[為什麼他們的毛巾每天都是濕濕的掛在那裏?]


先生回答;[因為他們用濕毛巾擦臉的~~台灣人洗臉都是這樣子~~]


&nbsp;


&nbsp;


原來如此!&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 台灣人的習慣是先把毛巾弄濕 ，然後直接擦臉!


&nbsp;


那，日本沒有這樣的習慣，日本人的洗臉方法是捧水用手洗臉洗得乾淨之後，用乾毛巾擦臉。


&nbsp;


我先生又說他的經驗給我聽&nbsp; 他說；他以前學日文的時候，他的台灣籍的日文老師告訴他說；


&nbsp;


[日本人不會用濕毛巾擦臉喔!]


&nbsp;


我先生回憶說，當時聽老師的話覺得很驚訝。


&nbsp;


&nbsp;


不過，我想，現在大部分的台灣人可能已經改變這個習慣了吧。


&nbsp;


市面上賣很多種洗面乳，大家應該都會先用這種洗面乳之後再擦臉，


&nbsp;


比較少人直接用濕毛巾擦臉的吧~~。也許年紀比較大的人還會做這樣子...。


&nbsp;


&nbsp;


後來我又發現一個很有趣，又感動的事情。今天的重點從這裡真正得開始喔~~!


&nbsp;


有一次，為了要寫大學研究所的研究計畫，我從圖書館借了一本舊書。


&nbsp;


這本叫做[台灣民俗誌]。


&nbsp;


這本書是在1920年，台灣日據時代，有一個日本人學者蒐羅了台灣人食衣住行育樂各種習俗民風的書。


&nbsp;


我看了這本書時，竟然發現，裡面有台灣人的洗臉方式習慣的記述! 


&nbsp;


那個日本學者寫說;[台灣人的洗臉方式是用毛巾擦的，而不是用水洗的。]


&nbsp;


看到這個記錄時，我覺得非常興奮，而且很感動。


&nbsp;


我現在所看到的台灣人的活生生的生活以及習慣，是有非常悠久的歷史。 


&nbsp;


90年前的台灣人的習慣，現在還活著。 我感到很浪漫~。


&nbsp;


還有，雖然我跟這本書的作者之間的時空遙遠，但當時的日本人跟現在的日本人遇到台灣人跟日本人的


&nbsp;


文化差異的反應，果然是一樣的。


&nbsp;


一條濕毛巾，平常幾乎都沒注意到得小東西裡，其實有很多有趣的故事讓我們感動的~~!
