&nbsp;




&nbsp;


&nbsp;


&nbsp;


離開一個人以後，人們多少都會感到有些失落。 <?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


曾經那麼愛你的人某天突然捨棄你了，


&nbsp;


你不免開始否定自己的價值。


&nbsp;


曾經你那麼愛的人忽然在你心中變得一點兒也不重要，


&nbsp;


你怎麼可以不去懷疑自己的眼光？


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


事實上，人對自己的評價，


&nbsp;


通常會隨著週遭環境的改變而改變。


&nbsp;


當一個人被愛的時候，他感覺全世界都受他吸引，


&nbsp;


就連麥當勞的店員也對他特別親切有禮。


&nbsp;


當一個人去愛人的時候，他也在付出中見證了自己的偉大，


&nbsp;


他以為自己看見的是世界上最美好的事物，


&nbsp;


所以他也有這份胸襟可以去容忍身邊周圍的一切醜惡。


&nbsp;


愛讓人變得高尚，也讓人變得卑微。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


當你所愛的人不愛你了，你也不願意再愛自己了。


&nbsp;


你開始自暴自棄，以為這樣就可以對抗他的薄情寡義。


&nbsp;


你犧牲一切，放棄自尊，只求換他一絲憐愛的目光，


&nbsp;


然而，他給你的卻再也不是愛情，而是同情。


&nbsp;


親愛的，難道你不知道，


&nbsp;


愛人的前提，首先是要學會自愛，


&nbsp;


唯有一個愛自己的人，


&nbsp;


才有愛人的權利，也才有被愛的條件。


&nbsp;


求來的感情，或許可以陪你渡過寂寞的夜，


&nbsp;


卻不能帶給你心靈的慰藉。


&nbsp;


&nbsp;


&nbsp;


想想看，你要求他，


&nbsp;


他才肯愛你，這真是你要的嗎？


&nbsp;


說穿了，所謂的「失戀」，


&nbsp;


只不過是失去了一個不愛你的人而已，


&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


別人越是對不起你，


&nbsp;


&nbsp;


你越是要加倍對得起自己。


&nbsp;


&nbsp;


因為，你可以離開任何人，


&nbsp;


&nbsp;


唯一離不開的，是你自己；


&nbsp;


&nbsp;


因為，即使週遭的環境改變了，




&nbsp;


你都仍然還是你自己。


&nbsp;
