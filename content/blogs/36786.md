&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;&nbsp;&nbsp;如果你老公很上進，妳要趕快跟上，否則會被他嫌棄。&nbsp;如果你的老公很上進又進取，妳要趕快加油，否則會被他淘汰。&nbsp;如果你的老公很頹廢，妳要自立又自強，否則會被他拖累。&nbsp;如果你的小孩很聰明，妳要趕快學習，否則會被瞧不起。&nbsp;如果你的孩子很遲鈍，妳要趕快成功，因為妳要照顧他一輩子。&nbsp;無知的愛是傷害，無知的消費是浪費。&nbsp;要做千面女人，不要做鉛面女人。&nbsp;女人要有三麗：美麗＋能力＋魅力。&nbsp;不要當三瓶女人：花瓶，醋瓶，藥瓶。&nbsp;女人有三美：形象美，語言美，心靈美。&nbsp;&nbsp;千萬別做 ~~&nbsp;三心女人，在家裡放心，想起來傷心，看起來噁心。&nbsp;三轉女人：圍著鍋台轉，圍著先生轉，圍著孩子轉。&nbsp;&nbsp;女人要有四立：思想獨立，能力獨力，交通獨立，經濟獨立。&nbsp;女人要美的自然，而絕不是自然就是美。&nbsp;漂亮美人像寶石，智慧女人像寶藏。&nbsp;女人因為有氣質才會千種風情，萬種浪漫。&nbsp;想要得到別人的愛，首先要自己愛自己。&nbsp;&nbsp;相愛不是互看對方的眼睛，而是要有共同的目標，理想，話題，朋友。相愛容易相處難，相處容易相信難，相信容易相諒難。&nbsp;行走在智慧中的女人最美麗，而要得到智慧就要走入人群中。
