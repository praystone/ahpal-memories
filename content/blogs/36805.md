1、在利益面前，沒有親情和道義可講，任何人都可能成為對你背後下手的賊；&nbsp;&nbsp; &nbsp; 2、幫你除草、殺蟲，對你示好的人，來你家的真實目的可能並不是這個，而是看你
有沒有可偷的東西；&nbsp; &nbsp; 3、越有錢的人賺錢的速度最快，溫飽線上的人都在量入為出中掙扎；&nbsp; &nbsp; 4、很多事情都有捷徑可走，有“背景”的人肯定升級快；&nbsp; &nbsp; 5、勤能補拙是有局限性的，每天靠除草、殺蟲的經驗只有那麼多；&nbsp; &nbsp; 6、挖、種是排除人民幣升級之外最快的升級方法，也就是說只要肯付出高昂的代價
走歪門邪道，肯定能領先別人一步；&nbsp; &nbsp; 7、那種以“友情”為名義的化肥，是最不講友情的東西；&nbsp; &nbsp; 8、想讓狗幹活，又不想給狗餵食，是不可能的，就算一條狗也會消極怠工；&nbsp; &nbsp; 9、狗會瘋狂地咬窮人，當你身無分文，被咬的概率是100%；&nbsp; &nbsp; 10、廣交朋友是硬道理，多個朋友就會多一條路；&nbsp; &nbsp; 11、有些時候我們期待著有人來搞一點小事端，從而獲得想要的經驗；&nbsp; &nbsp; 12、不遵守時間是要付出代價的；&nbsp; &nbsp; 13、沒事的時候多出去轉轉，總會有意想不到的收穫；&nbsp; &nbsp; 14、未必撒下昂貴的種子就一定賺更多的錢，但被盜時種貴菜的損失肯定會更多；&nbsp; &nbsp; 15、任何活動都是有目的的，不管是促銷化肥還是促銷打狗棒；&nbsp; &nbsp; 16、集體的力量是巨大的，可以瞬間讓一個人破產；&nbsp; &nbsp; 17、當有人告訴你快去某某的菜地偷菜時，不要把他當成最親密的戰友，因為當你成
熟的時候，他也一定會這麼告訴別人；&nbsp; &nbsp; 18、大地主都是排在前面的；&nbsp; &nbsp; 19、很多級別高而且地多的人在種白蘿蔔，不是他們傻，而是因為他們想升職，而且
不差錢兒；&nbsp; &nbsp; 20、早晨很早就起床，並不是不可能的。
