&nbsp; 有位網友到日本去玩，在某家寵物店玻璃窗上，看到了一張「告

示」，熱淚盈眶，回國之後將它四處發放。寵物店的玻璃窗上貼著「

寵物給主人的十大叮嚀」：



&nbsp;



&nbsp; 一，把我帶回家之前，請記得我的壽命約有十到十五年，若你離棄

我，會是我最大的痛苦。



&nbsp;



&nbsp; 二，請對我有耐心，你要給我一些時間來瞭解我。



&nbsp;



&nbsp; 三，信任我──那對我十分重要。



&nbsp;



&nbsp; 四，請別對我生氣太久，也別把我關起來當作懲罰。你明白嗎？你

有你的工作、你的娛樂、你的朋友，而你是我的唯一。



&nbsp;



&nbsp; 五，請時常對我說話，縱使我不懂你說話的內容，但我會感覺到，

你的聲音在陪伴我。



&nbsp;



&nbsp; 六，你如何對待我，我將永記在心。



&nbsp;



&nbsp; 七，你打我時請記得，我擁有可以咬碎你手骨的尖銳牙齒，我只是

選擇不做這樣的事。



&nbsp;



&nbsp; 八，當你想責罵我不合作、固執或懶惰，請你想想，是否有什麼正

困擾著我，或許我沒獲得我想要的食物、很久沒在溫暖的陽光下奔跑

，或者我的心臟已經太弱或太老。



&nbsp;



&nbsp; 九，在我年老時請好好照顧我，因為你也會變老。



&nbsp;



&nbsp; 十，當我要捱過生老病死最辛苦的歷程時，請千萬不要說：「我不

忍心看，我不想在場。」只要有你和我在一起，所有的事都會變得容

易接受。請你永遠不要忘記，我愛你。



&nbsp;



&nbsp; 看完，我也淚水盈眶。



&nbsp;



&nbsp; 我認為，不只所有的寵物店門口都該貼上這個告示。每一對誓言長

相廝守的情人們也該略略修飾一下文句，對彼此複述一次。每一對打

算生孩子的父母，也該有另一個版本，以免因為自己的不成熟禍延子

孫。我將情人之間的愛情版本稍稍更動如下：



&nbsp;



&nbsp; 一，決定與我結婚前，請記得激情的熱度不會燃燒太久。若你離棄

我，會是我最大的痛苦。



&nbsp;



&nbsp; 二，請對我有耐心，對我溫柔，不要以為你已經完全瞭解我，你還

要給我更多時間來瞭解我。



&nbsp;



&nbsp; 三，信任我──那是愛的主要能量。



&nbsp;



&nbsp; 四，請別對我生氣太久，也別禁閉我的自由。你可以有你的工作、

你的娛樂、你的朋友，而對我來說，人生缺你不可。



&nbsp;



&nbsp; 五，請時常對我說話且傾聽，縱使有時我不懂你而你不懂我，但我

會感覺到，你願意陪伴我。



&nbsp;



&nbsp; 六，你如何對待我，我將永記在心，一世不忘。



&nbsp;



&nbsp; 七，你想動手時請記得，我有足夠的能力報復，只是看我做不做。



&nbsp;



&nbsp; 八，當你想責罵我不合作、固執或懶惰，請你想想，是否有什麼正

困擾著我，或許我沒獲得我想要的溫柔、為了工作很久沒有休閒，或

者我的心已在生活的折騰中變得僵硬。



&nbsp;



&nbsp; 九，在我年老時請好好照顧我，不要嫌棄我，因為你也會變老。



&nbsp;



&nbsp; 十，當我捱過生老病死最辛苦的歷程、當我面對人生中最難承受的

挫折，請千萬不要說：「我不忍心看，我不想在場。」只要有你和我

在一起，所有的事都會變得容易接受。請永遠不要忘記，我愛你，而

你也曾許諾，你愛我。



&nbsp;



&nbsp; 天下父母何妨做個家庭作業，將以上十條愛的守則，改成適合你的

條款。



&nbsp;



&nbsp; 不離不棄是天下至愛。



&nbsp;



&nbsp; 溫柔守信對待感情，縱然未必得到想像中的報償，卻可能在愛的天

堂中得永生。
