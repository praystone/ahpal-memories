&nbsp;

&nbsp;

雖說幸福靠雙手創造，

&nbsp;

但是&nbsp; 細心的我們總會不經意的發現：幸福只需要一步。

&nbsp;

媽媽的嘮叨，爸爸的關心，朋友的問候。這都可算是幸福。

&nbsp;

幸福沒有大小，只要隨意就好。

&nbsp;

有的人太在意大的幸福，從而忽視了小小的幸福。

&nbsp;

在生活中，我們無時無刻在享受幸福。

&nbsp;

正因為它的存在才在

&nbsp;

我們生活的這張白紙上寫下了濃郁的色彩。

&nbsp;

有人問，幸福究竟是什麼？

&nbsp;

我的答案很簡單：幸福就是活的自在，沒有煩惱。

&nbsp;

就算幸福在你身上停留一秒，那也算是幸福。

&nbsp;

我身邊有很多人遇到了困難，就把世界看的很灰暗。

&nbsp;

不管是什麼美好的東西，在他的眼裏總是不好的。

&nbsp;

困難會蒙蔽你的雙眼，蒙蔽已經來到你身邊的幸福。

&nbsp;

佛家說：一念成魔，一念成佛。

&nbsp;

道理很簡單，只要你邁出一步，就一小步。

&nbsp;

垮過困難，你就不難發現，

&nbsp;

幸福其實就在身邊，世界變的多姿多彩。

&nbsp;

在幸福中，我們更多的是因該如何知道感恩。

&nbsp;

別人在我們最困難的時候幫助了我們，

&nbsp;

我們因該學會感謝，說一聲謝謝。

&nbsp;

這是我們最起碼的做人原則。

&nbsp;

在你受別人幫助時，你幸福了，

&nbsp;

在別人接到你謝謝時，我相信別人也幸福了。

&nbsp;

一念成魔 一念成佛

&nbsp;

只要你細心的發現生活中微小的幸福，

&nbsp;

只要你在困難的時候邁出一小步，幸福就在你身邊。

&nbsp;

朋友，現在就尋找屬於你的幸福吧！
