任性的權利






文/萊姆



我一直覺得，懂得任性的女孩子，比知所進退的良家婦女要有魅力。

&nbsp;

會任性的女孩懂得要求，懂得保留自己的驕傲，懂得去追求自己想要的東西。

&nbsp;

「借物少女艾莉緹」的女主角艾莉緹就是這樣的女孩。

&nbsp;

我很喜歡吉卜力工作室的影片，雖然不是每部都看，不過經典的龍貓、魔女宅急便、天空之城，到較為近期的霍爾的移動城堡與波妞我都有看過。這些動畫電影，大多都是以女性為主角，她們都勇敢、積極、充滿熱情，即使遇到困難，大哭後便擦乾眼淚繼續向前；相較之下男主角都比較單純溫柔（不過我個人很喜歡這款就是）。

&nbsp;

我行我素，對於某些人來講大概是困擾吧！

&nbsp;

在「借物少女」中的艾莉緹，她就是個我行我素的女孩。她很勇敢、自信滿滿，不管別人的勸說，她相信自己的直覺，勇往直前去做自己認為對的事。

&nbsp;

有這樣的小孩是令人頭疼的，但這樣的女孩，會讓人覺得什麼事都難不倒她。

&nbsp;

已經習慣了，在生活中有許多事情需要跟驕傲妥協。

&nbsp;

對老闆妥協、對客戶妥協、對情人妥協，有時候試著想任性一下，卻摔了個大跤。

&nbsp;

「妳怎麼了？」

「妳都沒有顧慮到我的心情嗎？」

「妳不知道這樣做是不可行的嗎？」

&nbsp;

跌倒一次，好痛。

&nbsp;

原來自己的任性會換來這樣的結果，原來想好好的任性一次，造成了別人的困擾，反過來傷害了自己，那麼，是不是只要好好聽話就好？

&nbsp;

自信不夠的女孩，加上表達錯誤的驕傲，在一次次跌倒的過程中，逐漸磨平了自己的任性，也磨去了自己的光。

&nbsp;

任性是每個人都希望擁有的權利，但我們是不是能遇到包容自己的人？

&nbsp;

「借物少女」中，因為艾莉緹的任性帶來了家族的危機，艾莉緹一度為此自責不已。

&nbsp;

「就是因為妳這樣做我們才會…」

「妳知道這樣做的後果是什麼了吧？所以以後妳要…」

&nbsp;

這樣的話語沒有從艾莉緹的父親波特口中說出。

&nbsp;

雖然女兒的任性帶來了災難，但這也是種族不可避免的命運。他依舊信任自己的女兒，期望女兒因此獲得成長。嚴厲，卻溫柔，也包容。波特沒有抹殺艾莉緹的本質，而男主角小翔和艾莉緹互動的過程，告訴了我們，因為妳是這樣驕傲而盈滿活力，妳吸引了我的目光，帶給我勇氣。

&nbsp;

多希望，可以很任性的做自己，多希望，這樣的自己在別人眼中明亮而充滿活力。

&nbsp;

我們都希望有個人在身旁支持自己，肯定自己的本質，幫助自己修掉不必要的菱角，讓自己的光芒更加燦爛。

&nbsp;

這個世界上，是不是有那樣一個人，懂得欣賞我的驕傲，能夠包容我的任性，在我跌倒時扶我一把，幫助我成為任性而可愛的人，而不是強硬的抹去我的驕傲，希望我乖巧聽話的，就像大家一樣？

&nbsp;

任性的權利是自己的，也是需要他人給予的。

&nbsp;

親愛的你，我任性，是因為你是可以放心讓我任性的人，希望你可以了解，我的任性是因為有愛，我才敢表現真實的自己。請不要一昧的指責我，請你了解我，然後伴我一起成長，讓我的任性是可愛的，不是自私的，不是傷害我們之間感情的利器。

&nbsp;

請你給我任性的權利。
