[摘至網路]✪ 一段真愛，足以讓女人活一輩子
_____________________________


&nbsp;


 

　她是個壞女人，這幾乎是所有人都認同的事實。 壞到什麼程度呢？ 


&nbsp;


她十六歲就早孕，然後被學校開除。 因為有幾分姿色，她後來嫁給了一個司機。 


&nbsp;


司機也老實，她便欺負他，後來她和別人私通。


遇到他的時候，她已徐娘半老。 不，這還不算完。 


&nbsp;


她命硬，已經克死了兩任丈夫，並且都給他們戴過綠帽子。


&nbsp;


&nbsp;而他則是一個未婚男人，因為家庭窮苦而耽擱了，等到兄弟姐妹都成了親，他已經35歲了。


她長他5歲，媒人來說媒時，提起她的過去，說：“只要你不介意，我可以給你說說。


&nbsp;


”他說我不介意。 他有什麼？ 一個修自行車的店鋪而已，人又生得難看。 


&nbsp;


她的風流是出了名的，而他的木訥也是出了名的。


&nbsp;


&nbsp;誰也不會相信他會娶她，誰也不會相信她會嫁給他，


&nbsp;


但那年的臘月，鞭炮響了，他們結婚了。


她帶著自己的兩個孩子，一個丈夫生了一個，一兒一女。


&nbsp;


&nbsp;他笑呵呵地說：“看我多幸福，還沒怎麼著就一兒一女了。”


&nbsp;


他並不介意別人的眼光。 


&nbsp;


她仍舊是懶、饞、愛打麻將、跑到四鄰八舍說是非，和男人眉來眼去。


&nbsp;


&nbsp;這毛病不是一天兩天了，但老了，沒有人要她了，可她還是去招惹男人。


有人去告訴他，他木訥著臉說她：“你要是沒事就在家裡唄。”


&nbsp;


他沒有惱，她先惱了：“你說我？在家中我還不悶死？去串個門怎麼了？”


&nbsp;


他沒有再說下去，還是去剝瓜子，這是他最愛做的事：給她剝瓜子。


&nbsp;


&nbsp;她最愛的零食是瓜子，一邊吃著瓜子一邊罵：“以後，你少管我，窩囊廢！”


她愛罵人，他嘿嘿地笑著聽，並不還言。 


&nbsp;


連兒女都聽不下去了，嫌她罵得寒磣。


&nbsp;


&nbsp;她說：“老娘混到這一步，還不是因為你們兩個兔崽子，


&nbsp;


如果不是你們，我不會嫁給個修車夫！”


但他還是那樣疼她，即使進了門涼鍋冷灶，他也不嫌，家裡有個女人總是好的。


&nbsp;


&nbsp;他做飯，揀她愛吃的做。 做熟了，一遍遍到鄰居家去喊她吃飯。 


&nbsp;


她總嫌他煩：“催死呢？還差兩圈！”兩圈打完了，菜涼了，他端下去熱，


&nbsp;


一邊熱一邊說：“別老去打牌了，打一小會兒就得了唄，


&nbsp;


時間長了對身體不好，你看你的胃，又疼了吧？”


她胃疼的時候，他灌個熱水袋放在她肚子上，


&nbsp;


左手拉著她的右手，有個女人真好，


&nbsp;


這身子是溫熱的，雖然不知道疼他，可到底是有女人了。 


&nbsp;


她也有對他好的時候，罵他賤骨頭，八輩子沒見過女人。 


&nbsp;


他就嘻嘻笑著：“我就是沒見過女人，還沒見過這麼俊的女人。”


這時候，女人就笑了，她去照鏡子，


&nbsp;


果然照著一張桃花臉，但卻是老桃花臉了。


&nbsp;


&nbsp;她已經40歲了，真的老了，年輕的時候打情罵俏，沒幹什麼正經事，


&nbsp;


到如今找了個知冷知熱的人，值了。 


&nbsp;


前兩個男人，為了她的輕浮，打她罵她，她沒有改過來，


&nbsp;


結果第一個喝多撞死了，第二個去游泳掉到河裡淹死了。 


&nbsp;


因為長期打打鬧鬧，他們死時，她只覺得少了個給她掙錢的，


&nbsp;


甚至沒有哭沒有鬧。 人們都說她心硬，說最毒不過婦人心，


&nbsp;


她磕著瓜子說，“哼，誰讓我長得美。”


如今美人遲暮了，但她依舊是美。 坐在巷子口和人打牌聊天。


&nbsp;


&nbsp;大雨天，他推著自己的車篷跑回家，


&nbsp;


有人說：“你男人回來了，快去燒壺熱水給他暖暖身子。


&nbsp;


”她卻磕著瓜子說：“打完了這圈再說。”


&nbsp;


連一雙兒女都覺得她有些可恨了，


&nbsp;


可男人說：“讓你媽玩吧，她心裡可鬱悶啊。”


&nbsp;


她聽了，側過臉去，眼睛有些微微濕潤，知道這男人是真心疼她了。


不久，男人覺得心口疼，一直疼到上氣不接下氣。 


&nbsp;


去醫院查，心臟壞了，要做搭橋手術。 


&nbsp;


她聽了，潑婦似地坐在地上罵：“挨千刀的啊，


&nbsp;


你怎麼得這個病，這不是要我死嗎？


&nbsp;


我的命怎麼這麼苦這麼硬啊？”到現在，她想的還是她自己。


錢是不夠的。 她趁男人不在家，把自行車鋪賣了，三萬多塊，還是不夠。 


&nbsp;


她去找親戚借，因為名聲壞了，沒人借給她，怕她說謊話。 


&nbsp;


她一狠心，重拾起年輕時學的本事：唱大鼓。 


&nbsp;


她怕人知道，於是買了火車票遠走，一個城市又一個城市地唱，


&nbsp;


如果你在街頭看到一個唱大鼓的女人，那就是她了。 


&nbsp;


她不年輕了，45歲了，濃妝豔抹，穿著廉價旗袍，


&nbsp;


一句一句地唱著《黛玉思春》、《寶黛初會》，很艷情的大鼓，一塊一塊地掙。


長到45歲，這是她第一次為一個男人掙錢，不，這不是掙錢，這是掙命呢！


&nbsp;


&nbsp;一年之後，她唱夠了做手術的錢。 


&nbsp;


等她回來時，所有人都發現她黑了瘦了，很多人都以為她跟別的男人跑了。 


&nbsp;


這樣的女人，看著自己的男人不行了就跟別人跑唄，很正常。 


&nbsp;


很多人都這樣看她，只有他不這樣看她，他說：“她會回來的。”


她真的回來了，帶著好多錢，


&nbsp;


跑到他跟前說：“做手術的錢咱有了，不是我和男人睡來的，是我給你掙來的。”


&nbsp;


這次哭的是他。 他哽咽著，撫摸著她有了白髮的頭，說：“瘋丫頭，怎麼學會疼人了？”


&nbsp;


一直，他把她當孩子，一個愛玩愛鬧的孩子，甚至她的輕薄他也沒有嫌，


&nbsp;


他相信，自己會感動她的，會讓她愛上的。


手術做得不成功，半年之後，他去了。 臨走之前，


&nbsp;


他拉著她的手說：“下輩子，我還娶你，即使你看不上我，但誰讓我喜歡你呢？


&nbsp;


所以，我前面等著你去了。”她撲到他身上大哭，“死鬼啊死鬼，你真忍心啊！”


&nbsp;


聲音如杜鵑啼血，在場的所有人為之動容，但他到底去了。


都以為她還會再嫁，都以為她還會再說再笑再招搖著打牌去，但所有的人全想錯了。 


&nbsp;


從此，她布衣布食，吃齋念佛，不再東家串西家串，


&nbsp;


把從前的自行車鋪又開了張，自己做生意，供兩個孩子上學。


她的心裡，從此就只有這個男人，他給了她一段情，一段人世間最美好的愛情。


&nbsp;


&nbsp;如果人有這樣一段情，是可以讓人活一輩子的。
