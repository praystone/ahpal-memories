[摘至網路]✪ 只為給你一生溫暖
_____________________________


&nbsp;


 

“愛”是孤單一個字，所以需要兩個人相擁。 


&nbsp;


她並非凡俗女子，相反，相當優秀，追求者云集。 


&nbsp;


而她，排開眾人，毅然跟了他。 


&nbsp;


當時，他一無所有，在一家工廠打工，收入​​不夠解決兩人溫飽。


&nbsp;


&nbsp;為了他，她失去親人，丟了工作。


他們藉了一間朋友的倉庫，簡單收拾後，作為臥室。


&nbsp;


&nbsp;寒冷的倉庫猶如一口冰窖，沒一床溫暖的被褥裹體，她常常在半夜裡被凍醒。


&nbsp;


&nbsp;他緊緊地抱住她，盡量把她貼在自己胸口，用自己的體溫去溫暖她。


一天，她從外面回來，神色恍惚，臉色蒼白。 


&nbsp;


他問：“怎麼啦，是不是病了？”她說：“沒事，就是有點累。”


&nbsp;


之後立刻興奮地從口袋裡掏出一張紅色大鈔，在他眼前晃了晃，


&nbsp;


亢奮地說：“我們有錢了，去買一床溫暖的棉被。”


&nbsp;


“哪來的錢？”“賺的。”他說：“怎麼賺的？如此容易。”


&nbsp;


“給人發廣告，一張一張地發，從早上站到現在，賺了100元小費。”


&nbsp;


兩人去街上買了一床棉被，經不起挑選，按著100元錢的價格買。


&nbsp;


&nbsp;從此，嚴寒的冬日，有了一床棉被，她不再半夜被凍醒。


幾年後，他慢慢好轉，有錢了，自己開了公司，不久買了房子和車。


&nbsp;


&nbsp;他們告別了當初飢寒交迫的日子。 


&nbsp;


家裡的裝修，極其講究，地磚牆紙都進口，連水龍頭都是最高檔的。 


&nbsp;


他要給她一個最溫暖的家。 住在這樣的環境裡，她有些徬徨。 


&nbsp;


搬家時，原來倉庫裡的東西全扔棄了，而她堅持留著那床棉被，


&nbsp;


幾年來，他們一直用著，已經破了好幾處。 他說：“扔了吧，再去買一床新的。


&nbsp;


到處都是高雅的東西，擺了這個，障眼。”


&nbsp;


她說：“不扔，這床棉被陪我們走過多少個嚴寒冬日，蓋在身上，總那麼溫暖。”


&nbsp;


他搖搖頭，不再堅持。


一天，他從外面回來，手裡提著一床新棉被，要求她扔了舊的，換上新的。


&nbsp;


&nbsp;她沒有辦法，只能聽從。 從此，退下舊的，換上新的。 


&nbsp;


每天晚上，她不像往常睡得安逸舒坦，心裡掠過一絲疼痛，


&nbsp;


常常在深夜，委屈的眼淚不知不覺沾濕枕頭。 


&nbsp;


她在心裡說：“你知道嗎，這床棉被經過多少努力，才買來的嗎？


&nbsp;


那天，我根本沒去發什麼小廣告，而去賣血了！


&nbsp;


第一次賣血，竟然是為了買一床棉被！這床棉被對我有多重要！


&nbsp;


而你，當成垃圾扔掉。”她覺得他不像以前那麼愛她了，


&nbsp;


雖然蓋著新的棉被，但沒了以前的溫暖。


一次，他去洗手間，忘了關手提電腦。 她無意中發現，


&nbsp;


他開了個人博客，每天堅持寫日記。 


&nbsp;


在一篇日記中，他說：“那天，她從外面進來，蒼白的臉，嚇了我一跳。


&nbsp;


為了賺夠買一床棉被的錢，她竟然給人發小廣告。


&nbsp;


那天晚上，我們睡在新的棉被下面，多麼溫暖，她從沒睡得那麼安穩。


&nbsp;


無意中，我發現，她手上有一塊紅腫，被針眼扎過。


&nbsp;


發廣告其實是她委婉的謊言，她跑去賣血了。


&nbsp;


這床棉被其實是她拿血換來的！她的身體那麼單薄！


&nbsp;


那晚，我暗自哭了一夜，我發誓，一定要出人頭地，給她幸福。


&nbsp;


經過這幾年的努力，我終於做到了。


&nbsp;


昨天，我也去血站，叫他們抽了血，我只想感受一下，那細小的針眼扎進血管時，


&nbsp;


那冰冷的疼痛，讓我猝不及防，


&nbsp;


然而，又是那麼幸福。我拿著錢，去買了這床棉被。”


她的眼睛早已模糊，原來，他的心如他對她的愛一樣，那麼細膩。 


&nbsp;


寒冷的冬日，他送她一床溫暖的棉被，連著帶來了整個春天！
