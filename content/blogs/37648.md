&nbsp;

人生的十全九美

&nbsp;



&nbsp;


有人曾對我說：

&nbsp;

&nbsp;&nbsp; 青春，是開啟了就合不上的書；&nbsp;&nbsp;&nbsp; 

&nbsp;

人生，是踏上了就回不了頭的路；

&nbsp;

愛情，是放下了就收不回的賭注；

&nbsp;

生活，是升起了就撥不開的迷霧；

&nbsp;

&nbsp;

而朋友，是找到了就捨不得丟的寶庫。

&nbsp;

他告訴我的，是對朋友之間那份真摯友誼的贊美和向往，

&nbsp;

卻莫名讓我感覺到他話語中夾雜的絲絲無奈和感傷，

&nbsp;

像是對世界有太多太多的失望……

&nbsp;

&nbsp;

其實我想說…

&nbsp;

青春僅是每個人對待生活的不同態度罷了。

&nbsp;

積極樂觀的人可以“永保青春”，享受生活的激情和樂趣，

&nbsp;

而悲觀消極者總是嘆息生活的不完美，

&nbsp;

永遠體會不到“青春生活”的滋味。

&nbsp;

人生則是永遠不必回頭的旅程。

&nbsp;

走過的路、錯過的風景，何以有再來一次的價值？

&nbsp;

&nbsp;

與其把時間浪費在過往的歲月裏，

&nbsp;

倒不如用心走好餘下的旅程，

&nbsp;

畢竟未來永遠比過去重要不是麼？


也許這一次的失去也預示著新的收穫

&nbsp;

（只是有些是還沒來得及印證而有些是被我們忽略了的罷了），

&nbsp;

也許這一次的結束也代表著下一輪新的開始。

&nbsp;

&nbsp;

愛情本就是沒有輸贏結局的賭局。

&nbsp;

它伴隨著我們直到生命結束的那一刻，

&nbsp;

愛情的結局才誕生，

&nbsp;

無論最後等待我們的是什麼，愛在心中已足已，

&nbsp;

我想珍惜當下應該來得更實際點吧！


&nbsp;

人生漫漫，

&nbsp;

有誰能一輩子把愛的他（她）永遠留在身邊呢？

&nbsp;

又有誰能說離失了他（她）就失去了一切意義呢？

&nbsp;

結局並非價值，值與不值在於愛情真正的主人翁自己，

&nbsp;

誰也沒有評判的資格！

&nbsp;

&nbsp;

生活就“霧裏看花”一樣，“花”會更美。

&nbsp;

有些人正是因為看“透”了這個世界，

&nbsp;

才會徒添那麼多多煩惱也許“傻”的“糊塗人”

&nbsp;

才算是生活真正的主人，樂在其中，活的自在。

&nbsp;

&nbsp;

而朋友是永遠解不開的不詳數。

&nbsp;

我們漸漸長大，朋友多了，交際圈也廣了，

&nbsp;

它在發生著“量變”的同時也伴隨著“質變”，

&nbsp;

有些朋友或許是受益一生的“寶庫”，

&nbsp;

而有些甚至會成為埋葬自己的“墓穴”，

&nbsp;

交往的度是永遠保持著彼此安全範圍內的距離，

&nbsp;

太遠了會生疏甚至是失去，

&nbsp;

而太近了卻又會產生摩擦和割痕了，同樣是失去呀！

&nbsp;

&nbsp;

世上所有繁雜的事：

&nbsp;

宇宙萬物生存繁衍的奧妙、國家社會經濟教育的發展、

&nbsp;

感情生活工作學習的和諧等等這些，

&nbsp;

裝訂成一本厚厚的書，書名就是——《人生》，

&nbsp;

而能讀懂它的、悟透它的是聖人都不能及的事，

&nbsp;

何況人非聖賢呢？

&nbsp;

&nbsp;

所以，十全九美已是完美，那些所謂追求“完美的人”

&nbsp;

其實是還不明白人生真正的涵義：

&nbsp;

對生活、對朋友家人、

&nbsp;

包括對我們自己，都不要太過苛求，

&nbsp;

應該學會知足常樂，

&nbsp;

學會欣賞已經存在的“缺陷美”！
