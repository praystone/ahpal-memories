知足者，身貧而心富;貪得者，身富而心貧。

&nbsp;

人生只有三天，迷惑的人活在昨天，奢望的人活在明天，只

&nbsp;

有清澈的人活在今天！

&nbsp;

「人生只不過來去一遭，是來圓緣，不必斤斤計較，讓自己

&nbsp;

怒火攻心。」


&nbsp;

簡單、不難。

&nbsp;

只要懂得為自己而活，為美好而生，為幸福而做，需求愈

&nbsp;

小，自由愈多; 奢華愈少，舒適愈多。


多一分快活，少一分憂傷; 


&nbsp;

多一分真實，少一分虛偽;


&nbsp;

多一分悠閒，少一分忙亂，便會換來內心的豐饒！


&nbsp;

少氣多閒，身忙心閒。改變一下自己態度去適應不同的情

&nbsp;

況，心情自然輕鬆順暢，不至於造成「心鬱氣結」，跟自己

&nbsp;

過不去。

&nbsp;

人生一場，別人追屋逐堡，我只要風花雪月，花棚石凳小坐

&nbsp;

微醺，歌一曲，茗一杯，花一簇，鳥一群。

&nbsp;

因為生活簡單，我多了聆聽松濤、諦觀風雨、仰望星河、敞

&nbsp;

開心扉的機會，靈性俱足。

&nbsp;

心境簡單了，就有心思經營生活，生活簡單了，才有時享受

&nbsp;

人生。

&nbsp;

富足的生命，竟然如此簡單，放手，就可以擁有全世界。
