&nbsp;



沒有晴空萬里的心 至少有溫馨的感覺

&nbsp;

心中冒出暖暖的微暈 我想那或許叫做幸福

&nbsp;

我不是最不幸的人&nbsp; 我知道

&nbsp;

我算是有福氣的人 四肢健全身體無大恙

&nbsp;

只是心一直處於受傷的狀態

&nbsp;

有時後 曾經有時候 問自己還呼吸做什麼

&nbsp;

看著天空 觀望大海 苦惱找不到自我

&nbsp;

許多無解的問號&nbsp; 一再反覆摸索

&nbsp;

當思想愚昧時&nbsp; 更找不到自性

&nbsp;

從二歲就學會躲藏 渴望隱形

&nbsp;

不是我聰明記憶好

&nbsp;

而是那麼深的傷口&nbsp;&nbsp;很難忘掉

&nbsp;

躲著藏著 始終逃不過命運之手翻覆

&nbsp;

在人群 我喜歡低頭最好能隱歿

&nbsp;

獨處時&nbsp; 又很努力伸展脖子硬是不低頭

&nbsp;

唯一 所堅持的單純&nbsp; 是不曾變的溫柔

&nbsp;

現在 那暖暖的微暈 我正在適應著

&nbsp;

有一天&nbsp; 我會貪心想要更多 更多 更多

&nbsp;

海深處 其實暗湧何嘗不是巨大的

&nbsp;
