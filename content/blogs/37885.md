如何孝順我們的老人<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp; &nbsp; 我要說的老人是特指一個年齡段的父輩，現在基本上七十歲以上，我的父親母親就是這一類人，這類人在實際生活中並沒有電視劇《金婚》那麼浪漫和甜蜜，實際相差太遠。
&nbsp; &nbsp; 之所以探討他們的問題，實在是他們是我的父輩，他們已經到了需要精心贍養的年齡，同時也在贍養過程中發現了巨多的問題，許多問題決不是一句兩句話可以概括地好，想說“孝順”兩個字是非常不容易的。
&nbsp; &nbsp; 我們都是佛子，我們又都是孝子，我們當然知道孝道是做人最基本的準則，但具體到怎麼孝，卻實實在在需要探討，需要智慧，需要在高僧大德的言語指導下做如法的研究才能完成，需要各位師兄提供具體方案的設計和思路幫助。
&nbsp; &nbsp; 我們的老人非常有意思，實在經歷太多：對日戰爭，解放戰爭，路線鬥爭，文革大革命，改革開放，下崗再就業。。。
&nbsp; &nbsp; 我們的老人受的教育實在可憐，我父親曾以小學六年級的學歷奪得他們連隊學歷之冠，全連120人只有兩個人有文化，連長居然看不懂作戰命令！
&nbsp; &nbsp; 我們的老人經歷了太多的苦楚：親人的亡故（非正常），饑餓，血腥，文化的斷裂和破壞等等。。。
&nbsp; &nbsp; 這造成了這些老人有著非常奇怪的性格特徵：
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;1.極端自私，比前輩和晚輩自私的多。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;2.夫妻關係不好的居多，相當一部分人打了一輩子，但那個年代想離婚也難！
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;3.對人極端不信任，相當一本分老人對子女是不信任的。甚至會把你的好心當成。。。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;4.對佛法抵觸的很厲害，基本上沒有什麼信仰。。。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;5.個別老人甚至有惡習，如賭博偷盜等。。。

&nbsp; &nbsp; 對待這些老人，如何做才能在如法德基礎上維護孝道呢？
&nbsp; &nbsp; 我們還不是佛，所以我們的孝必然會遇到各種各樣的實實在在地阻礙，所以我們需要指導性的意見，讓我們大家把遇到的想不通的問題提出來讓一起探討吧，為了我們的父輩的晚年。
