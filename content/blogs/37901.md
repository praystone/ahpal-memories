&nbsp;

&nbsp;

曾有一抹光點 隱約漂浮

&nbsp;

試著追隨 總在半途就消失

&nbsp;

&nbsp;

曾有一朵百合 暗藏香氣

&nbsp;

試著綻放 卻毀於暴雨狂風

&nbsp;

&nbsp;

曾有一曲相思 曖昧動人

&nbsp;

試著定調&nbsp; 然早已人去樓空

&nbsp;

&nbsp;

&nbsp;

哪還能有心想著捉不到的琉璃光

&nbsp;

哪還有緣栽種最初的那一株清香

&nbsp;

哪還有意回顧著聲聲殷切的呼喚

&nbsp;

&nbsp;

&nbsp;

似有像無&nbsp; 如霧似雨&nbsp; 渾沌了鮮紅的心

&nbsp;

原來是枝芽一葉&nbsp; 卻當做了扁舟來行

&nbsp;

錯了&nbsp; 不過就置身一場夢罷了

&nbsp;

清醒了&nbsp;&nbsp; 心還是溫熱的暗紅跳動
