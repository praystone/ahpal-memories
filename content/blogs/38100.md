&nbsp;

&nbsp;


&nbsp;

幸福是這樣嗎？

&nbsp;



&nbsp;

&nbsp;


他說：讓我抱抱你，我不知道下次是什麼時候。

&nbsp;

他說：我不想跟你吵架，因為我不想你不開心。

&nbsp;

他說：不喜歡上班就算了，我又不是養不起你，

&nbsp;

不過，你以後可能要吃得少一點。


&nbsp;

重量級的情話要輕得像一根羽毛，

&nbsp;

不經意飄落在對方心裡，卻正好搔著他的癢處。

&nbsp;

&nbsp;

寫小說的人總害怕重複，

&nbsp;

為了不重複自己的作品，創作的時間一次比一次長，

&nbsp;

終於有一天什麼也寫不出來了。

&nbsp;

為什麼害怕重複呢？

&nbsp;

我們所謂的幸福不正是重複地做同一件事情嗎？

&nbsp;

&nbsp;

每天跟自己喜歡的人一起、每天跟情人通電話、

&nbsp;

常常跟他一起去旅行、甚至每夜同眠共寢、

&nbsp;

重複一個承諾和夢想、聽他第二十八次提起童年往事、

&nbsp;

每年的同一天和他慶祝生日、

&nbsp;

每年的情人節、聖誕節、除夕也和他共度。

&nbsp;

&nbsp;

多少年來，只是和他一個人睡，

&nbsp;

只是嗅著他一個人的氣息，

&nbsp;

甚至連吵架也是重複的，為了一些瑣事吵架，

&nbsp;

然後冷戰，瘋狂思念對方，最後和好。

&nbsp;

我們不是重複做著這些事情，然後相信這就是幸福嗎？

&nbsp;

幸福就是重複。

&nbsp;

&nbsp;

有人說，

&nbsp;

世上所有的幸福家庭都是一個樣子的，

&nbsp;

不幸則有很多種。

&nbsp;

所謂一個樣子，也許就是重複。

&nbsp;

&nbsp;

想像有一天早上....

&nbsp;

張開眼睛再看不到你、再也嗅不到你的氣息、

&nbsp;

你不再睡在我身旁、你不再像往常一樣吻我、

&nbsp;

你不再像過去那樣溫柔地待我、你不願意重複，

&nbsp;

那就是愛情消逝而我不再幸福的時候....


我突然不再害怕重複。


幸福的愛一個人，一個是純真，一個是樸實，

&nbsp;

兩個人一個愛情，兩顆心，一個靈魂

&nbsp;

&nbsp;

簡單一點~ 中庸一點~ 生活快樂而滿足... 

&nbsp;

前進一點~ 後退一點~ 人生優游而自在... 

&nbsp;

&nbsp;愛自己一點~ 愛別人一點~ 幸福為你而存在...


&nbsp;
