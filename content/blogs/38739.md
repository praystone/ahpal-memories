世間萬象，哪一個不讓你動容？！



&nbsp;



抱抱。委屈難過的時候 有我呢。



&nbsp;



&nbsp;



&nbsp;



父親節。爸爸，很久前你也這樣騎車帶我逛公園。



節日快樂。我想你。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



當你大價錢買下一隻名犬的同時，



正有一隻沒人收養的流浪狗被安樂死。



如果真喜歡小狗，不論品種血統怎樣都可以是很好的夥伴。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



澳洲火災後的無尾熊。==真想抱抱。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



聆聽關注不僅是尊重，更是投入心底的溫暖。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



不管交際圈是大是小，能交到知心又有心的朋友都是難得。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



地震後見到救援人員的熊貓。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



哈哈~搶鏡頭搶這麼兇喔。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



微笑，換生活多一點美好。

&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



“乖，閉上眼。我可要親了。”



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



退伍的不捨。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



這是爸爸最愛我的姿勢。也是我最依賴爸爸的姿勢。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



有紀律的小崽子們。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



沒有山珍海味 只是一個最最普通的饅頭。



&nbsp;



可是每每看起來都會覺得溫暖。



&nbsp;



經得起時間的考驗，相濡以沫，白首偕老。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



央視“外國人中國才藝大賽”上出現了意外，



來自喀麥隆的選手傑蓋表演的變臉



只變了兩張臉就因為技術失誤再也變不出來了。



淚流滿面的傑蓋當眾跪倒向觀眾道歉請大家原諒。



震驚感動之餘，我們懂這是他對中國的尊重，



是對藝術的尊重。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



一群來自山東的消防隊員在經過近八十個小時的連續奮戰後，



已處於極度疲勞狀態，消防戰士和搜救犬趁救援命令間隙片刻休息。山東人驕傲。中國人也驕傲。軍犬軍人一樣受敬重。



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



賣菜謀生。還要提防一些合法的畜生。當然只是一些。



這是父親。萬苦千辛賺錢鋪就我們安穩的成長道路。



&nbsp;

&nbsp;



&nbsp;



&nbsp;



&nbsp;



依靠。
