&nbsp; 

&nbsp; 你是愛我還是需要我？&nbsp; 

&nbsp; 


&nbsp;

&nbsp;


著名的心理學家弗格姆(E.Fromm)


&nbsp;

在他的名著(愛的藝術)中有這麼一句名言：

&nbsp;

不成熟的愛是「因為我需要你,所以我愛你」，

&nbsp;

而成熟的愛是「因為我愛你,所以我需要你」。

&nbsp;

&nbsp;

一個人付出的愛是不是成熟，

&nbsp;

從他最原始的動機與表達得到驗證。

&nbsp;

如果是基於需要例如：因為我孤單、寂寞，

&nbsp;

所以我需要你陪我與安慰

&nbsp;

那麼他所說的愛其實不是真愛，

&nbsp;

而是一種條件的需索卻假冒愛的名義。

&nbsp;

這假愛的鑑別非常容易，就是當他的需求已得到滿足。

&nbsp;

(例如：因為你的陪伴安慰，他已不再感到寂寞)，

&nbsp;

便會對你的存在覺得多餘與厭煩。

&nbsp;

&nbsp;

所以，當你的情人打電話給你，

&nbsp;

訴說他見不著你的日子真是茶不思飯不想，

&nbsp;

而求你趕過去給他看看的時候，你且慢高興.因為說穿了，

&nbsp;

他只是要你去給他下飯罷了！他只是需要你，那裡是愛你呢！

&nbsp;

&nbsp;

而真正的愛是無條件的自由付出，

&nbsp;

所謂需要，其實只是一種邀請：

&nbsp;

他需要一個人和他共同完成這樁愛的事實，

&nbsp;

所以他對你提出邀請了。

&nbsp;

而這樣的真愛也很容易鑑別，

&nbsp;

就是當你對他的邀請婉拒甚至只是沈吟的時候，

&nbsp;

他立刻就能尊重你的意願而停步，

&nbsp;

而不會死追活纏，非要你答應才甘心。

&nbsp;

何以故？只因他並不是荏弱的人格需要你去支持，

&nbsp;

而是秉其人格的獨立堅強，願邀你分享他生命的美好時光。

&nbsp;

&nbsp;

因此我們說愛的第一要義就是自由，

&nbsp;

這一方面是指愛的付出應當基於自由意志，

&nbsp;

而別無潛在的陰暗動機。

&nbsp;

一方面則是指對對方人格自由的充分尊重，

&nbsp;

而不在付出的愛上面附帶有渴想、期望、要求乃至逼迫的壓力。

&nbsp;

而真的相愛是一種愉悅甜美的經驗，

&nbsp;

而不是互相剝削的債務。

&nbsp;

但許多情人的相處卻總是從無私的愉悅始，

&nbsp;

而以沈重的負擔終。

&nbsp;

&nbsp;

情人總忍不住想用對方的束縛來保障自己的安全，

&nbsp;

卻不知只會帶來更多的煩憂。

&nbsp;

而一個願意對方完全自由的人，又有誰捨得離棄？

&nbsp;

只是道理雖然簡明，當事到臨頭，總是不容易做到罷了！

&nbsp;

&nbsp;

有人問：『你為什麼喜歡一個人？』

&nbsp;

我只能夠說出為什麼不喜歡一個人，

&nbsp;

卻說不出為什麼喜歡個人。

&nbsp;

喜歡一個人，是一種感覺。

&nbsp;

不喜歡一個人，卻是事實。

&nbsp;

事實容易解釋，感覺卻難以言喻。

&nbsp;

&nbsp;

愛情是忽然有一個人，

&nbsp;

我們覺得一見如故，很想靠近他，

&nbsp;

我們的內分泌忽然起了翻天覆地的變化，很想擁抱他。

&nbsp;

以後，無論快樂或哀愁，

&nbsp;

我們也想不起當初為什麼愛他。


&nbsp;

只有當我們不愛一個人時，才會找出不愛他的原因，

&nbsp;

因為我們開始挑剔。

&nbsp;

任何一個人，只要你去挑剔，一定找得出缺點。

&nbsp;

越去挑剔，缺點越多，

&nbsp;

我們便可以說出為什麼不喜歡他。

&nbsp;

&nbsp;

我們想買一件衣服時，即使發現他有小小瑕疵，

&nbsp;

埋怨幾句，也肯將就，

&nbsp;

因為只有這一件，而且我們太喜歡它了，瑕不掩瑜嘛！

&nbsp;

假使我們根本不想買那件衣服，它的小小瑕疵便是致命傷。


&nbsp;

我們更會努力地找出其他缺點，

&nbsp;

譬如質料不夠挺，顏色太鮮豔，向售貨員證實，

&nbsp;

我們不是隨便來逛逛的，我有認真考慮過的呀！

&nbsp;

分手可以有很多原因，結合卻只有一個原因，

&nbsp;

原因就是：不需要原因！


&nbsp;
