[摘至網路]✪ 往好的方面想

_____________________________


&nbsp;


 

Jerry 是美國一家餐廳的經理,


他總是有好心情，當別人問他最近過得如何,

&nbsp;

他總是有好消息可以說,他總是回答


&nbsp;

"如果我再過得好一些, 我就比雙胞胎還幸運囉 !"
&nbsp;&nbsp;&nbsp; 
當他換工作的時候,

&nbsp;

許多服務生都跟著他從這家餐廳換到另一家,

&nbsp;

為什麼呢?


&nbsp;

因為Jerry是個天生的激勵者,如果有某位員工今天運氣不好,

&nbsp;

Jerry總是適時地告訴那位員工往好的方面想.
&nbsp;&nbsp;&nbsp;&nbsp; 

看到這樣的情境真的讓偶很好奇,


&nbsp;

所以有一天偶到Jerry那兒問他


&nbsp;

"我不懂!沒有人能夠老是那樣地積極樂觀, 你是怎麼辦到的?"

&nbsp;

Jerry 回答 "每天早上我起來告訴自己,


&nbsp;

我今天有兩種選擇, 我可以選擇好心情,


&nbsp;

或者我可以選擇壞心情,


&nbsp;

我總是選擇有好心情,即使有不好的事發生,

&nbsp;

&nbsp;

我可以選擇做個受害者,或是選擇從中學習,


&nbsp;

我總是選擇從中學習. 當有人跑來跟我抱怨,


&nbsp;

我可以選擇接受抱怨或者指出生命的光明面,

&nbsp;

&nbsp;

我總是選擇生命的光明面."

&nbsp;

&nbsp;

"但並不是每件事都那麼容易啊!" 我抗議地說

&nbsp;

&nbsp;

"的確如此" Jerry 說


&nbsp;

"生命就是一連串的選擇,每個狀況都是一個選擇,你選擇如何回應,


&nbsp;

你選擇人們如何影響你的心情,


&nbsp;

你選擇處於好心情或是壞心情. 你選擇如何過你的生活."
&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

&nbsp;

數年後, 我聽到Jerry 意外地做了一件你絕想不到的事:


&nbsp;

有一天他忘記關上餐廳 的後門,


&nbsp;

結果早上三個武裝歹徒闖入搶劫,他們要脅Jerry打開保險箱,


&nbsp;

由於過度緊張 ,Jerry 弄錯了一個號碼,


&nbsp;

造成搶匪的驚慌,開槍射擊Jerry, 幸運地,


&nbsp;

Jerry很快地被鄰居發現,緊急送到醫院搶救,


&nbsp;

經過18小時的外科手術,以及密集照顧,jerry終於出院了 ,


&nbsp;

還有塊子彈留在他身上.
&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

&nbsp;

事件發生6個月之後,我遇到jerry, 我問他最近怎麼樣,


他回答 "如果我再過得好一些, 我就比雙胞胎還幸運了.


&nbsp;

要看看我的傷痕嗎?" 我婉拒了,


&nbsp;

但我問他當搶匪闖入的時候,他的心路歷程. Jerry 答道


&nbsp;

"我第一件想到的事情是我應該鎖好後門的, 

&nbsp;

當他們擊中我之後 ,我躺在地板上, 

&nbsp;

還記得我有2個選擇:


&nbsp;

我可以選擇生,或選擇死. 我選擇活下去&nbsp;&nbsp; 

&nbsp;

"你不害怕嗎?" 我問他.

&nbsp;

Jerry 繼續說 "醫護人員真了不起,


&nbsp;

他們一直告訴我沒事,放心.


&nbsp;

但是當他們將我推入緊急手術間的路上,

&nbsp;

&nbsp;

我看到醫生跟護士臉上憂慮的神情,


&nbsp;

我真的被嚇到了, 

&nbsp;

他們的眼睛好像寫著 "他已經是個死人了"


&nbsp;

我知道我需要採取行動.

&nbsp;

&nbsp;

"當時你做了什麼?" 我問.

&nbsp;

Jerry 說 "嗯,


&nbsp;

當時有個碩大的護士用吼叫的音量問我一個問題;


&nbsp;

她問我是否會對什麼東西過敏." 我回答 "有.."


&nbsp;

這時醫生跟護士都停下來等待我的回答.
&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

我深深地吸了一口氣喊著 "子彈!" 聽他們笑完之後,


&nbsp;

我告訴他們 "我現在選擇活下去,


&nbsp;

請把我當作一個活生生的人來開刀, 不是一個活死人."

&nbsp;

Jerry 能活下去當然要歸功於醫生的精湛醫術,


&nbsp;

但同時也由於他令人驚異的態度.
&nbsp;&nbsp;&nbsp; 


我從他身上學到,每天你都能選擇享受你的生命,或是憎恨它.


&nbsp;

這是唯一一件真正屬於你的權利 --


&nbsp;

沒有人能夠控制或奪去的東西 -- 就是你的態度.
&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

&nbsp;

如果你能時時注意這件事實,


&nbsp;

你生命中的其他事情都會變得容易許多.

&nbsp;
