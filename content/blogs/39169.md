&nbsp;

人生在世，憂慮與煩惱有時也會伴隨著歡笑與快樂的。

&nbsp;

正如失敗伴隨著成功，如果一個人的腦子裏整天胡思亂想，

&nbsp;

沒有價值的東西也記存在頭腦中，那他或她總會感到前途渺

&nbsp;

茫，人生有很多的不如意。

&nbsp;

所以，我們很有必要對頭腦中儲存的東西，給予及時清理，

&nbsp;

該保留的保留下來，把不該保留的予以拋棄。

&nbsp;

那些給人帶來諸方面不利的因素，實在沒有必要過了若干年

&nbsp;

還值得回味或耿耿於懷。

&nbsp;

這樣，人才能過得快樂灑脫一點。

&nbsp;

眾所周知，在社會這個大家庭裏，你要想贏得別人的尊重，

&nbsp;

你首先必須尊重別人，多記住的優點，而學會遺忘別人的過

&nbsp;

失。

&nbsp;

其次，一個人要學會遺忘自己的成績，有些人稍微做了一點

&nbsp;

成績就驕傲起來，沾沾自喜，這顯然是造成失敗的一個原因。

&nbsp;

成績只是過去，要一切從零開始，那樣才能跨越人生新的境界。

&nbsp;

同時，一個人自己對他人的幫助，應該看作是一件微不足道

&nbsp;

小事，以至於遺忘。這樣，你的處事之道方能獲得他人的贊許。

&nbsp;

人生需要反思，需要不斷總結教訓，發揚優點，克服缺點。

&nbsp;

要學會遺忘，用理智過濾去自己思想上的雜質，保留真誠的情

&nbsp;

感，它會教你陶冶情操。
