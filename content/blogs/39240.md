&nbsp;

聊天是在尋找一種感覺

&nbsp;



&nbsp;

&nbsp;


聊天是在尋找一種感覺，

&nbsp;

是在尋找一種意境，是在尋找一種心態，

&nbsp;

更是在尋找一種"幸福"，

&nbsp;

生活在茫然不知所措的世界裏，

&nbsp;

我們的心情有時是痛苦低落的，有時是寂寞孤獨的，

&nbsp;

有時是失意無奈的，情緒跟隨著心態的變化而變化，

&nbsp;

心態跟隨著情緒的起伏而起伏。

&nbsp;

&nbsp;

當我們的心情處於低落之時，

&nbsp;

總想尋找一個心靈對話者發泄我們心中的憤您，

&nbsp;

當我們的心情舒暢興奮之時，

&nbsp;

也想尋找一個"心怡"的人分享我們此時此刻心中的快樂，

&nbsp;

高興也好悲哀也罷，尋找感覺是我們的靈魂在升華，

&nbsp;

尋找"幸福"是我們人生總美妙之快感，

&nbsp;

人生其實就是一種感覺在伴隨著，沒有感覺了就什麽也沒有.

&nbsp;

&nbsp;

現實生活中我們在尋找感覺，

&nbsp;

網絡世界裏我們也在尋找感覺，談天說地談情說愛是一種感覺，

&nbsp;

魂牽夢縈也也是一種愛的感覺。

&nbsp;

心靈相通卻是一種愛的意境，心心相印是愛的牽掛，

&nbsp;

魂不守捨是愛的一種另類幸福，或許你會發出一種人生的感嘆:

&nbsp;

"知心真難求,紅顏何處覓.

&nbsp;

"我們需要的是相互幫助能與我們共分享的朋友。

&nbsp;

&nbsp;

能竊竊私語心靈對白的,

&nbsp;

聽取知心話的感覺幸福歡樂的朋友，

&nbsp;

無論是同性還是異性紅顏，

&nbsp;

只要在一塊感到幸福美妙就是最好的了。

&nbsp;

&nbsp;

我們都是在尋找一種感覺，

&nbsp;

一種美妙無限的感覺，一種啟迪靈魂的感覺，

&nbsp;

一種令人心曠神怡,神采奕奕的感覺，

&nbsp;

大家都在不斷努力的尋找，

&nbsp;

因為尋找的過程本身就是一種幸福，

&nbsp;

就是人生的無限延伸！


&nbsp;
