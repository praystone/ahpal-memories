Hamurana Spring 的天與地


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


2010年四月十一日，傍晚剛從羅托路瓦撿完栗子飆車回家，這次撿栗子的地方是羅托路瓦市區以北，在一處叫做Hamurana Spring 的冷泉公園，距離觀光景點羅托路瓦開車半小時，算是周邊附屬的景點，但是一般觀光客囿於行程太趕，都不會去非常可惜。


&nbsp;


Hamurana Spring 森林園區可分為自然景觀、高球場二部分，前者又分冷泉、植物生態、動物生態三部分。


冷泉：羅托路瓦出名在它的地熱，也就是用之不竭的溫泉，本地人都買年票約二百五左右，天天去洗溫池洗澎澎哩！偏偏Hamurana Spring 出的卻是稀有冷泉，自公園入口處，沿著冷泉溪旁林間步道一路向裡走，溯溪而行約二十分鐘可達最大一處泉眼，深度十五公尺，每小時出水量高達450萬公升。冷泉溫度常保攝氏十度低溫，甘甜冷冽泡茶極品，我每次都會帶空瓶子去裝水，裝上來的水是冰的呢！今天就裝了四大瓶，下回帶菜籃車來拖，可裝更多。


&nbsp;


植物生態： Hamurana Spring 種植了為數不少的加州紅木，是紐國最早試種的一批，約在1920年種下，迄今九十年了，加州紅木樹型高大筆直，動輒近四百英尺高，直徑可達四十英尺，站在樹群下方抬頭仰望，陽光自葉間灑下，深淺不同的綠襯以藍天白雲，美到你寧願脖子酸痛也捨不得低頭不看，我每次去都會找一處樹最美的地方躺在天然落葉鋪成的紅色地毯上看個夠。<?xml:namespace prefix = v ns = "urn:schemas-microsoft-com:vml" /> 



走進沿溪步道，紅木森林的芬多精首先就洗滌了一身的都市污濁，清新芬芳的空氣令人精神振奮，溪水清澈蜿蜒迂迴，遠處高大的紅木樹群相襯，更顯深遠幽靜，除了踏在落葉上的腳步聲，妳身邊只有蟲鳴、鳥叫、微風穿過林間、潺潺溪水等等大自然的天籟。保持肅靜是最佳的拜訪方式，也是對身邊一切自然景物最高的尊重。 



溪水清澈透明，有多種水生植物，各類水草深淺不同鬱鬱蔥蔥，隨著水波悠然飄動，水草濃密處往往就是鴨群、天鵝等水鳥的築巢基礎。繁殖季節時往往可在水中高處、濃密近岸灌木叢中看到小天鵝、小綠頭鴨等等隨著爸媽在溪中覓食嬉戲。 


&nbsp;


動物生態：春夏季節在溪水中很容易看到彩虹鱒、棕鱒，Hamurana Spring 是一處少見的冷泉，也是羅托路瓦湖的發源地，園區內大小泉眼數不清，提供了清澈甘甜的冷泉源源不絕，這也是鱒魚如彩虹鱒、棕鱒的最愛，鱒魚必須生長在絕無污染的水中，水溫也必須很低，因此，冷泉攝氏十度，就是量身打造的「鱒魚天堂」。但這裡不准釣魚。

想釣鱒魚可到羅托路瓦湖和周邊小溪中去釣，可溯溪站在水中釣，可租船在湖心釣，或是秘密岸邊垂釣，釣到的鱒魚又大又肥，不怕釣不到，只怕釣到你拉不動。 



此地釣鱒魚必須買執照，可買單次或整年的，大小、數量有限制，而最重要的是「絕對禁止買賣」，市場是買不到的，要吃自己釣。要小心陷阱，有人釣到會來兜售，便宜算妳啦！二十、三十元，妳要是一時不查貪便宜買了，萬一被逮到或賣東西給妳的人就是漁業局的督察員inspector，你就等著吃牢飯＋重罰吧！ 



Hamurana Spring 公園入口處就是一個小湖，湖上架起一座木橋，遊客可站在橋上餵食水鳥，手中拎著土司袋子還沒打開，遠近水鳥就急速游過來，牠們認得麵包袋。少不得一陣喧鬧搶食，這時就可搶拍不少好鏡頭。



此地有不少英國大白鵝，牠們的特徵是有一個肥大的肚皮，特別是秋天開始準備過冬，一個個吃的肥肥的，肚皮都拖到地上了，在陸地行走實在是困難笨拙，下了水倒依舊敏捷。看牠們肥成這樣，我實在忍不住要幻想一下牠們的「桌上」英姿，金黃酥脆的皮、鮮嫩多汁的鵝腿….唉！罪過罪過！！ 



其餘有擅長潛水的小黑鴨Scaup、魚狗（潛水後需站上岸展開雙翼曬乾，樣子超爆笑），綠頭鴨Mallard 、紫水雞Pukeko、白冠雞等水禽，飛禽中有喜歡跟著你前後飛繞鳴叫的扇尾鳥Fanntail ，牠因尾羽張開向上豎起，像一把小扇子而得名，不過繞著你飛可不是喜歡你，而是因為妳入侵了牠的領域，在向妳示威呢！牧師鳥Tui，通體漆黑，唯獨喉嚨處有一撮白毛，很像牧師的黑制服領口處的白色小領夾，而牠的叫聲就是TUI（凸亦）。


&nbsp;


每次去Hamurana Spring ，我都一定帶好多空瓶去裝泉水，清甜甘美冷冽，拿回家不必放冰箱，幾個月都不會有變化，隨便喝都不會拉肚子。


Hamurana Spring 的自然生態是上帝的傑作，在此處無論動物、植物都擁有屬於他們應得的尊重與尊嚴。&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
