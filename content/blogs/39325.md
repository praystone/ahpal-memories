&nbsp;

一個人會有很多朋友 。


&nbsp;

卻不會有很多真正的知己。

&nbsp;

知己是能夠在心靈上相通， 


&nbsp;

能夠互相瞭解對方的人 。


&nbsp;

真正的知己不一定是夫妻， 


&nbsp;

也不是能整天相互廝守的人 。


&nbsp;

他們可能相隔遙遠， 


&nbsp;

也許會近在咫尺 ，

&nbsp;

他們能互相讀懂對方的每一個眼神。 


&nbsp;

能明白對方每句話的含義 。


他們無須花言巧語。


也無須朝夕相處 。


他們不在乎對方的相貌。 


也不在乎對方的貧陋 。


他們無須刻意隱瞞自己。


他們能容納對方的所有瑕疵。


他們肯為對方兩肋插刀。 


能為對方捨棄所有 。


當你遇到挫折時，


他會為你送去溫馨的話語。 


他會說一句損你尊嚴的話。


當你意氣用事時 ，


他會費盡心機為你擺明事理。


你有了錯誤他絕不遷就。 


會不厭其煩的幫助你 。

&nbsp;

當你心情不好時 ，


&nbsp;

他也不會和你一般見識大吵大鬧，


會為你想盡一切來排遣煩悶。


當你愉快時，


他也會把自己的愉快告訴你 。


與你共享那分喜悅。


當你煩惱時， 


他即使正在煩惱也不會告訴你。 


知己沒有相互間的佔有慾。


知己只有默默的奉獻自己。


知己就是彼此的牽腸掛肚。


知己就是彼此的心領神會。


人生得一知己足矣！
