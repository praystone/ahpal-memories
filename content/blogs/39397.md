二十五年前了吧！當時我在政大唸書，班上大部分都是女生，&nbsp;所以常會有台大、交大、清大的男生，來找我們班的女生出去跳舞聯誼、或郊遊烤肉。



&nbsp;



記得當時，我們班上有個女生，身高只有一百四十五公分，體重五十五公斤，圓圓滾滾的，臉上有一顆痣，又戴著近視眼鏡，很
像台語連續劇裡的阿匹婆，所以大家就叫她「阿嬤」。 



&nbsp;



&nbsp;那
時，我們這群漂亮女生都有男生追，經常出去談戀愛，唯獨阿嬤，總是孤零零的，沒有男生願意追她、或邀她出去玩。不過，阿嬤卻依然個性開朗，她總是很豪氣地
說：「像我這麼有才華的女生，我才不願意隨便亂嫁，我將來一定要嫁給清華學理工的電機工程師，而且，身高一定要一百七十五公分以上，才能改善我的矮小品
種！優生學不都是這麼教我們的嗎？」 



&nbsp;



每
當阿嬤笑嘻嘻地在「高談闊論」、大談自己「遠大的志向」時，我們這群女生就嗤之以鼻、暗自地笑她－－「呵，阿嬤也不去照照鏡子，看看自己的模樣……」當
然，阿嬤都知道我們在取笑她，不過她仍然樂觀、笑瞇瞇地說－－「妳們不要笑我，我告訴妳們，只要我覺得能，我就一定能！」



後來，清大的男生又來邀我們出去烤肉，只見阿嬤大聲地說：「&nbsp;買肉、醃肉、買沙茶醬、買飲料、買木炭……這些拉雜的事，都由我阿嬤來處理就好了，妳們都可以放心！」 



&nbsp;



烤肉當天，我們這群「自認美女」的女生，只負責把自己打扮得漂亮、美美的，什麼事都沒做；而阿嬤呢，卻搬著木炭、醃肉、飲料，汗流浹背地在營地裡升火、烤肉，並將烤好的肉分送給大家吃。 



&nbsp;



那天，清華電機帥帥的班代，身高一百七十六公分，剛剛失戀、&nbsp;心情很低潮；可是，阿嬤這個人「很賊」，她就趁機發揮她「母性的本能」，不斷地安慰他、陪伴他、逗笑他，也讓那帥哥班代吃飽飽的、吃得很舒服.... 



&nbsp;



你知道嗎，畢業後，我們全班女生都跌破眼鏡，大家不敢相信地 



&nbsp;



奔相走告－「阿嬤結婚了耶！」



「真的啊？怎麼那麼快？她嫁給了誰？」 



&nbsp;



「她嫁給了那個清華電機的帥哥班代啊！」天哪，阿嬤怎麼會嫁給帥哥？太離譜了吧！ 



「啊？怎麼可能？太可笑了，他們兩個人怎麼可能在一起？」 



&nbsp;



「是真的，他們真的結婚了！」 



「啊？是真的？那我保證，他們一、兩年內就會離婚！」「&nbsp;真的，我們這些女生聽到「阿嬤嫁給帥哥」時，都又憤恨、又嫉妒，真想詛咒她幾句，也希望不久之後，就可以馬上聽到她「離婚的不幸消息」。 



&nbsp;



然而，二十多年過去了，以前我們這些被別人捧在手上、大談戀愛的美女，結婚，卻又一一離婚了；而阿嬤呢，卻仍和她的白馬王子、清華老公，兩人如膠似漆、恩恩愛愛，每天長相廝守。 



&nbsp;



那天，我問同學：「阿嬤現在怎麼樣？」「她還住在新竹啊，她先生已經是電子公司的高級主管，住在別墅裡。」「那她的小孩呢？」「她兒子考上建中，女兒唸了北一女啊……rn天哪，怎麼天下所有的好事，都讓阿嬤一個人給全包了？ 



&nbsp;



記得，在阿嬤結婚當晚，班上一暗戀帥哥新郎的女生，忍不住地大聲問新郎：「喂，帥哥，我們班上美女那麼多，你為什麼偏偏要選擇阿嬤？你說，你到底看上阿嬤哪一點？」 



&nbsp;



新郎想了一下說：「說真的，阿嬤並不漂亮，可是我娶了她，我就很放心，因為她溫柔勤勞、快樂開朗；不像我以前的女朋友，是美女漂亮，可是每天卻愛耍脾氣、要我伺候她！我如果娶了她，每天都會擔心『哪一天會惹惱她、失去她？』 



&nbsp;



可是，阿嬤把我當成『寶』，我一輩子ㄛ都是阿嬤心中最珍貴的寶，我當然選擇她呀！」 



&nbsp;



聽到朋友告訴我的這則真實故事，真是有趣，也不禁想到－－ 



&nbsp;



年輕漂亮的女孩啊，妳要做個冷若冰霜、要人服侍、愛耍脾氣的「大美女」呢？還是要做一個樂觀、開朗、溫柔勤勞的「阿嬤」呢？ 



&nbsp;



大美女，什麼事都不做，都要別人做，只要被別人「捧在手心」「天天呵護」；可是，男人選擇對象時，不一定都要選擇這種「令人擔心的大美女」呀！



所以，快樂、開朗的醜女有福了，因為她們最後都可能會嫁給美男子啊！ 



&nbsp;



戀愛小講義 



有人說：「沒有笨小孩，只有懶父母。」的確，若是小孩表現不佳，那父母一定有責任，可能父母太懶了，才沒有把小孩教好。 



&nbsp;



也有人說：「沒有醜女人，只有懶女人。」是的，再美麗的女人，若整天懶散、不勤快、不做事，則看起來也是十分醜陋的。 



&nbsp;



其實，上天會給人們一個「愛情的奇蹟」，但，婚姻的經營卻需有「努力的成績」！ 



&nbsp;



如果，女人只是靠著美麗的外表，來擄獲男人的心，可是，她這個大美女，若永遠需要別人伺候，也要別人順著她、呵護她，那麼，誰能天天小心翼翼地捧著她、哄著她，怕她發怒生氣呢？美貌不足恃呀！ 



&nbsp;



事實上，人的心，才是最重要的﹔能開朗、常微笑，做事主動、勤快、不抱怨、不生氣，這不就是令人喜歡的女人嗎？ 



所以《聖經》上說：「艷麗是虛假的，美容是虛浮的……才德的婦人，價值遠勝過珍珠。」 



&nbsp;



一般來說，出家修行的人，是不結婚的，可是感情和婚姻，卻可以讓人修行。 



&nbsp;



一
個外表美麗的大美女，若只是一直花錢在打扮自己，一直衣著美艷亮麗、花枝招展，可是，若無內涵、若無才德，看久了，似乎是少了些什麼？就像是「失了溫度的
溫泉」，不熱了、不燙了，還有誰願意進去池子裡浸泡呢？人，總要用氣質、內涵、才德來打扮自己；人，總是要開朗、勤快、樂觀來讓自己永保新鮮！ 



所
以，有一男人說，他經常相親，看到女方身材矮胖，心裡很不甘願﹔可是媒人向他保證，這女生雖不是長髮美女，但她心地善良、做事勤快、很會理財，而且「醜妻
家中寶」，絕不會有男人來勾引，也不會紅杏出牆！後來，他們結婚了，兩人同甘共苦，十年後，他從兩袖清風，變成擁有三棟房子！ 



&nbsp;



真的，女人要讓自己永保新鮮、永保開朗、永保熱情、永保勤奮！
