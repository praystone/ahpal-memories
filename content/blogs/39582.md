&nbsp;

累了：別逞強，歇會；煩了：別悶著，找樂；困了：別硬撐，早

&nbsp;

點睡；樂了：別獨吞，與我分享；

&nbsp;

想了：別不說，與朋友聯繫；人生短暫，要善待自己！

&nbsp;

一日一笑，越來越俏；一日二笑，吉星高照；一日三笑，未來有

&nbsp;

個好依靠；笑笑笑，幸福跟著就來到！

&nbsp;

做人記得天天笑，今天你笑了沒有？累了：請將心靠岸;錯了：請

&nbsp;

不要後悔；苦了：你才懂得滿足；傷了：才能明白堅強；
&nbsp;
醉了：才能知道難忘；笑了：才能體會美麗；悶了：才知有朋友

&nbsp;

是最好！

&nbsp;

因為有了你的摯誠，雪化了；因為有了你的爽朗，天晴了；

&nbsp;

因為有了你的笑容，風停了；因為有了你的熱情，空氣暖了；

&nbsp;

因為有了你這個朋友，我也快樂了！

&nbsp;

累了：要好好休息;錯了：別埋怨自己；苦了：是幸福的 階梯；

&nbsp;

傷了：才懂得什麼是珍惜；醉了：就是折磨自己；

&nbsp;

笑了：便忘記曾經哭泣；悶了：才知朋友最好！

&nbsp;

有難題了嗎？

&nbsp;

我要繞過去、跳過去、闖過去、晃過去、溜過去、

&nbsp;

混過去，實在不行，暈過去！哈哈，笑一笑!
