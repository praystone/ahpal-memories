&nbsp; 


&nbsp;

生命中終將會錯過一些人，

&nbsp;

我們應該感謝那些錯過的人，

&nbsp;

他們讓我們明白了幸福的珍貴，

&nbsp;

是該好好反省自我的時候了，

&nbsp;

不要再去錯過適合自己的人了，

&nbsp;

不要任由往事的缺憾佔據痛楚的心扉，

&nbsp;

時光不等人，只有人去等時光。

&nbsp;

不要相信該是自己的終該是自己的，

&nbsp;

不去爭取不去把握的話，永遠都不會有機會。

&nbsp;

緣分是什麼，緣分就是給了你一次遇到的機會，

&nbsp;

幸福全靠去爭取。

&nbsp;

天上不會掉下禮物，

&nbsp;

天底下也不會有無緣無故的良緣，

&nbsp;

天賜的更在於人為。

&nbsp;

我們都應該去爭取，去珍惜，

&nbsp;

不要再錯過了--

&nbsp;

&nbsp;“執子之手，與子偕老”的人生忠實的伴侶。

&nbsp;

世事無常，人生反覆，我們不管什麼時候，

&nbsp;

處在怎樣的環境裡，都要堅定自己的信仰，


不要讓遺憾吞噬了靈魂，

&nbsp;

不要讓生命飲恨在荒廢的時光……

&nbsp;
