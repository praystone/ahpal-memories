[摘至網路]✪ 每一個人都是一個獨立的主體
_____________________________


&nbsp;


 

星期日的那一天，大衛的兒子與同學出去，

&nbsp;

大衛一個人來到兒子的房間，發現兒子的書


桌上很亂，就走過去想整理一下。
&nbsp;&nbsp; 

此時，大衛突然靈機一動，就打開兒子的抽屜，發現了一個藍色的日記本。
&nbsp;&nbsp; 

兒子的日記本第一頁上寫道．．

&nbsp;

「自打我上初中以後，我的心裹十分的空虛與孤獨，父母


&nbsp;

除了關心我在學校的表現外，跟本就不會關心我

&nbsp;

對學校、對生活的各種感受與希求，

&nbsp;

每天當我伏在桌前，永不停地寫那永遠做不完的該死的作業時，

&nbsp;

我特別地痛苦，我多麼想能像其他同學那樣，

&nbsp;

能有時間到外面去打打籃球，去輕鬆地活動一下啊‥‥」
&nbsp;&nbsp; 

&nbsp;

讀完兒子的日記，大衛內心感到了一種強烈的震撼。

&nbsp;

他原以為自己的心靈與兒子貼得很近，可萬萬沒有料到兒子

&nbsp;

並沒有把自己當作「朋友」，雖然他自以為是除了父親之外，

&nbsp;

也是「朋友」。
&nbsp;

&nbsp;傍晚，兒子回到家裏，又關上房門獨處，吃晚餐的時候，

&nbsp;

兒于突然問道：「爸，你們倆誰動過我的東西了?」
&nbsp;

&nbsp;大衛假裝糊塗地說：「沒有啊!」
&nbsp; 

見大衛如此的裝聾作啞，兒于什麼也沒說，就滿臉不悅地走開了。
&nbsp; 

過了兩天以後，乘著兒于不在家，大衛又偷偷溜進他的房間，

&nbsp;

企圖從日記裏洞察他內心的祕密，令大衛驚訝的是，

&nbsp;

抽屜上不知何時安裝了一把鎖。


&nbsp; 

頓時．大衛的大腦一片空白，大衛突然意識到自己犯了一個低級錯誤，

&nbsp;

他不應該私下偷窺兒于的祕密，應該尊重兒子的隱私才是。


&nbsp; 

晚上，兒子回到家後，

&nbsp;

大衛鼓足勇氣對兒子說：「兒子，爸爸犯了一個錯誤，

&nbsp;

你能原諒我嗎?」
&nbsp;

&nbsp;兒子沈思片刻說:「不就是偷看日記的事嘛，我不想再談這件事。」
&nbsp; 

「如果你原諒爸爸，就請你打開鎖，別把爸爸當賊似的。」
&nbsp; 

兒于氣呼呼地對大衛說：「這是鑰匙，交給你，這回你滿意了吧?」


&nbsp;

大衛望著桌上的那把鑰匙，當場愣住了。
&nbsp; 

若千天以後，當大衛無意中再一次來到兒于的房間時，

&nbsp;

一心想走進兒子內心世界的大衛，

&nbsp;

又鬼使神差般地欲偷看兒子的日記。
&nbsp; 

大衛驚訝地發現，兒子的抽屜雖然沒有上鎖，

&nbsp;

可那日記本不知何時已無影無蹤了。
&nbsp;

&nbsp;有一天，兒子突然對大衛說：「老爸，你是不是覺得很失望?」
&nbsp; 

「這話怎講?」
&nbsp; 

大衛對兒子的問話，感到十分不解。
&nbsp; 

「因為我把日記扔了，並且發誓，以後不會再寫日記了。」
&nbsp; 

大衛這時才徹徹底底地覺悟到&nbsp; 兒子心中早已有了一把鎖。

&nbsp; 

&nbsp;

雖然父親與兒子之間的問係十分親密，

&nbsp;

但是他們之間的地位應該是平等的，

&nbsp;

誰也不應該侵入另一方的「私人領域」，

&nbsp;

因為每一個人都是一個獨立的主體。

&nbsp;
