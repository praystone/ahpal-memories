[摘至網路]✪ 做女人難，做男人更難～
_____________________________


&nbsp;


 

男人累，所以才去敲背 


&nbsp;

男人愁，所以才去洗頭 


&nbsp;

男人苦，所以經常去賭 


&nbsp;

男人忙，所以經常上錯床 


&nbsp;

男人這輩子挺難的 


&nbsp;

帥點吧，太搶手 


&nbsp;

不帥吧，拿不出手 


&nbsp;

活潑點吧，說你太油 


&nbsp;

不出聲吧，說你太悶 


&nbsp;

穿西服吧，說你太嚴肅 


&nbsp;

&nbsp;

穿隨便點吧，說你太庸俗 


&nbsp;

會賺錢吧，怕你包2奶 


&nbsp;

不會賺錢吧，又怕孩子斷奶 


&nbsp;

結婚吧，怕自己后悔 


&nbsp;

&nbsp;

不結婚吧，怕她后悔 


&nbsp;

要個孩子吧，怕出來沒人養 


&nbsp;

不要孩子吧，怕老了沒人養 


&nbsp;

這年頭做女人難，做男人更難！ 


&nbsp;

男同胞們～對自己好點吧…！
