三、當腎臟出現問題時<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 我們的身體會產生的現象會有：腎臟有兩條通路，從腳底的涌泉上來，走到腳後


&nbsp;&nbsp;&nbsp;&nbsp; 根內側，再順著腿的內側往上走。


&nbsp;


　　 第一條從後方上來走到腰與膀胱結合，再順著脊椎兩側往上走當我們腎臟不好，


&nbsp;&nbsp;&nbsp;&nbsp; 氣會不足，血就上不來；因此腰會酸，背會痛，再往上到頸部，頸部會覺得僵硬；


&nbsp;&nbsp;&nbsp;&nbsp; 到了後腦勺會感覺昏脹不舒服，到了頭頂會覺悶脹，過了頭頂往下到兩個眉心之


&nbsp;&nbsp;&nbsp;&nbsp; 間的"精明穴"，氣不到會覺兩眼幹澀。


&nbsp;


　　 第二條從前面上來，經過大腿跟我們的生殖器及肝臟結合，最後延著身體兩側到


&nbsp;&nbsp;&nbsp;&nbsp; 胸前與肺臟結合。


&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;&nbsp;&nbsp;&nbsp; 腎臟有問題，大腿兩側會酸、軟、無力，經常發癢。


　　&nbsp; 1.無法把氣送到胸口與肺臟結合，我們的呼吸就慢慢不順暢，久了以後裏面的


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 氣管就會自然閉鎖，一閉鎖空氣就不易進來，人就會感覺到窒息，必須"幹咳


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; "來減緩它。


&nbsp;


　　&nbsp; 2.氣不足不能與膀胱結合，造成膀胱中括約肌的細胞就容易代謝死亡而造成鬆


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 弛，排尿狀況不好，頻尿，久了以後細胞慢慢壞死，最後就尿失禁。


&nbsp;


　　&nbsp; 3.看東西的瞳孔部份叫做"視覺"，就是由腎臟直接控制，腎有問題，不能將腎


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 水送達到眼睛，眼會覺得幹、酸、澀、慢慢視覺就會模糊，嚴重會出現黑影，


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 叫做"飛蚊症"，久了以後壓力會越來越大，造成"青光眼"。


&nbsp;


　　&nbsp; 4.早上起床，腳後跟會不舒服因為，人在休息時，血液是在肝，腎臟會暫時缺


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 血，起床須把血液送至全身，由於腎臟不好，氣太弱，血液來的太慢，關節


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 失血自然就會僵硬，活動一下，血液迴圈到了關節才會輕鬆。


&nbsp;


　　&nbsp; 5.人活著就會講話，講話耗元氣，本身腎臟不好氣太弱，再把氣耗掉就會不想


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 說話，因工作不能不說話時，聲音就會出不來，就會沙啞。


&nbsp;


　　&nbsp; 6.想要深呼吸總是覺得氣不夠，自然呼吸就會快，呼吸一短促，鼻腔就會缺血，


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 鼻腔的黏膜因為缺血，抵抗力就會減低，空氣中的塵蹣就會破壞它，破壞了


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 當然就會敏感，天氣潮濕、變化，承受不了就會發作，稱為"過敏性鼻炎


&nbsp;


　　&nbsp; 7.男性朋友的攝護腺，婦女的卵巢、子宮都間接、直接跟腎臟有關，因此，腎


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 臟有了問題，到了一定的年齡，攝護腺就會肥大；婦女因腎臟不好，卵巢、


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 子宮就會虛弱、寒冷，虛寒就沒有力量將每個月應該排出的經血排掉，排不


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 乾淨都還滯留在子宮裏，每個月經血都要出來，不能完全排掉都停留在子宮


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 裏，久了難免造成血塊堆積，形成腫瘤，稱為"子宮肌瘤"。


&nbsp;


　&nbsp; 　8.每個月經血出不來，在裏面來回撞擊，子宮的內膜會受不了這些經血會受不


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 了這些經血在裏面的推擠，就會變形、異位，稱為"子宮內膜異位"；慢慢的


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 內分泌就會混亂，過多的分泌物，赤白帶就會形成。


&nbsp;


　&nbsp; 　9.時間久了，腎臟越來越不好，氣越來越弱，手腳就會開始冰涼，尤其到了冬


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 天特別冰冷。慢慢久了，坐也不是，站也不是，走也不是，肯定會造成神經


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 受傷，晚上睡覺不好入睡，好不容易睡著了，一點點聲音就會被吵醒，縱使


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 睡著了，整夜都在作夢，有睡跟沒睡一樣，天天都很累。
