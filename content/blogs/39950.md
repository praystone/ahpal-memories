五、糖尿病<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;




　1.糖尿病不只是胰島素不足而已，而是腎臟、肝臟、心臟都不是很健康的情形下


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 所形成的，因此不易醫治。而且易造成其他病變如：腎臟衰竭、中風、失明、


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 截肢……


&nbsp;


　　 2.糖尿發展到一定階段會明顯出現三多一少的症狀。三多（吃多、喝多、尿多）


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 一少（體重減少）。


&nbsp;


&nbsp;&nbsp;&nbsp; 糖尿病患者可能發生下列幾項症狀：


&nbsp;


　　 1.視力異常：因糖尿會引起眼睛末梢微血管阻礙，造成眼睛易疲勞、視力模糊、


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 細小字看不清，嚴重者會導致失明。


&nbsp;


&nbsp;　　2.易疲勞：因體內血糖無法進入細胞，導致全身無力。


&nbsp;


　 　3.皮膚抵抗力差：體質通常呈現酸化，末梢血管易堵塞，傷口不易癒合、易化膿、


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 也易引起牙周病、香港腳。


&nbsp;


　 　4.神經障礙：肌肉和神經組織得不到滋養，因此阻塞迴圈不良，指尖出現麻痛，


&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;重者甚至失去感覺。


&nbsp;


　 　5.傷口不易癒合：糖尿末期，因末梢血管壞死，傷口發黑、潰爛不易癒合，有時


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 甚至需截肢以延續生命。
