那是我嗎？〖轉貼〗<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />



&nbsp;


最近突然間會很氣自己，為什那麼笨，


為什麼那麼煩，為什麼那麼怕別人生氣，


為什麼最近做事都那麼的沒有信心，那麼的膚淺呢？ 


為什麼為什麼？ 


&nbsp;


自從長大之後，都很少跟家人說我的事了，


尤其是受委屈的事，然後就一直藏在心裡，


不斷的壓抑著，一直告訴自己，沒事的，很快就過去的。


&nbsp;


但是當委屈一個接一個的來，我發現我越來越承受不了了，


又不敢說出來。越來越辛苦了.............


&nbsp;


&nbsp;


&nbsp;


&nbsp;


每次都會突然間流淚，


就好像那天我朋友在網上送了首歌給我，我一邊聽一邊流淚，


其他朋友問我那首歌有什麼感動的，我不懂如何解釋。 


&nbsp;


就是覺得有一個人跟我感同身受，結果眼淚就留下來了。


&nbsp;


覺得我越來越不像我自己了，沒有了判斷力，


平時最不喜歡做作的人了，但是越來越覺的我自己很做作，


一點都不像我自己。


&nbsp;




&nbsp;


&nbsp;


一時又做了些無聊而且做了才覺得為什麼我做了。


我真的很煩，辛苦。 


要如何這些東西才能爆發出來呢？ 


如何才會走出我的腦海呢？


&nbsp;


我每天就在逃避，逃避我所面對的東西，


不想想它，但是最後還是會想啊！


&nbsp;


每天一有空的時候我就會想東想西，


想回為什麼我會受到這些委屈？ 


是哪裡出了問題呢？


&nbsp;




&nbsp;


累了，快支撐不下去了........

心痛，心累，頭也痛了........
