一種異性朋友叫-溫暖

&nbsp;



&nbsp;


這種異性之間的友誼確是存在的，

&nbsp;

並且它的名字應該叫做——溫暖。


&nbsp;

當你高興時，你會第一個想到他，把你的快樂告訴他。

&nbsp;

而他 會比你更加高興，他會陪你一起興奮、一起開懷大笑。

&nbsp;

當你傷心時，你也會第一個想到他。

&nbsp;

他不會和你一同悲傷，而會用他特有的方式，

&nbsp;

給你鼓勵、給你體貼，讓你在他的關懷中 感到絲絲溫暖，

&nbsp;

在不知不覺中撫平你心靈的創傷。

&nbsp;

當因為你的固執而傷害了自己時，他會大聲地訓你，

&nbsp;

甚至會罵 你幾句，但你也從不會記恨，

&nbsp;

甚至你體會到的是一種暖暖的心意。

&nbsp;

同時，你也會為他而拿出你的真心與真情，

&nbsp;

也會把他的一切 記在你的心間。

&nbsp;

&nbsp;

當你知道他要出門遠行，

&nbsp;

你會發自內心地為他的行程擔心和祝福； 

&nbsp;

當你知道他身體有什麼不適，

&nbsp;

你會真心真意地為他而感到心疼；

&nbsp;

當他的事業不順心，你會真心地為他焦急，

&nbsp;

並奉上你微薄而真心的鼓勵。

&nbsp;

這種朋友，你可以和他開各種深淺不一的玩笑，

&nbsp;

甚至會說：「我喜歡你，我愛你。」

&nbsp;

而不必擔心他會真的成為你的情人

&nbsp;

而 讓你受到一絲一毫的傷害。

&nbsp;

你可以把自己所有的心裡話都說給他聽，

&nbsp;

甚至是夫妻之間、情人之間都無法表達的心裡的秘密。

&nbsp;

而這時候 的他，就是一個最好的聽眾，

&nbsp;

一個最好的咨詢專家，為你解除心底的迷惑和痛苦。

&nbsp;

這種朋友，不會有像情人那樣，

&nbsp;

一日不見如隔三秋的相思，

&nbsp;

但也會時時從心底扯出一絲絲牽掛，從而溫暖你的心。

&nbsp;

這種朋友，不管有多長時間沒見，

&nbsp;

見了後，都會有一種最親、最近的感覺，

&nbsp;

都會讓你有一種溫馨的暖意在心中升起。

&nbsp;

在你需要的時候，他總是一棵大樹，

&nbsp;

為你撐起一把摭風擋雨的綠傘；

&nbsp;

在你無力的時候，他會為你撐起一片藍天。

&nbsp;

而他卻從不求回報，

&nbsp;

只需你抬起頭，為他獻上甜甜的一笑；

&nbsp;

只需你輕輕地撫摸一下他粗大的樹幹，

&nbsp;

他就會因你的鼓勵而成長地更加枝繁葉茂。

&nbsp;

而那種鬱鬱蔥蔥地綠，會給你更多舒心的清涼。

&nbsp;

&nbsp;

很多時候，我們用自己的方式與標準去經營友誼，

&nbsp;

卻往往忽略了對方的存在。

&nbsp;

堅持只用自以為是的方法經營友誼，它會帶來許多壓力。

&nbsp;

此因你認為付出許多，對方卻拒絕湧泉以報。

&nbsp;

拉扯之間，友誼即出現裂痕。

&nbsp;

雙方積怨壓在心中，時間一到，

&nbsp;

火山整個爆發，友誼終於壽終正寢。

&nbsp;

&nbsp;

所以，即使世間知音難尋，

&nbsp;

但如能學習先做別人的朋友，成功的機會才較大。

&nbsp;

一個有智慧的人，會先選擇交往的對象，

&nbsp;

其後視情況決定深交的程度。

&nbsp;

有的朋友在特定時空中如魚得水，過了則船過水無痕。

&nbsp;

唯有知音，歷經歲月滄桑而更加燦爛；

&nbsp;

然而雙方的付出卻是先決條件。

&nbsp;

&nbsp;

因此，當你在人生旅途中巧遇好友時，

&nbsp;

最好用經營事業的心情來處理友誼。

&nbsp;

許多人跟著感覺走，最後多半抱憾終生。

&nbsp;

人會改變，但許多特質卻恆久如常，

&nbsp;

例如喜歡別人了解自己的嗜好與背景，

&nbsp;

不喜歡被人操弄，渴求對方的諒解，

&nbsp;

厭惡朋友的疑心。

&nbsp;

人們多半希望受苦時朋友伸出雙手，

&nbsp;

成功時也贏得對方的祝福，而後者卻往往很難做到。

&nbsp;

拿捏之間，需要一生不斷的學習。


&nbsp;
