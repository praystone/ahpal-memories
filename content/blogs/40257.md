&nbsp;

&nbsp;

生活中 有的人活的特別的輕鬆，而有的人活的特別的累，
&nbsp;
活的輕鬆的人是拿得起，放得下，
&nbsp;
而活的特別累的人是拿得起，放不下的，
&nbsp;
生活中有很多事不得不放棄，也不得不放下，
&nbsp;
棄應該放棄的才是人生最高境界，人生路上有很多的風景，
&nbsp;
而每一處風景都如詩如畫，人生路上有許多的捨與得，
&nbsp;
而每一種選擇都有它美麗的地方，
&nbsp;
人一昧的沈浸在回憶的世界裡，總想著過去的那些事那些人，
&nbsp;
有人說這是浪費生命，也有的人總沈浸在權力與名利的角逐中，
&nbsp;
有人說這是貪婪，有的人一輩子只為一個人而活，
&nbsp;
有的人一輩子只能記住一個人，有的人一輩子只為自己 有的........
&nbsp;
人一生只為別人 ，不管你選擇什麼樣的生活態度，
&nbsp;
也不管你選擇什麼樣的生命之路，如果你是幸福的，就堅持 ，
&nbsp;
而如果你是痛苦的而且並不快樂，為什麼不去選擇改變以前的生活模式，
&nbsp;
為什麼不去放棄應該放棄的東西?為什麼不去另辟蹊徑呢?
&nbsp;
朋友今天告訴我，她終於放下了近N年的感情之苦 ，
&nbsp;
為她高興也為她慶幸 走出這一步，也許真的需要很大的勇氣和忍耐，
&nbsp;
走出這一步，她幾乎好幾天睡不著吃不下，
&nbsp;
曾經是那樣的想他戀他愛他 可是，他卻冷漠如冰，


朋友明知道她錯了，而且明白錯的很深 可是她就是忘不了他，
&nbsp;
就是老牽掛著他 ，朋友告訴我， 她等了這麼久，堅持了這麼久，
&nbsp;
就是為給他祝福一個生日，因為她曾經答應過他，要為他過一個生日，
&nbsp;
可是現在他卻不願意見她不願意理她 所以她還是放下了所有的尊嚴，
&nbsp;
放下了所有的自信，甚至放下了自己的人格，給他發去了生日的祝福，
&nbsp;
給他送去了最真誠的祝願，給他送去她的思念，給他送去了她的愛戀，
&nbsp;
而他一字未回，連一個最簡單的謝字都沒有，朋友失望了，
&nbsp;
她知道該是放手的時候了!
&nbsp;
曾經有過這樣一句話“如果你愛他，請放手 讓他尋找自己的幸福快樂，
&nbsp;
如果你不愛他，請放手 也給自己一次選擇的機會”
&nbsp;
放棄應該放棄的 會改變你的生活，使你的生命更加精彩，
&nbsp;
放棄應該放棄的，會改變你自己的形象，讓你的人格更加的豁達開朗，
&nbsp;
放棄你應該放棄的，會改變你自己的命運，讓你的生命更加的美麗動人，
&nbsp;
學會放棄吧，放棄失戀的痛苦，放棄留在心裡的仇恨，放棄心中難言之隱 。 
&nbsp;
放棄無謂的爭吵，放棄權力的角逐，放棄虛偽的生活態度，放棄感情的創

&nbsp;

傷。 放棄所有的夢幻人生，放棄所有應該放棄的，做人要拿得起，放得下!
&nbsp;
做事也一樣，拿得起，放得下 做人拿得起，實為可貴!
&nbsp;
做事拿得起，實為難得 做人放得下，是人生的真諦 做事放得下，是生活的感

&nbsp;

悟!
&nbsp;
生命中陪伴我們走過的人很多，所以我們要學會選擇真心的朋友，
&nbsp;
生命中我們遇到的情感特別的多，而真正能陪我們走完人生的只有一個人。 
&nbsp;
生命中我們經過的事情也特別的多，而適合我們自己的事情只有一點點，
&nbsp;
所有我們要學會選擇，生命中給于我們的太多太多了，珍惜應該珍惜的，
&nbsp;
放棄應該放棄的，才是人生最真實的境界!
&nbsp;
做一個拿得起，放得下的人，才是生命中最完美的人!!

&nbsp;

不要評價別人的德行，因為你不比他高尚。&nbsp;
&nbsp;

不要評價別人的家庭，因為那和你無關。

&nbsp;

不要評價別人的學問，因為世上最不缺的就是學問。 

&nbsp;

總之，不要評價任何人，哪怕是你的家人。

&nbsp;

&nbsp;

不要亂花錢，因為明天你就可能失業。 

&nbsp;

不要趾高氣揚，因為明天你就可能失勢。 

&nbsp;

不要太過張揚，因為要明白沒有一個人會比你弱小。 

&nbsp;

不要委屈自己，因為明天你就可能死去。

&nbsp;

總之，做人低調一點。
