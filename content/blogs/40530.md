母親一生中撒的八個謊

&nbsp;




&nbsp;

&nbsp;


1、兒時，小男孩家很窮，吃飯時飯常常不夠吃，

&nbsp;

母親就把自己碗裏的飯分給孩子吃。


母親說，孩子們，

&nbsp;

快吃吧，我不餓！&nbsp;母親撒的第一個謊 

&nbsp;

&nbsp;

2、男孩在發育的時候，勤勞的母親常利用

&nbsp;

週日休息時間去田旁的河溝裏撈些魚來給孩子們補鈣。 

&nbsp;

魚很好吃，魚湯也很鮮。孩子們吃魚的時候，

&nbsp;

母親就在一旁啃魚骨頭，用舌頭舔魚骨頭上的肉漬。

&nbsp;

男孩心疼，

&nbsp;

就把自己碗裏的魚夾到母親碗裏，請母親吃魚。

&nbsp;

母親不吃，母親又用筷子把魚夾回男孩的碗裏。

&nbsp;

母親說，孩子，快吃吧，

&nbsp;

我不愛吃魚！ 母親撒的第二個謊

&nbsp;

&nbsp;

3、上國中了，為了繳夠男孩和哥姐的學費，

&nbsp;

當縫紉工的母親下班後還去工廠領些半成品回家來做，

&nbsp;

每個晚上辛勤的賺點手工錢來補點家用。 

&nbsp;

有個冬天，男孩半夜醒來，

&nbsp;

看到母親還躬著身子在微弱的燈光下做代工。 

&nbsp;

男孩說：媽媽睡了吧，明早您還要上班呢！

&nbsp;

母親笑笑說，孩子，你快睡吧，我不睏！母親撒的第三個謊 

&nbsp;

&nbsp;

4、大學聯考那年，

&nbsp;

母親請了假陪著男孩參加大學聯考為男孩助陣。

&nbsp;

時逢盛夏，烈日當頭，

&nbsp;

固執的母親在炎熱的天氣下一陪就是幾個小時。 


考試結束的鈴聲響了，母親迎上去遞過一杯用保溫瓶

&nbsp;

泡好的人蔘茶叮囑孩子快喝了，茶濃，情更濃。 

&nbsp;

望著母親乾裂的嘴唇和滿頭的汗珠，

&nbsp;

男孩將手中的保溫瓶反遞過去給母親喝。 

&nbsp;

母親說，孩子，快喝吧，我不渴！ 母親撒的四個謊 

&nbsp;

&nbsp;

5、父親病逝之後，母親又當爹又當娘，

&nbsp;

靠著自己工廠裏那點微薄收入，

&nbsp;

含辛茹苦拉扯著幾個孩子，

&nbsp;

供他們念書，日子過得苦不堪言。 

&nbsp;

隔壁巷裡的李叔叔知道後，

&nbsp;

大事小事就找岔過來打個幫手，送些錢糧來幫助男孩的家裏。 

&nbsp;

人非草木，孰能無情。左鄰右舍對此看在眼裏，

&nbsp;

記在心裏，都勸母親再嫁，何必苦了自已。

&nbsp;

然而母親多年來卻守身如玉，

&nbsp;

始終不嫁，別人再勸，母親也斷然不聽，勸也無用。

&nbsp;

母親說，我不愛！ 母親撒的五個謊 

&nbsp;

&nbsp;

6、男孩和她的哥姐大學畢業開始工作後，

&nbsp;

退休的母親就在附近夜市擺了個水果攤維持生活。

&nbsp;

身在外地工作的孩子們知道後，

&nbsp;

就常常寄錢回來補貼母親，

&nbsp;

母親堅決不要，並將錢退了回去。 

&nbsp;

母親說，我有錢！ 母親撒的六個謊 

&nbsp;

&nbsp;

7、男孩留校任教兩年，

&nbsp;

後又考上了美國一所知名大學的博士，

&nbsp;

畢業後留在美國一家科技研究機構工作，

&nbsp;

待遇相當豐厚，生活條件很好，

&nbsp;

身在異國的男孩想把母親接來享享清福卻被老人回絕了。 

&nbsp;

母親說，我不習慣！ 母親撒的七個謊。 


&nbsp;

8、晚年，母親患了重病，住進了醫院，

&nbsp;

遠在國外教書的男孩乘飛機趕回來時，

&nbsp;

手術後的母親已是奄奄一息了。 

&nbsp;

母親老了，望著被病魔折磨得死去活來的母親，

&nbsp;

男孩悲痛欲絕，潸然淚下。 

&nbsp;

母親卻說，孩子別哭︰我不痛！母親撒的八個謊。 


&nbsp;

朋友你的母親曾經為你撒下幾個謊呢？

&nbsp;

&nbsp;&nbsp;這些謊都是她愛你的表現，要好好珍惜唷！
