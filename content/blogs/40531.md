&nbsp;







揭秘男女存在的7個有趣差異



&nbsp;

&nbsp;


女人善於記細節，男人善於記大局

&nbsp;

男女大腦中的記憶區域不同，女性情感區域活躍，

&nbsp;

與情感有關的細節容易被記住，

&nbsp;

例如各種紀念日、生活瑣事。

&nbsp;

而男性的記憶區域在接受視覺刺激後會變得越發活躍，

&nbsp;

而且男性更善於關注大局，如道路佈局等，

&nbsp;

因此，他們對大局的記憶更深刻。



女人能一心多用，男人只能一心一意

&nbsp;

英國謝菲爾德大學研究發現，

&nbsp;

女人能在做事的同時也不耽誤與人聊天，

&nbsp;

而男性與人對話時必須集中精力。

&nbsp;

因為男性在聽別人說話時，只啟動大腦的一側，

&nbsp;

女性則激 活大腦的兩側。

&nbsp;

這其實也是進化的結果，

&nbsp;

女性的最初角色就是需要照顧孩子、處理家務兩不耽誤。

&nbsp;

而男性要狩獵，必須集中精力。


女人易“入戲”，男人更冷酷


女人比男人更愛看小說，會跟著主人公一起哭一起笑。

&nbsp;

心理學家西蒙·伯龍·科恩表示，

&nbsp;

女性擁有“情感化”大腦，男性擁有“機械化”大腦。

&nbsp;

這就註定了女性經常設身處地感受他人的處境，

&nbsp;

而男性表現就比較冷酷，不太能理解人。



女人比男人怕疼

&nbsp;

當疼痛襲來，女人大腦中的感情中樞就異常活躍，

&nbsp;

只讓女性把注意力集中於疼痛的感受上，

&nbsp;

對疼痛變得非常敏感。但在男性的大腦中，

&nbsp;

疼痛會啟動認知和推理區域，

&nbsp;

他們會分析疼痛原因以及解決辦法，

&nbsp;

化解了部分疼痛。

&nbsp;


女人愛閒逛，男人買前就打定了主意

&nbsp;

女人事先並沒有特別想買的東西，

&nbsp;

但大多會在閒逛中臨時決定買什麼。

&nbsp;

男性則是計畫好要買哪幾樣，然後直奔貨架而去。

&nbsp;


女人腋下大蔥味，男人腋下乳酪味

&nbsp;

女性腋下出汗後的味道比男性重。

&nbsp;

女性腋下汗味通常散發出大蔥味，男性則發出類似乳酪的味道。

&nbsp;


喝酒後男人覺得女人醜，萊賈斯特大學科學家艾根說，

&nbsp;

&nbsp; 男性喝多後，會覺得女性更醜。

&nbsp;

女性在喝酒後沒有變化。
