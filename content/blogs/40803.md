我想說：「親愛的，對不起!」

&nbsp;

我總是這麼任性又這麼愛生氣又那麼愛吃醋...

但我真的很愛很愛很喜歡很喜歡你!!

&nbsp;

昨晚說要發你卡，真的只是玩笑話...

你知道...我不是真心想這樣...

&nbsp;

我真的真的真的....很沒有自信...

&nbsp;

因為我從小就是處在這樣的環境下...

在同儕間被當皮球或垃圾一樣踢來踢去...

&nbsp;

所以我的心更脆弱...更容易受傷...也更容易猜忌...

&nbsp;

我也跟你說過...在網路上...我見過太多沒心的人...

所以你的表白，我一開始真的是很猶豫也很猜疑的...

&nbsp;

但是你真的讓我看到你的真心

所以我願意相信

我們也才有機會走到這裡

&nbsp;

即使我們的未來不容易

我也願意努力

還有...

我承認...&nbsp;&nbsp;&nbsp; 我很多時候真的是口是心非的女孩...

&nbsp;

我很怕受傷，更怕你會就此離開...

因為... 我真的真的真的...很愛你。

&nbsp;

知道嗎?!&nbsp; 

我跟我媽感情一向很好

我們彼此間沒有任何秘密

你是我們的第一個秘密

因為我想讓媽媽看到你的好

讓媽媽知道

其實，在虛擬的世界裡，是有真心存在的。

&nbsp;

還記得嗎?!

我們在一起的第一個晚上

那個晚上

真的是我哭的最悽慘的一個晚上

&nbsp;

也許是那陣子聊的特別入心

所以那晚也哭的最傷心

&nbsp;

你談話間的反反覆覆

給我一個不確定感

所以我們才會再那個問題上一直打轉

眼淚才會在電腦前不斷的落下

即使對話紀錄早已被yahoo吃掉&nbsp;&nbsp; 再也看不到

但我也還記得你對我說的話

&nbsp;

我哭著說：所以你最後還是只想當我的哥哥!!

你說：不是

我說：那你到底想要什麼?&nbsp; ( 我茫然了... )

你很肯定的說：情人

&nbsp;

這真的是最甜的一句話。

&nbsp;

知道嗎?!

每次我總捨不得關電腦、捨不得掛電話

因為這是我們最真實的聯繫

即使我每天早上總是爬不起來上課

也很努力的讓自己習慣&nbsp; 晚睡 早起

每天只睡5小時

但我依然甘之如飴

&nbsp;

昨晚，你掛了我的電話

我知道，你很累了...

我不應該這樣硬賴著你...

但我真的真的真的... 很受傷...

&nbsp;

想起看過的一篇日誌

裡頭說：" 最後掛電話的最愛你。"

&nbsp;

親愛的，我真的真的真的很愛你。

&nbsp;

我知道這樣說很傷你的心

但我真的非說不可

因為我很愛你，也很怕自己受傷，更怕讓你傷痕累累...

&nbsp;

我以真心待你

希望得到你真心的對待

若只是玩玩而已

請告訴我

&nbsp;

我媽雖然有3個孩子，但是她只有一個女兒。

她的女兒玩不起感情，付出的是百分百的真心。

&nbsp;

因為她的女兒真的很愛你。

&nbsp;

最後，我想說：「親愛的，對不起！ 謝謝你一直包容我，容忍我的任性。」
