15個自然乾淨蔬果<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


洋蔥Onions


為什麼它是乾淨蔬果：洋蔥製造自己的防護品，含有硫化合物，阻止昆蟲咀嚼。雖然農民在生長季節初期噴灑農藥，殘留物在收割時因外層的脫落而同時被除掉了。


&nbsp;


鱷梨Avocado


為什麼它是乾淨蔬果：大部分的農藥是堆積在果皮上。


甜玉米SweetCo


為什麼它是乾淨蔬果：殘留農藥在外殼上面。


&nbsp;


鳳梨Pineapple


為什麼它是乾淨蔬果：噴灑在生長季節初期便噴灑了農藥，所以收穫後殘留極少。而極少的殘留也只是在厚厚的外皮上。


&nbsp;


芒果Mangoes


為什麼它是乾淨蔬果：芒果種植在墨西哥，加勒比，南美，那裡的氣候乾燥，阻止真菌生存和手工除草代替除草劑。此外，芒果去皮才可食用。


&nbsp;


甜豌豆Sweet Peas


為什麼它是乾淨蔬果：他們都受他們的豆莢保護。


&nbsp;


蘆筍Asparagus


為什麼它是乾淨蔬果：生長很快，幾乎沒有時間給昆蟲攻擊。


&nbsp;


獼猴桃Kiwifruit


為什麼它是乾淨蔬果：草蛉和寄生蜂幫助控制喜歡吃獼猴桃的害蟲。


捲心菜Cabbage


為什麼它是乾淨蔬果：雖然噴灑農藥，但吸收農藥外葉銷售前被丟棄。


&nbsp;


茄子Eggplant


為什麼它是乾淨蔬果：茄子有一個光滑的表面，農藥容易掉落。


&nbsp;


哈密瓜Cantaloupe


為什麼它是乾淨蔬果：雖然西瓜也噴灑殺蟲劑它們都留在厚厚的外皮,而我們不吃皮的。


&nbsp;


西瓜Watermelon


為什麼它是乾淨蔬果：殺蟲劑在水果外皮，同樣的我們也不吃西瓜皮。


&nbsp;


柚子Grapefruit


為什麼它是乾淨蔬果：雖然農民經常使用殺真菌劑來控制蟲害，大部分的殘留物留在果皮上。


&nbsp;


甘藷Sweet Potato


為什麼它是乾淨蔬果：甘藷有內置的防禦。如果被咬，它會滲出一乳白色汁液把昆蟲口黏住。在賣完前，甘藷在高溫和高濕下自已癒合。這會導致外皮增厚，提供保護防止被傷害和產生疾病。


&nbsp;


蜜瓜Honeydew Melon


為什麼它是乾淨蔬果：蜜瓜包裝過程中用稀釋氯水洗過，以抵禦腐朽導致腐朽的微生物。但是，需要我們再說一遍嗎？，你須丟棄果皮方可食用。


只要記住，無論你選擇傳統或有機的，你最好還是多吃水果和蔬菜，而不是減少。而且不管你買任何蔬果，都要清洗或削皮後才可食用!。
