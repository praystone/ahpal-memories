醫學專家警告 ...&nbsp;&nbsp;




睡前、洗澡時候，水分流失量大，



&nbsp;



已經養成睡前不吃東西不喝水習慣的人，



&nbsp;



容易造成血液中水分不足，而引起腦梗塞或心肌梗塞的危險。



&nbsp;



人在睡眠中仍會消耗一至兩杯左右的水分，從晚餐後到第二天早上起床前，如果都不補充水分， 第二天早上起床或快天亮的時侯，最容易發生血栓， 使血管堵住，引發心臟病及腦部疾病。



&nbsp;



國人在習慣上喜歡睡前沐浴，洗個乾乾淨淨的澡再上床， 但洗澡的時候最容易流失水份， 



&nbsp;



&nbsp;



所以醫生建議，洗澡後應該要馬上補充水分，



&nbsp;



如果有泡澡習慣的人，則應該在洗澡前先喝一大杯水，



&nbsp;



以免在浴室停留太久，流失過多的水分，



&nbsp;



輕者也會發生呼吸困難、休克的現象。



&nbsp;



&nbsp;



&nbsp;





夏天開冷氣睡覺能睡得好一點，不過冷氣有防濕乾燥的作用，更是會流失水分，



&nbsp;



&nbsp;



因此有開冷氣睡覺習慣的人更應該睡前喝水，但是不要喝茶，因為醫生說，茶有利尿作用， 反而會排出比喝下去更多的水分，造成反效果， 就算不會有咖啡因提神作用的人，也不適合在睡前喝茶。



&nbsp;



&nbsp;



省錢又衛生的公開秘密



&nbsp;



&nbsp;





相信你不知道水公司一度水到底等於多少的水吧!?



&nbsp;

(= 一立方公尺= 1,000公升 = 1,000公斤 )



&nbsp;



換句話說,



&nbsp;



一度水可裝 53加侖 =汽油桶 5 大桶 或



&nbsp;



= 啤酒瓶 1667 瓶

&nbsp;



所以 20 元很大

&nbsp;

&nbsp;

&nbsp;
