[摘至網路]✪ 傷心咖啡店～
_____________________________


&nbsp;


 

&nbsp;

叮咚！門上的鈴鐺響了起來，一個30多歲穿著西服的男人，

&nbsp;

走進這家飄散著濃濃香咖啡香味的小小咖啡廳。


“午安，歡迎光臨！”年輕的老板娘親切的招呼著。
&nbsp;&nbsp;&nbsp; 
男人一面客氣的微微的點著頭，一面走到吧臺前的位子坐了下來，

&nbsp;

開口對老板娘說：

&nbsp;

“麻煩給我一杯藍山咖啡，謝謝。”
&nbsp;&nbsp;&nbsp; 
“好的，請稍等”老板娘微笑著說。
&nbsp;&nbsp; 
&nbsp;接著他便開始熟練的磨碎咖啡豆，煮起咖啡來。

&nbsp;

男人一直帶著笑容看著老娘煮咖啡的動作，一副很享受的樣子。
&nbsp;&nbsp;&nbsp; 
過了沒多久，老板娘便將一杯香醇的咖啡端到男人的面前“請慢用！”
&nbsp;&nbsp;&nbsp; 
“謝謝。”男人將杯子拿到嘴邊，淺淺的嘗了一口。
　　
“第一次來嗎？”老板娘問。
&nbsp;&nbsp;&nbsp; 
“是啊！！”男人答。
&nbsp;&nbsp;&nbsp; 
“覺得我們這家店怎麼樣？”
&nbsp;&nbsp; 
&nbsp;“很不錯！氣氛很好！”
&nbsp;&nbsp;&nbsp; 
“我自己也是很喜歡，所以雖然生意不好，

&nbsp;

我卻還是舍不得把它關掉。”
&nbsp;&nbsp;&nbsp; 
“恩……”男人好像有所同感的點了點頭，又喝了一口藍山咖啡。
&nbsp;&nbsp;&nbsp; 
兩人沉默了一會，一時間空蕩的店只余悠揚爵士音樂。

&nbsp;

男人忽然開口，打破了這短暫的寧靜。
&nbsp;&nbsp;&nbsp; 
“額……不好意思可以請教你一個問題嗎？?”
&nbsp;&nbsp;&nbsp; 
“什麼問題？”老板娘好奇的問。
&nbsp;&nbsp;&nbsp; 
“恩…這…這該怎麼說好呢？”男人抓著頭，一副不知所措的樣子。
&nbsp;&nbsp; 
“或者你可以先聽我說個故事嗎？？”男人說道。
&nbsp;&nbsp;&nbsp; 
&nbsp;老板娘點了點頭示意男人繼續說下去。
&nbsp;&nbsp;&nbsp; 
“我以前有個很要好的女朋友，已經到了要論及婚嫁的地步。

&nbsp;

我跟她的感情發展的很平凡，

&nbsp;

並不是經過大風大浪.轟轟烈烈般的愛情。

&nbsp;

但我想從我第一眼看到她的時候，就仿佛有一股魔力，

&nbsp;

有一個聲音，在推動著我，告訴著我，就是她就是這個女孩！

&nbsp;

她就是我一直期待著的女孩。

&nbsp;

更令我高興的是她也響應了我的示愛，接受了我。

&nbsp;

這一切的順利讓我整個人陶醉在幸福的喜悅之中，只不過……”


&nbsp;

“只不過！！發生了什麼事情了嗎？

&nbsp;

？”老板娘顯然給故事吸引住了，他打斷男人的話。
&nbsp;&nbsp;&nbsp; 


“恩……”男人的臉色沉了下來，停頓了一下，繼續說了下去。
&nbsp;&nbsp;&nbsp; 


“只不過我忘了幸福的背后，往往藏匿了可怕的惡魔。

&nbsp;

就在我們訂婚的前一個月的一個晚上，

&nbsp;

她……她被……她被歹徒強暴了”啊！

&nbsp;

！老板娘驚訝的啊的一聲叫了出來。
&nbsp;&nbsp;&nbsp; 


“都怪我！要是我那天堅持送她回去就好了！”

&nbsp;

男人用力的捶打著桌面，杯子中的咖啡因為震動的關系灑了出來。
&nbsp;&nbsp;&nbsp; 


“你要問我的該不會就是這個吧”

&nbsp;

老板娘一面擦拭著灑出來的咖啡一面說。
&nbsp;&nbsp;&nbsp;
&nbsp;

“不！不是這樣的！我對她的感情不會因為這樣而有所動搖，

&nbsp;

我決定仍舊如期訂婚，

&nbsp;

可惜就在我們訂婚的那一天，她……她上吊自殺了！”
&nbsp;&nbsp;&nbsp;
&nbsp;

男人的語調異常的平緩，從他的表情可以看得出，

&nbsp;

他當時多麼的難過與震驚。
&nbsp;&nbsp;&nbsp; 


“自殺！那她有沒有怎麼樣？”

&nbsp;

老板娘為突轉而下的劇情睜大了眼睛，緊張的看著男人。

&nbsp;

“幸運的是我們發現得早，送到醫院還有口氣，呈現昏迷狀態，

&nbsp;

當時醫生說她一度有成為植物人的危險。”
&nbsp;&nbsp;&nbsp; 
老板娘松下一口氣，“那她后來又醒過來嗎？”
&nbsp;&nbsp;&nbsp; 
“有的，她醒了！”
&nbsp;&nbsp;&nbsp; 
“但……但當時得知她醒來的消息，

&nbsp;

高興得要去看她的時候，卻被她的父母攔在門外。”
&nbsp;&nbsp;&nbsp; 
“為什麼？她父母為什麼不讓你去看她？”
&nbsp;&nbsp;&nbsp; 
“她父母跪在地上求我，原來她失去了記憶，

&nbsp;

失去了認識我以后的記憶，醫生說這是選著性失憶癥，

&nbsp;

當人在受到極大的打擊時，會逃避性地藏起一些記憶。

&nbsp;

她父母求我暫時不要再出現在她的面前，

&nbsp;

他們認為讓她就這樣忘了之前的一切對她比較好，

&nbsp;

怕我要是去見她或許會讓她回想起來，

&nbsp;

到時她可能又會陷入昏迷，甚至跑去自殺。”
&nbsp;&nbsp;&nbsp; 

“她父母這麼說也是有道理，反正只是暫時嘛！

&nbsp;

等她情緒和身體都穩定了，你就又可以見她啦！”

&nbsp;

老板娘聽了男人的話后這樣說道。
&nbsp;&nbsp;&nbsp;
&nbsp;

男人勉強擠出了一絲笑容，樣子無限凄涼，

&nbsp;

“你知道他們的暫時指的是多久嗎？是十年啊！

&nbsp;

也就是這十年我得要忍受這樣沒有她的日子，

&nbsp;

就算偶爾在路上碰面也得要裝作陌生人一般的和她擦身而過。

&nbsp;

”男人快要咆哮起來似的，“你知道這樣的日子又多難熬，

&nbsp;

這樣想愛卻又不能愛的心情有多痛苦！”
&nbsp;&nbsp;&nbsp; 

&nbsp;

“雖然會很痛苦，但你還是選著了這條路吧！”

&nbsp;

老板娘看著這男人的眼神變得非常溫柔。
&nbsp;&nbsp;&nbsp; 
老板娘的眼神讓男人冷靜了下來，

&nbsp;

點頭說道：“恩！到今天就滿十年了！”
&nbsp;&nbsp;&nbsp; 
“哦！真的嗎!?那真是恭喜了，你努力撐了十年，

&nbsp;

到今天終于可以去見她了！”老板娘開心的說。
&nbsp;&nbsp;&nbsp; 

&nbsp;

“是這樣沒錯！但是越到這一天，我反倒越害怕。

&nbsp;

十年了，我的心意是沒有改變，但是她呢？

&nbsp;

如果我跟她說了以前的事，她還是想不起我那怎麼辦？，

&nbsp;

或者是她已經有男朋友，甚至結婚了呢？”

&nbsp;

“這才是我想請教你的問題！”

&nbsp;

男人似乎略帶緊張的看著眼前的年輕女店主，

&nbsp;

靜靜地等待著她的答復。
&nbsp;&nbsp;&nbsp; 


“恩……”老板娘用手托著頭，

&nbsp;

臉色凝重的想著男人所提問的問題。
&nbsp;&nbsp;&nbsp; 


“我想既然你這麼愛那個女孩，她記不記得比其實並不重要，

&nbsp;

最多再重新開始而已，在重新追求她一次，

&nbsp;

在重新談一次戀愛，其實也很不錯吧！！

&nbsp;

而且就算有男朋友了也沒關系啊！

&nbsp;

把她從他手中搶過來不就行了！”老板娘笑著說。
&nbsp;&nbsp;&nbsp; 

&nbsp;

“但是！”她忽然將表情嚴肅了起來，

&nbsp;

“但是如果她已經結婚了的話，那你就放棄吧！

&nbsp;

我們結了婚的人啊！是最痛恨破壞人家家庭的人了！”
&nbsp;&nbsp;&nbsp; 


“是嗎？”男人低著頭冷漠的說道。
&nbsp;&nbsp;&nbsp; 


“沒錯！！所以你可千萬別做個破壞別人家庭的人哦！”
&nbsp;&nbsp;&nbsp;


&nbsp;叮咚！掛在門上的鈴鐺又響了起來，走進來幾個剛下課的大學生，

&nbsp;

老板娘走出吧臺，忙著招呼這幾位新來的客人。
&nbsp;&nbsp;&nbsp; 
“對了！”老板娘好像忽然想到了什麼，轉過頭來看著男人。
&nbsp;&nbsp;&nbsp; 


“你為什麼會想問我這些問題啊！我和你不過是第一次見面而已。

&nbsp;

”她好奇的問。
&nbsp;&nbsp;&nbsp; 
“恩…...為什麼呢……大概是因為那個女孩曾經說過，

&nbsp;

結婚以后要和我一起開一家像這樣的咖啡店吧！”
&nbsp;&nbsp; 
&nbsp;“哦！！原來是這樣啊！”老板娘說。
&nbsp;&nbsp; 
&nbsp;“恩！只是這樣而已！只是這樣而已！只是這樣而已！只是這樣……”

&nbsp;

男人不停地重復著同樣一句話，好想藉此告訴自己什麼似的。

&nbsp;

爵士樂停了下來，整個屋子只裡聽得到大學生清爽的談笑聲。

&nbsp;

男人低著頭偷偷地瞄著老板娘手上的結婚戒指，一滴溫暖的眼淚，

&nbsp;

悄悄地滑進了那杯早已冷卻的咖啡。
