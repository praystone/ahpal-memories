&nbsp;

&nbsp;
 
願你(妳)懂得快樂

&nbsp;



&nbsp;

&nbsp;


快樂並不是擁有的多，而是計較得少，

&nbsp;


不少人因為過多的貪婪而失去了生命的快樂

&nbsp;

人生如水，我們必須學會向水流一樣一樣適應環境，

&nbsp;

該轉則轉，該彎則彎，並始終保持奔流不息的韌性。

&nbsp;

人生要有所取，也要有所放棄，

&nbsp;

如同一塊石頭一樣，只有去掉多餘的部份，

&nbsp;

才能雕琢成美麗的雕塑

&nbsp;

&nbsp;

所有的人都渴望幸福，並追求幸福，

&nbsp;

但人們往往忽略了幸福

&nbsp;

其實只是點點滴滴的心靈感受，

&nbsp;

總是在不經意間和我們擦肩而過..

&nbsp;

知道一件事該不該做，叫成熟

&nbsp;

&nbsp;

人總是要有點精神的，

&nbsp;

如果物質財富是骨骼的話，那麼精神財富就是血液

&nbsp;

世上沒有兩片完全相同的葉子，

&nbsp;

同樣，也沒有兩個完全相同的人，

&nbsp;

儘管你很可能是渺小的、平凡的、甚至微不足道的，

&nbsp;

但請記住，你是芸芸眾生中的唯一無二的，

&nbsp;

這~就是你存在的價值...

&nbsp;

&nbsp;

每一粒飽滿的種子…都蘊藏著一個收穫的季節；

&nbsp;

每一個人的生命之海..都蘊藏著一顆顆成功的珠貝，

&nbsp;

而勤奮，正是打撈這些珠貝的網

&nbsp;

&nbsp;&nbsp; 相信完美，但不要追求完美，

&nbsp;

相信完美，是人生的清純

&nbsp;

不追求完美，則是一種理性的自覺

&nbsp;

遺憾與痛苦多是因為追求完美，

&nbsp;

而忽視了完美是理想化的，只有欠缺才是現實的.
