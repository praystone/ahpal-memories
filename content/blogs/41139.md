這一年，我剛搬到了新家，新家就在靠近海邊的地區，是棟三層樓的透天房子，我放下了 那些重死人的行李，大包小


包，包一包說不定都可以開個市場……，我打消那種一時的好笑想法，將那些行李整理了一下，過了幾個小時也沒有


多算，但是總算把那些行李整理好。 


&nbsp;


我開了冰箱，冰箱內還有幾瓶果汁，隨便拿了一瓶，將果汁轉開一口氣灌光，將瓶子丟進垃 圾筒內，現在也無聊，該做的事情也都結束了，還是去外面晃晃吧？


&nbsp;


&nbsp;踏出了家門，走個幾條路就是那片乾淨的沙灘，這片沙灘不久前才剛整頓好，行成規劃區， 現在夕陽也快要落下，傍晚到了，俗話不是說，晚上不要去海邊會被水鬼抓走的嗎……呃， 我想，我很鐵齒的，那種想法，我從來不去多想，還是往那片沙灘上走去。 


&nbsp;


瀕臨海邊，我將鞋子脫下，赤腳踩在這片沙灘上，陣陣的海風拂過身上，但是明明就貨真價實的踩著，卻有種莫名的不真實感，我也說不上來，我抬起頭，在我眼前，出現了一位少女。 


&nbsp;


少女的年紀大約十三、四歲左右，她也赤著腳丫子站在這，黑色的長髮飄逸著，穿著白色的蕾絲洋裝，個子很矮，大概還比我矮上半顆頭，我仔細端倪著她的臉，只是浮出了一個詭異的想法－－為什麼她長的和我那麼像。 


「嗨。」她走過來，禮貌的對我笑著，那笑容充滿了天真無邪，完全充分的發揮她的可愛。


&nbsp;


「妳好阿，怎麼這麼晚還不回家？」我也揚起了笑容，拍拍她的頭。


&nbsp;


「我？」少女眨眨漂亮的眸子，「我在找一個東西，很重要的東西。」


找？在這一望無際的海邊？在這空無一物的沙灘上嗎？


&nbsp;


「不介意的話，我來幫妳吧。」我捲起了褲管，將頭髮用大夾子夾起來。


她用力的點點頭，又揚起了笑容，我和她就這樣在這裡找了好幾個小時，天黑了，黑的深沉，太陽完完全全的消失了，我開了手機的燈，勉強才可以看到一些。


&nbsp;


「小妹妹，有找到嗎？」我喘著氣，結果找了很久，什麼東西都沒找到，貝殼倒是挖了一大堆。


&nbsp;


「沒有呢。」她失望的表情全寫在臉上，讓我也多了幾份的心疼。


&nbsp;


「大姐姐，時間不早了，妳快回家吧。」


回家？阿，也是，時間不早了，雖然說明天也沒有什麼特別重要的事情，就算熬夜也無所謂。


&nbsp;


「小妹妹，妳家在哪裡，我帶妳回家吧。」


&nbsp;


她搖搖頭。「我家就在這附近，很近的。」她指了指沙灘後不遠處的山洞。


為什麼她會住在那山洞裡頭？而且裡面聽說出過事不是嗎？……雖然種種的疑問讓我很疑惑，但淺意識告訴我，還是


什麼都別問的好。


最後我還是告別了她。


－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－


回到了家中，沖了澡，我的雙腳又在隱隱的作痛，這種痛像是從神經痛到肌肉組織，雖然不至於痛死人，但是一直這


樣抽痛也是很不舒服的，在一個月前就這樣了－－唉，明天還是給醫生看看吧？


&nbsp;


第二天早晨。


第二天，打理好頭髮後，換上衣服，今天我經過了那沙灘，我看見了那女孩還徘徊在那，她並不是在玩，而是蹲下身


子，繼續翻騰著那些沙子，臉上毫無表情、毫無血色，我走向前。


&nbsp;


我關心的問著：「還沒找到嗎？」也許真的遺失了很重要的東西吧，要是我能夠幫她找到就好了。


&nbsp;


她搖搖頭，焦急的找著，「找不到的話，我該怎麼辦吶，就不能回到姊姊那裡了。」她令人憐愛的眼眸眨了眨。


&nbsp;


「姊姊？妳的家不是住在這裡嗎？」我疑惑的望著那不遠處的山洞，就算是白天，僅僅盯著看也令人毛骨悚然。


&nbsp;


「是的，我們家住那，不過我姊姊不住那，所以我要找到她，不過也要先找到那東西才可以。」


&nbsp;


「是這樣阿，那我去看個醫生，回來繼續幫妳找，好不好？」


她開心的點點頭，和我打勾勾並且做了約定，我站起身，拍拍身上的沙子，就騎著摩托車去了醫院。


&nbsp;


＊＊＊＊＊


反覆的做了些檢查，Ｘ光也照了，雖然我不太認為，有嚴重到要照Ｘ光的程度，但那醫生似乎很頭痛，他看著手上那


些文件，「小姐，妳的腳，檢查出來是沒問題的。」


&nbsp;


「果然是我多心了吧，謝謝。」我帶著微微的笑容，從大腿一直痛到腳底，持續了一個月，尤其到晚上更是一直隱隱


作痛，唉，不好受阿，但也許忍忍就沒事了吧，我還是早早離開醫院，幫那小妹妹找東西吧。


&nbsp;


＊＊＊


每天一早，我都會看見那女孩在沙灘上找著那重要的東西，每天我也都會去幫忙，連續了七天，什麼都沒有找到，當我問起那是什麼東西時，她總是很難回答。


&nbsp;


「大姐姐，妳以前住這附近嗎？我以前好像沒有看過妳呢。」她一手翻騰著沙子，一邊問著我。


&nbsp;


「以前我不住這裡呢，我是搬來這裡的。」我也幫忙尋找著，但是怎麼找永遠都是沙子、貝殼以及寄居蟹。


搬家……對了，我是搬家來這裡的，但我為什麼要搬家呢？以前我又是住哪裡的－－？


好奇怪，我想不起來。


為什麼我要搬家呢？為什麼要搬到這裡？以前我又住在哪？


&nbsp;


「大姊姊為什麼要搬家呢？」她用稚氣的聲音問著。


&nbsp;


「我－－也忘了。」現在回想起來，我好像只知道自己的名字、幾歲，以前我讀過什麼國小、國中，我忘了，以前我


住哪，我忘了，為什麼要搬家，我忘了－－以前發生過什麼，我不知道。


&nbsp;


「是嗎。」她只是平淡的說著，沒有什麼表情。


&nbsp;


「大姐姐，今天就先找到這邊吧，對了，我家就在那裡，有空的話，可以來找我玩喔！」她對我笑著，跑著離開了。


&nbsp;


＊＊＊


今天是雨天，雨和狂風交加著，雷聲轟轟作響，是個不令人討喜的天氣，這種天氣，不知道住在那洞穴裡的小女孩會


不會感冒？會不會著涼？


我喝了杯熱咖啡，試圖回想起以前，我的父母是誰？我住哪裡？我讀過哪裡的學校……但可惜，什麼都沒有，完全都


是空白。


&nbsp;


我懵然放下咖啡杯，對了，既然是行李廂，說不定會有相片之類的東西？


&nbsp;


我啊的一聲，天阿，我怎麼那麼笨！如果有相片的話，也許能想起什麼也不一定？


跳起身，狂奔到那堆行李廂裡頭，最後那一廂，我還未整理完的行李箱。


&nbsp;


拉開行李廂的拉鍊，東翻西找，衣服、內褲內衣、泰迪熊、化妝品、保養品……不是，我要的不是那些。


在最底下的一層，終於找到了一張相片，唯一的一張。


&nbsp;


照片上只有兩個人，一個人很明顯的是我，而且我搭著輪椅，另一個人年紀比我小，但是她站在我旁邊，用很燦爛的


笑容笑著－－是海灘上的那個妹妹？是她？


&nbsp;


我的頭開始劇烈的疼痛，總覺得，有些事情不對勁。


&nbsp;


我奔向那洞穴，狂風豪雨打在我身上，但那些不重要，踏進了那陰冷的山洞，裡頭很深，沒有什麼燈光，吸著這股潮


溼的味道，我緩緩想起來了－－－全部。


－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－


出生開始，我和我妹妹就是孤兒，我們兩個靠捕魚維生，當然，我的腳是不能動的，先天性的殘缺，我們從出生起，


就住在山洞內，我妹妹和我不同，她非常健康，但可惜，她有些天然呆，總是讓魚跑掉，她出力，我出頭腦，我們


兩個總是這樣互補的，日子也一天天過去，我們好不容易一天天的長大了，她十三歲，我十七歲。


&nbsp;


「姊姊，等我長大了，我要賺很多錢，帶妳去醫院治妳的腳。」


&nbsp;


「謝謝妳。」但我心裡清楚，那是不可能的，這是先天性的－－－怎麼可能治的好，但如果用她的腳的話……


&nbsp;


這一晚，我對她下了安眠藥，風雨交加的夜晚，雷聲瘋狂的怒吼，刀子在我手中盤旋，我將她用鐵絲綁住全身，僅只


露出了她的腳。


&nbsp;


我用力下了手，毫無一絲絲的同情，刀用力的砍在她那嫩白的大腿上，濺灑出了大量的鮮血，噴上我的臉，她被痛醒


了，她淒涼的叫喊著，淚伴隨著鮮血，哀號比雷聲更大聲，迴盪在這洞穴內，我就這樣砍下了她兩雙腿，她腰部以下


只剩下鮮血淋漓的模糊畫面，我永遠記得，在她淒涼的叫喊中，曾這麼說著：「我一定會找到妳、找到我的腳！我會


找妳報仇！」


&nbsp;


為了避免麻煩，我ㄧ刀斷了她的喉嚨，擱下了她的頭，在山洞內將她的屍體埋起來，立了她的墳墓。


&nbsp;


安息吧。


我切下了自己的腿，裝上了她的腿，這是不合醫學邏輯的，但很奇妙的是，我暈過去了，等我醒過來後，我人就躺在


醫院內，雙腳被包起來，我的腳能動了，但我犧牲了我妹妹，揚起了詭異的笑容，從此以後，這是我的。


&nbsp;


＊＊


回想起了全部，我開始反胃，不遠處的地方，我看見了當初我為她立下的墳墓－－難道她就是在這裡等我、找著她的


雙腿、並且守著自己的墳墓－－？


&nbsp;


　　　　　　　　　　「大姊姊！妳來找我玩了嗎！今天要玩什麼呢！」


她的聲音從我面前響起，她的臉正笑的扭曲不堪，看看她的雙腳，在山洞的陰影下，顯得那樣殘缺。


我不敢抬頭看她……。


&nbsp;


&nbsp;
