&nbsp;


&nbsp;

&nbsp;

多一份快樂，少一份悲苦

&nbsp;



&nbsp;

&nbsp;


每個人都有自己的朋友，

&nbsp;

有的人朋友比較多，有的人朋友比較少。


&nbsp;

有同甘苦共患難的朋友，

&nbsp;

有萍水相逢的朋友，有感情深的，也有感情淺的。


&nbsp;

擁有朋友就可以笑對人生，

&nbsp;

感悟生命，調整好人生航向！


人生沒有完美，如果你發現錯了。

&nbsp;

重新再來，別人不原諒你，你可以自己原諒自己。


&nbsp;

千萬不要用一個錯誤去掩蓋另一個錯誤。


&nbsp;

人活著的意義應當是一個過程，而不是結論，

&nbsp;

要以自己的觀點和經驗去影響另一個人，

&nbsp;

人生的酸甜苦辣應當自己都去嘗一嘗，

&nbsp;

嘗試才是人生。


&nbsp;

人是一面鏡子，如果你對他笑他就絕不會對你哭。


&nbsp;

關心他人就是關心自己，

&nbsp;

我們應該拋棄虛偽，用“真心”來結交朋友，

&nbsp;

因為真正的朋友可以不計得失，

&nbsp;

甘願付出，讓我們一起真心真意做朋友。


&nbsp;

人是有血有肉有靈魂的動物，

&nbsp;

他們的身上同樣也散發著與眾不同的美，

&nbsp;

每一種美好的品質都是誘人的。


&nbsp;

任何時候，都要學會用欣賞的眼光去看待世界，

&nbsp;

看待周圍的人，這樣可以坦然面對一切。


&nbsp;

人的弱點是強烈的占有欲望，侵占一切自己喜愛的東西 。


&nbsp;

人是有思維的，沒有一種情感是永恒不變的，

&nbsp;

不要奢望能擁有很多，

&nbsp;

用一種平常心態去欣賞一個人足已，

&nbsp;

就象欣賞一幅畫，你會很快樂，也會很坦然。

&nbsp;

當你用一種平常的心境去認識一個人，

&nbsp;

結交一個人，

&nbsp;

你便沒有了私情雜念，交往是自由隨意的，

&nbsp;

心也會一點點交融 ，

&nbsp;

真正的朋友便會在欣賞的眼光中向你逼近，

&nbsp;

友情同樣是生命中不可缺少的東西，

&nbsp;

在你擁有了很多真心朋友的時候，

&nbsp;

你才會覺得生命的快樂。

&nbsp;

&nbsp;

幸福是一種感覺，是一種平常的心，

&nbsp;

幸福是安定的生活，幸福是內心的充實。


&nbsp;

幸福也是可遇而不可求的，

&nbsp;

可幸福是為那些不懈追求的人準備著的。


&nbsp;

我們都渴望從容的生活，

&nbsp;

從容就是幸福，是一種恬靜的幸福，

&nbsp;

幸福就是對世界和周圍人群的關愛，

&nbsp;

幸福就是不懈的追求，

&nbsp;

幸福就是心與心之間最真實，最坦誠的交流。


&nbsp;

找到幾個心靈上息息相通的朋友，

&nbsp;

在心與心坦誠地交流的那一刻，你會感覺自己就是幸福的。


&nbsp;

平凡的生活中蘊含著偉大的力量，

&nbsp;

從平凡生活中感悟快樂，學會品味生活中的過程之美，

&nbsp;

放慢腳步，我們會發現，

&nbsp;

平常的日子裏也充滿了幸福。


&nbsp;

擁有一個好朋友，

&nbsp;

比擁有一段感情要平實的多，

&nbsp;

在人的一生中，每一次用心的投入都是一種傷害，

&nbsp;

而朋友則不同，你可以在擁有朋友的同時，

&nbsp;

體味到人的純美、真情的可貴，

&nbsp;

友情同樣是一種高尚更至誠的愛。在現實的生活中，

&nbsp;

知心朋友願意為對方排憂解難，不求回報。


&nbsp;

歲月如一首歌，歌到情處淚會雙流；

&nbsp;

&nbsp;&nbsp; &nbsp; 歲月如一杯酒，酒將醉時笑語稠；&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

歲月又是一首詩，詩言有盡意難盡；


&nbsp;

歲月是一杯茶，茶香滿口情悠悠。


&nbsp;

生命有限，人生短暫。趁春日勃發，趁風花正茂，

&nbsp;

莫停留、莫嘆息，要思考、要奮鬥。


&nbsp;

雖然人生前行的路途中還會布滿荊棘，可逃避，

&nbsp;

懦弱都是無能的表現，讓我們盡快行動起來，

&nbsp;

鼓起生活的信心，滿懷新生活的憧憬，

&nbsp;

編織著七彩的夢想，播下生命的希望，迎著朝霞，昂然前行。


多一份舒暢，少一份焦慮；


&nbsp;

多一份真實，少一份虛假；


&nbsp;

多一份快樂，少一份悲苦；


&nbsp;

多一份愛心，少一份仇恨。


&nbsp;

我們的生活可以更充實，日子可以更快樂。

&nbsp;

幸福就是這麼簡單，幸福就在我們眼前。


&nbsp;
