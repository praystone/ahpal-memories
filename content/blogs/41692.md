&nbsp;


&nbsp;


一天，佛祖站在雲端翹首俯瞰人間，

他看到每一個城市都車水馬龍，

人來人往，每個人都奔

&nbsp;

著自己的目標匆匆獨行，

甚至急得汗流滿面。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

佛祖若有所思地問他的弟子：

“弟子們，你們看呀，

人們整天都忙忙碌碌，

這究竟是為了什麽呢？”

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

弟子們雙手合十，恭聲答道：

“佛陀，人們整天這樣的忙忙碌碌，

不外乎是為了‘名利’二字。” 

&nbsp;

&nbsp;

&nbsp;

&nbsp;

“那麽，有了名利又能怎樣呢？”

&nbsp;

佛祖接著問道 

&nbsp;

“有了名可以得到別人的尊重，

有了利可以滿足肉體的奢侈。”

一個弟子回答。

&nbsp;

“無名無利的平民百姓，

他們整天到晚勞累忙碌，



又是為了什麽呢？”

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

“佛陀，平民百姓勞累忙碌，



是為了養家糊口，吃飯穿衣。”



一個弟子平靜地答道。 

&nbsp;

“吃飯穿衣又是為了什麽呢？”


佛祖接著問。

&nbsp;

&nbsp;一個弟子站起身來，躬身答道：

“佛陀，人們吃飯穿衣是為了滋養肉身，

享盡天年的壽命呀！”

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;佛祖用清澈的目光環視著弟子們，

沈靜地問道：“那麽，



你們且說說肉體生命究竟有多長久？” 

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

“佛陀，有情眾生的生命


&nbsp;

平均起來有幾十年的長度。”

一個弟子充滿自信地回答。

&nbsp;

&nbsp;佛陀搖了搖頭說：

“你並不了解生命的真諦。” 

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

另一個弟子見狀，充滿肅穆地說道：

“人類的生命如花草，春天萌芽發枝，

燦爛似錦，冬天枯萎雕零，化為塵土。”



佛陀露出了贊許的微笑，

“你能夠體察到生命的短暫迅速，

但是對佛法的了解，仍然限於表面。” 

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

又聽得一個無限悲愴的聲音說道：

“佛陀，我覺得生命就像浮遊蟲一樣，

早上才出生，晚上就死亡了，


充其量只不過是一晝夜的時間！”

&nbsp;

&nbsp;

“喔！你對生命朝生暮死的現象

能夠觀察入微，

對佛法已經有了進入肌肉的認識，



但還是不夠透徹。”

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

在佛陀的不斷否定、啟發下，

弟子們的靈性越來越被激發起來，

這時又有一個弟子站起來說道：



“佛陀，其實人們的生命跟朝露

沒有什麽兩樣，看起來不乏美麗，



甚至有的時候是如此的淒美壯觀，



但是只要陽光一照射，



一眨眼的功夫它就蒸發消逝在這個空間

而變得無影無蹤了。”

&nbsp;

&nbsp;

&nbsp;

佛陀含笑不語，

弟子們更加熱烈地討論起生命的長度來。

這時，一個弟子站起身來，

語驚四座地說道：

“佛陀，依弟子看來，

人命只在一呼一吸之間。” 

&nbsp;

&nbsp;

&nbsp;語音一出，四座愕然。



大家都凝神地看著佛陀，



期待著佛陀的開示。

&nbsp;

&nbsp;

嗯，說得好！



人命的長度，就是一呼一吸之間。



只有這樣認識生命，



才能真正體味生命的精髓。



弟子們，你們切不要懈怠放逸，



以為生命很長，明日復明日地活下去，



像露水有一瞬，像浮遊有一晝夜，



像花草有一季，像凡人有幾十年。 

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;其實生命只有一呼一吸這樣的短暫呀！

&nbsp;

&nbsp;

你們應該好好地珍惜自己所擁有的一切，

把握生命的每一分鐘、每一時刻，



認識真諦，返本歸真，


&nbsp;


勤而行之，勇猛精進。


&nbsp;
