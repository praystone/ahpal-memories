&nbsp;




一杯清茶
&nbsp;
一本書
&nbsp;
一首歌
&nbsp;
這便是我午夜的快樂
&nbsp;
守著一份寂寞
&nbsp;
留著一份孤單
&nbsp;
在心底最深處開花
&nbsp;
然後綻放出一種魅惑的憂傷
&nbsp;
在午夜的風中獨自蕩漾
&nbsp;
然後醉迷而去
&nbsp;
七夕
&nbsp;
沒有太多的感慨和心思
&nbsp;
只想靜靜的為我的愛人寫一首傾城花開之歌
&nbsp;
月色在這樣的日子裡總是那樣的美麗迷人
&nbsp;
就像你給我最溫暖的微笑
&nbsp;
就像我在紅塵等你時的悸動
&nbsp;
就像這個世界是因為有你才這樣幸福
&nbsp;
就像我的生命因你而燦爛一樣
&nbsp;
夏花漸漸遠去
&nbsp;
夏風漸漸離去
&nbsp;
那一地的流殤
&nbsp;
帶走的不是落寞的心
&nbsp;
而是我永遠愛你的執著
