&nbsp;

&nbsp;

&nbsp;

我們已經不太會為了一個誤會，衝動地說再見
&nbsp;
也不會為了面子問題，驕傲地僵持著
&nbsp;
人生走到中年，我學會了虛心等待
&nbsp;
學會了給對方、也給自己機會 
&nbsp;
把事情說清楚，把事情做乾淨
&nbsp;
如果這樣，還是必須分手
&nbsp;
那必然是因為更基本的理由，也就很難妥協了
&nbsp;
&nbsp;
&nbsp;


&nbsp;
許多人喜歡談EQ、談溝通，其實，情到中年
&nbsp;
所遇到的感情挫折，常常不是改善溝通就能夠解決的
&nbsp;
因為問題不只在於表面的「態度」而是更深層的差異，

&nbsp;

最多的是彼此都有著歲月累積出來的固執
&nbsp;
這種事情是連吵架都多餘了
&nbsp;
因為就某一個層面來看，也正是這些堅持、
&nbsp;
支撐著中年的自己一路行到水窮、坐看雲起
&nbsp;
所以，能夠放水多少，心裡一清二楚
&nbsp;
&nbsp;

&nbsp;

&nbsp;


那麼，就謝謝生命裡曾經一起走過某些段落的人吧
&nbsp;
我們都知道，彼此已經盡了力，到了要分手的地步
&nbsp;
那肯定是不得不然；雖然枝上柳棉吹又少
&nbsp;
但天涯何處無芳草？我們互相打氣：
&nbsp;
「沒有我陪著你，自己多保重」，這些話，我們說得多

&nbsp;

麼認真
&nbsp;
&nbsp;

&nbsp;


年輕時愛得衣帶漸寬，

&nbsp;

中年分手，說得最多的話總是「努力加餐飯」 
&nbsp;
&nbsp;柴米油鹽是生命的根本，

&nbsp;

眼裡看得到這些的，總能捱過緣起緣滅的折磨
&nbsp;
看過那麼多飛蛾撲火，我們心裡清楚，能夠和一個人和

&nbsp;

平分手
&nbsp;
並不是理所當然的，這是天大的福份
&nbsp;
&nbsp;


&nbsp;

所以，我們都該感謝那分手後還能夠好好過日子的人
&nbsp;
這樣的人讓我們的生命不致於留下太大的遺憾
&nbsp;
也讓我們總是敢繼續愛下去
&nbsp;
十年修得同船渡，百年修得共枕眠
&nbsp;
前世要修多久才能碰到一個愛過之後還可以互道平安的

&nbsp;

人呢？
&nbsp;
瞬間電光石火不是難事，

&nbsp;

困難的是曾經滄海而後又能雲淡風輕 ... 


&nbsp;
