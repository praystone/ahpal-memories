&nbsp;&nbsp; 


&nbsp;

◆愛情就像一壺開水，不經常煮一下，它就會變


&nbsp;&nbsp;&nbsp; 涼，經常煮吧，它又會漸漸蒸發，空空如也。

&nbsp;

◆男人喜歡流行中的女人，卻不喜歡流言中的女


&nbsp; 人。

&nbsp;

◆女人和電腦一樣，沒有時渴望，到手時又覺得


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 不過如此，有了一個以後，又發覺還有更好的。


&nbsp;&nbsp; 為了能讓她趕上時髦，只有不斷地在她身上花


&nbsp; 錢。

&nbsp;

&nbsp; ◆不成熟的愛說：我愛你，因為我需要你。成熟


的愛說：我需要你，因為我愛你。

&nbsp;

&nbsp; ◆感覺不到痛苦的愛情不是真正的愛情，感覺不


&nbsp; 到幸福的婚姻必是悲哀的婚姻。


&nbsp; ◆女人的聰明就像愛情一樣——不是太少，就是


&nbsp; 太多。

&nbsp;

&nbsp; ◆孤單是一個人的狂歡，狂歡是一群人的孤單。


&nbsp; ◆除了初戀，於任何事情都是生活閱歷越豐富越


&nbsp;好。

&nbsp;

&nbsp; ◆有心的無力，有力的無錢，有錢的無情，有情


&nbsp; 的無緣，有緣的無份，有份的正鬧著離婚。


&nbsp;&nbsp;◆愛情的溫度就像洗澡水——不是越熱越好，自


&nbsp;&nbsp;&nbsp; 己覺得舒服就行。

&nbsp;

&nbsp;&nbsp; ◆男人從不後悔結婚，只是後悔沒有娶到另一個


&nbsp; 女人。

&nbsp;

◆所謂情敵，就是愛好相同，目標也相同的敵


&nbsp; 人。

&nbsp;

&nbsp;&nbsp; ◆戀愛中的男人個個優雅，婚姻裏的男人個個憂


&nbsp; 愁。

&nbsp;

&nbsp; ◆一道幸福之門關閉時，另一道就會打開。我們


&nbsp; 經常盯著關閉的門，對開啟的門卻視若無睹。

&nbsp;

&nbsp; ◆生活的悲劇不在於一個人輸了，而在於他差一


&nbsp; 點贏了。
