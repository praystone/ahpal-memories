&nbsp;

客服人員的七種等級!!&nbsp;
&nbsp;
&nbsp;&nbsp;&nbsp;&nbsp;
&nbsp;
&nbsp;(1)初級客服員&nbsp;

客戶來電劈頭大罵：「你娘咧！」&nbsp;

客服員： 「嗚...........（哭泣聲）&nbsp;
&nbsp;
&nbsp;&nbsp;&nbsp;&nbsp;

&nbsp;&nbsp; (2)中級客服員&nbsp;
&nbsp;
&nbsp;&nbsp; 客戶來電劈頭大罵：「你娘咧！」 


&nbsp;&nbsp; 客服員：「這位先生請息怒，有什麼可以為您服務的嗎？」&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;
&nbsp;
&nbsp;&nbsp; (3)高級客服員&nbsp;

&nbsp; 客戶來電劈頭大罵：「你娘咧！」&nbsp;
&nbsp;
&nbsp;&nbsp; 客服員：「家母身體很好，謝謝您的關心。」&nbsp;
&nbsp;&nbsp;&nbsp;


&nbsp;
&nbsp; (4)專業客服員&nbsp;
&nbsp;
&nbsp;&nbsp; 客戶來電劈頭大罵：「你娘咧！」 

&nbsp;&nbsp; 客服員：「家母身體很好，謝謝您的關心。那.... 你娘咧？」&nbsp;
&nbsp;
&nbsp;&nbsp;&nbsp;
&nbsp;
&nbsp;&nbsp; (5)超級客服員&nbsp;
&nbsp;
&nbsp;&nbsp; 客戶來電劈頭大罵：「你娘咧！」&nbsp;

客服員：「這通電話已錄音存證,&nbsp;
&nbsp;
&nbsp;本公司將保留一切追訴之權利. 」&nbsp;
&nbsp;
&nbsp;&nbsp;&nbsp;&nbsp;

(6)終極客服員&nbsp;

客戶來電劈頭大罵：「你娘咧！」&nbsp;

客服員：「請稍後,馬上為您轉接!.......」&nbsp;

(電話放一旁,讓客戶一直等候...)&nbsp;
&nbsp;
&nbsp;
&nbsp;
&nbsp; (7)無敵客服&nbsp;
&nbsp;
客戶來電劈頭大罵：「你娘咧！」&nbsp;

客服員：「啊死囝仔..&nbsp;

竟然在你祖媽上班時間打電話來鬧.. 返去你就知死..」&nbsp;
