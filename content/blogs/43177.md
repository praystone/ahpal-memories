&nbsp;

&nbsp;

&nbsp;




如果

&nbsp;

你已擁有

&nbsp;

更貴重的寶物

&nbsp;

你自然會

&nbsp;

輕看其他的東西

&nbsp;

對你而言

&nbsp;

什麼事物是你

&nbsp;

看為最貴重的呢

&nbsp;

讓財富

&nbsp;

不致成為我們

&nbsp;

唯一的追求目標

&nbsp;

人生

&nbsp;

還有許多

&nbsp;

更珍貴的東西

&nbsp;

可以傾一生之力去追尋
&nbsp;
