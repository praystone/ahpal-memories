&nbsp;

現在在哪 過的好嗎

&nbsp;

有沒有什麼不適

&nbsp;

很難受吧 只剩淚水

&nbsp;

我像傻瓜一般

&nbsp;

偶爾期望著有你的訊息

&nbsp;

不知為何總有著落淚的衝動

&nbsp;

你明白吧 可以將我記住嗎

&nbsp;

想起我嗎 我在這裡

&nbsp;

我還在線上 你呢

&nbsp;

也許你會再次尋找著我

&nbsp;

不論何時我都存在

&nbsp;

都會靜靜的 我會這樣等待

&nbsp;

有時候會想

&nbsp;

疲憊軟弱的妳

&nbsp;

真的不要緊嗎 願意記住我嗎

&nbsp;

我永遠存在 你呢

&nbsp;

對我來說你是唯一

&nbsp;

我會守護著妳

&nbsp;

當你感到辛苦 疲憊的時候

&nbsp;

我都在這裡

&nbsp;

即使偶爾 即使短暫

&nbsp;

我會想妳 我會守護著妳

&nbsp;

即使偶爾 即使短暫

&nbsp;

不要緊 我仍等你
