&nbsp;

話 不要滿

&nbsp;



&nbsp;

&nbsp;


遇上不喜愛的事情或是不平等的情況，

&nbsp;

我們總會認為自己有理，

&nbsp;

於是就會把話給說滿，有時是得理不饒人，

&nbsp;

有時是自以為的高傲作祟，但是當一句話說出口的時候，

&nbsp;

我們有沒有考慮到它的後果呢？

&nbsp;

它不是一句話如此簡單而已，

&nbsp;

不同的人聽到或看到就會產生不同的效應，

&nbsp;

可能我們會覺得有理，

&nbsp;

但在他人的眼中卻是你自己自以為的道理而已。

&nbsp;

&nbsp;

不喜歡的人，不需要去惡意中傷更沒必要去隨雞起舞；

&nbsp;

不喜歡的事情，不該去逃避，

&nbsp;

更不能完全的否決定它存在的意義；

&nbsp;

即使你因為親自接觸過知道了它們的不美好，

&nbsp;

更知道這些缺陷，然而當你將它們批判的一無是處的同時，

&nbsp;

是不是也在斷絕自己的後路呢？

&nbsp;

誰能保證你不會在某年某月又遇見相似的人事物，

&nbsp;

可是當把話給說的太滿，又如何虛心的重新接納，

&nbsp;

又如何的把話收回去，只不過讓自己難堪而已。

&nbsp;

&nbsp;

每個人都會遇見自己不喜歡的事情，

&nbsp;

可是不喜歡或厭惡的情況下反而不該衝著一口氣

&nbsp;

而說出讓自己後悔的字句，一句話對自己來說無關緊要，

&nbsp;

但既然說出口了就代表著會被許多人聽見然後口耳相傳，

&nbsp;

如果是路人聽見當然無所謂，

&nbsp;

可是要是朋友、親戚、家人甚至工作領域的上司聽見，

&nbsp;

他們都會有不同的想法跟感受，

&nbsp;

這時候又如何把某些說死的話重新收回呢？

&nbsp;

&nbsp;

當某些言論要表達出來之前，

&nbsp;

別急著只因為要出一口氣，

&nbsp;

思考一下當自己說出這些話的時候是有什麼意義，

&nbsp;

當自己靜下心思考後其實很多話就不需要把它說的太滿，

&nbsp;

話說的滿只是讓自己走向死路，

&nbsp;

一方面自己不可能承認自己的錯誤，

&nbsp;

另方面當對方誤會了或者認真看待了又如何去接納你，

&nbsp;

說過的話並非能輕易消失，

&nbsp;

反而會留在被你刺傷的人的內心很久很久。
