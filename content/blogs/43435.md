&nbsp;

&nbsp;

親愛的

&nbsp;

牽手了就不放了，好嗎


&nbsp;





&nbsp;

&nbsp;


有人說，冬天不適合分手


&nbsp;

因為冷，人與人之間需要牽手和擁抱


&nbsp;

其實，很多時候


&nbsp;

我們都需要一雙溫暖的手，互相取暖，互相鼓勵


&nbsp;

而無論是春夏秋冬哪個季節


&nbsp;

牽手，多麼溫暖的一個詞 ，牽手，多麼溫暖的一個動作


&nbsp;

&nbsp;

在我們很小很小的時候


&nbsp;

爸爸媽媽牽著我們的手，教我們學步


&nbsp;

直到我們能自己獨立的走路，這樣的牽手叫做親情


&nbsp;

讀小學了


&nbsp;

老師說，同學們要手牽著手一起排隊走哦


&nbsp;

這樣的牽手叫做友情


&nbsp;

等我們再大一點，讀中學了


&nbsp;

女生就開始拉著女生的手一起走路，逛街


&nbsp;

偶爾，有男生偷偷地拉著女生的手，在學校大大的操場上


&nbsp;

一圈又一圈的散步，聊天，這樣的牽手，叫做純情


&nbsp;

上大學了或者工作了


&nbsp;

大男孩就緊緊的拉著身邊女孩子的手一起壓馬路了


&nbsp;

在十字路口


&nbsp;

男孩更是小心翼翼地把女孩小小的手放在掌心裡


&nbsp;

護著女孩過馬路，這樣的牽手叫愛情


&nbsp;

&nbsp;

結婚了


&nbsp;

來自兩個不同環境不同世界的人


&nbsp;

在那一句『我願意』的誓言後，便開始了一生一世的牽手


&nbsp;

於是，我們給愛人一個親暱地稱謂叫做牽手


&nbsp;

&nbsp;

當時間流逝，不再年輕的時候


&nbsp;

我們在藍藍的天空下，在綠綠的草地上


&nbsp;

牽著老伴那飽經滄桑甚至有點粗糙的手


&nbsp;

輕輕地哼唱『我能想到最浪漫的事，就是和你一起慢慢變老


&nbsp;

直到我們老的哪裡都去不了，你還依然是我手心裡的寶』


&nbsp;

這樣的牽手叫做『執子之手，與子攜老』


&nbsp;

在彌留之際，我們牽著彼此的手，微笑著流淚


&nbsp;

幸福地告訴對方『來世，來世我們再牽手，好嗎』


&nbsp;

這樣的牽手叫做生生世世，不離不棄


&nbsp;

&nbsp;

在我心懷感恩地寫著這些溫暖的文字的時候


&nbsp;

突然就想到最近放的很多的一首歌&lt;有一種愛叫做放手&gt;


&nbsp;

裡面有一句『為愛放棄天長地久』感覺鼻子有點酸酸的


&nbsp;

放手了，是不是也叫一種愛呢


&nbsp;

或許，在愛的時候契機不對，對像不對


&nbsp;

那麼，放手對彼此而言的確是一種解脫


&nbsp;

也惟有放手


&nbsp;

才能找尋到心裡真正的所愛，才能擁有真正的幸福


&nbsp;

&nbsp;

但是，如果放棄的是真愛呢


&nbsp;

那麼，等到白髮蒼蒼的時候，會不會後悔的老淚縱橫呢


&nbsp;

&nbsp;

所以，當相愛的兩個人想要放棄的時候，

&nbsp;

請再牽一牽手吧


&nbsp;

如果在牽手的時候還有捨不得，還有依戀，還有愛


&nbsp;

那麼，就請不要放手，繼續勇敢的走下去吧


&nbsp;

所以，當戀人中的一個感覺愛的疲累想放手時


&nbsp;

請另一方輕輕地

&nbsp;

再跟他說一句『親愛的，讓我們再牽一牽手好嗎』


&nbsp;

親愛的，牽手了就不放了，好嗎


&nbsp;

可能，這一牽，就會是一生了.....


&nbsp;
