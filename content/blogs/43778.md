&nbsp;



愛人是路 朋友是樹

&nbsp;



&nbsp;


愛人是路，朋友是樹；

&nbsp;

人生只有一條路，一條路上多棵樹，

&nbsp;

有錢的時候莫忘路，缺錢的時候靠靠樹，

&nbsp;

幸福時候別迷路。

&nbsp;

細細品味，覺得這句話挺富哲理的。


&nbsp;

愛人是路。

&nbsp;

有了路我們才不會像無根的浮萍那樣飄零，

&nbsp;

才能腳踏實地，走得更遠，心靈也才能歸依。

&nbsp;

世間路，有千條萬條。世上的人，也是形形色色。

&nbsp;

選擇愛人就如同選擇要走的路，

&nbsp;

&nbsp;

選擇對了~~

&nbsp;

找到一塊充滿快樂、陽光、幸福和愛的地方。

&nbsp;

在充滿誘惑的岐路口，

&nbsp;

如果辨不清東南西北，顧左盼右，

&nbsp;

最終只能是“窮途末路”。


所以我們要選擇一條也只能選擇一條正確的，

&nbsp;

適合自己的路來走。不管這條路是栽滿鮮花，

&nbsp;

還是布滿荊棘，只要感覺幸福，

&nbsp;

那就走自己的路，讓別人去說吧。

&nbsp;

&nbsp;

朋友是樹。正如人的生活離不開樹一樣，

&nbsp;

人的生活也離不開朋友。

&nbsp;

而友誼之樹，是否能茁壯成長，

&nbsp;

需要我們用心呵護。友誼需要用忠誠去播種，

&nbsp;

用熱情去灌溉，用原則去培養，用諒解去護理。


樹多對人類益處多多，

&nbsp;

同樣的，朋友多是我們的寶貴財富。

&nbsp;

&nbsp;

正如要在路旁多栽樹一樣，

&nbsp;

我們也要在自己的人生路上多交些知心朋友，

&nbsp;

那麽你這一路走來，便會是馨香滿懷，心曠神怡。

&nbsp;

愛人是路，朋友是樹。

&nbsp;

一路上有朋友相伴，但千萬莫忘路，也別迷路。

&nbsp;
