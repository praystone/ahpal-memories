[摘至網路]✪ 【學會正確的戀愛方式】 
_____________________________


&nbsp;


 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
一段感情的成功與否，不是看是否還牽手，

&nbsp;

而是由感情品質而定，

&nbsp;

很多時候牽手不代表成功，分手不代表失敗。


關鍵是看在這段感情中

&nbsp;

你是否完成了兩件重要的戀愛心理任務。


你是否更了解自己的需求，你是否已學會疼愛別人。




愛的反面不應該是恨，而應該是淡忘；

&nbsp;

那為什么有些人的愛會變成恨，而不能成為淡忘呢，

&nbsp;

那是因為他在愛里面，缺乏了自信......


在戀愛中我們需要完成兩項重要的心理任務：


一、要更了解自己。


除自我認知概念外，讓兩性戀愛中的自己更完整清晰地呈現出來。


二、培養我們愛人的能力。


從自小習慣被愛開始學會愛人。




看一個男人是不是好男人有三個基準：


負責、尊重和穩定。


負責意味著他能對自己所說過的話負責。


尊重則是指，他能夠尊重自己的另一半，

&nbsp;

就是我們通常所說的，你和他之間建立的是“伙伴式關系”，

&nbsp;

你們相處的方式是平等的。


另外，他還要是一個情緒穩定的人。


有些人情緒容易大起大落，

&nbsp;

這樣的人是很難維持一段長久的關系的。




上面說的只是好男人的基準。


如果我們把條件再抬高成精品男人的話，

&nbsp;

還可以歸納出所謂“三心二意”的基準。


首先第一個心是開心。


他自己應該是一個開朗的人，

&nbsp;

這會讓和他一起相處的人也感到心情愉快。


第二個心是關心。關心意味著體貼，

&nbsp;

這是所有女生都很容易理解的。


第三個心是同理心。


什么叫同理心？就是設身處地為別人著想的能力。


同理心是尊重的來源，

&nbsp;

也是情侶間解決沖突時最重要的能力。


還有兩意。


第一個意是誠意。誠意意味著真誠，真誠又是負責的基礎。


第二個意是善意，就是要能夠用善意的方式去解讀情侶的行為。


這是很多人在與情侶相處時很難做到的，

&nbsp;

比如對方不小心遲到時，用惡意的解讀方式來理解，

&nbsp;

就會開始責怪對方，你不在乎我！


有人買了一只不停虧損的股票，

&nbsp;

就像面對一段無法挽救的婚姻，

&nbsp;

該不該拋出就跟是否應該離婚一樣困擾著他。


在事情上所花出去所有的成本，

&nbsp;

比如耗費的時間、金錢等，當這些成本無法回收時，

&nbsp;

在心理學上被成為沉默成本。


為什么我們不愿意離開一個不健康的婚姻，

&nbsp;

為什么不愿意放棄一個沒有價值的股票，

&nbsp;

原因是我們不愿意去承認這些沉默成本再也無法回收。


男生在戀愛里的情緒需求有如下幾點：


一、自身的能力被肯定。他時常會關心是否有讓人瞧得起？


二、才華被欣賞。也許他有些嗜好和才華與其工作完全不干，

&nbsp;

但你仍需學會喜愛和尊重。


三、努力被感激。

&nbsp;

他對你以及對這段感情所做的努力需要被感激。


女生在戀愛里的情緒需求：


一、時常被關懷。雖是日常的嘮叨，請你耐心傾聽。


二、再三地被肯定。她可能一二再而三地詢問你是否愛她。


其實她只是需要再三地肯定，你需要給她信心。


三、想法被尊重。（在分享情緒種種時增進彼此感情）

&nbsp;

保持愛情天長地久的方式：


制定一個三乘三的保鮮計劃。


一天三次一次三分鐘。


三A計劃，第一Attention，全神貫注。


在我們日常生活中，

&nbsp;

我常認為我們能給別人最好的禮物是時間，

&nbsp;

放掉你手邊的所有活，關掉手機專心地聽對方說話。


第二Affection，濃情蜜意。


非口語的溝通，即肢體語言的溝通。沒事多抱抱對方。


第三Appreciation，相互欣賞。


每一個成熟的女性身體里都有個非常幼稚的小女孩，

&nbsp;

每一個幼稚小女孩體內都有個幼稚的小問號。


那就是我到底有沒有討人喜歡。


在這個時候你需要學會稱贊對方，

&nbsp;

當然稱贊對方外貌、身材是個不錯的選擇。


或者她照顧家庭的能力也是不可忽視的。


當然每一個成熟的男性身體里都有個非常幼稚的小男孩，

&nbsp;

每一個幼稚的小男孩體內都有個可笑的小問號，

&nbsp;

那就是我有沒有讓人家瞧不起？


不管變成多成熟的男性，這個小問號依然存在。


學會給他肯定，從來沒有什么事情比愛更動容。


如果現在覺得生命中有一些不完整的地方，

&nbsp;

很可能就是這個功課還沒有做完。


愛情其實有規律可尋，如果遵循這些心理情緒需求，

&nbsp;

當最后一次對對方說我愛你的時候，我們會了無遺憾。
