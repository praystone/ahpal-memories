兩隻老鼠<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


在一個遙遠的國家，有兩位非常出色的木匠，他們的手藝都很好，難以分出高下。一天，國王突發奇想：「到底哪一個才是最好的木匠呢？不如我來辦一次比賽，然後封勝者為『全國第一木匠』。」


&nbsp;


於是國王把兩位木匠找來，為他們舉辦了一次比賽，限時三天，看誰刻的老鼠最逼真，誰就是全國第一木匠；不但可以得到許多獎品，還可以得到冊封。


&nbsp;


在那三天裡，兩個木匠都不眠不休地工作，到第三天，他們把雕刻好的老鼠獻給國王，國王把大臣全部找來，一起做本次的評審。


&nbsp;


第一位木匠刻的老鼠栩栩如生、纖毫畢現，甚至連鼠須也會抽動。


&nbsp;


第二位木匠的老鼠則只有老鼠的神態，卻沒有老鼠的形貌，遠看勉強是一隻老鼠，近看則只有三分像。


&nbsp;


勝負即分，國王和大臣一致認為第一個木匠獲勝;但第二個木匠當庭抗議，他說：「大王的評審不公平。」


&nbsp;


木匠說：「要決定一隻老鼠是不是老鼠，應該由貓來決定，貓看老鼠的眼光比人還正確呀！」


&nbsp;


國王想想覺得道理，就叫人到後宮帶來幾隻貓，讓貓來決定哪一隻老鼠比較逼真。沒想到，貓一放下，都不約而同地撲向那只看起來並不像老鼠的『老鼠』，使勁的啃、咬、搶、奪，而那只栩栩如生的老鼠卻完全被冷落了。


&nbsp;


事實擺在眼前，國王只好把『全國第一』的冊封給了第二位木匠。


&nbsp;


事後，國王把第二個木匠找來，問他：「你是用什麼方法讓貓也以為你刻的是老鼠呢？」


&nbsp;


木匠說：「大王，其實很簡單，我只不過是用魚骨刻了只老鼠罷了！貓在乎的根本不是像不像，而是那腥味呀！」


&nbsp;


人生的競賽往往是這樣，獲勝者往往不是因為技巧最好，而是最能貼近對方的心！！
