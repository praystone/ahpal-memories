&nbsp;




&nbsp;

要忘記一個人，也不是沒有方法的。

&nbsp;

這個方法，包括外在和內在。 

&nbsp;

外在的方法，你和我早就知道了，那就是時間。 

&nbsp;

無論你是否願意，時間流逝，會讓你忘記一個人。 

&nbsp;

內在的方法，是不要依戀。 

&nbsp;

分手之後，持續地想著對方有多麼好，

&nbsp;

那樣只會讓自己沉淪，

&nbsp;

愈來愈執著，也依戀得愈來愈深。 

&nbsp;

他不愛你了，不要再想著他有多麼的英俊。

&nbsp;

他走了，不要再想著他多麼的富有。

&nbsp;

他不在你身邊了，不要再想著他的性格多麼可愛。

&nbsp;

已經分手了，不要再想著他曾經待你多麼好。 

&nbsp;

不再執著他的優點，你才可以快點忘記他。

&nbsp;

也不要執著他對你曾經多麼壞，

&nbsp;

整天心懷憤恨，你便沒法忘記他。 

&nbsp;

他再怎麼好，都已經是昨天的事了。 

&nbsp;

我們無法忘記一個人，

&nbsp;

往往不是因為對方有多麼難忘，

&nbsp;

而是因為我們有多麼依戀和執著。 

&nbsp;

當你執著，連時間也要向你投降。

&nbsp;

他有什麼好呢？他都不愛你了。

&nbsp;

他將與另一個人共渡餘生。
