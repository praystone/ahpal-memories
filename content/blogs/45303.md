&nbsp;


&nbsp;


幸福是圓滿的人生。幸福是一種狀態，當我們的需求獲得滿足，


&nbsp;


因此，哪怕只是一碗泡麵，餓的時候，也能令我們幸福。










&nbsp;


幸福是，在愛情發生的那瞬間，不需猶豫就能夠說出：我--愛--你。






&nbsp;


另一種幸福，是說完就忘記的人。


&nbsp;


以前覺得理想中的幸福，是可以隨心所欲，



但往往好像總會有一些羈絆，讓我們無法隨心所欲；


&nbsp;


現在倒是覺得，只要能有心情想些隨心所欲的事，就已經夠幸福！






&nbsp;


&nbsp;


&nbsp;


&nbsp;


關於幸福，我們寧願「見賢思齊；見不賢而內自省。」



而不是把自己觀察到的不幸案例，送進腦海裡的黑白影印機，


&nbsp;


不斷複製對愛情與婚姻的懷疑。






&nbsp;


幸與不幸，常常只在一念之間。換個角度看待幸福與不幸福吧！






&nbsp;


當你看見別人的幸福時，不妨問問他們經營幸福人生的成功之道，


&nbsp;


讓自己有學習的機會。






&nbsp;


當你見識別人的不幸時，在同情與憐憫之餘，


&nbsp;


靜下心來冷眼旁觀，找出造成這些不幸的蛛絲馬跡，自我剔勵。


幸福，是一種習慣。一個小動作、一種思考方式、一項反應行為……

日積月累之後，讓你在不知不覺中向幸福接近。






&nbsp;


&nbsp;


&nbsp;


相對地，不幸福，也是由負面的習慣累積而成。它，讓你離幸福更遠。


&nbsp;


不管世間有多少不義與背離，永遠對愛情懷抱著信心與期待。



終於，你擁有了對不幸的免疫力，


&nbsp;


從每一個案例的思考中獲得警惕，


&nbsp;


也因此培養出幸福的習慣。






&nbsp;


每個愛情故事，都是一個情關。


&nbsp;


聰明的人，總在別人的傷痕中，看見智慧的光，


&nbsp;


讓自己的愛情，順利過關！






&nbsp;


&nbsp;


&nbsp;


你半生一直尋找不到的東西，你尋它像尋夢一樣，


&nbsp;


一但你找到它，就成了它的俘虜了。
