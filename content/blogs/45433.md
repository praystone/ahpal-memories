&nbsp;

說不出口的愛




&nbsp;


從小跟父親感情好到連妳都吃醋,

&nbsp;

妳說我不是妳親生的,害我好難過....

&nbsp;

曾經以為是真的,一直以來跟妳的距離好遙遠,

&nbsp;

想跟妳靠近一點,可是我又辦不到!

&nbsp;

&nbsp;

妳從20歲時經媒妁之言嫁來這個大家族,

&nbsp;

任勞任怨為家庭付出,

&nbsp;

凌晨三點半就得起床準備大家的早餐,

&nbsp;

因為每個人愛吃的口味不一樣,

&nbsp;

叔叔要吃撈飯(就是粥煮一半時把飯粒撈起來),

&nbsp;

光是飯就得煮了好幾種,

&nbsp;

因為人多所以煮早餐就會用掉你很多時間了,

&nbsp;

接下來又得忙於農事!
&nbsp;


身為長男的媳婦妳也不能喊苦,

&nbsp;

雖然外公家算是小康家庭,妳在家是長女,

&nbsp;

但頂多是做一些女生該的事情而已,

&nbsp;

嫁到這兒除了要幫忙種田.除草.插秧…割稻...

&nbsp;

甚至懷著大弟時,妳還肩挑近百斤的沙子….

&nbsp;

直到肚子痛,很快就把弟弟生下來,

&nbsp;

女人真的是很辛苦,母親妳更是偉大!

&nbsp;

種種的苦都很少聽你抱怨過,

&nbsp;

只因妳愛我們這十一個小孩,甚至爺爺打妳打到妳受傷了,

&nbsp;

妳也都忍下來(重男輕女的家庭很多少都會有家暴)….

&nbsp;

雖然不能為妳分擔什麼,打從7歲開始,

&nbsp;

我就負責幫忙帶弟弟妹妹,照顧好他們讓妳無後顧之憂,

&nbsp;

是我小小年紀唯一能做的! 

&nbsp;

雖然至今這包袱還在,但我很樂意為妳分擔這一切,

&nbsp;

因為妳是我最愛的媽媽,

&nbsp;

也許我也會覺的妳疼哥哥勝過我,

&nbsp;

覺得這是重男輕女的家庭,

&nbsp;

但是我比男生更來得努力,雖然沒什麼大成就,

&nbsp;

至少不曾讓妳擔憂過,這也是我唯一能為自己做的,

&nbsp;

因為事實更證明,女生不一定是弱者!

&nbsp;

&nbsp;

親愛的媽媽,我傳承了妳的韌性,

&nbsp;

但把妳的柔弱拋開了,不曾對妳說過我愛妳,

&nbsp;

妳一直是心裡的月亮,在我看不到夜晚的路時,

&nbsp;

妳總會帶著皎潔光輝出現,妳對我們的愛…

&nbsp;

妳的美…是無人能比的,小蓁永遠愛妳.,

&nbsp;

永遠會當個懂事的女兒,不讓妳擔心的女兒!


&nbsp;

雖然父親已經不在了,

&nbsp;

知道妳又住不習慣都市,寧可自己住在山上,

&nbsp;

但是只要妳開心,沒什麼比這更重要,

&nbsp;

有空我會回去看妳的,

&nbsp;

在這佳節來臨時先祝妳母親節快樂,身體健康沒煩惱…

&nbsp;

最親愛的媽呼咪我永遠愛妳!




&nbsp;


小蓁祝福亞寶及全天下的媽媽


100年母親節快樂
