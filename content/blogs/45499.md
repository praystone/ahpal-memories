爆笑相親
女：「你有三室一廳嗎？」

&nbsp; &nbsp; 男：「沒有。」

&nbsp; &nbsp; 女：「你有本田嗎？」

&nbsp; &nbsp; 男：「沒有。」

&nbsp; &nbsp; 女（站起）：「我有點事，先走了。」

&nbsp; &nbsp; 男（喃喃自語)：「俺有獨棟別墅，為啥要住小公寓？」

&nbsp; &nbsp; 女（僵住）……

&nbsp; &nbsp; 男（自語）：「俺開著賓士，難道要換成日本車？」

&nbsp; &nbsp; 女回眸一笑，相親繼續。

&nbsp; &nbsp; 男：「我創業把別墅、車子全抵押了，現在一點現金都沒有了。」

&nbsp; &nbsp; 女（大怒）：「我有好多事，先走了。」

&nbsp; &nbsp; 男：「還好後來拿到日本的天使基金，公司上市了。」

&nbsp; &nbsp; 女轉身坐下相親繼續。

&nbsp; &nbsp; 男：「不過IT行業風起雲湧，股票跌破發行價，快要停盤了。」

&nbsp; &nbsp; 女一聲不吭，站起身。

&nbsp; &nbsp; 男：「幸好被微軟收購，有了幾億現金，可以支持我二次創業。」

&nbsp; &nbsp; 女（轉身媚笑）：「你好壞啊，老是逗人家。」
