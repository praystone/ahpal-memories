如果有一天我離開了，


&nbsp;

不能再出現了，你會想我嗎?
&nbsp;
在你伸出手臂想擁我入懷的時候，


&nbsp;

我已經不能輕輕的抱著你了，親愛的人，

&nbsp;

你會，會，想​​我嗎？ 


&nbsp;

會懷念那些曾經相擁的甜蜜嗎？


&nbsp;

如果有一天，我離開了，


&nbsp;

不能再出現了，你會想我嗎？

&nbsp;

走在街角的時候，


&nbsp;

你還會不會自然而然的伸手去握我的手，


&nbsp;

你的目光是否會在人群中急切的尋找，


&nbsp;

雖然你深知那已是徒勞。
&nbsp;

&nbsp;

如果有一天，我離開了，


&nbsp;

不能再出現了，你會想我嗎？

&nbsp;

漫步於那片我們經常去的海灘，


&nbsp;

你還會想起那個調皮的逐浪嬉戲的女子嗎？ 

&nbsp;

而你還會嘮叨的說：


&nbsp;

小心，會摔倒的。你，還會去嗎？


&nbsp;

如果有一天，我離開了，


&nbsp;

不能再出現了，你會想我嗎？


&nbsp;

每天不再有一個人等在做好的飯菜旁，


&nbsp;

痴痴的盼你回來，


&nbsp;

在你不回來之前她的心總是那樣忐忑，


&nbsp;

直到看見你疲憊的身影，她才會微笑上前，


&nbsp;

彼時此時，望著空蕩的餐桌，你會淚流滿面嗎？ 


&nbsp;

如果有一天，我離開了，


&nbsp;

不能再出現了，你會想我嗎？

&nbsp;

還記得那首歌嗎？


&nbsp;

我能想到最浪漫的事，就是和你一起慢慢變老，


&nbsp;

一路上收藏點點滴滴的歡笑，

&nbsp;

留到以後坐著搖椅慢慢聊。
&nbsp;


對不起，在你把我當成手心裡的寶時，


&nbsp;

我也許會隨風而飄，當你一個人聽到這首歌時，


&nbsp;

你的心該會有多疼呢？而你也許不知道，


&nbsp;

如果我的世界沒有你了，我會深深的想你。

&nbsp;

漆黑的夜裡，我會摸索你的手臂，


&nbsp;

希望你輕輕擁我入懷，等到冷的偷偷的哭泣。


&nbsp;

走在街角的剎那，


&nbsp;

我會在來來往往的人潮裡尋找你，


&nbsp;

直到累的我不能站穩腳步，


&nbsp;

蹲在那裡，此時，多希望你能將我拉起。

&nbsp;

漫步那片沙灘時，我不會再像個孩子似的逐浪嬉戲，


&nbsp;

因為不會再有一個聲音在耳邊響起，

&nbsp;

“小心，會摔倒的。”


&nbsp;

此時，我只會默默的傾聽那海哭的聲音。

&nbsp;

傍晚的餐桌旁，我會痴痴的等，


&nbsp;

你踏進門口的身影，任那飯菜熱過又涼了，


&nbsp;

直到下一個不眠的天亮。


&nbsp;

沒有了你，我想我不能再聽那首歌了，


&nbsp;

因為我不能忍受那歌詞在耳邊纏繞，


&nbsp;

那只會讓我更想你，


&nbsp;

想的撕心裂肺，哭的潰不成堤。


&nbsp;

如果有下一世的輪迴，如果有來生相伴，

&nbsp;

你的劇本依然由我領銜主演，

&nbsp;

依然選擇與你相伴，不過那時我希望的期限是，

&nbsp;

相伴到永遠。
