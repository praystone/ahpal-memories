&nbsp;


&nbsp;

你沒有反對我站在風中等候

&nbsp;

霧鬢風鬟是你喜歡的姿態

&nbsp;

一如往常我總側身回眸

&nbsp;

&nbsp;

你沒有阻止我飛揚中的裙襬

&nbsp;

害羞淺笑是你喜歡的神態

&nbsp;

一如初識你總靜靜凝望

&nbsp;

&nbsp;

我沒有說出思念

&nbsp;

那纏纏綿綿總是掛意

&nbsp;

是不是你心房懸著軸心

&nbsp;

等著纏繞我幽幽的絲線

&nbsp;

&nbsp;

我眼中的你的眼

&nbsp;

只見明月光輝了星辰

&nbsp;

哪怕你閉上眼

&nbsp;

殘留的光暈

&nbsp;

也足夠點亮我心頭

&nbsp;

只為你開啟的燭火

&nbsp;
