&nbsp;

&nbsp;

棧戀過白花飄落的步道

&nbsp;

挽過的手 垂直冷清空洞

&nbsp;

在你耳邊細語的時光

&nbsp;

時空跳換 唇已沉默不語

&nbsp;

觀望潮汐喊過的海洋

&nbsp;

朵朵浪花被回憶蒸發

&nbsp;

在你悄然入睡之後

&nbsp;

我的一切都變調了

&nbsp;

非關是非好壞

&nbsp;

從作伴到孤單

&nbsp;


由茫然到繁忙

&nbsp;

心境是節節變涼

&nbsp;

唯一的遺憾

&nbsp;

是意志太堅強

&nbsp;

學不會依賴的心臟

&nbsp;

將美夢留置陰暗

&nbsp;

過著半生活 混其一生

&nbsp;
