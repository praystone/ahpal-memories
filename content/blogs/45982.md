非常有名的心理測驗

&nbsp;



&nbsp;

&nbsp;


L小姐 和M 先生是一對戀人，兩人隔河而居， rn&nbsp;

那條河不寬，也不闊。

&nbsp;

有一天，M先生得了急病，L小姐知道了心急如焚，

&nbsp;

但是那一天出現了暴風雨，河水暴漲，風急雨勁，

&nbsp;

M先生叫她不要去探望他，可L小姐還是要不顧一切

&nbsp;

去看看他。


&nbsp;

於是她去找B先生，因為B先生有一條船，

&nbsp;

有能力送她過河。

&nbsp;

可是，B先生卻要收過河費一百萬，

&nbsp;

即使她向他解釋M先生的情況，他也一樣不為所動。

&nbsp;

L小姐當然沒有那麼多錢，於是她去找S先生，

&nbsp;

因S先生也有一條船。


豈料，S先生竟是無恥之徒他要求L小姐獻上她的身體，

&nbsp;

方才載她渡河。L小姐為了愛情，最後犧牲了自己……

&nbsp;

最後，S先生也載了她過河。


&nbsp;

M先生的急病，最後也沒有惡化，是化險為夷了。

&nbsp;

但當他知道L小姐居然犧牲了自己的貞節，他很生氣，

&nbsp;

因為他早已吩咐她不要來，何況還因此犧牲了身體！


&nbsp;

於是，M先生 和L 小姐就這樣分手了。

&nbsp;

L小姐很傷心，不久之後，他認識了年紀較大的F先生。

&nbsp;

當他知悉了她的過去後，不但不介意，還向她示愛。

&nbsp;

雖然L小姐並不太愛F先生，他也不太勉強 ……


&nbsp;

&nbsp;

&nbsp;

好了，問題來了：


參考故事內容，然後從故事的五位人物 ，

&nbsp;

L, M, B, S, F


&nbsp;

五位人物，按照你喜歡他們的程度，

&nbsp;

由最喜歡到最不喜歡排出一個等次。


&nbsp;

&nbsp;

解 答 如 下 :　

&nbsp;

這個其實是美國心理學家研究出的

&nbsp;

一個略有名氣的心裡測驗，

&nbsp;

其實每一個故事人物都代表一個意義 


&nbsp;

L小姐 - Love ( 愛情 )


M先生 - Morality ( 道德 )


B先生 - Business ( 事業 / 金錢 )


S先生 - Sex ( 性 )


F先生 - Family ( 家庭 )

&nbsp;

當你領會故事情節之後，

&nbsp;

對故事人物所排列出來的喜愛次序，

&nbsp;

正反映以上人性觀念在你心目中之排列次序。
