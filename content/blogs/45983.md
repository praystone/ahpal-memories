最成功的一次謊話


&nbsp;

打開心胸，多記好事。


&nbsp;



&nbsp;


一個朋友跟我說&nbsp; 


&nbsp;

她的女兒一向都很喜歡上學，


&nbsp;

但是升上五年級換了導師後，兩人「不來電」，


&nbsp;

每天都回 家抱怨 老師不喜歡她，


&nbsp;

把她學術股長分內的工作派給別人去做，


&nbsp;

老師也抱怨她女兒 ，跟老師說話臉色不好，沒有禮貌。


&nbsp;

孩子開始不喜歡上學，常常遲到。


&nbsp;

有一天，老師又叫我這個朋友去學校談話，


&nbsp;

她回家時一肚子氣正想發作，


&nbsp;

但是看到女兒恐懼的臉，


&nbsp;

便不忍心罵她，隨便說了一句：「老師說你很好。」

&nbsp;

想不到她女兒立刻碇放出喜悅的笑臉，


&nbsp;

追問道：「真的嗎？老師真的說我很好嗎？」


&nbsp;

她不得已又加了一句：「老師說你在班上幫她很多忙。」


&nbsp;

結果，一個晚上，女兒都心情很好。

&nbsp;

&nbsp;

第二天上學時，路邊有人賣玉蘭花，


&nbsp;

女兒便向她要錢買了一串，說「老師喜歡香花」。


&nbsp;

老師以為香花是女兒道歉的表示，便對她微笑了一下，


&nbsp;

女兒看到老師笑了，更確定母親昨天說的話是真的，


&nbsp;

於是便很高興的幫老師做事。


&nbsp;

雙方正向回饋的結果是:她的女兒喜歡上學了。


&nbsp;

她說，這是她這一輩子說的最成功的一次謊話。

&nbsp;

人際關係是世界上最複雜的一個非線性關係，


&nbsp;

&nbsp;

很多時候，

&nbsp;

一點的誤會會造成很大的人際關係惡化，


&nbsp;

付出的代價常是一輩子的遺憾，

&nbsp;

在生活中這種例子不知道有多少，


&nbsp;

但是人都很容易掉進這個泥沼中，不可自拔。


&nbsp;

&nbsp;

其實，只要一開始不要以負面的觀點

&nbsp;

去解釋別人的行為，就可以避免。

&nbsp;

&nbsp;

我想起小時候，父親每天檢查我們的日記，


&nbsp;

一方面是訓練我們作文，


&nbsp;

另一方面是藉此知道我們每天在做些什麼。

&nbsp;

&nbsp;

有一次，我在日記上寫道:「今天諸事不順」，


&nbsp;

我雖然已經去睡了，父親還是把我叫起來問：


&nbsp;

「為什麼今天諸事不順？」 

&nbsp;

我回答道：

&nbsp;

「放學時沒趕上公車，等了四十五分鐘才來第二班，


&nbsp;

因為公車脫班，所以人很擁擠，


&nbsp;

我被人踩到腳，白球鞋要重刷鞋粉，


&nbsp;

明天才能通過檢查，書包帶子被擠斷，用抱著回家。

&nbsp;

父親問：「早上去上學時有趕上公車嗎？」


&nbsp;

我說：「有，一出巷口車就來了，到校還有十分鐘的空檔。」


&nbsp;

他又問：「今天便當有丟掉嗎？」 我說：「沒有。」

&nbsp;

&nbsp;

早期臺灣物質缺乏，

&nbsp;

學校蒸便當常會丟掉便當，丟的人只好餓肚子


&nbsp;

「有被老師打嗎？」我說：「沒有。」&nbsp; 


&nbsp;

父親就正色說：「那你為什麼說諸事不順 ？


&nbsp;

總是記得不好的事，不記得好的事，


&nbsp;

你這樣會使你變得尖酸刻薄，人家不喜歡你。」

&nbsp;

&nbsp;

後來，我發現人果然總是記得不順的事，

&nbsp;

把順利的事當作理所當然，


&nbsp;

而人也真的是不喜歡總是怨天尤人的朋友。


&nbsp;

很多時候，

&nbsp;

如果我們肯放開心胸，先不要懷疑別人的話是有惡意，


&nbsp;

我們會發現他的話的確沒有惡意，


&nbsp;

只是表達不當，聽起來不順耳而已。

&nbsp;

&nbsp;

英文有句話 :


"give the benefit of doubt"，


"當不確定時，先假設對方沒有惡意。"


如果能做到這點，人生的路會平坦許多。
