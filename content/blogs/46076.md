&nbsp;

&nbsp;

親愛的謙育皮北鼻

&nbsp;

無時無刻都在想你

想你對我的好

想你對我的欺負

想你老是逗著我玩

每天都很幸福&nbsp;&nbsp;&nbsp; 很開心&nbsp;&nbsp;&nbsp; 很快樂

&nbsp;

也想著

北鼻對我說過的話

對不起&nbsp;&nbsp;&nbsp; 我總是亂想

對不起&nbsp;&nbsp;&nbsp; 我總是笨笨的&nbsp;&nbsp;&nbsp; 說話前都沒有好好想

&nbsp;

你說要我當你的小綿羊

乖乖的在你身邊就夠了

可是...我不是乖乖的小綿羊

我是有攻擊力的山羊

我不乖 只是在你身邊&nbsp;&nbsp; &nbsp;不夠 

想要黏住你&nbsp;&nbsp;&nbsp; 佔住你&nbsp;&nbsp;&nbsp; 膩著你&nbsp;&nbsp;&nbsp; 對你撒嬌&nbsp;&nbsp;&nbsp; 

要你疼我&nbsp;&nbsp;&nbsp; 要你愛我&nbsp;&nbsp;&nbsp; 要你抱我&nbsp;&nbsp;&nbsp; 要你只有我

&nbsp;

聖書對愛的描寫總是很偉大、很大愛

但是長越大越發現

要做到這些&nbsp;&nbsp;&nbsp; 有可能

但真的&nbsp;&nbsp;&nbsp; 太難

這些&nbsp;&nbsp;&nbsp; 都是我們愛一個人的表現

這些&nbsp;&nbsp;&nbsp; 都是無法克制的情感

問天&nbsp;&nbsp;&nbsp; 有誰能做到?

我說&nbsp;&nbsp;&nbsp; 我不相信

因為&nbsp;&nbsp;&nbsp; 太大愛了&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 我只是一介凡人&nbsp;&nbsp;&nbsp; 我做不到如此的大愛

&nbsp;

皮是我的開心果。

&nbsp;

這是我們深交前的一句話

一句真心的話

&nbsp;

在一起後

皮不只是我的開心果

也是我幸福的依靠

對不起是我沒注意到

總是在你面前哭泣

卻忘了告訴你

我有多麼愛你&nbsp;&nbsp;&nbsp; 多麼喜歡你

&nbsp;

你依然是我的開心果

只要想到你

我就會不自覺的微笑

想到你總是逗我

雖然有時候真的不知道要怎麼說

但是總是不自覺

微微的笑&nbsp;&nbsp;&nbsp; 總會變成靦腆害羞的笑

&nbsp;

每次落寞的一個人穿梭在校園

想著你&nbsp;&nbsp; &nbsp;我就不寂寞

因為我知道&nbsp;&nbsp;&nbsp; 你心與我同在

即使你不在身邊&nbsp;&nbsp;&nbsp;&nbsp;我依然堅強

&nbsp;

每晚&nbsp;&nbsp;&nbsp; 是我最期待的時刻

因為有皮陪著我

每天&nbsp;&nbsp; &nbsp;只要看到&nbsp;&nbsp;&nbsp; 皮上線&nbsp;&nbsp;&nbsp; 皮打電話

我都會一個人傻笑

笑的很幸福&nbsp;&nbsp;&nbsp; 笑的很像傻蛋

每次&nbsp;&nbsp; &nbsp;總是等皮自己密我

因為&nbsp;&nbsp;&nbsp; 皮是大忙人

我怕打擾到你

所以即使不斷的換狀態

也盡量都不密你

看到你對我的回應

我很開心

&nbsp;

知道為什麼我老是想打電話給你嗎?

因為&nbsp;&nbsp; &nbsp;在這刻皮是我一個人的

聽著你的聲音&nbsp;&nbsp;&nbsp; 聊聊天&nbsp;&nbsp;&nbsp; 即使只有少少的幾句話&nbsp;&nbsp;&nbsp; 心裏一樣很甜

&nbsp;

心疼你總是那麼那麼累

沒有多少時間休息

卻還是自私的佔有了你一部分的時間

每晚 總是賴在電腦前&nbsp;&nbsp; &nbsp;不肯離去

仔細想想&nbsp;&nbsp; &nbsp;知道北鼻也是心疼我

每天晚睡早起沒精神

在心疼你的時候卻忘了照顧好自己讓你也擔心了...

&nbsp;

你說&nbsp;&nbsp;&nbsp; 要我一星期不要找你

對我來說&nbsp;&nbsp;&nbsp; 真的很難

因為我巴不得自己就在你身邊&nbsp;&nbsp;&nbsp; 一直膩著你

&nbsp;

還有...對不起....

我那麼愛賭氣...

總是沒有好好把你打的字看完

好好的想清楚你要表達的意思

卻老是自己一個人生悶氣....

&nbsp;

我真的很笨

遇到你後又變的更笨

因為我很在乎你&nbsp;&nbsp;&nbsp; 很喜歡你&nbsp;&nbsp; &nbsp;很愛你

&nbsp;

你總是讓我變成好奇寶寶

卻老是不把話說完

真的讓我摸不著頭緒&nbsp;&nbsp;&nbsp; 雖然我知道有時候是情趣

&nbsp;

親愛的謙育

我真的很想站在你的面前&nbsp;&nbsp;&nbsp; 在你的身邊

看看你愛我的心

也讓你看看我愛你的心

這樣你就會知道

我打出的每一個難過與哭泣的符號

有多少個是對你的依賴與撒嬌

更何況是那些高興傻笑

&nbsp;

昨晚&nbsp;&nbsp;&nbsp; 是我對你的撒嬌與依賴

但沒想到&nbsp;&nbsp;&nbsp; 我卻會真的落淚。

一覺醒來&nbsp;&nbsp;&nbsp; 眼角淚痕乾了

想了整天

笨笨的腦袋才想到

竟然沒有把最重要的兩個字放進腦袋

北鼻對我說的&nbsp;&nbsp;&nbsp; 愛妳

這個時候腦袋的結才打開了吧

北鼻要我早點睡

要我好好讀書

是心疼我&nbsp;&nbsp;&nbsp; 愛護我

我卻一直在角落埋怨

北鼻沒有再多陪我一點

&nbsp;

突然想起一篇日誌&nbsp;&nbsp;&nbsp;&nbsp;沒錯 又是一篇日誌

日誌裡說了

兩個人在一起

愛情&nbsp;&nbsp;&nbsp; 絕對不要也不是擺第一位

可以排在第二、第三&nbsp;&nbsp;&nbsp; 就是不要第一

因為&nbsp;&nbsp;&nbsp; 一個不小心會失去自我&nbsp;&nbsp;&nbsp; 失去所愛的人

而我看了&nbsp;&nbsp;&nbsp; 卻一直沒有做到

&nbsp;

想對你說的話 比什麼都多

就算只是點小事&nbsp;&nbsp;&nbsp; 也可以很開心很幸福

是自私也是....想要你多關心我一點

所以才會.....受傷了就跟你說....

讓你擔心了...&nbsp;&nbsp;&nbsp; 

&nbsp;

這篇日誌的最後

我要說：「親愛的謙育皮北鼻&nbsp; 我很喜歡你&nbsp; 很愛很愛你&nbsp; 很想很想你&nbsp; 你不只是我的開心果&nbsp; 也是我的依靠&nbsp; 我絕對不要輕易的離開你!!」

&nbsp;

&nbsp;

還有&nbsp;&nbsp;&nbsp; 這篇日誌只屬於你與我，不會有其他人看見，除非你開給他們看。

&nbsp;

愛要勇敢大聲說。

「謙育北鼻我愛你」 



你呢&nbsp;
