&nbsp;


&nbsp;



別靠的太近 我是危險的晚香玉

&nbsp;

許給你歡愉 也將帶走你的靈敏

&nbsp;

&nbsp;

&nbsp;

別想的太多 我是遠離的金盞花

&nbsp;

哪怕匆匆一眼 也將帶你入煉獄

&nbsp;

&nbsp;

&nbsp;

別等的太久 我是傲慢的水仙花

&nbsp;

關於你的愛 從來都不曾重視它

&nbsp;

&nbsp;

&nbsp;

別說的太多 我是忙碌的蔦蘿花

&nbsp;

非關生與死 請不要煩擾我生活

&nbsp;

&nbsp;

&nbsp;

別愛的太深 我是善變的大理花

&nbsp;

從沒有把握 想對愛情從一而終

&nbsp;

&nbsp;

文章對花的描素純屬抒發..無對任何花朵有不敬之意
