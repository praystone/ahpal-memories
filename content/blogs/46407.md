&nbsp;

&nbsp;

你總說我還不懂事

&nbsp;

維護我像一張白紙

&nbsp;

你眼中我永遠是

&nbsp;

長不大的孩子

&nbsp;

雖然我有好多心事

&nbsp;

卻已不願說與你知

&nbsp;

我曾任性地排斥

&nbsp;

你愛我的方式

&nbsp;

想逃離你到遠方去

&nbsp;

做我最想做的自己

&nbsp;

當我陷落在人群裏
&nbsp;

我最想念的人是你

&nbsp;

當離開了你想說給你聽

&nbsp;

喔媽媽我愛你

&nbsp;

當歲月過去我欠你一句

&nbsp;

現在說會不會太遲

&nbsp;

你會不會笑我還是多像孩子

&nbsp;

ha...啊

&nbsp;

我已經越來越想你

&nbsp;

我就是另外一個你
