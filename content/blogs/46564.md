記住這25條了，你就成熟了

&nbsp;



&nbsp;

&nbsp;


1、 遇到不想回答的問題：直視對方的眼睛，微笑、沈默。 

&nbsp;

2、走路抬頭挺胸，心情不好時，

&nbsp;

不想跟人招呼，點頭微笑，逕直過 。 

&nbsp;

3、請記得：好朋友的定義是，你混的好，


&nbsp;

他打心眼裡為你開心，你混的不好，他由衷的為你著急。 

&nbsp;

4、做自己的決定，然後準備好承擔後果。


&nbsp;

從一開始就提醒自己，世上沒有後悔藥吃，


&nbsp;

而我永遠有個B計劃。&nbsp;&nbsp; 

&nbsp;

5、自己分內的事情，努力做到一百分。 

&nbsp;

&nbsp;

6、接受自己不過是個"小小的我"，

&nbsp;

但眼裡要能夠悅納"大大的世界"。 

&nbsp;

7、如果你真的喜歡一個人，就給他自由。


&nbsp;

如果他能回到你身邊，他就是你的，


&nbsp;

&nbsp;&nbsp;&nbsp; 如果他沒有回來，那他也永遠不屬於你。&nbsp; 

&nbsp;

8、不要試圖給自己找任何藉口，錯誤面前沒人愛聽那些藉口。&nbsp; 

&nbsp;

9、不要隨意發脾氣，誰都不欠你的。&nbsp; 

&nbsp;

10、不說謊話，因為總有被拆穿的一天。 

&nbsp;

&nbsp;

11、別低估任何人。 

&nbsp;

12、你沒那麼多觀眾，別那麼累。

&nbsp;

13、過去的事情可以不忘記，但一定要放下。 

&nbsp;

14、別人說的記在腦袋裡，而自己的則放在心裡。 

&nbsp;

15、社會是有等級的，

&nbsp;

很多事不公平，別抱怨，因為沒有用。

&nbsp;

&nbsp;

16、你永遠沒有你自己想像中那麼重要。

&nbsp;

17、錢能解決的問題通通不叫問題。 

&nbsp;

18、無論何時說"我愛你"，請真心實意，無論何時說"對不起"，


&nbsp;

請看著對方的眼睛。

&nbsp;

19、永遠不要以貌取人，慢慢地說，但要迅速地想。&nbsp; 

&nbsp;

&nbsp;

20、找點時間，單獨呆會兒。 



&nbsp;

21、不是自己的東西不要，

&nbsp;

&nbsp; 就是再喜歡也不行，要懂得放棄。

&nbsp;

22、不要覺得是生活虧欠了你，其實是我做的努力不夠。 

&nbsp;

23、努力向前，再努力向前，再努力一下下，願望就會實現！&nbsp; 

&nbsp;

24、永遠沒有堅持到底的失敗，也不會有半途而廢的成功。&nbsp; 

&nbsp;

25、三人行必有我師，沒有人會比你弱，


&nbsp;

好學、上進的心態。多問問自己："我努力了沒有？"。

&nbsp;

&nbsp;

非洲古諺語:


&nbsp;

如果你想走得快，你要自己走；

&nbsp;

如果你想走得遠，你要找個伴。說得真是好 !
