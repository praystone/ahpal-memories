&nbsp;

用心去珍惜

你在網上遇到的好朋友



&nbsp;

&nbsp;


有個知心網友,真好。 

&nbsp;

因為不曾謀面，互相間沒有落差沒有害羞、

&nbsp;

沒有尷尬，不必矜持、不必設防，

&nbsp;

心裏有了不能說出卻只能寫在日記裏的話，

&nbsp;

有個知心網友，便可以盡情傾訴。


&nbsp;

這時，他真的成了這世界上最可以信賴，

&nbsp;

最可以親近的人。有個知心網友，真好。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

也許永遠無須謀面，

&nbsp;

互相間就有了一種想了解的渴望，

&nbsp;

卻總朦朦朧朧的不能透明，

&nbsp;

不像面友交往幾次熟了，互相看透了，就膩了。


然而，他的音容笑貌以想象的姿式鮮活於互相的心裏、夢裏，

&nbsp;

而想象的土地上永遠不生長俗品，有個知心網友，真好。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

塵俗的欲念從指尖通過電腦過濾，

&nbsp;

穿越真實的萬水千山，

&nbsp;

在網絡中擁抱的靈魂可以無拘無束，

&nbsp;

互相間索取的是心情，奉獻的也是心情，

&nbsp;

在純潔的天宇中，

&nbsp;

精神的享受比物質真實，比物質持久。

&nbsp;

&nbsp;

有個知心網友，真好。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


被友情呼喚被心情滋潤，

&nbsp;

手中的鍵盤操練起來總是很容易投入，

&nbsp;

就會有意想不到的珍言珠語閃著光澤從心河汩汩湧出，

&nbsp;

給生活添了幾分色彩，給季節增加了一分成熟，

&nbsp;

有個知心網友，真好。
&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

他可以不必挑剔相貌和身高，

&nbsp;

可以不必挑剔權勢和貧富，甚至，連年齡都可以不必挑剔。


進入知心網友，就走出塵俗，走出虛偽，

&nbsp;

走向美麗，走向純樸，走向春天，走向成熟。


&nbsp;

知心網友是互相的陽光，知心網友是互相的雨水，

&nbsp;

知心網友是互相的長鞭，知心網友是互相的海岸，

&nbsp;

卻不是誰都能很容易走進知心網友享有知心網友的愜意。


&nbsp;

知心網友的紅繩是用知識、

&nbsp;

指力、真誠、涵養、韌力……

&nbsp;

許多成分擰就的，也不必等待完全具備了才開始尋覓，

&nbsp;

一邊結識一邊投入，

&nbsp;

知心網友的紅繩就在日子中結實起來。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


在茫茫的網海裏能與你結緣是我的福份，

&nbsp;

希望好友與我相互珍惜這份真誠友誼，

&nbsp;

願我們的友誼天長地久......

&nbsp;
