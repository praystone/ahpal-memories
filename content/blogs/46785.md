&nbsp; 

&nbsp;
 
情是無所求的




情感是人生的表現形式，沒有情感，

&nbsp;

就無法談論人生。

&nbsp;

從情感中可以派生出人生一切的欲望和追求，

&nbsp;

不論是物質的，科學的，

&nbsp;

還是藝術的都離開人生的根本----情感。


也許我們往往只看到人生繁華美麗的枝葉，

&nbsp;

卻看不到支撐這繁華美麗的根系。

&nbsp;

情感的產生，來原於人對世界的看法。


&nbsp;

有了看法就有了情感，有了情感就會產生感情，

&nbsp;

尤其是在愛情上，情感的產生，

&nbsp;

讓我們知道異性的相吸，通過相互的吸引，

&nbsp;

使我們了解了那惟妙惟肖的感情。


&nbsp;

愛一個人並不是要從對方身上得到什麼利益，

&nbsp;

愛一個人就是願意對他好，因為你會覺得很快樂。

&nbsp;

為什麼我們常說這是一個無情的時代，

&nbsp;

就是因為每個人在付出感情的同時，就像在做生意一樣。


&nbsp;

付出了就一定要有回報，當我們去愛一個人的時候，

&nbsp;

總是喜歡先去確定對方是不是也愛自己，

&nbsp;

若對方不愛自己，那自己就不會去愛對方，

&nbsp;

沒有幾個人能夠用自己的真誠，

&nbsp;

無私的深愛對方，為對方去生，為對方去死。


&nbsp;

年代不同了，真的不同了，每一個相愛的人，

&nbsp;

都希望得到對方關愛，都不想為對方去犧牲。

&nbsp;

所以說這個年代是無情的年代。


&nbsp;

感情是一種付出，而不是一種得到，

&nbsp;

也不應計較對方能給你多少，因為你本來就一無所有。

&nbsp;

你也可以為愛情犧牲，但這犧牲一定要是自己心甘情願，

&nbsp;

而不是委屈、很勉強、然後要求對方來報答你的。


&nbsp;

有人說：“偉大的愛情應該禁得起考驗”，

&nbsp;

可是感情既然這麼可貴，就應該小心翼翼的呵護才對，

&nbsp;

而不是有事沒事拿來考驗對方。

&nbsp;

就像一顆雞蛋拿在手裏，應該小心呵護，

&nbsp;

而不是將它丟到地上，才訝異它怎會破掉！


&nbsp;

不要去考驗愛情，但也不要害怕考驗，

&nbsp;

更無須害怕考驗會失敗。


&nbsp;

我們當然都希望愛情能談的平凡、順利，

&nbsp;

一輩子都沒有任何問題。

&nbsp;

但若愛情必須受到一些波折、一些打擊、

&nbsp;

一些傷害的時候，我們也能挺身去接受。


勇敢的迎接自己所得的愛情，盡力去享受愛情的美好，

&nbsp;

避免它會帶給我們的痛苦、傷害才好。


&nbsp;

多用豁達的角度去看待愛情，

&nbsp;

這樣，你就會感覺到愛情給你帶來的快樂！

&nbsp;
