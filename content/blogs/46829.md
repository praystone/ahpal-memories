&nbsp;

淡泊人生

&nbsp;



&nbsp;

&nbsp;

&nbsp;


攜一份淡泊 品一份寧靜

&nbsp;

在紛繁複雜的塵世間

&nbsp;

擁有一份屬於自己的寧靜&nbsp; 實在是一種獨特的享受


拒絕外來的誘惑

&nbsp;

獨自倘佯於自己營造的淡泊的氛圍裡

&nbsp;

沏一杯香茗、放一段音樂

&nbsp;

讓疲憊的身心在靜靜的寧靜中&nbsp; 好好的放個假


什麼也不做就靜靜的思索

&nbsp;

讓思緒在寧靜中&nbsp; 飄的很遠很遠......


寧靜是心靈的潔淨&nbsp; 寧靜是一種禪意

&nbsp;

心中寧靜 就不會困於喧囂的市井

&nbsp;

就不會被流言蜚語擾亂心智


心中寧靜意味著能靜下心來思考

&nbsp;

人因思考而得到靈魂的自由與永恒


&nbsp;

淡泊與寧靜 就是同一種境界&nbsp; 江水澄澈千里


&nbsp;

在平淡中執著地奔流&nbsp; 高山巍峨千年


&nbsp;

在靜默中恒久地屹立


自然早已將這種境界展現給我們


&nbsp;

如同日夜更迭 季節流轉&nbsp; 如同松濤起伏 清泉流淌


&nbsp;

一切在淡然之中&nbsp; 一切在寧靜之中


&nbsp;

沒有慾望和雜念&nbsp; 一切都是和諧美好


&nbsp;

而且生生不息&nbsp; 這就是智慧


如果人能悟到淡泊寧靜的真諦


&nbsp;

就不會再因紛繁的&nbsp; 人情世故而精疲力竭


"行到水窮處，坐看雲起時"


&nbsp;

淡泊寧靜之中


&nbsp;

是和諧和深邃的心態&nbsp; 淡而越深 近而越遠


當放開生活的那些細枝末節&nbsp; 所嚮往的


&nbsp;

所追求的生命的形式&nbsp; 才真正的在我們的前方


&nbsp;

而不再是糊塗&nbsp; 和慌亂中的一時夢幻

&nbsp;

&nbsp;

Angela編制
