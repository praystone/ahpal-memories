小羊藏刀救母，屠夫落淚轉行


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 遼寧大連市新商報訊5月29日（記者陳璟華） 近日，馬欄村一家生意興隆的羊湯館突然關門歇業，讓許多老主顧非常不解。記者通過知情者瞭解到，原來不久前，這裏上演了一出山羊母子生離死別的感人場面，令羊湯館老闆心裏難安，最後他決定關掉羊湯館，不再從事這個行業。


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 在店門口宰殺活羊，是這家羊湯館的老規矩，也標榜該店提供的肉質鮮活味美。但據知情者告訴記者，半個月前，羊湯館的趙老闆從一家農戶買了一大一小兩隻羊。這天，趙老闆準備先把大羊殺了，讓夥計著手準備。夥計把刀放在屋外的長凳上，轉身進屋拿盆以備接羊血用，可等他把盆拿出來卻怎麼也找不到刀了，店裏的人都說沒看到。


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 此時，那只大羊正低頭流著淚舔舐著小羊，而小羊趴在地上仰臉看著大羊，眼淚已經打濕了眼睛下方的毛。看到這個情景，夥計叫來了老闆。趙老闆看到這一幕，心頭也不禁一顫。回想起賣羊的人曾說過這兩隻羊是娘倆兒，看此情形，應該是這娘倆兒都知道臨別將至，正在依依惜別呢。為了不讓小羊親眼看到大羊被宰殺，趙老闆讓夥計拉走小羊。可就在小羊被拽起來的一刹那，夥計在小羊趴著的地方發現了他正在找的那把刀。誰都不知道刀是怎麼到小羊身底下的，但在場的人都一致認為，一定是小羊為了阻止媽媽被殺而將刀藏在身底的。


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 以前也曾聽說過牛、馬等牲畜在被殺前流淚的事情，但開羊湯館已五年多的趙老闆卻是第一次親眼目睹這種事，猶豫再三，他示意夥計留這兩隻羊一條生路。幾天過去了，羊母子流淚惜別的情景總不時出現在趙老闆的眼前，讓他心裏難安。這樣經過幾天的思想鬥爭，最後他決定關掉羊湯館，不再從事這個行業！

人類一直認為動物不會哭泣，但是這只水牛卻哭泣得像個嬰孩！ 


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


一群目瞪口呆的屠宰場工幷人，拒絕宰殺一隻跪地求饒的大水牛，它的雙眼充滿哀傷，同時臉頰掛滿著眼淚。 「人類一直以為動物是不會哭泣，可是那只水牛真得像個嬰孩一樣地啜泣著！」一位香幷港的包裝廠老闆Billy Fong如此告訴記者。


&nbsp;


&nbsp;


&nbsp;


「當時至少有一打強壯魁梧的男士在場，而負責宰殺動物的那些男孩，他們的眼淚也不禁奪眶而出。」在場的人都非常地感動，他們一起出錢買下這只水牛，將它送到一間佛幷寺，並祝福這只水牛能平靜地過完餘生。


&nbsp;


&nbsp;


&nbsp;


轉貼自：世界新聞周-刊1996.5.28&nbsp; 


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


這個水牛哭泣求饒的感人故事是這樣開始的：一群工幷人牽著一隻水牛走進包裝廠內，準備將它宰殺做成牛排和燉牛肉。當他們接近屠宰房門口時，那只悲傷的水牛突然停步不前，兩隻前腳往前跪下，眼淚也跟著撲簌簌地流了下來。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


「當我看到這種被人們認為是愚笨的動物，竟然在哭泣，以及看到它那充滿恐懼和悲哀的雙眼時，我忍不住地發起抖來。」一位受到極度震撼的屠夫Shiu Tat-Nin回憶說。 「我趕緊叫其他人過來看，他們也和我一樣地訝異！我們不住地推拉著那只水牛，可是它卻一動也不動，只是坐在那邊不斷地哭泣。」


&nbsp;


&nbsp;


&nbsp;


&nbsp;


「我們被眼前的景象給震撼住，因為那只牛看起來就好像是人一樣。我們環顧著彼此，內心都很清楚，這裏沒有一個人忍心下得了手殺它。接下來面對的問題是：我們該怎麽來處理這件棘手的問題？」 最後他們決定大家一起出錢買下這只哭泣的水牛，並且送給那些會愛護它的出家人，好讓它可以安心地度過這一輩子。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


「當我們向這只水牛保證不會殺它時，它才肯移動，然後起身緊緊跟隨著我們。」Shiu如此說。 「不管你們相信不相信，這是千真萬確的事情，雖然聽起來確實是不可思議。」


&nbsp;


&nbsp;


&nbsp;


&nbsp;


「這只看起來很愚笨的動物，彷佛可以瞭解我們所說的每一個字！」 其他的屠宰工幷人都過來圍觀這只哭泣的水牛，現場擠得水泄不通。 「他們其中有三個人，當場就愣住了。」工頭Fong說；「永遠不會忘掉這只淚流滿面的水牛」
