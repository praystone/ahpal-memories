請看人畜輪回的新聞報導： 


&nbsp;


&nbsp;


【【【印度少年自稱五次在同一家庭投胎；人、蒼蠅、蜜蜂和蛇的形態 】】】&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;


&nbsp;


2009年12月 各大媒體都報導了，60條


16歲的印度少年阿傑上周死於車禍，但他留下了令人驚奇的輪回事蹟。阿傑生前曾告訴家人，在1984到1993年間，他以人、蒼蠅、蜜蜂和蛇的形態，在同一個家庭轉世5次。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;據印度媒體報導，在印度北方邦的加斯根傑地區，少年阿傑的祖母蘭姆貝蒂說，“原先我們以為他在編故事，但隨著他的年齡增長，他仍然堅持這個說法，並說他在這個家第一次出生是在1984年，那 


時他是我的兒子，他死時只有6歲。”


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 的確，蘭姆貝蒂有個兒子只活到6歲。當年一位鄰居婦人沒有子女，十分嫉妒蘭姆貝蒂，在一種當地常見的甜點裏下毒，“他死了，這是千真萬確的事，當他說這件事時，我們感到震驚。”蘭姆貝蒂說，這件事少有外人知道，阿傑竟能講得十分詳細。阿傑告訴他的家人，當他再次投胎，他變成蒼蠅，之後是蜜蜂和蛇，“在1991年，有一條蛇在院子裏出現，被我婆婆打死。阿傑說他就是那條蛇。”蘭姆貝蒂說。阿傑之後投胎成為蘭姆貝蒂女兒的兒子，但當他僅2歲時，他又因為吃甜點噎死；到了1993年，他投胎成為蘭姆貝蒂媳婦的兒子。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 阿傑記得他五次轉世的每一個細節，蘭姆貝蒂說，他們帶他去許多寺廟或找巫醫求助，希望瞭解這些“故事”是否是阿傑的幻想，但阿傑的描述又讓人不能完全不信。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;蘭姆貝蒂的家人仍對阿傑的死感到哀痛，不過，他們也好奇他會以什麼形體再轉世回到家裏。“在他之前的每一次轉世，都沒有過完完整的生命，我們為他祈禱。我們正諮詢祭司，要為他舉行一次儀式，讓他的靈魂得到平安。”老祖母說。

人類學家對人畜輪回的研究： 


&nbsp;


&nbsp;


&nbsp;


【著名人類學家馬里奧博士驚人發現：——許多人前生原是飛禽走獸】 


&nbsp;


&nbsp;


&nbsp;


馬里奧博士是利幷用前生回溯催眠法，發覺出別人前生的事蹟，他在十多年幷前便發現此事，近年，這類形的個案逐漸增幷加了。


&nbsp;


&nbsp;


&nbsp;


馬里奧博士是研究人類輪回學的專幷家，他的研究已經可以肯定輪回是存在的。在他研究的一千多個個案中，被研究者在接受了前生回溯催眠後，都能說出前生的事蹟。絕大部分研究者描述的前生事蹟，都證實是真幷實無訛的。


&nbsp;


&nbsp;


&nbsp;


最近，馬里奧博士又發表了新的研究報告。他發現了，原來有些人的前生竟然是動物！


&nbsp;


&nbsp;


&nbsp;


海豚前生


&nbsp;


他首次研究個案的主角是一名三十多歲的男人，他為了體重問題而來求他幫助。這位男人十分喜愛參加派對，在派對中，他往往不能自幷制地大飲大食，使得他不斷地發胖。


&nbsp;


&nbsp;


&nbsp;


很多醫生都建議他減少參加派對，但無論他如何努力，總不能控幷制自己內心的衝動，於是求助於馬里奧博士。


&nbsp;


&nbsp;


經過前生回溯催眠後，博士發現他的前生竟然是一條海豚！


&nbsp;


&nbsp;


他憶述他自己的前生是一條年輕的雄性海豚，是它們一群中最具才智、最聰明的。有一次，他感覺到一群殺人鯨—海豚的天然敵人，正游向它們，他嘗試去警告它的同伴，但它們被眼前的食物所吸引著，對它的警告全不理會，於是他只好自己離群避難。


&nbsp;


&nbsp;


&nbsp;


果然，一群兇猛饑餓的殺人鯨，將那群海豚全群殺死，只剩下他獨自一條，在該海域之中孤獨無伴地渡過一生。 


&nbsp;


馬里奧從他的前生經歷之中，發覺他現今生活問題癥結所在—他渴望伴侶。 


&nbsp;


於是他現生之中有強烈潛在的恐懼感，他害怕再孤獨，希望一直經常有一大群人在他身邊。


&nbsp;


&nbsp; 


&nbsp;


蟒蛇前世


&nbsp;


馬里奧博士的另一個有趣個案是，有一名男子前生竟然是一條蟒蛇，當他在椅上憶述這件事時，他甚至做出蟒蛇爬行動作。 


&nbsp;


這名男子說：他前生有一天正盤作一團在曬太陽，突然之間火山爆發，使他整個滾落到山下，被土石活幷埋了。


&nbsp;


&nbsp;


灰熊前生


&nbsp;


在另一個案中，一名三十多歲的女秘幷書，憶起自己的前生是一個全身長有紅毛，會站著走路的雄性灰熊。她生動地形容了她的前生，如何從一枝枯死的樹幹內，檢出裏面的昆蟲和吃食它們，馬里奧博士認為她的前生很明顯是一頭灰熊。


&nbsp;


&nbsp;


&nbsp;


響尾蛇前世


&nbsp;


另一個案的主人翁是一位二十四歲的家庭主婦，在催眠下，她告訴研究人員，她正蜷伏幷在沙漠的一處陰暗的石塊下。當她形容四周事物時，顯示她是從地面上望著東西的，就像一條響尾蛇一般。


&nbsp;


&nbsp;


&nbsp;


賽馬前生


&nbsp;


有一個十分愛馬的女子，曾求助於馬里奧博士，她是一名醫生，收入頗豐，但往往入不敷出，因為她實在太愛馬了，她不能控幷制自己花費於馬匹上，她曾經先後求助於數位心理醫生，都不能解決她的問題，最後經馬里奧博士用前生憶述催眠法診治後，才知道問題所在，原來她前生是一匹賽馬，它叫‘珍納第’，二幷十幷年代在美國南方各個州出賽，頗有名氣。 


&nbsp;


獸王前世


&nbsp;


有一名少年描述自己的前生是一頭黑豹，他描述了一隻黑豹自幷由自在的感受，他清楚地說出他如何或受到，自己比森林內其他動物優勝，像萬獸之王一般。


&nbsp;


&nbsp;


&nbsp;


老虎前生


&nbsp;


另一個老婦在催眠之下，則說出她前生是一隻老虎，這只老虎十分兇猛，曾經殺死過五千隻動物以上，最後被一個獵人打死了。


&nbsp;


馬里奧博士聲稱其實他在十多年幷前，便發現有動物輪回為人的個案，不過一直未發表。近年來，這類型的個案增幷加了，經過調幷查發現其中大部分是十分可信的，所以他才整理發表，但他未能提出新的理論來解釋這些現象。


&nbsp;


西剛博士亦是研究輪回學的著名學者，他甚至認為輪回轉幷世，應超越人類與地球上動物之界域，宇宙中適合生物生長的星球有很多，單是在銀河系中，可能有上百個甚至數千個，適合生物生存的星球。


&nbsp;


&nbsp;


在那些星球，有許多我們想像不到的生物存在，不管它們之形態如何，它們體幷內也一定有支配其自身活動之中心，即是腦或與腦相似的器官。


&nbsp;


&nbsp;


人類死後，生命便成為宇宙生命的一部分，可到處飛行，亦有進入宇宙生物腦的可能性，同樣動物，或其他宇宙生物，亦有可能進入嬰兒的胚體，輪回成為人類。


&nbsp;


&nbsp;


當然宇宙之中，一定有一個嚴格的法則，控幷制一切的輪回活動，這方面佛家有十分詳細的研究。很多科學家已開始，對那些描寫輪回的佛幷學書籍發生興趣，因為那些書上有很多的記載，和近年的研究十分吻合。
