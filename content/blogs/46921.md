統計學老師 


&nbsp;

&nbsp;

&nbsp;


一位在某大學任教的統計學老師

&nbsp;

與其說他是仙人，不如說他很機車。

第一次上課時－－ 

&nbsp;

老師：「上我的課，你們可以很輕鬆，

&nbsp;

要吃早餐的可以，但要吃得營養：

&nbsp;

基本上除了牛排、我不想看到有人在吃別種食物；

&nbsp;

要睡覺也可以，但是一定要蓋棉被....」 

&nbsp;

同學：「-_-'....」&nbsp;&nbsp;&nbsp;&nbsp; ( 哪裡??&nbsp;&nbsp; 銹逗!! )

&nbsp;

老師：「我唯一比較在意的是：

&nbsp;

手機一定要關機，因為我絕對不允許

&nbsp;

有人打擾那些正在睡覺的同學。」 

&nbsp;

同學：「O_o'....」&nbsp;&nbsp; ( 啥米??&nbsp; 碗跪~~ )


期中考時，大家都各自忙著作答。

&nbsp;

下課鈴聲響起後，有一個學生神情慌張的

&nbsp;

在考卷下塞了1000元，外加一張紙條，

&nbsp;

上面寫著「10元1分」，還很得意的對老師比ok~的手勢，

&nbsp;

老師也對學生比了ok...&nbsp; ^____ __^|||&nbsp;&nbsp; 

&nbsp;

下一次上課時，老師發考卷，該生心想：

&nbsp;

這次考試一定是100分的啦！

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

沒想到老師給了他一張59分的考卷和410元。...= =|||&nbsp;&nbsp; 



&nbsp;

&nbsp;

微積分老師&nbsp; 


某天，一位同學跟微積分老師說：

&nbsp;

「老師啊！我今天心情很不好耶！」 

&nbsp;

老師就說：「那我幫你用微積分來卜卦看看！」

&nbsp;

然後要求同學寫幾個字。 

&nbsp;

同學寫了「麻煩」兩個字。老師看了之後，

&nbsp;

笑笑的說：「你一定是被爸媽罵了！」 



&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

同學說：「哇！老師啊！你怎麼那麼厲害？一下就知道了！」 
&nbsp;
老師說：「你別急！我慢慢解釋給你聽－－

&nbsp;

首先，我們用一次微分，

&nbsp;

把『麻煩』的『麻』字的蓋子去掉，

&nbsp;

不是就剩下『林』了嗎？


然後用二次微分，把『煩』這個字的『火』去掉，

&nbsp;

再把剩下『頁』這個字的頭頂也去掉，

&nbsp;

不是就剩下『貝』了嗎？


&nbsp;從『林貝』就可知你被你爸爸罵了啊！

&nbsp;

還有，剩下的『貝』，你再一次微分，

&nbsp;

把下面去掉，就得到『目』，

&nbsp;

那麼『林目』就說明你也有被你媽媽罵囉！」&nbsp;
&nbsp;
這位同學聽了之後，

&nbsp;

當場 ....... #@@$%&amp;*!~
