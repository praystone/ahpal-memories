★別等不該等的人，別傷不該傷的心★

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

有時，愛也是種傷害.殘忍的人，選擇傷害別人;善良的人

&nbsp;

&nbsp;

選擇傷害自己.

&nbsp;

&nbsp;

暗戀是最好的啞劇，說出來可能會變成悲劇：

&nbsp;

&nbsp;

哭，並不代表我屈服；

&nbsp;

&nbsp;

退一步，並不象徵我認輸；

&nbsp;

&nbsp;

放手，並不代表我放棄；

&nbsp;

&nbsp;

正如我微笑，並不意味著我快樂

&nbsp;

&nbsp;

只有放棄，沒有忘記。

&nbsp;

&nbsp;

看的淡一點，傷的就會少一點，時間過了，愛情淡了，也就散了。

&nbsp;

&nbsp;

時間，讓深的東西越來越深，讓淺的東西越來越淺。

&nbsp;

&nbsp;

佛說緣是一塊冰，要度五百年。

&nbsp;

&nbsp;

佛問苦嗎?我說不苦。佛於是許我一段緣。得之我幸，不得我命。如此而已.

&nbsp;

&nbsp;

前世的500次回眸才換來今生的一次擦肩而過。

&nbsp;

&nbsp;

我寧願用來世的一次擦肩而過來換得今生的500次回眸。

&nbsp;

&nbsp;

我笑，全世界都跟著我笑；我哭，全世界只有我一個人哭。

&nbsp;

&nbsp;

孤獨，不一定不快樂；

&nbsp;

&nbsp;

得到，不一定能長久。

&nbsp;

&nbsp;

失去不一定不再擁有，

&nbsp;

&nbsp;

可能因為某個理由而傷心難過：但，卻能找個理由讓自己快樂

愛上一個人的時候，總會有點害怕，怕得到他;怕失去他。

&nbsp;

&nbsp;

不用等待的人，是幸福的.

&nbsp;

&nbsp;

我們真的要過了很久很久，才能夠明白，&nbsp; 自己真正懷念的，到底是怎樣的人，怎樣的事.

&nbsp;

&nbsp;

什麼事情都會習慣的，譬如別離和思念。

&nbsp;

&nbsp;

愛與被愛，不一定成正比。

&nbsp;

&nbsp;

在對的時間，遇見對的人，是一種幸福

&nbsp;

&nbsp;

在對的時間，遇見錯的人，是一種悲傷

&nbsp;

&nbsp;

在錯的時間，遇見對的人，是一聲嘆息

&nbsp;

&nbsp;

在錯的時間，遇見錯的人，是一種無奈&nbsp;&nbsp;&nbsp;&nbsp; 

不要輕言放棄，否則對不起自己

&nbsp;

&nbsp;

如果哪天，我為別人穿了禮服，也許是因為年齡，也許是因為累了，也許是因為真的想與那個人攜手一生..

&nbsp;
