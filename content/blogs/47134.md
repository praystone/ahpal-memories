我在衣櫥裡面 如果你找不到衣服 

&nbsp;

我在思念上面 假如你開始想我

&nbsp;

我在天梯中間 可能你看不見

&nbsp;

我在海面翻騰 如果你肯落一滴淚

&nbsp;

我在荒野迷失 假如你遺忘了我

&nbsp;

我在黑夜慌亂 可能你說再見

&nbsp;

我想在你心裡躲貓貓

&nbsp;

請你很快找到我

&nbsp;

我已經躲在最角落

&nbsp;

好怕你疲憊了之後-----我就無法求救

&nbsp;

我要在你眼裡躲貓貓

&nbsp;

請你一定要跟好我

&nbsp;

我已經踩上了邊線

&nbsp;

好怕你一眨眼------我就被判出局了

&nbsp;
