&nbsp;

原是潔淨的淺灘

&nbsp;

在一次次現實洗禮下

&nbsp;

我逐構成深深的海洋

&nbsp;

在意你們隨意扔的垃圾

&nbsp;

我又能如何 無能為力

&nbsp;

看著內臟一日日腐敗

&nbsp;

在你們讚嘆我海面潾光時

&nbsp;

我僅能依偎著垃圾哭泣

&nbsp;

從此不再光潔無瑕

&nbsp;

你們微笑的目光

&nbsp;

更讓我自卑不已

&nbsp;

曾幾何時我悄悄上岸

&nbsp;

剖開真心任世人交惡受傷

&nbsp;

來不及得到真相

&nbsp;

早早躲藏於深海

&nbsp;

游進污漬的大洋

&nbsp;

縮進黑暗的心臟

&nbsp;

人魚一但落淚

&nbsp;

終究化成泡沫消失

&nbsp;

皎潔的月光&nbsp; 使我迷惘

&nbsp;

有一天是不是長出翅膀

&nbsp;

飛向另一座天堂

&nbsp;

輕撫我滿是瘡痍的眼光
