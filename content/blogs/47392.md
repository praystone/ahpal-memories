&nbsp; 
我不吃青椒喜歡苦瓜的清香

&nbsp;

我不喝咖啡喜歡果汁的甜美

&nbsp;

我不追流行喜歡復古的感覺

&nbsp;

我不聽搖滾喜歡抒情的音樂

&nbsp;

我不常微笑喜歡靜靜的想念

&nbsp;

我不愛熱鬧喜歡山海的擁抱

&nbsp;

我不戀春天喜歡秋天的感覺

&nbsp;

我不說八卦喜歡快樂的氣氛

&nbsp;

我不是聰明喜歡笨笨的自己

&nbsp;

我不是盲目喜歡認真過生活

&nbsp;

我不懂世界喜歡驚奇去探索

&nbsp;

我不談戀愛喜歡懷念舊傷口

&nbsp;

我不羨鴛鴦喜歡一個人自由

&nbsp;

我不去猜測喜歡亞寶的暖和




&nbsp;

&nbsp;

母親節快樂我的好友們

謝謝你們讓深海有自信

我實在太平凡太愛哭了

你們都是我愛的及時雨
