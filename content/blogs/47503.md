等 一 等 . 靜
一 靜



&nbsp;





我們越來越沒有耐心了。





到銀行存取錢，看的前邊有幾個人，



就覺得好多的人，就等不及了。





到菜市場覺得人比菜多，到公路上心裏罵著車多路擠。

&nbsp;

&nbsp;

就是上網，慢一點也會覺得身上如同起了毛，



急的哪都想撓撓……





呵呵，這是不是就是我們現在的心態？

&nbsp;



我們一天到晚都巴不得——來，快一點，



再快一點啊……快快……





快——快餐——快艇——快鐵——快軌…… 

&nbsp;

&nbsp;

快？？？？？

&nbsp;

&nbsp;

我們就不能等一等麼……

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

等，不也是生活中一種正常的狀態嗎？

&nbsp;

&nbsp;

慢慢地走，慢慢地看風景，慢慢的品味人生，慢慢的，



可能活的更有滋味。

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

否則，快活，就不是快樂，而是快快把自己這一生過完的意思了。

&nbsp;

&nbsp;

與等一等相比，其實是靜一靜更重要。 

&nbsp;

&nbsp;

心靜自然涼，是火熱炎夏的心靈解藥；

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

心靜生慧，慧生靈，靈動的工作；

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

心靜如止水，與周遭的喧鬧和浮躁的侵蝕，



你毫發無損。

&nbsp;

&nbsp;

靜下來你會發現，這份安恬的心境是如此的妙不可言。

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

看一看天下佛道名勝，皆在靜寂之地-----

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

與天通靈的風水寶地，何謂地靈人傑，想一想，



就會恍然大悟。

&nbsp;

&nbsp;

對蕓蕓眾生而言，看破紅塵只是一種幻夢，



可靜一靜的條件總還是有的呀！ 

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

有道是小隱於野，中隱於市，大隱於朝，



說的亦是靜的妙處。

&nbsp;

&nbsp;

我心即佛，我心即是整個世界，何嘗不是靜慧的力量。

&nbsp;

&nbsp;

靜一靜，放下心底雜念，

&nbsp;

&nbsp;&nbsp; 

靜一靜，聆聽八方清音，

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 

靜一靜，與天賴知音。

&nbsp;

&nbsp;

【慢呼吸】





生活的慢行，可以使人心靜。





而靜才能體味人生的美，才能有靜中思考，



靜中的求索，靜中得來的人生智慧，還有慢慢愛，



讓愛一點點滲入我們的感官和生命，慢慢的品讀你，



那般的精緻，真捨不得一下子讀完，美好的感覺，



默默感受安然的情懷。



&nbsp;
