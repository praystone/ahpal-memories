這我的遺書，我太太會來拿...

&nbsp;

(超感人的)&nbsp; 

&nbsp;


&nbsp;

&nbsp;


這是淡水站捷運站發生的真實故事.....&nbsp; 

&nbsp;

這一包是我的遺書，等一下我太太會來拿，

&nbsp;

一天有位阿伯來到淡水站的詢問處，

&nbsp;

拿著一包用牛皮紙袋裝的東西，很慎重的告訴站長說：

&nbsp;

這一包是我的遺書，等一下我太太會來拿，

&nbsp;

麻煩你幫我交給我太太。

&nbsp;

站長說好啊，幫旅客做服務是捷運的精神，

&nbsp;

幫忙轉交東西有什麼困難的，就答應了。

&nbsp;

當站長回過神來什麼是遺書時，

&nbsp;

這位阿伯已經刷了票進站去了。


由於當時距離淡水線發生旅客自殺事件才沒多久，

&nbsp;

站長心想這下完蛋了，這位阿伯連遺書都寫好了，

&nbsp;

可不要做出什麼想不開的事情才好，

&nbsp;

萬一阿伯真的跑去臥軌了，

&nbsp;

那站長可要為了自己疏忽放阿伯進站而愧疚一輩子，

&nbsp;

好歹也是一條人命啊！


&nbsp;

所以站長趕緊衝上月台，結果不見阿伯的身影！

&nbsp;

顯然阿伯已經坐車跑掉了！

&nbsp;

可能是要找個不為人知的地方去了結自己的殘生吧 ！

&nbsp;

站長第一時間趕緊以無線電呼叫

&nbsp;

行控中心報告這個緊急狀況，

&nbsp;

行控中心接到這個訊息也全部緊張起來，

&nbsp;

除了呼叫全線列車注意

&nbsp;

是否載有長得像那位阿伯的可疑乘客，

&nbsp;

還發動全線的站長到車站各處尋找阿伯的身影，

&nbsp;

連在線上巡邏的捷運警察都全體出動去找那位阿伯。 


&nbsp;

隨著時間的過去，各站、各列車及

&nbsp;

巡邏員警逐一回報無發現，

&nbsp;

阿伯的太太也一直未出現在淡水站

&nbsp;

行控中心主任的心一直往下沈，

&nbsp;

心裡擔心著會不會下一次回報就是不幸的消息呢？


&nbsp;

這時站長想說，

&nbsp;

阿伯的遺書中可能會有相關的線索，

&nbsp;

也許可以找得到 人，

&nbsp;

於是打開牛皮紙袋，發現裡面裝的竟然是……&nbsp;&nbsp; 

&nbsp;

&nbsp;

&nbsp;

淡水名產－－
&nbsp;

&nbsp; 魚酥！(遺書)&nbsp;&nbsp;
