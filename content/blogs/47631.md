人生需要放下的8樣東西 

&nbsp;

&nbsp;

&nbsp;

放下不是失去，而是另一種獲得。想要一個快樂幸福的人生，

&nbsp;

您需要下這8樣東西：

&nbsp;

1、放下壓力。（累與不累，取決於自己的心態）


&nbsp;

&nbsp;

2、放下煩惱。（自己的快樂，自己決定）


&nbsp;

&nbsp;

3、放下自卑。（把自卑從你的字典裡劃去）

&nbsp;



4、放下懶惰。（奮鬥將改變命運）


&nbsp;

&nbsp;

&nbsp;

5、放下消極。（放下絕望，擁抱希望）


&nbsp;

&nbsp;

6、放下抱怨。（與其抱怨，不如努力）

&nbsp;



7、放下猶豫。（立即行動，成功無限）


&nbsp;

&nbsp;

8、放下狹隘。（心寬，天地就寬）
