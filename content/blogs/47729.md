&nbsp;

&nbsp;




&nbsp;

老天曾給了我如花的幸福

&nbsp;

卻又這樣殘忍地收回

&nbsp;

是我不配嗎

&nbsp;

還是我不夠努力

&nbsp;

是上輩子我犯下的錯

&nbsp;

這輩子要我用一生的幸福來償還

&nbsp;

我一直多麼努力在用一雙乾淨清澈的眼睛

&nbsp;

找尋我期待的幸福

&nbsp;

一直在用一顆純淨仁愛的心

&nbsp;

去發現世間的美好

&nbsp;

就算是跋山涉水

&nbsp;

曆(歷)盡艱辛

&nbsp;

我都咬著牙向前

&nbsp;

淚往肚裏吞

&nbsp;

血往心裏流

&nbsp;

我願意相信我的幸福在遠方

&nbsp;

我總相信總會有苦盡甘來的一天

&nbsp;

我的心痛總有一天會平復

&nbsp;

我的心總有一個人會懂

&nbsp;

會珍惜

&nbsp;

可是現實總讓我的眼蒙上了灰

&nbsp;

我看不清那些過往有幾分真實

&nbsp;

也看不清未來的路有多清晰

&nbsp;

人生就是這樣在一片渾渾噩噩中飄飄蕩蕩

&nbsp;

寂寥而悲傷

&nbsp;

我一直清新淡然地行走在紛亂的塵世中

&nbsp;

我守著我的孤獨

&nbsp;

堅持著我的夢

&nbsp;

期待著永遠

&nbsp;

我願意給自己的世界留一份乾淨和美好

&nbsp;

等一個知我懂我憐我愛我的人走近

&nbsp;

那裏會有他期待看到的令他眼前一亮的風景

&nbsp;

會有一個只有他才能駐足欣賞的世界
