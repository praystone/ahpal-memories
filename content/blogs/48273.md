&nbsp;


讓懂你的人愛你

&nbsp;



&nbsp;

&nbsp;


愛不只是走進對方的生活,

&nbsp;

&nbsp;&nbsp;更要能走入彼此的生命..."

&nbsp;

總以為愛一個人只要對她好就足夠了。

&nbsp;

&nbsp;

殊不知，

&nbsp;

找個愛你一時的人很容易，找一個愛你一生的人也不一定很難，

&nbsp;

而找個一生真正懂你的人談何容易！


懂你的人不一定會是你一生相守的人，

&nbsp;

也許只是你生命中的一個過客，也許只是你一個知己，

&nbsp;

也許只是一個一生都不曾謀面的朋友，

&nbsp;

所以既然感覺有人懂你，就會是快樂的、幸福的。

&nbsp;

&nbsp;

張愛玲就曾說過：

&nbsp;

我自己的事，只有我自己明瞭。

&nbsp;

因為在當時她沒有遇到可以讀懂她的男人，

&nbsp;

年輕時，她曾將終生托付給了胡蘭成，

&nbsp;

但胡也不例外，他走不進她的世界裏。

&nbsp;

&nbsp;

也許是張的內涵太深了，無人能讀懂她，她是悲哀的。

&nbsp;

仔細閱讀她的文字時你會發現，她的世界裏始終只有孤獨與驕傲。

&nbsp;

對我們而言，未來是未知的，未來是迷茫的，

&nbsp;

但未來又是掌握在我們自己手中的。


&nbsp;

我們也都有過這樣的體會，

&nbsp;

自己不喜歡的人越是對自己好，心裏就越煩。

&nbsp;

不是所有的愛意都能滋養我們的心。

&nbsp;

而有一天你一旦含糊的默許了這份感情，麻煩也就真正開始了。

&nbsp;

&nbsp;

&nbsp;

你會發現，

&nbsp;

你其實並不愛他（她）,但卻在無意中傷害了他（她）。

&nbsp;

&nbsp;

所以，如果不愛別人，千萬不要接受別人的好意。

&nbsp;

如果別人不愛我們，也千萬不要強求一份不屬於自己的感情。

&nbsp;

因為愛情是自私的，

&nbsp;

所有的付出必須要得到相同的回報才可以平衡，

&nbsp;

否則就會成為一種痛苦。

&nbsp;

即使不愛別人，也不該讓別人痛苦，即使我們所愛的人再可愛，

&nbsp;

也不該因此而降低了自己。

&nbsp;

&nbsp;

有人說：“世界上真正的暴力是一個人對另一個說，

&nbsp;

你是屬於我的，因為我愛你。”

&nbsp;

我想這樣的感情其實不能算是愛。

&nbsp;

因為這樣的人不懂對方想的是什麼，也不懂得如何去愛人。 

&nbsp;

愛情其實是一種無法用語言說清楚的感覺，

&nbsp;

是一種心電感應的默契。

&nbsp;

是一種非人為可以控制的感覺，是一種靠強求得不來的情意。

&nbsp;

如果真的要用一個詞來描述，

&nbsp;

我只能說這是一種瞑瞑中自有安排的“天意。”

&nbsp;

也許是現代社會人與人之間的關系越發的冷漠，

&nbsp;

在寂寞和孤單的時候，只有愛可以讓人感到安慰。


&nbsp;

從新選擇，去選擇一個讀懂你的人。

&nbsp;

因為相愛不僅要走進對方的生活裏，

&nbsp;

更要走入對方的生命中來。

&nbsp;

因為懂你，就可以相知，就可以知道對方的思想，

&nbsp;

明瞭對方所擁有的內涵，明了感情的需求。

&nbsp;

當一個他選擇了一個可以讀懂她的愛人時，

&nbsp;

即使不可能與愛人默默相對，可是卻能做到心靈相同，

&nbsp;

也許那才真的是：心有靈犀一點通！


&nbsp;

幸福的婚姻是需要經營的，兩人既然相愛，

&nbsp;

那麼在愛的過程中就不要將對方看似細微或無足輕重的付出

&nbsp;

當成淡漠與敷衍，沒有誰應該永遠付出，

&nbsp;

更沒有人付出後不想得到回報，

&nbsp;

當然婚姻生活中還會偶爾出現夫妻間鬥嘴的小插曲，

&nbsp;

但這種插曲需要一個人當提線木偶，一個當提線人、

&nbsp;

幸福美滿的婚姻是要兩個人來共同配合完成的。

&nbsp;

&nbsp;

《哈利·波特》裏曾寫到了一種神奇的愛情魔藥，

&nbsp;

但遺憾書裏沒有給出配方，求教華齡，她說，

&nbsp;

愛情魔藥需要的藥材無他，

&nbsp;

都是不假他求就可以找到的愛的美德，

&nbsp;

包括：學會撒嬌、培養默契、勇於追求、適度放手……

&nbsp;

或許，真應該像蘇永康所唱的那樣“...

&nbsp;

至少，懂你的人會更了解你的為人和個性，

&nbsp;

會更包容你的一起，爭執也許就會少很多吧。

&nbsp;

願普天之下的人，在你們的感情世界裏，

&nbsp;

能夠真正得到一個懂你的人：讓懂你的人愛你！

&nbsp;

找一個你可以讀的懂的人去愛吧。


&nbsp;
