&nbsp; 


&nbsp;


 心態是最大的本錢 




&nbsp;

&nbsp;


生活中，一個好的心態，可以使你樂觀豁達；

&nbsp;

一個好的心態，可以使你戰勝面臨的苦難；

&nbsp;

一個好的心態，可以使你淡泊名利，過上真正快樂的生活。

&nbsp;

人類幾千年的文明史告訴我們，

&nbsp;

積極的心態能幫助我們獲取健康、幸福和財富。

&nbsp;

&nbsp;

一、心態決定人生

&nbsp;

一位哲人說過：“你的心態就是你的主人。”

&nbsp;

在現實生活中，我們不能控制自己的遭遇，

&nbsp;

卻可以控制自己的心態；我們不能改變別人，

&nbsp;

卻可以改變自己。

&nbsp;

其實，人與人之間並無太大的區別，

&nbsp;

真正的區別在於心態。

&nbsp;

所以，一個人成功與否，主要取決於他的心態。

&nbsp;

&nbsp;

二、生氣不如爭氣

&nbsp;

人生有順境也有逆境，不可能處處是逆境；

&nbsp;

人生有巔峰也有穀底，不可能處處是穀底。

&nbsp;

因為順境或巔峰而趾高氣揚，

&nbsp;

因為逆境或低谷而垂頭喪氣，都是淺薄的人生。

&nbsp;

面對挫折，如果只是一味地抱怨、生氣，

&nbsp;

那麼你註定永遠是個弱者。

&nbsp;

&nbsp;

三、有自信才能贏

&nbsp;

古往今來，許多人之所以失敗，

&nbsp;

究其原因，不是因為無能，而是因為不自信。

&nbsp;

自信是一種力量，更是一種動力。

&nbsp;

當你不自信的時候，你難於做好事情；

&nbsp;

當你什麼也不做不好時，你就更加不自信。

&nbsp;

這是一種惡性循環。若想從這種惡性循環中解脫出來，

&nbsp;

就得與失敗作鬥爭，就得樹立牢固的自信心。

&nbsp;

&nbsp;

四、心動更要行動

&nbsp;

心動不如行動，雖然行動不一定會成功，

&nbsp;

但不行動則一定不會成功。

&nbsp;

生活不會因為你想做什麼而給你報酬，

&nbsp;

也不會因為你知道什麼而給你報酬，

&nbsp;

而是因為你做了些什麼才給你報酬。

&nbsp;

一個人的目標是從夢想開始的，一個人的幸福是從心態上把握的，

&nbsp;

而一個人的成功則是在行動中實現的。

&nbsp;

因為只有行動，才是否滋潤你成功的食物和泉水。

&nbsp;

&nbsp;

五、平常心不可少

&nbsp;

人生不可能一帆風順，有成功，

&nbsp;

也有失敗；有開心，也有失落。

&nbsp;

如果我們把生活中的這些起起落落看得太重，

&nbsp;

那麼生活對於我們來說永遠都不會坦然，永遠都沒有歡笑。

&nbsp;

人生應該有所追求，

&nbsp;

但暫時得不到並不會阻礙日常生活的幸福，

&nbsp;

因此，擁有一顆平常心，是人生必不可少的潤滑液劑。

&nbsp;

&nbsp;

六、適時放棄才會有收穫

&nbsp;

命裡有時終須有，命裡無時莫強求。

&nbsp;

不要去強求那些不屬於自己的東西，要學會適時的放棄。

&nbsp;

也許在你殫精竭慮時，你會得到曾經想要得到

&nbsp;

而又沒得到的東西，

&nbsp;

會在此時有意外的收穫。適時放棄是一種智慧。

&nbsp;

它會讓你更加清醒地審視自身內在的潛力和外界的因素，

&nbsp;

會讓你疲憊的身心得到調整，成為一個快樂明智的人。

&nbsp;

盲目的堅持不如理智的放棄。

&nbsp;

苦苦地挽留夕陽的人是傻人，久久地感傷春光的人是蠢人。

&nbsp;

什麼也捨不得放棄的人，往往會失去更加珍貴的東西。

&nbsp;

適當的時候，給自己一個機會，學會放棄，才有可能獲得。

&nbsp;

&nbsp;

七、寬容是一種美德

&nbsp;

俗話說得好：“退一步海闊天空，讓幾分心平氣和。”

&nbsp;

這就是說人與人之間需要寬容。寬容是一種美德，

&nbsp;

它能使一個人得到尊重。寬容是一種良藥，

&nbsp;

它能挽救一個人的靈魂。寬容就像一盞明燈，

&nbsp;

能在黑暗中放射著萬丈光芒，照亮每一個心靈。

&nbsp;

&nbsp;

八、學會給心靈鬆綁

&nbsp;

人的心靈是脆弱的，需要經常地激勵與撫慰。

&nbsp;

常常自我激勵，自我表揚，會使心靈快樂無比。

&nbsp;

學會給心靈鬆綁，就是要給自己營造一個溫馨的港灣，

&nbsp;

常常走進去為自己忙碌疲憊的心靈做做按摩，

&nbsp;

使心靈的各個零件經常得到維護和保養。

&nbsp;

&nbsp;

九、別把挫折當失敗

&nbsp;

每個人的一生，難免都會遭受挫折和失敗。

&nbsp;

所不同的是失敗者總是把挫折當失敗，

&nbsp;

從而使每次都能夠深深打擊他取勝的勇氣；

&nbsp;

成功者則是從不言敗，在一次又一次的挫折面前，

&nbsp;

總是對自己說：“我不是失敗了，而是還沒有成功。

&nbsp;

”一個暫時失利的人，如果繼續努力，

&nbsp;

打算贏回來，那麼他今天的失利，

&nbsp;

就不是真正的失敗。相反的，

&nbsp;

如果他失去了再戰鬥的勇氣，那就是真輸了。

&nbsp;

&nbsp;

十、避免煩惱成心病

&nbsp;

在現實生活中，終日煩惱的人，

&nbsp;

實際上並不是遭遇了太多的不幸，

&nbsp;

而是根源於煩惱者的內心世界。

&nbsp;

因此，當煩惱降臨的時候，我們既不要怨天尤人，

&nbsp;

也不要自暴自棄，要學會給心靈鬆綁，

&nbsp;

從心理上調適自己，避免煩惱變成心病。

&nbsp;

&nbsp;

十一、快樂其實很簡單

&nbsp;

有人說，快樂是春天的鮮花，

&nbsp;

夏天的綠蔭，秋天的野果，冬天的漫天飛雪。

&nbsp;

其實，快樂就在我們身邊。

&nbsp;

一個會心的微笑，一次真誠的握手，

&nbsp;

一次傾心的交談，就是一種快樂無比的事情。
