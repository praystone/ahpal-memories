測你的腦年齡


題目：如果有人偷吃你的零食，

&nbsp;

你會…？ 

&nbsp;



&nbsp;

&nbsp;


A. 光明正大拿出來給他吃 

&nbsp;

B. 氣死了！馬上臭罵他 

&nbsp;

C. 安慰自己，下次要藏好 

&nbsp;

D. 加料一下，引誘他吃 

&nbsp;

&nbsp;


分析～


◆選A 光明正大拿出來給他吃的人：

&nbsp;

腦年齡10~20歲 

&nbsp;

天真的你，心地善良又好相處，喜歡熱心助人，

&nbsp;

抱著童話故事裡好人有好報的心態，

&nbsp;

常表現出純真的一面，很受歡迎，是朋友眼中的小天使，

&nbsp;

為你贏得不少友誼，不太顯老，永遠有可愛的一面。 


&nbsp;

◆選B氣死了！馬上臭罵他 的人：

&nbsp;

腦年齡40~50歲 

&nbsp;

你常用腦過度，並熱衷於權力地位，在工作上要求完美，

&nbsp;

脾氣不太好，常板著撲克臉，或完全不給對方面子，

&nbsp;

直接臭罵一頓，讓同事毫無招架之力、直接喊投降，

&nbsp;

動不動就生氣發火，小心未老先衰！ 

&nbsp;

&nbsp;

◆選C安慰自己，下次要藏好的人：

&nbsp;

腦年齡30~40歲 

&nbsp;

你做事很有原則，會把事情規劃得有條不紊，

&nbsp;

但有時怕做錯事，過於小心，反而無法掌握事情脈絡，

&nbsp;

加上勤勉自己一絲不苟、思慮較多，怕事又易後悔，

&nbsp;

更不懂人情世故，老成過了頭，不知變通。 


&nbsp;

◆選D加料一下，引誘他吃的人：

&nbsp;

腦年齡20~30歲 

&nbsp;

鬼靈精怪的你，總能裝可愛加上裝無辜博取同情，

&nbsp;

會天馬行空編劇本，然後將自己融入情節中，

&nbsp;

再來個出奇不意的突擊，讓大家覺得你是個開心果。

&nbsp;

想法不受拘束，讓生活充滿樂趣，身心保持年輕！ 


&nbsp;
