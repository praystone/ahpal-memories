 天殺的『一物剋一物』互剋星座大公開




&nbsp;

&nbsp;


艾菲爾老師認為花心的情人總是很狡猾，

&nbsp;

深藏不漏的劈腿招數常常讓情人防不慎防，

&nbsp;

然而你知道什麼星座的對付花花公子最有辦法，

&nbsp;

所謂『一物剋一物』?

&nbsp;

放鬆心情，艾菲爾老師要告訴大家，

&nbsp;

哪些星座配對是『一物剋一物』的互剋星座組合。


&nbsp;

天秤座vs雙子座

&nbsp;

天秤座的忽冷忽熱最能收服雙子座

&nbsp;

如果你的太陽星座或上昇星座是天秤座，

&nbsp;

個性冷靜、聰明，光是憑著天秤座的身材與相貌

&nbsp;

就足以讓花花公子深深著迷，

&nbsp;

而且天秤座除了非常懂得情人的心思外，

&nbsp;

也深黯『感情不能強求』與『欲擒故縱』的道理。

&nbsp;

天秤座vs雙子座在感情世界中注定成為『互剋星座』。


因為天秤座最常對付雙子座的方法，

&nbsp;

就是跟他們玩諜對諜的遊戲，

&nbsp;

這樣雙子座反而會被她這種忽冷忽熱、

&nbsp;

若近若離的態度給收服，再加上天秤座的邏輯力超強，

&nbsp;

總是能很快的就看穿雙子座的任何策略，

&nbsp;

因此當雙子座碰到天秤座時，

&nbsp;

那些說謊的招數通常都會變得無所遁形，

&nbsp;

到最後只好乖乖的屈服在天秤座的手上。


&nbsp;

巨蟹座vs獅子座

&nbsp;

巨蟹座的以柔克剛最能收服獅子座

&nbsp;

如果你的太陽星座或上昇星座是巨蟹座，

&nbsp;

個性溫柔，害羞嬌柔的模樣時常讓情人忍不住想照顧它，

&nbsp;

但其實缺乏安全感的巨蟹座，

&nbsp;

對於愛情的佔有欲強，

&nbsp;

絕不能容許自己的另一半有花花公子的行為出現。


巨蟹座vs獅子座在感情世界中注定成為『互剋星座』。


&nbsp;

巨蟹座收服獅子座的辦法，

&nbsp;

就是從他們周遭的親朋好友下手，

&nbsp;

這樣不但可以讓獅子座

&nbsp;

身旁的人都知道自己是它的正牌女友，

&nbsp;

在討好他的家人時還可以製造出家庭溫暖氣氛，

&nbsp;

讓獅子座不自覺陷入柔情似水的攻勢，

&nbsp;

到最後那些自大、

&nbsp;

驕傲的獅子座就會對巨蟹座的依賴心越來越重，

&nbsp;

因而無法離開她。

&nbsp;

&nbsp;

雙魚座vs天蠍座

&nbsp;

雙魚座的軟弱其實是扮豬吃老虎的手段

&nbsp;

如果你的太陽星座或上昇星座是雙魚座，

&nbsp;

個性活潑，而且非常會製造浪漫氣氛，

&nbsp;

因此雙魚座總是能很快的就讓花花公子解除武裝，

&nbsp;

並且瘋狂的愛上她，

&nbsp;

說到雙魚座收服花花公子的手腕上也非常有一套。


雙魚座vs天蠍座在感情世界中注定成為『互剋星座』。


雙魚座收服天蠍座的辦法，

&nbsp;

通常會選擇按兵不動先觀察敵情，

&nbsp;

再開始想一些策略改變現狀，

&nbsp;

然而你絕不能小看雙魚座的觀察力，

&nbsp;

憑著她精明的頭腦不論是有什麼小變化，

&nbsp;

都逃不出雙魚座的眼睛，之後只要等感情穩定、

&nbsp;

時機成熟，雙魚座就會出奇招，

&nbsp;

趁機斬斷天蠍座的野桃花，讓天蠍座再也無法使壞，

&nbsp;

乖乖的屈服在讓雙魚座手上。

&nbsp;

&nbsp;

雙子座vs射手座

&nbsp;

雙子座的善變讓花心漢射手座也招架不住

&nbsp;

如果你的太陽星座或上昇星座是雙子座，

&nbsp;

個性善於觀察，對於人際之間的相處相當有一套，

&nbsp;

活潑、開朗的個性再加上時而性感、時而可愛表情，

&nbsp;

讓雙子座常常是花花公子最想追求的對象。

&nbsp;

雙子座vs射手座在感情世界中注定成為『互剋星座』。

&nbsp;

說到雙子座收服花花公子的招數可說是屬一屬二的，

&nbsp;

原因就在於雙子座的不但會善用

&nbsp;

許多巧妙的方法對付花花公子以外，

&nbsp;

更懂得吊花花公子的胃口，

&nbsp;

這樣反而讓花花公子永遠被他的神秘、任性、

&nbsp;

不容易掌控的特質所吸引，

&nbsp;

因此不管是怎樣高明像野馬的射手座，

&nbsp;

雙子座都可以綁住他的心。

&nbsp;

&nbsp;

牡羊座vs水瓶座

&nbsp;

牡羊座的霸道和不講理讓水瓶座只能乖乖收心

&nbsp;

如果你的太陽星座或上昇星座是牡羊座，

&nbsp;

個性率直、天真，行為看似霸道，

&nbsp;

其實只要覺得自己受到情人寵愛的時侯，

&nbsp;

就會變成最可愛、最撒嬌的模樣，

&nbsp;

但相反的若是你敢惹到她或傷害她的尊嚴和面子，

&nbsp;

那很難保證牡羊座不會變成一個蠻不講理的暴君。

&nbsp;

牡羊座vs水瓶座在感情世界中注定成為『互剋星座』。

&nbsp;

佔有欲強、個性獨立的超強的牡羊座，

&nbsp;

無法忍受自己的情人眼裏還有別人，

&nbsp;

說到牡羊座收服花花公子的辦法就是確實掌握他的行蹤，

&nbsp;

這招雖然看似平凡但其實效果奇佳，

&nbsp;

這樣一來即使是再怎樣厲害的花花公子，

&nbsp;

一但碰上牡羊座的也會變得無所遁形，

&nbsp;

到最後只好收拾完心，乖乖回到牡羊座身邊。
