下一步，該怎麼走？


&nbsp;


什麼是智慧呢？智慧就是懂得下一步，該怎麼走？


&nbsp;


一件事情，本來只是單純的「一件事」，然而如果我們不知道該怎麼處理，就會產生「焦慮」；焦慮累積，會形成「壓力」；壓力不能解決，就變成「問題」；而問題太多又生出「煩惱」；煩惱久了，就變成「抑鬱」和「痛苦」。這說穿了，就是「沒智慧」。


&nbsp;


一個心情，原本也只是單純的「心情」，但是如果我們不知道該如何平撫，起伏不定的心情就形成「情緒」；情緒累積下來，就產生「憤怒」；憤怒積壓久了，就變成「怨恨」；怨恨轉向自己，就變成了「悲傷」；悲傷會引發「恐懼」，而恐懼加上了不穩定的情緒，就會變得「神經質」和「情緒化」。這一樣也是「沒智慧」。


&nbsp;


引自教育家喬丹（David Starr Jordan）的話：「『智慧』是知道下一步該做什麼，『技巧』是知道怎麼做，而『美德』就是身體要力行。」 


&nbsp;


當害羞的時候，把自己忘了。


&nbsp;


當欠缺不足的時候，數數你擁有的幸福。


&nbsp;


當不順心的時候，把焦點放在美好的事物上。


&nbsp;


當猶豫不決的時候，試用一下富蘭克林的辦法。


&nbsp;


當遇到問題的時候，改變問話方式。


&nbsp;


當擔心憂慮的時候，安排三十分鐘憂慮時間。


&nbsp;


當聽到流言的時候，必須「過三關」再說。


&nbsp;


當徬徨失措的時候，你可以用歸零思考。


&nbsp;


當失敗的時候，把錯誤當經驗。


&nbsp;


當壓力太大的時候，讓肌肉放鬆下來。


&nbsp;


當緊張不安的時候，儘可能地呼氣。


&nbsp;


當懊悔的時候，精力集中在「現在我能做什麼？」


&nbsp;


當憤怒的時候，從一數到十。


&nbsp;


當懷恨的時候，饒了別人讓自己解脫。


&nbsp;


當爭吵的時候，不說最後一句話。


&nbsp;


當被批評侮辱的時候，用漠視取代對抗。


&nbsp;


當情緒低落的時候，盡速轉移焦點。


&nbsp;


當心情不定的時候，只要觀察而不認同。


&nbsp;


當疲勞倦怠的時候，假裝積極熱情的樣子。


&nbsp;


當乏味無趣的時候，練習「新生活運動」。


&nbsp;


當痛苦的時候，首先要做的就是放下。


&nbsp;


當不快樂的時候，不要預設條件。


&nbsp;


當寂寞的時候，主動付出愛與關心。


&nbsp;


當憂鬱的時候，先診斷，再治療。


&nbsp;


當嫉妒的時候，不要跟別人比。


&nbsp;


當不滿的時候，去想想更糟的人。當害怕的時候，哪裡痛，就往哪裡紮。


&nbsp;


當顧慮太多的時候，做對的事，不當對的人。


&nbsp;


當不好拒絕的時候，Just Say No。


&nbsp;


當挫折的時候，給什麼，就要什麼。


&nbsp;


當患得患失的時候，注重過程，不在意結果。


&nbsp;


當負擔太多的時候，把「加法」改成「減法」。


&nbsp;


當忙亂的時候，刻意「慢半拍」。


&nbsp;


當溝通不良的時候，先聽再說，以問為主。


&nbsp;


當感情失合的時候，列出十個缺點，視而不見。


&nbsp;


當情人變心的時候，隨他去吧！


&nbsp;


當陷入困局的時候，站在較高的地方看看自己。


&nbsp;


當放不下的時候，想像你已經不在人世了。


&nbsp;


當失去的時候，去享受，並分享所有的一切。


&nbsp;


當效率不張的時候，善用時間三步驟。


&nbsp;


當迷失方向的時候，快設定目標。


&nbsp;


當壓抑的時候，把情緒發洩出來。


&nbsp;


當不被尊重的時候，先學會尊重自己。


&nbsp;


當怠惰的時候，趕快踏出第一步。 


&nbsp;


人生或許無法重新來過，但或許應該停下來，想一想，下一步，該怎麼走？
