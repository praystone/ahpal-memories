&nbsp;

&nbsp;人類有趣的十四項心理定律


&nbsp;

&nbsp;

&nbsp;


以下是人類有趣的十四項心理定律，

&nbsp;

你可以應用它們在任何的領域裡。

&nbsp;

無論是銷售溝通、還是設立目標、時間管理、

&nbsp;

領導組織都可以應用這些原理和定律。

&nbsp;

&nbsp;

1、堅信定律～

&nbsp;

當你對某件事情抱著百分之一萬的相信，

&nbsp;

它最後就會變成事實。


&nbsp;

2、期望定律～&nbsp;期望定律告訴我們，&nbsp;&nbsp; 

&nbsp;

　當我們懷著對某件事情非常強烈期望的時候，

&nbsp;

我們所期望的事物就會出現。


&nbsp;

3、情緒定律～

&nbsp;

情緒定律告訴我們，人百分之百是情緒化的。

&nbsp;

即使有人說某人很理性，

&nbsp;

其實當這個人很有"理性"地思考問題的時候，

&nbsp;

也是受到他當時情緒狀態的影響，

&nbsp;

"理性地思考"本身也是一種情緒狀態。

&nbsp;

所以人百分之百是情緒化的動物，

&nbsp;

而且任何時候的決定都是情緒化的決定。


&nbsp;

4、因果定律～

&nbsp;

任何事情的發生，都有其必然的原因。

&nbsp;

有因才有果。換句話說，當你看到任何現象的時候，

&nbsp;

你不用覺得不可理解或者奇怪，

&nbsp;

因為任何事情的發生都必有其原因。

&nbsp;

你今天的現狀結果是你過去種下的因導致的結果。


&nbsp;

&nbsp;

5、吸引定律～

&nbsp;

當你的思想專注在某一領域的時候，

&nbsp;

跟這個領域相關的人、事、物就會被你吸引而來。


&nbsp;

6、重複定律～任何的行為和思維，

&nbsp;

只要你不斷的重複就會得到不斷的加強。

&nbsp;

在你的潛意識當中，

&nbsp;

只要你能夠不斷地重複一些人、事、物，

&nbsp;

它們都會在潛意識裡變成事實。


&nbsp;

&nbsp;

7、累積定律～

&nbsp;

很多年輕人都曾夢想做一番大事業，

&nbsp;

其實天下並沒有什麼大事可做，有的只是小事。

&nbsp;

一件一件小事累積起來就形成了大事。

&nbsp;

任何大成就或者大災難都是累積的結果。


&nbsp;

8、輻射定律～當你做一件事情的時候，

&nbsp;

影響的並不只是這件事情的本身，

&nbsp;

它還會輻射到相關的其他領域。任何事情都有輻射作用。


&nbsp;

9、相關定律～相關定律告訴我們：

&nbsp;

這個世界上的每一件事情之間都有一定的聯繫，

&nbsp;

沒有一件事情是完全獨立的。

&nbsp;

要解決某個難題最好從其他相關的某個地方人手，

&nbsp;

而不只是專注在一個困難點上。

&nbsp;

在加拿大艾伯塔省有一名高中女生最近發出豪言壯語：

&nbsp;

到25歲，她一定會成為百萬富翁！

&nbsp;

她近日接到美國收視率極高的奧普拉電視台的邀請，

&nbsp;

將到該台的脫口秀節目上與觀眾分享她的致富理念和經驗。


&nbsp;

&nbsp;

10、專精定律～

&nbsp;

專精定律告訴我們，只有專精在一個領域，

&nbsp;

這個領域才能有所發展。

&nbsp;

所以無論你做任何的行業都要把做該行業的最頂尖為目標，

&nbsp;

只有當你能夠專精的時候，

&nbsp;

你所做的領域才會出類拔萃地成長。


&nbsp;

&nbsp;

11、替換定律～替換定律就是說，

&nbsp;

當我們有一項不想要的記憶或者是負面的習慣，

&nbsp;

我們是無法完全去除掉，

&nbsp;

只能用一種新的記憶或新的習慣去替換他。


&nbsp;

12、慣性定律～

&nbsp;

任何事情只要你能夠持續不斷去加強它，

&nbsp;

它終究會變成一種習慣。


&nbsp;

13、顯現定律～

&nbsp;

顯現定律就是說，當我們持續尋找、

&nbsp;

追問答案的時候，它們最終都必將顯現。


&nbsp;

14、需求定律～

&nbsp;

任何人做任何事情都是帶有一種需求。

&nbsp;

尊重並滿足對方的需求，別人才會尊重我們的需求。


&nbsp;
