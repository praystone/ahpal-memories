放開一點，簡單一點，



單純一點











&nbsp;


放開一點開心與不開心，


&nbsp;


往往都只在人的一念之間，何不放開一點、簡單一點、


&nbsp;


單純一點呢？


放開一點，一定找到趣味的！


&nbsp;


放開一點，海闊天空！不要擔心。不要那麼會計較


&nbsp;


這樣日子會過的開心一點，


&nbsp;


不要太在意外界對批評，衝出自己的框框，


&nbsp;


因為能遮月的雲，總會散去。


&nbsp;


手就放開一點。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


簡單一點簡單是最有價值的商業目標，


&nbsp;


原因如下：


01.簡單可以節省時間、金錢與精力。02.簡單是優雅且強而有力的。03.簡單讓生活更輕鬆，


&nbsp;


並創造更多自由。&nbsp;


&nbsp;


如何化繁為簡？有３種作法：


&nbsp;


&nbsp;


01.取某樣既有的東西，


&nbsp;


想想有什麼方法可以將它簡化。


&nbsp;


02.從好多個可行方案中，


&nbsp;


選擇最簡單的方法做出一樣新東西。


&nbsp;


03.想出能讓某項程序


&nbsp;


變得更簡單的新點子。


&nbsp;


&nbsp;


讓生活簡單一點


01.讓外表簡單一點，


&nbsp;


內涵就會更豐富一點。


&nbsp;


02.讓需求簡單一點，


&nbsp;


心靈就會更豐富一點。


&nbsp;


03.讓流程簡單一點，


&nbsp;


質感就會更豐富一點。


&nbsp;


04.讓言語簡單一點，


&nbsp;


溝通就會更豐富一點。


&nbsp;


05.讓學習簡單一點，


&nbsp;


知識就會更豐富一點。


&nbsp;


06.讓私心簡單一點，


&nbsp;


友情就會更豐富一點。


&nbsp;


07.讓挫折簡單一點，


&nbsp;


經驗就會更豐富一點。


&nbsp;


08.讓情緒簡單一點，


&nbsp;


人生就會更豐富一點。


&nbsp;


09.讓效率簡單一點，


&nbsp;


成果就會更豐富一點。


&nbsp;


10.讓行銷簡單一點，


&nbsp;


業績就會更豐富一點。


&nbsp;


11.讓環境簡單一點，


&nbsp;


空間就會更豐富一點。


&nbsp;


12.讓愛情簡單一點，


&nbsp;


幸福就會更豐富一點。


&nbsp;


&nbsp;


&nbsp;


單純一點


在愛情上，單純一點去愛，



給雙方都會帶來快樂。愛情不需要轟轟烈烈，



不需要刻骨銘心，



只要單純一點就完美了。


人和人的關係單純一點。每個人都努力完成自己的事業，



不要把心思和精力糾纏在小事情上。不要整天勾心鬥角，



要把更多的精力放在發展事業上，



放在享受生活上。單純一點、天真一點，



或者說平和一點，



以愉快的心情面對每一天，比較單純一點，也許容易受傷害。不要想太多，就不會感到痛苦。單純一點，容易集中目標。不要自己給自己找麻煩。讓自己的眼神單純一點，



純淨一點，不以物喜，不以己悲。


存著這樣單純的心：



少一點慾望、多一點赤 子之心。真心多一點忍讓，少一點計較，



換回一點自在。

生活中，

我們不必把事情都弄得那麼複雜！做人，也許單純一點會更輕鬆。開心與不開心，

往往都只在人的一念之間，何不放開一點、簡單一點、單純一點呢。集滿三點..就會開心一點，



生命就應該浪費在美好的世界裡！


快樂是一種人權，不需要以善事來交換。幸福是一種空氣，你可以自由呼吸。那些宣稱沒有找到幸福的人，



只是沒有瞭解幸福的真諦…
