( 1 ) 人之所以痛苦，在於追求錯誤的東西。&nbsp;&nbsp;( 2 ) 與其說是別人讓你痛苦，不如說自己的修養不夠。&nbsp;( 3 ) 如果你不給自己煩惱，別人也永遠不可能給你煩惱。只因你執著放不下。&nbsp;( 4 ) 不寬恕別人，是苦了你自己。&nbsp;( 5 ) 學佛是對自己的良心交待，不是做給別人看的。&nbsp;( 6 ) 修行是點滴的工夫。&nbsp;&nbsp;( 7 ) 在順境中修行，永遠不能成佛。&nbsp;( 8 ) 你永遠要感謝給你逆境的人 . 因為他成就你.( 9 ) 這個世界本來就是痛苦的，沒有人是例外的。&nbsp;( 10 ) 當你快樂時，你要想，這快樂不是永恆的。當你痛苦時你要想這痛苦也不是永恆的。&nbsp;( 11 ) 認識自己，降伏自己，改變自己，才能改變別人。( 12 ) 今日的執著，會造成明日的後悔。&nbsp;( 13 ) 你可以擁有愛，但不要執著，因為分離是必然的。&nbsp;( 14 ) 每一種創傷，都是一種成熟。&nbsp;( 15 ) 當你知道迷惑時，並不可憐， 當你不知道迷惑時，才是最可憐的。&nbsp;( 16 ) 你不要一直不滿人家，你應該一直檢討自己才對。不滿人家，是苦了你自己。&nbsp;( 17 ) 當你未學佛的時候，你看什麼都不順眼。當你學佛以後，你要看什麼都很順眼。&nbsp;( 18 ) 你要包容那些意見跟你不同的人，這樣子日子比較好過。你要是一直想改變他 ，那樣子你會很痛苦。
要學學怎樣忍受他才是。你要學學怎樣包容他才是。&nbsp;( 19 ) 承認自己的偉大，就是認同自己的愚痴。&nbsp;( 20 ) 修行就是修正自己錯誤的觀念。&nbsp;( 21 ) 一個人如果不能從內心去原諒別人，那他就永遠不會心安理得。&nbsp;( 22 ) 心中裝滿著自己的看法與想法的人，永遠聽不見別人的心聲。&nbsp;( 23 ) 毀滅人只要一句話，培植一個人卻要千句話，請你多口下留情。&nbsp;( 24 ) 當你勸告別人時，若不顧及別人的自尊心，那麼再好的言語都沒有用的。&nbsp;( 25 ) 不要在你的智慧中夾雜著傲慢。不要使你的謙虛心缺乏智慧。&nbsp;( 26 ) 忌妒別人，不會給自己增加任何的好處。忌妒別人，也不可能減少別人的成就。&nbsp;( 27 ) 戀愛不是慈善事業，不能隨便施捨的。感情是沒有公式，沒有原則，沒有道理可循的.可是人們至死
都還在執著與追求。&nbsp;( 28 ) 請你用慈悲心和溫和的態度，把你的不滿與委屈說出來，別人就容易接受。&nbsp;( 29 ) 創造機會的人是勇者。等待機會的人是愚者。&nbsp;( 30 ) 能說不能行，不是真智慧。&nbsp;( 31 ) 多用心去傾聽別人怎麼說，不要急著表達你自己的看法。&nbsp;( 32 ) 同樣的瓶子，你為什麼要裝毒藥呢？同樣的心理，你為什麼要充滿著煩惱呢？&nbsp;( 33 ) 得不到的東西，我們會一直以為他是美好的，那是因為你對他瞭解太少.沒有時間與他相處在一起。
當有一天，你深入瞭解後，你會發現原不是你想像中的那麼美好。&nbsp;( 34 ) 修行要有耐性，要能甘於淡泊，樂於寂寞。&nbsp;( 35 ) 活著一天，就是有福氣，就該珍惜。當我哭泣我沒有鞋子穿的時候，我發現有人卻沒有腳。&nbsp;( 36 ) 憎恨別人對自己是一種很大的損失。&nbsp;( 37 ) 每一個人都擁有生命，但並非每個人都懂得生命，乃至於珍惜生命。不瞭解生命的人，生命對他來
說，是一種懲罰。&nbsp;( 38 ) 自以為擁有財富的人，其實是被財富所擁有。&nbsp;( 39 ) 情執是苦惱的原因，放下情執，你才能得到自在。&nbsp;( 40 ) 隨緣不是得過且過，因循苟且，而是盡人事聽天命。&nbsp;( 41 ) 用傷害別人的手段來掩飾自己缺點的人，是可恥的。&nbsp;( 42 ) 世間的人要對法律負責任。修行的人要對因果負責任。&nbsp;( 43 ) 在你貧窮的時候，那你就用身體去佈施，譬如說掃地、灑水、搬東西等，這也是一種佈施。&nbsp;( 44 ) 內心充滿忌妒，心中不坦白，言語不正的人，不能算是一位五官端正的人。&nbsp;( 45 ) 默默的關懷與祝福別人，那是一種無形的佈施。( 46 ) 多講點笑話，以幽默的態度處事，這樣子日子會好過一點。&nbsp;( 47 ) 不要刻意去猜測他人的想法，如果你沒有智慧與經驗的正確判斷，通常都會有錯誤的。&nbsp;( 48 ) 要瞭解一個人，只需要看他的出發點與目的地是否相同，就可以知道他是否真心的。&nbsp;( 49 ) 人生的真理，只是藏在平淡無味之中。&nbsp;( 50 ) 不洗澡的人，硬擦香水是不會香的。名聲與尊貴，是來自於真才實學的。有德自然香。( 51 ) 與其你去排斥它已成的事實，你不如去接受它，這個叫做認命。&nbsp;( 52 ) 逆境是成長必經的過程，能勇於接受逆境的人，生命就會日漸的茁壯。&nbsp;( 53 ) 你要感謝告訴你缺點的人。&nbsp;( 54 ) 能為別人設想的人，永遠不寂寞。&nbsp;( 55 ) 如果你能像看別人缺點一樣，如此準確般的發現自己的缺點，那麼你的生命將會不平凡。&nbsp;( 56 ) 原諒別人，就是給自己心中留下空間，以便迴旋。&nbsp;( 57 ) 你硬要把單純的事情看得很嚴重，那樣子你會很痛苦。&nbsp;( 58 ) 永遠扭曲別人善意的人，無藥可救。&nbsp;( 59 ) 人不是壞的，只是習氣罷了，每個人都有習氣，只是深淺不同罷了。只要他有向道的心，能原諒的就
原諒他，不要把他看做是壞人。&nbsp;( 60 ) 說一句謊話，要編造十句謊話來彌補，何必呢？&nbsp;( 61 ) 世界上沒有一個永遠不被譭謗的人，也沒有一個永遠被讚歎的人。當你話多的時候，別人要批評你，
當你話少的時候，別人要批評你，當你沈默的時候，別人還是要批評你.在這個世界上，沒有一個不被批評
的。&nbsp;( 62 ) 誇獎我們，讚歎我們的，這都不是名師。會講我們，指示我們的，這才是善知識.有了他們我們才會
進步。&nbsp;( 63 ) 你目前所擁有的都將隨著你的死亡而成為他人的，那為何不現在就佈施給真正需要的人呢&nbsp;( 64 ) 沈默是譭謗最好的答覆。&nbsp;( 65 ) 對人恭敬，就是在莊嚴你自己。&nbsp;( 66 ) 仇恨永遠不能化解仇恨，只有慈悲才能化解仇恨，這是永恆的至理。&nbsp;( 67 ) 你認命比抱怨還要好，對於不可改變的事實，你除了認命以外，沒有更好的辦法了。&nbsp;( 68 ) 別人講我們不好，不用生氣、難過。說我們好也不用高興，這不好中有好，好中有壞，就看你會不會
用？&nbsp;( 69 ) 如果你自己明明對，別人硬說你不對，你也要向人懺悔，修行就是修這些。你什麼事都能忍下來，
才會進步。就是明明是你對，你也要向他人求懺悔，那就是修行了。&nbsp;( 70 ) 不要常常覺得自己很不幸，世界上比我們痛苦的人還更多。&nbsp;( 71 ) 愚癡的人，一直想要別人瞭解他。有智慧的人，卻努力的瞭解自己。&nbsp;( 72 ) 來是偶然的，走是必然的。所以你必須，隨緣不變，不變隨緣。&nbsp;( 73 ) 慈悲是你最好的武器。&nbsp;( 74 ) 只要面對現實，你才能超越現實。&nbsp;( 75 ) 良心是每一個人最公正的審判官，你騙得了別人，卻永遠騙不了你自己的良心。&nbsp;( 76 ) 不懂得自愛的人，是沒有能力去愛別人的。&nbsp;( 77 ) 學佛就是在學做人而已。&nbsp;( 78 ) 有時候我們要冷靜問問自已，我們在追求什麼？我們活著為了什麼？&nbsp;( 79 ) 不要因為小小的爭執，遠離了你至親的好友，也不要因為小小的怨恨，忘記了別人的大恩 .&nbsp;( 80 ) 勇於接受別人的批評，正好可以調整自己的缺點。&nbsp;( 81 ) 感謝上蒼我所擁有的，感謝上蒼我所沒有的。&nbsp;( 82 ) 凡是能站在別人的角度為他人著想，這個就是慈悲。&nbsp;( 83 ) 學佛不是對死亡的一種寄托，而是當下就活得自在和超越。&nbsp;( 84 ) 佛陀從不勉強別人去做他不喜歡的事情，佛陀只是告訴眾生，何者是善？何者是惡？善惡還是要自己
去選擇，生命還是要自己去掌握。&nbsp;( 85 ) 所謂的放下，就是去除你的分別心、是非心、得失心、執著心。&nbsp;( 86 ) 說話不要有攻擊性，不要有殺傷力，不誇已能，不揚人惡，自然能化敵為友。&nbsp;( 87 ) 一個常常看別人缺點的人，自己本身就不夠好，因為他沒有時間檢討他自己。&nbsp;( 88 ) 真正的佈施，就是把你的煩惱、憂慮、分別和執著心通通放下。&nbsp;( 89 ) 如果你真的愛他，那麼你必須容忍他部份的缺點。&nbsp;( 90 ) 要克服對死亡的恐懼，你必須要接受世上所有的人，都會死去的觀念。&nbsp;( 91 ) 瞭解永恆真理的人，就不會為任何的生離死別而哀傷悲泣，因為生離死別是必然的。&nbsp;( 92 ) 希望你常對自己說，聞到了佛法，我是最幸福的人，除了這幸福外，再沒有別的了。&nbsp;( 93 ) 我的財富並不是因為我擁有很多，而是我要求的很少。&nbsp;( 94 ) 如果你準備結婚的話，告訴你一句非常重要的哲學名言「你一定要忍耐包容對方的缺點，世界上沒有
絕對幸福圓滿的婚姻，幸福只是來自於無限的容忍與互相尊重。」&nbsp;( 95 ) 如果你能夠平平安安的渡過一天，那就是一種福氣了。多少人在今天已經見不到明天的太陽.多少人
在今天已經成了殘廢，多少人在今天已經失去了自由，多少人在今天已經家破人亡。&nbsp;( 96 ) 是非和得失，要到最後的結果，才能評定。&nbsp;( 97 ) 你不要常常覺得自己很委曲，你應該要想，他對我這樣已經很好了，這就是修行的功夫。&nbsp;( 98 ) 如果一個人沒有苦難的感受，就不容易對他人給予同情。你要學救苦救難的精神，就得先受苦受難。&nbsp;( 99 ) 世界原本就不是屬於你，因此你用不著拋棄，要拋棄的是一切的執著。萬物皆為我所用，但非我屬。&nbsp;( 100 ) 雖然我們不能改變週遭的世界，我們就只好改變自己，用慈悲心和智慧心來面對這一切。
