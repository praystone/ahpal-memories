一個男人看見美女時的想法 


&nbsp;

&nbsp;


剛出生時看見一個也是剛出生的女嬰,

&nbsp;

除了哭聲外，什麼想法都沒有；

&nbsp;

5歲時看到同齡的小美女，第一個想法是，

&nbsp;

如果這小美女是我認識的小夥伴該多好呀！


&nbsp;

10歲時看到同齡的小美女，第一個想法是：

&nbsp;

如果這小美女是我的同學或同桌該多好呀！


&nbsp;

15歲時看到同齡的小美女，第一個想法是：

&nbsp;

如果這小美女能讓我拉拉手或擁抱一下該多好呀！


&nbsp;

20歲時看到同齡的美女，第一個想法是：

&nbsp;

如果這美女讓我親一下或做我的初戀情人該多好呀！


&nbsp;

25歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女願意嫁給我該多好呀！


&nbsp;

30歲時看到年輕的美女，第一個想法是：

&nbsp;

如果政策允許男人娶兩個老婆該多好呀！


&nbsp;

35歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女願意和我發生婚外一夜情該多好呀！


&nbsp;

40歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女願意做我的二奶該多好呀！

&nbsp;

&nbsp;

45歲時看到年輕的美女，第一個想法是：

&nbsp;

如果我是個當大官的或名人該多好呀！


&nbsp;

50歲時看到年輕的美女，第一個想法是：

&nbsp;

如果我是個有錢人或大老闆該多好呀！


&nbsp;

55歲時看到年輕的美女，第一個想法是：

&nbsp;

如果我能年輕30歲該多好呀！


&nbsp;

60歲時看到年輕的美女，第一個想法是：

&nbsp;

如果60歲的人也算是年青人該多好呀！


&nbsp;

65歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女和我成為“忘年交”朋友該多好呀!


&nbsp;

70歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女每天都牽著我的手去逛公園該多好呀！


&nbsp;

75歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女是我家的保姆該多好呀！


&nbsp;

80歲時看到年輕的美女，第一個想法是：

&nbsp;

如果這美女是我的私人保健醫生該多好呀！


&nbsp;

85歲時看到年輕的美女，第一個想法是：


如果我的身體一直都健健康康該多好呀！


&nbsp;

90歲時看到年輕的美女，第一個想法是：

&nbsp;

如果人能長生不老該多好呀！


&nbsp;

100歲時看到年輕的美女，第一個想法是：

&nbsp;

如果天堂裏也有這樣的美女該多好呀！
