&nbsp;
[塔羅]測你愛逞強指數 rn&nbsp;

&nbsp;

有些人的自尊心太強、很愛面子，不喜歡向別人低頭，

&nbsp;

因而喜歡逞強，不管遇到任何問題或困難，

&nbsp;

總是表現出「我可以」的樣子不願意請別人幫忙，

&nbsp;

你也是愛逞強的人嗎？今天請到魔女克洛蒂老師，

&nbsp;

從塔羅牌分析你的愛逞強指數有多高囉！


測驗開始


請憑個人直覺，從下列6張塔羅中挑選1張。

&nbsp;


 rn&nbsp;

選好了嗎？開始解析囉！

&nbsp;

&nbsp;


選A的人

&nbsp;

因為你平日就是成熟穩重的模樣，

&nbsp;

而且經常是他人請求援助的對象，

&nbsp;

所以久而久之你就會培養出堅強的個性，

&nbsp;

即使有時候遇到令自己困擾的問題，

&nbsp;

你也覺得應該自行處理，很難對別人要求援助，

&nbsp;

為了個人尊嚴與面子問題，你也只好逞強地獨自面對難題囉！

&nbsp;

愛逞強指數80％

&nbsp;

&nbsp;

選B的人

&nbsp;

你是屬於做事比較小心翼翼、不容許自己犯錯的人，

&nbsp;

當然有時也會因為愛面子而不承認無法做到，

&nbsp;

所以一旦你遇到難題無法解決時，就會想辦法逃避，

&nbsp;

盡可能地去掩飾，表現出一副「我可以」的樣子，

&nbsp;

而且你覺得請別人幫忙需要還人情，因而感到很不劃算。

&nbsp;

愛逞強指數55％

&nbsp;

&nbsp;

選C的人

&nbsp;

你擁有能屈能伸的個性，平常獨立自主、

&nbsp;

辦事能力很強，但真的遇到了自己無法解決的難題時，

&nbsp;

絕對不會為了無意義的面子問題而愛逞強，

&nbsp;

你反而會懂得保持低姿態，向周圍的人求助，

&nbsp;

加上你謙虛請求他人協助的態度，

&nbsp;

不但可以讓問題迎刃而解，

&nbsp;

更能從中學習許多經驗，算是獲益良多。

&nbsp;

愛逞強指數15％

&nbsp;

&nbsp;

選D的人

&nbsp;

從你的外表及行事風格就知道你是個自尊心很強的人，

&nbsp;

因為你很少顯露內心的情緒，

&nbsp;

總是表現出一副冷靜理智的態度，

&nbsp;

加上個性驕傲的你不容許自己向別人低頭，

&nbsp;

一旦遇到困難也不輕易對他人訴說，

&nbsp;

而且你不相信別人有能力幫得了你，

&nbsp;

所以只好逞強地假裝沒有問題，獨自解決囉！

&nbsp;

愛逞強指數65％

&nbsp;

&nbsp;

選E的人

&nbsp;

平常的你非常喜歡跟朋友分享事情，

&nbsp;

彼此交流心得並互相扶持，一旦遇到困難，

&nbsp;

一定二話不說趕緊向死黨求助，

&nbsp;

不會因為自尊心或面子問題而讓自己困在煩惱裡，

&nbsp;

因為你深知三個臭皮匠勝過一個諸葛亮的道理，

&nbsp;

根本沒有必要在好友面前逞強為難自己。

&nbsp;

愛逞強指數20％

&nbsp;

&nbsp;

選F的人

&nbsp;

你的自尊心超強、非常愛面子，

&nbsp;

習慣一肩扛起所有的重擔，並在別人面前扮演領導的角色，

&nbsp;

無論遇到任何困難，都不會向他人開口要求幫助，

&nbsp;

寧可自己咬著牙關硬撐過去，

&nbsp;

打死都不願意表現出軟弱的一面，

&nbsp;

而且你還會一派輕鬆地說：

&nbsp;

「沒問題，我自己可以處理」，是個相當愛逞強的人！

&nbsp;

愛逞強指數90％
