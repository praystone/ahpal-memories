&nbsp; 

&nbsp;
 
愛情需要表達出來

&nbsp;



&nbsp;

&nbsp;


人的一生是一個相互關心、

&nbsp;

關愛的過程，每個人都有情感的需要，

&nbsp;

其中，語言的交流和情感的表達又是關鍵。

&nbsp;

不要讓愛人只是用猜想知道你的關愛，

&nbsp;

而是要讓對方時時感受到你的心意。

&nbsp;

這就是你用嘴巴告訴對方你的愛，還需要用行動來表達愛的程度。


愛就是打開心扉，讓它自由地流淌，

&nbsp;

讓對方看得到、聽得到、感受得到。

&nbsp;

不管多忙，都不要忘記給愛人打個電話；

&nbsp;

不管多累，都要在回家之後給愛人一個擁抱。

&nbsp;

不管生活中有多少煩惱，都應該給愛人一個微笑……


&nbsp;

心中有愛，

&nbsp;

我們就應該大聲說出來，就應該做出來，

&nbsp;

用行動和語言標的心中那份溫暖和幸福。

&nbsp;

愛不表現則不存在，愛情是需要表達的。

&nbsp;

愛情不僅是實際生活中的柴米油鹽醬醋茶，

&nbsp;

它還是一件莊重的事情，

&nbsp;

它需要應對和承諾，需要證實和鼓勵。

&nbsp;

愛情的表達可以是深夜花園中的吟唱，

&nbsp;

可以是花前月下的山盟海誓，

&nbsp;

因為這些都意味著承諾和責任，意味著接受和渴望。

&nbsp;

從古至今，無論東方還是西方，

&nbsp;

愛情的表達方式都是多種多樣的。


&nbsp;

人們用歌聲傳遞愛情，

&nbsp;

用詩句讚美愛情，用文字記載愛情，

&nbsp;

用畫筆感悟愛情，用肢體表達愛情，

&nbsp;

用信物寄託愛情……

&nbsp;

愛情最直接有效的一種方式就是用言語說出來。

&nbsp;

不要輕視這一句簡單的話，

&nbsp;

它能將所有愛的資訊全部地透徹地傳遞到對方心底。

&nbsp;

經過表達的愛情才被賦予了生命，

&nbsp;

有了意義深刻的靈魂。

&nbsp;

愛情的表達不一定昂貴，不一定耗時，

&nbsp;

一起生活久了，

&nbsp;

愛情的表達或許就變成一些雞毛蒜皮的生活習慣。

&nbsp;

比如為愛人沏一杯熱茶，

&nbsp;

跟愛人開一個玩笑。

&nbsp;

當然，茶可能太燙，玩笑可能稍顯粗俗。

&nbsp;

但是，千萬不要拒絕。

&nbsp;

因為你拒絕的，已經不是一個動作，而是愛情。


&nbsp;

我們要知道，

&nbsp;

一碗熱湯的關懷絕不比玫瑰所表達的愛分量輕。

&nbsp;

生活如水般波瀾不驚，平平淡淡，

&nbsp;

緩緩地流過男人的額頭和女人的眼角。

&nbsp;

不知不覺間，歲月的紋路就爬上了曾經年輕的面龐。


&nbsp;

有條不紊的時光中，

&nbsp;

愛情很容易變得靜如止水，失去韻律和色彩。

&nbsp;

適時地表達愛情不僅能換回逝去的溫情，

&nbsp;

而且它還是生活的調味劑，

&nbsp;

讓每一天都沉浸在期盼和喜悅中。

&nbsp;

為愛人說的一個老掉牙的笑話而捧腹大笑，

&nbsp;

看報紙雜誌時剪下他喜歡的文章送給他。

&nbsp;

記得每天都說早安、晚安、再見，

&nbsp;

與他共享他感興趣的球賽或其他活動。

&nbsp;

和他一起在廚房做一頓飯，鄭重其事為一件小事謝謝他，

&nbsp;

給他買一些古怪有趣的小禮物，記得他父母的生日……

&nbsp;

這些都是生活中細碎的事情，

&nbsp;

卻可以讓愛人從心底感受到你的愛。


&nbsp;

愛情的表達，就是為了給對方看自己的那顆心，

&nbsp;

看那顆心裡的愛戀、溫情、惦記和顫動。

&nbsp;

對平平常常的人來講，

&nbsp;

這種以心換心的事最好是以樸素的、

&nbsp;

細微的、綿長的方式進行。

&nbsp;

這才和我們的樸素的、細微的、綿長的生活更加吻合。


&nbsp;

“我愛你”是人間最美好的語言。

&nbsp;

戀人之間一句“我愛你”，常常是情感升溫的開始。

&nbsp;

夫妻之間一句“我愛你”，往往是愛情保鮮的祕方。

&nbsp;

愛要說，要讓對方明白你的愛意。

&nbsp;

愛也要做，以證明你愛的深度。


&nbsp;
