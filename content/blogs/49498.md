有時候...也許不必事事在意!


&nbsp;

&nbsp;

&nbsp;


有的時候，別人對我們莫名其妙的熱情

&nbsp;

有的時候又無端地冷漠，有的時候我們與別人打招呼

&nbsp;

而對方卻視而不見

&nbsp;

有時候，我們與別人交談，對方好像心不在焉，忽冷忽熱

&nbsp;

也許這些都沒有理由，只是一種偶然

&nbsp;

也許是我們過於敏感了，所以我們不要太在意

&nbsp;

要用一顆平常的心對待


&nbsp;

別人對我們微笑，我們也報以微笑就可以力量

&nbsp;

不必去想微笑背後的動機和含義

&nbsp;

同樣，別人對我們視而不見，冷面相向時

&nbsp;

我們也大可不必疑神疑鬼自己嚇自己，自己折磨自己

&nbsp;

也許別人本是無心的，或他本人正陷於苦悶中

&nbsp;

只因我們過於多心

&nbsp;

才使別人的態度有了一種特殊的意義

&nbsp;

有時候，

&nbsp;

我們自己遇到麻煩的事，生活不太如意或者情緒不好

&nbsp;

別人在與我們打招呼交談時

&nbsp;

我們也會這樣的，換位想想，也就沒什麼了


&nbsp;

不必把時光用作無謂的思慮

&nbsp;

一千個人也許會用一千中不同的神情面對我們

&nbsp;

難道我們要一一去作註腳嗎

&nbsp;

不管我們做的是對是錯

&nbsp;

總會有各種各樣的態度，各種各樣的議論

&nbsp;

如果我們糾纏其中，不但要遭受煩惱

&nbsp;

而且什麼事也無法去做


&nbsp;

假如我們做了一件好事，忘掉它就是了

&nbsp;

「做不求回報的善事，自會有美麗的結局」

&nbsp;

假如我們做了一件錯事

&nbsp;

只要從中吸取教訓，不再犯同樣的錯誤就是了

&nbsp;

任何事都可以化解，有什麼值得耿耿與懷的呢

&nbsp;

假如我們在無謂的瑣事上，少用些心思，少花點精力

&nbsp;

一心一意地投入自己想要的生活

&nbsp;

或許會活得更加輕鬆更加愜意

&nbsp;

&nbsp;
