&nbsp; rn&nbsp;
 
愛情經不起風雨

&nbsp;




&nbsp;

&nbsp;


現在的情感都是脆弱的，

&nbsp;

經不起一點點的考驗和磨練！

&nbsp;

所以才會發生很多讓人遺憾的事。看過很多電視劇，

&nbsp;

好像劇中全是錯過，誤解，無一例外，

&nbsp;

曾經的海誓山盟，天長地久和永不變心的誓言，

&nbsp;

卻隨著一句分手而化為子虛無有。
&nbsp;
&nbsp;
感情是如此的脆弱，社會太過現實，
&nbsp;
特別是在金錢的面前，

&nbsp;

感情經不起一點點的考驗，
&nbsp;
難道愛情真的是虛無，完全沒有任何實用價值。
&nbsp;
為什麼有的愛情經不起風雨的挫折？
&nbsp;
&nbsp;
在愛情的世界裏,人們總是問, 
&nbsp;
你愛不愛我？你愛我多深？為什麼你不愛我？
&nbsp;
為什麼...有多少人得到確切的答復？
&nbsp;
其實，愛情是沒有什麼定義的。
&nbsp;
&nbsp;彼此不懂對方的心,彼此之間沒有信任. 
&nbsp;
一份經不起風雨，經不起考驗的感情不叫愛情!
&nbsp;
&nbsp;
現在很多情侶在一起不是因為愛，
&nbsp;
而是因為兩顆寂寞的心而開始相愛，
&nbsp;
也有的情侶是因為對方的金錢而在一起，
&nbsp;
最後因性格不合等種種原因而分手，試問：為了目的而愛，
&nbsp;
沾了銅臭味的感情能維持多久，走多遠？

&nbsp;

曾經的戀人，今日成了仇人，彼此傷害，
&nbsp;
難道當初的相愛只是想刺激一把嗎？

&nbsp;

還是想玩愛情遊戲？
&nbsp;
&nbsp;
愛情，就像是一個易碎的玻璃杯，
&nbsp;
有美麗的外表，美麗的心，但是卻那麼的脆弱，
&nbsp;
那麼的易碎……當你不小心把它碰碎，
&nbsp;
再去拾一地的閃亮時，你會發現它依舊是那麼美麗，
&nbsp;
但，那一地的碎片卻已把你傷的鮮血淋漓，

&nbsp;

使你以後不敢去碰觸。
&nbsp;
&nbsp;
偶然聽到《不要連分手都騙我》這首歌，蠻感傷。

&nbsp;

很喜歡裏面的歌詞，
&nbsp;
當戀人不能再繼續了，就像歌曲中唱的那樣，
&nbsp;
既然緣分已盡，就好聚好散吧，愛情是兩個人的事情，
&nbsp;
沒有什麼所謂的誰對誰錯，只能怪兩個人有緣無份，
&nbsp;
在愛情字典中沒有所謂的：
&nbsp;
不是情人就是敵人，有的最多是陌生人。

&nbsp;

分手後做不成朋友，也別責怪誰，怨恨誰，

&nbsp;

因為彼此都傷害過。
&nbsp;
