數字測驗：

&nbsp;

未來一個月誰是我的財神爺？ 

&nbsp;

（測驗日期為5/15~6/15）


&nbsp;月初好不容易等到薪水入帳，但扣除了生活支出、

&nbsp;

水電費、卡費、貸款…，轉眼間就所剩無幾了，

&nbsp;

想要改變現狀、增加收入的機會又在哪？

&nbsp;

苦無對策的你，趕緊來選組數字，

&nbsp;

看看最近一個月，誰是你的財神爺，能幫助你財運大開！ 

&nbsp;

&lt;數字選項&gt; 

&nbsp;

請憑直覺選出一組喜歡的數字 

&nbsp;



&nbsp;

&nbsp;

&nbsp;

解析～
&nbsp;


&nbsp;


☆選「1718」此組數字：發財指數　20% 

&nbsp;

選到這組數字的朋友，發財指數只有二十分，

&nbsp;

最近一個月遇到財神爺的機會微乎其微，

&nbsp;

目前的你太過安逸，總是想要找到賺錢的捷徑，

&nbsp;

渴望休息或是懶惰的態度，或是虎頭蛇尾的工作態度，

&nbsp;

可是無法讓你賺飽荷包，應該更努力衝刺事業，

&nbsp;

雖然勞累但卻是實在的過程。 


&nbsp;

☆選「1783」此組數字：發財指數　60% 

&nbsp;

選到這組數字的朋友，發財指數有六十分，

&nbsp;

最近一個月你的財神爺就是你親朋好友裡的理財高手，

&nbsp;

其實你有許多不錯的兼差機會，能讓你賺進不少外快，

&nbsp;

可是因為你平時太過忽略，總是擦身而過，

&nbsp;

所以只要多留意身邊的資訊，或是多培養不同的技能，

&nbsp;

都可以為你賺入不小的財富。 


&nbsp;

☆選「1825」此組數字：發財指數　100% 

&nbsp;

選到這組數字的朋友，發財指數滿滿一百分！

&nbsp;

代表最近一個月自己就是財神爺，

&nbsp;

同時也是別人的財神爺，不但財運不錯、進財容易，

&nbsp;

還能夠幫助身邊的人度過難關；

&nbsp;

因此若是有什麼創業的想法，或是投資、轉跑道的計畫，

&nbsp;

不妨趁這個時間去試看看，都能得到不錯的結果。 


&nbsp;


☆選「2258」此組數字：發財指數　40% 

&nbsp;

選到這組數字的朋友，發財指數有四十分，

&nbsp;

最近一個月你的好朋友就是財神爺，遇到困難時，

&nbsp;

不妨主動開口求援；

&nbsp;

另一方面表示你最近正徘徊在財務的十字路口上，

&nbsp;

猶疑不定，此時你身邊的好友們，

&nbsp;

會給予你一些不錯的建議，只要聽從建議一步步的細心解決，

&nbsp;

就能找出方向，度過危機。 


&nbsp;
☆選「1731」此組數字：發財指數　80% 

&nbsp;

選到這組數字的朋友，發財指數有八十分，

&nbsp;

代表你最近的財神爺是老闆和長官，

&nbsp;

工作表現出色的你，能夠讓大家都看見你的努力，

&nbsp;

不但能夠擔當重任，還能有不錯的獎勵，讓你進帳少；

&nbsp;

同時也表示如果這段時間，有想要離職的打算，

&nbsp;

建議先緩一緩，先顧好目前的工作比較好。
