懂了淚水，就懂了人生
&nbsp;



&nbsp;

&nbsp;


&nbsp;生命總是在自己的啼哭中開始，

&nbsp;

於別人的淚水裡抵達終點。

&nbsp;

醫學上認為，眼淚有清潔眼球的作用，

&nbsp;

是對外界刺激的一種應激性反映，從胎兒時開始，

&nbsp;

就有了基礎淚。

&nbsp;

於是，淚水就給生命打上了烙印，直到生命結束後，

&nbsp;

或許還有淚水在記憶你已經飄逝的靈魂。
&nbsp;
&nbsp;
人是情感的動物，
&nbsp;
有七情六欲，不能長期壓抑在心底，

&nbsp;

顯現於外，不外乎表情、語言、動作等，

&nbsp;

喜也好，悲也罷，哭著笑著，
&nbsp;
淚水就在眼眶中積聚，水一樣地流，
&nbsp;
一滴一滴便是情感的世界。


這世界裡有真也有假，有呼喚也有陷阱……

&nbsp;

淚水不僅與傷感、悲痛有關，也和喜樂有關。


怒極反笑，喜極而泣，人在巨大的驚喜或者幸福之前，

&nbsp;

一時難以找到最好的表達情感的方式，

&nbsp;

而淚水往往先一步淋漓而出。


&nbsp;

笑中有淚，性情率真，

&nbsp;

然而之後的諸多感慨復雜情感一時之間是難以道盡的，

&nbsp;

全部凝聚在這奪眶而出的液體之中了。


淚水似乎與女子有緣，善睞明眸，

&nbsp;

若有霧氣朦朧，

&nbsp;

便是幽潭一碧的美麗和誘惑，生生攝人魂魄風流無限。


&nbsp;

淚光點點，
&nbsp;
嬌喘微微的黛玉硬是勾走了無數男人的心，

&nbsp;

為什麼都指望“天上掉下個林妹妹”，可想而知。

&nbsp;

有淚水，男人往往自作多情地要去憐香惜玉，

&nbsp;

女人也往往順水推舟小鳥依人，

&nbsp;

淚水就成為和諧愛情的一種潤滑劑。
&nbsp;
&nbsp;
但女人們不能過多地使用，因為面對女人的淚水，

&nbsp;

男人總是惶恐不安，不知所措，

&nbsp;

要嘛就不聞不問，要嘛就溜之大吉。


&nbsp;

女人，請記住，許多時候，笑容和淚水同等重要。

&nbsp;

男兒有淚不輕彈，
&nbsp;
所以男人習慣於把眼淚藏在心底，

&nbsp;

讓它在血液裡流動，這是文化傳統的影響。


偽裝出來的堅強總會有崩潰的一天，

&nbsp;

當男人真正要哭的時候，

&nbsp;

一定要當心，那可真實決堤的海一發不可收拾。


&nbsp;

但大多數男人都會選擇在無人的角落

&nbsp;

或者最親近的女人面前傷心欲絕地哭一場的，

&nbsp;

大部分時間裡他用笑容掩飾著淚水，

&nbsp;

因為他相信“莫斯科不相信眼淚”。


&nbsp;

敢笑敢哭，是真性情人。

&nbsp;

心真情真，淚水也真.有一顆感動的心，

&nbsp;

我們用淚水滋潤世間的真善美；

&nbsp;

有一顆憐憫的心，
&nbsp;
我們用淚水去祭奠痛苦和哀傷；

&nbsp;

有一顆真誠的心，
&nbsp;
我們用淚水去溫暖苦痛的靈魂。


人生總在淚水中前行，酸甜哭辣百味嘗盡，
&nbsp;
或許，懂了淚水，就懂了人生。
