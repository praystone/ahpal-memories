一個真實的地藏菩薩感應-------外婆的生日<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


阿彌陀佛，願看到我這帖子的同修都精進念佛，將來鐵定往生西方極樂世界不退成佛。
&nbsp; &nbsp;&nbsp; &nbsp; 我信佛半年，吃全素三個月。現在在廣州做男裝西裝批發的生意。由於資金不夠宏厚，不能選一個客流量很多很旺的市場，也租不起很大面積的店面，最後在三元里地鐵附近的一個青黃不接的批發市場裏租了一個七八平方大的小小店。那個服裝批發市場主要是做牛仔和貨尾的多，我的男裝西裝批發店開在那，真的有點不合流。開店一個月，來看西裝的客才寥寥無幾，這不，已經有四五天沒做成一單生意了。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;2011年<?xml:namespace prefix = st1 ns = "urn:schemas-microsoft-com:office:smarttags" />農曆4月4日，是文殊菩薩誕，我準時地回到店開門，清潔一番過後就拿出《地藏經》念了一遍。念完地藏經，心裏特別舒坦，就趴在桌上休息了，這時，我的媽媽發資訊給我說今天是外婆的生日。看到這資訊，我原來清涼的心裏就開始不平靜了。腦海中不時浮現一個片段：外公才離開我們不足30天，剩下今年80歲的外婆獨居。外婆沒有兒子，生了6個都是女兒。往年的生日都有外公陪她度過，今年生日卻剩風燭殘年的她沉浸在喪夫之痛還沒褪色的回憶裏，我很想回老家陪陪外婆，尤其在今天這個開心而又帶點傷感的日子裏。外婆今年都80高齡了，試問我們做孫女的還可以和她共度多少個生日以表孝意呢？想到這，我真的盼望時間快點到5點，可以關鋪乘車直奔老家外婆家去。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;打開錢包放卡的一格，看到羊城通在，乘地鐵和乘巴士的時候，需要用的，從廣州回到南沙區老家，來回需要28元車費，清晰記得昨天在 711 便利店購物後，卡裏才剩下30元，今早乘公車回來開店的時候又扣掉一些，羊城通裏的錢，還夠乘車回老家麼？打開放錢幣的一格，唉，裏面空空如也，沒有現金，萬一車卡裏的錢不夠回家的路費，被卡在半路上，又沒現金買臨時票回家，怎麼辦？我多麼希望自己的錢包裏變成一張百元大鈔，就可以充值羊城通，今晚回老家陪外婆過生日去啊！又或者是突然來個顧客，哪怕在這只買一套西裝，我也可以先花著這錢回家去。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;期盼和焦急中，時間已到下午三點了，我所期望的，一樣都沒有發生。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;我拿出早上剛讀過的《地藏菩薩本願經》，立起地藏菩薩像，在地藏菩薩像前很真切地把我外婆生日，但自己又沒錢回老家看她老人家的情況說了一下，懇求地藏菩薩加持我，快點有生意，我不要多，夠充車卡就好，哪怕一百塊也行的了……喃喃自語了一會，就翻開《地藏經》念起來。
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;念到第六品中後部分，就進來一位元客人，我們一番交談後，最後，他給了100元訂金說過兩天再告訴我具體要買哪幾套西裝。
我拿著這張嶄新的一百塊人民幣，心裏充滿著無限的驚喜，真的是無限的感激啊！
&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;感恩大慈大悲大願地藏菩薩的加持啊！如果沒有您的加持，我想我會錯過了一個與外婆共度生日的美好的晚上，如過沒有您的顯靈，我想我不能盡孫女的孝心，雖然我去到外婆家也不能給她老人家一些錢意思意思一下，但她老人家見到我回去，已很高興了，臨睡前，我給外婆按摩腰部，地藏王菩薩，我想年年都能為外婆做按摩，讓她老人家健健康康，活到我有出人頭地的時候，好正正經經地報答她老人家，孝敬她老人家，好讓她享享孫福，才往生西方極樂世界啊！
&nbsp; &nbsp;&nbsp; &nbsp; 地藏王菩薩，您與閻浮提眾生有大因緣，果言不虛！連我這個平凡的小人物的一個心願都不會忽略，在這麼急的時間裏，幫我實現了願望，真的太不可思議了！
