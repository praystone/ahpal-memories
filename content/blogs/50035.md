&nbsp;
 
從潛意識來

看你的心智年齡是幾歲


&nbsp;

&nbsp;

你覺得女兒跟爸爸"不能說的秘密"會是什麼呢?


1.未婚懷孕

&nbsp;

2.花錢養情人

&nbsp;

3.裸照被PO上網

&nbsp;

4.被情人打

&nbsp;

&nbsp;

&nbsp;

解析～

&nbsp;

&nbsp;


1未婚懷孕

&nbsp;

2歲 

&nbsp;

選這個答案的人,想吃就吃,想生氣就生氣,

&nbsp;

開心就很開心,還有很多的真性情,

&nbsp;

雖然有時候挺幼稚的,不過還是滿討人喜歡的. 

&nbsp;

&nbsp;

2.花錢養情人

&nbsp;

80歲 

&nbsp;

選這個答案的人,內心深處已經很平穩,

&nbsp;

你覺得就像老人家一樣,穩穩當當,

&nbsp;

平平安安的過生活才最安心,

&nbsp;

不過你還會像老人家一樣偶爾耍點小任性哦. 

&nbsp;

&nbsp;

3.裸照被PO上網

&nbsp;

17歲 

&nbsp;

選這個答案的人,內心深處還有很多夢想還沒有實現,

&nbsp;

所以你們還在追逐夢想,在一般的日常生活之外,

&nbsp;

你們會覺得有許多夢想,這樣生活才會多采多姿. 


&nbsp;

4.被情人打

&nbsp;

30歲 

&nbsp;

選這個答案的人,其實你們的內心還滿成熟的,

&nbsp;

你們此刻,最重要的就是抗責任,你會覺得責任很重要,

&nbsp;

家人對你來說是目前的重心,

&nbsp;

所以你大部分精力都花在家人身上,

&nbsp;

讓家里和樂融融,這樣你才會覺得安心. 

&nbsp;

&nbsp;
