&nbsp;
 
你面對喜歡的人時有何反應?



&nbsp;

公司聚餐，飯桌上有道你最愛吃的菜，

&nbsp;

可是離你滿遠，就算你伸長了胳膊也夾不到，

&nbsp;

這時你會怎麼辦呢？


&nbsp;

A 放棄！自己的形象重要

&nbsp;

b 請接近那菜的人幫你夾

&nbsp;

c 為了口福，站起來夾！

&nbsp;

d 跟靠近那菜的人換座位

&nbsp;

&nbsp;

&nbsp;

解析～

&nbsp;

&nbsp;


A 放棄！自己的形象重要

&nbsp;

生活中的你比較低調，少言寡語的，

&nbsp;

面對喜歡的人也沒有勇氣說出來。

&nbsp;

過於羞怯與自卑總讓你與戀愛失之交臂！

&nbsp;

TAKE IT EASY，其實你有很多的優點，

&nbsp;

或許對方已經

&nbsp;

在悄悄地注意你了，為什麼不說出你的真實感覺呢？

&nbsp;

&nbsp;

b 請接近那菜的人幫你夾

&nbsp;

你凡事都小心謹慎，不慌不忙，再經過深謀遠慮後，

&nbsp;

等到一切盡在你的掌控中，就開始行動了，

&nbsp;

你的城府有夠深，哈哈！

&nbsp;

想想你如此地謹慎，你的愛情路豈有不一帆風順，

&nbsp;

馬到成功呢！ 


&nbsp;

c 為了口福，站起來夾！

&nbsp;

你這個人“侵略性”較強，只要是自己喜歡的人，

&nbsp;

一定會想盡辦法追到手。

&nbsp;

你認為愛就該對方知道，並且拿出實際行動來，

&nbsp;

不過你的表達方式容易被誤解為太過霸氣，

&nbsp;

所以有時候結果會令你相當的失望！ 


&nbsp;

d 跟靠近那菜的人換座位

&nbsp;

你是個很有主見的人，

&nbsp;

善於運用計謀來輕易的俘獲目標物，

&nbsp;

而且做事乾淨利落不拖泥帶水，

&nbsp;

讓身邊的人佩服不已。

&nbsp;

不過有時候也會過於自信，要知道強中自有強中手，

&nbsp;

如果遇到一個跟你一樣的情場高手，就有的瞧囉！
