記住別人的好

&nbsp;



&nbsp;

&nbsp;


對於別人給我們造成的傷害
&nbsp;
我們不要記在心上，要盡快淡忘掉
&nbsp;
對於別人給予我們的恩惠，我們要時刻記在心上
&nbsp;
並在條件許可的情況下，回報別人的恩德
&nbsp;
如果我們能夠以寬容的心來
&nbsp;
對待別人對我們的傷害
&nbsp;
以感恩的心來對待別人對自己的恩惠
&nbsp;
則人世間就會減少許多仇恨，增加更多的人間真情
&nbsp;
&nbsp;
人生道路充滿了曲折坎坷
&nbsp;
我們經常會遭遇挫折和失敗，我們之所以能夠在
&nbsp;
充滿艱難險阻的人生中克服困難，順利成長
&nbsp;
都是因為有人在我們困難之時，向我們伸出溫暖的雙手
&nbsp;
幫助我們解除生活的困頓，在我們迷惑困苦時
&nbsp;
有人為我們指點迷津，讓我們明白前進的方向
&nbsp;
甚至還會有人甘願為你作墊腳石，幫你戰勝苦難
&nbsp;
揚帆遠航，駛向光明幸福的彼岸


&nbsp;
朋友間
&nbsp;
記住別人的好，就會擁有更多的朋友
&nbsp;
夫妻間
&nbsp;
記住對方的好，關係會更加融洽恩愛
&nbsp;
家庭成員
&nbsp;
記住別人的好，這個家庭一定會其樂融融

&nbsp;

記住別人的好，擁有一顆感恩的心
&nbsp;
遠比記住別人的缺點、毛病
&nbsp;
懷著一顆怨恨之心痛苦地生活要強一萬倍
&nbsp;
&nbsp;
&nbsp;既然如此
&nbsp;
我們為什麼不去記住別人的好呢
&nbsp;
因此，我們始終要懷有一顆知恩圖報的心
&nbsp;
永遠記住別人對我們的好
&nbsp;
並在適當的時機回報別人對我們的恩惠
&nbsp;
同時，我們也應當學會擁有一顆仁愛之心

&nbsp;

盡己所能地幫助那些需要幫助的人
&nbsp;
讓更多的人因為我們的幫助而過得更為快樂
