小慧是本人好友,是某大汽車公司的當家台柱

經理有她在一年可多領100多萬

&nbsp;

在她大學時有位同學很喜歡她 常幫她跑腿做事

因為那男的長的有點不像台灣人

&nbsp;

所以她給他一個外號叫(長工)

&nbsp;

古時長工都得打雜,他也不例外


這位長工很小氣又不懂愛屋及烏

&nbsp;

喜歡女生又不會找機會表現

&nbsp;

儘管小慧至今仍未婚也不考慮他

&nbsp;



有一回她要交車去南部

&nbsp;

又不想自已一個人搭高鐵回台北

&nbsp;

因此請長工幫忙她...

在小慧跟客戶點交車時,長工一個人獨自去買了85度C的蛋糕跟飲料吃

&nbsp;

都沒幫我朋友買半樣東西

那天天氣超熱的,交完車之後已經又累又渴,

&nbsp;

長工白目的表現己經讓她氣到半死....

&nbsp;



後來又去辦了好多事,但忙到沒時間用餐

&nbsp;

好不容易忙完也晚上了,長工提議吃薑母鴨,

&nbsp;

因為我朋友超愛吃薑母鴨的,兩人就一邊吃一邊聊著天

突然長工問我朋友為什麼不吃肉

&nbsp;

她告訴他喜歡吃煮久一點的肉,不愛吃硬的

&nbsp;

沒多久她想說肉比較爛了想撈來吃

卻已經都撈不到,因為被長工吃完了

&nbsp;

還問她在撈什麼啊,還說菜剩很多要不要打包...

&nbsp;

她真的好生氣,氣到不想理他...

&nbsp;



因此當場一直發簡訊告訴我這件事

&nbsp;

像這位男士這種與女生相處的模式

&nbsp;

會有女生想嫁給他才有鬼,難怪只能當跑腿的...

&nbsp;
