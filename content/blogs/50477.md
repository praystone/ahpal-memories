感受生活的美



&nbsp;


生活不可能盡如人意，
&nbsp;
總為這些不可能盡如人意的事情生氣，
&nbsp;
是跟自己過不去。
&nbsp;
改換一個角度、觀念去看待造成你不便的人事物，
&nbsp;
以欣賞、享受的心態去接納，
&nbsp;
如此，生活便會少了不悅，而多出歡喜。
&nbsp;
須知，你一時的不便，
&nbsp;
將造就日後多數人的便利，包括你自己。


&nbsp;

生活是靠內在心靈在感受，而非藉外在物質在促成。
&nbsp;
就如一片葉子飄落，你能看它很詩情，

&nbsp;

也能看它很哀愁。
&nbsp;
用包容、豁達的心情看待世事，縱使身處生命的低谷，
&nbsp;
也能覺察、感受人世的美好。


&nbsp;成功的人生，不該著重在物質的成就，
&nbsp;
而該落實在生活的營造。
&nbsp;
汲汲累積財富，全心打拼事業，待走到生命終點，

&nbsp;

回首觀望，是失落了一切？還是收穫良多？


&nbsp;

一名世人認為很成功的實業家，臨終前說了一句話：
&nbsp;
『我這輩子最大的遺憾是，我有這麼成功的事業！』
&nbsp;
事業的成功，

&nbsp;

剝奪了他與親人相處的時間，剝奪了他品味生活的時間，
&nbsp;
剝奪了他接觸許多人事物的時間， 
&nbsp;
剝奪了他一輩子的歲月；以致，
&nbsp;
他的人生空洞到只有一項『成功的事業』。
　
&nbsp;不管你現在是怎樣的心情，怎樣的處境，請檢視你的人生，

&nbsp;

看看你的人生是否少了溫情？
&nbsp;
少了浪漫？少了夢想？少了自在？少了開懷？
&nbsp;
如果是，別在耽誤了，要盡快補充！


&nbsp;

《幸福！一種距離產生的美 》
&nbsp;
一個朋友，喜歡一個人，佔有，是他僅有的方式，

&nbsp;

證明愛的存在。 
&nbsp;
一天，他突然來電，電話裡，
&nbsp;
竟慌張地哭了起來，像個要不到糖的小孩，只有哭，
&nbsp;
才能喚起注意，以為哭，就可以擁有一切。
&nbsp;
沒有多說什麼，只是聽著他的故事，
&nbsp;
聽著他如何百般地呵護她，寶貝她，
&nbsp;
用盡一切心力，
&nbsp;
只為讓她習慣二個人的世界，一定要有他。
&nbsp;
什麼時候，愛情變得如此極端，一個人，
&nbsp;
便能左右你的情緒，茶不思，飯不想，
&nbsp;
就只為對方無心的一句話，便失魂一整天。
&nbsp;


生命重了口味，只剩極端的二邊，
&nbsp;
快樂與不快樂，幸福與不幸福，生氣與不生氣。
&nbsp;
感覺不對了，就後退一步，退到無法忍受的距離時，
&nbsp;
總有一方舉白旗，親密到忘了當初是誰犯的錯，
&nbsp;
不重要，只因愛情裡，不需要標準答案。


&nbsp;

愛，總是讓世界，
&nbsp;
縮到只剩下二個人可以立足的空間，
&nbsp;
卻忘了思索，在你出現前，她的世界曾經擁有過的美麗，
&nbsp;
貪心地只想一個人給她所有的好，
&nbsp;
卻還是讓她痛苦地只想深呼吸一口氣，
&nbsp;
如此的愛，未免驚心動魄，落得只能在得與失中，
&nbsp;
尋求一個平衡點，以為握在手中，就是幸福。


&nbsp;

付出，總是期盼對等的回應。

&nbsp;

朋友氣憤的說，
&nbsp;
對於她，我算是仁至義盡了，什麼樣的好，
&nbsp;
只要是她點頭，我總是沒有第二句話。
&nbsp;
現在可好了，在她身上投資這麼多，
&nbsp;
連我的生命都當了籌碼，如果輸了，
&nbsp;
那真的只剩死路一條了。

&nbsp;

很能明白朋友痛苦的原因，緊握著幸福，
&nbsp;
害怕失去，讓他只能如飛蛾，只有撲火的宿命。

&nbsp;

只是，如果真心愛一個人，害怕的，
&nbsp;
不應該是自己將會失去什麼，而是擔心她會失去什麼。


緊握著的，更不應該是自己的幸福，
&nbsp;
而是她因為你，多了幾分幸福，握在掌心。
&nbsp;


&nbsp;

幸福的人，

&nbsp;

並非是找到生命裡讓自己幸福的人，
&nbsp;
而是作一個讓別人感到幸福的人，這才是真幸福。


放心讓愛情自由的飛翔，每一次的相逢，
&nbsp;
都當成是初次見面般的幸福，只要一點點，
&nbsp;
便足以讓自己開心一整天。


&nbsp;每一次的相逢，都當成是最後一天般的相處，
&nbsp;
你會珍惜到不想把時間浪費在無畏地爭吵，
&nbsp;
每一刻，都將是感動與幸福。
&nbsp;

&nbsp;

最後，贈予朋友一句話，付出，
&nbsp;
就別期待收穫，不期待，便不會有落空的苦痛，
&nbsp;
而擁有的，都將會是驚奇，如此生活，多自在！
&nbsp;
埋了顆幸福的種子在朋友心中，有一天，他一定會懂。


&nbsp;
