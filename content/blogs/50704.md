你耍狠的程度

&nbsp;



&nbsp;

我們生活周遭，常會遇到底下幾種疼痛，

&nbsp;

你個人覺得哪種痛苦是你最無法忍受的？


&nbsp;

&nbsp;

A.牙齒痛

&nbsp;

B.閃到腰的痛

&nbsp;

C.腳抽筋的痛

&nbsp;

D.手麻掉的痛

&nbsp;

E.被愛人傷害的痛

&nbsp;

&nbsp;

解析～


&nbsp;

&nbsp;


選擇A的人～耍狠程度：100%

&nbsp;

你耍狠發飆的程度讓人無話可說！

&nbsp;

不管你的長相是否凶神惡煞或是文靜貌，

&nbsp;

一發起飆來總是氣勢萬千，震攝當場！

&nbsp;

讓人印象深刻，以後當然也不會再隨便招惹你！

&nbsp;

只是你也必須學習控制自己的脾性，

&nbsp;

才不會因為發飆次數多了，

&nbsp;

就把身邊的好友們也一併嚇跑喔。


&nbsp;

選擇B的人～耍狠程度：60%

&nbsp;

你的個性平穩，也不會隨便發怒。

&nbsp;

所以遇到許多不合理的事情，你只會在心中咒罵，

&nbsp;

不會輕易表露出來。

&nbsp;

只是你也很容易去累積自己的情緒，

&nbsp;

時間一久，很可能會因為一件小事發作，

&nbsp;

特別是那種長期讓你不爽的人。

&nbsp;

因為理由正當，所以對方也自然懂得去收斂。 


&nbsp;

選擇C的人～耍狠程度：80%

&nbsp;

你平時自我保護的動作蠻明顯的喔。

&nbsp;

因為心理隔了道牆，所以你不隨便和陌生人打交道，

&nbsp;

也不會主動跟人哈啦，

&nbsp;

甚至也容易因為對方的輕浮或是小玩笑而面有慍色，

&nbsp;

讓人感覺你不好相處。

&nbsp;

只是相處時間久了，你的心房漸開，

&nbsp;

反而讓人直覺你是最罩得住的朋友。 


&nbsp;

選擇D的人～耍狠程度：40%

&nbsp;

你不適合耍狠。因為就連在發飆過程當中，

&nbsp;

你也多所顧忌，不是顧忌對方會從此跟你翻臉成仇，

&nbsp;

就是顧忌對方以後會挾怨報復。

&nbsp;

使得你就算有在正當的理由生氣，

&nbsp;

也會因為你的態度，而讓人不知道錯在哪一方。

&nbsp;

不妨試著以理服人，那可能會變成你的長處。 


&nbsp;

選擇E的人～耍狠程度：20%

&nbsp;

你大概是天底下最不可能發飆耍狠的人了。

&nbsp;

不管你心理到底有多生氣，你幾乎都不會當場發作，

&nbsp;

只會到沒有人的地方發瘋怒吼來宣洩，

&nbsp;

甚至就此把情緒給悶在心裡，默默承受；

&nbsp;

不理人也是你最常用的方法。只是有個適當的情緒宣洩管道，

&nbsp;

這樣你的人格才會健康正常。&nbsp;
