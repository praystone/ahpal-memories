&nbsp;

 
女人一生的愛情語錄

&nbsp;



&nbsp;

&nbsp;


1.不是每個男人都是騎著白馬的王子，

&nbsp;

所以，請不要苛求他不夠高大和英俊，

&nbsp;

不要責怪他送給你的只是一雙手套而不是九十九朵玫瑰。

&nbsp;

寶貝們，要知道，不是王子，你才是他永遠的公主，

&nbsp;

他的愛便是讓你變成公主的水晶鞋。


&nbsp;

2.不是每個男人都能把愛掛在嘴邊，

&nbsp;

所以，請不要

&nbsp;

在他回答「愛不愛你」不夠乾脆時心生懷疑，

&nbsp;

不要讓他把這種回答變成一種無奈的習慣。

&nbsp;

寶貝們，你要學著體會無言的承諾，請相信，

&nbsp;

當他靜靜的看著你微笑自然的牽著你的手時，

&nbsp;

他就是愛你的。


&nbsp;

3.不是每個男人都善於反駁，所以，

&nbsp;

當出現誤會而他卻沉默不語時，

&nbsp;

請不要推開他兀自哭紅了眼睛。

&nbsp;

也許在他看來那只是一個無關的女人

&nbsp;

或者一件他絕不會做的事，他總相信那是事實，

&nbsp;

就不需要太多解釋。寶貝們，

&nbsp;

不要輕易把這份堅持當做一種默認的表示。

&nbsp;

難道，你沒看到他手足無措的樣子？


&nbsp;

4.要知道，你的他不是超人或者蝙蝠俠，

&nbsp;

所以，當他不能在你有困難時第一時間出現。

&nbsp;

請你不要責難他，因為在你無助時不能守在你的身邊，

&nbsp;

那份擔心已經是他最大的懲罰。

&nbsp;

寶貝們，請記住，當他事後關心的詢問時，

&nbsp;

請給予溫柔的回答，告訴他已經沒事了，不要牽掛。
&nbsp;

&nbsp;

5.面子對男子來說比什麼都重要。

&nbsp;

所以，在他的朋友面前，請給他十足的地位。

&nbsp;

如果他在朋友面前忽略了你，不要任性的以為那是不重視，

&nbsp;

也許他只是想顯出你的溫順。

&nbsp;

不要介意在人前當個小女人，寶貝們，要知道，

&nbsp;

那可是被寵愛的女子才有的特權哦。
&nbsp;

&nbsp;

6.也許男人總搞不懂女人在想什麼？

&nbsp;

所以，當你故意說不而他卻真的走開時，

&nbsp;

請不要發誓一定要好好的懲罰他，

&nbsp;

要知道，一頭霧水的他此刻心裡比你還要鬱悶。

&nbsp;

如果你的他總不能領會你的意思，

&nbsp;

那麼，寶貝們，

&nbsp;

就明白的告訴他吧，他會愛的輕鬆許多，

&nbsp;

而你也可以得到你真正想要的，為什麼不呢？
&nbsp;


&nbsp;

7.男人也要有自己的生活。

&nbsp;

他們也會迷戀遊戲，也會想和朋友出去喝酒，打牌。

&nbsp;

這時，請不要短信電話步步緊逼，

&nbsp;

也不要問他為什麼不帶你一塊前往。

&nbsp;

你們自己不也會有女人們私有的空間嗎？

&nbsp;

寶貝們，給彼此足夠的空間才會有新鮮的空氣。
&nbsp;


&nbsp;

8.男人也會脆弱，也會突然的莫名情緒低落。

&nbsp;

所以，當他的臉上寫滿疲憊，

&nbsp;

眼中充滿厭倦，請不要再去追問是不是不愛你了。

&nbsp;

要知道，時刻的討好，誰也做不到。

&nbsp;

寶貝們，此刻，不要再去問他怎麼了，

&nbsp;

只要安靜的陪在他身邊就好。
&nbsp;

&nbsp;

9.總說，男人不懂女人心，可有時候，

&nbsp;

你們不也常常忽略他們的感受？

&nbsp;

有義務陪女朋友，又沒有權利放棄工作。

&nbsp;

在堅強的標誌下，男人們只能把所有的事情一肩扛。

&nbsp;

生活本來就很讓人疲憊，當他為了未來打拚的時候，

&nbsp;

寶貝們，你們不該再讓他們太累。
