&nbsp;

面對你，我只是個小女人，或者只是個小女孩
我沒那麼堅強，即使知道這陣子我們都很忙
但是明知你有出現，卻總是遇不到你、找不到你...我好落寞...
給你的每個訊息、留言
就像石沉大海般
沒有任何回應


親愛的，我真的沒有想像中的那麼堅強...
我知道我們可以一直一直走下去，
但是要一直像這週一樣的生活...

說真的

我會崩潰


是我亂了分寸
是我放錯重心
是我找不到路
是我...是我...

&nbsp;

昨天
5/20 是網路情人節

&nbsp;

今天
5/21是交往兩個月

&nbsp;

我依然獨自一人忙碌

那些甜蜜
不只是過往
更會是未來

&nbsp;

我茫然了
為什麼我突然找不到話題跟你聊
我慌亂了
"為什麼"一直盤旋在我腦海裡

&nbsp;

知道嗎?
這感覺
好像我要失去了你一樣
比失去哥哥
更深更深更深.......的感受

&nbsp;

哥哥，不知道耶
那天，哥哥說你吃醋了
你什麼也不肯說
我心裡甜甜的
你說&nbsp; 你最愛我了
我好開心&nbsp; 好開心

&nbsp;

哥哥說&nbsp; 朋友當這樣
他都不知道說什麼了
最後&nbsp; 他答應不會刪好友
因為我說那是越描越黑
但是&nbsp; 那天之後&nbsp; 他再也沒理過我

&nbsp;

因為哥哥很重視你這個朋友
更甚於我這個妹妹
我跟哥哥&nbsp; 只是朋友&nbsp; 只是兄妹
為了不介入我們之間
所以他走了

&nbsp;

得不到哥哥的回應
只是生氣&nbsp; 難過

&nbsp;

得不到你的回應
是落寞&nbsp; 是傷心&nbsp; 是難過

&nbsp;

的確
我們在一起後
我的淚水變多了
因為我只是個小女孩
我不懂得不知道的太多

&nbsp;

我說 我愛你
你說 妳確定那是愛?不是喜歡?
問你 愛跟喜歡的差別在哪裡?
你不語

&nbsp;

你跟姊姊都叫我不要想太多
可是我是標準的水瓶座
天真浪漫想像力豐富
好啦...
我是天真&nbsp; 沒有浪漫
有想太多的功力&nbsp;&nbsp; 沒有多餘的想像力


知道嗎

如果你現在
給我一則訊息&nbsp; 一個留言&nbsp; 密我即時&nbsp; 給我通電話
我的眼淚就會嘩啦啦的滾下來

&nbsp;

如果
一直都得不到你回應
日復一日&nbsp; 週復一週&nbsp; 月復一月
我的眼淚就會不間段的落下來

&nbsp;

知道這之間的差別嗎
前者&nbsp; 是喜悅的淚水
後者&nbsp; 是悲傷的淚水

&nbsp;

想跟你說的話好多好多好多
但想跟你說再多也沒用
因為你不知道什麼時候才會看到才會知道

能夠跟你相處的時候
有再多再多的話&nbsp; 都沒有話了
因為你在我的身邊了
足 以

&nbsp;

你在身邊
會讓我依靠
為我撫去寂寞傷心的淚水
對不對
