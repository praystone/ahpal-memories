&nbsp;
 
女人最無法接受的五個事實!


&nbsp;

(很毒ㄛ)

&nbsp;



&nbsp;

&nbsp;


關於這五件事，別跟女人們說她們錯了，

&nbsp;

說她們天真或者幼稚。

&nbsp;

雖然她們知道每個女人都這麼想，別的女人都很荒唐，

&nbsp;

但她們還是堅定不移地認為，自己不是別人。


&nbsp;

1.我一定能變瘦

&nbsp;

所有的女人都認為自己會變瘦，

&nbsp;

無論她們現在的身材如何。

&nbsp;

她們去買衣服時常常會念的一句話就是：

&nbsp;

“這件衣服緊一點也沒關係，反正過一段時間我就會瘦下來。”


但事實是，隨著年輪不停滾動搖擺，

&nbsp;

大多數女人不但沒有瘦下來，她們甚至越發肥胖，

&nbsp;

衣櫃裡塞滿了以前能穿可現在已經穿不下

&nbsp;

或者那些以為有朝一日能穿進去的嶄新衣褲。

&nbsp;

無論這個謊言她們已經使用了多少年，

&nbsp;

她們依然不會對其進行懷疑。

&nbsp;

也是，哪有一個女人明知道自己這輩子

&nbsp;

都瘦不下來還有勇氣一直快樂生活呢？

&nbsp;

&nbsp;

2.我不會成為姐妹的八卦對象

&nbsp;

別以為女人只講敵人的壞話。對於八卦，

&nbsp;

女人們不分敵我。即使是其樂融融的辦公室，

&nbsp;

即使是好得穿一條褲子的姐妹三人，

&nbsp;

只要有一個人不在場，她立刻就會成為八卦對象。

&nbsp;

她的男朋友如何如何啦、她的穿衣品味怎麼樣啦、

&nbsp;

她那天和誰誰發生的口角到底是怎麼回事啦，

&nbsp;

都可能成為其他姐妹津津樂道的話題。


她們倒不是有意詆毀你，只不過這是女人們的天性。

&nbsp;

所以，女人們，

&nbsp;

不要天真地以為你和別人說八卦時，

&nbsp;

而你的姐妹們和另一位閨密說私房事，

&nbsp;

而你能夠倖免於難。
&nbsp;

&nbsp;

3.我的老公不會出軌

&nbsp;

女人們時常以為天下烏鴉一般黑，

&nbsp;

唯有自己的老公不會黑。說到誰家老公又婚變了，

&nbsp;

哪天又在街上看到誰男朋友跟別的女人在一起了，

&nbsp;

女人們總是會豁然地說到： 

&nbsp;

這也沒什麼奇怪的，現在的男人不都這樣嗎，

&nbsp;

有本事的男人都偷腥，不偷腥的男人都沒本事。

&nbsp;

但是一但被問到你覺得你老公會出軌嗎？ 

&nbsp;

幾乎所有的女人都會說： 

&nbsp;

我老公是個例外，他不是那種人，他特別老實， 

&nbsp;

他連跟女孩子說話都臉紅，他對我特別忠心……， 

&nbsp;

但如果每個女人的老公都是例外，

&nbsp;

婚外戀到底都是從哪蹦出來的？



4.我比實際年齡顯得小 

&nbsp;

女人們最愛玩的一個遊戲，

&nbsp;

就是讓另一位初識的同性猜自己的年齡。 

&nbsp;

所以，你也一定有這樣的心得，當要求猜別人的年齡時， 

&nbsp;

一定會猜比實際認為的再壓低幾年的年齡， 

&nbsp;

時常，當對方說出實際年齡時，你深呼了一口氣。 

&nbsp;

幾乎所有的女人都認為自己比實際年齡顯得小，

&nbsp;

這已經不是什麼秘密。 

&nbsp;

但是，沒有哪個女人敢讓男人來猜她們的年齡， 

&nbsp;

因為她們發現，男人總是很不客氣地

&nbsp;

猜出甚至比自己的實際年齡還大的年齡。 

&nbsp;

其實，在男人眼裡，沒有22歲和25歲的區別， 

&nbsp;

他們只將年齡區分為女孩、女人、婦女、和老太婆， 

&nbsp;

或者，可以上和不可以上的女人。
&nbsp; 

&nbsp;

5.我的孩子很不凡&nbsp; 

&nbsp;

這世界上本來就沒有多少天才和“很特別”的人， 

&nbsp;

但是所有的母親都認識不到這一點。 

&nbsp;

當女人升格為了人母， 他們便把自己當女孩、

&nbsp;

當老婆時的盲目自信發揮到了下一代的身上。 

&nbsp;

我家孩子早一個月說話、

&nbsp;

我家孩子會模仿某個明星、我家孩子畫畫有多棒， 

&nbsp;

即使這些“出眾”的條件

&nbsp;

完全達不到生理學和心理學上的顯著水平， 

&nbsp;

所有的母親都還是會覺得自己的孩子很不凡。 

&nbsp;

這應驗了心理學當中的“過分自信”理論， 

&nbsp;

絕大多數的人都認為自己處於平均水平之上， 

&nbsp;

如果大家真的都處於平均水平之上，

&nbsp;

那平均水平又是什麼呢？ 

&nbsp;

所以，如果平凡人偏多，你的孩子很可能也普通得要命﹔ 

&nbsp;

如果大多數男人都不老實，你的老公可能也並不安分守己。 

&nbsp;

自信不是壞事，但是不要用過分自信來掩蓋事實真相，
&nbsp;

&nbsp;

姐姐妹妹們啊 是該醒醒的時候了，

&nbsp;

不然等到災難降臨，你可能是崩潰得最直接的一個。
