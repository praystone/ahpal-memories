朗誦比賽 


&nbsp;

一天小英去參加朗誦比賽弄到很晚才回家，

&nbsp;

一進家門父親就很嚴厲的責問她：為什麼這麼晚才回來 ? 

&nbsp;

小英很累所以不耐煩的回答說：朗誦啦！ 

&nbsp;

父親聽了之後更生氣的說：人爽（台語）？

&nbsp;

妳在爽啥咪？！ 

&nbsp;

&nbsp;

很厲害的學生 


&nbsp;

大學有一門哲學課，期中考時教授在考卷出了一道題目：

&nbsp;

「何謂勇氣？」


&nbsp;

大家還在思考時有一位同學第一個交卷 

&nbsp;

空白的答案卷上寫了一行小字「這就是勇氣！」 
&nbsp; 
氣急敗壞的教授在期末考又出了一道題目「這就是題目」 

&nbsp;

不一會那同學又交了卷答案卷上寫「這就是答案」 

&nbsp;

教授很生氣把那位同學找來說： 

&nbsp;

「給你兩個問題，答對第一題第二題就不用回答，

&nbsp;

這學期 也不當你了！」
&nbsp;

教授：「第一題，你有多少根頭髮？」 

&nbsp;

學生：「1億2 百零5根」 

&nbsp;

教授：「你怎麼知道？」 

&nbsp;

學生：「此題不用答」 

&nbsp;

這件事傳開之後，國文老師自告奮勇的跳出來出題...... 

&nbsp;

他出的國文題目是這樣的： 
&nbsp;

〈.........〉之謂〈.........〉 
&nbsp;
〈.........〉之謂〈.........〉 
&nbsp;
〈.........〉之謂〈.........〉 
&nbsp;
〈.........〉之謂〈.........〉 
&nbsp;
此四者〈...............〉也。 
&nbsp;

考試結束，

&nbsp;

大家都花了半小時以上，卻發現他還是一下子就寫完了！
&nbsp;

他的答案就是 ........ 

&nbsp;

〈愛〉之謂〈菜心〉 
&nbsp;
〈愛〉之謂〈脆瓜〉 

&nbsp;

〈愛〉之謂〈麵筋〉 
&nbsp;
〈愛〉之謂〈土豆〉 
&nbsp;

此四者〈稀飯之必備〉也...

&nbsp;

笨蛋基因會遺傳的

&nbsp;

&nbsp;

警車追逐一輛超速又橫衝直撞的小客車，

&nbsp;

終於追到路邊給攔了下來！
&nbsp;

警察：先生，你開那麼快，知道要被罰多少錢嗎？

&nbsp;

這些錢能用來做多少事，你知道嗎？

&nbsp;

駕駛：我知道，它夠讓我去補習考駕照了！

&nbsp;

警察：什麼！你無照駕駛？
&nbsp;

&nbsp;

就在爭論的時候，駕駛的老婆趕緊下車﹏﹏﹏

&nbsp;

老婆：長官，抱歉抱歉，他就是這樣，

&nbsp;

喝了點酒就亂說話，你可別認真啊！ 

&nbsp;

警察：啊！無照外還酒後駕車！好好好，來做個酒測！
&nbsp;

此時後座的老太太被這一陣交談給吵醒，悻悻然下車﹏

&nbsp;

老太太問：幹麼那麼吵？

&nbsp;

駕駛：媽，沒事沒事！車開太快被警察攔下而已。

&nbsp;

老太太：不是早叮嚀你，偷來的車別開太快嗎？
&nbsp;
警察：「＊＃☆※△﹏﹏﹏！」
