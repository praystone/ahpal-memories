&nbsp;

&nbsp;

 
美 麗 人 生

&nbsp;



&nbsp;

&nbsp;


人生 是一個過程，

&nbsp;

可悲的是，它不可以重新來過，

&nbsp;

可喜的是，它也不能重頭來過！

&nbsp;

在這趟名為人生的列車上，

&nbsp;

就算我們花再多的錢 也買不來回程的票，

&nbsp;

所以，我們一定要竭盡所能的讓它變得更加的美麗！


&nbsp;

在這個物欲縱橫的現代都市叢林中，

&nbsp;

種種的壓力，我們看到了越來越多悲觀厭世的人

&nbsp;

於是，無形中：活得真累啊，

&nbsp;

便成了許多人的口頭彈。累啊。。累啊。。

&nbsp;

這樣的人生，待到風燭殘年之時再回首所走過的路，

&nbsp;

又何來的美麗呢？我想除了遺憾，也還是遺憾吧！


&nbsp;然而，活在世態如此炎涼的當下，

&nbsp;

又怎麼可能使人生了無遺憾呢？也許我們無力做到事事完美，

&nbsp;

也無能給自己制定出最完美的人生計畫，

&nbsp;

但我們一定可以試著給自己一份美麗的心情！


&nbsp;

常言道：長得漂亮不如活得漂亮！

&nbsp;

的確，一趟漂亮的人生旅程，

&nbsp;

一份貫穿著整個歷程的美麗心情，

&nbsp;

一定可以普寫出精彩的傳奇來！而那些傳奇裡，

&nbsp;

當走過人生的終點站，也許就不會有過多的遺憾，

&nbsp;

不會有過多的抱怨，更不會有整段整段空白無緒的記憶，

&nbsp;

有的-------全是身後美麗的片片足跡和那一份美麗的心情！


&nbsp;四季的輪回，在那些美麗足跡的裝飾下，

&nbsp;

會是一幅充滿詩情畫意的人生之畫！


&nbsp;儘管，四季的風花雪月總會讓人不堪憔悴，

&nbsp;

世事的紛亂，滾滾紅塵又總是會磨礪著我們每一個人的心，

&nbsp;

&nbsp;

但是，陽光就在窗外，

&nbsp;

當我們帶著美麗的心情去丈量時光流轉的痕跡，

&nbsp;

去感受季節輪回的腳步，去和我們的人生約會，

&nbsp;

那麼美麗，也就一定會擁抱我們的人生！


&nbsp;
