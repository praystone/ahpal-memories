越是熟的朋友，對話就越粗魯；

&nbsp;

越是熟的朋友，行為就越猥瑣； 

&nbsp;

越是熟的朋友，開玩笑就越不計較；

&nbsp;

越是熟的朋友，你出來玩就越是要管你； 

&nbsp;

越是熟的朋友，見面少了就越思念； 

&nbsp;

越是熟的朋友，你一有錯他就越毫不留面地罵你； 

&nbsp;

越是熟的朋友，不開心時他想起的第一個人就越是你。 &nbsp; 

&nbsp;

如果是朋友、請不要在我面前偽裝；

&nbsp;

如果是朋友、請不要在我面前逞強； 

&nbsp;

如果是朋友、請不要背叛我； 

&nbsp;

如果是朋友、請不要做對不起我的事； 

&nbsp;

如果是朋友、請不要在你需要幫助的時候不向我開口； 

&nbsp;

如果是朋友、請不要在你寂寞的時候怕打擾我而一個人傷心； 

&nbsp;

如果是⋯⋯朋友、請不要對我說：我害怕有一天你會離開； 

&nbsp;

如果是朋友、請不要對我說不正當的話； 

&nbsp;

如果是朋友、請不要一個人喝悶酒； 

&nbsp;

如果是朋友、請不要一個人躲在被子裡哭泣； 

&nbsp;

如果是朋友、請不要說一些要輕生的念頭； 

&nbsp;

如果是朋友、請不要覺得沒人在乎你； 

&nbsp;

如果是朋友、請不要做一些傻事； 

&nbsp;

如果是朋友、請相信，我會記住你。&nbsp;&nbsp; 

&nbsp;

在我面前、你沒有偽裝的必要、沒有逞強的需要。 

&nbsp;

朋友是一輩子的事。 不管什麼時候，你感到難受，

&nbsp;

不要一個人去承受，請你相信我、我陪你！ 

&nbsp;

在你需要幫助或想找人傾訴的時候，找我、我幫你！ 

&nbsp;

在你想哭的時候、找我，我給你肩膀！ 

&nbsp;

在你不爽想喝酒的時候、找我，我陪你耍酒瘋！ 

&nbsp;

在半夜寂寞的時候、找我，我陪你說話！ 

&nbsp;

在你覺得沒人相信的時候、找我，告訴我、我信你！
