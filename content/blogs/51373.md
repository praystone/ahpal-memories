你犀利嗎？


又是在哪方面非常犀利呢？


&nbsp;

是人氣還是事業？

&nbsp;

快一起來測驗看看吧～ 

&nbsp;

請憑直覺從下列4組數字中選出1組

&nbsp;


 
分析～


&nbsp;


◆選A的人～人氣犀利 

&nbsp;

你的人緣很好，是天生社交專家，能言善道 

&nbsp;

讓你無往不利，無論如何打扮，都能流露自信魅力，

&nbsp;

人氣指數很高。你雖迷糊，卻讓人覺得很好親近，

&nbsp;

會藉由別人讚許肯定自我價值，因怕失去舞台的落寞感，

&nbsp;

反而花很多精神蒐集掌聲，來鞏固人氣寶座。 


&nbsp;

◆選B的人～事業犀利 

&nbsp;

你是個工作狂，具有活躍的思維和強烈的好勝心，

&nbsp;

總是把滿腦子創意發揮得淋漓盡致，

&nbsp;

常有傑出的表現，更充滿刻苦耐勞的精神，

&nbsp;

為了賺錢，拜訪客戶，要你走遍天涯都在所不惜，

&nbsp;

只要可以獲得上司賞識，

&nbsp;

多苦都願意，實在是老闆眼中的最佳員工。 


&nbsp;

◆選C的人～健康犀利 

&nbsp;

你是個身體健康的人，不太容易生病，

&nbsp;

但卻在乎心理層面的滿足，因此很會規劃自己的休閒生活，

&nbsp;

並徹底利用出遊的機會放鬆身心、

&nbsp;

好好充電一番，只要生活作息不要太混亂，

&nbsp;

基本上還是一尾活龍，整個人元氣滿點，十分有活力。 


&nbsp;

◆選D的人～愛情犀利 

&nbsp;

愛情至上的你，為愛走天涯的機率相當高，

&nbsp;

很懂得經營感情的走向，忠誠度也很高，

&nbsp;

不在乎對方付出多少，每當要做出抉擇時，

&nbsp;

會馬上揹起包袱與情人遠走高飛！

&nbsp;

這種沒有愛情就會死的感覺，遇到心儀對象，

&nbsp;

會義無反顧的付出，只為了和他在一起。
