&nbsp;




&nbsp;愛的方式 

&nbsp;



&nbsp;

&nbsp;


我們常常用自己的方式去愛自己所愛的人，
&nbsp;
包括男女朋友，丈夫、妻子和孩子以及

&nbsp;

身邊所有你最愛的人你總以為自己很愛很愛對方，

&nbsp;

這麼說、那麼做都是為了她(他)好 
&nbsp;
但，這未必是他們所喜歡所能接受的生活方式，
&nbsp;
也許照著你的方式走，也許照著你的規定做，
&nbsp;
她一定是你最愛的人，你才會規定這麼多，給的壓力這麼重，
&nbsp;
無形之中，你的愛給了他們壓力，也給了他們痛苦。
&nbsp;

&nbsp;

你真的愛他嗎？
&nbsp;
愛她--就是給她關懷，就算她（做錯了什麼）
&nbsp;
關懷總比指責來得有用，用你的真心聆聽她的內心
&nbsp;
知道她想什麼？知道她要什麼？
&nbsp;
在她心情不好時，

&nbsp;

你的陪伴和支持，是她最大的安慰和精神支柱


&nbsp;

你真的愛她嗎？你愛一個人一定希望她快樂
&nbsp;
不希望她滿臉倦容、滿心憂愁
&nbsp;
在她歡欣鼓舞的時候，看著她那可愛的模樣
&nbsp;
洋溢著歡笑、幸福，你是不是也覺得很滿足，
&nbsp;
甚至比他更快樂、更幸福？
&nbsp;
懂得欣賞也是一種愛的表現方式，

&nbsp;

你必須摒除自我，用欣賞的角度，
&nbsp;
看待你身邊每一個你愛的人和每一事物
&nbsp;


男女之間的感情瞬息萬變
&nbsp;
前一分鐘才一起開心甜蜜，後一秒鐘就吵架分離…
&nbsp;
喜歡一個人…有可能隨時會改變
&nbsp;
當初的吸引，

&nbsp;

有可能過了一陣子，會覺得不如想像中的美好，
&nbsp;
&nbsp;
愛情，很難說誰對誰錯，
&nbsp;
在結婚之前，每個人都有選擇的權利和自由
&nbsp;
愛情沒有保證書，太過小心、

&nbsp;

太過憧憬或期望過深，都不是一件好事
&nbsp;
但…若沒有真心投入，

&nbsp;

又怎麼會知道你們是不是王子與公主
&nbsp;
在戀愛初期，

&nbsp;

對什麼事都充滿好奇，一點點愛意就感覺甜蜜
&nbsp;
但是，你不可能每天都100%的沉浸在愛情的世界裡
&nbsp;
生活中還有很多重要的事情要處理，
&nbsp;
生活中也難免有小插曲，浪漫歸浪漫，現實畢竟是現實
&nbsp;

兩個來自不同環境的獨立個體，觀念、想法不一
&nbsp;
因為愛，相遇，相知，而相惜需要更多的包容和學習
&nbsp;
吵架的時候，多想想對方的好
&nbsp;
生氣的時候，多用溫柔來代替
&nbsp;
可是…如果你愛的是一個不值得你愛的人，
&nbsp;
那麼…這些體諒都會成了你日後的委曲
&nbsp;
有句話說：『因為誤會而結合，因為了解而分開…』
&nbsp;


所以，愛情沒有保證書，
&nbsp;
它來的時候，可能不知不覺的發生，
&nbsp;
要走的時候，可能不是你哭天喊地所能挽留
&nbsp;
感情不是東西，不能用度量衡來算計
&nbsp;
我這樣對你，你也必須這樣對我才可以，
&nbsp;
愛一個人最好的方式是關懷也是付出
&nbsp;
不是佔有，也不是要求，你會希望他快樂，希望他幸福…
&nbsp;
天冷了...要多加點衣服，下雨了…要記的攜帶雨具

&nbsp;

累了….要記得多休息，生病了，讓我多關心你

&nbsp;

有好吃的東西….我會買給你，做什麼事情都會想到你
&nbsp;
&nbsp;
那是因為，你的柔情感動我的心，
&nbsp;
讓你駐留在我心底，使我不知不覺的想你
&nbsp;
『溫柔』

&nbsp;

就是感情最好的潤滑劑在賽程中，如果你太過自我、

&nbsp;

不夠努力，那麼，拔得頭籌的人，肯定不是你… 


&nbsp;
