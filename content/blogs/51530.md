&nbsp;


海天未成雲雨&nbsp;&nbsp; 這藍 

&nbsp;

太深沉

&nbsp;

如果背對著

&nbsp;

如果闔上眼

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 戀妳

就可以不想&nbsp; 

&nbsp;

太好了

&nbsp;

這聲音太甜

&nbsp;

這眷戀太黏

&nbsp;

這濕潤太稠

&nbsp;

這愁緒太苦

&nbsp;

這眼淚太澀

&nbsp;

這夜寂太靜

&nbsp;

這寒露太重

&nbsp;

月華如練&nbsp;&nbsp; 忍更思念太碎

&nbsp;

濁酒一杯&nbsp;&nbsp; 燈滅怎勘由醉&nbsp;&nbsp;

&nbsp;

人不寐&nbsp;&nbsp;&nbsp;&nbsp; 淚枕三更雨

&nbsp;

妳已睡！
