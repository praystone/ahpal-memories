不計較與不比較 

&nbsp;



&nbsp;

&nbsp;

&nbsp;


每個人一生中都要信兩種教，

&nbsp;

你 知道是什麼教嗎....? 當然不是睡覺 .....^.^

&nbsp;

是 不計較與不比較 .....

&nbsp;

人活著都會有許多的慾望，慾望多了，漸漸會慾求不滿，

&nbsp;

到最後就演變成為了滿足自己的慾望而去傷害別人 ...


&nbsp;

如果我們凡事不與人計較，

&nbsp;

便不會有口角，也不會勾心鬥角，

&nbsp;

如果我們凡事不與人比較，

&nbsp;

便不會有慾望，也不會慾求不滿，

&nbsp;

因此我們做人要謙虛，要知足，更要惜福 ....

&nbsp;

&nbsp;

我們要把自己縮小，不斷的縮小自己，

&nbsp;

小到能將自己放入別人眼中，

&nbsp;

因為眼裡是容不下一顆沙子的，倘若能將

&nbsp;

自己縮小到放入別人眼中，讓別人都能接納你，

&nbsp;

這樣才是真的會做人，

&nbsp;

世界這麼大，每個人都有他的過人之處，

&nbsp;

如果我們不懂得縮小自己，

&nbsp;

只是一味的覺得自己比別人厲害，這樣永遠都不會成功，

&nbsp;

永遠都不會滿足，也永遠都不會快樂 ....

&nbsp;

&nbsp;

因為一山比一山高，所以不要去和人家比較，

&nbsp;

這不是要你因此不求上進喔 .....，是要你懂得謙虛 ..

&nbsp;

而是要你將心放大，去包容每一個人，

&nbsp;

從家人，朋友，甚至陌生人 .....

&nbsp;

也許我解釋得不是很好，但我體會很深 ....

&nbsp;

如果每個人都能有所體悟，都能放寬心，

&nbsp;

相信都會過得很快樂 .....
