&nbsp;

&nbsp;
 
人生情懷


&nbsp;



&nbsp;

&nbsp;


願你的人生擁有這樣的情懷，

&nbsp;

永遠不要因為工作的繁忙而忘記你的周年紀念日，

&nbsp;

生活中每一個特殊的日子是你人生積累的最大財富。


&nbsp;

經常讓你視野中的某些事物保持美麗，

&nbsp;

即使它只是插在一個果醬瓶中的一朵雛菊花。

&nbsp;

把你的手錶撥快五分鍾，無論做什麼事情，

&nbsp;

比別人搶先一步，為自己多贏得一點時間來準備。

&nbsp;

&nbsp;

冒險就是風險。

&nbsp;

如果你從不曾冒險，也就不會有成功的風險。

&nbsp;

在冒險中尋求成功的人生吧！


&nbsp;

用你最喜歡的音樂開啟每一天。

&nbsp;

音樂是心靈的歌唱，在每天清晨放飛心靈，憧憬美好明天。


&nbsp;

當有了分歧的時候，不管是誰的錯，

&nbsp;

首先道歉說：

&nbsp;

「對不起，惹你生氣，你能原諒我嗎？」

&nbsp;

這是消除分歧的靈丹妙藥。


&nbsp;

不要顧影自憐，當這種感情襲來的時刻，

&nbsp;

為那些處境比你更不幸的人作一點好事。

&nbsp;

幫助別人可以忘卻自己的不幸。


&nbsp;

不要害怕說「對不起！」。

&nbsp;

對別人真誠地致歉往往能贏得別人的尊重，

&nbsp;

磊落的胸懷是快樂人生的源泉。


&nbsp;當有人擁抱你時，讓對方最先離開你的懷抱。

&nbsp;
