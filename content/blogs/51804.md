星座中最真實的射手座（射手座必看）

射手快樂嗎？射手會背叛感情嗎？&nbsp; &nbsp;
流過的淚比誰都多，受過的傷比誰都痛，&nbsp; 愛過的人一生一世，只是沒人能懂...&nbsp; &nbsp;
每個射手都能這里看到自己的影子,&nbsp; 為終于有人了解自己而感動 
——一個真實的射手座! &nbsp;
射手總是喜歡說謊--善意裝飾的謊言，快樂和開心背后的謊言，&nbsp; 
代替真實的謊言，留給別人掩蓋悲傷的謊言，&nbsp; 卻把真實留給謊言背后的自己…&nbsp; &nbsp;
一個欺騙的快樂角色，看似正常而幸福&nbsp; &nbsp;
可事實卻是扭曲而黑暗！&nbsp; &nbsp;
天使與惡魔的完美組合---極端的完美也是極端的扭曲。 
射手會冷-像冰；射手會熱-像火；&nbsp;&nbsp; &nbsp;
兩種極端在射手身上不停的相互自我折磨著…&nbsp;&nbsp; &nbsp;
一旦射手碰上自己不想談論,不想說起的事&nbsp;&nbsp; &nbsp;
就會掩飾--完美的掩飾！比正常軌道還要正常的掩飾！&nbsp;&nbsp; &nbsp;
射手--天生的演員！！！ &nbsp;
射手也會害羞,也會搖擺&nbsp;&nbsp; &nbsp;
有時嘴里說出來的並不一定就是自己所想的&nbsp;&nbsp; &nbsp;
射手會隱瞞--隱瞞一些思想，一些想法&nbsp;&nbsp; &nbsp;
但這卻不是說謊的欺騙，而是想把快樂帶給別人的表現，&nbsp;&nbsp; &nbsp;
--也是保護自己的做法。 &nbsp;
和射手真正的溝通你會發現： &nbsp;
→射手並不像表面看上去那麼的快樂,充滿了無限的熱情 &nbsp;
射手有著天生的演技而世人也總會被這表面的假象所蒙住眼睛。 &nbsp;

射手是溫柔的 快樂的 悲傷的 堅強的...... 喜歡？ 
那就去真正看清他〈她〉吧！ 
射手也許是不夠勇敢，但絕對堅強； &nbsp;
從來都不是經不起考驗，只是往往當考驗來臨時 &nbsp;
那個平時粘得自己不能自由呼吸的人卻沒有緊緊抓住自己的手！ 
從來都不是飄忽不定，而是有著屬于射手特有的執著 &nbsp;
放手，不代表愿意放棄！--更不代表放棄愛一個人的執著。 &nbsp;
又有誰知道他〈她〉也會悲觀的看不清前方？也會--需要鼓勵？ &nbsp;
射手會把悲傷藏在心里，不會表現絲毫 &nbsp;
而別人只會被他〈她〉的堅強所蒙蔽而無法真正看清他〈她〉 &nbsp;
射手就是懶,懶得去管別人的事, &nbsp;
卻總在不經意間就為自己在意的人不顧一切..... &nbsp;
射手就會裝,明明軟弱卻抬頭歡笑, &nbsp;
把一切的辛酸眼淚全留給自己...... &nbsp;
射手就是犟,打死不愿承認自己的傷和痛, &nbsp;
面對人群時展現的永遠都是開心和快樂...... &nbsp;
射手就是牛,騙過一切的人,讓全世界以為我們是快樂的!! &nbsp;
但事實卻......... &nbsp;
哎~~說到底，也只有射手才能真正了解射手~~ &nbsp;
射手總想讓身邊的一切人事物都開心 但怎麼可能會讓所有人都開心呢？ 
做不到。 &nbsp;
于是，射手就會變得悲傷---看身邊的人難過自己也會感傷。 &nbsp;
射手敏感 善良 心細 溫柔， 射手不喜歡抱怨，不喜歡計較， &nbsp;
即使委屈自己 傷害自己 &nbsp;
也還是想讓他人開心，還是不想傷害別人 &nbsp;
射手就是這樣--再多的苦水也只往肚子里咽，不會說出來。 &nbsp;
嘴上始終都掛著微笑，讓別人認為還是他〈她〉很開心 &nbsp;
射手不想讓人看到自己的悲傷不快樂， &nbsp;
因為射手想把最好的分享給大家，帶給身邊的人。 
與射手相愛是幸福的---他（她）會給你全世界最真最多的愛， &nbsp;
用心去了解他（她）吧！是善良的 溫柔的。 &nbsp;
射手值得去愛！ --不要傷害他（她），不要離開他（她） &nbsp;
更不要輕言放棄他（她）！ &nbsp;
不然你就會失去這個可以放棄全世界來愛你的人。 &nbsp;
射手的沉默 無言 微笑 &nbsp;
其實就是在掩蓋世人的眼睛 &nbsp;
一種變相的欺騙 &nbsp;
射手的微笑 &nbsp;
其實是別人無法鄰近射手的心 &nbsp;
他（她）在以此作自我保護 。 &nbsp;
只有自己知道自己的射手帶著只有自己知道的快樂和悲傷 &nbsp;
射手所走的路---只有自己才看得見！ &nbsp;
既然不會了解 不會理解 &nbsp;
那麼即使說了也只會是徒增傷害 &nbsp;
&nbsp; 射手會很容易相信別人，于是很容易被騙， 
雖然很容易的就原諒別人，卻會在潛意識里留下很多傷疤。 &nbsp;
也許射手會淡忘這些傷痕，不再提起。 &nbsp;
可是不提起不代表沒有受過傷，不代表不會有疼痛。 &nbsp;
一直以來射手背負的傷痕已經夠多了，不想再有所增加！ &nbsp;
射手從不想給別人增加負擔，因為射手可以感覺別人的悲傷。 &nbsp;
射手會很容易相信別人，于是很容易被騙． 
雖然很容易的就原諒別人，卻會在潛意識里留下很多傷疤。 &nbsp;
也許射手會淡忘這些傷痕，不再提起。 &nbsp;
可是不提起不代表沒有受過傷，不代表不會有疼痛 &nbsp;
---不是不傷心， 只是未到傷心處。這些擦不掉看不見的傷痕 &nbsp;
即使淡忘，還是會隱隱做疼，碰觸時還是會流血。 &nbsp;
當然會累，可即使如此，還是要繼續 &nbsp;
因為-- 這是天生的注定的。 &nbsp;
看不見射手的真實，只是無法臨近射手的心…. 
你是射手座的嘛？我是，所以我莫名的傷感。 &nbsp;
是的，傷感！--可，誰讓我們是射手呢？ &nbsp;
如果說每個星座都代表一樣東西，那麼，射手代表的就是--希望。 &nbsp;
不論生死，情感，物質，精神，只有懷著希望才能繼續。 &nbsp;
于是，射手在這樣的使命中，漸漸只讓別人看見燦爛的笑。 &nbsp;

身邊熟識的朋友會抱怨說：認識久了，發現- &nbsp;
--其實你並不快樂，一點都不像表現的那樣好接近。 &nbsp;
我想，或許這就是射手的偽裝吧！不愿讓陌生人看到自己的軟處。 &nbsp;
不過還好，其實有很多人都見過射手寶寶的眼淚。。 &nbsp;
因為，射手大都擁有很多的朋友，每個朋友都是可以說心事的知己。 &nbsp;
同樣的，看見掛滿淚珠還保持微笑的射手，也未償不是一種鼓勵。 &nbsp;
不熟悉的人，總喜歡對我說：真羨慕你啊，天天嘻嘻哈哈，沒有一點煩惱。 &nbsp;
每當聽到這類似的話時，我就明白---我又要當一回傾聽者。 &nbsp;
能看到射手哭泣的人，應該都是射手十分親近的人。 &nbsp;
因為，那代表著射手全部的信任。 &nbsp;
&nbsp; 射手真的喜歡在人群中引人注意嗎？ &nbsp;
其實更多的時候，覺得自己是一個低調的人---不同于別人的低調。 &nbsp;
對別人來說，不炫耀，不高聲說笑，整天低眉順眼，不聲不語才叫低調。 &nbsp;
射手的低調不同，射手的低調只是為了掩飾。 
當一個射手高聲大笑時，可能剛剛經曆了一場傷痛，正借機發泄！ &nbsp;
這樣的事情我常常做。 
傷著了？那就不讓自己靜下來，找一大群人，放肆的吵鬧… &nbsp;
或是獨自走到熱鬧的街，讓滿街的喧器掩蓋滿心的孤寂… &nbsp;
或者找一個自己最信賴的朋友，一聲不坑，卻在他〈她〉身上任意揮灑眼淚 &nbsp;
大部分的時候，射手能做的就是努力的深呼吸，背過臉去擦掉淚 &nbsp;
然后，笑著告訴所有的人不疼---一點都不疼。 &nbsp;
最慘的是別人不信，會跑過來再打兩下…哈哈 
有些事，不忘記又能怎麼辦？ 要堅強，就不能壓抑，--不壓抑，就要會忘記。
&nbsp;所以，每個射手寶寶都有健忘癥。 &nbsp;
再堅強的射手內心也是孤獨的。 &nbsp;
沒有人能陪哄自己一輩子，所以射手會珍惜所有的朋友。 &nbsp;
做射手的朋友其實很難。 &nbsp;
很多人都是被射手熱情的笑聲吸引而來，可惜射手本身也有自己的懦弱。 &nbsp;
當你想看透射手臉上的陽光時，他〈她〉---卻選擇了逃避… &nbsp;
很多的朋友都說我善變，身邊人大都被我有意無意的傷過。 &nbsp;
他〈她〉們被我滿臉的陽光吸引，走近了卻發現我其實沒有想象的陽光。 &nbsp;
于是，有人離開，有人留下， &nbsp;
離開的人活在射手記憶里，不再提起，卻久久不能忘記… &nbsp;
留下的人成了射手真正的朋友，從此兩肋插刀，融化了看似堅硬的冰。 &nbsp;
射手的朋友都是知己，一點也不夸張。 &nbsp;
所有人都說射手花心，那麼怎樣才叫癡心？ &nbsp;
也許人們心中只有時間才能評定一段感情是否完滿。 &nbsp;
射手活著，就是為在尋找----穿過時間和空間去找那個拿著另一半蘋果的人… &nbsp;
射手絕對不會對自己不喜歡的人花言巧語 更不會為其它而放棄真愛。 
所以當射手愛上你的時候，不用懷疑--你已經成為世界上最幸福的人。 &nbsp;
只要給射手絕對的信任，射手會還給你最浪漫最溫暖的一生。 &nbsp;
只是…很少人能讓射手愛上。 &nbsp;
敏感的射手會察覺到對方任何一絲的動搖。 &nbsp;
射手要的愛情是最簡單的。 
不用金錢，權勢，相貌等等世俗條框。 &nbsp;
只要讓我知道，任何時候你都信任我，愛我！ &nbsp;
那麼就算是刀山火海我也陪你！ &nbsp;
這樣的誓言有幾個射手立過？ &nbsp;
不是射手不負責任，不敢承諾， 而是…有幾個人值得？ 
不相信感情的射手，是因為看了太多悲愴，為成全愛情而選擇流浪… 
微笑，矛盾，憂郁，希望，尋找，孤獨，堅強，樂觀，睿智才是真的射手！ &nbsp;
永遠有憂郁的灰色纏繞在三月的陽光中， &nbsp;
---讓別人看到希望，讓自己尋找答案
