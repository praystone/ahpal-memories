愛情來的時候，悄無聲息，我沒有想過它是怎麼來的，

為什麼我會愛上這個人或是他會愛我什麼，

我只願意享受每一個甜蜜的時刻。


愛情去的時候，仍悄無聲息，

&nbsp;

我一次次地想它是怎麼去的，

為什麼我仍在愛他而他卻不再愛我，

&nbsp;

到最後也想不明白，于是悲痛欲絕。

&nbsp;

女人總是敏感、脆弱的，

&nbsp;

所以為愛情而受傷的總是女人居多。


&nbsp;

男人其實比想像中的堅強，也現實的多，

&nbsp;

所以男人總是很容易從失戀中走出來，

&nbsp;

唯有女人，戀愛時像傻瓜，

&nbsp;

失戀了更像傻瓜，她的傷似乎很難復原。

&nbsp;

其實愛情真的是一個奇妙的東西，

&nbsp;

愛上一個人的時候，就覺得他是全世界最好的，

&nbsp;

所謂情人眼裡出西施。

一個不愛的人，即使他再優秀，

&nbsp;

你再去努力卻也很難真的愛上他，

除非是你妥協了，那不是真正的愛情。


&nbsp;

有人說，時間可以淡化傷痛&nbsp;&nbsp; 

&nbsp;

也可以淡化對一個人的感情。


&nbsp;

傷痛確實是可以淡化的，

&nbsp;

如果你還痛，那是因為時間不夠久，

而愛情，是絕不會隨時間的流逝而淡去的，

如果淡去了那就不是愛情，

這個世界也不會有關于愛情的千古絕唱

活在這個世界上的就應該知道，

生活是現實的，而現實是殘酷的，

所以很多時候，當愛情遠去，

&nbsp;

我們唯有放手。

然後因為寂寞，因為親人，

&nbsp;

或僅僅是因為某個瞬間的衝動，

我們選擇了另外一個人。

&nbsp;

一生中能夠愛上的人很少，遇到的人會很多，


&nbsp;

但真正適合或者說合適的人，只會有一個。

當你不再感到孤獨，疼痛，雖然也沒喜悅或是心動，


&nbsp;

那就好好珍惜身邊的那個人吧，

&nbsp;

其實這才是上帝原本的安排


&nbsp;

你曾經愛上的或曾經愛你的，

都不過是平淡的人生中一點點特殊的風景而已，

走過了就不會再回來，前方的路還很遠，

人生原本平淡，所以要有平淡的心情。
