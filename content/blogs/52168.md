&nbsp;

&nbsp;

 親愛的，你怎麼不在我身邊？

&nbsp;



&nbsp;

&nbsp;


窗外，靜寂

&nbsp;

親愛的，你怎麼不在我身邊？

&nbsp;

聽著那旋律，心又一次被拽的又沉又遠

&nbsp;

思緒又一次重的掂不起來，真的是無法解脫夜空，

&nbsp;

冷霧散開，淡淡月光彌漫想你，在這不經意間

&nbsp;

&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？

&nbsp;

一曲歌又讓我沉入記憶之淵遙遙灑向塵世間，

&nbsp;

沉沉的夜空把我們分割兩地間

&nbsp;

一切美好的神秘被掩遮得無處尋覓


月亮也在一池清水中沉澱

&nbsp;

古人把月亮在夜寫含蓄文字和淚水

&nbsp;

不敢暴露於曉風之中，走過了多少年輪相加的圓

&nbsp;

卻沒有迎來秋夜秋風秋雨月光如語，

&nbsp;

風你撐開心胸為誰扇動永遠的心事

&nbsp;

&nbsp;

此刻，我靜靜坐下，多少次

&nbsp;

我就是這樣期待風送我遠航

&nbsp;

或許我的期待早已化作淡淡的風飄遠了

&nbsp;

可我仍然捧著心中的希望在苦苦的求索

&nbsp;

好想生活的清泉能賜我少許的幸福伴我一生一生。

&nbsp;

四季循環，永久停留掩卷沉思，心中有許多的光亮在湧動

&nbsp;

&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？

&nbsp;

我不敢說，這是一個多感的季節

&nbsp;

從一片落葉開始,我已溶入深遠的啟示

&nbsp;

思念，常取於什麼？我不知道

&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊?

&nbsp;

思念的歌聲飄蕩，迷不清歲月癡迷破碎的詩心

&nbsp;

你那一雙感動的雙眼，就像一季江南雨

&nbsp;

總是滴著思念

&nbsp;

一聲問候，如那一季的秋陽，滿天滿地鋪灑著溫馨


&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？

&nbsp;

你知道的，我徬徨於日子的邊緣，

&nbsp;

而我生命又是多麼的脆弱和空虛&nbsp;&nbsp;&nbsp; 

&nbsp;

告訴我，你什麼時侯會踏一曲童話，為我而歸

&nbsp;

為那一首輸了你贏了世界又如何?

&nbsp;

&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？


你是否明瞭我在異地的苦心，

&nbsp;

栽下甜中帶苦的希冀，丟進乾裂的心裏

&nbsp;

用眼睛挖出一條心渠，讓我的愛在裏面流淌

&nbsp;

你說一切會好的，會好的.....菩提本非樹，明鏡亦無台

&nbsp;

本是無一物，何處惹塵埃，你知道的，我不是要那種境界

&nbsp;

只是因為一曲憂傷的歌會使我心靈波動
&nbsp;


親愛的，你怎麼不在我身邊？


在思念中，我千萬遍呼喚你的名字

&nbsp;

我解釋不清那卻道天涼好個秋的滋味，或許，

&nbsp;

一個字一個詞概括不了，

&nbsp;

或許，只是因為瑟瑟的冬風拂裂硬土

&nbsp;

我已無法面向歲月，無法為你指出那枝葉的蹤跡

&nbsp;

只是靜靜等你歸來

&nbsp;

夜空空曠，我把一支歌播入泥土，

&nbsp;

讓它蠕動蓄積想像中含苞吐芽

&nbsp;

　　&nbsp;&nbsp; 讓我在一抹芳香中期待奇蹟．．．


&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？


我不敢說也不要說這是一個多感的季節翹首遠望，

&nbsp;

心動如弦，夜空掩住你的蹤跡，

&nbsp;

思念卻在道路曲折的誘惑中慢慢遠去……

&nbsp;

&nbsp;

&nbsp;

親愛的，你怎麼不在我身邊？

&nbsp;

或許心靈的交流和感應，是一道永不消失的電波

&nbsp;

所以，渺遙的空間距離，也不會損害我們的理性融合

&nbsp;

凝望暮色，或許遠遠的正在歸來

&nbsp;

我把理不盡的相思搓成長長的絲線，

&nbsp;

一頭繫上你一頭繫上我


&nbsp;

親愛的，你怎麼不在我身邊？


沒有你的日子濕漉漉的情緒飄灑一地，

&nbsp;

寂寞瘋長天地間，無人收割孤獨，

&nbsp;

于是，飄零的感覺密密荒蕪了所有方向

&nbsp;

遙遠的夜空，晃動迷離的憂傷，倦了的心覓不到棲息的土壤


&nbsp;
親愛的，你怎麼不在我身邊？


聽著憂傷的旋律，在歌聲中找尋依托和歸宿

&nbsp;

宛若輕煙，飄在融融月色中……
