 rn&nbsp; 你心中事業與愛情那個重要？&nbsp;&nbsp;&nbsp;




&nbsp;

&nbsp;

&nbsp;


很多人常常煩惱結婚之後，就會被家庭綁住，

&nbsp;

不能夠好好打拼事業，導致社會上有好多四十多歲的

&nbsp;

黃金單身漢，

&nbsp;

不能就是年紀輕輕就被生活重擔所苦的可憐蟲。

&nbsp;

女性更是可憐，

&nbsp;

年過三十就不太容易找到好人家。

&nbsp;

到底事業與愛情那個重要，有沒法兒可以兼顧呢？

&nbsp;

做做小測驗，希望可以幫你解答 疑惑。

&nbsp;

&nbsp;

&nbsp;

測驗開始：

&nbsp;

&nbsp;

如果有一天你要出國了，是第一次而且是一個人出國，

&nbsp;

來到一個語言不通的國家，你會最害怕什麼？


&nbsp;

Ａ‧護照證件不見了。 &nbsp;Ｂ‧身上沒有任何一毛錢。 
&nbsp;
Ｃ‧被以犯罪嫌疑居留。 Ｄ‧受騙，遇到壞人。
&nbsp;


Ａ.～護照證件不見了的人
&nbsp;
&nbsp; &nbsp;你的事業佔 80%，愛情佔 20% 

&nbsp;

&nbsp;

你的事業心很重，為了衝刺光明的前程，

&nbsp;

你可以暫時不顧兒女私情。你的愛情也不喜歡對方太黏你，

&nbsp;

喜歡享受對方的愛卻又吝於付出。

&nbsp;

成功的背後的確是需要一個偉大的男(女)人，

&nbsp;

只是對方也有被愛的權利。

&nbsp;

建議你別把工作跟愛情分得太清楚，

&nbsp;

有時候也可以跟你的愛人分享工作上的心酸，

&nbsp;

別以為這無所謂，一個你不常陪伴的人，

&nbsp;

他寧願可以是你最後的依靠也不想總是依靠你。
&nbsp;
&nbsp;
&nbsp;Ｂ.～身上沒有任何一毛錢的人
&nbsp;
你的事業佔 60%，愛情佔 40% 

&nbsp;

&nbsp;

基本上你的另一半如果不是感情用事的人，

&nbsp;

相信你們會是很幸福的一對，很多事情也都可以一起面對。

&nbsp;

平常可以享受感情的甜蜜，

&nbsp;

也間接化解了工作上可能面對的壓力。

&nbsp;

只是有時候壓力常來自於工作，

&nbsp;

你也常因此而不小心傷害了愛自己的另一方。

&nbsp;

別太相信另一半就一定能體諒你的情緒宣洩，

&nbsp;

理性的人就該好好用理性解決事情，

&nbsp;

感情用事只會造成雙方永難磨滅的裂痕。
&nbsp;
&nbsp;
&nbsp;C.～被以犯罪嫌疑居留的人
&nbsp;
你的事業佔 40%，愛情佔 60% 


&nbsp;

你是一個很重感情的人，有時候寧願成全愛情，

&nbsp;

也甘心放棄自己辛苦打拼的事業。

&nbsp;

只是只有愛情

&nbsp;

也不能沒有麵包，這個社會實在是樣樣都要錢，

&nbsp;

大多數的夫妻吵架也都是因為錢。

&nbsp;

沒有了過得去的經濟環境，

&nbsp;

你也可能得不到心裡憧憬的愛情。

&nbsp;

建議夫妻雙方可以好好協調，

&nbsp;

例如其中一方可以維持小部分的經濟獨立，

&nbsp;

都可以在照顧家庭之餘，

&nbsp;

還能夠分擔家計以及另一方的生活壓力與辛苦。
&nbsp;


Ｄ.～受騙，遇到壞人的人
&nbsp;
你的事業佔 20%，愛情佔 80% 

&nbsp;

&nbsp;

基本上你的事業心本來就不算重，甚至也不喜歡工作，

&nbsp;

所以你會花很多心思的愛情上，

&nbsp;

也容易博取對方的好感進而願意跟你在一起，

&nbsp;

等到婚後才會感受到『巧婦難為無米之炊』，

&nbsp;

沒有錢是多麼可怕的一件事。

&nbsp;

你對工作的消極態度對方看在眼裡是又氣又難受，

&nbsp;

你們也不可能再恢復婚前的甜蜜。

&nbsp;

對工作不積極就努力鑽研

&nbsp;

自己的專長興趣期能殺出一條活路，

&nbsp;

否則再多的甜言蜜語也抵銷不了現實的無奈。

&nbsp;
