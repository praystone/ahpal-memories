&nbsp;


&nbsp; 


《細看人生》




世界很大
&nbsp;
我們終其一生無法徹底瞭解萬物的道理，
也無法走遍全天下，
世界上有太多的可能會發生，
我們沒辦法參與每件事。


&nbsp;


路有很多條 
&nbsp;
人類的腦中每天會出現四萬五千個想法，
每一個想法都會決定下一步路怎麼去走，怎麼決定。
這就像小時候玩的捲紙迷宮，
有些路上佈滿了陷阱，
有些路繞了幾圈又回到原點，
而我們永遠不會知道自己選擇的路上，將會發生什麼事。
&nbsp;


&nbsp;


時間一直在走
&nbsp;
一天二十四小時，一個月三十天，一年十二個月，
時間很有規律地運作自己的步調，
沒有任何事可以令它加快或變慢，
即使我們忽略了這個事實。


&nbsp;


我們不能去走每條路
&nbsp;
魚與熊掌不能兼得，遊戲規則是這樣說的。
在我們浪費時間老是游走於尋覓人生跑道的時候，
其他人已經迅速地離我們遠去。


&nbsp;


也沒有時間停下來休息
&nbsp;
時間雖然有限，
生命卻充滿著無限的可能及被創造性。
因此，我們可以把握僅有的時間做更多的事。


&nbsp;


青春就這樣過了...
&nbsp;
不知不覺中，
生命中最璀璨亮麗的十八歲少年時期已經過去。
接下來呢？
青少年期、中老年期...
經過這些時期需要多少時間？
能夠自在活動的又是哪些時期？
還剩下多少青春呢？


&nbsp;


從生命的窗口之中，看到了什麼？
&nbsp;
對自己的生命，我們認識了多少？掌握了多少？
我們的生命是由自己主宰的嗎？
目前的生活正是我們所希望的嗎？
是彩色的？還是黑白的？
&nbsp;


&nbsp;


是片段？還是電影？
&nbsp;
我們的生活是部什麼樣的電影？
喜劇、悲劇、羅曼史、動作片？是精彩還是乏善可陳？
亦或只是一段段串不起來的片段？
只能擺在倉庫永不見天日？


&nbsp;


我們要做生命中的導演
&nbsp;
是的！生命是我們的，我們才是自己生命中的主人，
我們必須規劃自己的人生劇本，
決定角色、演員，並主導這一切。


&nbsp;


燈光、配樂、剪接
&nbsp;
世界是如此的多彩多姿。
因此，我們也要為生活加入些許調味劑，
替生命添加顏料與音符，讓生命躍動起來，
並將拍壞的片段剪掉，去蕪存菁。


&nbsp;


製作出自己的生命影集
&nbsp;
將所有生命中的要素，組合成一部個人的電影，
藉著這部電影來感動周遭的人，
隨著劇情的高潮迭起，帶領觀眾走進我們的人生。


&nbsp;


要和許多不同的人接觸
&nbsp;
每個人在當初做的決定不同，走的路就不一樣，
有的人一步登天，有的人雖然一路從挫折中走過來，
卻不斷地成長、茁壯。
&nbsp;


&nbsp;


每個人走的路不一樣
&nbsp;
我們無法去走每一條路，但是藉由認識別人，
可以開拓更非凡、更遼闊的視野。
和比自己強的人接觸，可以學會謙和；
和弱於自己的人接觸，可以學會知足。


&nbsp;


可以開啟不同的人生
&nbsp;
也許，我們不可能探索整個世界，
但是，我們可以透過與人接觸，分享許多人所認識的世界，
來拓展及充實自己的小小世界。
能夠如此的話，整個世界就是我們的了。


&nbsp;


接著，要走穩自己選擇的路，
留下生命的足跡。
&nbsp;
生命具有無限的特質，一切靠自己去創造，
雖然每個人起跑點不盡相同，
但是我們不需要妄自菲薄，或是好高騖遠，
將腳步踩穩，累積自己的實力，等待機會來臨，全力以赴，
為自己的生命譜出一章章美妙的樂章！


&nbsp;
