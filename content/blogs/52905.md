曾和朋友很好很好過&nbsp;
當你忙於自己的事情而疏於連絡時&nbsp;
不夠堅固的友情&nbsp;
往往這麼不堪一擊地毀了&nbsp;
從此只是點頭之交&nbsp;
曾經的秘密也都蒸發於空氣中&nbsp;
少了個知心朋友的感覺 真的很爛&nbsp;
朋友有很多種&nbsp;
酒肉朋友 點頭朋友 打混朋友&nbsp;
那種朋友數量多少無所謂

但是....&nbsp;
好朋友在精不在多 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;
而好朋友在於你可以說任何事&nbsp;
可以一而再 再而三地說著相同架構的故事 &nbsp;
但是他總是很耐心地聽你說&nbsp;
最後才慢慢道出&nbsp;
你的道術愈來愈高招囉&nbsp;
加油 加油&nbsp;
最愛你的人一定還在等待你在愛情中的成長
而真正的好朋友 是在你高興時潑點冷水給你
告訴你 不要太過得意&nbsp;
你和好朋友都聊些什麼&nbsp;
談心 還是 說笑 還是儘說些無聊的話&nbsp;
或許在細訴人生大道理&nbsp;
對人生的看法 對生活的態度

有空時和朋友聊聊也是很棒的&nbsp;
不過 能找到一個能聊的人真的很難很難&nbsp;
要在一個別人的面前 將自己的心思坦白
很難很難&nbsp;
你有可以聊人生大道理的好朋友嗎 &nbsp; &nbsp; &nbsp;&nbsp;
很高興 我有說 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;
誤會是人際關係的殺手&nbsp;
不溝通不協調 更是友誼的迷魂藥&nbsp;
如果心裡有了怪怪的感覺&nbsp;
希望你們能彼此溝通清楚&nbsp;
因為 一個好朋友的結緣&nbsp;
是靠天時地利人和 得來不易

誤會或許可怕
但是我覺得懷疑更是厲害
因為懷疑來自於不信任
或許誤會是來自於許多事情的陰錯陽差
但是懷疑來自於人主動的 感覺-不信任別人
最爛的一個做法

愛情的確是很可愛
但是如果因為愛情而忘記了很多事情
我想在沒有愛情之後
需要愛情的人 一定會很快死掉
就像人沒有了空氣一樣
慢慢地在自己的生活空間裡窒息了

沒有愛情的人不懂愛情如何地好
沒有友情的人不懂友情如何地妙
珍惜你所擁有的!

珍惜一切.相遇的緣分.只因人生多變.唯有把握才能擁有

我要謝謝你 &nbsp; 讓我不孤單&nbsp;
我要謝謝你 &nbsp; 讓我的信箱有信可以收&nbsp;
我要謝謝你 &nbsp; 讓我無聊寂寞時有人可以說說話
我要謝謝你 &nbsp; 讓我心情激動難過時有人安慰我&nbsp;

我要謝謝你 &nbsp; 讓我有好東西有人可以分享&nbsp;
我要謝謝你 &nbsp; 一路走來有你們真好&nbsp;
希望以後我們能再繼續走下去好嗎
