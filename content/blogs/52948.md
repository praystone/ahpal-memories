珍惜美好的片段


&nbsp;




&nbsp;



人生原本就聚散無常
&nbsp;
只要能珍惜最美好的片段
&nbsp;
又何必在乎是聚是散，有過愛情經驗的人常說，
&nbsp;
相愛簡單，相處難，但是分手更難！
&nbsp;


人和人之間的關係本來就是很微妙的東西
&nbsp;
很難說上一個具體的形態來 不是嗎？
&nbsp;
就也是因為這樣的微妙和難說出個所以然來
&nbsp;
才會有許多的不可預期，這不可否認的
&nbsp;
其實，或許在經過一些的事後大概會發覺
&nbsp;
原來，並沒有所謂的永永遠遠的友情和愛情
&nbsp;
能永永遠遠的友情和愛情固然可喜
&nbsp;
但這在機率上又佔了多少的百分比



&nbsp;


我想大家都想永遠一輩子珍惜擁有的友情和愛情
&nbsp;
卻每一個人都沒把握，看了你受傷的心情 


&nbsp;


我只是淡淡的一笑，笑是因為 


&nbsp;


你還沒學會在這複雜的人際關係中
&nbsp;
找到自己天秤上的平衡點
&nbsp;
&nbsp;
很多事，越是在乎越會深覺不快樂
&nbsp;
不快樂了，氣忿和抱怨也會特別多，習慣一個人 


&nbsp;


去做我自己想做的事
&nbsp;
不必在乎某些人的言語、行為和舉動
&nbsp;
&nbsp;
朋友的定義是什麼？好朋友的定義是什麼？
&nbsp;
都不重要，重要的是你用怎樣的心態去看待
&nbsp;
相信自己，用眼睛看，


&nbsp;


用耳朵聽 用心去感覺吧！
&nbsp;
你會發現，許多事原來和自己所認為的不一樣



人的一生是無數的輪迴，記取經驗與記憶的累積
&nbsp;
就可減少猶豫的光陰，也可避免選擇的錯誤
&nbsp;


不管我們跌倒多少次，總會繼續向前走

不管我們心碎多少次，陽光永遠不會消失 


&nbsp;
