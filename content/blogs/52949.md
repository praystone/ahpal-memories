&nbsp;

張愛玲寫給女人的49句話
&nbsp;



&nbsp;


1.就算眼前的這個男人，千般好，萬般好，處處是優點，


&nbsp;

他不愛你，這個缺點，你永遠改變不了。


&nbsp;

2.分手時，不哭。


&nbsp;

當然，不是要你一點都不哭。


&nbsp;

當著面，別哭，背地裏，往死裏哭。


&nbsp;

3.一個人最大的缺點，不是自私、野蠻、任性，


&nbsp;

而是偏執的愛著一個不愛自己的人。


&nbsp;

4.不管你的條件有多差，總會有個人在愛你。


&nbsp;

不管你的條件有多好，也總有個人不愛你。


&nbsp;

5.抓住男人的不二法門，


&nbsp;

應該就是，永遠不要讓他滿足。


&nbsp;

6.打扮的再美，穿的再昂貴，


&nbsp;

那只是個幌子，用善良做的外衣才是真的美。


&nbsp;

7.如果我們責怪愛情傷害了我們，


&nbsp;

那請問，開始的時候是不是你點頭答應愛情的來臨。


&nbsp;

8.能開口說出的委屈，便不是委屈。


&nbsp;

能離開的人，便不算是愛人。


&nbsp;

9.所有愛著的人，愛過的人，都做著同一件事，犯賤。


&nbsp;

10.心裏能裝著一些時間帶不走的淡淡悲傷，


&nbsp;

也是一種幸福。


&nbsp;

11.人永遠是寂寞而自我的生物。


&nbsp;

無論多麼真誠的說出自己的愛，也總會有無法被理解的心情。


&nbsp;

12.不卑不亢，從容優雅，面對一切。


&nbsp;

13.一個人，如果沒空，那是因為他不想有空；


&nbsp;

一個人，如果走不開，那是因為不想走開；


&nbsp;

14.一個人，對你藉口太多，那是因為不想在乎。


&nbsp;

15.有的事情，沒法說明。


&nbsp;

你覺得值，就值，你覺得不值，別人說值，你也覺得不值。


&nbsp;

16.要明白一個道理，男人可是輕易的喜歡一個人，


&nbsp;

但不會輕易的愛上一個人。


&nbsp;

17.女人，戀愛的時候，就像，與世隔絕般。


&nbsp;

18.在風平浪靜的日子裏，


&nbsp;

留點空間給自己，留點空間給對方，留點美好給距離。


&nbsp;

19.有的時候不要太計較，男人都有點粗枝大葉，


&nbsp;

忘了一件事，不代表他不愛你，別自己嚇自己。


&nbsp;

20.女人，往往喜歡坦白心事，男人，則恰恰相反。


&nbsp;

21.有時候，學會把失望當做一種收穫，

&nbsp;

因為有期望，才會有失望。


&nbsp;

22.女人的心慈手軟，與男人的口是心非，成正比。


&nbsp;

23.不要妄想試圖改變誰，因為誰也改變不了誰，


&nbsp;

只有，他願不願意為你改變。


&nbsp;

24.時間，可以瞭解愛情，可以證明愛情，也可以推翻愛情。


&nbsp;

25.自由可貴，但是，每天數以萬計的人，在用自由換取愛情。


&nbsp;

26.你可以虛榮，因為，那是女人的天性，


&nbsp;

但，不要讓自己變成為別人增加虛榮的工具。


&nbsp;

27.不要說，這世上沒個好男人了，

&nbsp;

不要去記恨那個拋棄你的人，


&nbsp;

畢竟曾經愛過你、疼過你，寬容會讓你更美麗。


&nbsp;

28.現任女友長得如何？身材如何？你這樣只是自尋煩惱罷了。


&nbsp;

29.說過的話一定要做到，


&nbsp;

哪怕是很愚蠢的，也總比言而無信的好。


&nbsp;

30.不要在你哭泣的時候，

&nbsp;

說氣話，下決定，否則你會後悔的。


&nbsp;

31.他說，我累了，讓我冷靜一段時間，好嗎？


&nbsp;

你就說好，因為，他是來通知你的，不是來取得你同意的。


&nbsp;

32.你清純就罷，你假裝清純，比醜還難看，明白嗎？


&nbsp;

33.不是所有的努力都會成功，


&nbsp;

但是，不努力，就一定不會成功。


&nbsp;

34.女孩子要自愛，不管你遇到多大的打擊，


&nbsp;

不管你遇到的情況多麼悲涼，藉故墮落，也是墮落；


&nbsp;

越是不愛自己，越是沒人愛你。


&nbsp;

35.美貌、智慧、 金錢，很多事，都是天生註定的，


&nbsp;

別想用你那嫉妒心，改變什麼。


&nbsp;

36.小心眼、嫉妒心、仇恨、報復，女人的伎倆不過如此，


&nbsp;

你要施展沒關係，關係的是你別被人發現。


&nbsp;

37.放好心態，失去的東西，


&nbsp;

不要悲傷，你就當，他本身就不屬於你。


&nbsp;

38.儘量做個優雅的女子，千萬別做作，


&nbsp;

因為，做作的女人，不僅女人討厭，男人更討厭。


&nbsp;

39.獨立，永遠。不管，感情還是金錢。


&nbsp;

40.嗯 ... 不要在哪幾個場合相信男人的話呢？


&nbsp;

床上、他開心的時候、有求於你的時候、犯錯的時候。


&nbsp;

41.不要想盡辦法的向很多人炫耀，


&nbsp;

你有很多男朋友或者男性朋友。


&nbsp;

因為，別人不僅不會羡慕你，只會看輕你。


&nbsp;

42.不要整天問，你愛我嗎？


&nbsp;

當你問的時候，他就不愛你了。


&nbsp;

43. 20歲以下，你相信偶像劇，那就算了。


&nbsp;

20歲以上，你還相信偶像劇，那就完了。


&nbsp;

44.要知道，一個男人好與壞，


&nbsp;

不是看他花心還是專一，自古男人都花心，


&nbsp;

而是要看，有沒有控制力。


&nbsp;

45.有沒有發現，往往刻骨銘心的愛戀。


&nbsp;

通常，沒有好結果。


&nbsp;

46.煙、酒，從古至今，被公認為兩大毒藥。


&nbsp;

而對，女人，愛情這一樣，足以致命。


&nbsp;

47.勇敢的女人，永遠比懦弱的女人美麗。


&nbsp;

如果，你的愛人不愛你，我勸你還是勇敢點分離，


&nbsp;

好過，懦弱的糾纏。


&nbsp;

48.善於妥協的女人，很寶貴。但是，

&nbsp;

只善於妥協的女人，很廉價。


&nbsp;

49.不要做女強人，要做強女人。
