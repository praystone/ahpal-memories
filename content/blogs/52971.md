&nbsp;

人會一天天走向老化，

&nbsp;

你最在意的老化癥兆是以下哪種？


A 體力變差&nbsp;&nbsp;&nbsp;&nbsp; B 身材走樣

&nbsp;

C 記憶消退&nbsp;&nbsp;&nbsp;&nbsp; D 皺紋增加

&nbsp;

&nbsp;


選擇A的人&nbsp;&nbsp; 

&nbsp;

你的個性很強勢，

&nbsp;

因此會將愛情主導權牢牢的掌握在手裏，

&nbsp;

期待愛情的發展依照你安排的劇本走，

&nbsp;

諸如何時結婚等議題都以你的意見為主，

&nbsp;

戀人只能乖乖扮演你愛情故事中的角色，

&nbsp;

雖有發言權卻無否決權，

&nbsp;

要是情人不願意服從你的專制領導，

&nbsp;

你會和他說拜拜。


&nbsp;

選擇B的人&nbsp;&nbsp;&nbsp; 

&nbsp;

你是個很敏感的人，

&nbsp;

不會直接講出你真正的想法，

&nbsp;

喜歡以退為進和拐彎抹角，來達到你真正的目的。

&nbsp;

你表面沒有掌控愛情主導權，

&nbsp;

看似都交給戀人，但是你卻會用天羅地網式的關心，

&nbsp;

逐步掌握情人的心和信任，進而左右情人的做法，

&nbsp;

所以你是隱身幕後的真正主導者。

&nbsp;


選擇C的人

&nbsp;

你的個性被動，所以你只會接受他人的追求，

&nbsp;

即使有心儀對象，你也不想採取主動。

&nbsp;

交往後你還是會將主導權交給情人，不想為戀愛傷神，

&nbsp;

你期望能夠得到戀人的寵愛和照顧，

&nbsp;

不過情人若是表現不如你意，你表面不動聲色，

&nbsp;

等到下一個來追求你的對象出現，

&nbsp;

你會拿回主導權，一腳踢開原本的情人。

&nbsp;

&nbsp;

選擇D的人

&nbsp;

在職場你是俐落聰明的角色，

&nbsp;

可是一換到情場，你會以為是你在掌握愛情主導權，

&nbsp;

事實上你卻經常會被情人的花言巧語所迷惑，

&nbsp;

被情人瞞騙和操控還不自知，

&nbsp;

如果遇上壞情人，當你人財兩失，

&nbsp;

你還會替情人辯護，親友的苦勸你都聽不進去。
