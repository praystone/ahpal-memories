&nbsp;

&nbsp;

勇敢我也可以 倔強我也可以

&nbsp;

先給我理由勇敢 讓我有藉口倔強

&nbsp;

面對著 我就是沒有勇敢的能量 是愛太強大

&nbsp;

真的不是嬌柔作態 更不會是故作可憐

&nbsp;

願我時時刻刻沐浴幸福光輝中

&nbsp;

由自己說出來顯的疲弱無力

&nbsp;

關於等待&nbsp; 身陷其中 我卻自得其樂

&nbsp;

誰孜孜不倦的重複倒帶&nbsp; 享受那痛苦的甜蜜

&nbsp;

不光是你 我也一樣 這是我們共同承擔的業障

&nbsp;

那麼 快樂多於苦一些 好不好 

&nbsp;

就讓&nbsp; 歡笑多於淚一些&nbsp; 要不要

&nbsp;

花期過了&nbsp; 就等待下一場花季 

&nbsp;

不是天災人禍可以毀了信心&nbsp; 

&nbsp;

是我們的心才能改變看見的風景

&nbsp;

說愛 太沉重 說不愛太矯情 都別說了

&nbsp;

一起數 一 二 三 同時關上連結的網

&nbsp;

默契依舊 我們都笑了 

&nbsp;

這不就是&nbsp; 愛過&nbsp; 必留下痕跡嗎 

&nbsp;
