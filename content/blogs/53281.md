&nbsp;


得與失...多與少 




&nbsp;

&nbsp;


我們用的工具越來越先進，但煩惱憂慮卻越來越多了；

&nbsp;

我們雖然不斷地努力生活，但日子卻越過越不開心了；

&nbsp;

我們的住屋比以前更大了，但活動的空間越來越小了；

&nbsp;

我們擁有了更多的知識，但判斷力卻更差了；

&nbsp;

我們擁有的財富倍增了，但其價值卻減少了；

&nbsp;

我們說的多了，愛的卻少了，對人的防備也更多了；

&nbsp;

我們可以登上月球，但卻難以走進一個人的心；

&nbsp;

我們可以征服太空，卻征服不了一個人的內心；

&nbsp;

我們的收入增加了，但追求的幸福卻越來越少了；

&nbsp;

我們的時代自由了，但心靈的自由卻越來越少了。

&nbsp;


在人的一生中：


應當多一點善心，少一點惡心；

&nbsp;

應當多一些善意，少一些惡意；

&nbsp;

應當多一點善言，少一點惡言；

&nbsp;

應當多一些善行，少一些惡行；

&nbsp;

應當多做些善事，少做些惡事；

&nbsp;

應當多積一點德，少造一些孽。

&nbsp;

&nbsp;

在對人的態度上：


當別人犯錯的時候，多一些寬恕，少一些指責；

&nbsp;

當別人困難的時候，多一些幫助，少一些冷漠；

&nbsp;

當別人感到為難的時候，多給一些顏面，少給一些難看；

&nbsp;

當別人對自己有意見的時候，多一些交流，少一些誤會；

&nbsp;

當別人對自己讚賞有加的時候，多一些謙虛，少一些驕傲；

&nbsp;

當別人對自己進行批評的時候，多一些反思，少一些怨恨；

&nbsp;

在利益的問題上多讓給別人一點，自己少爭一點；

&nbsp;

在工作範圍內對自己要求嚴一點，對別人寬一點。

&nbsp;

&nbsp;

在對待自己的態度上：


少一些疑惑，多一些理解；

&nbsp;

少一些苦惱，多一些開竅；

&nbsp;

少一些煩躁，多一些悠閒；

&nbsp;

少發一些脾氣，多找一些樂趣；

&nbsp;

少討一些沒趣，多增一些自律；

&nbsp;

少一些精神的空虛，多一些心理的充實；


&nbsp;

少一些個人的恩怨，多一些安寧的和諧。
