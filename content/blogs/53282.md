&nbsp;

&nbsp;

我的辭呈

&nbsp;



&nbsp;


老闆老闆別神氣，我將不再拍馬屁； 

&nbsp;

因為你常發脾氣，經常拿我來出氣； 

&nbsp;

微薄薪水真小氣，要求業績與壓力； 

&nbsp;

我是白癡兼奴隸，忍氣吞聲當小弟； 

&nbsp;

若非生活有壓力，早就離職與唾棄； 

&nbsp;

竟然上班沒波蜜，下班也無供馬力； 

&nbsp;

聊天不得話情意，害我嘴巴變麻痺； 

&nbsp;

加班沒有新臺幣，一年到頭沒福利； 

&nbsp;

初一十五要拜祭，也沒賞賜表心意； 

&nbsp;

辦公不準吹冷氣，汗流夾背一滿地； 

&nbsp;

沒有電腦來算計，自己大腦當機器； 

&nbsp;

文具用品都不必，自掏腰包當救濟； 

&nbsp;

公司小姐雖美麗，只能觀賞與哭泣； 

&nbsp;

我想泡妞談天地，因為忙碌無體力； 

&nbsp;

你常花天與酒地，雖是逢場與作戲； 

&nbsp;

竟然將我來忘記，令我難嚥這口氣； 

&nbsp;

我在公司令你氣，不如改行展魄力； 

&nbsp;

辭呈放在你抽屜，求我挽留都不必；

&nbsp;

本月薪水別忘記，我會回來找會計。
