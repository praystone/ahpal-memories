謝謝那個愛你的人

&nbsp;



&nbsp;

&nbsp;


我們總以為自己很重要、

&nbsp;

實際上在別人眼裏你往往一錢不值.

&nbsp;

在上司眼裏你只是一個無足輕重的職員，

&nbsp;

在下屬眼裏你只是一個可有可無的工頭。

&nbsp;

有你，酒席無非多添一雙筷子；

&nbsp;

無你，辦公室可能少擺一張椅子。


在薪資條上你是一個名單，在電影院裏你是一個座號--

&nbsp;

是的，在云云眾生之中你只是一個名字

&nbsp;

一個過客一個無關痛癢的陌生人。 

&nbsp;

此時此刻,是誰在說你很優秀？是誰認為你很重要？是她！

&nbsp;

是那個愛你的人！

&nbsp;

在這個世界上,只有她才能發現你的優點，

&nbsp;

只有她才會寬容你的缺點。


&nbsp;

她說你才華橫溢，實際上你可能一無所長；

&nbsp;

她說你心比天高，實際上你總是命比紙薄。

&nbsp;

當你窮困潦倒她說你懷才不遇，

&nbsp;

當你趾高氣揚她勸你月盈則虧。

&nbsp;

你陰天她下雨，你咳嗽她感冒。

&nbsp;

你一生中聽到最肉麻的吹捧、

&nbsp;

最溫暖的勸慰都是愛你的那個人說出來的。


只有在愛你的人那裏,你才是英俊的嫵媚的聰明的優秀的,

&nbsp;

甚至是不可替代的。


因此,無論你多?舉足輕重，無論你多?不同凡響，

&nbsp;

在內心深處，你都應該感謝那個愛你的人。 

&nbsp;

實際上，我們做的總是恰恰相反：

&nbsp;

在愛你的人面前驕橫跋扈，在不愛你的人面前低三下四。

&nbsp;

&nbsp;

如果為了生計為了前途為了財富為了理想，

&nbsp;

你必須與陌生不陌生的人，恨你不恨你的人周旋，

&nbsp;

但在內心中私下裏你應該為愛你的人保留溫暖的一角。

&nbsp;

你可以把所有的恭敬，溫順，慈祥，

&nbsp;

責任留給你的長官，朋友，家人，

&nbsp;

但至少你應該把一種感謝留給愛你的人。

&nbsp;

&nbsp;

對愛你的人的那一份感情，

&nbsp;

也許你難以回報，但不要漠視：

&nbsp;

也許你必須拒絕，但不要嘲笑。

&nbsp;

至少，在心中說聲謝謝總是可以的吧——

&nbsp;

對於自已這是舉手之勞，對於別人卻是善意的回報。 

&nbsp;

請你謝謝那個愛你的人，沒有她你一點也不重要！
