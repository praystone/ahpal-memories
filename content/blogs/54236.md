品味心境，品味人生



&nbsp;



泡一杯濃茶，細細地品味一下人生，是一件很愜意的事情。




有人說生活是一本打開的書，一百個人有一百種讀法，



&nbsp;



那麼人生則是一幅展開的畫，一百個人，自然也就有一百種感受。



&nbsp;



但是正如品茶要品出滋味一樣。品味人生，總不免有所感觸，



&nbsp;



或長嘆，或欣然，感觸愈多，收穫愈多。




先人留下的很多智慧多是無數人經過數代的經驗品味出來的人生哲理。


所謂仁者愛人，智者知人。一杯濃茶，品味人生，在這裡，






就成為了一種智慧：退一步海闊天空，是忍讓，是寬心；



&nbsp;



知足者常樂，是平衡，是清心；滴水穿石、鐵杵成針，



&nbsp;



是專心、是耐心。其實，無論這世間事物如何變化，



&nbsp;



只有這人，才是最有品賞價值的，



&nbsp;



而品賞出來的人性，更是永恆的。




不同的茶，泡出不同的口味，溢出不同的茶香，



&nbsp;



猶如人之愛心、虛心、清心、誠心、信心、專心、






耐心、寬心八種心性，蘊含人之一生的哲理。




在陰沉而窒息的空氣裡，泡一杯茶，坐在窗台下。



&nbsp;



四月的柳樹，幽淡、素潔！




我沒有吸煙的習慣，可我喜歡品茶，尤其是釅茶。



&nbsp;



端起杯，輕輕吹去漂浮的茶葉，望著那濃濃的湯液，



&nbsp;



看著那冉冉升起的縷縷白氣，仿佛進入了一個飄然的夢境；



&nbsp;



輕啜一口，微微的苦澀，濃濃的清香，通體的疲倦蕩然無存，



&nbsp;



諸多的煩惱悄然遠逝，遐思也飄遠了。




品味人生的滋味亦如同一杯濃濃的茶。少年，初識愁滋味的季節，



&nbsp;



成長的歲月浸透了淡淡的苦澀；青年，一段如火如荼的季節，



&nbsp;



亮麗的青春總有那麼幾抹灰色；中年，閱歷人生的坎坷，



&nbsp;



趨向成熟的歲月，雙肩摃起沉重的包裹；



&nbsp;



老年，飽嘗了歲月的風霜雨雪，懷念已逝的青春韶華總難免酸澀。



&nbsp;



人生，不正如那一杯捧在手裡的茶嗎？



&nbsp;



或許唯有天真無邪的童年才如同一掬可人的清泉吧！

是的，今天有今天的煩惱，明天又有明天的困惑，



&nbsp;



或許沒有這些就沒有人生了。人生的苦不是酒，



&nbsp;



酒讓人沉醉不解愁；人生的苦恰如茶，痛苦中給你警醒，



&nbsp;



給你希望，淡淡的苦澀蘊蓄著清香。 



&nbsp;



&nbsp;
