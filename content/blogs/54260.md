你能區別「愛」和「喜歡」嗎？

&nbsp;



&nbsp;

&nbsp;


一套區分「愛」與「喜 歡」的問卷，

&nbsp;

兩種量表都根據受測者對另一個人的態度來評分。


&nbsp;

「喜歡量表」包括覺得對方

&nbsp;

「令人欣賞」、「可敬」、「與自己類似」等等，

&nbsp;

「愛量表」則包括「與他（她）在一起的需要」、

&nbsp;

「即使花很大的代價也願意幫助他（她）」、

&nbsp;

「親密及獨佔的渴望」等。


&nbsp;

心理學家用這個量表來測驗一組男女大學生，

&nbsp;

發現男生對「愛」與「喜歡」有較接近的感受，

&nbsp;

女生對「愛」與「喜歡」有較大的區別能力。

&nbsp;


那就是說，

&nbsp;

女生比較易於去愛一個她不喜歡的異性，

&nbsp;

她能區別甚麼是愛，甚麼是喜歡，

&nbsp;

正如她能區別哪個男人可以做丈夫，

&nbsp;

哪個男人只可以 做情人。


&nbsp;

男人並不太會區分「愛」和「喜歡」，

&nbsp;

他們的「愛」和「喜歡」總是混雜一起的。


女人把「愛」和「喜歡」分得很清楚。

&nbsp;

我是喜歡你，不是愛你。 


從喜歡到愛，是一條漫長的路，

&nbsp;

要看他為她付出多少。


&nbsp;

女人決不肯對自己喜歡的人說「我愛你」，

&nbsp;

當他還沒到那個級數，她只肯對他說「我喜歡你」。


&nbsp;

男人卻很糟糕，

&nbsp;

「我喜歡你」和「我愛你」差不多可以同時說出來，

&nbsp;

中間並不需要一段漫長的路。


因為，無論是喜歡還是愛，

&nbsp;

他也想跟她發展親密的關係。

&nbsp;

當兩人發展了親密的關係之後，

&nbsp;

他還有需要區別「愛」和「喜歡」嗎 ？

&nbsp;

&nbsp;

女人要把「愛」和「喜歡」分得清清楚楚，

&nbsp;

因為，如果只是喜歡的話，

&nbsp;

她是有防線的，

&nbsp;

如果是愛，這條防線就可以拿走。


&nbsp;
