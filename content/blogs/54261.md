友情無敵~~(臭屁)

&nbsp;




&nbsp;


有一天， 

&nbsp;

四個已經退休的老人一起打麻將。 

&nbsp;

打了幾圈，中場休息時間， 一個老人想去上廁所， 

&nbsp;

其他的三個於是就開始聊起來了…

&nbsp;

&nbsp;

一個老人講到他的兒子俊明， 

&nbsp;

就忍不住臭屁一下 「我們家的俊明啊…… 

&nbsp;

在作珠寶生意，前一陣子不知道發了什麼瘋， 

&nbsp;

竟然送個大鑽戒給他朋友， 真是受不了他啊…… 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;（不肖子 ）&nbsp; 　 　　 


&nbsp;

&nbsp;

另一個老人也不甘示弱的說 

&nbsp;

我那個建國啊……在汽車公司裡作經理，前一陣子也是的，

&nbsp;

不知道怎麼著，送了一部凱迪拉克給他朋友！ 

&nbsp;

你說敗不敗家嘛！
（不肖子 ） 


&nbsp;

第三個老人也說話啦 &nbsp;

&nbsp;

我那個不成才的兒子志雄啊！ 

&nbsp;

在搞房地產，現在經濟不景氣， 

&nbsp;

前一陣子他竟然還送了一棟房子給他朋友！ 

&nbsp;

真搞不懂他在想什麼…… 三個老人臭屁了半天， 

（不肖子 ）

&nbsp;

&nbsp;

第四個老人上完廁所回來了， 


他說：「你們在聊些什麼啊？」 

&nbsp;

聊兒子啊……， 對了，你的兒子家明最近怎樣啊？

&nbsp;

其中一個老人問到。 

&nbsp;

&nbsp;

只見第四個老人深深地探了一口氣…… 

&nbsp;

說著 唉……我家那個變態家明啊…… 

&nbsp;

別提了，竟然是個同性戀，

&nbsp;

不過前一陣子，不知道走了什麼狗屎運， 

（不肖子 ）

&nbsp;

有朋友送他大鑽戒，又有人送凱迪拉克， 

&nbsp;

還有個人送了棟房子給他！你們說奇不奇怪啊……
