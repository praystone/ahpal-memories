&nbsp;

你知道刺鳥的故事嗎 

&nbsp;

終其一生 牠就只為了尋著那棵樹

&nbsp;

樹上必須長著又大又尖銳的刺

&nbsp;

然後用力飛讓胸膛穿過那根刺

&nbsp;

華麗絢爛的結束ㄧ生

&nbsp;

&nbsp;

經過一場渾沌的感情漩渦

&nbsp;

過去自以為是一隻讓人幸福的青鳥

&nbsp;

萬萬沒意料卻讓自己成為哀傷的刺鳥

&nbsp;

回到最初之後&nbsp; 其實沒那麼糟糕

&nbsp;

心裡痛他幾個月 眼淚流上一年

&nbsp;

熬過去了也就不再那麼忐忑心碎

&nbsp;

&nbsp;

我後悔翻動你的靈魂

&nbsp;

讓你陷入猜測不安的生活

&nbsp;

如今深深的歉意昭然若揭

&nbsp;

對不起---心愛的人

&nbsp;

你也同樣讓我日日夜夜痛苦牽掛

&nbsp;

我再也無法當你的青鳥

&nbsp;

你也無法成為我的使者

&nbsp;

傳說---也只是傳說 不能為愛帶來藉口

&nbsp;

我不當刺鳥...也不是青鳥...

&nbsp;

我是落點凡間的人類...為愛而生存

&nbsp;
