老婆和老媽同時掉在了水裡了.....終於有解答ㄌ


&nbsp;&nbsp;&nbsp; 老婆和老媽同時掉在了水裡，


先救老婆&nbsp;， 老媽就會沒命!


先救老媽&nbsp;， 老婆就會沒命!


先救老婆?還是先救老媽?還是誰都不救呢？


看看古人是怎麼做的...

&nbsp;

&nbsp;

孟子：


我從小死了老爸，老媽拉拔我不容易，


為了讓我健康成長，又搬了三次的家，


無法吃好的穿好的，為的就是讓我有出息。


老媽和老婆落水當然先救老媽了，萬惡淫為首，百善孝為先嘛！


老婆死了我可以再找一個，老媽死了可不能再找一個，


再找一個那就是後媽了。聽說後媽沒幾個好的。


世上只有媽媽好，沒媽的孩子像根草。


老媽，我來救您了！撲通一聲，『孟子』跳下了水。

&nbsp;


&nbsp;周幽王：


老婆和老媽落水了當然得先救老婆了。


想當年俺為了逗親愛的褒姒笑一笑，


連江山都不要了，連自己的小命都不要了，何況是老媽？


再說這死老太婆在立太子的時侯老是偏向俺弟弟，


害得俺差點都沒當成太子。 
&nbsp;

情深深雨濛濛，我對你的愛很深，褒姒我來救你了。


『周幽王』撲通一聲跳進了水裡。

&nbsp;

&nbsp;

劉備：

&nbsp;

兄弟如手足，老婆如衣服，

&nbsp;

衣服破尚可補，手足斷安可續？


只要俺二弟和三弟沒掉水裡就行了，其它人俺可不管他。


老婆，老媽。你們死的好慘呀！

&nbsp;

『劉備』一頭栽在河邊上嚎嚎大哭起來。

&nbsp;

&nbsp;

曹操：


寧叫我負天下人，休叫天下人負我。


管它是老婆還是老媽了，只要不是我掉水裡就行了。


輕輕的我走了，正如我輕輕的來，

&nbsp;

我揮一揮手，不帶走一片雲彩。

&nbsp;

『曹操』哼著詩，提著劍，慢慢的走遠了。

&nbsp;

&nbsp;

屈原：

&nbsp;

這個世界太黑暗了，這個國家太腐敗了，


活著也沒啥意思，不如都死了乾淨，


滄浪之水清兮，可以濯吾纓，滄浪之水濁兮，可以濯吾足。


投身于河水中倒是一個挺好的歸宿。 
&nbsp;

現在的一片天，是骯髒的一片天，星星在文明的天空裡，

&nbsp;

再也看不見。老婆，老媽，我和你們一起死。

&nbsp;

『屈原』一邊唱著一邊跳進了水裡。

&nbsp;

&nbsp;

莊子：

&nbsp;

生又何歡，死又何哀？

&nbsp;

其始而本無生；非徒無生也，而本無形；非徒無形也。

&nbsp;

老媽和老婆死了就死好了，不過是從有形的元氣狀態，

&nbsp;

回到了無形的元氣狀態，有啥好傷心的呢？

&nbsp;

救他們幹啥呢？誰都不救啦！


對面的女孩看過來，看過來，看過來。
&nbsp;

『莊子』分開著雙腿像簸箕一樣坐著，

&nbsp;

手中拿著一個瓦罐，

&nbsp;

邊敲邊唱，看著老婆和老媽慢慢地淹沒在水中，

&nbsp;

滿臉快快樂樂的樣子。

&nbsp;


&nbsp;王勃：

&nbsp;

手心手背都是肉，老婆是自己最愛的人，

&nbsp;

老媽是自己最親的人，怎麼辦呢？

&nbsp;

不管它，先跳下去，看看離誰最近,就先救誰吧。

&nbsp;

王勃撲通一聲跳了下去。


不好，我忘了自己不會游泳了。 
&nbsp;

『王勃』咕嚕嚕地喝了幾口水，也慢慢地沉了下去。

&nbsp;

一代才子『王勃』就是因為此事溺水而死的。

&nbsp;

&nbsp;

孫悟空：

&nbsp;

「我是從石頭縫裡蹦出來的，沒有老媽。

&nbsp;

所以不存在老媽落水的問題；我是個和尚，沒有老婆。

&nbsp;

所以不存在老婆落水的問題。

&nbsp;

不存在老媽落水的問題，也不存在老婆落水的問題，

&nbsp;

就更不會存在老媽和老婆同時落水的題。

&nbsp;

這白癡的問題也不知道是哪個豬頭想出來的，

&nbsp;

簡直比俺師弟豬八戒還蠢。

&nbsp;


&nbsp;這才是真正的答案啊！

&nbsp;

這個答案雖然搞笑，但卻有一絲絲的禪意。

&nbsp;

有句話說得好：「人生是一連串的選擇。」

&nbsp;

你怎麼選的呢？留意看看自己的內心喔！
