夠了..夠了..真的夠了..

我做人怎麼這麼失敗這麼差勁阿!!

&nbsp;

這樣的忙碌

每個團體都分掉我一大部分的時間

我已經沒有時間可以好好休息了

我好累..好累了..

&nbsp;

可是我還是一直撐著

我沒有放棄

但我這是...&nbsp; (唉...

&nbsp;

每個人每件事

都在述說

我做的不好&nbsp; 不夠完美

我不夠主動 不夠積極

&nbsp;

每個人每件事

都在責怪

我參與的不夠

我消失的太多

每個團體都分掉我一大部分的時間

然後都卡在一樣的時間點上

我只有一個人

你要我怎麼去抉擇..

&nbsp;

&nbsp;

我也是人

我也希望被讚美 也希望被支持

我的主動&nbsp;&nbsp;沒有任何人理會

我的積極 沒有任何人看的出來

我的苦&nbsp; 沒有任何人去理解

&nbsp;

這樣在我分身乏術之後

我還有辦法去做嗎

告訴你們

我沒辦法!!

&nbsp;

我說的話沒有人理睬

我做的事沒有人滿意

一次兩次 我可以再繼續的撐下去

三次四次&nbsp;&nbsp;&nbsp; 我漸漸的沒有話了

n次之後&nbsp;&nbsp;&nbsp; 造就現在的我

&nbsp;

問天&nbsp; 這樣的我是怎麼來的

這是&nbsp; 大家造就出來的

&nbsp;

是你們先抹煞掉我的

為什麼還要這樣怪我..

&nbsp;

我還不夠逆來順受嗎?

&nbsp;

有能力的人都躲起來在背後做事

能力不足的我&nbsp; 是白癡 是笨蛋

自己就這樣跳出來

然後被你們這樣的對待

一群有能力的人一直這樣對我施壓有用嗎!!

明明是你們先否決掉我&nbsp;&nbsp; 先不理睬我

繞了一大圈後&nbsp; 才發現我早已述說的事實方法

怪誰?&nbsp; 怪我沒貢獻?

那為什麼討論時&nbsp; 我出聲都沒有人要好好聽

我說話都要一直打槍我

最後繞了一圈才用我的方法

然後都說是自己想的&nbsp; 我沒有幫上

怪誰?&nbsp; 我在說沒有人要聽&nbsp; 當然最後就會歸類我為不主動 沒貢獻&nbsp; 

&nbsp;

那我再有想法有什麼用

你們總是在我沒有想法的時候找我要想法

在我有想法時漠視我

那這樣子&nbsp; 我怎麼才能讓你們都滿意

&nbsp;

我願意這樣嗎!!

搞到現在

連我媽都無法體諒我了

沒有任何人&nbsp;&nbsp; 能夠體諒..

沒有人想理解&nbsp; 亦沒有人 去理解..

&nbsp;

&nbsp;

&nbsp;

&nbsp;

這樣的我

還說的出什麼..

還能做的了什麼..

&nbsp;

就讓我倒了吧

只要一次就夠了

一次就帶走我

不要再多了

反正也不是第一次了

這兩年經歷的也夠多次了

&nbsp;

至少

&nbsp;

別讓我再這樣掙扎下去了
