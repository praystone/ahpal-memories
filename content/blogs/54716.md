&nbsp;



小時候常作夢，夢裡五顏六色天馬行空

&nbsp;

最讓我恐懼縈繞不忘的是那場夢

&nbsp;

我老喜歡往地上一蹬躍起，那天竟然騰空飛行

&nbsp;

回頭遠眺竟然漂離地球，任憑我哭啞了嗓子，喊破了喉嚨

&nbsp;

底下的朋友、兄弟姊妹、父母和我可愛的玩偶渾然不知

&nbsp;

頓時我傻了！

&nbsp;

越是掙扎越是在無重力空間失重&nbsp; 漂‧‧‧‧呀‧‧‧漂‧‧‧

&nbsp;

號啕大哭&nbsp;&nbsp;&nbsp;&nbsp; 雨落藍海

&nbsp;

藍色的地球被淚水淹沒

看不到丘壑海川&nbsp;&nbsp;&nbsp; 看不到山稜水霧


&nbsp;

逐漸收縮凝結

&nbsp;

滑過天際&nbsp;&nbsp;&nbsp; 漫過蒼穹

&nbsp;

在太陽系&nbsp;&nbsp;&nbsp; 在獵戶星座

&nbsp;

數十年了

&nbsp;

那顆藍色淚珠又回來了！
&nbsp; 
而我好想家！

&nbsp;

求主悲憫赦免我‧‧‧ 
後記：經過這些年在職場奔波，我終於知道為何狂戀夏卡爾的畫了
