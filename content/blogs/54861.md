&nbsp;

&nbsp;


&nbsp;


境界　這個詞很抽象，然而現代人很喜歡用


&nbsp;


它是一種感受　一種美　一種靜態的美　一種深遠的美


&nbsp;


一種只可意會不可言傳的美


&nbsp;


每一個人都想活出一種境界、英雄想要一種豪放的境界


&nbsp;


文人想要一種高雅的境界、偉人想要一種崇高的境界


&nbsp;


我們能看到“人生自古誰無死　留取丹心照汗青”的悲壯


&nbsp;


也能看到“數風流人物　還看今朝”的豪放


&nbsp;


同樣我們也能體會到


&nbsp;


"隨風潛入夜　潤物細無聲"　的清新自然


&nbsp;


大千世界　芸芸眾生　每一個物體都有它自己的境界


&nbsp;


山有它的氣勢，水有它的柔情，星星有它的永恆的美麗


&nbsp;


曇花一現雖在深夜時無人知曉，更沒人欣賞


&nbsp;


但是它的生命同樣精彩過，這是大自然的不同境界


&nbsp;


&nbsp;


&nbsp;


我們應該坦然地面對生活中的每一天


&nbsp;


一年三百六十五天不可能天天有太陽


&nbsp;


人也不可能天天都有好心情


&nbsp;


我們不能要求事事順心如意


&nbsp;


但我們可以做到事事盡心盡力


&nbsp;


我們不可能控制時間　也不能預知明天


&nbsp;


但我們可以控制自己　利用今天


&nbsp;


我們不能要求別人給自己快樂


&nbsp;


但是我們可以在生活中自己尋找快樂


&nbsp;


這樣我們將會生活的輕鬆自如


&nbsp;


人活著為了體現自身的價值


&nbsp;


追求完美的幸福才有了不息的奮鬥


&nbsp;


&nbsp;


&nbsp;


也許我們無法改變生活的品質


&nbsp;


但是我們可以改變自己的心態


&nbsp;


&nbsp;


&nbsp;


如果我們能以“不以物喜　不以已悲"&nbsp;的平和心態


&nbsp;


樂觀向上的、積極的面對一切


&nbsp;


我們的世界就會變得美麗多彩


&nbsp;


在這個社會上，人的地位與能力都是相對的


&nbsp;


我們沒必要求得別人的認可，




只要我們努力了，我們可以自己認可，




事在人為、境由心造


&nbsp;


讓我們多些快樂、少些煩惱


&nbsp;


多些自信、少些遺憾，




相信我們都能做到


&nbsp;


寵辱不驚　笑看庭前花開花落


&nbsp;


去留無意　任由天外雲卷雲舒
