&nbsp;

&nbsp;

&nbsp;





&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

不要只因垂涎我姿色就愛上我。&nbsp;
因為，很快的，我會年華老去，
我的額頭會出現皺紋，

我的身材會走樣，我會青春不再。



不要只因一時的感覺就愛上我。
因為，這種飄渺的感覺太不可靠，


生命週期太短暫，
有一天他要離開的時候，

他只需要告訴我：因為沒感覺了。&nbsp;

不要只因我柔順就愛上我。
因為，這樣一來，

我便失去了表達意見的理由，
我在愛情裡便失去了抗議的權利，

只能做一個無聲的子民。&nbsp;

不要只因我的笑容就愛上我。&nbsp;
因為，我從不對外人表現任何不悅，
我只對自已人傾訴

我的寂寞、我的傷心、我的忿怒、我的眼淚，

只讓我愛的人看見。&nbsp;



不要只因我鬼點子多就愛上我。
因為，我不知道那一天我會江郎才盡，
我不知道，那一天，

你又會愛另一個更有才華的人。&nbsp;

&nbsp;

&nbsp;

&nbsp;


更不要因看電影沒人陪、寂寞少個人擁抱、

&nbsp;

逛街沒人讓他牽、摩托車後座多個位，


這樣才說愛上我，

&nbsp;

這樣的需求，太多人可以滿足他，

&nbsp;

並不需要非得我來不可。&nbsp;

&nbsp;

&nbsp;

&nbsp;


我要一個了解我後，才說愛上我的人。

&nbsp;

&nbsp;

&nbsp;


了解一個人需要花多少的時間呢？


等你我了解彼此的時候，

已經花了多少的時間？


而你，到時候還會不會愛上我？&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

幸福常常像貓和他的尾巴，

&nbsp;

&nbsp;

&nbsp;

所以當貓決定努力往前走時，



&nbsp;


幸福就跟在後面了。
