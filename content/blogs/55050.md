有時候喜歡比愛還要幸福

&nbsp;

&nbsp;&nbsp;&nbsp; &nbsp; &nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

&nbsp;


因為喜歡......比較容易解決

&nbsp;

喜歡可以淡淡地不必怕被太濃的愛給沖昏了頭

&nbsp;

毫無理智地猜忌、懷疑、生氣、傷心 .......

&nbsp;

喜歡可以說來就來說走就走

&nbsp;

偶爾忽然想起的思念也會帶來柔柔的滿足感

&nbsp;

只是想就會覺得很幸福

&nbsp;

可是愛就會逼的自己想就一定要見得到　

&nbsp;

聽得到碰得到&nbsp; 反而會讓情人誤以為無理取鬧

&nbsp;

喜歡雖然不比愛可貴

&nbsp;

但是喜歡就像是夏天的巧克力聖代　

&nbsp;

很單純的必須


喜歡會讓兩顆心慢慢地加溫&nbsp; 可是又害怕溫度升的太高　

&nbsp;

兩個人都會熱過頭受不了

&nbsp;

因為它開始輕敲起“愛”的那扇門囉


&nbsp;

喜歡就像一首喜歡聽的歌

&nbsp;

可以一邊洗澎澎一邊唱可以一邊讀書一邊聽

&nbsp;

想聽就聽想唱就唱沒有限制沒有規定

&nbsp;

喜歡可以很輕鬆很簡單就只是喜歡

&nbsp;

喜歡喜歡他的感覺喜歡聽他唱歌聽他說話

&nbsp;

喜歡他的笑聲喜歡他說好心疼　

&nbsp;

喜歡他溫柔的體溫

&nbsp;

喜歡他可愛的煩悶喜歡他無理的喜歡


&nbsp;

因為喜歡就喜歡只要感覺喜歡

&nbsp;

又何必一定要變成愛又何必一定要永遠都喜歡

&nbsp;

只要那一刻是真正的喜歡就緊緊抓住那感覺

&nbsp;

不要讓感覺消失不見了才在遺憾


&nbsp;

喜歡不必很複雜就算他有女朋友　

&nbsp;

我還是可以喜歡

&nbsp;

因為我只是喜歡我並不是想要愛的霸佔

&nbsp;

我也可以喜歡他對她的溫柔　

&nbsp;

喜歡她為他的付出綻放幸福的笑容

&nbsp;

感情不是束縛而是了解的幸福貼心的感動

&nbsp;

如果一個人失去了喜歡的能力那是比愛更可悲的

&nbsp;

在我有能力喜歡人的時候不管他的“背景”如何

&nbsp;

我只想要單純的喜歡他就好

&nbsp;

喜歡不必有承諾　喜歡沒有壓力 

&nbsp;

喜歡不必有結果　只要當時能擁有釋懷的感動 


&nbsp;

喜歡像氣球當你灌滿喜歡的氣息　

&nbsp;

它就可以在空中盡情地飄蕩～

&nbsp;

當它飄遠了飛高了你也抓不住他了

&nbsp;

所以當你喜歡一個人的時候

&nbsp;

不要害怕那感覺而急著想要拉住它　

&nbsp;

為什麼要勉強自己不要喜歡呢

&nbsp;

輕輕地輕輕地放開你的手　

&nbsp;

讓它自由自在地飄它會有停歇的時候 

&nbsp;

好好地享受喜歡的感覺吧!
