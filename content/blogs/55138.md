&nbsp;

&nbsp;

你的...我的...永遠也會變短暫

&nbsp;

我的...你的...霎那也成了永恆

&nbsp;

有些話&nbsp;&nbsp;風裡來風裡去&nbsp; 最後都虛空了

&nbsp;

有些人&nbsp; 錯過身回錯頭&nbsp; 終究成了遺憾&nbsp;

&nbsp;

&nbsp;

男人女人 這世界是這樣區分性別的

&nbsp;

好人壞人 這世間是這樣黑白分明的

&nbsp;

中間灰色地帶 最是惹人心疼

&nbsp;

&nbsp;

我愛過的男男女女啊 我要你們都幸福

&nbsp;

這樣才不能抹滅我對愛的記憶

&nbsp;

我怨過的男男女女啊&nbsp; 我更要你們幸福

&nbsp;

被禁錮的枷鎖才能讓彼此重見光明

&nbsp;

&nbsp;

我的深海包容著悲傷與快樂

&nbsp;

我的深海藏匿著幸福與哀慟

&nbsp;

然而我的深海沒有放棄過

&nbsp;

ㄧ點一滴&nbsp; 生命隨著時間流逝

&nbsp;

深海擁有的緊緊都存放心中

&nbsp;

總結是---生命可喜 因為愛與感動
