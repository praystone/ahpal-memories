男女之間..

&nbsp;

女人要悄悄知道的十件事


&nbsp;

&nbsp;

&nbsp;


一︰愛人就是愛人，只要去愛，不要拿來比較，
&nbsp;
不要老說別人的老公如何如何好，別數落他沒出息，
&nbsp;
你是他最親密的人，你還這麼說他，好像不太應該， 
&nbsp;
對大多數男人來說，

&nbsp;

贊賞和鼓勵比辱罵更能讓他有奮鬥的力量。
&nbsp;
何況，愛他還忍心傷害他嗎？愛他一定要尊重他，
&nbsp;
再生氣也不可以出口傷人，

&nbsp;

言語的傷口有時一生都在流血的。
&nbsp;
身體的傷害很容易治癒，精神的傷害後果是可怕的。
&nbsp;
&nbsp;
二︰不可以整天追問對方愛不愛你。
&nbsp;
他若真愛你，你不必問；他若不愛你，
&nbsp;
他已做了你的丈夫，難道他會對自己的妻子明確地承認嗎？
&nbsp;
除非他不想要這段婚姻了。
&nbsp;
他對你的愛，用心去體會就品味出來了。
&nbsp;
愛是做出來的，不是說出來的。
&nbsp;
老掛在口頭上不落到實際的愛太蒼白無力，
&nbsp;
婚姻是現實的，生活是現實的，風花雪月的戀愛，
&nbsp;
不是真實的生活。

&nbsp;

婚姻是從柴米油鹽中感受愛的。


三︰不要擺臉色給對方看，一個生氣的女人是很醜陋的。
&nbsp;
他工作已有許多壓力，

&nbsp;

沒有義務回家還要看你的臉色哄你開心。
&nbsp;
對方性格上會有缺點，生活細節會與你不同，
&nbsp;
令你不滿意，但他怎麼可能是完美的，在你面前，
&nbsp;
他要放下面具，做回自己，做個普通人。
&nbsp;
寬容是做人和對待婚姻應有的態度。
&nbsp;
容忍和體諒對方，是很重要的一件事。
&nbsp;
&nbsp;
四︰男人對自己的尊嚴看得比什麼都重要，
&nbsp;
不管在私下他有多麼寵愛你，多麼怕你。
&nbsp;
在人前一定要給足對方面子，

&nbsp;

讓他做天不怕地不怕老婆更不怕的他口中的
&nbsp;
頂天立地的男子漢，

&nbsp;

他應該不大會喜歡朋友們開玩笑取笑
&nbsp;
他怕老婆。除非他有足夠的強大後盾和高高在上的身份，
&nbsp;
可是，我們大多是普通人呀。
&nbsp;
&nbsp;
五︰男人大多喜歡吹牛，你別戳破他的這個小把戲，
&nbsp;
他們這麼樣可以讓自己得到一點力量，
&nbsp;
找到一點自信，好繼續人生征程下面的拼搏。
&nbsp;
虛擬的成就感能讓他心情明朗起來不好嗎？
&nbsp;
沒人喜歡自己一無所是。
&nbsp;
和妻子在一起，做愛是身體的放縱，談話是心靈的放縱，

&nbsp;

只要愛人得到快樂，

&nbsp;

輕鬆一點裝傻附合他一下不是很好嗎？
&nbsp;

六︰男人骨子裡全都喜歡美女，
&nbsp;
看到美女會目不轉睛或回頭行注目禮，
&nbsp;
你別認為他不愛你，也別認為他好色，
&nbsp;
愛看美女是男人的本能，與品格無關。
&nbsp;
何況，愛美知心人皆有之。你難道沒偷看過帥哥嗎？
&nbsp;
&nbsp;
七︰不要太虛榮，不要太功利，

&nbsp;

物質的追求是無止境的，你是活自己，不是活給別人看的，
&nbsp;
鞋子合不合腳只有自個知道，舒服最重要，
&nbsp;
其它的都是裝飾，是虛設。

&nbsp;

何況俗話說︰
&nbsp;
千金易得，有情郎難尋。真愛無價，情義無價。
&nbsp;
&nbsp;
八︰男人為何喜歡溫柔的女人，

&nbsp;

因為他們內心很脆弱，不像外表般堅強，

&nbsp;

他們需要妻子的柔情似水，柔聲細語，輕憐蜜愛。
&nbsp;
知要你有溫雅如蘭的外表和氣質，

&nbsp;

有吐氣如蘭的聲音，有含情脈脈的眼波，

&nbsp;

他們很容易化百煉鋼為繞指柔的，
&nbsp;
溫瑞安有本書叫《溫柔一刀》，溫柔，可以殺死一個男人的，
&nbsp;
對於男人，那是致命的誘惑。


九︰家庭永遠是第一，我們固然要對工作負責，
&nbsp;
要有職業道德，要從工作中得到樂趣，但不要做工作的奴隸，
&nbsp;
我們工作是為了更快樂地和家人在一起， 

&nbsp;

享受生活，享受生命很重要。
&nbsp;

十︰愛人的父母就是自己的父母，
&nbsp;
將心比心，愛屋己屋，老吾老以及人之老，
&nbsp;
只要內心深處真正感到這就是我自己的父母，
&nbsp;
心理上對老人依戀親密，老人會感受到這份真心
&nbsp;
何況，人老了很像孩子，
&nbsp;
只要像哄孩子般哄老人開心就好了。
&nbsp;
我們自己也有老的一天。
