&nbsp;

&nbsp;

 
捨不得放，捨不得忘


&nbsp;




&nbsp;

&nbsp;


思念分分秒秒擋住視線，

&nbsp;

除了你誰也看不見我在每一天喊你一千遍，

&nbsp;

不管你是否出現，我渴望我就是藍天，

&nbsp;

每一片雲煙就散在胸前，

&nbsp;

絲絲縷縷都融進我心間，

&nbsp;

捨不得放過去的好時光，就算有更美的地方。

&nbsp;

&nbsp;

捨不得忘捨不得放，

&nbsp;

我情願就這樣直到地老直到天亮。

&nbsp;

對你我該如何去放手？如何去忘記？

&nbsp;

我不想放，我不想忘！

&nbsp;

可是！當你放開我的手，你已不再回頭，

&nbsp;

不讓你看見我的淚，微笑送你走，

&nbsp;

轉身的背影是那麼無助，為何你不曾回頭？

&nbsp;

&nbsp;

明天我還會再繼續默默地去想你，

&nbsp;

在離去那一刻已明白，走了，不再回頭；

&nbsp;

放了，不再執迷；忘了，不再後悔；

&nbsp;

一切都煙消雲散了。

&nbsp;

煙火短暫的美麗已留在心間，

&nbsp;

何必再去苦苦追尋？可是……你依然：

&nbsp;

駐地在我心，如何讓你離去，

&nbsp;

捨不得放，捨不得忘，思念的心不停的飛向你，

&nbsp;

無聲無息停留在你身旁。

&nbsp;

寂靜的夜，孤單的城市，依然想你。

&nbsp;

一個人的時候，我忘記我還會孤獨。

&nbsp;

希望有一天你也會笑著想我。

&nbsp;

習慣在傍晚；讓思念，忘情地日落！

&nbsp;

不知如何去愛你，只是在靜靜地想你。


&nbsp;
