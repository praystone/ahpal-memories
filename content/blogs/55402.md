&nbsp;

&nbsp;

 
只是一瞬間 



&nbsp;

&nbsp;


想與不想，只是個念頭， 

&nbsp;

說與不說，只是個決定。 

&nbsp;

要觸碰別人傷口之前、

&nbsp;

請先衡量自己有沒有替人包紮傷口的能力。

&nbsp;

在感情的世界裡， 

&nbsp;

如果其中一個人感覺不同了， 

&nbsp;

對另外一個人來說是很慘忍的， 

&nbsp;

一個還在享受著那幸福的味道， 

&nbsp;

而另一個卻已深陷在痛苦之中。

&nbsp;

我們都認為，愛一個人就是要對他好， 

&nbsp;

對他好的同時，

&nbsp;

是不是也要去考慮到對方要不要這份好？ 

&nbsp;

沒錯；你不能阻止任何一個人，　

&nbsp;

對你好、喜歡你、或愛你、

&nbsp;

如果他沒有要求相對的回報，那也是他的權力。 


&nbsp;

分手的時候，

&nbsp;

很多當初喜歡對方的原因，　

&nbsp;

都成了分手的理由和藉口， 

&nbsp;

有人說：愛一個人就是愛，說不出原因的， 

&nbsp;

但是通常要求分手時，

&nbsp;

對方一定要逼你說出一個原因來， 

&nbsp;

等你說出口時，他又會說就因為這個原因？ 

&nbsp;

你就要我放棄那麼多年的感情？ 

&nbsp;

我們辛苦經營了那麼久！怎能說放就放？ 

&nbsp;

愛真的可以不求回報嗎？ 到底，

&nbsp;

兩個人在一起是因為不甘心就這樣放手， 

&nbsp;

還是因為習慣了？

&nbsp;

或是因為真的還相愛著？ 


&nbsp;
