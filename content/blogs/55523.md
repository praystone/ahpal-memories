整整五小時&nbsp; 淚海淹沒了快樂

&nbsp;

你說 讓我自由&nbsp; 

&nbsp;

這次是我願意擁抱悲傷

&nbsp;

請讓我留下

&nbsp;

&nbsp;

整整ㄧ顆心&nbsp; 迅速碎裂了夢想

&nbsp;

我說 讓我離開

&nbsp;

這次是我願意擁抱悲傷

&nbsp;

請讓我遠去

&nbsp;

&nbsp;

望不穿你眼裡的情意

&nbsp;

我只好先蓄滿水滴

&nbsp;

猜不透你心裡的愁緒

&nbsp;

我只能靜默著陪你

&nbsp;

&nbsp;

多苦 很無奈 但我也願意

&nbsp;

我只是失去某些快樂而已

&nbsp;

我只是失落某些祝福而已

&nbsp;

我只是回到封鎖的原點而已

&nbsp;

不是可惜&nbsp; 是心已經關上而已

&nbsp;

不再妄想&nbsp; 是心已經鎖死而已

&nbsp;

只剩下你&nbsp; 幸不幸福&nbsp; 老天奪定

&nbsp;

&nbsp;

&nbsp;
