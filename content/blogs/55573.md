聽說、愛情很美

&nbsp;



&nbsp;

&nbsp;


我，翻閱所有的書，我，找尋適合的路！

&nbsp;

一頁一本翻閱，看到的，是別人說的評書。

&nbsp;

感覺，愛情多途。


&nbsp;

我，生長在盆中的土，我，攀沿在盆中的樹。

&nbsp;

一腳一步旅途，站著的，是自己要的國度。

&nbsp;

履步，愛情迷途。


&nbsp;

我，迷茫在牆中堵，我，支撐在牆中弧。

&nbsp;

一磚一瓦拼圖，建造的，是自己有的依附。

&nbsp;

呼吸，愛的幸福。

&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

我，翻越過生命的乾枯，我，刻畫著生命的腳步。

&nbsp;

一呼一吸領悟，感受的，是自己有的幸福。

&nbsp;

回憶，星的最初。


&nbsp;

我，安靜回想陽光的溫度，我，安靜開始月光的孤獨。

&nbsp;

一睜一閉觀看，閃爍的，是自己看的星圖。

&nbsp;

飛翔，夢的旅途。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

我，帶上白色翅膀在空中飛舞，

&nbsp;

我，伏於赤色土地在聆聽心述。

&nbsp;

一起一仆休憩，擁有的，是自己心的守護。


&nbsp;

我，開始想，愛，開始路，

&nbsp;

它，將以怎樣的方式指引我的腳步？

&nbsp;

它，也許，有著等待， 

&nbsp;

坐在可以提供幻想的有花的國度，

&nbsp;

凝望可以看見遠方的有路的前途。

&nbsp;

等待著，更近或是更遠的幸福的追逐。


&nbsp;

它，也許，伴著獨舞。

&nbsp;

站在一個人的舞台上掂起腳步，

&nbsp;

移動一個人的身體來隨風飛舞，

&nbsp;

飛舞著，更真或是更幻的幸福的舞步。


&nbsp;

它，也許，藏著巨毒。

&nbsp;

細數著有過的針針上癮的毒，

&nbsp;

畏懼著將有的枝枝傷人的樹，

&nbsp;

踟躇著，更淺或是更深的幸福的巨毒。


&nbsp;

也許，想著沉睡。

&nbsp;

沉睡在已看不到頂端的這棵愛情的樹，

&nbsp;

倚靠於粗枝枯葉間與白雪傳遞著溫度；

&nbsp;

沉睡著，更溫或是更冷的幸福的掌管神父。
