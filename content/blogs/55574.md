人就這麼一輩子



&nbsp;

&nbsp;


人就這麼一輩子，生不帶來死不帶去的一輩子。

&nbsp;

我們在親人的歡笑聲中誕生，又在親人的悲傷中離去。

&nbsp;

而這一切我們都不知道，

&nbsp;

我們無法控制自己的生與死，

&nbsp;

但我們應慶幸自己擁有了這一輩子。

&nbsp;

&nbsp;

人就這麼一輩子，但在生活中，不是一切都盡人意，

&nbsp;

每天我們都會遇到各種各樣的困難和煩惱。

&nbsp;

人活一輩子，會遭遇多少無可奈何的事，

&nbsp;

邂逅多少恩恩怨怨的人。

&nbsp;

可是想到人不就這麼一輩子嗎，有什麼好看不開的？

&nbsp;

人世間的煩惱憂愁，

&nbsp;

恩恩怨怨幾十年後不都煙消雲散了，

&nbsp;

還有什麼不能化解，不能消氣的呢。

&nbsp;

&nbsp;

人就這麼一輩子，我們不能白來這一遭。

&nbsp;

所以讓我們從快樂開始！做你想做的，愛你想愛的。

&nbsp;

做錯了，不必後悔，

&nbsp;

不要埋怨，世上沒有完美的人。

&nbsp;

跌倒了，爬起來重新來過。

&nbsp;

不經風雨怎能見彩虹，相信下次會走得更穩。

&nbsp;

&nbsp;

人就這麼一輩子，

&nbsp;

不要去過份地苛求，不要有太多的奢望。

&nbsp;

若我們苦苦追求過卻還是一無所獲，我們不妨這樣想：

&nbsp;

既然上帝不偏愛於我，不讓我鶴立雞群，

&nbsp;

不讓我出類拔萃，我又何必硬要去強求呢？

&nbsp;

別人聲名顯赫，而自己卻平平庸庸。

&nbsp;

我們不妨這樣安慰自己：

&nbsp;

該是你的，躲也躲不過；不是你的，求也求不來。

&nbsp;

&nbsp;

人就這麼一輩子，

&nbsp;

我們又何必要費盡心思絞盡腦汁地去佔有

&nbsp;

那些原本不屬於我的東西呢？

&nbsp;

金錢、權力、名譽都不是最重要的，

&nbsp;

最重要的還是應該善待自己，就算擁有了全世界，

&nbsp;

隨著死去也會煙消雲散。

&nbsp;

&nbsp;

若我們要是這樣想，

&nbsp;

我們就不會再為自己平添那些無謂的煩惱了。

&nbsp;

人就這麼一輩子，沒有來世。

&nbsp;

所以讓我們從微笑開始！人活一輩子開心最重要。

&nbsp;

人就這麼一輩子，

&nbsp;

好好地去珍惜它，善待它，把握它吧！
