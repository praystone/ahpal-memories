&nbsp;

 
你是我今生最美的思念

&nbsp;



&nbsp;

&nbsp;


有一種美酒一小滴就叫人回味，

&nbsp;

有一種音樂一小段就叫人陶醉，

&nbsp;

有一種書看過還叫人百看不厭，

&nbsp;

&nbsp; 有一種人一認識就叫人感到溫馨。

&nbsp;

可愛的朋友，那就是你，你是我今生最美的思念。


&nbsp;

靜坐電腦窗前，苦等好友上線，

&nbsp;

千絲萬縷情緣，盡在屏前展現， 

&nbsp;

明知網聊交友，為何情意綿綿？

&nbsp;

明知不能相依，為何夢縈魂牽？

&nbsp;

這是愛的執著，這是心的呼喚，

&nbsp;

人間真情在，相遇也是緣。你是我今生永遠的思念。


&nbsp;

風清清，雲淡淡，雨細細，情綿綿。

&nbsp;

網路相識便是緣，讓鍵盤敲上我的祝福，

&nbsp;

讓滑鼠點擊我的祝願：願你快樂每一天！

&nbsp;

你是我今生永遠的思念。


&nbsp;

有一種距離叫遠，有一種相遇叫緣。

&nbsp;

有一種情懷叫思念，有一種關心叫無言。

&nbsp;

有一個人在天邊，她有一個小心願，

&nbsp;

願你快樂每一天！你是我今生永遠的思念。


&nbsp;

相識是緣起，相知是緣續。 

&nbsp;

是緣使我們走到了一起，你我有緣相逢在這一時空。

&nbsp;

讓我陪你分享這一生的夢，

&nbsp;

讓我陪你分擔這一生的愁，

&nbsp;

讓我們珍惜緣份直到永久，你是我今生永遠的思念。
