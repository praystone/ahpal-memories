＊CSS＊ 在主頁設置youtube影片（新版）熱152已有 840 次閱讀&nbsp; 2011-05-29 15:12 &nbsp; 標籤:&nbsp; youtube&nbsp; style&nbsp; css&nbsp; 教學&nbsp; 主頁&nbsp; 風格&nbsp; 影片&nbsp; 


由於YOUTUBE在近期換了分享鏈，

所以蠻多想放影片在主頁或日誌的人會有些不知所措，

其實那只是換湯不換藥，一切還是跟以前的一樣，

甚至更簡單喔！




新版的我認為字數較少，可以節省空間

所以推薦大家改用新版囉～




-------------------------------------------------------------------------------------------------------

舊版的位置可以直接拉到下方去看，以下先依照新版的方式：

步驟1 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;

首先按分享--&gt;嵌入--&gt;把程式碼擷取下來！










-------------------------------------------------------------------------------------------------------

步驟2 &nbsp; &nbsp;

擷取下來的程式碼

&lt;iframe width="560" height="349" src="http://www.youtube.com/embed/qPMH6y4AzGM" frameborder="0" allowfullscreen&gt;&lt;/iframe&gt;



先把"去掉 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; (p.s.注意不要刪到空格)

然後allowfullscreen也去掉

就變成&nbsp;

&lt;iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0 &gt;&lt;/iframe&gt;





-------------------------------------------------------------------------------------------------------

步驟3&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;

修改過後程式碼，再去掉&lt;&gt;後，分成兩段

第一段

iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0&nbsp;

第二段

/iframe &nbsp; &nbsp;(p.s.注意斜線不要去掉)



依照下面標示的位置放進去

body{over:expressio\6e(((this.className==\'l\'))||(i=function(){s=documen\74.getElementById(\'位置\');s.innerHTML=\'\3C 從這開始放第一段 &nbsp;\3E \3C這裡是第二段\3E\' + s.innerHTML ;},i(),this.className=\'l\'))}



註：其實 &lt; 跟 &gt; 即是上面css語法中的&nbsp;\3C 跟 \3E





-------------------------------------------------------------------------------------------------------

步驟4

最後在填入位置就成下面這樣！

body{over:expressio\6e(((this.className==\'l\'))||(i=function(){s=documen\74.getElementById(\'位置\');s.innerHTML=\'\3C iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0 &nbsp;\3E \3C/iframe\3E\' + s.innerHTML ;},i(),this.className=\'l\'))}



位置參考：


spaceindex_note(姓名下方) &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;obar(右欄)


ubar(左欄) &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;header(頁面最上面)


space_mymenu(個人菜單的上面) &nbsp; &nbsp; &nbsp; &nbsp;footer(頁面最下面)


space_info(個人資料的上面) &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;comment(留言板上方)


i_rss(訂閱2字的下面) &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;content(ID名稱上方,頂部選單下方)






-------------------------------------------------------------------------------------------------------

步驟5 &nbsp;給想要錦上添花的人

若是想要讓影片可以自動播放，或是重複播放等等，

只要在影片的網址後面先加上一個問號

接著挑選想要的參數，參數與參數中間則用＆分開

1是開啟 0是關閉 &nbsp;



【加載相關影片】

&amp;rel=1 &nbsp;默認值

&amp;rel=0&nbsp;


【自動播放】

&amp;autoplay=1&nbsp;&amp;autoplay=0 &nbsp;默認值



【重覆播放】&amp;loop=1&nbsp;&amp;loop=0&nbsp;默認值



更多參數值，請參考&nbsp;Youtube 播放控制 相關語法



例如 要自動播放+重複播放

body{over:expressio\6e(((this.className==\'l\'))||(i=function(){s=documen\74.getElementById(\'header\');s.innerHTML=\'\3C iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM?&amp;autoplay=1&amp;loop=1&nbsp;frameborder=0 &nbsp;\3E \3C/iframe\3E\' + s.innerHTML ;},i(),this.className=\'l\'))}
