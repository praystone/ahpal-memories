&nbsp;











&nbsp;

在閒暇之餘總是喜歡上網瀏覽空間

&nbsp;

從每個人的文字中體味

&nbsp;

游離在網路裡各類人的心態

&nbsp;

感動裡面演繹的是一個個美麗的愛情故事

&nbsp;

而每一種感情的答案卻是截然不同的

&nbsp;

我們的內心都希望能真 情 永 遠

&nbsp;

&nbsp;

有些時候不想和任何人說話

&nbsp;

只想一個人靜靜的發呆

&nbsp;

明明自己心裡有很多話想說

&nbsp;

卻不知從何說起?如何表達?

&nbsp;

有時候覺得自己擁有了整個世界

&nbsp;

一瞬間卻又覺得自己其實是一無所有

&nbsp;

明明身邊有很多朋友卻依然覺得孤單

&nbsp;

我是這樣告訴自己的

&nbsp;

在丟了自己的時候

&nbsp;

一定要記得撿回來

&nbsp;

再寂寞也要自己品嘗自己的滋味

&nbsp;

&nbsp;

有沒有這樣的一個時刻

&nbsp;

有沒有那樣的一首歌

&nbsp;

是在深夜看滿天繁星點點時

&nbsp;

你會想起我嗎?又是如何想起我的呢?

&nbsp;

是沈默還是微笑是欣喜還是失望

&nbsp;

其實是想問問你何時你才會來找我

&nbsp;

&nbsp;

人的一生像脫離不了「等」這個字

&nbsp;

有些人心很急總覺得「等」讓人不耐煩

&nbsp;

在等的過程中急躁難安當

&nbsp;

閱盡人世滄桑看過許多人心與人性後

&nbsp;

終於明白人世間的一切有很多的事

&nbsp;

與因緣都是老天既有的安排

&nbsp;

有些人始終會是你最深的傷痛

&nbsp;

有些事始終不是你想要的結果

&nbsp;

&nbsp;

日記文章或許是紀錄自己的生活點滴

&nbsp;

也是分享自己的點點滴滴

&nbsp;

部落格是可以分享的

&nbsp;

也可以是很單純的紀錄自己

&nbsp;

不用刻意寫下的一種自在

&nbsp;

想寫就寫想分享就分享

&nbsp;

只要我喜歡有什麼不可以的呢

&nbsp;

&nbsp;

寂寞的人渴望著相聚

&nbsp;

但是又害怕相聚後的別離

&nbsp;

通常寂寞的人都喜歡獨來獨往

&nbsp;

寂寞的人喜歡與文字為伍

&nbsp;

因為寂寞的時候陪伴著他們的

&nbsp;

除了文字還是文字

&nbsp;

把快樂帶給別人把悲傷留給自己

&nbsp;

寂寞的人唱著寂寞的歌寫著寂寞的故事

&nbsp;

寂寞的人寂寞的心其實很寂寞只是不想說

&nbsp;

&nbsp;

有時候太多的言語擠壓了聆聽的空隙

&nbsp;

穿過重重人群接收四面八方的聲音

&nbsp;

也看盡各式各樣的行徑

&nbsp;

知道身外的一切都是幻象

&nbsp;

也知曉內在的一切純淨清晰

&nbsp;

有時候什麼也不說什麼也不做

&nbsp;

聆聽來自空間的聲音才能把整個世界

&nbsp;

放進自己的手心裡

&nbsp;
