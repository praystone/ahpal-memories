&nbsp;






&nbsp;

&nbsp;

你問我最愛你什麼

&nbsp;

能不能說你像杯醉人的醇酒

&nbsp;

最愛在這寂靜的夜裡與你相守讓人醉

&nbsp;

醉在不言中

&nbsp;

&nbsp;

你問我最懂得你什麼

&nbsp;

能否形容你是動人的小說

&nbsp;

是融合了多少浪漫和驚奇

&nbsp;

你完全給了我憂與喜最真實的擁有

&nbsp;

就這樣醉著讀著你的心

&nbsp;

&nbsp;

你知道這一生我只為你執著

&nbsp;

管別人心裡怎麼想

&nbsp;

眼怎麼看話怎麼說

&nbsp;

你更知道這一生我只為你守候

&nbsp;

我對你的情怎麼深

&nbsp;

意那麼濃愛那麼多

&nbsp;

當你感到寂寞需要有人擁抱著你

&nbsp;

你可以呼喚我的名字

&nbsp;

在那試煉你的夜裡

&nbsp;

只要想到我的時候我就在你身邊了

&nbsp;

而且我會是最後一個陪在你身邊的人

&nbsp;

&nbsp;

你可以呼喚我的名字

&nbsp;

親愛的，我倆的時間多的是

&nbsp;

親愛的，我以為自己是最寂寞的人

&nbsp;

卻忘記了身邊那雙溫暖的眼神

&nbsp;

再怎麼寂寞又算得上什麼

&nbsp;

只要有你陪著我

&nbsp;

我以為自己可能是最孤獨的人

&nbsp;

卻忽略了心中那份美麗的溫存

&nbsp;

再怎麼孤獨也算不上無助

&nbsp;

因為身邊有你的腳步

&nbsp;

&nbsp;

當我孤獨的時候還可以抱著你

&nbsp;

那是多麼的甜蜜啊

&nbsp;

當我寂寞的時候還可以想著你

&nbsp;

我是多麼的幸運啊

&nbsp;

當我孤獨的時候就這樣抱著你

&nbsp;

一輩子不放棄

&nbsp;

當我寂寞的時候就這樣想著你

&nbsp;

一生都只為你珍惜
