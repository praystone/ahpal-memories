如果失去，你是否會選擇忘記？




&nbsp;

&nbsp;


經歷了人生的滄桑，

&nbsp;

有些事情應該遺忘了，但卻無法忘記……


有這樣一段話：

&nbsp;

有些色彩只適合淡泊，有些馨香只適合清甜，

&nbsp;

有些過去只適合懷念，有些悸動只適合冥想，

&nbsp;

有些節律只適合放在心上。


極喜歡這段話，

&nbsp;

不是所有的玫瑰都應該在情人的手中。

&nbsp;

我們在這個城市中匆匆揮霍著自己的青春和時間，

&nbsp;

一點一點的，

&nbsp;

忘記了所有的事情其實也有脫離它原有的軌跡。


所以，我們就一點一點的，選擇了懷念，

&nbsp;

把這些刻意的、深深的放進原本就已經開始遺忘的腦海裏。

&nbsp;

不知道為什麼，想到看過的一個故事。

&nbsp;

&nbsp;

彼此相愛的男人和女人。

&nbsp;

&nbsp;

男人剛剛給女人買了結婚戒指，卻立刻就要去出差。

&nbsp;

女人雖然不捨，但還是送愛人上了飛機。

&nbsp;

可是男人所坐的飛機卻失事了。


這個時候，女人正在家中，

&nbsp;

精心的怖置她永遠也不會到來的求婚儀式。

&nbsp;

女人有一隻貓。很老。是她和男人的媒人。

&nbsp;

她對貓百般的疼愛。就在男人所在的飛機失事的

&nbsp;

新聞報道播出前一分鐘，她的貓不辭而別。


她以為牠很快會回來，也沒有留心。

&nbsp;

女人還是看見了那則新聞報道。 她沒有哭，

&nbsp;

也沒有任何的確認。她只是呆呆的坐在電視機旁邊。

&nbsp;

&nbsp;

就在這個時候……


男人奇跡般的出現在門口。

&nbsp;

他氣喘吁吁，衣服淩亂。焦急的擁抱著心愛的女人，

&nbsp;

輕輕的說，親愛的，不要怕。

&nbsp;

她這才痛哭出聲。顫抖著哭泣。


後來，女人問男人，你怎麼就回來了？

&nbsp;

男人笑，我臨時突然接到通知，不用去了。

&nbsp;

女人的心終於沉定到底。


&nbsp;

他們結婚了。 男人告訴她，我是多麼的愛你。

&nbsp;

那麼愛你。

&nbsp;

如果我不在了，請相信我，我還是依然愛你。

&nbsp;

女人聽到這裏，連忙輕輕遮住男人的嘴。

&nbsp;

一個月。整整一個月的纏綿。

&nbsp;

他們無時無刻不在說著愛你的甜言蜜語。


&nbsp;

這天男人出去上班。

&nbsp;

她在家裏微笑著等他回來。他的母親突然來訪。

&nbsp;

女人驚訝的看見他的母親穿著黑色的喪服。

&nbsp;

他的母親將一枚她熟悉的戒指放在她的手心，


&nbsp;

說，他過世一個月，也不見你來。

&nbsp;

怕你出什麼事，所以親自送這個來。她震驚的不能言語。

&nbsp;

不可能。他明明早晨還吻過我。他明明還和我生活過一個月。

&nbsp;

她的淚水一滴一滴的掉落。

&nbsp;

他的母親把死亡證明拿給她看。黑暗撲天蓋地的襲來。

&nbsp;

&nbsp;

男人，

&nbsp;

我們姑且還用這個來稱乎這個身份不明的人吧。

&nbsp;

男人下班回家，

&nbsp;

就看見她蜷縮在墻角，用茫然的眼光看著他。

&nbsp;

男人放下包，問:你怎麼了？

&nbsp;

你是誰啊，他不是已經死了麼!

&nbsp;

女人的聲音彷彿來自很遙遠的世界。他明白了一切。


他笑。如果我不在了，你會好好的吧？

&nbsp;

說完，他就轉身離去。女人急忙跟他出去。

&nbsp;

追到一條馬路的時候，發現那裏發生了一起車禍。

&nbsp;

死的是一隻貓。她的貓。


&nbsp;

不久之後，女人離開那個城市。

&nbsp;

我不知道那個回來安慰女人的靈魂究竟是誰的。

&nbsp;

男人的 ? 或是貓的? 但是，我寧願相信，

&nbsp;

他是那個男人和貓的結合。

&nbsp;

他們都想讓今後只有一個人的女人過的很好。


所以，他們只陪她一個月。

&nbsp;

一個月之後，魔法解除，她還是要回到現實。

&nbsp;

她不可能永遠守著一個悲哀的承諾過完一生。

&nbsp;

看到這裏，我覺得自己有些羨慕那個女人。

&nbsp;

她是那麼的幸運。有著兩份穿過了空間界限的愛。

&nbsp;

&nbsp;

仍然想起那段話。


有些色彩只適合淡泊，有些馨香只適合清甜，

&nbsp;

有些過去只適合懷念，有些悸動只適合冥想，

&nbsp;

有些節律只適合放在心上。有些愛情只適合遺忘。


也許你認為遺忘是對愛情的褻瀆。

&nbsp;

可是永遠記得了，就是對它的膜拜嗎。

&nbsp;

&nbsp;

那麼，我想不管是我，還是那個女人，

&nbsp;

或是別的什麼人，終究還是會選擇遺忘。

&nbsp;

遺忘是為了記得。


&nbsp;
