你錯過花季，並不會走進雨季

&nbsp;



&nbsp;


人生有許多的經歷，

&nbsp;

這些經歷並能使人步行，也能困擾人心。

&nbsp;

只有去想明白，才能走得忠實踏實。

&nbsp;

不因為片刻的得失，而大悲大喜，則是成功的人生品質。


&nbsp;

許多的事情，

&nbsp;

總是在經歷過以後才會明白，

&nbsp;

一如感情，痛過了，才會懂得如何保護自己；


&nbsp;

傻過了，才會懂得適時的堅持與放棄，

&nbsp;

在得到與失去中慢慢找回屬於自己生命中的一部分。

&nbsp;

生活不需要這麼多的執著，

&nbsp;

沒有什麼是真的不能割捨，不會放棄。


&nbsp;

在愛情方面，

&nbsp;

如果和自己曾相愛過的人不得不分手，

&nbsp;

那就從他的手中輕輕地抽出手，說聲再見，

&nbsp;

感謝這一路上的情緣，

&nbsp;

然後在落淚之前轉身而去，留下一個瀟灑的背影，

&nbsp;

給自己，也給別人一個笑臉。


&nbsp;

愛情是一種偉大的奉獻。

&nbsp;

喜歡一個人並不一定要和他時刻在一起，

&nbsp;

愛情有時如原野中的百合花，愛它，卻不能攜它而歸，

&nbsp;

否則，它的生命將從此凋零。


&nbsp;

生活中太多的東西如愛情一樣，

&nbsp;

一個人如果喜歡一樣東西，

&nbsp;

並不意味著一定要得到它才是幸福的。


&nbsp;

劉墉曾對他女兒說過這樣一句話：

&nbsp;

“你喜歡，但你不可以。”

&nbsp;

在現實生活中，我們會遇到很多這樣的情況。

&nbsp;

對待人生如同對待愛情。


&nbsp;

人生的每一段真實的感情，

&nbsp;

不管它是甜，是苦，是酸，是辣，

&nbsp;

都是一種美麗的財富。只是經歷過，就曾擁有。

&nbsp;

感情是一份沒有答案的問卷，

&nbsp;

苦苦地追尋並不意味著一定能圓滿。


&nbsp;

也許有一點傷感，有一份遺憾，有幾許眷戀和依戀，

&nbsp;

收拾起這份心情，將它記在筆記裏繼續走。


&nbsp;

如果這樣對待生活或人生中失去的美好東西，

&nbsp;

也不失為一種明智。


&nbsp;

錯過花季，並不就會走進雨季。

&nbsp;

首先，喜歡一樣東西，即使已經失去，

&nbsp;

也學會欣賞它，珍惜它，才會使它更加珍貴。


喜歡一個人，就要讓他快樂，讓他幸福，

&nbsp;

才會使那份感情更純潔。


&nbsp;

在給鳥兒一個自由的天空時，

&nbsp;

自己也會感受到細雨綿綿的情意。


這樣即使錯過了人生路上的許多花季，

&nbsp;

給自己的也並不是一個雨季，相反，因為學會欣賞和珍惜，

&nbsp;

就能等待下個花季的來臨。


&nbsp;
