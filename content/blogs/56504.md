像貓一樣無聲無息溜進你的被窩

&nbsp;

暖好被....才發現你這裡是盛夏的火爐

&nbsp;

&nbsp;

像蟲一樣轉來彎去的爬上你胸膛

&nbsp;

想親吻....才知道你已經開始沐浴

&nbsp;

&nbsp;

喔....親愛的....我只是做白工而已

&nbsp;

你毋須瞪眼生氣

&nbsp;

我...親愛的....我只是被沖刷而已

&nbsp;

你無須為我嘆息

&nbsp;

&nbsp;

我仍然無畏懼 我還在努力暖被

&nbsp;

會選在寒冬的季節裡....

&nbsp;

天知道那個幸運兒絕不是你

&nbsp;

&nbsp;

我仍然無畏懼 我還在努力親吻

&nbsp;

會選對時間唱進行曲....

&nbsp;

我知道那個好運人絕不是你

&nbsp;

&nbsp;

我像貓一樣安靜&nbsp; 等待中頑皮

&nbsp;

我像蟲一樣律動 忙碌中無語

&nbsp;
