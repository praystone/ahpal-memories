&nbsp;

&nbsp;

我...想你了

&nbsp;

就這麼靜靜地想你...
&nbsp;

&nbsp;

想知道你在做什麼

&nbsp;

想知道你有沒有在想我

&nbsp;

想知道當凝視遠方的時候

&nbsp;

你的眼前是否劃過我的身影?

&nbsp;

就這麼靜靜地想你...


&nbsp;

有人說:有一個能思念的人 也是一種幸福

&nbsp;

想著你的時候&nbsp; 我想&nbsp; 我是幸福的


&nbsp;

在這個平淡的夜晚

&nbsp;

因為想起了你

&nbsp;

這個夜晚變得美麗而憂鬱

&nbsp;

靜靜地想著你

&nbsp;

我祈求

&nbsp;

祈求這一刻的寧靜、永恒

&nbsp;

&nbsp;

我喜歡這樣想你

&nbsp;

讓自己的心

&nbsp;

有了柔柔的疼痛和幸福的甜蜜

&nbsp;

&nbsp;

不經意間

&nbsp;

我會靜靜地想你的名字&nbsp; 

&nbsp;

很多時候

&nbsp;

就這樣靜靜地想一個人

&nbsp;

其實也是一種幸福、一種期冀 

&nbsp;

&nbsp;

佛說：

&nbsp;

前世的五百次回眸

&nbsp;

才換來今生的擦肩而過 

&nbsp;

我會用一萬次回眸

&nbsp;

換取與你的一次相遇

&nbsp;

再用我如花雲的心

&nbsp;

柔柔的疼你 

&nbsp;

&nbsp;

在某個遙遠的地方

&nbsp;

我隱約又開始靜靜的想你了... 

&nbsp;

你在忙些什麼？

&nbsp;

是否有按時吃飯、睡覺？

&nbsp;

是否有好好善待自己？

&nbsp;

&nbsp;

夜&nbsp; 深了

&nbsp;

卻了無睡意

&nbsp;

就讓自己坐下來

&nbsp;

靜靜的想你好了 

&nbsp;

想知道當你走進甜美的夢鄉

&nbsp;

是否看到我在夢的路口等你？

&nbsp;

&nbsp;

開始喜歡靜靜地坐在這兒想你

&nbsp;

雖然

&nbsp;

我不知道這樣想你

&nbsp;

你是否能真切地感受到？

&nbsp;

如果...你常常會有一種莫名的心動 

&nbsp;

你是否會想到那是因為我在想你

&nbsp;

&nbsp;

不知從何時開始

&nbsp;

我隨時都會想起你

&nbsp;

有的時候思念就像正在洶湧的大海 

&nbsp;

一波高過一波

&nbsp;

綿延不絕... 

&nbsp;

&nbsp;

無論我在世界哪個角落 

&nbsp;

無論我在做什麼 

&nbsp;

我都會如此劇烈的想你

&nbsp;

那是一種巨大的孤獨

&nbsp;

只因為你不在我身邊...... 

&nbsp;

&nbsp;

我曾經嘗試著每天不再那麼想你

&nbsp;

此刻我才發現

&nbsp;

原來想你已成一種習慣

&nbsp;

&nbsp;

戒不了想你

&nbsp;

戒不了心疼你

&nbsp;

說好了要少想你的

&nbsp;

可是不知道為何又想起了你 


&nbsp;
夜很安靜

&nbsp;

無法寧靜的

&nbsp;

可能就是我想你的心了...

&nbsp;
