&nbsp;

 


愛不在於距離，而在於心的遠近 

&nbsp;



&nbsp;

&nbsp;


曾經我聽過這樣一句話

&nbsp;

『一對戀人就像時鐘裡的時針和分針

&nbsp;

無論誰走的快，誰走的慢

&nbsp;

它們總繞著同一個點，一直走到海枯石爛』

&nbsp;

我不知道這句話的起點，也不知道多少人說過

&nbsp;

或許我聽到的並不是原版

&nbsp;

或許它在流傳的過程中改變了許多次

&nbsp;

或許它的原意並非我所想的那樣

&nbsp;

但我認為它所表現的是一種完美的愛情
&nbsp;

&nbsp;

真正的愛是什麼

&nbsp;

有人說『真正的愛就是自私』

&nbsp;

當一個人把所有的感情都放在另一個人身上時

&nbsp;

那麼他會認為他所愛的人就屬於自己

&nbsp;

因為他們擁有的都是彼此的一切

&nbsp;

強烈的佔有欲便是愛的表現

&nbsp;

兩個人每天像是被膠黏上一樣，沒有個人的空間

&nbsp;

這種人愛起來，會愛的被人嫉妒

&nbsp;

因為他們會把自己的熱情表露其外

&nbsp;

因為他們要告訴別人，他們是多麼相愛

&nbsp;

他們的愛是多麼深刻，多麼的不可分離

&nbsp;

其實他們要說的就是她/他是多麼愛我

&nbsp;

她/他不會離開我，她/他只屬於我
&nbsp;

&nbsp;

他們的眼裡不會留一粒沙子

&nbsp;

當愛人多了一些親密的異性朋友時

&nbsp;

他們就會像一條經嚴格訓練的看家犬一樣

&nbsp;

瞪著機警的眼睛，發出警告的犬吠

&nbsp;

必然的時候他們還會用力的咬住『外侵者』的褲管

&nbsp;

讓他/她不能靠近，自己辛苦保護下的一切

&nbsp;

這樣的愛就像熱情的紅玫瑰

&nbsp;

開的時候很美，很燦爛

&nbsp;

每個人都嚮往這樣的愛情，看起來轟轟烈烈

&nbsp;

但當激情過後

&nbsp;

當自己的朋友怕瘋狗咬到，越來越少的時候

&nbsp;

當自己無法自由安排自己時間的時候，紅玫瑰凋零了

&nbsp;

愛情則成了累贅

&nbsp;

當一個人背者一個包袱，氣喘吁吁的去戀愛時

&nbsp;

她/他會感受的愛情的甜美嗎

&nbsp;

玫瑰開時美，凋謝的也快，這樣，愛情便枯萎了
&nbsp;
愛不在於距離，而在於心的遠近


&nbsp;

泰戈爾說過

&nbsp;

『世界上最遙遠的距離不是生與死的距離

&nbsp;

不是天各一方的距離

&nbsp;

而是我就站在你面前，你卻不知道我愛你』

&nbsp;

距離不是問題，問題是倆個人的心是否相通

&nbsp;

當一個人愛上另一個人的時候就是心靈的觸動

&nbsp;

不在乎身隔千山萬水

&nbsp;

只要想到他是愛我的，那就是幸福真正的愛就是這樣的

&nbsp;

不用每天都綁在一起，也不用總是把甘言蜜語掛在嘴邊

&nbsp;

更不用戒備她有一天會被偷走

&nbsp;

愛他，就要求永遠的信任她

&nbsp;

讓她陪著自己幸福的走以後的路

&nbsp;

『執子之手，與子偕老』是永恆不變的愛情經典

&nbsp;

愛情就是這樣自然、甜蜜、幸福的感覺

&nbsp;

沒有苛求，只是一種心與心的交流
&nbsp;

&nbsp;

當愛人冷了時，不用說，一件衣服披在肩上

&nbsp;

無論衣服是薄是濃，是否可以抵御寒冷

&nbsp;

但這樣的一個舉動就會使愛人感到溫暖

&nbsp;

當愛人失落時，不用說，把肩膀靠向你

&nbsp;

無論是瘦小還是寬大，能否為你承擔一切壓力

&nbsp;

但這樣一個舉動就會使愛人得到安慰

&nbsp;

當愛人哭泣時，不用說，一塊手帕遞給你

&nbsp;

無論它是新是舊，能否為你抹走傷心

&nbsp;

但這樣的一個舉動就會使愛人享受幸福

&nbsp;

這一切都是一種溝通

&nbsp;

&nbsp;

一種『執子之手，與子偕老』的無聲誓言

&nbsp;

一種心的靠近
&nbsp;

時針和分針，雖然它們的步伐不同

&nbsp;

但是她們繞著同一個點相互追逐

&nbsp;

當分針走一圈時就會與時針相遇一次

&nbsp;

有的人會說『這樣不是很累嗎』

&nbsp;

辛辛苦苦的追了一個小時只能在一起不到一分鐘

&nbsp;

朋友，你錯了


&nbsp;

其實它們時時刻刻都在一起

&nbsp;

不要忘記，它們的心靠在一起，合二為一

&nbsp;

它們圍著自己的心走著、走著

&nbsp;

表面上它們追逐的很辛苦

&nbsp;

但它們的心永遠在一起到天長地久，海枯石爛


&nbsp;

&nbsp;
