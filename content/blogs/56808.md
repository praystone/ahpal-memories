一個苦者找到一個和尚傾訴他的心事。
&nbsp;
他說：“我放不下一些事，放不下一些人。”
&nbsp;
和尚說：“沒有什麼東西是放不下的。”
&nbsp;
他說：“這些事和人我就偏偏放不下。”
&nbsp;
和尚讓他拿著一個茶杯，然後就往裡面倒熱水，一直倒到水溢出來。
&nbsp;
苦者被燙到馬上鬆開了手。
&nbsp;
和尚說：“這個世界上沒有什麼事是放不下的，痛了，你自然就會放下。”
&nbsp;
&nbsp;
你可能覺得難過
&nbsp;
因為無論你對他怎麼好他都不領情
&nbsp;
他不是看不到他只是裝作看不到
&nbsp;
或者他根本不想看到
&nbsp;
你覺得自己很喜歡他
&nbsp;
甚至覺得再沒有一個人可以像你那麼喜歡他
&nbsp;
你用盡全力對他好
&nbsp;
把他看的比自己還重要
&nbsp;
有什麼事情第一個就想到他
&nbsp;
聯繫不到他的時候你擔心他擔心的快瘋了
&nbsp;
然而你有沒有想過
&nbsp;
這並不在你的責任範圍
&nbsp;
而且很有可能他是在躲著你
&nbsp;
他受不了你對他那麼好
&nbsp;
不要一直發短信給他
&nbsp;
不要一直找他
&nbsp;
你也許只是想找他說說話
&nbsp;
你覺得那很正常不算苛求
&nbsp;
但是也許他並不這麼想
&nbsp;
記住你的想法不代表他的想法
&nbsp;
你是真的不求回報的在喜歡他嗎
&nbsp;
你捫心自問一下
&nbsp;
你確定不用他回報什麼嗎
&nbsp;
那為什麼你會難過
&nbsp;
若是真的一無所求
&nbsp;
你又怎麼會覺​​得難過呢
&nbsp;
所以別覺得你那麼愛他是偉大的
&nbsp;
也許她根本不在乎你怎麼為他付出
&nbsp;
有時候你給他的愛或許是種負擔
&nbsp;
這種負擔只會讓他更加想遠離你
&nbsp;
因為他不想虧欠你
&nbsp;
別事事為他擔心為他張羅
&nbsp;
你覺得他沒有你不行
&nbsp;
你覺得別人做不到你那麼完善
&nbsp;
但是你要清楚
&nbsp;
你不是他要的那個人
&nbsp;
你做的再完善也敵不過人家不做
&nbsp;
那個位置本來就不是你的
&nbsp;
你何必硬要擠上去呢
&nbsp;
你說道理你都懂只是你做不好
&nbsp;
喜歡他不是你的錯
&nbsp;
想關心他不是你的錯
&nbsp;
控制不住自己不是你的錯
&nbsp;
但是那是你的方式
&nbsp;
人家不一定就能接受你這種所謂無私的愛
&nbsp;
所以如果你喜歡他他不喜歡你
&nbsp;
那麼就請你默默的
&nbsp;
別試圖讓他知道
&nbsp;
就算你會難過甚至難過的流淚
&nbsp;
就請你默默的
&nbsp;
就算是逼自己也好
&nbsp;
一定要忍著
&nbsp;
&nbsp;
傻孩子。
&nbsp;
忘了吧。所有你留戀的。你回憶的。你擁有過的。
&nbsp;
那些。都已是記憶。
&nbsp;
缺失並不可怕。
&nbsp;
可怕的，是無法面對。
&nbsp;
&nbsp;
傻孩子。
&nbsp;
你無法輕易忘記放棄。是因為你付出過。
&nbsp;
付出了，她就會像柱子一樣紮根在心。
&nbsp;
不要刻意去逃避。刻意忘記。那隻會讓你更痛苦。
&nbsp;
繞開這個柱子。尋找未來的幸福生活吧。
&nbsp;
那裡，有你的理想。
&nbsp;
&nbsp;
傻孩子。
&nbsp;
開始新的習慣吧。
&nbsp;
習慣，每天一個人生活。
&nbsp;
習慣。一個人過生日。一個人行走。
&nbsp;
習慣。走過熟悉的路。面對熟悉的景。
&nbsp;
你逃不掉。逃不掉的。
&nbsp;
那麼，就勇敢面對。現實。
&nbsp;
現實是。一切。畫上了句點。
&nbsp;
&nbsp;
傻孩子。
&nbsp;
勇敢看著鏡子中的自己吧。
&nbsp;
這個悲傷軟弱滿面憔悴的自己。
&nbsp;
這也是你。成長中的你。
&nbsp;
這個你。正在逐漸死去。
&nbsp;
新的你。即將重生。
&nbsp;
找尋你的路，你的未來。
&nbsp;
你知道的，所有的浩劫。都是成長的祭奠。
&nbsp;
做最好的自己。即使。一個人。
&nbsp;
&nbsp;
傻孩子。
&nbsp;
好，好。盡情發洩吧。
&nbsp;
剝開自己的心，用文字，用聲音，用所有能發洩的方式。
&nbsp;
洩完了。就要振作。
&nbsp;
看吧，你失去的。其實微不足道。
&nbsp;
還有那麼多人關心著你。以不同的方式。
&nbsp;
所以，你並不孤獨。
&nbsp;
正是這樣的失去。讓你看清現在所擁有的幸福。
&nbsp;
&nbsp;
傻孩子。
&nbsp;
別哭，別再哭。
&nbsp;
不值得。真的。不值得了。
&nbsp;
把過去塵封吧。別委屈。別不甘心。別不接受。
&nbsp;
開始新的旅程吧。去遇見新的風景。新的際遇。
&nbsp;
做你該做的事吧。有很多事。等待著你完成呢。
&nbsp;
傻孩子。
&nbsp;
生活褪去了曾有的顏色。暫時寧靜。
&nbsp;
別沉淪在這片寧靜裡。那會毀掉你。
&nbsp;
你要明白，雖然殘忍，但這個決定。足夠正確。
&nbsp;
現在的生活，不是你想要的。
&nbsp;
為了你的理想，你必須學會適時放棄。
&nbsp;
給對方最好的關懷。就是。變的更好，更強大，更幸福。
&nbsp;
現在我對你很好，很好，很好，你不需要，你無所謂，你不在乎，你不珍惜。
&nbsp;
當某天，你被傷害，想起我，那時的我再也做不到像現在這樣一如既往，不顧一切的對你好了。
&nbsp;
因為那時的我，已經將你放低。。
&nbsp;
原來，放低一個人，最後是被對方逼出來的
