&nbsp;

&nbsp;

&nbsp;

 
沒有最好的，只有最真的

&nbsp;



&nbsp;


今天和朋友聊了很多


&nbsp;

讓我也想了很多


&nbsp;

人世間，什麼最好？什麼最真？


&nbsp;

什麼是快樂？什麼是幸福？


&nbsp;

人生最寶貴的是什麼？人生最珍惜的是什麼？

&nbsp;

什麼最好？好好做事才是最好


&nbsp;

什麼最真？老老實實做人最真


&nbsp;

什麼最快樂？不做虧心事最快樂


&nbsp;

什麼是幸福？懂得珍惜的人最幸福


&nbsp;

什麼最寶貴？自己的生命最寶貴


&nbsp;

什麼最應該珍惜？婚姻家庭最應該珍惜

&nbsp;

&nbsp;

人生路上


&nbsp;

我們常常會因為孤獨寂寞


&nbsp;

會做很多的傻事錯事


&nbsp;

這些事會讓我們失去原來的純真和溫暖


&nbsp;

在愛情中，因為好奇


&nbsp;

我們會站在十字路口不知道拐彎


&nbsp;

但無論你怎麼樣的行走，都要記得回家

&nbsp;

&nbsp;

其實在人世間


&nbsp;

有一種最寶貴的東西是最值得我們珍惜的


&nbsp;

它就是離我們最近也是最難懂得的東西

&nbsp;

最近讀了很多文字&nbsp; 讓我明白了很多的道理


&nbsp;

&nbsp;

那些深陷在愛情裡的朋友


&nbsp;

愛的越深，越沒有自信。&shy;愛的越深，越在乎別人


&nbsp;

愛的越深，越會失去自己。愛的越深，越沒有自尊


&nbsp;

愛的越深，嘲笑的越狂。&shy;愛的越深，越難回頭


&nbsp;

其實在愛情裡，沒有真正的自己

&nbsp;

『問世間，情為何物』一直不懂它的意思


&nbsp;

&nbsp;

在我的心裡


&nbsp;

其實我覺得情只是自己心裡的一種感覺


&nbsp;

它並代表愛情和婚姻，希望心裡有愛的朋友


&nbsp;

愛別人的同時，好好的愛自己


&nbsp;

好好的珍惜自己所擁有的一切快樂和幸福


&nbsp;



&nbsp;
