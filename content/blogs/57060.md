好想摸摸彩虹......我說

&nbsp;

我會為你搭一座彩虹橋.......你說

&nbsp;

摸摸七彩的紅光....有沒有你血液滾動的熱燙

&nbsp;

輕觸七彩的橘光....是不是懂我夕顏花的哀愁

&nbsp;

貼近七彩的黃光....能不能收藏你真實的那一笑

&nbsp;

我會為你搭長長的彩虹橋........你說

&nbsp;

天空好久好久沒出現過彩虹

&nbsp;

我心裡真的真的沒感受到愛情的那座橋

&nbsp;

我的綠....早就逐漸隱形

&nbsp;

你的藍....漸行漸遠

&nbsp;

找不到的依偎是那深深的暗靛

&nbsp;

遺憾 是我們在無法浪漫的紫

&nbsp;

我會讓你在彩虹橋歇息靜靜望著我.....你說

&nbsp;

彩虹橋在你藍圖中&nbsp; 可惜你忘了建造

&nbsp;

你的紅澄黃&nbsp; 我的綠藍靛紫

&nbsp;

你的驕傲 我的執著

&nbsp;

你.....是你的

&nbsp;

我....走

&nbsp;
