男人是山 .女人是水

男人是山

雄山磅礴亦蛇龍，天斧神開傲此功。

拔地淩雲男兒夢，挺身偉岸入雲蜂。

女人是水

秀氣清流依碧崇，縱橫曲折浪無同。

多情惠我山中戀，嶺峻貪青水愛峰。

&nbsp;

&nbsp;

男人是一座青山，山不在高，只要青翠、挺拔。

男人不在奇，只要踏實、勤勞。

女人是一道秀水，水不在深，只要潔淨、清甜。

女人不在美，只要賢慧、溫柔。

&nbsp;

&nbsp;

好男人是一家之主，

是力量與智慧的象徵，是信念與意志的旗幟。

好女人是一家之魂，

是情愛與母愛的天使，是溫馨與柔情的源泉。

&nbsp;

&nbsp;

男人喜歡女人如水，是因為水是生命誕生的搖籃，一個真正的女人應該像水一樣溫柔多情，女人如水，可以讓東奔西走，為生活打拼的男人歸來時洗清疲憊，洗盡風塵，因為這裏是他棲息的港灣，是他調整身心，酣然入夢的地方。

&nbsp;

&nbsp;

水要秀。女人要不斷努力去豐富自己的內涵，愛的源泉才會永不枯竭。即便男人是好漢，也需要女人用愛情的甘露去滋潤，去撫平他的創傷，消除他的疲憊，幫他鼓起生活的風帆。

&nbsp;

&nbsp;

女人喜歡男人如山，是因為山是堅強剛毅的，一個真正的男子漢應該如山，當風雨來臨時，男人張開羽翼，挺身而出，不讓心愛的女人受到一點點傷害，任憑電閃雷鳴，山巖然兀立，決不動搖。

&nbsp;

&nbsp;

山要青。男人要不斷用知識和能力去充實自己，不愧為家人的靠山。即使自己的女人是女中豪傑，她也願以青山為依託，激勵她走向輝煌。

&nbsp;

&nbsp;

山要青，水要秀，只有水秀山青才是最美的風景。以山水喻男女，因為山水和諧構造世間美麗。人世間有了如山的男人而彰顯浩然之氣，因為有了如水的女人而平添嫵媚春光，人生也因此而精彩。

&nbsp;

&nbsp;

喜歡男人如山，因為山有挺拔的恢弘氣勢，有豪情壯志，男人如山，胸襟開闊,雍容大度，以德服人，雖然山也有奇、險、幽，有風浪驟起的時候，但在如山的男人身邊，就是遇到風險也會溫馨浪漫的度過此生。

&nbsp;

&nbsp;

女人如水，因為水有溫柔和包容的品格，她能給山以足夠的空間，把清涼留給他，讓歡樂嫋繞山，山對水依戀，水對山敬仰，山守護著水，水纏繞著山，山環水繞是人間絕美的畫面，人生有了如山的男人，多了一份陽剛，有了如水的女人，多了一份柔情。

&nbsp;

&nbsp;

要熱愛珍惜自己的這道風景。不要守著這山望著那山，看著這水想那水。要知道，那山那水再好，是別人的風景。強佔為已有，必然會破壞原有的景致。即使能組成新的風景，或殘或缺，也難以實現想像中的美麗。

&nbsp;

&nbsp;

十年修得同船渡,百年修得共枕眠。

能走到一起真的不易。擁有彼此就該去珍惜彼此。
