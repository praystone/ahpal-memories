用心祝福

世間，有「大乾坤」與「小乾坤」。

宇宙是大乾坤，人身是小乾坤。

小乾坤，可以影響大乾坤。

心理的小氣候能對周圍產生影響，

而漸匯成宇宙的大氣候。

所以調和氣候，要從---人的心開始，

人心不淨化，空氣也會不乾淨。

我們生活在同一個地球上，

地球又是圓的，所以我們的距離一定不會太遠。

&nbsp;

時時發揮愛心，天天祝福別人，

一念善心轉，乾坤就轉，

必可降低天災人禍，天地平安。 

•&nbsp;&nbsp;&nbsp; 感恩上天，賜予父母給我們，

讓我們領悟愛，你回報父母的愛了嗎？

&nbsp;

•&nbsp;&nbsp;&nbsp; 你曾擁抱悲苦的陌生人，感恩並表達祝福嗎？

•&nbsp;&nbsp;&nbsp; 手機裡的電話號碼，是不是有一個是鄰居的？

•&nbsp;&nbsp;&nbsp; 每天都要祝福孩子，幫助孩子找出他的秉賦

&nbsp;

•&nbsp;&nbsp;&nbsp; 叛逆期是孩子的人格特質即將成形，需要祝福！

留錢給孩子，不如留德；留下好習慣，

多行善事，孩子一定能用得到。

&nbsp;

教孩子克己復禮的美德，

是比萬貫家財還要重要的資產 。

&nbsp;

雖說心中像水庫般儲存許多許多的愛，

但恐懼、害怕、擔憂會敞開後門，

讓愛流失，感受不到愛，只有恐慌的效應。

&nbsp;

時時喚醒沉睡的心靈，增進心智的力量，

不要讓心放逸。

&nbsp;

過度保護自已、便不容易承擔錯誤。

&nbsp;

要有能力改正錯誤，要認錯也要改過。

&nbsp;

當獨行俠常會遇到創意的瓶頸。

&nbsp;

走入人群，從別人那兒借火，

可以更快點亮創意的蠟燭；

多接觸人群，交有正知、正見的朋友，

就會有正點子。

&nbsp;

每天是否祝福自己，創新自己的觀點，擴展自己的視野？

&nbsp;

當別人固步自封，不肯接納新的想法時，

是否能真誠祝福他，讓他的創意，有更多的成長？ 

&nbsp;

看別人不順眼，是自己的問題。

&nbsp;

如果看到的盡是缺點，他們就變得醜陋。

&nbsp;

每一個人都有其存在的意義和價值，

像這棵蔬菜，是為了奉獻給蟲吃的，沒理由看不順眼。 

&nbsp;

我們要為令人討厭的人、失望的人、結惡仇的人，

虔誠說出祝福的話，祝福他得到更多的愛與信任。

&nbsp;

放空心境，清澈明澄的心境，才能如實地反映事物，

不會被環境所蒙蔽，不會為自己的感情所衝動，

才能面對一切本來的面目，去作正確的反應。

&nbsp;

忍字是心上一把刀，得忍且忍，會內傷，

不如忍而無忍，才能無怨。

&nbsp;

我們無法控制別人用言語刺傷自己，

但能克制自己，用善解來平緩心緒 。

這一生不在於您超越多少人，

而是您超越了多少自己的習氣，

超越了我執，並且也協助多少人，不斷超越自己。

&nbsp;

做一個時時能影響更多人，成為更好的人。

人生中全勝並不是好事，有挫敗才能增加抗壓性，

才能學會自在。

&nbsp;

壓力來自於知道自己的力量有限，

能凝聚他人的力量，才是懂得信任與感恩的智慧。

行惡就是向老天貸款，享受就是向老天提款，

人行善就是向老天存款。

&nbsp;

每天給自己一個祝福，也給他人一個祝福。
