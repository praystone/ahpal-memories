&nbsp;


&nbsp;


你說你的分身會陪我渡過長夜


&nbsp;


此時我有淡淡紫色情懷


&nbsp;


紫的是空氣裡一抹抹的酸意


&nbsp;


紫的是心田裡一陣陣的甜蜜


&nbsp;


&nbsp;


海岸線已經退到很遠的那一邊


&nbsp;


只要是想起腦袋總像要剥離


&nbsp;


是時間還不夠長久


&nbsp;


我知道有種感傷在逗留


&nbsp;


&nbsp;


猜不透你的心思果真很神奇


&nbsp;


給的是一片相思林


&nbsp;


也送了滿天問號在我心裡


&nbsp;


你是個頑皮的老精靈


&nbsp;


&nbsp;


&nbsp;


深海入睡前的雜音




&nbsp;
