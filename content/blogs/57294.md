今天天氣不錯很適合爬山,或許是許久沒有去爬山景物是沒有多大的變化,&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;沿途我們有遇到筍農在採收筍子一個割筍子一個撥筍殼,一路上有許多的蜘蛛網
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;我們發現一隻超大隻的蜘蛛差不多跟我小拇指一樣大.
山上今天有許多的蝴蝶是林內特有紫斑蝶大小隻在沿途的花草中飛舞,
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;也有看到好幾隻蜥蝪,到茶園附近有看到一對鷓鴣鳥在相擁,
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 山上的人家養鵝都沒有關起來讓鵝自行游走吃附近的雜草,
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;我們也在一戶人家門前發現一株長滿黑色辣椒.
回到停車場時在車窗發現一隻竹節蟲,怎麼趕就是不走等車一開動牠就自行走開了,
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;今天爬山看一些平常比較少看到的景物收益良多喔.
