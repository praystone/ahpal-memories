&nbsp;

&nbsp;

 
想念一個人的滋味 

&nbsp;



&nbsp;

&nbsp;


夜色擋不住醉人的溫柔

&nbsp;

淡淡的月光灑下寧靜的細碎

&nbsp;

輝映在我的長髮上，留下了一抹霧一樣的清冷

&nbsp;

手捧一杯清茶，端坐於窗前

&nbsp;

懷想從那一刻開始蔓延，一點一點，直到淹沒了我的思念

&nbsp;

感受著久違的心情

&nbsp;

牽掛著，惦念著，期盼著，渴望著，糾纏著，淡漠著

&nbsp;

複雜的心緒也遮蓋不了我此時的眼睛

&nbsp;

因為，那裡有一顆晶瑩的淚珠兒似乎要滾落

&nbsp;

你會心疼嗎？我想你會的

&nbsp;

&nbsp;

滿天的星斗，閃閃爍爍

&nbsp;

有的耀眼明亮，有的幾乎看不見模樣

&nbsp;

不知道

&nbsp;

這些星斗裡面哪一顆會是屬於你，而哪一顆又會是屬於我

&nbsp;

是否，我們有著同樣的軌跡，永遠也不可能重合

&nbsp;

是否我們有著不一樣的行程

&nbsp;

有一天，我們彼此驚奇的發現

&nbsp;

前面的或者是後面的那顆星星就是你或者就是我

&nbsp;

美麗的夢想隱藏不了滿臉的幸福

&nbsp;

那上面有一絲淺淺的微笑彷彿要綻開

&nbsp;

你會開心嗎？我想你會的

&nbsp;

&nbsp;

遙遠的燈光點綴了夜的黑暗

&nbsp;

霓虹的色彩裝飾了一個一個瑰麗的夢

&nbsp;

月兒朦朧，似嫦娥在揮舞著搖曳的水袖，欲說還羞

&nbsp;

這樣迷醉又浪漫的夜晚

&nbsp;

不需要什麼語言，不需要什麼行為

&nbsp;

只要彼此懂得心靈中共鳴的聲音就夠了

&nbsp;

你心中有我，

&nbsp;

我心中有你靈犀的精神世界裡游走著我們的祕密，

&nbsp;

而心情也不再感到那麼壓抑

&nbsp;

你會陶醉嗎？我想你會的

&nbsp;

&nbsp;

輕柔的風脈脈的吹拂

&nbsp;

彷彿也感覺到了你和我心中滿滿的情誼

&nbsp;

你還好嗎

&nbsp;

我托風兒把我的祝福送給你

&nbsp;

帶著濃濃的思念，帶著長長的牽掛，帶著深深的眷戀

&nbsp;

在這風清雲淡的夜晚，你是否能感知我的想念

&nbsp;

月兒跨越紅塵，傳遞一闕千裡嬋娟的詩篇

&nbsp;

你會幸福嗎？我想你會的

&nbsp;

&nbsp;

靜謐的夜晚，容易讓一個人想念

&nbsp;

往日的點點，涌上心頭，徘徊久久

&nbsp;

原來，即使時光流逝

&nbsp;

心中也無法忘卻這一段浪漫的情緣，任思念蔓延

&nbsp;

釋放滿懷的柔情，盡情演繹溫柔的眷戀

&nbsp;

一顆流星劃過夜空，留下墜落的光華點點，知道嗎

&nbsp;

那就是我為你送上的美好心願，用心的凝望好嗎

&nbsp;

它會為你帶去一個美好而溫馨的夜晚

&nbsp;

你會感動嗎？我想你會的

&nbsp;

&nbsp;

心情中流落的思緒越來越柔軟

&nbsp;

一個人，就這樣脈脈的溫柔，脈脈的想念

&nbsp;

有風吹來，竟是這樣的溫暖

&nbsp;

風過處，有著暗夜裡獨特的氣息

&nbsp;

那麼的曖昧和纏綿

&nbsp;

是否在這樣的一個夜晚，我們不應該只這樣的想念

&nbsp;

可我們還是冷靜了，把這美麗留在心中吧

&nbsp;

也許會有另外一種情緣延續在心間

&nbsp;

你會失望嗎？我想你不會，因為你是懂我的

&nbsp;

&nbsp;

夜色闌珊

&nbsp;

不知道此時的你是否也在想念

&nbsp;

也在期盼，也在糾纏，也在傷感

&nbsp;

如我一樣，心中的呼喚聲聲，臉上的淚光點點，知道嗎

&nbsp;

不是因為憂傷，而是因為太想

&nbsp;

心中的渴望時時撞擊著心底深處

&nbsp;

帶來一處處看不見，卻感覺很痛很痛的傷

&nbsp;

你落淚了嗎？我想你不會，因為我希望你是快樂的＾＾


&nbsp;
