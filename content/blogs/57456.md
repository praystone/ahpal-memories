男人&amp;女人敏感的話題



&nbsp;

&nbsp;


有人說︰如果男人是社會進步的火車頭

&nbsp;

那麼女人就是火車司機

&nbsp;

因為總是有人會說

&nbsp;

一個成功男人的背後，一定有一個好女人

&nbsp;

現在人對好女人的定義是什麼呢

&nbsp;

很難說得清，但一定很有很種

&nbsp;

因為好女人太多了，漂亮的，溫柔的，賢慧的，能幹的

&nbsp;

到底哪一種才是男人的最愛

&nbsp;

也許不同的男人有不同的選擇

&nbsp;

&nbsp;

有人說︰女人有三張會說話的嘴

&nbsp;

第一張在女人的鼻子下面

&nbsp;

那是真正用來說話吃飯和別人交流的嘴

&nbsp;

第二張在女人的眼睛下

&nbsp;

不是有人形容女人的眼睛漂亮的會說話嗎

&nbsp;

關健時刻它會傳情，會讓男人心動，為之神往

&nbsp;

大概就是這個意思吧

&nbsp;

第三張嘴應該說是男人的嘴

&nbsp;

它長在女人的耳朵上

&nbsp;

女人喜歡聽男人的那張嘴在她耳邊綿綿細語

&nbsp;

只要男人一張嘴，女人便會陶醉

&nbsp;

&nbsp;

對女人來說

&nbsp;

控制男人的意志需要智慧

&nbsp;

阻擊男人的進攻需要策略

&nbsp;

截斷男人的撤退卻需要藝術

&nbsp;

男人總是喜歡在女人面前擺出男子漢的氣魄來

&nbsp;

有責任感的男人他總想讓女人為他信服

&nbsp;

為他陶醉，為他守候一生

&nbsp;

為此他就會不惜一切地去努力奮鬥

&nbsp;

以卓越的成績讓她心怡的女人為他折服，永遠追隨

&nbsp;

這樣的男人對於女人來說也是最難於控制的

&nbsp;

他們由於工作的原因

&nbsp;

常常會接觸到社會上各種各樣的女人

&nbsp;

一不小心就會陷入美色的漩渦，不能自拔

&nbsp;

不但會毀了一個家庭，還有可能毀了這個男人

&nbsp;

所以好女人，在這個時候絕對不會去大吵大鬧

&nbsp;

要想阻擊別的女人的進攻需要策略

&nbsp;

截斷男人的撤退卻更需要藝術

&nbsp;

每個女人都應該有不同的方法

&nbsp;

但聰明的女人大都不會去硬拼

&nbsp;

那樣有可能三敗俱傷得不償失

&nbsp;

&nbsp;

對男人來說理想的好女人應該具備的幾個條件是

&nbsp;

一是能拿的出去，二是能帶的回來

&nbsp;

就像過去的人要求女人出得庭堂，入得廚房一樣

&nbsp;

現在的好女人

&nbsp;

既要有素質，有智慧，有能力，有氣質

&nbsp;

又要溫柔，賢慧

&nbsp;

有自已的生活模式，不能完全倚賴於男人

&nbsp;

既能帶得出去，又不會被繁華世界所吞沒

&nbsp;

能帶得回來

&nbsp;

對孩子對丈夫，對家庭有一份責任感時刻記在心頭

&nbsp;

她不一定要有自己的事業

&nbsp;

但她一定把經營家庭當成一份長遠的事業來做

&nbsp;

&nbsp;

男人在剛剛認識愛情時

&nbsp;

會認為愛情是一所有魔力的大房子

&nbsp;

他會罔顧一切滿面紅光拼命撞進去

&nbsp;

然後又憔悴不安身心疲憊地爬出來

&nbsp;

他們覺得還是外面的世界最好

&nbsp;

而女人看待愛情卻是一所正在建築的漂亮別墅

&nbsp;

裝滿了鮮花和夢想

&nbsp;

住進去後才知道裡面雖然有麵包和咖啡

&nbsp;

卻也裝滿了寂寞和淒涼

&nbsp;

但她們卻願意用盡餘生守住這別墅裡的一切

&nbsp;

因為這裡裝滿了她們曾經的浪漫和幸福

&nbsp;

&nbsp;

男人會因為生活和工作閱歷的累積而變成哲學家

&nbsp;

他們會變得更理智，更慷慨豁達

&nbsp;

得以更多女人的欣賞和崇拜

&nbsp;

而女人會因為生活和工作的壓力而變成思想家

&nbsp;

她們要思想如何在工作中出類撥翠，不被淘汰

&nbsp;

如何在家庭中站穩腳跟，不被下崗

&nbsp;

不停地思想和壓力會讓她們越來越老

&nbsp;

她們的臉蛋也會因長時間思考而阡陌縱橫

&nbsp;

&nbsp;

男人和女人，看來真有許多不同的地方

&nbsp;

不過，男人和女人都是社會發展進步的動力

&nbsp;

學會互相理解，互相包融，相互尊敬

&nbsp;

互相支持是人們共同思考和實踐的話題

&nbsp;

只有男人和女人真正達到平等互利，互相協作

&nbsp;

社會才能真正達到共同進步和諧發展
