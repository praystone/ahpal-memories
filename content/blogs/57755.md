可憐的男人

&nbsp;




&nbsp;

&nbsp;


親愛的~今天好嗎~認識你一段日子了

&nbsp;

~有些話想對你說~

&nbsp;

&nbsp;

一、 沒認識妳之前我拿獎學金，認識妳之後我考試補考。

&nbsp;

沒認識我之前妳補考，認識我之後妳拿獎學金。 

&nbsp;

二、 我忍著讓別人笑話的恥辱給妳洗衣服。

&nbsp;

三、 一個蘋果，都給妳吃，兩個蘋果，我把大的給妳吃。 

&nbsp;

四、 同吃一條魚，我讓妳吃大身，我自已吃魚頭。 


&nbsp;五、 妳這麼難看，我 還說妳漂亮。

&nbsp;

我這麼帥，妳還說我難看。 

&nbsp;

&nbsp;

六、 出去玩都是我花錢，回來我只能吃蘿蔔。

&nbsp;

妳省下錢當然可以自已吃魚翅了）

&nbsp;

七、 認識妳之前我沒交過女朋友。

&nbsp;

認識我之前妳交了兩個男朋友（高中一個，初中一個。） 

&nbsp;

八、 妳生氣時，我讓妳當出氣筒。

&nbsp;

我生氣時，我把自已當出氣筒。 


&nbsp;九、 妳想吻我的時候就可以吻我。

&nbsp;

我想吻妳的時候還要經過妳同意。 

&nbsp;

十、 妳經常打我，我從來沒打過妳。 

&nbsp;

&nbsp;

十一、 有一次妳問我如果妳愛上別的男人了我會怎樣，

&nbsp;

我說我要殺了那個男的。

&nbsp;

我又問妳如果我愛上別的女人了妳會怎樣，

&nbsp;

妳說妳要閹了我。

&nbsp;

十二、我買200塊的面膜給妳，騙妳才50塊。

&nbsp;

妳買30塊的手錶給我，騙我要300塊。

&nbsp;

十三、 那次妳說妳想要跟我做愛，


&nbsp; 我興沖沖地跑了兩里路買來了保險套，

&nbsp;

妳卻說妳只是要試試我是不是好男生，還罵我賤。

&nbsp;

&nbsp;

十四、 我把妳的耳機用壞了，我買新的賠妳，

&nbsp;

妳把我的自行車丟了，連句對不起也沒說。 

&nbsp;

十五、 妳生病一次，我要瘦兩斤，

&nbsp;

我生病一次，妳反而胖兩斤

&nbsp;

（妳來寢室陪我，吃光了我所有的食物）

&nbsp;

十六、 我沒嫌妳矮，妳卻嫌我高。

&nbsp;

十七、 妳來我家，我睡沙發，我去妳家，還是我睡沙發。


&nbsp;十八、 我媽對妳那麼好，妳媽對我一點也不好。

&nbsp;

&nbsp;

十九、 那次去看露天演唱會，妳騎在我頭上看得津津有味，

&nbsp;

我被妳壓在下面在人群中流淚。

&nbsp;

二十、 我家的狗生了，我把最好看的一條送給妳。

&nbsp;

妳卻把妳養得快要死掉的金魚送給我，

&nbsp;

害我才養兩天就得給它們送終。

&nbsp;

二 十一、我給妳洗了N次的襪子，從未給妳丟過一個，

&nbsp;

妳只在我生病的時候給我洗了兩雙襪子，就各丟一個。

&nbsp;

二十二、妳的生日我每年都記得，

&nbsp;

我的生日妳到現在還是不知道是哪年哪月
