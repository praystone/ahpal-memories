&nbsp;  
有一種愛....




&nbsp;


當日子在指縫間悄然流走的時候

&nbsp;

留在心裡的是深情的感嘆

&nbsp;

我們一路走來，在歲月的長河裡寫滿了濃濃的愛

&nbsp;

因為這份愛，使生活變得更加精彩

&nbsp;

因為這份愛，真情在人間才款款流淌

&nbsp;

因為這份愛，不管在何時不需要你知道

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是在呼嘯的凜冽寒風裡一件

&nbsp;

暖暖的棉衣披在你睡熟的身上

&nbsp;

帶著母親慈祥無限的關愛

&nbsp;

這份愛無時無刻都伴著我們左右

&nbsp;

即便歲月染白了青絲，即便額頭刻滿年輪

&nbsp;

即便我們已經不再年輕

&nbsp;

可那份無私博大的愛依然流變你的全身

&nbsp;

那是一個眼神的關愛，那是一個回眸的深情

&nbsp;

那是掛在心頭的遙遠的牽掛

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是在鐵做的肩膀上晃悠的扁擔

&nbsp;

支撐起全家生計的父親深沉與博大的愛

&nbsp;

那是一抹目光就折射出嚴厲的愛

&nbsp;

這份愛伴隨你走過人生的坎坎坷坷

&nbsp;

指引你前行，攙扶你成長

&nbsp;

糾正你的錯誤，讚賞你的成績

&nbsp;

陪伴你走出人生的低谷

&nbsp;

時常高興你的高興，快樂你的快樂，憂愁你的憂愁

&nbsp;

把一生的偉岸與挺拔全都傾注在你的心田

&nbsp;

直到風燭殘年累彎了腰

&nbsp;

卻依然在笑容裡綻放那份關愛

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是一份流淌在心底深處的濃濃親情

&nbsp;

那份愛帶給你力量，在你迷茫困頓苦痛時

&nbsp;

無聲就是支持，靜默就是關注

&nbsp;

指引你走出迷途，支持你成就事業

&nbsp;

無須太多的表白，無須過多的言語

&nbsp;

一個眼神，傾注全部疼愛

&nbsp;

一聲問候，暖流融遍周身

&nbsp;

這份愛是一生一世的情感

&nbsp;

不會因為地域的改變而淡薄，不會因為時間的消逝而淡化

&nbsp;

就如那份老酒，愈久愈香醇，愈久愈濃烈

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是一份在婚姻殿堂裡彼此攙扶彼此關心

&nbsp;

走過風雨、走過黑夜、走過陰霾的愛

&nbsp;

這份愛是一碗熱粥留給愛人

&nbsp;

而自己卻想著他喝粥時的那份幸福

&nbsp;

這份愛是深夜裡等著你歸來

&nbsp;

端上一杯熱茶，溫暖了你的心扉，滋潤了彼此的心田

&nbsp;

這份愛釋放了人間最真誠的情感

&nbsp;

在磕磕絆絆的婚姻裡

&nbsp;

彼此寬容著走過無法繞過卻終於繞過去的瓶頸

&nbsp;

多了一份耐心，多了一份等待，多了一份寬容

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是一份在彼此的心田裡流淌

&nbsp;

一起分享一起快樂一起調侃

&nbsp;

走過歲月的精彩時光，留下一生的永遠

&nbsp;

在你困難時，他會把手伸出來拉你一把

&nbsp;

在你高興時一起分享你的成功

&nbsp;

在你無助時他會義不容辭的站出來為你遮風擋雨

&nbsp;

一起走過生活中的艱難困苦

&nbsp;

一起領略生活中的苦辣酸甜

&nbsp;

看淡花開花落的季節輪迴，不屑於低頭媚骨的人間真情

&nbsp;

&nbsp;

有一種愛不需要你知道

&nbsp;

那是亙古不變的悠悠情懷

&nbsp;

那是流淌在心海深處的默默情懷

&nbsp;

那是情到深處淚滿襟

&nbsp;

愛你又不能讓你知道的無奈

&nbsp;

那份愛是站在遠處，靜默的註釋你的寬闊的雙肩

&nbsp;

卻又無法走近你的焦灼

&nbsp;

那份愛是站在你的窗前，把愛灑滿天宇的釋然

&nbsp;

那份愛是拿起電話又放下放下又拿起的心力交瘁

&nbsp;

那份愛是看著你的文字，咀嚼著每一個字的深刻含義

&nbsp;

看似否也藏匿著自己的影子


&nbsp;
