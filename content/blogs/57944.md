&nbsp;

 
幸福是一種平淡的香氣



&nbsp;


生命的三片花蕾和我的容顏同歲，

&nbsp;

我睜大雙眼看著它們一起改變，

&nbsp;

第一片叫做：醞釀；第二片叫做：開始；

&nbsp;

而另一片叫做：暗思。

&nbsp;

上帝曾說，人生其實就是一杯水，

&nbsp;

而我們則是從其中引入我們的生活。

&nbsp;

&nbsp;

不同的人選擇自己不同的生活，

&nbsp;

有的人喜歡甜的味道，

&nbsp;

於是用白開水加蜜糖調成蜂蜜喝；

&nbsp;

有的人鍾情苦澀滋味，

&nbsp;

於是泡成摩卡或炭燒咖啡來品嚐；

&nbsp;

有的人喜歡追求刺激，於是調製成不同口味的雞尾酒類。

&nbsp;

當然，還有人，甚麼也不放，

&nbsp;

只是細細品味其原始味道。

&nbsp;

然而，不知從何時起，發現愈來愈很多的人捧著這杯水，

&nbsp;

表情開始復雜，不是怡然，而是形似倦怠。

&nbsp;

&nbsp;

曾經，在許多不經意的時刻，

&nbsp;

收集了不少真實而燦爛的微笑。

&nbsp;

曾經，也在一些經典的書籍中，

&nbsp;

看過其對生活美好而深動的描述。

&nbsp;

曾經的曾經，一切平淡卻真實，一切簡單卻知足，

&nbsp;

所有的所有，只要是自己的調製，

&nbsp;

就能在品嚐的同時而感覺到幸福的香氣。


&nbsp;

然而，在彷彿對一切習以為常的時候，

&nbsp;

隨著一種叫做『時間』的儀器的推移，

&nbsp;

一顆名為『變化』的種子開始逐漸茁壯成長。

&nbsp;

從此，幸福的定義不再那麼單純，

&nbsp;

幸福的感覺也不再那麼隨心。

&nbsp;

&nbsp;

在物慾橫流的當代，在現實與夢想的邊緣，

&nbsp;

我們很容易在五光十色裡迷失了自己。

&nbsp;

漸漸的，發現理想與現實似乎大相徑庭，

&nbsp;

總是在鏡中看到自己複雜的表情，

&nbsp;

總是聽到此起彼落的嘆息，總是感受到生活中的無可奈何。

&nbsp;

人總是這樣，

&nbsp;

很多時候，不曉得自己想要甚麽，

&nbsp;

無窮盡的慾望宛如一個個用花環掩飾的陷阱，

&nbsp;

使人陷入一個無底深淵，永遠看不到陽光，

&nbsp;

也永遠無法得到內心真正的快樂。

&nbsp;

&nbsp;

於是，我們都沒有了自己的底線，得到了還想得到更多，

&nbsp;

失去了卻仍心有不甘地繼續深陷。

&nbsp;

到底是生活讓我們變得複雜，還是我們複雜了生活？

&nbsp;

生命，有時充滿了太多的變數和不期而遇，

&nbsp;

這一秒的我們永遠無法預料，下一秒的我們會在哪裡、

&nbsp;

會與誰相遇、會做些甚麽事..... 


&nbsp;

不要讓自己太累，不要讓自己太吝嗇微笑，

&nbsp;

也不要讓自己有太多的無奈。

&nbsp;

在慶幸自己手中還握有這樣一杯清澈的水時，

&nbsp;

我們更應該學會珍惜、把握，

&nbsp;

學會用自己有限的一生細細的去品嚐。

&nbsp;

平淡中的幸福，需要我們用心來書寫，

&nbsp;

用真摯的情感來吟唱的。

&nbsp;

我相信，平淡中也有著幸福，

&nbsp;

幸福中的我們也在體味著這份平淡的香氣。
