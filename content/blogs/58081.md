薰衣草傳說1

&nbsp;

&nbsp;

&nbsp;

在法國的普羅旺斯，

&nbsp;

也就是薰衣草的故鄉之一

&nbsp;

(另一為日本北海道的富良野)， 

&nbsp;

流傳著這麼一個有關薰衣草的愛情故事...

&nbsp;

&nbsp;　　

話說普羅旺斯的村裡有個少女，

&nbsp;

一個人獨自在寒冷的山中採著含苞待放的花朵，

&nbsp;

但是卻遇到了一位來自遠方但受傷的旅人，

&nbsp;

少女一看到這位青年，

&nbsp;

整顆心便被他那風度翩翩的笑容給俘虜了！

&nbsp;

於是少女便將他請到家中，也不管家人的反對，

&nbsp;

堅持要照顧他直到痊癒，

&nbsp;

而過了幾天後，青年旅人的傷也已經康復，

&nbsp;

但兩人的戀情卻急速蔓延，已經到了難分難捨的地步。

&nbsp;

不久後的某日，青年旅人向少女告別離去，

&nbsp;

而正處於熱戀中的少女卻堅持要隨青年離去，

&nbsp;

雖然親人們極力挽留，

&nbsp;

但她還是堅持要和青年一起到開滿玫瑰花的故鄉！

&nbsp;

就在少女臨走的前一刻，

&nbsp;

村子裡的老太太給了她一束薰衣草，

&nbsp;

要她用這束薰衣草來試探青年旅人的真心，

&nbsp;

因為...傳說薰衣草的香氣能讓不潔之物現形...

&nbsp;

正當旅人牽起她的手準備遠行時，

&nbsp;

少女便將藏在大衣裡的薰衣草丟擲在青年的身上，

&nbsp;

沒想到，青年的身上發出一陣紫色的輕煙之後，

&nbsp;

就隨著風煙消雲散了！

&nbsp;

而少女在山谷中還彷彿隱隱的聽到青年爽朗的笑聲，

&nbsp;

就這樣，留下了少女一人孤形影單...

&nbsp;

沒過多久，少女竟也不見蹤影，

&nbsp;

有人認為她和青年一樣幻化成輕煙消失在山谷中，

&nbsp;

也有人說，她循著玫瑰花相去尋找青年了...

&nbsp;

無論如何，薰衣草的傳奇故事就這麼被流傳了下來。

&nbsp;

&nbsp;




&nbsp;

&nbsp;

所以，直到現在，

&nbsp;

薰衣草還是被人們

&nbsp;

認為是驅除不潔之物及薰香的重要工具之一。

&nbsp;

薰衣草是一種色澤呈紫藍色的小花，

&nbsp;

又被人稱為「寧靜的香水植物」，

&nbsp;

英文名稱「Lavender」乃源自拉丁文的「Lavare」，

&nbsp;

其意為「洗滌」。

&nbsp;

由於薰衣草的香氣濃郁，令人感到安寧鎮靜，

&nbsp;

具有潔淨身心的功效，

&nbsp;

故古代羅馬人經常使用薰衣草來沐浴薰香。

&nbsp;

薰衣草原產於地中海地區，喜歡乾燥的環境，

&nbsp;

開花後形狀如小麥穗，有細長的莖幹，花上覆蓋著星形細毛，

&nbsp;

窄長的葉片呈現灰綠色，末梢上則開著小小的紫藍色花朵，

&nbsp;

通常在六月開花，成株時高可達60~100公分。

&nbsp;

一般人對薰衣草的印象就是每當花開風起時，

&nbsp;

整片的薰衣草田就像深紫色的波浪層層疊疊地上下起伏著，

&nbsp;

讓人不由自主的喜歡上薰衣草。 &nbsp;

&nbsp;
