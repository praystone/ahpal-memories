薰衣草傳說2

&nbsp;

&nbsp;

在一個小鎮裡，有一位賣薰衣草的少女，

&nbsp;

她特別的地方就是她有一頭藍紫色的長髮，

&nbsp;

由於她早逝的父母親都是耀眼的金髮，

&nbsp;

所以她那一頭藍紫色的頭髮更是引人側目，

&nbsp;

而鎮裡的人非但沒有因為她是孤兒而更加憐憫她，

&nbsp;

反而還因為她那一頭藍紫色的頭髮而對她冷嘲熱諷的，

&nbsp;

但是，少女一點都不在意，

&nbsp;

依舊在小鎮上賣著她的薰衣草。

&nbsp;

&nbsp;

一天，一位少年在少女的面前昏倒了，

&nbsp;

少女趕緊將少年給送到醫院，

&nbsp;

事後，少年非常感激少女， 就邀請少女到他家去玩，

&nbsp;

當少女看到少年他家那一大片薰衣草田時，

&nbsp;

便深深的愛上這個地方了，少年知道少女喜歡薰衣草，

&nbsp;

也很熱情的邀請少女常來他家，

&nbsp;

自此，少女就常常出現在少年他家了。

&nbsp;

少年原來是因為車禍失明的原因，

&nbsp;

才會來到這個小鎮，

&nbsp;

當他正在和少女敘訴他來這裡的原因時，

&nbsp;

少女忽然想起老一輩的人的人說森林裡有一座生命之泉，

&nbsp;

可以治百病，說不定也可以治好少年的眼睛，

&nbsp;

於是，少女就和少年一起去尋找這座生命之泉了。

&nbsp;

在尋找的過程中，少年愛上了少女的溫柔體貼，

&nbsp;

而少女也被少年給深深的吸引住了。

&nbsp;

這天，少年摸著少女的頭髮對少女說:

&nbsp;

「你是這麼的溫柔體貼，

&nbsp;

那你的長髮一定也是耀眼的金色，對吧!」

&nbsp;

少女支支吾吾的說

&nbsp;

「嗯…對啊!我的長髮就像是陽光一樣耀眼的金色啊!」

&nbsp;

這是少女第一次希望少年的眼睛不要恢復，

&nbsp;

因為，少年的眼睛一恢復以後，

&nbsp;

她就不能在待在少年的身邊了。

&nbsp;

但是，少年終究是找到了生命之泉了，

&nbsp;

他用生命之泉的泉水洗了眼睛後，

&nbsp;

他就又看的見了，就在他高興的要告訴少女這個好消息時，

&nbsp;

少女就這樣無聲無息的消失了，

&nbsp;

不管少年怎麼找都找不到少女，

&nbsp;

這時他發現，每天早上在少年家的門口都會有一束薰衣草，

&nbsp;

少年想這會不會是少女送來的，

&nbsp;

他就埋伏在他家的門口，果然，在凌晨的時候，

&nbsp;

有一個身影偷偷摸摸的走到了少年的門口，

&nbsp;

放下了薰衣草正打算離開時，

&nbsp;

少年的直覺認定他就是那個少女，

&nbsp;

於是就追了上去，少女也嚇了一跳，拔腿就跑，

&nbsp;

就在他追到薰衣草田時，他抓住了少女的手，

&nbsp;

他將少女深深的擁在懷中說

&nbsp;

「不管你的頭髮是金色或者是藍紫色的，

&nbsp;

我愛的不只是你的人，

&nbsp;

你的心，你的全部我都愛，就算是藍紫色的頭髮，

&nbsp;

又有什麼關係呢?我還是會一直愛你的啊!」

&nbsp;

少女聽了以後，她的淚就忍不住掉了下來，

&nbsp;

這時，少年驚訝的說「妳…妳的頭髮變成金色了!」

&nbsp;

少女一看， 她的頭髮果然變成了耀眼的金色，

&nbsp;

但是他們身旁的薰衣草全由純潔的白色變為美麗的藍紫色了，

&nbsp;

從此，薰衣草就一直是現在的藍紫色了
