請轉個身





&nbsp;

&nbsp;

行走在喧囂的塵世，我們常會有許多的煩惱和怨言，許多難以名狀的感嘆和憂患，尤其我們遭到委屈失敗時，易沈浸其中，難以自拔。



&nbsp;

&nbsp;

然而回過頭才發現， 自己當時太看重的東西根本不值得一提。



&nbsp;

&nbsp;

生活照樣繼續，太陽照樣從東方升起……有人會問問你的委屈、你的悲傷，但都是暫時的撫慰，最終靠的是自我平衡、自我調節。



&nbsp;

&nbsp;

面對生活，我們有一個退卻的借口，更有一萬個打拼的理由。



&nbsp;

&nbsp;

人活世上，總會遇到難解的結，面對痛苦，如果不及時打開心結，任由自己在痛苦中沈淪，結果是只能給自己帶來更大的痛苦。



&nbsp;

&nbsp;

面對痛苦，我們不妨轉身，這是人生的豁達和藝術，不要因為暫時的失敗責備自己，不要悲觀地懲罰自己，更不要一味地跟自己過不去，要學會善待自己，學會讓自己轉個身。



&nbsp;

&nbsp;

如果別人不把我們當回事，我們千萬要把自己當回事，別人不把我們當回事，或許他們不了解我們，或許對我們一時有些誤解，如果擺脫不了別人的評價，自己看輕自己，自己看低自己，那麼就等於用自己扭曲了的行為印證別人的看法，等同於拿別人的偏見懲罰自己。



&nbsp;

&nbsp;

如果別人把我們當回事，我們自己千萬別把自己太當回事，



&nbsp;

&nbsp;

也許別人太關注我們成功的同時忽略了我們的不足之處，



&nbsp;

&nbsp;

也許別人是有求於我們而以此取悅、刻意擴大對我們的好感。



&nbsp;

&nbsp;

如果自己太把自己當回事，給點陽光就燦爛，給點掌聲就膨脹，那麼就會跟著別人的感覺走，在客觀上也為別人提供了不把我們當回事的理由。



&nbsp;

&nbsp;

唯有別把自己太當回事，才能笑看雲卷雲舒，靜觀花開花落，不失信心，不失樂趣地做自己該做、想做的事。



&nbsp;

&nbsp;

當你從痛苦中轉過身後，一定會覺得生活如此多姿多彩，即使現在看是黑暗一片，只要嚮往未來，一定會找到屬於自己的快樂！
