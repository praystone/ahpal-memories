&nbsp;

&nbsp;


每個人 都是一個循環。

&nbsp;

&nbsp;

總會有人 每天都會想起你。

&nbsp;


總會有人 為你改變到不認得自己。

&nbsp;


總會有人常常拐彎抹角的四處打聽你最近過得好不好。

&nbsp;


總會有人 想知道你的以前。

&nbsp;


總會有人 想到你就會掉眼淚。

&nbsp;


總會有人把你們彼此的回憶看得比自己還重要。

&nbsp;


總會有人 承諾了就會去做。

&nbsp;


總會有人為你做了太多卻………

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 什麼都不說。

&nbsp;


總會有人無論多固執還是對你根本沒有脾氣。

&nbsp;


總會有人 關心你會不會胃疼。

&nbsp;


總會有人電腦裡全都是你的相片可能有的你自己都記不得。


&nbsp;

總會有人 得不到看見也好。

&nbsp;


總會有人 想要等你等到在一起。

&nbsp;


總會有人 過了那麼久愛的還是你。


&nbsp;

總會有人 打好了短信卻不敢發。


&nbsp;

總會有人 想的太多。


&nbsp;

總會有人 想把你紋在身上。


&nbsp;

總會有人 經常怕打擾你讓你心煩。


&nbsp;

總會有人天天進你主頁看你做了點什麼。


&nbsp;

總會有人故意跟你買相同的衣服自我安慰。


&nbsp;

總會有人明明知道自己真的很二還是義無反顧的去做。


&nbsp;

總會有人 想等你。

&nbsp;

&nbsp;

總會有人 像愛自己一樣愛你。
