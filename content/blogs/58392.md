想說：脫了衣服就要跳下水了，就不用防曬了！

&nbsp;



記住～這是錯的...皮好痛啊

&nbsp;

這是通霄龍鳳魚港，沒什麼人，正點...

&nbsp;



&nbsp;

天氣熱，連海水都是溫的,,好像泡溫泉喔

&nbsp;

&nbsp;



&nbsp;

做一下戶外教學，這是我們常吃的那種螃蟹。但是我有放回去喔！

&nbsp;



&nbsp;

海港邊風力發電的風車，據說一隻很多錢..但不知道效果如何?!

&nbsp;



&nbsp;

中午到苗壢外埔魚港吃海鮮..偷偷說一下(這家叫"太興"選這家沒錯唷)

&nbsp;

&nbsp;



&nbsp;

再來是到內灣玩 GO Car，對面有個內灣公園，很漂亮的。

&nbsp;



&nbsp;

有看到幾個美女，但外婆的教誨是說：路邊的野花不要採！

&nbsp;

&nbsp;



&nbsp;

那既然來到了內灣，就放上這張..象徵來過的痕跡。

&nbsp;

&nbsp;



&nbsp;

後記：各位美女們請注意，別以為玩只玩一個多小時就不防曬。

&nbsp;

下場是很痛的呀　＞＜！還有些雜圖..我就自己收藏囉
