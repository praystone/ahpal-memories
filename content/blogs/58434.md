窗外此時只有遠方的路燈和黑黑的天空

&nbsp;

突然想起兩段全不相干的往事

&nbsp;

正好屬於過往的 都提醒著我曾年輕過

&nbsp;

情節在當下也只是一個小插曲

&nbsp;

總在若干年後 呈現回憶的小歷史

&nbsp;

原來ㄚ...每一個當下都好重要的

&nbsp;

小腦袋瓜轟隆隆的運轉著

&nbsp;

馬達也舊了....想著都格外吃力

&nbsp;

找不到的來時路&nbsp; 在屬於我的故事裡陳舊了

&nbsp;

嘩啦嘩啦自己又亂下雨了........

&nbsp;

我的傘阿 在夢中幫我遮遮雨吧.....

&nbsp;

或者.................

&nbsp;

跳出腦螢幕 給我一個擁抱好了~~~~~~~

&nbsp;

&nbsp;

&nbsp;




不知道她是什麼花....隨手插在髮上當裝飾~~

&nbsp;

配上綠色系衣服~~自己覺得挺順眼
