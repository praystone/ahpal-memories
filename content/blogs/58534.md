愛一個人到底有什麼感覺呢 

&nbsp;

&nbsp;

&nbsp;


記得曾有人說過，孤獨和寂寞真的不一樣 

&nbsp;

孤獨只是說明身邊沒有人

&nbsp;

真正的寂寞是你自己忘記了愛一個人的感覺

&nbsp;

愛一個人到底有什麼感覺呢

&nbsp;

誰也分不清

&nbsp;

只記得愛情這東西，它來得悄然無聲

&nbsp;

散發著詭異的氣息，逐漸靠近你，捕獲你

&nbsp;

讓你無處可逃

&nbsp;

陷進去的時候，不管是心甘情願，還是後悔莫及

&nbsp;

都必將經歷一場刻骨銘心
&nbsp;

&nbsp;

再兩個人的舞台中，誰又傷害了誰

&nbsp;

糾纏的腳步讓每個人傷痕累累

&nbsp;

是繼續還是放棄，或許只有時間才會賦予答案

&nbsp;

只是，在愛著彼此的時候，我們只顧著專注地去愛了

&nbsp;

卻沒有看到當真正公手時，背後那些痛徹心扉的傷害
&nbsp;

&nbsp;

愛情就像握在手心裡的沙子

&nbsp;

你越想努力把它抓緊，它反而流失得更快

&nbsp;

青絲會退色，承諾會變味，等待會過去

&nbsp;

愛情也會慢慢地流失
&nbsp;


愛情是一條很長的路，相愛以後～兩人之間，

&nbsp;

還要經歷許多的可能現變數

&nbsp;

經得起時間的打磨，才能體會現珍惜手中的感情

&nbsp;

有時候，你感覺愛情似乎消失了

&nbsp;

可能，只是你忽視了

&nbsp;

好多時，只有在寂寞想念的痛苦來襲

&nbsp;

才知分手前自己是幸福的
&nbsp;


真正的愛情是彼此平等地付出與得到

&nbsp;

是兩個人選擇了往同一個方向走

&nbsp;

同甘共苦，相攜相扶，不離不棄

&nbsp;

它不需要有華麗的外表來製造浪漫

&nbsp;

它是需要雙方在力所能及的情況下來營造

&nbsp;

如果脫離了現實，追求浪漫的結果只有失望

&nbsp;

婚姻更是雙方共同的責任

&nbsp;

倘若完全由一方承擔，生活就會走形

&nbsp;

其實，愛需要坦然為對方付出

&nbsp;

沒有付出，沒有給予的愛，也只是曇花一現
&nbsp;


愛就像流星

&nbsp;

每一個愛過的人，每一段付出過的感情

&nbsp;

都是生命夜空中耀眼的流星

&nbsp;

劃下了你曾用心尋覓幸福的軌跡

&nbsp;

珍惜每一份愛，把握每一段情

&nbsp;

不要讓福祉如沙般從手中流失，要想擁有一份真掣的愛情

&nbsp;

不一定要愛得死去活來，轟轟烈烈

&nbsp;

只要是彼此真心付出，平平淡淡才是真
&nbsp;


後記：經歷了許多事以後

&nbsp;

才發覺自己對感情只是一知半解

&nbsp;

曾經無數的夢想

&nbsp;

忽視了許多身邊真實存在的感情

&nbsp;

讓自己拘束於幻想中，蹉跎了歲月

&nbsp;

當一切夢想在歲月的蒼傷中一個個被撒裂

&nbsp;

才發覺自己又回到了起點
&nbsp;

其實每個人都應該守護住自己手中的那份感情

&nbsp;

它不需要太多裝飾

&nbsp;

只要是真實，真心，幸福會在你身邊


&nbsp;

人生的慾望不是過於複雜

&nbsp;

得到幸福和快樂其實是件很簡單的事情
