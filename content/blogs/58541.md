&nbsp;


&nbsp;


空氣中瀰漫的感情是來自內心的反射


四季的氣候更迭往往難密自心的感情輪迴


筆者在空氣中尋覓 ...


來自內心的記憶拼圖


這張附圖對我的感情寫照是奇妙的


曠野中的一棵大樹


在夏天茂密感情豐盛中目送倩影走向遠方天涯


它無言 ...


只有雁天晚風裡落下幾許惆悵秋黃


秋蟬在呢喃


細數著心中無數企盼


寒風來&nbsp;&nbsp;&nbsp;落葉散&nbsp;&nbsp;&nbsp;北風勁掃冬枝寂寥


歲晚斷鴻霜白梢&nbsp;&nbsp;&nbsp;知音少&nbsp;&nbsp;&nbsp;心待老


倏忽飄雪 ...


雪泥中的腳印是烙在心中的震撼


看著這張附圖


我就像那棵樹獨露身軀在雪夜裡


倩影來伴


天空中落下的片片花雪


我只感覺


&nbsp;


&nbsp;


冬天裡的溫暖




&nbsp;



這是我今年初對一篇散文附圖所作的心得回覆


&nbsp;


讀者大概以為樹與霓嫣


&nbsp;


天涯為伴


&nbsp;


...


&nbsp;


其實


&nbsp;


霓嫣畢竟是霓嫣


&nbsp;


而樹終究是木頭


&nbsp;


這不是重逢&nbsp; 而是霓嫣的最後道別


&nbsp;


一幕散場電影


&nbsp;


在彼此的故事書一角留下清明上河圖的春季饗宴


&nbsp;


霓嫣消失了


&nbsp;


她告訴樹&nbsp; 來自山上的孩子&nbsp; 數千里的追逐不僅只樹蔭


&nbsp;


嚮往的是天空的漫步雲階


&nbsp;


那兒才是沒有風沒有雨的仙鄉


&nbsp;


...


&nbsp;


樹依然是木頭的呆立


&nbsp;


輕風吹來


&nbsp;


祝福中目送霓嫣走向遠方天涯


&nbsp;


就像去年的夏天


&nbsp;


...


&nbsp;


唯一不同


&nbsp;


樹蔭下再也看不到落葉堆積的倩影


&nbsp;


輕風悠颺


&nbsp;


...


&nbsp;


...


&nbsp;


...


&nbsp;


&nbsp;


&nbsp;


&nbsp;


樹笑了


&nbsp;


&nbsp;


&nbsp;


&nbsp;


今生聚散兩茫茫 過盡千帆 孤影伴夕陽


莫道晚風近身涼 唯盼藍天展眉揚


愛恨交織淚兩行 一往情深 梧桐棲鳳凰


忘川哽咽將心葬 盡飲孟湯煑黃梁
