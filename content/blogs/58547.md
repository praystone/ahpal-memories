讓心靈小憩一下

&nbsp;



&nbsp;

&nbsp;


人活著是一種心情！

&nbsp;

這個世界本來很簡單，是我們把它搞複雜了。

&nbsp;

人之所以痛苦，

&nbsp;

是由於你沒有按照自己喜歡的方生活。

&nbsp;

大多數人是在按照別人的要求生活，

&nbsp;

刻意的改變，違背內心的所想，所以痛苦。

&nbsp;

人生在世有許許多多的無奈，

&nbsp;

如果 不能改變什麼，

&nbsp;

那不如在我們有自由空間的時候，

&nbsp;

珍愛自己一下，讓心靈小憩一下。


讓你的風鈴晃動的，是風；

&nbsp;

讓你的生命靈動的，是愛；


&nbsp;

在那個有風的午後，

&nbsp;

默默地聆聽著風鈴叮叮的響聲；

&nbsp;

在那個有風鈴響動的午後，

&nbsp;

默默地想念著心裡的那個人；


讓自己和風鈴化為一體，讓心和愛隨風一起流動。


&nbsp;

在這個世界上，

&nbsp;

有許多事情是我們所難以預料的。

&nbsp;

我們不能控制機遇，卻可以掌握自己；

&nbsp;

我們無法預知未來，卻可以把握現在；

&nbsp;

我們不能知道自己的生命到底有多長，

&nbsp;

但我們卻可以安排當下的生活；

&nbsp;

我們左右不了變化無常的天氣，

&nbsp;

卻可以調整自己的心情。

&nbsp;

&nbsp;

所以我們應該一天給自己一個希望。

&nbsp;

希望，看似很平淡的字眼，

&nbsp;

卻包含著各種不同的內涵。

&nbsp;

試著每天給自己一個希望，

&nbsp;

靠自己的努力和嘗試去創造，

&nbsp;

去探索，去發展，就會進步，就會成功，

&nbsp;

你的生活也會因此變得美麗而有意義。

&nbsp;

每天給自己一個希望，就是給自己一個目標，

&nbsp;

給自己一點信心。


&nbsp;

每天給自己一個希望，

&nbsp;

我們將擁有一個豐富多彩的人生。



&nbsp;
