&nbsp;

&nbsp; rn&nbsp;感恩父母 




&nbsp;

&nbsp;


日子總是像從指尖滑過的細紗

&nbsp;

在不經意間悄然逝去

&nbsp;

那些往日的憂愁

&nbsp;

在似水流年的蕩滌下隨波輕輕地逝去

&nbsp;

而留下的歡樂和笑容就在記憶深處歷久彌新

&nbsp;

不要忽略那份真情

&nbsp;

莫讓歲月的風霜掩蓋了那世間彌足珍貴的親情

&nbsp;

『總有一些東西是歲月所消融不了的』

&nbsp;

它不會因為時光流逝而熄滅

&nbsp;

它一直陪伴在我們左右，為我們驅散黑暗，帶來光明
&nbsp;

&nbsp;

生活在現代社會的我們

&nbsp;

被濃重的商業化氣息所包圍著

&nbsp;

就像是被捆綁在一架高速運轉的機器上

&nbsp;

我們顧不得體察他人的情感世界

&nbsp;

也忘記了品味自己的情感世界

&nbsp;

我們總是習慣於在自己擁有的時候不懂得珍惜

&nbsp;

在錯過以後才知道珍貴

&nbsp;

惰性的力量，讓我們失去了許多美好的事物

&nbsp;

在這其中親情佔據著巨大的比重

&nbsp;

我們要珍惜一切美好的東西

&nbsp;

不要等到無法彌補的時候，才想到補償

&nbsp;

珍惜我們所擁有的

&nbsp;

而不是等到失去才追悔，這才是人生的大智慧
&nbsp;

&nbsp;

長大了的我們

&nbsp;

經常會忘記回家的路，不管有心還是無意

&nbsp;

但是我們可曾體會過步入晚年的父母的心境

&nbsp;

多回家看看我們的父母

&nbsp;

讓我們的父母知道我們的心中至少還有他們

&nbsp;

多往家跑跑，因為我們已經欠下了太多的感情債
&nbsp;

&nbsp;

『路有盡頭，愛無止境』

&nbsp;

人之所以區別與一般動物就在於人有情感、

&nbsp;

有道德，有感恩之情、有正義之心

&nbsp;

我們常說的『孝道』

&nbsp;

就是要求做為子女的我們一定要對父母感恩

&nbsp;

感恩是一種做人的道德，是一種處世哲學

&nbsp;

人人都應該懷有一顆感恩之心感激生育我們的人，

&nbsp;

感激撫養我們的人，感謝幫助我們走向成熟的人
&nbsp;

&nbsp;

『父母在，不遠游』，是千年的古訓

&nbsp;

儘管有些陳舊，但是卻有其自身的道理

&nbsp;

當我們在外面拼打，抑或在外面遊玩時，

&nbsp;

千萬別太貪戀要記得家裡還有我們的父母-----

&nbsp;

需要我們關心的孤獨的老人
&nbsp;

&nbsp;

慶幸的是我們現在仍然有機會

&nbsp;

請珍惜父母的愛，父母的寬容

&nbsp;

使母父母能快樂、幸福地生活

&nbsp;

不要在我們心中留下任何的悔與恨

&nbsp;

讓我們多為自己的父母考慮一點

&nbsp;

多回家陪陪自己的父母

&nbsp;

讓父母在有生之年多享受一點天倫之樂



&nbsp;



&nbsp;
