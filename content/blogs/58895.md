&nbsp;

巨蟹喜歡和自己喜歡的人鬥鬥嘴，

卻不會大聲吵架或者說根本不會吵架。

你想吵，可以。巨蟹只會轉頭走人。



&nbsp;

甩掉巨蟹很容易，蟹子不會糾纏，

也不會乞求愛，更不會要施捨的愛。

同樣，巨蟹死去的愛情，

是絕對沒有可能愛火重燃的。



&nbsp;

蟹子相信分手的戀人還可以做朋友，

只要對方願意，希望大家都好。



&nbsp;

如果你不能給蟹子什麼，

不要招惹他們，

他們比你想像的單純，

也沒你想像的堅強。



&nbsp;

寬容。

蟹子只會對別人寬容

卻不會對自己寬容對自己要求挺嚴格的。

經常和自己過不去，

別問理由，蟹子自己也不知道。



&nbsp;

巨蟹不擅表達，

如果你能感覺蟹子對你三分的喜愛，

事實上會有五分；

如果你能感覺到五分，

事實上會有七分。

巨蟹是不坦白的，

會淡化感情的表達，

會壓抑自己的情緒。



&nbsp;

審美觀超強，

愛一切美好的事物。

比如帥哥美女，但只是欣賞，

當作藝術品。



&nbsp;

超能忍，

比如明明想見一個人，卻不會見面。

比如明明想知道誰的消息，卻什麼都不問。

除非不想忍。



&nbsp;

不愛發短信，不愛打電話，懶蛋一個。

對特別的人會例外。



&nbsp;

自尊心很強！

強過金錢，強過事業，也強過愛情。



&nbsp;

巨蟹需要慢慢相處，

因為蟹子是個被動的星座，

慢熱的星座，放不開的星座，

認識時間越久對你越好。

如果只是你喜歡蟹子，蟹子卻不喜歡，

頻頻接觸的結果則是會對你越來越冷淡。



&nbsp;

一見鍾情很難發生在巨蟹身上，

蟹子的愛需要時間。

會喜歡很多人，卻很難愛上一個人。

喜歡細水長流的感情，暖暖細流，長長久久。



&nbsp;

蟹子知道什麼是感恩圖報。

你對他們仁，他們就對你義。



&nbsp;

蟹子的喜歡不等於愛。多情而不濫情。



&nbsp;

除了感性，巨蟹也可以理性的可怕。

會很現實的考慮兩個人的將來，

如果覺得沒有未來，就放開。



&nbsp;

巨蟹的情商其實挺低的，

對這種事情有點遲鈍。



&nbsp;

配合。

蟹子喜歡配合別人，遷就別人。

自我意識比較薄弱。

其實巨蟹不擅交際的，

一般情況下不喜歡說太多。

小老實，小保守。

雖然嘴巴小笨卻知道什麼話該說，什麼話不該說。

不過在人多的場合也不會扭扭捏捏小家子氣，

說話會大大方方。

這也是蟹子氣質出眾人緣好的一個原因。



&nbsp;

巨蟹重視內在多於外在，重視精神多於物質。



&nbsp;

巨蟹對朋友沒什麼要求，人好就行。

就算心直口快老得罪人也無所謂。

因為巨蟹不愛生氣不會記仇，對誰都會寬容。

就算傷害過自己的人。只記得別人的好。



&nbsp;

討厭誰不會表現出來，

只是不愛和你說話，或者乾脆不睬你。



&nbsp;

有了心愛的人後就會變得很沒安全感，怕寂寞。



&nbsp;

不要獻媚的亂誇獎，蟹子沒你想像的那麼虛榮，

也沒你想像的那麼白痴。

他們能清楚的分出哪句是虛情，哪句是假意。



&nbsp;

巨蟹的頭腦中性、冷靜，不論男女，

分析對待問題不會因為性別問題而偏激。

處變不驚。

巨蟹做事情處理事情好像一直都會不緊不慢，

就算在一種很混亂的情況下也能冷靜的思考。

不知道為啥，歸天性吧。



&nbsp;

不喜歡做決定，

小事情隨便怎麼樣都行，沒所謂。

大事情很喜歡聽朋友的意見。

如果你是巨蟹可以信賴的人他們會問你的意見，

你需要做的只是分析，決定巨蟹會自己來做。

如果他們覺得你分析的有道理，

會在心裡琢磨。可行就採納。

如果巨蟹有了自己的想法，

一旦下了決定就算全天下反對幾乎沒有改變的可能。

一意孤行。

其實多多少少有些靠直覺行事。

不過巨蟹的直覺大多時候還蠻準的。



&nbsp;

溫柔。

溫柔是巨蟹的本性。

就算外表看來是阿飛或者小太妹裡頭，

也絕對有溫柔的一面。



&nbsp;

蟹子有善辯的口才，

被別人誤會的時候卻不愛解釋。

不要問為什麼，就是不愛解釋。



&nbsp;

不喜歡傷害任何人，寧願傷害自己。

前景不樂觀時會對喜歡的人冷靜的說狠話，

會口是心非。

為的是不傷害任何人，

結果反到是既傷了別人，

傷得更多卻也正是蟹子自己。



&nbsp;

吃軟不吃硬的一族。

你軟，蟹子就對你沒脾氣。

你硬，蟹子就比你還橫。

有項調查，

十二星座謀殺記錄最少的就是善良的巨蟹，

不過發現大多死亡記錄裡都是和對方同歸於盡的。

蟹子脾氣倔，惹怒了絕對敢和你同歸於盡。



&nbsp;

讓巨蟹消氣很容易，

不管男蟹子還是女蟹子，

也不管對異性或者同性，

只要你撒撒嬌說兩句軟話，

包準巨蟹不會再有脾氣。



&nbsp;

巨蟹對朋友絕對夠義氣，

不過很多時候巨蟹往往會低估自己這一點。

只有碰到事情才能發現。



&nbsp;

不管對朋友還是戀人，

在外邊巨蟹絕對袒護的是你，

就算錯的是你，沒道理的是你，

也會和你一起對付外敵，

不過

事後你們單獨相處的時候，

才會告訴你說他們覺得哪裡哪裡似乎是你的不妥。



&nbsp;

不要因為在蟹子面前丟了人而感到自卑或在意，

因為蟹子絕對不會在意。

蟹子覺得有時候丟人也是可愛的一種表現。



&nbsp;

不會打擊別人，開玩笑時候除外。



&nbsp;

一般人都覺得巨蟹會做人，不會得罪人。

那是因為巨蟹覺得沒有和他們認真的必要。

其實巨蟹說話會很直，

只有對好朋友說話才會一根腸子通到底，

老說大實話。

太直接偶爾會小傷人，但都是為了朋友好。

比如知道好朋友的男朋友和其他女生在一起，

一定不會怕好朋友傷心而因此隱瞞，

巨蟹會直言不諱的幫好朋友看清事實，面對事實，

減少以後的傷害。

對此，蟹子當作身為朋友義不容辭的責任。



&nbsp;

巨蟹不喜歡向別人提要求。

對朋友一點要求都不會提。

如果向你提要求，

就代表對你的喜歡和信賴非同一般，

不過就算再信賴一個人，

巨蟹也很少開口要求什麼。

因為巨蟹是隨遇而安的，

心態很平靜悠哉悠哉的。

而且不喜歡欠任何人的人情



&nbsp;

不喜歡打探朋友的太多私事，

因為覺得不禮貌。

也不喜歡逼人講不願講的，

蟹子認為這是一份尊重。



&nbsp;

巨蟹很好騙，因為單純。

蟹子不會沒事就想著別人是不是在騙自己。



&nbsp;

失戀的時候喜歡聽悲傷地情歌。

既然傷就傷個夠吧。

還會刪除對方的電話號碼聯繫方式，

以及丟掉有回憶的東西。



&nbsp;

巨蟹對理財沒什麼概念。

經常不知道自己帳戶裡有多少錢，

也不知道花了多少錢。

對父母挺捨得花錢。

對好朋友和喜歡的人也不會把帳算的很清。



&nbsp;

你可以欠巨蟹的錢或者什麼，

但是巨蟹卻不喜歡欠別人的。

巨蟹欠別人錢的時候會天天惦記著，

老覺得不爽，比別人欠自己錢還不爽。

理性的巨蟹更感性，

有顆不切實際單純美好的心靈。

比如看到藍藍的天會感動，

會覺得生活真美好。

比如看到乞討的老人，

會覺得可憐，

然後想著以後有能力要幫助好多好多可憐的人。

所以，

當一個巨蟹對你說他的願望是

“世界和平，人人幸福”的時候，

不要懷疑它的真實性，

因為那顆美好稚氣的心絕對是真的。



&nbsp;

巨蟹是脆弱的一族，

卻不會讓別人看到自己的脆弱，

甚至最好的朋友。

心裡有什麼憋悶，

不喜歡找好朋友傾訴，

有時候寧願拉著一個陌生人傾訴。

因為陌生人聽完就不會再記得那是誰。



&nbsp;

有條不紊的蟹子很少很難會情緒失控，

也很少有人能讓巨蟹情緒失控，

如果有，就是看的很重的事或人。

失控時間不會很久，

短些就是幾秒鐘，長些就是幾分鐘。

然後很快又會恢復先前的平靜和冷靜。

自我調節能力蠻強。



&nbsp;

心情低落或受傷的蟹子不需要任何人的安慰，

更加不會自暴自棄一蹶不振。

需要的只是空間時間以及那顆樂觀的心。

會自我安慰，自己勸自己看開，

自己為自己療傷，自己把自己武裝。

這個時候最好讓蟹子自己呆著，

因為朋友的出現不會對蟹子有什麼幫助，

而且，蟹子更不希望朋友看到自己低落受傷的樣子。



&nbsp;

巨蟹是樂觀的，

不喜歡對人抱怨，更不喜歡聽別人找自己訴苦。

所以你最好別在蟹子面前抱怨，

就算你是他們最好的朋友。

當你抱怨第一句時蟹子會安慰你，

抱怨第二句是會附和你，

抱怨第三句的時候，

保證巨蟹已經失去了繼續聽下去的耐心，

雖然不會表現出來，

但你會發現蟹子已經開始不說話了，

只是“恩恩恩”“是?”“哦”。

巨蟹可以幫你出點子，做分析，

但絕對受不了嘮嘮叨叨抱怨訴苦。



&nbsp;

巨蟹吃醋時不愛說話，也不會明講。

只是你會發現蟹子有點氣嘟嘟的一個人生悶氣，

說話語氣有點陰陽怪調，自然就不會給你好臉色看了。



&nbsp;

很少說承諾，一旦說出就會履行；

很少說“我愛你”，說了出來就是真的愛你。

喜歡用行動來證明一切。責任心重。



&nbsp;

蟹子不愛懷疑別人，

所以也別懷疑蟹子誠實度。

懷疑的結果是讓蟹子傷，生氣，

也會變得不再相信你。

48.喜歡創造小驚喜，喜歡製作小浪漫。



&nbsp;

如果兩個互相相愛的人，

巨蟹覺得自己的存在阻礙對方的前途或發展，

會選擇自動離開。

很愛很愛你，所以願意，捨得讓你，

往更多幸福的地方飛去。

很愛很愛你，所以願意，不牽絆你，

飛向幸福的地方去。



&nbsp;

&nbsp;

接受能力很強，

什麼都可以理解，什麼都可以接受，

但請你親口說出來。

因為即使蟹子猜得到，

從別人那裡聽的到，

也希望親耳聽你說出來。

因為關於你，蟹子在乎的只是你。



&nbsp;

如果你表白後，

一個蟹子對你說“不喜歡你”或者類似的話，

就等於判了你死刑。

這個時候不要想著繼續努力來感動蟹子。

沒用的。蟹子就像彈簧，

你施力越大，他們就把你彈的越遠。

蟹子對自己不喜歡的人可以很殘忍，

就算心裡會內疚也會繼續殘忍，

好像這也是蟹子最冷血的時候。

如果還想做朋友，就什麼都不要做。



&nbsp;

小事糊塗，大事聰明。

有些蟹子看起來是正常人，

可經過交談後會發現有些很簡單的東西都不知道。

不要以為那是在裝，蟹子就是這樣，

出人意料的單純，大家都懂的事情會不懂。

發覺了單純之後也不要以為蟹子就蠢的什麼都不懂，

大事情照樣可以比你更有智慧，

更有主見，更有見地。

蟹子沒你想像的精明，

他們本不是精打細算的人；

蟹子沒你想像的愚蠢，

他們有的是大智慧。
