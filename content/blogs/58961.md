&nbsp;&nbsp;&nbsp; 大乘佛教中有著重要影響力的經典《金光明經》當中有這樣一則故事：


&nbsp;


&nbsp;&nbsp;&nbsp; 諸葛長青：這個故事是說釋迦牟尼佛成佛之前放生的故事。


&nbsp;


&nbsp;&nbsp;&nbsp; 在寶積如來出世的時候，當時釋迦牟尼佛是流水長者。


&nbsp;


&nbsp;&nbsp;&nbsp; 他經年累月不疲不厭地救濟眾生，因此受到人民的敬仰。富貴高權的長者經常四處訪視，關心周遭一切，在民間時常流傳著長者助貧扶弱的仁慈事蹟，讚揚長者的種種菩薩行持……


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 有一天，他看到附近一個大水澤中，忽然乾旱了、


&nbsp;


&nbsp;&nbsp;&nbsp; 放眼望去，橫豎躺著成千上萬的魚群，奄奄一息，在幾乎見底的水澤中不斷掙扎。眼看烈日曝曬下，魚群必死無疑！


&nbsp;


&nbsp;&nbsp;&nbsp; 他用大象往一個快要乾涸的水池當中運水，救活了水池當中的一萬條魚。


&nbsp;


&nbsp;&nbsp;&nbsp; 長者為了搶救魚命，甚至向國王借來二十頭大象。父子三人領著群象至大河中取水後，立即放水至空澤中，在他們的努力下，終於使水澤的水位逐漸上升，魚群獲得豐沛的水量，恢復生機，歡悅地悠游于水中。見到魚群得以脫離險境，長者松了一口氣，來回巡視魚池四周，魚群感應到長者的慈悲救生，紛紛循岸而遊，緊跟著長者的腳步。看著魚群眼神中流露著祈盼，長者突然想到，這段時間下來，魚群沒有食物，現在一定很饑餓，於是吩咐兒子趕緊回家收集食物，以最快的速度運送到這裏。經過長者的施予，魚群總算安穩了下來。


　　長者思惟：「我今天給予這些魚群所需、所食，希望未來亦能施予眾生無上法食！過去曾經聽聞一位比丘讀誦大乘經典，經上說：『若有眾生臨命終時，得聞寶勝如來名號，即生天上。』我現在也應該為魚群解說十二因緣之法，並為魚群稱說寶勝如來名號。」為魚群宣說經義後，一行人也法喜的踏上歸途。


　　後來，這些魚群死後往生至忉利天，化為容貌端嚴的天人。


&nbsp;


&nbsp;&nbsp;&nbsp; 其中有些天人憶念起前世的因緣，便告訴其他天人說：「我們曾于閻浮提內墮入畜生道受魚身，那時流水長者不但供給水和飲食，又為我們宣說十二因緣法和寶勝如來名號。因為這樣的助緣，我們才得以生天，我們應供養長者，報答此恩！」


&nbsp;


&nbsp;&nbsp;&nbsp; 在長者沉睡的一個夜裏，樓屋上空出現了一片光明，祥雲聚集，數千萬天人來到長者的處所，奉上無數珍寶，飄落的天花伴著虛空中響起的美妙天籟……


&nbsp;&nbsp;&nbsp; 偉大的佛祖釋迦牟尼佛的這個故事，告訴人們：


&nbsp;


&nbsp;&nbsp;&nbsp; 行善積德，持續發生，福報巨大！


&nbsp;&nbsp;&nbsp; 現實生活中，人們面對激烈的市場競爭，往往迷失了自己。


&nbsp;


&nbsp;&nbsp;&nbsp; 有的人渴望富貴吉祥、吉祥如意。


&nbsp;


&nbsp;&nbsp;&nbsp; 有的人渴望財源廣進、事業騰飛......。


&nbsp;


&nbsp;&nbsp;&nbsp; 如何實現啊？


&nbsp;


&nbsp;&nbsp;&nbsp; 阿彌陀佛，實際上很簡單啊，那就是“諸惡莫作、眾善奉行”。


&nbsp;


&nbsp;&nbsp;&nbsp; 戒殺放生，是行善的一大功德！


&nbsp;


&nbsp;&nbsp;&nbsp; 持續放生功德無量。


&nbsp;


&nbsp;&nbsp;&nbsp; 人生在世，為什麼不做善事，反而去殺生呢？


&nbsp;


&nbsp;&nbsp;&nbsp; 行善積德，必有福伯，命運肯定迅速改變。


&nbsp;


&nbsp;&nbsp;&nbsp; 諸葛長青你為，如果大家做好“懺悔、施食、放生行善、念佛吃素、回向”五合一，那麼命運就會立刻改變！


&nbsp;


&nbsp;&nbsp;&nbsp; 放生，要符合儀軌，有緣者可以多看諸葛長青老師新浪博客文章。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;&nbsp;&nbsp; 有慈悲心的有緣者“花開千年”，念佛放生，有了很多感應。


&nbsp;


&nbsp;&nbsp;&nbsp; 她對諸葛長青老師說：


&nbsp;


&nbsp; &nbsp;&nbsp;諸葛長青先生好，我自從最近看了您的博客後，就開始放生，念佛號。


&nbsp;


&nbsp;&nbsp;&nbsp; 昨天放生回來後，晚上夢見紅色的花轎。


&nbsp;


&nbsp;&nbsp;&nbsp; 還夢見我的遠房奶奶向我媽借錢，數額是3000元，媽媽並沒有多少錢，但是很樂意將錢錯給她，3000元錢是由我丈夫幫我媽開鑰匙拿給我的遠房奶奶的。我在邊上聽到我的遠房奶奶口中說：你那點錢都借給我。好象沒瞧得起這點錢似的，但又需要媽媽錯給她，我就不服氣，講道理給她聽，我對她說：媽媽一共好不容易就聚這點錢，答應借給你，別人她都不一定借，你還不珍惜。你用完了明年就要還這錢。


&nbsp;


&nbsp;&nbsp;&nbsp; 她聽了我的話，也知道自己不好有點慚愧，認可了我的說法。後來夢就醒了。說明一下，媽媽和遠房奶奶都健在呢。


&nbsp;


&nbsp;&nbsp;&nbsp; 不知這夢預示著什麼。
