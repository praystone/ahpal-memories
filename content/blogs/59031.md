&nbsp;

網路給人與人之間帶來了什麼 



&nbsp;




&nbsp;


在茫茫的五彩斑斕的網路中

&nbsp;

人與人之間的相遇就是緣

&nbsp;

是一種最純潔，最高尚，最樸實，最平凡的情感
&nbsp;

網絡世界是虛擬的，也是最真誠的

&nbsp;

是具體的，也是最抽象的

&nbsp;

這就正好地填補了人生中的缺憾與不足

&nbsp;

但正是這些生活中的不足

&nbsp;

才給許多人帶來最動人，最浪漫，最堅實，

&nbsp;

最永恆的情緣

&nbsp;

&nbsp;

在這個大千世界裡，紅塵涌動，芸芸眾生

&nbsp;

能夠彼此相遇，能夠走到一起

&nbsp;

彼此相望，相互認識，相互了解，相互走近

&nbsp;

這就是由網路交友提升到情感中的一個量變到質變的過程

&nbsp;

是由一個普通的交友變成一個深層次的交友的過程

&nbsp;

這就是當今網路給人與人之間帶來

&nbsp;

發展交友的振落激進的過程

&nbsp;

它的飛躍是在網海中聚散分離的人生旅途的歷程

&nbsp;

在各自不同的人生軌跡中的一個轉折點

&nbsp;

網海的存在促成了網民面貌的煥然一新

&nbsp;

不同的經歷，有不同的波折，能彼此相遇，相聚，相逢，

&nbsp;

帶來盼望己久的生機勃勃的春天

&nbsp;

可以說都是網絡帶來的通途
&nbsp;

&nbsp;

在現實生活中不曾擁有的人生幸福與快樂

&nbsp;

在網絡中可以萌芽漸漸獲得

&nbsp;

也就是這種神奇的網路中才會有這份真正的緣情

&nbsp;

有時網友們也不要求真正的擁有

&nbsp;

只需要那份深深的牽掛

&nbsp;

也不需要真正生活在一起，但需要那份真摯的友情和關懷

&nbsp;

不需要永遠的攜手，更需要那份永遠的友情和知已

&nbsp;

是網路拉近了彼此的距離

&nbsp;

是緣的相識有了精神上的寄托

&nbsp;

是力量的支持，是一種伴著記憶的安慰

&nbsp;

在網友的心中永久的那份期盼

&nbsp;

那就是彼此的相扶，相承，相伴，相佐的網路情緣
&nbsp;

&nbsp;

走近網絡的迅速形成

&nbsp;

是高科技傳播的高潮崛起，也是當今網路繁榮的主要體現

&nbsp;

是人與人之間心胸豁然的開朗，彼此也呼吸著新鮮的空氣

&nbsp;

也在迷茫之中找到了精神的寄托

&nbsp;

彼此敞開了心扉，訴說那生活中的許多無奈

&nbsp;

還可以在網路中盡情傾訴，發洩來自心底的悲泣


&nbsp;

有無數個知已，心靈上的相惜與攜手

&nbsp;

在各自的軌跡中把友情化為無聲的珍藏

&nbsp;

是網路的紐帶靜靜的滋潤那乾涸的心底

&nbsp;

有多少次靈魂被一次，又一次的洗滌

&nbsp;

又有多少夢從這裡放飛，盡情的徜徉，

&nbsp;

再次撥動那誘人的心弦，又有多少疲憊的身軀得到釋放

&nbsp;

又有多少個祝福與祈禱帶著生命的希望

&nbsp;

又有多少受傷的心靈與破碎的心，在這裡脫殼而出

&nbsp;

同時也更換了一顆心，慢慢的更新蛻變

&nbsp;

一個命運的毀滅，另一個命運誕生
&nbsp;

這就是網絡給網民們帶來的思念，

&nbsp;

牽掛，失落，遺憾以及滿足欲的需求



&nbsp;
