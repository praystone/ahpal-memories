望著你漸漸離去的背影

&nbsp;

&nbsp;

已然…

&nbsp;

&nbsp;

有種崩潰的無助襲上四肢…

&nbsp;

&nbsp;

這樣強烈的渴望與呼喊

&nbsp;

&nbsp;

究竟只是今晚的微醺氣氛使然

&nbsp;

&nbsp;

還是被壓抑許久的思念爆發所導致？

&nbsp;

&nbsp;

無論如何

&nbsp;

&nbsp;

在你掙脫我的雙手時

&nbsp;

&nbsp;

這股力量猛然地回擊心頭…

&nbsp;

&nbsp;

你沒發現到

&nbsp;

&nbsp;

其實我已搖搖欲墜… 

&nbsp;

&nbsp;

「可以不要走嗎？」

&nbsp;

&nbsp;

這是用幾近卑微哀求的姿態

&nbsp;

&nbsp;

所發出的求救訊號

&nbsp;

&nbsp;

如果不曾擁抱…

&nbsp;

&nbsp;

是否就可以不貪婪你的體溫？

&nbsp;

&nbsp;

如果沒有那個吻…

&nbsp;

&nbsp;

是否就可以永遠保持安全距離？

&nbsp;

&nbsp;

如果不去執起你的手…

&nbsp;

&nbsp;

是否就可以輕易放手？

&nbsp;

&nbsp;

現在的你到底有多想我呢？

&nbsp;

&nbsp;

你對我到底是怎樣的感覺呢？

&nbsp;

&nbsp;

這樣的疑問句

&nbsp;

&nbsp;

終究還是會不停地在心中浮現…

&nbsp;

&nbsp;

之於你

&nbsp;

&nbsp;

也之於自己… 

&nbsp;

&nbsp;

掉下了眼淚…

&nbsp;

&nbsp;

心好痛好痛...

&nbsp;

&nbsp;

好多的記憶浮上心頭

&nbsp;

&nbsp;

好多的感覺來不及消化

&nbsp;

&nbsp;

好多的思念與無奈刺痛了我心…

&nbsp;

&nbsp;

我是怎麼了

&nbsp;

&nbsp;

我到底是怎麼了

&nbsp;

&nbsp;

為什麼會這樣… 

&nbsp;

&nbsp;

在電話的那頭

&nbsp;

&nbsp;

我聽見了你淚水的泣訴…

&nbsp;

&nbsp;

在凌晨零點10分的冷清街頭

&nbsp;

&nbsp;

我也聽見了自己的… 

&nbsp;

&nbsp;

閉上眼…

&nbsp;

&nbsp;

根本…

&nbsp;

&nbsp;

我還停留在這一夜情感

&nbsp;

&nbsp;

全然釋放的漩渦中

&nbsp;

&nbsp;

無法逃脫……。
