&nbsp;

打開日記本，讀著每一天的想念。

&nbsp;

我想，在這個淡藍色的回憶中，

&nbsp;

充斥著的，除了思念，還有什麼呢？



這些由思念所帶出的心情在歲月中流逝，

&nbsp;

我只是用另一種文字的形式將它們記錄。

&nbsp;

末了，輕輕地寫上一句，想念你。

&nbsp;

淡淡的，如茶一般。

&nbsp;



有人說，

&nbsp;

愛一個人是那樣的平平淡淡，

&nbsp;

而想一個人卻是那樣的撕心裂肺。

&nbsp;

每天都是那麼平淡地走完，如同一杯淡茶，

&nbsp;

而思念卻讓人無懈可擊，如同茶中微微的苦。



終於明白，原來自己每時每刻都在想他。

&nbsp;

思念的衝擊如同呼吸一般緊緊跟隨，

&nbsp;

卻也逃脫不了。

&nbsp;

只是，何人能夠記得自己時刻在想念，

&nbsp;

正如沒有人能夠記得自己時刻在呼吸。

&nbsp;

平淡得成為了一種習慣。



&nbsp;

於是我說，

&nbsp;

當思念成為了一種習慣，

&nbsp;

我們還會不會找回最初的那份心動？

&nbsp;

距離的隔閡會不會真的能讓人兩兩相忘？



或許……

&nbsp;

或許自己早已在這種習慣中深陷，無法自拔。

&nbsp;

愛一個人也許就是這樣，

&nbsp;

在不知不覺中迷失了自我。

&nbsp;

可是，當有朝一日，

&nbsp;

突如其來的分離面臨時，

&nbsp;

我會是怎樣的一種脆弱與頹廢？

&nbsp;

我不敢想像……



&nbsp;

&nbsp;

有一種距離，無法逾越；

&nbsp;

有一種想念，無法抹去。

&nbsp;

在疲憊的腦海裡幻化他的身影，最終一片空白。

&nbsp;

我什麼都沒有，一種空洞的守望。

&nbsp;

以為愛對了，得到的寂寞卻那麼長。



&nbsp;

在街角處，有一種人潮湧動的喧鬧襲來。

&nbsp;

壓抑得我只想逃避。

&nbsp;

城市的霓虹燈絢爛得刺目，

&nbsp;

街頭華麗而昂貴的櫥窗陳列著愛情最美的象徵。

&nbsp;

我想，這個世界很精彩，

&nbsp;

可它卻不屬於我。



我想，我只是習慣了那麼一份平淡和安靜而已。

&nbsp;

　　無論背負著多麼重的包袱，

&nbsp;

卻始終不願脫離自己的殼。

&nbsp;

也許，我早已習慣了這種防備中淡淡地思念……



只是，當思念成為一種習慣，

&nbsp;

我們還會不會尋回愛來的方向？

&nbsp;

&nbsp;
