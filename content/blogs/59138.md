&nbsp;

有一種朋友 ,

&nbsp;

我想那是一種介乎於愛情與友情之間的感情，

&nbsp;

你會在偶爾的一時間默默地想念他，

&nbsp;

想起他時，心裡暖暖的，

&nbsp;

有一份美好，有一份感動。

&nbsp;

在憂愁和煩惱的時候，你會想起他，

&nbsp;

你很希望他能在你的身邊，

&nbsp;

給你安慰，給你理解，

&nbsp;

而你卻從沒有向他傾訴，

&nbsp;

你怕屬於自己的那份憂傷會妨礙他平靜的生活。 

&nbsp;

&nbsp;

&nbsp;

你會因為一首歌曲，一種顏色，想起他，

&nbsp;

想起他的真摯，想起他的執著，

&nbsp;

想起他那曾經一起經歷過的風風雨雨。

&nbsp;

因為有了這樣一個朋友，

&nbsp;

你會更加珍惜自己的生命，

&nbsp;

熱愛自己的生活，

&nbsp;

因為你知道他希望你過的很好，

&nbsp;

他希望你能好好的照顧自己，

&nbsp;

再見面時，他希望你能告訴他你很幸福。

&nbsp;

&nbsp;

&nbsp;

那些世俗的觀念，在你的心中，

&nbsp;

因為他的存在而變的蒼白無力，

&nbsp;

你只是在心底深處為這個人設置了一處小小的空間，

&nbsp;

靜靜地固守著那份美好的回憶，

&nbsp;

從一開始你就知道，

&nbsp;

在你們之間不會有什麼愛情，

&nbsp;

似乎談起愛情就褻瀆了這份情感，

&nbsp;

這只能是一種友情。

&nbsp;

這到底是怎麼一回事呢？

&nbsp;

你想了許多年，卻始終沒有頭緒。

&nbsp;

&nbsp;

&nbsp;

你們很少聯絡，

&nbsp;

在這長長的一生中，

&nbsp;

你門相聚的時光也許只有幾萬分之一，

&nbsp;

但是在彼此的心中都保留了一份惦念，一份囑咐，

&nbsp;

就算他去到天涯海角，

&nbsp;

就算過了許多許多年，

&nbsp;

就算再見面時，早已是人非物亦非了，

&nbsp;

你仍然會那樣深刻的記著這樣一個人，

&nbsp;

這已經足夠了。 

&nbsp;

&nbsp;

&nbsp;

生活有時候平靜的會像一口枯井，

&nbsp;

也許你也會掉進這口枯井裡去，

&nbsp;

也許你沒有什麼天荒地老、海枯石爛的愛情，

&nbsp;

也許華髮早生、滿鬢蒼白，

&nbsp;

但是有了這樣的一位朋友，

&nbsp;

在你的生命中就會有些許漣漪，

&nbsp;

些許色彩，你想著他。

&nbsp;

默默的記起他，

&nbsp;

也許此生此世都不會忘記了。

&nbsp;

&nbsp;

&nbsp;

你很感激在這個世界上，

&nbsp;

有這樣的一個人，

&nbsp;

他不在你的身邊，

&nbsp;

他也並沒有為你做些什麼，

&nbsp;

你卻希望，他會過的很好，

&nbsp;

長命百歲，子孫滿堂，幸福安康……

&nbsp;

你也很高興有過那樣的一份感情，

&nbsp;

純淨而又綿長，

&nbsp;

在這紛繁複雜的人世中，

&nbsp;

有這樣的一個朋友，

&nbsp;

值得你去祝福，去思念 ……
