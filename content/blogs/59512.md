心裡好多小花貓 

&nbsp;

有時喵了一隻在哭泣&nbsp;&nbsp; 當我難過時

&nbsp;

偶爾輕聲喵了哼著歌&nbsp;&nbsp; 在我開心喜悅時

&nbsp;

那隻喵了好憂傷 心中千結萬愁時

&nbsp;

喵阿喵 輕輕柔柔的卻聽不進你心裡

&nbsp;

小花貓竄的心口疼疼地&nbsp;&nbsp; 尖牙刺的痛痛地

&nbsp;

喵阿喵 委屈的眼神是那麼濕濕地

&nbsp;

小花貓啊&nbsp;&nbsp; 可不可以乖乖的守護我的心

&nbsp;

用喵的撒嬌淡化了溼答答的天氣

&nbsp;

讓空氣水分子飄到河川去

&nbsp;

讓眼睛的濕淋淋變的亮晶晶

&nbsp;

喵嗚 喵嗚&nbsp;&nbsp; 又是哪隻在不安靜

&nbsp;

為了什麼喵喵又不安靜

&nbsp;
