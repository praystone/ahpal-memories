我以後嫁給你 好嗎?


要用她的一生來說這樣的一句話

&nbsp;



&nbsp;

&nbsp;


有個女孩子小時候腿就不靈活

&nbsp;

常年只能坐在門口看別的孩子玩 很寂寞

&nbsp;

有一年夏天 鄰居家城裡的親戚來玩

&nbsp;

帶來了他們的小孩 一個比這女孩大五歲的男孩

&nbsp;

因為年齡都很小的關係

&nbsp;

男孩很快就和附近的小孩打成了一片

&nbsp;

跟他們一起上山下河 一樣曬得很黑 笑得很開心

&nbsp;

不同的是他不會講粗口

&nbsp;

而且他注意到了一個不會走路的小姑娘

&nbsp;

男孩第一個把捉到的蜻蜓放在女孩的手心

&nbsp;

第一個把女孩背到了河邊，第一個對著女孩講起了故事

&nbsp;

第一個告訴她，她的腿是可以治好的

&nbsp;

第一個，仔細想來也是最後一個

&nbsp;

女孩很難得的開始有了笑容

&nbsp;

夏天要結束的時候 ，男孩子一家人要離開了

&nbsp;

女孩子眼淚汪汪來送，在他耳邊小聲的說

&nbsp;

我治好腿以後嫁給你好嗎? 男孩點點頭


&nbsp;

一轉眼二十年過去了

&nbsp;

男孩由一個天真的孩子長成了成熟的男人

&nbsp;

他開了一間咖啡店

&nbsp;

有了一個未婚妻 ，生活很普通也很平靜

&nbsp;

有一天他接到一個電話，一個女子細細的聲音說她的腿好了

&nbsp;

她來到了這個城市，一時間他甚至想不起她是誰

&nbsp;

他早已忘記了童年某個夏天的故事

&nbsp;

忘記了那個臉色蒼白的小女孩

&nbsp;

更忘記了一個孩子善良的承諾

&nbsp;

可是他還是收留了她 ，讓她在店裡幫忙

&nbsp;

他發現她幾乎終日沉默的，可是他沒有時間關心她

&nbsp;

他的未婚妻懷上了不是他的孩子，他羞恨交加

&nbsp;

扔掉了所有準備結婚用的東西 ，日日酗酒

&nbsp;

變得狂暴易怒 連家人都疏遠了他

&nbsp;

生意更是無心打理 ，不久. ..他就大病一場

&nbsp;

這段時間裡，她一直守在他身邊照顧他，容忍他，

&nbsp;

酒醉時的打罵，更獨立撐著那片搖搖欲墜的小店

&nbsp;

她學到很多東西 ，也累得骨瘦如柴

&nbsp;

可眼裡總跳躍著兩點神采


&nbsp;

半年之後他終於康復了，面對她所做的一切只有感激，

&nbsp;

他想把店送給她 她執意不要

&nbsp;

他只好宣佈她是一半的老板

&nbsp;

在她的幫助下他又慢慢振作了精神

&nbsp;

他把她當做是至交的好友

&nbsp;

掏心掏腹的對她傾訴 她依然是沉默的聽著


&nbsp;

他不懂她在想什麼


&nbsp;

他只是需要一個耐心的聽眾而已，這樣又過了幾年


&nbsp;

他也交了幾個女朋友，但都不長久


&nbsp;

他找不到感覺了，她也是 一直獨身


&nbsp;

他發現她其實是很素雅的 ，風韻天成


&nbsp;

不乏追求者 他笑她心高 ，她只是笑笑


&nbsp;

終有一天 他厭倦了自己平靜的狀態

&nbsp;

決定出去走走 ，

&nbsp;

拿到護照之前，他把店裡的一切正式交給了她


&nbsp;

這一次她沒再反對 只是說為他保管，等他回來

&nbsp;

&nbsp;

在異鄉飄泊的日子很苦 ，可是在這苦中


&nbsp;

他卻找到了開寬的眼界和胸懷，過去種種悲苦都雲淡風清


&nbsp;

他忽然發現無論疾病或健康，貧窮或富裕 如意或不如意


&nbsp;

真正陪在他身邊的 ，只有她


&nbsp;

他行蹤無定，她的信卻總是跟在身後


&nbsp;

只字片語 輕輕淡淡 ，卻一直覺著溫暖


&nbsp;

&nbsp;

他想該是回去的時候了


&nbsp;

回到家的時候，他為她的良苦用心而感動


&nbsp;

無論是家裡還是店裡 ，他東西的位置


&nbsp;

都一直好好保存著 ，彷彿隨時等著他回來


&nbsp;

他大聲叫喚她的名字卻無人應答


&nbsp;

店裡換了新主管，他告訴他


&nbsp;

她因積勞成病去世已半年了


&nbsp;

按她的吩咐 ，他一直叫專人注意他的行蹤


&nbsp;

把她留下的幾百封信一一寄出


&nbsp;

為他管理店裡的事 為他收拾房子 等他回來


&nbsp;

他把她的遺物交給他 一個蜻蜓的標本


&nbsp;

還有一卷錄音帶 ，是她臨終遺言


&nbsp;

帶子裡只有她迴光返照時宛如少女般的輕語

&nbsp;

&nbsp;

我 嫁給 你 好嗎?

&nbsp;

拋棄二十七年的歲月，他像孩子一樣嚎啕大哭起來

&nbsp;

沒有人知道，有時候 一個女人

&nbsp;

要用她的一生來說這樣一句簡單的話
