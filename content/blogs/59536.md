古 來 輪 迴 常 定 數

&nbsp;

不 離 五 行 三 界 住

&nbsp;

縱 觀 物 化 生 類 聚

&nbsp;

雖 各 千 秋 亦 演 復

&nbsp;

得 失 盛 衰 不 由 術

&nbsp;

志 之 所 向 矢 盡 處

&nbsp;

若 能 脫 羣 造 新 命

&nbsp;

必 非 朝 陽 葵 花 木

人從出生就成了死神的箭垛

&nbsp;

智慧開啟是文昌之矢 職場升遷是官祿之矢 感情觸動是紅鸞之矢

&nbsp;

...

&nbsp;

奚以箭垛謂之？蓋其不自得矣。

&nbsp;

非是命定論

&nbsp;

矢之未發意在先 志初萌而弓滿弦 待時彀弽

&nbsp;

人生的階段有無數小輪迴 我們常陷入後悔的輪迴中重復

&nbsp;

無論如何改變自己總是無法改變錯誤的輪迴

&nbsp;

因為心向的目的地並沒有被修正 過程經歷雖有不斷努力改善

&nbsp;

其實

&nbsp;

箭落處的標靶仍未移動 錯誤之矢早已蓄勢待發！

&nbsp;

網路上有一則戲謔短語：

&nbsp;

在錯的時間遇到對的人 ~&nbsp;這是小三

&nbsp;

在對的時間遇到錯的人 ~ 這是三小

&nbsp;

在錯的時間遇到錯的人 ~ 這是雖小

&nbsp;

在對的時間遇到對的人 ~ 這是濠小

&nbsp;

&nbsp;

這只是則笑話 並無邏輯可言

&nbsp;

真是對的人就不會有時間對錯的問題

&nbsp;

我們想改變自己一直重覆的錯誤

&nbsp;

&nbsp;

應當由心開始

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

往事如灰愛情寫湮滅

唯有落日前夕陽的餘暉

&nbsp;

描繪昨日的美和高貴

&nbsp;

思念結解開花已落成堆
