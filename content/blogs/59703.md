情感的驚嘆號

&nbsp;



&nbsp;

&nbsp;


人活這一輩子，總會碰到幾個特別的人，

&nbsp;

這個人可能就是你找尋一生的至愛，

&nbsp;

也可能只是你純粹的精神寄托，


說他是你的朋友吧！

&nbsp;

但他卻對你傾注的關愛超出了一般朋友的界階和理念，

&nbsp;

可你和他又不曾有過將之昇華為愛人的那種具體行動，

&nbsp;

你們之間或者常常淡如水，

&nbsp;

所以，這一類人，應該是你的情人和朋友，


&nbsp;

你或許會因為一首懷舊的老歌，

&nbsp;

一幕戀人的牽手想起他，想起他的愛戀，想起他的寵愛，

&nbsp;

你或許會因為一道似曾相似的風景，

&nbsp;

你會執著與他的情，與他的緣，總想留住幸福的時間，

&nbsp;

你不求擁有，只盼望痴痴地守侯，

&nbsp;

你想綁住他在你身邊，

&nbsp;

卻怕妨礙他在藍天白雲間翱翔的自由，

&nbsp;

那些世俗的道德理念，因他而瓦解，

&nbsp;

即使成為世人眼裡的叛離者，

&nbsp;

而你只是在心底深處為這個人留了一個小小的空間，

&nbsp;

靜靜地守著那份說不清的情感，即使陪伴寂寞你亦不會後悔。

&nbsp;

生命有時是無奈的，生活有時又是殘酷的，

&nbsp;

當你覺得生命像一潭死水，

&nbsp;

寂靜得沒有一圈漣漪泛起時，你會心慌，你怕被生命遺忘，

&nbsp;

但是，因為有了他的存在，

&nbsp;

你的生命多了條雨後彩虹，

&nbsp;

你很想念他，或許你們的相識相知只是瞬間，

&nbsp;

他會盤踞在你的內心深處，但是你卻很感激命運，

&nbsp;

感激上蒼給了你這樣的一個人。

&nbsp;

一個讓你在這個世上不在孤單，不再寂寞的人，

&nbsp;

即使是痛苦，也甜過麻木的蒼白，

&nbsp;

雖然他不會永遠的陪伴在你的身旁，

&nbsp;

雖然，你不曾要求他為你做些什麼，

&nbsp;

你卻希望他會過得很好，過的幸福安康。

&nbsp;

在這複雜的社會當中，在這無奈的人生當中，

&nbsp;

有這樣一個人，當你走得疲倦時，

&nbsp;

只要一轉身就能找到依靠，

&nbsp;

&nbsp;

當你絕望時會及時拯救你的靈魂，你還奢求什麼。

&nbsp;

這樣一個人，這樣一種情感，讓你飄蕩的心變得柔軟脆弱，

&nbsp;

讓你思念的心擁有溫潤的一刻。

&nbsp;

更讓你獨享著一生眷戀和牽掛，

&nbsp;

一世寬容和給予，擁有著今生的思念與回憶，

&nbsp;

來生的執著與寄托，情感的驚嘆號，

&nbsp;

只能用心去感受，用心去儲藏。


&nbsp;



&nbsp;
