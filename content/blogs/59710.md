今天在公司吃晚飯

&nbsp;

菜色中規中矩

&nbsp;

吃沒多久  我旁邊坐了一個人

&nbsp;

讓我心中緊張了起來

&nbsp;

夾菜時還會不小心掉入桌子

&nbsp;

他不是別人 他是老闆的2女兒 2千金

&nbsp;

&nbsp;

&nbsp;

2千金人皮膚白白&nbsp; 高雅中有種特殊發出來傲氣(這種傲氣有點像寒冷的冰山)

&nbsp;

2千金滿高的167~169吧 不會太瘦不會胖 人也滿漂亮唷  是 碩士畢業

&nbsp;

有時候上班我會偷看她幾眼 (不能說上喜歡 ˊ只是喜歡看有錢人穿著打扮)

&nbsp;

上回 參加老闆女兒訂婚&nbsp;&nbsp; 是大千金&nbsp; 是2千金的姐姐

&nbsp;

聽說2千金 還沒有男朋友  (公司的人都說人人有機會啦)

&nbsp;

&nbsp;

&nbsp;

2金千 坐在我旁邊 我整個人動作都變了

&nbsp;

吃飯小小口 喝湯也不敢發出一點點聲音

&nbsp;

我心中想您趕快走啦  害我吃得那麼不自在

&nbsp;

可是心中又有另一個想法&nbsp; 能跟2千金難得坐一起 也是甜呀

&nbsp;
