從前有兩隻小豬，整天過著無憂無慮的生活，他們互相相愛著。
&nbsp;&nbsp;
每天主人送來吃的時候，公豬總是先讓母豬吃，

&nbsp;

等她吃飽了再上去吃母豬吃剩下的東西，

&nbsp;

每天晚上公豬總是給母豬放哨，他生怕主人乘他們熟睡時把母豬拉出去宰了。
&nbsp;&nbsp;

日子一天天的過去，母豬日漸長胖，而公豬則一天天瘦下去。


&nbsp;

有一天，公豬突然聽見主人在跟屠夫商量，

&nbsp;

要把長勢見長的母豬殺了給賣掉，公豬傷心至極。
&nbsp;&nbsp;

於是從那天開始公豬性情大變，

&nbsp;

每當主人送吃來時公豬總搶上去把東西吃的一乾二淨，

&nbsp;

每天吃後便躺下大睡，並且告訴母豬現在換做她來放哨，

&nbsp;

如果他發現她沒放哨的話就再也不理她。
&nbsp;&nbsp;

漸漸的日子一天天過去，母豬覺得公豬越來越不在乎她，

&nbsp;

母豬失望了，而公豬還是若無其事的過著安樂日子&nbsp;................&nbsp;

&nbsp;

很快一個月過去了，主人帶著屠夫來到豬圈， 

&nbsp;

他發現一個月前肥肥壯壯的母豬瘦的沒剩下多少肉而公豬則長的油光發亮．
&nbsp;&nbsp;
這時的公豬拼命的奔跑，想引起主人的注意，表明他是頭健康的豬。


終於，屠夫把公豬拖出豬圈的那一刻，公豬朝著母豬笑著說：『以後別吃這麼多！』

&nbsp;

母豬傷心欲絕，拼命的衝出去，

&nbsp;

但圈門被主人關上了，擱著柵欄，母豬看著閃著淚光的公豬。
&nbsp;&nbsp;


那晚，母豬望著主人一家開心的吃著豬肉，

&nbsp;

母豬傷心的躺倒在以前公豬每天睡的地方，突然她發現牆上有行字：

&nbsp;

『如果愛無法用言語來表達，我願意用生命來證明』！
&nbsp;&nbsp;


母豬看到這行字肝腸寸斷，人類聽到這個淒美的愛情故事也無不為之動容，


&nbsp;

女性們為了紀念這段愛情，

&nbsp;

同時也表示沒忘記公豬臨前的遺囑『以後別吃這麼多』&nbsp;.....................................&nbsp; 
..

..

..

&nbsp;

開始流行減肥的啦......!!
