有人牽掛真好

&nbsp;



&nbsp;

&nbsp;


有人牽掛真好，那被人牽掛的感覺很妙。

&nbsp;

牽掛，

&nbsp;

那是人間至真的情，那是人間至真的愛。

&nbsp;

如果有人牽掛你，如果你也牽掛別人，

&nbsp;

你就會是最幸福的人。 


牽掛一個人，是對他的深深惦記，

&nbsp;

是分分秒秒的思念，是時時刻刻的祝福，

&nbsp;

是日日夜夜的期盼。

&nbsp;

&nbsp;

牽掛一個人，是你閒適時的全部，

&nbsp;

是你忙碌時的休憩，

&nbsp;

心中有牽掛人的話語，夢中會有牽掛人的身影。

&nbsp;

牽掛一個人，那是放不下的情懷，剪不斷的情思。


&nbsp;

有了牽掛，親情就多了一份溫馨；

&nbsp;

有了牽掛，友情就多了一種幸福；

&nbsp;

有了牽掛，愛情就多了一縷相思。


&nbsp;

牽掛別人是甜蜜的幸福，

&nbsp;

被人牽掛則是世上最美妙的幸福。

&nbsp;

來自親友的問候，讓你從不孤單。

&nbsp;

朋友的真誠祝福，讓你信心倍增。

&nbsp;

愛人的思念，讓你的心靈充滿陽光。
　　

有人牽掛真好，所有人都在尋找，

&nbsp;

那被人牽掛和牽掛別人的感覺。

&nbsp;

你牽掛的人值得你珍惜，牽掛你的人你要懂得珍惜。


&nbsp;

有人牽掛真好，

&nbsp;

那是一杯濃郁的感情瓊漿，

&nbsp;

醉了多少人的心，圓了多少人的夢。

&nbsp;

愛你的人對你的牽掛是你前進的動力，

&nbsp;

是你創業的階梯，是你心靈的港灣。

&nbsp;

&nbsp;

有了那份牽掛，

&nbsp;

你的生命不在蒼白，你的生活不在無奈。

&nbsp;

有了那份牽掛，

&nbsp;

你會感覺夏天不在炎熱，冬季不在寒冷。

&nbsp;

有了那份牽掛，

&nbsp;

你的身體更健康，你的笑容更燦爛。
　　

&nbsp;

愛你的人牽掛著你，你牽掛著你愛的人，

&nbsp;

他的心中時時記得你，你也會在意他的一切。

&nbsp;

讓你們的情感在牽掛中沉澱，讓你們的心靈有所寄託。


&nbsp;

牽掛，是心靈的對話，

&nbsp;

是心靈的呼喚，是心靈的回應！
　　
牽掛啊，你是世界上最美好的情感！

&nbsp;

誰不想擁有你呢？
