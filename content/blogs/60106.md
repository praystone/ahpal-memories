&nbsp;


這個故事說穿了你我的心態


&nbsp;



&nbsp;

&nbsp;


A不喜歡吃雞蛋，每次發了雞蛋都給B吃。

&nbsp;

剛開始B很感謝，久而久之便習慣了。

&nbsp;

習慣了，便理所當然了。

&nbsp;

於是，直到有一天，A將雞蛋給了C，B就不爽了。

&nbsp;

她忘記了這個雞蛋本來就是A的，A想給誰都可以。

&nbsp;

為此，她們大吵一架，從此絕交。


&nbsp;

有一年，很熱的夏天，一隊人出去漂流。　　

&nbsp;

女孩的拖鞋在玩水的時候，把拖鞋掉下去了，沉底了。

&nbsp;

到岸邊的時候，

&nbsp;

全是曬的很燙的鵝卵石，他們要走很長的一段路。

&nbsp;

於是，女孩兒就向別人尋求幫忙，

&nbsp;

可是誰都只有一雙拖鞋。

&nbsp;

女孩心裏很不爽，因為她習慣了向別人求助，

&nbsp;

而只要撒嬌就會得到滿意地答覆。可是這次卻沒有。

&nbsp;

她忽然覺得這些人都不好，都見死不救。


&nbsp;

後來，有一個男孩將自己的拖鞋給了她，

&nbsp;

然後自己赤腳在那曬得滾燙的鵝卵石上走了很久的路。

&nbsp;

還自嘲說是鐵板燒。

&nbsp;

女孩表示感謝，男孩說，你要記住，

&nbsp;

沒有誰是必須要幫你的。

&nbsp;

幫你是出於交情，不幫你是應該。女孩記住了男孩的話，

&nbsp;

自此以後學會了對施以援手的人銘記在心，

&nbsp;

並給以更大的回報。

&nbsp;

&nbsp;

很多時候，我們總是希望得到別人的好。

&nbsp;

一開始，感激不盡。可是久了，便是習慣了。

&nbsp;

習慣了一個人對你的好，便認為是理所應當的。

&nbsp;

有一天不對你好了，你便覺得怨懟。

&nbsp;

其實，不是別人不好了，而是我們的要求變多了。

&nbsp;

習慣了得到，便忘記了感恩.


&nbsp;
