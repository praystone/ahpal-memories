所有的女生都不願意做地下情人，但是有上榜的星座會「不小心」，
&nbsp; &nbsp; 或是在「某種機緣下」，容易當地下情人。

第3名&nbsp;&nbsp;天蠍座

&nbsp; &nbsp; 通常天蠍座願意做地下情人是有但書的，就是他在等某個機會。
&nbsp; &nbsp; 他先佔1個位置，就好像佔停車位的感覺。就算這個停車位不適合他，
&nbsp; &nbsp; 但是他先佔著位置。所以有些天蠍座可能暫時做地下情人，但是他心裡不願意。
&nbsp; &nbsp; 如果有機會，他還是想做正牌的那個情人，但是他會先卡1個位置，
&nbsp; &nbsp; 他抱著隨時篡位的心態。

第2名&nbsp;&nbsp;天秤座

&nbsp; &nbsp; 你要給天秤座1個平衡點，譬如說他沒有很愛你，你卻每個月給他花用，
&nbsp; &nbsp; 他就會想說：「反正我也沒有很愛你，而且我外面有男朋友。」
&nbsp; &nbsp; 他找到平衡點就OK。但他在當地下情人的過程當中，會一直碎碎唸，
&nbsp; &nbsp; 一直覺得自己過得不是很好。也許最後還是分手，但是他會忍受一陣子的狀況，
&nbsp; &nbsp; 最後分手他可能自己也受不了，就分了。可是在當地下情人的時候，
&nbsp; &nbsp; 只要你有給他平衡點，比方說該照顧他有照顧他，他還是可以在心裡，
&nbsp; &nbsp; 微微地忍受一下，他是需要常常呼呼跟惜惜的那種。

第1名&nbsp;&nbsp;水瓶座

&nbsp; &nbsp; 水瓶座的想法就比較獨立和另類，他會想說：「是你玩我，還是我玩你？
&nbsp; &nbsp; 搞不好大家互玩，也很難講。」而且水瓶座會認為：「現在是地下情，
&nbsp; &nbsp; 看起來好像我是你的地下情人，可是在別人眼中，你才是我的地下老公。」
&nbsp; &nbsp; 他會有另外1種想法，所以他完全不會在意這種情況。
