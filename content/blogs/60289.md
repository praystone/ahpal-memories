有什麼好煩惱的，有什麼好擔心的，最壞、最差勁、&nbsp;&nbsp;



最痛苦的情況也不過如此了，既然是在谷底，


&nbsp;


就不用在擔心什麼，事情會慢慢在你的堅信之下，


&nbsp;


往好的、光明的方向去走，但你要堅信事情會往好的方向去走，


&nbsp;


要是自己無法把自怨自艾、怨嘆的心態放下，


&nbsp;


你同樣的只會在谷底無法看見光明。


&nbsp;


遇上了不願意面對的情況，逃避無法解決問題，


&nbsp;


墮落更無法處理好事情，可是你有選擇的權利，


&nbsp;


選擇用什麼心態去處理它，或許無法處理的盡善盡美，


&nbsp;


不過要知道盡力就好，盡力之後，剩下的就是看開一點，


&nbsp;


然後聽天由命吧！告訴自己最壞的情況也不過是如此而已，


&nbsp;


不必要一直把自己困在沒有陽光的地方。


&nbsp;


<?xml:namespace prefix = v ns = "urn:schemas-microsoft-com:vml" />




&nbsp;


盡力做好該做的本份，然後接受一切環境或命運的安排，


&nbsp;


環境可能可以改變也可能無法改變，


&nbsp;


有時候改變之後要付出的代價會超乎你的想像，


&nbsp;


有時候則會讓你好過些，


&nbsp;


可是當你在想著要如果改變這些遭遇的同時，


&nbsp;


問問自己有盡力了嗎？其實當我們盡力，


&nbsp;


就是在改變命運了，其實當我們學著看開些的時候，


&nbsp;


就在改變遭遇了。


&nbsp;


自己站在黑暗的地方，那就不要再繼續往黑暗裡去，


&nbsp;


可是太多人明明已經都站在黑暗裡了，


&nbsp;


卻一邊自怨自艾一邊怨嘆著命運的不公平，


&nbsp;


然後自己把自己推向更黒更暗的地方去，


&nbsp;


你不用一直用悲哀來裝飾自己，因為不但會沒人同情你，


&nbsp;


你還是把自己越推向無法回頭的地步，


&nbsp;


告訴自己，最壞也不過如此，


&nbsp;


當下立刻重新走向光明。


&nbsp;


別認為自己多可憐，你要思考的是要如何


&nbsp;


重新在痛苦的遭遇中苦中作樂，


&nbsp;


你的人生可以任由你揮霍，可是別忘記，


&nbsp;


當你把時間浪費在悲傷、痛苦的輪迴中，


&nbsp;


失去的一切都不會再回來，而你只會越來越可憐而已。


&nbsp;


請相信自己，因為最壞也不過如此，


&nbsp;


放下些、看開些、盡力些，所有的美好都會再度出現，


&nbsp;


要是無法接受這些考驗、面對最壞的遭遇、


&nbsp;


不想重新面對陽光，那你的人生才真正的可悲。
