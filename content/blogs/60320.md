&nbsp;

&nbsp;

 
真情最珍貴 



&nbsp;

&nbsp;


世界上什麼是最珍貴的

&nbsp;

答案有很多種

&nbsp;

但有一種那就是人與人之間的那份真情

&nbsp;

友誼是建立在相互信任的基礎上的

&nbsp;

友誼有時也很脆弱

&nbsp;

一句話可能讓非常好的朋友分道揚鑣

&nbsp;

越是走的很近的人關係就更加的微妙

&nbsp;

人與人之間最關鍵的就是包容

&nbsp;

你的親人朋友誤會你時你不要和他爭吵

&nbsp;

就讓他給你使使性子、發發脾氣

&nbsp;

當他回過味兒的時候他就會感激你

&nbsp;

誰讓他是你的朋友和親人呢
&nbsp;

&nbsp;

我喜歡一句話

&nbsp;

「捨得捨得只有捨才有得」

&nbsp;

但是真正理解並做到「捨得」的人卻少之又少

&nbsp;

「捨」是一種心胸更是一種魄力

&nbsp;

那「捨」字其實就是忍痛割愛

&nbsp;

有的人自己很節儉為了親人卻十分捨得

&nbsp;

有的人為別人從不願意付出什麼

&nbsp;

為了自己卻非常捨得

&nbsp;

「捨」是人的境界一種真實寫照

&nbsp;

是人品德的一種展示，更是人心善的完美表現
&nbsp;

&nbsp;

我還欣賞一句話叫「心有多大舞台就有多大」

&nbsp;

同樣都是人有的人心胸很寬廣

&nbsp;

能容很多常人難以容忍的事情

&nbsp;

海納百川有容為大，宰相肚裡能撐船

&nbsp;

講得都是一個「容」字

&nbsp;

寬容別人就是善待自己

&nbsp;

包容他人就是濃重自己

&nbsp;

心是世界上最難捉摸的

&nbsp;

當一個人心胸敞開的時候

&nbsp;

我感覺比天空還要開闊，比大海還要蔚藍
&nbsp;

&nbsp;

世界上你可能遇到過很多人

&nbsp;

但有一種人一輩子沒有造化你絕對遇不上

&nbsp;

那就是把自己的心交給信任的人

&nbsp;

而無怨無悔地去為了一個人心甘情願地為他/她著想的人

&nbsp;

&nbsp;

緣分很奇妙

&nbsp;

茫茫人海芸芸眾生那麼多的人

&nbsp;

能相知相惜真的是一輩子的情

&nbsp;

有個哲人說過『金錢買不到讓自己發自內心的感動』

&nbsp;

我起初對這句話理解不是很透

&nbsp;

有的人很富有可精神世界裡很孤寂

&nbsp;

有的人很貧困可每天活的很快活

&nbsp;

因為境界不同索取不同

&nbsp;

人與人之間的差異就不可同日而語了
&nbsp;

&nbsp;

當你遇上一個可以交心的人

&nbsp;

這是一個值得慶幸的事情

&nbsp;

做朋友就要做一生一世的朋友

&nbsp;

既然能走到一起既是冥冥之中的一份緣

&nbsp;

更是濃濃的一份情

&nbsp;

要用一輩子的時間來呵護這份來之不易的情感

&nbsp;

不要像曹孟德那樣

&nbsp;

寧可我『負天下人，天下人決不能負我』的千古罪人


&nbsp;
