在一場國立大學EMBA、高階企業經理人的演講中，我提到簡單的數字遊戲：1x1x1x1，1乘1，乘以十次，答案會變多少呢？答案很簡單，當然是「1」啦。

&nbsp;

&nbsp;可是，若1.1x1.1x1.1x1.1，也就是1.1乘1.1，乘以十次之後，答案會變多少呢？我想，答案就不容易算了！ 

&nbsp;我問學員，有人猜十，有人猜八……，正確答案多少呢？

&nbsp;你要不要用計算機算一下？答案是「2.85…」。

&nbsp;假如每天進步一點點，日積月累，積極、不斷地進步、再進步，那麼「乘以10次」之後，答案就變「2.85…」

&nbsp;可是，如果每天懶散一點、懈怠一點、沒有目標、無所事事……0.9x0.9x0.9x0.9

&nbsp;亦即，「0.9」乘以十次以後，答案會變多少呢？

&nbsp;我問學員，有人答：「0.8」，有人答「0.7」……

&nbsp;正確答案是多少呢？

&nbsp;請你親自用計算機算一下好嗎？

&nbsp;相信你的印象會更深刻！

&nbsp;答案是「0.31」

&nbsp;

&nbsp;啊？「0.9」自乘十次以後，會變「0.31」而已呀？

&nbsp;這，就是「積極」與「懈怠」 截然不同的命運！

&nbsp;

&nbsp;有人在自我生命中，加入了「正向」、 「積極」、「堅持」、「永不放棄」的因數，每天努力朝向自己的目標前進，那麼，他們的目標就愈來愈近了！

&nbsp;

&nbsp;可是，有些人偷懶、萎靡、沒有目標、不願積極行動，那麼他們的命運，可能就是極普通，甚至是「倒退嚕」的景象。

&nbsp;

&nbsp;「不跪地，怎能聞花香？」

&nbsp;&nbsp; 一名攝影師說：「要拍出花的氣味，就要蹲下、跪下，以謙卑的態度貼近花 朵！」

&nbsp;

&nbsp;人，也是一樣，想要有精彩的人生，就必須以實際行動，積極的用生命來交換！

&nbsp;所以，「少年時要狂，目標遠大、胸懷天下；青年時要闖，要勇於行動、創新， 成為生命的勇敢戰士！」

&nbsp;因為，「上半輩子不猶豫， 下半輩子才能不後悔！」

&nbsp;真的是一題蠻有趣的數學題！

「 1 x 1 x 1」意指，每天一成不變，最終的結果還是1。 

「 1.1 x 1.1x 1.1」意指，每天改變或學習一點點，最後也將聚少成多聚沙成塔。

「 0.9 x 0.9 x 0.9」意指，每天偷懶一點，損失在不知不覺中變大，競爭力也在不知不覺中消失。
