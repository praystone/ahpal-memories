&nbsp;  
淺說隨緣 



&nbsp;

&nbsp;


曾經看到過這樣一則佛經故事 

&nbsp;

從前有個書生，和未婚妻約好在某年某月某日成親

&nbsp;

到了那一天，未婚妻卻嫁給了別人

&nbsp;

書生受此打擊，一病不起

&nbsp;

這時路過一遊僧，從懷裡掏出一面鏡子叫那書生看

&nbsp;

書生看到茫茫大海，一名女子一絲不掛的躺在海灘上

&nbsp;

路過一人，看一眼，搖搖頭，走了

&nbsp;

又路過一人，將衣服脫下，給女屍蓋上，走了

&nbsp;

再路過一人，過去，挖個坑，小心翼翼的把屍體掩埋了

&nbsp;

&nbsp;

僧人解釋道，那具女屍，就是你未婚妻的前生

&nbsp;

你就是那第二個路過的人，給過她一件衣服

&nbsp;

她今生和你相戀，只是為還你一個情

&nbsp;

她最終要報答一生一世的

&nbsp;

是那個把她掩埋的人，那個人就是她現在的丈夫

&nbsp;

書生聽完，恍然大悟

&nbsp;

&nbsp;

我們有時往往會遇到這樣的情形

&nbsp;

某一天，在人群中遇見一個人

&nbsp;

明明是素未謀面，卻覺得似曾相識

&nbsp;

對方的一個眼神，他身上散發的獨特味道，

&nbsp;

明明就像是自己很熟悉的

&nbsp;

突然間就有那種夢裡尋他千百度，驀然回首，

&nbsp;

那人竟在此處的感覺

&nbsp;

而當你最終牽起他的手

&nbsp;

或許，也是有前世殘存的記憶在指引你吧

&nbsp;

&nbsp;

這世間，從不缺乏痴情的人

&nbsp;

看過太多太多的男男女女，

&nbsp;

愛著，愛著，就把它變成了習慣

&nbsp;

變成了自己的致命傷，變成了自己為自己設的牢籠

&nbsp;

一廂情願的，封閉了所有的退路

&nbsp;

得到時歡喜，失去時傷心

&nbsp;

更有甚者，連自己的生命也可以漠視

&nbsp;

這樣的愛，就如同罌粟，

&nbsp;

一沾上，該是讓人怎樣的身心俱疲

&nbsp;

愛，應當是輕鬆的，美好的

&nbsp;

如果當一份感情沉重到讓對方疲憊或是永遠無法解脫的時候

&nbsp;

應該講，你更多的只是在對自己痴迷罷了

&nbsp;

原本你是因為愛，而最終，你卻似乎是最無情的人

&nbsp;

&nbsp;

人與人之間，都存在著一種緣分，或深，或淺

&nbsp;

佛經有雲︰前世因，今生果，今生因，來世果

&nbsp;

一切的一切，冥冥中都早已注定

&nbsp;

&nbsp;

張愛玲有那麼經典的一段話

&nbsp;

於千萬人之中遇見你所遇見的人

&nbsp;

於千萬年之中，時間的無崖的荒野裡

&nbsp;

沒有早一步，也沒有晚一步，剛巧趕上了

&nbsp;

沒有別的話可說，唯有輕輕的問一聲

&nbsp;

哦，你也在這裡

&nbsp;

一句簡簡單單的話

&nbsp;

其實早已注定了所有的開始和結局

&nbsp;

&nbsp;

有時仔細想想，漫漫人生路

&nbsp;

已經有那麼多不可預知的狀況隨時會發生

&nbsp;

又何必讓自己背負了太重的包袱行走

&nbsp;

緣分來時，誰都無法阻擋

&nbsp;

這時的你就應當好好珍惜，盡情享受

&nbsp;

而當兩人之間的感情走到盡頭時

&nbsp;

既然留不住，就該瀟瀟灑灑的轉身

&nbsp;

當是還彼此一個自由，無須怨恨

&nbsp;

你曾經付出了，但同樣你也曾經擁有過

&nbsp;

&nbsp;

有些事物，有些人，如果我們不能再去擁有

&nbsp;

那麼，我們唯一能做的，

&nbsp;

就是把它好好的保存在記憶裡吧


&nbsp;


&nbsp;
