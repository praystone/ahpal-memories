&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;二、你會為什原因而撒謊？以及你所撒的謊究竟傷人有多深？

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;1、用美妙的歌聲 使人心醉

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;會為了討人喜歡而撒謊，若以日行一善的精神來看，很多事情你應該都會給予添油加醋，當然這並不算什惡意的謊言，但如果 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;謊言逐漸擴大的話，就容易在眾人面前丟臉，即時你有說謊，有很多事情也會因為過份的誇大而讓對方有所誤解，所以，你對於 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;任何事情都要謹言慎行。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;2、模仿 對方戀人的聲音

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;會以認真的態度說謊，是個撒謊高手。當然，這謊言不管是善意與否，在還沒被揭穿之前，是很少人會因此而受傷的，之所以如 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;此說，是因為一旦這個謊言被識破時，就會讓人遭受很重的的打擊，而這也是這類撒謊高手的特征，正因為你是這類型的人，所 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;以大家對你的印象會有股深怕被出賣的感覺，而這種感覺會越來越強，所以，為了自己，即時只有千分之一被識破的可能，也絕 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;對不可以撒這個謊。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;3、散發迷人的樹香

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;你不會利用謊言去傷人，可稱得上是誠實的人，開門見山的說，你是個不善於說謊的人，只要你想說謊就會被別人看穿，也因此 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;，你的名譽不會受損，反而會有很多人認為你很這樣很可愛。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;4、利用飛翔在他周圍的小鳥使者

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;有撒謊時喜歡找代罪羔羊的傾向，為了使謊言變得有說明力，你是否常使用“因為某某人說。。。”或是“從某某人那裏聽來的 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;。。。。”等語句呢？如此以來，當謊言被識破時，那個人的信用也跟著完蛋了，所以當你在編造謊言時，這個責任應該由你一 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;個人來承擔，如果把別人也卷入你的謊言中，那就太令人難堪了。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;5、什都不做，只是靜靜等待好奇的人走過來

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;屬於絕不撒謊，忠厚老實的人。最痛恨的就是欺騙別人，也正因如此，即時對方不想聽的事實，你也毫不隱瞞的全盤托出，結果 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;通常是傷人很深，在必要時，你也要機靈的學會撒謊。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;三、測量你的性格

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;1、從左 端開始切，一塊一塊的吃

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;最普遍的情況，這種人非常重視形式，喜歡一般認為合理及正常的事，有一種強加自己的生活方式或思想向別人推銷的傾向。若 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;是覺得自己想的說的正確無誤，就很難再去聽取他人的意見。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;2、從右端開始切，一塊一塊的吃

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;性格比較溫順，也是較易為對方著想的那一類人。一般認為，此類的人較易和他人親近而打成一片，即時心裏有什不愉悅之處 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;，也不會表現於外，通常都能和諧相處。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;3、把全部切成小塊後，再一塊一 塊的吃

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;自己想要的東西無法立刻得手時，就會急躁不安的類型。想要做的事情，不管遭受到多少反對也會一意孤行。另外，這一型人喜 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;歡照顧、安慰別人，當他人有煩惱時不會置之不理，而會伸出援手。對於人的喜惡會明顯的表示出來不加掩飾。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;4、從中央開始切，一塊一塊的吃

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;屬於才幹型的人，常會因考慮其個人本位之種種而較自私自利。若有什想做的事則會毫不猶豫地去做，是座而言不如起而行的 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;那一型人。比較善於社交，廣結人緣。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;5、只切一小塊吃

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;是一個道地的現典主義者。能使生活和自我相互調和，並且有社交性，和誰都可以說上幾句話並應對自如。工作能順利完成，關 

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp;&nbsp;鍵在於能與他人通加合作。

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;6、吃法經常改變

&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;&nbsp; &nbsp;性情易變，所以經常會無法適應人群，在工作或私生活上也是如此，常因無法與他人合得來而造人誤解。
