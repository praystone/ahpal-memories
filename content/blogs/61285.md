有你/妳真好 

&nbsp;



&nbsp;

&nbsp;


有朋友真好

&nbsp;

何必曾相逢，何必怕陌生

&nbsp;

網路初相識，互動結友情

&nbsp;

或許你只想要一縷春風

&nbsp;

而空間的朋友卻給了你整個春天
&nbsp;

&nbsp;

熱情的問候、真誠的關懷

&nbsp;

善解人意的體諒、獨道精闢的觀點

&nbsp;

語重心長的開導，都是欣賞別人真誠付出的一種友情
&nbsp;

&nbsp;

當你遇到挫折而感到抑郁的時候

&nbsp;

向知心朋友的傾訴可以使你得到疏導

&nbsp;

否則這種積郁會使人致病

&nbsp;

沒有任何藥物可以醫治心病

&nbsp;

除非你有一個知心摯友

&nbsp;

因為只有對朋友

&nbsp;

我們才可以盡情傾訴自己的憂愁和歡樂

&nbsp;

那壓在我們心頭的一切沉重

&nbsp;

透過友誼的肩頭而被分擔了
&nbsp;

&nbsp;

一種心思

&nbsp;

一件寶貝受大家喜愛，認同

&nbsp;

這種共享的快樂難以言表

&nbsp;

你我在手指與心靈的凝眸間盈盈淺笑，靈犀剔透
&nbsp;

&nbsp;

那是一種知音的情懷帶來的愉快，讓人難以忘懷

&nbsp;

小小空間就像是一個沒有拘束的世界

&nbsp;

每個人都可以相互傾聽，相互鼓勵，相互安慰

&nbsp;

無處不透露出脈脈溫情
&nbsp;

&nbsp;

朋友是一把傘

&nbsp;

沒有朋友就像雨中無傘獨行

&nbsp;

惟有默默承受雨淋心頭的那份傷痛

&nbsp;

朋友是一種心的交流

&nbsp;

在語言的撞擊中你或許能得到意想不到的快樂

&nbsp;

追思與暢想趕走了孤單

&nbsp;

一腔柔情也有了著落

&nbsp;

心靈的平衡帶來謙讓與寬容

&nbsp;

人性因此而和善，世界也因此而更加美麗
&nbsp;

&nbsp;

本來世界就應該是這樣的

&nbsp;

每當手指輕輕的敲擊著鍵盤

&nbsp;

好像整個人沁浸在香茗的芬，有朋友真好
&nbsp;
朋友是一種相遇知音似的感動，讓人久久難以忘懷
&nbsp;

&nbsp;

網路給了我們空間

&nbsp;

拿起你的筆放開您智慧的大腦

&nbsp;

盡情的塗抹網路中最美麗的情懷

&nbsp;

互出你我的心聲，動出你我的友情

&nbsp;

讓我們永結友誼緣
&nbsp;

我也想對我的朋友說一聲『有你/妳真好』

&nbsp;

謝謝你/妳對我的幫助

&nbsp;

在我最無助的時候你伸出友愛之手

&nbsp;

我今生都不會忘記你/妳
