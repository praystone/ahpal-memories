生活，不需要答案____<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


人最悲哀的，並不是昨天失去得太多，而是沉浸於昨天的悲哀之中。


&nbsp;


人最愚蠢的，並不是沒有發現眼前的陷阱，而是第二次又掉了進去。


&nbsp;


人最寂寞的，並不是想等的人還沒有來，而是這個人已從心裏走了出去。


&nbsp;


人最無聊的，並不是隨便撥通一個電話號碼，而是別人撥錯時，


他還一直地說下去。


&nbsp;


人最卑鄙的，並不是點燃了一根導火線，而是想看到爆炸後的效果。


&nbsp;


人最可恨的，並不是他拔掉了一棵樹，而是沒有埋掉樹下的坑。


&nbsp;


人最可笑的，並不是端起了別人的茶杯，而是把自己的杯子端給別人。


&nbsp;


人最骯髒的，並不是出賣了自己的肉體，而是出賣了自己的靈魂。


&nbsp;


人最痛苦的，並不是沒有得到一個所愛的人，而是所愛的人


一生沒有得到幸福。


&nbsp;


人最幸福的，並不是終於得到了一束花，而是永遠被花包圍著。


&nbsp;


人最快樂的，並不是別人給你帶來了快樂，而是你給別人帶去了快樂。


&nbsp;


人最聰明的，並不是撿起了別人還沒撿到的東西，而是別人撿到了你不想撿的東西。


&nbsp;


人最富有的，並不是擁有一座金山，而是擁有一座金山買不到的東西。


&nbsp;


人最高尚的，並不是別人還記著他的好處，而是自己忘了曾給予別人的好處。


&nbsp;


人最偉大的，並不是創造了這個世界，而是創造了創造這個世界的人。


&nbsp;
