銀行不只是用來存錢的


&nbsp;&nbsp;

&nbsp;


阿明是一位號稱銀行殺手的神偷，

&nbsp;

他偷過上百家銀行而至今尚未被抓到過。

&nbsp;

某一天，阿明在街上閒晃，

&nbsp;

不意發現了一家新的銀行在放鞭炮慶祝開幕。

&nbsp;

當下他就決定今晚要去光顧這家、見識見識 。

&nbsp;



&nbsp;

當夜幕低垂，

&nbsp;

身經百戰的他果然了得，三兩 下子

&nbsp;

就把層層的門鎖弄開、登堂入室，

&nbsp;

快步潛行進入那家銀行的「金」庫 。


&nbsp;

阿明的第一件感受是：唉唷！

&nbsp;

新開張的銀行冷氣果然特別強勁！

&nbsp;

來看看有啥值錢的東西吧！

&nbsp;

&nbsp;

阿明打開第一個保險箱…「X的，是果凍！」

&nbsp;

第二個保險箱…「又是果凍！」

&nbsp;

打開第三個保險箱「挖哩勒，還是果凍阿！」 

&nbsp;

開了所有保險箱後「果凍的逆襲阿… 」

&nbsp;

阿明：X 的，怎麼全都是果凍？

&nbsp;

算了，既然來都來了，絕沒有空手回去的道理。


&nbsp;

阿明就把那些果凍都吃下肚子，

&nbsp;

打了個飽嗝之後從容離開現場... 

&nbsp;

依然是神不知、鬼不覺，阿明覺得百分百、好自豪。


&nbsp;

隔天一大早，阿明特地去買了份報紙，

&nbsp;

想看看是否有昨天銀行的新聞 ，

&nbsp;

結果看到報紙的頭條居然是：




&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

「史無前例，精子銀行被盜！」
