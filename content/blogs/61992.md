&nbsp;

&nbsp;

我一向不喜歡看書時翻到最後一頁睹結局

&nbsp;

那多麼嚴重破壞我閱讀的樂趣

&nbsp;

慶幸自己擁有雙眼能閱讀書籍&nbsp; 那是恩賜

&nbsp;

我一像喜歡青山綠水 不論多少愁都能被吸收

&nbsp;

我始終相信人間有愛

&nbsp;

擁有一顆愛的心&nbsp; 世界會更兼善美好

&nbsp;

長輩都當父母看 好友都當兄妹待&nbsp; 

&nbsp;

對於另一半 都能一輩子只放大美好 縮小缺點

&nbsp;

我想願天下有情人都成眷屬實在是神話...也是鬼話

&nbsp;

但是---一定要好好愛著疼著你深愛的人

&nbsp;

生老病死 緣份深淺 都不是在控制範圍

&nbsp;

前天同事大姊說我的缺點就是把人都當好人

&nbsp;

我想...那是我的優點 我有一顆想要美好的心

&nbsp;

為什麼?因為知道自己不美好 不夠好&nbsp; 所以努力求取美好

&nbsp;

我說阿 當不成林志玲 當個小風鈴也可以

&nbsp;

只要風一吹&nbsp; 我會快樂的搖動歌唱

&nbsp;

或許吧 當我哭泣時 風願意停一停&nbsp;&nbsp; 誰又知道呢

&nbsp;




&nbsp;&nbsp; 深海的長髮那麼開心的遊蕩&nbsp; 或許當時心裡甜蜜吧

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

我喜歡的詩 再次分享&nbsp; 希望好友也喜歡


讓我與你相遇&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;


假如我來世上一遭&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 只為與你相聚一次
只為了億萬年的那一剎那
一剎那裡所有的甜蜜與悲淒
那麼就讓一切該發生的都在瞬間出現
讓我俯首感謝所有星球的相助
讓我與你相遇與你別離
完成了上帝所作的一首詩
然後再緩緩地老去.....
讓我與你相遇與你別離
讓我與你相遇與你別離
