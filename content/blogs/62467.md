&nbsp;

&nbsp;

玩你的人：半夜會找你打電話聊天到很晚。

&nbsp;


愛你的人：會告訴你不要聊那麼晚。

&nbsp;


玩你的人：他會找你出去玩，叫你放棄正事。 

&nbsp;


愛你的人：他會催你好好工作，踏踏實實。 

&nbsp;


玩你的人：在你生病時，會講好話關心你。 

&nbsp;


愛你的人：在你生病時，他會關心到你煩，並強迫你去看醫生。

&nbsp;


玩你的人：他會盡量說好話來討好你，你也會覺得很開心。

&nbsp;


愛你的人：他所說的話，都是關心你的，但是通常像是在命令。

&nbsp;


玩你的人：他什麼事情都會配合你，只要你開心。

&nbsp;


愛你的人：他會幫你辨別是非，但是你會感覺他管的太多。

&nbsp;


玩你的人：他說他要給你最大的快樂。

&nbsp;


愛你的人：他只能給你保證，你跟他在一起，他是最快樂的。

&nbsp;


玩你的人：他在意你的生活細節，即使你做錯了什麼，他也不會指出來。 

&nbsp;


愛你的人：他在意你的一舉一動，告訴你什麼地方錯了，什麼地方該如何做，該如何與別人 交往。 

&nbsp;


玩你的人：他不會在意你去做什麼，與什麼人交往。 


&nbsp;



愛你的人：他很在意你去做什麼，與什麼人交往。他還會告誡你不要與什麼人交往 。 



玩你的人：他只想要現在 。 


&nbsp;



愛你的人：他已經預見未來，該怎麼自我努力，好好給你幸福。


&nbsp;



玩你的人：他會說“我喜歡你！”


&nbsp;



愛你的人：他會說“我愛你。如果，你愛過或者被愛過，那麼，你會感到這些話千真萬確。
