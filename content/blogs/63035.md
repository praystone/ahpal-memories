&nbsp;

&nbsp;

&nbsp;



&nbsp;

&nbsp;

&nbsp;

不是每個擦肩而過的人都會相識

&nbsp;

也不是每個相識的人都會讓人牽掛

&nbsp;

至少我們在今生 在某個地方 在一轉身的時候沒有錯過

&nbsp;

在我們雙眼相望的時候 在眼中找到了愛的緣份

&nbsp;

若大的地球上能和你相遇真的不容易

&nbsp;

感謝上天給了我們這次相識 和相戀的緣份

&nbsp;

&nbsp;

&nbsp;

&nbsp;

曾經你也帶給我快樂 曾經你也帶給我幸福

&nbsp;

曾經我也讓你無奈 曾經你也讓我等待和期盼

&nbsp;

曾經我們也都忘了自己 體會那心跳的感覺和纏綿的愛

&nbsp;

只是有一段感情再也不可能繼續

&nbsp;

有一個人再也不能相依偎

&nbsp;

有一個聲音再也不能經常在耳邊響起

&nbsp;

有一雙手再也握不住那手心的溫度與舒適

&nbsp;

不是每一段愛情都有美麗的回憶

&nbsp;

也不是每段回憶都是那麼的刻骨銘心

&nbsp;

&nbsp;

&nbsp;

&nbsp;

我們既然不能相伴到老

&nbsp;

就讓我在這裡為你祝福

&nbsp;

因為你已是我今生永遠無法割捨的牽掛

&nbsp;

只是再多的思念和牽掛也換不回擁有你的日子

&nbsp;

喜歡人是這種感覺 原來愛你一樣的不容易

&nbsp;

也許你的那句「我喜歡你」曾經是個玩笑

&nbsp;

但我付出的依然是最真心

&nbsp;

如果你真的喜歡過我 那我是幸福的

&nbsp;

就算和你走不到天涯 我的心依然為你牽掛

&nbsp;

我會為你永遠的祈禱和祝福 願你永遠的幸福 平安… 

&nbsp;
