阿彌陀佛，諸惡莫作、眾善奉行，持之以恆，有求必應。


&nbsp;


----- 諸葛長青


&nbsp;


&nbsp;


&nbsp;


&nbsp;&nbsp;&nbsp; 阿彌陀佛，諸惡莫作、眾善奉行，持之以恆必有福報。


&nbsp;


&nbsp;&nbsp;&nbsp; 說道行善，有很多學佛的有緣者提出疑問：路邊乞丐該不該救助？


&nbsp;


&nbsp;&nbsp;&nbsp; 有人說，乞丐都是騙人的，騙了錢回家蓋高樓！


&nbsp;


&nbsp;&nbsp;&nbsp; 有人說，乞丐都是騙人的，騙了錢到星級酒店揮霍！


&nbsp;


&nbsp;&nbsp;&nbsp; 伴隨著一些電視劇對“丐幫”的描述，伴隨著媒體對騙子乞丐的曝光，該不該救助乞丐成了很多學佛有緣者遇到的一個現實問題。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 正如有緣者“感恩的心”對諸葛長青老師說。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 諸葛長青老師您好：


&nbsp;&nbsp;&nbsp;&nbsp; 最近經常和同事們討論一個問題：到底該不該給乞丐錢？


&nbsp;&nbsp;&nbsp;&nbsp; 他們說現在乞丐都是假的，給他們錢是“助紂為虐”，無形中成就了他們的不勞而獲！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 我不能改變他們的看法，甚至搞的空氣有些緊張。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 能有什麼方法能說服他們呢 ?


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 阿彌陀佛，這樣的問題的確在我們周圍放生，很多人對乞丐表現出了憤憤不平。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 阿彌陀佛，諸葛長青今天單獨為有緣者講講這件事。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 一、遇到乞丐該不該救助？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 諸葛長青認為，遇到乞丐要大發慈悲、立刻行動、絕不拖延！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 為什麼這樣呢？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 諸葛長青為大家分析八條理由，也作為對“感恩的心”等有緣者的解答。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 1、乞丐，本身是可憐的，即使是騙子，也是被迫的，你想，誰願意裝作乞丐？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 2、不論乞丐是真是假，你給他饅頭、金錢都是有大福報的。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 3、你給了乞丐錢，乞丐是否騙人是乞丐的事，與你無關。他騙人是他的罪業！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 4、你給了乞丐錢，你的功德就會是你自己的，有巨大陰德福報。你救助是你的福報！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 5、你遇到乞丐，就是磨練你慈悲心的大好機緣，很多乞丐就是佛菩薩派來的，他們派來磨練你的慈悲心、看你是否行善？再說，你如何知道他是否騙人？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 6、趙匡胤、毛澤東、朱元璋、毛岸英都做過乞丐，你說都是騙人的嗎？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 7、觀音菩薩、地藏王菩薩、釋迦牟尼佛、玉皇大帝、鐵拐李等都扮演過乞丐，你說他們是騙人的嗎？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 8、諸葛長青主張：見了乞丐，一是給他一點錢，二是有時間則給他買點食物買瓶礦泉水，三是可以同時教給他佛法。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 所以，遇到乞丐，都要立刻行動，立刻救助！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 你做到這些就可以了，不要管乞丐是否騙人。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 如果你反復思考這個乞丐是否騙子，你就有分別心，就會喪失慈悲心。&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;


&nbsp;&nbsp;&nbsp; 二、如何對乞丐弘揚佛法？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 很多有緣者可能說：諸葛長青老師，我們給乞丐錢、給乞丐饅頭礦泉水好辦，可是如何對乞丐弘揚佛法？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 說來，還要感謝一位叫“陽光”的慈悲心有緣者。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 她很有慈悲心，每次見到乞丐都真心救助，而且創造了“對乞丐弘揚佛法”的先河！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 我們讚歎“陽光”的慈悲創舉。


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 對乞丐弘揚佛法！為乞丐種下成佛的種子，功德無量！


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; 她向諸葛長青老師彙報了他救助乞丐的做法。她還寫了一篇《對乞丐弘揚佛法感想》文章，非常好。


&nbsp;


&nbsp;&nbsp;&nbsp; 如何對乞丐弘揚佛法，諸葛長青建議如下：


&nbsp;


&nbsp;&nbsp;&nbsp; 一是確定是否有時間。


&nbsp;


&nbsp;&nbsp;&nbsp; 看自己是否有時間，如有時間，則可以蹲下身子，慢慢和乞丐說說話。


&nbsp;


&nbsp;&nbsp;&nbsp; 二是贈送食品金錢。


&nbsp;


&nbsp;&nbsp;&nbsp; 把買好的食物、水以及錢送給乞丐，說，你好，這是給您的。


&nbsp;


&nbsp;&nbsp;&nbsp; 三是微笑尊重。


&nbsp;


&nbsp;&nbsp;&nbsp; 乞丐也是我們的親人啊。要微笑者、尊重者對乞丐說，根據年齡可以分別稱為大爺、大娘；老爺爺、老奶奶；大哥、大姐；小弟、小妹、小朋友等。


&nbsp;


&nbsp;&nbsp;&nbsp; 四是靈巧弘揚佛法。


&nbsp;


&nbsp;&nbsp; ( 以下是諸葛長青老師為有緣者考慮的簡單模式，具體大家要隨機應變)


&nbsp;


&nbsp;&nbsp;&nbsp; 1、你可以說:老爺爺您好，這是給您的饅頭、礦泉水、幾十元錢，您拿著。


&nbsp;


&nbsp;&nbsp;&nbsp; 2、老爺爺，我告訴您一個改變命運、不生病的好方法，就是多念觀世音菩薩、阿彌陀佛，你只要持續念，就會有好福報的。念完了，你可以說希望自己的冤親債主越來越好，希望自己越來越好。


&nbsp;


&nbsp;&nbsp;&nbsp; 3、如果此人同意，你可以說：老爺爺，一個觀世音菩薩、一個阿彌陀佛，你喜歡念哪個？


&nbsp;


&nbsp;&nbsp;&nbsp; 4、根據老人喜歡一個，還是都喜歡，你可以教他念：觀世音菩薩、觀世音菩薩、觀世音菩薩，希望我的累世冤親債主悅來越好、希望自己越來越好。


&nbsp;


&nbsp;&nbsp; 5、如果對方不喜歡，就是無緣。佛法廣大，難度無緣之人，無需強求。放下物品離去即可。


&nbsp;


&nbsp;&nbsp; 三、有緣者“陽光”對乞丐弘揚佛法的感悟


&nbsp;


&nbsp;&nbsp; 諸葛長青希望有緣者多看看這篇文章，提醒自己多做善事。


&nbsp;


&nbsp;&nbsp; 阿彌陀佛，我們感謝“陽光”的慈悲心，現身說法，即是行菩薩道。


&nbsp;


&nbsp; &nbsp;有緣者“陽光”對乞丐弘揚佛法感悟：


&nbsp;


&nbsp;&nbsp; 一天晚上開完家長會在回家的路上，遇到一個中年男子過來向我乞討，我每次看見在乞討的人我都會同情他們，都會給他們錢，有時候也會心裏還有一點的難受吧。


&nbsp;


那天那個男子到我的面前向我要錢，我愣了一下，這麼晚怎麼還有乞丐啊，而且他看上去好像身體也沒有殘疾挺健康的。


&nbsp;


可能遇到困難真的生活艱難吧，不管他是真的還是假的，都說學佛的人要心存善良，對任何人都要向對自己的父母一樣，何況拿一點錢出來也不會對我的生活造成任何影響啊。


&nbsp;


我趕緊拿了點錢給他，正好我也沒有吃飯剛買了點點心，遇見是緣就一人一半吧。他很感動的說了很多感謝話，也許遇到太多的不信任，以致他很失望吧，現在他那種出自肺腑的感恩之情，是無法言喻的。


&nbsp;


我想，既然緣分相遇，我何不教給他佛法？


&nbsp;


於是，我告訴他要念阿彌陀佛，念阿彌陀佛會改變命運的，呵呵。


&nbsp;


他還很聽話，很激動的念了很多遍。


&nbsp;


很遺憾由於我急著回家，沒有跟他多說幾句。


&nbsp;


我遇到佛法後才明白，實際上最應該表示感謝的是我呀，我要感謝他給了我一個種福田的機會。


&nbsp;


我們有福報獲得圓滿人身，多麼難得啊！


&nbsp;


仔細想想，有能力的人，誰會放棄尊嚴去乞討？


&nbsp;


當然，有的乞討者本就是菩薩的化現，為的是讓眾生種下佈施的種子。


&nbsp;


因為佈施的物件是菩薩，我們佈施一毛錢甚至一分錢，可能就意味著積累了無量的資糧啊！


&nbsp;


遇到這樣的乞丐菩薩，我們難道不應該十二萬分感謝嗎？


&nbsp;


而如果對方是普通的乞討者，他以未來世受窮的果報代價，成就了我佈施的因緣，換來佈施的功德，我怎麼能不感謝人家啊！


&nbsp;


就我個人而言，平時出行開車比較多，但開車也經常遇到乞討的，就是等紅綠燈的時候，常有乞討者穿梭其間向駕駛員乞討。


&nbsp;


只要到了我車前，我基本上都會給一點，車上備有零錢的。


&nbsp;


有時，我看到乞討者在前面的車旁點頭哈腰鞠躬作揖好久對方也不給，我很著急，我就希望他快點到我這裏來，我來給他點吧，如果綠燈亮了前面的車一走我就沒有機會給他了（好幾次就是這樣）。 


&nbsp;


其實，經常佈施，經常想著他人想著眾生，他的心胸會越來越寬廣，人生會過得非常快樂哦。


&nbsp;


&nbsp;&nbsp;&nbsp; 阿彌陀佛，我們感謝有緣者“陽光”，祝福她闔家幸福、吉祥如意、富貴吉祥！


&nbsp;


&nbsp;&nbsp;&nbsp; 諸葛長青：阿彌陀佛，諸惡莫作、眾善奉行，持之以恆、有求必應！


&nbsp;


&nbsp;&nbsp;&nbsp; 祝福天下有緣者富貴吉祥、天官賜福、事業騰飛、財源廣進！
