&nbsp; 


&nbsp;

愛情是一種付出 

&nbsp;



&nbsp;

&nbsp;


愛情的可貴是付出


&nbsp;

漫漫人生路上人海茫茫

&nbsp;

相愛的人能走到一起，那是緣分


&nbsp;

人世漫漫，能白頭偕老，那是真情


&nbsp;

生命中有太多遺憾，歲月裡有太多傷感


&nbsp;

在我們的有生之年應好好地把握自己的愛


&nbsp;

去付出真心好好地愛一個人，只有這樣，當生命終結的時候


&nbsp;

才不會讓愛人帶走遺憾


&nbsp;

才不會給自己留下傷感


&nbsp;

才可以為人生畫一個美麗的圓

&nbsp;

&nbsp;

當你經歷了愛與被愛，學會了怎樣去愛


&nbsp;

才知道什麼是你最終想要的


&nbsp;

請不要在戀愛中放著一把天平秤


&nbsp;

愛的本身就是無法稱量

&nbsp;

有的付出多，有的付出少


&nbsp;

無論怎樣去要求加量，始終是無法同等的

&nbsp;

&nbsp;

愛一個人就要付出你的全部真心和愛戀


&nbsp;

愛一個人就要給他（她）溫柔的依靠


&nbsp;

愛一個人就要讓他（她）因為有你而快樂


&nbsp;

當你的愛給愛人帶來煩惱


&nbsp;

當愛人對你的愛使你壓抑，當愛情變成雙方交換的籌碼


&nbsp;

當愛情自私到只剩下索取


&nbsp;

當愛情成為兩個人刻意追求的完美


&nbsp;

愛情也就不再是一種美好


&nbsp;

而是變成了一種讓人痛苦的負擔


&nbsp;

一種讓人煩惱的累贅

&nbsp;

&nbsp;

例如我們期待自己的愛人永遠那樣愛著自己


&nbsp;

我們就應該努力的提升自己，努力的愛著對方


&nbsp;

人常說女人是水做的、細膩如斯


&nbsp;

女人也是最容易感動的動物，柔軟如斯


&nbsp;

女人又是最敏感的動物，甚至尖刻如斯


&nbsp;

愛情是公平的，你付出多少，就會得到多少


&nbsp;

你收回去多少，便會失去多少


&nbsp;

做到「一直和永遠」不容易


&nbsp;

誰也不會輕易的擔著這無限時光的責任


&nbsp;

但想獲得「永遠」，就先付出「永遠」

&nbsp;

&nbsp;

愛情


&nbsp;

應該是無怨無悔、不求回報的付出


&nbsp;

也許你付出得越多，失去的也越多


&nbsp;

但請不要後悔


&nbsp;

因為你曾經為愛情付出過，因為愛情，是最難得的緣分


&nbsp;

付出，真的不需要理由

&nbsp;

加油囉！在此祝福家園所有朋友們！有情人終成眷屬！ 
情人節快樂！！
