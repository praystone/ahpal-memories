前2天有事外出辦事..
&nbsp;
就在停紅綠燈時..
&nbsp;
看見有人再發傳單..
&nbsp;
一般(包掛我在內)
都不想收..
&nbsp;
會門窗緊閉..
&nbsp;
但是痞忽然有一個想法..
&nbsp;
天阿..這種天氣那麼的熱..
&nbsp;
他要發的什麼時候...
&nbsp;
而且..我看大家都不收.
&nbsp;
他一輛輛車子面前點頭
&nbsp;
好像好失望..
&nbsp;
當下痞就把車窗搖下..
他就好像很高興.
趕緊把傳單給我..
我也收下.
&nbsp;
正準備搖起車窗時..
&nbsp;
一陣天音發出..........(好大聲)說了謝謝..
&nbsp;
我嚇了一跳...
&nbsp;
然後綠燈亮起..
我就跟著車陣離企...
&nbsp;
&nbsp;
*************************************
&nbsp;
&nbsp;
不知道我說什麼嗎..
&nbsp;
就是..
&nbsp;
隨時隨地都可以幫助人..
連收一個傳單也可以幫到人.
&nbsp;
天氣那麼的熱.
大家都不收
他要發到什麼時候..
那點錢.他要賺到什麼時候..
你拿它一張小小的傳單..
就可以幫他多賺一點錢.
就可以幫他早一點下班..
*********************************
&nbsp;
常聽人說..
等............................(等個屁阿)..
等將來他有能力..
等他有錢
等它有時間
等他退休..
&nbsp;
等..................................
&nbsp;
她會好好幫助別人..
但是現在不是時候...(因此就不幫了)
***************************************
&nbsp;
此篇只是小小感想..
讓大家知道.
隨時隨地
都可以幫到人...
坐而言.不如起而行..
&nbsp;
凡是....有心...
