遇上正妹就腦殘的星座男

&nbsp;



&nbsp;

&nbsp;


正妹在這個世界上是很珍貴的，對於很多男人來說，

&nbsp;

看到長得很漂亮的女生、身材很豐滿的女生，心情就會大好，

&nbsp;

但有些男人不只是會心情大好而已，

&nbsp;

還會好到連自己的爹娘姓什麼都可能會忘記，

&nbsp;

只要正妹叫他們往東、他們就不會想要往西，

&nbsp;

失魂落魄到讓其他的女人覺得很生氣，

&nbsp;

哪些男人看到正妹就會被迷得神魂顛倒

&nbsp;

又容易因此癡癡傻傻有如腦殘呢？


&nbsp;

第一名：獅子男～★

&nbsp;

看到正妹的獅子男就是獅子見到了獵物一樣，

&nbsp;

獅子座本身就是個跟戀愛、玩樂很有關係的一個星座，

&nbsp;

見到正妹更是會沒有辦法管住自己心中的那份激動，

&nbsp;

特別是身材很好、臉蛋又很可愛的正妹，

&nbsp;

更是會讓獅子男看得直流口水。


&nbsp;

&nbsp;有好兄弟、有酒壯膽的場合上頭，

&nbsp;

獅子男更是會整個人就陶醉在正妹的微笑裡頭，

&nbsp;

如果這個正妹的態度是很會撒嬌的，

&nbsp;

那麼獅子男大概一聽到這個女生的聲音

&nbsp;

就整個人茫茫然不知身在何處，

&nbsp;

眼裡頭、心裡頭大概也只看得到這個女生而已。


&nbsp;

第二名：金牛男～★

&nbsp;

金牛男本身是一個非常單純

&nbsp;

或該說是一種很癡情的生物，基本上如果看到自己喜歡的正妹，

&nbsp;

整個人大概就會完全忘記其他的事情，

&nbsp;

越是身材好、若隱若現的正妹

&nbsp;

最容易讓金牛男整個人變得失魂落魄，口水整個吞不完。


&nbsp;

&nbsp;由於天生的專一性、加上隱藏在靈魂裡頭的好色，

&nbsp;

加上思考往往不算是太快太靈敏，

&nbsp;

很容易就會掉進正妹的笑容當中，

&nbsp;

遇上了特別有心機的正妹，

&nbsp;

金牛男大概就很容易變成供養很多錢的火山孝子，

&nbsp;

而且旁人根本就沒辦法拉得住金牛男、勸也勸不聽呢！


&nbsp;

第三名：雙魚男～★

&nbsp;

幻想是美麗的、

&nbsp;

陶醉在幻想裡的男人都會變得傻傻的，

&nbsp;

雙魚男就是看到正妹後就會「腦內補完」很多的幻想、

&nbsp;

很多的美夢，跟正妹講上幾句話，

&nbsp;

就會很自然的陶醉在自己編織的夢想未來裡頭，

&nbsp;

當然，雙魚男講出來的話跟做出來的事

&nbsp;

大概就像自己在演偶像劇一樣。


&nbsp;

&nbsp;要說雙魚男很腦殘，

&nbsp;

倒不如說他們是過度浪漫的類型，

&nbsp;

會想很多很傻氣又很浪漫的手法，想要感動這個正妹，

&nbsp;

只要這個正妹不要給雙魚男釘子吃，那麼雙魚男大概就會

&nbsp;

陶醉到忘記今天是幾年幾月幾日，

&nbsp;

每天都魂牽夢縈在這個正妹身上。


&nbsp;

第四名：牡羊男～★

&nbsp;

在男人裡面，這個星座也算是還滿單純的星座男，

&nbsp;

特別是看到自己喜歡的女人時，

&nbsp;

是屬於會全心全意放在這個女人身上的男人，

&nbsp;

某個程度上的牡羊男可說是「使命必達」的類型，

&nbsp;

通常只要喜歡的女生說一句話，他們就會盡全力辦到。


&nbsp;

&nbsp;有時候就像是著了魔一樣的瘋狂的愛上某個女生，

&nbsp;

加上很多牡羊男都是以第一眼的感覺為準，

&nbsp;

往往也都還滿外貌協會，加上個性很主動，

&nbsp;

只要對方有所回應，牡羊男就會加碼向前，

&nbsp;

好像耳朵裡頭只聽得見這個女生的話一樣，

&nbsp;

讓身邊的人覺得牡羊男還真是看到美女就失心瘋。


&nbsp;

第五名：巨蟹男～★

&nbsp;

純情派路線的巨蟹男其實對於女性的

&nbsp;

上圍有著還滿深的執著，

&nbsp;

對於身材好的正妹有著很強烈的喜好感，加上感情態度

&nbsp;

比起其他星座的男人來得單純許多，

&nbsp;

外表看起來是害羞沒說太多話，

&nbsp;

但是內心早就已經是驚濤駭浪不可自制。


&nbsp;

&nbsp;如果正妹多送點秋波，多裝點可憐，很多巨蟹男

&nbsp;

大概就成了火山孝子，照顧東照顧西、每天噓寒問暖、

&nbsp;

掏心掏肺，是典型很容易被哄的星座男，

&nbsp;

但前題還是得要正妹主動一點過來撫慰巨蟹男的心靈，

&nbsp;

否則巨蟹男比較容易停留在心情激動但羞於向前的狀態。


&nbsp;

第六名：射手男～★

&nbsp;

該說射手男是屬於「看場合腦殘」的類型，

&nbsp;

如果是在娛樂場所裡頭、有酒、有音樂的話，

&nbsp;

射手男當然就不管那麼多，先玩得開心再說，

&nbsp;

看到美女當然也是怦然心動，否則射手男怎麼會排名在

&nbsp;

「下半身思考排行榜」的前三名呢？


&nbsp;

&nbsp;但是，如果不是在玩樂的場合，

&nbsp;

射手男大概就不會那麼容易掉進正妹的笑容裡頭，

&nbsp;

他們雖然還是會凡事以正妹為優先，

&nbsp;

但是腦袋還是很清楚的，

&nbsp;

除非這個正妹讓射手男的色欲過份旺盛，

&nbsp;

否則在一般場合裡的射手男可是很難被正妹牽著鼻子走的。
