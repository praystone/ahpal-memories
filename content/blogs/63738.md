【材　 料】
冬瓜糖磚 &nbsp; &nbsp; &nbsp; &nbsp; 300公克
水 &nbsp; &nbsp; &nbsp; &nbsp; 1500㏄
珍珠 &nbsp; &nbsp; &nbsp; &nbsp; 適量
檸檬汁 &nbsp; &nbsp; &nbsp; &nbsp; 1大匙
檸檬片 &nbsp; &nbsp; &nbsp; &nbsp; 適量
冰塊 &nbsp; &nbsp; &nbsp; &nbsp; 適量

【做　 法】
1.取一鍋加入水煮開，放入冬瓜糖磚煮約5分鐘至冬瓜糖磚溶勻，熄火待涼。
2.將珍珠放入杯中，加入檸檬汁、檸檬片，倒入作法1冬瓜茶，再加入少許冰塊即可。
