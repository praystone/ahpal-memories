1.這世上蠢人多而聰明人少，多數表決其實是讓多數蠢輩，決定蠢事。(一 : 三角會議最終場)

2.有權力的人，只要輕聲細語，每一個人也能聽得詳細；沒權力的人，就算聲嘶力竭，也沒人聽聞。(一 : 三角會議，凱旋落幕)

3.所謂的會議，不過是一群彼此不能被說服的人，在努力呻吟而已。妳們可以繼續呻吟，吾喜歡看，看一群人為了自己的利益，努力保持風度的醜態。(二 : 梟皇論戰)

4.明明是眾人想除之而後快的對象，卻又想留下敵人的敵人，為了更大的慾望，所以掩蓋現在的慾望，這場梟皇論戰並無新意。離開吧，替西瓜化妝都比參加這場會議來得有意義(劍子先跡：太傳神了！)。(二 : 梟皇論戰)

5.禮儀，是上者逼使下者更加屈服的心理枷鎖，因為違背禮儀將招致禍害，所以讓下者對上者，更加敬畏。(二 : 魔王戢武雙雄會)

6.信用，是將自己利益無條件交給他人掌控，弱者遵守信用，因為他們必須依靠一套名叫道德的規則存活，敢背信的人，是擁有對方不敢報復的自信。(二 : 魔王戢武雙雄會)

7.(魔王子：我想小妹，把小妹還我，不然我會哭。戢武王：你的樣子跟語氣不像....) 吾只是陳述情感，言語能夠表達的，不需要語氣與肢體的輔助，反正也是騙人的。(二 : 魔王戢武雙雄會)

8.多少仇恨，才能培育出一顆背叛的種子，又是多少憤怒，多少委屈的澆灌，讓他出賣故鄉，出賣族人。(二 : 句芒大殿)

9.真正的忠心是喪失理智的服從，莫非你的忠心不過爾爾？世上沒真正的忠心，忠‧是一個詐欺的遊戲，盡忠者得到了尊嚴、虛名與讚嘆，被盡忠的人得到了統御與利益，如此而已(三 : 霓羽滅)

10.你們有捨已為人的情操，吾有捨人為己的胸懷，捨你們為吾，你們壯烈犧牲，吾為父報仇，彼此成全，這不是兩全其美嗎？(三 : 霓羽滅)

11.(迦陵：為啥不回句芒?‧魔王子：太舊我叫明玉燒了...‧迦陵：為何，那可是火宅佛獄百年王城) 當維持比重建更費心力時，就有人用歷史與傳統當作阻擋進步的藉口，如果百年是歷史，那九十九年就不是了?認清吧，不過就是拆掉的危樓而已(三 : 墮落天堂。)

12.(魔王子：你想念王嗎?迦陵：王的精神不滅) 他活在心中，吾活在世界，千年之後，當他連名字都被遺忘時，精神永存就成了最巨大的謊言(五 : 墮落天堂)

13.善良是一種美德，因為懦弱的不敢傷害別人，自卑的恐懼被人傷害，所以將施捨稱為同情將暴露弱點叫作信任(五 : 王樹殿。)

14.(寒煙翠：你難道不曾為父王悲傷?魔王子：當然有!赤睛：一秒鐘...。魔王子：差不多。) 嫌短嗎?要多久才能表達哀傷?三個月?三年?三十年?每一個人每天都在懷念死去的先人，道路上就會充斥著滿滿的哭聲，太吵了~，所以我們需要的是誠心的哀悼，只要誠心，一秒鐘足夠了(六 : 墮落天堂)。

15.人總是喜歡謊言，吾只是配合謊言演出，為父報仇，多高貴的情操，包裝的完美，連妳也會動搖接受，但吾非常誠懇，誠懇的只想以真面目示人。父王死了，死就死了，人‧總是會死(六 : 墮落天堂)。

16.愛情，能使人癡迷，兩個字，就包括了生物的求偶本能，占有慾望與自毀傾向(七 : 火宅草屋)

17.畫了一條線，再限制自己不可跨過這條線，這世上，還有比道德更愚蠢的事情嗎?(八 : 火宅草屋)。

18.為什麼要問理由?真正每一件事情都有理由嗎?你愛問理由，吾給你一個理由，你又不相信吾的理由。沒理由，真正沒任何理由，要說理由，吾想做，就是一個念頭，想做、去做，這就是理由(九 : 碎雲天河)。

19.爭贏了又如何，結果仍是自以為是(九 : 碎雲天河)。

20.那種約定未來的事情，實在無法讓人認真，畢竟未來太遙遠，而我們只能把握當下(九 : 墮落天堂)。

21.當你報不了仇的時候，你只能選擇原諒(十 : 墮落天堂情之墮落)。

22.難道寬恕不是美德，只是故做大方，只是妄想用得到的補償代替傷害(十 : 墮落天堂情之墮落)。

23.每一個祈求原諒的人都與吾一般，不同的是他們凌虐的是對方的心靈，吾凌虐的是肉體，相較之下吾更善良(十 : 墮落天堂情之墮落)。

24.(魔王子：用愛包容苦境人民，如果苦境人民傷害佛獄子民就跟我滅了霓羽族一樣道歉就好了) 荒謬嗎?無數的荒謬正在這世間運行，但是你察覺到了嗎?或者愚蠢的視而不見(十一 : 墮落天堂)。

25.愛是什麼?明明是需求與依賴，卻被包裝成純粹無理由的偉大情操。吾配合這世間的荒謬，做出最忠誠的表現(十一 : 佛獄草屋)。
