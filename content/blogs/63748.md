夢境很妙 那些不再可能的事情&nbsp; 居然從夢中提醒

&nbsp;

一年了 我離開也快一年 不知道您是否安好

&nbsp;

痛風還會不會干擾您的行動 你的血糖有否好好控制

&nbsp;

說是會想念我 直到今天&nbsp; 還未曾接獲您的電話

&nbsp;

或許您也在等我的問候 按常理我當請安的

&nbsp;

只是 那些歲月帶給我的除了學習就剩下折磨

&nbsp;

能不去碰我就不去碰 都過去了 不是嗎

&nbsp;

是無情也罷 是無心也好 我努力遺忘到是真的

&nbsp;

忘年之交是這樣吧 謝謝你對我疼愛有加

&nbsp;

十年光陰 走來不是夢一場 好的都放在我心裡

&nbsp;

後期公司的瑣碎讓您身體更吃力 

&nbsp;

希望歸家安養的時間 您的健康已慢慢控制

&nbsp;

我很好 臉上學會掛著微笑 絕不再是您熟悉的冷漠臉

&nbsp;

滾在紅塵中&nbsp; 某些態度真的要符合普羅大眾 

&nbsp;

做自己沒什麼不好 只是做自己可以快樂一點

&nbsp;

過去十年我錯了 謝謝你那麼寵我 

&nbsp;

現在開始的省悟 也不算太晚

&nbsp;
