&nbsp;

曾經站在愛情的另一岸邊

&nbsp;

是誰在等待著誰

&nbsp;

&nbsp;

&nbsp;

一直知道 愛從來不是容易的東西

&nbsp;

誰會平白無故的愛上誰

&nbsp;

誰會沒有理由的和誰生活在一起

&nbsp;

誰會沒有情由地感受到愛情的召喚 聆聽著幸福的聲音

&nbsp;

&nbsp;

&nbsp;

愛情 不是願意付出就會予以回應的

&nbsp;

幸福 也不是只是付出就可以有回報的

&nbsp;

我愛你 三個字要入退場的門很容易

&nbsp;

真的愛 到底卻是那麼那麼的難

&nbsp;

&nbsp;

&nbsp;

有時候覺得

&nbsp;

愛情是迷茫的開始 自由的結束

&nbsp;

風花雪月 只不過是一種真實的錯覺

&nbsp;

相信真愛 只不過是一場心甘情願的迷茫
