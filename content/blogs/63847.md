&nbsp;

悠悠的思念，淡淡的幸福 

&nbsp;



&nbsp;

&nbsp;


花落無痕，過去的事，我們不能改變

&nbsp;

或好，或壞，它只能是一段回憶

&nbsp;

一段思念的往事，擦不掉，抹不去
&nbsp;

思念就像一根永無止境的線

&nbsp;

牽掛著我們的心，不經意地還有些揪心的痛

&nbsp;

有誰不曾為那思念而受苦

&nbsp;

我們總以為那份思念很重，很重

&nbsp;

是世上最重的重量，有一天，驀然回首

&nbsp;

我們才發現它一直都是很輕，很輕的
&nbsp;

人生無非就是一些人來，一些人走罷了

&nbsp;

開門，關門的瞬間，一切都成了決絕

&nbsp;

任憑人流涌動，仍是孑然一身，安靜地走近，安靜地離開
&nbsp;

&nbsp;

看見天空雲朵濃重起伏，不可限量

&nbsp;

日光照耀不留餘地，這種力量生生不息

&nbsp;

這彷彿在一場長眠之後

&nbsp;

醒來時，嗅到新生的氣息，感到潔淨無比

&nbsp;

可是一切不過一時，我們暗自承受

&nbsp;

或者一世空虛，我們義無反顧

&nbsp;

走得很急的往往都是最美的風景

&nbsp;

傷得最最深的總是那些最最真的感情
&nbsp;

&nbsp;

珍惜身邊所有的一切事物吧

&nbsp;

生活不是電影，錯過了就是失去了，沒有了

&nbsp;

不可能像電影裡一樣有重新再來一次的機會

&nbsp;

或許一次的錯過就會讓我們悔恨終身
&nbsp;

&nbsp;

能在茫茫人海中相遇、相知、相守，是難得的緣份

&nbsp;

但無論誰都不會一帆風順，只有一顆懂得付出

&nbsp;

懂得感恩的心才能擁有一生的愛和幸福

&nbsp;

幸福如那已悠然遠去的浮雲般，消失了，便不再出現

&nbsp;

還會有誰在世界的某個角落低低地啜泣，扼腕嗎

&nbsp;

答案卻是那樣不言而喻

&nbsp;

下個輪迴，誰會遇見誰，誰又是誰的幸福

&nbsp;

比別人多一點或是少一點的都是幸福
&nbsp;

&nbsp;

曾經我們的思惟和處世模式

&nbsp;

影響了我們對幸福的感知能力

&nbsp;

幸福經不起你刻了一把尺子去量

&nbsp;

它有一顆比磨難更敏感的心稍對它挑剔，

&nbsp;

它就棄你而去要獲得幸福並不難，

&nbsp;

對他人、對自己、

&nbsp;

對生活寬容些，幸福就藏在你心裡


&nbsp;
