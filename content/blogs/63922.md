幸 福 

&nbsp;




幸福 似乎很近 又似乎很遙遠

&nbsp;


就如流星般瞬間劃過星空 卻無法把它抓牢

&nbsp;


真的好想能永遠的抓住這瞬間的美麗

&nbsp;


能讓我想要的幸福停留在那個空間

&nbsp;

&nbsp;


想要把你的身影永遠鎖在我的視線之內

&nbsp;


可卻那樣的無力站在夜空下遙望著星空

&nbsp;


我的愛 就彷彿像天空中閃爍的星光般閃亮著

&nbsp;


卻永遠都不屬於我...

&nbsp;

&nbsp;

因為它只出現在漆黑的夜空中

&nbsp;



我要的幸福在那裡...我無力的對著夜空吶喊


&nbsp;

&nbsp;

可我的聲音在無際的星空下卻顯得那樣的飄渺

&nbsp;


幾乎看不到自己的存在 也感覺不到你的方向

&nbsp;


好想你能為我停留下流浪的腳步

&nbsp;

&nbsp;


這個世紀我似乎只能做你生命中的過客

&nbsp;


希望在下個世紀你的心能為我停留

&nbsp;


讓我有個可以停泊的港灣

&nbsp;


讓我能抓住那份遙望已久的幸福

&nbsp;

&nbsp;

&nbsp;
