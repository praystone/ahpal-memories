有的人 喜歡一個人
有的人 不喜歡一個人...

&nbsp;

簡單來說不喜歡一個人
也代表他怕孤獨與寂寞

&nbsp;

這一類的人&nbsp; 通常都會一個人胡思亂想
你不能否認的...

&nbsp;

一個人的時候，常常會想起好多的事情
沒來由的想起一些無關緊要的人
一些無關緊要的事

&nbsp;

一個人的時候，孤寂便會來陪著作伴
因為孤獨&nbsp; 所以寂寞。沒有誰是誰的誰。

&nbsp;

一個人的時候，總會靜靜的想一想以前的自己&nbsp; 是多麼的單純和無知

&nbsp;

一個人的時候，總會慢慢的等待癒合的傷口&nbsp; 等帶著心開始變得麻木

&nbsp;

一個人的時候，心情總會不佳&nbsp; 想著自己是多麼的孤獨

&nbsp;

一個人的時候，做什麼都覺得不稱心

&nbsp;

一個人的時候，會對自己有很多設問

&nbsp;

一個人的時候，感到寂寞是在所難免

&nbsp;

一個人的時候，沒有人在身邊陪伴著

&nbsp;

一個人的時候，說習慣了其實是謊言

&nbsp;

一個人的時候，總是悲傷的孤身作戰


一個人的時候，偶而會想起以前的快樂或不快樂的時光
想了&nbsp; 就會覺得以前的自己是多麼幼稚
只是朋友說了甚麼&nbsp; 就去做了什麼
想一想&nbsp; 累了&nbsp; 歇一歇


一個人的時候，看著流星在天際劃過&nbsp; 
一秒鐘的時間&nbsp; 就消失的無影無蹤&nbsp; 想著&nbsp; 人生不過如此
心底不免有一絲落寞&nbsp; 一絲莫名的憂傷
精彩的背後&nbsp; 總是寂寞


孤獨，永遠都是一個人，
任由你怎麼想&nbsp; 都不會與任何人交涉
還可能越想越快樂&nbsp; 是一種情境


寂寞，卻不一定是一個人
無論怎麼想&nbsp; 一定都是不快樂的
就算努力的想著愉快的事情
最後還是抵不過無窮的威力&nbsp; 就是一種情緒


那種寂寞的痛&nbsp; 真的是無法言喻的痛


話繞回來
如果你喜歡一個人
你的想法跟不喜歡一個人的想法大有不同了


我喜歡一個人的感覺
一個人&nbsp; 伴隨我的只有快樂
在一個人的影子裡我尋過不到在淒涼的寂寞
若一個人走在大街上&nbsp; 那是我最愉悅的時光
我不需顧及別人追隨的腳步
我可以放蕩無羈奔跑 
可以我行我素的慢行


喜歡一個人，一個人的感覺恬淡而清淋

&nbsp;

一個人&nbsp; 我可以大聲唱歌 不用擔心走音破音被人發現

&nbsp;

一個人&nbsp; 我可以放著熱門舞曲&nbsp; 搭配著自創的舞步&nbsp; 也不怕被人笑&nbsp; 開心就好

&nbsp;

一個人&nbsp; 我可以無限的批判心裡的牢騷

&nbsp;

一個人&nbsp; 我可以燦爛的微笑

&nbsp;

一個人&nbsp; 是快樂的 在沒遇到另一個人時

&nbsp;

一個人&nbsp; 可以隨心情的起伏而抱怨天氣的變化

&nbsp;

一個人&nbsp; 可以自由的去擊破藍天而不用擔心自己的羽翼

&nbsp;

一個人&nbsp; 可以開心看著別人的眼淚而不用擔心自己的淚水

&nbsp;

一個人&nbsp; 的感覺&nbsp; 甜美而細膩

&nbsp;

一個人&nbsp; 的感覺&nbsp; 快樂而回味

&nbsp;

一個人&nbsp; 的感覺&nbsp; 淡然而重憬

&nbsp;

一個人&nbsp; 可以遐想&nbsp; 可以深思&nbsp; 還可以淺讀

&nbsp;

一個人&nbsp; 可以幻想&nbsp; 可以安慰&nbsp; 還可以自滿與自作

&nbsp;

一個人&nbsp; 我可以行走觀看他人

&nbsp;

一個人&nbsp; 我可以私語

&nbsp;

一個人&nbsp; 我可以咒罵...

&nbsp;


我喜歡一個人的感覺，那種自娛的感覺很快樂，
那種幻想的感覺很滿足


我喜歡一個人的感覺，無羈的感覺讓我色彩斑斕


一個人的感覺，微笑的綻放&nbsp; 靈感的泉源&nbsp; 
文字的聚集還有幻想的成真
一個人的感覺...真好


就看你自己怎麼經營一個人
是孤單寂寞一個人
還是快樂無憂一個人
選擇權還是在你手中!!!
