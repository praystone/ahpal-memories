&nbsp; 


&nbsp;

為你打開一扇窗



&nbsp;

&nbsp;


窗外的世界總是清朗多彩

&nbsp;

就像一道美麗的風景線，也像一幅多變的油畫

&nbsp;

外面的世界有多精彩，不言而喻

&nbsp;

每一個人的世界也是一道窗口，一個風景線

&nbsp;

就像地球分佈的每一個角落

&nbsp;

每一個角落會有不同的風景

&nbsp;

每一個人的視角不同，折射的光線也不同

&nbsp;

因此看到的也會有不同的風采不同的看法
&nbsp;

&nbsp;

我很慶幸自己所擁有的一個窗口

&nbsp;

有自己眼中的世界，還有耳濡目染的世界

&nbsp;

甜酸苦辣的人生全在自己的知覺和把握中展現

&nbsp;

你說有多苦就有多苦，你說有多甜就有多甜

&nbsp;

而其實真正的體會是來自你心裡的感覺

&nbsp;

所以，把握好自己的喜怒哀樂也在你自己
&nbsp;

&nbsp;

常常有人會說『幸運』這兩個字

&nbsp;

而我也會說我很幸運

&nbsp;

所不同的是我是在品嘗人生後的感覺

&nbsp;

每一個感動的瞬間總會牽引我的每一個細胞

&nbsp;

每一個傷心的場面也會震撼我的每一次心靈

&nbsp;

只要有良知的人相信都會有感動和震動二種感覺

&nbsp;

再接下來就是行動了

&nbsp;

常常在看到或聽到感人的事跡

&nbsp;

我會感到自己原來也可以做些力所能及的事情

&nbsp;

不一定要偉大的舉動

&nbsp;

當看到或聽到無奈的傷感的事情時我會流淚我會感慨

&nbsp;

也由此感到自己真的好幸運

&nbsp;

自己活著真是一種幸福
&nbsp;

&nbsp;

為你打開一扇窗，故事有很多，感慨也會很多

&nbsp;

不同的角落不同的人物風情不同的視角給了你不同的觀點

&nbsp;

就像愛美都是每一個人心中的渴望

&nbsp;

快樂是每一個人心中的希望

&nbsp;

甜蜜是每一個人心中的夢想

&nbsp;

誰都希望自己眼中的世界是一道靚麗的風景

&nbsp;

但夢想與現實總是一對無緣的朋友

&nbsp;

那麼除了靠你自己的努力爭取，用理智去閱讀用行動去考驗

&nbsp;

才能有緣去接近去感受美好的一刻

&nbsp;

為你打開一扇窗，做你自己的主人

&nbsp;

&nbsp;

用你的雙手用你的雙眸去好好地感知吧

&nbsp;

外面的世界是為你而開的，

&nbsp;

只要你活著，你還是有機會的

&nbsp;

不要只傷感別人的不幸，至少給你帶來的是勇氣和行動

&nbsp;

不要只羨慕別人的幸福，其實你也是幸福的

&nbsp;
