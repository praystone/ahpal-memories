&nbsp;

 

&nbsp;


&nbsp;


&nbsp;


卡布奇諾的濃郁　醞釀著一股散不開的情緒


&nbsp;


&nbsp;


&nbsp;


感受著握在手心的溫度　不加糖　輕輕攪拌


&nbsp;


&nbsp;


&nbsp;


此刻　我只想淺嚐那苦中帶澀的滋味


&nbsp;


&nbsp;


&nbsp;


杯口氤氳著釋放的芬芳　足以包容瞬間的滄桑


&nbsp;


&nbsp;


&nbsp;


回憶裡零碎的畫面　已經無法完整的拼湊


&nbsp;


&nbsp;


&nbsp;


此時　唯有細細地品味曾走過的點點滴滴


&nbsp;


&nbsp;


&nbsp;


透過裊裊上升的熱氣　凝視玻璃窗內反射的自己


&nbsp;


&nbsp;


&nbsp;


憂鬱的眼神　飄忽不定　是累了嗎


&nbsp;


&nbsp;


&nbsp;


朦朧中　彷彿看見歲月留給自己的淡淡影子


&nbsp;


&nbsp;


&nbsp;


也許是因為咖啡苦澀中揉合的醇厚甘香


&nbsp;


&nbsp;


&nbsp;


最能詮釋一個人記憶深處的味道


&nbsp;


&nbsp;


&nbsp;


所以在一杯咖啡的催化下　就能喚醒


&nbsp;


&nbsp;


&nbsp;


那些已被收藏起來的樂與悲　笑與淚


&nbsp;


&nbsp;


&nbsp;


很多時候　喝咖啡　喝的是一種心情


&nbsp;


&nbsp;


&nbsp;


正如現實生活的樣子　甘甜與共　冷暖自知
