&nbsp;

&nbsp;



 
思念是海邊一片流雲


&nbsp;



在天空中打開


&nbsp;



浪一樣地


&nbsp;



起伏在心底


&nbsp;



思念


&nbsp;



是晨起吐出的一線陽光


&nbsp;



灑在身上


&nbsp;



記憶似的


&nbsp;



落入雲烟深處


&nbsp;



思念


&nbsp;



是浪尖一抹白沫


&nbsp;



伴着星子


&nbsp;



寂寥而细密地升腾、又墜落


&nbsp;



珍珠似的


&nbsp;



划入夢與魂的烟塵中
