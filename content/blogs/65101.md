這年頭拼的就是經驗<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


&nbsp;


&nbsp;


廣東一夥劫匪在搶劫銀行時說了一句至理名言："通通不許動，錢是國家的，命是自己的！"


&nbsp;


大家一聲不吭全躺倒。


&nbsp;


劫匪望了一眼躺在桌上四肢朝天的出納小姐，說："請你躺文明些！這是劫財，又不是劫色！"


&nbsp;


劫匪回去後，其中一個新來的碩士劫匪說："老大，我們趕快數一下搶了多少錢。"那老劫匪（小學畢業）說："你傻啊？這麼多，你要數到什麼時候啊？今天晚上看看新聞不就知道了嗎。"


&nbsp;


這就叫工作經驗，這年頭工作經驗比學歷更重要！！！


&nbsp;


劫匪走後，行長說，趕緊報案！主任剛要走，行長急忙說："等等！把我們上次私自挪用的五千萬也加上去！"


&nbsp;


主任會意，陰笑道："要是劫匪每個月都來搶一回就好了。"


&nbsp;


第二天，新聞聯播報導銀行被搶了七千萬。


&nbsp;


劫匪數來數去只有兩千萬。


&nbsp;


老大罵道："*媽的，老子拼了一條命才搶了兩千萬，銀行行長動動嘴皮就賺了五千萬，看來這年頭還是要讀書啊！
