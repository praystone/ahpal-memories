&nbsp;


想攀上高峰 必先丟棄包袱


&nbsp;



邊走邊撿石頭 只會徒增氣喘風來了


&nbsp;



竹子的枝幹被風吹彎


&nbsp;



風走了 竹子又站得直直的


&nbsp;



好像風沒來過一樣


&nbsp;



雲來了 在潭底留下一道影子


&nbsp;



雲走了 潭底乾乾淨淨的


&nbsp;



好像雲沒來過一樣


&nbsp;



竹子不會因為被風吹過


&nbsp;



就永遠直不起腰來


&nbsp;



清澈的潭水 也不會因為雲飄過


&nbsp;



就永遠留住雲的影子


&nbsp;



同樣的 心胸寬大的人


&nbsp;



不會因為別人兩句不禮貌的話


&nbsp;



就颳起永遠的狂風巨浪


&nbsp;



也不會因為別人不禮貌的行為


&nbsp;



就在心底刻下無法磨滅的傷痕


&nbsp;



像清澈的潭水一樣


&nbsp;



雲過了 不留痕跡


&nbsp;



像堅韌的竹子一樣


&nbsp;



風過了 不留痕跡
