&nbsp;

&nbsp;

梧桐葉落&nbsp; 在秋天

&nbsp;

想念的季節思絮紛紛

&nbsp;

旋轉的心情沒有方向&nbsp; 只是不斷地留下缺口

&nbsp;

心中的堅持是否只是潰堤的等待

&nbsp;

這一季的風即將走過

&nbsp;

仲夏夜裡沒有夢

&nbsp;

守候的仍然是梧桐樹下的失落

&nbsp;

枯萎的心&nbsp; 風化的情

&nbsp;

去年今日依舊

&nbsp;

知音少&nbsp; 心待老

&nbsp;

滿地秋葉無人掃

&nbsp;

埋了

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

花瓣多少

&nbsp;

&nbsp;



&nbsp;



&nbsp;

&nbsp;

&nbsp;

黃鶯初啼谷幽蘭

&nbsp;

簫笙問情聲聲慢

&nbsp;

塵海泛舟逐千帆

&nbsp;

燈火闌珊紅顏晚

&nbsp;

星院流螢蜃月樓

&nbsp;

紫羽吹雪始覺寒

&nbsp;

寄語朔雁春來早

&nbsp;

梧桐細雨淚秋蟬
