睡到自然醒7個關鍵____


&nbsp;<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


有沒有人每天為了睡不著而煩惱呢? 以下提供各位10個方法, 


因為我沒這類問題,所以不知效果如何? 希望能對失眠的朋友有所幫助!!


&nbsp;


人一生有三分之一的時間都花在床上，可見睡眠在我們的生活中佔了


一個很重要的部分。


&nbsp;


不過你知道嗎？睡覺也有很多的禁忌喔！不信讓我告訴你！


&nbsp;


1.不要仰睡：
避免手放在胸部，壓迫心肺，而且仰臥時舌根部往後墜縮，影響呼吸，


容易發出鼾聲。


&nbsp;


2.不要睡前思緒萬千：
宋代蔡季通〈睡訣〉中說：「早晚以時，先睡心，後睡眼」。


現代研究約80%的失眠是精神疾病所造成。換句話說睡前不要讀理科的東西！


&nbsp;


3.不要說話：
孔子云：「食不言，寢不語」，睡前嘮叨不絕會使思緒興奮，不得安寧，


因而影響入睡。


&nbsp;


4.不要開燈：
中國傳統醫學認為，從寤入寐，進入睡眠狀態，是個引陽入陰的過程。


醒時屬陽，睡時屬陰，光亮屬陽，黑暗屬陰。而西方醫學也報導，


晚上睡覺開燈會影響智力發展，所以最好養成晚上睡覺關燈習慣。


&nbsp;


5.不要蒙面睡：
因為睡覺時用被子蒙住頭面，會使人吸入大量的二氧化碳，發生呼吸困難。


&nbsp;


6.不要吹風而睡：
古書記載：當風「恐患頭風，背受風則嗽，肩受風則臂疼，善調攝者，


雖盛暑不可當風及坐臥露下。」現代生活中的電風扇，在睡眠中亦當小心，


因為人在睡眠中，生理機能較低，抵抗力較弱。


&nbsp;


7.不要飲酒飽食：
古人認為「胃不和則臥不安」，現代則認為睡前三小時不進食，


可使胃部獲得充份休息，一杯熱牛奶可免因飢餓而睡不好。喝少量的酒，


則可以鬆弛減少緊張。


&nbsp;


8.不要張口呼吸：
古代藥王孫思邈說：「夜臥常習閉口」因為張口呼吸，空氣未經鼻腔「預熱」


、「過濾」處理，容易引起咽乾咳嗽或其它感染。


&nbsp;


9.不要睡中忍便：
憋尿忍便對人體均有害處,也會影響睡眠。


&nbsp;


10.不要貪睡懶覺：
中國的早有「早睡早起」「久臥傷氣」的告誡，故而睡眠應以醒為度，


睡懶覺對人體是有害的。但是睡覺應該依照四季調度，春夏宜晚睡早起、


秋天早睡早起、冬天早睡晚起！
