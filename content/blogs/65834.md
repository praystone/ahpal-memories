不要低估你對朋友的重要性



&nbsp;



&nbsp;



我唸高一時，有一天看到一位同班同學吉米‧凱從學校走回家



&nbsp;



他看來是把所有在學校用的書要都帶回家。&nbsp;



&nbsp;



我想著：為什麼有人要在禮拜五把所有的書都帶回家呢？&nbsp;



&nbsp;



他一定是個很無趣的人。&nbsp;



&nbsp;



這個週末我已經計畫好參加一個宴會加上明天下午與朋友們來一場足球賽；&nbsp;



&nbsp;



所以我聳了聳肩，繼續走在回家的路。&nbsp;



&nbsp;



不一會兒，我看到一群小孩跑向他，撞了過去，把他的書全撞飛了，&nbsp;



&nbsp;



並且絆倒他，讓他跌到泥中。&nbsp;



&nbsp;



他的眼鏡也掉在離他有十尺遠的草地上，&nbsp;



&nbsp;



當他抬頭起來時，我看到他流露出很悲傷的眼神；&nbsp;



&nbsp;



那時我心軟了，我趕緊跑到他的身邊幫他找到眼鏡，同時看到了他眼角的淚光。&nbsp;



&nbsp;



當我把眼鏡遞還給他時，「那些小孩真是混蛋，他們真的是欠扁！」&nbsp;



&nbsp;



他臉上浮出一個大笑容，說：「謝了！」。&nbsp;



&nbsp;



那不是普通的一笑，而是由心裡發出對他人真誠的謝意。&nbsp;



&nbsp;



我幫他撿起散落的書，並問他住在那裡，原來他住在我家附近，但我卻不曾看過他。&nbsp;



&nbsp;



他說，因為之前他是上私立學校。&nbsp;



&nbsp;



我和他一直聊天到家，我也幫他揹著他的書，我又發現，他是一個蠻酷的小子。&nbsp;



&nbsp;



分手前，我問他要不要在禮拜日一起去踢足球。&nbsp;



&nbsp;



他說好。&nbsp;



&nbsp;



我們就整個週末都玩在一起，而且我又發現越認識吉米，我越喜歡他；&nbsp;



&nbsp;



我的朋友們也有同感。&nbsp;



&nbsp;



禮拜一早上，我又碰到吉米和他那一大堆的書。&nbsp;



&nbsp;



我問他：「你真是不簡單喔，每天這樣下去，你的臂力將會不得了喔！」&nbsp;



&nbsp;



他只是笑笑，並把一半的書丟給我。&nbsp;



&nbsp;



在後來的四年，我跟吉米成了最好的朋友。&nbsp;



&nbsp;



當我們唸到高四時（這是美國的學制），&nbsp;



&nbsp;



經過一番考慮，吉米決定要到喬治城大學讀醫學，&nbsp;



&nbsp;



而我要到伯爵大學唸書；但我知道我們會永遠都是朋友。&nbsp;



&nbsp;



畢業那一年是由吉米代表畢業班致詞，&nbsp;



&nbsp;



我一直以這是很無趣的事來開他的玩笑。&nbsp;



&nbsp;



畢業典禮的那一天，我見到吉米，他真是帥呆了！&nbsp;



&nbsp;



他胖了一點，帶眼鏡也比較好看些；&nbsp;



&nbsp;



而且他很受女孩們的喜歡，比我有更多的約會。



&nbsp;



這時我看出他很緊張，所以就拍拍他的背，&nbsp;



&nbsp;



又說：「嘿！你一定沒問題的！」。&nbsp;



&nbsp;



他很感激的看著我，並笑著說「謝謝」。&nbsp;



&nbsp;



他上台後，先清了清喉嚨開始他的致詞，&nbsp;



&nbsp;



「畢業是要來感謝一些曾經幫你度過難關的人，&nbsp;



&nbsp;



比如是你的父母、老師、兄弟姊妹，或是你的教練....和你的朋友們。&nbsp;



&nbsp;



在這裡我要告訴大家，&nbsp;



&nbsp;



「做一個人的朋友」是你可以給對方的最好禮物。&nbsp;



&nbsp;



我要來說一個故事，.......。」&nbsp;



&nbsp;



我以不可思議的眼神看著他，&nbsp;



&nbsp;



當他講著我們第一次相遇的故事。&nbsp;



&nbsp;



他說，那時正計畫要在週末時自殺，



&nbsp;



於是把學校置物箱裡的東西都清光了，&nbsp;



&nbsp;



希望死後媽媽不必再為他收拾殘局。&nbsp;



&nbsp;



然後，他很認真的看著我，並對我微笑，&nbsp;



&nbsp;



「很幸運的，我被救了。我被我的朋友從要做的錯事中救了出來。」&nbsp;



&nbsp;



當全場的聽眾聽到這位帥哥說出這件事時，歎息聲四起；&nbsp;



&nbsp;



我看到他的雙親看著我，並且對我報以感激的微笑。&nbsp;



&nbsp;



直到那時我才發現到，&nbsp;



&nbsp;



千萬不要低估自己的行動可能帶來的後果，&nbsp;



&nbsp;



也許一個小小的動作可以改變一個人的一生。&nbsp;



&nbsp;



不管世界變的怎樣，上帝讓我們和別人的生活交錯在一起時，&nbsp;



&nbsp;



要我們要儘量找出對方的優點來！&nbsp;



&nbsp;



&nbsp;



&nbsp;



&nbsp;



--摘自耕心週刊&nbsp;
