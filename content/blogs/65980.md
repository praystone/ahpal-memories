怎麼看自己






有一位牧師的女兒，她天生就是一位腦性痲痺患者，全身佈滿不正常的高張力，且無法言語。



&nbsp;



但，她卻靠著無比的毅力與信仰的扶持，在美國拿到了藝術博士，並到處現身說法，幫助他人。



&nbsp;



有一次，她應邀到一個場合演”寫”（不能講話的她必需以筆代口），會後發問時，



&nbsp;



一個學生當眾小聲的問：「妳從小就長成這個樣子，請問你怎麼看你自己？妳都沒有怨恨嗎？」



&nbsp;



這個無心但尖端的問題讓在場人士無不捏一把冷汗，深怕會深深刺傷了她的心。



&nbsp;



只見她回過頭，用粉筆在黑板上吃力地寫下了「我怎麼看自己？」這幾個大字。



&nbsp;



她笑著再回頭看了看大家後，又轉過身去繼續寫著：



&nbsp;



一、我好可愛！



&nbsp;



二、我的腿很長很美！



&nbsp;



三、爸爸媽媽這麼愛我！



&nbsp;



四、上帝這麼愛我！



&nbsp;



五、我會畫畫！我會寫稿！



&nbsp;



六、我有隻可愛的貓！



&nbsp;



七、還有……



&nbsp;



八、……



&nbsp;



忽然，教室內一片鴉雀無聲，沒有人敢講話。



&nbsp;



她又回過頭來靜靜地看著大家，再回過頭去，在黑板上寫下了她結論：



&nbsp;



「我只看我所有的，不看我所沒有的。」



&nbsp;



眾人安靜了幾秒後，一下子，全場響起了如雷的掌聲與無數感動的淚水….



&nbsp;



那天，許多人因著她的樂觀與見證而得到激勵。



&nbsp;



這個樂觀的腦性痲痺患者是誰？



&nbsp;



她，就是美國南加洲大學藝術博士，在台灣開過多次畫展的黃美廉女士。



&nbsp;



「我只看我所有的，不看我所沒有的。」



&nbsp;我喜歡這樣的人生觀，很健康也很愜意。
