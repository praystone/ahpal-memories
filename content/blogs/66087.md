天生萬物 都有它可愛之處&nbsp; 生命本多變化&nbsp; 接受它&nbsp; 

&nbsp;

在我遍尋不到彩紅時&nbsp; 仍會發現石縫裡可愛的小草而驚喜

&nbsp;

在我徬徨無助時 總有二三好友適時給予鼓勵

&nbsp;

若沒有熾熱的心 走到哪裡都會覺得無趣冷清

&nbsp;

朋友小美是多發性關節炎患者併發紅斑性狼瘡

&nbsp;

住在男友家中 和男友母親極度不合&nbsp; 與男友關係緊張

&nbsp;

多次聽她訴苦之後&nbsp; 我發現癥結在哪裡

&nbsp;

她沒有快樂的心 同她相處半年&nbsp; 只感染她負面情緒

&nbsp;

她只看見眼中不好的結果&nbsp; 沒去體驗過程的努力

&nbsp;

幸福已經慢慢毀在她手裡&nbsp; 面對男友提的分離 

&nbsp;

讓她處在自怨自哀的折磨裡&nbsp; 我勸導她的話 似乎不被接受

&nbsp;

聽那無止盡的抱怨咒罵 是我也會逃離遠遠的

&nbsp;

何況他們幾乎24小時相處一起 怎能不厭煩

&nbsp;

對我而言&nbsp; 眼裡的壞結果往往是過程有了差池

&nbsp;

下一次警惕自己多注意小心加以改進

&nbsp;

不是誰不好 不是誰的錯&nbsp; 而是修正到彼此最適合的角度

&nbsp;

只要方向正確了 別害怕過程冗長

&nbsp;

小美有一雙水靈漂亮的眼睛

&nbsp;

卻沒有好好領悟看清生命的本質&nbsp; 很可惜

&nbsp;

在我嘆息天上那顆明亮的星星如夢幻般閃爍時

&nbsp;

她說那比較像飛機飛遠了

&nbsp;

我說湯很可口時 &nbsp; 她說太油太鹹

&nbsp;

我說某甲做人很和善&nbsp; 她說那人心腸不好

&nbsp;

在她心中沒有善知覺&nbsp;&nbsp; 只有現實與埋怨

&nbsp;

可惜了世界萬物在她心中到底成了什麼

&nbsp;

那一面鏡子 我看到了我該珍惜的好人生
