&nbsp;



 




&nbsp;


人與人之間的相識相知，


&nbsp;


真的是人世間最奇妙的一件事情。


&nbsp;


在重逢相遇時，在分分離離裡，感受著命運的未知。


&nbsp;


一步步走過人生的每一個季節，


&nbsp;


品味著每個季節的風韻，體驗著歲月的風霜雪月；


&nbsp;


在或明或暗，或清醒或困惑的人生路途中，蹣跚前行。


&nbsp;




有時候，彼此的距離是不能以空間來計算的。


&nbsp;


近在咫尺，但卻橫亙著永遠不可逾越的山巒，


&nbsp;


只能遠遠地凝望，卻不能走近，更不能去牽那一雙手。


&nbsp;


這一切的美好，都彷彿是水中花、鏡中月，


&nbsp;


只怕一碰觸便會消失得無影無踪，只好駐足欣賞，


&nbsp;


靜靜地把這一切埋藏於心底，


&nbsp;


只能幻化成無奈的文字或低吟、或淺唱。



&nbsp;


有時候，心靈的距離是無法用空間來衡量的。


&nbsp;


即使遠隔天涯，卻依然能夠在奇妙的默契中，


&nbsp;


感受到近在咫尺的氣息，一切好像都已經成了習慣。


&nbsp;


每一秒的歡樂都想一起分享，


&nbsp;


感覺在分享中那快樂好像膨脹成了整個世界。


&nbsp;


每一縷的憂傷也想一起承擔，


&nbsp;


患難與共的每一滴淚可以瓦解那徹骨的痛楚。


&nbsp;


咫尺天涯的距離是一份無奈，是一份傷感，


&nbsp;


是一份遺憾，是一種永遠無法癒合的心靈創傷。


&nbsp;


天涯咫尺的心靈是一份默契，是一份甜蜜，


&nbsp;


是一份溫馨，是用一生守望來固守的精神園地。


&nbsp;


就這樣，靜靜地感受著咫尺天涯的距離，


&nbsp;


也許距離能夠產生美，


&nbsp;


希望永遠不要打破那份神秘的美麗。


&nbsp;


就這樣，靜靜地品味著天涯咫尺的靈犀，


&nbsp;


讓心泉在汩汩奔湧中，


&nbsp;


盡情地流淌著水乳交融的酣暢淋漓。


&nbsp;


帶著一份從容和淡定，勇敢地面對咫尺天涯的距離；


&nbsp;


帶著一份寬容和自在，坦然地迎接天涯咫尺的心靈。
