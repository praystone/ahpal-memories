休假日時總是期待有個愉快愜意的休閒時間


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


但！


&nbsp;


卻要參加頗久的煩人煩瑣訓練課程


&nbsp;


抱著不願的心態頂著赤白大太陽馳騁於鄉間小道


&nbsp;


於抱怨的心情下不知不覺來到目的地


&nbsp;


烈焰般的熱火無情的烘烤著


&nbsp;


內心還嘀咕著是否太早到了


&nbsp;


看不著幾隻貓（同事）到達該處^^


&nbsp;


只能望著不遠處樹蔭下三尺高的大石


&nbsp;


迅速移動接近一躍而上地坐著


&nbsp;


滿意著打量這塊難得的地方^-^


&nbsp;


微笑著仰臥這恰巧可容下一人休息的大床


&nbsp;


平穩而舒適^^


&nbsp;


好久沒這麼平靜的仰觀藍天白雲


&nbsp;


好滿足、好幸福的感覺


&nbsp;


此時樹葉細縫中窸窸窣窣傳來陣陣微風報到的聲音


&nbsp;


瞬時讓我穿梭時光倒返童年時期


&nbsp;


常常天真無邪般的在學校草皮上滾來滾去


&nbsp;


最後累了總躺臥在大地的懷抱


&nbsp;


感受大地母親般的呵護及寧靜


&nbsp;


並寂靜看著天空


&nbsp;


好藍的天


&nbsp;


好白的雲


&nbsp;


及好舒服的風


&nbsp;


原來等待也可以這麼美好！
