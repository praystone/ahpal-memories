&nbsp;

&nbsp;









&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


愛上下雨的夜&nbsp; 愛上這雨後暈染的清新


&nbsp;


&nbsp;


&nbsp;


唯有此時&nbsp; 我才能掙脫這世間的繭


&nbsp;


&nbsp;


&nbsp;


讓繁華下保有的 最後一份存真縱情的想妳


&nbsp;


&nbsp;


&nbsp;


風 在窗邊呼嘯&nbsp; 匆匆的來來去去


&nbsp;


&nbsp;


&nbsp;


窗外飛舞的雨絲&nbsp; 成了唯一忠實的觀眾與聽眾


&nbsp;


&nbsp;


&nbsp;


雨滴聲忠實的在窗檑伴奏


&nbsp;


&nbsp;


&nbsp;


滴滴答答成就著我的傾聽


&nbsp;


&nbsp;


&nbsp;


人說相逢何必曾相識&nbsp; 相識至始成相思


&nbsp;


&nbsp;


&nbsp;


在熙熙攘攘的人群裡


&nbsp;


&nbsp;


&nbsp;


多少個千分之ㄧ才能成就相遇


&nbsp;


&nbsp;


&nbsp;


當我像個沒有靈魂的流浪者 四處尋覓著莫名


&nbsp;


&nbsp;


&nbsp;


妳不經意的進入我的記憶 也讓孤寂淋濕我的翅膀


&nbsp;


&nbsp;


&nbsp;


總是在我失落時 燃起我的信心與希望


&nbsp;


&nbsp;


&nbsp;


當我鼓起勇氣追逐時 妳又遺落下成就相思的種子


&nbsp;


&nbsp;


&nbsp;


有時一句輕描淡寫的想妳&nbsp; 妳是否看出了


&nbsp;


&nbsp;


&nbsp;


這裡頭醞釀了多少個深夜書寫下的眷戀


&nbsp;


&nbsp;


&nbsp;


生命的恆流有多少痕跡會被淡淡的遺忘


&nbsp;


&nbsp;


&nbsp;


有時留下的片段 又未必是自己所願的精彩


&nbsp;


&nbsp;


&nbsp;


也許是我的無心


&nbsp;


&nbsp;


&nbsp;


因而有時在妳腦海裡殘忍的只留下一半


&nbsp;


&nbsp;


&nbsp;


每個人都有著各自的故事&nbsp; 也都有著深藏的遺憾


&nbsp;


&nbsp;


&nbsp;


存於我腦海裡的念念不忘


&nbsp;


&nbsp;


&nbsp;


並不是我還眷戀的讓心少了一半的空間


&nbsp;


&nbsp;


&nbsp;


而是深知遺憾帶來的痛


&nbsp;


&nbsp;


&nbsp;


&nbsp;


藉此提醒著自己別再留下遺憾


&nbsp;


&nbsp;


&nbsp;


所以我開始學著表達 學著如何將真實的自己呈現


&nbsp;


&nbsp;


&nbsp;


卻有時讓自己像個孩子似的徬徨&nbsp; 因而沉默…


&nbsp;


&nbsp;


&nbsp;


存於妳腦海裡的記憶


&nbsp;


&nbsp;


&nbsp;


我懂妳的無奈與不堪


&nbsp;


&nbsp;


&nbsp;


也懂回憶有時讓妳膽怯了…


&nbsp;


&nbsp;


&nbsp;


原諒我沒有來得及在最早的時刻遇見妳


&nbsp;


&nbsp;


&nbsp;


也原諒我沒來得及擦掉一些令妳堅強的起源


&nbsp;


&nbsp;


&nbsp;


如果為了要成就愛情的美麗


&nbsp;


&nbsp;


&nbsp;


反而破壞了 愛情該屬於的寧靜


&nbsp;


&nbsp;


&nbsp;


那我寧願讓自己試著學習&nbsp; 只在妳心上種下快樂


&nbsp;


&nbsp;


&nbsp;


還記得初識時 那份只有文字的傾聽與陪伴


&nbsp;


&nbsp;


&nbsp;


沒有虛偽的對白 也沒有膚淺的客套


&nbsp;


&nbsp;


&nbsp;


成就了那難以忘懷的美好


&nbsp;


&nbsp;


&nbsp;


&nbsp;


我讓自己閉上眼&nbsp; 在這過往的煙花裡摸索


&nbsp;


&nbsp;


&nbsp;


&nbsp;


我懂了


&nbsp;


&nbsp;


&nbsp;


&nbsp;


原來愛妳&nbsp; 也可以讓相思在筆尖蔓延


&nbsp;


&nbsp;


&nbsp;


讓彼此沒有負擔的在愛情裡呼吸


&nbsp;


&nbsp;


&nbsp;


&nbsp;


也懂 愛妳就要學會去關心


&nbsp;


&nbsp;


&nbsp;


&nbsp;


靜靜的去等待妳的破繭


&nbsp;


&nbsp;


&nbsp;


&nbsp;


如果愛妳是一種上癮&nbsp; 那就沉溺吧


&nbsp;


&nbsp;


&nbsp;


&nbsp;


就像此刻


&nbsp;


&nbsp;


&nbsp;


&nbsp;


讓相思在筆尖蔓延…


&nbsp;


&nbsp;


&nbsp;
