 rn&nbsp;

&nbsp;

&nbsp;
 
受用一生的愛情感悟 



&nbsp;

&nbsp;


真正的愛情，

&nbsp;

不是一見鍾情，而是日久生情；


真正的緣份，

&nbsp;

不是上天的安排，而是你的主動；


真正的自卑，

&nbsp;

不是你不優秀，而是你把她想得太優秀；


真正的關心，

&nbsp;

不是你認為好的就要求她改變，

&nbsp;

而是她的改變，你是第一個發現的；


真正的矛盾，

&nbsp;

不是她不理解你，而是你不會寬容她。 


我們一直覺得妥協一些、將就一些、容忍一些

&nbsp;

可以得到幸福。

&nbsp;

但當你的底線放得越低，

&nbsp;

你得到的就是更低的那個結果！不是嗎? 


不要因為寂寞愛錯人，更不要因為愛錯人而寂寞一生，

&nbsp;

嘗試信任才能得到幸福。

&nbsp;


緣分是本書，

&nbsp;

翻的不經意會錯過，讀得太認真會淚流。


&nbsp;

女人會記得讓她笑的男人，

&nbsp;

男人會記得讓他哭的女人，


&nbsp;

可是女人總是留在讓她哭的男人身邊，

&nbsp;

男人卻留在讓他笑的女人身邊。 


&nbsp;

多少人在說，我會等你，等你回心轉意的那一天；

&nbsp;

我會等你，等你願意和我在一起的那一天；

&nbsp;

我會等你，等你離開那個人來到我身邊的那一天；

&nbsp;

我會等你，等你……

&nbsp;

然而人們可曾知道，

&nbsp;

世上的愛情，沒有幾份真的經得起等待！
