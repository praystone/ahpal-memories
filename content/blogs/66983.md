有一種愛





&nbsp;


有一種愛，很淒迷


&nbsp;

有一種愛，只能遠望


&nbsp;

有一種愛，註定要成傳奇…


&nbsp;

有一種愛，像遙遠的大海，即使被酷日蒸乾了水分，


&nbsp;

它仍會化作甘霖，遍灑饑渴的大地…


&nbsp;

有一種愛，叫作痛，痛得心臟起了褶子，


&nbsp;

痛得頭腦空洞無物，痛得意志麻木蕭瑟…


&nbsp;

有一種愛，叫放棄，明知道許多事情是沒有答案的，


&nbsp;

卻想找尋一個答案，真的好累…

&nbsp;

&nbsp;

有一種愛，叫忍讓，忍讓也是一種愛。


&nbsp;

以愛的方式善待對方的缺陷，


&nbsp;

用包容的胸懷寬恕自己的愛人，給他一個悔悟的機會，


&nbsp;

留一個自省的空間，於平平淡淡中演繹經典，


&nbsp;

在無聲無語中融洽恩愛。


&nbsp;

這樣，即使是不傳奇的愛情也將變得永恆；


&nbsp;

再平淡的婚姻，依然一如既往令人流連。


&nbsp;

有一種愛，叫放手


&nbsp;

曾經天真的以為不管時間和空間的距離有多長多遠，


&nbsp;

感情一定會不變，因為愛是沒有理由的……


&nbsp;

愛不能成為牽絆，

&nbsp;

所以要選擇放手，從容的讓彼此走出彼此的世界。


&nbsp;

凡事到極至，傷也會痛。

&nbsp;

其實愛過就會懂，


&nbsp;

彼此個性的太過堅強終究會是一起生活的陰影。


&nbsp;

昨日的幸福已成為一種痕跡。


&nbsp;

兩人能攜手走完整人生固然美好，

&nbsp;

可陪上了一段也應心存感激了。


&nbsp;

愛一個人不是要成為所愛的人的牽絆，只要心中有愛，

&nbsp;

生活總是那麼美好。


&nbsp;

相遇是一種緣，相識，相戀更是一種緣，


&nbsp;

緣起而聚，緣盡而散，放手才是真愛！


&nbsp;

有一種愛，叫離開


&nbsp;

曾經以為自己的愛情能夠長久，


&nbsp;

曾經以為真心的付出就能夠換來幸福。


&nbsp;

其實錯了…愛情給的唯一的東西就是背叛，無情的背叛！


&nbsp;

曾經是那麼相愛的兩個人，轉眼陌路。


&nbsp;

留下的是殘缺不全的記憶和心痛。


&nbsp;

沒有想到結局會是這樣，曾經的海誓山盟，


&nbsp;

曾經的天長地久轉眼都成了飛灰。


&nbsp;

還記得她口中的永遠，讓我恍若夢中，


&nbsp;

但夢醒的時候，才發覺她早已離開。


&nbsp;

我們認識自己也認識世間，就是有這樣無緣而有情的瞬間，


&nbsp;

讓我們輕輕的歎息，深深的愛。


&nbsp;

分享你生命中快樂的事 


&nbsp;

分享你生命中難過的事 分享你生命中一切的一切


&nbsp;

你會發現 分享也是一種獲得


&nbsp;

祝福 我的朋友 


&nbsp;


&nbsp;
