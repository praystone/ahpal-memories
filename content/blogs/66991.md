有一種愛不一定都要相守，只要學會欣賞


&nbsp;



&nbsp;


和女人最重要的是相知相愛 
&nbsp;
其實在你的一生中真正能打動你的人遠遠不止一個
&nbsp;
都去相愛嗎 ? 很不現實... 
&nbsp;
&nbsp;
愛是一種用心投入的狹隘當你愛一個人的時候 
&nbsp;
想完完整整的擁有他,包括他的思想、他的情感、以及他整個人 
&nbsp;
但每一次的感動過後，你又能長久的擁有嗎? 
&nbsp;
&nbsp;
沒有永遠不變的思想，也沒有永遠唯一的情感 
&nbsp;
所以重要的不是愛，而是欣賞的情感 
&nbsp;
&nbsp;
它美好但獨立而排他優秀的人
&nbsp;
身上會分散著誘人的光彩，他不僅吸引你，
&nbsp;
同時也吸引著和你同樣有著鑒賞能力的人

&nbsp;

就像美麗的風景，
&nbsp;
它的存在不是為了一座山、一片曠野 
&nbsp;
而是為了整個自然，是為了點綴這美麗的世界 
&nbsp;
是為了讓更多的人去欣賞、去品味、去陶醉其間 
&nbsp;
不同的人、不同的品味，會對同一幅景像產生不同的感覺

&nbsp;

晶瑩的雪山有著冰清玉潔的美，
&nbsp;
潺潺的小溪有著清秀自然的美波，
&nbsp;
瀾壯闊的大海有著寬廣豪放之美，
&nbsp;
每一種美都給人不同的震撼，每一個人都是有血有肉有靈魂的 
&nbsp;
他們的身上同樣散發著不同的美，每一種美好的品質都是誘人的 
&nbsp;
&nbsp;
任何時候，學會用欣賞的眼光去看待世界 
&nbsp;
看待你周圍的人，你便會更坦然地面對一切了 
&nbsp;
人性的弱點就是想占有，想占有自己喜愛的一切東西 
&nbsp;
但人又是有思維的 這種思維隨時都在變 
&nbsp;
沒有一種情感是永恆不變的...所以，不要奢望你能擁有很多
&nbsp;
用一種平常心態去欣賞一個人，就像欣賞
&nbsp;
一幅畫一樣，你會很快樂，也會很坦然 
&nbsp;
&nbsp;
當你用一種平常的心境去認識一個人，結交一個人的時候 
&nbsp;
你便會沒有了一些私情雜念，你們便可以自由隨意的交往 
&nbsp;
心也便會一點點的交融 
&nbsp;
&nbsp;
真正的朋友便會在你欣賞的眼光中向你走來 
&nbsp;
友情同樣是生命中不可缺少的東西 
&nbsp;
在你擁有了很多真心朋友的時候，你才會覺得生命的快樂
&nbsp;

擁有一個好朋友，比擁有一段感情要平實的多 

&nbsp;

在人的一生中，每一次用心的投入都是一種傷害 
&nbsp;
而朋友則不同，
&nbsp;
你可以在擁有朋友的同時體味到人性的純美、
&nbsp;
真情的可貴友情同樣是一種愛、一種更高尚更至誠的愛 
&nbsp;
&nbsp;
這世上樹葉有千萬片,這世上人有千萬種,不一定都要相愛, 
&nbsp;
不一定都要相守,只要學會欣賞。

&nbsp;
