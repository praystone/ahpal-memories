人前人後 





常常在想: 

&nbsp;

一個富有的人，心裡，有什麼擔憂？ 

&nbsp;

一個成功的人，背後，有沒有憂愁？ 

&nbsp;

一個外表看似堅強的人，內心，會不會也有懦弱？ 

&nbsp;

沒有人，

&nbsp;

可以永遠精神飽滿，不停的工作 

&nbsp;

沒有人，

&nbsp;

可以無煩無憂，沒有疲憊的時候 

&nbsp;

沒有人，

&nbsp;

不需要關懷問候，沒有過無助的感受 

&nbsp;

&nbsp; 沒有人，

&nbsp;

一生有著輝煌成果，卻從沒有失敗的經過 

&nbsp;

&nbsp;

人生，難免走到低潮，感覺身心俱疲的低落 

&nbsp;

人前堅強，人後落寞，難以理解的憂愁 

&nbsp;

是種孤單心情，彷彿到了該充電、改變的時候 

&nbsp;

路，好像走到了盡頭 

&nbsp;

但，其實，那就是該轉彎的時候 

&nbsp;

此路不通，還有別條道路可以走，不必過於執著 

&nbsp;

大多數人與我們擦肩而過 

&nbsp;

只有少數的有緣人，才能在你我的內心深處佇留 

&nbsp;

有緣相遇卻無緣聚守，痛在心，口難說 

&nbsp;

不能改變的，只有接受 

&nbsp;

&nbsp;

有些思念、關心的話想說，總是不好開口 

&nbsp;

各自忙碌，成了司空見慣的理由 ，悸動顫抖的心，隱約浮現莫名的歉疚 

&nbsp;

世事無常，千頭萬緒，總是覺得莫可奈何 

&nbsp;

時光匆匆過，轉眼又是一個年頭， 好多時候，不是無情，而是懶惰 

&nbsp;

是勇氣不夠，想愛卻不敢說， 是成見太深或是誤會太多 

&nbsp;

萬般掙扎的難過，無法釋懷，難以解脫

&nbsp;

&nbsp;

這年頭，各種壓力，擔在肩，重在心頭 

&nbsp;

朋友雖多，礙於面子，有些人，有些心事卻難訴說 

&nbsp;

仰天長〝笑〞，竟不知所措，無奈佇立心頭 

&nbsp;

幾度愁眉深鎖，獨愴然而淚流 

&nbsp;

寒風蕭瑟，心，似雪花紛飛雲遊 

&nbsp;

一個人，徬徨的走在街頭，看著五彩繽紛的霓虹燈閃爍 

&nbsp;

在喧嘩熱鬧的人後，常見的是孤單與落寞 

&nbsp;

有一種激動，直催人想大聲嘶吼 ，是發洩，是釋放，是解脫 

&nbsp;

總希望明日過後，心情一切從頭，生活從此快樂無憂 

&nbsp;

&nbsp;

愛情，像美麗奪目、光彩燦爛的煙火 

&nbsp;

絢麗迷濛的背後，夾帶著複雜的不安和寂寞 ，只在乎曾經擁有，

&nbsp;

怎敢奢望天長地久？ 

&nbsp;

不安的心，浮現出空虛念頭，不敢再想以後 

&nbsp;

溫柔，可以溶化冰雪，也能讓頑石點頭 

&nbsp;

只是，人生多事無法強求 ，有時候，疲累不是休息不多 

&nbsp;

無助，不是能力不夠 

&nbsp;

心知凡事不能強求，也不敢奢望太多 

&nbsp;

但是，偶爾希望，依靠的肩膀可以更為寬闊 

&nbsp;

愛護的心，能夠更甜蜜溫柔 

&nbsp;

好包容我短暫的懦弱以及忙碌的錯 

&nbsp;

&nbsp;

人生何求，一份安心就足夠 ，如果信心不夠，何來以後？ 

&nbsp;

不要刻意去掩飾內心哀愁 

&nbsp;

總是悶著胸口，壓力勢必無法承受太久 

&nbsp;

想辦法多做幾件事，讓自己回復快樂 

&nbsp;

找過去相談甚歡的朋友，吃頓大餐，喝喝茶，敘敘舊 

&nbsp;

回想過往快樂的生活，人生沒有放不下的憂愁 

&nbsp;

生活，原來可以這麼悠閒、自在、灑脫 

&nbsp;

人生，其實還是相當美好的！
