★男人一生中的女人★

&nbsp;&nbsp;&nbsp; 




&nbsp;

&nbsp;&nbsp;&nbsp; 


人的一生，


&nbsp;

總有許多種感情，

&nbsp;

交織成一生的愛怒情仇。

&nbsp;

&nbsp;

一個男人，生命裏決不只有兩朵玫瑰。

&nbsp;

在他人生的各個階段，有多個不同的女人，

&nbsp;

占據他人生不同的地位。

&nbsp;

永遠不要奢求，在他心理，只有唯一的一個人。

&nbsp;

男人覺得最無怨無悔的是初戀的那個女孩。


&nbsp;

初戀是不設防的，在他尚未準備時，

&nbsp;

沒有經過思考，不用比較，便那麽悄悄地理所當然了。

&nbsp;

雖然初戀的結果很少圓滿，烙印在心中的有點青澀的笑容

&nbsp;

卻永遠是最幸福甜蜜的記憶，令他心甘情願、無怨無悔。

&nbsp;&nbsp;&nbsp; 

&nbsp;

男人最無法忘記的，是他未得到的那個女子。


&nbsp;曾為她窗前佇立，曾為她翻遍情書大全，

&nbsp;

有時也為她落淚心痛，

&nbsp;

然而她的笑總是為了另一個人，即使哭，

&nbsp;

都把淚掉在另一個人的肩頭，就如同天上的一輪明月，

&nbsp;

總令他忍不住想親近，卻清冷高傲，無法觸及。

&nbsp;

所以，便始終懸在男人的心頭。

&nbsp;&nbsp;&nbsp; 


&nbsp;

男人最懷念的，是在患難時陪著他的那個女人。

&nbsp;

不一定是懷念她，

&nbsp;

或許只是因為不能忘記那段日子，

&nbsp;

所以一並記住了那個人。


&nbsp;

在他的成功時，總會不經意提起：

&nbsp;

我那個時候啊，真是難，但她一直都在我身邊，

&nbsp;

只可惜今天……

&nbsp;

言語裏更多的希望那個女人看到他今日意氣風發、

&nbsp;

揚眉吐氣的樣子。

&nbsp;

&nbsp;

&nbsp;

因為女兒是男人一生中唯一不能得到的女人。

&nbsp;

不論更多愛她、寵她，始終眼睜睜的將她交給另一個男人，

&nbsp;

然而，對這永遠只有付出的卻得不到回報的男女之情、

&nbsp;

男人卻又甘之如飴，而且還祈求她永遠幸福快樂。


&nbsp;

所以，女兒對男人而言，永遠是心中最特別的存在，

&nbsp;

也是最特別的感情付出。


&nbsp;


&nbsp;
