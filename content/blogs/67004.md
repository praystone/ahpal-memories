猶豫 將使你一事無成

&nbsp;



&nbsp;

&nbsp;


顧慮太多所以每次只要在下決定的時候就開始猶豫，

&nbsp;

擔心著下決定後的後果，

&nbsp;

擔心著下決定之後產生的問題會接踵而來，

&nbsp;

可是你知道嗎？

&nbsp;

猶豫的同時，你同樣在原地踏步，根本什麼事情或目標都沒完成，

&nbsp;

甚至顧慮到最後，機會消失了，因為你有時間可以讓你猶豫、

&nbsp;

可以讓你考慮，機會卻是沒有時間會等你。

&nbsp;

&nbsp;

自己擔心許多沒發生的問題，把猶豫當成自己不敢前進的藉口，

&nbsp;

可能因為你的猶豫不決，讓自己在舒適區過的安安穩穩，

&nbsp;

但你的人生就已經停留在此地，

&nbsp;

更不用說有機會去創新不同的未來，

&nbsp;

就是猶豫給了你包袱，它讓你在下決定前有了脫逃的理由，

&nbsp;

讓你的人生少了一次次可以創造不同以往的機會。

&nbsp;

&nbsp;

你擔心失敗、擔心失去、擔心太多太多，但這些根本都沒發生，

&nbsp;

你就已經用自己的角度把自己綁死在自己的象牙塔中，

&nbsp;

更不用說這些問題有沒有產生的可能；

&nbsp;

做任何一件事都要思考、都要評估（這是一定要的），

&nbsp;

但不該被猶豫牽制住，決定了就做吧！任何事情肯定都會有問題，

&nbsp;

可是你能隨遇而安也能迎刃而解，

&nbsp;

不要失去創造屬於自己人生的勇氣。

&nbsp;

&nbsp;

有想完成的事情，既然決定好，

&nbsp;

仔仔細細思考、評估後就做，

&nbsp;

不要被猶豫綁死，擔心東擔心西擔心到最後，

&nbsp;

你根本連第一步都沒踏出，還沒開始就直接宣告失敗，

&nbsp;

不需要猶豫，你所擔心的問題不會在你沒踏出任何一步的時候發生，

&nbsp;

而更不用擔心你下定決心後所產生的問題，

&nbsp;

因為你的決心會讓這些都變成不是問題。

&nbsp;

&nbsp;

需要下決定的時候，不要給自己有猶豫的藉口，

&nbsp;

你會因為未知的未來擔心，但不要因為未知的未來而猶豫，

&nbsp;

這是你自己的人生，你該有創造自己人生的勇氣，

&nbsp;

不要被猶豫浪費的人生

&nbsp;

也不要因為沒發生的事情讓自己猶豫不前，

&nbsp;

無論是誰說，你思考後要下任何決定就下，

&nbsp;

因為它是你的人生，不要被猶豫弄的一事無成了。
