&nbsp;


十件老闆沒說的事…你得參透

&nbsp;

十件事上司不會明說，但你心裡有數或許比較好

&nbsp;

&nbsp;



&nbsp;

&nbsp;


1.「我們監看你的電子郵件和即時通訊。」 

&nbsp;

美國券商Wedbush的資訊科技部門主管說，

&nbsp;

公司利用軟體監看逾千名員工的郵件、即時通訊及社群網路活動；

&nbsp;

估計每日員工傳送的訊息中，有5%至10%受到監看。

&nbsp;

去年有20%的美國大企業以違反電子郵件政策為由開除員工。

&nbsp;

&nbsp;

2.「你年紀太大。」 

&nbsp;

調查發現，約25%的雇主不願僱用較年長的員工，

&nbsp;

只看履歷表的雇主歧視50歲以上的女性。

&nbsp;

&nbsp;

3.「我知道你裝病。」&nbsp; 

&nbsp;

彭博新聞周刊報導，

&nbsp;

愈來愈多公司僱用私家偵探，追蹤託病請假的員工。

&nbsp;

還有主管說，他很清楚員工假裝賣力工作。

&nbsp;

無論是偷懶打混、騎驢找馬、稱病告假或虛報支出，

&nbsp;

老闆其實都看在眼裡，只是暫時忍耐。

&nbsp;

&nbsp;

4.「小孩是妳的問題。」 

&nbsp;

女性的薪酬通常比男性少，養育小孩更影響女性賺錢的潛力。

&nbsp;

「媽咪懲罰條款」處處可見：

&nbsp;

職業婦女可能失去升遷機會，也無法負責重要專案，

&nbsp;

因為老闆擔心她無法盡心盡力。

&nbsp;

&nbsp;

5.「我是你最好的朋友...」 

&nbsp;

和老闆成為至交好友，有利升遷或得到特殊待遇；

&nbsp;

但上司有權開除下屬，兩者地位永遠不可能平等。

&nbsp;

職場專家柯恩建議，

&nbsp;

別越線和老闆建立私交，也避免談及敏感的私人問題，

&nbsp;

以免有一天被老闆用來對付你。

&nbsp;

&nbsp;

6.「...也是你最可怕的敵人。」 

&nbsp;

與老闆關係變差，絕對重創事業。

&nbsp;

人力資源管理協會（SHR）說，72%的霸凌來自頂頭上司。

&nbsp;

半數被老闆欺負的員工有壓力相關病痛。

&nbsp;

職業與環境醫學雜誌（JOEM）年前刊出的研究發現，

&nbsp;

在難搞、諱莫高深或不願溝通的老闆手下做四年，

&nbsp;

心臟病發機率增加60%。(去年%數會更高)

&nbsp;

&nbsp;

7.「我決定升遷不看績效表現。」 

&nbsp;

除工作表現外，決定升遷的因素還包括主管偏好、

&nbsp;

組織規章及企業文化；部分公司把資歷列為重要考量；

&nbsp;

是否和主管合得來也是關鍵。

&nbsp;

聰明能幹不保證不會丟工作，亞歷桑納州投資規劃公司主管坦承，

&nbsp;

他開除一名聰明伶俐、學經歷俱佳的員工，

&nbsp;

只因他很難管理，兩人關係已鬧僵。

&nbsp;

&nbsp;

8.「我很膚淺。」 

&nbsp;

外形清瘦又有吸引力讓事業一帆風順，

&nbsp;

反之，在主管眼中其貌不揚又過胖的員工並不討好。

&nbsp;

雖然吸引力並不等同績效表現，但許多主管相信「美就是好」。

&nbsp;

&nbsp;

9.「我沒空理你。」 

&nbsp;

老闆向來忙碌，經濟衰退時大舉裁員後，

&nbsp;

主管現在更沒空督導下屬，甚至連交談時間也沒有。

&nbsp;

調查顯示，三分之二的員工表示和老闆互動過少。

&nbsp;

&nbsp;

10.「我最重要。」 

&nbsp;

幾乎半數的員工說，主管搶他們的功勞；

&nbsp;

逾三分之一說，主管犧牲他們以成全自己。

&nbsp;

老闆爭功諉過很普遍，有時是因為高層只在乎成果，

&nbsp;

不在乎團隊成員的個別貢獻；

&nbsp;

有些主管則認為，下屬幫襯是天經地義的事；

&nbsp;

至於成員眾多的團隊，老闆壓根不記得誰做了哪一部分。
