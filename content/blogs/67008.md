&nbsp;

★善待愛情★

&nbsp;



&nbsp;


親情，愛情，友情是人生最珍貴的情感

&nbsp;

親情是人與生之俱來的緣分

&nbsp;

友情是人生的點綴

&nbsp;

愛情是人生可遇而不可求的緣分

&nbsp;

人人渴盼愛情，然而當愛情降臨，卻又不知善待愛情

&nbsp;

常見相愛的人兒因為種種勞燕分飛

&nbsp;

愛瞬間變恨，曾經的海誓山盟俱化為虛無，往事如煙，不堪回首


&nbsp;

　也許愛情給人的感覺太過浪漫

&nbsp;

相愛的人對愛情寄予了許多美的想像對愛人寄予了許多願望

&nbsp;

只預見了愛的風花雪月，不曾預見愛的淒風苦雨

&nbsp;

想像中的愛情是不食人間煙火的仙子

&nbsp;

而現實中的愛情必須植根於現實的土壤

&nbsp;

經過悉心的澆灌，呵護，經風歷霜，才會成熟


&nbsp;

愛情最初是甜蜜的

&nbsp;

當婚姻為其築成圍牆，愛情似乎在柴米油鹽醬醋茶中，

&nbsp;

慢慢失去了原有的滋味

&nbsp;

曾經的謙謙君子也會變為暴君，只不過他面對的不是被愛俘虜的順民

&nbsp;

曾經的窈窕淑女也會變河東獅，只不過她面對的不是被愛俘虜的小動物

&nbsp;

於是愛情遭遇婚姻之後，遇到了前所未有的考驗

&nbsp;

於是有人會將“婚姻是愛情的墳墓”這句話搬出來安慰自己

&nbsp;

真是這樣的嗎？是愛人變了嗎？不是。是自己變了嗎？也不是

&nbsp;

那麼是什麼改變了這一切呢


也許都會苦苦地問自己︰當初，

&nbsp;

我怎麼會愛上這麼個人，這個人是當初我愛的人嗎

&nbsp;

殊不知，這時的男女才是自己本真的模樣

&nbsp;

當初是愛情最初的美好給彼此戴上了光壞

&nbsp;

熱戀時男人表現的大男子主義也許被女人視作男子漢氣概

&nbsp;

而女人的撒嬌刁蠻全被當作了可愛

&nbsp;

是愛的激情讓我們閉上了那只挑剔的眼睛

&nbsp;

當愛情歸於平淡，那只閉著的眼睛睜開了，甚至比什麼時候都要挑剔

&nbsp;

越是熟悉越是了解，優點缺點便會一目了然

&nbsp;

也許因為親密，無所防備，袒露的是本真的自己

&nbsp;

“金無足赤，人無完人”，對方是不完美的

&nbsp;

那麼我們自己呢

&nbsp;

我們自己不也是俗人，也不是完人嗎

&nbsp;

既然我們自己也不完美，

&nbsp;

那麼閉上那只挑剔的眼睛，睜大那只發現美的眼睛

&nbsp;

善待愛人，其實也是善待我們自己

&nbsp;

善待愛人

&nbsp;

讓我們認識真正的愛情不僅僅是什麼花好月圓

&nbsp;

有花開花謝

&nbsp;

有月圓月缺這是愛情的本來面目吧

&nbsp;


善待愛情，讓我們學會忘記

&nbsp;

最親近的人傷自己最深，為愛我們沉醉，我們心碎

&nbsp;

只因為那個我們深愛著的人深深傷了自己的心

&nbsp;

唇齒相依，難免發生矛盾

&nbsp;

那麼讓我們忘記愛人的無心之失


&nbsp;

善待愛情，學會讓步

&nbsp;

一個巴掌拍不響，矛盾的發生不僅僅是那一個人的錯

&nbsp;

也許一個錯的多點，一個錯的少點

&nbsp;

既然相愛，誰對誰錯有什麼關係呢

&nbsp;

&nbsp;

看著盛怒的愛人，既然爭吵不能平息他的怒火，那麼就以柔克剛吧

&nbsp;

隱去眼中的淚，暫別心中的不滿和憤怒

&nbsp;

給他一個微笑，一個親吻，他還會怒氣沖沖嗎

&nbsp;

是不是會像一拳打空似的尷尬呢

&nbsp;

看著粉面含嗔的愛人，給她一個擁抱，她是不是會在你的懷中撒嬌呢

&nbsp;

讓步，你們是不是雙贏呢

&nbsp;

人都是自私的，其實讓步也是為了自己能夠快樂和幸福

&nbsp;

你的另一半如果陷在壞情緒中，你能好過嗎

&nbsp;

為了自己，為了愛情，學會退一步吧

&nbsp;


給愛情一個台階

&nbsp;

別把她想得太過美好，讓她能在現實的土壤中茁壯

&nbsp;

讓她能經歷世俗的歷練，願相愛的人能牽手到永遠




&nbsp;
