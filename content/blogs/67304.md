&nbsp;






&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;



遇見你，就是我最好的緣，在這之中，不分你我，即使我們尚無法解讀。


&nbsp;


&nbsp;




如果遇見一個人，你的想像便會漫無邊際地輕舞飛揚，說明你是真的喜歡了。


&nbsp;


&nbsp;


&nbsp;



也許，在很大程度上，你並不是真的喜歡這個人，卻是享受這種心猿意馬，難以描繪的心跳時刻。


&nbsp;


&nbsp;




如果遇見你喜歡的人，你會感覺對方跟自己以前的一些人總有著熟悉的地方。


&nbsp;


&nbsp;


&nbsp;



你會先在心裏親切起來，便找機會結識對方，雖然說的話語有些言不由衷，但是你相信那是上天給予自己的緣分。


&nbsp;


&nbsp;




你若問起，愛是什麽？愛就是不捨晝夜。


&nbsp;


&nbsp;


&nbsp;



愛著的時候，心裏總會開出花來，甜甜蜜蜜的，想方設法地對對方好，那時候的人活在虔誠中，樸素的願望莫過於天長地久，生生世世。


&nbsp;


&nbsp;




有一天，當你發現自己長大了，也懂得了憂傷，卻不能理解，為什麽憂傷是思念一個人最美，最芬芳的心情。


&nbsp;


&nbsp;


&nbsp;



思念的滋味，就像一個人深夜裏飲下的涼水，爾後用心暖出的淚點。


&nbsp;


&nbsp;




有一天，當遇見的那人離去時，你會不會也感到憂傷，甚至心痛，相遇是緣，相離是怨。


&nbsp;


&nbsp;


&nbsp;



既然相遇是如此美好，下一次相逢何嘗不是，充滿期待，人生莫不是如此。


&nbsp;


&nbsp;




人生既要學會面對孤獨，又要學會品悟思念，孤獨是一種心情，思念是一種情懷。


&nbsp;


&nbsp;


&nbsp;



戀愛中的人，最怕的就是孤獨，最詩意的才是思念；


&nbsp;


&nbsp;


&nbsp;



思念中的人，才知道愛的分量，才體味愛原是瑣碎的。


&nbsp;


&nbsp;




有時，在你感到幸福的時候，你也會笑著流著眼淚，那是喜極而泣。


&nbsp;


&nbsp;


&nbsp;



喜歡流淚的人，不一定都是脆弱的，而脆弱的人往往無淚可流。


&nbsp;


&nbsp;


&nbsp;



你要知道，真正懂得珍惜你的人，往往是不大會在你面前淚流滿面的。


&nbsp;


&nbsp;




一個人，在一生中應該有一次真愛。


&nbsp;


&nbsp;


&nbsp;



也許，你會說真愛難尋，只有真正愛過的人才會明白？


&nbsp;


&nbsp;


&nbsp;



其實不然。因為愛是一種付出，是不求索取的，愛永遠不落俗套，也永遠不會失去。


&nbsp;


&nbsp;


&nbsp;



愛是我們心靈不竭的源泉，是滋養生命的精神食糧。


&nbsp;


&nbsp;




請相信愛，一直一直。


&nbsp;


&nbsp;


&nbsp;



當愛來臨的時候，就願意在一個地方一直等下去，你若不離，我亦不棄，愛是你我。


&nbsp;


&nbsp;


&nbsp;



相信你也知道，世上最珍貴的情感不是擁有，而是牽掛。


&nbsp;


&nbsp;


&nbsp;



牽掛對方，甚至忘記了自己，不求你是不是愛我，只求讓你知道，我是在乎你的。


&nbsp;


&nbsp;




遇見你，遇見愛，你是我人生的續集；


&nbsp;


&nbsp;


&nbsp;



遇見你，遇見愛，你是我生命的傳奇。


&nbsp;


&nbsp;


&nbsp;



我只希望和你在一起，共赴一場醉生夢死的繁華，演繹一場百轉千回的愛戀。


&nbsp;


&nbsp;


&nbsp;



我的一生，因為遇見你而完整。
