九月十二日就是中秋了！
每年中秋是我和TEAM裡同事歡聚時刻，一方面感謝同仁的包容協助
也為秋天美食揭開序幕，這套烤肉食譜是我多年經驗，三年前把它整理好
今天在這裡分享給網路好友囉

LET'S PARTY ALL NIGHT LONG！

烤肉趴料理
烤肉時切記一個原則─炭不見火離十寸
&nbsp;
海鮮肉類
&nbsp;
一.&nbsp; 鹽封羊腿（也可以是整塊羊排）
&nbsp;
作法：
&nbsp;
至傳統市場買粗鹽，量要足夠包覆整支羊腿，再取蛋白加入薄荷及檸檬葉以料理機打勻成綠色糊狀後，和粗鹽充分調和包覆羊腿並以鋁箔裹緊烤約五十分鐘，不過烤爐最好能密閉烘烤，上菜時當眾敲開，保證驚喜連連，香味四溢。
&nbsp; &nbsp;
二.&nbsp; 迷迭香雞腿排
&nbsp;
作法：
&nbsp;
去骨清雞腿均勻灑上鹽和的義大利綜合香料，蒜頭切片並剪幾枝迷迭香平鋪在雞腿上，再淋上初榨頂級橄欖油醃一小時，以文火慢烤翻面至全熟即可大快剁飴。
&nbsp;
三.&nbsp; 炭烤PRIME級沙朗牛排
&nbsp;
作法：
&nbsp;
頂級牛肉只吃原味，料理方式只要忠實呈現肉質鮮美就好，以粗鹽和黑胡椒在文火(千萬別大火烤黑)條件下邊灑邊烘烤，五分熟最美味，如何判斷呢？豎起大拇指繃緊肉墊是七分熟，放鬆後自己試著觸碰軟硬，那觸感就是五分熟，很簡單的。
&nbsp;
四.&nbsp; 孜然羊肉串
&nbsp;
作法：
&nbsp;
孜然是新疆烤肉的絕妙滋味，灌著啤酒吃過一回就忘不了，孜然粉現在賣場都有，選用紐澳羊肉火鍋片(肥一點也行)捲成一卷，五卷一串，若要飾以青蔥也行，邊烤邊灑酌量孜然，你一定要看著守著點唷，不然一會兒就會被搶光了。
&nbsp;
五.&nbsp; 法式芥茉羊小排
&nbsp;
作法：
&nbsp;
最好選用紐西蘭六個月以下小羔羊排，但別用羊肩排，因為法式羊小排口感細緻多了，同樣地先用義大利香料橄欖油蒜片醃一小時，文火烤至五分熟時抹上芥茉子醬再烤五分鐘，離火靜置十分鐘再切片，這樣就不會出血水，切出來的小羊排粉嫩juicy，沾著酸甜薄荷醬，哇！真是美味！這可是我的招牌菜，至於薄荷醬怎麼做？就等你留言回文囉！
&nbsp;
六.&nbsp; 楓糖培根蘆筍卷
&nbsp;
作法：

不妨用進口蘆筍，較粗大口感也好，一根蘆筍裹一片培根，再用半截牙籤扎緊烤幾分鐘就可吃，一般培根也行，不過我個人偏好帶點楓糖味兒的培根，甜滋滋加上青綠蘆筍，色美香氣足，小朋友大人都愛吃。
&nbsp;
七.&nbsp; 蘋果薑汁豬肋排
&nbsp;
作法：
&nbsp;
豬肋排要整塊的，傳統市場不好買，建議去好市多賣場選購，回來先整理川燙至五分熟再料理，不然不易烤好，畢竟戶外烤肉不是家裡專業烤箱，溫度不平均想烤得漂亮是挑戰，豬肋排瀝乾後，再以蘋果、嫩薑打成泥與烤肉醬(不要太鹹的)充分調合成醃漬豬肋排的醬汁，最好一晚讓肋排入味，隔天趴踢再用餘火慢烤，這可急不得，最後的美食會讓你大呼值得。
&nbsp;
八.&nbsp; 蒜醉鮮蝦
&nbsp;
作法：
&nbsp;
準備一個可密封的鋁箔烤皿(超市都有賣)，蝦子只要夠新鮮都可以，美洲白蝦、劍蝦、斑節蝦無一不可，但我習慣用白蝦，肉厚實有彈性蝦膏也多，蝦洗淨帶殼不用挖泥腸，加蒜末拌勻加米酒、鹽巴調合密封烘烤廿來分鐘就好了，上菜開封前再以蔥末攪伴，鮮紅的白蝦和著酒香蝦膏，讓人聞了也醉！
&nbsp;
九.&nbsp; 香草鮭魚
&nbsp;
作法：
&nbsp;
若預算充足，就買一整條鮭魚吧！會讓整個烤肉宴豪氣十足，身為主人也很體面；鮭魚洗淨剖肚後放在一大片鋁箔上，要確認不會在燒烤中破掉，將一把香茅、幾束百里香和奧勒崗、幾片檸檬(可以多一些)加上幾顆去皮蒜頭塞滿鮭肚，外層抹一層薄鹽再覆蓋二、三束蒔蘿後，淋上一些橄欖油和一杯微甜白酒，接著再以鋁箔裹緊密封烘烤約一小時，整條魚開封上菜，誰還能坐得住？
&nbsp;
十.&nbsp; 奶油螃蟹
&nbsp;
作法：
&nbsp;
奶油螃蟹是基隆廟口夜市遠近馳名小吃，也很容易料理，把梭子蟹(俗稱三點蟹)掰開將兩邊鰓肺去除洗淨，放在已鋪好一層和著無鹽奶油洋蔥絲的圓型鋁箔烤皿中，淋上適量米酒密封燒烤，洋蔥烤後伴隨蟹黃酒香滿溢，讓人陶醉！
&nbsp;
十一.蒜悶圓鱈
&nbsp;
作法：
&nbsp;
圓鱈算是相當高檔的食材(好市多有賣)品質較讓人放心，比一般的鱈魚肉質來得結實有彈性，濃郁鮮甜令人垂涎，做法也儘量呈現原味最好，灑一層椒鹽鋪上適量蒜末放在鋁箔烤皿烘烤半小時，你會知道為什麼圓鱈會如此美味！
&nbsp;
十二.鹽烤明蝦
&nbsp;
作法：
&nbsp;
這是每年都有的大菜，不過成本太高，通常只有大人一人一隻，小孩就唬弄過去！料理很簡單，先將明蝦去筋好讓蝦能攤平，抹一層鹽巴(可以厚一點溫度會均勻一些)，烤熟後撢開鹽巴，吃蝦時要不要淋一些檸檬汁提味，就看個人口味了！
&nbsp;
&nbsp;
青菜：青菜原則上都隔著鋁箔燒烤比較不會讓青菜原味流失
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 可以視青菜種類包覆悶烤或直烤
&nbsp;
一.養生百菇
&nbsp;
作法：
&nbsp;
只要是菇類，個人覺得怎麼料理都好吃，鴻喜菇、杏苞菇、金針菇、新鮮香菇要單烤混著料理都可以，原則上不添加多餘調味料和油，灑一些椒鹽密封烘烤，自然會出水，野味香氣令人神神一振！
&nbsp;
二.海瓜子絲瓜
&nbsp;
作法：
&nbsp;
這道菜在烤肉趴算是大眾菜，也可以用蛤蜊代替，不過我喜歡吃海瓜子，準備烤皿絲瓜切片嫩薑切絲和海瓜子調合後密封燒烤，先吃原味，因為海瓜子本身有鹹味，不夠時再調整。
&nbsp;
三.悶烤洋蔥
&nbsp;
作法：
&nbsp;
烤洋蔥有幾種方式簡單容易，紫洋蔥別剝皮以鋁箔裹緊整個丟下碳火烤半小時，就是這麼豪邁，吃得時候再去除外皮，裡頭洋鬆軟味甜；另一種是將洋蔥切約0.5公分厚，鋪在烤皿中灑些鹽，淋一些初榨橄欖油和水，再灑適量巴西利，密封烤軟也好吃！
&nbsp;
四.高麗菜芯
&nbsp;
作法：
&nbsp;
高麗菜芯清脆味甜，就別用油了，灑些鹽調味，一小棵一小棵菜心並列烤皿密封烤熟，口感清爽解膩。
&nbsp;
五.碳烤甜玉米筊白筍
&nbsp;
作法：
&nbsp;
我習慣不剝皮直火烤，不過得耐心點，慢工出細活，烤好的甜玉米筊白筍也漂亮。
&nbsp;
六.南瓜、地瓜片
&nbsp;
作法：
&nbsp;
南瓜就帶皮切片烤，地瓜要用紅心紫心或黃肉都好吃，切片或整個烤就看自己了，原則上地瓜我會交給小朋友玩一玩！
&nbsp;
七.蘿蔓生菜
&nbsp;
作法：
&nbsp;
美國蘿蔓生菜我幾乎每天都吃，好市多賣得多，可淋上油醋醬或凱薩沙拉醬，若用凱薩沙拉醬再灑上適量的帕瑪森起司伴勻，並裝飾一些麵包塊！
&nbsp;
八.水果沙拉
&nbsp;
作法：
&nbsp;
其實水果沙拉不做也行，單吃水果最棒，不過這個醬汁太迷人，想介紹給好友知道；準備品質不錯的蘋果、酪梨或水梨、香瓜和甜桃，若常去好市多賣場也可以添加綜合莓類(覆盆子、藍莓，小紅莓、蔓越莓等)，伴勻後先冰鎮擺著；接著製作醬汁(當然要先調製好)，準備無糖優格、純柳橙汁和一些薄荷醬，灑一些巴西利以調理機打勻後就完成，想甜一些就以蜂蜜調味，這沙拉醬汁我自創，還沒看過不喜歡吃的朋友。
&nbsp;
飲料：
&nbsp;
綠茶、純果汁、黑麥汁、可樂是一定要的啦
台灣純麥啤酒Mine、麥格黑啤酒、德國莫絲蘭微甜白酒、
法國A.O.C.波爾多紅酒，更是歡樂助興的佳釀
