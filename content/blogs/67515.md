有一個人 &nbsp; 你會很想每晚對他說 晚安

有一個人 他不會主動和你聊天 但你會忍不住想和他聊天

&nbsp;

有一個人 你一上線就會去看他在不在

不在就一陣失落 在～又不敢打擾他

&nbsp;

有一個人 他的狀態簽名只要一換 你立刻胡思亂想 揣測不安

&nbsp;

有一個人 你在線只是在等他

&nbsp;

有一個人 你總是忍不住去看他的空間

即使他什麼新鮮事都沒有

&nbsp;

有一個人 你會看他的最近來訪和留言

然後又胡思亂想 揣測不安

&nbsp;

有一個人 你一直在等他

他卻忘記了你

&nbsp;

有一個人 你真的好愛他

可是仔細一想 你愛他什麼

愛他的壞？

&nbsp;

有一個人 你以為他是你的永遠

但是他卻告訴你 你只是他的過客

&nbsp;

有一個人 你真的可以對他無條件付出

他卻不稀罕 對他來說 你只是負擔

&nbsp;

有一個人 你那麼那麼捨不得

他卻那麼隨意 灑脫 不在乎

&nbsp;

有一個人 教會你怎麼去愛了

但是 他卻不愛你了

&nbsp;

有一個人 你總說要放下他

卻總是忍不住又拿回來回味

&nbsp;

有一個人 你真的好想他快樂

所以你寧願自己不快樂

&nbsp;

有一個人 離開他的時候你笑了

但是一轉身 早已淚流滿面

&nbsp;

有一個人 你好想大聲告訴他

我真的好後悔愛上你了

因為 你發現 你真的 是真的愛他

但是他不愛你了 這就是事實

&nbsp;

&nbsp;

那個驕傲的你去哪裡了？
