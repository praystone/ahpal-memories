&nbsp;

異地戀。

&nbsp;

無可否認是困難的。

&nbsp;

&nbsp;

人人都說，只要一直愛著對方就能繼續下去。

&nbsp;

眼看身邊跟遙遠的另一半分離了的朋友，我質疑愛到底能夠堅定多久？

&nbsp;

起初拼死相愛的決心和熱戀總會慢慢淡去，

那時候堅持下去的可能只有一方，可能雙方亦隨意地讓感情凋謝。

&nbsp;

能夠維持的一對有幾多？

&nbsp;

這就是最讓人害怕的事。

&nbsp;

另結新歡，時差和聯絡不上只是次要。

&nbsp;

真正讓人害怕的是下次見面的時候感情已大不如前，

害怕自己一直努力撐下去後，發覺對方早已放棄了。

&nbsp;

等待總是難熬的，但知道對方亦同樣地想念你，

其實是很幸福，很幸福的。

&nbsp;

有多少人會時刻地想著你？

&nbsp;

他是我苦中的一點甜。

&nbsp;

&nbsp;

異地戀的問題也會發生在身處同地的情侶身上，

&nbsp;

即使在同一個地方，能日夜相見，

亦不代表沒有感情的危機和問題。

&nbsp;

對我而言，異地戀有一個好處，

它讓人更懂得珍惜對方，珍惜每一次見面的時間。

&nbsp;

因為那些人都明白有些事得來不易。

&nbsp;

此刻坐在窗前，仰望著漆黑一片的天空，我在等待一架飛機飛過。

&nbsp;

我對自己說，別傻了，由我房間看出去，從來都沒有飛機出現。

&nbsp;

從前沒有，今夜沒有，只要一天是住在這屋都不會有。

&nbsp;

或許我只是在等待與你最後一個檫身而過的機會，就是這樣單純。

&nbsp;

每當我盼望著什麼的時候，總是變得像小孩般的單純。

&nbsp;

在小孩子的角度來看，沒有什麼是沒可能的，沒有事是絕對的。

&nbsp;

譬如說，你乘坐的航班會突然更改路線，然後飛過我房間對出的上空。

&nbsp;

這時候你應該在機場重複做著你不耐煩的事，

排隊check-in，把行李寄艙，等候登機，

再看那段你能背出來的教你如何逃生的短片。

&nbsp;

而我亦會繼續像從前一樣，等待你每一次的歸來。

&nbsp;

然後在機上空中小姐會跟你說:「先生，請你關掉你的電子通訊儀器。」

&nbsp;

在這之前，你會致電給我，跟我說句I miss you，到達後再聯絡我。

&nbsp;

我知道我掛線後會忍不住哭起來，但我會在電話裡笑著跟你說:「我等你。」

&nbsp;

一句我等你不單止需要勇氣，還證明了在我心中留給了你一個重要的位置。

&nbsp;

雖然我看不清前路，但我會為你睜開眼睛一步一步地走下去。

&nbsp;

SAFE FLIGHT,I MISS YOU.
