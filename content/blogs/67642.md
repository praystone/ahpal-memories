人終要長大的。換言之，是自己慢慢學著長大。

&nbsp;

在人生的道上一步一個腳印，或深或淺記錄著蕓蕓眾生成長的深度。

&nbsp;

成長越慢的人往往受得傷就會越多，

&nbsp;

面對種種傷痕我們要做的不僅僅是承受，更多的是要感恩。

&nbsp;

感謝那些讓你受傷的事情，忘記那些讓你受傷的人，

&nbsp;

傷害也許是無意的，成長卻是必須的。

&nbsp;

&nbsp;

1.當你發現自己不再盲目的喜歡跟風似的和一群人混在一起，

&nbsp;

&nbsp; &nbsp;開始尊重自己的意願做自己需要做的事情，開始安排自己的種種計劃，

&nbsp;

&nbsp; &nbsp;規劃自己的方向，自己的獨處也變得充滿意義。

&nbsp;

2.當你面對很多選擇時，不再猶豫不定，

&nbsp;

&nbsp; &nbsp;腦中會很快得閃過三個以上選擇某種選項的必要原因。

&nbsp;

&nbsp; &nbsp;有了自己獨立的思想，開始學著鎮定理性得思考問題。

&nbsp;

3.當你開始覺得時間明顯得不夠用，漸漸的覺得睡懶覺，

&nbsp;

&nbsp; &nbsp;逛街等是相當浪費時間金錢的事情，思想與行動上的時間概念達成了一致，

&nbsp;

&nbsp; &nbsp;合理的安排時間，充實的生活會把自己帶入一個更喜歡的世界。

&nbsp;

4.當你在上網或閱讀時，會把側重點從一味的關註娛樂雜談轉移到新聞國事，

&nbsp;

&nbsp; &nbsp;經濟發展趨勢的版圖，娛樂雜談永遠是用來開懷大笑的，

&nbsp;

&nbsp; &nbsp;而新聞國事則是提高個人認知程度關心國家發展以及愛國的表現，

&nbsp;

&nbsp; &nbsp;開放的心靈開放的國度，互通有無，共同進步，閉關鎖國萬萬不得已，

&nbsp;

&nbsp; &nbsp;經濟發展趨勢往往會影響人們囊中銀子的分量。

&nbsp;

5.當你在飲食習慣上越來越重視食物的質量，

&nbsp;

&nbsp;&nbsp; 養生之道的念頭闖入腦海，學著堅持吃早餐，

&nbsp;

&nbsp; &nbsp;每天堅持鍛煉身體。俗話說得好，留在青山在，

&nbsp;

&nbsp;&nbsp; 不怕沒柴燒。這個道理無人不知曉吧。

&nbsp;

6.當你再次被人問到愛情，友情，親情三者的分量時。

&nbsp;

&nbsp; &nbsp;首先想到的應該是家中的父母，血濃於水是千古不變的真理。

&nbsp;

7.當你再遇到不順心的事情時不再是用哭鬧來解決問題，

&nbsp;

&nbsp;&nbsp; 眼淚能沖刷的永遠是面容，能改變現狀的只有行動。

&nbsp;

8.重視自己的朋友，愛人。

&nbsp;

&nbsp;&nbsp; 因為這些人不是總會存在你的生命中的，

&nbsp;

&nbsp;&nbsp; 也許在不輕易間就物是人非了。在他們面前你無需作假，

&nbsp;

&nbsp;&nbsp; 天真無瑕的自己在這個大千世界裏是為他們上演的。切忌不要忘了真誠。

&nbsp;

9.讓自己快樂，讓周圍的人快樂。絕對比金錢有價值。

&nbsp;

10.在面對得與失，去與留的問題上，

&nbsp;

&nbsp;&nbsp;&nbsp; 大度與開懷會讓復雜的事情變得簡單，簡單的事情變得富有意義。

&nbsp;

11.任何時候不要與老人與小孩子計較，

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; 生命的開始是無知的，生命的完結應該快樂的。

&nbsp;

12.學著尊重每個人每個生物，就如向日葵喜歡面對太陽才會微笑。

&nbsp;

13.心態，健全平和的心態是始終貫穿成功之路的籌碼。

&nbsp;

&nbsp;&nbsp;&nbsp; 正確地樹立前進的目標，讓生活目標而不是在沈重氛圍的度過，

&nbsp;

&nbsp;&nbsp;&nbsp; 記住，任何時候都不要把自己搞得太累，生活的價值就完全失去了。

&nbsp;

14.自信的生活，開心的笑，成功與快樂並駕齊驅。不以物喜，不以己悲。

&nbsp;

15.淡忘仇恨，春暖花開。心有多大，舞臺就有多大。

&nbsp;
