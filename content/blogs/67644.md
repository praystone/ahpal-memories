27日因中颱南瑪都的原故在公司忙碌中勉強的渡過這一天一夜


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


28日一早拖著疲憊的身心下班返家


&nbsp;


懸著一顆不安的心先前往父母居所


&nbsp;


幫其視察遭豪雨凌虐一天的排水系統是否因此而阻塞當機


&nbsp;


慶幸的事是天空雖被厚厚的雲層沈悶的堆疊著，但並未因此而下雨


&nbsp;


安心而大膽的由下往上的逐層檢視著排水口


&nbsp;


看著許許多多不請自來來此作客的竹片、綠葉輕輕著在排水旁玩起疊羅漢


&nbsp;


當然我也只能很禮貌性的慢慢請其集中在一處所


&nbsp;


等待著回歸大自然當作有機分解物囉


&nbsp;


忘情著逐一拜訪至二樓後陽台的排水口


&nbsp;


半蹲著玩起淤泥清除工作


&nbsp;


此時身後傳來一聲巨響〝碰〞


&nbsp;


驚訝的徐徐轉回頭


&nbsp;


哈哈哈，我被關在門外了


&nbsp;


此時也只能冷靜下來用心電感應找尋可幫忙之人的位置


&nbsp;


除了年邁雙親除外


&nbsp;


尚有一位鄰居阿桑在家作客


&nbsp;


千里傳音此時自然起了它的作用


&nbsp;


心中不僅寛慰了不少


&nbsp;


家裡來了這位救星真好


&nbsp;


此時心中默然的感謝老天我還真是有福報之人


&nbsp;


不然還真不知怎從這五米高的二樓安然離去


&nbsp;


就在這位熱心而我心目中偉大的救命天神阿桑


&nbsp;


忙了十餘分鐘外加漸漸的風強雨急之下


&nbsp;


門依然如故著不動著，僅不間斷的傳來努力的開門聲


&nbsp;


突然覺得好像被關進保險櫃的感覺


&nbsp;


我是珠寶還是黃金啊？


&nbsp;


我著實瞬間失去了希望


&nbsp;


想請其幫忙連絡人民救星-消防局


&nbsp;


但為免增加其勤務負擔(其實怕被笑啦)還是作罷


&nbsp;


只能在心裡做了此生至今最大的一個決定


&nbsp;


衡量著週邊最柔軟的草地


&nbsp;


評估實際的高度


&nbsp;


減去自身拉掛的高度


&nbsp;


嗯


&nbsp;


似乎可行


&nbsp;


為免最後成了落湯雞而省去熬雞湯的時間


&nbsp;


躊躇而勇敢的跨出第一步


&nbsp;


果然就回不了頭了


&nbsp;


哇！


&nbsp;


後悔了


&nbsp;


挺高的


&nbsp;


但經歷練了一天一夜的工作淬練


&nbsp;


實在巳無餘力在回溯而上


&nbsp;


為免自由落體


&nbsp;


只能兩眼一閉、雙手一放、兩腳往後一蹭


&nbsp;


真的


&nbsp;


經歷分享一下


&nbsp;


不到一秒就著地並差點五體投地^^


&nbsp;


不過


&nbsp;


雖然落地姿勢沒有一百分，少說應該也有七十分吧


&nbsp;


哈哈哈


&nbsp;


還安然無漾的活著哦


&nbsp;


趕緊出現在2樓阿桑的身後


&nbsp;


請其不必再開門，並感謝她的好意，雖然她手上還拿著撬門的工具


&nbsp;


阿桑一臉茫然疑惑的問我怎會出現在此


&nbsp;


我只能直言以告：我跳樓了^^


&nbsp;


好個南瑪都


&nbsp;


竟讓我以這個方式完成此生的跳樓儀式
