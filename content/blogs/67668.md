&nbsp;

&nbsp;




人生的幸福美滿其實就是一種感覺，一種心情。

&nbsp;


你是歡欣鼓舞、輕鬆快樂，還是孤獨苦悶、疲勞不堪，主要有心態來支配。

&nbsp;


我們必須學會經常讓心靈放個假，做到內心平衡安寧，才能感受到生活的輕鬆快樂和人生的

幸福美好。

&nbsp;


空虛憂鬱之時，給心靈放個假。在平淡的日子裏尋找不平淡的感覺，從沒意思的事情尋求出

它的有意思，打破現狀，超越寂寞、空虛和內在的貧乏，去體現生活的快樂和意義。

&nbsp;


失敗沮喪之時，給心靈放個假。不因一時的失敗而心灰意冷，用希望打開一條活路。精神是生命

的真正支柱，只要它不垮下，生命就不會變形。

&nbsp;


成功得意之時，給心靈放個假。頭腦要清醒，不盲目樂觀，不氣盛用事，不好大喜功，不滿足現狀，心中存有憂患意識，能清醒地看到還有很長的路要走。

&nbsp;


苦悶茫然之時，給心靈放個假。不因奔波、跌倒、無助而抱怨，不因往事而悔恨，不為未來的事情

而擔憂，不畏懼生活，敞開心靈，勇敢地面對一切。

&nbsp;


疲憊不堪之時，給心靈放個假。生活中不是只有打拼，還要有享受，不要只忙於事業，忙於掙錢，

忙得不顧命。累了就歇歇，做好自我調節，找到工作生活、事業家庭的平衡點。

&nbsp;


感情淡漠之時，給心靈放個假。時時用美麗友善的心感悟生命的真諦，人生的多彩，生活的幸福，

以及友情的可貴，用柔軟仁愛的心去善待身邊的每一個生靈。

&nbsp;


不幸降臨之時，給心靈放個假。生命需要錘煉才能飽滿厚重，從容地迎接命運的挑戰。辦法

總比困難多，諸多人生難題總能圓滿解答。

&nbsp;


生氣發怒之時，給心靈放個假。盡力克制自己，用冷靜澆滅心頭火，試著找出建設性的方法解決問題，用寬容對待傷害。人生苦短，沒有必要把自己的精力都消耗在小事上面。

&nbsp;


恐懼膽怯之時，給心靈放個假。人生難免經歷風雨，不能害怕壓力，不能逃避責任，勇敢地迎上去，戰勝它，自己就成了生活的主宰。

&nbsp;


執著出現之時，給心靈放個假。貪得者身富而心貧，知足者身貧而心富，在人生追求的過程當中，

淡泊明心，既不絕望於人生的苦，也不執著於人生的樂。

&nbsp;


我們每個人都可能遭受情場失意、官場失位、商場失利等諸多方面的打擊；還有幸福時的歡暢、

順利時的激動、委屈時的苦悶、挫折時的悲觀、選擇時的仿徨，這就是人生。

&nbsp;


人生就是一碗酸、甜、苦、辣、鹹五味俱全的湯，每種滋味你都可能品嘗，我們無法選擇，

只能調整心態去適應。

&nbsp;


人生一世，活的就是一種精神。我們要適時地給心靈放個假，擁有一副健康的身體養成一種良好

的心態，過著一種從容安適的生活。心靈安頓了.平衡了.豐盈了.我們的人生也就快樂了.美好了.無憾了。

&nbsp;


在自己心靈的港灣，穩穩地停靠一會兒。

&nbsp;


在自己心靈的驛站，靜靜地享受一會兒。

&nbsp;


在自己心靈的夜空，深深地凝望一會兒。

&nbsp;


在自己心靈的牧場，盡情地瀟灑一會兒。
