&nbsp;

&nbsp;

&nbsp;

我寫下 每天


&nbsp;


開始寫 什麼是思念


&nbsp;


就像詩篇


&nbsp;


並不能單方面的 了解


&nbsp;


習慣 溫柔的甜


&nbsp;


不是寂寞


&nbsp;


游移的雲 所能看見


&nbsp;


我只查到一個字 甜


&nbsp;


在確定


&nbsp;


愛上你的 那一天


&nbsp;


關於季節 它與思念


&nbsp;


站在 同一個畫面


&nbsp;


我翻閱 字典


&nbsp;


查詢所能 形容你的世界


&nbsp;


就像藍天


&nbsp;


沒辦法離開 陽光的體貼


&nbsp;


心字部 最美的那一面


&nbsp;


陶醉微醺的 臉


&nbsp;


不是孤單


&nbsp;


泅游的夜 所能了解


&nbsp;


我只看


&nbsp;


那兩個字 思念


&nbsp;


在確定


&nbsp;


握住你的 那一天


&nbsp;


我寫下 完美


&nbsp;


開始了解


&nbsp;


什麼是 纏綿


&nbsp;


字典裡頭


&nbsp;


清楚著 寫下


&nbsp;


我對你


&nbsp;


的


&nbsp;


每


&nbsp;


天
