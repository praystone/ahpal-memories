&nbsp;


&nbsp;





&nbsp;


&nbsp;


&nbsp;


一個人活在世上，都是需要愛人和被愛的。


&nbsp;


&nbsp;



我寧願相信，這是人類最基本的精神需求。


&nbsp;


&nbsp;



一畝心靈的良田，愛就是汩汩的清泉，有了它的


&nbsp;


&nbsp;


滋養，草木豐盛，鮮花綻放。


&nbsp;



而缺少了愛的澆灌，這畝良田會慢慢地乾涸、裂


&nbsp;


&nbsp;


縫，在烈日下伸展著光禿禿的無邊無際的孤獨。



&nbsp;


很多人永遠不知道什麽是愛，這與年齡無關，與


&nbsp;


&nbsp;


閱歷無關。



&nbsp;


&nbsp;


不管他多麽年長，不管他涉獵了多少異性，都只


&nbsp;


&nbsp;


是欲望的填充，得到的只是感官的刺激，內心空


&nbsp;


&nbsp;


空蕩蕩。



&nbsp;


&nbsp;


毋庸置疑，這樣的人活著，就像一具披著衣服的


&nbsp;


&nbsp;


空殼，可悲復可憐。



&nbsp;


&nbsp;


慶幸的是，這樣的人大多時候意識不到自己的愛


&nbsp;


&nbsp;


無能，他愛著自己，活在自己的世界裏自娛自


&nbsp;


&nbsp;


樂，不至於陷入痛苦的深淵。



&nbsp;


&nbsp;


一個不懂愛的人，也很難得到別人的愛。



&nbsp;


&nbsp;


即使他得到了世間最深厚、最純真的愛情，也會


&nbsp;


&nbsp;


在他的不珍惜裏隨風飄離。



&nbsp;


&nbsp;


畢竟，沒有人能忍受捧著自己熾熱的心，被冰冷


&nbsp;


&nbsp;


的利刃一次次割，一刀刀削。



&nbsp;


&nbsp;


愛，是心靈深處最柔軟、最深刻、最無私、最專


&nbsp;


&nbsp;


註的一種疼惜。



&nbsp;


&nbsp;


愛，其實一直都在，只不過因為我們步履匆匆、


&nbsp;


&nbsp;


心思易變而一次次錯過。



&nbsp;


&nbsp;


愛一個人，沒有理由，沒有借口，他會裝進你的


&nbsp;


&nbsp;


心裏，融化為你生命的一部分，時時為他著想，


&nbsp;


&nbsp;


刻刻為他擔憂，又怎麽捨得遠離、傷害？



&nbsp;


&nbsp;


愛一個人的時候，他的身影無時無刻不在你的腦


&nbsp;


&nbsp;


海，全是甜蜜；不愛的時候，他的影子偶爾翻過


&nbsp;


&nbsp;


你的記憶，只是過客。



&nbsp;


&nbsp;


愛一個人的時候，你會包容他所有的缺點，怎樣


&nbsp;


&nbsp;


都是可愛；不愛的時候，你會覺得他早已面目全


&nbsp;


&nbsp;


非，怎麽都是不堪。



&nbsp;


&nbsp;


愛一個人的時候，你眼裏心裏只有他，沒有人比


&nbsp;


&nbsp;


他更好；不愛的時候，才知道那是自己給自己編


&nbsp;


&nbsp;


織的童話。



&nbsp;


&nbsp;


我真的不願相信，隨著社會的發展，人類的進


&nbsp;


&nbsp;


步，物質越來越豐富，欲望越來越高漲，愛卻離


&nbsp;


&nbsp;


我們越來越遙遠。一個缺失了真愛的人類社會該


&nbsp;


&nbsp;


是怎樣的淒涼而悲哀？


&nbsp;


&nbsp;


&nbsp;
