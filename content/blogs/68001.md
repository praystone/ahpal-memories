人們所從事的善惡事業，都會給自己和親人造成很大影響人們所從事的善惡事業，都會給自己和親人造成很大影響

&nbsp; &nbsp; 一般世人所從事的事業，多數是善惡間雜的，不容易觀察，但只要觀察周圍那些善惡業比較純粹、明顯的家庭，或者瞭解一下歷史，就會發現，因果規律真實不虛。

&nbsp; &nbsp; 惡業者，教人學壞作惡，引人遠離諸善，誤人慧命者最重，其次是殺生，再其次是貪污、腐敗、偷盜、淫亂。善業者，教育人行善，啟發人善心智慧，以善法供養眾生功德最大，其次是救助生命（放生），再次是佈施。

&nbsp; &nbsp; 孔子創立儒家思想，董仲舒宣導儒家思想，利國利民，其子孫後代多為名門望族，至今受人尊敬。而情愛、造反、暴力小說著者，子孫多不吉祥，《紅樓夢》作者曹雪芹，中年喪子，自己也鬱鬱而終；《水滸傳》作者施耐庵，兒子、孫子、曾孫，生下來都是啞巴、殘疾。《西廂記》作者王實甫，自己嚼舌而死，《金瓶梅》作者笑笑生，子孫三代都是啞巴。

&nbsp; &nbsp; 批判封建禮教，卻不分青紅照白砸爛“孔家店”的新文化運動兩位旗手陳獨秀、胡適，各有兩個孩子先己而亡，顛倒黑白的《厚黑學》作者李宗吾，五十多歲即喪二子，自己也死於酗酒。

&nbsp; &nbsp; 教導人類“物種起源”，導致大批西方人放棄宗教信仰，而改信極端種族主義的大科學家達爾文，自己近親繁殖的10個孩子非死即病；希特勒的思想導師——尼采，得了精神分裂；誤導人類“性解放”的佛洛德，死於口腔癌。勞倫斯寫完《查泰萊夫人的情人》，第二年即早逝。

&nbsp; &nbsp; 這些名著都把“殺盜淫”看成是人的自然本性，對社幷會思想文化影響極壞，對社幷會的破壞性也極大，但至今仍是暢銷名著。所以，文人學者對社幷會的影響是很大的，千萬要自重，千萬要慎重。

&nbsp; &nbsp; 開國皇帝行善積德，能為子孫後代遺傳幾百年的江山大業，但子孫皇帝如果沉迷欲樂、喪失德行，不務朝政、荒淫無恥，濫殺無辜，致百姓于饑寒交困，慢慢就會把列祖先宗所累積的功德福報消耗殆盡，從而導致江山易主、朝代更替。

&nbsp; &nbsp; 從事純粹貪污事業、黑金交易、屠夫獵捕、色情業、詐騙、暴力、偷盜者們的兒女，或者是紈絝子弟、敗家子，或者容易遭意外橫事、得精神病，很少有成就出息的。

&nbsp; &nbsp; 父輩多惡少善，子輩挨餓，上不了學；父輩缺少功德，子輩畢業不好找工作，類似的例子就多了。

&nbsp; &nbsp; 佛教不是說自作自受嗎，怎麼還會連累親人呢？

&nbsp; &nbsp; 事實就沒有一個究竟不滅的“自我”，世界是普遍聯繫的，眾生是眾緣和合的，一切都是相互關聯的，具體因果關係極其複雜。自心是內因，對自身命運影響最大，其他影響都是外緣，外因都要通過內因而起作用，一念善即感召諸善緣來集，一念惡即感召諸惡緣來聚。所以，自作自受是最主要的因果關係，影響最大，其次是直系親屬間的相互影響，然後再影響其他人。所以，人造惡業，對直系親屬子女影響很大，一人造大惡，全家都受牽累。自己最親的親人遭現世報，也常常比自己受惡報更令人痛苦。

&nbsp; &nbsp; 在社幷會中做事也一樣，跟著仁王賢臣一起做官，跟著大慈善家一起做企業，大家都有功德貢獻，事業也蓬勃發展；跟著昏君、貪官一起共事，跟著奸商一起做買賣，只能得眼前利益，最終大家都一起倒楣而完蛋。

&nbsp; &nbsp; 世人總說因果不准，天地不公，主要是孤立、靜止、片面地看問題，只要把觀察的範圍擴大，把時間延長，就會發現天地間的因果規律非常明顯。常人是生活在迷中，普通人看不到前世來生，而因果報應卻不只是在一生體驗，常常報在後世。常人看不到，古今有許多大德之士能看到，把因果規律告訴世人，這是得到幸福遠離災禍的至寶啊！
