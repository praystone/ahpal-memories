師傅觀到的前因後果——深信因果老實念佛
提示：本文內容或許超出了您的認知範圍，請保持中立或謹慎地做出評論，以免給您造成潛在的不利影響，南無阿彌陀佛。

（1）曲折的婚姻

&nbsp; &nbsp; 李女士從江蘇打來電話，跟我談起她這輩子婚姻不順，為此專門找了會觀因果的師傅幫她看。關於她婚姻不順的原因，至少找到了七個，其中六個與她的前世有關，一個與她今世的父親有關。
&nbsp; &nbsp; 一、過去某生中，她是一名男子，家財萬貫。後來決定出家，妻子堅決不同意，他仍然拋下了妻子和三個孩子；
&nbsp; &nbsp; 二、過去某一生曾經是獵人，專門打鴿子、鴛鴦、天鵝等。打死了一隻，另一隻也殉情自殺了（這一行為也影響到了這一世她的眼睛，因為瞄準要睜一隻眼閉一隻眼，睜的那只眼這輩子就不太好）；
&nbsp; &nbsp; 三、過去某一世爬山的時候，喜歡把藤從樹上扯下來，拆散了樹和藤的親密關係；
&nbsp; &nbsp; 四、某一生，當時是個20多歲的女子，因為受了刺激，於是發了毒誓：生生世世不結婚！結果多少輩子以來都受這一毒誓的影響；
&nbsp; &nbsp; 五、曾經做過青樓女子，用情不專；
&nbsp; &nbsp; 六、曾經做過紈絝子弟，非常風流；
&nbsp; &nbsp; 七、跟這一輩子有關的原因是因為她父親曾經行為不檢點，結果影響到了她。
&nbsp; &nbsp; 李女士被師傅關照念誦《地藏經》多遍，同時真心懺悔自己的業障，結果婚姻境況改善了。她問我有沒有興趣把她真實的因果事例，乃至她的朋友們的真實因果事例寫下來，讓更多的人知道，避免大家再犯錯。我覺得很好，於是就有了這些文字。

（2）半身為什麼這麼沉？

&nbsp; &nbsp; 李女士一度左半身很重，右半身倒很靈活。去問因果，師傅告訴她七大原因：
&nbsp; &nbsp; 一、過去生曾經做過豬肉店老闆，沿著脊柱分割豬肉，然後冷凍（這輩子她就怕冷）；
&nbsp; &nbsp; 二、曾經有一世她是一頭黑熊，被獵人打死了。它的愛人，一隻大母熊抱著一隻很小很小的小熊殉情自殺了。這只母熊和小熊多少世以來都暗中跟著她。現在看到李女士婚姻好了就嫉妒，從中拆散，因為母熊希望和李女士在一起；
&nbsp; &nbsp; 三、曾經偷了人家一桶蛤蠣，背在了左邊；
&nbsp; &nbsp; 四、李女士還覺得左腳脖子有鏈子鎖著，師傅一看她的左腳脖子掛著一個魚簍，裏面一半是螃蟹，一半是蛤蠣。
&nbsp; &nbsp; 五、李女士覺得左腿有根繩子在往上拉，很不舒服。師傅看到她前世抓到一隻猴子，用繩子吊著猴子的一隻腳，不給吃喝，猴子後來餓死了。就此她念了10遍《地藏經》，把這個冤結解了；
&nbsp; &nbsp; 六、後來身體又覺得有點重，原來某一世她偷了人家八、九條槍背在了背上，還挖了個坑埋了進去，然後賣錢；
&nbsp; &nbsp; 七、曾經有一世養了一個寵物小熊。李女士要出遠門，但沒有把小熊託付給別人照看，結果小熊餓死了。
&nbsp; &nbsp;&nbsp;&nbsp;李女士在反復念誦《地藏經》多遍後，身體也就好了。（佛教不贊同養寵物，比如養了寵物要喂魚、蝦等活物，結果因此而殺生。或因為照顧不周結下怨恨。有些人買、領養寵物的時候稀奇得不得了，等到不想要的時候就把寵物送人，或者丟在外面不管它。結果寵物在外受凍受餓，或被人打死，因此而與主人及其他人等結下怨結。）

（3）尿毒癥、白血病是為什麼？

&nbsp; &nbsp; 李女士姐姐的兒子一直鼻炎，鼻子不通，常常流血。查過因果，說是前世曾朝某石頭撒尿，而此石頭正好附有鬼神精靈。你淋到人家，人家不高興了，結果報到這輩子來了。本來聽說在荒郊野外方便時要注意，事先要咳嗽或者拍手幾下，讓有關的無形眾生及早避讓，沒想到隨便在石頭上撒尿也不行啊。

&nbsp; &nbsp; 杭州某物-流-公司一員工，膀胱和腎盂之間的管道太窄，做過三次手術還不行。查過因果，是過去生曾經打獵，打到一隻白狐狸，正好打中人家腎臟；還曾經打過一條蟒蛇燉了吃了。……想想現在飯店吃蛇的風氣很盛。某人點了條蛇，服務員立即拎了個袋子來，打開袋子，問道：你看這條行吧？另外，還有吃猴腦，吃甲魚等，這些靈性特別高的動物吃了它們後果會很嚴重。當然，雞、鴨、魚、豬等所有的生命都不能吃。

&nbsp; &nbsp; 某男孩得了白血病，社幷會上捐了很多錢，並漸漸看好，後來又加重了。查過因果後，師傅沒把看到的內容直接告訴患者家屬，而是讓李女士轉告。說這戶人家前世是個詐騙集團，這輩子孩子生病就是報應，要搞得他傾家蕩產，也讓他們嘗嘗把人家搞得傾家蕩產是什麼滋味。問題是，這戶人家的詐騙習氣還在，還在還在寫文章到處募捐。看因果的師傅說了，毛病見好，得趕緊把多餘的錢捐出去，否則還是會復發。

&nbsp; &nbsp; 某人患了尿毒癥，而且腦子裏經常有污穢不堪的男女念頭產生。查過因果，說是他某生中是個郎中，專門販賣春藥。

&nbsp; &nbsp; 某女誦經時感覺很困難，但討論問題時卻思路清晰，不知道為什麼。查過因果，說她某一生曾經三、四個人一起，嘲笑人家出家人趕場做經懺賺錢，結果落得這一報應。也就是說，人家趕場做經懺有人家的因緣，不可嘲笑他人。嘲笑人家，就會被人家嘲笑。嘲笑人家誦經，結果自己就誦經困難；嘲笑人家長相不好，結果自己就長相不好。因果報應，從來不以人的意志而轉移。

&nbsp; &nbsp; 某男30多歲，生意做得很好，但婚姻就是不順，談過什麼女孩子都沒結果。原來，他曾經做過山大王，搶過八個女人，這一生，他至少要錯過八個女性，然後才有結婚的可能。

&nbsp; &nbsp; 如上這些案例，其當事人都被要求讀誦《地藏經》以求化解。

（4）兒子為什麼這麼笨？

&nbsp; &nbsp; 李女士覺得自家兒子很笨，想弄明白為什麼。師傅說，首先，你不能說兒子笨，只能說他厚道。要查原因，首先要查你們夫妻倆做了什麼，怎麼攤了這麼個兒子；然後，要看你兒子做了什麼。

&nbsp; &nbsp; 原來，李女士夫妻倆曾經有一世是朋友。一天，倆人帶了只猩猩，來到某三層樓高的山崖前。某甲說把猩猩扔下去看看要不要緊？猩猩掉下去，把腦袋摔壞了，某甲起了同情心，又把它領了回去。這個某甲就是你家先生，猩猩是你家兒子，你就是某甲的朋友——那個旁觀者。因為某甲是主謀，但也是他在關心猩猩，所以你兒子跟你老公關係就比較緊密，跟你就比較疏遠。李女士說對的是這樣的。觀因果的師傅讓李女士回去誦14遍《地藏經》，然後再看。誦完之後，發現倆人扔猩猩的圖像還在，說明業障還沒有完全清除。於是繼續誦，一直誦到看不到這一圖像。

&nbsp; &nbsp; 再查她兒子前世做了些什麼？原來，某一世他是一個非常漂亮的女演員，從20多歲一直到40多歲，演的都是刁鑽、狠毒、機關算盡的那類角色，演著演著，就深入骨髓，而且誤導了很多人……因此這一世就走向了聰明的反面。最近聽說某學生綁架案就是模仿了某電影，就不知道這些演員、導演、製片、發行人都會負怎樣的連帶責任了。從事娛樂、媒體報導、文字寫作等傳播面較大的行業的人應記住，您少穿了一件衣服，所說的一句不當的話，一個不乾淨的鏡頭等，都會給您帶來料想不到的災難。
