&nbsp;











&nbsp;


&nbsp;


&nbsp;


&nbsp; 


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;


&nbsp;


有一種距離是更加想念


&nbsp;


&nbsp;


&nbsp;


有一種思念是更加心碎


&nbsp;


&nbsp;


有一種淚水是靜靜的流淌


&nbsp;


&nbsp;


&nbsp;


還有一種心境是優郁的無奈


&nbsp;


&nbsp;


只因在心路上架起了一座真誠的橋樑


&nbsp;


&nbsp;


&nbsp;


在神奇的網線兩端


&nbsp;


&nbsp;


&nbsp;


一頭繫住你


&nbsp;


&nbsp;


&nbsp;


一頭牽住我


&nbsp;


&nbsp;


&nbsp;


也因一條長長的網線


&nbsp;


&nbsp;


&nbsp;


架起了緣份的橋樑


&nbsp;


&nbsp;


&nbsp;


架起了緣份的紅絲帶


&nbsp;


&nbsp;


&nbsp;


拉近了彼此間心的距離


&nbsp;


&nbsp;


&nbsp;


感受到


&nbsp;


&nbsp;


&nbsp;


彼此間身影親切的感覺


&nbsp;


&nbsp;


&nbsp;


路在我們的腳下慢慢延長
&nbsp;


&nbsp;


這長長的紅絲帶在我們心中也拉的好緊


&nbsp;


&nbsp;


&nbsp;


無論經過多少的寒冬都不願放手


&nbsp;


&nbsp;


&nbsp;


我只想一生把你放在心裏


&nbsp;


&nbsp;


&nbsp;


一生把你珍藏在我的心裏


&nbsp;


&nbsp;


&nbsp;


一生與你在現實的空間裏



&nbsp;


&nbsp;


共同享受著這世界上的幸福和快樂



&nbsp;


&nbsp;


共同分擔著彼此間的憂傷與痛苦



&nbsp;


&nbsp;


真的很感謝你就這樣一直靜靜的


&nbsp;


&nbsp;


&nbsp;


無怨無悔的守候在我身旁


&nbsp;


&nbsp;


&nbsp;


守住一顆沈睡多年的心


&nbsp;


&nbsp;


&nbsp;


守住一個歷經滄桑


&nbsp;


&nbsp;


&nbsp;


忘了自己年齡的身影



&nbsp;


&nbsp;


這顆心、這身影雖然算不上完美


&nbsp;


&nbsp;


&nbsp;


但它擁有自己的獨特


&nbsp;


&nbsp;


擁有自己的靈魂


&nbsp;


&nbsp;


擁有自己的思想


&nbsp;


&nbsp;


&nbsp;


擁有自己的……



&nbsp;


&nbsp;


不斷地感動


&nbsp;


&nbsp;


&nbsp;


不斷地甦醒


&nbsp;


&nbsp;


&nbsp;


不斷地擁有


&nbsp;


&nbsp;


&nbsp;


不斷地享受


&nbsp;


&nbsp;


&nbsp;


不斷地心碎


&nbsp;


&nbsp;


&nbsp;


不斷地快樂


&nbsp;


&nbsp;


&nbsp;


不斷地感受這一切你給的幸福與快樂


&nbsp;


&nbsp;


&nbsp;


享受一份關愛


&nbsp;


&nbsp;


&nbsp;


享受一份呵護


&nbsp;


&nbsp;


冰冷的心


&nbsp;


&nbsp;


寂寞的身影


&nbsp;


&nbsp;


從此失去了冰涼的溫度


&nbsp;


&nbsp;


&nbsp;


變成了柔柔的、纏綿的、甜甜的...


&nbsp;


&nbsp;


&nbsp;


那是一種快樂無比的幸福溫度



&nbsp;


&nbsp;


你就這樣像雨點一樣滋潤著我漸漸乾澀的心


&nbsp;


&nbsp;


&nbsp;


感覺有一種微微幸福的痛


&nbsp;


&nbsp;


&nbsp;


你給了我那麼多刻骨銘心的記憶


&nbsp;


&nbsp;


&nbsp;


你也給了我那麼多的感動


&nbsp;


&nbsp;


&nbsp;


可我卻沒能給過你什麼



&nbsp;


&nbsp;


風在水上寫詩


&nbsp;


&nbsp;


&nbsp;


雲在天空裏寫詩


&nbsp;


&nbsp;


&nbsp;


燈在書上寫詩


&nbsp;


&nbsp;


&nbsp;


微笑在你臉上寫詩


&nbsp;


&nbsp;


&nbsp;


你能看到我留在螢幕上的字


&nbsp;


&nbsp;


&nbsp;


卻看不到我落在鍵盤上的淚


&nbsp;


&nbsp;


&nbsp;


眼淚的滋味好像苦水


&nbsp;


&nbsp;


&nbsp;


我會記得你的好一輩子


&nbsp;


&nbsp;


&nbsp;


落下的淚滴是為了妳


&nbsp;


&nbsp;


&nbsp;


也為了我真的愛你
