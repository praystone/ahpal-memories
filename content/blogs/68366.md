&nbsp;







&nbsp;


因為不曾謀面，



&nbsp;


相互間沒有落差.



&nbsp;


沒有害羞.沒有尷尬；


&nbsp;


不必矜持，不必設防。


&nbsp;


如果心裏


&nbsp;


有不能說出卻只能埋在心底的話，


&nbsp;


有個知心網友傾訴，


&nbsp;


便可以盡情傾訴。


&nbsp;


這時，


&nbsp;


他仿佛成了這世界上


&nbsp;


最可以信賴最可以 親近的人。


&nbsp;


有個知心網友，真好! 


&nbsp;


也許永遠無須謀面，


&nbsp;


互相間就有了一種想了解的渴望，


&nbsp;


卻總朦朦朧朧的不能透明。


&nbsp;


不像朋友，交往幾次，


&nbsp;


熟了，互相看透了，就膩了。


&nbsp;


然而他的音容笑貌以想像的姿勢


&nbsp;


鮮活於互相的心裏夢裏，


&nbsp;


而想像的土地上永遠不生長俗品。


&nbsp;


有個知心網友，真好! 


&nbsp;


塵俗的欲念


&nbsp;


從指尖通過電腦過濾，


&nbsp;


穿越真實的萬水千山，


&nbsp;


在網路中擁抱，


&nbsp;


不穿衣服的靈魂可以無拘無束。


&nbsp;


互相間，索取的是心情，


&nbsp;


奉獻的 也是心情。


&nbsp;


在純潔的天宇中，


&nbsp;


精神的享受比物質真實比物質持久 。 


&nbsp;


有個知心網友，真好! 


被友情呼喚被心情滋潤，


&nbsp;


手中的鍵盤操練起來總是很容易投入。


&nbsp;


就會有意想不到的


&nbsp;


珍言珠語閃著光澤從心河汩汩湧出，


&nbsp;


給生活添幾分色彩,


&nbsp;


給季節增一分成熟。


&nbsp;


有個知心網友，真好! 


&nbsp;


他可以


&nbsp;


不必挑剔相貌和身高，


&nbsp;


可以不必挑剔權勢和貧富，


&nbsp;


甚 至，


&nbsp;


連年齡都可以不必挑剔。


&nbsp;


進入知心網友，


&nbsp;


就走出塵俗，走出虛偽，


&nbsp;


走向美麗，走向純樸，


&nbsp;


走向春天，走向成熟。


&nbsp;


知心網友是互相的陽光，


&nbsp;


知心網友是互相的雨水，


&nbsp;


知心網友是互相的長鞭， 


&nbsp;


知心網友是互相的海岸。 


&nbsp;


不是誰都能很容易走進


&nbsp;


知心網友享有知心網友的愜意。


&nbsp;


知心網友的紅繩是用


&nbsp;


知識、指力、真誠、涵養、韌力.....


&nbsp;


許多成分擰就的！


&nbsp;


知心網友的紅繩就在


&nbsp;


日子中慢慢結實起來的。


&nbsp;


好朋友為書，值得久讀。


&nbsp;


好朋友如酒，需要細品。


&nbsp;


好朋友乃天，一生所求。


&nbsp;


好朋友是詩，必須尋韻；


&nbsp;


擁有朋友，幸福永久。


&nbsp;


&nbsp;


朋友你有嗎？有個知心朋友，真好！
