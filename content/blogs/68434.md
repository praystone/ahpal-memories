&nbsp;



&nbsp;


天 涯 信 飄 渺


寸 心 難 逍 遙


敢 問 燕 歸 期


明 月 千 里 遙


&nbsp;


&nbsp;




&nbsp;




&nbsp;


想念妳


入夢尋倩影


海棠湘村覓靜居


冥空皎月撥白雲


天邊劃流星


！


&nbsp;


&nbsp;




&nbsp;




&nbsp;


看從前


素淡樸


身閒心靜平生足


&nbsp;


煙花謝


秋月獨


春風不皺心湖


&nbsp;


睹倩顏


羞月兔


朝思暮念繫囹圄


&nbsp;


紅鸞動


塵緣浮


一往情深追逐


&nbsp;


&nbsp;




&nbsp;




&nbsp;


我問嫦娥




人生匆匆，去日無蹤。


獨守月宮，誰能與共？


月娘問我


靜夜不眠，念念紅顏。


方寸心田，所為何緣？


我答月娘


但願日日月月年年！


嫦娥答我


千里嬋娟相思與共！


&nbsp;


&nbsp;




&nbsp;




今晚有點冷


走在街上默默無語


想念孩子也想念妳


對街公園裡


零星的夜燈散佈在迷宮狀的步道間


孤單的感情


較以往更為深切


鞦韆搖盪的嘻笑聲


喚回我的記憶童年


童年的身邊總是圍繞著街頭跟街尾的玩伴


如今只有佇立在身旁的零星夜燈


&nbsp;


不復往日舊情柔


片片落葉細說愁


&nbsp;


夜深


&nbsp;


風漸涼


&nbsp;




&nbsp;

&nbsp;



&nbsp;


 


&nbsp;


灰濛天空


鐵鳥疾鳴


多少旅人越山陵


離愁漸遠漸深濃


相思綿綿秋水瞳


海棠寄情


晚風催盅


摘星攀雲醉月宮


洞庭湖外春江窄


佳人更在春江外
