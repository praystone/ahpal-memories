&nbsp;

&nbsp;

花季到了　等待燦爛 


&nbsp;

&nbsp;

牽手一起面對勇敢 


&nbsp;

&nbsp;

淚流過了會乾 心痛過了會習慣 


&nbsp;

&nbsp;

花季未了　感情圓滿 


&nbsp;

&nbsp;

我們互相取暖 


&nbsp;

&nbsp;

有心事我和你彼此分攤 


&nbsp;

&nbsp;

沒有你生命少一半 


&nbsp;

&nbsp;

經過的挫折　並不悲傷 


&nbsp;

&nbsp;

從坎坷到平淡 你是我幸福的開關 


&nbsp;

&nbsp;

這世界有你陪伴 任何事都變簡單 


&nbsp;

&nbsp;

終於知道我並不孤單 


&nbsp;

&nbsp;

這一路有你陪伴﻿ 感動就永遠收不完 


&nbsp;

&nbsp;

終於懂得怎麼辦 


&nbsp;

&nbsp;

這世界有你陪伴 還會有什麼遺憾

&nbsp;

你的喜怒哀樂　我保管 


&nbsp;

&nbsp;

這一路有你陪伴 就不怕要轉幾個彎

&nbsp;
