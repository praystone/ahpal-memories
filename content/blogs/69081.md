有事做的時候我們把忙碌當作累，


&nbsp;



沒事做的時候我們卻把放鬆當作無聊。


&nbsp;



我們總喜歡去驗證別人對我們許下的諾言，


&nbsp;



卻很少去驗證自己給自己許下的諾言。


&nbsp;



走向最遠的方向——哪怕前路迷茫；


&nbsp;


抱著最大的希望——哪怕山窮水盡；


&nbsp;


堅持最強的意志——哪怕刀山火海；


&nbsp;


做好最壞的打算——哪怕從頭再來。


&nbsp;



有人認為這個世界太現實，


&nbsp;


現實得在你最需要幫助的時候沒有人幫助你；


&nbsp;


也有人認為這個世界太虛偽，


&nbsp;


虛偽的在你最需要幫助的時候，


&nbsp;


那些平常“想”幫助你的人都已煙消雲散。 


&nbsp;



今天我發現：


&nbsp;


為什麼我們總是覺得痛苦大於快樂；


&nbsp;


憂傷大於歡喜；悲哀大於幸福。


&nbsp;



原來是因為我們總是


&nbsp;



把不屬於痛苦的東西當作痛苦；


&nbsp;


把不屬於憂傷的東西當作憂傷；


&nbsp;


把不屬於悲哀的東西當作悲哀；


&nbsp;



而把原本該屬於快樂、歡喜、幸福的東西看得很平淡，


&nbsp;


沒有把他們當作真正的快樂、歡喜和幸福。 


&nbsp;



&nbsp;


我不能隨波浮沉，


&nbsp;


為了我至愛的親人，


&nbsp;


再苦再難也要堅強。


&nbsp;


只為那些期待眼神。


&nbsp;


心若在夢就在，


&nbsp;


天地之間還有真愛，


&nbsp;


看成敗人生豪邁，


&nbsp;


只不過是從頭再來。


&nbsp;


&nbsp;


&nbsp;



當我生病時，我發現健康是最重要的；


&nbsp;


當我傷心時，我發現快樂是最重要的；


&nbsp;


當我失戀時，我發現戀愛是最重要的；


&nbsp;


當我窮困時，我發現金錢是最重要的；


&nbsp;


當我飢餓時，我發現溫飽是最重要的；


&nbsp;


當我沮喪時，我發現信心是最重要的；


&nbsp;


當我離開人世時，我發現時間是最重要的。


&nbsp;


&nbsp;



然而，當我不在人世時，


&nbsp;


卻發現什麼都很重要，什麼都不重要。


&nbsp;


-----到底什麼是重要的，什麼是想要的呢。
