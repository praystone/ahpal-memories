看著你，仔細的看著你


&nbsp;


&nbsp;


&nbsp;


在你深邃迷人的眼眸中

&nbsp;

&nbsp;


&nbsp;


為什麼?

&nbsp;


&nbsp;

&nbsp;

&nbsp;


走在鋼索的兩端

&nbsp;


&nbsp;


你和我必須共同攜手走過


&nbsp;


&nbsp;


&nbsp;


若是你站在原地不動


&nbsp;


&nbsp;


&nbsp;


讓我獨自一個人

&nbsp;


&nbsp;


我可能會摔得粉身碎骨

&nbsp;


&nbsp;


不是依賴，而是信任

&nbsp;


&nbsp;


若沒共識

&nbsp;


&nbsp;


這感情

&nbsp;

是否還走得下去

&nbsp;


不要想得太複雜

&nbsp;
