求偶？


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


&nbsp;


因事在鄉間小路的歸途上


&nbsp;


騎著我的萬年老（里）鐵馬


&nbsp;


舒服著享受著夕陽歸山的彩氛


&nbsp;


及不間斷迎面而來的神風特攻小飛蚊


&nbsp;


打的我安全面罩霹靂拍拍的作響


&nbsp;


不過總是有成功的<?xml:namespace prefix = st1 ns = "urn:schemas-microsoft-com:office:smarttags" />一兩隻技術不好的徧離航道


&nbsp;


往我的頸部突破而入


&nbsp;


讓我超凡穩定的水平續航力瞬間出現了亂流


&nbsp;


而出現了左右搖擺的現象


&nbsp;


真不知它們想幹嗎！？


&nbsp;


就這樣在推行至一個90度的大轉道時


&nbsp;


正要高興我又一次成功的挑戰高難度技術突破時


&nbsp;


彎道的盡頭在眼前瞬間出現了一部自小客車！


&nbsp;


而讓我捏把冷汗的並不是那部小客車！？


&nbsp;


而巳一隻視死如歸的鴿子


&nbsp;


如泰山五嶽般靜靜不動如山的擋在車前頭


&nbsp;


在我滑行偏閃而過時


&nbsp;


還是忍不住的回頭望了一眼這隻偉大的鴿子下場！


&nbsp;


沒想到對恃許久後


&nbsp;


龐然大物的香檳自小客車自行退縮了


&nbsp;


乖乖的緩慢倒車繞道而前行（真是好笑^^）


&nbsp;


真是一隻偉大的動物讓我肅然起立！


&nbsp;


為免夜幕低垂外加某位駕駛萬花筒般的眼晴


&nbsp;


令這位不知天高地厚的小動物突然閤眼


&nbsp;


莫名直線上昇至天堂世界


&nbsp;


我還是摸摸鼻子的自認倒楣的趨前將其小心撈起


&nbsp;


小心翼翼的置入前方的置物架


&nbsp;


以徐徐的速度返家


&nbsp;


雖不敢說能讓其得到醫療專業級或五星級飯店般的呵護與照顧


&nbsp;


但免其夜宿街頭或荒山野嶺的能耐總是有的


&nbsp;


此時的內心的心情甚是愉快


&nbsp;


況且看著它莫名的在置物架內自轉圓圈繞行及跳上跳下的怪異舉動


&nbsp;


雖怕其一不甚摔落路面受傷一顆總是忐忑不安的持續著


&nbsp;


但看著這不解的動作


&nbsp;


不是一般初見面的動物會驚怕的舉動


&nbsp;


內心不僅放心不少


&nbsp;


也真是愉快及心花怒放無比（我很有親和力哦^-^）


&nbsp;


還真是有點飄飄然哩（呵呵呵）


&nbsp;


回到家迅速的將其安頓一下


&nbsp;


撥個知識電話問一下懂鴿友人討教一下飼養初步技巧


&nbsp;


也順道問一下轉圈等等的舉動


&nbsp;


哈哈哈


&nbsp;


我哩！！！！！


&nbsp;


不問還好！？


&nbsp;


一問還讓我不知所以然？


&nbsp;


原來那些動作是求偶的動作！！！！！！！！！！！！！！？？？？？？？


&nbsp;


況且這隻鴿子還是雌性的……………………….！
