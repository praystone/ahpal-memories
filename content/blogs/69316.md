&nbsp;

&nbsp;

左手親情 右手愛情

&nbsp;



&nbsp;

&nbsp;


親情的信念，
&nbsp;
是回憶裏不可或缺的給予自己安慰的良藥。
&nbsp;
有人說過：家，
&nbsp;
就是一個人無論走多遠都回順著腳印找回去的地方；
&nbsp;
家，就是一顆心無論飄多遠，都會留戀張望的地方。
&nbsp;
當脆弱的心再也經受不起,太多,太多,
&nbsp;
流離失所的折磨時，便會選擇最終的沈默。
&nbsp;


&nbsp;

這個時候，父母一句鼓勵的話語，
&nbsp;
也會讓我們在感慨萬千的同時心靈洗滌掉更多的寂寞。
&nbsp;
回過頭再次面對那些所謂的一無所有。


一個人不可能永遠的停留在父母的身邊，
&nbsp;
終有一天要離開父母，獨自到外面的世界裏體會百味人生，
&nbsp;
闖出屬於自己的一片天地。
&nbsp;


&nbsp;

而親人的關心卻是不可缺少的。
&nbsp;
它給予了我們心靈和靈魂上的更多更大的動力。


可是我們也很清楚的明白，
&nbsp;
在自己一天天長大成熟的時候，
&nbsp;
我們的父母卻在隨著歲月的滄桑而衰老。
&nbsp;
那些滿頭白髮的畫面又在我們生命過往中逐漸的定格。
&nbsp;
模糊了歲月的過眼煙雲，

&nbsp;

但是卻抹不掉那些龐大的記憶。
&nbsp;


也終會又那麼一天，他們會一一離開我們而去，
&nbsp;
因此，在生命的這些時刻，我們能做到的便是珍惜這一切。
&nbsp;


&nbsp;

眼淚不能夠代表什麼，

&nbsp;

這種情感的面前，它是那樣的軟弱。


每一個人一生中受這種關懷的時刻只是那些短暫的時間，
&nbsp;
不懂得去珍惜，便會留下所有的遺憾和後悔。
&nbsp;


而在我們繼續自己難過後悔的時候，
&nbsp;
時光就這樣的溜過，我們倉皇失措的背影。


&nbsp;

感謝他們給予了我生命，
&nbsp;
是他們讓我來到了這個千姿百態的世界上,
&nbsp;
感知怎樣去面對生活,面對未知的一切。


&nbsp;


&nbsp;

愛情？愛情是什麼？
&nbsp;
是風化了曾經的記憶裏不可磨滅的背影。
&nbsp;
那些在我們轉身離開哪個地方的背影是那樣的糾結。
&nbsp;
因為這，因為留念，才會想念，才會傷心欲絕，
&nbsp;
而當這一切離我們遠去時，

&nbsp;

能夠讓我們懷念的還會有什麼呢？？ 
&nbsp;
一恍惚，就一輩子。
&nbsp;


&nbsp;

那些熟悉而又陌生的音樂聽過一遍又一遍，
&nbsp;
可是，曾經有多麼的重要，
&nbsp;
我們卻再也找不到那些有開心笑臉的快樂時光。


也許應該感謝這些,在的生命裏出現過的,

&nbsp;

以及所喜歡過的人們，
&nbsp;
雖然每一次的喜歡最後的,結局卻是那樣的心疼。
&nbsp;


&nbsp;

有人說過：

&nbsp;

既然忘不了的事情,那就讓我們記住它好了。
&nbsp;
誠然,時光它徑自的走了，
&nbsp;
它不會因為我們哪一個人的難過而放慢腳步的。&nbsp;
&nbsp;


&nbsp;

當所有的屬於自己的疼痛喜歡和愛不在時，
&nbsp;
開始明白：愛情，不過是一場煙花盛世！ 
&nbsp;
每一個時刻，每一個地方都發生著一些事情，
&nbsp;
而我們所能夠做到的，便是勇敢的面對生活，
&nbsp;
面對自我，面對生活本身的一切。


&nbsp;



&nbsp;
