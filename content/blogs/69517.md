妳只用一根手指頭　就撐起　我整個宇宙

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

不到天的盡頭　不會懂擁抱的溫柔

&nbsp;

&nbsp;

&nbsp;

唯一　妳無法被代替

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

回頭　一路上看著妳

&nbsp;

&nbsp;

&nbsp;

牽著我　走過的足跡

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

除非我忘記了呼吸

&nbsp;

就算來不及告訴妳

聽海　都感動的窒息
