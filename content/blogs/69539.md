&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


有一種人，你想忘了，卻忘不了；<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


而有一種人，你不想忘了，卻忘了。



有一種人，你只能放在心裏，卻不能在你身邊；



而有一種人，只能在你身邊，卻不能放在心裏.



有一種人，你只能根植在記憶裏，但不會開花結果；



而有一種人，能夠開花結果，卻進不了你的記憶，


&nbsp;


你只能讓他（她）隨著歲月而去，隨著記憶而逝。



&nbsp;


&nbsp;


有一種人，


&nbsp;


他（她）信任你、接納你、關心你、


&nbsp;


理解你、在乎你、維護你、包容你、


&nbsp;


他（她）會為你毫無保留的付出，


&nbsp;


他（她）能分享你的快樂，承接你的痛苦。



你的冷暖他（她）記在心裏，


&nbsp;


你的安危他（她）放在心上，


&nbsp;


他（她）不允許別人


&nbsp;


對你有一絲一毫的侵犯、傷害、侮辱、中傷。



&nbsp;


&nbsp;


&nbsp;


因為真正的愛情，離不開默默地奉獻，


&nbsp;


精心地守護，是真心地給予真心地付出。



&nbsp;


&nbsp;


&nbsp;


有一種人，和你在一起的時候，


&nbsp;


他（她）能懂你的好、分享你的好、記住你的好；



不在一起的時候，他（她）會惦記你、想念你、牽掛你。



&nbsp;


因為真正的愛情，是一種發自內心地


&nbsp;


決意、體貼、思念、關心、照顧。



&nbsp;


&nbsp;


&nbsp;


有一種人，你和別的異性接近他（她）會嫉妒，


&nbsp;


因為真正的愛情，一定包含了自私和佔有。



他（她）的眼裏揉不進任何一粒沙子，


&nbsp;


那是因為真的在乎你，因為在乎你，


&nbsp;


才很難擁有所謂的“豁達”與“寬廣”的心胸。



&nbsp;


&nbsp;


每天我們都會遇到各式各樣，不同的人，


&nbsp;


他(她)們大都是匆匆過客，路過你的身邊，


&nbsp;


也許也會路過你的記憶，


&nbsp;


但是，只是路過，就像風一樣，風過無痕。



&nbsp;


&nbsp;


&nbsp;


可是，茫茫人海中總有一個人，他(她)曾經路過你的心，


&nbsp;


留下了永遠不能磨滅的腳印，深深的印在你的心頭，


&nbsp;


無論時光流逝，時空轉變，


&nbsp;


他(她)的腳步印不曾褪色，不曾消失。



&nbsp;


&nbsp;


&nbsp;


不要努力的忘記，那只會讓你的記憶更加深刻，


&nbsp;


既然他(她)曾經路過你的心，那就為他(她)留一片小小的空間，


&nbsp;


成為一份遙遠的回憶，一份甜美的回憶吧！



&nbsp;


&nbsp;


&nbsp;


曾經看到一句話：


&nbsp;


“人字，一個撇，一個捺，只有一個交點，


&nbsp;


就註定一生中只能為一個人停留。”


&nbsp;


一生中，也許真的只有一個人能路過你的心。



愛就像拔河，一個人放掉，另一個人就會受傷。



火車的一頭是永遠的牽掛，另一頭則是永遠的嚮往。



有些事一轉身就一輩子。



最初不相識，最後不相知。



有些愛, 不得不放開，驀然回首，已無力訴說。



時間不會改變痛，時間只能適應痛。



生活就是這樣，四季流轉著，

一些人遇見了，一些人失去了，

最後又會留下誰陪伴在身旁呢。
