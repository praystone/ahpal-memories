&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 






&nbsp;


&nbsp;


1.放心~


&nbsp;


&nbsp;


&nbsp;


要懂得對男、女朋友放心


&nbsp;


&nbsp;


不要一天到晚擔心她~


&nbsp;


&nbsp;


&nbsp;


2.真心~


&nbsp;


&nbsp;


&nbsp;


交往中最忌諱就是不真心。


&nbsp;


&nbsp;


還想要到處拈花惹草!這樣可不行!~


&nbsp;


&nbsp;


&nbsp;


3.安心~


&nbsp;


&nbsp;


&nbsp;


工作中或朋友圈難免會有男同事或女同事


&nbsp;


&nbsp;


不要因為一點小事情


&nbsp;


&nbsp;


例如:同事吃飯、工作、喝茶


&nbsp;


&nbsp;


不安心!或小心眼!~


&nbsp;


&nbsp;


&nbsp;


4.用心~


&nbsp;


&nbsp;


&nbsp;


交往中的情侶當然要互相用心


&nbsp;


&nbsp;


讓對方感到溫暖這樣才會長久唷~


&nbsp;


&nbsp;


&nbsp;


5.開心~


&nbsp;


&nbsp;


&nbsp;


交往中彼此要找到開心的人、事、物。


&nbsp;


&nbsp;


如果都不開心這樣交往很痛苦的~


&nbsp;


&nbsp;


&nbsp;


6.知足心~


&nbsp;


&nbsp;


&nbsp;


別抱怨對方付出的不夠多。


&nbsp;


&nbsp;


要有知足的心，這樣愛情會更甜蜜!~


&nbsp;


&nbsp;


&nbsp;


7.別有用心~


&nbsp;


&nbsp;


&nbsp;


交往時可不行別有用心唷!


&nbsp;


&nbsp;


這樣一定很快就散場結束咯!~


&nbsp;


&nbsp;


&nbsp;


8.感謝心~


&nbsp;


&nbsp;


&nbsp;


體會到以上那七個心後


&nbsp;


&nbsp;


要用感謝的心為人處事喔!~
