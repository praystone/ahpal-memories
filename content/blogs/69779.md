&nbsp;



&nbsp;


&nbsp;


夜風&nbsp; 唱著美麗的歌


&nbsp;


我在夜的掌紋中迷路


&nbsp;


&nbsp;




&nbsp;


&nbsp;


落葉 &nbsp;頑皮的偷襲


&nbsp;


蝴蝶 &nbsp;甜蜜的採擷


&nbsp;


&nbsp;






&nbsp;


&nbsp;


醉飲&nbsp; 夜色的醺茫


&nbsp;


綽開 &nbsp;宿命的流浪


&nbsp;


&nbsp;




&nbsp;


&nbsp;


旅途中


&nbsp;


交纏&nbsp; 碰撞的星斗滿天


&nbsp;


滾燙 &nbsp;微啟的思繹蔓延


&nbsp;


&nbsp;




&nbsp;


&nbsp;


聽 &nbsp;夜風在我耳畔低聲輕吟


&nbsp;


依著胸口&nbsp; 聆注悸動的羞怯


&nbsp;


&nbsp;




&nbsp;


&nbsp;


看 &nbsp;夜樹在我髮際生長茁壯


&nbsp;


無尾熊般的&nbsp; 貼著心椏枝幹


&nbsp;


&nbsp;




&nbsp;


&nbsp;


飛馳中


&nbsp;


夜風 &nbsp;親吻我的臉


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 痴狂我的戀


&nbsp;


&nbsp;




&nbsp;


&nbsp;


在夜的靈眸 &nbsp;溫潤的唇瓣


&nbsp;


開了一朵一朵&nbsp; 蜜語甜言


&nbsp;


&nbsp;




&nbsp;


&nbsp;


浸漬&nbsp; 浪漫的天真


&nbsp;


偷渡&nbsp; 隔岸的香芬


&nbsp;


&nbsp;






&nbsp;


&nbsp;


一起身


&nbsp;


夜風&nbsp; 迎著疾駛的雙輪


&nbsp;


我在夜的動脈中&nbsp; 沉淪


&nbsp;


&nbsp;




&nbsp;


&nbsp;


隔天


&nbsp;


又是一個睡過頭的清晨


&nbsp;


&nbsp;
