&nbsp;


是誰&nbsp; 夜半闖入夢境


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 喚起未成形的依戀


&nbsp;


&nbsp;




&nbsp;


&nbsp;


是誰&nbsp; 叮嚀響徹耳畔


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;催眠未沈澱的懸念


&nbsp;


&nbsp;




&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;


是夢&nbsp; 一連串脫序的情節


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;組合成若有似無的追趕


&nbsp;


&nbsp;




&nbsp;&nbsp;&nbsp;


&nbsp;


&nbsp; 是風&nbsp; 一轉身遠行的遺忘


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;拼湊成若隱若現的容顏


&nbsp;


&nbsp;




&nbsp;


&nbsp;


一顆&nbsp; 旅人漂泊的心


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 在不安定的軀體裡跳動


&nbsp;


&nbsp;




&nbsp;


&nbsp;


兩顆&nbsp; 戀人相遇的心


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 在不設防的靈魂裡雀躍


&nbsp;


&nbsp;




&nbsp;


&nbsp;


只是&nbsp; 隨興地飄落


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;留下&nbsp; 一地如夕陽燦爛的氣息


&nbsp;


&nbsp;




&nbsp;


&nbsp;


只是 &nbsp;靜悄地走過


&nbsp;


&nbsp;&nbsp;&nbsp; &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;相視&nbsp; 一眼便笑意盈滿的默契


&nbsp;


&nbsp;




&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;


&nbsp;


&nbsp;思緒中&nbsp; 垂釣淡水的夢季


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 深呼吸&nbsp; 傳遞綿柔的甜蜜


&nbsp;


&nbsp;




&nbsp;


&nbsp;


給陽光&nbsp; 空隙


&nbsp;


給山水&nbsp; 空地


&nbsp;


&nbsp;




&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;


給旅人&nbsp; 自由飛翔的伴侶


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;給戀人&nbsp; 自在相契的結局
