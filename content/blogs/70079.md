&nbsp;


男人喝酒，多半是心裡惦記著女人。


&nbsp;


女人流淚，多半是男人傷了她的心。


&nbsp;




男人喝酒是把煩惱隨酒喝進肚裡，


&nbsp;


女人流淚是讓苦衷跟淚流出心來。


&nbsp;




喝酒的男人，拿酒來消愁，看似堅強，


&nbsp;


實際是一種麻醉，是在逃避；


&nbsp;


流淚的女人，用淚來宣洩，看似脆弱，


&nbsp;


實際是一種隱忍，是在面對。


&nbsp;




男人是酒，他給女人的愛


&nbsp;


從來就是少了不盡興，多了會失控。


&nbsp;


女人是淚，她對男人的愛


&nbsp;


從來就是時時向外湧，只是味不同。


&nbsp;




酒是男人，是醇香的，是剛烈的；


&nbsp;


淚是女人，是苦澀的，是柔軟的。


&nbsp;




酒喝多了，人就會麻醉；


&nbsp;


淚流多了，心就會破碎。


&nbsp;


無論是酒或淚，都是愛情的滋味。
