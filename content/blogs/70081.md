&nbsp;





&nbsp;







&nbsp;

&nbsp;

&nbsp;

男人需要有一個私人的洞穴，

&nbsp;

&nbsp;

&nbsp;

當他沮喪、當他受傷、當他疲倦、

&nbsp;

&nbsp;

&nbsp;

當他遭遇到挫敗的時候，

&nbsp;

&nbsp;

&nbsp;

他可以躲在那個洞穴裡。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

他在裡面，

&nbsp;

&nbsp;

&nbsp;

也許甚麽都不會想，甚麽都不會做。

&nbsp;

&nbsp;

&nbsp;

他不需要傾訴，也不需要安慰，

&nbsp;

&nbsp;

&nbsp;

他只想一個人在那裡發呆。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

這個時候，女人唯一可以做的，

&nbsp;

&nbsp;

&nbsp;

是守在洞穴外面等他，

&nbsp;

&nbsp;

&nbsp;

千萬別闖進去，也千萬不要把他拉出來。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

女人對男人最深的體諒，

&nbsp;

&nbsp;

&nbsp;

便是接受他偶爾會躲進自己的洞穴裡。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

是的，每一個人都需要一個這樣的地方。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

我們都害怕孤獨，卻又需要孤獨。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

女人何嘗不需要一個洞穴呢？

&nbsp;

&nbsp;

&nbsp;

我們的洞穴，便是所愛的人的臂彎。

&nbsp;

&nbsp;

&nbsp;

男人的洞穴是無形的，

&nbsp;

&nbsp;

&nbsp;

女人的洞穴是有形的。

&nbsp;

&nbsp;

&nbsp;

我願意在洞穴外面守候著你，

&nbsp;

&nbsp;

&nbsp;

但是，當我有需要的時候，

&nbsp;

&nbsp;

&nbsp;

你也要借出你寬大的臂彎來......

&nbsp;

&nbsp;

&nbsp;

&nbsp;
