&nbsp;


&nbsp; 






我把我的愛情折成紙飛機 

&nbsp;




投向空中，讓它飛到你懷中


&nbsp;


只是我不知道它究竟能飛多遠


&nbsp;


也許剛起飛就落下，也許可以飛得很


高很遠....


&nbsp;


只是，就怕紙飛機落下


&nbsp;


紙飛機不痛，我的心卻好痛


&nbsp;


那上面載滿了我所有的愛


&nbsp;


這愛是如此的讓人心驚膽顫


&nbsp;


看著那晴空。我想著:我的愛正遨遊天


際間


&nbsp;


只希望快點飛到你身邊


&nbsp;


而我正在享受份幸福的滋味


&nbsp;


只是我害怕那脆弱的愛情，不堪風的


吹襲


&nbsp;


失去平衡的紙飛機究竟還能飛多久


是否代表著永遠也到達不了你的地方


奢望著一份簡單的情感，卻是遙遙無期


這樣的愛對我是種傷害


在奢望與傷害之間已沒有多大的分別了....
