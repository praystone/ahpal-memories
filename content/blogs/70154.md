&nbsp;



&nbsp;












&nbsp;


&nbsp;


有人說，


&nbsp;


愛情是鮮花美酒、燭光晚餐，


&nbsp;


婚姻是柴米油鹽、醬醋茶。


&nbsp;


&nbsp;


也有人說，


&nbsp;


愛情是心跳的感覺讓人激情澎湃，


&nbsp;


而婚姻卻是愛情的墳墓。


&nbsp;


&nbsp;


那麼...


&nbsp;


當愛情遇上美酒呢？


&nbsp;


&nbsp;


有人說：


&nbsp;


紅酒是以年份來定優劣，


&nbsp;


那一年的葡萄收成好，便能夠釀出好酒來。


&nbsp;


&nbsp;


聽說1982年是好年份，


&nbsp;


該年的美酒便比1972年的值錢，


&nbsp;


所以紅酒的優劣是以年份論，


&nbsp;


而不是以年資論。


&nbsp;


&nbsp;


如果是這樣的話...


&nbsp;


那麼男人與紅酒類似，


&nbsp;


仍是以收成論。


&nbsp;


&nbsp;


相信很多人不明白，


&nbsp;


沒關係就來說個小故事，


&nbsp;


有一個男人在工廠工作，與同一工廠女工戀愛，


&nbsp;


兩個人情不自禁擁吻


&nbsp;


&nbsp;


這時......


&nbsp;


被一個惡作劇的人扔石頭，


&nbsp;


於是男人發誓要發憤圖強，


&nbsp;


發達之後便可以在高尚的地方接吻，


&nbsp;


就不怕再被人扔石頭。


&nbsp;


&nbsp;


終於...男人發達了，


&nbsp;


但...男人已經不大記得那個女人，


&nbsp;


卻記得當時的窮困。


&nbsp;


&nbsp;


所以說...


&nbsp;


男人總是將女人放在收成裏，


&nbsp;


在他收成最壞的時候出現的女人，


&nbsp;


他會永遠感激。


&nbsp;


&nbsp;


在他收成最壞的時候


&nbsp;


離開的女人，男人就會記恨，


&nbsp;


這就是收成論。


&nbsp;


&nbsp;


那麼...女人呢？


&nbsp;


&nbsp;


女人算是情緒性動物，


&nbsp;


容易依靠自己的內心感覺做出決定，


&nbsp;


女人對舊情的回憶也跟紅酒一樣，


&nbsp;


但不是以年分論，而是以品質論。


&nbsp;


&nbsp;


女人只記當時狀態。


&nbsp;


如果當時狀態最好，容貌漂亮，


&nbsp;


身材迷人，她會特別記得那個男人。


&nbsp;


因為，女人回憶舊情時總愛說：


&nbsp;


“我最好的歲月都給了他。”


&nbsp;


&nbsp;


&nbsp;


其實，


&nbsp;


每一款美酒都有屬於自己的個性，


&nbsp;


不同的香氣，不同的色澤，不同的口味，


&nbsp;


給人的感覺也就不同，相信.......


&nbsp;


總有一款適合你和你的他（她）。


&nbsp;


&nbsp;


當愛情遇上美酒如同，


&nbsp;


相識、相知到相愛的歷程，


&nbsp;


那份美酒般的濃情蜜意，將使彼此的心靠的更近，


&nbsp;


彼此的愛更加醇厚！


&nbsp;


&nbsp;


曾經有一位


&nbsp;


偉大的思想家兼政治家和科學家，


&nbsp;


（本傑明·佛蘭克林）曾經說過：


&nbsp;


“好的葡萄酒證明了上帝希望我們幸福。”


&nbsp;


&nbsp;


那就讓這神明所賜的


&nbsp;


瓊漿玉液葡萄美酒


&nbsp;


來見證這世間無數美好的愛情吧！


&nbsp;
