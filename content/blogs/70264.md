&nbsp;

&nbsp;






&nbsp;


&nbsp;


&nbsp;


常常聽人說&nbsp; 


&nbsp;


好女人是所學校 


&nbsp;


能夠調教出好男人來



&nbsp;


&nbsp;&nbsp; 我想這話是有些道理吧&nbsp; 


&nbsp;


&nbsp;&nbsp; 因為很多的事情都是相對的&nbsp; 


&nbsp;



可我也認為&nbsp;


&nbsp;


&nbsp;如果說每個女人都是降落凡間的那個天使的話&nbsp;


&nbsp;


&nbsp;那麽好男人就為


&nbsp;


這天使插上了翅膀


&nbsp;


壞男人則能折斷那個天使翅膀


&nbsp;


並讓之瘋狂



&nbsp;


好男人張揚個性


&nbsp;


壞男人顯擺條件


&nbsp;



&nbsp;


好男人追求和喜歡一個女子


&nbsp;


更願意用人格上的的魅力去征服她


&nbsp;


這樣得來的欣賞


&nbsp;


或者才是真正的相知



&nbsp;


壞男人喜歡顯擺外在的條件去吸引女人


&nbsp;


卻不知道這樣招來的女子未必能夠留的長久


&nbsp;



好男人懂得珍惜女人


&nbsp;


哪怕不是他所愛的


&nbsp;


也一樣保護且尊重著


&nbsp;


她的聲譽


&nbsp;


身體或者其他


&nbsp;


哪怕是自己受到委屈


&nbsp;



壞男人喜歡踩著別人把自己往上擡


&nbsp;


存在不存在的他都會到處宣示著


&nbsp;


和他有過關系


&nbsp;


以至來證明自己的魅力和不凡


&nbsp;



好男人坦蕩蕩


&nbsp;


不愛就直接說出來


&nbsp;


不讓女子深陷傷害


&nbsp;



壞男人心戚戚


&nbsp;


不管愛與不愛


&nbsp;


先玩弄了再說


&nbsp;


根本不管什麽責任


&nbsp;


道義或者是良知


&nbsp;



好男人不會讓女人誤會


&nbsp;


更多的是給女人包容和謙讓


&nbsp;


會和女人擺事實&nbsp;&nbsp; 說道理


&nbsp;


讓女人無法去怨


&nbsp;


也怨不起來


&nbsp;



壞男人喜歡逃避


&nbsp;


現實還有責任


&nbsp;


不會留給女人說話的機會


&nbsp;


甚至還會把責任全推到女人身上


&nbsp;


自己裝作很無辜的樣子


&nbsp;


這近乎讓女人瘋狂


&nbsp;



&nbsp;


&nbsp;


在婚姻裏


&nbsp;


男人如果找到自己理想的女人


&nbsp;


&nbsp; 那麽家是好男人的全部


&nbsp;


妻子將是他的最愛


&nbsp;


好男人認為


&nbsp;


是男人就勇於承擔


&nbsp;


就像是教堂的結婚誓言念的一樣


&nbsp;


既選擇了


&nbsp;


就不管貧窮富貴&nbsp;&nbsp; 生老病死


&nbsp;


都將對妻子不離不棄


&nbsp;


於是


&nbsp;


好男人的妻子就如天使般&nbsp; 溫柔&nbsp; 善良&nbsp; 賢惠


&nbsp;


因為


&nbsp;


她滿足&nbsp; &nbsp;她幸福


&nbsp;



對壞男人來說


&nbsp;


家就是他的負累和牽絆


&nbsp;


妻子於他來說就是那個生孩子洗衣做飯的工具


&nbsp;


可以隨便是任何一個女人


&nbsp;


他不需要付出什麽的


&nbsp;


只要得到


&nbsp;


殊不知每個女人開始都有靈魂的


&nbsp;


遭遇到這樣的男人


&nbsp;


&nbsp;


&nbsp;


就是天使也會瘋
