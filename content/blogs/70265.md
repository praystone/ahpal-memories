&nbsp;


&nbsp;


石頭


&nbsp;


&nbsp;



就像一顆堅強的心


&nbsp;


&nbsp;



橫衝直撞　什麼東西都不怕


&nbsp;


&nbsp;



往往都沒考慮到事情的後果


&nbsp;


&nbsp;



&nbsp; 　


&nbsp;


&nbsp;



布


&nbsp;


&nbsp;



就像一顆成熟的心


&nbsp;


&nbsp;



事事包容　只想要別人開心


&nbsp;


&nbsp;



往往受傷的卻是脆弱的自己


&nbsp;


&nbsp;



&nbsp; 　


&nbsp;


&nbsp;



剪刀


&nbsp;


&nbsp;



就像一顆冷淡的心


&nbsp;


&nbsp;



四處挑剔　只會想到自己好


&nbsp;


&nbsp;



凡事都要別人順著自己


&nbsp;


&nbsp;



卻傷害了想要對它好的別人


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp; 


&nbsp;


&nbsp;


&nbsp;



曾經　


&nbsp;


&nbsp;



抱著石頭般的心做自己


&nbsp;


&nbsp;



什麼事都是如此的單純　順其自然


&nbsp;


&nbsp;



但事情有了紕漏　卻被人包容　原諒著


&nbsp;


&nbsp;




&nbsp;


&nbsp;



長大


&nbsp;


&nbsp;



一切都不再單純


&nbsp;


&nbsp;



嚮往著　布　的心


&nbsp;


&nbsp;



把最真的自己藏著　為它造了一座迷宮


&nbsp;


&nbsp;



笑容　不再只是笑容


&nbsp;


&nbsp;



包容　一切只能包容


&nbsp;


&nbsp;



但卻容易被曲解　被挑剔　利用


&nbsp;


&nbsp;



最後帶著受傷的心　躲在迷宮之中


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;



心冷


&nbsp;


&nbsp;



把自己當成剪刀


&nbsp;


&nbsp;



利則利　不利則避


&nbsp;


&nbsp;



四處要求　四處冷諷


&nbsp;


&nbsp;



卻不信任任何人


&nbsp;


&nbsp;



為自己的心造起一座冰宮


&nbsp;


&nbsp;



擋住了所有的關懷


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;



每個人的心裡都有座迷宮


&nbsp;


&nbsp;



是大是小　卻是不一定的


&nbsp;


&nbsp;



布　可以呵護著石頭


&nbsp;


&nbsp;



石頭　也可以保護著布　


&nbsp;


&nbsp;


&nbsp;


關懷　是必須


&nbsp;


&nbsp;



接受關懷也是必須　


&nbsp;


&nbsp;



是布　是石頭　還是剪刀


&nbsp;


&nbsp;



完全取於自己
