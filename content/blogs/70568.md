像中槍一樣


&nbsp;

정신이 너무 없어&nbsp;


神志無法清晰


&nbsp;

웃음만 나와서 

笑著對我走過來


&nbsp;

그냥 웃었어 .. 그냥 웃었어&nbsp;

總是那樣笑著 總是那樣的笑


&nbsp;

그냥 .. 

總是那樣…



허탈하게 웃으면&nbsp;


&nbsp;只因空虛而笑的話

&nbsp;

&nbsp;

하나만 묻자해서 ..

&nbsp;

&nbsp;獨自一人疑惑著


&nbsp;

우리 왜 헤어져 ..


我們為什麼要分離…


&nbsp;

어떻게 헤어져 ..&nbsp;


該怎麼離開…


&nbsp;

어떻게 헤어져 .. 어떻게&nbsp;

該怎麼離開…該怎麼做


구멍난 가슴에 ..


胸口破了個洞

&nbsp;

&nbsp;

우리 추억이 흘러 넘쳐 ..&nbsp;

我們的回憶流洩而出


&nbsp;

잡아보려해도

就那樣拉扯著


&nbsp;

가슴을 막아도 

內心抵擋著


손가락 사이로 빠져나가

從指縫中流逝


&nbsp;

심장이 멈춰도&nbsp;

心臟也停止跳動


&nbsp;

이렇게.. 


這個樣子…

&nbsp;

&nbsp;

아플꺼 같진 않아 ..

這麼的痛卻不能在一起 


&nbsp;

어떻게 좀 해줘..&nbsp;


該怎麼做才好

&nbsp;


나 좀 치료해죠&nbsp;

才能讓我稍微癒合.

&nbsp;


이러다 내 가슴 다 망가져

就這樣讓我的心壞死吧


&nbsp;

구멍난 가슴이
&nbsp;
破了洞的心



어느새 눈물이



無意識的眼淚


나도 모르게 흘러


我也不知道為何流下


이러기 싫은데..


討厭這個樣子

&nbsp;


정말 싫은데 ..


真的非常討厭

&nbsp;


정말 싫은데 .. 정말 .. 

真的非常討厭 真的…
