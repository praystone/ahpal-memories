有關【薑】【山藥】【蕃茄】的注意事項? 嗯!這些很實用而且重要!!
1. 薑
&nbsp; &nbsp; 在家煮飯燒菜所用的生薑只要有一部分爛掉&nbsp;便要整個丟棄
&nbsp; &nbsp; 千萬不要捨不得只把爛的切掉 而留下好的繼續燒菜
&nbsp; &nbsp; 因為薑腐爛時 &nbsp;薑體會產生很強的 " 黃樟素 "
&nbsp; &nbsp; 人體吃進黃樟素會造成肝細胞病變 &nbsp;&nbsp;嚴重影響身體健康
&nbsp; &nbsp; 所以婆婆媽媽們不要因小失大
&nbsp; &nbsp; 薑爛了就整個丟掉~ rn2. 山藥
&nbsp; &nbsp; 山藥有收斂作用
&nbsp; &nbsp; 有便秘或排便不順的人不要吃 &nbsp;否則便秘更嚴重~
&nbsp; &nbsp; 多吃山藥會促進人體分泌賀爾蒙
&nbsp; &nbsp; 賀爾蒙對一般人有益
&nbsp; &nbsp; 但是有子宮、卵巢、乳房腫瘤者不宜進食
&nbsp; &nbsp; 還有男性攝護腺腫瘤也一樣 &nbsp;吃了會助長腫瘤
&nbsp; &nbsp; 要注意喔~
3. 蕃茄
&nbsp; &nbsp; 未成熟的綠蕃茄含有可溶性收斂劑
&nbsp; &nbsp; 它會把胃液結成塊堵住胃的賁門(胃口)&nbsp;&nbsp;使胃壓升高讓人感覺不舒服~
&nbsp; &nbsp; 生蕃茄(綠色)含有大量的 " 龍葵素 "&nbsp;龍葵素是一種生物鹼&nbsp;具有腐蝕性和溶血性
&nbsp; &nbsp; 大量吃的話會咽喉麻養、胃部灼痛&nbsp;胃腸發炎
&nbsp; &nbsp; &nbsp;所以蕃茄要買熟透的、全紅的比較安全~
