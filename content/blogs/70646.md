面對自己人生道路會怎麼選擇


&nbsp;


&nbsp;


&nbsp;


&nbsp;


我們的人生道路，有很多的岔口，


&nbsp;


你會怎麼選擇，你會怎麼走。


&nbsp;


當你走到一條路的盡頭


&nbsp;


會有很多的岔口，


&nbsp;


一條是很平坦的大路。


&nbsp;


一條是很荒的草地。


&nbsp;


另外的一條是高山。


&nbsp;


你會怎麼選擇。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


平坦的道路看上去沒有什麼危險，


&nbsp;


越是平坦越是危險，平坦道路必有陷阱。


&nbsp;


不要去選擇平坦的路，並不是那麼的好走，


&nbsp;


看上去鳥無硝煙的，


&nbsp;


但只要你認真的會發現財富和你想要的生機。


&nbsp;


你會成功的走完這條道路。


&nbsp;


高山是最有挑戰性的，


&nbsp;


他的生命力生存能力極強。


&nbsp;


只有在苦境中，才能激發人的潛能。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


面對你的人生道路會有很多種，


&nbsp;


到底怎麼選擇，別人無權干涉，


&nbsp;


最終權在自己手中。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


選擇錯誤的話，


&nbsp;


那麼你的人生也會有很大的改變。


&nbsp;


一切從現在開始。


&nbsp;


人生也許是上天安排了，


&nbsp;


但　你可以改變自己的命運。


&nbsp;


微笑　面對問題，面對人生，


&nbsp;


問題會有解決的辦法。


&nbsp;


遇事不要急，心平氣靜。
