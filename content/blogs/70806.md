&nbsp;

一日無常到，方知夢裡人；
萬般帶不去，唯有業隨身。
&nbsp;
一息不來，乃屬後世；
一念若錯，便墜輪迴。
&nbsp;
一生一世如幻夢，莫貪眼前虛華景，
不認真理誤自身，枉得來去一場空。
&nbsp;
人生於世似夢景，光陰如箭不停留，
昔日年輕今日老，瞬息之間換白頭。
&nbsp;
人生到處知何似，應似飛鴻踏雪泥；
泥上偶然留指爪，鴻飛那復計東西。
&nbsp;
不醒沈淪苦海中，忙忙世事走西東，
金錢情愛迷真性，往往來來一世空。
&nbsp;
夫妻本是同林鳥，大限來時各自飛，
功名蓋世徒何用，轉眼成空罪難當。
&nbsp;
少年莫笑老人顏，老年不奪少年春；
此老老人不將去，此老還留與後人。
&nbsp;
世事紛紛不用爭，心田免稅應勤耕，
長江後浪推前浪，轉眼又聞落葉聲。
&nbsp;
世事紛紛如閃電，輪迴滾滾似雲飛；
今日不知明日事，哪有工夫論是非。
&nbsp;
功名利祿水上漚，無常一到萬事休；
千載難逢好機緣，好向靈山塔下修。
&nbsp;
功名半幅紙，富貴一場空。
&nbsp;
春日才看楊柳綠，秋風又見菊花黃；
榮華總是三更夢，富貴還同九月霜。
&nbsp;
看來世事皆如夢，何必貪求日日忙，
世間美景無長久，一氣不來萬事休。
&nbsp;
榮華富貴總有盡，青山綠水永長存，
大江後浪推前浪，世上新人換舊人。
&nbsp;
去年今日此門中，人面桃花相映紅；
人面不知何處去，桃花依舊笑春風。
&nbsp;
感嘆人生甚短暫，世事種種何計較；
三寸氣在千般用，一旦無常萬世休。
&nbsp;
休教六賊日相攻，色色形形總是空，
悟得本來無一物，靈台只在此心中。
&nbsp;
朝看花開滿樹紅，暮看花落樹還空；
若將花比人間事，花與人間事一同。
&nbsp;
金銀積如山，難買無常到，
好高爭名利，轉眼伴荒郊。
&nbsp;
命裏有時終須有，命裏無時莫強求。
命裡窮時畢竟窮，撿到黃金也變銅。
&nbsp;
萬般變化總由心，至誠行道貫古今，
百年光陰如流水，一世浮華似行雲。
&nbsp;
富貴花間露，功名草上霜。
&nbsp;
富貴貧賤要看淡，從無穿食莫怨天，
眼前就是大劫到，富貴貧賤是一般。
&nbsp;
百年榮華風前燭，三世富貴轉眼無。
&nbsp;
休得爭強來鬥勝，百千渾是戲文場；
頃刻一聲鑼鼓歇，不知何處是家鄉。
&nbsp;
&nbsp;
～～一切有為法，如夢幻泡影，如露亦如電，應作如是觀。～～
