&nbsp;

空著手　猶如你來的時候

&nbsp;

緊皺的額頭　終於再沒有苦痛

&nbsp;

走得太累了　眼皮難免會沉重

&nbsp;

你沒錯　是應該回家坐坐

&nbsp;

&nbsp;

&nbsp;

&nbsp;

鳴笛聲　悄悄地刺進耳朵

&nbsp;

這一次揮手　恐怕再沒機會問候

&nbsp;

最後一遍了　換你躲進我雙肘

&nbsp;

像靠在　曾搖動我的天空

&nbsp;

&nbsp;

&nbsp;

&nbsp;

別說話 淚水你別帶走　鏡子裏的我

&nbsp;

已留下你　輪廓上的笑容

&nbsp;

別回眸 末班車要開了　你不過先走

&nbsp;

深愛是讓不捨離開的人　好好走
