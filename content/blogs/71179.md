&nbsp;


&nbsp;


遇到你真的愛的人時…要努力爭取和他相伴一生的機會…！


&nbsp;


因為當他離去時…一切都來不及了……！


&nbsp;


遇到可相信的朋友時…要好好和他相處下去……


&nbsp;


因為在人的一生中…可遇到知己真的不易…！


&nbsp;


遇到人生中的貴人時…要記得好好感激…


&nbsp;


因為他是你人生的轉折點…！


&nbsp;


遇到曾經愛過的人…記得微笑向他感激…


&nbsp;


因為他是讓你更懂愛的人…！


&nbsp;


遇到曾經恨過的人時…要微笑向他打招呼…


&nbsp;


因為他讓你更加堅強…！


&nbsp;


遇到曾經背叛你的人時…要跟他好好聊一聊…


&nbsp;


因為若不是他……今天你不會懂這世界…！


&nbsp;


遇到曾經偷偷喜歡的人時…要祝他幸福唷…！


&nbsp;


因為你喜歡他時…不是希望他幸福快樂嗎？


&nbsp;


遇到匆匆離開你人生的人時…要謝謝他走過你的人生…


&nbsp;


因為他是你精采回憶的一部分…！


&nbsp;


遇到曾經和你有誤會的人時…要趁現在解清誤會…


&nbsp;


因為你可能只有這一次機會解釋清楚…！


&nbsp;


遇到現在和相伴一生的人…要百分百感謝他愛你…


&nbsp;


因為你們現在都得到幸福和真愛…
