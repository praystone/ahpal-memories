&nbsp;


希望長大是位美麗的Lady


&nbsp;


擁有天使的臉孔和魔鬼的身軀


&nbsp;


可以穿著夢幻的長裙


&nbsp;


踩著細的高跟搖來搖去


&nbsp;


幻想著男人都會對我目不轉睛


&nbsp;


再和我心愛的哈尼共譜戀曲


&nbsp;


生一群可愛的小Baby


&nbsp;


小女生的幻想總是那麼天真無比


&nbsp;


那是純真無邪的心靈


&nbsp;


長大後


&nbsp;


憧憬卻不如兒時想像的那麼開心


&nbsp;


為了讀書要花腦筋


&nbsp;


工作賺錢又筋疲力盡


&nbsp;


戀愛怕被拋棄


&nbsp;


結婚後又怕老公外遇


&nbsp;


生兒育女又惹人生氣


&nbsp;


房價又貴的嚇死自己


&nbsp;


只能窩在小小的公寓


&nbsp;


旅行一趟就得縮緊肚皮


&nbsp;


我覺得還是單身比較隨性


&nbsp;


把自己弄好就全部搞定


&nbsp;


不用委屈自己還要拍人馬屁


&nbsp;


一個人的天地


&nbsp;


雖然有時也會孤寂


&nbsp;


但是電子的發明手機第一


&nbsp;


按鍵一碰就找Call得到你


&nbsp;


不過還是兒時比較Happy


&nbsp;


不用事事求助神明和上帝


&nbsp;


唉唷~我的媽咪


&nbsp;


為什麼長大那麼令人煩心


&nbsp;


無論是兒時的憧憬


&nbsp;


還是成人後的洗禮


&nbsp;


總之


&nbsp;


就是要
