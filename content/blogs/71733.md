&nbsp;



&nbsp;





我的心


那是水晶做的&nbsp;&nbsp;&nbsp; 晶瑩剔透 


其實


我是想讓你看到它的容易碰傷和摔碎


&nbsp;



對你，我從不設防



你那麼擅自的輕易的就闖進我的心


走的時候卻讓它燃成灰燼



我已經快要忘記


&nbsp;


這個世界上還會有一種可以讓我哭的人



因為&nbsp;&nbsp; 我和自己說



那個值得我愛的人根本就不會捨得讓我哭


我會撿回我的矜持&nbsp;&nbsp; 我會重拾我的驕傲


我會偽裝我的冷淡



我總是嘴裏說著要你走開


&nbsp;


心裏卻一直叫你留下



我總是在電話的這邊說要掛斷



心裏卻一直叫你在電話的那邊好好的呵護我


打開你的心


&nbsp;


把在你心裏曾經傷過的地方交付給我



不要用我和那個她比較


&nbsp;


因為我是你的醫生&nbsp;&nbsp; 我只會治癒你



在我對你的世界裏沒有“傷害”這兩個字


聽我心裏真正的呼喚


而不是倔強時候的我嘴裏的口是心非



看著你轉身，然後，我會跟著你轉身



即使難過時候的我，也一樣會跟著你



就算當側身而過的時候


&nbsp;


你也不會看見我的淚



因為我已經把它們滂沱在心裏



我愛的你


&nbsp;


如果你也一樣愛我&nbsp;&nbsp; 請你多陪我


我愛的你


&nbsp;


如果你也一樣愛我&nbsp;&nbsp; 請你多寵我



我愛的你


&nbsp;


如果你也一樣愛我&nbsp;&nbsp; 請你多讓我



親愛的..你聽到了嗎？&nbsp;



在我------


&nbsp;


你的女人的心裏吶喊著——


&nbsp;


抱抱我...



愛情裏沒有你對我錯


&nbsp;


也沒有我多你少



你愛我&nbsp;&nbsp; 像你說過那樣的愛我



我愛你&nbsp;&nbsp; 比我說過的更愛你


&nbsp;


如此就已經足夠了...



不要嘗試傷害彼此


&nbsp;


不要讓彼此變得脆弱



我們需要的


&nbsp;


是溫暖


&nbsp;


是幸福


&nbsp;


是甜蜜


&nbsp;


是快樂



我們一起手拉手拒絕傷害


&nbsp;


把傷害擋在我們的門外



別再用沈默宣戰&nbsp;&nbsp; 也別再互不相讓



更別再什麼話都不講&nbsp;&nbsp; 就冷漠離去



我知道&nbsp;&nbsp; 當你離去的時候


&nbsp;


你的眼睛起了霧



可你知道嗎？


&nbsp;


在我離開的時候&nbsp;&nbsp; 我的眼角泛著淚光...



越是安靜&nbsp;&nbsp; 戰火就越不會熄滅



&nbsp; 這是冷戰&nbsp;&nbsp; 卻也是無法癒合的痛



擁我入懷&nbsp;


&nbsp; 


用你的懷抱化去我心裏的悲傷



用你的唇吻去我眼角的淚水


&nbsp;


我不會拒絕你的擁抱


&nbsp;


我只是怕極了你的冷漠



你的轉身&nbsp;&nbsp; 你的無聲&nbsp;&nbsp; 你的安靜



其實


&nbsp;


我只是想你寵我


&nbsp;


想你抱我



哪怕


&nbsp;


沒有道歉


&nbsp;


沒有任何聲音



只要你把我全部攬入你的懷抱...
