期待很久的一日訓要來 不過我的上線 沒辦法來參加

&nbsp;

家裡有喜事就沒辦法了 結婚最大 &nbsp;可真是可惜

&nbsp;

這次的一日訓 因為白說實在有薛地方明明有去過

&nbsp;

但還是不知道 要怎走 &nbsp;起機車過去好了 天氣不佳

&nbsp;

老天爺是怕我迷路 所以用這場與 提醒 改做大種工具

&nbsp;

還滿算順利的 從 海山站 一路做台北 再轉到大坪林 呼呼

&nbsp;

原來我也會坐捷運 遇到VEMMA讓我學會座捷運

&nbsp;

工作常常跑 東跑西 不過不是騎車 就是開車 拿有機會做 大眾交通

&nbsp;

不過走出捷運站 &nbsp;亂換了依下才發現我出錯路口了

&nbsp;

這樣不行 在下捷運站 走其他路口

&nbsp;

第次次 出捷運站 哈哈 這次走對邊了

&nbsp;

離我的目標越來越近了 就像看到奇蹟的署光

&nbsp;

讓我雙眼 禿然開時泛紅 低出幾滴淚水

&nbsp;

實在太感動了 我到達目的地了 喜吉而泣 的飛奔到目的地

&nbsp;

近去才知道原來這次在2樓

&nbsp;

&nbsp;一上樓 就看到 讓我站嘆不一的團隊 這才是 利用愛創造的團隊

&nbsp;

報到以後 &nbsp;拿到今日的武林密集 要練此供 必先加入 愛的團隊

&nbsp;

早上第一節 是傳說中的 精神提升課程 哈哈

&nbsp;

不外乎 就是要 從頭到尾動起來 從前到後 轉起來

&nbsp;

精神力提昇了不少 &nbsp;感覺上能讓我變造及塞亞人 卡洛特 (這好像是要騙小孩吃飯花招)

&nbsp;

再來進入 真正的課程 原來是!原來是! VIVI老師

&nbsp;

傳說是這樣來的 他是一個很能幹 又賢慧的領導者 不但散發誘人 又神祕的氣息

&nbsp;

這樣不根緊他 好像對不起我自己 &nbsp;呵呵

&nbsp;

VIVI老師的是 公司的工具跟使用方式

&nbsp;

交了滿多的 有淺到深 用從出發點跨依不出去了

&nbsp;

呼這堂上完

&nbsp;

在來是傳授搭訕秘辛 傳有耳聞 &nbsp;穎而老師

&nbsp;

這不是必學的昭示 加上我內涵不佳

&nbsp;

小生怕怕 這堂 沒學到出去會吃虧

&nbsp;

只能多聽多看 多學學 不過這次我覺得我有點慌了 殺氣太重

&nbsp;

只能說做工的人 發揮出來的特點比較誇示&nbsp;

&nbsp;

呼 中午休息一下 叢中出現小插曲 就是張老師 分享她的故事

&nbsp;

聽完以後 我是覺得個人的信念 要明確&nbsp;

&nbsp;

堅定 跟 信心 才能勇敢 向未知的理想 跟夢想 去達成

&nbsp;

休息解數 &nbsp;下午 第一節 是博凱老師的課

&nbsp;

網路工具 跟如何 去運用 &nbsp;實際抄作&nbsp;

&nbsp;

這堂 說真的還滿重要的 已依個新人來說

&nbsp;

要如何開發未知的人脈 博凱的細心講解 &nbsp;中肯 的說明&nbsp;

&nbsp;

原來 人人多可以

&nbsp;

再來是小麟老師的課 散加運用補助軟體

&nbsp;

這對一些兼差 獲學生 有所幫助

&nbsp;

小麟老師 悉心講解 這套軟題不難

&nbsp;

但是天天該做的是還是要作 事業是自己得

&nbsp;

壓軸登場 EE老師的 天堂/天時&nbsp;

&nbsp;

哇這原來把所有東西輕鬆簡單化

&nbsp;

只要一健 可以經營各地&nbsp;

&nbsp;

這也太神了吧 &nbsp;

&nbsp;

感謝 VIVI老師 穎兒老師 張老師 博凱老師 小麟老師 EE老師 細心講解

&nbsp;

真是充實的一天 要不斷學習 不斷開發自己的淺能 一同努力 團隊夥伴們
