&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 一個風雨交加的晚上&nbsp; 零亂的小屋

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 女人靠在床頭抽著煙，旁邊一個神情沮喪的男人趴在床上哭泣

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：妳幹嗎強姦我？？妳這個禽獸！！~
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：因為我是禽獸所以我才強姦你，這麼笨的問題你也問。

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：嗚嗚~！妳讓我以後怎麼辦？？
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：我哪知道，我是強姦你的！又不是你女朋友。

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;A男：妳要懷孕了呢，我要負責麼？
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;B女：我操，你當我小白（白癡）啊~

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：嗚嗚~~嗚，嗚！
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;B女：別哭了，有什麼大不了的，好了，好了，頂多以後我常來看看你

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：真的嗎！！！妳真會來看我麼？？真的來麼！妳能來麼！
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：靠~你當我強姦是假的啊，我說來就會來~

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;A男：那妳強姦我之後，難道就沒有內疚麼！
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：哎，你還別說，你這一說我還真有點內疚!

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：那妳要補償我！~~~
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：（驚訝）怎麼補償？？？

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：妳當我女朋友吧~~.
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：汗~~~~~~（我今年30了，還沒個對象，今天就有了？？？？

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：同意麼？
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女：好，既然你這麼說了，我就勉為其難，答應你了！

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; A男：妳太好了，說完在B女的臉上親了一口！~ (幸福中……)
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B女 淚流滿面的說：強姦無罪~~~~~！！

&nbsp;

&nbsp;&nbsp;&nbsp;&nbsp; （從此他倆快快樂樂的生活著）^__________^ ~ !!!&nbsp;
