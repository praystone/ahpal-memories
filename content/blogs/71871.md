&nbsp;

&nbsp;

&nbsp;

&nbsp;

音樂課


&nbsp;


看似 簡單的喧然


&nbsp;


就是這麼 不簡單


&nbsp;


或許音符 本身也應該


&nbsp;


帶點甜美的 轉彎


&nbsp;


以閃開避免 任何一段


&nbsp;


反覆 分岔的呆板


&nbsp;


固定臉紅 心跳的眼光


&nbsp;


以虔誠中的 告解收場


&nbsp;


在芬芳 綻放的廣場


&nbsp;


任誰


&nbsp;


都不得不 瘋狂的愛上


&nbsp;


他們繼續在粉刷 晴朗


&nbsp;


避免愛情 少了點浪漫


&nbsp;


接近 明天的鐘響


&nbsp;


具體的輕脆 很璀璨


&nbsp;


希臘被迫等於 神話的家鄉


&nbsp;


還包括


&nbsp;


那些太過 美滿的收場


&nbsp;


還有什麼


&nbsp;


就該把幸福 彩繪在玻璃窗


&nbsp;


有些浪漫 就是


&nbsp;


簡簡單單的 令人如此瘋狂


&nbsp;


固定堆積思念的 迴廊


&nbsp;


以簡單的 微笑漆上


&nbsp;


在毫無預警的 瘋狂


&nbsp;


不知道 該如何不去想


&nbsp;


幸福依舊 粉刷那牆


&nbsp;


避免太過甜蜜的 浪漫


&nbsp;


哥德式 裝扮著教堂


&nbsp;


還播放著 幸福的鐘響


&nbsp;


留下這些


&nbsp;


抓進愛情 期待的模樣


&nbsp;


在愛情之地


&nbsp;


最最


&nbsp;


接近幸福的 噴泉旁


&nbsp;


需要投擲


&nbsp;


適度 彎曲的浪漫


&nbsp;


才能許下


&nbsp;


愛你的


&nbsp;


願


&nbsp;


望
