&nbsp;&nbsp; 


&nbsp;緣份與宿命 




&nbsp;


&nbsp;

緣份和宿命似於冥冥中注定


&nbsp;

一個生靈與另一個生靈的相遇是千載一瞬


&nbsp;

分別卻是萬劫不復


&nbsp;

茫茫人海中


&nbsp;

相遇是緣起，相識是緣續，相知是緣定


&nbsp;

無論得失，皆順其自然


&nbsp;

必需的是感謝他曾走入你的生命


&nbsp;

或許正是他豐富了你人生的記憶


&nbsp;

任何美麗而痛苦的回憶


&nbsp;

終將會成為昨日的樂章


&nbsp;

寄情於那曾一度輝煌過的親切記憶


&nbsp;

輾轉沉溺於早已虛幻如夢的往日悲歡


&nbsp;

便不會看到威力的愛情芳草重生


&nbsp;

即使日，月，星辰都從你身邊溜走


&nbsp;

至少你還擁有一片天空


人生來如風雨，去如微塵


&nbsp;

&nbsp;

歲月本長


&nbsp;

苦短幾十年切勿給自己留下遺憾


&nbsp;

想笑則笑，欲哭便哭 


&nbsp;

該愛的時候就去愛，無謂壓抑自己


&nbsp;

曾經擁有的，不要忘記


&nbsp;

不能得到的，更要珍惜


&nbsp;

屬於自己的，不要放棄


&nbsp;

已經失去的，留作回憶

&nbsp;

&nbsp;
