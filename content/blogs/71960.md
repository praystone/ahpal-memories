兩段情，忘不了，放不下，前前後後的記憶全都混在一起了
&nbsp;
不知道為什麼，都沒有在一起了，卻有那腳踏兩條船的感覺。
&nbsp;
高中夜校時交了兩年的女友，她大我4歲，交我開車的那段記憶是最深的
&nbsp;
她那時已經20歲有一台BMW E36&nbsp;M3，剛開始也是學開這台車。
&nbsp;
最後她也是死在這台車，這記憶到現在還是好深刻。
&nbsp;
雖然當時不在她身邊，卻一直幻想她撞車的那一剎納，她會有那種無助，恐懼的神情
&nbsp;
因為我了解她，他性情雖有些驕弱，但在公開場合他總是能當個大主角。
&nbsp;
她真的很漂亮，也好開心擁有過她，只是時間還是抹去了我的催淚感
&nbsp;
隔了整整快5年了那天一個女孩找上了我。
&nbsp;
而他撒驕的樣子很像她，但只有這一點變成了我的慰藉，
&nbsp;
其他生活作息，頭腦，思想，全部都不一樣。
&nbsp;
剛開始一直沒有愛的感覺，她剛開始個性有夠倔，小孩子氣
&nbsp;
並用了小孩的語氣說她多愛我，其是那時在心裡早就有譜，她會自己離開我
&nbsp;
對吧！她走了，不過他在行為上應該成熟不少了，但那是她渴望學習的一環
&nbsp;
所以才成長，但她超級懶惰，把我的房間到處都是衣服，內衣的
&nbsp;
每次都只能無奈的自己幫她收拾，雖然很嘔。
&nbsp;
我想是日久生情吧!(根本就是… …。)
&nbsp;
總覺得自己每次一但投入就脫離不了，人與人之間我是這樣
&nbsp;
做事情與工作也是，一但投入就捨不得離開= ="
&nbsp;
現在都走了，留下我自己一個，我在想著會不會又要等5年了
&nbsp;
那時後自己就30歲了耶....= ="
&nbsp;
我在想如果又是5年，5年後的我能夠親手把握住愛嗎?
&nbsp;
只有從高處跳下來，才能舒坦一些，我想還是跳水去的好。
