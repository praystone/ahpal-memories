&nbsp;


&nbsp;隨緣心




&nbsp;

&nbsp;


幸福不是終點，而是努力走過的道路。

&nbsp;

路上遇到的風雨、挫折、痛苦，豐富了這條路。

&nbsp;

也是因為有了這些，

&nbsp;

我們才明白真實的幸福，其實就在每一天！

&nbsp;

每個人都有自己生命的價值不要忽視自己。

&nbsp;

並且善加利用一定也會開出生命中美麗的花朵。

&nbsp;

&nbsp;

有一顆隨緣心，你會更灑脫；

&nbsp;

有一顆平常心，你會更從容；

&nbsp;

有一顆慈悲心，你會更積善；

&nbsp;

有一顆感恩心，你會更幸福；

&nbsp;

有一顆因果心，你會更明理；

&nbsp;

有一顆忍讓心，你會更快樂；

&nbsp;

有一顆超脫心，你會更淡然；

&nbsp;

有一顆修行心，你會更智慧；

&nbsp;

有一顆質樸心，你會更純粹；

&nbsp;

有一顆自知心，你會更清醒。

&nbsp;

&nbsp;

一分耕耘一分收，一寸逆境一寸修，

&nbsp;

一分愛心一分熱，一寸善行一寸福，

&nbsp;

一分歷練一分智，一寸寬容一寸道，

&nbsp;

一分付出一分得，一寸禮儀一寸美，

&nbsp;

一分施捨一分喜，一寸忍讓一寸天，

&nbsp;
