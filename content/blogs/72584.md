&nbsp;



&nbsp;










 




輾轉紅塵遇見了你，


&nbsp;


凄美了我守候千年的愛戀。


&nbsp;


今世的約定，


&nbsp;


來世的相牽，


&nbsp;


我的執著守望成一道永恒的風景，


&nbsp;


想你是一種憂傷的美麗........


&nbsp;


我是你前世種下的玫瑰，


&nbsp;


註定在每一個輪迴的渡口用淚濕透花蕊，


&nbsp;


期待著你在寂靜的夜裡，


&nbsp;


聞到我吐露的幽香。


&nbsp;


我用深情的文字書寫著浪漫的情懷，


&nbsp;


用微弱的生命感受著多情的雨季。


&nbsp;


我的思念穿越漆黑的夜空，


&nbsp;


是否你能聽見我在夢裡重覆千百次的呼喚？


&nbsp;


為了與你隔世的相逢，


&nbsp;


我寧願承受著無可避免的花開花落，


&nbsp;


歷經了無數次的春來秋去，


&nbsp;


散落的花瓣凋謝了一季又一季的等待。


&nbsp;


即使哪天枯萎了只剩殘枝，


&nbsp;


仍會在空氣裡留下一縷彌漫的芬芳，


&nbsp;


只為了能讓你見證我堅守誓約的印記。



&nbsp;


今夜，花蕾綻放無聲，


&nbsp;


朵朵披上色澤鮮紅的孤獨外衣，



&nbsp;


默默的守候著前世曾許下的約定.......


&nbsp;


我是你前世種下的玫瑰，


&nbsp;


注定今世用愛來回報你的一生。
