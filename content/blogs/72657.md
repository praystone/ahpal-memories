&nbsp;

愛情裡沒有公不公平 

&nbsp;



&nbsp;

&nbsp;


有時候哭泣不是因為難過，

&nbsp;

有一些東西錯過了，就一輩子錯過了。

&nbsp;

人是會變的，守住一個不變的承諾，

&nbsp;

卻守不住一顆善變的心。

&nbsp;

有時候執著是一種負擔，放棄是一種解脫，

&nbsp;

一顆心屬於一個人，愛情裡什麼是公平。

&nbsp;

愛的深，傷的深，愛情裡沒有不公平，

&nbsp;

愛上不該愛的人，是永無天日的嘆息，

&nbsp;

愛了不愛你的人，是眼淚決堤的開始。

&nbsp;

&nbsp;

承諾是一張白紙，

&nbsp;

再厚的劇本也有了結局。

&nbsp;

我想我知道眼淚的味道，

&nbsp;

就算付出每一分每一秒我都不曾想逃，

&nbsp;

在這個世界上沒有恆久的幸福，

&nbsp;

只有瞬間的愜意和安適。

&nbsp;

也許無言才是最好的安慰，也許回憶是最好的結局，

&nbsp;

不要因為沒有陽光，而不走進春天。

&nbsp;

不要因為沒有歌聲，而放棄自己的追求。

&nbsp;

不要因為沒有掌聲，而丟掉自己的理想。

&nbsp;

&nbsp;

其實每一條都通往陽光的大道，都充滿坎坷，

&nbsp;

每一條通向理想的途徑，都充滿了艱辛與汗水。

&nbsp;

很多事情的發展注定有個結束，

&nbsp;

好好享受美麗的過程，

&nbsp;

擦身而過的時候，我們應該學會遺忘，

&nbsp;

放聲的笑一回，大膽的哭一場。

&nbsp;

抬頭望一望，一片燦爛的陽光，相信時間可以改變一切，

&nbsp;

不要輕易讓自己掉眼淚。

&nbsp;

&nbsp;

春有春的風情，夏有夏的烈艷，

&nbsp;

秋有秋的素潔，冬有冬的雅緻。

&nbsp;

人生各有各的美麗，各有各的瀟灑。

&nbsp;

你笑，全世界跟著你笑，

&nbsp;

你哭，全世界只有你一個人哭。

&nbsp;

當不能擁有時，

&nbsp;

唯一能做的就是令自己要學會遺忘。 


&nbsp;
