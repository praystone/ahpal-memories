1.


其實，


我不是一定要等你，


只是等上了，


就等不了別人了。


——《朝露若顏》


&nbsp;


2.


如果世界上曾經有那個人出現過，


其他人都會變成將就！


而我不願意將就。


——《何以笙簫默》


&nbsp;


3.


我不能給你全世界，


但是，


我的世界，


全部給你。


——《念念不忘》


&nbsp;


&nbsp;


4.


第一步，抬頭。


第二步，閉眼。


這樣，


眼淚就都流進心裡了。


我想起來了我從來沒有不喜歡你，


那些讓你傷心的難聽話，


全是我撒謊。


——《歲月是朵兩生花》


&nbsp;


5.


沒有我在家等著你，


不要，


忘了回家的路。


——《十年一品溫如言》


&nbsp;


&nbsp;


6.


一生一世……不離不棄！


你是我的……我亦是你的。


——《獨步天下》


&nbsp;


&nbsp;


7.


我知道她想要什麼，


可是我給不了她。


我給過你的，


再也給不了別人。


——《來不及說我愛你》


&nbsp;


8.


我已經暗戀他很久了，


如果我不走到他的前面，


他永遠不會看見我。


——《被時光掩埋的秘密》


&nbsp;


&nbsp;


9.


時間沒有等我，


是你忘了帶我走。


——《夏至未至》


&nbsp;


&nbsp;


10.


歲歲長相伴，


白頭不相離。


----------《長相思》


&nbsp;


11.


如果幸福不在巴黎，


就一定在別處。


可是我的世界已沒有巴黎，


只有你。


——《巴黎沒有摩天輪》


&nbsp;


&nbsp;


12.


你喜歡我，


因為我是個不錯的人，


但你愛他，


哪怕他是個錯的人。


——《許我向你看》


&nbsp;


&nbsp;


13.


遇見你，


我打開一扇門，


門後是天堂。


——《原來愛很殤》


&nbsp;


&nbsp;


14.


你的心，


是我去到世界盡頭、


也想回來的地方。


——《溫暖的弦》


&nbsp;


&nbsp;


15.


原來眼淚真的可以綿綿不絕,


而天堂卻比不上你對我的微微一笑。


——《一光年的距離有多遠》


&nbsp;


&nbsp;


16.


你轉身的一瞬，


我蕭條的一生。


——《何以笙簫默》


&nbsp;


17.


如果當初我勇敢，


結局是不是不一樣。


如果當時你堅持，


回憶會不會不這樣。


——《曾有一個人愛我如生命》


&nbsp;


&nbsp;


18.


明明是無所謂的東西，


一旦自己突然說好想要，


久而久之，


就真的很想要了。


我想要你。


——《牧小瘋的燃情歲月》


&nbsp;


&nbsp;


19.


有時候恨你，


更多的時候我愛你。


——《原來你還在這裡》


&nbsp;


&nbsp;


20.


曾經我們都以為自己可以為愛情死，


其實愛情死不了人，


它只會在最疼的地方扎上一針，


然後我們欲哭無淚，


我們輾轉反側，


我們久病成醫，


我們百煉成鋼。


你不是風兒，


我也不是沙，


再纏綿也到不了天涯。


——《致我們終將逝去的青春》
