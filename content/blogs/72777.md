&nbsp;

知足常樂



&nbsp;

&nbsp;


人之所以不快樂，就是計較的太多。

&nbsp;

不是我們擁有的太少，而是我們計較的太多。

&nbsp;

不要看到別人過得幸福，自己就有種失落和壓抑感。

&nbsp;

其實你只看到了別人的表面現象，

&nbsp;

或許他過的還不如你快樂。

&nbsp;

&nbsp;

人的欲望是無止盡的，人人都在追求高品質的生活，

&nbsp;

人人都想得到自己想要的東西，

&nbsp;

人人都在為了自己的目標，整天裏忙碌著，奮鬥著，

&nbsp;

得到了，開心一時，得不到，痛苦一世。

&nbsp;

世界上沒有完美無缺的東西，不完美其實才是一種美，

&nbsp;

只有在不斷的爭取，

&nbsp;

不斷的承受失敗與挫折時，才能發現快樂。

&nbsp;

&nbsp;

人之所以不知足，就是有著太多的虛榮心。

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

俗話說知足者常樂，

&nbsp;

但又有幾個人能達到這樣的境界。

&nbsp;

大千世界無奇不有，有著太多太多的誘惑，

&nbsp;

我們不可能不動心，不可能不奢望，不可能不幻想。

&nbsp;

面對著諸多的誘惑，有多少人能把握好自己，

&nbsp;

又有多少人不會因此而迷失自己？

&nbsp;

但話又說回來，有了知足心，哪會有上進心？

&nbsp;&nbsp;&nbsp;&nbsp; 
時代在發展，生活在繼續，

&nbsp;

我們需要不斷地去努力，去追求，

&nbsp;

如果只滿足於現狀，一味地沉浸在自己的知足裏，

&nbsp;

那還有什麼遠大的理想和追求？


&nbsp;

每個人對幸福的感覺和要求都不相同，

&nbsp;

一個容易滿足、懂得知足的人才更容易得到幸福。

&nbsp;

&nbsp;

曾經看到過這樣一句話：

&nbsp;

“幸福就如一座金字塔，是有很多層次的，

&nbsp;

越往上幸福越少，得到幸福相對就越難。

&nbsp;

越是在底層越是容易感到幸福；越是從底層跨越的層次多，

&nbsp;

其幸福感就越強烈。”

&nbsp;

&nbsp;

幸福其實就是一種期盼，是一種心靈的感受。

&nbsp;

只要我們用心去發現，用心去感受，

&nbsp;

你就會發現幸福其實就在我們身邊，

&nbsp;

只是這樣的幸福常常被我們忽略。

&nbsp;

人之所以活的累，就是想的太多。

&nbsp;

身體累不可怕，可怕的就是心累。

&nbsp;

心累就會影響心情，會扭曲心靈，會危及身心健康。

&nbsp;

其實每個人都有被他人所牽累，被自己所負累的時候，

&nbsp;

只不過有些人會及時地調整，

&nbsp;

而有些人卻深陷其中不得其樂。


&nbsp;
