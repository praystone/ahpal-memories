&nbsp;

&nbsp;&nbsp; 







&nbsp;


&nbsp;


&nbsp;


柴


&nbsp;


柴生火，賣火柴的小女孩擦亮火柴


&nbsp;


看到的是希望，火柴滅了希望散了


&nbsp;


愛情，有時候也是需要互相的取暖


&nbsp;


&nbsp;


&nbsp;


&nbsp;


米


&nbsp;


有些人選擇愛情，有些人選擇了米


&nbsp;


不能把愛情和米跟魚和熊掌做比較


&nbsp;


我堅信因為你，我可以倆者都兼得


&nbsp;


&nbsp;


&nbsp;


&nbsp;


油


&nbsp;


從超市買回了一瓶香醇濃的花生油


&nbsp;


廚房裏飄的油香都是那花生的味道


&nbsp;


每天一直都縈繞著我的思念和等待


&nbsp;


&nbsp;


&nbsp;


&nbsp;


鹽


&nbsp;


把鹽放進菜裏，才能顯出菜的味道


&nbsp;


鹽用的適當，適當了才能夠合口味


&nbsp;


合了口味的關鍵是心裏有一份寬容


&nbsp;


寬容的關鍵是有愛，愛是鹽的精華


&nbsp;


&nbsp;


&nbsp;


&nbsp;


醬


&nbsp;


在這裡的冬天空氣既潮濕而且陰冷


&nbsp;


燈光下，心中又不由自主的想起你


&nbsp;


就如同紅紅的辣椒醬被抹在心頭上


&nbsp;


只有一點卻讓我流下惹人愛憐的淚


&nbsp;


&nbsp;


&nbsp;


&nbsp;


醋


&nbsp;


淺嘗即止，話雖如此依然出現爭執


&nbsp;


人在激動的時候會挑選自己所知道


&nbsp;


的最凌厲的辭彙投擲對方傷害對方


&nbsp;


同時令自己一點後退的餘地都沒有


&nbsp;


相信總有不謝之花季，不老的傳說


&nbsp;


&nbsp;


&nbsp;


&nbsp;


茶


&nbsp;


七味之末，因此顯得愈發悠遠綿長


&nbsp;


忙碌如你，因此就把它留給我自己


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


別後的日子在茶葉的起伏中豐盈著


&nbsp;


彼此的理解和彼此的安慰溫潤清幽


&nbsp;


泛著些許的甜蜜也泛著些許的苦意


&nbsp;
