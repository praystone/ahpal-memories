心情短語精選


&nbsp;



既不回頭，何必不忘。


既然無緣，何須誓言。


&nbsp;



相愛的人，不一定會結婚，
而結婚的人又不一定是自己的意中人。


&nbsp;



今日種種，似水無痕。明夕何夕，妳已陌路。


&nbsp;



心沒有棲息的地方，到哪裏都是流浪.........要學會放開。


&nbsp;



男人因孤獨而優秀，女人因優秀而孤獨。


&nbsp;



這世界上有一個人是永遠等著你的，不管是什麼時候，
不管你是在什麼地方，反正你知道，總有這樣一個人。


&nbsp;



快樂要有悲傷作陪，雨過應該就有天晴。
如果雨後還是雨，如果憂傷之後還是憂傷，


請讓我們從容面對這離別之後的離別。
微笑地去尋找一個不可能出現的你！


&nbsp;



請不要欺騙善良的女孩。這個世界上，善良的女孩太少。


&nbsp;



有些事情本身我們無法控制，只好控制自己。


&nbsp;



不管從什麼時候開始，重要的是開始以後不要停止；
不管在什麼時候結束，重要的是結束以後不要後悔。


&nbsp;



我們確實活得艱難，一要承受種種外部的壓力，更要面對自己內心的困惑。在苦苦掙扎中，如果有人向你投以理解的目光，你會感到一種生命的暖意，或許僅有短暫的一瞥，就足以使我感動不已。


&nbsp;



後悔是一種耗費精神的情緒，
後悔是比損失更大的損失，
比錯誤更大的錯誤，所以不要後悔。


&nbsp;



天長地久有沒有？當然有！為什麼大多數人不相信有？


因為他們沒有找到人生旅途中最適合自己的那一個。
也就是冥冥中註定的那一個。為什麼找不到？


茫茫人海，人生如露，
要找到最合適自己的那一個談何容易？
你或許可以在40歲時找到上天註定的那一個，
可是你能等到40歲嗎？
在20多歲時找不到，卻不得不結婚，
在三四十歲時找到卻不得不放棄。
這就是人生的悲哀。


&nbsp;



每個人對待愛情的態度都會不一樣，
各人有各自的愛情原則，有自己接受的底線
——你最好先問問自己的原則和底線是什麼，
怎樣做能令內心的自己真的快樂。


&nbsp;



我們一生當中，並不可能只愛一個人，
但往往有一個人讓你笑得最甜，讓你痛得最深，
往往有一處美麗的傷口，成為你身體上不能癒合的一部分！


&nbsp;



有一種感覺總在失眠時，才承認是“相思”；
有一種緣分總在夢醒後，才相信是“永恒”；
有一種目光總在分手時，才看見是“眷戀”；
有一種心情總在離別後，才明白是“失落”。


&nbsp;



我們的人生，如果沒有了愛的存在，那該有多麼多麼的寂寞。


然而，愛情有時候更像是一個童話故事，永遠若即若離，永遠難於把握。


平淡的生活裏，我們不一定可以找到自己最理想也最完美的愛情。


可是，幸好，我們的心靈並沒有因此關閉那扇嚮往美好的門。


有時候，哪怕僅僅是紙上的愛情，也可以溫暖我們日漸荒蕪的心靈。


&nbsp;



浪漫是什麼？是送花？雨中漫步？樓前佇立不去？


如果兩人彼此傾心相愛，什麼事都不做，靜靜相對都會感覺是浪漫的。


否則，即使兩人坐到月亮上拍拖，也是感覺不到浪漫的。


&nbsp;



不管多大多老，不管家人朋友怎麼催，都不要隨便對待婚姻，
婚姻不是打牌，重新洗牌要付出巨大代價。


&nbsp;



也許，上天不給我的，無論我兩臂怎緊扣，仍然走漏；
給我的，無論過去我怎失手都會擁有。


&nbsp;



明知道是讓對方痛苦的愛就不要讓它繼續下去，割捨掉。
如果不行就將它凍結在自己內心最深的角落。


&nbsp;



我不知道我現在做的哪些是對的，那些是錯的，
而當我終於老死的時候我才知道這些。
所以我現在所能做的就是盡力做好每一件事，
然後等待著老死。


&nbsp;



沈溺於以前與回憶的人是一個很懦弱的人，
因為她（他）不敢勇敢地正視現實。
現實是什麼？現實就是變化。
沒有不變的感情，沒有不變的人。


&nbsp;



這個世界永遠充滿著誘惑。
就像猴子掰玉米那樣，
看到好的又把懷裏的扔了，
看到好的又把懷裏的扔了，
到了最後，留在懷裏的其實是個最小的。


&nbsp;



癡情的人永遠都抱著這樣的想法：
連我自己都被自己感動，她有什麼理由不被我打動呢？
但堅持不懈的追求只能證明你是一個堅持不懈的人，僅此而已。


&nbsp;



一個人一生可以愛上很多人的，
等你獲得真正屬於你的幸福之後，
你就會明白以前的傷痛其實是一種財富，
它讓你學會更好地去把握和珍惜你愛的人。


&nbsp;



愛是一種殘忍，只有在心中的天平上秤出自己在對方心中是否有愛的分量。


&nbsp;



思憶常會在夜靜燈昏時翻開甜酸苦辣也成了一道最淒美的風景線，
陳舊的美無法在代謝中泯滅。


&nbsp;



異地戀要求你要能夠忍受寂寞，
而且這種戀情需要一個大團圓的希望，
就算很渺茫也好。這是一種精神支柱，
是支撐著你堅持這段感情的信念。


&nbsp;



沒有一個完全契合你的人，沒有一段完美無缺的感情。
大家合不合適，大家完不完美，都需要雙方有所付出，
有所犧牲，彼此去創造。


&nbsp;



好男人不會讓心愛的女人受一點點傷，
決不會像陣風在深夜裏遊蕩，
好男人不會讓等待的情人心越來越傷，
孤單單看不見幸福回來的方向。
