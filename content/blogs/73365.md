在你非常愛一個人並最終決定和他結婚的時候，你一定對婚姻充滿著想像，好像所有的童話故事最完美的結局都是王子與公主終於結婚，從此過上幸福的生活。

所以看著童話長大的你也許沒有想過，所謂的幸福生活就是你的愛人每天都會因為諸如清晨誰先用盥洗室、晚餐由誰來做這樣的小事而與你爭執不休，你也被他的不解風情氣得大發雷霆。<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


既然真實的婚姻是這樣的，那麼我們只有摒棄了對婚姻的不切實際的幻想，才能更多地體會到婚姻裡的美好和快樂。


&nbsp;






&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


幻想１：你們會逐漸習慣與對方分享彼此的興趣。
事實：你以為你們會愛屋及烏地接受對方的一切，把他的興趣當作自己的興趣，你幻想著你們能夠舉案齊眉、琴瑟和諧，而這種幻想在當你被倔強的馬摔得遍體鱗傷後，就再也不想跟他一起去體會策馬揚鞭的威風。相比之下，你更願意蜷在家中的沙發裡，抱著乖巧的小狗看肥皂劇，而他則對你的興趣嗤之以鼻。
心情營救：與其勉強自己分享他的興趣，不如因各自不同的興趣而有永遠說不完的新鮮話題，只要在對方需要你與他一起分享快樂或痛苦的時候陪在他身邊就足夠了。各自擁有獨立的心理空間會使雙方更親密。


&nbsp;


幻想２：無論發生什麼分歧，你們都會想出一個折中的辦法。
事實：你會發現，婚後你的丈夫會為了一點小事而與你抬槓，而你自己也變得斤斤計較起來。
心情營救：兩口子吵架根本分不出誰對誰錯，所以別指望你們能心平氣和地找出一個令兩個人都滿意的折中的解決辦法，永遠別希望他能像你一樣，每到週末就迫不及待地想回家看望母親，也不必勉強自己非要認同他準備買進的那隻爛股票。發生分歧的時候只有一方做出讓步和暫時的容忍，你們的日子才可能告別戰火紛飛。這時候，平和的心態比什麼都重要。





幻想３：你們還會像以前那樣，當因為出差而暫時分別時，每天用電話追逐著彼此。
事實：婚後的你只有在無事可做或有事商量的時候，才會算計著在電話費打折的時段裡給他打電話，而且僅僅是就事論事，而不會像以前那樣拿著電話纏綿個沒完。至於你的丈夫，如果你出遠門了，建議你乾脆放棄在任何時間都能找到他的想法，他會像一隻撒出去的兔子一樣，在最快的時間裡跑得無影無蹤。
心情營救：其實，這樣又有什麼不好呢？只有自由呼吸才能保證身體的健康，對於婚姻也是這個道理呀！


&nbsp;


幻想４：婚後你們將熱衷於為對方做他喜歡吃的飯菜，並且看到他吃得津津有味，比自己吃還高興。
事實：除非你們當中有一個人持之以恆地熱愛廚藝，否則你們遲早都將對做飯深惡痛絕，並且對飯後的洗碗工作推三阻四。有的女士還經常因為丈夫自顧自地吃了她愛吃的菜而生氣，看來把愛情當作食糧的情景只是婚前的曇花一現了。&nbsp;
心情營救：婚姻是要靠雙方用心來共同經營的，其中也應該包括共同來經營你們的飯桌，試試每餐兩個人各做一個自己喜歡吃的菜，再合作一道雙方共同喜愛的菜，這不僅可以增添許多生活樂趣，還是解決做飯問題最公平的方法。


&nbsp;


幻想５：婚後你們依然會像婚前那樣不時地徹夜長談。
事實：婚後你才發現，丈夫好像婚前把要說的話都對你說完了，對你的喋喋不休，他總是以最簡短的詞句來回答，甚至有時竟然充耳不聞，裝聾作啞。當然你們也會有徹夜說話的時刻，但那很可能是徹夜地爭吵。
心情營救：不充足的睡眠對生理和心理的健康並不是什麼好事，而且徹夜長談，應該不如擁有一次美好的性愛後相擁而眠更有樂趣。如果你們實在缺乏交談，可以增加一些外出就餐的機會，或在做家務和看電視時聊一會兒，或者你可以準備一個筆記本，把想說的重要的話寫下來留給對方，日久天長，你翻看時會發現你們的交談並不比徹夜長談少。


&nbsp;


幻想６：婚後他將遵守向你求婚時的許諾，為了你他會改變所有的缺點。
事實：婚後的他像完成了一項重要使命一樣，不僅將自己的承諾忘得一乾二淨，還因為完全地鬆懈而增加了更多你無法容忍的毛病。你在心裡痛罵他是個騙子，手上還得無奈地給他洗臭氣熏天的襪子，收拾永遠凌亂不堪的房間。
心情營救：不要指望利用婚姻來改變彼此，婚前的你也曾鄭重地向他表示會做一個賢妻良母，而現在卻被他和孩子稱為“凶神惡煞”，那麼己所不欲，勿施於人，嘗試著慢慢接受或淡化他的某些缺點。多看看他的可愛之處，快樂與不快樂其實僅僅是看待問題的角度不同。


&nbsp;


幻想７：婚後你們將毫無保留地把自己的一切告訴對方。
事實：仔細注意你們每天的交談，是不是都是些“晚上吃什麼？”、“週末回誰家？”、“又該交水電費了！”之類雞毛蒜皮、無關緊要的話，而你心裡真正想的，比如“真想和電視上那個英俊的男影星共進晚餐”、“這筆錢是不是可以留作私房錢”之類的話，你肯定不能告訴他，而他肯定也沒告訴過你他的前一位女友比你更性感，或者公司的同事對他暗送秋波。婚後的你們都學會了把真正重要的事情藏在心裡。
心情營救：“距離產生美”尤其適用於現代婚姻，有所隱瞞說明你們還是非常在意彼此的，那麼只要無傷婚姻的實質，留些滋味在心裡回味吧。


&nbsp;


幻想８：婚後他的錢即是你的錢，都應該交給你保存。
事實：你總會在他的錢包裡發現來路不明的錢，而他掙了一筆額外收入後，首先想到的竟是為自己買一部數碼相機或幾套遊戲軟件。你們之間在金錢上的關係有點像“貓捉老鼠”，你總是在他出其不意、毫無防備的時候突然發問，企圖套出他的小金庫裡藏了多少錢。
心情營救：不要說他的錢即是你的錢，而要對他強調“我們掙錢是為了家，掙來的錢是這個家的”，相信大部分男人都是有家庭責任感的。而且丈夫的錢就像握在你手中的沙子，攥得越緊漏得越多，不如適度放開，他也就不再對你嚴加防備。


&nbsp;


幻想９：如果你們其中一方生病，任何一方都要衣不解帶地侍奉左右。
事實：即使你發燒在家，他也會照常出去應酬、晚歸，而每當他生點小病就大呼小叫時，你都會有克制不住的厭煩心理，甚至有時竟然有了逃離的念頭。
心情營救：不要過於要求自己和他人太完美，既然你會為了自己養的小狗生病而奔走落淚，那麼用一些同樣的耐心給你的愛人，此時的他，無論是體能還是心力，都是脆弱的。
