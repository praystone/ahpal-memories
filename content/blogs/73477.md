來碗幸福人生湯 


&nbsp;


&nbsp;


世間沒有一種具有真正價值的東西，是可以不經過


艱苦辛勞而能夠得到的。──美國發明家湯瑪斯•


&nbsp;


阿爾瓦•愛迪生


&nbsp;



有個年輕人最近被公司裁員，好幾個月都找不到工 rn&nbsp;


作。心情已經夠低落了，偏偏女友又提出分手，讓


&nbsp;


他萬念俱灰，躲在家中足不出戶，時間長達好幾個


&nbsp;


星期。


老母親看了既心疼又焦急，硬把兒子從房間裡拖出


&nbsp;


來，並對他說：「你小時候，媽媽常熬雞湯給你


&nbsp;


喝。今天我也買了材料回家，你要不要嚐一嚐？」


兒子無精打采點了點頭



&nbsp;

&nbsp; 

突然，母親「砰」地一聲，把幾支生的雞腿丟在兒

&nbsp;

&nbsp;

子眼前，說：「湯還沒煮呢！你先啃雞腿吧！」


兒子抬起頭，詫異地說：「媽，這雞肉還是生的，

&nbsp;

&nbsp;

不能吃呀！」

母親又陸陸續續把一些東西丟在兒子眼前：「不然

&nbsp;

&nbsp;

你先吃一點中藥材？還是嚼乾香菇？對了，雞湯也

&nbsp;

&nbsp;

有加鹽，不然你先吃一點鹽？」

兒子驚慌地看著母親，覺得媽媽一定是瘋了：

&nbsp;

&nbsp;

&nbsp;

「媽……您沒事吧？這些東西不能吃的！」

&nbsp;


母親這才柔聲地說：「直接吃這些東西，一定難以


&nbsp;


入喉；但只要把這些東西加在一起，再經過小火熬


&nbsp;


煮，就會成為美味的雞湯！你現在遇到的痛苦，也


&nbsp;


許讓你難熬，但誰說這些痛苦，不會成就你美好的


&nbsp;


人生呢？」


兒子這才瞭解母親的苦心，決定振作起來。

多數人都希望自己的生活「一帆風順」，但一帆風


&nbsp;


順的人生，真的是值得羨慕的嗎？


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;  



多年前有一則社會新聞：一個年輕人自殺身亡，自 rn&nbsp;


殺的原因，竟然只是沒有被公司選為新任經理。因 


&nbsp;


為他出生健全、富裕的家庭，一向衣食無缺；他從


&nbsp;


小到大都是資優生，一路保送、跳級，畢業後又有


&nbsp;


許多大企業爭搶……換句話說，他的人生一直都非


&nbsp;


常順利，幾乎沒有經歷過挫折，所以一點小小的挫


&nbsp;


敗，就把他徹底壓垮了！


&nbsp;


記者訪問時，他的父親老淚縱橫地說：「都是一帆


&nbsp;


風順的生活，害慘了他啊！」


沒有人知道上天為什麼要給我們諸多試煉，但請讓


&nbsp;


我們永遠記住：我們所受的痛苦，永遠不會白費。


&nbsp;


因為曾經困頓，我們才能學會感恩知足；因為曾經


&nbsp;


受挫，我們因此學會努力；因為我們都曾經遭受背


&nbsp;


叛，所以知道怎麼看人；因為曾經飽嚐失戀的痛


&nbsp;


&nbsp;


苦，我們才終於瞭解該怎麼去愛一個人……


&nbsp;


如果人生像一鍋湯，那麼湯料就是挫折，湯底就是


&nbsp;


淚水。但經過時間的熬煮，這些讓我們難以下嚥的


&nbsp;


種種，也能成為一鍋「幸福之湯」！
