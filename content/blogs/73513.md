&nbsp;

綿綿相思無藥醫 雖然分開也抹慣習

&nbsp;

親像秋風彼呢冷 陣陣吹來的畏寒

&nbsp;

誰人知影 失去了所愛的感覺

&nbsp;

&nbsp;

&nbsp;

放抹落心不想你 思念槌心也未覺醒

&nbsp;

親像花開彼呢水 無奈風雨彼呢大

&nbsp;

欲哭無聲 風中的誓言無靠岸

&nbsp;

&nbsp;

&nbsp;

對你的愛 親像海水還抹乾

&nbsp;

對你的關懷 是永遠抹變卦

&nbsp;

我是世間最最愛你的彼個人

&nbsp;

&nbsp;

&nbsp;

偏偏為情 傷心也是我

&nbsp;

深深的愛 陪伴寂寞甲孤單

&nbsp;

綿綿的約束 也已經無卡紙

&nbsp;

我是世間最最愛你的彼個人

&nbsp;

放阮一個你甘會快活
