戀人間最遠的距離




&nbsp;

&nbsp;


戀人間最遠的距離，

&nbsp;

不是空間，也不是長度，所以無法測量。

&nbsp;

那是彼此心裏的感受，無法衡量的一種距離，但是，

&nbsp;

我們卻可以在見面的瞬間立刻察覺出遠近。


&nbsp;

愛情其實沒有道理可言，

&nbsp;

深愛對方的那種無怨無悔，也不是旁人可以理解的，

&nbsp;

但是戀人們自有一套公式，

&nbsp;

知道愛有多深，知道思念有多長，當然；

&nbsp;

也知道忌妒和猜疑的背後暗藏一把利刃，

&nbsp;

知道所有的不信任都會累積彼此心中，

&nbsp;

直到有一天，愛情被驅逐出境，被利刃砍傷。


&nbsp;

對愛情失溫的戀人，

&nbsp;

即使天天見面，朝夕相伴，也無法跨越眼底的陰霾，

&nbsp;

再也嘗不到愛情的甜美。

&nbsp;

彼此深愛的戀人們，就算相隔半個地球，

&nbsp;

也無法隱藏那躲在心底的濃濃愛意。


&nbsp;把距離當作無法相愛的藉口，

&nbsp;

是最不負責任的愛人，不值得我們用心對待。

&nbsp;

&nbsp;

戀人間最遠的距離，

&nbsp;

其實是因為誤會而停止相愛，

&nbsp;

在你眼裏不再有我，就如同「傲慢與偏見」的故事，

&nbsp;

雖然彼此相愛，

&nbsp;

但是在對方的眼底卻看不見自己，

&nbsp;

即使將戀人擁入懷中，也無法感受絲毫愛情的美好。

&nbsp;

直到卸下彼此心中的成見，解開誤會的那一瞬間，

&nbsp;

才恍然大悟，最愛的人就在身邊。 


&nbsp;
