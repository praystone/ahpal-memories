妳知不知道?

&nbsp;

妳傷了對妳說我等妳的人

&nbsp;

&nbsp;

他每天一下班馬上開機上,即時通,FB

&nbsp;

等待妳上線和妳講話

&nbsp;

他總是想把心裡話告訴妳

&nbsp;

&nbsp;

妳記不記得妳有時候會跟他說妳的心裡話

&nbsp;

妳說:喜歡不能不喜歡也不對

&nbsp;

妳說:不能否認他的出現深深的撼動妳

&nbsp;

&nbsp;

妳知不知道對他來說

&nbsp;

他高興但又難過

&nbsp;

他高興是因為他真的有打動過妳的心

&nbsp;

他難過的是打動了妳的心

&nbsp;

為什麼妳還是無動於衷

&nbsp;

&nbsp;

妳曾跟他說不要等我我不值得

&nbsp;

可是對他來說妳是最值得的!

&nbsp;

他還是仍然堅持的對妳說:我等妳

&nbsp;

妳卻只輕輕的說:&nbsp; 笨蛋

&nbsp;

&nbsp;

每當他有不想說的事

&nbsp;

而妳總是會倒數5 4 3 2 1

&nbsp;

讓他說出來

&nbsp;

&nbsp;

但說出來了妳有真正體會過他的感覺嗎??

&nbsp;

一天沒跟妳傳簡訊講電話

&nbsp;

或是遠遠看妳一眼

&nbsp;

他那一天都開心不起來

&nbsp;

&nbsp;

後來他把全部的心裡話都告訴妳

&nbsp;

妳卻跟他說:對不起

&nbsp;

妳知不知道他心裡有多痛?

&nbsp;

&nbsp;

妳曾告訴他妳有男朋友但不會有結果

&nbsp;

這句話對他來說他不是沒機會

&nbsp;

&nbsp;

可是妳知道嗎?

&nbsp;

妳已經把他的關心當做理所當然

&nbsp;

是因為妳仗著他不會不要妳嗎??

&nbsp;

還是有特別的原因?

&nbsp;

&nbsp;

妳的冷淡或者對妳來說的謊言

&nbsp;

正一點一滴的傷害他

&nbsp;

妳的傷害他不能跟誰抱怨!

&nbsp;

因為他跟妳說我等妳!

&nbsp;

&nbsp;

這是他的選擇是好是壞都要承受

&nbsp;

&nbsp;

他不計較的付出妳卻不在意

&nbsp;

妳不開心他陪著妳逗妳開心

&nbsp;

妳開心他陪著妳開心

&nbsp;

可是他的難過妳看到了嗎??

&nbsp;

&nbsp;

外表堅強的他內心反而很脆弱

&nbsp;

&nbsp;

妳常跟他說不要等我

&nbsp;

他雖然堅持的說我等妳可是眼框都紅了妳知道嗎?

&nbsp;

這句話足夠讓他痛上百次上千次

&nbsp;

&nbsp;

妳知不知道?

&nbsp;

妳傷了真正愛妳的人

&nbsp;

妳知不知道? 

&nbsp;

妳傷了默默為妳付出的人

&nbsp;

妳知不知道?

&nbsp;

妳傷了即使妳不在意他&nbsp; 他還是一直等妳的人

&nbsp;

妳知不知道?

&nbsp;

妳傷了對妳說我等妳的人!

&nbsp;

請好好珍惜對妳說:【我等妳的人】♥...
