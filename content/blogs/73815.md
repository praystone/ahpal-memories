&nbsp;

&nbsp;

朋友結婚七年，分居五年，

最後終於決定和丈夫離婚，


簽字以後，她有無限的感慨，卻也覺得萬分輕鬆。


十二年了，她用這麼長的時間證明自己努力過了，


但放手的時候，遺憾還是無法防備地湧上心頭。


&nbsp;


&nbsp;


&nbsp;


　　　要一起拖到最後　



&nbsp;


&nbsp;


她問我倆：「婚姻，究竟要如何經營呢？」


我倆回答說：「婚姻，就像兩個人拖著一個旅行箱，


裡面裝著滿滿的幸福和辛苦，一定要一起拖到最後。


如果，其中一個人放手，就會拖不動。」


&nbsp;


&nbsp;


婚姻是兩個人共同的責任！


從兩人決定結為夫妻開始，就必須共同承擔這個責任。


因為，幸福的行李箱裡，裝的是兩個人共同的用品，


而不是單方面的衣物。


倘若其中一個人很自私，不夠盡力，婚姻就會出問題。


&nbsp;


&nbsp;


例如：丈夫貪玩，不顧太太感受，這就是自私的開始。


當太太發現丈夫經常晚歸、可能有了外遇，


忿恨不平的心就是要為自己討回公道，


若無法主張自己的權益，就很容易走上離婚一途。


&nbsp;


&nbsp;


兩個人的關係發展到這裡，無異於雪上加霜。


太太卻沒有想到，丈夫固然有錯，


卻不必因為丈夫犯錯而減損自己對婚姻該有的責任與付出。


總有一天，丈夫迷途知返， 兩人還是可以再度攜手。


除非，丈夫的越軌行為已經很明顯的是棄家於不顧，


只剩太太一個人拖著沉重的行李箱，


拖到走不動時，逼不得已就只好放手。


&nbsp;


&nbsp;


放手未必不幸福　　　　


&nbsp;


&nbsp;


放手之後的行李箱，也未必就不能幸福。


記得把跟對方有關的物品清理出來，


該還的還，該丟的丟，重量減輕、體積變小，


自己還是可以帶著它走。


&nbsp;


&nbsp;


直到下一次碰到另一個要求結為伴侶的人，


再認真考慮要不要讓對方的物品裝進來，


只要兩個人願意共同承擔責任，


願意同心協力一起拖著行李箱，


就能走到天涯海角，即使辛苦，也是幸福。
