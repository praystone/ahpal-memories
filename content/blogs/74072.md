很多事情，沒走過就別說了解什麼




&nbsp;



很多事情，只能默默才能得到尊重



&nbsp;



很多事情，別只看著外表就下定論



&nbsp;



很多事情，不是說要就要說有就有



&nbsp;



很多事情，要多看才能了解到事情



&nbsp;



很多事情，別只聽別人口中所聽來



&nbsp;



很多事情，要得去了解才會有真相



&nbsp;



很多事情，不是不願意給你知道的



&nbsp;



很多事情，要順著別人才能繼續走



&nbsp;



很多事情，很複雜但是別太早放棄



&nbsp;



很多事情，我們很多不了解得了解



&nbsp;



&nbsp;

 &nbsp; &nbsp;

很 多 時 候

&nbsp;

很多時候，一句關心的話，
&nbsp;

總是因為許多忙碌，暫時放下而忘了說，
&nbsp;

其實很多時候，這些話不能等，

也不能期望自己想起來時再說。
&nbsp;

或者，她給你關心時，你才予以回應，
&nbsp;

你才開口，你也正同樣關心著她。
&nbsp;

總是遲到的關懷，久了以後她怎麼相信你的真誠，
&nbsp;

相信你也有同樣掛念的心。

&nbsp;

很多時候，愛一個人，要說出口，
&nbsp;

不要認為她可以感受你的心意，就不需再說。
&nbsp;

愛一個人，卻也不能只是掛在嘴邊說，
&nbsp;

沒有真正的行動表現，她一樣無法感受。
&nbsp;

愛，是在別人的需要上，看到自己的責任，
&nbsp;

以尊重的態度去承擔這份愛。

&nbsp;

很多時候，人們只期待別人對自己的付出，
&nbsp;

然後再評估自己該回饋些什麼，
&nbsp;

這讓愛情中的施與受，變成了一種交換的條件，
&nbsp;

卻還渴望得到更多。

很多時候，你只憑自己的需求，
&nbsp;

要求別人必須接受你的的安排，好像理所當然。
&nbsp;

遇到拒絕，只認為是別人失去了你給的機會，
&nbsp;

而不願意思考，自己不被接受的理由，
&nbsp;

甚至認為，別人的拒絕是別人的損失。

&nbsp;

很多時候，人都以為自己是最重要的，
&nbsp;

以為自己會帶給別人幸福，卻只是不斷追求自己想要的，
&nbsp;

不肯認真去面對，該給對方再多些什麼。

&nbsp;

很多時候，人總是把自私放在最前面，
&nbsp;

認為錯誤或遺憾都是別人造成的，
&nbsp;

責任對你來說，輕易的就有千百種藉口可以推拖。
&nbsp;

很多時候，人們可以找各種不同的事情來做，
&nbsp;

掩飾自己的孤單和寂寥，
&nbsp;

當你面對生活中親近的人，卻無言以對，
&nbsp;

有沒有想過，你已高估了自己，
&nbsp;

如果不能放開胸懷，回想你的初衷，

又如何能活的悠然自在。
