&nbsp;


&nbsp;


&nbsp;


好朋友是應該相互欣賞，


&nbsp;


&nbsp;


而不是相互利用。


&nbsp;


&nbsp;


好朋友只能在同一階層中產生，


&nbsp;


&nbsp;


而窮人和富人，百姓與達官，


&nbsp;


&nbsp;


草根與明星，白丁與學者


&nbsp;


&nbsp;


則比較難成為真正意義上的朋友。


&nbsp;


&nbsp;


因為不在同一階層，


&nbsp;


&nbsp;


便很難對其階層的深刻體會與感悟。


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


飯應該一口一口的吃，


&nbsp;


&nbsp;


事要一點一點的做。


&nbsp;


&nbsp;


沒有一蹴而就的事情，


&nbsp;


&nbsp;


所以就不應該疲於奔命。


&nbsp;


&nbsp;


生命，應該活得從容。


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


任何事物都是有一體兩面的，


&nbsp;


&nbsp;


有時候甚至沒有對錯，


&nbsp;


&nbsp;


你以為錯的，在別人看來或許是對的。


&nbsp;


&nbsp;


而你竭盡全力為之奮鬥的，


&nbsp;


&nbsp;


卻很有可能正是別人想擺脫和拋棄的。


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


生活品質的優劣，


&nbsp;


&nbsp;


完全取決於自己的心態。


&nbsp;


&nbsp;


珍饈美味，觥籌交錯間


&nbsp;


&nbsp;


如果掩飾的是爾虞我詐，


&nbsp;


&nbsp;


則遠不如三五知己坐，


&nbsp;


&nbsp;


淡茶話家常來得可心。 


&nbsp;


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


我們對孩子溺愛


&nbsp;


&nbsp;


就像高脂高糖一樣危害著他們的健康，


&nbsp;


&nbsp;


我們害怕他們走彎路。


&nbsp;


&nbsp;


我們擔心他們吃苦頭，


&nbsp;


&nbsp;


我們憂慮他們經風雨。


&nbsp;


&nbsp;


我們全家人為他們搭起了大棚，


&nbsp;


&nbsp;


然後呆呆地望著他們柔弱的發育成長。


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


對待父母再不可做薄養厚葬的傻事了，


&nbsp;


&nbsp;


他們那一輩子受的磨礪太多了，


&nbsp;


&nbsp;


善待他們就是善待我們的良心。


&nbsp;


&nbsp;


&nbsp;


說起善待父母都很心疼錢的，


&nbsp;


&nbsp;


但要動動腦筋事情就會圓的完成； 


&nbsp;


&nbsp;


比如，可以去酒店訂一份極品燕窩湯，


&nbsp;


&nbsp;


端回家告訴父母是在小攤上買的銀耳湯，


&nbsp;


&nbsp;


然後看著他幸福的享用。


&nbsp;


&nbsp;


&nbsp;


明白：


&nbsp;


&nbsp;


職位只不過是一個杯子，


&nbsp;


&nbsp;


而你的修養和品性才是杯中的尤物，


&nbsp;


&nbsp;


夜光杯中盛的未必就是葡萄美酒，


&nbsp;


&nbsp;


也可能是一杯濁水，


&nbsp;


&nbsp;


粗瓷盞裏不見得就是白開水，


&nbsp;


&nbsp;


很可能是泡的一盞極品龍井。


&nbsp;


&nbsp;


個中的品質全在自己的後天造化！！！


&nbsp;
