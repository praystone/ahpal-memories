&nbsp; 
生活是一望無際的大海，
人便是大海上的一葉小舟。
大海沒有風平浪靜的時候，
所以人也總是有歡樂也有憂愁。 


&nbsp; 


&nbsp;

守住一顆寧靜的心，
你會明白博大可以稀釋憂愁，
寧靜能夠驅散困惑。

&nbsp;

當無名的煩惱襲來，
失意與仿徨燃燒著每一根神經。
但是，別忘了守住一顆寧靜的心，
痛苦將不再有。


&nbsp;





&nbsp;


每個人的前面，
都有一條通向遠方的路，
崎嶇但充滿希望。


&nbsp;

在芬芳甘甜的泥土氣息中
尋找一絲的寧靜
於是，心中便多了一份慰藉與欣喜。

&nbsp;



&nbsp;


所以，主宰人的感受的，
並非歡樂和痛苦本身，
而是心情。


&nbsp;



當生活的困擾襲來，
請丟下負荷，
仰頭遙望明麗、湛藍的天空，
讓溫柔的藍色映入心田。






&nbsp;


當層層的失意包圍，
請打開窗戶，
讓沁人心脾的新鮮空氣走進來。


在芬芳甘甜的泥土氣息中，
尋找一絲的寧靜，
於是，心中便多了一份慰藉與欣喜。

&nbsp;



&nbsp;


當無奈的惆悵湧來，
請擦亮眼睛，
看夕陽的沈落。


&nbsp;



聽蟲鳴鳥叫，
擡頭數天上閃爍的星星。
於是，一切令人煩惱的嘈雜漸漸隱去，
擁有的是一顆寧靜的心。


&nbsp;





&nbsp;


守住一顆寧靜的心，
你會由衷地感嘆：
即使我不夠快樂，
也不要把眉頭深鎖。


&nbsp;



是的，人生本短暫，
沒有人知道遠方究竟有多遠，
為什麽還要栽培苦澀?


&nbsp;





&nbsp;


守住一顆寧靜的心，
你會明白博大可以稀釋憂愁，
寧靜能夠驅散困惑。


&nbsp;



打開你的心靈之窗，
讓快樂的陽光湧進來，
寧靜之心便有了一支，
永不熄滅的快樂之歌。
