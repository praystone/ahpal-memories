&nbsp;

&nbsp;











&nbsp;



&nbsp;


人最軟弱的地方，是捨不得。捨不得一段不再精彩的感情，捨不得一份虛榮，捨不得掌聲。



&nbsp;


&nbsp;


我們永遠以為最好的日子是會很長很長的，不必那麼快離開。 就在我們心軟和缺乏勇氣的時候，最好的日子毫不留情地了。



&nbsp;


&nbsp;


這個世界上，總有一個人在某處等你。不在這裏，不是此時，便會在那裏，是彼時，等你。
&nbsp;


&nbsp;


&nbsp;


有一個可以想念的人你就是幸福的.



&nbsp;


&nbsp;


我們再也回不去了 , 我們不可能再有一個童年；不可能再有一個初中；不可能再有一個初戀；不可能再有從前的快樂、幸福、悲傷、痛苦。昨天，前一秒，通通都不可能再回去。
&nbsp;


&nbsp;


&nbsp;


生命原來是一場無法回放的絕版電影。



&nbsp;


&nbsp;


沒有人有耐心聽你講完自己的故事，因為每個人都有自己的


話要說；



&nbsp;


&nbsp;


沒有人喜歡聽你抱怨生活，因為每個人都有自己的苦痛；



&nbsp;


&nbsp;


世人多半寂寞，這世界願意傾聽，習慣沈默的人，難得幾個。 



&nbsp;


&nbsp;


我再也不想對別人提起自己的過往，那些掙紮在夢魘中的寂寞，荒蕪，還是交給時間，慢慢淡漠.



&nbsp;


&nbsp;


不要想如果…… 生命中不可承受之情，就在於人生沒有重來的機會。



&nbsp;


&nbsp;


如果當初如何如何，現在就不會怎樣怎樣……每一個岔口的選擇其實沒有真正的好與壞，只要把人生看成是自己獨一無二的創作，就不會頻頻回首如果當初做了不一樣的選擇。……



&nbsp;


&nbsp;


人生只售單程票，過去的就過去了，更重要的是走好後面的路。



&nbsp;


&nbsp;


遺忘，是我們不可更改的宿命，所有的一切都像是沒有對齊的圖紙。 從前的一切回不到過去，就這樣慢慢延伸，一點一點地錯開來。



&nbsp;


&nbsp;


也許錯開了的東西，我們真的應該遺忘了。
&nbsp;
&nbsp;


&nbsp;


別讓深愛變成一種痛 。
&nbsp;


&nbsp;


&nbsp;


如果你不愛一個人，請放手，好讓別人有機會愛她。如果你愛的人放棄你，請放開自己，好讓自己有機會愛別人。——



&nbsp;


&nbsp;


愛一個人不一定要擁有，但擁有一個人就一定要好好的去愛他。



&nbsp;


&nbsp;


生命中令人悲傷的一件事是你遇到了一個對你來說很重要的人，但卻最終發現你們有緣無份，因此你不得不放手。
&nbsp;


&nbsp;


&nbsp;


一世容顏，過路的風景 —— 紅塵中，我們擦肩而過，到底，誰是誰的風景……我只知道當距離不再是距離的時候，我們一定會相遇，結成水，凝成冰，亦或，化作塵埃……但願你是我最美的風景，我是你久等的歸人
&nbsp;


&nbsp;


&nbsp;


生命中，不斷的有人離開或進入。於是，看見的，看不見了；記住的，遺忘了。
&nbsp;


&nbsp;


&nbsp;


生命中，不斷的有得到和失落。於是，看不見的，看見了；遺忘的，記住了。



&nbsp;


&nbsp;


然而看不見的，是不是等於不存在？記住的，是不是永遠不會消失？
&nbsp;


&nbsp;


&nbsp;


我們一生當中，並不可能只愛一個人，但往往有一個人讓你笑得最甜，讓你痛得最深，往往有一處美麗的傷口，成為你身體上不能愈合的一部分！因為陌生，所以勇敢，因為距離，所以美麗。
&nbsp;


&nbsp;


一段不被接受的愛情，需要的不是傷心，而是時間，一段可以用來遺忘的時間。



&nbsp;


&nbsp;


一顆被深深傷了的心，需要的不是同情，而是明白。
&nbsp;


&nbsp;


&nbsp;


因為愛過，所以慈悲；因為懂得，所以寬容。 



&nbsp;


&nbsp;


幸福不是終點 幸福是努力走過的道路，路上遇到的愛與感動，路上遇到的風雨、挫折、痛苦一起構成了這條路。 也是因為有了它們，我們才明白了幸福的真諦。
&nbsp;


&nbsp;


當你一個人的時候，別想兩個人的事，把回憶丟在一旁；
&nbsp;


&nbsp;


&nbsp;


當你一個人的時候，只想高興的事，把憂傷拋在腦後；
&nbsp;


&nbsp;


&nbsp;


當你一個人的時候，來到一個人的浪漫，釋放你的情感，敞開你的心靈。



&nbsp;


&nbsp;


其實一個人的時候，心在隱隱作痛，淚在蠢蠢欲動。
&nbsp;


&nbsp;


&nbsp;


幸福的時刻，一半是和你在一起，一半是在夢裏；
&nbsp;


&nbsp;


&nbsp;


痛苦的時刻，一半是分離一半是默默地想著你......&nbsp;
