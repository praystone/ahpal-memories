&nbsp;



妻子：『我跟你講什麼，你總是這耳朵進，



那耳朵出，講跟不講都一樣。』



&nbsp;



丈夫：『我跟妳講什麼，妳總是兩隻耳朵進，



一張嘴巴出，講比不講更糟。』



&nbsp;



在這個日益講究溝通的年代，



人們似乎變得愈來愈難以溝通



你可以隨便去問一個人際關係不好，



或是夫妻失合的人，為什麼會這樣？



&nbsp;



如果他們有想過真正的原因，



通常都會得到同一個答案，



就是──我們根本無法溝通。



&nbsp;



這是真的，這世界上所有的衝突、



誤解大都是因為溝通不良所造成。



&nbsp;



你說了一些話，但對方卻將它想成另一些話；



或者對方說了一些事，而你卻將它當成是另外一件事。



&nbsp;



你們只關心著自己想說的話，或只聽進去自己想聽的話，



這也難怪雙方的『溝』會愈挖愈深，愈挖愈『不通』。



&nbsp;



到處普遍都有這種情形，



許多婚姻諮詢顧問和離婚專業律師會告訴你，



他們天天在聽委託人抱怨：



『他（或她）根本沒在聽我說話！』



&nbsp;



不少企業的老闆、職場的主管也常有過類似的煩惱，



他們以為已經把自己的意思說得夠清楚了，



卻發現下面的人根本沒聽到他們說了什麼。



&nbsp;



你也有相同的困擾嗎？



或者你是他們所說的那種人？



&nbsp;



傑克是夢幻西餐廳裡新來的服務生。



&nbsp;



這天晚上有兩個客人用完主菜牛排之後，



傑克走過去幫他們把餐盤收走，並問他們，



飲料是要咖啡還是茶。



&nbsp;



一個人說：『我要茶。』



&nbsp;



另一個人說：



『我也是，麻煩幫我看一下裝紅茶的玻璃杯乾不乾淨。』



&nbsp;



一會兒，傑克端來兩杯茶，問他們：



『這是你們的茶，請問哪位先生要乾淨的杯子？』



&nbsp;



你可曾注意到這種情形？



&nbsp;



當別人正對著你說話時，你是那麼地忙碌，



忙著準備你要接著說什麼、忙著弄清楚對方說的是對或錯，



或是你的腦子已被別的人、別的事塞滿了……



&nbsp;



所以你只能聽到片段的訊息，最後的結果也就『半調子』，



就像那位服務生一樣。



&nbsp;



這就是大家溝通不良的主要原因──根本就沒有在溝通。



『傾聽』才是溝通的第一步



&nbsp;



許多人常會用主觀認知來揣測說話者的意思，



並先入為主地下判斷，因而無法真正聽進去對方所說的話；



其次，聽者也可能急於將自己的感受、



經驗或意見告訴對方，以致於最後常變成了雞同鴨講、各說各話。



&nbsp;



你可以注意一下，兩個人在談論某件事情時，



他們會從別人的談話裡抓幾句話，



然後將自己想說的話依附在那些話上面，再繼續講。



&nbsp;



&nbsp;



溝通已經變成這麼大的一個難題，



每一個人都覺得無法跟別人溝通，問題到底出在哪裡？



&nbsp;



在於願意『傾聽』的人實在太少，不是嗎？



&nbsp;



我有一位病人，曾陷入沮喪憂鬱的深淵中，



她想把自己的感受告訴父母。



&nbsp;



她第一次說：『我覺得了無生趣。』可是父母毫不在意。



&nbsp;



後來她又對父母說她不想活了，但雙親仍不以為意，



只回道：『別再胡思亂想了！』



&nbsp;



她終於自殺，最後所幸救活。



&nbsp;



當父母趕到醫院才心急如焚地說：



『妳好傻，為什麼這麼做？



有什麼不能解決的，為什麼不早告訴我們。』



&nbsp;



各位不難想像，聽到這話的女孩，心裡會有多難過。



&nbsp;



用心『傾聽』是一種愛的表現，



而家庭或婚姻則是這種表現的最好場所。



&nbsp;



可惜的是，很多父母、配偶從不用心聽對方說話。



&nbsp;



『傾聽』代表耐心、開放與想要瞭解對方的誠意，



這些都屬成熟人格的修養。



&nbsp;



心理醫師在協助家庭或婚姻失和時，



最主要的工作往往就是教他們彼此『傾聽』。



&nbsp;



因為光說不聽、聽了卻不瞭解，



就好像把一截電線剪成兩段，



然後插入插頭，還指望某個東西會發亮一樣，你想，



這可能嗎？



&nbsp;



要真正的聆聽，就必須把所有的成見、預設、判斷、



信仰都擺在一邊。



&nbsp;



只要你的心處在接受的狀態，



你才可能進入對方的內心世界，



真正瞭解『他在說什麼？』『她的意思是什麼？』



溝通的目的是『瞭解』而非『改變』



&nbsp;



伏爾泰曾說：『通往內心深處的路是耳朵。』



&nbsp;



早在兩千年前，希臘哲人戴奧真尼斯也說過：



『上天給我們兩個耳朵、一個嘴巴的意思，



就是要我們多聽少說。』



&nbsp;



的確，一雙願意聆聽的耳朵，



遠比一張愛說話的嘴巴更受歡迎。



&nbsp;



我們都知道說話沒被對方傾聽是多麼令人挫折沮喪的事，



但我們又有多少人曾真正靜下來聽聽別人的心聲？



&nbsp;



父母抱怨孩子不聽話，孩子埋怨父母只會說教；



先生指責太太意見太多；太太責怪先生不聽別人的意見；



就連一些同事、同學、朋友，我們也因太忙或太懶，



而忘了去傾聽他們的心事。



&nbsp;



要知道，溝通的目的是為了…



『瞭解對方』，而不是『改變對方』。



&nbsp;



多數的人有種謬誤，以為溝通就是要表達自己的看法，



希望對方能改變，改變成你喜歡的樣子，



這顯然『扣錯了釦子』，



往住很多的衝突和誤會也由此而生。



&nbsp;



記住，重要的不是『講』什麼，而是『聽』什麼。



&nbsp;



真正成功的溝通就是：



『無我』的傾聽，



靜靜地聆聽對方的想法及憤怒和失望，



而不加任何否定或批判，這就對了！&nbsp;



&nbsp;
