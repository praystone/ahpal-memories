&nbsp;

&nbsp; 





&nbsp;


在我人生的一個黑暗路口


&nbsp;


&nbsp;


&nbsp;


星光並不溫柔


&nbsp;


&nbsp;


&nbsp;


我低著頭行走任淚流或不流


&nbsp;


&nbsp;


&nbsp;


偶爾與人擦身而過卻也無意去回首


&nbsp;


&nbsp;


&nbsp;


直到你出現在我的世界


&nbsp;


&nbsp;


&nbsp;


對我而言是一種挽救


&nbsp;


&nbsp;


&nbsp;


像柔風一縷


&nbsp;


&nbsp;


&nbsp;


如潤雨一場


&nbsp;


&nbsp;


&nbsp;


你掠過我的心房溫馨飄逸


&nbsp;


&nbsp;


&nbsp;


從此


&nbsp;


&nbsp;


&nbsp;


你就是我的方向


&nbsp;


&nbsp;


&nbsp;


到後來我甚至祈求永遠都像現在這樣


&nbsp;


&nbsp;


&nbsp;


可是


&nbsp;


&nbsp;


&nbsp;


現實從來不會跟從人的期望


&nbsp;


&nbsp;


&nbsp;


或許這就是人生


&nbsp;


&nbsp;


&nbsp;


總是在相聚的歡樂後給人分離的傷痛


&nbsp;


&nbsp;


&nbsp;


多少話還未說出口


&nbsp;


&nbsp;


&nbsp;


就只能相見在夢中


&nbsp;


&nbsp;


&nbsp;


那些永遠也抹不掉的記憶


&nbsp;


&nbsp;


&nbsp;


一次又一次地環繞


&nbsp;


&nbsp;


&nbsp;


閉上眼以為我能忘記


&nbsp;


&nbsp;


&nbsp;


但流下的淚


&nbsp;


&nbsp;


&nbsp;


卻沒有騙到自己


&nbsp;


&nbsp;


&nbsp;


而如今……


&nbsp;


&nbsp;


&nbsp;


我不是你的永遠對嗎


&nbsp;


&nbsp;


&nbsp;


我們真的只是彼此的過客嗎


&nbsp;


&nbsp;


&nbsp;


我不想


&nbsp;


&nbsp;


&nbsp;


我能放下尊嚴放下個性…


&nbsp;


&nbsp;


&nbsp;


卻唯獨放不下


&nbsp;


&nbsp;


&nbsp;


你和我的約定…
