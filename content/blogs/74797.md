&nbsp;






&nbsp;


不曾淋雨　又怎會明白濕透的心情


&nbsp;


對於　一些事　一些人　一些過去


&nbsp;


你可以假裝不在乎　骨子裡卻執迷不悔


&nbsp;


念念不忘　


&nbsp;


也許　只是因為一個回眸眼神


&nbsp;


耿耿於懷　


&nbsp;


也許　只是因為一時意氣用事


&nbsp;


思念的距離有多遠　觸摸不著朦朧的美


&nbsp;


為自己編織一堆幸福的謊言


&nbsp;


以修飾的信念　迎接下一個陰晴不定的明天


&nbsp;


光陰改寫了當初故事的完結篇


&nbsp;


一些支離破碎的章節　依然清晰在記憶裡


&nbsp;


思念一個荒廢的名字


&nbsp;


在情感的缺口　拼上一塊不完整的圖片


&nbsp;


總是這樣的告訴自己


&nbsp;


寧願選擇度日如年　也不要委屈求全
