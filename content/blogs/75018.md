白羊座

&nbsp;

&nbsp;

白羊座的女孩骄傲、自信，虽然她们外表霸道蛮横，但内心却期待能被真正的强者所征服，对于备份男友，更多的时候应该称做是玩伴，喜欢热闹，又很男子气的白羊女孩，会吸引更多男孩子的目光，喜欢和她们在一起玩闹的感觉。

&nbsp;

&nbsp;

金牛座

&nbsp;

&nbsp;

金牛座的女孩大多安静，也很固执，她需要的是一个真正的男人，可以托付终身的人，和几个男友相处，以金牛座女孩的精明，可以很好的处理他们之间的关系，她们重实际，会在男友间衡量谁才是真正适合自己的人。

&nbsp;

&nbsp;

双子座

&nbsp;

&nbsp;

双子座的女孩要比一般女孩要多好几倍的变化，令人难以预测，她们思维的速度太快了，又喜欢恋爱的感觉，所以常会令人有点放心不下，不过爱情本身就是一次冒险，不甘寂寞的男子倒不妨可以试试。

&nbsp;

&nbsp;

巨蟹座

&nbsp;

&nbsp;

巨蟹座的女孩天生就是很好的听众，再加稍被动的女性风情最能搔动男人的心，使男性都不由自主想要追求她。她身边的备份男友想必都是希望可以在温柔的巨蟹女孩那得到丝丝的安慰。

&nbsp;

&nbsp;

狮子座

&nbsp;

&nbsp;

狮子座的女孩像向日葵，永远明艳动人，人前好强，拥爱自己的事业，人后不过是只大号的猫，需要人爱需要人宠，拥有几个备份男友，是为满足一下自己空虚的内心，不过只有她最清楚心里最爱是谁。

&nbsp;

&nbsp;

处女座

&nbsp;

&nbsp;

处女座的女孩不喜欢感情发展得太快，太快会让她们有不安全感，认为所有的一切都应像细水长流那样，慢慢来，慢慢培养，对于自已的男友也是如此，要求甚严的处女座女孩会从各男友的日常生活习惯中挑选自己的另一半。

&nbsp;

&nbsp;

天秤座

&nbsp;

&nbsp;

拥有天秤座的女友，不知是幸还是不幸，天秤座的女孩具有迷人的气息与高雅的气质，最能吸引异性，虽也会有专情的一面，但基本不离喜欢恋爱的本性，所以会周期性地更换男朋友。

&nbsp;

&nbsp;

天蝎座

&nbsp;

&nbsp;

天蝎座的女孩的爱具有毁灭性，有着很强烈的占有欲，虽然在外表看不出她的热情，但她绝对是真的热情。至少她会使你热情起来！拥有备份男友的可能性不大，爱一个人就已令她疲惫不堪了，但爱转为报复时，那后果可是可怕的。

&nbsp;

&nbsp;

射手座

&nbsp;

&nbsp;

射手座的女孩热力四散，活泼好动，而且对于男性朋友，也是相当的直接，不拘小节，在你眼里觉得奇怪的事，在她而言，却是正常的，没什么值得惊讶的，只是很多时候，她常会搞错感情，错把友情当爱情，爱情当友情。

&nbsp;

&nbsp;

摩羯座

&nbsp;

&nbsp;

摩羯座的女孩有着独特的优雅、保守、传统、风范、礼仪、顽固、忧郁、悲观及沮丧。在那个能够让自己依靠的男人出现之前，还有很多事得自己做；即使对待自己的备份男友，也是用最直接的方式，这并不代表她不需要感情，只是她不想浪费时间罢了。

&nbsp;

&nbsp;

水瓶座

&nbsp;

&nbsp;

水瓶座女孩有着特有的专情，但从她的外在表现上来看，是一点都看不出来的。她是每个人的朋友，却可以很清楚的区分朋友与情人的差距，同时拥有几个男友，是因为她们喜爱检验人的真诚，感觉谁是会令她心跳加快的人。

&nbsp;

&nbsp;

双鱼座

&nbsp;

&nbsp;

双鱼座女孩常会使男人解除武装，去谈谈心中的感受，聊过之后，就像是催眠似地放松了自我，并可能疯狂地喜欢上她。她们的人见人爱，理所当然会拥有众多备份男友。
