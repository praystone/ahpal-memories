&nbsp;

&nbsp;

烙下了相思 

&nbsp;

那是靈魂的印記 



在雲端之間相逢

&nbsp;

來來往往 總在一線之間

&nbsp;

遇見妳後的幸福

&nbsp;

才知 

&nbsp;

泛起漣漪的夢

&nbsp;

是一種專屬 只屬於我的

&nbsp;

在深夜裡 獨自徘徊

&nbsp;

總能從心裡深處

&nbsp;

凝聚妳那優美的氣質

&nbsp;

讓人所驚豔的容顏

&nbsp;

高挑的身段 

&nbsp;

如搖曳風中的青蓮

&nbsp;

眷戀著妳 

&nbsp;

真想擁妳在我懷中 

&nbsp;

緊緊的 

&nbsp;

我絕不放手

&nbsp;

遇見妳 

&nbsp;

我終於不再飄搖凡世間

&nbsp;

每夜這時候

&nbsp;

都在雲端中的魚雁往回

&nbsp;

說真的

&nbsp;

其實妳 

&nbsp;

離我並不遙遠

&nbsp;

而我

&nbsp;

也在妳身邊守護著
