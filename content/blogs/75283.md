其實，我一直都在你身後，就差你一個回頭1、想哭就哭，想笑就笑，不要因為世界虛偽，你也變得虛偽

&nbsp; &nbsp; &nbsp;了。
2、成熟是一種明亮而不刺眼的光輝，一種圓潤而不膩耳的音

&nbsp; &nbsp; &nbsp;響，一種不需要對別人察顏觀色的從容，一種終於停止了向

&nbsp; &nbsp; &nbsp;周圍申訴求告的大氣，一種不理會哄鬧的微笑，一種洗刷了

&nbsp; &nbsp; &nbsp;偏激的淡漠，一種無須聲張的厚實，一種並不陡峭的高度。
3、有一些人活在記憶裡，刻骨銘心；有一些人活在身邊，卻很

&nbsp; &nbsp; &nbsp;遙遠。這個世界很大，即使是擦肩而過的陌生人，相遇時也

&nbsp; &nbsp; &nbsp;飄散著淡淡的緣，所以，緣來是你，我惜；緣盡你去，我
&nbsp; &nbsp;&nbsp;
&nbsp; &nbsp; &nbsp;放。

4、每個人都會累，沒人能為你承擔所有的傷悲，人總有那麼一

&nbsp; &nbsp; &nbsp;段時間要學會自己長大。
5、思念是一種病。幸福的是你病了，他也病了；不幸的是，他

&nbsp; &nbsp; &nbsp;康復了，你卻一病不起。
6、戀愛潛規則：婚姻的難處在於我們是和對方的優點談戀愛，

&nbsp; &nbsp; &nbsp;卻要和對方的缺點生活在一起。所以，聰明的男人說一半，

&nbsp; &nbsp; &nbsp;留一半，而聰明的女人睜一隻眼，閉一隻眼！
7、 現在要一份純粹的愛情，很難。放不下驕傲，放不下身

&nbsp; &nbsp; &nbsp; 段，參雜太多人太多事，彼此撐著，最後以愛不起、不適

&nbsp; &nbsp; &nbsp; 合收場。陪我們走到最後的人，也許算不上是我們最愛

&nbsp; &nbsp; &nbsp; 的，但會是最合適的。這樣也很好，不是嗎？人生本不完

&nbsp; &nbsp; &nbsp; 美，也許懂得知足。年輕就是這樣，有錯過有遺憾，最後

&nbsp; &nbsp; &nbsp; 才會學著珍惜。
8、你整天愁眉，自然生就苦臉；你一臉怒氣，必定生成怨相；

&nbsp; &nbsp; &nbsp;你樂觀和善，當然慈眉善目。哲人道：10歲前的相貌，是

&nbsp; &nbsp; &nbsp;父母給的，30歲後的相貌，是自己修的。表情是瞬間的相

&nbsp; &nbsp; &nbsp;貌，相貌是凝固了的表情。從今天開始，每天微笑吧，哪怕

&nbsp; &nbsp; &nbsp;你遇見的都是煩心事。
9、人一定要想清三個問題：第一你有什麼，第二你要什麼，第

&nbsp; &nbsp; &nbsp;三你能放棄什麼。對於多數人而言：有什麼，很容易評價自

&nbsp; &nbsp; &nbsp;己的現狀；要什麼，內心也有明確的想法；最難的是，不知

&nbsp; &nbsp; &nbsp;道或不敢放棄什麼。這點恰能決定你想要的東西能否真正實

&nbsp; &nbsp; &nbsp;現，沒有人可以不放棄就得到一切。
10、出生一張紙，開始一輩子；畢業一張紙，奮鬥一輩子；婚

&nbsp; &nbsp; &nbsp; &nbsp;姻一張紙，折磨一輩子；金錢一張紙，辛苦一輩子；榮譽

&nbsp; &nbsp; &nbsp; &nbsp;一張紙，虛名一輩子；看病一張紙，痛苦一輩子；悼詞一

&nbsp; &nbsp; &nbsp; &nbsp;張紙，了結一輩子；淡化這些紙，明白一輩子；忘了這些

&nbsp; &nbsp; &nbsp; &nbsp;紙，快樂一輩子
11、愛情的最高境界，不是一方為另一方無休止的付出以換取

&nbsp; &nbsp; &nbsp; &nbsp;回報，而是你豐富了我的生命，我也豐富了你的生命。我

&nbsp; &nbsp; &nbsp; &nbsp;們相遇之前是兩個人。相遇之後，不是變成一個，而是一

&nbsp; &nbsp; &nbsp; &nbsp;個半。我把一半留給自己，那樣我才可以更清醒的去愛

&nbsp; &nbsp; &nbsp; &nbsp;你。
12、 或許你不會再回來，或許我們不會再見面，或許你找到了

&nbsp; &nbsp; &nbsp; &nbsp; 她，我找到了他，或許我們在各自的新生活裡不再存在。

&nbsp; &nbsp; &nbsp; &nbsp; 我還是會懷念，不是懷念你，而是懷念我愛過你。謝謝你

&nbsp; &nbsp; &nbsp; &nbsp; 給了我最溫暖的愛，雖然最後的最後，我們還是沒有再相

&nbsp; &nbsp; &nbsp; &nbsp; 逢。我想快樂，為你，為我，為我們。我知道即使沒有當

&nbsp; &nbsp; &nbsp; &nbsp; 初的愛，你還是願我一切安好。
13、其實，我一直都在你身後，就差你一個回頭。
14、吃醋是因為喜歡，生氣是因為在乎，發呆是因為想念，傷

&nbsp; &nbsp; &nbsp; &nbsp;心是因為不想失去。

15、想留住身邊的女人，就要讓她知道，你隨時都在想她；想

&nbsp; &nbsp; &nbsp; &nbsp;留住身邊的男人，就要讓他知道，你可能隨時會離開他。
16、 看別人不順眼，是自己修養不夠。人憤怒的那一個瞬​​間，

&nbsp; &nbsp; &nbsp; &nbsp; 智商是零，過一分鐘後恢復正常。人的優雅關鍵在於控制

&nbsp; &nbsp; &nbsp; &nbsp; 自己的情緒，用嘴傷害人，是最愚蠢的一種行為。我們的

&nbsp; &nbsp; &nbsp; &nbsp; 不自由，通常是因為來自內心的不良情緒左右了我們。一

&nbsp; &nbsp; &nbsp; &nbsp; 個能控制住不良情緒的人，比一個能拿下一座城池的人強

&nbsp; &nbsp; &nbsp; &nbsp; 大。
17、不失戀的方法只有兩個：一是不再戀愛；二是勇敢去愛，

&nbsp; &nbsp; &nbsp; &nbsp;直至遇見一個永遠不會讓你失戀的人。
18、某天你一定會感謝那個遺棄你的人，感謝那個你曾深愛著

&nbsp; &nbsp; &nbsp; &nbsp;卻置之你不顧的人。他的放棄，促使你找到更好的下一

&nbsp; &nbsp; &nbsp; &nbsp;個。記住，永遠不要為一個不愛你的人，去浪費一分一

&nbsp; &nbsp; &nbsp; &nbsp;秒。
19、愛情，要么讓人成熟，要么讓人墮落。
20、我常常覺得，流下一滴眼淚，需要很久很久。人越長大，

&nbsp; &nbsp; &nbsp; &nbsp;就越習慣於壓抑內心的真實感受，不再放聲大哭放聲大

&nbsp; &nbsp; &nbsp; &nbsp;笑，什麼都只是淡淡的點到為止。好像越來越沒有什麼事

&nbsp; &nbsp; &nbsp; &nbsp;情，可以讓傷心到立刻落淚，最終，我們變成了不會哭的

&nbsp; &nbsp; &nbsp; &nbsp;小孩。
