&nbsp;












風在空中搖 雨在水上飄


&nbsp;


風雨飄搖彩虹橋 春天的花開了


&nbsp;


天邊的雲在跳 遠處的山在笑


&nbsp;


湖裡的鴛鴦鳥 雙雙恩愛在消遙


&nbsp;


&nbsp;


揮著翅膀的女孩在跳躍


&nbsp;


樹上的小鳥也在叫


&nbsp;


白色的桂冠頭上瞧


&nbsp;


櫻桃小嘴往上翹


&nbsp;


&nbsp;


婚禮的琴聲陣陣飄


&nbsp;


紅婚紗 白面罩


&nbsp;


嬌羞模樣真美妙


&nbsp;


小花童倆相好 男女儐相團團繞


&nbsp;


&nbsp;


掌聲響 花雨頭上倒


&nbsp;


拉炮聲 沖雲霄


&nbsp;


聲聲吶喊來熱鬧


&nbsp;


新郎新娘晚上不要跑


&nbsp;


&nbsp;


紅唇印 交杯酒


&nbsp;


生生世世相愛到永久


&nbsp;


無盡的愛 牽手陪你走


&nbsp;


不吵不鬧 陪你一起老


&nbsp;


&nbsp;




&nbsp;

&nbsp;






遠處的教堂傳來幸福的鐘聲


&nbsp;


聖潔的殿堂裡神聖十字架前


&nbsp;


牧師為著牽手的愛來做見證


&nbsp;


歡歡喜喜願作你今生的新娘


&nbsp;


&nbsp;


白雲片片為新嫁娘披上白紗


&nbsp;


花田上的鳥兒忙著穿梭頭冠


&nbsp;


飛舞中的蝶兒忙著點綴捧花


&nbsp;


樹上的鵲鳥也在興奮的歌唱


&nbsp;


&nbsp;


風雨中相逢愛在彩虹的天空


&nbsp;


七彩霓虹為新人搭起緣分橋


&nbsp;


難忘相遇相知的幸福與甜蜜


&nbsp;


誓言共譜那三生三世的戀曲


&nbsp;


&nbsp;


盟約鏤刻在來世今生的記憶


&nbsp;


伊甸中共度芳華繾綣倆相依


&nbsp;


沈倫在有你的溫柔歲月之中


&nbsp;


彩虹下的約定陪著你一起老

&nbsp;
