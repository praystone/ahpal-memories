&nbsp;


用一生一世只想珍惜一個人


&nbsp;


&nbsp;


用真心真意只想愛一個人


&nbsp;


&nbsp;


這是你說過的話


&nbsp;


&nbsp;


彷彿還在耳邊.


&nbsp;


&nbsp;


我比任何一個人&nbsp; 


&nbsp;


&nbsp;


都喜歡回首看看來時的路


&nbsp;


&nbsp;


但是時光卻扔下我 轟轟烈烈 獨自的向前行


&nbsp;


&nbsp;


忙碌的生活讓&nbsp; 自己不再多想有關你的一切


&nbsp;


&nbsp;


但回首來時路&nbsp; 誰是誰的曾經?&nbsp;&nbsp; 誰又是誰的過客?




&nbsp;


&nbsp;


抬頭看著 滿天閃爍的星星


&nbsp;


&nbsp;


想念-心底懸念已久的人 


&nbsp;


&nbsp;


在這煙火漫天的夜晚


&nbsp;


&nbsp;


感慨全湧上心頭


&nbsp;


&nbsp;


喜歡品嚐一個人的咖啡和天光 


&nbsp;


&nbsp;


靜靜的&nbsp; 看著天色的變化


&nbsp;


&nbsp;


一顆懸在心底的思念 原來遺忘在相遇的街角


&nbsp;


&nbsp;


一場愛恨離別的痛&nbsp; 我們都無處可逃




&nbsp;


&nbsp;


用一顆真誠的心 


&nbsp;


&nbsp;


可不可以&nbsp; 將永遠延伸得更深更遠


&nbsp;


&nbsp;


用一顆無悔的心 


&nbsp;


&nbsp;


可不可以綁住輪迴的沒測


&nbsp;


&nbsp;


&nbsp;






&nbsp;


&nbsp;


那個曾經 為愛心疼


&nbsp;


&nbsp;


因為你而 心跳的自己


&nbsp;


&nbsp;


再次與你相遇


&nbsp;


&nbsp;


我在你眼中看見了 許久不見的自己


&nbsp;


&nbsp;


好想對自己說聲:好久不見




&nbsp;


&nbsp;


因為一秒鐘的緣分遇見你


&nbsp;


&nbsp;


卻讓我懸懸念念一輩子


&nbsp;


&nbsp;


如果 我們只是個孩子 


&nbsp;


&nbsp;


是不是 就可以留在時光的原地


&nbsp;


&nbsp;


慢慢聽著許多故事 


&nbsp;


&nbsp;


一直到天荒地老..

 


 rn&nbsp;


我們都不知道 生命的下一個停靠站在哪

只能珍惜現在 把握現在
