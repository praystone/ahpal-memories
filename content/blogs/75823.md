&nbsp;





 


&nbsp;


走了


&nbsp;


真的&nbsp;走了


&nbsp;


柔情在靜夜中顫抖


&nbsp;


夢


&nbsp;


每一處都是你


&nbsp;


愛


&nbsp;


每一個心跳都是為了你


&nbsp;


&nbsp;


為何不回頭再看看我


&nbsp;


你害我沉沉浮浮的心


&nbsp;


因你而起


&nbsp;


又為你淹沒


&nbsp;


&nbsp;心窩裡的牢結是你給


&nbsp;


&nbsp;


我將手伸向黑暗的空間


&nbsp;


你是那麼飄渺


&nbsp;


一針針的憂愁


&nbsp;


我已淚成河


&nbsp;


&nbsp;


你是瀟灑不拘的風


&nbsp;


浪流天際


&nbsp;


慣於自由


&nbsp;


愛上你是我莫名的衝動


&nbsp;


註定期待


&nbsp;


染上淡淡的哀愁


&nbsp;


&nbsp;


&nbsp;


不悔的是我的癡情


&nbsp;


今晚月光清水似流


&nbsp;


好想親親你


&nbsp;


跟你說一聲


&nbsp;


回來 我的愛
