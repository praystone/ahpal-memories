&nbsp;

&nbsp;



 


&nbsp;

因為親密、因為熟悉，便少了關注、少了體貼，


&nbsp;

所以就常輕忽了、漠視了。


&nbsp;

這是我們性格的劣質，也是我們情緒的慣性，


&nbsp;

我們縱容著自己，卻傷害著親人，


&nbsp;

直到後來也傷害了自己。

&nbsp;



&nbsp;

&nbsp;

不要看著父母，也不要盯著父母的相片，

&nbsp;

要你畫出父母的容貌，你畫得出來嗎？


&nbsp;

認真想想：

&nbsp;

母親的眼皮是內雙還是外雙？

&nbsp;

父親的耳垂是厚大還是薄短？

&nbsp;

母親的魚尾紋多或少？父親額上的皺紋有幾條？

&nbsp;

母親的臉上有幾顆痣？父親的雙眉是濃還是稀？……

&nbsp;

閉上眼睛再想想：

&nbsp;

父母朝你走來的姿態是如何？

&nbsp;

父母轉身離去的背影又怎樣？

&nbsp;

從童稚到現在，父母的姿態及背影改變了多少？

&nbsp;

母親操勞家務的模樣，曾讓你不忍嗎？

&nbsp;

父親外出工作的架勢，曾引你注視嗎？……

&nbsp;

是不是到現在才愕然發現：

&nbsp;

越是親密的人，越是識他不清！

&nbsp;

以為熟悉得不得了，卻竟陌生得可以？

&nbsp;

父母記錄我們的成長，

&nbsp;

我們卻忘了記錄父母的年老。



&nbsp;

&nbsp;

一位伯伯就說到，當他四十一歲再婚時，

&nbsp;

由於無從通知在大陸的雙親，

&nbsp;

便想親手畫出父母掛在牆上，聊表孝思。

&nbsp;

哪想畫筆握在手上幾個月，

&nbsp;

竟然一筆也畫不出來！

&nbsp;

思念中的父母是那樣清晰，

&nbsp;

但當細細回想父母的五官、長相、神色，

&nbsp;

竟又那樣模糊，

&nbsp;

以致無法運筆！

&nbsp;

20歲以前，他一直跟父母住在一起，

&nbsp;

那樣親密，那樣熟悉，卻也那樣陌生，那樣疏離！

&nbsp;

陌生到，描繪不出父母的五官；

&nbsp;

疏離到，拼湊不出父母的長相！

&nbsp;

他曾為此感傷了好些年，

&nbsp;

直到三個孩子相繼出世，

&nbsp;

才在兒女的成長中逐漸淡忘了感傷。



&nbsp;

&nbsp;

這位伯伯的心情，我近年才得體會。

&nbsp;

於是便趁某次回家幫母親染髮之際，

&nbsp;

在母親打盹的當兒，細細端詳了母親的容顏，

&nbsp;

將母親牢牢地記在了眼裡、腦裡、心裡，並擺進了意識裡。

&nbsp;

再將母親青壯時的面貌與現在的容顏重疊，

&nbsp;

我濕潤了眼眶。



&nbsp;

&nbsp;

每個人，都是父母以青春、用歲月撫養成的。

&nbsp;

父母記錄我們成長的同時，

&nbsp;

我們卻常忘了記錄父母的年老，

&nbsp;

以致，常在長久分離後，

&nbsp;

有著莫大的懊惱，有著至深的追悔。

&nbsp;

別讓懊悔及心痛，持續一輩子；

&nbsp;

不僅對父母如此，

&nbsp;

太多人待兄弟姊妹也這樣，

&nbsp;

在家時吵吵鬧鬧，

&nbsp;

一旦因工作、因婚姻而分開，

&nbsp;

便不太見面了，甚至老死不相往來；

&nbsp;

等到有所覺悟，通常已經太遲。




&nbsp;

&nbsp;

幾年前，由於學習皮雕而認識了一位朋友。

&nbsp;

她隻身從台南北上工作，待人很親切，

&nbsp;

然而，

&nbsp;

這番親切只對朋友不對姊妹。


有一次，她嫁到台中的姊姊打了電話來，

&nbsp;

正在她那兒的我就聽見她以敷衍、無奈的口氣應對，

&nbsp;

並在掛上電話後露出了厭煩的神態。


「妳姊找妳有事啊？」我問她。



&nbsp;

「哪有什麼事！她一個家庭主婦，整天窩在家裡，能有什麼事！

&nbsp;

還不就想探探，我過得有沒有比她好！

&nbsp;

她就是這樣，

&nbsp;

從小就愛跟我比較，比功課、比獎狀、比學校、比人緣，

&nbsp;

等出了社會，就比工作、比男友，真的好討厭！」


「可現在她結婚啦，又離妳最近，妳們應該更親密才對！」

&nbsp;

我提醒她。



&nbsp;

「不可能啦！她那種個性，我才不可能跟她親密！

&nbsp;

我們兩個可能天生犯沖，從小就愛吵，每次吵都是我捱罵，

&nbsp;

因為她最奸了，一聽到大人來

&nbsp;

就趕快擠出眼淚，自然捱罵的是我！

&nbsp;

現在，好不容易擺脫她了，換我姊夫去受罪，

&nbsp;

我幹嘛還跟她親密，又不是腦袋壞了！……」


這番抱怨猶在耳邊，數月後，

&nbsp;

竟在一個清晨突然接到她的電話，哽咽了好會兒，

&nbsp;

才吐出話：「我姊死了，就在半夜，是產後血崩！

&nbsp;

她體質本來就不好，這次又懷孕，我就告訴她最好拿掉，

&nbsp;

因為老大才一歲，應該間隔久一點讓身體復原，

&nbsp;

可她不聽啊!

&nbsp;

說這三四年辛苦一點，以後就輕鬆了，

&nbsp;

可以做點自己想做的事，也許再出去工作，結果咧！……」


她在電話那頭說了好多、哭了好久，

&nbsp;

見了我之後又說了好多、哭了好久。好多話，

&nbsp;

原該是對她姊姊說的，現在沒機會了。


她辭了工作去台中，幫忙姊夫料理姊姊的後事，

&nbsp;

抱著初生的外甥女打過幾次電話給我。

&nbsp;

電話的那頭，不知事的外甥女哭了，她也哭了；

&nbsp;

電話的這頭，我也哭了。


她姊姊結婚近三年，她從沒去過姊姊家，

&nbsp;

第一次去，竟然是給姊姊送終，而不是賀喜。



&nbsp;

&nbsp;

我感受得到她的懊悔及心痛。

&nbsp;

而這份懊悔及心痛，必會持續一輩子。


內在的關愛，勿以冷漠來表態

&nbsp;

我們太會輕忽、漠視周遭的人情事物，

&nbsp;

總是等到失去了，才頓覺對方的重要，而自責、內疚。



&nbsp;

&nbsp;

在某公司任職時，同部門裡有對夫妻，

&nbsp;

或許是整天都處在一塊，所以兩人不太對話，

&nbsp;

甚至各自來公司、各自吃午飯。


有一天，太太沒來上班，先生幫太太遞了假條，

&nbsp;

口裡叨唸著：

&nbsp;

「要病就病個大的，還有住院補給可以請領，

&nbsp;

每次都請這種半天幾小時的，全勤獎金都沒了！」


有同事聽不過去，

&nbsp;

說了：「喂，她是你老婆耶，你怎麼在咒她！

&nbsp;

病痛又不是她願意的，體貼一點嘛！」



&nbsp;

他竟回了：「這就是我的體貼啊！她愛生病嘛，

&nbsp;

乾脆就病個大的，可以偷懶久一點！」


幾個月後，有一天，夫妻倆都沒來，

&nbsp;

近中午時，先生才打了電話來，說要請三天假，

&nbsp;

竟然，他太太得了子宮頸癌，已經末期。


兩天後他來了，鬍子沒刮，一臉憔悴，

&nbsp;

說假不請了，他要辭職，

&nbsp;

想全心全意陪太太走完人生的最後一程。

他分明關愛太太，卻總以冷漠來表態，

&nbsp;

直到太太的生命將完結，才把深藏的情意釋放出來，卻已嫌遲。



&nbsp;

&nbsp;

沒有親人，一切便會變得毫無意義


唸小學的時候，我就發現了，

&nbsp;

最會遲到的同學，常是住離學校最近的；

&nbsp;

因為住得近，便少了認真、少了用心，所以就常遲到了。


我們也一樣，

&nbsp;

因為親密、因為熟悉，便少了關注、少了體貼，

&nbsp;

所以就常輕忽了、漠視了。

&nbsp;

這是我們性格的劣質，也是我們情緒的慣性，

&nbsp;

我們縱容著自己，卻傷害著親人，

&nbsp;

直到後來也傷害了自己。



&nbsp;

&nbsp;

「我」，雖然是個個體，

&nbsp;

但這個個體，可不是單憑自己打造的，

&nbsp;

更是周遭的人情事物拱托的，尤其是親人。



&nbsp;

沒有親人，沒有周遭的人情事物，

&nbsp;

「我」及「我」的一切便會變得毫無意義，

&nbsp;

甚至根本不算存在。


是因為自己的情感跟周遭的情感連結、交流，

&nbsp;

才有「我」的具體存在。



&nbsp;

輕忽、漠視了這些情感，

&nbsp;

自己的情感便不完整了，甚至潰散了，

「

我」恐怕也就不存在了。
