&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 車遙遙篇 &nbsp; &nbsp; 范成大　　&nbsp;
&nbsp;
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 車遙遙，馬幢幢，

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 君遊東山東復東，安得奮飛逐西風。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 願我如星君如月，夜夜流光相皎潔。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 月暫晦，星常明。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 留明待月復，三五共盈盈。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 摸魚兒　 ( 金 )　元好問
&nbsp;
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 問世間，情是何物，直教生死相許。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 天南地北雙飛客，老翅幾回寒暑。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 歡樂趣，離別苦，是中更多癡兒女。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 君應有語，渺萬里層雲，千山暮景，隻影為誰去？

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 橫汾路，寂寞當年簫鼓。荒煙依舊平楚，

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 招魂楚些何嗟及，山鬼自啼風雨。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 天也妒，未信與，鶯兒燕子俱黃土。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 千秋萬古，為留待騷人，狂歌痛飲，來訪雁丘處。
