&nbsp;


&nbsp;


當彩虹出現在天邊


&nbsp;


把風雨化為纏綿


&nbsp;


從來我們都不曾走遠


&nbsp;


&nbsp;


當心雨濺濕了容顏


&nbsp;


落葉跌滿了桑田


&nbsp;


看見野百合開在春天


&nbsp;


&nbsp;


白天黑夜的思念


&nbsp;


將淚水凝結成斷點


&nbsp;


魔鬼精靈的考驗


&nbsp;


想你依然是千萬遍


&nbsp;


&nbsp;


五百年前的情緣


&nbsp;


在遇見你之後出現


&nbsp;


等待重逢的諾言


&nbsp;


在今生也不會改變


&nbsp;


&nbsp;


記的我們有約


&nbsp;


你的笑容在眼前


&nbsp;


&nbsp;


記的我們有約


&nbsp;


你的溫柔在心田


&nbsp;


&nbsp;


記的我們有約


&nbsp;


陪你到老在身邊


&nbsp;


&nbsp;


記的我們有約


 
就在誓言的終點 
 
我們牽手相見 
 
將彩虹掛上藍天 


&nbsp;


&nbsp;


冬天走了春天就回來


&nbsp;


花兒謝了明年又會開


&nbsp;


愛情像是空中的虹彩


&nbsp;


傳說中永遠有你的愛
