照樣造句，小朋友寫： 

1. 題目：原來 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫：原來他是我爸爸 。 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 評語: 媽媽關切一下 

2. 題目: 樹呀樹呀我把你種下 &nbsp; &nbsp; &nbsp;小朋友寫: 湯圓湯圓我把你吃掉 &nbsp; &nbsp; &nbsp; &nbsp; 評語: 真是口愛 

3. 題目: ..一邊..一邊..小朋友寫:他一邊脫衣服一邊穿褲子評語他到底要不要脫還是穿阿 


4. 題目： 課本 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫：上課本來就很無聊。 &nbsp; &nbsp; &nbsp; &nbsp; 評語: 上課要專心 

5 &nbsp;題目: 吃香 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫： 我很喜歡吃香蕉。 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 評語: 小心噎到 

6. 題目: 其中 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫: 我的其中一隻左腳受傷了 &nbsp; &nbsp; 評語: 你是蜈蚣ㄇ~~ 

7. 題目: 一...就.... &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 小朋友寫: 一隻娃娃就要一百塊 &nbsp; &nbsp; &nbsp; &nbsp; 評語: 老師笑到不行.. 

8. 題目: 你看 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫：你看什麼看! 沒看過啊! 

9. 照樣造句 
&nbsp;&nbsp;&nbsp; 例題:你(唱歌) 我(跳舞) &nbsp; &nbsp; &nbsp; 小朋友寫:你(好嗎) 我(很好)&nbsp;&nbsp;&nbsp;&nbsp;評語:你在寫英文翻譯嗎? 

10. 照樣造句 
&nbsp; &nbsp; 例題: 別人都誇我( )，其實我( ) 
&nbsp; &nbsp;小朋友寫: 別人都誇我( 很帥)，其實我( 是戴面具的)&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;評語: 什麼面具這麼好用??? 

11. 題目: 先...後.........&nbsp;
&nbsp;例題:我先寫了功課,後來才去洗澡.小朋友寫:先總統蔣公,後來死了評語:回去罰抄100遍 


12: 題目：好... 又好...&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;小朋友寫:媽媽的腿,好細又好粗 &nbsp; 評語：那到底是細還是粗？ 

13. 題目: 陸陸續續~小朋友寫:下班了,爸爸陸陸續續的回來評語ㄋ到底有幾個爸爸ㄚ? 

14. 題目: 先．．．再．．． 例題：先吃飯，再洗澡 &nbsp; &nbsp; &nbsp; &nbsp;小朋友寫：先生，再見 

15.題目: 天涯海角 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 小朋友寫: 妹妹亂跑跑到天涯海角. &nbsp; &nbsp; &nbsp; &nbsp; 評語: 你妹妹真會跑 

16.題目：馬上 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 小朋友寫: 我騎在馬上 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 評語: 馬上來找老師 

17.題目: 皮開肉綻&nbsp;小朋友寫:停電的夜晚，到處很黑，我嚇得皮開肉綻!&nbsp;評語:看到這句... 老師佩服你 

18.題目: 欣欣向榮-比喻生長美好的樣子.小朋友寫:我的弟弟長得欣欣向榮.&nbsp;評語： 孩子,你弟弟是植物人嗎??
