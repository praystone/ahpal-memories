不要把一生賣給公司


&nbsp;


&nbsp;


留給家人的卻是破銅爛鐵！


&nbsp;

&nbsp; 





很有意思的一句話！形容的很貼切不是嗎，


&nbsp;


在台灣大家都只忙著工作賺錢，忘了工作原先的旨意；


&nbsp;


反觀國外，大家努力工作也努力享受工作帶來的


&nbsp;


成就感及所提供的生活品質。




&nbsp;


不要把一生賣給公司，留給家人的卻是破銅爛鐵！&nbsp;


&nbsp;


程天縱──出身惠普（HP），在他離開時，


&nbsp;


惠普(HP)員工送給─程天縱


&nbsp;


（德儀Texas Instrument亞洲區總裁）之口訣：


&nbsp;


以健康為中心，瀟灑一點，


&nbsp;


糊塗一點，功勞是老闆的，錢財是子女的，


&nbsp;


官爵是一時的，只有身體是自己的，


&nbsp;


「不要把一生心血精華賣給公司，留給家人的卻是破銅爛鐵」。


&nbsp;


維豐在新竹科學園區上班，每天不管工作到幾點，


&nbsp;


他一定開車回台北的家，


&nbsp;


每個人聽了都好羨慕他們夫妻如此恩愛。


&nbsp;


季擇聽了這種事，頗不以為然，


&nbsp;


說他每天雖然應酬到很晚，一定回家睡覺，


&nbsp;


他也是先生，怎麼沒人讚美他？


&nbsp;


鼓勵做老公做爸爸的男人回家，


&nbsp;


是一樁推行很久的運動，有些男人就把「回家」


&nbsp;


當作指標，但他卻忘了，他的心有沒有一起跟著回家。


&nbsp;





曾經在美國住過一陣子，他們的社區裡，


&nbsp;


每到下班時間，就看到一家家的先生


&nbsp;


開車回來後可沒閒著，衣服一脫換上工作服，


&nbsp;


不是除草修自行車，就是遛狗整理庭院。


&nbsp;


夜幕低垂，全家一起看電視，很早就上床睡覺，


&nbsp;


很少人會去喝酒應酬。


&nbsp;


週末假日，不是在院子裡除草、烤肉，或在車庫


&nbsp;


辦個小型舊物拍賣，就是全家出門旅行。


&nbsp;


他們回家，是把心和身和愛，都一起放在家裡。


&nbsp;


反觀我們這兒，賣命加班、努力應酬、拚命喝酒、


&nbsp;


用勁唱歌，把實驗室當家、把PUB當家、把朋友家當家，


&nbsp;


你的家只是摸黑回去了，


&nbsp;


管他是沙發是地板是浴室，倒頭就睡。


&nbsp;


醒來迷迷糊糊的，梳洗一番又去上班了，沒跟太太說上一句話，


&nbsp;


沒跟孩子打過一個照面，搞不好跑錯人家，你都不知道。


&nbsp;


做爸的如此，兒女上行下效也如此，


&nbsp;


做媽的心想，你們都不回來，


&nbsp;


我也出去吧！「家」就變成了一個空殼子。


&nbsp;


不論你家誰是一家之主，不妨率先示範：


&nbsp;


※每週最多一晚去應酬。


&nbsp;


不管是談生意，跟朋友聊天，或是跟主管籠絡感情，


&nbsp;


一週最少一次，其餘時間應該留給伴侶談話，


&nbsp;


和孩子聊天，跟家人建立感情。


&nbsp;


※即使晚歸，也要清醒。


&nbsp;




&nbsp;


醉酒開車要重罰，真是一大福音，至少大家都不敢在夜裡喝了，


&nbsp;


最好是連計程車也拒載酒醉之人，


&nbsp;


說不定能挽救不少形同陌路的婚姻。


&nbsp;


因為沒喝酒，回到家，至少還能清醒的跟家人說說話。&nbsp;


&nbsp;


※回家以後，不以自己會賺錢自誇，照樣樂在家事中。 


&nbsp;


家事是全家人的事，在外奔波雖然很辛苦，


&nbsp;


但是在家忙碌，也不輕省，互相體貼。


&nbsp;


付出愛心，隨手做家事




&nbsp;


不要把一生心血精華賣給公司，留給家人的卻是破銅爛鐵。


&nbsp;


為公司賣命，贏得高薪與高職，確實很有成就感。


&nbsp;


但隨著你的退休被淘汰，這些都成過眼雲煙。




&nbsp;


然而，你給家人的愛，卻是一輩子不會變質，


&nbsp;


他們會回報你以更多的愛。 


&nbsp;


&nbsp;




&nbsp;




&nbsp;


&nbsp;




&nbsp;


Be home with your heart. 


&nbsp;


看完這一封信，不知道你是否也和我一樣有相同的感觸，


&nbsp;


我們每個人似乎都將工作的順位給顛倒了，


&nbsp;


總是工作第一、應酬第二，忽略了家庭的重要性。


&nbsp;


甚至未婚的年輕男女，也許因為過於賣命的工作，


&nbsp;


而失去了許多結交男女朋友的時間與機會，


&nbsp;


而已婚的男女，亦常常忽略了家人的重要性，


&nbsp;


不要以為結了婚就是保證，


&nbsp;


殊不知現在離婚率這們高，每五對夫妻，就有一對離婚。 


也許我們都應該停下來想一想，


&nbsp;


我們工作的目的是為了什麼？


&nbsp;


是為了改善目前的生活，讓家人過好日子呢？


&nbsp;


是為了要讓喜歡的人得到幸福而事先做好準備呢？


&nbsp;


還是毫無意義的工作，只因為自己已長大了。


&nbsp;


亦或是在權力與地位上的追求，滿足自己的虛榮心自己的。


不要管任何人怎們想，真實的面對你自己，



正視你所要的是什麼， 


&nbsp;


也許將腳步放慢點，


&nbsp;


你會發現我們要的不僅是為了賺很多錢，


&nbsp;


而是為了自己的理想在努力奮鬥，


&nbsp;


為了實現對你所愛的人的承諾，


&nbsp;


沒有什麼是不能捨得，因為有捨才有得。


&nbsp;


與你共勉之！ 


&nbsp;


希望你們對生活都能滿意&nbsp;


不要期待別人給你希望，希望是你自己去創造的！
