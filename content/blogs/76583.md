&nbsp; 






&nbsp;


&nbsp;


理解是一座橋，兩頭是路，沒有橋，路就斷了．


&nbsp;


寬容是一把傘，傘下是溫情，


&nbsp;


沒有了傘，世界就變得冰冷了。


&nbsp;


&nbsp;


因為我們有太多的煩惱，太多的怨氣和不如意．


&nbsp;


於是覺得天昏地暗，無限感慨；


&nbsp;


感覺人情薄如紙．


&nbsp;


其實陽光依然溫暖，天空依然晴朗，


&nbsp;


只是我們自己站在陰影裡，


&nbsp;


理解會讓我們走出陰影，走進一個新天地．


&nbsp;


過了橋條條大路都寬廣，


&nbsp;


煩惱的黑蝴蝶飛遠了，路邊開滿溫情的小花，


&nbsp;


從此世界變得更加美麗了。


&nbsp;


&nbsp;


話說退一步海闊天空，寬容別人也是善待自己；


&nbsp;


原諒了別人就把微笑留給了自己．


&nbsp;


寬容是一把盛開著的傘，在傘下我們享受著溫暖的陽光．


&nbsp;


&nbsp;


人生旅途能遇上你是一種緣分，我們應該珍惜這份緣分。


&nbsp;


不要讓怨氣衝跑了溫情，不要讓怒火留下遺憾．


&nbsp;


原諒別人不代表軟弱，那是一種氣度是一種胸懷，


&nbsp;


那是聰明的選擇．


&nbsp;


讓我們共同搭建一座理解的橋，撐一把寬容的傘，


&nbsp;


享受美好的生活，讓世界處處充滿陽光！


&nbsp;
