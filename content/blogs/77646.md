智慧型的笑話
背景音樂：周杰倫 牛仔很忙mp3

1. 兩只青蛙相愛了，結婚後生了一個癩蛤蟆?

&nbsp; 公青蛙見狀大怒說：「賤人，怎麼回事！？」

&nbsp; 母青蛙哭著說：「孩子他爹，我本是癩蛤蟆，認識你之前我整過容。」


&nbsp; →〖 缺乏充分瞭解的愛情，就要承擔所帶來的苦果！〗

&nbsp;

&nbsp; 2. 小驢問老驢：「為啥咱們天天吃乾草，而奶牛頓頓精飼料？」

&nbsp; 1驢嘆到：「咱爺們比不了，我們是靠跑腿吃飯，人家是靠胸脯吃飯！」


&nbsp; →〖 各有前因莫羨人，生活需要忍耐，更要認命。〗

&nbsp;

&nbsp; 3.鴨子和螃蟹賽跑，一起到達終點，難分勝負。

&nbsp; 裁判說：「你們來個剪刀石頭布吧！」

&nbsp; 鴨子大怒：「媽的，算計我！？我一出就是布，他總是剪刀。」


&nbsp; →〖 競爭需要天賦，也需要機遇。〗

&nbsp;

&nbsp; 4.狗對熊說：「嫁給我吧，嫁給我你會幸福。」

&nbsp; 熊說：「才不嫁呢，嫁給你只會生狗熊，我要嫁給貓，生熊貓那才尊貴呢！」


&nbsp; →〖 挑結婚對象一定要有理智和有理想。〗

&nbsp;

&nbsp; 5.老鱉調戲河蚌，被咬，老鱉忍痛拖著河蚌來回爬。

&nbsp; 青蛙見了敬佩的說：「怪怪，鱉哥混大了，出入都夾著公文包！」


&nbsp; →〖老大在出醜，做小的也要說點門面話賣乖。〗

&nbsp;

&nbsp; 6.一壁虎誤入鱷魚池，喪命之時，壁虎急中生智，一把抱住鱷魚大叫「媽媽！」

&nbsp; 鱷魚一愣，立刻老淚縱橫：「都瘦成這樣了，你咋就不聽我的話，不讓你炒股吧，你偏要去，看看股市縮水都把你縮成啥了！」


&nbsp; →〖 投資是一定要小心的！ 〗

&nbsp;

&nbsp; 7.蜜蜂狂追蝴蝶，蝴蝶卻嫁給了蝸牛。

&nbsp; 蜜蜂不解，問：「他哪比我好？」

&nbsp; 蝴蝶回答：「人家好歹有自己的房子，哪像你住在集體宿舍。」


&nbsp; →〖 這年頭，無房一族要找結婚對象是難上加難~ 〗

&nbsp;

&nbsp; 8.母雞跟鄰居正在聊天，看到公雞無精打采的回來了。

&nbsp; 母雞說：「怎麼啦？」

&nbsp; 公雞：「做個買賣給累的。」

&nbsp; 母雞問：「做啥買賣累成這副德行？」

&nbsp; 公雞臉紅低下頭說：「賣點雞精。」


&nbsp; →〖 做老婆的要體諒老公在外邊賺錢養家有多辛苦！〗

&nbsp;

&nbsp; 9.餐廳蒼蠅對廁所蒼蠅說：「你整天追腥逐臭，我整天吃香喝辣，過來吧！」

&nbsp; 廁所蒼蠅：「道不同不相謀！吃再好有啥用，光屁屁美女你見過幾個？」


&nbsp; →〖不要坐井觀天只顧眼下的利益，外面的世界可能更精彩！〗
