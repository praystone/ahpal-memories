俗話說...可俗話又說... 


( 網路文章 ) 


&nbsp;


1、俗話說：兔子不吃窩邊草；


可俗話又說：近水樓台先得月! 


&nbsp;


2、俗話說：宰相肚裡能撐船；


可俗話又說：有仇不報非君子! 


&nbsp;


3、俗話說：人不犯我，我不犯人；


可俗話又說：先下手為強，後下手遭殃! 


&nbsp;


4、俗話說：男子漢大丈夫，寧死不屈；


可俗話又說：男子漢大丈夫，能屈能伸! 


&nbsp;


5、俗話說：打狗還得看主人；


可俗話又說：殺雞儆猴! 


&nbsp;


6、俗話說：知無不言，言無不盡；


可俗話又說：交淺勿言深，沉默是金! 


&nbsp;


7、俗話說：車到山前必有路；


可俗話又說：不撞南牆不回頭! 


&nbsp;


8、俗話說：條條大路通羅馬；


可俗話又說：一條道走到黑! 


&nbsp;


9、俗話說：禮輕情誼重；


可俗話又說：禮多人不怪! 


&nbsp;


10、俗話說：人多力量大；


可俗話又說：人多嘴雜! 


&nbsp;


11、俗話說：買賣不成仁義在；


可俗話又說：親兄弟，明算帳 ! 


&nbsp;


12、俗話說：一個好漢三個幫；


可俗話又說：靠人不如靠己! 


&nbsp;


13、俗話說：人往高處走；


可俗話又說：爬得高，摔得重! 


&nbsp;


14、俗話說：一口唾沫一個釘；


可俗話又說：人嘴兩張皮，咋說咋有理! 


&nbsp;


15、俗話說：知識要有產權；


俗話又說：不分享心裡不安! 


&nbsp;


16、俗話說：亡羊補牢，未為遲也；


可俗話又說：亡羊補牢，為時已晚！ 


&nbsp;


17、俗話說：瘦死的駱駝比馬大；


可俗話又說：拔了毛的鳳凰不如雞！ 


&nbsp;


18、俗話說：寧可玉碎，不能瓦全；


可俗話又說：留得青山在，不怕沒柴燒！ 


&nbsp;


19、俗話說：人不可貌相，海水不可斗量；


可俗話又說：人靠衣裳馬靠鞍！ 


&nbsp;


20、俗話說：浪子回頭金不換；


可俗話又說：狗改不了吃屎！ 


&nbsp;


21、俗話說：苦海無邊，回頭是岸；


可俗話又說：開弓沒有回頭箭！ 


&nbsp;


22、俗話說：退一步海闊天空；


可俗話又說：狹路相逢勇者勝！ 


&nbsp;


23、俗話說：萬般皆下品，唯有讀書高！


可俗話又說：三百六十行，行行出狀元。 


&nbsp;


24、俗話說：書到用時方恨少；


可俗話又說：百無一用是書生！ 


&nbsp;


25、俗話說：金錢不是萬能的；


可俗話又說：有錢能使鬼推磨！ 


&nbsp;


26、俗話說：天無絕人之路；


可俗話又說：天網恢恢，疏而不漏！ 


&nbsp;


27、俗話說：出淤泥而不染；


可俗話又說：近朱者赤，近墨者黑！ 


&nbsp;


28、俗話說：捉賊捉贓，捉奸捉雙；


可俗話又說：欲加之罪，何患無辭！ 


&nbsp;


29、俗話說：貧賤不能移！


可俗話又說：人貧志短，馬瘦毛長！ 


&nbsp;


30、俗話說：青出於藍而勝於藍；


可俗話又說：薑還是老的辣！ 


&nbsp;


31、俗話說：後生可畏；


可俗話又說：嘴上無毛、辦事不牢！ 


&nbsp;


32、俗話說：有緣千裡來相會；


可俗話又說：不是冤家不聚頭！ 


&nbsp;


33、俗話說：在天願作比翼鳥，在地願為連理枝；


可俗話又說：夫妻本是同林鳥，大難來時各自飛！ 


&nbsp;


34、俗話說：得饒人處且饒人；


可俗話又說：縱虎歸山，後患無窮！ 


&nbsp;


35、俗話說：善有善報，惡有惡報；


可俗話又說：人善被人欺，馬善被人騎！ 


&nbsp;


36、俗話說：一分耕耘、一分收獲；


可俗話又說：人無橫財不富、馬無夜草不肥！ 


&nbsp;


37、俗話說：小心駛得萬年船；


可俗話又說：撐死膽大的，餓死膽小的！ 


&nbsp;


38、俗話說：量小非君子；


可俗話又說：無毒不丈夫！ 


&nbsp;


39、俗話說：一寸光陰一寸金；


可俗話又說：寸金難買寸光陰！ 


&nbsp;


40、俗話說：日久見人心；


可俗話又說：人心隔肚皮！ 


&nbsp;


41、俗話說：光陰似箭；


可俗話又說：度日如年！ 


&nbsp;


42、俗話說：己所不欲，勿施於人；


可俗話又說：順我者昌，逆我者亡！ 


&nbsp;


43、俗話說：邪不勝正；可俗話又說：


道高一尺，魔高一丈！ 


&nbsp;


44、俗話說：小不忍則亂大謀；


可俗話又說：不蒸饅頭蒸(爭)口氣！ 


&nbsp;


45、俗話說：人人為我，我為人人；


可俗話又說：人不為己，天誅地滅！ 


&nbsp;


46、俗話說：不怕人不敬，就怕己不正；


可俗話又說：眾口爍金，積毀銷骨！ 


&nbsp;


47、俗話說：三個臭皮匠，勝過一個諸葛亮；


可俗話又說：一個和尚挑水喝，兩個


和尚抬水喝，三個和尚沒水喝！ 


&nbsp;


48、俗話說：不入虎穴，焉得虎子；


可俗話又說：老虎屁股摸不得！ 


&nbsp;


49、俗話說：百行孝為先；


可俗話又說：忠孝不能兩全！ 


&nbsp;


50、俗話說：人無遠慮，必有近憂；


可俗話又說：今朝有酒今朝醉，明日愁來明日憂！ 


&nbsp;


51、俗話說：家事國事天下事，事事關心；


可俗話又說：老婆孩子熱炕頭！ 


&nbsp;


52、俗話說：人定勝天；


可俗話又說：天意難違！ 


&nbsp;


53、俗話說：愚公移山；


可俗話又說：胳膊擰不過大腿！ 


&nbsp;


54、俗話說：哪裡跌倒哪裡爬起；


可俗話又說：一失足成千古恨！ 


&nbsp;


55、俗話說：路不平有人鏟，事不平有人管；


可俗話又說：各家自掃門前雪，莫管他人瓦上霜！ 


&nbsp;


56、俗話說：滴水之恩當湧泉相報！


可俗話又說：過河拆橋、卸磨殺驢、


兔死狗烹、鳥盡弓藏！ 


&nbsp;


57、俗話說：雙喜臨門；


可俗話又說：福無雙至，禍不單行！ 


&nbsp;


58、俗話說：人挪(移動)活，樹挪死；


可俗話又說：滾石不生苔，轉業不生財！ 


&nbsp;


59、俗話說：嫁雞隨雞，嫁狗隨狗；


可俗話又說：男怕選錯行，女怕嫁錯郎！ 


&nbsp;


60、俗話說：明人不做暗事；


可俗話又說：兵不厭詐！
