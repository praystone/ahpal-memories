女人一生一定要做的20件事



&nbsp;



每天我們都要做很多事,不時會有人說這件事情是你必須做完的。



漸漸的忙碌讓我們有些漠視我們自己，



也似乎漠視生命中一定要做的事情其實



是那些真正對自己好的事情…… 



&nbsp;



	※擁有幾個閨中密友



	在女人漫長的一生中，一定要有幾個親如姐妹的好友陪伴。 

像瓊瑤小說《煙雨濛濛》中的依萍和方瑜，


	像亦舒小說《流金歲月》中的蔣南孫和朱鎖鎖，


	歲月更迭，人事變遷，兩個女孩子之間的


	情誼卻從未更改。



	這種朋友，有一個溫暖的名字，叫做


	「閨中密友」。「閨」，不單單指閨閣、


	閨女、閨房，而是指那些只有同性之間才能


	明白和理解的閨中情懷。總要有那麼一個或


	幾個密友，陪伴我們經歷情事艱難和人生滄桑，


	等到我們滿頭華髮、子孫滿堂時，仍然可以


	一起坐在搖椅上，面帶恍笑地，聊起年少荒唐事。 

「誰能夠划船不用漿，誰能夠揚帆沒有風向，


	誰能夠離開好朋友，沒有感傷？我可以划船


	不用漿，我可以揚帆沒有風向，但是朋友啊，


	當你離我遠去，我卻不能不感傷。」——


	唱起無印良品這首《朋友》的時候，


	有多少女孩子，哭紅過眼睛？ 



	　　※認真寫一封情書 


	　　在通訊越來越發達的年代，我們可以很


	輕鬆地找到一個人，卻更難進入一個人的內心了。


	&nbsp;


	我們曾經為沈從文寫給張兆和的那段情話


	「我行過許多地方的橋，看過許多次數的雲，


	喝過許多種類的酒，卻只愛過一個正當最好


	年齡的人」無限唏噓過，但趕時髦的


	年輕情侶們，大多對此無動於衷。 

　　試想，當多年之後，「情書」成為被


	「愛情電郵」或「愛情MSN」取代的出土文物，


	那將是多麼可惜的事！ 

　　所以，讓我們安靜下來，鋪一紙素箋，


	拾起擱置多時的筆，認真地寫一封情書吧，


	讓承諾擱淺，讓瞬間永恆。


	&nbsp;


	即使時過境遷，即使你們已經海角天涯，


	他還能從字裡行間，尋找到曾被你深愛過的


	證據，並且在看到舊情書的時候，頭腦中


	仍是你年輕美麗的面龐。


	&nbsp; 

	※嫁給一個愛你的人


	&nbsp;


	如果你的另一半，正好愛你也為你所愛， 


	那當然是最理想的狀態。 


	&nbsp;


	但是，有情人終成眷屬的美滿結局，


	並不是每個女人都能得到的。 


	&nbsp;


	過來人的建議一般都是：可以一廂情願地選個


	你愛的男人談戀愛，但若要結婚，還是請挽住


	一個真正愛你的男人的手臂吧。 　　


	&nbsp;


	因為愛，他對你的一切，才會有足夠憐惜和包容。


	&nbsp;


	&nbsp;很多執著的現代女性都說，她們也可以包容


	一個不愛自己的男人做丈夫，但事實證明，


	女性對婚姻和關愛的渴求更甚於男性，


	這種婚姻，大多並不幸福。 　　


	&nbsp;


	年輕的男歌手如羽泉，都這樣忠告女性：


	把愛留給愛你的人吧，至少他會對你認真。





	※寬容理解是美滿婚姻的保障 

　　去年一部熱播的電視劇《中國式離婚》，


	給不少「望夫成龍」的女性敲響了警鐘。


	&nbsp;


	根本沒有第三者的穿插和背叛，一切矛盾，


	都是從妻子對丈夫無休止的猜忌開始的，


	正是妻子的歇斯底里、無中生有，將原本


	幸福的家庭推向破裂的邊緣。


	&nbsp;


	其實，沒有必要去哀歎「婚姻是愛情的墳墓」


	這樣的老話，婚前的期待和婚後的現實，


	本來就相差很遠，再堅定的愛情，也必須


	接受從浪漫到實戰的考驗。


	&nbsp;


	繁瑣的家務事，沉重的社會壓力，在某些時候，


	肯定會讓夫妻雙方都感到無力和疲憊。


	&nbsp;


	但是，也有無數美好的婚姻提醒我們，


	寬容和理解，才是讓婚姻保鮮的最大秘訣。


	這也是女性需要格外注意的。 

　　※營造浪漫，發掘生活情趣 


	生活中不是沒有美，而是缺乏發現美的眼睛。


	&nbsp;


	同理可證，生活中並非沒有女性所孜孜以求


	的浪漫，而是缺乏營造和發掘生活情緒的心靈。


	&nbsp;


	沒錯，浪漫其實就是一種純真的心態，


	也是一種對待生活的熱忱。


	&nbsp;


	在感恩的眼睛裡，突如其來的鮮花是浪漫，


	粗布餐桌上的一支蠟燭也可以是浪漫；


	包裝精美的禮物是浪漫，但與愛人手拉手


	漫步街頭同樣也是浪漫。


	&nbsp;


	生活原本就是平淡無奇的，只有善於


	營造浪漫的女人，才是真正懂得生活的女人。 

　　小女人趙詠華一再吟唱的


	「我能想到最浪漫的事，就是和你一起


	慢慢變老，一路上收藏點點滴滴的歡笑，


	留到以後坐著搖椅慢慢聊」，


	誰能說這種返璞歸真，


	不是真正的幸福和浪漫呢？ 



	　　※放開胸懷，扮一回叛逆角色 


	　　很多女性，從小就被定型為「淑女」，


	不能弄髒衣裙，不能大聲叫嚷，不能一個人


	跑去旅行，等等。


	&nbsp;


	長大了，又必須上大學，工作，按部就班，


	當了妻子與母親後，更加不能異想天開，


	日子過得四平八穩但平淡無奇。


	&nbsp;


	但是，問問你身邊的這些高貴優雅的女性，


	她們真的幸福快樂嗎？


	&nbsp;


	私底下的她們，其實經常憂心忡忡、疲憊不堪，


	因為她們往往刻意把自己裝進套子裡。


	&nbsp;


	為了迎合莊嚴、正統而虛偽的社會風範，


	她們壓抑了自我，泯滅骨子裡的那份瘋狂和反叛。 

　　所以，在某些無傷大雅的場合，


	放縱一下自己吧，像《鐵達尼號》中的羅絲，


	終於擺脫母親的束縛，跟著傑克跑到船頭，


	張開雙臂，讓長髮在風中翻飛，


	那也是她一生中，最暢快淋漓的時刻。 



	　　※熱烈投入地愛一次 


	情歌聽得唱得太多了，反而覺得愛情是如此


	可望不可及的事情，特別是對女性而言。


	&nbsp;


	問問自己，有沒有過古代女子「拼將一生休，


	盡君一日歡」的堅貞決絕？


	&nbsp;


	有沒有過張愛玲所謂「見到他，


	她變得很低很低，低到塵埃裡，


	但她心裡是歡喜的，從塵埃裡開出花來」


	的純淨清澈？


	&nbsp;


	有沒有辛曉琪「我們的愛若是錯誤，願你我


	沒有白白受苦」的寬厚堅忍？


	&nbsp;


	一個人怕孤獨，兩個人怕辜負，斤斤計較的愛情


	充斥在我們周圍，往往會讓女性望而卻步。


	&nbsp;


	但是，當你夢想中的那個人出現，當你嚮往的


	愛情來臨，就深情熱烈地愛一次吧。


	&nbsp;


	也許你會受傷，但這是讓你人生完整的惟一方法。 

　　讓我們仍然信仰席慕蓉的詩句：


	年輕的時候，如果你愛上了一下人，請你，


	請你一定要溫柔地對待他。


	&nbsp;


	不管你們相愛的時間有多長或多短，


	若你們能始終溫柔地相待，那麼，


	所有的時刻都將是一種無瑕的美麗。


	&nbsp;


	若不得不分離，也要好好地說聲再見，


	也要在心裡存著感謝，感謝他給了你一份記憶。


	&nbsp;


	長大了以後，你才會知道，在驀然回首的剎那，


	沒有怨恨的青春才會了無遺憾，


	如山岡上那輪靜靜的滿月。 



	　　※至少要為自己留一次長髮 

有一回在公共汽車上，旁邊女乘客的頭髮掠過


	我的手臂，這原本是電視裡洗髮水廣告的


	動人一刻，下一個鏡頭就該是某美女


	烏黑亮麗的長髮了。


	&nbsp;


	但是，當我轉過頭，卻發現那縷頭髮非但


	枯燥不齊，而且夾雜著大量白髮，


	其主人，則是一位五十歲開外的阿姨！


	&nbsp;


	當時就感歎，女人，在什麼年紀，


	就得做什麼年紀的打扮，你不服都不行！


	&nbsp;


	那次經歷，也刺激我頻頻向女友們進言：


	一定要趁年輕，留一次長髮！ 

　　這並不是說，年長的女人絕對不能留長髮，


	但白髮零星，確實很難給觀者美感。


	&nbsp;


	瀟灑老女人如三毛，她數十年如一日的麻花辮子


	造型，也遭到過非議；羅大佑可以唱


	「穿過你的黑髮的我的手」，但如果這


	「黑髮」變白，份量和感覺要大打折扣吧？ 



	　　※拜訪一位景仰的名人 


	　　很多人心目中都有這樣的一個人：


	你熟知他/她的一切，你以他/她為榜樣，


	他/她是你生命中的一線光明，在遭遇挫折時，


	除了親朋好友，你還會想到他/她。


	&nbsp;


	不，這並不是時下被說得氾濫的「偶像」，


	他/她是你真正景仰的人物。


	&nbsp;


	柴可夫斯基在第一次見到托爾斯泰後，曾激動地


	寫了這樣的文字：「我第一次去見托爾斯泰，


	心裡惶惑不安，覺得十分害怕。我想，他只要瞧


	我一眼，就會把我心靈深處的秘密看透。


	在他面前，人絕不可能把自己心底裡的邪念


	藏起來瞞過他。……托爾斯泰坐在我旁邊，


	聽我彈奏我的第一部四重奏中的行板，我看見


	眼淚從他的面頰流下來。在我此生中，作為一個


	作曲家，我的奢望也許再也得不到比這


	更大的滿足了。」 

　　相信我，如果你真的有一個景仰的人，


	並且能夠拜訪到他/她，你會情不自禁地


	用上全部的真誠、全部的智慧和全部的努力，


	你的人生，也必然因那一刻而有所提升。 



	　　※開懷暢飲讓自己醉一次 


	　　綠蟻新醅酒，紅泥小火爐。


	晚來天欲雪，能飲一杯無？


	&nbsp;


	白居易的這首《問劉十九》，讓我等充滿嚮往：


	在天黑欲雪的傍晚，一個人獨飲太過沉悶，


	於是寫張紙條邀請朋友前來，而朋友呢，


	看到這麼別緻的詩句，肯定也會酒興大發吧？


	&nbsp;


	雖然因為性別的差異，女中劉伶人數極為有限，


	大口吃肉大碗喝酒，也並不符合社會對


	女性形象的期待。


	&nbsp;


	但是，大學畢業晚會上，童年好友別後重逢時，


	你是端莊地坐在一邊干看著，還是豪情萬丈地


	浮一大白？


	&nbsp;


	相信很多女子，至少有一次會毫不猶豫地


	選擇後者。要知道，即使是女人，一輩子


	如果沒有一次酣暢淋漓的經驗，


	那也算得一種遺憾。


	&nbsp;


	選擇一個無關大局的場合，最好身邊還有


	一個可靠的人隨時準備照顧你，那麼，


	你就可以一醉方休了。



	　※至少獻一次血 

　　要知道，我們不僅是女兒、妻子、母親，


	更多時候我們是一個社會人，要擔負起屬於


	自己的社會責任。


	&nbsp;


	太多相識或不相識的人，給過我們關愛、溫情


	和幫助，我們也要反饋給他人。


	&nbsp;


	女性一生中，至少應該去獻一次血，去享受


	一下與世界、與人群血脈相通的快樂。


	&nbsp;


	這也是對自己健康的一種投資。 




	　　※至少學會一種樂器 

　　問過很多陪著小孩子去學琴的家長，


	他們的回答大致都是一樣的：一個普通孩子，


	也許沒有天賦成為另一個貝多芬，也沒有機會


	成為另一個貓王，但是，會一種樂器，


	卻將成為孩子一生中不離不棄的好朋友。



	對女性來說，無論是撫琴還是一種樂器，


	更足以提升她的個人氣質。


	&nbsp;


	我們都有很多話，也許找不到任何人傾訴，


	但是當彈奏起自己心愛的樂器時，世界所有的


	喧囂都暫時離你而去，所有的委屈都可以隨風而散。 



	　　※在生日那天，給母親寫封信 


	　　還記得冰心那首廣為流傳的詩嗎？


	「母親啊，/你是荷葉，/我是紅蓮，


	/心中的雨點來了，/除了你，/誰是我


	無遮攔天空下的蔭庇？」


	&nbsp;


	身為女性，當然更知道生日就是母親的受難日


	這樣的道理，在你生日那天，更多地


	想到你的母親吧。


	&nbsp;


	想想她愛憐溫柔的眼睛,想想她永遠寬容的


	懷抱，想想她無怨無悔的曾經歲月，想想她


	隱隱出現的白髮，和日漸消失的紅顏......


	&nbsp;


	在你生日那天，請給媽媽寫一封信，告訴她，


	你對生命的感激和體會，告訴她，你一直知道


	她的愛，而你將永遠愛她。


	&nbsp;


	只要有過這麼一次，母親就會覺得，


	她所有的辛苦都是值得的。 



	　　※在公共場合作一次演講 


	　　大多數女子，受的都是「不拔尖、不冒進」


	的中庸教育，能像「萬人迷」那樣對自己有


	自信的，在平常人中寥寥無幾。


	&nbsp;


	雖然不少女作家曾發過類似「有幾個女人


	敢說自己是因為內在美而被愛的？


	如果有，那麼也是辛酸多於自豪」的言論，


	但是，智慧和能力，照樣能給女性帶來自信。 

　　試著有機會，在公共場合作一次演講、


	唱一首歌、或跳一曲舞吧，你雖然不是明星，


	但那一刻，你也是萬眾矚目的。


	當觀眾被你的激情感染而喝彩時，


	你完全可以對自己說：「我自信，我勇敢，


	我是一個有魅力的女人！」 



	　　※每天閱讀15分鐘 


	　　張愛玲說過，有美的身體，以身體悅人，


	有美的思想，以思想悅人。


	&nbsp;


	娘生爹養，先天不是美女，這根本沒辦法怪誰。


	&nbsp;


	但，通過後天努力讓自己做個「氣質美女」，


	卻不是沒有可能，這就應了「腹有詩書氣自華」


	的古訓。


	&nbsp;


	不管外界壓力有多大，也要給自己訂一個


	讀書計劃，讓心靈家園豐潤起來。 



	　　※將購物時間削減一半 


	　　估計這一點，會是大多數男性對女性


	最誠摯的懇求。大多數女人天生就是逛街動物，


	經常是興沖沖出門去，大包小包地回家來，


	但當她們頭腦冷靜下來，卻發現買回來的很多


	都是可買可不買、或者根本無用的東西。 

這種購物衝動，持續不斷地消耗著個人的時間、


	精力和金錢，也讓女性自己感到困惑。


	&nbsp;


	所以，學著把自己的購物時間減少吧。


	&nbsp;


	要改變一個習慣，最好的方法，就是用另一個


	行為來代替。打個比方，去散步、找朋友聚會、


	去圖書館或做運動，任何可以阻止你


	衝動購買的事情，都是有效的方法。 

　　或許，剛開始你會有一種被剝奪了逛街樂趣


	的感覺，但當你逐漸不再被自己強迫著要去


	逛街、購物，你一定會有一種無法形容的解脫感。

　　※去一個你心儀的地方 


	　　年少的時候，每個人都有著「去遠方」


	的夢想，但是，繁忙喧囂的工作、生活、家事，


	渺小可憐的工資、存款，一點一點地啃噬著


	我們原本就脆弱的嚮往。 

　　有空的時候沒錢，有錢的時候沒空，


	等到時間和錢都具備的時候，大多數人已經到了


	意興闌珊的老年，再也很難拔得出腳出門了。


	&nbsp;


	而女性呢，有家庭孩子的束縛，


	出外旅遊的機率，比男性還要小一些。 

　　還是不要把夢想束之高閣吧。


	&nbsp;


	年輕的時候，別讓自己的腳步停止在灰暗嘈雜的


	辦公室天空下，別把自己的心情


	拘束在家長裡短的狹小環境中。


	&nbsp;


	至少去一個你的夢想之地，當你達到那個高峰、


	平原或者低谷，你才會真切地體會到造物主


	的偉大：世界很大，而人，很小。 



	　　※為孩子寫成長日記 


	非常喜歡最近的一則電視廣告，媽媽很自豪地


	對孩子一一細數自己的收藏：「寶寶的胎發，


	媽媽留著；寶寶穿的小鞋子，媽媽留著；


	寶寶細嫩光滑的皮膚，媽媽也留著……」


	&nbsp;


	在媽媽眼中，我們永遠都可以是當年那個


	紅通通、香噴噴、眼睛大大、淌著口水的小寶貝。


	&nbsp;


	只要一想起幼年時在媽媽懷抱中的溫暖和


	無憂無慮，無論成年的我們遭受多大的挫折，


	也都不會輕易放棄自己。 

建議每一個媽媽，為孩子留住一些成長的痕跡。


	&nbsp;


	用筆、用照相機、或者DV，記錄他們成長路上的


	片斷，讓成年的他們看到媽媽無盡的關愛，


	讓他們永遠不會感到孤單無援。 



	　　※參加一次葬禮，體味生命的可貴 


	大多數時候，我們都很難真切地體會到生命的


	可貴，很難有時間認真地考慮生老病死的問題。 

　　當生命無可挽回地從手邊溜走時，


	我們才知道這是無法彌補的損失。


	&nbsp;


	所以，一定要去參加一回葬禮，


	真切地感受一下人們對死亡的態度.
