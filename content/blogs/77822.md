拴不住漂亮，就要做個精緻的女人



&nbsp;

女人過了三十歲，就過了如花的季節，

年齡不芳，漂亮就像是握在手裏的沙，

攥的越緊從指縫中流失的就越快。

&nbsp;

但是有了一把年紀，也有了底蘊和魅力，

從內而外散發出來的成熟氣息，

是小女孩兒那種絹花似的漂亮所不及的。

&nbsp;

拴不住漂亮，就要力爭做個精緻的女人，

精緻的女人不會老！　　

&nbsp;

女人想精緻就要懂得包裝自己，

女為悅己者容，當然女也應當為自己容。

&nbsp;

在柴米油鹽中摸爬滾打過來的女人，

被老公的臭襪子和孩子的髒衣服

纏裹得透不過氣的女人，

最需要一分好心情來善待自己，

也最需要好好打扮自己。　　



美容大師克萊爾·瑪娜有一個著名的公式：

三分姿色＋一分化粧＋二分服裝＋

二分首飾＋二分手袋＝百分之百美人。

&nbsp;

這跟我們國家的一句古老俗語：

“三分長相，七分打扮”異曲同工。

&nbsp;

但是三十歲的女人打扮自己要懂得遊戲規則：　　

&nbsp;

一分化粧要淡雅。

&nbsp;

粧要上得乾淨、不留痕跡，似有若無才是最高的境界。

過了三十歲，日粧中藍眼影，黑唇膏是萬萬用不得的，

即便是艷紅色也要用得小心翼翼。

眉要修得適合臉型、眉影要打的自然清晰，纖毫必現。

不可王婆畫眉，草書一樣在眼睛的上方

留下兩道又濃又黑的炭痕。

粉底要打的透明，細緻，刷塗料一樣掛著一張假臉，

白是白了，美卻沒有了。

上班前攬鏡細照，看看牙齒上是不是粘有唇膏

(常見粗心的女子浩齒上面一點紅)，

再看看眉毛裏是不是藏了粉底，

精緻是講究細節的，不可粗心大意。

一切無誤，走出門的將是個清清爽爽的小女子。　　

&nbsp;

二分 服裝要得體。

&nbsp;

衣服除了保暖、禦寒、遮羞之外，

還有一項功能就是揚美抑醜。

關於穿衣的三六九，恐怕一本書也羅列不完。

服裝不在貴賤，得體是首選，然後考慮其他。

過了三十歲就不再是個亂穿衣的年齡，所以穿衣

要符合身份、年齡、職業、場合，這樣才能穿出品味、

穿出個性、穿出獨一無二，不能人云亦云。

長裙的飄逸，短裙的簡約，牛仔褲的精練，

吊帶小背心的性感……不管哪一款，

適合自己的才是最好的。

穿衣要穿出自信來，自信的女人是精緻的。　　

&nbsp;

二分 首飾要精美。

&nbsp;

作為一個心繫美麗的女子，首飾絕對是最愛，

翠玉的手鐲、本色陶土的項墜，貓眼兒、珍珠項鏈、

鉑金的指環、鑲鑽的耳釘和髮釦……也許許多首飾

只伴了你從商廈到回家的路，

但我相信每一款都會凝結一個前世來生的約定，

下次遇到喜歡的，依然還會有據為己有的衝動。

精緻的女人配戴首飾從來不會有珠光寶氣，

環佩叮噹的俗，而是彰顯個性，盡現從容與優雅。

是那種增一件太多，減一件又太少的恰到好處。　　

&nbsp;

二分 手袋要簡約。

&nbsp;

手袋是精緻女人不可缺少的道具。

手袋除了用來盛物之外，

決不能忽視它跟服飾的互相搭配。

手袋和鞋子一樣重要，用的好是錦上添花，

用的不好則是敗筆。

因為手袋不用像衣服一樣換的那麼頻，

所以手袋從款式到做工再到質地都要選上乘的，

而且要與服裝渾然一體，不能將就。

皮手袋的典雅、布手袋的純樸、

結珠綴金手袋的精巧……提在手裏，挎在肩上，

每一款都能演繹出一個精緻女人的動人小故事。　　

&nbsp;

三分 姿色 

&nbsp;

跟遺傳有關，與生俱來，天生天養，

這三分要看你的造化如何

(當然不包括現在的人造美女)。但

“腹有詩書氣自華”，

就算你沒有先天的漂亮臉蛋，

還可以有後天修來的傲人氣質，

這是神韻，跟最原始的姿色無關

，只要你拒絕平庸，拒絕呆板，拒絕性格上的粗線條，

收斂一下風風火火、大大咧咧、不拘小節的行為，

想做一個精緻的女人不難。



精緻的女人要陰柔，即要有所謂的女人味。

　　女人味跟漂亮無關，

漂亮的女人不一定有女人味，

但有女人味的女人一定會流露出奪人心魄的美，

那種伴著迷人眼神的嫣然巧笑、

吐氣若蘭的燕語鶯聲、

輕風拂柳一樣飄然的步態，

再加上細膩的情感、純真的神情，

都會讓一個並不炫目的女子

溢出醉人的嫻靜之味、

淑然之氣，置身其中，暗香浮動，

女人看了嫉妒，男人看了心醉。

&nbsp;

女人味也跟貧富無關，

一個全身名牌的女人一張嘴就吐出

國罵實在讓人不敢恭維。

這樣的女子一身銅臭而索然無味，

看久了傷眼，只想遠之再遠之。

&nbsp;

而一介布衣布履的女子因為自身

散發出來成熟和知性美，

會讓人覺得有如鄰家姐妹一樣親切怡人。　　

&nbsp;

女人的精緻不關外貌的美醜、

不關貧富貴賤、也不關風花雪月。

篡改一句很喜歡的廣告詞：

女人的精緻——從內而外。
