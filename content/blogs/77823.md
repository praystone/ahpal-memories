心烙&nbsp;&nbsp;&nbsp;&nbsp; 墨海深藏


&nbsp;


道盡世間柔情無限


&nbsp;


卻訴不盡心愁幾許


&nbsp;


今夜～


&nbsp;


且讓靈羽飄逸悠遊


&nbsp;


馳騁綠野銀波


&nbsp;


讓夜月笙歌輕揚&nbsp;&nbsp;&nbsp;&nbsp; 讓銀空鑲滿水鑽


&nbsp;


讓靈魂微笑&nbsp;&nbsp;&nbsp;&nbsp; 讓記憶徜徉


&nbsp;


不再是單調黑白相間


&nbsp;


是你留下繽紛的彩艷


&nbsp;


將冰冷的灰白&nbsp;&nbsp;&nbsp; &nbsp;塗上生命色彩


&nbsp;


喜上眉梢&nbsp; &nbsp;&nbsp; 翩然起舞


&nbsp;


尋求一個讓傷口癒合的境地


&nbsp;


拾起天真...


&nbsp;


是你默許相應的契心


&nbsp;


感動雀躍...


&nbsp;


勝過千萬個深詠的愛語


&nbsp;


也勝過無數悲情淚水的企盼


&nbsp;


相知相惜&nbsp;&nbsp;&nbsp; &nbsp;烙印心田


&nbsp;


超越世俗情愛的枷鎖


&nbsp;


照見赤然純真


&nbsp;


願與～


&nbsp;


奔向遼闊銀漢&nbsp;&nbsp; &nbsp; 隨風萬里無羈


&nbsp;


天地悠悠


&nbsp;


共


&nbsp;


翱


&nbsp;


翔


&nbsp;
