&nbsp;

&nbsp;

&nbsp;

雨濛濛&nbsp;霧濛濛的&nbsp; 暗夜裡 ...
突然的 寒流來襲...
偶爾聽到救護車
急駛而過的阿~嗚~聲...
&nbsp;
也讓我 想起去年...
冷颼颼 的星期天...
跟著師兄姊去到老人院
&nbsp;
我還全副武裝(羽絨衣防寒褲)
當然...棉被/外套/食物...等(贈送物品
在團聚時... 老爺爺/老奶奶&nbsp;&nbsp; 很高興
&nbsp;
有一個80多歲的老爺爺(我服務過3次
突然摔倒在輪椅下...大夥都嚇一跳 !!
醫務人員也趕來急救&nbsp; 我忽然大喊&nbsp; 救護車呢??
趕快送醫院呀~ 我掏起口袋裡的手機...緊張的按~按~
&nbsp;
師兄說話了~他們有一套作業系統 別緊張...............
經過約半小時的救護&nbsp;&nbsp; 老爺爺甦醒過來..用微弱的聲音
說:小兄弟 幫我點根菸...

&nbsp;

&nbsp;

********************************************

&nbsp;

&nbsp;

老爺爺 姓賈 江西人&nbsp; 16歲還在讀書時 因為 國共內戰.
邊打邊跑 到大陳島駐紮.也當起國軍的勇士.
撤回台灣後.支援金門戰地.也遇上823戰役.
&nbsp;
我第一次服務他的時候.是在夏天...............

我盯著他看.他還很開朗的叫了一聲.小兄弟 幹嘛盯著我手背看?
呵呵~ 反攻大陸/效忠國家 是我的責任 

(雖然刺青顏色已經褪去...


我跟老爺爺相談甚歡.奉上菊花茶 (我也陪著抽菸.....
&nbsp;
今年3月我們再去時...沒有見到他了............


院方&nbsp;&nbsp;遞了一張紙條交給我&nbsp; 寫著 

&nbsp;

&nbsp;

小兄弟&nbsp; 永別了&nbsp; 不用傷心


&nbsp;

我知道你會再來看我&nbsp; 可惜啊 !! 

&nbsp;

見不到你很遺憾 不過我會保佑你.


&nbsp;

&nbsp;

剎那間 我淚如雨下............

&nbsp;

&nbsp;

雖然才幾次的服務.不過我永遠都還記得老爺爺開朗的笑聲說:&nbsp; 
&nbsp;
小兄弟~ 你又來了.
&nbsp;
葬在彰化的軍人公墓. 我在假日時...去過幾次~


&nbsp;

我想...元旦! 還會去~ 他喜歡菊花茶/香菸........
&nbsp;


&nbsp;

PS: 我已經離開志工隊半年了. 也許我太年幼吧!!
