&nbsp;





&nbsp;






 











&nbsp;


人生一世，就好比是一次搭車旅行，


&nbsp;


&nbsp;


要經歷無數次上車、


&nbsp;


&nbsp;


下車時常有事故發生，


&nbsp;


&nbsp;


有時是意外驚喜，


&nbsp;


&nbsp;


有時卻是刻骨銘心的悲傷。 


&nbsp;


&nbsp;


有時候對你來說情深義重的旅伴


&nbsp;


&nbsp;


卻坐到了另一節車廂。


&nbsp;


&nbsp;


你只得遠離他，繼續你的旅程。


&nbsp;


&nbsp;


當然在旅途中，


&nbsp;


&nbsp;


你也可以搖搖晃晃地穿過自己的車廂，


&nbsp;


&nbsp;


去別的車廂找他，


&nbsp;


&nbsp;


可惜你再也無法坐在他身旁，


&nbsp;


&nbsp;


因為這個位置已經讓別人給佔了。 


&nbsp;


&nbsp;


沒關係旅途充滿挑戰、


&nbsp;


&nbsp;


夢想、希望、離別就是不能回頭。


&nbsp;


&nbsp;


因此，盡量使旅途愉快吧！&nbsp; 


&nbsp;


&nbsp;


&nbsp;


永遠記住，


&nbsp;


&nbsp;


在某一段旅程中，有人會猶豫彷徨，


&nbsp;


&nbsp;


因為我們自己也會猶豫彷徨。&nbsp; 


&nbsp;


&nbsp;


我時常這樣想：


&nbsp;


&nbsp;


到我該下車的時候，我會留戀嗎？ 


&nbsp;


&nbsp;


和我的朋友分離，我會痛苦嗎？ 


&nbsp;


&nbsp;


生命旅程就像火車一樣，


&nbsp;


&nbsp;


有快速的自強號，很快就到達目的地。


&nbsp;


&nbsp;


沿途只停靠幾站，


&nbsp;


&nbsp;


但你應該沒心情看沿途風景。


&nbsp;


&nbsp;


因為你只想要的很快速到達目的地。


&nbsp;


&nbsp;


很多人的人生像自強號，


&nbsp;


&nbsp;


到結束仍然是呼嘯而過，


&nbsp;


&nbsp;


生命裡的沿途風景也跟著呼嘯而過，


&nbsp;


&nbsp;


有些可惜。


&nbsp;


&nbsp;


&nbsp;


什麼才是對、錯、好、不好，


&nbsp;


&nbsp;


有人也喜歡選擇慢車，


&nbsp;


&nbsp;


喜歡慢慢的欣賞沿途風景， 


&nbsp;


&nbsp;


品嚐人生每一階段所經歷的喜樂哀愁。


&nbsp;


&nbsp;


當下的你心情除了慢，連動作也慢了，&nbsp; 


&nbsp;


&nbsp;


當你做這樣的選擇，你的人生閱歷豐富，


&nbsp;


&nbsp;


明白人生除了快，也可以選擇慢，


&nbsp;


&nbsp;


等你想到應該要轉換其它列車時，


&nbsp;


&nbsp;


那時你便開心並清楚的知道，&nbsp;&nbsp; 


&nbsp;


&nbsp;


人生美景，只要用心無所不在，


&nbsp;


&nbsp;


因為這都是你自己的選擇，&nbsp; 


&nbsp;


&nbsp;


我正朝這樣的選擇慢慢前進中。


&nbsp;




&nbsp;



&nbsp;
