&nbsp;









&nbsp;




&nbsp;


愛你 一年期待 已來臨


&nbsp;


&nbsp;


圓又圓的你粉胖胖可愛


&nbsp;


&nbsp;


對你另眼看待


&nbsp;


&nbsp;


今晚一直纏我視線


&nbsp;


&nbsp;


望見圓又圓一直猛吞口水


&nbsp;


&nbsp;


是愛想黏你 想舔吻想吞了你


&nbsp;


&nbsp;


夜半到天明 等待一宿的念意


&nbsp;


&nbsp;


東方魚肚微光


&nbsp;


&nbsp;


起來望一望 天寒地凍 


&nbsp;


&nbsp;


為了你披上衣


&nbsp;


&nbsp;


取了一把冬天的火


&nbsp;


&nbsp;


轉個念頭揉揉惺忪雙眼 


&nbsp;


&nbsp;


目視在微溫的體溫


&nbsp;


&nbsp;


正快樂滾動 跳躍著 香香的 


&nbsp;


&nbsp;


想起了 一顆紅豆


&nbsp;


王維:紅豆:


&nbsp;


&nbsp;


紅豆生南國 春來發幾枝


&nbsp;


&nbsp;


勸君多採擷 此物最相思



&nbsp;


&nbsp;


再為你加上溫暖的花生仁 


&nbsp;


&nbsp;


又再抓把細白嫩肉的杏仁


&nbsp;


&nbsp;


成為一道精緻好味覺的冬至湯圓


&nbsp;


&nbsp;


冬至了 


&nbsp;


&nbsp;


祝福大家吃的巧 快樂等過年


&nbsp;


&nbsp;


又添一歲 


&nbsp;


&nbsp;


代表我們今天又更增廣見聞


&nbsp;


&nbsp;


更成熟穩重 


&nbsp;


&nbsp;


不要忘了與家人 親人的互動關懷


&nbsp;


&nbsp;


在此祝福大家 


&nbsp;


&nbsp;


收穫滿滿 無論好的 會有得有失


&nbsp;


&nbsp;


得失心不用太顧慮 


&nbsp;


&nbsp;


準備迎接快樂新氣象的一年
