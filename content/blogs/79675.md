&nbsp;



&nbsp;rn我 要嫁給妳???



&nbsp;


八八風災 約半年後...

&nbsp;

我們去到南部某個孤兒院

&nbsp;

院長出來接待...小朋友們...繃繃跳跳的笑開懷.

&nbsp;

當我眼光一掃.有個小女生就躲在榕樹後...

&nbsp;

黑黑的皮膚.好大的眼睛...


院方幫我們把車上的禮物搬到遊戲間.

&nbsp;

當我們分發禮物後...我覺得樹後的小女生.

&nbsp;

沒有來領取...後來我問了院長...

&nbsp;

才知道.她是八八風災的遺孤&nbsp; 才7歲(好心疼...


&nbsp;

當吃飯時...我就刻意的坐在她對面...

&nbsp;

在用餐時問她...怎麼回事??不喜歡禮物嗎??

&nbsp;

她回說:我的芭比娃娃在土堆裡.找不到了...

&nbsp;

看她滿臉的委屈...

&nbsp;

我回了她...下次我送妳.她用疑惑的眼光看我...

&nbsp;

可是...她笑了......笑的好甜...真的嗎??我點頭.

&nbsp;

&nbsp;

&nbsp;

九月... 師兄告知我明天要去南部的某孤兒院.

&nbsp;

突然讓我想到她(黑妞

&nbsp;

我很高興的馬上去到百貨公司找芭比...

&nbsp;

還買了3件一服...又加買了兩件...花了我3千多塊錢.


&nbsp;

當車子停到院內時.我看到她跑好快.....


說:大哥哥...牽著我的手 等你好久.以為你不會來了

&nbsp;

我抱著她...摸著她的頭...說:妳要的

&nbsp;

我專程送來給妳...接著我把箱子給了她

&nbsp;

遊戲時...院長說...誰有願望可以說出來

&nbsp;

沒想到...黑妞竟然跑到我面前...

&nbsp;

親我一下說:

&nbsp;

等我大學畢業後大哥哥要嫁給我

&nbsp;

院裡的所有人...都拍手說:嫁給她～嫁給她

&nbsp;

讓我無地自處～～我回說:以後嫁給妳.......

&nbsp;

&nbsp;

她被國外的善心人士領養了

&nbsp;

在澳洲 過的很幸福......

&nbsp;

想想...我會嫁給妳&nbsp;&nbsp;&nbsp;&nbsp; 我笑了&nbsp; !!
