&nbsp;



兩顆往口裡 一含.喔!!!!

&nbsp;

酸中又帶微甜.雙眼微微一閉...

&nbsp;

靠在沙發上.靜靜的享受....

&nbsp;

突然間老媽衝了過來並且......

&nbsp;

雙掌一出~~~~

&nbsp;

啪~啪~速度之快 絕無出其右...(比無影手更快)

&nbsp;

一手額頭.一手 肚子..........

&nbsp;

驚問道: "發燒" "肚痛"...我只是 我只.......驚聽一聲!!

&nbsp;

"媽咪"放在哪呀!!老媽出聲說話 放在小碟上...&gt;&nbsp;

&nbsp;

妹妹回應說 沒有啊...

&nbsp;

是否被布丁(貓咪)叼走了?? (我養的喵咪)

&nbsp;

再去拿兩顆.順便體溫槍也拿來!!快喲...&nbsp;

&nbsp;

老媽有一點點緊張的開口說

&nbsp;

哎呦!貓可不愛吃酸的呀!! 我想回口時...

&nbsp;

別亂動.舉起槍(體溫槍)就往我額頭一頂..........

&nbsp;

&nbsp;

老爸大笑著說..才偷吃兩顆"蔓越莓錠"罪不至於槍刑吧!!

&nbsp;

&nbsp;

&nbsp;

PS: 其實...老爸自己最愛偷吃"蔓越莓錠"了...
