&nbsp;

&nbsp;

&nbsp;

微醺的夜 ，

&nbsp;

與好友們分享一篇

&nbsp;

觸動心扉的新詩~

&nbsp;

&nbsp;

&nbsp;


要什麼，

&nbsp;

要一握燭光吧

&nbsp;

帶著你暖暖的叮嚀

&nbsp;

要幾莖細梗玫瑰

&nbsp;

柔軟而白

&nbsp;

在如水的花器裡

&nbsp;

透徹，如你

&nbsp;

&nbsp;

要，就要這份情

&nbsp;

殷然如酒

&nbsp;

且藏之經年的

&nbsp;

要你用眼睛寫下

&nbsp;

許諾------

&nbsp;

一行不落文字的詩

&nbsp;

&nbsp;

而我是那

&nbsp;

微醺的讀詩人

&nbsp;

&nbsp;

&nbsp;&nbsp;&nbsp; ...摘自 陳育虹 『其實，海』
