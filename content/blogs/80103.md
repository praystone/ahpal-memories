&nbsp; 


人依舊，愛依然，情永遠



&nbsp;

&nbsp;


看花開花落，淡看雲卷雲舒，

&nbsp;

讓心回歸自然，尋找一份簡單和平靜；

&nbsp;

辛苦顛簸在紅塵裏，認識了許多形形色色的人，

&nbsp;

在我們身邊來了又走。

&nbsp;

有些人僅僅只是我們生命中過客，

&nbsp;

來無痕去無跡，有些人有緣相守一輩子，

&nbsp;

卻在心裏激不起一絲波瀾，寡淡無味，

&nbsp;

有些人僅僅就看了一眼，卻在心底從此生根，

&nbsp;

甚至牽念一生，千帆過盡之後，

&nbsp;

心中最美的仍是那一閃而過的心悸和燦爛。

&nbsp;

真真切切地愛過，也被深深地愛過。

&nbsp;

&nbsp;

在愛能繼續的時候，讓我們傾盡所有的依戀和期盼，

&nbsp;

去守一份難得的情緣，學會珍惜當初的擁有；

&nbsp;

在愛結束的時候，讓自己笑著揮一揮手，

&nbsp;

彼此互道祝福，然後華麗地轉身，留一個優雅的背影。

&nbsp;

這樣的愛，永遠是無悔！

&nbsp;

&nbsp;

歲月讓我們懂得，

&nbsp;

有些愛即使你傾盡所有也無濟於事，

&nbsp;

不愛了就是不愛了，再多的努力和等待只是徒勞，

&nbsp;

剩下的只是卑微。

&nbsp;

所以瀟灑地揮一揮手與往事作別，

&nbsp;

給自己一個堅強的理由，尋找下一個出口。

&nbsp;

愛也不可能隨心所欲，面對殘忍的現實，

&nbsp;

它有著太多的無奈，即使面對一份難能可貴的曠世真愛，

&nbsp;

也只能忍著痛放手，落下的是一地的遺憾，

&nbsp;

回憶成了僅存的溫暖。

&nbsp;

因為你再強大也抗拒不了命運的力量！

&nbsp;

&nbsp;

有些人無謂失去，有些愛無謂永遠，

&nbsp;

有些情無謂天長地久。

&nbsp;

&nbsp;

失去了，前方會有更好的風景在等你駐足，

&nbsp;

兩個人牽手之後就是心痛的放手，

&nbsp;

而人生最可愛就在那一撒手。

&nbsp;

那麼在生活給我們戲謔玩笑的同時，

&nbsp;

我們就從容大度地綻放給生活一個無比燦爛的笑容，

&nbsp;

相信太陽依然會升起，月亮依然會如水溫柔，

&nbsp;

星星依然會在天空微笑，大地依然會煥發生機，

&nbsp;

明天會更加美好，

&nbsp;

當我們在人生的旅途中辛苦打拼、

&nbsp;

追求，不斷地在得到後失去，在失去中得到，

&nbsp;

總有一些東西是光陰難以磨滅的留在我們記憶裏，

&nbsp;

有苦澀，有歡笑，有感動，有淚水。

&nbsp;

&nbsp;

人生就是一場無止境的漂泊。

&nbsp;

請記得給自己一個堅強的聲音，一個自信的微笑，

&nbsp;

勇敢地站起來繼續無畏前行，相信陽光總在風雨後。

&nbsp;

在這戀戀紅塵裏，

&nbsp;

但願人依舊，愛依然，情永遠。

&nbsp;

&nbsp;
