小時候
&nbsp; &nbsp; 有人只講一句話 &nbsp; 就會讓我們感
&nbsp; &nbsp; 激的想親他 但有時候
&nbsp; &nbsp; 有人只講一句話 &nbsp; 就會讓我們恨
&nbsp; &nbsp; 他一輩子

&nbsp; &nbsp; 不知道這是一句什麼樣的話 &nbsp; 竟
&nbsp; &nbsp; 讓我們的心判若雲泥
&nbsp; &nbsp; 仔細思索 &nbsp; 總是叫我們難以捕捉

記得一個公車上的故事 :
&nbsp; &nbsp; &nbsp;一位男士面對兩位女士站著
&nbsp; &nbsp; &nbsp;一個是美若天仙豔若桃李的女郎
&nbsp; &nbsp; &nbsp;而旁邊的一位是個面貌平庸的婦女
&nbsp; &nbsp; &nbsp;這位男士的眼光游移了一下
&nbsp; &nbsp; &nbsp;終於把目光輕輕地放在那位平庸的婦女上
&nbsp; &nbsp; &nbsp;那位婦女下車的時候 &nbsp; 低聲地向那位男 士 說:
&nbsp; &nbsp; &nbsp;謝謝你 &nbsp; 先生

這裏頭的心思 &nbsp;是如此纖細
在一念之間 &nbsp; 竟使那位婦女充滿了感激

在家裏 孩子噙著眼淚回家
&nbsp; &nbsp; &nbsp;說老師討厭他 &nbsp;同學不喜歡他
&nbsp; &nbsp; &nbsp;做母親的立刻把孩子抱到懷裏
&nbsp; &nbsp; &nbsp;輕聲地說:

你永遠是我最好的

&nbsp; &nbsp; &nbsp;我們不知道要如何感激這個母親
&nbsp; &nbsp; &nbsp;她的心思是如許的可人 善良

&nbsp; &nbsp; &nbsp;有一位充滿挫折的中學生
&nbsp; &nbsp; &nbsp;絕望的把失敗的學業說給父親聽
&nbsp; &nbsp; &nbsp;這位父親站了起來執起兒子的手說 :
&nbsp; &nbsp; &nbsp;孩子 &nbsp; 我永遠相信你的能力

&nbsp; &nbsp; &nbsp;這時候做兒子的總忍不住地想:
&nbsp; &nbsp; &nbsp;爸爸 &nbsp; 你為什麼不罵我 &nbsp; 打我
&nbsp; &nbsp; &nbsp;卻讓我心裏感激的想掉淚

&nbsp; &nbsp; &nbsp;事實上 &nbsp; 父親若是真的打了 &nbsp; 罵了
&nbsp; &nbsp; &nbsp;兒子不但倔強的 一滴眼淚也掉不下來
&nbsp; &nbsp; &nbsp;心中更是充滿敵意與痛恨
&nbsp;&nbsp;
&nbsp; &nbsp; &nbsp;不知道從什麼時候開始
&nbsp; &nbsp; &nbsp;我們忘掉了受傷的心需要修補
&nbsp; &nbsp; &nbsp;卻用針去刺它
&nbsp; &nbsp; &nbsp;我們用了太多的道理去安慰一顆
&nbsp; &nbsp; &nbsp;只需要善意的心
&nbsp; &nbsp; &nbsp;我們學會了太多的字眼卻使
&nbsp; &nbsp; &nbsp;我們對內心的那點情失去了蹤影

&nbsp; &nbsp; &nbsp;後來我們終於明白
&nbsp; &nbsp; &nbsp;當我們一點一滴地長大時
&nbsp; &nbsp; &nbsp;內心的那點善意卻不小心地失落了
&nbsp; &nbsp; &nbsp;失落在考試之後的名次裏
&nbsp; &nbsp; &nbsp;失落在意見不同的爭執裏
&nbsp; &nbsp; &nbsp;更失落在內心的不滿意裏

&nbsp; &nbsp; &nbsp;也許 &nbsp; 我們在諸種事物裏
&nbsp; &nbsp; &nbsp;那股被鐘愛的感覺逐漸退色 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;

&nbsp; &nbsp; &nbsp;鐘愛人的心
&nbsp; &nbsp; &nbsp;卻老是長不大內心有點 " 侏儒症 " 的痛
&nbsp; &nbsp; &nbsp;直到有個人在你困苦的時候
&nbsp; &nbsp; &nbsp;輕輕地給你一句話
&nbsp; &nbsp; &nbsp;就為了那句話 &nbsp;你三更半夜也會爬
&nbsp; &nbsp; &nbsp;起來唸書
&nbsp; &nbsp; 也為了那句話 &nbsp;你越過山嶺 &nbsp; 涉過深水
&nbsp; &nbsp; 去走更遠的路
&nbsp; &nbsp; 也為了那句話 &nbsp;你的怨聲突然啞了
&nbsp; &nbsp; 惡相忽然美麗起來了 心也突然善良起來了

&nbsp; &nbsp; 就在這麼一刻
&nbsp; &nbsp; 我們好像從批評的煉獄逃了出來
&nbsp; &nbsp; 心裏頭變得婉約可人
&nbsp; &nbsp; 內心的激情 淹沒了多少年來的委屈
&nbsp; &nbsp; 多少的不快樂頓成過眼雲煙
