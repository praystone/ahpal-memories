&nbsp;



有一種愛，叫做喜悅。 


喜悅，是因為相愛在一起的簡單的幸福。 　　


&nbsp;


有一種愛，叫做甜蜜。 


甜蜜，是因為愛是醞釀甜蜜的花朵。 　　


&nbsp;


有一種愛，叫做微笑。 


微笑，是因為愛像成熟了的掛上枝頭的開心果。 　　


&nbsp;


有一種愛，叫做坦白。 


坦白，是因為愛的存在， 


每個人的心裡都能夠明白。


&nbsp;　　


有一種愛，叫做依賴。


&nbsp;依賴，是因為可以依偎的心， 


不再害怕孤單的傷害。 　　


&nbsp;


有一種愛，叫做思念。 


思念，是因為離別即使短暫， 


也會讓愛在心裡無盡的蔓延。 　　


&nbsp;


有一種愛，叫做無奈。 


無奈，是因為已經為愛承受得太多， 


只能用無奈來稍微釋懷。 


&nbsp;


有一種愛，叫做放棄。 


放棄，只因為這一句 


“我會學著放棄你，是因為我太愛你”。 　　


&nbsp;


有一種愛，叫做傷心。 


傷心，是因為我再也找不到那些愛過的曾經。 　　


&nbsp;


有一種愛，叫做寂寞。 


寂寞，是因為一個人為愛走的路。 　　


&nbsp;


有一種愛，叫做淒苦。 


淒苦，是因為愛的路上， 


總會遇到猛烈的暴風雨。 　　


&nbsp;


有一種愛，叫做迷糊。 


迷糊，是因為看不清楚愛該走的路。 　　


&nbsp;


有一種愛，叫做辛苦。 


辛苦，是因為喜歡愛的一起吃苦的幸福。 　　


&nbsp;


有一種愛，叫做曲折。 


曲折，是因為愛總要轉幾個彎才到來。 　　


&nbsp;


有一種愛，叫做後悔。 


後悔是因為等愛走了以後， 


才明白，原來自己真的愛過。 　　


&nbsp;


有一種愛，叫做感動。 


感動，是因為愛會在寒冷的冬天， 


脫下棉衣，送你一度的溫暖。 　　


&nbsp;


有一種愛，叫做心碎。 


心碎，是因為愛，被凍結在寒冷的季節。 　　


&nbsp;


有一種愛，叫做刻骨。 


刻骨，是因為愛的痕跡， 


像鎖向靈魂的永不腐朽的枷鎖。
