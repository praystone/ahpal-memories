每天吃麵包的人，容易得癌症 ==&gt; 請特別注意 !!!

看來還是要自己下廚最健康…雖然沒有外面的東西好吃,但總比吃壞身體好!!

太白粉是細食，腎臟瞬間大負擔 &nbsp;
&nbsp;
用太白粉勾芡的食物 -- 經水分解，會變成最小的葡萄糖，被身体迅速而完全的吸收，造成100%醣。

四十歲以上者，身体會受不了。
&nbsp;

廚師考照是不隨便勾芡的。
&nbsp;
小心 ! 燒仙草等黏稠點心，或菜名中有「羹、膾、滑、溜」的都用太白粉勾芡，對健康危害較大。
&nbsp;
謹記：
&nbsp;
麵粉是粗食，不容易消化，血醣慢慢的上升，腎臟沒有負擔。

太白粉是細食，容易消化，血醣迅速的上升，腎臟瞬間大負擔。
&nbsp;
&nbsp;
吃食物、不要吃食品 『未加工的叫食物，加工的叫食品。』
&nbsp;
現在的廚師做菜好吃，但是不道德。
&nbsp;
在外面吃多了，中年以後，會很痛苦。

以下的資訊，告訴你為什麼中年以後，會很痛苦。

你若讀過，一定會對你的飲食習慣，造成永久的影響。

&nbsp;
第一條守則：應多吃符合大自然守則的食物。
&nbsp;
人應符合大自然的規定，吃：蛋白質：12%，脂肪：25%，醣：63%。
&nbsp;
經常吃40%以上的蛋白質，則得癌症。
&nbsp;
例如：排骨便當 ─ 有40%蛋白質，對腎臟負擔太重了。
&nbsp;
麵筋、烤芙 ─ 麵粉團一直沖水，沖掉了所有的醣，產生100%的蛋白質，也就是麵筋、烤芙。
&nbsp;
每天吃這些，對腎臟負擔太重，很快就落葉歸根了。
&nbsp;
五星級飯店的菜 ─ 有90%以上的蛋白質與脂肪，很缺德。
&nbsp;
許多五星級飯店的年菜，60% 的蛋白質，30% 的脂肪，不利健康。
&nbsp;
現在，中年以後得癌症、糖尿等文明病的人，多得不得了，都是因為吃錯了食物。
&nbsp;
骨骼疏鬆：原來都以為是缺乏鈣。
&nbsp;
最近研究發現，是因為蛋白質吃太多，血液變成酸性，所以骨骼的鈣，怎樣也留不住，被抓走了。
&nbsp;
怎麼治療？病因不是缺乏鈣。
&nbsp;
要降低蛋白質，使血液漸趨鹼性，才能根治。
&nbsp;
糖尿病：少吃糖不會好。病因是胰島素沒有發揮作用，所以醣類沒有辦法代謝。

為什麼呢？因為高蛋白質吃太多，把身体胰島素作用壓抑成無能。

怎麼治療？要降低蛋白質，回復胰島素本來的作用。
&nbsp;
注意：不是吃低蛋白質的食物，是要吃正常蛋白質，只是降低量的攝取。
&nbsp;
並且，要減少慾望，特別是食慾。
&nbsp;
癌症腫瘤：因高濃度的蛋白質吃太多，例如營養補品、肉類、麵筋、種子類等。
&nbsp;
尤其的營養補品是最小分子食品，代謝困難；或者吃太多加工食品，毒素無法代謝。

怎麼辦？若有癌，要降低蛋白質至8%以下。
&nbsp;
&nbsp;
第二條守則：吃食物，不要吃「食品」。
&nbsp;
未加工的叫食物，加工的叫食品。
&nbsp;
若「食品」吃得堆積如山，則一定得癌症。
&nbsp;
因為身體代謝辛苦。
&nbsp;
食品：麵包(添加人工甜味、乳化劑、發漲劑、等等) 會生病。
&nbsp;
食物：饅頭 (不添加) 會健康。
&nbsp;
所以每天吃麵包的人，容易得癌症。
&nbsp;
脫脂奶粉 ─ 是缺德的食品，常吃會得結石。
&nbsp;
因為脫脂奶粉一定添加高鈣D(脂溶性)或高鐵，而脂肪已經被去除，人体就無法吸收、代謝鈣。
&nbsp;
因此這個添加的鈣，容易傷腎，成為結石。所以要吃低脂奶粉，有一點脂肪的。

脫脂與低脂奶粉，都會添加合成香料。因為奶粉中已去除脂肪，不加點合成香料，如何能好吃?
&nbsp;
素食加工品 ─ 因為素食蛋白質的黏性不好，所以會加添(劣等)動物蛋白質。
&nbsp;
另外，一切的造形素(素火腿、素雞鴨、素龍蝦等)，不但是高蛋白質，更添加了人工色素、人工染色，合成香料、

合成調味，以及葷食材料。
&nbsp;
因為人工的色素，幾乎永不退色，而自然色素會退色。
&nbsp;
若常常吃素食餐廳的合成造形素，則危害身体，容易致病、早死。
&nbsp;
米蛋白質食品是高蛋白質食品，又是加工化學物，危害身体，少吃為妙。
&nbsp;
&nbsp;
第三條守則： 不要太講究口味。
&nbsp;
外面的好吃料理，九成以上都是很缺德的。
&nbsp;
首先，了解味道如何來的，才能不被味道，牽著鼻子走。
&nbsp;
1、蛋白質：胺基酸(提供鮮味)。

2、脂肪：脂肪酸(提供香/濃味)。

3、醣：簡單糖(提供甜味)。
&nbsp;
這三種味道來源，如果粒子体積越小，與舌頭接觸交涉面就越廣，味道就越叫人喜好。
&nbsp;
而可怕的是，粒子越小，身体也就越難以代謝，所以基本上，食物變好吃，都是害人的。
&nbsp;
(廣告說：親愛的，我把雞精變好吃了..)
&nbsp;
蛋白質：胺基酸(鮮味) 它們是什麼?
&nbsp;
它們都是不必要胺基酸，好吃的廢棄物胺基酸，有必要與不必要兩種：
&nbsp;
身体所需要的，叫作必要胺基酸。
&nbsp;
它的粒子大，不好吃，而且很貴，但因為人體自己無法合成，所以必須攝取。
&nbsp;
不必要胺基酸 (毒)，危害人體，卻好吃得不得了，又便宜，可提煉出鮮度，可以說俗又大碗。所以常常被用來做

成加添味道的「鮮味劑」。
&nbsp;
&nbsp;
常見的「鮮味劑」：
&nbsp;
其中蠔油不含蠔、雞粉沒有雞、魚露也沒有魚。
&nbsp;
它們不會壞，也不發霉，因為連細菌也不敢吃。
&nbsp;
它們是什麼? 它們都是不必要胺基酸，好吃的廢棄物，對身体毒，很不容易代謝，所以食用以後，吸水性強，身体

中毒，會非常口渴。
&nbsp;
在外面吃東西，愈是鮮香甜的口感，愈產生口渴，愈造成身体不適。
&nbsp;
所以，吃東西時，可以先叫一碗飯吃下去，等血糖等一切上昇，飢餓感減低時，再吃其他東西，以免吃過量傷害

身體，造成負擔。
&nbsp;
在台灣，九成的餐廳，是不熬湯，只用雞粉、鮮味劑的。
&nbsp;
必要的胺基酸對身体好。雖然粒子大，貴又不好吃。
&nbsp;
身体必須先消化再吸收。
&nbsp;
不必要的胺基酸便宜又好吃。
&nbsp;
粒子小，身体會先吸收，再想辦法消化，代謝非常困難對身体差。
&nbsp;
便宜普及性高集一切好處於一身，只是會吃死人。
&nbsp;
&nbsp;
可怕的食品實例：
&nbsp;
健康食品：所謂的健康食品，都是最小分子量的食品，粒子小而難以代謝，對人体很危險。
&nbsp;
自已要多看書，去了解營養的吸收，應該從多種的來源，非單一品。
&nbsp;
&nbsp;
QQ的飯：好吃的飯的便當，便利商店QQ 的飯團。
&nbsp;
又Q又軟又一粒粒晶瑩剔透的，好像日本皇家吃的好米，而且放久也不會酸。
&nbsp;
那是為什麼? 因為添加了一種叫炊飯劑的東西。
&nbsp;
炊飯劑的成份是酵素，離胺酸，胺基乙酸NH 2C H2、矽力焢silicon，屬於樹脂類的防腐消毒劑。
&nbsp;
它又是最小分子的胺基酸與酵素，要命的好吃口感，但吸水量大，所以沒有細菌，使便當的飯不容易壞，又Q又好

吃又透明，外面廣為使用，只是對身体完全的負面，非常不好。
&nbsp; 
好吃的湯頭：胺基乙酸，用買的還要錢。有一種久遠就有的味素，可以用醋和人尿合成，發酵一個星期即成。
&nbsp;
醋(=乙酸)，加上尿(=阿摩尼亞，也是最劣質的胺基酸。別忘了：蛋白質a胺基酸a阿摩尼亞a排泄)。
&nbsp;
這種胺基乙酸(古早味味素)，若加在湯頭中，就變成了你所吃過最順口的自然美味，很難形容，很好吃，不像加了

化學味精。
&nbsp;
只是這種胺基乙酸缺德，而且對人体非常不好，很傷腎。

所以常吃這類的東西以後，有時還可能會忽然不明的腰酸。

&nbsp;
雞湯塊等：基本的雞湯塊，如果連吃上六年，則可能洗腎。
&nbsp;
而九成以上的餐廳，都是缺德的使用同類的大量高纖味精，這種味精比傳統的更鮮美。
