&nbsp;

 
阿伯你攏用蝦米餵豬？

&nbsp;



&nbsp;

&nbsp;


一個偏僻ㄉ鄉村有個養豬農，

&nbsp;

一天，有一個年輕人跑來問他說：

&nbsp;

ㄚ伯，你隆用瞎密起低？ ( 起低 = 餵豬 )

&nbsp;

阿伯：哇攏用ㄆㄨㄣ ㄚ(ㄆㄨㄣ = 餿食 )

&nbsp;

年輕人一聽就拿出它ㄉ證件說：

&nbsp;

我是愛護動物協會ㄉ人，我懷疑你虐待動物

&nbsp;

說完就開了一張十萬元ㄉ罰單給ㄚ伯，

&nbsp;


&nbsp;

隔天 ~ 又一個年輕人跑來問他說：

&nbsp;

ㄚ伯，請問尼都用瞎密起低ㄚ？

&nbsp;

ㄚ伯心想：哇 ! 靠北 ! 再來一次啊！

&nbsp;

於是記取昨日ㄉ教訓說：

&nbsp;

ㄟ，偶都用鮑魚、燕窩、魚翅和麥當勞、肯德基餵牠們ㄚ

&nbsp;

年輕人一聽就拿出他ㄉ證件說：

&nbsp;

我是饑餓三十協會ㄉ人，我懷疑你浪費食物

&nbsp;

說完又開了一張十萬元ㄉ罰單給ㄚ伯

&nbsp;

ㄚ伯已經快吐血ㄌ


&nbsp;

第三天，又一個年輕人跑來問ㄚ伯說：

&nbsp;

阿伯，你都用瞎密起低ㄚ？

&nbsp;

ㄚ伯心想：你X勒，擱來ㄚ，兩次還不夠喔？

&nbsp;

於是就很肚爛ㄉ大聲說：
&nbsp;


X&nbsp; ! 每天中午我就給牠們兩百塊，

&nbsp;

要吃瞎密牠們自己企買啦 ! 

&nbsp;
