&nbsp;

想你，是不經意的一瞬間，

&nbsp;

讓淡淡憂傷跨過矜持惆悵的邊緣，

&nbsp;

透過每個罅隙的空間，

&nbsp;

在心頭暗暗滋長蔓延。

&nbsp;

如同一張無形的網把心攏緊，

&nbsp;

而網裡的我無遁路可逃，

&nbsp;

任憑自己黯然的把你默讀成記憶符號。

&nbsp;

只是在想你的時候，

&nbsp;

思念寫就的符號在銘刻，

&nbsp;

在搖擺與這個時端，

&nbsp;

散亂的心一點點被你無形的勒緊。

&nbsp;

而我尋不到有你的代號。



&nbsp;

想你，把記憶輕啟後，

&nbsp;

才明白我不曾把思念擱淺，

&nbsp;

目光延伸遠方，飄渺如同虛無，

&nbsp;

把你幻化成寂寞的影子，

&nbsp;

寂寥而冗長，

&nbsp;

而在影子裡，

&nbsp;

我孤單的依舊把自己迷失，

&nbsp;

沒了方向，

&nbsp;

看寂寞的風吹亂了曠野裡的絕望，

&nbsp;

而心卻讓你的影子漲滿，

&nbsp;

載不動思念悠悠，

&nbsp;

而我找不到有你的彼岸。



想你，眉心緊緊一皺，

&nbsp;

才知道我用思念剪斷了這個時光，

&nbsp;

陷入了一種屹立的悲涼，

&nbsp;

看記憶把時間穿亂，

&nbsp;

留我獨自徬徨，

&nbsp;

不知道起點、終點，

&nbsp;

只是在每個思念的站點，

&nbsp;

總是對往事回首，

&nbsp;

看我悸動的心淒然一笑，

&nbsp;

讓自己守望在有你的每一個路口，

&nbsp;

把想你想成了一種傷，

&nbsp;

一種灼人的傷，

&nbsp;

而我依舊無悔的期盼，

&nbsp;

隨手翻看的記憶裡找不到來時的路，

&nbsp;

看自己無望的沉淪在想你的極端。



&nbsp;

想你，看手指在鍵盤上孤單的跳躍，

&nbsp;

敲打我翻飛的思念，

&nbsp;

讓牽掛在心頭湧動，

&nbsp;

化為迭次起伏而寂寥的音符

&nbsp;

在空氣中飄蕩。

&nbsp;

習慣了屏幕那邊你熟悉的笑，

&nbsp;

將永遠定格我的心間。

&nbsp;

只是突然依賴的隔屏，

&nbsp;

消失了你的身影，

&nbsp;

讓我的思念在空中流轉，

&nbsp;

無奈只好讓無言的文字傾訴我的想念，

&nbsp;

只是你看不到一米之外的距離，

&nbsp;

有纏繞的思念在指尖停留，

&nbsp;

而我無所適從這沒有你的習慣。



&nbsp;

想你的時候，

&nbsp;

總是勾起了過去的點滴，

&nbsp;

因為有你存在我的記憶，

&nbsp;

才能給想你寫一個幸福的概念。

&nbsp;

可只因你只存在我的回憶裡，

&nbsp;

才讓我有了無端的牽絆。

&nbsp;

只因不知朝朝暮暮的想念，

&nbsp;

何時可了斷，徒曾無奈！

&nbsp;

又怕想你，成為了習慣後，

&nbsp;

把自己濃縮與這份情感，

&nbsp;

驟添傷悲！

&nbsp;

只好把思念存與心底，

&nbsp;

只是依然無法給自己一個釋懷的答案。

&nbsp;

我才明白：

&nbsp;

想你，我無能為力...

&nbsp;
