當你犯罪那刻起 你已自動放棄人權

何謂慈悲...

&nbsp;

神的世界裡..也有地獄....

&nbsp;

&nbsp;

刑完還被打進畜牲道..在讓大家殺來吃這也是我佛慈悲嗎??


&nbsp;

&nbsp;

有句話...神也發火....當惡鬼惡慣滿盈時..一樣會把它煉化不是嗎??

&nbsp;

&nbsp;

而那些死刑犯&nbsp; 哪個不是關了又犯&nbsp; 犯了又關又不是沒給改過的機會


&nbsp;

&nbsp;

不然就是弒親 弒友的...這種人能給機會嗎??

放1人&nbsp; 弒10人....這樣對善良老百姓又有慈悲心嗎???


&nbsp;

&nbsp;

放也不是 終身監禁更是對彼此的折磨 那就不如早死早超生 那才是人權...

&nbsp;

&nbsp;

法律是管理社會秩序的規範....當它失去公信力和約束力時....


&nbsp;

&nbsp;

社會會陷入無政府的狀態..到那時...大家就會知道什麼叫人權....

&nbsp;

就會懂得人權真正的意義 那就是...

&nbsp;

人權是用來幫善良百姓爭取權利的...

&nbsp;

人權是用來保護善良百姓的...

&nbsp;

&nbsp;

&nbsp;

或許還有人不懂

&nbsp;

我舉例來說好了

&nbsp;

當一個人生病或得癌症時&nbsp; 是不是要打針吃藥做化療

&nbsp;

但....那為什麼要打針吃藥.....


因為身體裡有危害自身生命的細菌存在,所以要打針吃藥才能殺菌...


你總不會說..細菌也有生命..我很有愛心不忍滅殺牠..就讓牠一直存在你體內吧!!!


甚至讓牠散播給別人 讓其它人一樣跟著生病吧!!


所以說...細菌=犯人&nbsp;&nbsp;打針吃藥=法律&nbsp; &nbsp;身體=守法的百姓

&nbsp;

有句話不是說&nbsp; 預防勝於治療

&nbsp;

死刑的存在就是預防

&nbsp;

再不懂的話那就.....
