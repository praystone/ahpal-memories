追逐著曾經留下的痕跡　意圖從中找尋那拋棄的故事

&nbsp;

一點一滴

&nbsp;

一絲一毫的拾起

&nbsp;

短暫的永遠　在那麼的一瞬間

&nbsp;

是期盼

&nbsp;

更是奢望

&nbsp;

期盼著這短暫的永恆

&nbsp;

奢望著這一瞬間的靜止

&nbsp;

彷彿這樣的一切　能試圖著給自己一些安慰的藉口

&nbsp;

飄零不斷的風兒　飄落不止的楓葉

&nbsp;

秋

&nbsp;

已經來訪了

&nbsp;

問候的不再是親切

&nbsp;

流水

&nbsp;

潺潺般的清澈

&nbsp;

誰人在

&nbsp;

再那麼一次的記得

&nbsp;

拾起的故事

&nbsp;

卻拾不起難忘的

&nbsp;

鏡花歲月
