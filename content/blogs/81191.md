話說某一年

&nbsp;

那時候的舞蝶才剛出生沒多久　而舞蝶的祖父　在某一次要為祖母

&nbsp;

抓藥的時候　出了一場客運車禍　而祖父也就這樣往生了　而舞蝶

&nbsp;

的故鄉有一個習俗　就是祖先往生的時候　要放在家中靈堂　而晚

&nbsp;

輩要從約五十公尺的地方　開始爬行進去　並且還要一邊哭一邊爬

&nbsp;

好笑的來了　舞蝶的父親那一輩份的先爬　然後才會孫子輩的爬

&nbsp;

蝶父:嗚嗚嗚　哇北喔　北喔　嗚嗚　嗚嗚嗚嗚　哇北喔　　(請以臺語發音.北=父親)

&nbsp;

這是蝶父當時的哭法　接下來請看蝶兄他們的哭法跟笑話

&nbsp;

蝶兄甲:嗚嗚嗚　哇北喔　北喔　嗚嗚　嗚嗚嗚嗚　哇北喔

&nbsp;

蝶兄乙:嗚嗚嗚　哇北喔　北喔　嗚嗚　嗚嗚嗚嗚　哇北喔

&nbsp;

蝶父:....................................

&nbsp;

蝶父:靠妖喔　林北低家啦　靠殺小　林北阿賣死耶啦　哭火大喔

&nbsp;

笑話二

話說有一天

&nbsp;

蝶兄甲跟蝶兄乙在討論床第的事　然後蝶兄甲先開口說

&nbsp;

蝶兄甲:唉　我那口子每次行房的時候　都很像死魚　不

&nbsp;

會叫就算了　連哼一聲都不會　

&nbsp;

蝶兄乙:大仔　你比我好太多了　我家那個是沒救了　

&nbsp;

蝶兄甲:安抓共　

&nbsp;

蝶兄乙:你是知道的阿　我辦事的時候　最愛問大不大

&nbsp;

粗不粗　深不深　爽不爽　叫　給我叫　叫老公

&nbsp;

蝶兄甲:我有聽你說過你有這習慣　阿然後咧

&nbsp;

蝶兄乙:那天我跟她辦事的時候　一如往常的問她那些

&nbsp;

她回了我一句話

&nbsp;

蝶兄甲:什麼話

&nbsp;

蝶兄乙:她說　靠北喔　緊幹啦

&nbsp;

蝶兄乙:聽完我馬上軟

&nbsp;

這就是舞蝶家中傻事之一
