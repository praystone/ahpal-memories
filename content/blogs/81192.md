如水一般的蝶心　如夢一般的妾心　蝶心中有著妾心

&nbsp;

帶著遙不可及的距離　妾心難忍憂傷的情懷　

&nbsp;

似是而非的海市蜃樓　是否隱藏著無法說出口的感受

&nbsp;

那樣的情景　如幻滅一樣的消失　

&nbsp;

似非而是的曾經滄海　淹沒了過往舊有的離愁

&nbsp;

這樣的滄海　不知是幾許人所留下的淚水

&nbsp;

告別了今日　蝶心塵封了堅強

&nbsp;

收起了蝶羽　歇息著不堪失落的身軀

&nbsp;

飛不近的終點　飛不進的世界

&nbsp;

妾心世界的封閉　

&nbsp;

蝶心般的不放棄　

&nbsp;

堅固的內心黑暗空間　總是帶著蝶羽的一絲閃亮

&nbsp;

如此的閃亮　卻試著撞擊這樣的堅固

&nbsp;

蝶嘗試了　

&nbsp;

妾明瞭了　但不願回應

&nbsp;

剩餘的生命將如風中殘燭一般

&nbsp;

再次的揮舞著翅膀　再次嘗試著

&nbsp;

捂住了雙耳　本以為這樣就能聽而不聞

&nbsp;

但　心依然可以聽的見

&nbsp;

停了

&nbsp;

所有的一切停了　

&nbsp;

靜止了　所有的感受都靜止了

&nbsp;

疑惑著　為何如此的安靜

&nbsp;

是蝶的放棄　或是這只不過是南柯一夢

&nbsp;

猶豫的神情　促使著妾的好奇

&nbsp;

門開了　見著了

&nbsp;

但只剩下破碎的蝶羽　只剩下揮盡生命的蝶心

&nbsp;

遙不可及的距離　原來是一扇門　

&nbsp;

不願捨棄的心情　原來是一縷煙

&nbsp;

失去了生命的蝶　換來一扇門的開啟

&nbsp;

更換來了最後擁抱的淚水

&nbsp;

後悔的妾心　試著以淚水喚醒蝶心

&nbsp;

晚了　始終晚了　

&nbsp;

滄海的形成是淚水　封閉的代價是後悔

&nbsp;

再也見不著蝶羽的閃亮

&nbsp;

再也無法見著

&nbsp;

無助的妾　失去了心

&nbsp;

癡癲了　帶著滿滿的悔意舞著

&nbsp;

舞著癡癲笑著癡
