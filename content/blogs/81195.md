晴空的天氣　

&nbsp;

卻有著皺眉的煩惱

&nbsp;

翡冷翠的雪　覆蓋了晴空的天氣

&nbsp;

雪翡翠的冷　下起了白茫的銀河

&nbsp;

雪兒飄落著　

&nbsp;

飄出了東方　飄進了西方

&nbsp;

晴空與雪兒的交涉

&nbsp;

雪兒不願退步

&nbsp;

像孩子般任性吵著

&nbsp;

晴空萬般無奈安撫著雪兒

&nbsp;

但可愛的雪兒　卻一直要求晴空的退讓

&nbsp;

搖頭聳肩代表說不過的無可奈何

&nbsp;

晴空任由雪花飄了

&nbsp;

雪兒如蝴蝶一樣開始飄舞著

&nbsp;

看著雪兒的歡笑　晴空雖是無奈　但又淡然一笑

&nbsp;

飄到日落　晴空要雪兒跟著回家

&nbsp;

雪兒聽不著　也裝聽不見

&nbsp;

沒法的晴空　只好告知要雪兒別玩過頭

&nbsp;

飄阿飄著　舞阿舞著

&nbsp;

飄到一戶人家　看著家家戶戶的團聚

&nbsp;

雪兒開始感到寂寞

&nbsp;

慢慢的哭起聲來

&nbsp;

像似一個迷路的小孩一樣

&nbsp;

任性的雪是天真

&nbsp;

寂寞的雪是害怕

&nbsp;

月娘兒見著了　輕輕的抱起雪兒

&nbsp;

問了一問　笑了一笑

&nbsp;

月娘兒要雪兒別怕

&nbsp;

雖然夜深了　但月娘兒還在

&nbsp;

月娘兒慢慢的收起美麗的圓臉

&nbsp;

再慢慢的形成搖籃

&nbsp;

輕輕的放進雪兒

&nbsp;

搖阿搖　雪兒飄　月娘搖

&nbsp;

慢慢的雪兒睡著了

&nbsp;

這樣的夜有著月　這樣的月有著雪
