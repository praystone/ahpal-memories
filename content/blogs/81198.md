似夢的情懷　彷彿是昨夜的幻境

&nbsp;

人去樓空的痕跡　只留下短暫的溫柔

&nbsp;

過腰的長髮　是我曾經留下的證據

&nbsp;

試圖證明我還曾經在乎過

&nbsp;

選擇剪短了頭髮　別問我是否確定

&nbsp;

女性自我的坦白

&nbsp;

所表現出來的　並不是堅強的外在

&nbsp;

港都的天空　愛河的步道

&nbsp;

這是我一個人的世界

&nbsp;

介意的過去　細髮的執著

&nbsp;

這卻是兩人世界的結果

&nbsp;

難過與開心

&nbsp;

活在當下的我　選擇了開心

&nbsp;

而這樣的開心　並不是因為頭髮的離去而偽裝

&nbsp;

坦白的天空　有著驕傲的自我

&nbsp;

荒涼最初的等待　是自我放逐的理想

&nbsp;

破曉的歲月

&nbsp;

時間的黎明

&nbsp;

再一次過肩的頭髮

&nbsp;

不再為誰而留

&nbsp;

這樣的心情　只為我自己而留

&nbsp;

逍遙般的風　吹起了我的長髮

&nbsp;

也吹起了我久違的開心
