請以臺語發音讀這文章　因為舞蝶無緣無故　一邊唸著臺語一邊打出的

&nbsp;

&nbsp;

　　　　　　　　　　　　戰　是無止盡的戰火

&nbsp;

　　　　　　　　　　　　敗　是弱者的停息

&nbsp;

　　　　　　　　　　　　亡　是遍地屍首的象徵

&nbsp;

　　　　　　　　　　　　狂　是咆哮天地的不滿

&nbsp;

　　　　　　　　　　　　怒　是心急攻擊的開端

&nbsp;

　　　　　　　　　　　　笑　是王者走向的不歸路

&nbsp;

　　　　　　　　　　　　極端的開始　漠然的冷笑

&nbsp;

　　　　　　　　　　　　手握生命的刀　一步一步揮向人群

&nbsp;

　　　　　　　　　　　　逃避不及的頭顱　宛如散花飄一樣

&nbsp;

　　　　　　　　　　　　是怎樣的王者踏著屍骸而行

&nbsp;

　　　　　　　　　　　　是怎樣的皇者創立一世的霸業

&nbsp;

　　　　　　　　　　　　慘叫漫天的哀鳴　是王者之路

&nbsp;

　　　　　　　　　　　　紅色血骨的天地　是皇者根基

&nbsp;

　　　　　　　　　　　　漫延著信念與理念

&nbsp;

　　　　　　　　　　　　何謂王者　皇者又是為何

&nbsp;

　　　　　　　　　　　　讚嘆的一聲　生是悲傷　死更是悲傷

&nbsp;

　　　　　　　　　　　　分不清王者與皇者之間

&nbsp;

　　　　　　　　　　　　殘酷是表象　

&nbsp;

　　　　　　　　　　　　世人的看待　有何重要

&nbsp;

　　　　　　　　　　　　唯有仁慈是不可犯之錯誤

&nbsp;

　　　　　　　　　　　　狂傲的笑聲　囂張的面貌　是不敗的宣言

&nbsp;

　　　　　　　　　　　　單膝跪地　是臣服亦或是反叛的假象

&nbsp;

　　　　　　　　　　　　誰人敗吾　誰能擋吾

&nbsp;

　　　　　　　　　　　　能敗吾者以不存在

&nbsp;

　　　　　　　　　　　　能擋吾者以不殘留

&nbsp;

　　　　　　　　　　　　如此說著的是無情　更是真實

&nbsp;

　　　　　　　　　　　　梟雄的掘起　王者的路程　皇者之傲視

&nbsp;

　　　　　　　　　　　　創造的不是龍圖　而是好戰嗜血的結局
