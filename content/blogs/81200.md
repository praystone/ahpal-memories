等待　是漫長無際的煎熬

&nbsp;

期待　是內心深處的奢望

&nbsp;

分不清的理和亂　

&nbsp;

像似說著所以這般

&nbsp;

平靜的心情　

&nbsp;

總是能因為這麼的一點點漣漪　

&nbsp;

而有所起伏

&nbsp;

收起了名為寂寞的相簿　

&nbsp;

但卻收不起孤單的深夜

&nbsp;

深夜　總是如此的困擾著人

&nbsp;

被掏空的位置　

&nbsp;

心

&nbsp;

已經不存在

&nbsp;

懷念著香水的氣味

&nbsp;

這樣的氣味總是如此的寧靜

&nbsp;

這樣的寧靜卻也是如此的淡然

&nbsp;

掌心

&nbsp;

將誰的心放在手中

&nbsp;

將誰的心輕輕的握著

&nbsp;

細雨的飄起　不是歸宿

&nbsp;

哭起的旋律　只是依賴

&nbsp;

依賴的情境　是幻想

&nbsp;

幻想著這樣的故事　只是個笑話

&nbsp;

但

&nbsp;

如此的笑話　

&nbsp;

卻怎麼也笑不出一點聲音來

&nbsp;

疲倦了

&nbsp;

一點一滴的落下

&nbsp;

落下的卻不是誰的眼淚

&nbsp;

而是一片一片的心碎
