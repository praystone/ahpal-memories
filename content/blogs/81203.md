交錯的意亂情迷　感受到的是妳的呼吸

&nbsp;

冷戰　是彼此之間的沉默語言

&nbsp;

這樣的空間裡　彷彿沒人願意先開口

&nbsp;

寂靜　時間像似被凍結一樣

&nbsp;

天秤的兩端　開始承受不了負荷

&nbsp;

世界開始崩潰　

&nbsp;

錯綜複雜的事由　

&nbsp;

只不過是換來安靜過後的爭吵

&nbsp;

選擇

&nbsp;

緩緩的站起身來　走到妳身後的是我

&nbsp;

選擇了不說話　選擇了從妳身後抱著妳

&nbsp;

妳　反抗

&nbsp;

妳　拒絕

&nbsp;

試圖扳開雙手的環抱　

&nbsp;

反應過度的情緒

&nbsp;

久了

&nbsp;

接受了　

&nbsp;

無語的空間

&nbsp;

卻能聽見彼此的心跳聲

&nbsp;

心

&nbsp;

在訴說著

&nbsp;

轉過身來的妳　

&nbsp;

看著的

&nbsp;

並不是容貌的樣子

&nbsp;

而是看著心的位置

&nbsp;

平息了　

&nbsp;

平息了無謂的堅持　

&nbsp;

親吻

&nbsp;

是妳我之間和平的誓言

&nbsp;

拉著我的手的是妳　牽著妳一生的是我

&nbsp;

拉不緊的是爭吵

&nbsp;

伴緊的卻是永恆

&nbsp;

體諒

&nbsp;

是對妳付出的感受

&nbsp;

原諒

&nbsp;

是妳對我釋懷的解釋

&nbsp;

相依

&nbsp;

緊緊擁靠的靈魂　是一份相依

&nbsp;

如果有人問

&nbsp;

追求幸福的結果是什麼

&nbsp;

那麼這就是幸福的結果

&nbsp;

因為這樣的依偎就是幸福
