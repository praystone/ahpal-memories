請別裝作沒發生什麼事一樣　

&nbsp;

我

&nbsp;

並沒有你想像那般的堅強

&nbsp;

虧欠的問候

&nbsp;

在如今看來　卻是如此的虛偽

&nbsp;

曾經試著對你不理不采

&nbsp;

但

&nbsp;

心卻沒辦法如此的忘懷

&nbsp;

畢竟

&nbsp;

承受分手的事實　是如此的難過

&nbsp;

多少個夜

&nbsp;

是一個人的面對

&nbsp;

多少滴的淚水　是無助的眼淚

&nbsp;

自私

&nbsp;

是你唯一的藉口跟理由

&nbsp;

背叛

&nbsp;

是你選擇這段感情的出口

&nbsp;

假裝的自我　是為了想表現無所謂的心

&nbsp;

傷害的干涉 　是你一直牽涉我的自由

&nbsp;

不願提起的回憶　是我一直想隱藏的過去

&nbsp;

而你

&nbsp;

卻總是挖出這樣的難堪

&nbsp;

喜歡的理由　

&nbsp;

你總是可以說上千百種

&nbsp;

但

&nbsp;

分手的理由

&nbsp;

永遠卻只有一種

&nbsp;

孤寂的自我

&nbsp;

如果能忘記你

&nbsp;

我願意忘記你

&nbsp;

但

&nbsp;

在我心中的你

&nbsp;

卻是沒有如果可言
