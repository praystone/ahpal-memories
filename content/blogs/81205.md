這是第幾個寧靜的夜晚

&nbsp;

他

&nbsp;

依舊每天的前來

&nbsp;

每每見到他　總是一身的香水味　還有那一身的瀟灑

&nbsp;

而他的手中　彷彿永遠都可以見到那一碗粥

&nbsp;

卸下的

&nbsp;

是他的瀟灑

&nbsp;

捲起了袖子　慢慢打開了粥的蓋子

&nbsp;

用著溫柔的嘴唇　輕輕的吹涼湯匙的清粥

&nbsp;

餵向的　卻不是她的嘴唇

&nbsp;

餵向的　卻是彼此的過去

&nbsp;

她

&nbsp;

幾年前的一場車禍

&nbsp;

使她變成了植物人

&nbsp;

身上沒任何證件的她

&nbsp;

醫院也愁著發慌

&nbsp;

突如其來的他　卻出現在醫院

&nbsp;

並且辦妥她所有的一切住院手續

&nbsp;

自此以後

&nbsp;

他每天的這個時候　總是拎著一碗粥出現

&nbsp;

醫院

&nbsp;

總是傳聞著他的來歷

&nbsp;

但

&nbsp;

沒有任何一個人可以真正瞭解

&nbsp;

龐大的醫療費

&nbsp;

對著這樣的他而言　不可能如此的輕鬆

&nbsp;

夜晚

&nbsp;

是他工作的環境

&nbsp;

香水　是他的必須品

&nbsp;

瀟灑　是他的裝飾品

&nbsp;

這樣的他　需要的是一筆龐大的醫療費

&nbsp;

這樣的他　是午夜女尋歡客的男公關

&nbsp;

賣出了歡笑　也賣出了廉價的靈魂

&nbsp;

唯有這樣的一步路

&nbsp;

他才能有醫療費的下落

&nbsp;

但

&nbsp;

他不曾提起一句苦

&nbsp;

奇蹟

&nbsp;

些許年後的某一天

&nbsp;

她醒了

&nbsp;

但　

&nbsp;

她也忘了所有的一切

&nbsp;

包含了她自己是誰

&nbsp;

更包含了他是誰

&nbsp;

無所謂

&nbsp;

他認為　這樣的情況　永遠比昏迷來的好太多

&nbsp;

出院了

&nbsp;

接回家的她　一直拼了命的找尋記憶

&nbsp;

而他的心中　卻奢望永遠不會有找尋的那一天

&nbsp;

原來

&nbsp;

他們曾經是一對情侶

&nbsp;

她曾經狠下心的拋棄了這段感情

&nbsp;

遍尋不著的他　曾經一度落漠

&nbsp;

再一次的消息　

&nbsp;

是好

&nbsp;

但也是壞

&nbsp;

如今失憶的她

&nbsp;

總是追問著過去

&nbsp;

而他　也總是逃避了過去

&nbsp;

偶然

&nbsp;

命運是交錯的偶然

&nbsp;

在一次他倆外出的當中

&nbsp;

出了一場意外

&nbsp;

她　意外的回想起所有的過去

&nbsp;

他　意外的變成了植物人

&nbsp;

極端的交集

&nbsp;

是否是無語的蒼天

&nbsp;

他入院了　他失去了

&nbsp;

她猶豫著　她遲疑著

&nbsp;

結果

&nbsp;

她選擇了再一次的狠心

&nbsp;

拋棄的不單單是過去

&nbsp;

也拋棄了他的所有付出

&nbsp;

離開了

&nbsp;

她再一次的離開了

&nbsp;

曾經擁有知覺的他　還能找尋著她的蹤影

&nbsp;

如今失去知覺的他　卻只能帶著難過的淚水而度過

&nbsp;

這樣的一切　總是能隱隱約約感受到他淚水的落下

&nbsp;

病床上的天空　是平靜

&nbsp;

病床上的心情　卻是如此的哭泣
