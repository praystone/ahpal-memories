淡藍色的晴天　水舞般的紅蝶

&nbsp;

晴天的淡藍　總是一如往常高掛在天空

&nbsp;

紅蝶的追逐　響往的是淺憂鬱的藍色

&nbsp;

自得其樂的淡藍　

&nbsp;

總是悄悄的陪著紅蝶

&nbsp;

這樣的淡藍　是滿足的

&nbsp;

飛天花舞的紅蝶

&nbsp;

總喜歡舞出一段情感

&nbsp;

這樣的自我　是表白的

&nbsp;

日覆一日的是過程　年覆一年的是回憶

&nbsp;

度過了夏春秋　

&nbsp;

陪伴了雨似夢

&nbsp;

情懷

&nbsp;

總是在淡藍的心

&nbsp;

無時無刻的想起這樣的蝶

&nbsp;

淺淡的微笑　吹起了徐徐的的涼風

&nbsp;

這樣的風

&nbsp;

是愉快的

&nbsp;

蝶兒乘起了這樣的風　飄舞著這樣的愉悅

&nbsp;

彷彿

&nbsp;

在回報著這樣的微笑

&nbsp;

見不著一絲的憂鬱　是如此的淡藍

&nbsp;

但

&nbsp;

這樣的淡藍

&nbsp;

卻總是如此的深怕失去的一天

&nbsp;

紅蝶的飄舞　

&nbsp;

舞的並不是天有多長

&nbsp;

心的舞動

&nbsp;

舞的卻是彼此之間的距離

&nbsp;

如此淡藍色的天空

&nbsp;

只有一片

&nbsp;

紅蝶學著舞更高

&nbsp;

試著更接近著淡藍

&nbsp;

是勉強嗎

&nbsp;

淡藍開始拒絕

&nbsp;

兩份不同的顏色　卻有著互相關愛的心

&nbsp;

但

&nbsp;

深怕失去

&nbsp;

所以開始逃避

&nbsp;

隔日的天空　不是一份淡藍

&nbsp;

昔日的晴空　如今卻是陰霾

&nbsp;

下著絲絲的細雨

&nbsp;

是淡藍的哭泣　

&nbsp;

或是

&nbsp;

深怕的心在作祟

&nbsp;

淡藍的拒絕　紅蝶的失眠

&nbsp;

紅蝶再一次的飄舞

&nbsp;

舞的不是華麗

&nbsp;

而是一份疲憊

&nbsp;

如今的天空　是雨天

&nbsp;

點點滴滴的雨水

&nbsp;

點點滴滴的落在蝶身

&nbsp;

昔日飄舞的華麗

&nbsp;

在如今看來　卻是水舞的寄託

&nbsp;

冷了

&nbsp;

失去一切的紅蝶冷了

&nbsp;

雨

&nbsp;

依舊下個不停

&nbsp;

見不著的淡藍

&nbsp;

蝶

&nbsp;

停了

&nbsp;

無法再次的舞出水舞的寄託

&nbsp;

蝶

&nbsp;

終於停了

&nbsp;

數日來的雨

&nbsp;

也隨著這樣的一切而落幕

&nbsp;

淡藍

&nbsp;

出現了

&nbsp;

淡藍

&nbsp;

傷心了

&nbsp;

挽留

&nbsp;

試圖挽留蝶的生命

&nbsp;

蝶不許

&nbsp;

曙光般的淡藍

&nbsp;

最後之舞

&nbsp;

是蝶的最後遺願

&nbsp;

舞了

&nbsp;

再一次飄舞了

&nbsp;

舞出了一身的紅色

&nbsp;

將這一身的紅色獻給了淡藍

&nbsp;

彷彿說著

&nbsp;

紅色的蝶沒有離開淡藍

&nbsp;

消逝了

&nbsp;

最後之舞也隨之落幕

&nbsp;

淡藍的明瞭

&nbsp;

披起這樣的紅色

&nbsp;

天

&nbsp;

開始黃昏了

&nbsp;

淡藍色的晴空

&nbsp;

紅色的夕陽

&nbsp;

原來

&nbsp;

這就是黃昏的開始

&nbsp;

原來

&nbsp;

紅蝶一直留在淡藍的身旁

&nbsp;

原來

&nbsp;

淡藍與紅蝶一直相依偎著
