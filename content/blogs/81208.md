天南地北的差距　是內心卑微的開始

&nbsp;

高攀不上的門風　是感慨自身的命運

&nbsp;

這樣的世界　心　始終無法進入

&nbsp;

癡人說夢的幻想　是否是一份過份的愚蠢

&nbsp;

光與陰　存在的極端

&nbsp;

光的世界　是如此的明亮

&nbsp;

闇的國度　是這般的頹廢

&nbsp;

兩人的背影　是背對著背

&nbsp;

彷彿這邊的距離　中間有著一條分隔線

&nbsp;

嘲笑的　是誰的無能

&nbsp;

再一次的

&nbsp;

躲進屬於自己的黑暗

&nbsp;

不容許的

&nbsp;

是光明的侵入

&nbsp;

卑微　心總是如此的卑微

&nbsp;

無奈　情卻是如此的嘆息

&nbsp;

或許在這兩者間　不該有著過多的幻境

&nbsp;

投降了　深深的向命運投降了

&nbsp;

認命了　不該如此的渴望有著希望的那一天

&nbsp;

永別了
