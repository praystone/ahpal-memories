舞蝶大約在五年前的時候　那時候因為發生了一些事

&nbsp;

所以很無奈的離開嘉義　選擇了搬回高雄　而那時候

&nbsp;

說真的　舞蝶是非常頹廢的　雖然現在也是很頹廢中

&nbsp;

那一天　舞蝶開了車回到嘉義　搬完了所有的行李後

&nbsp;

準備第一趟回高雄　再回嘉義搬第二趟　那天舞蝶還

&nbsp;

記得車上　還載了舞蝶兩位朋友　在行徑國道的時候

&nbsp;

因為那時候蝶是在快車道超車　準備要轉進內車道

&nbsp;

那時候　舞蝶叫副駕駛座的朋友幫忙看一下　看說內

&nbsp;

車道有沒有什麼車　他看完後說沒有　誰知道正要轉

&nbsp;

進的時候　忽然也有一輛外車道的車準備插入內車道

&nbsp;

那時候舞蝶的朋友只說了一句　小心　相信大家都知

&nbsp;

道　國道最低限速是多少　雖然是最低的了　但是一

&nbsp;

車禍一樣要人命　那時候舞蝶看了一眼後　馬上拉回

&nbsp;

快車道　說真的　如果不拉回的話　一定跟那輛車擦

&nbsp;

撞　但是　不拉回還好　一拉回更麻煩　因為當時是

&nbsp;

情急的　拉回後　因為拉過頭　所以又差一點撞到中

&nbsp;

央分隔島　所以又急忙打正方向　但因為之前車速過

&nbsp;

快　所以當在打正的時候　根本是來不急了　那一瞬

&nbsp;

間　蝶的整輛車子在國道高速公路上　先行甩尾　然

&nbsp;

後在高速公路整整轉了七圈半　車子在道路上　像似

&nbsp;

畫圓圈一樣　轉了七圈半　那時候舞蝶的心中　認為

&nbsp;

完了　因為要是沒翻車的話　也會被後方的來車追撞

&nbsp;

一團　那就是所謂的連環車禍了　而且　那時候的車

&nbsp;

上　只聽見舞蝶兩位的慘叫聲　而說真的　那時候舞

&nbsp;

蝶的心　反而是非常的平靜　心想　要是死了　那或

&nbsp;

許也是不錯的選擇　最後的半圈車子停了　為什麼是

&nbsp;

半圈　因為車子停的方向　車頭剛好是在所有車子的

&nbsp;

前面　舞蝶那時候心想　來吧　準備要撞過來了　舞

&nbsp;

蝶準備好接受死亡了　誰知道停下一看　後方的來車

&nbsp;

都停在那邊　而且不是塞車而停下　而是停下那邊以

&nbsp;

防追撞事件　奇觀阿　高速公路所有車輛都停下了

&nbsp;

而且還有人站在車外看　看剛剛舞蝶那七圈半的奇蹟

&nbsp;

後來舞蝶慢慢的轉到路肩停了一下　兩位朋友傻了

&nbsp;

舞蝶那時候笑了　不知道是當時考駕照的時候　舞蝶

&nbsp;

有專心看書的結果　還是死神還不打算來抓舞蝶　

&nbsp;

本來已經遺忘的這一段故事　在今天看了絕命終結站

&nbsp;

四的時候想起　呵　命囉~
