空白的思維　理不清頭緒的盲目　

&nbsp;

天是如此的寒冷　

&nbsp;

妄想的雙眼　

&nbsp;

總渴望能見到最真實的甜蜜

&nbsp;

能嗎

&nbsp;

一句疑問　一個問號

&nbsp;

打破了這樣的僵局　

&nbsp;

明白了是非　卻永遠不明白情感的糾葛

&nbsp;

心是如此的淒涼

&nbsp;

幸福的途徑　原來只不過是另一段悲傷的捷徑

&nbsp;

走進了途徑的迷惘　卻陷入捷徑的憂傷

&nbsp;

破碎不堪的擁抱　是一張張的照片

&nbsp;

擁抱的

&nbsp;

不是這樣的一切

&nbsp;

擁抱的

&nbsp;

是過去的記憶

&nbsp;

一杯溫和的酒　帶動了情緒的波動

&nbsp;

飄浮不定的眼神　是醉意還是沉溺

&nbsp;

語言

&nbsp;

是如此的真實　卻也是如此的殘酷

&nbsp;

訴說著殘酷的真實　更記載著真實的謊言

&nbsp;

幾分的醉意說著殘忍的事實

&nbsp;

沉溺的謊言記載著曾經的訴說

&nbsp;

今天

&nbsp;

依然是悲劇的上演

&nbsp;

一段又一段的演著

&nbsp;

傷

&nbsp;

一遍又一遍的淌血著

&nbsp;

淚

&nbsp;

一滴又一滴的飄落著

&nbsp;

悲傷的故事

&nbsp;

沒有結局

&nbsp;

永遠都沒有
