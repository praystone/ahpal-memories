現在的年輕人都是船過水無痕嗎

&nbsp;

有需要幫忙的時候

&nbsp;

總是好聲好氣.稱兄道弟

&nbsp;

一朝沒利用價值了　

&nbsp;

就隨便冠上一個莫須有的罪名

&nbsp;

然後賜你一死

&nbsp;

什麼玩意阿

&nbsp;

討厭　非常討厭　

&nbsp;

說得都是兄弟　做的都是自己

&nbsp;

男男女女都一樣

&nbsp;

早些年　為了幫朋友

&nbsp;

錢也出　力也出

&nbsp;

換來的終究是一樣的下場

&nbsp;

狗屎

&nbsp;

真是天大的狗屎

&nbsp;

連過年過節一通問候都沒有

&nbsp;

笑話

&nbsp;

蝶真是天大的笑話

&nbsp;

本來不在意

&nbsp;

但今天遇到的事　簡直讓蝶火上加火

&nbsp;

不禁讓蝶想起所有不愉快的事

&nbsp;

死小孩~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
