夢境中的妳　

&nbsp;

是如此的真實　

&nbsp;

真實到讓我忘了這是一場夢

&nbsp;

夢境的序曲　

&nbsp;

是夜晚的一場慶典　

&nbsp;

有著歡笑聲　有著熱鬧的沸騰

&nbsp;

這樣的夢　是一份捨不得

&nbsp;

捨不得醒來　捨不得面對

&nbsp;

靈魂的悸動　

&nbsp;

是一幕幕妳我的親吻

&nbsp;

這樣的吻

&nbsp;

彷彿訴說著兩個靈魂的交談

&nbsp;

吻

&nbsp;

如此的美

&nbsp;

眼

&nbsp;

是這般的陶醉

&nbsp;

親吻過後的餘溫　是彼此的不願罷手

&nbsp;

激情

&nbsp;

床第上的溫存　是妳和我之間靈魂的纏綿

&nbsp;

分不開

&nbsp;

相依相偎的呼吸　是這樣的離不開

&nbsp;

片刻的過後　

&nbsp;

是妳要離去的身影

&nbsp;

遞了一把鑰匙

&nbsp;

妳說著

&nbsp;

這是妳心房的鑰匙

&nbsp;

妳說著

&nbsp;

這是我倆的世界與秘密

&nbsp;

手

&nbsp;

緊緊的握住了心鑰

&nbsp;

吻

&nbsp;

是離別前的擁吻

&nbsp;

醒了

&nbsp;

夢醒了

&nbsp;

如此真實的夢醒了

&nbsp;

攤開了手

&nbsp;

看不見心鑰

&nbsp;

最後的吻

&nbsp;

也無法感受到任何一點點餘溫

&nbsp;

如果可以

&nbsp;

我願意選擇夢醒

&nbsp;

如果可以

&nbsp;

我寧願

&nbsp;

心永遠不要醒
