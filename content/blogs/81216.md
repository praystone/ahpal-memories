君曰：此行人生戲　何須掛礙擾心頭

&nbsp;

吾曰：莫此言　庸人不擾　紅塵擾人　觀世誰為平淡客

&nbsp;

兩君相談風笑聲　

&nbsp;

惜之

&nbsp;

問君幾時歸

&nbsp;

君笑而不語

&nbsp;

十數秋冬集一身

&nbsp;

心盼君

&nbsp;

君盼緣

&nbsp;

若是此生此世未了情　何須擔憂難聚首

&nbsp;

嘆之

&nbsp;

應天命而行

&nbsp;

送行終須一別　若君他朝日　勿忘故友庄　

&nbsp;

珍重聲　連聲起　揮手別　道平安

&nbsp;

身影落陽蹤　走之　遠之

&nbsp;

一方已逝　一方仍在

&nbsp;

心如水鏡面　照看離人故人心
