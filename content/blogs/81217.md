妳說　寂寞是一份如影隨行的朋友　總是與妳行影不離

&nbsp;

我說　這樣的妳　是否已經染上了情感的嗎啡

&nbsp;

妳說　沒有染上　但　也無法戒掉

&nbsp;

寂寞孤獨的妳　總是渴望一份適當的瞭解　還有那一份

&nbsp;

適當的關心　

&nbsp;

太多　對妳來說　是一份沉重的負擔

&nbsp;

太多　對妳來說　是一份想逃避的理由

&nbsp;

緊緊封鎖的是妳的心房

&nbsp;

而對我來說

&nbsp;

我只是一個敲敲妳心房門口的人

&nbsp;

背對著背

&nbsp;

妳和我之間

&nbsp;

坐在那心房門口的中間

&nbsp;

妳說著　我聽著

&nbsp;

這樣的妳　說了些什麼　已經不再重要

&nbsp;

這樣的我　聽了些什麼　已經會心一笑

&nbsp;

伴隨孤單　妳已經習慣

&nbsp;

摸不著妳的思緒　我並沒有再有任何的動作

&nbsp;

只是心中有著疑問

&nbsp;

但　那對我來說　並不是那麼的重要

&nbsp;

如今現在的我　卻忽然想起了妳　

&nbsp;

走到了窗外　看了一看屬於妳和我的天空

&nbsp;

心中想著　這樣的妳　現在在做些什麼

&nbsp;

心中問著　現在的妳　如今在想些什麼

&nbsp;

在這樣的空中　沒想到　也會有著一份漣漪的心情

&nbsp;

不知道在遠方的妳　是否也能稍稍感受到那微微的心情
