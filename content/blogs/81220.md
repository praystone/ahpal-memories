聽

&nbsp;

聽見了海浪的聲音

&nbsp;

也聽見了妳哭泣的內心

&nbsp;

海

&nbsp;

赤腳踏在沙灘上

&nbsp;

是妳唯一向大海的傾訴

&nbsp;

淚

&nbsp;

無法言語的心情

&nbsp;

是妳傾盡的無奈淚水

&nbsp;

心

&nbsp;

瞭解不了的故事

&nbsp;

是妳不願提起的心房

&nbsp;

夢

&nbsp;

總是難過的逃避

&nbsp;

想逃到一個荒蕪沙漠

&nbsp;

妳說

&nbsp;

如果想瞭解一個這樣的妳

&nbsp;

那麼必須先學會聽海

&nbsp;

因為

&nbsp;

妳已經把所有的心情

&nbsp;

都寄託在這海面上

&nbsp;

如果用著心聽

&nbsp;

那麼自然會聽到妳的心情

&nbsp;

妳說

&nbsp;

如果你想追求我

&nbsp;

那麼你的心　

&nbsp;

必須像大海一樣包容我

&nbsp;

包容我的任性

&nbsp;

包容我的脾氣

&nbsp;

包容我的一切

&nbsp;

妳說

&nbsp;

妳沒什麼朋友

&nbsp;

除了這片海　

&nbsp;

妳什麼都沒有

&nbsp;

所以

&nbsp;

海

&nbsp;

是妳唯一的情人

&nbsp;

妳說

&nbsp;

如果有一天

&nbsp;

妳已經不在了

&nbsp;

那麼妳希望將身體獻給這片海洋

&nbsp;

好讓海洋擁抱妳一輩子

&nbsp;

妳喜歡著海

&nbsp;

更喜歡浪花賤在妳的微笑

&nbsp;

女人的心

&nbsp;

是一片海

&nbsp;

原來這樣的心

&nbsp;

是那麼的美麗
