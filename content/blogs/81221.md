是誰挑動了我的心　讓著這樣的夜無法平息

&nbsp;

接觸不到妳的臉頰　是否是一份虛構的幻想

&nbsp;

感覺著有妳的每一天　

&nbsp;

試著幻想著有妳的香水味

&nbsp;

輕輕的走到妳身後

&nbsp;

從妳身後擁抱妳

&nbsp;

髮稍

&nbsp;

是如此的迷人

&nbsp;

妳的驚嚇　妳的微笑

&nbsp;

帶動著妳回頭的一吻

&nbsp;

讓妳平躺在我的心跳上

&nbsp;

慢慢的摸著妳的髮稍

&nbsp;

看著妳愛笑的眼睛

&nbsp;

聽著妳細語的內容

&nbsp;

入眠的情懷　是有妳的陪伴

&nbsp;

這樣的感情　是如此的簡單

&nbsp;

這樣的一切　是如此的真實

&nbsp;

這樣的真實　卻又是如此的虛幻
