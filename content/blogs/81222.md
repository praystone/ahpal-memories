離職前

&nbsp;

下午三點起床　刷牙洗臉換衣服準備上班

&nbsp;

騎上蝶的橘色笨野狼　一路慢慢飄到公司

&nbsp;

每每經過漢神巨蛋　都會停下等紅燈發發

&nbsp;

呆　看看巨蛋什麼時候要倒

&nbsp;

到了公司打卡　然後到倉庫整理髮型　稍

&nbsp;

微跟客人聊聊天　三點五十分開始交接班

&nbsp;

交完班　繼續跟客人聊天　常常東聊西聊

&nbsp;

或是閒到發慌掃掃地　看看客人打打機臺

&nbsp;

再不然就是機臺有問題　然後處理一下

&nbsp;

或是客人不會抓牌　蝶總是要被叫去幫忙

&nbsp;

抓抓牌　

&nbsp;

客人：阿月仔　來抓一下七仔　

客人：阿月仔　來抓一下黑麻

客人：阿月仔　機臺歹去阿

客人：阿月仔　機臺沒代幣了

客人：小月　這應該要聽什麼比較好

客人：小月　按鈕出問題了

&nbsp;

這是天天常聽見的

&nbsp;

不然就是到店面前方偷打電玩　或是跟其

&nbsp;

他組員聊聊天　

&nbsp;

晚上五~七點準備吃飯　

晚上十點半開始打掃

晚上十一點開始廣播趕未成年

晚上十一點開始抄表

晚上十一點五十分準備交班

晚上十二點交完班

晚上十二點十五分打電話給老闆報帳

晚上十二點二十分下班後　跟其他組員打電玩比賽

&nbsp;

下班後　到貴的要命的清粥小菜包宵夜吃

&nbsp;

回到家看一下八點檔的重撥　一邊吃一邊

&nbsp;

看　看完上樓開機　下樓洗澡　洗完打打

&nbsp;

線上遊戲　看看有沒有影片可以抓　

&nbsp;

早上五~六點　天亮了　該睡了

&nbsp;

一天就這樣過去了

&nbsp;

離職後

&nbsp;

天天睡到自然醒　不過不知道為什麼　蝶

&nbsp;

離職後　睡眠時間都以四到六小時　一天

&nbsp;

平均就睡這樣的時間　醒了開電腦　繼續

&nbsp;

看看有沒有什麼影片可以抓　掛網出門覓

&nbsp;

食　晚上八點一到　開始看起八點檔大戲

&nbsp;

常介於民視跟三立跳來跳去的看　一邊看

&nbsp;

一邊激動　天阿　蝶開始邁入喔吉桑當中

&nbsp;

然後每隔一星期至十天　蝶又要準備

&nbsp;

出遠門散心　

&nbsp;

人阿　果然不能太閒= =
