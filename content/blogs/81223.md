悲傷　什麼樣的悲　才能帶來如此的傷

&nbsp;

憂愁　什麼樣的憂　才能帶來如此的愁

&nbsp;

帶走的　是誰的傷

&nbsp;

帶不走的　是誰的悲

&nbsp;

時間刻痕的證明　是憑添一樁無謂的畫

&nbsp;

一筆落下　是那一絲絲的憂

&nbsp;

一劃揮下　是那輕淡淡的愁

&nbsp;

描述著意境的情感

&nbsp;

是誰

&nbsp;

在徒傷悲

&nbsp;

細膩的心　是易碎

&nbsp;

一顆顆易碎的心　總是如此的細膩

&nbsp;

察覺不到的碎裂　

&nbsp;

留下了一小缺口的拼圖

&nbsp;

是細膩捉迷藏的惡作劇

&nbsp;

拼不回

&nbsp;

也找不回

&nbsp;

缺陷的一角

&nbsp;

是否是遺忘的世界

&nbsp;

如果是

&nbsp;

那麼該清醒嗎

&nbsp;

如果不是

&nbsp;

是否就該繼續沉醉下去

&nbsp;

含糊的回答

&nbsp;

是不願面對的心情

&nbsp;

這樣的情感　

&nbsp;

再次逃避了

&nbsp;

薩克斯風的響起

&nbsp;

是夜風的來臨

&nbsp;

吹奏著一首首的曲風

&nbsp;

也吹奏了一段段的逃避

&nbsp;

心

&nbsp;

倦了

&nbsp;

原來這樣的心

&nbsp;

是屬於一杯杯滿滿的苦酒

&nbsp;

原來

&nbsp;

這樣的逃避

&nbsp;

是一份苦酒滿杯
