躺在枕邊的　是曾經愛過的人

&nbsp;

在曾經來看　這樣的感覺是一份幸福

&nbsp;

在如今來看　這樣的感覺是一份陌生

&nbsp;

伸出手來想摸一摸他的臉龐

&nbsp;

但

&nbsp;

回憶卻阻止了

&nbsp;

是哪一天的開始　他們不再相愛

&nbsp;

是哪一天的開始　他們只會爭吵

&nbsp;

忽然間

&nbsp;

好懷念過往的一夜擁抱入眠

&nbsp;

熄滅了照亮的燈光

&nbsp;

靜靜的躺了下來

&nbsp;

一張床　兩個人

&nbsp;

轉身的淚水

&nbsp;

是默默的泣流著

&nbsp;

再次開了燈光

&nbsp;

走到曾經擁有歡笑的客廳

&nbsp;

一張紙　一隻筆

&nbsp;

寫著離開的一切

&nbsp;

帶著簡單的行李

&nbsp;

走出了所有一切的點點滴滴

&nbsp;

街燈的明亮

&nbsp;

是否是在為這樣的舉動而送別

&nbsp;

該何去何從

&nbsp;

心是如此的問著

&nbsp;

就北方吧

&nbsp;

畢竟背靠著背的一張床

&nbsp;

早已經形成一夜夜的一個北字了

&nbsp;

投降了

&nbsp;

這樣的一段愛戀

&nbsp;

沒想到卻輸在一個北字

&nbsp;

走出疑惑的步伐

&nbsp;

北之國的雪

&nbsp;

也正一滴滴的默哀著
