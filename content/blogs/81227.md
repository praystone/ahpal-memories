天微微亮了

&nbsp;

劃破寧靜夜空的聲音

&nbsp;

是鳥兒的啼叫聲

&nbsp;

今晚

&nbsp;

看來又是失眠的抗議

&nbsp;

一壺熱茶　陪了一整夜

&nbsp;

天空開始下起了毛毛的細雨

&nbsp;

有點寒冷

&nbsp;

索性的關了窗

&nbsp;

試圖給這樣的空間一點溫暖

&nbsp;

但卻不見任何效果

&nbsp;

房間　依然寒冷著

&nbsp;

猶豫的選擇

&nbsp;

選擇到底是否要跟失眠抱怨一下

&nbsp;

好讓失眠放過一副空蕩蕩的軀體

&nbsp;

彷彿這樣的失眠

&nbsp;

瞭解了這樣的一切心情

&nbsp;

失眠

&nbsp;

始終不願解放等待救贖的靈魂

&nbsp;

更像是說著

&nbsp;

這樣的靈魂不值得解放

&nbsp;

不肯妥協的商量

&nbsp;

不知是否是無情的折磨

&nbsp;

嘆息的無奈

&nbsp;

高高舉起了投降的白棋

&nbsp;

今晚

&nbsp;

又再次的敗給了殘酷的夜未眠
