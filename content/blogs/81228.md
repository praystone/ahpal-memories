人以去　樓以空

&nbsp;

留下的只是滿滿的回憶

&nbsp;

剩下的只是滿滿的憂傷

&nbsp;

看著同樣的空間裡

&nbsp;

心與情

&nbsp;

泣訴著

&nbsp;

這樣的空間　卻有著不同的故事

&nbsp;

曾經熟悉的容顏

&nbsp;

如今　卻只剩下替換過的陌生

&nbsp;

什麼時候開始

&nbsp;

開始眷戀著這般的情感

&nbsp;

片刻微笑在心田

&nbsp;

絲絲過往擁夢中

&nbsp;

今夜

&nbsp;

心田卻以枯萎

&nbsp;

夢中卻以破碎

&nbsp;

滿身傷痕的微笑

&nbsp;

原來是這般的難過

&nbsp;

原來所有的一切

&nbsp;

名為甘願
