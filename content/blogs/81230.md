延著人生的路往下走

&nbsp;

試著向周遭的人

&nbsp;

討一份屬於自己的愛

&nbsp;

雨

&nbsp;

是如此的下著

&nbsp;

破碎的心境

&nbsp;

就連夢境也快要隨之破滅

&nbsp;

將心放在遺憾裏

&nbsp;

蹲在一旁的角落

&nbsp;

伸出了卑微的雙手

&nbsp;

奢望著

&nbsp;

有人會丟下一份屬於名為永遠的愛

&nbsp;

但

&nbsp;

其心此情卻總是被視若無睹

&nbsp;

乞討著愛

&nbsp;

向上天乞討著一份愛

&nbsp;

不允許

&nbsp;

是得到的唯一回應

&nbsp;

乾涸的雙眼

&nbsp;

是否是靈魂早以不在

&nbsp;

佇著一柺一柺的身驅

&nbsp;

討著一份一份的感情

&nbsp;

心不是乞丐

&nbsp;

但心

&nbsp;

卻是乞愛
