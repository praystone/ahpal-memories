據聞很久很久以前　

&nbsp;

有一片海洋

&nbsp;

它是由無數傷心的人

&nbsp;

流下傷心淚水而形成

&nbsp;

什麼樣的傷才叫真正的傷

&nbsp;

什麼樣的淚才叫真正的淚

&nbsp;

不清楚

&nbsp;

畢竟範圍太過廣範

&nbsp;

這一陣子以來

&nbsp;

蝶流下太多的淚了

&nbsp;

哭過一夜又一夜

&nbsp;

蝶總是自言自語一句話

&nbsp;

已經失去小孩了　為什麼還要失去妳

&nbsp;

得到的答案

&nbsp;

永遠只是

&nbsp;

不知道

&nbsp;

哭了

&nbsp;

今夜又再一次的哭了

&nbsp;

深深的哭了

&nbsp;

傷心的海洋又再一次的形成

&nbsp;

歲月並沒有在蝶的身上留下太多的刻痕

&nbsp;

唯有情傷

&nbsp;

總是傷了又傷

&nbsp;

總是留下一筆又筆的新痕跡

&nbsp;

掏空的心

&nbsp;

是一份空虛

&nbsp;

那一份空虛好難喘氣

&nbsp;

那一份空虛總是好疼

&nbsp;

失去了

&nbsp;

永遠的失去了

&nbsp;

就讓蝶

&nbsp;

為今夜取名為

&nbsp;

失去
