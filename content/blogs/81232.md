是回憶嗎

&nbsp;

還是曾經的承諾

&nbsp;

蝶並不是很清楚自己的想法

&nbsp;

只知道

&nbsp;

蝶該去做一些事而已

&nbsp;

這些日子以來

&nbsp;

蝶一直跑通信行

&nbsp;

也一直看所有的網拍

&nbsp;

終於找到了一隻全新的k770i

&nbsp;

原本心想買白色的

&nbsp;

但是

&nbsp;

好笑的命運總是捉弄人

&nbsp;

白色的缺貨

&nbsp;

只剩下紫色的

&nbsp;

是天意嗎

&nbsp;

還是永無止盡的心酸

&nbsp;

不管了

&nbsp;

蝶拜託了麥可戴蝶去這一趟路

&nbsp;

心一狠

&nbsp;

買下了紫色k770i

&nbsp;

拿在手心的感覺

&nbsp;

在回程的路上

&nbsp;

哭了

&nbsp;

為了回憶而哭

&nbsp;

麥可安安靜靜的聽著蝶在哭

&nbsp;

每每拿著k770i的時候

&nbsp;

心總是想著之前的過去

&nbsp;

想著那人打著牌

&nbsp;

蝶在一旁拿著那人手機的感覺

&nbsp;

旁人則說著

&nbsp;

說著蝶是無謂著

&nbsp;

是如此嗎

&nbsp;

蝶不覺得

&nbsp;

或許心中還在期待

&nbsp;

或許吧

&nbsp;

這樣的日子裡

&nbsp;

也只剩下或許了
