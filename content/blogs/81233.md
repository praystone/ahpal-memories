這一段時間裡

&nbsp;

蝶幾乎下班後都不敢回家

&nbsp;

心是恐懼的

&nbsp;

畢竟房間裡是滿滿的過去跟故事

&nbsp;

那麼蝶該去哪裡

&nbsp;

蝶不知道

&nbsp;

蝶只有想到哪裡就去哪裡

&nbsp;

那一天的夜

&nbsp;

蝶忽然想起她曾經的一個夢

&nbsp;

她說著

&nbsp;

我作了一個夢

我跟你還有娟姐在同一家公司上班耶

&nbsp;

或許是她的一句話吧

&nbsp;

蝶開始找威尼斯公司的電話

&nbsp;

從公司內到公司外

&nbsp;

能問的都問了

&nbsp;

沒有一個人知道

&nbsp;

但是

&nbsp;

沒想到總公司就在威尼斯附近

&nbsp;

於是蝶拜託了福伯跑這一趟路

&nbsp;

幫蝶問問威尼斯的電話

&nbsp;

而呂小澤也剛好知道蝶在找娟姐這人

&nbsp;

他也給了蝶娟姐的行動電話

&nbsp;

是偶然嗎

&nbsp;

還是蝶一直拼命的不放棄她曾經說過得話

&nbsp;

那天的夜裡

&nbsp;

蝶隻身的到了威尼斯

&nbsp;

一進門

&nbsp;

就看見了娟姐

&nbsp;

娟姐不認識蝶

&nbsp;

所以不敢做蝶的生意

&nbsp;

硬生生的把蝶擋在門外

&nbsp;

蝶沒辦法的情況下

&nbsp;

打電話給呂小澤求救

&nbsp;

呂小澤接到電話後

&nbsp;

也馬上到了威尼斯

&nbsp;

然後把蝶帶進去消費

&nbsp;

而蝶要離開之前

&nbsp;

問了呂小澤說

&nbsp;

蝶下次要怎麼進來

&nbsp;

娟姐則說

&nbsp;

下次蝶只要報呂小澤的名就好

&nbsp;

但是可能暫時目前不能換卡

&nbsp;

蝶笑了一笑說

&nbsp;

蝶志不在贏錢　蝶志在認識妳

蝶還會再來找妳的

&nbsp;

她曾經走過的路

&nbsp;

她曾經認識重要的人

&nbsp;

在蝶回過頭的時候

&nbsp;

蝶則是一一的去走她曾經走過的路

&nbsp;

去品嘗她曾經的酸甜苦辣

&nbsp;

而呂小澤問了蝶一個問題

&nbsp;

你為什麼不報她的名字就好了

&nbsp;

蝶笑了一笑說

&nbsp;

蝶只想來看看娟姐

蝶只想認識認識娟姐

蝶只想來間接的幫她回報給娟姐而已

&nbsp;

瘋了

&nbsp;

這是呂小澤給蝶的答案

&nbsp;

呵

&nbsp;

是阿

&nbsp;

蝶是瘋了

&nbsp;

而遠方的她

&nbsp;

永遠都不知道蝶是如此的瘋狂吧
