今天是分手後的第幾天

&nbsp;

不知道

&nbsp;

蝶沒有一一的去牢記

&nbsp;

畢竟

&nbsp;

這不是好事一件

&nbsp;

而這些日子以來

&nbsp;

蝶除了趕緊回去洗個身體以外

&nbsp;

其餘的時間

&nbsp;

除了上班外

&nbsp;

剩下的

&nbsp;

蝶不是睡公司

&nbsp;

就是睡公園

&nbsp;

更或者

&nbsp;

睡在妳跟蝶曾經去過的回憶裡

&nbsp;

睡的下嗎

&nbsp;

答案依舊是沒辦法

&nbsp;

蝶蒼老了許多

&nbsp;

白髮一根多過一根

&nbsp;

臉一天比一天更憔悴

&nbsp;

但淚水卻開始停止了

&nbsp;

無心的蝶

&nbsp;

也已經無法再流出有心的淚水了

&nbsp;

如果有一天

&nbsp;

真要再一次流出淚水的話

&nbsp;

或許也只剩下血淚可以流了

&nbsp;

蝶天天都在玩Touching

&nbsp;

只要每到一個地方就玩

&nbsp;

而只要得到名次

&nbsp;

蝶都會留下屬於紅色般的名字

&nbsp;

旁人則問著

&nbsp;

你為什麼要這樣做

&nbsp;

蝶的回答永遠都是一樣

&nbsp;

或許有一天她到了這個地方

看見了她的名字

那麼就代表著

蝶曾經到過這個地方

&nbsp;

旁人則繼續說著

&nbsp;

時間會沖淡一切的

你要看開一點

&nbsp;

蝶的回答依舊沒有變過

&nbsp;

對別人來說

時間會沖淡所有的一切

但是對蝶來說

剛好相反

時間只會加深蝶的傷痛

時間越長

時間越多

時間越久

蝶越痛

蝶越傷

時間只會帶給蝶無止盡的煎熬

&nbsp;

而蝶則是會問自己

&nbsp;

蝶該跟她聯絡嗎

她還知道蝶想著念著她嗎

她是否知道蝶的心

一直深深的記著她

那怕那樣的心

已經破碎不堪

&nbsp;

算了

&nbsp;

蝶無法提起勇氣再次找尋她

&nbsp;

畢竟

&nbsp;

這是蝶曾經給過的承諾

&nbsp;

只是這樣的承諾卻是如此的沉重

&nbsp;

微笑祝福的背後

&nbsp;

只留下一段又一段的悔恨吧

&nbsp;
