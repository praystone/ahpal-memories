說沒有記住妳跟蝶分開的日子

&nbsp;

蝶是騙人的

&nbsp;

七月七日是晴天

&nbsp;

那天妳與蝶彼此約定好分手後的承諾

&nbsp;

那天

&nbsp;

是蝶永遠的痛之一

&nbsp;

那天正打算要離去的時候

&nbsp;

就因為k770i的關係

&nbsp;

蝶暫緩的停下了腳步

&nbsp;

並答應了阿榮到十九號為止

&nbsp;

離十九號只剩下四天了

&nbsp;

昨夜

&nbsp;

蝶作了一個夢

&nbsp;

夢中的妳打了電話給蝶

&nbsp;

妳說著

&nbsp;

我要跟你拿鑰匙

&nbsp;

蝶回著

&nbsp;

妳說什麼?!

&nbsp;

妳笑了一笑說著

&nbsp;

沒聽到就算了

&nbsp;

夢中的蝶是激動著

&nbsp;

夢

&nbsp;

很短

&nbsp;

希望

&nbsp;

一瞬間是破滅

&nbsp;

醒來

&nbsp;

哭了

&nbsp;

一直哭

&nbsp;

心中問著

&nbsp;

為什麼彼此已經分開了

&nbsp;

為什麼妳的身影總是圍繞在蝶的身邊

&nbsp;

七月十九號

&nbsp;

將是蝶離開南部的日子

&nbsp;

如果

&nbsp;

真有那所謂奇蹟的話

&nbsp;

蝶希望

&nbsp;

上天

&nbsp;

能降臨一次奇蹟給蝶

&nbsp;
