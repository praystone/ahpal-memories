上星期四下午

&nbsp;

蝶終於病倒了

&nbsp;

昏迷在公司裡

&nbsp;

醒來時

&nbsp;

蝶已經在長庚

&nbsp;

醫生告訴蝶的情況

&nbsp;

腦部狀況

睡眠嚴重不足

營養失調

發燒

勞累過度

&nbsp;

蝶聽完後笑一笑

&nbsp;

是阿

&nbsp;

蝶曾經跟她說過

&nbsp;

蝶絕對不會為了她而自殺

&nbsp;

蝶是如此的做到

&nbsp;

但是

&nbsp;

蝶卻沒有說過

&nbsp;

蝶不會折磨自己的身體

&nbsp;

而讓自己的身體瀕臨無用之身

&nbsp;

簡單的說

&nbsp;

蝶只不過是在慢性自殺而已

&nbsp;

上星期六午夜

&nbsp;

蝶做了一個夢

&nbsp;

夢中又再一次的出現了她

&nbsp;

她說：

你恨我?

蝶回說：

為什麼會恨妳?

她說：

因為我沒辦法給你所有的愛!

蝶沒回應.........

她又說：

你可以恨我嗎?

夢中的蝶是哭著回答

蝶做不到恨妳

&nbsp;

醒了

&nbsp;

蝶坐在病床裡呆著

&nbsp;

一邊想

&nbsp;

一邊慢慢的哭

&nbsp;

星期日早晨

&nbsp;

雨天依舊不願停

&nbsp;

蝶慢慢的起身下了樓

&nbsp;

雨好大

&nbsp;

那麼就當一隻雨蝶吧

&nbsp;

蝶的野狼在公司

&nbsp;

所以沒辦法騎車

&nbsp;

那麼就慢步而行吧

&nbsp;

該往哪裡去

&nbsp;

不知道

&nbsp;

蝶就任著雙腳而行

&nbsp;

一路從長庚到本館路

&nbsp;

再從本館路到經武路

&nbsp;

再慢慢的從經武路到大寮

&nbsp;

最後

&nbsp;

到了她家

&nbsp;

淋了一身的雨

&nbsp;

蝶是冷著

&nbsp;

但是心卻不放棄著

&nbsp;

偷偷的躲在一旁的角落裡

&nbsp;

偷看著她的家

&nbsp;

雨

&nbsp;

彷彿不讓任何人看見蝶的淚水

&nbsp;

雨

&nbsp;

下的更大了

&nbsp;

蝶再一次的起身

&nbsp;

慢慢的從原路的走回長庚

&nbsp;

只知道走了好久

&nbsp;

只知道一邊走一邊哭

&nbsp;

回到了長庚

&nbsp;

蝶再一次的發高燒了

&nbsp;

這一次燒到四十度了

&nbsp;

那時候的蝶

&nbsp;

真希望就這樣燒死好了

&nbsp;

但是醫生卻不願意放棄讓蝶離開人間

&nbsp;

蝶終於倒了

&nbsp;

就像蝶之前寫得文章一般

&nbsp;

破碎的蝶羽

&nbsp;

但是現實中

&nbsp;

卻沒有妾心的淚水和後悔

&nbsp;

這段時間裡

&nbsp;

除了麥可跟藍兒以外

&nbsp;

就沒有任何人來看過蝶

&nbsp;

包含蝶的家人

&nbsp;

因為蝶並沒有讓家人知道蝶的狀況

&nbsp;

昨天

&nbsp;

蝶出院了

&nbsp;

但是身體狀況依舊不好

&nbsp;

醫療費該怎麼辦

&nbsp;

蝶在出院之前

&nbsp;

已經先拜託藍兒幫忙了

&nbsp;

這段時間裡

&nbsp;

好在有藍兒的筆電

&nbsp;

好讓蝶不那麼無聊著

&nbsp;

有一天

&nbsp;

藍兒罵著蝶

&nbsp;

你現在像是什麼樣子

你根本就不是我們認識的月

你知道嗎

你變的好憔悴

你已經不是你了

她真的那麼值得你那麼為她嗎

她能感受到嗎

你現在住院了

她知道嗎

她有來看過你嗎

她有打過一通電話給你嗎

&nbsp;

蝶沉默不語

&nbsp;

過了一回

&nbsp;

蝶回著

&nbsp;

她知不知道都沒關係

應該說

蝶不想讓她知道吧

也可以說

蝶只想折磨自己

好讓自己可以離開這一切

好讓淚水可以停止.........

&nbsp;

藍兒無語了

&nbsp;

是阿 

&nbsp;

蝶真的倦了

&nbsp;

蝶只想好好的

&nbsp;

就這樣的睡下去

&nbsp;

好想好想

&nbsp;

蝶可以不再哭泣嗎

&nbsp;

蝶真的累了

&nbsp;

蝶不想再哭泣了

&nbsp;

蝶好想離開了

&nbsp;

好想

&nbsp;

好想好想............

&nbsp;
