一絲絲的離別

&nbsp;

再也沒有收到任何屬於妳的消息

&nbsp;

哭泣

&nbsp;

是永恆不止

&nbsp;

旋律

&nbsp;

是動人或是傷心

&nbsp;

凌亂

&nbsp;

空蕩蕩的心房

&nbsp;

如今卻是如此的髒亂

&nbsp;

不經意的想起妳

&nbsp;

總是在生活中每一個角落

&nbsp;

每一段回憶

&nbsp;

總能因為一個舉動

&nbsp;

總能因為一句話

&nbsp;

慢慢浮現屬於曾經的過去

&nbsp;

是否能停止

&nbsp;

答案

&nbsp;

不能

&nbsp;

也無法

&nbsp;

放縱自私

&nbsp;

自我折磨

&nbsp;

是解脫

&nbsp;

無心

&nbsp;

解脫過後的心

&nbsp;

是歸零的開始

&nbsp;

染白過後的黑髮

&nbsp;

將再一次深深的封鎖

&nbsp;

就任黑暗吞噬黑髮

&nbsp;

無止盡思念

&nbsp;

是妳

&nbsp;

崩潰的生命

&nbsp;

將聽見

&nbsp;

滴答滴答的倒數

&nbsp;

失去的

&nbsp;

永遠將只是失去

&nbsp;

如果

&nbsp;

妳能聽的見

&nbsp;

請妳用心的聽

&nbsp;

聽這麼一句

&nbsp;

我愛妳

&nbsp;

永遠的最後一句

&nbsp;

心鑰的遺失

&nbsp;

等待著妳的拾回

&nbsp;
