雨季

&nbsp;

是下班後唯一的禮物

&nbsp;

再次淋了一身的雨

&nbsp;

徬徨的回到家

&nbsp;

雨停了

&nbsp;

人也出門了

&nbsp;

經過一個曾經熟悉的地方

&nbsp;

人停了

&nbsp;

本為不餓的心

&nbsp;

當看到曾經熟悉的一樣菜後

&nbsp;

是錯覺的誘惑

&nbsp;

於是買下妳曾經愛吃的豬耳朵

&nbsp;

回到了短暫的收留所

&nbsp;

轉了手邊的電視

&nbsp;

電視演的

&nbsp;

是感人

&nbsp;

淚稍稍忍不住要落下

&nbsp;

這樣的錯覺

&nbsp;

總是如此難熬

&nbsp;

強忍的淚水

&nbsp;

終於壓抑住

&nbsp;

輕咬一口了豬耳朵

&nbsp;

嘴中是沒感覺

&nbsp;

心

&nbsp;

卻是回憶

&nbsp;

是命運嗎

&nbsp;

手邊的電視

&nbsp;

轉到了新兵日記時

&nbsp;

由葉家妤所演的角色

&nbsp;

剛好像似妳的名字

&nbsp;

玉婷

&nbsp;

雖然字不同

&nbsp;

但是

&nbsp;

音卻像似

&nbsp;

淚水

&nbsp;

再次狠狠的背叛了眼睛

&nbsp;

淚水一邊落下

&nbsp;

嘴裡一直叫妳

&nbsp;

一天之內

&nbsp;

三個錯

&nbsp;

錯在不該出門

&nbsp;

錯在不該買

&nbsp;

錯在不該看電視

&nbsp;

今夜

&nbsp;

又是如此的想妳

&nbsp;
