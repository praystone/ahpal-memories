兩個星期前

&nbsp;

蝶忽然打開了許久沒開的MSN

&nbsp;

剛上線沒多久

&nbsp;

就遇到了舊同事

&nbsp;

佩珊

&nbsp;

認識佩珊也有四~五年了

&nbsp;

在線上跟她閒聊了一下

&nbsp;

才發現

&nbsp;

她原來已經回到高雄工作了

&nbsp;

蝶問她

&nbsp;

妳好久沒有給蝶探班了

什麼時候要再來給蝶探探班

&nbsp;

她也總是如此的乾脆

&nbsp;

總是輕鬆的回答著

&nbsp;

好

&nbsp;

她問蝶目前在哪裡工作

&nbsp;

蝶大約跟她說了一下地點後

&nbsp;

上星期六

&nbsp;

她如期的依約而來

&nbsp;

在公司裡

&nbsp;

蝶跟她閒聊了一回

&nbsp;

蝶問她

&nbsp;

好久沒有出去逛一逛了

要去嗎

&nbsp;

她

&nbsp;

真的依舊沒有變

&nbsp;

總是對蝶隨和著

&nbsp;

加班

&nbsp;

是星期六唯一的夢魘

&nbsp;

蝶跟她說著

&nbsp;

今天蝶要加班

下班後

蝶會去妳家接妳

&nbsp;

她回著

&nbsp;

你還記得我家嗎

&nbsp;

蝶說著

&nbsp;

記得

&nbsp;

晚上下班後

&nbsp;

蝶飄到了她家

&nbsp;

雖然過程中

&nbsp;

有遺忘她家在哪裡

&nbsp;

呵

&nbsp;

蝶問她

&nbsp;

妳有想去哪裡嗎

&nbsp;

她說

&nbsp;

沒有

只要別再去六合跟瑞豐

其他都OK

&nbsp;

蝶回著

&nbsp;

那麼我們到青年吧

&nbsp;

但是

&nbsp;

在要去的路途中

&nbsp;

發生一些小意外

&nbsp;

所以

&nbsp;

蝶與她沒去成青年

&nbsp;

蝶問著

&nbsp;

那麼妳現在有什麼特別的地方想去嗎

&nbsp;

她思考了一回

&nbsp;

她問著

&nbsp;

你知道靜園嗎

&nbsp;

蝶疑惑著

&nbsp;

她說

&nbsp;

那是在小港那邊附近

可以喝喝東西

跟看飛機降落的地方

&nbsp;

蝶回著

&nbsp;

曾經聽過有這地方

但是不曾去過

&nbsp;

她問著

&nbsp;

那麼要去嗎

&nbsp;

蝶沒多說什麼

&nbsp;

轉頭帶著她前去

&nbsp;

她說

&nbsp;

你知道怎麼走嗎

&nbsp;

蝶說著

&nbsp;

只要到小港

其他的

妳應該就知道了吧

&nbsp;

她笑了一笑

&nbsp;

蝶沒有經由中正路

&nbsp;

蝶轉往鳳山切入小港

&nbsp;

在前去的路程上

&nbsp;

她訝異著一個問題

&nbsp;

她問著

&nbsp;

你對高雄的路很熟嗎

不然怎麼會走這邊

&nbsp;

這次換蝶笑了一笑

&nbsp;

到了靜園

&nbsp;

人潮

&nbsp;

是一堆

&nbsp;

畢竟是星期六

&nbsp;

難免如此

&nbsp;

蝶與她找了一家咖啡店

&nbsp;

點了兩杯許久沒喝的拿鐵

&nbsp;

坐了下來

&nbsp;

倆人

&nbsp;

開始聊起過去的回憶

&nbsp;

回憶

&nbsp;

在談話的過程中

&nbsp;

一片一片慢慢的浮現

&nbsp;

聊出了一段又一段的往事

&nbsp;

她總是在公司愛捉弄蝶

&nbsp;

蝶也總是報復回去

&nbsp;

在公司裡

&nbsp;

她與蝶

&nbsp;

總是嘻笑打鬧著

&nbsp;

也聊起廖仔跟小菁的八卦往事

&nbsp;

也說到了阿豪

&nbsp;

更說起了

&nbsp;

小敏

&nbsp;

她疑惑著當年的一切

&nbsp;

蝶也慢慢的講起當年的故事

&nbsp;

當年的一切

&nbsp;

更逼的蝶不得不調店

&nbsp;

她完全的瞭解了

&nbsp;

雖然與佩珊同事不到兩個月的時間

&nbsp;

但

&nbsp;

蝶與她的友誼卻一直到現在

&nbsp;

而蝶當年調店的時候

&nbsp;

她也曾給蝶探了數次的班

&nbsp;

倆個人

&nbsp;

兩杯拿鐵

&nbsp;

彼此的友誼

&nbsp;

說出了一段曾經的辛酸與淚

&nbsp;

包含了蝶目前的狀況

&nbsp;

她全都瞭解

&nbsp;

雖然她一邊聽一邊驚訝著

&nbsp;

驚訝蝶目前的這段感情

&nbsp;

時間

&nbsp;

很快

&nbsp;

那一夜

&nbsp;

如此的放鬆

&nbsp;

送了她回去

&nbsp;

她也不忘捉弄一下蝶

&nbsp;

是阿

&nbsp;

這畢竟曾經是蝶與她的相處方式

&nbsp;

而也因為佩珊的關係

&nbsp;

蝶

&nbsp;

終於進入新的序曲

&nbsp;

蝶

&nbsp;

終於成了

&nbsp;

罪孽之蝶

&nbsp;

改變了舊有的外型

&nbsp;

更結合了兩份不同的元素

&nbsp;

而兩份不同的元素

&nbsp;

卻有著相同的心情

&nbsp;

那就是

&nbsp;

心鑰

&nbsp;

但

&nbsp;

那一切都已封鎖

&nbsp;

剩下的

&nbsp;

只有

&nbsp;

冷漠

孤單

寂寞

狂傲

衝動

不羈

瘋癲

&nbsp;

蛻變過後的白蝶

&nbsp;

將是最完美

&nbsp;

最痛苦不堪的

&nbsp;

罪孽之蝶

&nbsp;
