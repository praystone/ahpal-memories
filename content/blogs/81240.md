上星期的某一天

&nbsp;

少華跟安安出現在蝶面前

&nbsp;

蝶吃驚了

&nbsp;

少華跟安安都是大忙人

&nbsp;

沒想到他們會南下而找蝶

&nbsp;

當然

&nbsp;

少華一見面就沒好臉色給蝶看

&nbsp;

而蝶

&nbsp;

也當然知道怎麼一回事

&nbsp;

而安安她也一點都沒變

&nbsp;

不負她的外號

&nbsp;

千年不老妖精

&nbsp;

安跟少華一坐下來沒多久

&nbsp;

少華馬上劈頭狂罵

&nbsp;

幹

認識你七~八年了

你還是一樣那麼龜毛

你要怎麼給我們解釋

&nbsp;

原因是什麼

&nbsp;

答案

&nbsp;

上個月蝶答應了少華要到日本去工作

&nbsp;

也請少華他們幫蝶先在新竹找房子

&nbsp;

而少華他們辦事是非常有效率的

&nbsp;

當然馬上幫蝶找好

&nbsp;

還幫蝶付了壓金跟租金

&nbsp;

而蝶

&nbsp;

放他們鴿子了

&nbsp;

蝶回著少華說

&nbsp;

蝶不是故意的

而是蝶放不下那個人

&nbsp;

少華說著

&nbsp;

當初是你堅決要搬離南部的

而你也要我們幫你

現在好了

我們都幫你了

你還卻給我搞這齣

而且

我們是為你好

要你離開臺灣去日本工作

一方面

你可以忘了她

一方面

你也可以到另一個地方療傷

而且

你不是說了嗎

你也想躲她嗎

怎麼還放不下

&nbsp;

蝶說著

&nbsp;

就............厄..........不知道

就............厄..........忘不了她

就............厄..........無法離開她

&nbsp;

少華聽完蝶的回答

&nbsp;

差一點氣到吐貓血

&nbsp;

安安比較理性的跟蝶說著

&nbsp;

月

我們認識你那麼久了

我們都知道你的個性

當年你為了情傷

已經傷了那麼久了

為什麼還要再如此的傷下去

&nbsp;

蝶回著

&nbsp;

因為上輩子相欠債

所以這輩子

蝶要來還她

&nbsp;

少華聽完後

&nbsp;

再一次深深的吐貓血

&nbsp;

少華說著

&nbsp;

什麼狗屁前世因.今世果

&nbsp;

蝶回著

&nbsp;

就真的相欠債咩

不然蝶也不會如此難熬

&nbsp;

安繼續問著

&nbsp;

那你覺得她值得嗎

&nbsp;

蝶馬上回答

&nbsp;

值得

&nbsp;

安繼續問著

&nbsp;

那麼你還愛著她嗎

&nbsp;

蝶馬上回答

&nbsp;

當然

不愛的話

蝶早就滾離開高雄了

就像當年離開嘉義那樣

&nbsp;

安繼續問著

&nbsp;

那麼她曉得嗎

那麼她感動嗎

&nbsp;

蝶說著

&nbsp;

她完全不知道

其實

她不是完全不知道

只是

她以為蝶在騙她而已

其實

蝶沒有騙她

因為

當初蝶真的傳錯簡訊到她那邊

而她

也認為蝶是故意的

&nbsp;

安說著

&nbsp;

月

說實話

你知道我跟少華的個性

我跟少華這趟下來不能沒有收穫

&nbsp;

蝶反問著

&nbsp;

你們要什麼收穫

&nbsp;

少華馬上搶著回答

&nbsp;

當然是要抓你回北部

&nbsp;

蝶馬上嚇了一跳

&nbsp;

因為他們真的是這樣的人

&nbsp;

安說著

&nbsp;

我跟少華不忍心繼續看你如此下去

我們都認識那麼久了

你就算不顧我們的情面

你也要顧思佳的情面吧

&nbsp;

蝶愣了

&nbsp;

蝶問著

&nbsp;

思佳過的好嗎

&nbsp;

安回著

&nbsp;

她過的很好

她也結婚了

也跟她老公生了一個小男孩

當年

是你撮合我跟少華認識到結婚

而當年的你

為了情傷

一句話都沒說的離開

你知道嗎

當時思佳多為你著急

她跑到嘉義去找冠廷跟蓉岑打聽你的消息

而你也知道

當時思佳對你有意思

你卻偏偏始終把她擋在門外

縱使當年的你是有女朋友的人

她也一直默默的等著你

&nbsp;

蝶問著

&nbsp;

那麼她現在知道蝶的狀況嗎

&nbsp;

少華說著

&nbsp;

佳佳她知道

佳佳她希望你能回北部

對彼此都有個好照應

而且

當年的我們

本來就是四個死黨

是你自己不珍惜離開我們的

如果當年

你不要那麼傻的話

或許現在的你跟她

也早已經是情侶

更或者

你們也已經結婚了

&nbsp;

蝶嘆了一口氣說著

&nbsp;

她幸福就好

蝶不是她想要的一切

而她更不是蝶所希望的一切

&nbsp;

少華第三次吐貓血

&nbsp;

一邊幹喬一邊問著

&nbsp;

你娘卡好

不然什麼才是你要的

像現在這樣嗎

一直傷

一直愛著一個不愛你的人

你真它媽的蠢耶

&nbsp;

蝶笑了一笑說

&nbsp;

是阿

蝶要是不蠢的話

怎會愛上她

蝶要是不蠢的話

怎會如此的離不開.放不下

&nbsp;

少華終於氣到貓血都吐完了

&nbsp;

安接著說

&nbsp;

月

不管如何

我跟少華今天要把你給帶走

&nbsp;

蝶回著

&nbsp;

那蝶工作怎麼辦

薪水怎麼辦

她要怎麼辦

&nbsp;

安回著

&nbsp;

工作好辦

看你是要先到少華那邊工作

還是要先到我那邊工作

我們都知道你作慣了八大行業

所以少華也幫你應徵好柏青哥了

薪水就算了

這段時間

我們都會幫你渡過難關的

至於她

我們希望你忘了她

當然如果可以的話

你最好離開臺灣到日本去工作

你可以放心

少華跟我會幫你安排好日本的一切

所以你今天必須跟我們走

&nbsp;

蝶回著

&nbsp;

非要今天嗎

改天不可以嗎

&nbsp;

安跟少華同時回答

&nbsp;

當然是要今天

&nbsp;

安說著

&nbsp;

我們都知道你非常憂柔寡斷

沒有馬上逼你的話

你不會乖乖的聽話

&nbsp;

蝶沉默了一下

&nbsp;

想了一想後回著

&nbsp;

說真話

蝶真的沒辦法離開高雄

因為蝶真的忘不了

也真的無法離開

就算她不愛蝶了

就算她心裏已經沒有蝶了

蝶還是無法離開她身邊

&nbsp;

少華說著

&nbsp;

你真他媽的賤阿

&nbsp;

蝶又笑了一笑說著

&nbsp;

是阿

蝶真他媽的賤

哈哈哈哈

&nbsp;

蝶笑完後說著

&nbsp;

你們給我一點時間

你們也知道

你們越是逼我

只會讓我躲你們躲更遠而已

&nbsp;

最後的結果

&nbsp;

安安跟少華認輸了

&nbsp;

但是他們也給蝶期限

&nbsp;

希望這段時間裡

&nbsp;

蝶能好好想想

&nbsp;

送走了他們後

&nbsp;

蝶開始回想當年的一切

&nbsp;

時間

&nbsp;

真的過的好快

&nbsp;

每天每夜

&nbsp;

蝶始終想著她

&nbsp;

真希望

&nbsp;

有那麼一天

&nbsp;

她還能回到蝶的身邊

&nbsp;

真希望

&nbsp;

有那麼一天

&nbsp;

蝶還能抱著她入睡
