最近蝶過的非常渾渾噩噩

&nbsp;

上星期少華他們走後沒多久

&nbsp;

隔天

&nbsp;

換阿彬出現在蝶面前

&nbsp;

阿彬問著

&nbsp;

阿月仔

阿你不是沒做了

怎麼還在這邊

&nbsp;

蝶馬上包起來

&nbsp;

害當時的蝶都不知道怎麼回答

&nbsp;

蝶總不能回說

&nbsp;

都是因為她吧

&nbsp;

那樣的話

&nbsp;

蝶包更大

&nbsp;

後來塘塞過去後

&nbsp;

阿彬帶著他的同事到餐賓那邊去玩

&nbsp;

過沒多久

&nbsp;

阿彬跑來找蝶說著

&nbsp;

阿月仔

餐賓那個七仔水耶

要不要介紹一下

你可以帶她到我們公司

我請你們吃蝦吃到吐

&nbsp;

蝶再一次塘塞過去

&nbsp;

因為蝶實在非常懶的理其他的事

&nbsp;

後來他們問說

&nbsp;

聽說美嘉這邊附近有開分店喔

阿月仔你知道在哪裡嗎

&nbsp;

蝶大約形容一下後

&nbsp;

他們就又回餐賓繼續輸錢

&nbsp;

不知道過了多久

&nbsp;

阿彬又出現在蝶面前

&nbsp;

還拿了一千要給蝶吃紅

&nbsp;

蝶就知道

&nbsp;

死阿彬又贏了

&nbsp;

後來下午的時候

&nbsp;

阿彬打電話給蝶

&nbsp;

問蝶有沒有腳

&nbsp;

要不要摸個幾圈

&nbsp;

蝶回說

&nbsp;

沒腳

&nbsp;

後來就沒鳥阿彬了

&nbsp;

晚上十一點半

&nbsp;

蝶正在愛河的時候

&nbsp;

阿彬又打電話來了

&nbsp;

電話裡頭問著

&nbsp;

阿月仔

你現在有沒有空

要不要摸幾圈

&nbsp;

蝶回說

&nbsp;

蝶沒錢

&nbsp;

阿彬不死心說著

&nbsp;

阿沒關係啦

我先借你啦

到時候你在還我就好了

&nbsp;

蝶心想

&nbsp;

死阿彬

你不知道蝶是不想去嗎

你怎麼聽不懂蝶的意思咧

&nbsp;

蝶回說

&nbsp;

不要啦

現在借一借

到時候還不出來的時候

就非常難笑了

&nbsp;

阿彬回著

&nbsp;

阿沒關係啦

都是自己的

你可以慢慢還啦

難道還會害你沒飯吃嗎

而且我們都玩兩佰五十的

一路直走沒外插的

&nbsp;

蝶問著

&nbsp;

那麼你要借蝶多少

&nbsp;

阿彬回著

&nbsp;

先借你五千

&nbsp;

蝶故意的問著

&nbsp;

五千喔

25的運氣不好的話

要輸五千是很輕鬆的耶

&nbsp;

阿彬說

&nbsp;

還沒賭

你就已經說自己輸

那有人這樣的

不然這樣啦

我先借你一萬

&nbsp;

蝶被死阿彬打敗了

&nbsp;

後來蝶心想

&nbsp;

好吧

反正閒閒的

雖然蝶有錢

但是既然有凱子要出錢的話

就多少打發一下時間

反正也沒地方去了

&nbsp;

蝶掛完電話後

&nbsp;

馬上到阿彬家去接他到建國三路報到

&nbsp;

第一圈下去

&nbsp;

真是輸到無話可說

&nbsp;

雖然非常少放槍

&nbsp;

但是

&nbsp;

光是被自摸

&nbsp;

就已經被摸到發炎了

&nbsp;

第二圈開始沒多久

&nbsp;

阿龍跟小玫出現了

&nbsp;

救星出現了

&nbsp;

不過阿龍跟小玫嚇了一跳

&nbsp;

第一

&nbsp;

蝶怎麼會在這邊

&nbsp;

第二

&nbsp;

蝶怎麼變了一個樣子

&nbsp;

不知道是怎麼一回事

&nbsp;

阿龍跟阿小玫出現後

&nbsp;

蝶二圈馬上開始狂摸

&nbsp;

而且馬上讓位給阿龍玩

&nbsp;

東風剛過

&nbsp;

阿龍接位

&nbsp;

蝶算了一下

&nbsp;

蝶第一圈輸三千快四千

&nbsp;

第二圈東風圈

&nbsp;

蝶贏回一點點

&nbsp;

所以那天

&nbsp;

蝶只輸一千整

&nbsp;

當天馬上勞跑回公司睡覺

&nbsp;

然而

&nbsp;

隔天阿彬又出現了

&nbsp;

他又玩餐彬贏了

&nbsp;

他說著

&nbsp;

阿月仔

昨天那一千塊就不用還了

當是給你吃紅好了

&nbsp;

這星期一

&nbsp;

呂娘

慧娘

菁娘

&nbsp;

三邀一

&nbsp;

她們要準備三娘教子

&nbsp;

她們這三個女人

&nbsp;

不知道那根經壞去

&nbsp;

忽然約要打牌

&nbsp;

而蝶也神經壞去

&nbsp;

既然答應說好

&nbsp;

當天下班

&nbsp;

四人一起回到小菁家大戰

&nbsp;

那天一共玩四圈

&nbsp;

蝶不知道發什麼爐

&nbsp;

從第一圈一直摸到第四圈

&nbsp;

除了自摸以外

&nbsp;

還一直狂糊她們的

&nbsp;

而那天

&nbsp;

蝶也知道呂娘果然是經過大風大雨的

&nbsp;

打牌快

&nbsp;

摸牌準

&nbsp;

釘蝶更是一把罩

&nbsp;

還好蝶跟呂娘都是打牌技的

&nbsp;

所以蝶不覺得什麼

&nbsp;

光是靠自己慢慢的入牌

&nbsp;

就足夠吃死慧娘跟菁娘了

&nbsp;

而那天運氣又特別順

&nbsp;

所以連呂娘都給蝶吃死死

&nbsp;

第四圈的時候

&nbsp;

蝶更是瘋氣到極限

&nbsp;

一直連莊一直摸

&nbsp;

結果那天戰局

&nbsp;

蝶贏三千多

&nbsp;

呂娘小贏七佰多

&nbsp;

慧娘小輸一千多

&nbsp;

菁娘大輸三千多

&nbsp;

而那天戰完後

&nbsp;

蝶老樣子先回公司

&nbsp;

不知道怎麼一回事

&nbsp;

蝶既然坐到北斗面前

&nbsp;

公司後期有規定員工可以打檯子

&nbsp;

蝶既然換了代幣下去玩

&nbsp;

剛玩沒多久

&nbsp;

瘋氣又來了

&nbsp;

五十元開出了八關

&nbsp;

後來這幾天裡

&nbsp;

蝶上班都在偷玩檯子

&nbsp;

連中班主任阿琦.晚班主任阿明都在偷玩

&nbsp;

還有阿B.琇琇.欣芮.吐司.阿坤.小佩他們都在偷玩

&nbsp;

加上蝶是早班主任

&nbsp;

天阿

&nbsp;

三班幹部跟員工放任公事不管

&nbsp;

都在偷玩檯子

&nbsp;

不過還好蝶這幾天都一直在瘋氣

&nbsp;

所以不管玩悟空抓猴

&nbsp;

或是玩北斗都狂開

&nbsp;

不過蝶還好

&nbsp;

還知道贏要斬

&nbsp;

所以開的差不多後

&nbsp;

就算是在城裡紅板

&nbsp;

蝶一律放檯不玩

&nbsp;

所以這幾天蝶過的非常

&nbsp;

渾渾噩噩

&nbsp;

但是今天卻遇到了小黑

&nbsp;

陳柏岳

&nbsp;

害蝶不經意的又想起了她

&nbsp;

唉

&nbsp;

忽然覺得

&nbsp;

怎麼不管走到哪裡

&nbsp;

為什麼都有她的影子存在
