今天她們三個女人又約要打牌了

&nbsp;

最近她們應該打上隱了

&nbsp;

由其是小菁

&nbsp;

她本身就特別喜歡打牌

&nbsp;

下班依舊

&nbsp;

到了小菁家報到

&nbsp;

老樣子

&nbsp;

今天一樣打四圈

&nbsp;

今天手氣普普

&nbsp;

沒什麼放槍

&nbsp;

也沒什麼糊跟自摸

&nbsp;

倒是今天不知道怎麼一回事

&nbsp;

今天的電話特別多

&nbsp;

光是小伶的電話就不知道打了多少通來

&nbsp;

老問題

&nbsp;

工作跟薪水的問題

&nbsp;

每接一次她的電話

&nbsp;

不是放槍就是被狂自摸

&nbsp;

倒是麥可打來的時候

&nbsp;

蝶自摸了~~~~~~~~~~~~~~~~~~~

&nbsp;

不過打牌的過程中

&nbsp;

免不了聊到黑熊跟小熊維尼的事

&nbsp;

最近蝶的公司搞了網咖

&nbsp;

就已經很忙了

&nbsp;

還要在公司裡加上網咖

&nbsp;

不過蝶倒是窩在網咖裡玩

&nbsp;

而嘉隆最近已經成了小熊維尼

&nbsp;

小慧今天還說笑

&nbsp;

說有個山洞

&nbsp;

裡面住了一隻小熊維尼

&nbsp;

蝶倒是回了一句話

&nbsp;

這是流氓板的小熊維尼

&nbsp;

抽煙吃檳榔

&nbsp;

而蝶今天才聽說黑熊很怕蝶

&nbsp;

黑熊他叫阿松

&nbsp;

蝶總是叫他黑熊

&nbsp;

今天聽呂姐說

&nbsp;

只要每次蝶叫他的時候

&nbsp;

他總是搖搖頭苦笑

&nbsp;

因為他的行動總是特別慢

&nbsp;

叫他

&nbsp;

他也不積極

&nbsp;

所以蝶對他會特別要求

&nbsp;

很多事都會叫他去做

&nbsp;

而且對他會特別的兇

&nbsp;

所以他才特別會躲蝶

&nbsp;

而且今天還小慧說

&nbsp;

蝶今天先離開公司的時候

&nbsp;

黑熊還特別跑去問小慧

&nbsp;

阿月去哪裡了

&nbsp;

小慧回說

&nbsp;

阿月有事先走了

&nbsp;

黑熊的表情才輕鬆下來

&nbsp;

蝶到了這家公司不到三個月的時間裡

&nbsp;

已經讓全早班很團結

&nbsp;

而中班卻是最亂的一班

&nbsp;

小慧跟小菁還有呂姐

&nbsp;

她們總是說蝶很會帶心

&nbsp;

不像阿琦那樣

&nbsp;

雖然蝶在上班的過程中

&nbsp;

都是在玩或是在偷懶比較多

&nbsp;

但是一但出事的時候

&nbsp;

蝶總是會擋在她們前面

&nbsp;

而且上班的時候

&nbsp;

蝶總是以很輕鬆的方式帶領大家

&nbsp;

COCO更是停不了

&nbsp;

一但蝶上班的時候

&nbsp;

就是空中情人的時間

&nbsp;

畢竟上個月的時間裡

&nbsp;

那是蝶最忙的時候

&nbsp;

四邊跑

&nbsp;

蝶的付出

&nbsp;

她們都知道

&nbsp;

所以她們也願意聽蝶的話

&nbsp;

而今天打牌的時候

&nbsp;

蝶一直在笑

&nbsp;

笑什麼

&nbsp;

笑說接電話的時候

&nbsp;

跟她一樣

&nbsp;

總是放槍或是被自摸不停

&nbsp;

更好笑的是

&nbsp;

紅中一直跟蝶跟不停

&nbsp;

只要打出一隻紅中

&nbsp;

下一輪馬上摸紅中

&nbsp;

全跟她好像

&nbsp;

而那三個女人卻不知道蝶在笑什麼

&nbsp;

其實

&nbsp;

蝶在一邊打牌

&nbsp;

也

&nbsp;

一邊想著她

&nbsp;

甚至想著

&nbsp;

如果她還在蝶身邊的話

&nbsp;

蝶還能帶她去打牌

&nbsp;

真的

&nbsp;

她的影子

&nbsp;

一直都在蝶的身邊

&nbsp;

蝶的心

&nbsp;

卻也總是在思念著她

&nbsp;

一直一直想著

&nbsp;

就連現在版面的歌曲

&nbsp;

都是要給她聽的

&nbsp;

因為

&nbsp;

這首歌曲的歌詞

&nbsp;

好像在說蝶對她的心情一樣

&nbsp;

而蝶也貼上這首歌的歌詞

&nbsp;

希望

&nbsp;

有一天

&nbsp;

她能瞭解跟感受到蝶對她的心情
