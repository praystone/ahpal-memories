這幾天

&nbsp;

蝶一直重複做同樣的一個夢

&nbsp;

回到了妳依舊是妳

&nbsp;

蝶依舊是蝶的那天

&nbsp;

依舊有著歡笑

&nbsp;

依舊有著相擁而眠的一切

&nbsp;

忘不了

&nbsp;

夢境的樂章

&nbsp;

是妳詢問著一個問題

&nbsp;

你忘的了我嗎

&nbsp;

微笑

&nbsp;

是一份輕鬆的回答

&nbsp;

要忘了妳是可以

但是

蝶必須先忘了自己

&nbsp;

呵

&nbsp;

沒有錯

&nbsp;

唯有先忘了自己是誰

&nbsp;

才能徹底的忘記妳

&nbsp;

畢竟

&nbsp;

妳

&nbsp;

是無法抹去的回憶

&nbsp;

曾經有人詢問過蝶一個問題

&nbsp;

你為何一直玩EZ.TOUCH

&nbsp;

因為

&nbsp;

蝶可以一筆一劃的寫下屬於她的名字

&nbsp;

一筆一劃的寫出回憶的過去

&nbsp;

一筆一劃的寫出忘不了的情懷

&nbsp;

今夜

&nbsp;

蝶獨自一人來到了海邊路

&nbsp;

走上了未曾關上門的階梯

&nbsp;

樓頂

&nbsp;

是眺望所有夜景的孤單

&nbsp;

忽然間

&nbsp;

想起了一段回憶

&nbsp;

心是微微一笑

&nbsp;

再次的離開

&nbsp;

心

&nbsp;

卻有著不同的意境

&nbsp;

回到了苓雅區

&nbsp;

回到了短暫的租屋處

&nbsp;

眼

&nbsp;

不是很願意的想休息

&nbsp;

呵

&nbsp;

一天總是睡不到一至三小時

&nbsp;

但

&nbsp;

卻不曾喊過一聲

&nbsp;

累

&nbsp;

或許

&nbsp;

早已經麻醉了吧

&nbsp;

今夜

&nbsp;

是悲傷的

&nbsp;

如此的悲傷

&nbsp;

證明著

&nbsp;

蝶還活著

&nbsp;

證明著

&nbsp;

蝶還活的很傷痛

&nbsp;

證明著

&nbsp;

蝶還活在這世上

&nbsp;

只是

&nbsp;

這樣的證明

&nbsp;

總是要背著傷痛難過而過下去

&nbsp;

淚月

&nbsp;

是柴崎幸的一首歌

&nbsp;

蝶個人滿喜歡聽的

&nbsp;

剛好符合蝶

&nbsp;

流淚的月

&nbsp;

失眠的朦朧月

&nbsp;

悲傷的朦朧月

&nbsp;

今夜

&nbsp;

蝶送上這一首歌

&nbsp;

希望遠方的心

&nbsp;

能感受到思念的難過

&nbsp;
