慵懶

&nbsp;

是蝶目前在公司所一貫的態度

&nbsp;

下午時分

&nbsp;

黃國榮來到了公司

&nbsp;

他見了蝶後

&nbsp;

便轉身回到了辦公室

&nbsp;

過沒多久

&nbsp;

蝶的電話便開始響起

&nbsp;

電話那頭

&nbsp;

他說在辦公室等蝶

&nbsp;

蝶還不知道該進去嗎

&nbsp;

蝶掛了電話

&nbsp;

進到了辦公室

&nbsp;

他問著

&nbsp;

為什麼蝶跟當初進來公司時

&nbsp;

整個態度差那麼多

&nbsp;

之前的蝶

&nbsp;

是積極的.是努力的

&nbsp;

現在的蝶

&nbsp;

偷打檯子.一直玩EZ.TOUCH.在網咖看韓劇.不理員工死活

&nbsp;

蝶只淡淡的回了一句話

&nbsp;

那

&nbsp;

開除蝶吧

&nbsp;

黃國榮頓了一下

&nbsp;

他說著

&nbsp;

我對你這句話感到很生氣

身為一個幹部

怎麼可以隨口說出開除這件事

你知不知道我為什麼要跟你借錢

那是因為好讓我自己覺得欠你一份情

&nbsp;

蝶心想著

&nbsp;

那是你自己好賭職棒

少來跟蝶套交情

&nbsp;

後來他便一直唸

&nbsp;

但

&nbsp;

蝶沒有去回他嘴

&nbsp;

因為蝶實在很懶的回

&nbsp;

直到他唸到了早班的員工時

&nbsp;

蝶才開始回他嘴

&nbsp;

蝶說著

&nbsp;

三班當中

早班是最團結

最配合的

三班相比之下

中班是最亂的

也是因為如此

蝶才能安安穩穩的慵懶下去

蝶雖然愛玩

但是一有事之時

哪一件事

不是蝶先擋在前面的

蝶之所以可以慵懶

那是因為她們都知道

沒有什麼事

她們能處理的就自己處理

除非有什麼大事

她們才會找蝶

&nbsp;

黃國榮才包起來沒在繼續唸下去

&nbsp;

後來他又說

&nbsp;

那麼蝶是否能改變回原有的造型

&nbsp;

蝶依舊淡淡的回了一句

&nbsp;

辦不到

&nbsp;

畢竟黃國榮自己也知道

&nbsp;

公司並沒有明文規定員工一些造型的問題

&nbsp;

所以他也不便多說什麼

&nbsp;

現在的公司對蝶來說

&nbsp;

可有

&nbsp;

也

&nbsp;

可無

&nbsp;

他們要開除也好

&nbsp;

不開除也罷

&nbsp;

蝶都無所謂

&nbsp;

畢竟很多事

&nbsp;

他們都吃蝶吃死死

&nbsp;

所以留不留在這家公司

&nbsp;

對蝶來說

&nbsp;

早已經不是很重要

&nbsp;
