八月二十七日

&nbsp;

蝶下班後

&nbsp;

便拿了五斤蝦子往南州跑

&nbsp;

一路急忙的到了目的地

&nbsp;

放下了蝦子給小玉後

&nbsp;

蝶便又急忙的衝回高雄蝶窩

&nbsp;

洗了一身的髒汙

&nbsp;

換了一身的乾淨

&nbsp;

招了計程車到了高雄前站

&nbsp;

當下便立刻坐上客運

&nbsp;

往臺北出發

&nbsp;

這次到臺北不為別的

&nbsp;

只為跟少華他們講清楚

&nbsp;

因為蝶知道

&nbsp;

再不講的話

&nbsp;

他們早晚又要下來高雄抓蝶了

&nbsp;

到了臺北已經是凌晨兩點多了

&nbsp;

蝶在客運上的時候

&nbsp;

便已經打電話知會少華他了

&nbsp;

少華聽完後

&nbsp;

還一臉開心的說

&nbsp;

你終於想開要搬回臺北了阿

&nbsp;

其實

&nbsp;

他不知道

&nbsp;

蝶這次是要上去攤牌的

&nbsp;

蝶到了三重便下車等少華

&nbsp;

結果來接蝶的

&nbsp;

不是少華他們

&nbsp;

而是更久沒有見的雪跟Jerry

&nbsp;

蝶一開始還納悶了一下

&nbsp;

心想

&nbsp;

怎麼會有女孩子傳簡訊問蝶在哪裡

&nbsp;

後來才知道

&nbsp;

少華有點事

&nbsp;

要他們先來接蝶

&nbsp;

雪一見到蝶便開始囉嗦起來

&nbsp;

你的電話怎麼都打不通

怎麼一直轉語音

&nbsp;

蝶笑一笑的說

&nbsp;

因為蝶有設定一些功能

&nbsp;

雪還問

&nbsp;

你怎麼變這個模樣阿

很嚇人耶

&nbsp;

蝶又笑了一笑說

&nbsp;

因為秘密

&nbsp;

後來Jerry便開車戴蝶到了士林

&nbsp;

先跟安安會面

&nbsp;

再轉往萬華

&nbsp;

一到萬華

&nbsp;

蝶才發現錯了

&nbsp;

因為她出現了

&nbsp;

思佳

&nbsp;

蝶見到了思佳只有微微一笑

&nbsp;

一路上

&nbsp;

蝶跟她沒有說到半句話

&nbsp;

倒是安安問了一個讓蝶滿好奇的問題

&nbsp;

佳

妳老公怎麼會放妳出來

都那麼晚了

他不怕嗎

&nbsp;

思佳回著

&nbsp;

他知道我要跟你們出來

他沒說什麼

他也沒權利說什麼

&nbsp;

就這樣又是一路安靜的沉默

&nbsp;

到了貓空

&nbsp;

少華已經在那邊等我們了

&nbsp;

大伙便開始東聊西聊起來

&nbsp;

蝶後來也跟大家說明

&nbsp;

蝶目前的心態

&nbsp;

跟不願離開高雄的一切

&nbsp;

當然

&nbsp;

免不了一陣又一陣的臭罵

&nbsp;

天亮了

&nbsp;

少華要大家先到他家一趟

&nbsp;

到了少華家

&nbsp;

他拿出了當年許多的照片

&nbsp;

看在眼裡

&nbsp;

心

&nbsp;

沒有任何的感覺

&nbsp;

蝶知道少華在想什麼

&nbsp;

只是

&nbsp;

蝶的天秤

&nbsp;

早已經被另一個她

&nbsp;

深深的壓住了

&nbsp;

沒有任何人可以憾動著蝶的天秤

&nbsp;

唯有她

&nbsp;

他們臭罵到了中午

&nbsp;

他們也應該累了

&nbsp;

他們提議著要去吃東西

&nbsp;

思佳開口了

&nbsp;

沉默一晚的她

&nbsp;

終於再次的開口了

&nbsp;

我們去吃港式飲茶吧

&nbsp;

雪跟安似乎有了默契一般

&nbsp;

不讓Jerry跟少華有機會開口

&nbsp;

便拉著大家往我們的回憶而走

&nbsp;

其實蝶知道她們倆在想什麼

&nbsp;

因為

&nbsp;

臺北的那家港式飲茶

&nbsp;

一直以來

&nbsp;

都是蝶最愛去跟最愛吃的地方

&nbsp;

那裡不但有最道地的港式飲茶

&nbsp;

還聚集了許多香港人還有外國人

&nbsp;

但

&nbsp;

蝶沒有阻擋她們的提議

&nbsp;

或許

&nbsp;

嘴饞了吧

&nbsp;

時間很快

&nbsp;

一天又這樣過了

&nbsp;

蝶沒睡一晚

&nbsp;

他們也跟著蝶沒睡一晚

&nbsp;

但是蝶終究是月

&nbsp;

而他們不是

&nbsp;

他們畢竟還是會累

&nbsp;

Jerry跟雪走了

&nbsp;

少華也跟安離開了

&nbsp;

只留下蝶跟思佳

&nbsp;

蝶與思佳就這樣一路默默的走到了大安

&nbsp;

找了一個地方歇腳

&nbsp;

倆人

&nbsp;

終於有了對談

&nbsp;

她問著蝶當年為何會一聲不響的離開

&nbsp;

還有著當年許許多多的一切

&nbsp;

更問著

&nbsp;

蝶現在對高雄的她

&nbsp;

是有著什麼樣的心情

&nbsp;

倆人

&nbsp;

一個問著

&nbsp;

一個答著

&nbsp;

時間

&nbsp;

來到了凌晨一點多

&nbsp;

電話再次的響起

&nbsp;

眼前所見的

&nbsp;

是一個喜悅

&nbsp;

耳邊所聽的

&nbsp;

是一份天籟

&nbsp;

沒有錯

&nbsp;

是蝶心目中的她打來的

&nbsp;

蝶拋下了思佳

&nbsp;

自顧自的跟她聊了起來

&nbsp;

她關心著蝶

&nbsp;

但是

&nbsp;

蝶卻不是要著她的關心

&nbsp;

蝶要的是

&nbsp;

她所有的一切

&nbsp;

再次聽到她的聲音

&nbsp;

蝶當下便落下了淚水

&nbsp;

只是

&nbsp;

蝶必須要強忍著

&nbsp;

不讓她有任何的擔心

&nbsp;

思佳見著了

&nbsp;

便從她的包包裡拿出了面紙

&nbsp;

電話裡頭

&nbsp;

蝶是冷靜的

&nbsp;

但是

&nbsp;

心

&nbsp;

卻是激動的

&nbsp;

蝶是多麼的想跟她說

&nbsp;

蝶還愛著妳

蝶根本無法忘記妳

妳是否還能回到蝶的身邊

妳知道嗎

蝶當初所錄下的電話錄音

蝶是每天的聽著

我們倆的照片

蝶是每天的看著

&nbsp;

這些話

&nbsp;

蝶是多麼的想跟她說

&nbsp;

但是

&nbsp;

蝶卻連一句都說不出口

&nbsp;

深怕蝶多說一句

&nbsp;

她會認為那是蝶給她的壓力

&nbsp;

掛下了電話

&nbsp;

蝶在大安深深的大哭

&nbsp;

一直哭

&nbsp;

思佳一直在安撫著蝶

&nbsp;

蝶跟思佳說著

&nbsp;

思佳妳知道嗎

蝶是多麼愛著她

蝶真的不能沒有她

&nbsp;

過沒多久

&nbsp;

思佳也跟著一起哭了出來

&nbsp;

她要蝶別哭

&nbsp;

不然的話

&nbsp;

她也無法停下淚水

&nbsp;

昨夜

&nbsp;

是深深崩潰的一夜

&nbsp;

就算

&nbsp;

她昨夜沒打電話來

&nbsp;

蝶還是會如此的哭著

&nbsp;

畢竟

&nbsp;

心

&nbsp;

早已經完全的屬於她

&nbsp;

思佳送蝶到了客運站

&nbsp;

她目送著蝶的離開

&nbsp;

離別前

&nbsp;

她囑咐著

&nbsp;

如果

真有那麼的一天

我希望你能回到臺北

我會在臺北等著你的回來

如果不能

我希望你能再去追回她

因為

她才是你真正的幸福

而不是現在如此不堪的你

加油

我相信你能追回她對你的愛

&nbsp;

八月二十八日

&nbsp;

分開後的一個月又二十一天

&nbsp;

蝶沒有絲毫的忘記過妳

&nbsp;

如果蝶再一次的追尋

&nbsp;

是否能再一次喚回妳對蝶的愛

&nbsp;

那怕

&nbsp;

只有那短暫的愛

&nbsp;

蝶也

&nbsp;

心甘情願

&nbsp;
