昨夜十點五十分

&nbsp;

蝶再次接到妳的電話時

&nbsp;

整顆心

&nbsp;

是莫名興奮著

&nbsp;

當時的蝶

&nbsp;

是多麼渴望見到妳

&nbsp;

用了很爛的理由想見見妳

&nbsp;

而妳

&nbsp;

似乎瞭解蝶的心

&nbsp;

淡淡的說著

&nbsp;

你是真的要買東西給我吃

還是想見我

&nbsp;

輸了

&nbsp;

蝶永遠都是輸給了妳

&nbsp;

妳總是瞭解著蝶

&nbsp;

急忙的換了衣服

&nbsp;

急忙的回到了公司

&nbsp;

急忙的撈了一斤的蝦子

&nbsp;

急忙的到了妳家

&nbsp;

見到了妳

&nbsp;

終於

&nbsp;

再一次的見到了妳

&nbsp;

妳

&nbsp;

沒有變

&nbsp;

蝶稍稍的牽著妳的手

&nbsp;

眼中的淚水

&nbsp;

有稍稍的打轉著

&nbsp;

妳

&nbsp;

一直說著最近的事

&nbsp;

蝶

&nbsp;

一直笑著聽妳訴說著

&nbsp;

妳問著

&nbsp;

蝶為什麼一直笑不停

&nbsp;

因為

&nbsp;

有妳在蝶的身邊

&nbsp;

蝶是如此的輕鬆幸福

&nbsp;

縱使

&nbsp;

這樣的一切

&nbsp;

是如此的短暫

&nbsp;

而且

&nbsp;

蝶當時有著一股想抱著妳.吻著妳的衝動

&nbsp;

只是強壓那樣的衝動

&nbsp;

蝶更想跟妳說

&nbsp;

蝶非常愛著妳

&nbsp;

而妳看著蝶

&nbsp;

妳說著

&nbsp;

為什麼蝶會如此改變自己

&nbsp;

妳希望著

&nbsp;

蝶能變回原本的模樣

&nbsp;

但是

&nbsp;

蝶卻沒有跟妳說

&nbsp;

除非妳還能回到蝶的身邊

&nbsp;

不然的話

&nbsp;

蝶這一輩子都不會改變了

&nbsp;

好想妳阿

&nbsp;

是如此的多麼想著

&nbsp;

好想抱著妳阿

&nbsp;

心是這般的希望著阿

&nbsp;

好想吻著妳的臉頰阿

&nbsp;

而妳

&nbsp;

慢慢的累了

&nbsp;

妳依靠在蝶的懷裡

&nbsp;

蝶要妳乖乖上床去休息

&nbsp;

妳總是像個頑皮的小公主一樣

&nbsp;

一直不依賴皮著

&nbsp;

蝶

&nbsp;

靜靜的抱著妳

&nbsp;

抱著妳進到妳家

&nbsp;

抱著妳上著樓梯

&nbsp;

抱著妳回到床上

&nbsp;

幫妳蓋好了被子

&nbsp;

幫妳打開了電風

&nbsp;

輕輕的撥開了妳的頭髮

&nbsp;

輕輕的一個吻

&nbsp;

吻在妳的額頭

&nbsp;

帶著一份不願的心

&nbsp;

幫妳鎖上門

&nbsp;

離開了

&nbsp;

夜

&nbsp;

好漫長

&nbsp;

沒有妳的夜

&nbsp;

更是如此的漫長

&nbsp;

慢慢的騎回公司的路上

&nbsp;

淚水

&nbsp;

稍稍的落下

&nbsp;

真希望

&nbsp;

蝶能真的永遠留在妳身旁

&nbsp;
