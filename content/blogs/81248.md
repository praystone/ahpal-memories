今夜

&nbsp;

出現了一位意外的訪客

&nbsp;

他的出現

&nbsp;

他的言語

&nbsp;

多少

&nbsp;

都讓蝶吃了一驚

&nbsp;

少華

&nbsp;

一個出差到南部的老朋友

&nbsp;

晚上八點

&nbsp;

他約著蝶出來

&nbsp;

此行

&nbsp;

他只有單獨一個人

&nbsp;

沒有安安陪著他

&nbsp;

蝶

&nbsp;

依約前去

&nbsp;

客套的話

&nbsp;

彼此之間已經省下了

&nbsp;

他問著

你還要留戀多久

&nbsp;

蝶回著

到死那一天

&nbsp;

他說著

司佳根本沒有嫁人

&nbsp;

蝶回著

SO

&nbsp;

他說著

司佳知道你不想見她

所以才會上演那齣戲

&nbsp;

蝶回著

SO

&nbsp;

少華忿怒了

&nbsp;

多年的友情

&nbsp;

今夜

&nbsp;

終於都撕破臉了

&nbsp;

他的忿怒

&nbsp;

是蝶的堅持

&nbsp;

出手了

&nbsp;

但

&nbsp;

他並沒有打蝶

&nbsp;

他只是要抓蝶回臺北而已

&nbsp;

蝶只靜靜的問著他

你要抓蝶回到臺北是可以

但是

你如果有本事的話

也請麻煩你

將蝶的心一起帶回去

否則

蝶要麻不是繼續回到高雄

要麻就是當一個稻草人

永遠

永遠

沒有心

&nbsp;

他

&nbsp;

平靜了

&nbsp;

他

&nbsp;

緩緩的說出

&nbsp;

那一夜

&nbsp;

蝶回到高雄的後續

&nbsp;

司佳跟他們聯絡

&nbsp;

聽說

&nbsp;

那一夜

&nbsp;

司佳是哭著

&nbsp;

安與少華不忍心

&nbsp;

少華選擇扛下這個問題

&nbsp;

他跟司佳打包票著

&nbsp;

不論如何

&nbsp;

他一定會將蝶帶回去

&nbsp;

看在眼裡&nbsp;&nbsp;&nbsp; 聽在心裡

&nbsp;

蝶

&nbsp;

並沒有任何的感觸

&nbsp;

少華問著

她到底哪裡好

好到讓你如此這樣狼狽

好到讓你到死那一天都不離開

&nbsp;

蝶只靜靜的唱了一首歌

&nbsp;

曾經真的以為人生就這樣了
平靜的心拒決再有浪潮
斬了千次的情絲卻斷不了
百轉千折它將我圍繞

有人問我妳究竟是哪裡好
這麼多年我還忘不了
春風再美也比不上你的笑
沒見過你的人不會明瞭

是鬼迷了心竅也好
是前世的姻緣也好
然而這一切已不再重要
如果你能夠重回我懷抱
是命運的安排也好
是你存心的捉弄也好
然而這一切已不再重要
我願意隨妳到天涯海角

雖然歲月總是匆匆的摧人老　　
雖然情愛種是讓人煩惱
雖然未來如何不能知道
現在說再見會不會太早

&nbsp;

當下

&nbsp;

他笑了

&nbsp;

蝶緩緩的說著

你們是知道的

只要有人在蝶的心中

那麼

蝶的眼中

就再也沒有任何人

除了心中的她

其他的

都不是人

當然

也包含了你們都不是人

&nbsp;

蝶的話

&nbsp;

總是如此的傷

&nbsp;

那怕是多年的好朋友

&nbsp;

也是一樣如此

&nbsp;

決裂了

&nbsp;

他

&nbsp;

終於氣走了

&nbsp;

蝶

&nbsp;

繼續哼著那首歌

&nbsp;

有人問我妳究竟是哪裡好
這麼多年我還忘不了
春風再美也比不上你的笑
沒見過你的人不會明瞭

&nbsp;

如果你能夠重回我懷抱~♫

我願意隨妳到天涯海角~♫
