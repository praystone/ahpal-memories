前一陣子

&nbsp;

蝶生了一場大病

&nbsp;

那場病

&nbsp;

並沒有帶走蝶的生命

&nbsp;

雖然

&nbsp;

有點遺憾

&nbsp;

但

&nbsp;

後遺症依舊存在著

&nbsp;

腦

&nbsp;

時而好&nbsp;&nbsp; 時而壞

&nbsp;

陣痛的時間

&nbsp;

一天比一天更常

&nbsp;

一天比一天更痛

&nbsp;

眼

&nbsp;

開始出現了不對焦

&nbsp;

容易泛紅

&nbsp;

背

&nbsp;

兩頰骨

&nbsp;

依舊是疼不停

&nbsp;

氣管

&nbsp;

咳

&nbsp;

除了咳還是咳

&nbsp;

失眠

&nbsp;

天天都失眠

&nbsp;

沒有一天是好睡的

&nbsp;

其實

&nbsp;

蝶是可以慢慢醫好

&nbsp;

但

&nbsp;

蝶卻沒有

&nbsp;

因為

&nbsp;

老話一句

&nbsp;

就這樣折磨自己吧

&nbsp;

失去了

&nbsp;

既然都已經失去妳了

&nbsp;

那麼

&nbsp;

蝶還有什麼好珍惜的

&nbsp;

沒有了

&nbsp;

既然沒有了

&nbsp;

那就一切都這樣吧

&nbsp;

如果

&nbsp;

蝶能完全擁有妳的話

&nbsp;

那麼

&nbsp;

蝶將會一切都聽妳的

&nbsp;

但是

&nbsp;

那只是如果而已

&nbsp;

而不是一份真實

&nbsp;
