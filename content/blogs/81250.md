冷漠　需要更多的冷漠

&nbsp;

才能帶來更多的絕情

&nbsp;

背叛　需要更多的背叛

&nbsp;

才能救贖絕望的深淵

&nbsp;

狂阿

&nbsp;

是屬於冷冽一笑

&nbsp;

將心悸逐一的打碎

&nbsp;

澈澈底底的埋葬在永恆的角落

&nbsp;

不為誰而心動

&nbsp;

不為誰而失落

&nbsp;

眼前的事實

&nbsp;

將成為孤身背叛離經的捷徑

&nbsp;

真實

&nbsp;

不再需要

&nbsp;

傲慢的象徵

&nbsp;

代表著

&nbsp;

不可一世的驕傲

&nbsp;

幻眼

&nbsp;

將看清何謂情感天下

&nbsp;

捨身入修羅

&nbsp;

天下在手

&nbsp;

捨情入地獄

&nbsp;

玩弄蒼生

&nbsp;

欺騙

&nbsp;

將是最後的語言

&nbsp;

摧毀

&nbsp;

將是最後的成果

&nbsp;

人心的愚昧

&nbsp;

唯有自私

&nbsp;

罪孽之蝶之型

&nbsp;

將屬

&nbsp;

天下禍害
