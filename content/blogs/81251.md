前天

&nbsp;

蝶與忠董.小慧.魯魯米.小菁出去聚餐

&nbsp;

在這邊先感謝忠董出錢又出力

&nbsp;

下班後

&nbsp;

蝶跟其他員工讓忠董接送到燒肉屋

&nbsp;

忠董在一旁根本都沒吃到什麼東西

&nbsp;

他只負責烤肉

&nbsp;

火鍋那邊就由小慧跟小菁負責煮

&nbsp;

蝶只會吃

&nbsp;

本來也有一起約小佩

&nbsp;

但是她說

&nbsp;

她要跟她姦夫出去偷情

&nbsp;

所以

&nbsp;

小佩這一次就沒跟

&nbsp;

這一次聚餐

&nbsp;

是目前早班第四次聚餐

&nbsp;

前三次聚餐都是打牌

&nbsp;

遇到的員工都是女牌鬼居多

&nbsp;

所以前三次

&nbsp;

都是打牌

&nbsp;

燒肉屋吃完的時候

&nbsp;

她們本來也要繼續約打牌

&nbsp;

但是小菁有事

&nbsp;

沒辦法打

&nbsp;

魯魯米便說要逛街

&nbsp;

但是高雄實在逛膩了

&nbsp;

所以

&nbsp;

忠董便開著他的車

&nbsp;

載著蝶等人

&nbsp;

到了台南小北成功夜市跟大東夜市

&nbsp;

一晚

&nbsp;

連續逛了兩邊的夜市

&nbsp;

非常的累阿

&nbsp;

但是蝶有偷偷的拍到夜市的猛男唷

&nbsp;

一直逛到十一點多

&nbsp;

蝶那天等於間接的加班了一天

&nbsp;

忠董送蝶與其他人回到公司的時候

&nbsp;

魯魯米便繼續約著下次的聚餐

&nbsp;

她們這一次打算要吃山產

&nbsp;

蝶是都無所謂

&nbsp;

反正都不是蝶出錢

&nbsp;

不過

&nbsp;

在逛夜市的時候

&nbsp;

看到了兩件東西

&nbsp;

倒是讓蝶哭笑不得

&nbsp;

第一樣是印度拉茶

第二樣是大東夜市

&nbsp;

印度拉茶跟大東

&nbsp;

喔

&nbsp;

娘的

&nbsp;

怎麼走到哪裡

&nbsp;

都有她的影子咧

&nbsp;

害蝶那天一直狂想她

&nbsp;

印度拉茶她滿喜歡喝

&nbsp;

大東

&nbsp;

就讓蝶想起她昏倒那天

&nbsp;

蝶送她到了大東醫院

&nbsp;

昏~
