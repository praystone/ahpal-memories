最近三班都處於造反的狀態

&nbsp;

從中班開始

&nbsp;

阿崎八個小時下來

&nbsp;

幾乎都窩在網咖比較多

&nbsp;

不然就是出來偷打一下檯子

&nbsp;

阿B則是打更大

&nbsp;

大夜

&nbsp;

阿明上班的時候

&nbsp;

則是約欣芮的男朋友合資打檯子

&nbsp;

吐司也跟著偷打

&nbsp;

下班後

&nbsp;

阿坤跟吐司.阿明留下來繼續打檯子

&nbsp;

阿坤則是打到早班快下班

&nbsp;

早班

&nbsp;

蝶最近比較少窩在網咖

&nbsp;

檯子也比較少偷打

&nbsp;

EZ也少了非常多

&nbsp;

倒是小佩跟小菁最近偷打很大

&nbsp;

小佩應該快要被蝶教壞了

&nbsp;

今天上班的時候

&nbsp;

阿明先玩北斗

&nbsp;

後玩麻雀物語

&nbsp;

他運氣不錯

&nbsp;

因為阿坤在他之前

&nbsp;

就已經先囤五佰在裡面了

&nbsp;

加上

&nbsp;

之前阿崎囤的

&nbsp;

所以

&nbsp;

他麻雀物語開了五小一大

&nbsp;

蝶一向非常會偷挖人家的檯子

&nbsp;

哪裡有囤

&nbsp;

蝶就挖到哪裡

&nbsp;

阿明後來放掉後

&nbsp;

蝶便換了九十元下去挖看看

&nbsp;

不到五十元

&nbsp;

就已經開牌出來了

&nbsp;

後來一共開了五大二小

&nbsp;

換了兩千多元

&nbsp;

後來蝶放掉後

&nbsp;

小佩還想挖看看

&nbsp;

但是

&nbsp;

她不知道

&nbsp;

蝶會放掉的檯子

&nbsp;

表示是不能再繼續玩下去的

&nbsp;

所以她雷下去了

&nbsp;

最近店裡

&nbsp;

有一個年約六七十的阿伯

&nbsp;

他跟之前蝶的公司

&nbsp;

有一個客人差不多

&nbsp;

都是號稱

&nbsp;

永不倒莊

&nbsp;

之前蝶的公司

&nbsp;

有一個叫周鳳明的阿伯

&nbsp;

他幾乎沒有輸過

&nbsp;

更沒有倒莊過

&nbsp;

而如今

&nbsp;

現在這個阿伯

&nbsp;

跟周鳳明一樣

&nbsp;

幾乎沒有輸過

&nbsp;

也沒有看他倒莊過

&nbsp;

難道

&nbsp;

現在的阿伯都比較會玩檯子了嗎
