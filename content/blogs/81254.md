人算永遠比不上天算

&nbsp;

計劃永遠趕不上變化

&nbsp;

蝶一直以來

&nbsp;

深信著這兩句話

&nbsp;

今天

&nbsp;

維修手機的業務打電話給蝶

&nbsp;

他說著

&nbsp;

裡面的主機板有問題

所以影響到視訊跟照相按鈕

如果

要換原裝料件的話

需要六千五

&nbsp;

蝶頓了

&nbsp;

他是建議乾脆另買一隻好了

&nbsp;

畢竟

&nbsp;

實在划不來

&nbsp;

蝶聽完後

&nbsp;

並沒有太多的想法

&nbsp;

就像蝶說得一樣

&nbsp;

猶豫

&nbsp;

是不允許在蝶身上發生

&nbsp;

如果有了猶豫

&nbsp;

那麼代表著

&nbsp;

蝶對這段情感

&nbsp;

是一個不可靠的男人

&nbsp;

就算

&nbsp;

她不知道

&nbsp;

那也無所謂

&nbsp;

蝶當下便跟他說

&nbsp;

那你們換吧

六千五蝶願意花

主要的是

修好了以後

還會不會有後續的問題

而且

你們什麼時候能交貨

最好是今天

&nbsp;

當然

&nbsp;

他們今天沒辦法

&nbsp;

所以約明天下午兩點取貨

&nbsp;

下了班

&nbsp;

回到了蝶窩

&nbsp;

電話再一次的響起了

&nbsp;

仔細一看

&nbsp;

原來是業務打來的

&nbsp;

他說著

&nbsp;

蝶先生非常抱歉

我們剛剛跟台北廠商調貨了

但是台北廠商是說

要一板換一板才行唷

但是

你的主機板是水貨

不是正原廠貨

所以

我們沒辦法幫你調貨了

除非

你有朋友K770壞了

或是不要的

那麼你可以拿他們的原廠主機板來換了

&nbsp;

蝶聽完心想著

&nbsp;

之前那個老闆果然非常黑心

&nbsp;

在網頁上打的標題是原廠貨

&nbsp;

結果賣的卻是爛貨

&nbsp;

而且那隻手機在業務解說之下

&nbsp;

蝶更明瞭一事

&nbsp;

那隻手機原來是組裝機

&nbsp;

簡單的說

&nbsp;

目前這隻手機的各部料件

&nbsp;

有臺灣製.大陸製.香港製等料件組裝而成

&nbsp;

蝶聽完後

&nbsp;

非常緊張的問他一個問題

&nbsp;

那怎麼辦

沒有辦法了嗎

錢不是問題

&nbsp;

結果答案是相同的

&nbsp;

除非有原廠主機板

&nbsp;

不然是沒辦法

&nbsp;

今天

&nbsp;

非常重創

&nbsp;

雖然視訊功能蝶非常少用

&nbsp;

但是

&nbsp;

蝶卻不允許這樣的缺陷

&nbsp;

因為

&nbsp;

這是蝶所許下的承諾

&nbsp;

心悶阿

&nbsp;

嚴重的心悶了

&nbsp;

目前處於快崩潰中了
