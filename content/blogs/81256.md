不語蒼天

&nbsp;

片刻思念在心間

&nbsp;

紅塵妃

&nbsp;

誰人明瞭千里夢

&nbsp;

幽幽情

&nbsp;

若干千年萬般笑

&nbsp;

癡人夢

&nbsp;

尋花孤守寒雪中

&nbsp;

醉臥眠

&nbsp;

問心此情歸何處

&nbsp;

一飲天下

&nbsp;

回首一眼苦中樂

&nbsp;

笑嘆眾生百回渡

&nbsp;

誰人不為伊癡狂

&nbsp;

二飲雲海

&nbsp;

一步一詩行數年

&nbsp;

笑看紅楓歸落土

&nbsp;

人生不外樂逍遙

&nbsp;

但聲起

&nbsp;

心猶豫

&nbsp;

若然真如輕鬆過

&nbsp;

為何今朝心折磨

&nbsp;

思君聲

&nbsp;

一話一句皆無奈

&nbsp;

夜風雨

&nbsp;

獨自一人備行囊

&nbsp;

此行一朝去

&nbsp;

再見已無遙期

&nbsp;

若君問何時再相逢

&nbsp;

唯有

&nbsp;

九幽黃泉再相會

&nbsp;
