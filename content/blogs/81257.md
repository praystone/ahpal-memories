距離

&nbsp;

已經越來越近了

&nbsp;

當現今所有的一切

&nbsp;

都已經改變時

&nbsp;

請妳

&nbsp;

不要怨

&nbsp;

畢竟

&nbsp;

機會已經給過

&nbsp;

彼此之間

&nbsp;

或許已經沒有了交集

&nbsp;

天秤的兩端

&nbsp;

沒有永恆的平衡

&nbsp;

失去一方

&nbsp;

便要承受另一方的難過

&nbsp;

電話裡頭

&nbsp;

妳說著很多的原因

&nbsp;

電話裡頭

&nbsp;

妳氣憤的說著為什麼要生氣

&nbsp;

但

&nbsp;

妳卻不瞭解

&nbsp;

生氣是沒有

&nbsp;

只是

&nbsp;

有一份非常徹底的失落而已

&nbsp;

但

&nbsp;

那都已經無所謂了

&nbsp;

越是如此這般

&nbsp;

逐漸的距離

&nbsp;

將會越離越遠

&nbsp;

而另一邊

&nbsp;

將會越離越近

&nbsp;

高興嗎

&nbsp;

難過嗎

&nbsp;

高興

&nbsp;

因為這樣的逐漸

&nbsp;

只會讓這一顆心

&nbsp;

慢慢的成長

&nbsp;

並且

&nbsp;

將幻化成另一種全新不同的姿態

&nbsp;

難過

&nbsp;

這樣的過程

&nbsp;

是必然的

&nbsp;

但

&nbsp;

那樣的一切

&nbsp;

曾經

&nbsp;

不也是早已經習慣

&nbsp;

逐漸遠離的心

&nbsp;

逐漸搬離的情

&nbsp;

苗

&nbsp;

已經發芽了

&nbsp;

慢慢的

&nbsp;

漸漸的

&nbsp;

將會輕輕的跟妳說聲

&nbsp;

掰掰

&nbsp;
