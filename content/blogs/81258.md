今天

&nbsp;

蝶終於離職成功了

&nbsp;

告別了所有公司同仁

&nbsp;

下了班

&nbsp;

蝶往她的住所前進

&nbsp;

看見了她的機車在家

&nbsp;

她

&nbsp;

或許在二樓玩電腦吧

&nbsp;

蝶

&nbsp;

並沒有停留

&nbsp;

轉頭看了一下

&nbsp;

便繼續往前而行

&nbsp;

蝶目前放在首頁的MV

&nbsp;

蝶個人滿喜歡的

&nbsp;

御不凡說著

你真的回來了

&nbsp;

漠刀絕塵回著

我說過

我不會丟下你一個人

&nbsp;

曾經

&nbsp;

蝶也曾經跟她如此說過

&nbsp;

但

&nbsp;

卻不曾有人對蝶如此說過

&nbsp;

蝶真的該飛了

&nbsp;

這三天

&nbsp;

將會繼續開放頁面

&nbsp;

三天過後

&nbsp;

無止期的封板

&nbsp;

但

&nbsp;

請別擔心

&nbsp;

蝶會另開一板

&nbsp;

這邊

&nbsp;

就這樣吧

&nbsp;

開這板也快要一年了

&nbsp;

這一年來

&nbsp;

發生很多事

&nbsp;

而所有的事

&nbsp;

彷彿讓蝶過了數十年般久

&nbsp;

如今

&nbsp;

就將這一切

&nbsp;

隨著這板而埋藏吧

&nbsp;

掰囉

&nbsp;

所有的好友們

&nbsp;

如果

&nbsp;

你們還能找到蝶所開的新板的話

&nbsp;

那麼

&nbsp;

我們自然還是朋友

&nbsp;

如果不能

&nbsp;

那麼就隨緣吧

&nbsp;

如果

&nbsp;

當妳有一天

&nbsp;

需要我的時候

&nbsp;

或許

&nbsp;

我已經沒辦法在妳身邊了

&nbsp;

如果

&nbsp;

真有那麼一天

&nbsp;

或許

&nbsp;

妳可以試著叫叫蝶的名字

&nbsp;

或許

&nbsp;

蝶就會出現在妳面前

&nbsp;

跟妳說著

&nbsp;

我說過

我決不會丟下妳一個人

&nbsp;
