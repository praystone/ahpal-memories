曾經

&nbsp;

在人們的身上

&nbsp;

是沒有任何一滴眼淚的存在

&nbsp;

然而

&nbsp;

有一天

&nbsp;

有一滴水告訴了天神

&nbsp;

水滴說著

天神阿

請您賜予我一場有感情的戀愛

&nbsp;

天神疑惑著問著

你為何想要一場戀愛

&nbsp;

水滴想了一想便說著

因為我想證明我的存在

&nbsp;

天神聽完後笑一笑說著

好

我便賜予你的願望

而後

凡是有人們悲歡離合

就有你的存在

凡是有情感的問題

就有你的存在

&nbsp;

久了

&nbsp;

人們開始落淚

&nbsp;

水滴戀上了人們的臉頰

&nbsp;

他慢慢的滑落

&nbsp;

試圖在臉頰上

&nbsp;

留下

&nbsp;

他曾經存在的證明

&nbsp;

水之戀

&nbsp;

戀上了人世間的悲歡離合

&nbsp;

淚雨落

&nbsp;

落下了紅塵情感的崎嶇路

&nbsp;

水的戀愛

&nbsp;

總是有點美麗

&nbsp;

但又帶點憂傷

&nbsp;

人的情感

&nbsp;

卻也總是不為過

&nbsp;

一滴滴的水滴

&nbsp;

一段段的句點

&nbsp;

一滴水滴

&nbsp;

一段句點

&nbsp;

是開始

&nbsp;

卻也是結束

&nbsp;
