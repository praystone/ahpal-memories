十一月九號

&nbsp;

睡醒是幾點了

&nbsp;

看了一下時間後

&nbsp;

才發現

&nbsp;

根本又睡不到兩個小時

&nbsp;

上午十一點三十分

&nbsp;

不知道怎麼回事

&nbsp;

心

&nbsp;

忽然想到米蘭走一走.看一看

&nbsp;

好久沒有走本館路那條了

&nbsp;

自從

&nbsp;

分開那一天後

&nbsp;

幾乎不曾走過那條常常接送妳的路

&nbsp;

一邊騎車

&nbsp;

一邊回想

&nbsp;

回想那條路上

&nbsp;

妳擁抱著我說過得話

&nbsp;

一路慢慢的回想到了大寮

&nbsp;

經過了雙九

&nbsp;

也經過了曾經妳與我吃過的飯館

&nbsp;

還記得大東嗎

&nbsp;

還記得News嗎

&nbsp;

米蘭

&nbsp;

到了

&nbsp;

看著收拾過後的一切

&nbsp;

心想著

&nbsp;

今年的時候

&nbsp;

妳與我還曾在這家店裡

&nbsp;

但

&nbsp;

如今卻已雙飛

&nbsp;

去找了一下肉圓伯

&nbsp;

也去找了一下香腸嫂

&nbsp;

當然賣煙的阿姐也有份

&nbsp;

他們

&nbsp;

都還記得我

&nbsp;

心

&nbsp;

忽然的

&nbsp;

想吃一下大腸跟香腸

&nbsp;

東西好吃嗎

&nbsp;

老實說

&nbsp;

並不是很清楚

&nbsp;

只是一邊吃的同時

&nbsp;

總是一直在想著過去

&nbsp;

妳與我一起同吃一盤

&nbsp;

離開了米蘭

&nbsp;

腦海裡

&nbsp;

忽然想起了妳每次上下班那條小路

&nbsp;

每次總是看妳離開

&nbsp;

卻不曾走過那條小路

&nbsp;

於是的

&nbsp;

走了一回

&nbsp;

一路進入美芳村

&nbsp;

最後從上寮路出來

&nbsp;

然後又一路到了妳家

&nbsp;

妳的機車在家

&nbsp;

看了一下時間

&nbsp;

下午兩點十四分

&nbsp;

相信那時候的妳

&nbsp;

應該在午睡吧

&nbsp;

當初要離開公司的時候

&nbsp;

佩君說過一句話

&nbsp;

她說

&nbsp;

留下來的人

會比離開的人更難過

&nbsp;

是阿

&nbsp;

當初妳離開的時候

&nbsp;

我的心就如此的難過

&nbsp;

再回首的日子裡

&nbsp;

我

&nbsp;

依舊什麼都沒有得到

&nbsp;

再過往的記憶裡

&nbsp;

我

&nbsp;

只能任憑獨自一人傷悲

&nbsp;

沒有我

&nbsp;

妳依舊過的很好

&nbsp;

但

&nbsp;

沒有妳

&nbsp;

我卻無法過的很好

&nbsp;

妳知道嗎

&nbsp;

我非常想妳

&nbsp;

妳知道嗎

&nbsp;
