窗外的風

&nbsp;

有著些許的涼意

&nbsp;

一個人

&nbsp;

總是靜靜的

&nbsp;

想睡

&nbsp;

卻又睡不入眠

&nbsp;

或許

&nbsp;

這樣的夜

&nbsp;

不應該想起塵封已久的故事

&nbsp;

是命運的捉弄嗎

&nbsp;

今天

&nbsp;

遇到了久違不見的妳

&nbsp;

沒想到

&nbsp;

當初妳與我離開嘉義後

&nbsp;

妳也搬回高雄

&nbsp;

要不是今天跟阿坤到魯魯米家的話

&nbsp;

或許

&nbsp;

再也見不到妳了

&nbsp;

妳沒變

&nbsp;

一點都沒變

&nbsp;

倒是我

&nbsp;

變了

&nbsp;

外表也好

&nbsp;

個性也罷

&nbsp;

一切都變了

&nbsp;

七年快八年了吧

&nbsp;

在一起兩年多

&nbsp;

分手

&nbsp;

也已經快五年了

&nbsp;

在偶然的相遇裡

&nbsp;

妳一句話都沒說

&nbsp;

而我

&nbsp;

也只靜靜的

&nbsp;

阿坤疑惑著到底該走

&nbsp;

還是該留

&nbsp;

妳的身後

&nbsp;

來了一個男人

&nbsp;

是嗎

&nbsp;

原來

&nbsp;

妳已經有了更好的歸宿

&nbsp;

執著嗎

&nbsp;

不

&nbsp;

一點也不

&nbsp;

畢竟

&nbsp;

一切的一切

&nbsp;

早已經都隨風了

&nbsp;

曾經

&nbsp;

妳是我的舊愛

&nbsp;

如今

&nbsp;

妳只是我的舊夢

&nbsp;
