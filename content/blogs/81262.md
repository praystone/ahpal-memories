凌晨四點二十六分

&nbsp;

剛從積甲回到家

&nbsp;

今天

&nbsp;

帶了阿坤跟阿明到積甲給阿龍捧場

&nbsp;

遇到了很多認識的人

&nbsp;

小鈺現在改上中班了

&nbsp;

瓊華依舊過的不錯

&nbsp;

一但場子裡有人開牌

&nbsp;

我總是會幫忙喊場

&nbsp;

瓊華說她很懷念我喊場的聲音跟笑梗

&nbsp;

康廣智本來玩的還不錯

&nbsp;

還拉了黑龍

&nbsp;

但也沒贏多少

&nbsp;

因為

&nbsp;

最後我都只幫他抓了黑BAR

&nbsp;

俊毅看到我後

&nbsp;

則是說我變了很多

&nbsp;

還說著

&nbsp;

怎麼一段時間沒有見而已

&nbsp;

整個人都變了

&nbsp;

現在的我

&nbsp;

算是潮男還是型男

&nbsp;

一開始的時候

&nbsp;

就連裕承也認不出我是誰

&nbsp;

裕承則是勸我不要再漂髮了

&nbsp;

我笑一笑回說

&nbsp;

反正我也快要變光頭了

無所謂了

&nbsp;

瓊華摸著我的頭髮說

&nbsp;

我的頭髮都死了

為什麼要這樣做

&nbsp;

我看著她

&nbsp;

心有所傷感得說

&nbsp;

人都沒心了

人也快死了

頭髮也無所謂了

&nbsp;

她問著

&nbsp;

小婷沒有跟你聯絡了嗎

&nbsp;

我回她說

&nbsp;

有

但非常少

&nbsp;

她繼續問著

&nbsp;

那你們是和平分手嗎

&nbsp;

我笑了一笑說

&nbsp;

算是吧

只是之前先吵起來放而已

&nbsp;

過沒多久

&nbsp;

小鈺也跑來摸摸我的頭

&nbsp;

後來我跟阿龍倒是非常有默契

&nbsp;

一個搓小鈺下面

&nbsp;

一個搓小鈺上面

&nbsp;

小鈺笑一笑說

&nbsp;

你們果然是兄弟

&nbsp;

都一樣色

&nbsp;

不知為何

&nbsp;

我跟瓊華說了一些話

&nbsp;

我說

&nbsp;

我前天有回米蘭看過

我好懷念之前

&nbsp;

瓊華也不知為何回了一句話

&nbsp;

阿月

你不是懷念米蘭

你是想念小婷而已

&nbsp;

我無語了

&nbsp;

今天

&nbsp;

好傷感

&nbsp;

傷感到差一點落下淚水

&nbsp;

差一點在場子裡哭出來

&nbsp;

差一點

&nbsp;

就差那麼一點

&nbsp;
