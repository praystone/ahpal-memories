今天下午四點十分打電話給瓊華

&nbsp;

本只想問她事情辦妥了沒

&nbsp;

沒想到

&nbsp;

她連處理都沒有

&nbsp;

後來

&nbsp;

不知道怎麼聊的

&nbsp;

又聊到小婷那邊去

&nbsp;

她也說

&nbsp;

我雖然外表變了

&nbsp;

但是內心依舊沒有變

&nbsp;

依舊是她認識的月

&nbsp;

我質疑了

&nbsp;

真的嗎

&nbsp;

我真的沒有變嗎

&nbsp;

我應該變了

&nbsp;

外表也好

&nbsp;

個性也好

&nbsp;

應該一切都變了吧

&nbsp;

至少

&nbsp;

身邊認識的每一個人都說我變了

&nbsp;

為什麼她會說我沒變

&nbsp;

只因為她問了一句

&nbsp;

你還有在為她哭泣嗎

&nbsp;

我茫然了

&nbsp;

瓊華勸我該離開了

&nbsp;

好好的一個人

&nbsp;

就這樣的先休息一陣子

&nbsp;

或許吧

&nbsp;

或許我該聽她的

&nbsp;

畢竟

&nbsp;

另一方也無心了

&nbsp;

阿龍八九點打了兩次電話來

&nbsp;

他說

&nbsp;

智均又要開店了

&nbsp;

他要我再過去那邊幫忙

&nbsp;

說真的

&nbsp;

我並不是很願意

&nbsp;

也應該不會答應吧

&nbsp;

因為

&nbsp;

小勳應該會再過去新店

&nbsp;

再者

&nbsp;

我會想起當初米蘭新開時候的事

&nbsp;

更何況

&nbsp;

新工作的關係

&nbsp;

我也必須搬離高雄到台東了

&nbsp;

這樣也好

&nbsp;

反正這些都是早晚的事

&nbsp;

就一切都隨命吧

&nbsp;
