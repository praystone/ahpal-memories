又一夜沒睡

&nbsp;

頭滿疼的

&nbsp;

今天

&nbsp;

決定不去那邊的新工作了

&nbsp;

雖然

&nbsp;

滿對不起麥可的

&nbsp;

但

&nbsp;

一想到

&nbsp;

要先去那邊受訓十天

&nbsp;

完了後

&nbsp;

每個月還要去台東支援五至八天

&nbsp;

加上

&nbsp;

那家店的店長騙阿明

&nbsp;

所以

&nbsp;

決定棄權

&nbsp;

反正

&nbsp;

現在孤身寡人一個

&nbsp;

什麼事都無所謂

&nbsp;

不過

&nbsp;

身上的金額

&nbsp;

也因為敗家的關係

&nbsp;

差不多敗的也快完了

&nbsp;

房租阿

&nbsp;

又是一個頭痛的問題

&nbsp;

不過

&nbsp;

決定的心

&nbsp;

暫時不會改變

&nbsp;

目前

&nbsp;

就不搬回老家了

&nbsp;

大不了

&nbsp;

睡

公

園
