舊有的愛情

&nbsp;

是依戀

&nbsp;

擁有的感情

&nbsp;

是眷戀

&nbsp;

萌芽的情愫

&nbsp;

總是帶著

&nbsp;

一邊傷

&nbsp;

一邊喜

&nbsp;

風雨的飄渺

&nbsp;

卻是留著

&nbsp;

兒時夢

&nbsp;

童顏笑

&nbsp;

曾經有過嗎

&nbsp;

有過那樣的兒時夢

&nbsp;

有過那樣的童顏笑

&nbsp;

時間

&nbsp;

總是流逝個不停

&nbsp;

渡過了童年

&nbsp;

換到了今朝

&nbsp;

如今

&nbsp;

笑過了什麼

&nbsp;

哭過了什麼

&nbsp;

卻早已經漸漸的麻木

&nbsp;

失去的

&nbsp;

永遠只是失去

&nbsp;

哭不回來

&nbsp;

也喚不回來

&nbsp;

一顆心

&nbsp;

慢慢的

&nbsp;

漸漸的

&nbsp;

碎了

&nbsp;

換來的

&nbsp;

只是一份想解脫的慾望

&nbsp;

好讓自己

&nbsp;

在那一失落中

&nbsp;

尋找一份慰藉

&nbsp;

苦笑聲

&nbsp;

永遠總是那麼不堪入耳

&nbsp;

假面具

&nbsp;

彷彿想試著掩飾這一切

&nbsp;

一字一句

&nbsp;

能寫出那樣的過去

&nbsp;

一筆一劃

&nbsp;

卻永遠寫不出一個能永遠的結果

&nbsp;

想的

&nbsp;

不過就是那一份渴望的結果

&nbsp;

但

&nbsp;

那樣的奢望

&nbsp;

卻只能永遠是天方夜譚

&nbsp;

看的到

&nbsp;

卻碰不著

&nbsp;
