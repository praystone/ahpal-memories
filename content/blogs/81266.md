剛剛三點多的時候&nbsp;

&nbsp;

吐司打電話給蝶

&nbsp;

看來

&nbsp;

他今夜的心情又是非常糟了

&nbsp;

自從

&nbsp;

他跟蝶發生同樣的問題後

&nbsp;

他的心情幾乎沒有好過

&nbsp;

雖然

&nbsp;

大家已經沒有在同一家公司了

&nbsp;

但是

&nbsp;

多少總是會聯絡一下

&nbsp;

就連前天

&nbsp;

麥可也打電話問要不要投資事業的事

&nbsp;

老實說

&nbsp;

蝶一點興趣都沒有

&nbsp;

畢竟不安的因素太多了

&nbsp;

滿危險又沒保障

&nbsp;

至於

&nbsp;

吐司的問題

&nbsp;

也是滿麻煩不好解決的

&nbsp;

所以

&nbsp;

蝶也只好聽聽他訴苦

&nbsp;

今天他倒是說了比較久的電話

&nbsp;

講了一個半小時多一點

&nbsp;

蝶對他還滿有耐心的

&nbsp;

雖然

&nbsp;

蝶跟吐司並不是很知交

&nbsp;

但是

&nbsp;

吐司知道蝶一個沒人知道的秘密

&nbsp;

就連之前早班的同事都不知道的秘密

&nbsp;

應該說

&nbsp;

目前這世上

&nbsp;

只有吐司知道的秘密

&nbsp;

也可以說

&nbsp;

就連之前蝶的情人都不知道過

&nbsp;

但是

&nbsp;

蝶當初不知道為什麼會想跟吐司說那些事

&nbsp;

對於這一點

&nbsp;

蝶自己本身倒是覺得滿訝異的

&nbsp;

目前

&nbsp;

只能希望吐司能好過一點

&nbsp;

不要像蝶這般落魄

&nbsp;
