摸著自己的心

&nbsp;

感覺到心的跳動

&nbsp;

久了

&nbsp;

開始問起自己

&nbsp;

這樣的心跳

&nbsp;

是為誰而跳

&nbsp;

還是為了什麼事而跳動著

&nbsp;

總是熟悉

&nbsp;

但

&nbsp;

卻又有點陌生

&nbsp;

禁錮許久的靈魂

&nbsp;

總是希望著

&nbsp;

有那麼一些許的感動

&nbsp;

好讓那樣的靈魂能離開

&nbsp;

感動

&nbsp;

是有那麼一點

&nbsp;

但

&nbsp;

卻總是那麼的一點點

&nbsp;

離不開

&nbsp;

總是那樣的離不開

&nbsp;

謊言

&nbsp;

是生活上的必須品

&nbsp;

每天

&nbsp;

又每天

&nbsp;

總是要選擇各式各樣的謊言

&nbsp;

好讓自己相信

&nbsp;

對於某些事

&nbsp;

或是

&nbsp;

對某些人

&nbsp;

可以看的開

&nbsp;

這

&nbsp;

不就是人生上的第一個謊言嗎

&nbsp;

欺騙

&nbsp;

或許是捨不得

&nbsp;

或許是放不開

&nbsp;

可能是惡意

&nbsp;

可能是善意

&nbsp;

但

&nbsp;

欺騙

&nbsp;

永遠只是欺騙

&nbsp;

在不同的包裝下

&nbsp;

意境或許有那麼些許的不同

&nbsp;

但

&nbsp;

它不也永遠只是一份欺騙嗎

&nbsp;

再一次的摸心

&nbsp;

試著瞭解

&nbsp;

再一次的問情

&nbsp;

瞭解結束

&nbsp;

辭窮般的文筆

&nbsp;

每每

&nbsp;

總是想寫出一份令人哀悼的故事

&nbsp;

但

&nbsp;

久了

&nbsp;

卻發現

&nbsp;

原來

&nbsp;

這樣的故事

&nbsp;

根本不需要寫

&nbsp;

原來

&nbsp;

自己所有的一切

&nbsp;

早已經注定悲傷的結束

&nbsp;

只是

&nbsp;

想以更哀悼的故事

&nbsp;

來滿足自己的不滿足

&nbsp;

好讓自己覺得

&nbsp;

自己

&nbsp;

不是最難過的那一個

&nbsp;

好讓自己感覺

&nbsp;

自己

&nbsp;

更不是最後一個難過的人

&nbsp;

但

&nbsp;

故事

&nbsp;

永遠都已經注定好

&nbsp;

摸心的故事

&nbsp;

一份摸著自己的心

&nbsp;

一份流著淚的故事
