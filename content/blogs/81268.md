輕輕的

&nbsp;

在妳耳邊說了一些話

&nbsp;

妳

&nbsp;

是睡著著

&nbsp;

聽不到話的內容

&nbsp;

妳

&nbsp;

是睡的如此的甜美

&nbsp;

摸摸妳的頭髮

&nbsp;

親親妳的臉頰

&nbsp;

妳彷彿不願被吵嚷的感覺

&nbsp;

妳嘟著小嘴

&nbsp;

嗯嗯阿阿的唸著

&nbsp;

笑了

&nbsp;

看見這般所謂的幸福

&nbsp;

人笑了

&nbsp;

心

&nbsp;

也更著笑了

&nbsp;

不過

&nbsp;

那只不過是回憶罷了

&nbsp;

擁有短暫幸福的後遺症

&nbsp;

是一天又一天的煎熬

&nbsp;

受著這樣的難過

&nbsp;

心

&nbsp;

必須先學會著苦笑

&nbsp;

那樣的笑

&nbsp;

有那麼一點的甜

&nbsp;

卻也那麼的酸

&nbsp;

天冷了

&nbsp;

人寂寞了

&nbsp;

找的到的過去

&nbsp;

是過往的景物

&nbsp;

找不回的情感

&nbsp;

是那麼一份沉重的包袱

&nbsp;

重嗎

&nbsp;

非常重阿

&nbsp;

不願的甘願

&nbsp;

無可奈何的選擇了背負

&nbsp;

人在等待

&nbsp;

等待著期待

&nbsp;

期待著盼望妳能歸來

&nbsp;
