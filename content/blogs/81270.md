今天

&nbsp;

友明見到蝶的時候

&nbsp;

說蝶瘦了很多

&nbsp;

算了一算

&nbsp;

也大約瘦了快十公斤了吧

&nbsp;

蝶疑問著

&nbsp;

有嗎

&nbsp;

友明拉了喵喵跟宜佳過來

&nbsp;

友明問著

&nbsp;

蝶是否瘦了很多

&nbsp;

喵跟佳說有

&nbsp;

那麼

&nbsp;

蝶該高興嗎

&nbsp;

還是該覺得又要苦笑一場

&nbsp;

今天

&nbsp;

不知道怎麼一回事

&nbsp;

總是覺得特別的酸痛與累

&nbsp;

但

&nbsp;

偏偏又睡不著

&nbsp;

然而

&nbsp;

今天友明還跑來跟蝶說

&nbsp;

他覺得

&nbsp;

蝶不單單是瘦了

&nbsp;

還變的很憔悴

&nbsp;

變的特別滄桑許多

&nbsp;

連黑眼圈都非常明顯

&nbsp;

無言了

&nbsp;

不過

&nbsp;

或許吧

&nbsp;

反正路也只能這麼走下去了

&nbsp;

就走到哪天不能再走為止吧

&nbsp;
