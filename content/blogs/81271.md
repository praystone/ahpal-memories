上個星期的時候

&nbsp;

蝶跟一個朋友去唱歌

&nbsp;

無意間

&nbsp;

蝶與朋友剛好聽到這首野薔薇

&nbsp;

兩人對這首歌滿有興趣的

&nbsp;

於是

&nbsp;

先點了一次聽聽看

&nbsp;

在第一次還沒有聽完的時候

&nbsp;

蝶已經抓了大約的音律

&nbsp;

也在第一次的時候

&nbsp;

大約先試唱一些些

&nbsp;

然後

&nbsp;

再重點一次

&nbsp;

蝶便可以唱出來

&nbsp;

不過

&nbsp;

蝶這位朋友滿喜歡考蝶一些沒聽過的歌

&nbsp;

然而

&nbsp;

總是要蝶聽一聽後

&nbsp;

就馬上唱

&nbsp;

所以大多歌曲

&nbsp;

不論台語.國語.英語.日語.韓語

&nbsp;

有時間的時候

&nbsp;

都多少找一些來聽聽

&nbsp;

還好

&nbsp;

蝶的音律也還算廣

&nbsp;

所以

&nbsp;

很多歌路都沒有什麼問題

&nbsp;

不過這個朋友倒是很喜歡出難題給蝶

&nbsp;

從男女高音到低音

&nbsp;

或是連最有名的　Gloomy Sunday　這首歌

&nbsp;

總是要蝶唱出來

&nbsp;

不過

&nbsp;

蝶對JAZZ或是嘻哈的歌

&nbsp;

蝶就完全投降了

&nbsp;

因為

&nbsp;

蝶唱完後

&nbsp;

會死厭厭的在那邊等斷氣

&nbsp;

所以囉

&nbsp;

周杰倫的歌

&nbsp;

大都不唱

&nbsp;

除了比較古調的歌

&nbsp;

像是蘭亭序.青花瓷這類型的歌

&nbsp;

但

&nbsp;

如果要唱搖滾的歌

&nbsp;

蝶就沒什麼問題

&nbsp;

之前

&nbsp;

蝶還在當街頭藝人的時候

&nbsp;

就必須要接受現場聽眾的點歌

&nbsp;

今天不會唱的

&nbsp;

下次來的時候

&nbsp;

就必須要會唱

&nbsp;

而現場的客人聽的歌

&nbsp;

也時常不定

&nbsp;

但是

&nbsp;

如果可以的話

&nbsp;

蝶不太喜歡唱流行歌曲

&nbsp;

除了

&nbsp;

蝶覺得中聽的

&nbsp;

但是

&nbsp;

當時的蝶

&nbsp;

並選擇的機會

&nbsp;

所以就算不喜歡

&nbsp;

也要硬著頭皮唱

&nbsp;

而前一陣子

&nbsp;

幫藍兒她們代班的時候

&nbsp;

也差點死厭厭

&nbsp;

一天大約有三至四場

&nbsp;

有的場喜歡聽可以吵熱場子的

&nbsp;

光是這些場

&nbsp;

客人所點的歌

&nbsp;

都是一些現在所流行的韓語歌曲

&nbsp;

光是還要練舞

&nbsp;

蝶就已經先死一半了

&nbsp;

上上星期

&nbsp;

蝶還跟藍兒她們到台中小ㄚ頭她們公司表演

&nbsp;

一場下來

&nbsp;

光是出場曲就先以　Super Junior M - Super Gir　暖場

&nbsp;

序場　Super Junior SORRY　

&nbsp;

中場　Super Junior - BONAMANA

&nbsp;

中半場　SHINee - Lucifer

&nbsp;

後半場　SHINee - RingDingDong

&nbsp;

最後剩一小時的時候

&nbsp;

藍兒她們還叫蝶一個人上去死

&nbsp;

不過

&nbsp;

當蝶唱到　熱情的沙漠　的時候

&nbsp;

那時候是全場最熱

&nbsp;

因為

&nbsp;

蝶要一邊唱

&nbsp;

還要一邊熱舞

&nbsp;

藍兒

&nbsp;

妳非常好

&nbsp;

妳給蝶記住

&nbsp;

光是前一陣子練Super Junior跟SHINee的舞蹈

&nbsp;

蝶就已經快死厭厭了

&nbsp;

不過

&nbsp;

還好KK有讓蝶選圭賢跟鐘鏇的位置

&nbsp;

但是

&nbsp;

人老了

&nbsp;

終究不重用了

&nbsp;

前天剛從台中回高雄的時候

&nbsp;

蝶就已經那邊酸.這邊痛了

&nbsp;

老囉

&nbsp;
