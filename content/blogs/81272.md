上個星期剛回高雄沒多久

&nbsp;

就馬上跟團出發去表演

&nbsp;

好景不常

&nbsp;

這一陣子

&nbsp;

楊淑君的事鬧的沸沸騰騰

&nbsp;

所以

&nbsp;

這一次的表演非常不順利

&nbsp;

當蝶跟團友唱到BONAMANA的時候

&nbsp;

檯下就有人開始丟東西

&nbsp;

所以

&nbsp;

小瑑說最近暫時先不要唱有關韓語歌跟舞蹈

&nbsp;

年關將近

&nbsp;

蝶明年將犯太歲

&nbsp;

但

&nbsp;

太歲還沒到

&nbsp;

人就開始非常不順利

&nbsp;

無緣無故的皮膚嚴重過敏

&nbsp;

喝個東西而已

&nbsp;

也嚴重腹瀉

&nbsp;

足足在天母腹瀉了兩天

&nbsp;

前天

&nbsp;

剛回高雄而已

&nbsp;

就緊跟著嚴重感冒

&nbsp;

最近

&nbsp;

都鮮少接任何電話

&nbsp;

所以

&nbsp;

當吐司他們打給蝶的時候

&nbsp;

蝶都沒有接

&nbsp;

更沒有回

&nbsp;

一回高雄的時候

&nbsp;

卻聽到兩件不得了的消息

&nbsp;

第一件是吳員外被充了

&nbsp;

第二件是阿龍出大禍了

&nbsp;

難怪

&nbsp;

阿龍會打電話給蝶

&nbsp;

原來

&nbsp;

出了那麼嚴重的事情

&nbsp;

而這樣的事

&nbsp;

或多或少

&nbsp;

對蝶來說

&nbsp;

蝶多少都有些在乎

&nbsp;

就像前幾天磚磚說得一樣吧

&nbsp;

蝶能瞭解磚跟紫羚的想法

&nbsp;

但

&nbsp;

蝶卻不能

&nbsp;

也無能

&nbsp;

最近雖然總是靠著團表演

&nbsp;

才能多少糊口一些

&nbsp;

蝶很感謝大家的幫忙

&nbsp;

但

&nbsp;

也請大家原諒蝶的自私

&nbsp;

畢竟

&nbsp;

不同樣的兩個人

&nbsp;

永遠無法組成相同的夢境

&nbsp;
