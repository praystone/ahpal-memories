馬嵬坡來君賜死　玉消逝

&nbsp;

回眸前塵

&nbsp;

三千寵愛繫一身

&nbsp;

萬般無奈妒紅顏

&nbsp;

三回離君　每回總是歸君擁　自古以來誰了得

&nbsp;

紅顏本是貴妃命

&nbsp;

國忠原是丞相身

&nbsp;

生於太平年　亡於流竄

&nbsp;

安史之亂　誰人家中可安寧

&nbsp;

再次回首故往事

&nbsp;

虢國貴妃兩爭寵

&nbsp;

如今只聞虢國滅天倫

&nbsp;

當年一亂　如今以逝

&nbsp;

苦了玄宗夜夜淚

&nbsp;

若朝當初可了之　不知是否捧安祿

&nbsp;

但豈能怨天命　若門風不敗壞　門人不跋扈　今日何來斷君腸

&nbsp;

後續總言傳佳話　紅顏並非薄命身　只因金釵現世蹤　只是無法見芳魂

&nbsp;

聲聲句句話當時　

&nbsp;

故人以故

&nbsp;

猶記七月七日長生殿

&nbsp;

不見霓裳猶似羽衣舞

&nbsp;

空留傳奇不見景

&nbsp;

只留

&nbsp;

長安回望繡成堆　山頂千門次第開　 一騎紅塵妃子笑　無人知是荔枝來
