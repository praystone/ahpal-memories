前幾天

&nbsp;

心不知怎麼一回事

&nbsp;

忽然想再次到鹿港看一看

&nbsp;

從上次到鹿港至今

&nbsp;

少說也有八年多了

&nbsp;

就這樣的

&nbsp;

從屏東縣老家搭火車到了高雄

&nbsp;

再從高雄轉車到台中

&nbsp;

再慢慢的轉車到鹿港

&nbsp;

蝶一到鹿港

&nbsp;

就馬上到已經預約的二鹿行館放行李

&nbsp;

然後

&nbsp;

再四處的遊行

&nbsp;

到了辜政甫當年的老家

&nbsp;

也到了丁家大宅

&nbsp;

去了甕牆

&nbsp;

逛了天后宮

&nbsp;

走了九曲巷

&nbsp;

看了城隍廟

&nbsp;

遊了鹿港老街

&nbsp;

吃了蚵仔煎

&nbsp;

也表演了蝶的歌聲

&nbsp;

鹿港

&nbsp;

當年的一旅

&nbsp;

是來的好玩

&nbsp;

去的簡單

&nbsp;

如今

&nbsp;

卻是來的沉重

&nbsp;

去的

&nbsp;

也沉重

&nbsp;

但是

&nbsp;

地球或許真的很小

&nbsp;

蝶沒想到

&nbsp;

當逛到鹿港老街的時候

&nbsp;

會遇到建和

&nbsp;

要不是建和跑來找蝶的話

&nbsp;

蝶還真沒注意到他的存在

&nbsp;

哈

&nbsp;

連走到了鹿港

&nbsp;

妳的影子似乎也不放過我

&nbsp;

連這樣

&nbsp;

都能遇到妳和我當初的同事

&nbsp;

或許是自作孽吧

&nbsp;

這一次到鹿港來

&nbsp;

本來就想起妳曾經說過得話

&nbsp;

妳說

&nbsp;

妳母親是鹿港人

&nbsp;

蝶也曾經說過

&nbsp;

蝶會到遍曾經有妳的一切

&nbsp;

但

&nbsp;

沒想到

&nbsp;

卻會在這樣的機緣下

&nbsp;

遇到了建和

&nbsp;

妳彷彿如影如形的跟著蝶

&nbsp;

蝶

&nbsp;

也彷彿的跟著妳的影子

&nbsp;

呵

&nbsp;

或許

&nbsp;

真是孽緣吧

&nbsp;
