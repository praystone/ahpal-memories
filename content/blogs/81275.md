三天前

&nbsp;

剛從外地要回高雄的時候

&nbsp;

由於車速過快　加上自己沒專心

&nbsp;

所以

&nbsp;

就這樣撞上了別人的後車尾

&nbsp;

賠了人家四千

&nbsp;

不過

&nbsp;

還好對方沒受到傷害

&nbsp;

不然的話

&nbsp;

四千是賠不起

&nbsp;

倒是自己

&nbsp;

摔車後

&nbsp;

自己右半邊都是傷

&nbsp;

連左邊也有

&nbsp;

一回到家

&nbsp;

開個機

&nbsp;

誰知道電腦顯示卡壞了

&nbsp;

哈

&nbsp;

禍不單行

&nbsp;

自己又拖著都是傷的身體到了建國路買顯卡

&nbsp;

又花了三千九

&nbsp;

簡單的一天　花了快八千

&nbsp;

一拿起電話

&nbsp;

又發現電話在剛剛摔車中

&nbsp;

已經陣亡了

&nbsp;

又仔細看了一下車子

&nbsp;

棒阿

&nbsp;

龍頭都歪了

&nbsp;

不知道又要花多少了

&nbsp;

明年自己犯太歲副沖

&nbsp;

但是

&nbsp;

太歲還沒到

&nbsp;

就已經那麼麻煩了

&nbsp;

受了傷的自己

&nbsp;

沒人關心　也沒人問

&nbsp;

每天每天

&nbsp;

洗個澡

&nbsp;

都非常難過

&nbsp;

每天每天

&nbsp;

都必須拖著身體到電梯等著

&nbsp;

好讓自己到樓下７－１１買個煙

&nbsp;

受了傷的自己

&nbsp;

目前已經沒辦法跟團去駐唱了

&nbsp;

這個月的房租

&nbsp;

也差不多快要到了

&nbsp;

能怎麼辦

&nbsp;

自己早已經不知道該怎麼辦了

&nbsp;
