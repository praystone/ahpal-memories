試著去淡忘過去的點點滴滴

&nbsp;

但這樣的感覺卻始終揮之不去

&nbsp;

我還很想妳

&nbsp;

妳知道嗎

&nbsp;

現在的妳

&nbsp;

是否過的順心如意

&nbsp;

是否每天的妳都是開心

&nbsp;

拿起了電話

&nbsp;

不敢

&nbsp;

手始終不敢按出通話

&nbsp;

妳有妳的生活跟空間

&nbsp;

就這樣認了吧

&nbsp;

就這樣繼續孤單下去吧

&nbsp;

至少

&nbsp;

妳還有妳的幸福

&nbsp;

至少

&nbsp;

妳還能過的很好

&nbsp;

如果真有來生

&nbsp;

那麼請讓我不要再遇見妳

&nbsp;

因為

&nbsp;

痛那麼一次就夠了

&nbsp;

妳知道嗎

&nbsp;

現在的我

&nbsp;

已經不會再哭泣了

&nbsp;

真的不再會了

&nbsp;

只不過

&nbsp;

現在的我

&nbsp;

換了一顆心在哭泣

&nbsp;

人沒有

&nbsp;

但心卻有

&nbsp;

這樣的感覺好惆悵

&nbsp;

如果真有那麼一天

&nbsp;

妳如果回過頭來看看我

&nbsp;

請妳相信

&nbsp;

我還是在原地等著妳
