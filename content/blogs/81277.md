昨天跟今天都接到阿明跟吐司打來的電話

&nbsp;

如果

&nbsp;

早知道這是一個壞消息的話

&nbsp;

那麼早就不接了

&nbsp;

百家樂已經新開張了

&nbsp;

黃國榮當初答應的

&nbsp;

全都跳票

&nbsp;

黃國榮有把阿明．芯芮．吐司他們拉進去

&nbsp;

你好樣的黃國榮

&nbsp;

當初你一直借錢的時候

&nbsp;

自己總是沒第二句話借你

&nbsp;

如今你船過水無痕

&nbsp;

山不轉路轉

&nbsp;

從今爾後

&nbsp;

你就不要再來求援

&nbsp;
