過往故態已然雲煙散

&nbsp;

留酒一杯

&nbsp;

笑嘆今生何來緣中份

&nbsp;

似箭歲月

&nbsp;

白髮蒼蒼心不從人願

&nbsp;

孤守一人留空房

&nbsp;

寂靜聲　寂寥起

&nbsp;

過完今朝又一朝

&nbsp;

不知何去又何從

&nbsp;

人生不過百八十

&nbsp;

卻似千年般長久

&nbsp;

望月已盼

&nbsp;

見星尤憐

&nbsp;

睹物思親已成局

&nbsp;

何須再問心中情

&nbsp;

前塵如夢似

&nbsp;

半夢半醒了半生

&nbsp;

問君情歸處

&nbsp;

情歸夢裡舊人往

&nbsp;

問情君歸處

&nbsp;

只留一聲長嘆息

&nbsp;

百年孤寂

&nbsp;

只留一人常嘆息
