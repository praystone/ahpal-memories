月光

&nbsp;

隨這每天的月光去尋找

&nbsp;

尋找著回憶的點滴

&nbsp;

好讓自己安慰著不堪的方向

&nbsp;

夜歸

&nbsp;

是否是一種蕩漾的情懷

&nbsp;

彷彿嘗試著要去淡忘

&nbsp;

淡忘著夢醒後永恆太短暫

&nbsp;

悲鳴

&nbsp;

擁抱不住的靈魂

&nbsp;

徬徨的迷罔

&nbsp;

沒有把握的把握

&nbsp;

原來是一個終點的來臨

&nbsp;

甦醒

&nbsp;

摸不著頭緒的廝守承諾

&nbsp;

往事就像隨花凋零那般殞落

&nbsp;

舊有的一點點

&nbsp;

失去的一些些

&nbsp;

隨風而起的旋律

&nbsp;

想抓　

&nbsp;

卻怎麼也抓不住

&nbsp;

遺忘的夜晚

&nbsp;

人在　心不在

&nbsp;
