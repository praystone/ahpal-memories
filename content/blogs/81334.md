&nbsp;身為現代的國文老師，最痛苦的事情就是「批改作文」，學生字醜就算了！還會自己學倉頡「創字」，創字也就算了，還會用自己「奇怪的邏輯」寫句子，每次都改到「哭笑不得」........

&nbsp;

&nbsp;

【國中作文篇】&nbsp;

學生：元旦時，我們全家一起到歷史博物館參觀「兵馬桶」。

師評：有這樣的東西嗎？我也想去看看......(兵馬俑)

&nbsp;

學生：早上起床，整理「遺容」之後，我們到學校集合，搭車前往墾丁畢業旅行。

師評：老師怎一直都不知道？你家是哪一家殯儀館......(儀容)

&nbsp;

學生：昨晚，左眼皮跳個不停！當時就覺得那是「胸罩」，果然今早，皮夾就被扒走了！

師評：孩子，你已經這麼大了嗎？(凶兆)

&nbsp;

學生：報上說，重金屬汙染的牡蠣可「治癌」。

師評：一字之差，養牡蠣人家可翻身矣！那老師是不是該趕快去養牡蠣，會賺到爆....(致癌)

&nbsp;

學生：星期天準備外出逛街時，匆忙之間，不小心被「肛門」夾到。

師評：老師很好奇？不知道誰的肛門有這麼大....(鋼門)

&nbsp;

學生：我的歷史老師，長髮披肩、個子矮小、脾氣不好、有一點點「胸」.....

師評：孩子，歷史老師要我轉告你：「等下上歷史課，皮繃緊一點！」(兇)

&nbsp;

學生：平時，同學們表面上相處融洽，但私底下卻「勾心鬥腳」.....

師評：你們是在比長短嗎？(勾心鬥角)

&nbsp;

&nbsp;

【國小造句篇】

題目　其中

學生：我的其中一只左腳受傷了。

師評：你是蜈蚣嗎？

&nbsp;

題目　陸陸續續

學生：下班了，爸爸陸陸續續的回家了。

師評：孩子，你家到底有幾個爸爸啊？

&nbsp;

題目　難過

學生：我家門前，有條水溝很難過。

師評：老師－更難過！

&nbsp;

題目　....又.....

學生：我的媽媽又矮又高又胖又瘦。

師評：孩子，你的媽媽是變形金剛嗎？

&nbsp;

題目　你看

學生：你看什麼看？沒看過啊！

師評：沒看過....

&nbsp;

題目　好吃

學生：好吃個屁！

師評：孩子，有些東西是不能吃的。

&nbsp;

題目　果然

學生：昨天，我吃水果，然後喝冰水。

師評：這是詞組，不能分開的。

&nbsp;

&nbsp;

&nbsp;這些天兵、天將們，每個都是國家未來的棟樑？？？

但那些國文老師，每次改作文都改到快「往生」了！！！
