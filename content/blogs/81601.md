霧雨魔理沙（Kirisame Marisa/きりさめ まりさ）

東方系列第二主角，由於穿著黑白相間的衣服而號稱黑白，也正好與號稱紅白的博麗靈夢對應。
&nbsp;　　最早的名字叫霧雨魔梨沙（第三作才變為現在的名字，推測可能是同一人）。
&nbsp;
　　最初是紅發紫服的,第3作開始改金發,第5作改黑色服,舊5作時代的服裝比較像魔法使，現在有部分像女僕。 

　　居住於魔法森林的魔法使，常騎著掃把，喜歡蒐集東西，努力追趕不用修行也很強的靈夢。性格直率喜歡惡作劇，房間髒亂程度幻想鄉第一，和另一位魔法使愛莉絲來往親密但兩人總是爭執不斷。她時常帶著迷你八卦爐，雖小但火力驚人，可燒掉一座山。

&nbsp;　　東方系列游戲STG類的圖標都是魔理沙的頭像。
&nbsp;　　在永夜抄和愛麗絲組成“詠唱組”。

人物簡介

　　魔理沙是住在魔法之森的一位奇怪的魔法使。不過魔法使只是一種職業，她是人類。

&nbsp;　 身穿黑色的衣服，戴著巨大的黑帽子，常常去拜訪博麗神社。基本上不去人類的村落。

&nbsp;　 人類的村落裡有間大道具屋，她身為霧雨店的獨女，已經和那裡沒了聯系，舍棄了本家到了魔法之森的霧雨邸住下。（因為是私人問題，所以不詳細記述。霧雨家是不使用魔法道具的，大概就是這樣。）

　　她並不只是住在魔法之森，其實在經營著「霧雨魔法店」，只有和魔法有關就行。不過，要進入魔法之森並找到這家店是很困難的，無法了解她接受過什麼工作，而且從沒見過她工作的樣子。
　　努力追趕著即使不做修行也很強的靈夢。 不過和靈夢的勝負記錄大致上是靈夢領先。 
　　彈幕以星形彈和激光為主,可以用微型八卦爐射出魔炮「マスタースパーク」

性格

&nbsp;　 性格愛戲弄人，很難要她理解對方，但和她一起會很有意思，讓人心情愉快。
&nbsp; 非常喜歡惡作劇（把魔法用在對世界沒有幫助的方向），討厭輸，也討厭被人發現自己不服輸的性格，努力追趕著不用努力也能力很強的靈夢。

能力

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 能使用魔法。她善長於光和熱的魔法。口頭禪是『只有華麗並不是魔法，彈幕最重要的是火力DA☆ZE』
&nbsp;　 這樣說的她使用的魔法十分華麗，啟動的方式卻很通俗。
　&nbsp; 首先，魔法的原料是異常的蘑菇，只能到相應的地方去采摘。
　&nbsp; 再經過數日獨方調配的煮熬，煮成湯汁。
　&nbsp; 湯汁再加幾種材料調配，曬干成固體。
&nbsp;　 這樣魔法實驗才總算可以開始。將固體物加熱，變回山之水後，進行各種實驗。有時就能發動十分稀罕的魔法。

&nbsp;　 伴隨成功和失敗，之後繼續去采摘蘑菇，如此循環。
&nbsp;　 她的魔法外表看來華麗瀟灑，實際上是背後默默的努力堆積而成的。而且她不願被別人看到她努力的樣子。就像大型煙花一樣。

&nbsp;　　不過，人類能將魔法運用到這地步，是很少見的。她說這是魔法之森的影響。（將來說不定能成為[妖怪的]魔法使）

霧雨魔法店

&nbsp;　 她的正職。雖說如此，但從未見過她工作的樣子。
&nbsp;　她的家就是店鋪，不但處於容易迷路的魔法之森，而且很少在家。一點也不像在營業。!
　&nbsp; 店內凌亂不堪，可以說是一個小小的魔法之森了。
　&nbsp; 至於工作的內容，小至賭博的預言，大至幫忙解決異變，都是接受的範圍。
　&nbsp; 不過，見過她的魔法後，夏天煙花大會請她幫忙，也算是不錯的主意吧。
&nbsp;　 成功的話就拿下報酬，失敗的話則一文不取，意外地心腸不錯。

使用的魔法

&nbsp;　 雖說是魔法使，不過實際上她並不是什麼魔法都會用。
&nbsp;　 她的魔法，只有破壞物品的程度，受托的工作也多數和退治妖怪有關。因為她的魔法弱點少，對手無論是妖怪還是人類都很有效，所以純粹追求破壞力的話，無人能出其右。（在人類之中）

　　她常流連在神社，對於博麗巫女妖怪退治的請求，總是樂於接受。
&nbsp;　 她對於退治妖怪十分在行，特別是Spell Card規則成立時，那華麗的魔法就能發揮至極點。
&nbsp;　 她和巫女在妖怪退治上競爭，同時也在互相修行。

小偷事業

&nbsp;　 &nbsp;&nbsp; 她還有一項職業，就是偷盜。而且看來比店鋪還要熱心。
&nbsp;&nbsp;&nbsp; 她的行動方針是堂堂正正地闖進去，大大方方地說「暫時借走」。
&nbsp;　 特別是書類，她從來沒有罪惡感，很容易遭竊，因此紅魔鄉圖書館經常被她光顧。
&nbsp;　 雖說稗田家的《幻想鄉緣起》現時還沒有受害過，不過此書被她知道了話，也會有危險的。

道具

　　魔法使有時也會使用道具。
　　她使用的道具有魔法之帚、小火爐、自制魔導書等等。
&nbsp;　 魔法之帚是她自己的想法，魔法使必須有掃把在身邊。（其實不用掃帚也可以飛,只是她認為不用就不像魔女）

&nbsp;　 本來只是一把普通的竹帚，不過用多了之後，也受到影響，成長成了奇妙的掃把。
&nbsp;　 應該已經死去的木柄，在尾部似乎有繼續長葉，那和魔法是無關的。

&nbsp;　 火爐是她最大的武器，同時魔法實驗和料理都不可欠缺。
　　是一種幻想鄉中稀有的小型強火力道具。

&nbsp;　 魔力來自燃料，能夠調節成晚餐用的小火或者山火般的強火。
　　現在，她不用自制，香霖堂裡有售。
　　因為制作材料裡混入了外部世界的東西，所以它有著各種各樣的效果。

&nbsp;　 爐子的一角可以吹出風來，夏天避暑時可以使用。
　　拿著它就有了驅邪和使人走運的效果（也許吧）。
　　東方香霖堂第四話中緋々色金修復了它、因此不會生鏽。
&nbsp;　 此外，霖之助因為自己的興趣，給它增加了淨化空氣的能力。
　　發射戀色魔炮也要用到它。

　　無論魔法實驗成功與否，都會記載在魔導書上。
　　雖說有魔導書之名，實則上只是一本筆記簿而已。
&nbsp;　 大概是覺得魔法使得有一本魔導書吧。
　　還有就是，帽子中、裙子裡似乎藏有什麼東西。（藏有易燃物是很危險的）

二次設定補充

　&nbsp; 寒冷時（因為穿上了厚厚的衣服）能力會下降若干。

&nbsp;　 霧雨家的人好像都有著魔法使的血統。 魔理沙舍棄了本家、在魔法之森的霧雨邸住下了。 遠離人們的生活是魔法使的宿命。似乎很討厭自己家人，即使路過村落也不願去霧雨家一趟，在霧雨家唯一關系最親密的是霧雨家曾經的雇員——森近霖之助，經常和靈夢到香霖堂玩。

　　有收藏癖，經常從不知何處帶一兩件東西拿回家，不過從來不會對帶回家的東西加以整理，使得物品越來越多把家裡堆積的滿滿的，所以幻想鄉頭號髒亂差當數霧雨邸。關於“不知從何處帶一兩件東西回家”這一點要加以說明的就是，魔理沙最常光顧的地方是紅魔館尤其是圖書館（偷書+搞破壞），於是在與帕秋莉的無數次戰鬥中產生某種曖昧關系…………“我是人類你們是妖怪，妖怪壽命那麼長，我死了之後你們自己拿回去好啦！”（人類的生命和妖怪相比只是須臾一瞬）是其最著名的“借”東西不還的理由。

　　喜歡魔法之森生長的蘑菇，與同樣住在魔法之森的愛麗斯水火不容（但是也是有某種曖昧關系）。

　　經常和靈夢一起去香霖堂玩，在森近霖之助提起八雲紫的那一話有吃過醋，所以二次同人經常描寫出魔理沙和森近霖之助有戀人關系。

&nbsp;　　彈幕非常有力，代表性必殺技為戀符/魔炮master spark（與高町奈葉並稱動漫同人界兩大魔炮娘，一說她和高町奈葉同様喜歡以魔炮交心）。
　　後宮王,小偷.

　　後宮名單：愛麗絲·瑪格特羅依德 、帕秋莉·諾蕾姬、河城荷取（這三個已經在《東方地靈殿》曝光- -b）、博麗靈夢、芙蘭朵露·斯卡雷特、十六夜咲夜…………（另外與東方地靈殿裡的古名地戀也有後宮關系）

&nbsp;　 屁股是她的秘密武器（東方緋想天中可以用屁股來攻擊對手…………）

　　在惡搞向同人中會自稱為“蘑菇的專家”，自己種植蘑菇，無論吃火鍋還是燉菜都會加蘑菇進去，看到沒見過的蘑菇一定要嘗一嘗。

　　由於求聞史記中提到過“裙子下面好像藏了些什麼東西”，同人中有時會出現在衣服裡裝滿汽油彈的設定。《東方電氣笛》中出現過紅美鈴亂動她的帽子結果被炸倒的畫面。
