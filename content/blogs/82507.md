‧悲向，慎入


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;他是個被上天宣判沒有未來的小孩。


&nbsp;有著一頭白髮和一雙紅色的眼，身上環繞著類似蛇紋的印記……村莊的人們將他視為是不祥的人與徵兆。


&nbsp;人們感覺出來他的出現，會帶來可怕與死亡。


&nbsp;因為如此，沒有人願意和他講話、做朋友甚至是接觸。


&nbsp;他並不明白人們為什麼這麼做，也不想去弄清楚，他知道自己是多餘的，是被所有人遺棄的。


&nbsp;更重要的，他根本不了解為什麼要活下去。 


&nbsp;


&nbsp;


&nbsp;這段什麼都沒有的日子過了很久，直到有個誤走進村莊的女孩發現了他。


&nbsp;女孩有著和人們一樣的黑髮黑瞳，皮膚也沒有特別的印記，唯一不同的是女孩對他感到好奇。


&nbsp;他很清楚，女孩並不知道自己是『不祥之物』，只是被他的『特殊』所吸引而已。


&nbsp;


&nbsp;女孩待在村莊的時間很短暫，在她要離開時，說出了自己的名字。


「我叫沙布，那你呢？」


&nbsp;他不知道該怎麼回答……因為被遺棄的孩子是沒有名字的，如同他一般。


&nbsp;沙布看著他困惑的眼神，突然了解其中的意思……或許他沒有名字吧。隨後看了看四周，發現一朵紫苑花。


&nbsp;這朵紫苑花很像他，都是孤單一個人。


&nbsp;靈機一動，沙布指著紫苑花，對著他說：「你就叫做紫苑吧！好嗎？？」


&nbsp;他停頓了一下，才點了點頭說出「紫苑」兩字。


&nbsp;沙布笑著和他揮揮手道再見。


&nbsp;望著走遠的女孩，他只是口中念著「紫苑」沒有任何的動作。


&nbsp;


&nbsp;


&nbsp;人們最害怕的事情還是發生了。


&nbsp;這天，村莊發生離奇大火，許多村民根本來不及逃生就葬送在火窟。


&nbsp;隨著火勢越來越大，所有的一切也一一的被燒毀。


&nbsp;他呆站在一旁，不清楚發生什麼事，只看見火吞噬很多東西，聽到許多人尖叫與哭泣。


&nbsp;此時，活下來的人們注意到他的存在……沒錯，一定是他這個不祥帶來了火災！！


&nbsp;憤怒的村民對著他怒吼，甚至毆打他，發狂的將他追趕到離村莊不遠的斷崖才停下腳步。


&nbsp;他不懂人們怎麼了，只是害怕的一直退後。但卻因為一個不注意，他摔落了。


&nbsp;掉下去的同時，他發現那個為自己取名字的女孩在哭泣。沙布大哭奔向他，卻被人們攔下阻止……


&nbsp;他想開口，告訴沙布自己不要緊也希望她能聽見，但卻喊不出任何的聲音來。


&nbsp;為什麼會這樣、為什麼……他究竟……做錯了什麼？


&nbsp;


&nbsp;在重重的撞到硬物後，他睜大了眼睛。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;一位正在旅行的男子，碰巧的經過了村莊，看著村莊被燒毀的慘狀，他搖了搖頭。


&nbsp;如此的悽慘，火到底是怎麼引發的……雖然感到疑惑，但畢竟不干他的事，也沒必要知道太多。


&nbsp;正當男子要離開時，遠處有位女孩奔向了他，淚水不停流下：「請、請你救救他吧！！救救他阿！……」


「什麼？」男子不解的問。


「在崖下！……快點救他、請救救他……嗚！」女孩的嘴被急忙趕來的村民捂住，這樣的舉動讓男子感到怪異，便想開口詢問。


&nbsp;見狀，村民著急的說：「不、不好意思！因為村莊被燒毀了，這孩子似乎嚇到了，情緒有點不穩定，才會說那些話來，請您不要在意。」


&nbsp;看起來應該是他想太多了，但男子還是隨口問：「怎麼會發生如此嚴重的火災？」


「那個……火災的事可能不方便告訴您……」聞言，他也就不勉強村民了。


&nbsp;就在男子準備要走時，被捂住嘴的女孩始終盯著他不放……『崖下』是吧，他會去看一看在走的。


&nbsp;


&nbsp;他果真在村莊的不遠處發現了個斷崖。


&nbsp;如果女孩是想要他救掉下去的人，那根本是不可能的事，因為這崖摔下去必死無疑。


&nbsp;看呀看的，他什麼也沒發現。當他準備轉身離去時，卻瞄到有個人在崖下，而且還是個活人！


&nbsp;這還真是個奇蹟。


&nbsp;男子很驚訝卻也很好奇……從崖上掉下去竟然還能活著，這人究竟是何方神聖？


&nbsp;他小心翼翼的爬到下去，等到他到了地面站穩之後，眼前的孩子令他嚇著。


&nbsp;從那麼高的崖上摔落，這孩子沒有流血，甚至連一點傷也沒有。更奇怪的是，他的眼睛是瞪大的。


&nbsp;嚥下一口口水，男子抱起了他，努力的往上爬。


&nbsp;


&nbsp;


&nbsp;時間已經是晚上。


&nbsp;看著剛醒過來的他，男子遞了碗熱湯給他。


&nbsp;對於這個孩子，說實在的他還滿好奇的。或許就是因為這份好奇心，孩子才能得救吧，要不然以自己不想惹上麻煩的個性來說，就算這孩子在怎麼會創造奇蹟，也活不了。 


&nbsp;只是，打從孩子清醒後，就一直看著他……讓他有些不自在。


「可不可以不要在看我了。」


&nbsp;孩子先是愣了一下，才開口：「為什麼要救我？」


&nbsp;老實說，他不懂眼前的男人為什麼要救他。以前在村莊，人們是儘可能的想遠離他，甚至掉下崖，也沒有人去救他。


&nbsp;那為什麼這個人要救他？


「因為我想要救你，就只是這樣而已。」一開始男子傻住了，隨後笑著回答。


&nbsp;他還是不能理解男人的意思，於是又再問：「為什麼要救我？」


&nbsp;這次換男人不懂他的意思了，但男人依舊是微笑著：「你不希望我救你？」


「人們害怕我，所以不敢接近我。你不怕我嗎？」


&nbsp;聞言，男人懂了。雖然還是笑著對他，不過男人眼中卻流露出不尋常……這孩子真的令他很好奇。


「我會帶著你，你以後就跟著我走，知道嗎？」他點了點頭。


「對了，我是老鼠，你的名字？」


&nbsp;他頓時愣住了，因為自己是沒有名字的，正當猶豫著該怎麼辦時，他想起那位女孩和那朵孤單的花。


&nbsp;最後他下定決心，回答：「我叫做紫苑。」 


&nbsp;


&nbsp;


&nbsp;雖然說方才才剛清醒，不過還有很多事情紫苑不清楚。


&nbsp;比方說……像是自己從崖上摔落，為什麼連一點傷也沒有？還有那個老鼠，又是為了什麼而救自己？？


&nbsp;他是個不祥，他知道。村莊裡的火也是因為他這個不詳而引起的，他也知道。


&nbsp;但上天先是拋棄了他，在生死關頭時卻不准他死……


&nbsp;究竟他活下去的意義是什麼？


&nbsp;活下去……又為了什麼？？


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;在漆黑的世界，紫苑獨自一個待著。


&nbsp;不知道過了多久，有個小女孩的聲音從四面八方傳來。


『為什麼……你活下來了？』


&nbsp;紫苑愣了一下，接著搖搖頭：『我不知道。』


『為什麼你沒死？為什麼！？我的家人全葬送在你引發的那場大火裡……我的臉……我的臉、你看看我的臉阿……』


&nbsp;從黑暗中，那個女孩出現了，她沒有五官但臉卻有半張被火燒傷，還不斷著流著血水。


&nbsp;紫苑害怕的拼命後退……他不想看到這麼恐怖的景象……他不想。


『很可怕對吧？？因為你，我的臉變成這樣了──』女孩突然向前走，靠近了紫苑，接著說：『你必須贖罪。』


『我該用什麼來……贖罪？……』


『你這不詳，能贖罪的方式就是死亡！所以你必須死……反正你也不知道自己活著要幹麻，不是嗎？』


&nbsp;心頭一震，紫苑感覺自己的心好沉重……沉重的──


&nbsp;


『好想死。』


&nbsp;


&nbsp;


&nbsp;剛才在小睡時做了個夢，這個夢讓紫苑不舒服。


&nbsp;儘管是個夢，但所有的一切都是那麼都真實……女孩的樣子，還有她說的話。


&nbsp;沒錯……


&nbsp;身為不詳，自己能贖罪的方式就是死亡。&nbsp; 


&nbsp;他已經引發一場大火害的許多人喪生了，不能在這樣下去。自己不死掉的話，身邊的人……老鼠會有危險的！


「我必須死才行。」


&nbsp;望向四處，紫苑發現老鼠正在收拾東西，往旁邊一看，石頭上有一把小刀。那是老鼠煮晚餐切東西用的。


&nbsp;彷彿受人牽引，紫苑走向那把刀，並輕輕舉起……只要他死了，就沒人會受傷了。將刀子刺下去的話，一切就會結束了。


&nbsp;紫苑閉上了眼。


&nbsp;


&nbsp;──啪。


&nbsp;


&nbsp;瞬間，有人賞自己一個耳光，紫苑吃痛的跌倒在地，手中的刀也掉落。


「你到底在做什麼！？」老鼠很憤怒，幾乎是完全用吼的才把話說完……但紫苑並不懂，他明明是在幫老鼠脫離危險阿。


&nbsp;只要自己還活著，老鼠就會永遠陷入死亡遊戲當中。


「為什麼要阻止我？」


&nbsp;老鼠聽見後，先是愣了一下，接著抓起紫苑的衣領：「那你為什麼要尋死啊？！我問你！！」


&nbsp;狠狠瞪了紫苑一眼，老鼠不知道為什麼更加生氣了……拜託，別開玩笑了好嗎？方才才救他而已，沒想到他就急著去送死......搞什麼東西阿。


「如果我不死，你會有危險的。」聞言，他覺得紫苑在戲弄他……一個跌下崖的人，能對他做出什麼傷害？！


「你活著也不會妨礙到我好嗎？更別說是危險不危險的！！」老鼠憤怒的將話吼完，他不知道自己為什麼這麼的生氣……但卻也管不了這麼多了。


&nbsp;下一秒，紫苑很冷靜的說出了令他驚訝的話。


&nbsp;


「村莊裡的大火是我照成的、人們的死是我一手促成的。我是個不詳……不詳只有死亡可言，你知道嗎？」


&nbsp;──對紫苑來說，這是殘酷卻也是最真實的事。


&nbsp;


&nbsp;頓時，老鼠像是想起什麼。&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
