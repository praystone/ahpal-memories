(取自於伊莉討論區)



&nbsp; &nbsp; &nbsp; &nbsp; 天文藝術概念圖：這顆行星（Wasp 12b）（橙色）是目前人類發現的第一顆碳元素多于氧元素的星球，它主要由氫氣組成，是一顆像木星一樣的氣體巨星閤閨閣隤，蘊藏豐富碳元素、有著鑽石或石墨的星球。



&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 據大陸媒體12月9日報導，據英國廣播公司報道嵷嶊嶉嶄，一個由美國和英國天文學家組成的專家組宣稱，他們發現了首顆碳元素密度超高的行星。他們的發現將是對“鑽石星球”存在的有力證明。

&nbsp; &nbsp; &nbsp; &nbsp; 研究人員稱漟漺滼漜，這個發現證明，宇宙中確實存在蘊藏豐富碳元素、有著鑽石或石墨大陸的星球。領導此項研究的尼庫·麥杜蘇德漢（Nikku Madhusudhan）說：“你甚至可能看到完全由鑽石組成的山脈。”

&nbsp; &nbsp; &nbsp; &nbsp; 研究人員利用美國宇航局斯皮策太空望遠鏡墈墆墂墎，捕捉到了這顆距離地球1200光年的星球發出的熱輻射，並據此計算出它的大氣成分。倫敦皇家格林威治天文台的瑪瑞克·庫庫拉說：“這顆行星比其環繞運行的恆星暗數千倍，因此科學家們需要對它進行非常精密的測量，才能得出這顆特殊星球的組成成分。”

&nbsp; &nbsp; &nbsp; &nbsp; 這個被命名為Wasp 12b的行星是目前人類發現的首顆碳元素多于氧元素的星球，它主要由氫氣組成，是一顆像木星一樣的“氣體巨星”。但是其核心部分可能是由鑽石、石墨或者其他碳混合物組成的，並且可能是以液體形態存在的。

&nbsp; &nbsp; &nbsp; &nbsp; 科學家稱，在銀河系中應該有許多碳密度超高的行星。但是這些星球與地球不同，它們多是由鑽石或者石墨組成的。這也就意味著，那裏可能存在著鑽石形成的山脈、大陸塊，而沙土卻是稀有之物。麥杜蘇德漢教授認為，這種“鑽石星球”應該有很多。&nbsp;
