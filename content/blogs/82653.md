&nbsp;假日大雨，哪裡都不能去！打開電視，你會想看哪一類型的節目？

&nbsp;

A、新聞性節目

&nbsp;

B、美食型節目

&nbsp;

C、綜藝性節目

&nbsp;

D、旅遊型節目

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;選擇A的人　脫線罪

&nbsp;

你的精神渙散！經常會出現『脫線』的情形，遇到需要集中心力或做重要決策的時

&nbsp;

候，常會突然呈現失常或放空的狀態，

&nbsp;

和別人一起共事時，整個人也會「置身事外」，遇到緊急的狀況，也是抱持「漫不

&nbsp;

經心」的態度。

&nbsp;

這種不在乎、脫線的舉動，常令人覺得很傻眼！對你失去「信任感」。 

&nbsp;

&nbsp;

&nbsp;選擇B的人　貪吃罪 

&nbsp;

你天生就愛吃！喜歡到餐廳、小吃攤嚐鮮，遇到美食常控制不了自己，也不在意身

&nbsp;

材發胖的問題，任何稀奇古怪的食物都

&nbsp;

敢吃！甚至會趁朋友不在時，偷吃別人抽屜裡的點心或放在桌上的便當，有時還會

&nbsp;

靠大吃來發洩！經常「暴飲暴食」。

&nbsp;

在朋友眼中的你，是個超級『貪吃鬼』。 

&nbsp;

&nbsp;

&nbsp;選擇C的人　白目罪 

&nbsp;

你的個性天真無邪！卻不懂得「察言觀色」，有時候因為表現得『太白目』，不小心踩到別人的地雷，以致於周遭的人常

&nbsp;

被你整到哭笑不得！甚至被你氣到連一句話都不想說，但即使如此！你事後還是不知道，自己做了什麼事而得罪別人？

&nbsp;

朋友都認為你超級白目！實在是沒藥醫了。 

&nbsp;

&nbsp;

&nbsp;選擇D的人　懶散罪 

&nbsp;

你是自我控制能力較差的人，經常忘東忘西，東西拿到哪就丟到哪，雖然你覺得這

&nbsp;

樣是「亂中有序」，也清楚知道東西放

&nbsp;

在哪裡，但隨著雜物愈堆愈多，到最後連你自己都被埋在垃圾堆裡，周遭朋友都受

&nbsp;

不了你的『懶散』。

&nbsp;

建議你~還是改掉壞習慣，學習把東西收拾整齊，當個愛乾淨的人。
