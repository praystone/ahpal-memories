&nbsp;


選擇


&nbsp;


用酒麻醉自己


&nbsp;


掩飾那哭紅淚眼




&nbsp;


想不完的纏綿


&nbsp;


痛不醒的醉夢


&nbsp;


唱不倦的情話


&nbsp;


始終揮不去




&nbsp;


抹不去的記憶


&nbsp;


忘不掉的你


&nbsp;


原來真心還在你那




&nbsp;


讓我醉&nbsp; 讓我忘


&nbsp;


請你


&nbsp;


將真心寄還給我


&nbsp;


讓我醉&nbsp; 讓我飛


&nbsp;


還我原來的自我


&nbsp;


求你


&nbsp;


將癡情離開你的枷鎖


&nbsp;


讓心弦&nbsp; 不再撥弄




&nbsp;


明知相愛不能


&nbsp;


卻糾結在你的夢裡




&nbsp;


不斷滲透真心


&nbsp;


不斷夢醒醉夢


&nbsp;


愛終究夢一回


&nbsp;


痛卻不斷的夢
