二零一二天象 別錯過日環食及金星凌日

&nbsp; &nbsp; &nbsp; &nbsp; 又跨進新的一年，二零一二年的星象，有什麼值得天文觀星迷一定不能錯過的呢？臺北市立天文科學教育館彙整了二零一二年全年，重要的天文大秀，而今年最特殊的天象，首推五月二十一號上午的「日環食」、及六月六號的金星凌日。

&nbsp; &nbsp; &nbsp; &nbsp; 二零一二年，有什麼天象，是天文觀星迷一定不能錯過的？台北市立天文教育館表示，二零一二的天象，最特殊的當屬五月二十一號的日環食及六月六號的金星凌日，儘管這兩場天文大秀，並不容易觀測，因為日環食發生在日出之後，太陽的仰角相當低；金星則因為離地球遠，相對於太陽只是一個小圓點，凌日過程就只能看到一個黑點緩緩劃過太陽表面。不過這兩個天象，在意義上卻是相當不凡，因為日環食在臺灣地區已經數十年不曾出現，而金星凌日更是我們今生唯一的一次。另外二零一二的天象，還有六月四號黃昏月出時，可以觀賞到已經缺角的月偏食、及十一月二十八號到二十九號的半影月食，至於十一月十四號的日全食則完全不可見。

&nbsp; &nbsp; &nbsp; &nbsp; 其他例如流星雨、彗星、行星動態等天象，值得推薦的包括一月份的象限儀座流星群、五月五號的寶瓶座η流星群；八月十二號的英仙座流星群；十月二十一號的獵戶座流星群；及十二月十三號的雙子座流星群。

&nbsp; &nbsp; &nbsp; &nbsp; 行星動態方面，內行星的東、西大距與外行星的衝，都是觀察該行星的好時機。今年水星西大距分別在4月19日、8月16日以及12月5日；東大距在3月5日、7月1日、10月27日；其中以7月初為觀察水星的最佳時間。金星則在3月7日位在東大距、8月15日位在西大距；4月30日前後與7月中旬是金星在今年內視亮度到達最亮的時段。外行星部分，火星衝在3月4日；木星衝在12月3日；土星衝在4月16日；天王星衝在9月29日；海王星衝在8月24日。
