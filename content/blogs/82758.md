『和不一樣的人在一起，就會有不一樣的人生』，在現實生活中，你和誰

&nbsp;

在一起的確很重要，甚至能改變你的成長軌跡，決定你的人生成

&nbsp;

敗。 

&nbsp;

&nbsp;

「和什麼樣的人在一起，就會有什麼樣的人生」，和勤奮的人

&nbsp;

在一起，你不會懶惰！和積極的人在一起，你不會消沈！與智

&nbsp;

者同行，你會不同凡響！與高人為伍，你能登上巔峰！『態度

&nbsp;

決定一切』，有什麼態度，就有什麼樣的未來；『性格決定命

&nbsp;

運』有怎樣的性格，就有怎樣的人生。

&nbsp;

&nbsp;

有人說人生有三大幸運：「上學時遇到一位好老師，工作時遇

&nbsp;

到一位好師父，成家時遇到一位好伴侶」，有時他們一個甜美

&nbsp;

的笑容，一句溫馨的問候，就能使你的人生與眾不同，光彩照

&nbsp;

耀；生活中，最不幸的是由於你身邊缺乏「積極進取」的人，

&nbsp;

缺少「遠見卓識」的人，使你的人生變得平平庸庸、黯然失色！

&nbsp;

&nbsp;

&nbsp;

有句話說得好：「你是誰並不重要！重要的是你和誰在一起。」
