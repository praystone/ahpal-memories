2千年歷史萬神殿 不思議光影魔術

&nbsp; &nbsp; &nbsp; &nbsp; 羅馬著名的古蹟萬神殿，已經有兩千年的歷史，每年都吸引大批的觀光客到此遊覽。萬神殿除了外觀雄偉之外，內部其實也暗藏玄機。在屋頂的天花板上，有一個巨大的圓洞，在每年春分這一天，光線從圓洞，穿過拱門，直接射到正門口的廊柱前，就像是一個巨大的日晷，古羅馬人的智慧，真是不可思議。

&nbsp; &nbsp; &nbsp; &nbsp;氣勢雄偉的羅馬萬神殿，至今已有2000年的歷史，完美的建築設計，依舊令人嘆為觀止，前廊巨大的圓形石柱，象徵當時羅馬帝國的強盛。CNN記者尼克葛拉斯：「白色大理石基座來自希臘，在最頂端的大理石雕飾來自北義大利，柱體本身是花岡石製成石材來自埃及，想像一下，石材是怎麼運來的，穿越沙漠、海洋，在延著台伯河北上，都是來自一塊巨石每塊重約100噸。」

&nbsp; &nbsp; &nbsp; &nbsp;除了雄偉的外觀，走進萬神殿的內部，你才會了解這座建築的奇特之處，進入殿內視線立刻會被圓型的屋頂所吸引，米開朗基羅稱它為天使的屋頂，這個寬約九公尺的圓洞，就像一個圓形天窗，是室內唯一的光線來源，建築和天文學家，仔細觀察室內光線的移動，結果有了驚人的發現，他們認為萬神殿對古羅馬人來說，就像一個巨大的日晷。

&nbsp; &nbsp; &nbsp; &nbsp; 原來坐南朝北的萬神殿，是配合光線精心設計而成的建築，屋頂上的圓洞，有其特殊用處，CNN記者：「在秋天和冬天時，光線照射在圓頂的上半部，而在春天和夏天時，光線會往下移照射在地板上」，不過真正神奇的是，在春分這一天的中午12點整，光線會穿越正門口上方的柵欄，照亮前門的廊柱區域。

&nbsp; &nbsp; &nbsp; &nbsp; CNN記者：「春分這一天被認為是羅馬皇帝加入眾神的日子」，看看室內光影的移動，陽光照進室內就像是探照燈一樣，在正中午時，精準的照在，入口拱門的上方，CNN記者：「然後光線會穿過門上柵欄，最後在4月21日這一天光線會灑滿整個前廊，這一天據傳是羅馬落成的日子。」

&nbsp; &nbsp; &nbsp; &nbsp; 米蘭工業技術學院教授馬格利：「我們認為羅馬皇帝進入萬神殿時，就像被太陽所邀請似的太陽，在某種程度上就代表羅馬皇帝他自己，因為他已被光奉為神明」，兩千年來，日昇日落的規律不變，而美麗又莊嚴的萬神殿，在巧妙的精心設計下見證了大自然的奇妙，也讓人讚嘆古羅馬人不凡的智慧。
