&lt; rn&nbsp;


&nbsp;


明知道 你嚮往外面的世界 


&nbsp;


卻還是想把你強求在我身邊


&nbsp;


&nbsp;明知道 你超乎平凡的夢想 


&nbsp;


卻還是想破壞你的目標 


&nbsp;


明知道 關不住你的心


&nbsp;


卻還是希望你能改變想法


&nbsp;


明知道你過的並不快樂 


&nbsp;


卻還是希望你能留下來 


&nbsp;


就算是我自私也好


&nbsp;


霸佔也好 


&nbsp;


我就是不願意眼睜睜看著你走 


&nbsp;


可是你的眼神告訴我 


&nbsp;


你的悲哀和無奈 


&nbsp;


相見恨晚的結果 


&nbsp;


數不清我內心的辛酸 


&nbsp;


我的心真的好痛 好痛


&nbsp;


&nbsp;像一把刀插進我的心坎裡 


&nbsp;


當我決定把手放開的那一剎那


&nbsp;


看見你快樂的飛翔 


&nbsp;


而背後的我 


&nbsp;


眼淚卻已經不由自主的流下來.
