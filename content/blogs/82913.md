人生中的一道道門檻，邁過了就是門，邁不過就是坎。


&nbsp;


有的事情讓我們很無奈，有的事情讓我們很無助，有的事


&nbsp;


情讓我們很無語—不管遇到怎樣的艱難，能否挺過去，取


&nbsp;


決於對自己的信心。


&nbsp;


換個角度看問題，結果可能就會大不一樣：毛毛蟲所謂的


&nbsp;


世界末日恰恰就是蝴蝶破繭而出的充滿陽光的時刻。




&nbsp;


不喜歡就不要選擇，喜歡了就要堅持。


&nbsp;


在一起是一種緣分，不要輕易讓喜歡你的人哭泣傷心，好


&nbsp;


好珍惜在一起的每一分鐘，美好的回憶應該留給快樂和歡


&nbsp;


笑。


&nbsp;


無論遇到什麼事情，都不要輕易說你不喜歡我，不要輕易


&nbsp;


放棄我這段感情，因為，下一站的人未必比我好。


&nbsp;


好男人經得起誘惑，好女人耐得住寂寞。




&nbsp;


愛可以簡簡單單，但不能隨隨便便。


&nbsp;


驕傲的女人大都嫁給了卑微的男人，驕傲的男人娶的大都


&nbsp;


是卑微的女人。


&nbsp;


世間沒有美麗的天使，只有善良的女人。


&nbsp;


沒有不能在一起的兩個人，只有靠不攏的兩顆心。


&nbsp;


女人最大的驕傲不是她的長相有多出眾，而是她的男人有


&nbsp;


多疼她。


&nbsp;


如果可以，麻煩你做最真實的自己。




&nbsp;


那些說過的做不到的，沒有再追究，那麼，現在就說你能


&nbsp;


做到的，做你已經說過的。


&nbsp;


如果他註定是你的，你就永遠不會失去他，如果他不是你


&nbsp;


的，不論你用盡千方百計，仍然永遠得不到他。


&nbsp;


當你擁有適當的愛情，遇到適當的人，你們倆都會在適當


&nbsp;


的時候知道，彼此是天造地設的一對，會牽手走一生。 


&nbsp;


那個妙不可言的一刻，才是值得等待的，所以不要逼任何人。


&nbsp;


逼來的承諾是不可靠的。


&nbsp;


能夠慢慢培養的不是愛情，而是習慣。


&nbsp;


能夠隨著時間得到的，不是感情而是感動。


&nbsp;


所以愛是一瞬間的禮物，有就有，沒有就沒有。


&nbsp;


但反過來說，愛和婚姻實際並不是一回事情，並不是所有


&nbsp;


的愛情都要結婚的，也不是所有婚姻都有愛情的。


&nbsp;


有時候沉默真好，可以假裝什麼都不知道。




&nbsp;


心裏明鏡似的，但更知道不能把這種感覺說出來，神情中


&nbsp;


更不能流露出來，於是，便用沉默來防患未然。


&nbsp;


說太多，不如沉默。


&nbsp;


想太多，我會難過！


&nbsp;


生命真的很精彩，每一次的經歷，你可以從中體會到不同


&nbsp;


的感受，酸甜苦辣，只要這4種都經歷過了，才算是完整


&nbsp;


吧！


&nbsp;


而且每次的經歷你都可以從中看到不一樣的自己，從中看


&nbsp;


到自己的優點跟不足的地方，你會想著如何面對這些優點


&nbsp;


跟不足的地方。




&nbsp;


使你更多方面的瞭解自己，人生就是個瞭解自己的過程。


&nbsp;


這個世界其實是公平的。


&nbsp;


有選擇的機會就不應該輕言放棄，況且也狠不下心。


&nbsp;


過去就當醉了，醒來就繼續吧！


&nbsp;


逃避並不是解決問題的最好方法不是嗎？


&nbsp;


不被認可的現在不能說明未來，讓所有過去不值得的東西


&nbsp;


放下，將所有自以為是花開，不用難過，不必傷心，不必


&nbsp;


等誰心疼·······
