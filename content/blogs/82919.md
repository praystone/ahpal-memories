&nbsp;

&nbsp;

&nbsp;&nbsp; 











&nbsp;


我以為我可以輕意的說分手 


&nbsp;


面對你的眼睛卻無法開口


&nbsp;


看到你憂鬱的眼神


&nbsp;


眼與眼的相逢


&nbsp;


溫柔裡揉著酸楚


&nbsp;


別也悠悠留也悠悠


&nbsp;


我怕我的無意會傷害你


&nbsp;


我以為我可以洒脫的不回頭


&nbsp;


面對你的容顏卻心有不忍


&nbsp;


握著你溫暖的雙手 


&nbsp;


手與手的相牽


甜蜜裡摻著苦澀


&nbsp;


聚也依依散也依依


&nbsp;


我怕我的有意會刺痛你


&nbsp;


我以為我可以洒落艱難的不再見


&nbsp;


&nbsp;


面對你的溫柔卻情不由己


&nbsp;


心與心的相融幸福裡伴著淚水


&nbsp;


想也漫漫愛也漫漫


&nbsp;


我怕我的情意會讓你心碎


&nbsp;


我以為悄悄的躲避會是一種放鬆


&nbsp;


怎想看一眼傷更深一層


&nbsp;


你的溫暖讓我越陷越沉


&nbsp;


我以為默默的離去會是一種解脫


&nbsp;


怎奈走一步痛更深一步


&nbsp;


你的柔情把我越纏越緊


&nbsp;


你愛我很輕又很重輕的像空氣


&nbsp;


我依然承受不起


&nbsp;


任往事在心裡慢慢堆積


&nbsp;


越想忘記越想起


&nbsp;


重的更像空氣


&nbsp;


我仍然不能呼吸


&nbsp;


任回憶在心裡漸漸擁擠


&nbsp;


越想逃離越沉迷


&nbsp;


我以為把傷心留給自己你就不會心痛


&nbsp;


可是盼到朝霞傷了自己也痛了你


&nbsp;


我以為把憂愁留給自己你就不會愁苦


&nbsp;


可是守到日落愁了自己也苦了你


&nbsp;


情隔著玻璃 


&nbsp;


透明美卻無法觸及


&nbsp;


愛隔著心牆 


&nbsp;


想看清你卻難尋身影


&nbsp;


無奈的思緒困惑的感情


&nbsp;


驚醒了我的夢柔碎了我的心


&nbsp;


柔碎了心
