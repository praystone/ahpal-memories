戀人（六首）


&nbsp;

2012/1/27作者：沈眠

&nbsp;

&nbsp;1.
&nbsp;
有許多的動詞跟著妳
&nbsp;
持續地移轉位置
&nbsp;
某些很甜
&nbsp;
某些是悲傷的
&nbsp;
某些不能被言語
&nbsp;
妳一揮手
&nbsp;
它們便要重新排列
&nbsp;
為了接近妳
&nbsp;
而調整存在的質量
&nbsp;


2.
&nbsp;
戀人是我的城市
&nbsp;
我們是彼此永不離棄的雙子城
&nbsp;


3.
&nbsp;
這些
&nbsp;
擠壓交疊
&nbsp;
彼此干涉、指引
&nbsp;
宇宙撩亂
&nbsp;
的噪音
&nbsp;
都是我思念的形狀
&nbsp;


4.
&nbsp;
這是我的思念
&nbsp;
透明的噪音
&nbsp;
而重量
&nbsp;
完全
&nbsp;
不堪負荷
&nbsp;


5. 

我的甜女神
&nbsp;
剛剛穿過
&nbsp;
心中的蜂蜜
&nbsp;
留下
&nbsp;
一些夢境
&nbsp;
任憑我吸吮
&nbsp;


6.
&nbsp;
想寫出
&nbsp;
恰恰等於我經驗的總和
&nbsp;
的詩
&nbsp;
而妳
&nbsp;
恆大於它們
&nbsp;

&nbsp;
