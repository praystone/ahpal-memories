&nbsp;

那些錯過的遺憾


&nbsp;



&nbsp;



&nbsp;



生命中不經意的錯過，讓我們學會了等待，

&nbsp;

時間記錄了生命的軌跡，歲月輪迴中，

&nbsp;

我們走過了青春的一站又一站，

&nbsp;

暮然回首你會發現，在我們的生命中，

&nbsp;

總有許多錯過的遺憾，也正因為錯過了，

&nbsp;

反而變成了美麗的期待，期待著下一次的重遇。

&nbsp;

時間無情的劃過，記憶的影子越拉越長，

&nbsp;

那些擦肩而的過瞬間，凝結成了永恆的感傷，

&nbsp;

錯過的，總是最美的，失去的也總是特別懷念。

&nbsp;

&nbsp;

而心底的那份孤獨，

&nbsp;

在夜深人靜的時候才越加明顯，

&nbsp;

每次回憶過往總會深深自責，沉淪在遺憾的錯失中，

&nbsp;

痛苦折磨著期待，幻想著能有下一次的重來，

&nbsp;

決不讓錯過變成遺憾，

&nbsp;

可是記憶終歸替換不了現實，

&nbsp;

我們還要在寂寞中煎熬那份美麗的等待。

&nbsp;

&nbsp;

花兒的開放，

&nbsp;

讓我們感受了美麗的存在，

&nbsp;

可是如果在它快要凋謝的時候，

&nbsp;

才被發現錯過了最美的花期，

&nbsp;

心底便生出些許遺憾，因為我們錯過了美麗。 

&nbsp;

&nbsp;

一場電影的演出，

&nbsp;

讓我們體會了故事的精彩，

&nbsp;

可是在它快要演完的時候，才被我們收看

&nbsp;

錯過了它的故事情節，也便錯過了精彩的體驗。

&nbsp;

然而；錯過了月缺月圓，錯過了花謝花開，

&nbsp;

對我們來說並不會感覺出什麼，

&nbsp;

只能說會有些淡淡的失落，

&nbsp;

可是生命中錯過了，那個可能與你一生相守的人，

&nbsp;

那將是一輩子的遺憾，

&nbsp;

失去的痛楚會深深的刻在你的心裡，

&nbsp;

滲出血絲，滲出淚滴，而你，也只能將淚吞下，

&nbsp;

流在心底，慢慢將傷痕隱去。 

&nbsp;

&nbsp;

生命中我們會錯過許多，

&nbsp;

整理心情去期待下一次的相遇，

&nbsp;

也許下一個會是最好的開始， 

&nbsp;

感激那些美麗的錯過，正因為錯過了，

&nbsp;

才給了我們更多一次的機會，

&nbsp;

而這個機會或許會變成我們最期待的完美，

&nbsp;

讓錯過不再只是遺憾。&nbsp;


&nbsp;

&nbsp;
