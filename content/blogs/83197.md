什麽是緣？怎樣隨緣？


&nbsp;

&nbsp;


&nbsp;

&nbsp;


人生一世都是一個緣字....
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
佛渡有緣人： 我們生活在一個相對的世界裏，

&nbsp;

所以一切都是相對，而不是絕對。


&nbsp;

有因緣和合的生起、存在，

&nbsp;

自然也就有因緣離散的變異、壞滅。

&nbsp;

青年男女，互相愛慕，交往一段時間後，

&nbsp;

終於締結連理，這其間，

&nbsp;

自然有它的因，也有它的緣；

&nbsp;

相反的，夫婦交惡，爭執不斷，

&nbsp;

日久不能相處，終至異離，這也有他的因、有他的緣。

&nbsp;

好友意氣相投，合夥創業，有它的因緣；

&nbsp;

到了事業有成，彼此猜疑，終至折夥，也有它的因緣，

&nbsp;

所以、‘有因有緣世間集’，

&nbsp;

同樣的，‘有因有緣世間滅’。

&nbsp;

一切都是因緣，離開因緣，就沒有所謂宇宙與人生。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

隨緣，

&nbsp;

就是有不自我執著，不堅持己見的意思，

&nbsp;

我們與人相處，包括家人、親族、街鄰、朋友，

&nbsp;

以至於公司的同事，如果處處執著自我、

&nbsp;

固執己見，豈不是自尋煩惱？

&nbsp;

佛經上說：‘隨順眾生’——隨順別人，

&nbsp;

也是尊重別人的一種表現。

&nbsp;

隨順眾生，尊重別人，也是結善緣的一種方法。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 
緣有順緣、有逆緣；有善緣、也有惡緣。


&nbsp;

我們在生活過程中，隨順眾生，

&nbsp;

處處與人結善緣，自然會順緣多而逆緣少；

&nbsp;

反之，處處與人結惡緣，自然是逆緣多而順緣少了。

&nbsp;

命相學上的術語：

&nbsp;

你命中有貴人相助，或者說：你命犯小人。

&nbsp;

貴人相助，是我們多生多劫結的善緣；

&nbsp;

命犯小人，自然是過去結的惡緣了。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 

&nbsp;

我們常常說：

&nbsp;

‘隨緣、隨緣’，要能隨順緣，也要能隨逆緣。

&nbsp;

如果只能隨順善緣，

&nbsp;

不如我意的緣我就變了臉，那叫隨什麽緣？

&nbsp;

如果能隨順逆緣，

&nbsp;

則逆緣也能化為順緣，惡緣也能化為善緣。


&nbsp;

但是，隨緣不是隨波逐流，

&nbsp;

更不是同流合汙，在修持上要中心有主，不隨境轉，

&nbsp;

在生活上要隨順因緣，一切不勉強。

&nbsp;

至於其間的分寸，就要靠自己的智慧來抉擇了。
