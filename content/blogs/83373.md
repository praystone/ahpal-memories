1.”夢裡出現的人，醒來時就該去見他，生活就是那麼簡單。

&nbsp;

2.在愛情沒開始以前，你永遠想像不出會那樣地愛一個人； 在愛情沒結束以前，你永遠想像不出那樣的愛也會消失； 在愛情被忘卻以前，你永遠想像不出那樣刻骨銘心的愛也會只留淡淡痕跡； 在愛情重新開始以前，你永遠想像不出還能再一次找到那樣的愛情。

&nbsp;

3.雨就這麼一直下著，我就這麼一直望著。雨就這麼一直下著，我就這麼一直數著。等到天晴的時候，我一定要——到山上走走，到海邊玩玩，到花園看花，到果園摘果，去看看朋友，逛逛市集，曬曬棉被，也曬曬自己… …我一定要。——不要問我為什麼，就是喜歡！

&nbsp;

4.和朋友說＂再見＂就怕好久不見和親人說＂再見＂就怕下輩子見和討厭的人說＂再見＂就怕抬頭不見低頭見和戀人說＂再見＂就怕再見----- -

&nbsp;

5.我要留下昨晚做的夢， 把它保存在冰箱裡。很久很久以後的一天， 當我變成一個白髮老翁， 便要取出我凍結的美夢， 把它融化，把它燒開， 然後我就慢慢坐下， 用它來浸泡我的一雙蒼老冰冷的腳。
&nbsp;

6.有一天，我帶瞭望遠鏡啟程。一路上，我用眼睛就能看清前方。某一天，我回過頭，卻發現起點已經不見。我開始拿起望遠鏡拼命的眺望。——其實，想看清未來，並不需要望遠鏡，我帶瞭望遠鏡，是為了回望路途的艱辛。只有回味了來時的“艱辛”，才能懂得珍惜現在“位置”。

&nbsp;

7.旅行讓人有一種生命延長的感覺，它是一種精神的長壽。

&nbsp;

8.來我懷裡，或者讓我住進你的心裡。默默相愛，寂靜歡喜。



9.地球是圓的，有些看上去是終點的地方，也許只是起點。

&nbsp;

10. 那一年，我花二十五塊錢給單車安了個後座。於是，我有了女朋友。我載著她去了很多地方，許下了很多不著邊際的誓言。我以為，這就是浪漫。後來，我拆了後座，載她去了更多的地方。風輕輕揚起她的長發，輕輕吹走了我的誓言...並不是每個女孩都喜歡浪漫，她們喜歡的，是你的幼稚.

&nbsp;

11.：“看一個人的心術，要看他的眼神。看一個人的身價，要看他的對手。看一個人的底牌，要看他身邊的好友。看一個人是否快樂，要看他清晨夢醒時的表情。看一個人的胸襟，要看他如何面對失敗以及被人出賣。”

&nbsp;

12.有一天，我看到一個人站在山頂，不知道高處的那個人看到了什麼，我很好奇，我相信他下來以後會給我描述他看到的一切：風的味道、雲的質感、還有遠方的霞光……可是我還是想自己爬上山頂，因為有些事必須自己去體會，就像有些人必須自己去了​​解一樣。

&nbsp;

13. 【有味·語錄】世界上​​最遠的距離， 是我站在你的面前，你卻不知道我愛你。世界上最遠的距離，是想你痛徹心脾，卻只能深埋心底。世界上最遠的距離，是尚未相遇，便注定無法相聚。世界上最遠的距離，是魚與飛鳥的距離，一個在天，一個卻深潛海底。——原來，海鳥跟魚相愛，永遠只是一場意外。

&nbsp;

14.有些人的生命沒有風景，是因為他只在別人造好的，最方便的水管裡流過來流過去。你不要理那些水管，你要真的流經一個又一個風景，你才會是一條河。By 蔡康永《有一天啊，寶寶！》

&nbsp;

15.：“喜歡自己，因為你是今生的唯一；善待自己，你將獲得對自己的認同和理解；只有愛自己才能更好的給予他人，讓別人喜歡自己！”

&nbsp;

16.：“聯繫我們的不是愛而是恐懼，也許正是因為這個原因，我才如此愛你。

&nbsp;

17. 儘管人群擁擠，每個人都是沉默的，孤獨的。對世界和對自己的評價不能正確地交錯吻合。我們不是生活在被毀壞的世界，而是生活在錯亂的世界。我們就像被遺棄的孩子，迷失在森林裡。當你站在我面前，看著我時，你知道我心裡的悲傷嗎，你知道你自己心裡的悲傷嗎？

&nbsp;

18.：“人與人的關係很謔畫：有的人與人相見恨晚，有的人與人相見恨早，有的人與人根本不該相見，有的該相見卻緣慳一面——陰錯陽差，怎麼也見不著。”（BY 李敖）

&nbsp;

19.生命中有一些人與我們擦肩了，卻來不及遇見；遇見了，卻來不及相識；相識了，卻來不及熟悉；熟悉了，卻還是要說再見。——對自己好點，因為一輩子不長；對身邊的人好點，因為下輩子不一定能遇見。

&nbsp;

20.：“真相、真相，你們每個人都希望真相，但真相和謊言一樣地骯髒。
&nbsp;

21.：前面的路還很遠，你可能會哭，但是一定要走下去，一定不能停。

&nbsp;

22.陪伴於男女之間的，起先是愛慕之神，然後是歡愉之神，然後是睡神，然後是孤單。

&nbsp;

23.：“我以為人們在每一期都可以過有趣而且有用的生活。我們應該不虛度一生，應該能夠說，'我已經做了我能做的事'，人們只能要求我們如此，而且只有這樣我們才能有一點快樂。

&nbsp;

24.每個人都有自己的幸福，仰望別人的幸福時，別人也在仰望你的幸福。難得糊塗，容易幸福；過於較真，容易煩惱。能終日快樂，就實現了生命最大的價值。

&nbsp;

25.：“我們，不要去羨慕別人所擁有的幸福。你以為你沒有的，可能在來的路上，你以為她擁有的，可能在去的途中……有的人對你好，是因為你對他好。有的人對你好，是因為懂得你的好！”

&nbsp;

26. 人生最寂寞的事：1、想對著喜歡過的人笑，結果卻笑著哭了出來。2、夜晚一個人面對黑暗和寂寞。3、看見穿著情侶裝的戀人牽手經過。4、有一堆明明不敢面對，卻又不捨得刪除或者銷毀的照片。5、看見似曾相識的一個背影。6、做夢夢見心愛的人，醒來卻只有自己一個人。7、想念對方的時候，對方卻不知道。

&nbsp;

27.：“我們要學會珍惜生活的每一天，因為這每一天的開始，都將是我們餘下生命之中的第一天。”

&nbsp;

28.：“如果你失去了太陽，你還有星光的溫暖；如果你失去了愛情，還有朋友的關愛；如果你失去了生命，你將擁有大地的親吻！”

&nbsp;

29.：“有的人你看了一輩子，卻忽略了一輩子；有的人你看了一眼，卻惦念了一生。”

&nbsp;

30.時間一天天過去，有時覺得它漫長難熬，有時卻又感到那麼短促；有時愉快幸福，有時又悲傷惆悵。一天與一天不同，一日和一日有別，彷彿一晝夜之間也有春夏秋冬之分。

&nbsp;

30.我最想旅遊的地方，我暗戀者的心。

&nbsp;

31. 不要想如果，生命中不可承受之情，就在於人生沒有重來的機會。如果當初如何如何，現在就不會怎樣怎樣。每一個岔口的選擇其實沒有真正的好與壞，只要把人生看成是自己獨一無二的創作，就不會頻頻回首。——人生只售單程票，過去的就過去了，更重要的是走好後面的路，收藏好沿途的點滴。

&nbsp;

32.傳說摩天輪的每個盒子裡都裝滿了幸福。當我們仰望摩天輪的時候， 就是在仰望幸福

&nbsp;

33.：“小時候，幸福——是件很簡單的事；長大後，簡單——是件很幸福的事。”

34.我獨自坐著；夏季的白晝在微笑的光輝中逝去； 我看見它逝去，我看著它從迷漫的山丘和無風的草地上消失。(BY艾米莉·勃朗特)

35.陌生人，我喜歡你如此靜靜地站立在你攜帶著的光的強度裡。

&nbsp;

36.：“你問我愛你值不值得，其實你應該知道，愛就是不問值得不值得。

&nbsp;

37. 那一瞬間，你終於發現，那曾深愛過的人，早在告別的那天，已消失在這個世界。心中的愛和思念，都只是屬於自己曾經擁有過的紀念。我想，有些事情是可以遺忘的，有些事情是可以紀念的，有些事情能夠心甘情願，有些事情一直無能為力。如果愛你是我的劫難，我卻開始嚮往飛蛾，撲向烈焰。

&nbsp;

38.有人把朋友都留給了我,然後就自顧自的消失了.我可以理解成他不想與我有任何關係嗎?（不是埋怨是很淡定的在說）

&nbsp;

39.遇到你真正愛的人時：要努力爭取和他相伴一生的機會。因為當他離去時，一切都來不及了；遇到可相信的朋友時：要好好和他相處下去。因為在人的一生中，可遇到知己真的不易；遇到曾經愛過的人時：記得微笑向他感激，因為他是曾經讓你更懂愛的人。

&nbsp;

40. 上段戀情,全心投入,結果重傷.於是這次戀愛怕受傷,就很保留。這意味著:上次那個傷你的爛人,得到最完整的你,而這次這個發展中的情人,得到個很冷淡的你。我知你是保護自己,但這若是做生意,你這店一定倒的。永不再來的惡客,得到最好服務,而新客上門,卻備受冷落,這店怎麼不倒?
