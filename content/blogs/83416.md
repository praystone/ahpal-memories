有人問蝶

&nbsp;

你是一隻什麼樣的蝶

&nbsp;

那麼蝶便來作一個回應

&nbsp;

也算是來到亞寶的自我介紹好了

&nbsp;

蝶在網路上一律都自稱蝶

另一個名稱是舞癡癲

而蝶是簡稱

全名叫罪孽之蝶

所以在伊莉的時候

蝶都會另一旁打上罪孽之蝶四字

&nbsp;

而真實的世界裡

蝶真正的名稱叫月

蝶的相本中

鹿港之旅-月

就是蝶本人

所以在生活跟工作裡

蝶的家人跟同事都叫蝶為月

像是林小月．阿月仔

&nbsp;

但是蝶在伊莉的時候

蝶是把所有有關自己的照片都封鎖起來

不對外開放

所以鮮少有人看過蝶的樣子

在亞寶這邊對外開放

算是蝶神經秀逗了吧

&nbsp;

蝶高一八零剛剛好

重八十嘟嘟好(應該有點過重才是)

長的不好看

&nbsp;

蝶是一隻情緒化的蝶

時而高興

時而悲傷

這一秒高興

下一秒翻臉不認人

&nbsp;

也因為這樣

所以蝶好友名單內

常常不超過三十五個以上

都維持在二十幾個左右

原因很簡單

不常聯絡的

只是加好玩衝人氣的

為了偷菜偷寵物的

蝶一律刪了再說

&nbsp;

蝶是隻急性子的蝶

所以很多事

蝶會當下要得到一個結果與答案

&nbsp;

而目前的蝶算是邁入了中年

因為已經三十一了

&nbsp;

蝶的愛車是野狼

蝶非常酷愛騎野狼

可能被偶像劇害的

&nbsp;

蝶一般不太愛看無聊的戲劇

而最近卻非常迷大陸劇

要是蝶的首頁MV出現的是什麼戲劇的歌曲

那麼表示蝶很迷這部

&nbsp;

蝶一開始出現的部落格是奇摩交友

但是有一天帳號被盜了

於是轉戰到無名

後來嫌太麻煩而退出

因緣巧合的情況下

蝶進入了伊莉部落格

開始了漫長的兩~三年部落格生活

&nbsp;

所以蝶所有的文章跟相本都在伊莉

算是蝶所有的一切故事

包含了蝶的失戀

蝶的工作

蝶的無奈

還有蝶去玩過的地方

都會貼一些照片

或是寫一些文章在裡面

&nbsp;

而文章蝶鮮少轉貼

一般都喜歡自己創作

&nbsp;

但目前蝶在亞寶的權限不夠

所以蝶還沒有把所有的文章跟照片轉來這邊

&nbsp;

而個人動態裡的文章

都是蝶自己寫完而自己又喜歡的文章

算是蝶非常驕傲的作品

當然

這些作品是個人滿意

不代表全天下都要喜歡

&nbsp;

蝶大約就是一隻這樣的蝶

&nbsp;
