愛情就像乘法，其中一項為零，其結果永遠為零…… 


&nbsp;


不要相信日韓肥皂劇中所謂的因為不能讓彼此幸福而離開。 


是否想過，你們正是對方的幸福。 


愛不是逃避，是努力。 


不是逃避著給彼此幸福的責任，而是努力的實現讓彼此幸福的義務。 


當你說離開是為了不讓對方受到傷害的時候，你已經給對方造成了最大的傷害。 


愛就是要努力在一起。


&nbsp;



不要因為害怕彼此離開而體諒。 


體諒是因為愛，而不是因為恐懼。 


愛是一種責任，不可以輕易的離開。 


讓你為離開而恐懼的人，算不上愛人，就算付出再多，要離開的人，終究是會離開。 


&nbsp;


&nbsp;


不要覺得不瞭解也會有愛情。 



在不瞭解的時候，我們僅僅是喜歡，達不到愛情。 


當彼此的缺點暴露出來以後，很多時候這喜歡也就會結束了。 


愛是寬容，愛著彼此的一切。 


愛上不瞭解的人，或許，你愛的只是他的新奇罷了。 



&nbsp;


不要相信對你說不介意你跟異性過於親密的人。 


這樣的人不是騙你就是在玩你，或者根本就不在意你。 


你會不介意你的愛人和異性親密到忘記你存在的地步麼？ 


想想就知道了。或者，他本身就不介意在幾個異性之間周旋。 


&nbsp;


&nbsp;


不要在幾個異性間周旋。 


愛情是2個人的存在，容不下第三個人。 


凡是覺得可以左擁右抱的無非是網上言情小說看多的人。 


愛情是專一的，請記好。 


&nbsp;


&nbsp;


不要給彼此太多的壓力。 


適當的和異性保持距離，對你們的愛情是有好處的。 


過近的距離，也許會在不經意間，做出讓彼此難堪的舉動。 


&nbsp;


&nbsp;


不要去欺騙你的愛人。 


記得，若你沒有騙他一輩子的把握，那麼便對他說實話。 


當謊言一再被揭穿的時候，有可能一切都結束了。 


&nbsp;


&nbsp;


不要覺得樣貌會成為很大的障礙。 


60年後，有沒有人能沒有皺紋，沒有白髮？誰又能不變衰老，不變矮小。 


也許你沒有貌，但你有才。也許你沒有才，但你溫柔。也許你沒有溫柔，但你....... 


也許你什麼都沒有，但是也許，他正愛著你的平凡。 



&nbsp;


不要把周圍的環境看的太重。 


談戀愛的是你們，和周圍的人又有什麼關係。 


但是請善待彼此的家人，朋友。很多東西，只是給自己的借口罷了。 


&nbsp;


&nbsp;


不要輕易許下承諾。 


做不到的承諾，比沒許下更可惡。 


也許很多男女都喜歡那一張張空頭支票， 


但當你發現每一張都不能兌現的時候，你還會愛著這個騙子麼？ 



&nbsp;


不要認為他愛你便不會離開你。 


在你的一再傷害下，他也會離開，因為你不懂得珍惜，不值得他去愛。 


懂得珍惜，才能懂得愛情。 


&nbsp;


&nbsp;


不要因為衝動說一些過激的話。 


沒有人願意拿熱情換冷漠，拿體貼換傷害。 


衝動的話語，也許已經傷透了他的心。 


釘下一顆釘子容易，但是拔起它，你是否能修復好柵欄上的洞呢？？ 


如果你已經說了，那麼請道歉，用你的溫柔去盡量彌補，只是是否有用就無法確定了。 


&nbsp;



不要玩失蹤。 


動輒無故失蹤十天半個月的人，很難給人安定的感覺。 


也同樣會讓人為你的安全而擔心。 


不要去踐踏自己的尊嚴。你可以沒有他，但不能沒有自己的尊嚴。 


記得，他不愛你，你做什麼他都看不到。 



&nbsp;


不要給不愛的人任何希望。 


希望越大，失望就越大。也許你只是喜歡被人愛的感覺吧， 


但是當失望來臨的時候，你也許會因為你的貪婪，而被對方厭惡。 


&nbsp;


不要後悔。 


不管做了什麼選擇，是不是正確的選擇。 


請不要後悔。時間不可能倒流，每個人都要為每個人的過錯承擔責任。 


很多時候，錯過的就再也回不來了。


&nbsp;



愛情就像乘法，其中一項為零，其結果永遠為零…… 



即使輸掉了一切，也不要輸掉微笑…… 


即使我們的「愛情」夾雜著欺騙，懷疑，徘徊，傷害…… 



也讓我們微笑著說：謝謝！謝謝你陪我一路成長……
