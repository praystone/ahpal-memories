藥師如來，不可思議！——請看我的求職、中獎奇遇<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


作者：吃虧波羅密多


&nbsp;


我2004年畢業，在學校時就接觸了佛法。2005年春節過後到東莞找工作，當時住在大嶺山，我哥就在那上班，我哥為我租了個房子，我在這房子裏住了三個月，平時上上網吧，吃住上網費用全我哥出。


&nbsp;


由於在學校時學習不好，還大二時做過傳銷（學費都虧進去了），幾乎荒廢了學業（要不是畢業時念地藏名號，可能連畢業學位證都拿不到）。


&nbsp;


在東莞找工作期間，常去智通人才市場，但從不敢投簡歷，因為知道自已有多少墨水。在此期間也常頌經念佛念咒，但好像一點用也沒有，當時心亂如麻，也不知道如何是好。


&nbsp;


一日，我在紙上寫上諸佛菩薩名號、經咒，誠心誦念地藏菩薩名號，自問“欲求工作當念何佛何咒何經”之後，拋手中寫有佛菩薩名號經咒的紙張，後拾起一張，上面寫著“藥師琉璃光如來”。


&nbsp;


菩薩要我當誦藥師佛名號？——我當時不解，我平常多念地藏，為何不拾得地藏菩薩而是藥師佛？後來誦《藥師經》才知，這是與藥師如來所發大願有關。


&nbsp;


既然拾得“藥師如來”，我便得專注念藥師佛名號，並且念《藥師經》，當時發願：願能找到工作與我專業相合，工資我能接受的，最好老闆也是信佛的。


&nbsp;


&nbsp;


就這樣，我天天老實念誦藥師如來名號。


&nbsp;


一天，“感覺到”今日應去人才市場看看，於是到了“智通人才”，見到一家企業要求不高，便投了份簡歷，與那位主管談得很歡。


&nbsp;


次日，便到公司面試去，公司大門竟然寫著“南無阿彌陀佛”六個字，這讓我大吃一驚。


&nbsp;


經過簡單面試後，主管決定用我，工資也很好，主管說：遺憾的一點是，這個廠每到初一、十五兩日，食堂只有素菜吃。


&nbsp;


他看我疑惑的樣子，解釋說：老闆及老闆娘是佛教徒，在臺灣及馬來西亞建了很多廟。


&nbsp;


上班幾天後，老闆決定親自培養招來的幾個人，於是我便有更大機會學習了。當工作快到年底時，廠裏要辦年終晚會，獎品豐富。


&nbsp;


在距離年終晚會前三天時，我對同事說：我將會在晚會上抽獎得到一輛自行車。當時，同事都只是笑笑，因為廠裏有幾千員工，沒那麼容易，又誰都想抽得10000元大獎，誰在乎你那輛自行車呢？


&nbsp;


當時我想要自行車，是因為我們廠距銀行太遠了，公車也不方便，每次給家人、給孤兒院寄錢很麻煩，如果有輛自行車就方便多了。


&nbsp;


到了年終晚會那晚，人山人海，喧鬧聲不絕於耳，我則照舊念藥師如來名號。


&nbsp;


當電子顯示牌有我名字時，我便到領獎處領獎。發獎人笑著說：你得到了一輛上等的自行車。


&nbsp;


當我把自行車推到同事面前時，我想他們都很驚詫吧。


&nbsp;


雖然已過去幾年了，現在念佛也很懶，但想到此事，還是很有感觸、心中充滿溫暖的。


&nbsp;


&nbsp;


南無藥師琉璃光如來！
