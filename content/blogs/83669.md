生活簡單就是幸福！


&nbsp;


&nbsp;


　　現代人每天生活在紛繁、複雜的社會當中，緊張、高速的節奏讓人難得有休閒和放鬆的時光。人們在奮鬥事業的搏鬥中深感身心的疲憊。


&nbsp;


然而，如果你細心觀察，你會發現作為現代人，其實人們每天都在盡可能的放鬆自己，調整生活節奏，追求充實快樂的人生。看似紛繁的社會裡，人們的生活方式其實也不複雜。


&nbsp;


大家在忙忙碌碌中體味著平凡的人生樂趣。由此我悟出一個道理，那就是----生活簡單就是幸福。


&nbsp;


　　生活簡單就是幸福。一首優美的音樂、一支喜愛的歌曲，會讓你心境開朗。你可以靜靜地欣賞你喜愛的音樂，可以在流蕩的旋律中回憶些什麼，或者什麼都不去想；


&nbsp;


你可以一個人在房間裡大聲的放著搖滾，也可以在網上用耳麥與遠方的朋友靜靜地共享；你還可以一邊放送著音樂，一邊做著家務....


&nbsp;


　　生活簡單就是幸福。一杯清茶，或一杯咖啡，放在你的桌邊，你的心情格外的怡然。你可以瀏覽當天的報紙，瞭解最新的國內外動態，哪怕是街頭趣聞；或者捧一本自己喜歡的雜誌、小說，從字裡行間獲得那種特別的輕鬆和愉悅....


&nbsp;


　　生活簡單就是幸福。經過精心的烹製，一桌可心的菜餚就在你的面前，你招呼家人快來品嚐，再備上最喜歡的美酒，這是多麼難得的享受！


&nbsp;


　　生活簡單就是幸福。春暖花開的季節，或是清風送爽的金秋，你和家人一起，或是朋友結伴，走出戶外，來一次假日的郊遊，享受大自然帶給你的美麗、芬芳。吸一口新鮮的空氣，忘卻都市的喧囂，身心彷彿受到一番洗滌，這是一種什麼樣的輕鬆感受！


&nbsp;


　　生活簡單就是幸福。你參加朋友們的一次聚會，那久違的感覺帶給你溫馨和激動，在觥酬交錯之間你享受與回味真摯的友情。朋友，是那樣的彌足珍貴....


&nbsp;


　　生活簡單就是幸福。週末的夜晚，一家老小圍坐在電視機旁，盡享團圓的歡樂....


&nbsp;


　　......


&nbsp;


　　現代人越來越會生活，越來越會用各種不同的方式來放鬆自己。垂釣、上網、打牌、玩球、唱卡拉OK、下棋.....不一而足。


&nbsp;


人們根據自己的興趣愛好尋找放鬆身心的最佳方式，在相對固定的社交圈子裡怡然的生活，而且不斷的擴大交往的圈子，結交新的朋友.....


&nbsp;


　　有時，你會為新添置的一套漂亮時裝而快樂無比；有時，你會為孩子的一次小考成績優異而倍感欣慰；有時，你會為剛參加的一項比賽拿了名次而喜不自勝；有時，你會為完成了上司交給的一個任務而信心大增.....


&nbsp;


　　生活簡單就是幸福！


&nbsp;


　　生活簡單就是幸福，不意味著我們放棄了對目標的追逐，是在忙碌中的停歇，是身心的恢復和調整，是下一步衝刺的前奏，是以飽滿的精力和旺盛的熱情去投入新的「戰鬥」的一個「驛站」；


&nbsp;


　　生活簡單就是幸福，不意味著我們放棄了對生活的熱愛，是於點點滴滴中去積累人生，在平平淡淡中尋求充實和快樂。


&nbsp;


　　放下沉重的負累，敞開明麗的心扉，去過好你的每一天。


&nbsp;


　　生活簡單就是幸福！
