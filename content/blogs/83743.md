いろは


作詞：rino／作曲：rino／編曲：大久保薰／歌：CooRie


差し出した心を色付けた
敞開的心扉變得五彩繽紛


&nbsp;

そう　君のその優しさって
沒錯　這就是你的溫柔


&nbsp;

早起きした朝の雫みたい
宛如清晨的朝露一般


&nbsp;

光へと吸い込まれそうなんだ
融入耀眼的陽光之中


&nbsp;

ふとした時に気付くもの
在不知不覺中發現


&nbsp;

居場所も探してた私ここにいたい
東奔西走尋覓的我　這裡才是容身之所


&nbsp;

愛と言う日々が生まれてく
愛在此每天萌芽


&nbsp;

今この一瞬が続いてく
此刻將會成為永遠


&nbsp;

大切な場所がここにある
心目中的聖地在此


&nbsp;

だから行くよ
因此我來了


&nbsp;

高い壁を見上げてないで
站在高牆下束手無策之時


&nbsp;

よリ道だって楽しい
繞道自有其中的趣味所在


&nbsp;

そう思える日々でいられるように
如此般快樂的度過每一天


&nbsp;

私は歩いて行ける

我繼續前行

備長炭 是由Alchemist企劃，把備長炭萌擬人化後的作品。原作作者及人物設定為江草天仁，於2003年推出日本漫畫。2006年改編為12集的電視動畫，並於2007年推出遊戲。劇中登場的人物的名稱皆與「炭」有關。
