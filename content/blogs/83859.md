智慧人生


&nbsp;


&nbsp; 你如果非常崇拜釋加牟尼、柏拉圖、莊子、黑格爾之一類人物，那麼你肯定欣賞智慧人生了。智慧人生是一種哲人的人生，其生命的快樂來自於對宇宙、對世界上萬事萬物、對生命本身的思考和感悟。 


&nbsp;


&nbsp; 這種思考和感悟會通過一種宗教、一種哲理、一種思想、一種人生觀，表達出來，這就是智慧的快樂；如果這種思考和感悟受到壓抑，不能得到正常表達，那就是智慧的痛苦。智慧人生就常常在這二者之間搖動，飽嘗人生地獄和天堂的滋味。


&nbsp;


&nbsp; 智慧人生是一種無與倫比的活法。


&nbsp;


&nbsp; 智慧人生的動力來自生命本身的最高要求。智慧是心靈的光輝，它照耀著生命本身，因此，生命本身有了光亮，才有了靈魂和眼睛。否則，生命只是運動而已，只有流動而沒有靈性，只有浪花而沒有光亮。


&nbsp;


&nbsp; 因為這靈性，因為這光亮，智慧人生開始出發，尋找生命的源頭，探索生命的意義，反思生命的存在，於是生命開始有自我感覺，開始意識到自我的存在，開始自覺地把自己檢討、完善和提升。 


&nbsp;


&nbsp; 智慧把生命提升到自覺。生命本身不再寂寞，也不再盲從，因為有智慧和人生結伴而行。


&nbsp;


&nbsp; 智慧的開墾地是未知。未知猶如那浩渺天際的星河，其中閃爍著無數熠熠生輝的星座；那星座就是真理，它們是那麼遙遠，那麼可望而不可及，但是它們就是智慧的嚮往，智慧的心儀。


&nbsp;


&nbsp; 智慧把這一切托負給了生命，於是生命燃起智慧的燭火，投入到那漫漫的星河之中，尋覓真理的星座。智慧人生並不佔據真理，只是不斷和真理交接，其最輝煌的時刻就是心靈之光與真理之光的碰撞和交匯，它們互相映照，光芒四射，不僅能夠照亮生命的蹤跡，而且能夠把光輝撒向世界，在萬事萬物上引起回光映照。


&nbsp;


&nbsp; 這就是智慧人生的價值。


&nbsp;


&nbsp; 正是為了這價值，人生負起了重擔，智慧找到了知音。智慧人生在探求「為什麼」「怎麼樣」「是什麼」的道路上樂此不疲，嘔心瀝血，最後的報答則是永恆和無窮。
