幽默人生


&nbsp;


&nbsp; 生活不能缺少幽默，而幽默人生則是生活的一種極致。尤其在現代社會中，無人不喜歡幽默、嚮往幽默和追求幽默。


&nbsp;


據說，歐美的女子選擇愛人，條件可能多種多樣，但不變的一條就是幽默。不管怎麼說，和一個幽默的人生活在一起，那簡直是無與倫比的幸福。


&nbsp;


&nbsp; 有人說，幽默是一種才華，一種力量，一種高度文明的象徵。


&nbsp;


&nbsp; 還有人說，幽默是一種引發喜悅和快樂的源泉，是人獲得精神快感的一種行為方式。


&nbsp;


&nbsp; 又有人說，幽默是一種人生智慧和技巧的最高表現，是協調自我和社會關係的靈丹妙藥。


&nbsp;


&nbsp; 更有人說，幽默是一種人生的藝術，它能夠使你笑口常開，青春永駐。


&nbsp;


&nbsp; 這些都沒有錯。


&nbsp;


&nbsp; 但是，我說，幽默就是一種高級人生，而且是一種能把自己和他人從尷尬境遇中解救出來的人生。


&nbsp;


&nbsp; 實際上，人生不僅存在著多種艱難、多種坎坷和多種冒險，而且會遇到各種各樣的尷尬。尷尬會使你進退兩難，尷尬會使你失掉機會，尷尬會使你掉架，尷尬會使你優雅不來，尷尬會使你活得不舒服，不自在，不瀟灑。 


&nbsp;


&nbsp; 只有幽默能把你救出來，只有幽默。 


&nbsp;


&nbsp; 幽默不單單是引人發笑，而且帶給人們心理上一種輕鬆和快慰。幽默是對他人一切過失的原諒，是對周圍環境的喜劇式調侃，也是對自我困境的一種自嘲和解脫。


&nbsp;


幽默絕對是善意的，絕不加雜半點惡意，相反，它是對惡意的一種消解和抹平。 


&nbsp;


&nbsp; 幽默的基礎是寬容和理解，寬容和理解這世界上的一切人，一切事，包括你自己，人才能幽默，才有幽默。


&nbsp;


所以，幽默首先需要很高的修養和健康的心態。人要活得不低俗，不粗野，不偏激，不苛刻，幽默才能稱得上幽默，否則就很容易走向諷刺。諷刺沒什麼不好，但是它不是幽默。


&nbsp;


&nbsp; 至於幽默人生需要智慧則不言而喻，不過，它不是在生活中「耍小聰明」，而是一種心智的神奇能力，一種把玩生活的爐火純青。


&nbsp;


正因為有了幽默，人才能夠在笑聲中克服恐懼、憂慮和尷尬，才能夠愉快地接受人生最後的悲劇。
