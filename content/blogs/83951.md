簡單做人---生活不需要「構思過度」 


&nbsp;


簡單才是真實，平淡才能恆久。就像朋友，能靜靜地聽完你的傾訴，不露痕跡地安慰你，像冬天裡的大衣，只要在身邊，就能感覺到溫暖。 


&nbsp;


　　生活不需要"構思過度" 


&nbsp;


　　這個世界很簡單，複雜的只是人心而已。人心其實也不複雜，只要別構思過度就行。 


&nbsp;


　　余秋雨說："我們的歷史太長，權謀太深，兵法太多，黑箱太大，內幕太厚，口舌太貪，眼光太雜，預計太險。因此，對一切都'構思過度'。" 


&nbsp;


　　受這種思維的影響，原本單純的孩子們早早地背負了"世界比你想像的還要複雜"的重殼，還未出校門就對社會產生了巨大的畏懼感，害怕自己無法適應這個"複雜"的社會。


&nbsp;


於是在長輩師長的諄諄教導下，心懷不安地開始鑽研《厚黑學》、《老狐狸經》、《人際關係學》、《處世哲學》等眾多權謀圖書，知道了對所處的環境要"眼觀六路，耳聽八方"，對朋友、對同事"逢人且說三分話，不可全拋一片心"，對謀事要"三思而行"等道理。


&nbsp;


做事處處設防，處處怕被人算計，整日小心謹慎地生活。刻意地與人拉開距離，孤獨無依，也不敢依。 


&nbsp;


　　這種小心謹慎、戰戰兢兢的心理使我們有限的生命變得沉重，不僅增加了無謂的時間成本，也間接地加大了事業的信譽成本，使生命的質量大打折扣。 


&nbsp;


　　事實上，我們並不需要想那麼多，想那麼遠，更沒必要把自己變成一個不停運轉的機器。我們只需要靜下心來，讓思維跟生活變得有條理、有順序，簡單與愜意的生活就會自主向我們走來。 


&nbsp;


　　不久前，有一位老領導，將他一生中所有的經驗教訓總結為簡單的四句話，告訴了他即將走入職場的兒子。 


　　第一句話："不要盤算太多，


要順其自然。"做人不要盤算太多，只要自身努力夠了，就不要拚命去求人，有時想得越多，心越急就越得不到回報；等你不想的時候，它反而會自主來到你身邊。有些潛規則與不能把握的東西，還是順其自然。該是你的東西終歸是你的，不要太強求。 


&nbsp;



第二句話："壓抑自己沒必要，奉承巴結也沒必要"。農村與城市、下屬與上級、窮人與富人不可能對等，壓抑自己完全沒有必要。相對於趾高氣揚的人，你再怎麼尊重他，他也不會平等對你。


&nbsp;


你再怎麼奉承、巴結，他也永遠不會因為同情而施捨你。不管出身低微，還是處境艱難，都不要寄希望於他人禮遇。


&nbsp;


當說時就說，當做時就做，只要別心虛和畏首畏尾，就不會讓人輕易看不起，而你也將贏得更多平等的機會和尊重。 


&nbsp;


　　第三句話："不要對誰特別好，也不要對誰特別不好。"物以類聚，人以群分。任何單位，任何群體，人際關係結構都離不開"三三制"，具體到個人身上就是三分之一的人對你一般，三分之一的人對你不"感冒"，三分之一的人對你好。


&nbsp;


這與我們常說的"三分之一的人在干、三分之一的人在看、三分之一的人在搗蛋"同理。所以，必須因人而異，好的要保持，中立的要爭取，敵意的要寬容。永遠不要被少數人利用。 


&nbsp;


　　第四句話："相信自己比依賴別人重要"。一個人，必須要有思想，有社會責任感，相信自己比依賴別人重要。不同的人做事肯定不一樣，上司一般都會看出來的。只要盡心盡力做事，就不會被埋沒。


&nbsp;


除非你對自己的能力有懷疑。關鍵是要擺正心態，有機會時就為社會多做點兒什麼，沒機會時要記住"為自己打工"，積累更多的有形無形資本。為自己做再多的事情也不過分，不論人生際遇如何，及時努力都不會錯。 


&nbsp;


　　很多時候，很多東西，非要親身經歷了，才更貼近真實，才會發現，真的沒必要太刻意地做一些，想一些事情。厚黑學之類的東西，並不是萬金油，貼在哪裡都管用。生搬硬套反倒容易給人邯鄲學步的感覺，徒增了不少尷尬。 


&nbsp;


　　世界上的真理永遠都是樸素的、自然的、簡單的。仔細研究一下現代成功人士的道路，就會發現，他們的共同點就是：簡單行事且極具思想。 


&nbsp;


　　其實，越好的團隊越會憎恨消耗內部戰鬥力的爾虞我詐。阿里巴巴總裁馬雲就直接告訴新來的員工，要是誰想違背"簡單"的公司文化，挑起辦公室政治煙火，沒別的話好說，立即走人！為了打擊辦公室政治，馬雲甚至在公司內部開展"延安整風運動"。 


&nbsp;


　　簡單出精英，簡單出實效。正如一則廣告所說的：把簡單的東西複雜化--太累，把複雜的東西簡單化--貢獻。世界比我們想像的要簡單，不要總是人為地給它徒添累贅。 


&nbsp;


　　簡單做人，就是對這個世界、對自己最大的貢獻。
