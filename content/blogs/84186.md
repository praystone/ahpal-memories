深思的一句話。。。。。。


&nbsp;




　　1.等待你的關心，等到我關上了心。 


&nbsp;


　　2.走完同一條街,回到兩個世界。 


&nbsp;


　　3.想你的時候有些幸福，幸福得有些難過。 


&nbsp;


　　4.你是我猜不到的不知所措，我是你想不到的無關痛癢。 


&nbsp;


　　5.所謂最難忘的，就是從來不曾想起，卻永遠也不會忘記 。 


&nbsp;


　　6.誰把誰真的當真，誰為誰心疼。 


&nbsp;


　　7.多謝你的絕情，讓我學會死心。 


&nbsp;


　　8.當眼淚流下來，才知道，分開也是另一種明白。 


&nbsp;


　　9.我真的愛你，閉上眼，以為我能忘記，但流下的眼淚，卻沒有騙到自己。 


&nbsp;


　　10.有時，愛也是種傷害。殘忍的人，選擇傷害別人，善良的人，選擇傷害自己。 


&nbsp;


　　11.人生最遺憾的，莫過於，輕易地放棄了不該放棄的，固執地，堅持了不該堅持的。 


&nbsp;


　　12.臉上的快樂，別人看得到。心裡的痛又有誰能感覺到。 


&nbsp;


　　13.不要輕易說愛，許下的承諾就是欠下的債！ 


&nbsp;


　　14.不是不死心是死不了心。 


&nbsp;


　　15.痛過之後就不會覺得痛了，有的只會是一顆冷漠的心 。 


&nbsp;


　　16.真心離傷心最近 。 


&nbsp;


　　17.我想哭，可是我已經不知道該怎麼流淚了。 


&nbsp;


　　18.在原諒與絕望之間遊蕩，唯一的感覺是傷　傷　傷！ 


&nbsp;


　　19.思念一個人的滋味，就像是喝了一杯冰冷的水，然後一滴一滴凝成熱淚。 


&nbsp;


　　20. 喜歡一個人沒有錯，錯就錯在喜歡一個不喜歡自己的人。 


&nbsp;


　　21.無法拒絕的是開始 ，無法抗拒的是結束。 


&nbsp;


　　22.等待.....也許並不容易；傷害......卻輕而易舉。 


&nbsp;


　　23.人生若只如初見,當時只道是尋常 


&nbsp;


　　24.對自己好點，因為一輩子不長；對身邊的人好點，因為下輩子不一定能夠遇見！ 


&nbsp;


　　25.對不起是一種真誠，沒關係是一種風度。如果你付出了真誠，卻得不到風度，那只能說明對方的無知與粗俗！ 


&nbsp;


　　26. 如果你知道去哪﹐全世界都會為你讓路。 


&nbsp;


　　27.我喜歡你，很久了，等你，也很久了， 現在，我要離開，比很久很久還要久...... 


&nbsp;


　　28. 純，屬虛構 。亂，是佳人。 


&nbsp;


　　29.一個人只有一個心臟，卻有兩個心房。一個住著快樂；一個住著悲傷。不要笑得太大聲，不然會吵醒旁邊的悲傷。 


&nbsp;


　　30.世界上最遠的距離 不是樹與樹的距離 而是同根生長的樹枝 卻無法在風中相依 


&nbsp;


　　31.蘋果最光輝的一刻就是砸在牛頓頭上！ 


&nbsp;


　　32.愛情使人忘記時間，時間也使人忘記愛情。 


&nbsp;


　　33.分手就是不愛了，那些冠冕堂皇的理由，不是想讓對方好過，而是想讓自己好過點！ 


&nbsp;


　　34. 生活累，一小半源於生存，一小半源於攀比。 


&nbsp;


　　35.不要讓太多昨天佔據你的今天！ 


&nbsp;


　　36. 如果說美貌是推薦信，那麼善良就是信用卡！ 


&nbsp;


　　37. 不吃飯的女人這世上也許還有好幾個，不吃醋的女人卻連一個也沒有。 


&nbsp;


　　38.失去的東西，其實從來未曾真正地屬於你，也不必惋惜。 


&nbsp;


　　39. 無論多豪華的婚禮都不代表幸福婚姻，兩個人終生相處和睦與否和筵開幾席、多少首飾全無關聯。 


&nbsp;


　　40.如花美眷，也敵不過似水流年 


&nbsp;


　　41. 廣告就是告訴別人，錢還可以這麼花 


&nbsp;


　　42.小三，除法中的餘數而已 


&nbsp;


　　43.人生的大部分時間裡，承諾同義詞是束縛，奈何我們嚮往束縛。 


&nbsp;


　　44.力的作用是相互的，除了愛情的力量。 


&nbsp;


　　45. 許多人在重組自己的偏見時，還以為自己是在思考。 


&nbsp;


　　46.生活中有太多無可奈何的選擇。社會就像江湖，總是讓人身不由己，言不由衷。 


&nbsp;


　　47.我們都是遠視眼，模糊了離我們最近的幸福。 


&nbsp;


　　48.原來那麼愛我的你和那麼愛你的我都停滯在曾經的時候,愛情就結束了. 


&nbsp;


　　49.你若先走了，轉身時就不要怪我也在背對著你 


&nbsp;


　　50.只要你的腳還在地面上，就別把自己看得太輕；只要你還生活在地球上，就別把自己看得太大。 


&nbsp;


　　51. 如果你要考驗我的耐心，請先把你的耐心準備好。 


&nbsp;


　　52. 每個人都是單數...來時是...去時也是..... 


&nbsp;


　　53.在我們的愛情裡，我一直扮演愛你的角色，分手時別問我為什麼分手，問問你自己。 


&nbsp;


　　54.人生---下課啦..放學啦..放假啦..畢業啦..混夠啦..老啦..後悔啦..死啦... 


&nbsp;


　　55.不能在一起就不能在一起吧,其實一輩子也沒那麼長... 


&nbsp;


　　56.古時候就有外星人的記載，因為丈二和尚摸不著頭腦 


&nbsp;


　　57.一個人身邊的位置只有那麼多,你能給的也只有那麼多,在這個狹小的圈子裡,有些人要進來,就有一些人不得不離開 


&nbsp;


　　58.很多人，因為寂寞而錯愛了一人，但更多的人，因為錯愛一人，而寂寞一生 


&nbsp;


　　59.你可知 上天是不公平的 你可以選擇 愛我 或者 不愛我 而我卻只能選擇 愛你 或者 更愛你 


&nbsp;


　　60.人人都覺得永遠會很遠 其實它可能短暫得你都看不見 


&nbsp;


　　61.媽媽說人最好不要錯過兩樣東西,最後一班回家的車和一個深愛你的人 。 


&nbsp;


　　62.時間仍在，是我們在飛逝。 


&nbsp;


　　63.我允許你走進我的世界,但不許你在我的世界裡走來走去.. 


&nbsp;


　　64. 我愛你時，你才那麼閃耀，我不愛你時，你什麼都不是 


&nbsp;


　　65.一路上總有一些人一些事讓你失望透頂,何必在一棵樹上吊死呢?其實一轉身就是好大的森林... 


&nbsp;


　　66.純粹的甜是給傻瓜和孩子準備的. 


&nbsp;


　　67.不要那麼相信回憶,裡面的那個人,不一定同樣想你.
