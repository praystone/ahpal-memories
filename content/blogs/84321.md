&nbsp;




&nbsp;




我用慢火熬煮，燉煮著一鍋暖暖的感情。


&nbsp;


我用溫暖的心，釋放光芒注射入你身邊。


&nbsp;


&nbsp;


沐浴著久違的陽光，舉起了顫抖的雙手，


&nbsp;


試圖想要抓住點什麼，然而雙手像沙漏，


&nbsp;


時光依然，從指縫間無情地流散，流逝。


&nbsp;


&nbsp;


輕鬆地閉起眼睛，安撫我們曾破碎心靈，


&nbsp;


輕聲細語地告訴自己：抵禦著不要害怕，


&nbsp;


想取悅別人，你越在乎別人，就越卑微。


&nbsp;


&nbsp;


日月風霜迎晨曦，清澈潺流的細細纏綿，


&nbsp;


是暖了你的心，暖了曾冰泠寒涷的感情。


&nbsp;


&nbsp;


因為珍惜，我們不再隨意發洩， 珍藏著，


&nbsp;


然後理智地傾訴；用溫暖 凝視這個世界。


&nbsp;


&nbsp;


舞台再大，人走茶涼，再走出一個故事，


&nbsp;


寧靜，才看清一切，放下，才展翅高飛。


&nbsp;


&nbsp;


自由的心態與寬廣的胸襟，點燃著希望，


&nbsp;


就教會了你愛與被愛的人，暖了你的情。


&nbsp;


&nbsp;


幸福其實很簡單，可以隨時隨信手拈來，



是一個意象，是一個心情，一個的安心。


&nbsp;


&nbsp;


流淚了，就為自己把淚擦乾，之後勇敢，


&nbsp;


心痛了，就為自己療癒傷痛，之後堅強。


&nbsp;


&nbsp;


生命的體驗，經歷過人生的百般的滋味，


&nbsp;


請你也小心翼翼的去熬煮一鍋暖暖的情。


&nbsp;


&nbsp;


暖了心，也暖了情，小心別燙了你的嘴，


&nbsp;


滿滿愛，是暖情的溫床，感動來自生活。
