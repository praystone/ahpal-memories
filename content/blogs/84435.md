&nbsp;


&nbsp;


&nbsp;


人生路上，有多遠走多遠


&nbsp;


那是一條茫然無邊的路


&nbsp;


那是一條沒有歸宿的路


&nbsp;


那是一條無所謂坎坷與平坦


&nbsp;


無所謂【痛苦】與【歡笑】的路


&nbsp;


從來到這個世界上的第一天起


&nbsp;


你就馱著先輩沉重的囑託上路了


&nbsp;


走過春季，你燦爛如花


&nbsp;


走過夏季，你眼含熱情


&nbsp;


走過秋季，你滿面沈思


&nbsp;


走過冬季，你身披風雪，滿懷滄桑


&nbsp;


&nbsp;


&nbsp;


&nbsp;






&nbsp;


&nbsp;


&nbsp;


&nbsp;



歲月用不同的形式，溫暖也錘煉著你成長


&nbsp;


成長是為了走更長更遠的路，有時為了達到一個目標


&nbsp;


你不得不架橋，乘船，但就是不能停下來


&nbsp;


一直走下去，便是人生的全部含義


&nbsp;


誰都不喜歡曲折，但誰都是從曲折中走過來


&nbsp;


失敗的路是曲折的，迷茫的路是曲折的


&nbsp;


走向成功與勝利的路，又何嘗不是蜿蜒崎嶇的呢


&nbsp;


曲折是路的性格，曲折是生活給我們的啟示


&nbsp;


&nbsp;


&nbsp;


&nbsp;



&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;



&nbsp;一生平坦，不能說就是幸福


&nbsp;


一生坎坷，也不一定就是不幸


&nbsp;


沒有經歷過曲折，卻實在是一種遺憾


&nbsp;


所以


&nbsp;


不能因為明天的分離，你就放棄了今天的諾言


&nbsp;


不能因為冬天的寒冷，你就永遠停留在春的驛站


&nbsp;


只有歷盡坎坷與曲折，你才能真正懂得人生的意義


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;






&nbsp;


&nbsp;


&nbsp;


&nbsp;



茫然的時候總喜歡回首


&nbsp;


那時，所經歷的點點滴滴便在風的吹動下


&nbsp;


漸漸連成一幅畫面


&nbsp;


但是你只能看，卻不能重新踏入


&nbsp;


人生，是一條無限延伸的路


&nbsp;


如果，一味沈緬于冰冷的過去


&nbsp;


你怎能不容顏憔悴，又怎能不留戀不前



&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


既然，注定要經歷那麼多的艱難和坎坷



那麼，就把這一切當作人生路上的風景



一路走過，一路欣賞，一路收藏，一路遺忘



讓我們的心有如大海，容納你無法改變的一切



讓我們的心堅如鋼鐵，去戰勝你能戰勝的一切



這樣，在每天的清晨



都會看到太陽下你的飛揚背影



又走在一條嶄新的路上


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;




&nbsp;


&nbsp;




&nbsp;


&nbsp;


選擇，是生命賦予我們每個人的權利



只是，這個權利對於我們來說，太沉，太重



一次選擇，往往會決定你的一生



我們無法把握選擇，



但我們可以把握選擇後的過程 



人生的路，可以走的充實，也可以走的寂寞



所以，你若珍惜生命，



就必須珍惜自己走過的每一步 



這樣，在你驀然回首的時候才會發現



原來，一切都已經在不知不覺中跨越



而前方的不遠處，


&nbsp;


又一幅美麗的畫卷正在為你徐徐地展開



&nbsp;



&nbsp;


&nbsp;


如果問我，人生的路到底哪裡才是盡頭，


&nbsp;


&nbsp;


我會回答不知道



如果問我在這條路上還要走多遠



我會告訴你︰



只要生命存在，有多遠，走多遠
