App好幫手 解決生活怎麼辦

&nbsp; &nbsp; &nbsp; &nbsp;2012台北電信應用展正在台北展演二館熱鬧登場，其中「Apps行動遊樂園」專區展出多款由國人自行開發的行動智慧App應用，發想創意與生活實用密切結合，相當有趣。

&nbsp; &nbsp; 「App行動遊樂園」整合44家App廠商展出共計233款應用服務產品，涵蓋生活、娛樂、工具、學習、遊戲五大分類App應用，可以解決日常生活各種「怎麼辦」的問題。

&nbsp; &nbsp; &nbsp; &nbsp;萬一找不到自己小孩，想趕緊知道小孩在哪裡怎麼辦？優福網資訊展出一款可掌握智慧型手機位置、並可啟動緊急求救功能的「MobileCare手機保姆」應用軟體。優福網資深顧問李志文表示，藉由智慧型手機的GPS導航和上網功能連結到雲端伺服器，透過取得智慧型手機的IMEI碼、SIM卡卡號和手機門號的方式，「MobileCare手機保姆」可以掌握手機所在的經緯度及時間。

&nbsp; &nbsp; &nbsp; &nbsp;手機保姆應用軟體不僅可追蹤手機位置，也可顯示求救地圖、發送求救簡訊、揪團遊樂或是建立企業群組等功能。李志文說，現在已經有超過1萬名會員註冊使用，去年相關營收超過新台幣20萬元，目前可支援Android 2.1版本作業系統以上的智慧型手機和平板電腦。

&nbsp; &nbsp; &nbsp; &nbsp;忘記電話號碼，想趕快找到以便撥打怎麼辦？StorySense Computing推出一款結合人工智慧和友善介面的快速搜尋撥打電話應用軟體「What’s TheNumber?」，只要Google網頁可搜尋到的電話號碼，無論是餐廳旅館、航空火車或是電影院KTV等，只要透過這款App鍵入欲搜尋的名稱和地點，便會列舉出已在網路上公布的所有電話號碼結果，透過圖示按鍵便可迅速撥打出去。

&nbsp; &nbsp; &nbsp; 目前「What’s The Number?」在全球的下載量已經超過11萬次，其中付費比例約占1成左右，這款應用軟體已建立繁體中文、簡體中文、英文和日文四種介面，可支援蘋果iPhone iOS以及Android作業系統。

&nbsp; &nbsp; &nbsp; &nbsp;想去郊外騎單車，可是不知道路況怎麼辦？內政部營建署委託勤崴國際科技，開發出一套生活圈自行車道系統路況資訊查詢和導航建置應用軟體，使用者可以透過智慧型手機免費下載，建立自行車路線規劃、景點查詢、大眾運輸規劃、單車軌跡記錄和個人健康管理等功能。

&nbsp; &nbsp; &nbsp; 這款自行車導航系統涵蓋區域目前以台北市和新北市為主，預估今年6月至7月涵蓋區域可擴及苗栗以北和宜蘭地區，預估到2013年可望擴及全台，目前透過Android和蘋果iOS行動裝置的下載量累計接近2萬次。

&nbsp; &nbsp; &nbsp; &nbsp;想要介紹外國朋友在台灣吃喝玩樂怎麼辦？溫普敦資訊推出一款「Mojotaiwan旅遊生活家」免費應用軟體，透過GPS導航定位，結合可即時翻譯繁體中文、簡體中文、英文和日文的功能，使用者可以藉由Android或是蘋果iOS行動裝置，瀏覽所在位置附近的各項旅遊景點資訊內容。

&nbsp; &nbsp; &nbsp;這款應用軟體愛用者以歐美人士居多，下載次數已經有1萬多次。
