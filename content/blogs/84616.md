酷炫新科技！　分身機器人仿本尊行動

&nbsp; &nbsp; &nbsp; &nbsp;電影「阿凡達」的分身科技，令許多人印象深刻，現在日本也研發出一種分身機器人，可以透過遠端遙控，模仿人類的一舉一動，機器人的感應器，還可以傳達視覺、聽覺，甚至是觸覺，讓操控者身歷其境。

&nbsp; &nbsp; &nbsp; &nbsp;電影「阿凡達」裡，主角透過高科技，分身成為納美人，到另一個星球執行任務，科幻的電影場景不是夢，類似技術已在日本出現。

&nbsp; &nbsp; &nbsp; &nbsp;東京慶應義塾大學，所開發的「Telesar V」機器人，以遠端技術遙控，只要操控者身穿裝備，機器人就可以模擬所有動作，更厲害的是，機器人也可以透過內建的視訊和傳聲器，將視覺和聽覺傳送給操縱者。

&nbsp; &nbsp; &nbsp; &nbsp;靈活的活動手臂設計，和特殊的指尖感應器，甚至能夠將觸覺也一併回傳，讓操縱者和機器人合為一體，機器人分身的高科技，未來可望在處理核電等高風險任務時，派上用場。

&nbsp; &nbsp; &nbsp; 為了配合情人節的浪漫氣氛，日本知名百貨也出動美女機器人，在櫥窗裡不時地眨眨眼睛、擺擺頭，等待著還沒出現的情人，生動逼真的表情，吸引大批人潮圍觀拍照。

&nbsp; &nbsp; &nbsp;購物民眾：「她看起來很像戀愛中的女孩，感染力很強。」

&nbsp; &nbsp; 搭上情人節禮物熱潮，百貨業者看準這波商機，以女性機器人營造浪漫氛圍，推銷巧克力等應景商品，希望能夠創下銷售佳績。
