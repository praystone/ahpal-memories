今晚

&nbsp;

再一次的吐出了鮮血

&nbsp;

不

&nbsp;

應該說是黑色的廢血了

&nbsp;

還能活多久

&nbsp;

還剩多久可以這樣的活下去

&nbsp;

有那麼的一瞬間

&nbsp;

哭出了淚

&nbsp;

自己不是早就應該習慣這樣的命運了嗎

&nbsp;

為何還會再一次的哭出了淚

&nbsp;

是否自己還怕死

&nbsp;

還是捨不得現在所有的一切

&nbsp;

還能見的到妳嗎

&nbsp;

還能見到自己想見到的人嗎

&nbsp;

當那一天

&nbsp;

醫生搖搖頭的時候

&nbsp;

忽然間

&nbsp;

心

&nbsp;

不知道該笑還是該惆悵

&nbsp;

當死亡那天到來的時候

&nbsp;

不知道

&nbsp;

是否會有人願意為這場喪禮而哭泣

&nbsp;

忽然間

&nbsp;

想看看會是一個什麼樣的場景

&nbsp;

血依舊的咳不停

&nbsp;

是啊

&nbsp;

已經沒有太多的時間

&nbsp;

可以去想多餘的問題了

&nbsp;

雖然

&nbsp;

心中難免有所遺憾

&nbsp;

但

&nbsp;

這條路

&nbsp;

自己知道遲早要走上

&nbsp;

雖然

&nbsp;

來的快了一些

&nbsp;

夠了

&nbsp;

這樣的病

&nbsp;

這樣的傷

&nbsp;

這樣的過去

&nbsp;

這樣的不堪

&nbsp;

是該停止了

&nbsp;

不屬於的

&nbsp;

就到這邊停止吧

&nbsp;

好讓自己疲憊不堪的心

&nbsp;

可以好好的沉眠

&nbsp;

笑不出的嘴角

&nbsp;

勾不起的情懷

&nbsp;

這場戲

&nbsp;

終於落幕了
