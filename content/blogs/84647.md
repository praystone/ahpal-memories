&nbsp;


我想我應該應該不會愛你　&nbsp;


為了要努力　努力的不愛你　&nbsp;


所以我讓自己那麼喜歡你&nbsp;


這樣你就不忍心和我分離　&nbsp;


我想我討厭﻿　討厭驕傲的你　&nbsp;


也討厭美好　美好的那個你　&nbsp;


於是我要自己假裝討厭你　&nbsp;


那麼你就捨不得離我而去　&nbsp;



&nbsp;


我必須說我真的不會喜歡你　&nbsp;


我不喜歡你佔據我所有思緒　&nbsp;


連你的竊笑也像是鼓勵　&nbsp;


從早安後的早餐到晚餐後的晚安　&nbsp;


別笑了　別笑了　我不會喜歡你　&nbsp;



&nbsp;


我放空了　我解脫了　&nbsp;


你還是在我的眼裡　我喜歡了　&nbsp;


我討厭了　影響不了我的呼吸&nbsp;


原來我　已經無法自拔　&nbsp;


我秘密的　愛上你　&nbsp;



&nbsp;


你不必懂　我真的不會喜歡你　&nbsp;


我不想要你因為我變得消極　&nbsp;


有你的城市下雨也美麗　&nbsp;


從黎明後的太陽　到深夜裡的月光　&nbsp;


別想了　別想了　我不會喜歡你　&nbsp;


別想了　別想了　我不會喜歡你
