紅塵中隨心，隨性，隨緣，逍遙自在


&nbsp;


忘記並不等於從未存在，一切自在來源於選擇，而不是刻意。


&nbsp;


不如放手，放下的越多，越覺得擁有的更多。 


&nbsp;


命由己造，相由心生，世間萬物皆是化相，


&nbsp;


心不動，萬物皆不動，心不變，萬物皆不變。 


&nbsp;


坐亦禪，行亦禪，一花一世界，一葉一如來，


&nbsp;


春來花自青，秋至葉飄零，


&nbsp;


無窮般若心自在，語默動靜體自然。 


&nbsp;


笑著面對，不去埋怨。悠然，隨心，隨性，隨緣。


&nbsp;


注定讓一生改變的，只在百年後，那一朵花開的時間。 


&nbsp;


剎那便是永恆


&nbsp;


若人生了悟如佛，


&nbsp;


無悲無喜無夢無幻，無愛無恨四大皆空，


&nbsp;


生與死又有何區別。


&nbsp;


不能了，不能悟，不能捨，不能棄，參不透，捨不得。


&nbsp;


不可說,不可說,一說即是錯。 


&nbsp;


一念愚即般若絕，一念智即般若生。 


&nbsp;


菩提本無樹，明鏡亦非台。本來無一物，何處惹塵埃。
