選擇放棄也是因為愛你


&nbsp;


　　當你不再愛我，當愛你已成為你的負擔，當相愛已是一種痛苦，那麼，我選擇放棄。 



&nbsp;
　　放棄你，是因為愛你。因為愛你，所以不願看見你不快樂；因為愛你，所以不願看著你強忍內心的掙扎；因為愛你，所以不願看見你勉強的笑容；因為愛你，所以願意放了你。 


&nbsp;



　　當愛已成往事，又何必苦苦追尋？強求得不到幸福，強求只能拉大你我的裂痕，只能加深你我的痛楚。如果你真的想走，我無言，只能任你去。 


&nbsp;



　　曾經以為你是風箏，我手中握著那根線，無論任你飛向何方，我最終都是你的歸屬。現在終於明白，其實愛你，就不應該束縛你。 


&nbsp;



　　「春花秋月何時了，往事知多少？」往事如風，不如就讓它隨風而去。當一切成空，惟有回憶伴我。時間能沖澹一切，包括我愛你的心。 


&nbsp;



　　不願意你看見我的眼淚，因為怕你會心軟，怕你不開心。因為愛你，所以不會用淚水強留，所以放了你。你的心已遠去，我又何苦留下你的人？ 


&nbsp;



　　雖然我渴望天長地久，但如果那只是一種奢求，那我不如只求曾經擁有。曾經擁有過你的愛，這已足夠。因為有一種愛，叫做放棄。 



　　放棄不是無私的奉獻。放棄你，這不僅是對你的愛，更是對我自己的呵護。放棄你，我很痛心，但我不會後悔。讓你從我的生命中消失，是因為「長痛不如短痛」。當我容顏盡老、行將就木，我依然不會後悔。因為曾經愛過你。 


&nbsp;



　　因為愛你，所以希望你快樂。 



　　有人說過這個世界不會有永恆的愛情。你我之間，如果連短暫的愛情也無法存在，不如放開彼此。愛你，就讓你去追尋你的幸福。只要你快樂，我也就快樂。 



　　因為你的一切，我都在意。 


&nbsp;


　　如果你要離開我，我不會怪你，只能怪我自己，怪自己太愛你。也許是我過分的寵溺讓你習慣平靜，也許是我過分的放任讓你沒有責任，也許是我過分的愛憐讓你壓力重重，也許是愛情她美麗的容顏讓你迷失方向。只怪你我有緣無份。 


&nbsp;



　　當你想要離去，請別管我，你只需告訴我，你不再愛我，你要走。我一定會讓你走，不會乞求你留下，哪怕聽見自己心碎的聲音。當你離去，請別再回頭。回頭是一種錯誤，回頭是對你我的不公。去了，就不要再後悔。 


&nbsp;



　　因為愛你，就該放了你。 



　　因為我知道，有一種愛叫做放棄，那是對你最深的愛。



&nbsp;
　　愛情,原來是含笑飲毒酒。愛一個人很難，放棄自己心愛的人更難。有些人注定是等待別人的，有些人是注定被人等的。


&nbsp;


　　曾經相遇，總勝過從未碰頭,離開之後，我想你不要忘記一件事：不要忘記想念我。想念我的時候，不要忘記我也在想念你 


&nbsp;



　　愛上了你，我才領略思念的滋味、分離的愁苦和妒忌的煎熬，還有那無休止的佔有慾.為什麼你的一舉一動都讓我心潮起伏？


&nbsp;


　　為什麼我總害怕時光飛逝而無法與你終生廝守？


&nbsp;


　　為什麼要那麼痛苦地忘記一個人，時間自然會使你忘記。


&nbsp;


　　如果時間不可以讓你忘記不應該記住的人，我們失去的歲月又有甚麼意義？ 


&nbsp;



　　愛情是風花雪月的事， 



　　失意的人是玩不起的。 



　　凡事皆有代價，快樂的代價便是痛苦。 



　　開始的時侯，我們就知道，總會有終結
