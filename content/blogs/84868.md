在一小時前

&nbsp;

亞寶發生一件讓蝶覺得非常可笑的事

&nbsp;

http://ahpal.com/home/space.php?uid=1&amp;do=blog&amp;id=84862

&nbsp;

主機系統發生故障

&nbsp;

所以導致亞寶所有會員的資料回朔到二月十四號

&nbsp;

而身為站長

&nbsp;

當然也在第一時間跳出來道歉

&nbsp;

於理

&nbsp;

站長是對的

&nbsp;

於情

&nbsp;

笑話一則

&nbsp;

蝶在伊莉跟其他網站非常多年

&nbsp;

一般來說

&nbsp;

維修是一定有

&nbsp;

但

&nbsp;

主機發生故障的事

&nbsp;

而導致所有會員權益受損的情況下

&nbsp;

而又沒辦法回復現今應有狀態

&nbsp;

這不就是笑話一則嗎

&nbsp;

二月十四號至現今二月十九號

&nbsp;

一共是五天

&nbsp;

這五天中

&nbsp;

有多少人上傳多少的文章．圖片．照片

&nbsp;

雖然不是什麼佳作

&nbsp;

但這些對當事人來說

&nbsp;

是一個點藏的回憶

&nbsp;

就因為你們的疏失

&nbsp;

而必須連帶大家一同與你們受罪

&nbsp;

另一方面來說

&nbsp;

是無恥

&nbsp;

誰能在當下馬上再創跟當時一模一樣的文章

&nbsp;

別忘了

&nbsp;

很多東西

&nbsp;

在不同的時空與情境下

&nbsp;

所寫出的心境也都全然不一樣

&nbsp;

那怕是差一個字

&nbsp;

也就差非常多了

&nbsp;

那麼對另一方面的會員來說

&nbsp;

農場牧場魚塘方面的受損

&nbsp;

對

&nbsp;

沒有錯

&nbsp;

雖然這些都是虛擬的

&nbsp;

但別忘了

&nbsp;

玩家們也必須負出相等的時間換取應該的代價

&nbsp;

五天的時間

&nbsp;

你們能賠的起嗎

&nbsp;

而不是單單的幾句道歉文了事

&nbsp;

若不能回復到現今應有的狀態的話

&nbsp;

這裡的一切

&nbsp;

不留戀又有什麼關係

&nbsp;

先不論這一切是純屬意外

&nbsp;

還是有心安排

&nbsp;

錯就是錯

&nbsp;

若是大家作錯只要一個道歉．一個下跪

&nbsp;

就能平息所有傷痛話

&nbsp;

那麼還需要法律做什麼

&nbsp;

更何況

&nbsp;

今天都能這樣發生一次

&nbsp;

誰能保障沒有下次

&nbsp;

蝶在這邊對外宣佈

&nbsp;

若是亞寶三天之內無法回復現今狀態的話

&nbsp;

那麼蝶只好離開這邊

&nbsp;

至於這邊認識的朋友

&nbsp;

蝶就說聲抱歉

&nbsp;

蝶一向敢說敢做

&nbsp;

既然說的出

&nbsp;

蝶就一定做的到

&nbsp;

當然

&nbsp;

若是大家還有緣的話

&nbsp;

或許

&nbsp;

在下一個空間還能遇到
