念

&nbsp;

依偎的相片是一張張

&nbsp;

思念卻也是一天天

&nbsp;

忘

&nbsp;

忘不了的故事是不了情

&nbsp;

不了情的故事卻忘不了

&nbsp;

驪

&nbsp;

分了的手

&nbsp;

就如同分了我的心

&nbsp;

片片都不齊

&nbsp;

靜

&nbsp;

無法平息的回憶

&nbsp;

總是在夜深人靜的時候

&nbsp;

悄悄的勾起

&nbsp;

迷

&nbsp;

泛紅的眼框

&nbsp;

總有那麼一點點的迷霧

&nbsp;

看不清

&nbsp;

卻傷的透

&nbsp;

若是

&nbsp;

早有所謂的知道

&nbsp;

也許現在的這段情

&nbsp;

就不會淚流的那麼徹底

&nbsp;

若是

&nbsp;

真有所謂的山盟海誓

&nbsp;

誰能期待著海枯石爛的那一天

&nbsp;

而不讓這場情感戲早早落幕

&nbsp;

若是

&nbsp;

非要難過才能走這一回

&nbsp;

那麼這一回的一生

&nbsp;

就已經足夠

&nbsp;

珍惜

&nbsp;

錯過了一次

&nbsp;

有時候就像是錯過了一輩子

&nbsp;

永遠

&nbsp;

不知道下一次什麼時候會再回來

&nbsp;

女人

&nbsp;

最在意介懷的

&nbsp;

是曾經有過在等待她的男人

&nbsp;

或許

&nbsp;

有那麼一點遺忘了

&nbsp;

但

&nbsp;

女人總是知道誰都沒有義務去等待

&nbsp;

於是的

&nbsp;

選擇了放手

&nbsp;

愛與被愛

&nbsp;

女人總是難過無奈

&nbsp;

今晚

&nbsp;

是一份蒼涼的夜

&nbsp;

伴隨的

&nbsp;

是一個個的女人

&nbsp;

月亮的昇起

&nbsp;

不是因為那月亮而美麗

&nbsp;

女人的璀璨

&nbsp;

不是因為那男人而華麗

&nbsp;

為的

&nbsp;

只是自己

&nbsp;

今晚將是女人夜

&nbsp;

而這樣的女人

&nbsp;

卻也是那麼的璀璨美麗

&nbsp;
