碎

&nbsp;

碎掉的那一年四季

&nbsp;

也碎掉了我們的夏天

&nbsp;

問

&nbsp;

從什麼時候開始

&nbsp;

就一直試問為何只剩如今

&nbsp;

字

&nbsp;

每一天的每一篇

&nbsp;

總是用著不同的心

&nbsp;

去描述曾經的點點滴滴

&nbsp;

吻

&nbsp;

忘懷不了的片刻餘溫

&nbsp;

現在卻只是往事的回首

&nbsp;

誰

&nbsp;

在那段曾經似回憶的記憶裏

&nbsp;

不捨離開你的人

&nbsp;

是我

&nbsp;

我說

&nbsp;

如果這一切只是一場夢

&nbsp;

那麼這一場夢

&nbsp;

是屬於噩夢

&nbsp;

因為

&nbsp;

我已經把所有的感情放在你身上

&nbsp;

而你

&nbsp;

卻已經離我遠去

&nbsp;

我說

&nbsp;

如果真有來生的話

&nbsp;

那麼我希望

&nbsp;

現在就是來生

&nbsp;

因為

&nbsp;

我不需要再輪一個世紀

&nbsp;

才能見到你

&nbsp;

我說

&nbsp;

如果現在的我

&nbsp;

還真能見到你

&nbsp;

那麼我只希望你能別在離開我

&nbsp;

好讓我再一次的躺在你懷裡入眠

&nbsp;

我說

&nbsp;

這會是一個可能的願望嗎

&nbsp;

一個悲傷的願望

&nbsp;

一個不知道什麼時候會實現的願望

&nbsp;

兩個願望

&nbsp;

卻同樣的只想見見你

&nbsp;

而這樣的想見見你

&nbsp;

卻是我的煎熬

&nbsp;

我喜歡著你

&nbsp;

從以前到現在都沒變過

&nbsp;

更喜歡你在我身旁的日子

&nbsp;

雖然

&nbsp;

現在的你

&nbsp;

已經不在我身旁了

&nbsp;

但

&nbsp;

請你相信

&nbsp;

我不曾遺忘過你

&nbsp;

自己的心

&nbsp;

是一片女人海

&nbsp;

原來這樣的女人心

&nbsp;

是那麼的脆弱

&nbsp;

卻也依舊那麼的美麗

&nbsp;
