蝶是一隻區域性非常強的個體

&nbsp;

只要蝶習慣一個地方後

&nbsp;

鮮少會離開區域範圍

&nbsp;

除非

&nbsp;

逼不得已的情況下

&nbsp;

對於很多事

&nbsp;

蝶一向不理會居多

&nbsp;

因為事不關己

&nbsp;

但發生在昨天事件當中

&nbsp;

其實蝶也可以認為沒什麼

&nbsp;

但是很抱歉一件事

&nbsp;

因為蝶時間不多了

&nbsp;

蝶已經沒有太多的時間可以浪費

&nbsp;

所以

&nbsp;

在一個這樣的情形下

&nbsp;

蝶必須力爭到底

&nbsp;

畢竟你們的命比蝶還要長

&nbsp;

而蝶卻剩六個月

&nbsp;

目前

&nbsp;

蝶需要完成一個空間

&nbsp;

好讓蝶的願望可以傳遞出去

&nbsp;

希望有一天

&nbsp;

某個人可以瞭解蝶的心意
