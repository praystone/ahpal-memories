人類的鏡子

「照照鏡子看看自己的臉」，是人生活休閒中一個少不了的動作。妄自菲薄的人對鏡子「拿不起放得下」，愛慕虛榮的人對鏡子「拿得起放不下」，謙虛力進的人對鏡子「拿得起放得下」。 


&nbsp;



閒暇中照照鏡子，這決不是什麼不良的行為習慣，是人追求文明的一個審美需要，是人的生理自我保護之功能反映表現。 


&nbsp;



人自「哇哇」叫著來到這個通靈的星球，從頭到腳、從內臟到皮膚，都離不開外界因素——尤其是細菌、病毒的侵襲（刺激）。


&nbsp;


雖昨日今天是同一張面孔，自己的面孔再熟悉也不過，什麼時候臉上長出難看的粉刺、癤子之類的東西，什麼時候眼瞼出現異物將影響視力，什麼時候鼻子粘有污垢後要出毛病，卻都是難以事先預料的。


&nbsp;


要保護、維持這張臉的正常模樣，防止不該損容的疾患，人就有必要尋找機會對著鏡子看看自己的臉。有的人照鏡子，或許僅僅是為了梳妝、打扮，到死也不會認識到：照鏡子是普遍具有愛美之心的人類的一個本能、一個「看家本領」。


&nbsp;


與人類最親近的猩猩即使對著鏡子，也看不懂鏡子裡的到底是什麼，更不用談及通過照鏡子照出來的停在臉上的小黃蜂是一個威脅，必須在其還沒叮臉時趕快驅之。猩猩驅逐逗留在臉上的小黃蜂，不是照鏡子照出來的結果，而是臉上有了不舒服甚至是痛的感覺使然。


&nbsp;



世界上最難認識的東西，即是人本身，人本身是個怪物。與其（含糊其詞）說「生命是個奇跡」，不如（直截了當）說「人本身是個奇跡」。


&nbsp;


人的一生是一個新生命發生、生長、衰老、死亡的過程；人的一生是「體內王國」（人體內的所有生命活動）矛盾鬥爭運動與「體外王國」（個人的全部社會生活）矛盾鬥爭運動相結合發展的過程；


&nbsp;


人的一生是從蒙昧（自然原始化）上升為理智（社會現代化）逐步認識自我、改造自我、實現自我價值的過程，是一個從非我到我再到非我的否定之否定過程。


&nbsp;


滄海滴水般的人生，有這麼多的看似簡單其實奇妙無窮的「過程」，有那麼多難解的疑問，怎不教人低頭沉思，仰天長歎，面對鏡子耗費精神！ 


&nbsp;



法國浪漫主義畫家德拉克洛瓦曾道：「Mediocrities can explain everything ,and are surprised at nothing.」（此話中文意為：「庸人能解釋一切，而且對任何事物都不會感到意外。」）人生在所謂的「庸人」眼裡，或許會變得「不過如此」、「沒啥稀奇」，當然，愛迪生的發明、愛因斯坦的發現「庸人」認為亦然。


&nbsp;


人生在徹底的辯證唯物主義者的眼裡，是深奧可以一步步認識的，牛頓、居里夫人的成功，是汗水與靈感的結晶。


&nbsp;


人自「哈哈」降臨於世，臉就一直處在變化之中，若像放電影一樣把近百年的人臉變化這一「慢動作」放成幾秒鐘之內完成的「快動作」，這種變化無異於神話影視劇中的神仙表演——臉面喝聲「變」就變。


&nbsp;


僅就臉形無情變化這一點，人就有必要照鏡子看著它一天天演進，何況還有那麼多因素，使人不得不最大限度地對鏡子默立呢。


&nbsp;


人對自己，其實知其然不知其所以然，或最多也不過是知其一分所以然而不知其究竟是為什麼這一分所以然。 


&nbsp;



人照鏡子還包含著一個哲理：人並不認識自己。孟加拉國的颶風，印度尼西亞的海嘯，山姆大叔望之不無惶恐的卡特裡娜小姐，中國的唐山大地震，這都是大自然對人類學識的挑戰——人啊，如果說你認識了自己，如果說你智力通達，為何你的生命在我的手掌心，原來你還是脆弱得不堪一擊，好可憐呵！


&nbsp;


古往今來無一人問津「長生不老」不受重挫，這又是人類學識受限的最好的佐證之一。誠然，即便是如此，其中仍然有自以為是膽敢昂首蹺足向大自然叫板的「猛男」、「勇士」。


&nbsp;


他一手高舉「環境污染」之盾，一手揮舞著「反生態平衡」之矛，對大自然躍躍欲試，什麼「溫室效應」，什麼「生態惡化」，什麼「道義罪惡」，對他來說都是春天刮過耳邊的風兒；


&nbsp;


結果，大自然狠狠地在這個「猛男」、「勇士」的屁股上拍了一巴掌，他還嬉皮笑臉無動於衷，等到大自然真格發怒，可愛的生命體化為烏有，舉世為之心痛，另有多少親人為之淚盡，悔之晚矣。


&nbsp;


感覺的載體——生命肉體都沒了，大自然再變相諷刺人如何如何無知也是枉然，這或許是此類「猛男」、「勇士」初生牛犢不怕虎地向大自然賣弄武功的理論依據。


&nbsp;


可愛可憐的人啊，你們要居安思危，用「發展共處」取代「同球操戈」，拋開掛在眉前的一時一方之油袋，放開眼界去學習智慧、開發智慧、利用智慧，有空時照照鏡子看看自己的臉，創造了幸福享受的也是你們自己，別再施放黑煙暗霧來蒙騙我的感情了，你們尊重我就是尊重你們自己，知道不？


&nbsp;


大自然對人類的希望是至大的，大自然對人類的心意是至誠的。在大鏡子面前，人類只能算是個傻里傻氣童真十足的小朋友；


&nbsp;


人是大自然一手打造的寵物，人依賴之而之不以人的意志為動；向大自然叫板的「猛男」、「勇士」狂妄無知之舉，產生的「蝴蝶效應」，有可能禍及其他無辜之人；


&nbsp;


「牽一髮而動全身」，大自然額外歎口氣或搖搖頭，就足以令息息相關的人們苦痛數周甚至終生，喪鐘不是為大自然而鳴，人類永遠沒有資格跟大自然對抗。


&nbsp;


「用鏡子照照自己」，含有一個人要「從實際出發，不可自高自大」之意；而如果甲對乙說：「你用鏡子照照你自己，」則意味著乙可能有「有嘴說別人，無嘴說自己」或「不知己丑」之嫌。
