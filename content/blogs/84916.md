蝶自小便是一個私生子

&nbsp;

從小時候開始

&nbsp;

蝶便一直受到異樣的歧視

&nbsp;

蝶的父親娶過很多個妻子

&nbsp;

所以蝶有同父異母的兄姐四個

&nbsp;

而蝶的母親

&nbsp;

在還沒有離婚的情況下

&nbsp;

選擇跟蝶的父親

&nbsp;

所以蝶也有同母異父的兄姐四個

&nbsp;

小的時候

&nbsp;

蝶父外面有女人

&nbsp;

選擇了拋家棄子

&nbsp;

加上蝶母那邊的兒子常欺負蝶

&nbsp;

所以蝶小時候便極度有怨恨之心

&nbsp;

蝶母那邊的兒子常跟蝶說一句話

&nbsp;

你只是暫時住在我們家而已

人在屋簷下不得不低頭

&nbsp;

被罵

被當奴隸般使喚者

&nbsp;

蝶母後來跟了另一個男人

&nbsp;

蝶的生活更是苦不堪言

&nbsp;

蝶母也好

&nbsp;

蝶父也罷

&nbsp;

他們從蝶小時候常說著

&nbsp;

長大要賺錢給他們

&nbsp;

他們要的無非就是錢而已

&nbsp;

後來蝶父有一次情況下

&nbsp;

硬是帶離蝶到台中

&nbsp;

當然也免不了叫另一個女人為媽

&nbsp;

但這樣的一切

&nbsp;

也不過兩年

&nbsp;

兩年後

&nbsp;

蝶父跟那個女人吵架後

&nbsp;

蝶就不常回來

&nbsp;

而那女人也早早就離開

&nbsp;

一當蝶父回來的時候

&nbsp;

常做的

&nbsp;

就是把蝶衣服脫到剩一件內褲

&nbsp;

然後把蝶綁在椅子上

&nbsp;

任由他隨意的鞭打

&nbsp;

打夠了

&nbsp;

他就去睡

&nbsp;

睡完後

&nbsp;

他幫蝶鬆綁完就出門

&nbsp;

當時的蝶

&nbsp;

有一餐沒一餐的

&nbsp;

常常要靠偷東西吃來過活

&nbsp;

那時候的學校

&nbsp;

並不像現在這樣關注家暴的問題

&nbsp;

哪怕當時蝶是如此在學校被欺負

&nbsp;

老師一個字從不說過什麼

&nbsp;

過沒多久

&nbsp;

他便將蝶帶回高雄交給外婆

&nbsp;

但說實話

&nbsp;

誰會願意白養一個外子

&nbsp;

再一次的寄人籬下

&nbsp;

只要一但外婆家有什麼東西不見了

&nbsp;

蝶便要當起　一．定．是．賊　的角色

&nbsp;

少不了的

&nbsp;

永遠都是一頓毒打

&nbsp;

打到你必須要承認不曾做過的事

&nbsp;

慢慢的

&nbsp;

蝶長大了

&nbsp;

蝶的心性開始起了大轉變

&nbsp;

蝶沒有去混黑道

&nbsp;

蝶只是變的非常冷漠

&nbsp;

非常無情而已

&nbsp;

而且只注意有關蝶一切的利益為優先

&nbsp;

但或許真有上輩子欠債的理論吧

&nbsp;

蝶怨歸怨

&nbsp;

但一看見蝶父老了的模樣

&nbsp;

蝶總是始終拿錢給他

&nbsp;

甚至為了這事

&nbsp;

蝶常跟當時的女友吵架

&nbsp;

後來女友受不了走了

&nbsp;

當時的蝶

&nbsp;

因為已經長大了

&nbsp;

所以再一次的自己離開高雄

&nbsp;

住遍臺灣個各角落

&nbsp;

這一離整整十多年

&nbsp;

一直到這五年

&nbsp;

才回來高雄

&nbsp;

但回來也不是好事

&nbsp;

因為蝶母那邊瑣事依舊很多

&nbsp;

而還沒回到高雄前

&nbsp;

蝶為了一個女友背了一條官司

&nbsp;

雖然蝶好運只受到鍰刑

&nbsp;

但是心卻更涼了

&nbsp;

後來認識了一個非常支持蝶的女朋友

&nbsp;

跟她在一起的日子中

&nbsp;

蝶過的非常開心

&nbsp;

彷彿從來不知道什麼叫寂寞一樣

&nbsp;

可是

&nbsp;

好命永遠不會輪到蝶

&nbsp;

她依舊選擇離開

&nbsp;

原因

&nbsp;

她家人的反對

&nbsp;

或許

&nbsp;

上天開始可憐了蝶

&nbsp;

於是的

&nbsp;

讓蝶的身體起了極度的變化

&nbsp;

當知道後

&nbsp;

蝶是一邊哭一邊笑

&nbsp;

但醫生說

&nbsp;

並不是完全沒的醫

&nbsp;

還是有百分之四十的機會

&nbsp;

但蝶選擇放棄機會

&nbsp;

因為

&nbsp;

累了

&nbsp;

因為

&nbsp;

蝶還有很多過去沒辦法一次說完

&nbsp;

這樣的蝶

&nbsp;

微兒瞭解了嗎
