人生


&nbsp;


人生是什麼？


&nbsp;


看著這個題目，


&nbsp;


我陷入了深深的沉思中。


&nbsp;


有人說：人生就是今朝有酒今朝醉，


&nbsp;


及時行樂方不悔。 


&nbsp;


也有人說：人生是一碟乏味的菜。


&nbsp;


為了嚥下這蝶乏味的菜，


&nbsp;


少不了種種佐料。 


&nbsp;


我想：也許吧，諸如麻辣、雞晶、各種調料，


&nbsp;


甚至加些許情意綿綿的語話。


&nbsp;


只有這樣，你才能創造出你獨有的人生。 


&nbsp;


聽聽「它們」怎麼說。


&nbsp;


&nbsp;事業說：人生就是建築歷史的一塊磚瓦。 


&nbsp;


奮鬥說：人生就是與風浪搏鬥的那雙擼。 


&nbsp;


希望說：人生就是萬綠之源的絢麗花朵。


&nbsp;


愛情說：人生就是尋找那甜蜜無比的吻。 


&nbsp;


友誼說：人生就是幫助別人攀登的階梯。 


&nbsp;


勤勞說：人生就是耕耘大自然的那頭牛。 


&nbsp;


自由說：人生就是清晨衝出籠子的飛鳥。 


&nbsp;


幸福說：人生就是一桌供人享受的佳宴。


&nbsp;


貪婪說：人生就是用一切手段盡情佔有。 


&nbsp;


無聊說：人生就是那一杯乏味的白開水。


&nbsp;


失意說：人生就是那只斷線飄搖的風箏


。


困難說：人生就是那條坎坷曲折的道路。 


&nbsp;


挫折說：人生就是那在暗礁中行進的船。 


&nbsp;


投機說：人生就是那一纖無孔不入的風。 


&nbsp;


地位說：人生就是那皇宮中閃光的寶座。 


&nbsp;


虛榮說：人生就是那件鑲金配玉的外衣。 


&nbsp;


厭世說：人生就是那塊很快破敗的墓碑。 


&nbsp;


你認為呢？
