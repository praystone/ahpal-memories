&nbsp;在一片鮮紅中，少年緩緩的睜開眼。 


&nbsp;不由的望向遠方……他只覺得天空好蔚藍。


&nbsp;


&nbsp;不知道過了多久，他才爬了起來。


&nbsp;自己身上全身都是擦傷、淤血，但不要緊，跟『他們』比起來真的不要緊。


&nbsp;可是，現在他的腦中……只剩下剛剛的話而已。


『孩子，不要怕，我們會保護你的，一定……要勇敢的活下去呦。』


&nbsp;很溫柔很暖和的聲音，自己卻再也聽不到。


「有聽見嗎？……」小小的呼喊，換來的只有沉默。


&nbsp;少年輕碰著『他們』，感覺只有冰冷。


『他們』……不會再回來了……只剩下自己一個人了。


&nbsp;再次望向天空，少年輕輕說道：「爸、媽，天空好藍喔。」


&nbsp;


&nbsp;


&nbsp;想起了不好的回憶吶……老鼠有些無奈的抓了抓頭。


「我說你阿，認為自己是個不祥嗎？」


「……我是個不祥，這是事實。」紫苑很認真的面對老鼠，等一下老鼠在怎麼阻止自己，他是絕對不會妥協的。只有不祥這個身份，才能讓他不會忘記大火的事，不會忘記自己怎麼傷害那些人的。


「其實，我也是個不祥喔，我親手害死我爸媽。」


&nbsp;紫苑愣了一下，接著身體不由的顫抖一下……


「我爸媽，是死在我手裡的。」很平靜，老鼠彷彿是在說與他不相干的事。


&nbsp;這孩子說他害死那些人是事實，而自己殺了最親最愛的人，也是事實。他早在好久以前，用這雙沾滿摯愛鮮血的手，將自己推下地獄。


&nbsp;望向一旁的紫苑，他難以置信的看著自己。


「我以前，因為貪玩而惹上了『不該惹的人』。那時我爸媽為了保護我，全部都犧牲了，只有我沒死。」


&nbsp;到最後還說要勇敢活下去什麼的……大人，真是太狡滑了。明明當時可以跑開的，卻堅持要保護他，如果不是因為這樣，他們就不會死了。


&nbsp;我和這孩子一樣，也是個不祥。


「即使背負著殺人這罪名，我還是選擇活下來，那你呢？你還想死嗎？？面對同樣是不祥的我，你的決定是？」


&nbsp;聞言，紫苑沒回答，卻伸出手來輕碰觸老鼠的臉頰：「你的胸口很痛嗎？」


「……什麼？」


「那為什麼要哭？」


&nbsp;老鼠頓時摸了摸臉，溼溼的感覺……那是眼淚。他，不知不覺的哭了，卻不知道。


&nbsp;當自己回過神時，紫苑已經開口了：「當時胸口很痛，也很難過，但我沒有哭。」他摔下崖時……看見那女孩，卻怎麼也說不出話來，胸口彷彿快撕裂了一樣，卻一點也哭不出來。


「不，我一點都不痛。倒是你，剛剛還沒有告訴我吶，你的答案。」


&nbsp;害怕的臉孔，帶著疑惑的心情紫苑問道：「……真的……我真的可以活下來嗎？即使我害死大家，仍然可以活下來嗎？？」


&nbsp;


「活下去。」


&nbsp;


&nbsp;就算會被人們恨死，就算今後必須帶著痛苦……也必須活下去。


&nbsp;不祥的人，不是只有你而已。


「吶紫苑，明天的天空會很藍吧。」


&nbsp;像那天一樣，對吧？


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;這裡，有著燒焦味與濃濃的不安氣息。


「還真是好險阿。」一群人站在遠方，有些傷腦筋的看著女孩。


&nbsp;有人不耐煩的說道：「乾脆把她處理掉好了，要不然她要是變成『下一個不祥』該怎麼辦？」 


&nbsp;躲在角落的女孩忍不注顫抖……她覺得這裡好可怕，真的。


「她可是差點害我們沒命吶。」 


「好不容易不祥終於死了，沒想到又出現個麻煩。」


&nbsp;不斷有聲音傳入她的耳中，她不敢抬頭，因為一看見那些人，她就害怕的不得了。


「記得她之前好像跟不祥很好吧？」


「跟不祥做朋友沒什麼好下場。」


&nbsp;她很害怕，卻同時也很生氣，因為、因為……：「紫苑才不是什麼不祥。」等回過神，她發現好多人用不削的眼神朝她看去。


「什麼紫苑阿，別笑死人。不祥就是不祥，沒資格有名字！！」其中一個人鄙視著她為紫苑取的名字，將此踐踏於地。


「紫苑……紫苑根本沒做什麼害過你們的事阿……為什麼要這麼對他！？」


「他、他可是不祥欸！從一出生就註定要害死我們了！！就看那場該死的大火好了，你敢說這不是他做的嗎？」一位中年婦人對著她大聲吼，但她發現婦人在說這段話時，聲音在顫抖……不知道為什麼大家沒有聽出來。


「那我問你，你有什麼證據證明紫苑是大火的元兇！！你說阿！！！」女孩憤怒的看向中年婦人，這些人莫名奇妙說紫苑是不祥就算了，現在還把大火的原因推給他……


「提早處理掉好了。」雖然不清楚是誰說的，但此話一出，大家紛紛點頭，接著靠近她。


「你們、你們要做什麼！？」女孩害怕的睜大了眼，她想逃走，但這已經是角落了，哪裡……哪裡可以逃出去！！──


「紫苑──」


&nbsp;連接內心的名字，沙布痛心的喊著，卻遲遲傳不到紫苑耳中。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;


&nbsp;不知道走了多久，紫苑有些疲憊的停下腳步。


&nbsp;在他決定活下去以後，老鼠說可以和他一起旅行，一起去前往『No.6』。


&nbsp;No.6是個繁榮的大都市，經濟發展好、交通也很便利。但這些只是傳說而已，『No.6』沒有人真正看過，在很久以前就有這個大都市的傳說了。


&nbsp;據說那邊的人民很友善，而且也很熱心，對於無家可歸之人還是流浪的旅人來說，No.6正是他們嚮往的地方。


&nbsp;雖然一直都沒問過老鼠去No.6的原因為何，但他大概是希望有『家』可去，才去尋找大都市的吧。 畢竟他的父母親早就已經──


「欸，在發什麼呆？」


&nbsp;見眼前的人停了下來，紫苑趕緊走向前。


「你這樣子遲早會跟丟的。阿，我們走散的話，好像吃虧的會是你喔。」有些惡作劇般的向紫苑說道，老鼠輕笑了一聲。


「才不會！！我剛剛只是想事情想到分心而已。」


&nbsp;老鼠停下腳步，然後轉過身來面對著紫苑問：「那是想什麼事情？」


&nbsp;沒料到老鼠會問他在想什麼，紫苑先是『咦』了一下，接著猛搖頭。


「剛剛就有說在想事情了，現在還搖什麼頭阿……」老鼠扶額的看著紫苑……倒底該說他單純還是傻子。


「快說，在想什麼事？？」他用近乎命令的語氣叫紫苑回答，讓紫苑實在是撐不下去，只好一午一時的說出。


&nbsp;聽完紫苑剛剛拼了命猛搖頭，也想封住的事情之後，老鼠嘆了一口氣。


「我說你……該不會真的認為我去No.6的目的是那樣子吧？」


「那不然呢？」


&nbsp;老鼠再次扶額了……怎麼打從自己叫他活下去的那刻開始，這傢伙就瞬間從憂鬱自卑型升級成天然呆……「我才不會為了區區『家』這種東西，就旅行去一個傳說的大都市好嗎？」


&nbsp;


「我去No.6的唯一目的，只是為了復仇。」


&nbsp;


「復仇？」紫苑不解的看著老鼠，像No.6這種什麼都是優等的大都市，老鼠到底要去復仇些什麼？


「雖然我害死了他們，但我還是要把殺了我父母親的人找出來。」


「兇手……在No.6嗎？」


「那些『不該惹的人』親口說出自己是No.6的人，就算No.6是個不存在的虛幻好了，我也會去找到它。」接著，在找到兇手的時候，我會親手殺了他們……這句話老鼠深深的埋在心裡沒說出口。


&nbsp;他活下去的理由只有這個而已……只要找到兇手並親手殺了他們，他活下去的理由只有這個。


&nbsp;老鼠知道自己靠著復仇當藉口很愚蠢，但在他孤苦無依時，這個想法讓他撐下去了。所以，他必須找到他們才行。


「萬一找不到呢？那老鼠你要怎麼辦？？」紫苑有些害怕的問著老鼠，感覺上自己好像不詢問些事情，就無法安心。


「直到我死亡，要不然我不會放棄。」


&nbsp;說出一句沉重的話後，老鼠沒有理會紫苑，繼續的往前走。


&nbsp;


&nbsp;等回過神來，紫苑發現自己跟著老鼠走。


&nbsp;是什麼時候開始走起步，紫苑不曉得。


&nbsp;他對於死亡一詞早就麻痺了，在還沒遇見老鼠前，自己總是過著那種生活。現在回想起真的很不舒服。


&nbsp;…….但願他所想的只是假設，因為老鼠的那句話像極了找到後會發生什麼事。


&nbsp;只是自己的假設對吧？


&nbsp;望向不發一語的老鼠，紫苑沒在多想。


&nbsp;


&nbsp;


&nbsp;


&nbsp;


「哈……呼、咳……」沙布延著牆壁一路的走下去。


&nbsp;在村民殘忍的毆打下，沙布全身都是傷。甚至有些人更加兇殘，對她鞭打或是拿尖銳物品刺傷她。也因為這樣沙布失去了右眼和左手。


&nbsp;她是逃出來的，在不逃走的話，自己遲早會死掉。


&nbsp;現在傷口還在持續惡化，眼睛與手臂的疼痛讓她咬緊嘴唇……


「……咳、咳！……」沙布捂著嘴大力的咳起來，往手掌心一看，她嚇傻了。


&nbsp;──那是血。


&nbsp;自己……已經撐不下去了嗎……看著那彷彿紅色花朵般的鮮血，沙布握緊手。


「至少…….」讓她見見紫苑……她好想看見紫苑。


&nbsp;這份心酸的心情，在遇見紫苑後就未曾消失過。第一次見到他時，自己早就深深被吸引，喜歡上……他了。


&nbsp;所以，至少讓她見見紫苑也好。


&nbsp;


「欸！！找到她人了！在前面而已！！」


&nbsp;


&nbsp;沙布驚恐的回頭，發現好多人在她後面追了上來！


&nbsp;──不要、不要！！不要把她抓回去！！！


「還跑！！回去看我們怎麼修理你！」


「放開我、放開我！──」


&nbsp;


&nbsp;顧不得自己身上還有傷，沙布用力的甩開村民的手，接著拼命往前跑。


&nbsp;現在只要能活著見到紫苑就好了……她的願望，只是如此而已……
