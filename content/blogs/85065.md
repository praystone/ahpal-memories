&nbsp;

我不想再有是非居然有人苦苦相逼

&nbsp;

&nbsp;

很可惜你不去當導演

&nbsp;

可以自導自演

&nbsp;

一定會得金鐘獎

&nbsp;

最近的18R照片問題說實在的關我屁事

&nbsp;

只是有人硬要栽贓影射

&nbsp;

是傻了還是後台很硬、有私下權限...這些我是不知他的用心

&nbsp;

應該不會是更年期到了吧&nbsp;... 

&nbsp;

若感覺誰是我的分身你可以直接跟我對質

&nbsp;

若非我分身你該如何交代...只會躲在後面亂咬

&nbsp;

若從一開始你確定都未私下攻擊我...那請你到天公廟去發誓

&nbsp;

若說謊的人必招譴延綿子孫致斷香火尚可停止...←(這句話重了些)

&nbsp;

敢做不敢當物以類聚...我很無言

&nbsp;

說謊太多會有壞細胞→壞細胞會吃掉好細胞→導致癌症←

&nbsp;

我真的不希望聖人們你們會如此

&nbsp;

&nbsp;

若你是想我要我回來直接跟我說...不用耍這種心機及手段

&nbsp;

無法認同就當放屁風吹雲散

&nbsp;

&nbsp;

刑法第235條第1項：「散布猥褻之文字、圖畫、聲音、影像或其他物品，或公然陳列，或以他法供人觀覽、聽聞者，處二年以下有期徒刑、拘役或科或併科三萬元以下罰金。」


&nbsp;

貼不雅照是有法律責任的

&nbsp;

&nbsp;

但是非該全然承受

&nbsp;
