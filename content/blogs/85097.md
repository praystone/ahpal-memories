種子沈睡3萬年 俄科學家喚醒

放大照片種子沈睡3萬年 俄科學家喚醒

&nbsp; &nbsp; &nbsp; &nbsp;1份新研究指出，俄國科學家在西伯利亞永凍土發現松鼠3萬多年前儲藏的水果種子，並讓種子復活長成完整的顯花植物。

&nbsp; &nbsp; &nbsp; &nbsp;俄羅斯科學院（Russian Academy of Sciences）的雅辛納（Svetlana Yashina）與季里欽斯基（DavidGilichinsky）領導這項研究，他們表示經放射性碳證實那是3萬1800年前的植物種子，這無疑是到目前為止復活的最古老種子。

&nbsp; &nbsp; &nbsp; 在此之前，科學家曾讓以色列死海附近1顆儲藏了2000年的棕櫚樹種子復活。

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;研究人員寫道，這個最新發現可能是古代生物素材研究的重要里程碑，並凸顯永凍土在「尋找古代基因庫的重要性，這些先前存在的生命原本假定老早就已從地表消失」。

&nbsp; &nbsp; &nbsp; &nbsp;這份研究描述在俄國東北部西伯利亞的柯里馬河（Kolyma）下游沿岸發現70個松鼠冬眠洞穴，內有數千顆各種不同植物種子。

&nbsp; &nbsp; &nbsp;研究說：「所有洞穴都在今日地表20至40公尺下發現，所在地層含有晚更新世（Late Pleistocene Age）的長毛象、披毛犀、野牛、馬、鹿以及其他動物等大型哺乳類的骨頭。」

&nbsp; &nbsp; &nbsp;科學家之所以能使如此古老的植物種子復活，主要原因在於這些冬眠洞穴很快就被冰覆蓋，接著就維持「持續冰凍且從未解凍」，這實際上避免永凍土劣化。

這顆種子是在科爾梅亞河(Kolyma River)附近發現，距今已有3萬1千年歷史，與更新世時期的長毛象骸骨一併被挖掘出來。科學家從冰層凍結的情形推測，種子一埋入土裡冰封後，就再也沒有容畫過了。

科學家透過顯微鏡觀察，發現它是「柳葉蠅子草」(Silene stenophylla)的種子，這是一種小型草本植物，會開出白色小花，至今仍在該地區生長。而這顆種子與現代種子唯一的差異為大小，它比它的子孫小一些。

科學家一開始採用一般種植方法，不過失敗了。後來他們挖出這顆史前種子的胎盤組織，移植到實驗室的培養盆中，終於讓這株3萬1千年前的老祖宗重生。研究團隊表示，這株「柳葉蠅子草」帶領人類一窺地球過去環境，或許也能利用同樣技術，讓已經滅絕的植物復活。
