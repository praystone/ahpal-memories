分手了誰比誰更難過


&nbsp;


　　曾經兩個相愛的人，一方提出分手，另一方痛苦是肯定了。但是，不管有多痛，分手時，都請不要和曾經愛我們的人和我們愛的人說狠話，就別再讓對方難過…… 


&nbsp;


　　你好好想想，這個世界上，能傷害到我們的人，一定是我們愛的人；能讓我們受傷的人，一定是愛我們的人。不然，他（她）怎麼有機會在你心上刻下傷痕？他怎麼有資格讓你在情海浮沉？ 


&nbsp;


　　如果命中注定要分手，你還咬牙切齒地說那些可笑的狠話有什麼用？有能耐你一天24小時罵他(她）烏龜王八甲魚鱉試試？人，本來是兩隻腳，現在被你多罵兩隻腳出來，他（她）只會跑得更快，而且會順手帶走以前屬於你們兩個人的東西，一點也不給你剩下。 


&nbsp;


　　既然人家已經放手，你就不要再握著那點微不足道的感情騙自己了。誰都知道，相愛總是簡單，相處太難。相處久了，烈焰激情自然會歸於平淡。而愛情與平淡，本來就是一胎孿生。這樣一來，在兩個曾經相愛的人之間發生悲傷的故事，也就不奇怪了。 　




　　愛，本來是快樂的事，現在，被弄成最傷心的事，你以為只是一方的責任嗎？現代愛情，不是父母說了算的年代；不是王老虎搶親的年代，不是下級有意見上級強制打壓的時代，一切自由都握在你自己手中。當初和他（她）牽手，是何等幸福。


&nbsp;


　　現在提出分手，也許是我們做了讓他（她）感到非常失望的事。上天給每個人，都預備好一張去地獄的單程車票。關鍵是，不要把自己當成天使，不然，就有時時被折斷翅膀的疼痛。　




　　不要相信流行歌曲裡「我的心只有你最懂」，那是騙人的。一個人的心，就是挖出來，放在我們手心裡，再讓我們戴上一萬兩千度窺視鏡，都看不出它裡面的內容。何況，他（她）的心，還好好地包裹在厚厚的皮肉裡呢。


&nbsp;


　　試想，我們的心如果真的只有他（她）一個人懂，那麼，他（她）離你而去，我們這一生不是無人再懂了嗎？無人懂的一生，是可憐的一生，可悲的一生，死活都無所謂的一生。你想自己的一生只為一個人活嗎？遇到這種人，我們不妨反覆唱：「我的心只有你不懂。」 　　


&nbsp;


　　愛，難分對錯，如果我們智慧地分清楚了，那就應該學會把錯忘記。忘記，是一種精神代謝，一個不會忘卻的大腦，如同一個只會進氣、不會撒氣的氣球，早晚讓你憋悶而亡。


&nbsp;


　　其實，我們只要知道，並不是所有的情意，都能纏綿；並不是所有的相遇，都能同行；並不是所有的愛戀，都能長相廝守；就行了。愛人可以走，但是，曾經的情意帶不走。面對轉身的愛情，真誠地道一聲「一路保重」，比硬著心腸說狠話好。 


&nbsp;


　　很多人張大嘴巴高喊：我愛就無怨無悔！


&nbsp;


　　其實，都是自欺欺人的鬼話。付出了，在心底都希望有回報。人心都是肉長的，有這種思想並不可恥。


&nbsp;


就像有的人，心裡明明愛，嘴卻硬說恨，這時候的恨，就像是抹在愛表面的一層黃油，是為了掩蓋真相。不然，愛火熄了，痛就不會燃燒。


&nbsp;


　　但是，千萬不要讓痛灼傷大腦，不要在分手時做愚婦或做蠢男，尤其不要讓對方為當時選擇離開你而感到萬分慶幸。 　 


&nbsp;


　　愛的反面是恨，恨的正面是愛。一個緣字，就會莫名其妙地將正反顛倒。愛像巧克力，吃得太快，品味香甜的時間就要縮短；吃得太慢，剩下的部分又會化掉；恨像酒，喝得太快，讓人沉醉同時也傷胃；喝得太慢，又感覺不夠濃烈。


&nbsp;


　　如果你不能適時恰當地把愛吃掉，不能及時妥當地把恨喝掉，任其發展，它們早晚會變成酒糟一樣即難聞又有毒的東西，這對身體是極其有害的。 　




　　一段感情走到盡頭，我們不要向他（她）傾倒無情的口水來證明我們被拋棄的痛苦和無辜。如果那樣做，能讓我們的傷口好得快一點；讓我們的心理平衡一點；讓我們重新找回自我的時間縮短一點，那麼，我們就不遺餘力地向曾經愛過你的人和你愛過的人猛烈開火吧！


&nbsp;


　　我們一定要近距離瞄準，出手時，爭取彈無虛發，招招致命。早聽說「殺人一千，自損八百。」不相信從你口中說出的狠毒的話，在讓對方無地自容的同時，你自己的心一點也不疼？ 


&nbsp;


　　如果我們真的從心底往外恨，那說明我們根本不是真愛他，我們只是習慣他（她）整天圍著我們轉罷了，他（她）的角色不過是備胎而已。既然從我們這裡得不到重視，人家選擇去為別的車服務，我們有什麼不捨，有什麼不平衡？ 


&nbsp;


　　傷口，是愛的筆記，裡面記載的許多內容是需要我們用一生來忘記的（或許只有死亡的那一刻才能真正忘記）。能夠相伴一生的情感，難道不值得珍惜嗎？痛苦是人生一筆重要的財富，不要輕易踐踏；曾經愛過我們的人，前世一定和我們有緣，不要語言虐待。


&nbsp;


如果他（她）今生真的負了我們，那是因為我們前生負了他（她），紅塵輪迴，無需計較。就像我哭著出生，大家笑了；我微笑著死去，大家都哭了。一切都是輪迴。 


&nbsp;


　　幸福的下一站是痛苦，痛苦的下一站是幸福，越是幸福就越是痛苦，越是痛苦就越是幸福。 


&nbsp;


　　如果，我們真的愛他（她），就應該尊重他（她）的選擇，只希望有人如同我一樣地善待他（她），呵護（她），照顧好他（她）的今生今世。


&nbsp;


　　不！應該比我們還要善待他（她）！呵護他（她）！照顧好他（她）的今生今世！我們應該一如既往地向上帝祝福他（她），而且因為他（她）不在我們身邊，我們無法親自照顧他（她），我們應10000倍地祈求上帝祝福他（她）！ 


&nbsp;


　　這樣我們或許能活地坦然些，能更好地面對未來！
