平平淡淡就是福

&nbsp;



&nbsp;

&nbsp;


人生如電亦如夢、緣起緣滅還自在

&nbsp;

人生如霧亦如幻、情如朝露去匆匆

&nbsp;

&nbsp;

生命是一個過程其間納入了太多的榮辱悲歡， 

&nbsp;

也有太多的不堪回首然，而終是隨波逐流而去， 

&nbsp;

風花雪月畢竟是少年時的過往， 

&nbsp;

而今站在這路的中間抬頭望去，

&nbsp;

未來的路依舊漫長，根本找不到夢的邊緣，

&nbsp;

滄海茫茫不知何時是彼岸，

&nbsp;

一顆飄蕩數年的遊子心，惟獨掌持心中的信念， 

&nbsp;

去追踏自己曾經失去的所有。 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

曾經的往事總是無聲無息的將心情刺痛， 

&nbsp;

然而人生風雨何能避免，

&nbsp;

生命永遠風雨變化無常，

&nbsp;

總有意想不到的突然，離合悲歡只是一個定數， 

&nbsp;

正如淙淙流水所到之處不僅僅只有平坦，還有坎坷，

&nbsp;

既然是水就不可能平靜，總須要奔流前去， 


&nbsp;

有人說離別是為了下一次的相聚， 

&nbsp;

即使相隔異域那麼聚便不是開始， 

&nbsp;

散也就更不是結束。 


&nbsp;

平淡的人才能體會到滿足是一種快樂， 

&nbsp;

是從一個平臺走向另一個更高平臺的短暫休憩， 

&nbsp;

知足不是安於現狀不是急流湧退， 

&nbsp;

更不是一個圓滿的句號，只有平淡生活的人

&nbsp;

才能體會到淡泊是一種享受， 

&nbsp;

&nbsp;

淡泊是一種心境，是經過厲練後素質的修養， 

&nbsp;

淡泊不是看破紅塵，不是對人間一切事物的否定， 

&nbsp;

更不是無所作為的得過且過

&nbsp;

不會淡泊的人必將是傷痕累累

&nbsp;

心緒煎熬而憔悴不堪，做到淡泊將會使心靈淨化

&nbsp;

成晶瑩剔透毫無雜質的翠玉，

&nbsp;

體會淡泊才能如魚得水，

&nbsp;

&nbsp;自由自在地欣賞這美妙的塵世， 

&nbsp;

體驗淡泊才能得意時而不張揚，失意時而不消沉， 

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 


&nbsp;

真正懂得平淡生活才能得到

&nbsp;

&nbsp; 實實在在心安理得享受幸福。才能理解別人善待自己，

&nbsp;

&nbsp;&nbsp; 享受幸福人生平平淡淡就是福。
