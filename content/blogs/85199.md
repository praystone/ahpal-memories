識破12星座的謊言

牡羊座



&nbsp; &nbsp; &nbsp; &nbsp;牡羊心直口快，當他說話的速度比平時要快半拍，噼哩啪啦地說著，還死死地叮著你的眼睛，擺出一副讓你感覺他很真誠的樣子。在他說完後如果你讓他把剛剛說的話再重複一遍，他會用眼斜視你，複述前後出入很大，這就說明他在對你說謊。



金牛座



&nbsp; &nbsp; &nbsp; &nbsp;金牛做事慢條斯理，說話也很輕柔。在他說謊時，他的言語會更溫柔，肩膀還會在不經意間抖動。當你不停追問他時，他還會變得結巴，半天說不出一句話來，或者乾脆就丟下一句「我有事要離開一下，這事以後再說吧」來搪塞你。



雙子座



雙子說謊能以假亂真，但依然會有破綻。他有意要隱瞞你時，會很突然地討好你，向你大獻慇勤，甜言蜜語不斷。說話時眼睛一眨不眨，雙手還插在口袋裡，身子微微向後傾，裝出一副很自在的樣子。可這恰恰說明，他很緊張，在極力掩飾自己的謊言。



巨蟹座



&nbsp; &nbsp; &nbsp; &nbsp;巨蟹不喜歡說謊，只偶爾撒撒小謊。他在說話時老低著頭，用眼角偷偷斜視你，看看你有什麼反應；緊張地搓著雙手，臉頰泛紅，說話吞吞吐吐，讓人感覺他受到了天大的委屈似的，這多半就是在說謊。



獅子座



&nbsp; &nbsp; &nbsp; &nbsp;獅子坦蕩磊落，一般不撒謊。可是，他說話嗓門一點點地提高，在你打斷他或是否定他時，他會在突然間變得很亢奮，把你的質疑一一駁回，說的頭頭是道，擺出各式各樣的事實以證明自己的觀點。有一隻腳還在不停地點地，十之八九是在說謊。



處女座



&nbsp; &nbsp; &nbsp; &nbsp;處女座不懂得撒謊，在沒辦法時才會說謊。他在說謊時會把不好的說成好的，或是盡量用婉轉的詞句來描述事實。還會不自然地摸耳朵，或是用手摸後腦勺，抑或是隨意玩弄手邊的東西，以掩飾自己的緊張與不安。



天秤座



&nbsp; &nbsp; &nbsp; &nbsp;天秤座愛說謊，但他說謊很容易就被識破。你問東他答西，而且還把事情描述得有聲有色，拐著彎繞開你的質疑；或是說話有氣無力，不經意地摸鼻頭，說完還背過臉去偷偷歎氣，這些都是他說謊的明顯表現。



天蠍座



&nbsp; &nbsp; &nbsp; &nbsp; 要識破天蠍的謊言不容易，但只要是謊話就有漏洞。當他說話時非常平靜，甚至鎮靜得有些讓人害怕。或拿著一杯水慢悠悠地喝，或拿著筆不停把玩，反正不讓自己閒著，擺出鎮定自若的神情，從始至終都沒用正眼看你。不用猜，此時的他正在撒謊。



射手座



&nbsp; &nbsp; &nbsp; &nbsp;射手可是說謊高手，他對你說謊還能讓你笑逐顏開。他說謊時聲調會一點點升高，為了烘托氣氛極力表現或高興、或憤怒、或哀怨的情緒，說到激動時會手舞足蹈，詞語不停重複或是顛三倒四，還不停用豐富的眼神試探你，以引起你的共鳴。



魔羯座



&nbsp; &nbsp; &nbsp; &nbsp;魔羯誠實守信，非到逼不得已不會說謊，哪怕說謊那也是善意的謊言。他說謊時說話常常停頓，偶爾還會緊咬下嘴唇，不停眨眼睛，眼神有點恍惚，但很柔和，表現出一副很無辜的樣子，以博得你的認同，希望你不要再追問。



水瓶座



&nbsp; &nbsp; &nbsp; &nbsp;水瓶很懂得說謊的藝術，會說得你糊里糊塗就相信了。他說話時偶爾會擺出一副自己是權威的架勢，還常常賣關子，先把你震住，再以假亂真。只是他那上揚的眉毛，微微不屑的撇嘴卻出賣了他，這些小動作恰恰說明他在睜眼說瞎話。



雙魚座



&nbsp; &nbsp; &nbsp; 雙魚感性，他說謊時要麼像是在編故事，眼睛一閃一閃的，好似有七彩光芒在閃動，沒騙著你卻把自己給「騙」進故事裡了，讓你不忍戳穿他；要麼就是不停地否定你，雙眼通紅，裝可憐，以求得你的認可。
