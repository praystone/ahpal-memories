入我夢來，我願長眠不醒



&nbsp; 



&nbsp; 這個看似安詳的午後，出奇的靜，清晰的只聽見掛在牆上的鍾 「滴 噠，滴噠」緩緩的走著。身體裡惆悵的蠱毒又開始慢慢的爬上來侵襲 我，直到完全被其吞噬…… 


&nbsp;



&nbsp;&nbsp; 那一刻我聽到了心湖上無蕊花乍開的聲音。而我卻不敢去看平靜的湖面是不是也蒙著雨霧的面紗，不敢去看岸邊的楊柳是不是也垂掛著如 淚的雨滴。只因風太冷，怕會刺傷了我的臉頰。只因雨太朦朧，怕會亂了我本就不安的心！ 


&nbsp;


&nbsp;&nbsp;&nbsp; 想擾醒時間的夢，翻叩著生活中美好的部分，努力的想讓自己笑出聲音，而空氣卻不肯睜開沉睡的雙眼，冰冷冰冷的沒有一絲暖意，站起身想掙脫這牽強的擁抱，卻無力逃脫。今生就這樣被困在紅塵世俗的懷抱裡，笑也隨你，怒也隨你，索性就這樣丟掉自己。


&nbsp;


&nbsp;&nbsp; 某個燈火闌珊的夜晚，我夢見有一雙溫暖的大手將我從湖底輕柔的抱起，那麼踏實，那麼溫暖。從那一夜起，我就決定不再屈服於所謂的宿命，我要隨了自己的性子去，我要隨了放任不羈的風狂，我要隨了飄忽不定的雲移，我要隨了瀟瀟蝕骨的飄雪紛飛……


&nbsp;


&nbsp;&nbsp; 任憑歡喜憂愁在我生命裡來回穿梭，是否最終，我的任何都只是在原地踱步？


&nbsp;


&nbsp;&nbsp; 我也曾笑過，哭過，傷過，悔過，卻從未像現在這樣不安過，彷徨過，心也從未像現在這樣不由自主過。堅信是愛情來了，無論是劫是緣，我都不所顧及，縱然是愛到無路可退，我也甘願縱身躍入冥河去邂逅彼岸花開，血液般鮮紅的花瓣將是我瞳孔裡僅有的顏色。


&nbsp;


在一切結果都還只是幻想之際，我已將自己置身在絢麗多彩的夢裡，在金燦燦的麥穗地裡我看到了我愛溫文儒雅的笑臉；在晶瑩剔透的月光杯裡我看到了我愛望眼欲穿的等待；


&nbsp;


在風雨飄搖的茫茫黑夜我感受到了我愛情愫濃烈的思念……夢醒來，我又似乎觸碰到了心裡隱隱作痛的傷口，這道神醫也無能為力的傷，一直等待著我愛來親手將它撫平。


&nbsp;


怎奈思念總是會悄然的滴落在眉間，凝結成眼裡溫熱的淚，淌過臉頰，滴落在心中央，聽見那清脆的聲響，訴說著我懂我愛也懂的語言。


&nbsp;


每晚每晚都欲隨夜的精靈去安撫你叩睡入夢的心靈，用縷縷情絲將你枕起，點燃黑夜裡愛的火種，照亮我愛甜美酣睡的臉。


&nbsp;


&nbsp;&nbsp; 相約彼此不要輕易轉身，是因為彼此瞭解無論是誰先轉身，都將會留下永恆的傷痛與孤寂。那麼就留住吧，留住我這笑顏如花的美麗。


&nbsp;


記不清曾經在哪本書裡看過這樣一段話：


愛情，往往是突如其來的


有時候，你不一定要記住他的樣子


但你會記得他的氣息


他手腕的溫度


他擁抱你的力氣


然後開始牽掛


開始如影隨形迴盪在你的記憶裡


一夜間你懂得愛情也相信你們會相愛


這一切 都是命中注定&nbsp;&nbsp; 既是冥冥中的天意，


既然注定每個人的生命裡都會有一顆屬於自己的流星，


那麼我，會不會就是你的那顆流星？ 


&nbsp;


&nbsp;&nbsp; 


&nbsp;


&nbsp;&nbsp; 佛說：人世有「貪、嗔、癡」三毒，而我，究竟是中了人世間的哪一種毒，且如此無藥可醫。我不知道自己究竟是勇敢的，還是懦弱的，我寧願守著我愛，那怕墜入地獄受烈火焚燒，也不要一個人這樣帶著錐心的痛活著！


&nbsp;


我不知道自己究竟是清醒的，還是朦朧的，不經在皎潔的明月面前潸然淚下：上邪，今生的劫，今世的緣都讓我今生來償，今世來續，又何苦只現三生石跡，荒蕪了這段唯美的遇見。&nbsp;&nbsp; 


&nbsp;


&nbsp;&nbsp; 是啊，人生並不是只有愛情，可人生又怎能缺少愛情。猶如春天不能沒有煙雨，夏天不能沒有知了，秋天不能沒有落葉，冬天不能沒有冰雪那般。


&nbsp;


故事若是沒有主題曲，又怎能算是完美；詩行裡若是沒有靈魂，又如何能煽動人心；蝴蝶若是錯過了花山，天賴村裡若是沒了聲音，又是何其的缺憾。


&nbsp;


&nbsp;&nbsp;&nbsp; 所以親愛的，別說我是花，我並不如花兒那般嬌艷欲滴；也別說我草，我也不想像草兒那般瀟瑟卑微。我只希望是你的寶貝，我只希望在每年的秋天都能收穫到你在春天播種的沉甸甸的愛情!
