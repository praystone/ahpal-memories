【軟體介紹】：

LockHunter 是萬無一失的檔案解除鎖定工具
它是一套免費的工具，用來刪除一些您不知道被何種處理程序所鎖住的檔案。LockHunter 用於對抗惡意程式和其他毫無理由鎖住檔案的程式是相當有用的。與其他類似工具不同的是它將檔案移至資源回收筒以便如果誤刪時您可以將檔案還原。它可強制移除任何檔案，就算那些檔案遭程式鎖定。

主要功能
&nbsp; &nbsp; 顯示鎖定檔案或資料夾的處理程序
&nbsp; &nbsp; 允許解除鎖定、刪除、複製或重新命名遭鎖住的檔案
&nbsp; &nbsp; 允許刪除鎖住檔案/資料夾的處理程序
&nbsp; &nbsp; 允許從硬碟中移除鎖住檔案/資料夾的處理程序
&nbsp; &nbsp; 可以從處理程序中卸載 DLL
&nbsp; &nbsp; 可整合到快顯功能表(安裝版本可以，但是可攜免安裝版不行)
&nbsp; &nbsp; 它將檔案移至資源回收筒以便如果誤刪時您可以將檔案還原
&nbsp; &nbsp; 同時支援 32 和 64 位元 Windows
