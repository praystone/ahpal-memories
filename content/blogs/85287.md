第一招：最常見的大概要算是吉普賽的“專業扒手”，嚴格說來也不算是騙，應說是手法高明快速的“偷”：婦女抱著小孩或幾個小孩子一組，繞著“待宰肥羊”團團轉幾圈，或是拿著報紙靠近你，幾秒鍾就能順利得手了！ rn&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;破解術：少用外露的霹雳包，改用內藏式貼身腰包，護照及金錢都放在貼身腰包裏，口袋只放當天要用的少量現鈔，最重要的是不要讓陌生人有靠近自己的機會。


&nbsp;第二招：在人群中故意散落滿地銅板，當有人目光被吸引，甚至好心蹲下去幫忙撿拾，這時候旁邊早已虎視眈眈的“第三只手”就會趁虛而入了！


&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;破解術：遇事不要太好奇，也不要因身邊發生的事而疏忽該有的警覺性。就算有心想幫助別人，也要先照顧好自己的行李。




第三招：公園裏，慈祥的老先生發現你背後衣服髒了，好心告訴你還幫忙清理。等到閑話家常完、衣服也清理幹淨後，口袋裏的錢和皮包當然也不翼而飛了！


&nbsp;　　破解術：友善的當地居民確實讓人覺得溫暖，但是防人之心不可無，有些事最好還是自己來吧！謝謝“好心人”然後迅速離開現場，最好馬上到人多的地方，以防扒竊不成反被搶。


&nbsp;第四招：快餐店的鄰桌客人（常是中東人）故意丟了人民幣在地上，然後告訴你：“：“是你的錢掉了嗎？”等你低頭撿起來時，鄰桌客人已經和你桌上（或椅上）的背包一起消失無蹤！


&nbsp;　　破解術：在餐廳或快餐店，同桌夥伴去洗手間、只剩自己一人看管行李時，不要理會鄰桌客人的動作和談話，所有行李都不可離開視線。


&nbsp;第五招：“假觀光客”拿著地圖來問路、或是一起研究行程，經過仔細討論後他們稱謝離去，只留下背包已被洗劫過的“真觀光客”。


&nbsp;　　破解術：旅行途中自己也是個需要看地圖的觀光客，被人問路當然不尋常。最好直接說自己也不清楚，馬上離開現場，不要讓自己被包圍在中間，增加騙徒下手機會。


&nbsp;第六招：歹徒假扮警察在路上檢查遊客的護照，還要求檢查攜帶的外幣是否爲假鈔。被帶回假警局（或帶進暗巷）的無辜遊客，不是真鈔被掉包，就是所有的錢全被當成“假美金”沒收了。


&nbsp;　　破解術：一般在沒有犯罪或意外情況發生時，不會有警察來“臨檢”觀光客。如果不能當場判斷警察的真僞，最好說護照和錢都在旅館保險櫃中，或是佯裝聽不懂請當地路人及店家幫忙翻譯，無論如何都不要掏出重要證件和金錢。


&nbsp;第七招：遇到願意權充當地導遊的熱心人，介紹許多景點、交通、食宿資料取得觀光客信任後，再介紹令人心動的黑市彙率，換完錢就發現換來的錢不是少了許多、就是全是假鈔！


&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;破解術：任何國家的黑市兌換都是不合法的，如果在黑市換錢而發生問題時，不但沒有申訴機會可能還要吃上官司。最保險的方法是在銀行換錢，雖然要付些手續費但卻安全得多。


&nbsp;第八招：在“兌換處”（Exchange）換錢也不見得百分之百安全，有時遇上牌告彙率和實際兌換時不同，換完詢問才知道牌告彙率是一次兌換五佰美元以上的優惠，這時想不換也來不及了！


&nbsp;　　破解術：每家銀行或兌換處的彙率、手續費計算都不盡相同，換錢之前一定要先問清楚，例如可問換一佰元美金（現金或旅行支票）可拿到多少外幣？這樣狠快就可以算出實際的彙率，再決定要不要換。換好錢之後，別忘了將護照和錢收藏妥當再離開銀行，以防歹徒早等在外面下手。


&nbsp;第九招：在幣值比較小的國家旅行，面額狠大的鈔票（動辄上萬元甚至百萬元一張）常讓人算不清楚，尤其拿大面額鈔票買便宜小東西時，一不小心花了眼睛，本來該找回九十九萬元卻只拿到九萬九千元！


&nbsp;　　破解術：買小東西時避免用大鈔，若正好沒有零錢就先算好該找多少錢，把找回來的錢當著商家面前算清楚，一旦離開可就沒有機會討回公道了。


&nbsp;第十招：無論是真豔遇或是假豔遇，在旅途中都同樣是的高風險的事。提防有心的騙徒搖身一變爲浪漫的異國情人，一夜風流或俪影成雙幾天之後人財兩失！


&nbsp;　　破解術：出國旅行時，就像脫離平常的現實生活走進另一個時空，狠容易讓人就失去原本應有的理智與判斷力。所以別對旅途中的異國戀情有過多的期待和幻想，就算有緣認識新朋友也不要急于發展，好好保護自己才是最重要的
