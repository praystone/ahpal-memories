&nbsp;



美麗的孤獨，無盡的思念


&nbsp;


&nbsp;


也只有在思念的時候，孤獨才顯得特別美麗。


&nbsp;


思念是一種幸福的憂傷，


&nbsp;


是一種甜蜜的惆悵，


&nbsp;


是一種溫馨的痛苦。


&nbsp;


&nbsp;


思念是對昨日悠長的沉湎和對美好未來的嚮往。


&nbsp;


正是在不盡的思念中，人的感情得到了淨化和昇華。


&nbsp;


沒有距離，便沒有思念。


&nbsp;


&nbsp;


當輪船的汽笛拉響，當火車汽笛長鳴，


&nbsp;


當汽車的輪子開始轉動，當飛機衝出跑道騰空而起，


&nbsp;


思念便開始了……。


&nbsp;


&nbsp;


也正是因為有了思念，才有了久別重逢的歡暢，


&nbsp;


才有了意外邂逅的驚喜，才有了親友相聚時的舉杯慶賀。


&nbsp;


&nbsp;


思念折磨人，也鍛煉人，


&nbsp;


更鑄造了人的性格的沉穩和感情的深沉。


&nbsp;


思念別人是一種溫馨，


&nbsp;


被別人思念是一種幸福，當然好的前提是——彼此思念。


&nbsp;


否則，單相思是一種哀愁，只被別人思念是一種負擔。


&nbsp;


&nbsp;


因為思念，月光被注入了人類濃郁的感情。


&nbsp;


月亮彎的時候，思念也彎；


&nbsp;


月亮圓的時候，思念也圓。


&nbsp;


&nbsp;


不論月亮是彎是圓，思念是一首皎潔的詩。


&nbsp;


思念可以讓你流淚，思念也可以讓你含笑。


&nbsp;


&nbsp;


不論你是哭著思念，還是笑著思念，


&nbsp;


在思念的時候，你都會心無旁騖。


&nbsp;


的確，思念也是一種純淨。


&nbsp;


&nbsp;


思念在朗月下，思念在黃昏裡，


&nbsp;


思念在秋雨中，美麗的景致，


&nbsp;


更易勾動人思念的情懷。


&nbsp;


&nbsp;


美麗的景致，也更襯托出那些蒼涼的美。


&nbsp;


伴隨著不盡思念而來的必然是漫長的等待。


&nbsp;


&nbsp;


美國女詩人荻金森說：


&nbsp;


「等待一萬年不長，如果終於有愛作為補償。」


&nbsp;


這真也可以說是一種思念中的忠貞與豁達。


&nbsp;


不論怎麼說，思念都是一筆巨大的精神財富。


&nbsp;


&nbsp;


一枚枚凝聚著深情的郵票，


&nbsp;


一封封散發著溫馨的信箋，


&nbsp;


都是這比精神財富的內容。


&nbsp;


&nbsp;


歲月盡可以像落葉一樣飄逝，但這筆財富永存。


&nbsp;


在你迢迢的人生旅途中，它會永遠陪伴著你，


&nbsp;


給你綿綿不絕的溫馨和取之不竭的力量!


&nbsp;


（作者：汪國真）
