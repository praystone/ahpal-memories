　牽 手


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;——　　　　　之走在夢裡


&nbsp;


題記：前些日子找了很多牽手的圖片，就一直想寫一首關於牽手的詩歌。那時候正牽著你的手，陶醉在夜色深處的長街。而今，當牽手已成為往事，一個人站在風中，竟不知道該如何路過。


&nbsp;


&nbsp;




寂靜的夜色裡，耳邊又響起那首歌：


&nbsp;


因為愛著你的愛，因為夢著你的夢，所以悲傷著你的悲傷，幸福著你的幸福。


&nbsp;


因為路過你的路，因為苦過你的苦，所以快樂著你的快樂，追逐著你的追逐。


&nbsp;


因為誓言不敢聽，因為承諾不敢信，所以放心著你的沉默，去說服明天的命運。


&nbsp;


沒有風雨躲得過，沒有坎坷不必走，所以安心的牽你的手，不去想該不該回頭......


&nbsp;


&nbsp;


&nbsp;&nbsp;&nbsp; 執子之手，生死契闊。只一句古詩，卻飽含著多少深情。共撐一片天，同走一條路，無論風雨驟，無論歲月深，無論你紅顏老去，也無論我情勢變化，讓我們一起走，生生世世不回頭，這也許就是牽手的內涵吧。


&nbsp;


所以牽手才會成為人們趨之若鶩的經典，才會成為兩情相悅的表徵。無論是什麼年齡，什麼身份，什麼樣的路上，你能夠看到那些牽手的人，臉上都洋溢著幸福的微笑。


&nbsp;


那種飛揚的流淌的感染力，讓你艷羨，也讓你妒忌，甚至於會讓你從心底生出祝福的想法，這也許就是牽手的魅力。


&nbsp;



&nbsp;&nbsp;&nbsp; 牽手，或許很簡單的一個動作，伸出你的手，伸出我的手，緊緊的相握，傳遞深情的暖流。就在那一刻，輕輕的閉上你的眼睛，再睜開的時候，手已經握在手中，那種感覺是無以名狀的美好。


&nbsp;


也或許牽手是一個很複雜的過程，需要等待著緣分到來，那一刻我們恰好相逢，不是擦肩而過，也不是遺憾的平行錯過，你渴望著我的出現，要我期望著你的陪伴，彼此沒有隔閡的全面兼容，才會有一份真心的付出。執子之手，再也不想分開。 


&nbsp;


&nbsp;&nbsp;&nbsp; 曾經一直夢想著與你牽手，靜靜的走在生命中，哪怕再多風雨來過，都能夠溫暖在心窩。


&nbsp;



也曾經真的牽手走過，一段短短的路程，短到那種甜蜜的感覺彷彿曇花一現，就難以再覓蹤影。你總是喜歡感傷，今天終於我可以駐足在感傷裡，回想這一段緣。


&nbsp;


&nbsp;&nbsp;&nbsp; 相逢，是一種冥冥中的巧合。那夜以後，長長短短的相逢在網絡中，我們見與不見都是一樣的牽掛著，就這樣牽手在臨屏的日日夜夜......


&nbsp;



&nbsp;&nbsp;&nbsp; 時間是一個魔鬼，可以讓人忘記，也可以讓人隨時記起。當彼此渴望到達到巔峰的時候，我們終於相聚。這是永遠無法複製的記憶，這是永生無法超越的欣喜！


&nbsp;


&nbsp;&nbsp;&nbsp; 於是我們牽手在紅塵繁華的長街。共看來來往往的人和車，共看遠遠近近的景與色。好喜歡那種甜蜜的感覺，好喜歡那種沒有拘束的時刻。


&nbsp;


&nbsp;&nbsp;&nbsp; 多少次相視一笑的瞬間，多少溫暖澎湃心田。


&nbsp;



&nbsp;&nbsp;&nbsp; 你曾經在牽手時永不言棄，於是我錯誤地以為我們會一直這樣走下去，倦了的身心在你身邊做永遠的棲息，記取朝朝夕夕的魂夢相依。你歌我賦唱和於心，相互欣賞相互鼓勵。同看斜陽脈脈告別的身影，牽手紅塵紛紛紜紜的經歷......


&nbsp;



&nbsp;&nbsp;&nbsp; 也曾經傻傻地癡心夢想著，感受著，牽你的手，甜蜜在心頭長流。你常說月滿西樓，最是深愛不能複製的清幽，你常說雲中誰寄錦書來，如夢如幻的冷冷清秋。你常說今生的緣分你會珍惜到永久，認識你真好，感謝人生中這相逢與相守。


&nbsp;



&nbsp;&nbsp;&nbsp; 曾經千里相思輾轉難眠，月夜下，人同念，千里共嬋娟。你說我會想你在睜眼閉眼之間，我說我會想你在可以思維的每一個空間。


&nbsp;


你說海上共升明月時，是我對你思念的起點；我說晨曦微綻的那刻，是我對你祝福的開篇。我會想你的信息，在我們牽手的第一步，開始到達彼此的心田...... 


&nbsp;



&nbsp;&nbsp;&nbsp; 曾經篤信你就是我的緣，茫茫人海，尋尋覓覓，相知在眼前。牽手聽潮來潮去那些千古的感歎，牽手看雲卷雲舒這自在的清閒。每一次你的飛鴻悄悄盤旋，我都望眼欲穿。每一次讀你的信箋，我都淚濕心田。


&nbsp;


為你的深情而眷戀，為你的執著而流連，為你的才情而傾倒，為你的境遇而感歎。不忍你感傷，不忍你孤單，默默的守候，默默的陪伴。


&nbsp;



&nbsp;&nbsp;&nbsp; 你說你喜歡蘇軾的才情與才智，你說你希望自己有一天，也可以詩書畫三絕於世，我說我相信總會有那麼一年，你的夢想必然會實現。


&nbsp;


於是，我願做你第一個執著的粉絲，用堅定的心和執著的愛，跟隨你前行到永遠。在我眼裡，你已經是東坡，你已經是畫聖和詩仙。在別人眼裡是身份的差別，在我心裡不過是時間的早晚。


&nbsp;



&nbsp;&nbsp;&nbsp; 你曾經說我才是你真的知己，是你所有情感的焦點，於是我相信自己一定是你的必需，有我的日子裡你不再孤單，安心做你的陪伴。快樂著你的快樂，思緒飛越萬水千山；痛苦著你的痛苦，放逐文字為你心酸。走過你的路，承受你的苦，揮灑萬語千言。用我的心，牽你的手，為你執著每一天。 


&nbsp;



&nbsp;&nbsp;&nbsp; 你說希望我們永遠不要分離，於是我放棄了所有的去路，全心全意只做你的信徒，給你一生的承諾——風雨共赴！牽手不再畏懼世俗，牽手不再擔心陌路，沒有什麼可以阻擋，兩顆心的結合一處！共情常駐，種愛成樹，讓心有靈犀與紅塵同步！


&nbsp;



&nbsp;&nbsp;&nbsp; 知道你曾經受苦很多，我多想用我全部的愛給你一個最溫暖的空間。知道你一個人在天涯漂泊，我多想用我的努力為你建造安定的家園。知道你沉浸在藝術的天地，我多想用我的心給你最有力的支援。知道你會醉在夢的曉風裡，我就早早抱著衣服等你在明月下的楊柳岸......&nbsp;&nbsp;&nbsp; 


&nbsp;


&nbsp;&nbsp;&nbsp; 感歎與感慨交錯，忽然想起了那句詩「此事不管風與月」！是啊，風來過的時候，我從風中走過了；月一直在微笑著，我在月下迷茫了。找尋那些記憶的種子，播撒在生命的綠洲，為此，我收集了牽手的圖片，對著那些從前的片段，想細細的咀嚼，一遍又一遍——


&nbsp;


&nbsp;&nbsp;&nbsp; 人道是金風玉露一相逢，便勝卻人間無數，為著七夕一聚，我奔波幾千里，卻終還是沒有在七夕見到你！幸好你說在我們的心裡有，就天天是七夕。我感動的無語。 


&nbsp;


&nbsp;&nbsp;&nbsp; 最近的離別可是最遠的思念？淡淡的問候可是最濃的祝願？拚命的忘可是最深的牽念？


&nbsp;


&nbsp;&nbsp;&nbsp; 往日的身影是如此的遙遠，淚水交流，模糊了我的視線——


&nbsp;


&nbsp;&nbsp;&nbsp; 我說我好想你，你說我也是。那些時候，我常常會醉的一塌糊塗。今天，我依然在想念著你，可是你還會說我也是麼？


&nbsp;


&nbsp;&nbsp;&nbsp; 回想過去，我們那些深深的渴望，那些深情的話語，讓我的淚水流滿心裡。


&nbsp;


&nbsp;&nbsp;&nbsp; 曾經幻想著就這樣走下去，一直到永遠。可以牽你的手，不問季節的變換，不問塵世的滄海桑田。應你的出塵之約，走在空靈的邊緣。即便化成你的影子，只要可以不離尺寸之間，我也會心甘情願。在心裡種下春天的希望，等候著秋天的豐收滿園——


&nbsp;



&nbsp;&nbsp;&nbsp; 此刻，我多麼想再聽你唱歌，唱那首濤聲依舊！想著和你牽手一起去看海，看那潮來潮去中等候的客船！那該是多麼美好的場景啊！可是你還會給我唱歌麼？你還會陪著我去看海麼？


&nbsp;


你說下次有機會的，下次，下次在哪裡呢？下次，還會濤聲依舊麼？ 聽你唱那些老歌的日子，那些和你共飲一壺酒的渴望，會淹沒在夕陽裡麼？
