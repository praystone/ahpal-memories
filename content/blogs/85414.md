&nbsp;

定做一個緣




&nbsp;


&nbsp;

&nbsp;


相見，是現實中的相遇

&nbsp;

懷念，是回憶裡的重逢

&nbsp;

人生一世，永遠不可能完美

&nbsp;

時間實在可怕它可以腐蝕一切，即使再堅強的心，

&nbsp;

遺忘也許是不可改變的宿命

&nbsp;

即使淚流滿面，就算隱隱作痛

&nbsp;

我們最終也會將彼此相忘於時間的無涯中

&nbsp;

一次偶然的擦肩而過

&nbsp;

一次無心的驀然回首

&nbsp;

也許就是另一個開始

&nbsp;

有幾分可笑

&nbsp;

但是人生就是那樣難以捉摸，變幻莫測

&nbsp;

一生可能就是因為那一天

&nbsp;

輕輕抬頭，淺淺微笑

&nbsp;

&nbsp;

總覺得「緣份」二字太過於矯情

&nbsp;

但是除卻兩個字

&nbsp;

實在找不出其它的詞語來詮釋

&nbsp;

人和人之間的相遇，相知，乃至相守

&nbsp;

你我相逢在茫茫人海

&nbsp;

剎那的光輝鑄就了一段刻骨銘心

&nbsp;

雖然並非總是柔情似水

&nbsp;

雖然可能是百感交集

&nbsp;

雖然最終還是勞燕分飛，相隔天涯

&nbsp;

但是那曇花一現的交集

&nbsp;

卻如午夜絢麗燦爛的煙花

&nbsp;

瞬間的美麗過後，回歸了夜的黑暗

&nbsp;
