三隻鬼的投訴 





&nbsp;

&nbsp;


話說有三隻倒楣鬼，有一天他們

&nbsp;

在逛街的時候遇到了上帝！ 


他們對上帝說，他們都死得很慘，

&nbsp;

希望讓他們上天堂！ 

&nbsp;

上帝很無奈地說，現在天堂的住戶太多，已經爆滿。

&nbsp;

但現在還有一個名額！

&nbsp;

你們說吧，看誰死得最慘，就讓誰上天堂！ 


&nbsp;

於是，第一個鬼開始說了～～

&nbsp;

我生前是一個清潔工。工作很辛苦的！

&nbsp;

從早忙到晚！

&nbsp;

有一天，我正在一棟大廈外面擦玻璃！ 

&nbsp;

是那種吊在外面的高空危險工作！在第30多樓！

&nbsp;

突然，我腳一滑，失足掉下去了！

&nbsp;

我想，完了！要死了！

&nbsp;

但求生本能讓我在無意識地亂抓！

&nbsp;

很幸運地，我抓住了一個陽臺的欄杆，在13樓。

&nbsp;

我想，有救了！於是想等緩過勁後爬上去！

&nbsp;

哪知，突然有人把我的手一揎，我又掉下去了！

&nbsp;

我想，這下我真的完了！

&nbsp;

但是，我命不該絕，底下有一個帳篷接住了我，

&nbsp;

我慶幸前世肯定積了德！

&nbsp;

想等緩過勁就下去。

&nbsp;

誰知，上面掉下來一個冰箱，把我給砸死了！ 

&nbsp;

&nbsp;

&nbsp;

第二個鬼說～～

&nbsp;

&nbsp;我生前是一個文員。什麼都還好，

&nbsp;

我有一個老婆，很漂亮。身材很棒！

&nbsp;

但就是有點水性揚花。我有輕微的心臟病。

&nbsp;

有一天上班忘了帶藥，我回家去拿。

&nbsp;

一進門，看見老婆頭髮散亂、衣衫不整。

&nbsp;

肯定有姦夫。 

&nbsp;

於是我滿屋找，廚房也找，廁所也找，都沒找到。

&nbsp;

到了陽臺，我發現有兩隻手扒在欄杆上，

&nbsp;

我想：姦夫！於是把他的手一揎。

&nbsp;

心想，13樓！看摔不死你！

&nbsp;

結果等我一看，居然沒死！被帳篷接住了！ 

&nbsp;

我著急，於是滿屋找，進了廚房，發現冰箱夠大，

&nbsp;

於是把冰箱扔下去。終於把他砸死了！

&nbsp;

我當時太高興了！大笑不止。 

&nbsp;

誰知笑得心肌埂塞，笑死了！ 

&nbsp;

&nbsp;

&nbsp;

第三個鬼說～～

&nbsp;

我生前是個小混混，但我沒做過什麼壞事！

&nbsp;

有一天我到一個女性朋友家裡晃！

&nbsp;

剛剛辦完事，她老公突然回來了！

&nbsp;

我得找地方藏起來。於是廚房也找，廁所也找，

&nbsp;

最後發現他們家冰箱挺大的，

&nbsp;

於是我就躲進冰箱裡去了！我就不明白，

&nbsp;

她老公怎麼知道我在冰箱?，

&nbsp;

他居然把冰箱從13樓給扔下去了！

&nbsp;

我就這樣連人帶冰箱摔死了！ 

&nbsp;

看來這三個鬼裡面最倒楣的就是那位清潔工鬼吧，

&nbsp;

辛勤的工作卻發生意外，

&nbsp;

僥倖逃過一劫卻又被人砸死。


&nbsp;
