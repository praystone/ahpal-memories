愛到放手 


&nbsp;



　　　　　　感激傷害你的人，因為他磨練了你的心態；　



　　　　　　感激絆倒你的人，因為他強化了你的雙腿；



　　　　　　&nbsp;感激欺騙你的人，因為他增進了你的智慧； 



　　　　　　感激蔑視你的人，因為他覺醒了你的自尊；



　　　　　　感激遺棄你的人，因為他教會了你獨立。



　　　　　　凡事感激，學會感激，感激一切使你成長的人！ 


&nbsp;


&nbsp;


&nbsp;


　　　　　　有一種愛叫放棄...... 


&nbsp;


　　　　　　有一種愛叫掛著淚珠但很淒美....... 


&nbsp;


　　　　　　有一種愛叫放手但放手不是放棄愛你…… 


&nbsp;


　　　　 一些黑夜來臨的夜晚，思念就像潮水般湧向心底.曾經的一切已成了過眼煙雲, 過去的事物已徹底改變了模樣.是否還記得:那滴曾經的淚,那臉曾經的笑,那份曾經的愛憐,是否要忘記過去人,過去的心,


&nbsp;



　　　　　　如果不是那偶爾的邂逅，你我即便擦肩，也會行同陌路．也就不會有現在的失意，痛苦，追溯...更不會日日夜夜牽掛．如果...如果...如果沒有如果...　　




　　有緣的相識，相知，相惜，卻是沒有份的相守，相伴，相攜．分分合合的過程裡，早已注定了此生的不得已，再回首，物是人非過... 


&nbsp;


　　　　　　　於是，習慣了在一個人的寂寞裡，空蕩蕩的身體在尋找蜷縮靈魂的角落，任淚水恣意橫流...過著靈魂與軀體分離的日日夜夜．


&nbsp;



　　　　　　離開你，離你生活的城市上千里，卻仍然發現，思念會再突不及防的某一時刻，突然來襲．那些過往的回憶，就像是閃爍的玻璃碎片，在昏暗的角落裡閃爍著光芒，用其獨有的魅力吸引著靈魂,欲罷不能,無法捨棄。


&nbsp;



　　　　　　電話拿起又擱下,信息寫好又刪除,最終只留下鹹鹹的淚水在不知不覺中默然滑落．．．．．． 


&nbsp;


　　　　　　聽．．．那歌聲明白了此時的靈魂： 


&nbsp;


　　　　　　鬆開你的手讓你走 


&nbsp;


　　　　　　沒有人會知道我的感受 


&nbsp;


　　　　　　若有一天你會發現 


&nbsp;


　　　　　　我在這裡等候 


&nbsp;


　　　　　　分手才是永恆 


&nbsp;


　　　　　　．．． 


&nbsp;


　　　　　　感受著無奈裡的心痛，感受著不得已的放手．．． 


&nbsp;


　　　　　　既然無法擺脫前世的定數,今生的束縛,為何,為何卻要相遇? 


&nbsp;


　　　　　　－－－如果沒有相遇,今生將又是如何走下去? 


&nbsp;


　　　　　　相遇是一種折磨，不遇卻是一種痛徹底心菲的錯過。 


&nbsp;


　　　　　　．．． 


&nbsp;


　　　　　　想到流淚的時候 


&nbsp;


　　　　　　一切都會變得模糊．．． 


&nbsp;


　　　　　　選擇了離開的時候， 


&nbsp;


　　　　　　也選擇了放手， 


&nbsp;


　　　　　　所謂的愛－－－就這樣漸漸的逝去 


&nbsp;


　　　　　　可是， 


&nbsp;


　　　　　　遠離熾烈的愛的火焰， 　　　




　　　　　　卻不能遠離對彼此深深眷戀。 


&nbsp;


　　　　　　於是， 


&nbsp;


　　　　　　愛一旦檫肩，咫尺即成天涯。 


&nbsp;


　　　　　　．．． 


&nbsp;


　　　　　　以後的過程裡， 


&nbsp;


　　　　　　沒有方向也沒有幻想 


&nbsp;


　　　　　　但願忘記那憂傷忘記這迷惘 


&nbsp;


　　　　　　忘記曾許下的願望 


&nbsp;


　　　　　　可是誰又瞭解 


&nbsp;


　　　　　　雖事過境遷 


&nbsp;


　　　　　　愛卻是永遠不可能的遺忘 


&nbsp;


　　　　　　那是一道永恆的傷 


&nbsp;



　　　　　　．．． 


&nbsp;


　　　　　　如果真愛，是一種幸福，心痛也是幸福 


&nbsp;


　　　　　　如果真愛，是一種享受，心累也是享受 


&nbsp;


　　　　　　如果真愛，是一種體會，心碎也是美麗 


&nbsp;


　　　　　　．．． 


&nbsp;


　　　　　　有一種感覺總在失眠時，才承認是「相思」 


&nbsp;


　　　　　　有一種緣分總在夢醒後，才相信是「永恆」 


&nbsp;


　　　　　　有一種目光總在分手時，才看見是「眷戀」 


&nbsp;


　　　　　　有一種心情總在離別後，才明白是「失落」 


　　　　　　．．． 






　　　　　　在時間的輪迴裡，沉沉的思念成了定格靈魂的枷鎖：愛不需要任可理由，忘記卻需要多少的借口？！


&nbsp;



　　　　　　愛可以由一面微笑來開始，一個長吻來成長，一滴眼淚來結束，一生思念來牽掛...愛一個人時可以不感到孤單，但想念一個人時卻一定會感到孤單...... 


&nbsp;


　　　燈睡了，把自己獻給了平庸的黑夜；影回了，把自已放進了麻木的軀體，而靈魂還在徘徊...沒有人懂得這種忠誠，當一切都在睏倦的失望中熄滅以後，思念的心會不會從身後走近我？ 


&nbsp;


　　　　　　愛到無語，愛到淚流，愛到無奈，愛到無求，愛到最終的釋然放手......
