我想跟你 一起浪漫!一起生活！一起平淡！一起變老


&nbsp;


我想這樣過我今後的人生--平淡卻幸福


&nbsp;


20——30 歲和你一起浪漫，


&nbsp;


冬天的夜晚騎車去湖邊聽薩克斯，天很冷，我的手套讓你帶，我站在車後座，用雙手幫你捂耳朵，


&nbsp;



夏天的傍晚一起坐路牙石上吃西瓜，你一半，我一半，但我還搶你的吃，我不小心把西瓜汁濺到身上，你邊罵我笨，邊給我擦


&nbsp;



春天的下午，我們一起去公園照相，只有我們兩人，沒法合照，於是，我們趴在地上，看著地上的相機傻笑，橫著合影，比豎著YA


&nbsp;



秋天的早春，我們一起運動，我耍賴不跑，你拿我沒轍，無奈的蹲下，我哈哈狂笑，剛爬上你的背，就被你撂倒。


&nbsp;


我幸福的等待，直到那一天的到來，我打開你送我的大盒巧克力，我看到你排列出的marry me。然後我哭著和媽媽擁抱，帶著我最愛的戒指投入你的懷抱


&nbsp;


&nbsp;


我們幸福的等待，直到那一天的到來，你要陪我看著他來到人間，再深吻我沾滿汗水的額頭，老婆，辛苦了


&nbsp;


&nbsp;


30——40，我們一起生活，


&nbsp;



每天上班下班，你親我一下，親寶寶一下，然後喝我煲給你的湯，每晚我們一起給寶寶講故事，知道他進入夢鄉，我陪你看球賽，從被迫變成粉絲；


&nbsp;


你陪我看韓劇，從無奈看到自願，我們在夜裡相擁而眠，我一個轉身，你會馬上醒來拉拉我的被，幫我蓋好，再去看看寶寶。我們在早晨拚命飆車趕時間，臨下車我還能有時間塞你一袋牛奶。


&nbsp;


下雨了，你會主動接我下班，除了一把雨傘，還有溫暖的外套。你工作不順利，我不去煩你，給你泡你最愛的咖啡，悄悄走開，我會在你的旁邊幫你熨燙明天要穿的白襯衫，你無意抬頭看我，給你最窩心的微笑


&nbsp;



節假日我們去看望雙方的父母：在你媽面前，我溫順的像任你宰割的羔羊；在我媽面前，你是世界上最好脾氣的大力士，我爸自從有了你，再也不用干家裡的重活……


&nbsp;


我們偶爾爭吵是為了寶寶：你吼他，我吼你；我打他，你讓我打你


&nbsp;


&nbsp;


40——50，我們一起平淡，


&nbsp;



孩子一天天長大，我們一天天年長，不再那麼心高氣傲，我們開始習慣平靜，週末的早晨我們一起買菜，買到一把新鮮的蔬菜足夠開心一天，


&nbsp;


有假的時候我們出去旅遊，不去擁擠不堪的景點，專去幽靜美麗的小鎮，我暈車，你習慣得從口袋拿出一片藥。


&nbsp;


我開始嘮叨，不讓你吸煙喝酒，你越來越知道給我買化妝品，嘴上還說我依然寶刀未老。


&nbsp;


我繡十字繡開始讓你替我穿線，而你也發現眼有點花，我們經常幫對方拔去冒出的白髮，回憶年輕時的點滴，你老說起我原來給別人寫過情書，我更是逼問你有沒有和初戀情人那個老太婆聯繫。


&nbsp;


我們的孩子已經上了大學，我們老是擔心他有了女朋友而偷聽他的電話。


&nbsp;


&nbsp;


50——60我們一起變老，


&nbsp;



腰有一點彎，我們都快退休了，我們都要吃常規的保健藥了，你突然學會了和我搶電視，我拿你沒辦法，有了兒媳婦，兒子似乎成她的了，我們好期待週末，能看他一眼。


&nbsp;


你老是看你的花，你的魚，不再喜歡看我；我也看膩了你，總是翻我們的相冊，年輕時的你多好看啊……我生病了，你陪我看醫生，醫生說沒什麼問題的瞬間，我們都鬆了一口氣。


&nbsp;


我們偶爾還去年輕人愛去的餐廳，雖然覺得貴，也會浪漫一下，我總問你多久沒說愛我了，你笑著說我更年輕，我不明白，原來是更年期！


&nbsp;


我收拾床發現了你的私房錢，又悄悄放回去，不久後，我們的結婚紀念日上，我送我了一個無比美麗的玉鐲：我哭了，你說我真僑情；我笑了，你說老太太真是可愛


&nbsp;


&nbsp;


60——70，我們一起糊塗，


&nbsp;


越來越愛忘事，電話號碼都記不清了，你每天去接孫子放學，我天天做飯等你們。看電視的時候你幫我按摩，按著按著你睡著了，我每天和你早起舞劍，人家都說我們有夫妻之象。


&nbsp;


我們都去配了假牙，一摘下來，就互相笑話，你還有點耳背，我讓你盛飯，你給了我一隻雞蛋。我抱怨身體不再那麼硬朗，你卻說我們能活120歲，


&nbsp;


現在剛到中年，我發現你沒事老買彩票，難道一把老骨頭還想發財，你卻說想給我多留點錢，萬一你先走，我上去就是一腳，不許胡說，你要伺候我一輩子，咱們一起死，誰先死了，另一個就自殺，誰不自殺誰孬種


&nbsp;


&nbsp;


70，80，90……我們腦子不好，應該不知道幹什麼了，總之，天天守在一起，兒孫把我們照顧地很好。


&nbsp;


如果有可能，我希望還能照一次婚紗照，等我們走了，在合葬的墓碑掛上它，多神氣！雖然我的手滿是皺紋，你還是要緊握，因為我們一起幾十年，都是攜手走過。。


&nbsp;



這就是我要的生活，很幸福，我相信上帝會讓這個夢成真。


&nbsp;


還有著淡淡的歌聲~
