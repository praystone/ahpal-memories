　　轉身 也是深愛


&nbsp;


&nbsp;


　　誰是我的救贖，誰令我笑靨如花。 


&nbsp;


　　這個問題，我傻呆呆地思考了很久。 


&nbsp;


　　結果仍是以問號呈現。 


&nbsp;


　　或許誰也不是誰的救贖，誰也無法給誰足夠的依賴。 


&nbsp;


　　我站在十字路口，張皇失措。 


&nbsp;


　　向前，退後，往左，往右。 


&nbsp;


　　皆望不到盡頭。 


&nbsp;


　　一場意外，一場相識，邂逅了愛情。 


&nbsp;


　　可是你告訴我，這是幸運還是不幸。


&nbsp;


　　我躺在時光裡，看塵事飛逝。一幕幕情節，驚心動魄。


&nbsp;


　　這是置身於我的舞台的故事，痛徹心痱，我努力想要抽離，等不及謝幕.


&nbsp;


　　如果年輪可以倒轉，我是否可以選擇觀望而非演繹。 


&nbsp;


　　記憶無法定格，那些美好的畫面只是經過。


&nbsp;


　　把點滴風景一一素描，放入相框標成標本。


&nbsp;


　　站在清冷的季節裡，娓娓鋪開陳舊的時光，


&nbsp;


　　看到的只是淚在手心跌碎成鑽石，在大片大片的蒼白裡發著寒光。 


&nbsp;


　　然後滲入空氣消失無影蹤。 


&nbsp;


　　怎樣才算是堅強？孤傲地抬頭不許淚流，


&nbsp;


　　一個人生活一個人歡笑一個人幸福。我告訴自己要學會要做到。 


&nbsp;


　　也告訴自己，愛情是奢侈的東西。


&nbsp;


　　它是懸掛在天空的星辰，遙遙相望，無法觸及。


&nbsp;


　　傷了，不愛了。痛了，明白了。哭了，心碎了。


&nbsp;


　　於是忘記，於是結束，於是不願再碰手愛情。


&nbsp;


　　那些刻骨銘心的記憶在時光的剝削中削瘦成線，密密的縫在心頭。


&nbsp;


　　不給於他人看不講於他人聽。只當在某個回望的時刻，把它深懷地鋪在自己平靜的歎息裡。 


&nbsp;


　　一些結局，我們的選擇，要自己承受。


&nbsp;


　　或許這是前世被遺棄的夢，只是我還沒有選擇放棄.


&nbsp;


　　緊緊拽著一點殘記，做著垂死的掙扎。


&nbsp;


　　可是我錯了，我們誰也不誰的救贖。


&nbsp;


　　你沉默地轉身，絕然的離去，徒留我在原地撕聲地哭泣。 


&nbsp;


　　你的背影是我絕世的遙望。 


&nbsp;


　　結局是注定還是偶然，已經不再重要。


&nbsp;


　　有些事情可以天長地久，有些事情只能留下遺憾。


&nbsp;


　　太耀眼的城市不適合看星星，就如同頹靡的心不適合談愛情。


&nbsp;


　　絕決的意念猶如刺蝟般讓人生畏。


&nbsp;


　　擺擺手，不言離別不言珍重，忘卻前塵。


&nbsp;


　　轉身行走自己的軌跡，忘了說，還有深愛.
