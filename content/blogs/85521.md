幸福·內涵


&nbsp;


　　幸福的含義是什麼？ 幸福就是……


&nbsp;


　　張開雙臂，為寒冷的人送去溫暖 


&nbsp;


　　展露笑顏，給哀傷的人帶來歡樂 


&nbsp;


　　幸福是無私奉獻、助人為樂！ 


&nbsp;


　　幸福就是自在的漂游！ 


&nbsp;


　　吹散薄雲，令和煦的陽光撒滿大地 


&nbsp;


　　輕撫風鈴，帶跳躍的音符飛向高空 


&nbsp;


　　幸福是隨心所欲、瀟灑自由！ 


&nbsp;


　　幸福就是隨性的飛翔！ 


&nbsp;


　　洗刷塵埃，讓污濁的世界回復透徹 


&nbsp;


　　喚醒綠意，用蓬勃的生命代替荒涼 


&nbsp;


　　幸福是輕靈純淨、生機盎然！ 


&nbsp;


　　幸福就是熱情的贈與！ 


&nbsp;


　　掃去陰霾，令大地充滿火樣的熱情 


&nbsp;


　　驅走灰暗，讓冷漠的人心尋回關懷 


&nbsp;


　　幸福是光明正大、寬宏大量！ 


&nbsp;


　　幸福就是周到的關懷！ 


&nbsp;


　　默默陪伴，使不安的心靈獲得平靜 


&nbsp;


　　無聲支持，為夜路的旅人指明方向 


&nbsp;


　　幸福是善解人意、無微不至！ 


&nbsp;


　　幸福就是勇敢的前進！ 


&nbsp;


　　擺脫困擾，讓重負的憂愁掙開禁錮 


&nbsp;


　　相信自己，放美麗的夢想自信飛翔 


&nbsp;


　　幸福是堅定信念、勇往直前！ 


&nbsp;


　　幸福就是真誠的感情！ 


&nbsp;


　　澆灌友誼，陌路的人們會成為朋友 


&nbsp;


　　珍藏愛情，寂寞的靈魂會擁有歸宿 


&nbsp;


　　幸福是執著夢想、懷抱希望！ 


&nbsp;


　　我追尋，所以我快樂！
