妳說
&nbsp;
歌詩的汐音只存於海潮
&nbsp;
我聽
&nbsp;
今夜我因妳的歌而來
&nbsp;
若不登岸
&nbsp;
春待的少女
&nbsp;
將不化為泡沫
&nbsp;
頌唱遙遠悠久的思暮之音
&nbsp;
佇於岬上之愚者同我將拜訪
&nbsp;
醉於絕非幻想的流歌

&nbsp;妳詞中思念著誰人?
&nbsp;
另有其人的水之民的贈禮
&nbsp;
伸手接收的&nbsp; 卻是我
&nbsp;
妳與汐歌&nbsp; 低泣&nbsp; 悲鳴&nbsp; 淒嘯著&nbsp; 哽咽了
&nbsp;
仍以長夜延著的魚尾
&nbsp;
延著期限
&nbsp;
延著地與海的必然距離
&nbsp;
這不想毀壞的關係

我苦笑著
&nbsp;
刺殺那份奢望的過際之情
&nbsp;
再次聆聽
&nbsp;
至滿潮消逝的一刻
&nbsp;
創作理念:&nbsp;普遍說到人魚，自然就會聯想到童話故事;但在這裡,我只是在悲嘆特定的人與另一群特定的人是無法接近太多的.這個世界上有著明明近在咫尺,卻還是萬分不合的人們,就像是地與海之間的住民要是想要與對方結合,卻被人魚的海潮之歌與惡作劇拖向死之門扉.......
&nbsp;
我覺得人魚應該不是喜好惡作劇,或者是就那麼討厭人類(好吧 現在有充分的理由可以討厭);我的觀點是從人魚出發,因為無法結合的事實而親手斷送自己的愛情與真心,卻還是有種不肯放手的猶豫與不捨;哪知道,這樣越是延長,兩人之間越是備感遙遠.即使是愛人真的死了或是背叛了,會有找個誰當作替代的想法,但當愚者的旅者給她溫暖的擁抱,她卻下意識的將這一切推開.人心如此 與人同源的人魚也是吧?有些人以為我是把人的人文投射到自然中移情,但是我從來沒這麼想.只是覺得,人以外的生命應該也有這樣的心.最後的無限延期只是習慣性地等待,人魚只是習慣性地等待一種早已沒有實體且虛幻的憧憬,最後只能哀鳴哽咽,甚至沒有淚珠.
&nbsp;
這是去花蓮七星潭的夜裡,那種彷彿在海潮中聆聽到人魚之歌的心情(其實那天因為一些意外與受傷的關係,我是心情非常之不好的;只有那裏的星空海夜能讓我冷靜些吧?);也許人魚真的就只是那個醜惡的海牛,也許人類不可能聽到人魚的流歌,但誰在乎?我就是覺得我能聽到,真正的聽到了,水之住民在海潮之中的悠久之歌.現在,除去那時的心情特寫,我覺得這真是個令人感動的地方.所以,我在昨天下午(重編日期是今天十二月十日凌晨兩點三十分)參加了七星潭的環境保育聯署.我可不希望,能夠聽到人魚之歌(我相信那並不是幻覺)的海角被人類給親手破壞啊!
