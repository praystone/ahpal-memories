 rn&nbsp;別讓生活輸給心情

&nbsp;

生活本身就是就是一種承受，

&nbsp;

承受痛苦；承受幸福；承受平淡；

&nbsp;

承受孤獨；承受失敗；承受責任


&nbsp;

過去的就讓它過去吧，

&nbsp;

因為拋下不必要的包袱，生活才會更好，

&nbsp;

人生如此的短暫有什麼理由不去好好的生活呢？

&nbsp;

有太多事情要你去做，有很重要的人等著你去珍惜，

&nbsp;

不要回頭看，前面的世界更精彩。


&nbsp;

當一切都可以看開時，

&nbsp;

往往也是沒有什麼可以失去的時候，

&nbsp;

時間就會把往事沖淡了，只留下美好的記憶，

&nbsp;

還有擦肩而過的燦爛笑容和寂寞黑夜裏的溫暖燭光。


人生是一個遺憾的過程，稍不經意的一次回眸，

&nbsp;

滿眼往事中最令人難忘和記憶猶新的，

&nbsp;

注定是曾經有過些許的遺憾，

&nbsp;

重要的是不要因為太多的無奈，

&nbsp;

太多的遺憾，而忘卻了風雨兼程的行旅。


&nbsp;

你改變不了環境，但可以改變自己；

&nbsp;

你改變不了事實，但可以改變態度；

&nbsp;

你改變不了過去，但可以改變現在；

&nbsp;

不能預知明天，但可以把握今天。


&nbsp;

平平淡淡才是真生活，

&nbsp;

花自飄零水自流，世間本來就無十全十美之事，

&nbsp;

何苦庸人自擾呢？

&nbsp;

就用淡淡的微笑去化解心中那份惆悵吧。

&nbsp;

不管怎樣，輸什麼也不能再輸了心情！
