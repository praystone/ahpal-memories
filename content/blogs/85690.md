放學後得等公車，擠得像沙丁魚罐頭，<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


&nbsp;


好不容易擠了上去，終於在司機旁搶得一個位置，


&nbsp;


但手卻無處扶搭，於是只好抓著票箱保持平衡。


&nbsp;


在一團混亂中，司機突然在一個轉彎處緊急煞車，


&nbsp;


情急之下，我只好抓緊零錢箱，


&nbsp;


沒想到那年久失修的零錢 箱竟然就這樣被我整個抽起來....


&nbsp;


全車的乘客望著我笑成一團；


&nbsp;


&nbsp;


&nbsp;


&nbsp;


而<?xml:namespace prefix = st1 ns = "urn:schemas-microsoft-com:office:smarttags" />司機先生這時候也說話了：小姐，我們做的是小本生意，請妳手下留情。
