分手時會傷害對方的星座男



&nbsp; &nbsp; &nbsp; &nbsp;愛情的世界有一句話特別流行：分手後我們不能做仇人，因為彼此深愛過；也不能做朋友，因為彼此傷害過。深愛是因為激情還在，傷害則有太多的無奈。都說男人多情，但深情的背面就是無情，究竟哪些星座的男人一旦絕情起來，會傷害對方最深呢？ 



TOP1 天蠍男



&nbsp; &nbsp; &nbsp; &nbsp;愛情初始，天蠍男全心全意，不顧一切付出真心，就算這段感情不被祝福，就算未來有著太多不可預計的困難，他也會咬牙堅持到底，把愛你當作是天責。只是，這世間唯一不變的就是變，當愛情走到分岔的路口，當天蠍男確定自己已經變心，就會毫不客氣，會坦白自己的心已他屬，在你也付出所有以後，換來他一句：「對不起，現在才發現，我們不合適。」並且他不會覺得這有什麼不對，不愛就是不愛了，拐彎抹角的敷衍有什麼意思？至於，你是心痛，還是心死，都不會是他考慮的。



TOP2 牡羊男



&nbsp; &nbsp; &nbsp; &nbsp;牡羊男對感情的表達從來都很直接，不需要培養情緒的時間，愛就是愛了，恨就是恨了，也不會去在乎對方會有什麼反應。他的感情來的快，去的也快。愛你的時候，恨不得把天上的星星摘下來，就為了哄你開心一笑，溫柔浪漫那是一個不少。一旦感情的方向轉移，遇到了更好的，就會直接把你推出他感情的世界。或許也會先隱瞞一段時間，但這絕對是出於給自己留條後路的打算。讓你在交出真心，充滿希望等待幸福到來的時候，給你當頭一棒的致命一擊。



TOP3 獅子男



&nbsp; &nbsp; &nbsp; &nbsp;獅子男對愛人，一向都特別大方溫柔。熱戀的時候，你可以明顯感受到他對你的保護與珍惜。但是，感情的承諾不會是牽絆住獅子男的枷鎖。當他決定不愛了，就不會給你任何解釋的機會，將主動力發揮到極致，果斷的提出分手，毫不留情的走掉。不用哭著請他留下，因為你挽留的眼淚在他看來，一文不值，只會增添反感。在你傷心欲絕的時候，他就已經開始了新的愛情旅程，並且還會有意無意的讓你知道，在你面前展現出和另一個人的濃情蜜意，把插入你心口的刀，再狠狠的拔出。



TOP4 魔羯男



&nbsp; &nbsp; &nbsp; &nbsp;理性的人，一旦絕情起來，就會最狠心，用昨日還溫暖拂過你臉龐的手，冷冷的把你推入萬劫不復的深淵，魔羯男就是這樣一個理性的人。在感情上不會太耍花樣，甜言蜜語總是恰到好處，不滿的發洩也總是點到為止，讓你一步步沉溺到他們的穩重感中，毫無保留的全部相信。直到他提出分手，還不知所以。在他看來，早些認清現實對誰都不好，特別是感情，至於心理上準備的時間，這是不需要的。所以，全然不會顧及到你此刻的心慌意亂，之後的此恨綿綿，一走了之。



TOP5 處女座



&nbsp; &nbsp; &nbsp; &nbsp;處女男除了追求完美，還有一點不得不提，那就是優柔寡斷，特別是在感情上。本意或許想要找到一個兩全其美的方法解決分手問題，卻因為自己的太過猶豫，把事情越弄越糟。遲遲沒有和你提出不合適的想法，又不拒絕你的溫柔，還和別人大搞曖昧。到後來出軌已成事實，到紙最終保不住火，到你哭著鬧著抓住他的手問為什麼，他卻輕輕撥開你抓住的手，表現的比誰都無辜，好像受傷的不是你。把你一顆心摔成粉碎之後，留下一句有緣無分，就和別人雙宿雙飛。



&nbsp; &nbsp; &nbsp; &nbsp;佛說：前世的五百次的回眸才換來今生一次的擦肩而過。兩個人能夠相識，相知，再到相愛，有多難得。分手就算沒辦法做朋友，也沒必要變成仇人。就算已經變心，也不要在沒有確切分手之前，腳踏兩隻船，或是不念舊情的一走了之。分手以傷害對方的方式結局，不如留下最後一片溫暖，讓彼此不後悔曾經愛過。
