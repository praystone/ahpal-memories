&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;　什麼時候了，還不快跑！



&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;恐龍時代，　巨大的隕石撞向了地球，

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 一只恐龍看到了，雙手合十，一動不動。



另一只恐龍看到了：“什么時候了，還不快跑”。



這只恐龍回答道：“好大的流星，我許個愿先”。
