提早「告訴你」，遠勝以後「早知道」

關於飲食 

1. 在牛奶和豆漿之間，選擇後者 


&nbsp;

2. 覺得還可以再吃半碗飯時，離開餐桌


&nbsp;

3. 如果身體不感到飢渴，每天只需飲用4杯水 


&nbsp;

4. 多喝酸奶 


5. 無論什麼原因，都別抽煙 


&nbsp;

6. 在食譜裡添加雜糧和菜蔬 


7. 飲綠茶勝過紅茶 


&nbsp;

8. 重視早餐多過晚餐 


9. 控制鹽的用量 


&nbsp;

10. 起床後先刷牙，再喝水 


11. 經常嚼口香糖 


&nbsp;

12. 一早一晚，兩個蘋果可以有效改善便秘 


13. 純素食可能導致荷爾蒙分泌異常，造成不孕 


&nbsp;

14. 每周至少吃一次魚 


15. 遠離可樂等碳酸飲料 


&nbsp;

16. 不喝久煮的火鍋湯 


17. 沒有果汁牛奶這回事，它們是天生的冤家 


&nbsp;

18. 飯前吃水果勝過飯後 


19. 睡前可以來一杯紅葡萄酒 


&nbsp;

20. 喝咖啡可能引起女性骨質疏鬆

關於運動 


1. 多享受早晨8－9點的陽光 


&nbsp;

2. 跑步、騎腳踏車等運動可以保持優美的腿部線條 


3. 熱水泡腳可有效預防靜脈曲張 


&nbsp;

4. 精神極度疲倦時並不適宜以運動減壓，休息更重要 


5. 冬季少做戶外運動 


&nbsp;

6. 10層以下，不乘坐電梯 


7. 每三個月改變一次你的健身選單 


&nbsp;

8. 每天運動半小時，而非週末運動3小時 


9. 邊看電視邊做柔軟體操 


&nbsp;

10. 經常散步 


11. 午休也是健身的好時間，不一定非等到晚上 


&nbsp;

12. 光腳穿運動鞋固然舒服，卻對健康不利 


13. 睡半硬的床鋪更有利於頸椎健康 


&nbsp;

14. 去正規的醫院而非美容院接受按摩 


15. 非運動狀態下不喝功能性飲料 


&nbsp;

16. 運動後休息半小時再入浴 


17. 不在過吵的健身房中鍛鍊 


&nbsp;

18. 正確的姿勢比專程去健身更有效

關於伴侶

伴侶不是結婚時發願非你不娶或非你不嫁的那個

&nbsp;

人，而是發現你身上有許多缺點仍然選擇你的那

&nbsp;

個人；


&nbsp;

伴侶不是生活中你愛吃黃瓜他也愛吃黃瓜的那個

&nbsp;

&nbsp;

人，而是你吃蛋清他吃蛋黃的那個人； 


伴侶不是天黑了和你一起手挽手走進飯店的那個

&nbsp;

人，而是守在門口巴望你回來共進晚餐的那個

&nbsp;

人； 


&nbsp;

伴侶不是和你大談愛情，把“我愛你”掛在嘴邊

&nbsp;

的那個人，而是和你平淡的嘮叨柴米油鹽、鍋碗

&nbsp;

瓢盆的那個人。 


&nbsp;

在福祉的婚姻中，伴侶已不是一個具體的人，而

&nbsp;

是你和他在幾十年的歲月中沈澱下來的︰一份默

&nbsp;

契、一份溫情、一份平淡、一份理解、一份寬

&nbsp;

容。愛他就要讓他開心，這就是伴侶......... 

關於微笑

被人誤解的時候能微微的一笑，這是一種素養；


&nbsp;

受委屈的時候能坦然的一笑，這是一種大度；


吃虧的時候能開心的一笑，這是一種豁達；


處窘境的時候能自嘲的一笑，這是一種智慧；


&nbsp;

無奈的時候能達觀的一笑，這是一種境界；


危難的時候能泰然一笑，這是一種大氣；


&nbsp;

被輕蔑的時候能平靜的一笑，這是一種自信；


失戀的時候能輕輕的一笑，這是一種灑脫。


&nbsp;

不管是有什麼事情，為了什麼原因......我們每天都

&nbsp;

要開心一笑............ 

關於生活

日出東海落西山，愁也一天，喜也一天； 


&nbsp;

遇事不鑽牛角尖，人也舒坦，心也舒坦； 


每天領取謀生錢，多也喜歡，少也喜歡； 


&nbsp;

少葷多素日三餐，粗也香甜，細也香甜； 


新舊衣服不挑撿，好也御寒，賴也御寒； 


&nbsp;

常與知己聊聊天，古也談談，今也談談； 


全家老少互慰勉，貧也相安，富也相安
