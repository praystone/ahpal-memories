&nbsp; 
我想..這個世界很精彩 rn&nbsp;

可它卻不屬於我 

我只是習慣了和自己的影子獨處

&nbsp;

的那麼一份平淡和安靜而已..
&nbsp;


一種無法逾越的距離

&nbsp;

好比自己和自己的影子

在疲憊的腦海裏幻化你的身影.. 

&nbsp;

最終一片空白 

我什麼都沒有

&nbsp;

一種空洞的守望

以為愛對了

&nbsp;

得到的寂寞卻是那麼長



&nbsp;

何故多了如此的悲傷..

&nbsp;

&nbsp;

不想執意去塑造淒涼


&nbsp;

那些尚未說出口的誓言


&nbsp;

就此在心中將它埋葬..


&nbsp;

為他 我已疲憊不堪..


&nbsp;

在偽裝堅強的軀殼下


&nbsp;

掩飾不住的是那顆飽經滄桑的心


&nbsp;

和早已不再年輕的靈魂..

&nbsp;

我相信 若有緣


&nbsp;

我們的人生之路必有交匯的一處


&nbsp;

我期盼...我等待...

&nbsp;

若無緣

&nbsp;

希望他的手能給我帶來

&nbsp;

我曾幻想過的溫暖...



&nbsp;

我不知道會堅持多久

&nbsp;

也許時間 才是最後的答案....
