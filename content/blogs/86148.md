先死盯著我的各個硬碟收藏，再切換到聊天室，我不禁第一次想問自己：

說起來，我除了懂些不能幫我考上更好的高中的的知識以外，強項就只有遊戲還有發明些怪東西了。拋開那些怪發明的內容先不談，我還是比較自豪自己在遊戲上的悟性。不只限於電玩上的，任何的遊戲我接觸過一次就能掌握到要訣，兩次就差不多能得心應手了，但是說起來也懶得去練習，畢竟沒有女孩子會喜歡上這樣的我，還不如多攻略些絕不會背叛自己，又合乎自己條件的二次元美少女來得實際。

&nbsp;

我，白井鳴海就是這樣的生存法則。不過突然闖入我這樣每天亂搞的生活的，就是這個分明屬於正常人範疇，卻一直踏進我怪異的世界的，就是這個如同子貓的學妹了。記得那個時候總是覺得太過認真的她還真讓人看不慣，所以中學時代的我總是拉著小梓東奔西跑的，好比說乘坐那台根本就不太堪用的浮游飛行器，或者是去試玩這附近新的遊戲機台之類的事情；常被她唸說不把才智用在考上更好的志願學校而淨做些蠢事，雖然也會感到些愧疚，但要我認真的去讀那些教科書反而是無用的舉動。就像不知道誰說過的：某些人就只擁有奇怪的才能吧。

來不及作出取消的任何指令，我已經失去了所有的感官。

這是個把精神以一定的時數與身體暫時分離的遊戲世界，藉由放鬆狀態的神經感官去「看見」，不，應該說「體會」這個被稱為「THE FULLEST AGE」的遊戲程式並且接著去遊玩。如果是將精神完全跟伺服器連結之後進入遊戲的技術，那麼這幾年要真的研發出來還真的有相當的難度，但若只是這樣類似催眠跟幻視現象的搭配，只要有恰當的方式確實就能實現。雖然只是高三生，這點小常識我還有。

看到我很自在的左顧右盼還能開她的玩笑，魅杏心裡自然不是滋味；不擅長跟人相處的她，本來就在模特兒這工作上很勉強；畢竟也算是公開在攝影機與鎂光燈之下的工作，總是臭臉一擺面對鏡頭會有損形象，即使緊張或者是焦急到無法笑出來也得擠出笑容是必要的，但這對於魅杏來說是相當的折磨。從小我們兩個都有一樣的毛病，只是我一直以來都藏身在遊戲與研究的世界裡，自然不會有面對的機會。不過在遊戲世界中，我是能把周圍的人都不當成人類的，而這點魅杏是做不到的。

魔女族的魔法師嗎……真是純到不行的魔法血統阿，我看她大約不知道光是靠那種網路上的無腦分配，就會變成非常可怕的強大火力吧。果然是沒玩過甚麼遊戲的人呢。突然因為心理不平衡而轉變的態度，果然我就是喜歡她這一點呢。

「仔細一看，連地圖跟任務指南都有呢。不過就是沒有離線還有更換角色的選項就是。」

「喔，要登出的話就利用每個城市或迷宮的登出點就可以了，就是那個『刺針之密室』。它會以一定程度的刺激感讓你從這種游離睡眠之中醒來的，雖然會有些小小的痛覺跟不舒服……但幸好時間不長，頂多也只是神經刺激裝置把男女主角弄醒的那種感覺吧？」

以明瞭直接的語氣告訴我這種事情也就罷了，我比較想知道的是，女孩子都是一個人去看這種電影的嗎……到底是為了甚麼阿。

&nbsp;

這我當然也猜得到。妳哪有多少時間可以上線，今天八成也是多要了些休息時間吧。至於神經連動的操作，我從剛剛就在摸清楚這種細微，比直接控制手腳的體感還要困難的方式了；不安分的走來走去可不是我好奇而已，同時也是熟悉操作的要訣的機會。對我來說這也是有難度的操作，但我想多摸索個幾天應該就能上手了。

那個讓人感到有些過熱、過於清爽，若是不加以阻止就會暴走的笑容，搞不好比唯學姊律學姊兩個人加起來還要更來得危險，艾嵐學長就是這麼一個讓人不放心必須放在視線裡的人。從他的行動裡可以看到孤獨，但是也可以看出自在跟夢想。

從岩塊之中伸出灰色的黏稠身體，發出低吼的巨型生物，正是我們的目標岩山蝸牛。基本上這傢伙的一般攻擊就是請人躲開一樣，只要注意別讓牠有去撞擊山壁的機會就只是會縮殼的血牛。現在魅杏的咒文還沒有詠唱完畢，我只能想辦法拖住牠了。

&nbsp;

我再次運起黑鐵大鎚，一招往蝸牛殼的左側狠狠的砸下去；我的武器之所以選擇大鎚，除了當初對這類的武器比較有好感之外，就是因為大鎚具有「裝甲破壞」的附加武器效果。也就是說，重戰士的我也是岩山蝸牛的棘手敵人，只需要一些時間就能讓牠變成無法防備我們攻擊的軟肉。剛剛那一砸，殼上面已經有些許的裂痕了。不過蝸牛還是選擇躲入殼中防禦。

&nbsp;

我這次是往蝸牛殼的右方招呼了一鎚，結果換來這傢伙要來個滾輪攻擊，想要一舉碾殺我們。不過——

&nbsp;

「可沒有你想得那麼簡單就結束阿！」

&nbsp;

我將大鎚的長柄用來抵擋住這股衝擊力道，並且借力將蝸牛整個推到半空中，一百八十度的大翻轉後，整個無法隱藏的灰色腹部面向地面上的我們；此時，魅杏的咒文正好只差最後的關鍵句。

&nbsp;

「遠上的雷鳴之聲阿，如同怒吼的獸牙，發出裂雲的閃光！『雷擊碎』！」

&nbsp;

不同於落雷的攻擊是由上往下劈擊，雷擊碎的攻擊方式，是引起了落雷之後再擴散到空氣之中，粉碎所有接觸到攻擊範圍的物體的中級魔法。雖然以威力來說沒有比落雷來得強，但是施術較快速，命中率也比較高，更沒有顧慮對方位置的問題；只要像這樣應用得當，足夠的連擊段數也能瞬間秒殺岩山蝸牛。

&nbsp;

「學長，我一次就提升了8個等級耶！」

&nbsp;

盯著「AIR TARGET」的資訊數據，率真的笑容出現在臉上的梓讓人覺得就如妹妹般惹人憐愛。因為我們跟小梓的等級畢竟是差得有點太多了，她無法一次吸受到太多經驗值也是不奇怪的事情。但對於從零開始的小梓根本不算少就是了。

&nbsp;

「艾嵐你這個大笨蛋！剛剛也太亂來了吧！憑著力氣去想辦法改變軌道，要是失敗了的話，你不就是生命垂危了，我們也相對的完蛋了嗎？到底有沒有動腦多想想阿！真是的，下次往旁邊閃比較……」

&nbsp;

「魅杏！快閃開，現在！」

&nbsp;

正當魅杏對著我破口大罵之時，一根宣告死亡的尾針，就這樣要從她的背後貫穿道我跟梓的眼前。以我的距離無法衝上去，梓也無法及時將她拉開……

&nbsp;

不行了。這次我真的守護不了她了。本來自信滿滿的由我的大鎚配上「炎紋劍」的技能，應該兩三下就能擊倒一隻漆黑巨蠍的，但是這距離是我無法趕上的。

&nbsp;

就算我大吼出聲，也無事無補了吧。

&nbsp;

「雖然魔法師小妹妹妳不是忍者，但是還是不能背對著敵人喔！火遁，『瀑炎龍』！」

&nbsp;

忽地一個金髮的嬌小少年以不費力，但是響徹山谷間的聲音喊著，像是迅雷般的劃過漆黑巨蠍的正上方，還順帶用左手劍指往下一劈，一條瀑布般的紅連之龍張開大口吞下了巨蠍，不一會兒工夫就將牠燃燒殆盡。剛剛少年提到「忍者」，那是在東方區域以暗器與短刀為武器，手甲與足袋為防具，以「遁」這種比魔法更快速、運用「氣」的特殊職業，會經過山道算是稀奇的。

&nbsp;

「剛剛在下本來覺得那位重戰士身手不錯，跟魔法師小妹妹配合得很好，沒想到這麼快就差點有人要回道城鎮去了，真是好險阿好險呢！如果不介意的話，可以讓在下與幾位同行嗎？多個夥伴就像是多個保障，我是來自山城青都的雷古。後面的是那這裡碰到的同伴，人族的格裡風騎士艾葛，就是她剛剛讓在下能及時看到危機的。阿，還有那位是老朋友的鬼族道士不方，主要是專攻附加跟治療方面的符咒。」

&nbsp;

自稱雷古的少年身後，確實有乘坐在天空王者格裡風之上的棕髮馬尾少女，一身輕便的裝備，身邊帶著輕弩砲，不讓豪傑的銳利眼神似乎也有些讓人不敢接近；另外還有肌膚是很罕見的深咖啡色，一身紫袍的銀髮男人，大約是東方的魔族之類的存在的種族吧？能確定的是這一行人看起來確實都有一定的實力，但對於應該是還沒有開放的格裡風騎士這職業為甚麼會出現實裝，我還是抱持著懷疑。

&nbsp;

但有何不可？「THE FULLEST AGE」終究也是個遊戲。既然是遊戲，那麼盡興即可。

&nbsp;

「好，那就以我為隊長，在此宣布隊伍『BLAZE』正式結成！」
