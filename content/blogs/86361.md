人生


&nbsp;


人們豈非總是會輕易放過一些他最需要的東西？只等他已失去了以後，才知道這種東西對他有多麼重要。


&nbsp;



一個真正值得你佩服的人，總是要等你已認得他很久之後，才會讓你知道他是怎麼樣一個人的。


&nbsp;


&nbsp;


人類的慾望是很難說的，有人得到的很多很多，卻永不知足，有人只得到星星點點就已知足。


&nbsp;



人類是否滿足，實在是個主觀問題。
人類的情感，本就是連神都無法控制得了的。
寬恕，對於一個自知犯罪的人來說，是一種最大的懲罰。


&nbsp;


多情人隱藏情感，遠遠要比無情人隱藏冷酷困難得多。
人類的感情，是絕對沒有一定規律的，也沒有任何人能控制，尤其是自己更不能控制。
溫柔就是一把刀。


&nbsp;


你可以說，世上根本沒有神，卻不能說，神是絕不流淚的。
因為神也有感情。
沒有感情的，非但不能成為神，也不能算是個人。


&nbsp;


癡並不可笑，因為唯有至情的人，才能學得會這「癡」字。



「癡」和「呆」不同。只有癡於劍的人，才能練成精妙的劍法


只有癡於情的人，才能得到別人的真情。



世上永遠沒有真情所不能感動的事。


&nbsp;


&nbsp;


人類有很多弱點，花錢擺派頭無疑也是人類的弱點之一。
所以特別貴的地方，生意總是特別的好。


&nbsp;


你可以不喜歡別人，卻沒法子不讓別人喜歡你。
你要我等你的時候，你自己豈非也同樣在等！
世上本就有很多事就像是寶劍的雙鋒。


&nbsp;



你要去傷害別人時，自己也往往會同樣受到傷害。
有時你自己受到的傷害甚至比對方更重！


&nbsp;


一個人若是已經在往下墜，不管是身子在往下墜，還是靈魂在往下墜，再想拔起來，都不是件容易的事。


&nbsp;



這就是人類的劣根性，當他們的敵人越鎮定時，他們自己就越不鎮定。
一個人樣子很狼狽的時候，非但不願意被人看見，也不想去看別人。


&nbsp;


你可知記憶雖好，但忘記更佳。只因世人可以記憶，方能日新又新，不斷進步；但忘記可使人的心靈活得寧靜與安恬。若無記憶，人類無法記取先人之遺教，必將停留於上古洪荒之野蠻狀態裡；但若無忘記，人們永遠將活在那些銷魂之痛苦與負心的愧疚中，時時刻刻受著它的折磨，那麼人生將變成一無樂趣——只因人可以暫時忘記，灰黯的人生才會有鮮艷的色彩。


&nbsp;


男人女人都一樣，哪怕自己結了婚，也希望有別人仍然深愛著自己，這就是自私，也是虛榮。


&nbsp;


情感有時候就像是眼罩，常常會把一個人的眼睛罩住，當然看不見他本來應該看見的事。


&nbsp;


人類最大的敵人，就是自己；最可怕的敵人，卻是朋友。
人們若太過得意時，必定疏於防護自己。


&nbsp;


只要你有決心，世上便沒有一件你真的不能忍受的事。
一個人在自我慚愧不安時，往往就會想去傷害別的人。
世上絕沒有任何事，能比被人逼著你作全無把握的決定更可怕！


&nbsp;


賭、女人、酒！
這三件事加在一起，又還有誰能保持著清醒的頭腦呢？


&nbsp;


隨遇而安這四個字本身，就已包含著忍耐堅毅的精神在內。


&nbsp;


只有等，永遠是不會錯的。



一個人只要能忍耐，能等，遲早總會等到機會的。


一個人若是忍耐得太久，憋得太久，有些時候總難免會想發洩一下的。否則，無論誰都難免要爆炸。


&nbsp;


一個人自己做錯了事，卻將錯誤發生的原因歸咎到別人身上，自己心裡非但沒有悔疚反而充滿了仇恨，反而要去對別人報復。這種行為本來就是人類最原始的弱點之一。



原諒自己豈非總比原諒別人容易？
就算別人對你是一種阿諛或是高估，你也以為總比低估好些。


&nbsp;


每一個人畢生最大的敵人，其實就是自己。要戰勝別人容易。而要戰勝自己，卻比戰勝任何敵人都更艱難千百倍。


&nbsp;


一個人的內心如果充滿了自卑，往往就會變成一個最驕傲的人。
世上唯又謙恭，才能得到人們的歡呼；而驕傲自大所得到的，卻只有不屑於辱罵。
有自卑的人，總是會故意裝得特別自大。


&nbsp;


人們為了保護自己心裡的弱點，通常都會做出一些奇怪的事。
每個人最喜歡的人都一定是他自己。
每個人偶爾都會說出一些他不該說的話，否則他就不是人了。
一個人最欣賞的人，本就必定是和他自己同樣的人。因為每個人都一定很欣賞自己。
每個人都帶著他自己的枷鎖，除了他自己外，誰也無法替他解脫。


&nbsp;


人的意念，都是在一剎那間決定的，亙古以來，又有誰能預先知道自己要做什麼呢？在下一刻會做出什麼樣的舉動？



外表越凶的人，內心一定越懦弱。
每個人都有逃避別人的時候，可是永遠都沒有一個人能逃避得了自己。


&nbsp;


一個人若已完全沉迷在一樣事裡，就好像已和魔鬼做了件交易。
一個人內心深處，往往會有些秘密是自己都不知道的——也許並不是真的不知道，只不過是不敢去把它發掘出來而已。
一個人肚子裡的秘密若是裝得太多，就像是乾柴上又澆了油一樣，總是容易引火上身的。


&nbsp;


「罵人」當然絕不是件值得向別人推薦的事，卻永遠有它值得存在的理由。無論誰痛痛快快地罵過一個自己痛恨的人之後，總是會覺得全身舒暢、心情愉快的，就好像便秘多日腸胃忽然暢通。


&nbsp;


人總是軟弱的，總是有弱點的，也正因如此，所以人才是人。
一個年輕氣盛的年輕人居然能說除「不敢」兩個字，那麼這個年輕人的心裡對另外一個人的崇敬已經可想而知了。


&nbsp;


只有鮮血才能激發人原始的獸性——情慾和仇恨，別的東西或許也能，卻絕對沒有鮮血如此直接。
這實在是件很奇妙的事——一個人流血的時候，往往就不再流淚。


&nbsp;


夢和現實畢竟是有明顯分別的，當一個人還能想，我到底是在做夢抑是在清醒中時，十之八九那不是夢。


&nbsp;


眼睛可以傳神，也能洩漏秘密。
有時不用眼睛而用腦子就能知道一些相當秘密的事。
一個人若已到了沒有任何東西可以依賴的時候，往往就會變得堅強起來的。


&nbsp;


一個人的心若已死，只有兩種力量能令他再生。
一種是愛，一種是恨。


&nbsp;


有些事不知道反而比知道好。
一個人要別人為他做事的時候，最好先問自己能為對方做什麼。
只有死人才能保守秘密，自古以來，這就是人類殺人時強烈的動機之一。
只有自己心裡想去害人的人，才會去提防別人。


&nbsp;


有些人在悲哀時不會落淚，在遇著最美的事卻不禁流下淚珠。


&nbsp;


暈厥，其實也是上天賜給人類的許多種恩惠之一。人們在遇著自己不願做、不願說、不願聽的事時，往往就會以暈厥這種方法來逃避。


&nbsp;



反抗欺壓，本就是人類最原始的憤怒之一，——就因為人類能有這種憤怒產生力量，所以人類才能永存。


&nbsp;


一個驕傲的人，在不得已非要誇獎別人不可時，自己總會對自己生氣的。
一個人的心靈縱然已受了控制，但你是要他去做一件他最不願意的事，他的理智還是會作最後一番掙扎的。


&nbsp;



能承認自己不是個君子，也是件不容易的事。
古今的英雄，又有幾人不貪杯好色？只可惜貪杯好色的卻大半都不是英雄好漢。


&nbsp;


一個人若想笑的時候都不能笑，活著才真是沒意思得很。
有些人就像是蜘蛛一樣，終日不停的在結網，等著別人來投入他的網，可是第一個被這面網困住的就是他自己。


&nbsp;



有些人認為蜘蛛愚昧，蜘蛛自己很可能也知道，可是它不能不這麼樣作，因為這面網不但是它糧食的來源，也是它唯一的樂趣，不結網它就無法生存。


&nbsp;


替別人保守秘密，本就是只有完全成熟的人才能做到的事。
當別人在考慮下決定時，你若催促他、壓迫他，得到的效果往往是相反的。


&nbsp;


麻煩多些，也比沒有麻煩好。
因為真正沒有麻煩的，也只有一種人——死人。
好管閒事的人通常也都是不怕麻煩的人。
世上除了死人外，沒有一個人能守口如瓶的。


&nbsp;


對於一個憎恨自己的人越表現得不在乎，往往就越使那個人憤怒。


&nbsp;


一個人身子最虛弱時，情感卻是最豐富。
一個人能使自己永保笑音，固然已很不容易，若還能讓別人笑，才真正偉大。
笑，就像是香水，不但能令自己芬芳，也能令別人快樂。
你若能令別人笑一笑，縱然做做愚蠢的事又何妨?


&nbsp;


一個人若還有淚可流，就不該死。
一個人若能多曬曬太陽，就不會作卑鄙無恥的事。無論是誰，在這麼可愛的陽光下，都想不出壞注意來的。


&nbsp;



人性並不僅是憤怒、仇恨、悲哀、恐懼，其中包括了愛與友情，慷慨與俠義，幽默與同情。
我們為什麼要特別著重其醜惡的一面？


&nbsp;



一個人若要遵守自己的原則，有時卻也並不太容易的，但你若無論在任何情況下都能守得住自己的原則，那麼你就會出現不但活著時比較安心，就算死了，也絕不會閉不上眼睛。


&nbsp;



一個人只要能安安心心地活著，安安心心地死，窮一點又有什麼關係？當然假如能闊一點，卻也不是什麼壞事。


&nbsp;


風在吹，鳥在啼，秋蟲在低語，混合成一種比音樂還美妙的聲音，它美妙得宛如情人在耳畔低語。
滿山瀰漫著花的香氣，草的香氣，風的香氣，甚至連夕陽都彷彿被染上了芬芳，芬芳得宛如情人「鬃邊的柔髮」。


&nbsp;



人生原來竟如此芬芳，如此美妙



所以朋友們，你絕不要為有錢而煩惱，更不要為窮煩惱，只要你懂得享受人生，你就算沒有白活。
那麼有天你就算死了，也會死得很開心，因為你活得比別人開心。
