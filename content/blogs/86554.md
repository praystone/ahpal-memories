網絡很淺 孤獨很深


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 有些東西，你可以日日夜夜與之相對。但其實，你只是在消磨——消磨時間和孤獨。 


&nbsp;


　　像浮在水面的泡沫。太淺，所以無法觸及靈魂。 


&nbsp;


　　我說的，可以是網絡。 


&nbsp;


　　開始是在什麼時候，五年前？還是六年前？ 


&nbsp;


　　初見時繁華耀眼，然後光影散盡，感到厭倦。 


&nbsp;


　　有天早上突然發現，我擁有很多個郵箱，但是沒有人給我寫信。我和很多不認識的人聊過天，但是我想不起來聊過什麼。我到很多地方註冊了會員，但是忘記了密碼。 


&nbsp;


　　我厭倦網絡，是因為它太複雜。 


&nbsp;


　　在網絡上，你可以去看，可以去想，可以去記憶，可以去相信，但是不要試圖去擁有。那是一個虛無的世界，沒有什麼東西真正屬於你。 


&nbsp;


　　一直以來，我去過的網站，只有可數的幾個。 


&nbsp;


　　通常打開電腦，沒有新的郵件，於是歎口氣，放上一首歌，去看文章。自己的，別人的。有的時候會發一個帖子。大多時候只是看，心裡暗暗點評，但不說話。 


&nbsp;


　　網上有太多地方可以去，有太多事情可以做，有太多歌曲可以聽，有太多遊戲可以玩兒。 


&nbsp;


　　可是我不想。哪裡都不想去，什麼都不想做。不想聽，也不想玩兒。 


&nbsp;


　　有人問我的QQ，我說我不上的。他問那你平時怎麼和別人聊天，我說我為什麼要和別人聊天。 


&nbsp;


　　可是我為什麼要上網？ 


&nbsp;


　　如果除去為了工作，還有原因的話，那又是什麼？ 


&nbsp;


　　為什麼有的人可以日日夜夜泡在上面，為什麼有的人會將一些虛幻的數字視為生命。 


&nbsp;


　　不管你開心還是悲傷，不管你蒼老還是年輕，不管你無聊還是充實，你都可以去上網。 


&nbsp;


　　但是你不可以孤獨。 


&nbsp;


　　網絡可以讓開心的人悲傷，讓悲傷的開心；也可以讓開心的人更開心，讓悲傷的人更悲傷。 


&nbsp;


　　但是它只能讓孤獨的人更孤獨。 


&nbsp;


　　我知道，不管我上網去哪裡，不管去做什麼，其實我不過是在等待。 


&nbsp;


　　或是懷念。 


&nbsp;


　　看著論壇裡的文章不斷地更新，時常會恍惚，覺得自己好像是孤魂野鬼，飄蕩在不屬於自己的世界。 


&nbsp;


　　那是一個太複雜的世界。我不喜歡。 


&nbsp;


　　但是不可以離開，因為要依賴它傳達的訊息。 


&nbsp;


　　它無法讓我真正的悲傷，無法讓我真正的快樂。因為歸根到底，那只不過是一堆符號和數字。 


&nbsp;


　　只有一個人才可以讓一個人悲傷。只有一個人才可以讓一個人快樂。 


&nbsp;


　　網絡，那是薄冰上的行走，泡沫上的舞步
