婦女節是宣示女性地位與紀念女權運動先

&nbsp;

鋒的節日。婦女節的構想最早在西元1909

&nbsp;

年，由美國社會主義黨(Socialist Party)

&nbsp;

首先提出。當時美國首次的全國婦女節訂

&nbsp;

在二月二十八日在全美各地舉行。至隔年

&nbsp;

1910年，社會主義國際(The Socialist 

&nbsp;

International)於哥本哈根聚會，決議制 

&nbsp;

定「國際婦女節」向女權運動致意並希望

&nbsp;

促成女性普遍的參政權。此後，國際婦女

&nbsp;

節在奧地利、丹麥、德國、及瑞士等國陸

&nbsp;

續受到重視，當時主要是訂在三月十九日

&nbsp;

那天慶祝。而有關女性投票權、擔任公職

&nbsp;

權利以及女性的工作權、受職業訓練的權 

&nbsp;

利、與終止女性在職場所受的歧視等訴求

&nbsp;

，均在當時被提出。至第一次世界大戰期

&nbsp;

間，俄羅斯婦女眼見許多士兵無謂地犧牲

&nbsp;

，死於戰場，於是發起反對戰爭與爭取女

&nbsp;

性投票權的運動。歐洲其他地區的女性，

&nbsp;

也選於三月八號，以集會遊行的方式伸援

&nbsp;

俄羅斯婦女行動。至此，三月八日為國際 

&nbsp;

婦女節正式抵定。
