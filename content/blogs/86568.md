在黑喑年代有一個巫師的徒弟， 因為無聊玩火而焚毀了巫師的堡壘，巫師為了懲罰他，將他變做火柴人，由五支

&nbsp;

巨大的火柴構成他的頭和四肢。但悲劇在於他仍可擁有思想和感情，過了大約一百年，火柴人遇上美麗的公主，

&nbsp;

公主途經森林時，遇到大風雪而迷失了路，幸得火柴人把她救援，帶她到山洞避雪。 

&nbsp;

火柴人對公主一見鍾情，但公主並不喜歡他。火柴人為得公主的歡心，知道她感到寒冷，便甘心燃點那對用火柴

&nbsp;

&nbsp;

造的腿來供應溫暖。腿被燒毀了但公主還未等到兵士來拯救自己，決定利用火柴人的雙手再一次取得溫暖，於是

&nbsp;

對火柴人說出綿綿情話，希望他能為愛情犧牲多一趟焚燒他雙手。 

&nbsp;

公主奸計得逞，現在火柴人只剩下頭和身。不過，外表美麗內裡自私的公主卻未受感化，仍然想繼續得到溫暖，

&nbsp;

她要求火柴人獻出剩餘的一枝火柴，火柴人知道這樣做會同是把生命終結，但他仍然願意為公主做一切的事，只

&nbsp;

要公主感到快樂。 

&nbsp;

擦一聲，火柴人把頭燃著了，他對公主說那段最後的對話：既然命運把我變成火柴人，我寧願為愛情轟轟烈烈的

&nbsp;

自焚直至死亡，總好比再悶活多一百年有意思。雖然我知你在利用我對你的愛，但我甘心給妳利用，最後公主真

&nbsp;

的被感動。 

&nbsp;

因為公主身邊沒有水源，她想用淚水救熄火柴人身上的猛火，但這女人一向鐵心得連眼淚也不流， 己經忘記了怎

&nbsp;

樣哭，到第一滴眼淚流出來時， 火柴人己經變成一堆黑炭，太遲了！巫師永遠譏笑火柴人的衝動，原來火柴人身

&nbsp;

上的咒語只有效一個世紀，如果，他可多等一天就可以變回真人。

&nbsp;

有時會想如果我們能預知將來，不知我們還會否仍願意犧牲呢?有時值得和不值得，可能只是一線之差，試問有誰

&nbsp;

可以有絕對的答案呢? 如果你是"火柴人 "，你會怎麼做呢? 

&nbsp;

很多人說，愛一個人要愛他的全部，關於他好的，還有不好的。但我想，這只是熱情時的話罷了。真正愛一個

&nbsp;

人，關於他好的，要懂得珍惜；不好的，要有耐性的幫他改掉，這才是追求永恆的相處之道吧！火柴人的愛是那

&nbsp;

麼完美無私，但值得嗎？為了一個不懂愛的人，若用一味的包容成全愛情，那麼，被愛太自私，愛人，卻太辛苦

&nbsp;

了! 幸福，請在對的地方尋找吧。
