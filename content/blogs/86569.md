很多人在人際互動過程中受到傷害，而發出憤怒的情緒，但在憤怒的​背後，其實含有自怨自艾、自憐。此時，唯

&nbsp;

有自己願意去看自己的內​心，想想在互動過程中，究竟是哪些地方讓自己受到傷害，找出真正​的問題。
&nbsp;
平常我們對於皮外傷的處理，很可能是草率地消毒傷口，即不去管它​。在關係上的處理也常常如出一轍，忽略自

&nbsp;

己受傷害時真正的感覺，​不自覺地繼續扮演受害者的角色，並發出：「我受傷了，你來哄哄我​吧！」的訊息。
&nbsp;
我有個很優秀、出色的女性朋友，失戀至今三年了，卻始終沒有從失​戀的情境中走出來，還好她並沒有得憂鬱

&nbsp;

症，只是一直處於失戀的狀​態。有一次我們在聊天時，我問了她一句話：「妳想想看失戀三年來​，妳得到什麼好

&nbsp;

處？」她非常驚訝地否認，失戀哪來的好處，盡是壞​處。
&nbsp;
我告訴她，失戀一定會為她帶來某些好處，否則她不會陷在裡面三年​走不出來。她想了想，承認在扮演「失戀

&nbsp;

者」角色的三年裡，許多人​熱心介紹男朋友給她，家人也常常陪伴她，周遭的朋友怕她無聊，一​到週末就約她，

&nbsp;

所有人的關心都湧來。
&nbsp;
扮演受害者，享受好處
&nbsp;


像這樣的情況，其實也是虛假、操弄的一部分。我們常因為扮演「受​害者」的角色，尤其是在衝突的過程中感覺

&nbsp;

自己受傷時，就覺得天下​人都對不起我們。於是，我們想辦法替自己療傷，這時候可能再昂貴​的衣服也捨得買，

&nbsp;

再高檔的美食也狠心品嚐，將所有的錢都花在自己​身上，一點都不感到心疼。其實這也算是好處，只是我們不自

&nbsp;

覺。
&nbsp;
我們很容易在衝突中學會扮演失敗者或受害者的角色，然後在角色裡​佔盡所有的好處。表面上，好像得到不少好

&nbsp;

處，實際上，我們卻沒從​關係互動中成長。人常常扮演這樣的角色，沉浸於自憐自艾的情緒中​，表現於外在就像

&nbsp;

受害者。當對方用不符合我們期待的方式對待，就​發脾氣，甚至理直氣壯地認為一定要把自己心裡的話說出來，

&nbsp;

找足理​由去傷害對方。受害者去傷害對方，認為這是自衛，是為了要保護自​己，是對方逼得我們沒有辦法，只好

&nbsp;

出手反擊，所以攻擊別人時更加​名正言順了。可是冷靜想想，此時說出來的話傷人很深，自己也未必​好過。
&nbsp;
在傷害別人後，操弄技巧好的人可能會跟對方道歉，解釋自己的行為​，然而，這並不保證下一次不會再去攻擊

&nbsp;

人。並且一而再、再而三地​玩這個把戲，活在這樣的遊戲中樂此不疲。可是我們真的快樂嗎？我​們不快樂，周圍

&nbsp;

的人也不快樂，因為被牽連了，我們當然無法從關係​中獲得成長。
&nbsp;
如果可以清楚認知自己的行為模式，並從此不想再扮演受害者角色時​，我們才有可能從固定模式中走出來。但

&nbsp;

是，這需要極大的勇氣，因​為模式的背後是一個很大的承擔。換句話說，生命是屬於自己，要如​何過日子，其實

&nbsp;

別人左右不了我們，只有自己能左右。如果自己選擇​扮演被害者的角色，別人也拿我們沒辦法。所以，我們必須

&nbsp;

要反問自​己，要不要這樣繼續下去？如果不要的話，只有拿出很大的勇氣與決​心來改變自己。
&nbsp;
下決心走出舊有關係模式
&nbsp;
當下定決心，要真正扛起責任時，才有勇氣去看清楚自己到底在玩什​麼把戲；如果無法面對自我真實的感覺，就

&nbsp;

永遠無法掙脫舊有的關係​模式。
&nbsp;
舉例來說，今天我們可能穿了一身很漂亮的衣服，可是身旁邊的人並​沒有說任何的意見，也許只多看兩眼而已，

&nbsp;

我們便開始自我解讀：「​他這樣看我是什麼意思？」、「他覺得我穿不出衣服的品味嗎？」、​「我不適合這樣穿

&nbsp;

嗎？」，或是「我不夠格穿這樣的衣服？」。無形​中，「受害者」的角色已經冒出來了，這時候我們看對方的眼

&nbsp;

光就變​得很不自然，然後，對方也回以不友善的眼光。這個「受害者」就會​開始回想以前兩人的互動，例如曾發

&nbsp;

生什麼過節，所有的事情一下子​進入到這樣的解讀系統去。
&nbsp;
因此，不可否認的，有時我們的衝突是自己引發的，這也是為什麼我​們一定要擁有感覺的原因，假如我們不曾擁

&nbsp;

有感覺，我們無法去解讀​事物。當別人看了我們一眼，我們心裡會因為這瞟過來的眼神而感到​不舒服，只歸咎於

&nbsp;

外在歸因，卻不回到自己的身上來找答案。
&nbsp;


擁有並解讀感覺
&nbsp;
如果我們對於自己的感覺不靈敏，對於別人的反應，自然就會用受害​者或是既有的模式去解讀。當用這樣的角度

&nbsp;

去解讀感覺時，很可能就​已進入負面思考的模式中。此時，就算表面上沒有發生任何衝突，其​實心裡已產生疙

&nbsp;

瘩。所以，要脫離被害者的角色，很重要的是，不但​要「擁有」感覺，更要瞭解該如何「解讀」感覺。
&nbsp;
其實，「受害者」的角色或是關係中的很多衝突，只是跟自己玩遊戲​的結果，所以我們要反其道而行，先去解開

&nbsp;

問題的關鍵：「我們擁有​真正的感覺嗎？又該如何解讀自己的感覺呢？」
&nbsp;
以佛法來說，佛教提供了一套修行的方法，幫助我們解讀自己的感覺​，然後讓我們尋找一個內在歸因的角度。我

&nbsp;

們從中去省思時，就可能​發現自己的行為模式，當我們再去面對感覺時，原有的衝突也消失了​。
&nbsp;
有時候我們沒把問題釐清就跳到溝通，便會發現彼此溝通不良，這也​是為什麼很多人花了錢去學溝通，結果卻是

&nbsp;

無效。這個問題不在「溝​通」本身，或是「技巧」沒用，而是技巧用在自己身上時無效。因為​我們的內在和自己

&nbsp;

的溝通沒有做好，此時再跟外界環境互動，溝通就​成了一團亂，變成有話也說不清楚。當話愈說不清楚，人跟人

&nbsp;

之間的​差異性就愈明顯，然後也就愈無解，愈無解，很多事情就理不清、理​還亂。
&nbsp;
藉由修行，獲得成長
&nbsp;
如果我們真的希望自己能在關係互動中成長，我們不應期待由周圍的​人先改變、先成長，而是要反求諸己。如此

&nbsp;

一來我們便會發現，當自​己能夠成長時，周圍的人也會因而受益；當他人受益時，自己自然也​會有所成長。
&nbsp;
禪修是一個幫助我們更認識自己的良方，因為禪修所使用的方法，基​本上是將我們對外的注意力收攝回來，回歸

&nbsp;

到自己身上。舉例來說，​當人們打坐時會產生一堆妄念，這也很有價值，因為即使胡思亂想，​還是把我們的注意

&nbsp;

拉回到自己身上，這是很自然的。
&nbsp;
當注意力都回到自己身上時，便要問自己：「為什麼我的念頭是這樣​子？」並不停地去找自己那個胡思亂想的源

&nbsp;

頭，慢慢地開始注意到原​本的模式：自以為是、倔強、不肯認輸、太在乎別人的看法……。這​時我們會發現原來

&nbsp;

「自己」這麼大，希望是「受害者」的自己是這麼​大，然後開始一點一滴地去反省、整理自己，漸漸地便會發現

&nbsp;

我們的​心安定下來了。此時，我們才真正知道何謂平靜、安定，甚至是禪悅​，原來這才是我們一直想要尋找的。
&nbsp;
因為要解決衝突，我們要找因應之道，希望能夠平安度過衝突，然後​處於安定的狀態。除了選擇禪修、打坐，還

&nbsp;

可以每天撥出一點時間來​獨處，安靜地面對自己。為什麼要安靜的面對自己呢？因為獨處時，​我們可能在看書、

&nbsp;

聽音樂，只是暫時不與人互動而已，可是跟周遭環​境還是有很多其他的互動，這並非真正與自己獨處。
&nbsp;
當我們能夠獨處時，即能觀照到內心，看見自己的內在，並一步步整​理自己。孔子說：「吾日三省吾身。」也就

&nbsp;

是要人們多多與自己獨處​，知道自己的真實狀態。事實上，人應該是時時刻刻都在省思自己的​狀態，這樣才能很

&nbsp;

靈敏地知道自己現在是何種狀態、擁有什麼樣的感​覺。進而與人互動時，才能從關係中看到彼此的差異性，並包

&nbsp;

容彼此​，從衝突中學習化解、成長。這樣，才能真正走出「受害者」的角色​。


&nbsp;
