&nbsp;


您悄悄的走了


&nbsp;


沒有帶走一片雲彩


&nbsp;


是您選擇了放棄


&nbsp;


還是緣份已到盡頭


&nbsp;


往事點點滴滴


&nbsp;


湧上心頭


&nbsp;


我喜歡挽著您手


&nbsp;


靜靜著陪您遙望星空


&nbsp;


探索虛擬夜空


&nbsp;


喜歡隨著您


&nbsp;


唱著望春風 


&nbsp;


傾聽無怨的青春夢


&nbsp;


喜歡在您懷裡撒嬌


&nbsp;


享受愛的傳送


&nbsp;


喜歡


&nbsp;


有您在身邊


&nbsp;


一次又一次


&nbsp;


重複甜蜜的嘮叨


&nbsp;


我知道


&nbsp;


今後


&nbsp;


你不會再回首


&nbsp;


一定


&nbsp;


會要我勇敢的往前走


&nbsp;


但我的淚水


&nbsp;


就是不聽使喚的滑落


&nbsp;


我親愛的媽媽


&nbsp;


我真的好想您


&nbsp;


我


&nbsp;


捨不得


&nbsp;


您走阿
