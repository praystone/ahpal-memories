&nbsp;


人與人之間要有分寸，


人與事之間也要有分寸，


尤其說話更要有分寸；<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />


如果沒有分寸，就會有衝突，


就會有是非，就會不歡而散。 


&nbsp;


&nbsp;


做人要明理，明理先要懂得彼此之間的分寸。


因為理是軌則，應該是連接在一起，是保持雙軌運行的；


人我之間彼此應該保持多少間距，此中都有分寸。 


&nbsp;


現在講究高人做事，都要先拿捏分寸、拿穩分寸，


合乎分寸，凡事就容易成功。


做人應該注意一些什麼分寸呢？列舉如下： 


&nbsp;


&nbsp;


&nbsp;


一、人情的分寸：


&nbsp;


人與人之間的交情，此中有分寸。小兒女可以叫爸爸跪下來給他當馬騎，爸爸會樂得哈哈大笑；如果是個外人，叫一個父執輩的人跪下來讓你當馬騎，不但要罵你，甚至要揍你，因為你太沒有分寸了。 


&nbsp;


&nbsp;


&nbsp;


二、好惡的分寸：


&nbsp;


每個人都有他的歡喜或不歡喜，


但歡不歡喜超過了分寸，別人就不以為然了。


請你喝一茶咖啡，不喜歡就隨便把咖啡倒了，此即不懂分寸；


請你喝牛奶，你大肆批評牛奶之害，這也失去了分寸。


人的喜歡不喜歡，不能太過強烈，


你非常喜歡的，也要顧念別人的不喜歡，


你非常不喜歡的，也要顧念別人的歡喜，這裡面都有分寸。 


&nbsp;


&nbsp;


&nbsp;


三、語言的分寸：


&nbsp;


說話，遣辭用句之間，分寸更大。


講話不但要注意對象與我關係的親疏、


對象跟我的輩分、對象跟我的性別，


尤其講話的音調、修辭用字的輕重，都有分寸。


你沒有拿捏好分寸，後果就會很麻煩。 


&nbsp;


&nbsp;


&nbsp;


四、賞罰的分寸：


&nbsp;


連續的嘉獎，會有人批評你私心；


連續的懲罰，即使高速公路警察開罰單，


一罰、二罰、三罰，駕駛人也會有反抗的心理，也會不服氣。


賞是鼓勵，罰是規誡，總要達到目的；


賞罰達不到目的，這就是沒有拿捏好分寸。 


&nbsp;


&nbsp;


&nbsp;


五、勞逸的分寸：


&nbsp;


人有時要分工，有時要合作；


分工的時候，勞逸不均，會引起抗爭，


因為失去了分寸。主管分配工作的時候，


對工作的輕重、時間、成效，要仔細的觀察，


要給予平均，不可失去分寸。


勞逸均衡，這是管理學上非常重要的原則。　 


&nbsp;


&nbsp;


&nbsp;


六、進退的分寸：


&nbsp;


在家庭裡，即使和父母講話，也要懂得進退分寸；


在公司和上級講話，更要知所進退。


什麼時候可以進言，什麼時候可以報告，


如果主管正在忙得不可開交，這時候你要插班報告，


事情的結果會如何，當然可想而知了。


所以，對於進退忙閒之間，時間要拿捏得好，尤其要拿捏得巧。 


&nbsp;


&nbsp;


&nbsp;


七、用錢的分寸：


&nbsp;


人會不會用錢，不在於錢多錢少，而是懂得用錢的分寸。


有的人每個月收入只有二萬元，可是收支平衡，甚至猶有餘裕；


有的人每個月有五萬元的收入，但是常常捉襟見肘，入不敷出，


這就是不懂得用錢的分寸。 


&nbsp;


&nbsp;


&nbsp;


八、兩性的分寸：


&nbsp;


兩性之間，尤其一對一的時候，


彼此的親疏、關係，更要拿捏好分寸，


免得日後麻煩。 


&nbsp;


說到分寸，佛陀講經說法契理契機，就是分寸；


人間佛教重視傳統與現代融和，就是分寸；


叢林四十八單職事各司其職，就是分寸；


政府升遷、待遇，都有分寸。


分寸，分寸，人與人之間有很多的分寸，不能不重視。
