妳或許不忍心傷害我。


&nbsp;


妳對我不想說很明白。


&nbsp;


我們現在的互動關係。


&nbsp;


對妳來說是朋友家人。


&nbsp;


對我來說超出範圍了。


&nbsp;


我把妳看待的很重要。


&nbsp;


妳怎麼看待我無所謂。


&nbsp;


妳覺得我很固執堅持。


&nbsp;


對妳義無反顧的對待。


&nbsp;


因為我心容不下別人。


&nbsp;


只有妳能住進我心理。


&nbsp;


我對妳說過我會等妳。


&nbsp;


我等妳這三個字意義。


&nbsp;


妳怎麼看待怎麼解釋。


&nbsp;


是脫口而出虛情假意。


&nbsp;


我說是一輩子的承諾。


------------------------------------


&nbsp;


這次勇敢做自己。


&nbsp;


我想給妳一輩子。


&nbsp;


遍體鱗傷沒關係。



用盡所有的勇氣。


&nbsp;


放下自己的自尊。


&nbsp;


旁人的冷言嘲諷


&nbsp;


可以什麼不在乎。


&nbsp;


只因為我喜歡妳。


&nbsp;


------------------------------------


愛妳,喜歡妳是一種責任。


&nbsp;


妳說,妳不是最好最完美。


&nbsp;


妳說,我會遇到比妳更好。


&nbsp;


我不會遇到比妳更好的。


&nbsp;


我不會輕易對別人動心。


&nbsp;


因為妳深深住在我心裡。


&nbsp;


希望妳真心明白感受我。


&nbsp;
