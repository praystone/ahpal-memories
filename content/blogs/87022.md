&nbsp;









上了一天班，回到家裡，丈夫只會粗聲粗氣的說：

&nbsp;

「飯煮好了沒？我餓死了。」

&nbsp;


對妻子的忙碌辛苦視而不見。&nbsp;&nbsp; 

&nbsp;&nbsp; 


有一天，丈夫帶著未婚獨居的同事回家，

&nbsp;



同事一進門，老婆接過兩人的公事包和外套，

&nbsp;



丈夫還是老話：「飯煮好了沒？」

&nbsp;


同事卻說：「大嫂，對不起，麻煩你了。」

&nbsp;


看到一桌熱騰騰的飯菜，同事感動的差點掉下淚來：

&nbsp;

「一回家就有熱飯熱菜可吃的感覺真好！

&nbsp;


哪像我，每天回家都只有冰冷的牆壁迎接我。」 

&nbsp;


然後埋頭拼命吃菜，彷彿一輩子都沒吃過飯的；

&nbsp;



對老婆的手藝讚不絕口，

&nbsp;



一盤簡單的炒青菜都被他說得像什麼山珍海味的。

&nbsp;


老婆眉開眼笑，不斷的夾菜給同事，還說：

&nbsp;

「請用。」 

&nbsp;

老公反而被冷落一邊。

&nbsp;


吃完飯，老公照例拍拍屁股，

&nbsp;



想移到客廳沙發看電視、聊聊天，

&nbsp;



正想開口叫老婆倒茶；

&nbsp;



那個不識好歹的同事，竟然幫忙收拾碗筷，

&nbsp;



還不忘跟老婆道謝：

&nbsp;



「大嫂，謝謝你費心做這麼豐盛的晚餐請我。

&nbsp;


&nbsp;&nbsp;這些碗盤我來洗就好。」 

&nbsp;

老婆當然不會讓客人洗碗。

&nbsp;


這時，丈夫說：「泡茶。」

&nbsp;



雞婆的同事居然說：

&nbsp;


「大嫂，你告訴我茶葉在哪裡，我自已來就好。」

&nbsp;


同事走了之後，老婆一邊洗澡一邊唱歌。

&nbsp;



丈夫問你為什麼那麼高興？

&nbsp;



老婆說：

&nbsp;



「我煮了十幾年的菜給你吃，

&nbsp;



&nbsp;&nbsp;你從來也沒有跟我說一聲謝謝。

&nbsp;



&nbsp;&nbsp;吃完飯不但不幫忙洗碗，

&nbsp;



&nbsp;&nbsp;還要我泡茶侍候你。

&nbsp;


&nbsp;&nbsp;你看看你那個同事多懂事。」 

&nbsp;&nbsp; 


老公回答：

&nbsp;



「因為他第一次來我們家啊，因為他不認識你，

&nbsp;


&nbsp;&nbsp;你等著看好了，看他結婚之後，會不會跟老婆說謝

&nbsp;

謝。」 

&nbsp;


為什麼？

&nbsp;


為什麼面對至親的人，我們總覺得一切都是理所當

&nbsp;

然，而忽略了最基本的禮貌和感謝？

&nbsp;


老婆為什麼一定要煮飯？

&nbsp;



因為那是她的工作、她份內的事？

&nbsp;


因為她愛你。

&nbsp;


丈夫為什麼要辛苦工作受到老闆指責、剝削仍然不敢

&nbsp;

辭職？

&nbsp;


因為他愛你。
