一笑而過rn&nbsp;rn&nbsp;rn面對失敗和挫折，一笑而過是一種樂觀自信，


&nbsp;


然後重整旗鼓，這是一種勇氣。


&nbsp;


面對誤解和仇恨，一笑而過是一種坦然寬容，


&nbsp;


然後保持本色，這是一種達觀。


&nbsp;


面對讚揚和激勵，一笑而過是一種謙虛清醒，


&nbsp;


然後不斷進取，這是一種如意。


&nbsp;


面對煩惱和憂愁，一笑而過是一種平和釋然，


&nbsp;


然後努力化解，這是一種境界。


&nbsp;


失敗和挫折暫時的，只要你敢於微笑，


&nbsp;


誤解和仇恨是暫時的，只要你達觀代之，


&nbsp;


讚揚和激勵是暫時的，只要你不耽於夢想，


&nbsp;


煩惱和憂愁是暫時的，只要不被它左右。


&nbsp;


生活中罩在我們頭上的光環和


&nbsp;


不如意的事情就像顏色不一的氣泡，


&nbsp;


人生不如意之時常一二，明媚之日常八九。


&nbsp;


別再留戀破碎的舊夢，別再沉迷於往日的幸福光環，


&nbsp;


別再計較人生的得失，別再擔憂明天的天氣。


&nbsp;


不要因為今天的痛苦而否定明天的幸福，


&nbsp;


不要因為微小的成功而迷失方向，


&nbsp;


不要因為眼前風雨而否定明天的陽光，


&nbsp;


因為烏雲是遮不住太陽的，


&nbsp;


也不要因為錯過星星而哭泣，


&nbsp;


否則我們會錯過月亮。


&nbsp;


既然這一切都是暫時的，


&nbsp;


我們為什麼不一笑而過。
