&nbsp;

丫頭，假如我娶到的是你,

我起床之后就可以端詳依舊熟睡的你,
&nbsp;
看你那可愛的面孔,亂亂的長發,還有一絲孩子氣,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們就可以在洗漱時互相潑水,打濕彼此的睡衣,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

我要為你做早餐,
&nbsp;
讓你醒來時朦朧著雙眼就看到香噴噴的飯菜和整齊的餐具,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們會高高興興的走出家門,為著溫馨的天空,
&nbsp;
互相加油,一同拼搏努力,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

每天中午,我會到你的單位接你,
&nbsp;
帶你去找一家隱蔽的小吃店或體面的飯店,享受浪漫與甜蜜,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

下班后,我們會一起去超級市場,或者買一點果蔬,或者買一點安逸,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

&nbsp;
回到我們溫馨的小屋后,我們要一齊在廚房開工,弄它個翻天覆地,&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

飽餐后的我們,要在電視前,我躺在沙發上,而你,躺在我的懷里,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們可以一起看看新聞,一起關注體育,
&nbsp;
或者弄幾個抑或浪漫抑或搞笑的連續劇,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

或許,我們會買兩臺電腦,打打游戲聊聊天,你在臥室,而我,在隔壁,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

躺在舒適的大床上,軟軟的被子里,我們會回歸兒時的搗蛋,兒時的調皮,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,&nbsp;
&nbsp;
我會在夢里與睡在身邊的你,牽手,嬉戲,回味每天的快樂記憶...&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

我們依偎著看看老電影,搞笑的大話西游,
&nbsp;
震撼的勇敢的心,浪漫的鐵達尼,
&nbsp;

丫頭，假如我娶到的是你,

我們要一起看世界杯,一起瘋狂的呼喊進攻,一起撅著嘴慨嘆失利,
&nbsp;

丫頭，假如我娶到的是你,

我們要組成夫妻cs小隊,刻苦訓練,默契配合,
&nbsp;
爭取參加wcg,(好像還沒有雙人組,hoho)
&nbsp;

丫頭，假如我娶到的是你,

我們要坐在床上打撲克,先贏你,看你嗔怪的樣子,
&nbsp;
再輸你,得到你的吻,你的甜蜜,&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
我們要躺在一起欣賞泰戈爾的詩,靜謐的臥室,你讀給我,我也讀給你,&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

我們會一起聆聽維也納的新年音樂會,聽我昏天黑地的賣弄,
&nbsp;
看你似懂非懂的傻兮兮,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,&nbsp;
&nbsp;
我們買一大堆好吃的,坐在一起,你爭我搶,話梅,薯條,烀豬蹄,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你
,&nbsp;
我們要一起打掃小窩的衛生,你擦玻璃,我擦桌椅,你洗衣服,我掃地,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,&nbsp;
&nbsp;
我們要去照好多好多大頭貼,貼在臥室,貼在廚房,
&nbsp;
貼在洗手間,貼在各自的錢夾里,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們買一對漂漂的手機,工作的間歇,可以打打電話,發發信息,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們要漫步在繁華的商業街,打爆信用卡,帶走心儀的 burberry &amp; gucci,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,&nbsp;
&nbsp;
我們要非常努力的工作,爭取早日買到你喜歡的QQ開出來自由瀟灑,
&nbsp;
還有對著大海的別墅,住進去心曠神怡,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們要一起去游樂場,過山車,死亡電梯,用這一切一切找回童年的回憶,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們要一起到湖邊垂釣,魚桿,魚餌,大大的遮陽帽,溫馨的雙人小椅,
&nbsp;

丫頭，假如我娶到的是你,

我們要一起去跑馬場,體驗英純血馬的風馳電掣,享受阿拉伯馬的輕盈飄逸,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們要一起去蹦極,體驗從天而降的快感,感受瘋狂的至死不渝,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

我們要一起去登山,不管它的海拔,不管它的名氣,
&nbsp;
只為我們彼此心中如青山的愛意...&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,

當你過生日時,我要每次想一個好點子,讓你開心,給你驚喜,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
當我過生日時,我們買一小塊蛋糕就好,坐在燭火旁,你吻我,我也吻你,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
當情人節時,我要送你7朵玫瑰花,代表咱爸咱媽咱未來的
&nbsp;
或已經有了的寶寶和咱自己,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
當情人節時,你送我一盒燦燦的巧克力,親手為我剝開一顆,放進我的嘴里,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
過新年時,我們各自去買新衣服,新圍巾,新鞋子,卻都不是買給自己,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當你生病時,我會背著玲瓏的你,到醫院看看照照,圖一個放心,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當我生病時,你會陪在我的身邊,給我講你和朋友的趣事,瑣碎的稀奇,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當你不開心時,我會哄你,逗你,讓你罵我,打我,直到你為笑破涕,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當我不開心時,你會安慰我,鼓勵我,
&nbsp;
或者就是趴在我的背上,輕輕在我耳邊吹氣,&nbsp;
&nbsp;
&nbsp;
丫頭，假如我娶到的是你,&nbsp;
&nbsp;
當你升職抑或我升職時,我們要出去狂歡,喝得醉醺醺,
&nbsp;
回來的路上還哼唱著婚禮進行曲,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當你懷孕時,我要更加小心的照顧你,
&nbsp;
你的飲食,你的運動,還要藏起來你的洗衣機,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,&nbsp;
&nbsp;
當你臨產時,我會一直陪著你,牽著你,在你的耳邊呼喚你,親愛的,
&nbsp;
我在這呢,我愛你,
&nbsp;
&nbsp;

丫頭，假如我娶到的是你,

當你做了媽媽我做了爸爸,我們就忙得不可開交啦,
&nbsp;
給寶寶喂奶,洗澡,教他(她)喊mammy和daddy...

祝 福大家 &nbsp; &nbsp;白色情人節快樂
