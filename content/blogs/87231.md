昨天沒出狀況.平安度過!


<?xml:namespace prefix = o ns = "urn:schemas-microsoft-com:office:office" />&nbsp;


今天出狀況


&nbsp;


店裡有用固定的炸粉


&nbsp;


店長今天叫他朋友買了另一種.......沒看哪種炸粉!


&nbsp;


結果


&nbsp;


我清理桌面


&nbsp;


我將三個些許炸粉盒


&nbsp;


全部合在固定的炸粉盒!!!!!!!!!!倒大楣了!


&nbsp;


剛倒傻眼到說不出話來.


&nbsp;


店長高興的跟朋友說話


&nbsp;


我已經嚇到不知所措了.


&nbsp;


之後客人叫了一份雞排


&nbsp;


店長覺得雞排炸起來特別白.


&nbsp;


店長回頭去看.


&nbsp;


發現哪盤炸粉.已空了


&nbsp;


當下跑來問我


&nbsp;


我是不是將哪盤試用的炸粉


&nbsp;


給丟進固定炸粉裡!


&nbsp;


我說對呀


&nbsp;


店長還沒動氣


&nbsp;


我已經開始害怕了


&nbsp;


店長說我怎麼沒說


&nbsp;


我說你當時在跟朋友說話…沒繼續解釋!


&nbsp;


完了…………


&nbsp;


接下來空氣整個凝結了.


&nbsp;


店長都不說話了


&nbsp;


快下班時


&nbsp;


來了好幾個客人


&nbsp;


我既緊張又害怕的


&nbsp;


有1.2張東西超多的


&nbsp;


看到頭上一排的單子


&nbsp;


腦袋完全打結了.


&nbsp;


我害怕又做錯


&nbsp;


小心的對著單子將每張單子的炸物都包好


&nbsp;


眼前的狀態是


&nbsp;


面前已堆一座山的炸物等著我去包裝


&nbsp;


今天店長的女友還有朋友都不約而同來店裡.


&nbsp;


我在亂時


&nbsp;


店長女友來幫忙結帳—瞬間降低害怕


&nbsp;


稱到最後一張單子


&nbsp;


我去外送找零給客人回來後


&nbsp;


店長說:下班了!


&nbsp;


整個鬆了口氣


&nbsp;


我知道我離開店後


&nbsp;


直奔家裡


&nbsp;


我想著


&nbsp;


每每出狀況我都怕的說不出話來


&nbsp;


我倒底該怎辦阿!


&nbsp;


我是不是應該提出我不要做了


&nbsp;


我太健忘…..真的很嚴重


&nbsp;


面對服務業我……….


&nbsp;


這個工作不適合我?????????


&nbsp;


我不知道該怎麼改善


&nbsp;


我很健忘


太容易緊張了


而且我超害怕別人生氣


&nbsp;


~~上星期店長說:


&nbsp;


他生氣的時候會口不擇言.破口大罵.會失控……….


&nbsp;


當我聽到店長說的時候


&nbsp;


我的腦袋浮現的是


&nbsp;


我不想做了~~~~~~~~~~~~~


&nbsp;


***今天這樣子的狀況


&nbsp;


我害怕明天…***
