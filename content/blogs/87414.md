一對年輕的夫婦正在所租的小套房裡為著添購新家具的事情而鬧彆扭​，女的口才犀


利，男的剛毅木納，過沒多久


作老公的就已處於挨轟的​態勢。不一會兒，兩個人都嚷得精疲力盡，說不出話來，


這時前幾分​鐘一直被迫採低姿


態的先生忽然開口了，他感慨地對他所愛的老婆說​：「老婆，就算妳講得全都對，


但為了辯贏我而毀掉一整個晚


上的氣​氛，值得嗎？」
&nbsp;


「為了辯贏我而毀掉一整個晚上的氣氛，值得嗎？」雖是短短的幾個​字，確多麼值


得我們這些講求「贏」為目的


的現代人省思啊！
&nbsp;


我很喜歡一句名言：「有時候你贏了，但其實你輸了！」可不是嗎？
&nbsp;


有時候你贏了面子，但其實你輸了感情；
&nbsp;


有時候你贏了口舌，但其實你輸了形象；
&nbsp;


有時候你贏了好處，但其實你輸了友誼.....
&nbsp;


總之，有時候您看似贏了，實際上你卻輸了！
&nbsp;


待人處事固然應該「據理」，但卻不一定要臉紅脖子粗地在那兒「力​爭」！理直氣


「和」的態度絕對比理直氣


&nbsp;


「壯」更易為人所接受。
&nbsp;


這世界上有四種人：
&nbsp;


第一種人，沒有立場，不講道理，態度也不好；
&nbsp;


第二種人，沒有立場，不講道理，態度卻很好；
&nbsp;


第三種人，有自己的原則，也很會講理，但表達方式卻很「衝」；
&nbsp;


第四種人，很有立場，很講道理，溝通方式也很溫和。
&nbsp;


如果將這四種人各配上一個形容詞，我們可以說：
&nbsp;


第一種人，是徹底的「可憐人」，因為他將一無所有；
&nbsp;


第二種人，是鄉愿型的「濫好人」，因為他實在缺乏立場；
&nbsp;


第三種人，是橫衝直撞的「機器人」，因為他雖然邏輯無礙，卻不懂​與人相處的藝


術。
&nbsp;


第四種人，是「最可愛的人」，因為他們就是像天使一般。
&nbsp;


在這個世界上，唯有成為「第四種人」，您才會是一個真正的贏家！
&nbsp;


在人際互動間，您會顧此失彼嗎？您常「看似贏了，但卻輸了」嗎？​實在值得您深


思咀嚼之。
&nbsp;


做人不講理，是一種缺點；
&nbsp;


做人硬講理，是一個盲點....
