商人的四個妻子


&nbsp;



從前，有個商人娶了四個妻子，第四個妻子深得商人喜愛，


不論坐著站著，商人都跟她形影不離。非常寵愛。


&nbsp;


第三個妻子是經過一番辛苦才得到，商人常常在她身邊甜言蜜語，


但不如對第四個妻子那樣寵愛。 


&nbsp;


第二個妻子與商人常常見面，互相安慰，宛如朋友。


只要在一塊就彼此滿足，一旦分離，就會互相思念。 


&nbsp;



而第一個妻子，簡直像個婢女，家中一切繁重的勞作都由她擔任。


她身陷各種苦惱，卻毫無怨言，在商人的心裡幾乎沒有位置。 


&nbsp;


&nbsp;


&nbsp;



一天，商人要出國做長途旅行，


&nbsp;


他對他四個妻子說：「你肯跟我一塊兒去嗎？」 


第四個妻子回答：「我可不願意跟你去。」 商人恨她無情，


&nbsp;


就把第三個妻子叫來問：「你能陪我一塊去嗎？」


第三個妻子回答道：「連你最心愛的第四個妻子都不願意陪你去，我為什麼要陪你去？」 


&nbsp;


商人把第二個妻子叫來說：「你能陪我出國一趟嗎？」


第二個妻子回答道&nbsp; :&nbsp; 「我受過你恩惠，可以送你到城外，但若要我陪你出國，恕我不能答應。」 


&nbsp;



商人也憎恨第二個妻子無情無意，對第一個妻子說：「我要出國旅行，你能陪我去嗎？」 


第一個妻子回答：「我離開父母，委身給你，不論苦樂或生死，都不會離開你的身邊。不論你去哪裡，走多遠，我都一定陪你去。」 


&nbsp;



　　 他平日疼愛的三個妻子都不肯陪他去，他才不得不攜帶決非意中人的第一個妻子，離開都城而去。 


&nbsp;


　　 原來，他要去的國外乃是死亡世界。擁有四個妻子的商人，乃是人的意識。 


&nbsp;


　　 第四個妻子，是人的身體。人類疼愛肉體，不亞於丈夫體貼第四個妻子的情形。但若大限來臨，生命終結，靈魂總會背負著現世的罪福，孤單寂寞地離去，而肉體轟然倒地，沒有辦法陪著。 


&nbsp;



　　 第三個妻子，無異於人間的財富。不論多麼辛苦儲存起來的財寶，死時都不能帶走一分一毫。 


&nbsp;



　　 第二個妻子是父母、妻兒、兄弟、親戚、朋友和僕傭。人活在世上，互相疼愛，彼此思念，難捨難分。死神當頭，也會哭哭啼啼，送到城外的墳墓。用不了多久，就會漸漸淡忘了這件事，重新投身於生活的奔波中。 


&nbsp;



　　 第一個妻子則是人的心，和我們形影相隨，生死不離。它和我們的關系如此密切，但我們也容易忽略了它，反而全神貫注於虛幻的色身.
