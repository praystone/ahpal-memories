只是夢一場，醒來卻已滄桑


&nbsp;


&nbsp;


所有人都笑著迎接我們的出生，只有我們是哭的，因為我們知道我們是來受罪來了。


&nbsp;


只是夢一場，醒來卻已滄桑


&nbsp;


懵懵懂懂的開始學習著自己所謂的人生，開心的笑，故作深沉的冷酷，模仿著風光亮麗的人們……


&nbsp;


當自己懂得了悲傷，當自己明白了痛苦，於是我們學會了逃避，學會了推卸。


&nbsp;


告訴自己勇敢些去面對，揮一揮手，當到了目的地，憋滿的氣卻突如其然的消散了，


&nbsp;


我們，總是不夠堅強……


&nbsp;


嫉妒著別人，理所當然的嫉妒著，我們也可以的，卻深深的埋藏著，或者發芽，或者腐爛。


&nbsp;


骯髒的世界，總是出些所謂單純的人們，他們用純純的眼神告訴我們，我們在不斷的攀登中迷失了自我。


&nbsp;


不敢相信自己曾經也有過如此的純潔，於是，告誡著他們，


&nbsp;


這個世界，沒有他們想像的那麼美，處處是危機，處處是荊棘，如同在告誡著自己……


&nbsp;


終於我們開始累了，攀巖中想找個伴了，以為他們總可以給自己些快樂，


&nbsp;


讓自己在猶豫的時候可以搭一把手。


&nbsp;


可現實總是比想像來的殘酷，找來的伴總是不那麼另你滿意，


&nbsp;


我們總是以為他們在肆意揮霍我們的愛，找來的愛情，總是自己付出的比得到的多，


&nbsp;


我們總是忘了擁有他們的初衷，


&nbsp;


只是想搭把手，只是想讓自己不寂寞……我們要求的更多更多……


&nbsp;


於是，爭吵開始蔓延……


&nbsp;


我們忘記了攀登，在中途停止向前，每天哀歎著，每天擦拭著眼淚，


&nbsp;


默默無語……從頭，才發現，我們沒有了朋友，那些曾經一起攀登過，


&nbsp;


幫助過的朋友已經被我們狠狠落在了世界的另一個角落……


&nbsp;


突然醒來，一覺卻失去了自己大半個青春……


&nbsp;


於是又是一個人孤孤單單的上路，想像著曾有人告訴我們，他們會陪著我們一路到底……


&nbsp;


一路走來到了原點，原來，人生一直都只是原地踏步，


&nbsp;


原來海枯石爛來的那麼早，天涯海角只在眼前……


&nbsp;


轉眼已白髮蒼蒼，或兒孫滿堂，或仍孤零零的一個人，愛，不愛，責任，逃避，


&nbsp;


我們笑了，轉了一個圈，世界沒有因為我們而改變，


&nbsp;


我們卻改變了那麼多，是適應還是反抗？


&nbsp;


又夢到孩時，又夢到他們……


&nbsp;


我們開始懂得感恩，開始珍惜自己曾經犯下的錯誤，開始搜尋這曾經的人們……


&nbsp;


因為知道自己沒有時間，才發現自己從來沒好好看過這個世界，或厭惡，或抱怨，卻從不曾懂得……


&nbsp;


一切都將結束，恩怨，就隨風吧……於是，我們笑了。


&nbsp;


所有人都哭著面對我們的離開，只有我們是笑的，因為我們知道，我們將不用再痛苦了……


&nbsp;
