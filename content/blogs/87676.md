&nbsp;


我現在只知道,能和妳真正在一起,是我最快樂的事情


&nbsp;


愛妳是一種感覺,即使痛苦也會覺得很幸福


&nbsp;


愛妳是一種感受,即使心碎也會覺得很甜蜜


&nbsp;


愛妳是一種經歷,即使破碎也會覺得很美麗


&nbsp;


因為有妳,我很快樂


&nbsp;


因為有妳,我很迷惑


&nbsp;


因為有妳,我很受傷


&nbsp;


因為有妳,我不知如何不放感情面對妳


&nbsp;


-------------------------------------------------------------------


&nbsp;


愛妳喜歡妳,原來很容易,就是永遠把妳放心裡


&nbsp;


愛妳喜歡妳,原來不容易,就是無法走到妳心裡


&nbsp;


無論世事如何變化,妳我距離多遠,我的心裡都是妳


&nbsp;


但最終妳我會漸行漸遠,是無可避免的結果


&nbsp;


放棄該放棄的是無奈,放棄不該放棄的是無能


&nbsp;


不放棄不該放棄的是執著,我對妳就是不放棄


&nbsp;


-------------------------------------------------------------------


說喜歡我,最終又會離我而去


&nbsp;


把我從天堂,又推入地獄,會這樣嘛


&nbsp;


無論多少壓力,我都默默接受


&nbsp;


要愛妳,喜歡妳是很容易簡單的事情


&nbsp;


但是,我要用一生歲月才能把妳忘掉


&nbsp;


對妳,我卻不知該如何收回我的心意


-------------------------------------------------------


每個人心裡都有一個最愛,最放不下的人


&nbsp;


我們之間總有一個人讓另一個人心痛


&nbsp;


我們之間總有一個人讓另一個人哭泣


&nbsp;


誰是誰的心痛,誰是誰的淚水,誰又是的最愛


&nbsp;


我也是有最脆弱的一面,誰都有軟弱的時候


&nbsp;


只有心底被傷的體無完膚,才會展露最脆弱


&nbsp;


-------------------------------------------------------------


曾經想過刪除妳的一切,把妳從我心裡刪除


&nbsp;


我始終辦不到,用逃避自己的方式來逃避妳


&nbsp;


我真的不該喜歡妳愛妳嘛,我真的是錯了嘛


&nbsp;


可是我真的很喜歡妳愛妳,不想離開妳身旁


&nbsp;


從外表看似堅強的我,內心早已經傷痕累累


&nbsp;


難道我只能當朋友,同事,哥哥,不會有所改變


&nbsp;


難道我角色只能妳所期望的,不會有所改變


&nbsp;


時間不能改變妳我嘛,我們不能更進一步嘛
