夜了

&nbsp;

墨黑迷離了方向

&nbsp;

光若水般傾泄下來 

&nbsp;

靜靜地爲影兒導航

&nbsp;

雖然沒有溫度

&nbsp;

星星點點卻能把通身照亮

&nbsp;

你看&nbsp;光至影顯

&nbsp;

在光裏輕舞&nbsp;于舞中飛揚

&nbsp;

沒了淚水

&nbsp;



卻胸懷憂傷

&nbsp;

沒有體溫

&nbsp;&nbsp; 

仍心存熱望

&nbsp;

願每一個夜幕陳鋪的時候

&nbsp;

光影相投

&nbsp;

共舞同聆一曲《殤》

&nbsp;

盡管 冰涼如水

&nbsp;

卻也是一種相守

&nbsp;

哪怕 沈寂靜默

&nbsp;

也有未泯的思量

&nbsp;

休管那&nbsp;休管那東方吐白的時候

&nbsp;

你去了何方

&nbsp;

深的哀怨 

&nbsp;

濃的情殤

&nbsp;

會在下個夜的光與影中奏響

&nbsp;
