他是剛退伍的年輕人，正要開始人生另一段新旅程，準備大展身手的時候。&nbsp;
這天他跟朋友喝完酒，騎摩托車，昏昏沈沈，撞到卡車，反彈回來，爆炸起火，全身燒成一個大火球。&nbsp;
還好路邊剛好有人洗車，趕快拿水沖他，叫救護車送醫院。&nbsp;
如果不是這樣，他當場就燒死了。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 人的際遇是很奇妙的，那個洗車的人早不洗晚不洗，偏偏就在那時候洗，剛剛好及時滅火。&nbsp;
我們每天發生的每一件事，跟別人每天發生的每一件事，似乎毫無牽扯，渺不相涉，但冥冥之中............&nbsp;
似乎又有著令人難以言喻的微妙關聯。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 腦出血，大腿骨折，全身百分之三十七的三度燒傷。
他先在別家醫院插管，太嚴重了，然後轉送來慈濟醫院。
在燒燙傷中心外面，我跟媽媽說：「救活的機率不大。」
&nbsp;&nbsp;
媽媽聽了之後面無表情，從一種悲傷中沉默下去。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; &nbsp;有肺水腫的併發症，骨科也開刀，還好傷口沒有感染。&nbsp;
&nbsp;&nbsp;
雖然傷口沒有感染，全身百分之三十七的三度燒傷還是太嚴重了。&nbsp;
一般說來，一度是像太陽曬傷那種，會脫皮，不會有水泡；會刺痛，皮膚變粉紅色。&nbsp;
二度又有分淺G度和深二度：有水泡，上皮層以及部分真皮層被燙之後，有滲液，皮跟下面已經分家了，這是淺二度；深二度是更深的真皮層受傷。&nbsp;
三度是上皮層、真皮層都壞死。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽告訴我：「鄭 醫師，你知道嗎？我兒子很喜歡當義工，他都在幫助別人。他在伊甸基金會當義工，幫老人送飯，後來還跟我
說，以後就算在上班，也要繼續當義工。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「他是個好人。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「我知道，但好人不一定會有好運。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;該我沉默了，好像被一道閃電擊中後的沉默。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;媽媽又說：「他很喜歡服務別人，他是個好兒子。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;我輕聲回應：「妳是個好媽媽。」&nbsp;

&nbsp; &nbsp;從此這位媽媽每天到燒燙傷中心門口守候，原來她立刻把工作辭了，每天就坐在燒燙傷中心門口等我。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;我不知道她去哪搬來一張小桌子和椅子，燒燙傷中心一天只開放兩次，早上一次，晚上一次，她就坐在門口，每天在門口等我出來。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「他今天怎樣？」媽媽問。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「危險。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;我從開刀房出來，一定會經過那條路，沒別的路。&nbsp;
每天碰到這位媽媽。&nbsp;
每天每天看著媽媽期待的眼神，我告訴她：「我不能說妳兒子一定會好，因為我真的不知道。」&nbsp;

&nbsp; 「機率多大？」 &nbsp;
&nbsp; &nbsp;&nbsp;
&nbsp; 「百分之十會活。」 &nbsp;
&nbsp; &nbsp;&nbsp;
&nbsp; 「百分之十會活？你怎麼不說百分之九十會死？」 &nbsp; &nbsp;
&nbsp; &nbsp;&nbsp;
&nbsp; &nbsp;「之前，有跟他類似的病人都好了，所以，我想，他還是有機會的。」&nbsp;

&nbsp; 「別再安慰我了，除非你也經歷過不知自己的孩子是否能活到明天的那種煎熬。」&nbsp;

&nbsp; 我不再說話。&nbsp;
媽媽從此依然每天坐在燒燙傷中心門口等我，她有時好像在寫什麼，有時口中唸唸有詞。&nbsp;
只是每次遇到我，一定會問：「我兒子今天怎樣？」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; 「還是很危險」、「還在昏迷」、「差不多」、「再觀察」、「植皮」、「還好」，所有我可以回答的話，我一直重複回答，每天看到這位媽媽，看到我都有點不知道要怎麼面對，媽媽每天一直到晚上九點多，醫院門禁時間開始才回家。&nbsp;
&nbsp; &nbsp;一大早就坐在那裡，一直等我，我幾乎每天進開刀房，所以每天會碰到她，因為從開刀房出來只有一條路，
她就在那裡等我，一定要跟我說到話，才安心。&nbsp;
那怕這些話是讓她失望的話，她還是安心，因為她一直抱著希望。&nbsp;

&nbsp; 兒子昏迷十二天後，忽然醒過來。&nbsp;
他之前昏迷的時候，換藥還不會覺得痛，之後他才知道痛，換藥是非常非常痛的，他全身像被通電一樣，在床上掙扎、扭曲、翻轉、頓足，哀嚎。&nbsp;

&nbsp; &nbsp; 他腦部嚴重受創，百分之九十以上救不活，但他就是從昏迷之中醒過來了；當然，後續還是要多次植皮、換藥。&nbsp;
燒燙傷疤痕對外觀影響很大，要用心處理。&nbsp;
我的工作不只是救人，還要讓人有品質的生活。&nbsp;
&nbsp;&nbsp;
我告訴媽媽，兒子醒了。媽媽沒有特別高興，但是她的表情卻更令我深深震撼。&nbsp;

&nbsp; &nbsp; 媽媽問：「現在呢？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「妳回家，好好休息，明天再來。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「就這樣？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「對，就這樣。」我頓了頓，「但並不容易。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「是不容易。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽沒有回家，還是坐在燒燙傷中心門口等，每天都在同一時間出現、每天都在同一地點出現，每天都問同樣的話。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 我還是每次回答「這星期三植皮」、「還好」、「這星期四植皮，取大腿的皮，補胸部的」、「這星期五要植皮，補小腿的。」&nbsp;
補皮是一次補一些，因為不能一下子取一大塊皮，手術時間太久，麻醉太久，對病人會有一些影響。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 這天早上我要上第一台刀，經過長走廊，一轉角，忽然發現眼前有個瘦小身影，正是那位媽媽。&nbsp;
我放輕腳步，她不知道我就走在她後面，她左手扛著一張小桌子，右手提著一張小椅子，肩上還背了一個袋子，顯得很吃力，我在她身後就可以聽到她的喘氣聲。&nbsp;
我故意放慢腳步，她和我的距離越來越遠。&nbsp;

&nbsp; &nbsp; 只見她走到燒燙傷中心門口，先放下椅子，再放下桌子。&nbsp;
那桌子是折疊的，她左手扶著桌子下緣，右手抓著桌子上邊，雙手展開成一個大大的一字型，那桌子的鐵榫似乎卡住了，她用力往下扳，顯出努力的樣子，試了好幾下，才把桌子攤平，她似乎鬆了一口氣，把椅子放好，&nbsp;
從袋子裡拿出好大一本很厚的電話簿，然後拿起筆，好像在寫什麼，有時口中唸唸有詞。&nbsp;

&nbsp; &nbsp; 我被這個畫面釘在原地。 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 這個媽媽寫字的畫面我已經看過無數次，但沒有一次這麼感動，感動到忘了移動。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 她就這樣端坐著，坐得很挺、很直，手裡的筆一直動一直動，不曾停息；口中還是唸唸有詞，沒有間斷。&nbsp;
那樣凝神、那樣專注，我眼裡的天地彷彿僅剩一張桌子、一張椅子、一個媽媽。&nbsp;

&nbsp; &nbsp; 我還是離開了，進了開刀房。&nbsp;
一直到中午我開完刀，走出來，這是唯一的走廊，我當然又遇到她，但這時她身邊多了一個小女孩，看起來大概六歲，頗為乾淨乖巧。&nbsp;

&nbsp; &nbsp; 媽媽立刻問我：「今天怎樣？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「我剛開完刀，還沒去看。」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽點點頭，不說一句話，雖然神情略顯疲憊，但梳理整齊；目光溫潤，清朗有神，有股令我非常難以形容的氣勢。&nbsp;
&nbsp; &nbsp; 我回想起這個媽媽自從兒子住進燒燙傷病房，每天每天搬桌子在這裡等我，早上跟我講一次話、晚上講一次，媽媽一定要聽到我講話，才能安心的離開。&nbsp;
&nbsp; &nbsp;
&nbsp; &nbsp; 我忍不住說：「真是難為妳了，受這樣的煎熬。」 &nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「這就是當媽媽的過程，一輩子都得對無法預料的事充滿信心。」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 真了不起！我打從心底敬佩，又問：「妳的信心從哪裡來？」&nbsp;

&nbsp; &nbsp; 她不說話。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 我看著桌上的紙筆，問她：「我可不可以看看妳在寫什麼？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 她微一點頭，我拿起桌上一張張的紙，原來那不是電話簿，是一張張薄薄的那種紅色格線的十二行紙，&nbsp;
累積厚度已經達到像厚厚的電話簿一樣，上面密密麻麻，寫滿了字，字跡娟秀，工整有力，上面寫的是：&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 假使興害意推落大火坑念彼觀音力火坑變成池&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或漂流巨海龍魚諸鬼難念彼觀音力波浪不能沒&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或在須彌峰為人所推墮念彼觀音力如日虛空住&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或被惡人逐墮落金剛山念彼觀音力不能損一毛&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或值怨賊繞各執刀加害念彼觀音力咸即起慈心&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或遭王難苦臨刑欲壽終念彼觀音力刀尋段段壞&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或囚禁枷鎖手足被鈕械念彼觀音力釋然得解脫&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 咒詛諸毒藥所欲害身者念彼觀音力還著於本人&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 或遇惡羅剎毒龍諸鬼等念彼觀音力時悉不敢害&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 若惡獸圍繞利牙爪可怖念彼觀音力疾走無邊方&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 蚖蛇及蝮蝎氣毒煙火然念彼觀音力尋聲自迴去&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 雲雷鼓掣電降雹澍大雨念彼觀音力應時得消散&nbsp;

&nbsp; &nbsp; 我在震撼中不能言語。&nbsp;

&nbsp; &nbsp; 媽媽說：「我小時候，我阿嬤每晚都會點一枝香，然後唸一遍經。&nbsp;
她說，每一枝香都代表沒有被回應的祈禱。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 日復一日月復一月年復一年，千千萬萬枝香被燃起。
其實，人們的祈求大多都會落空的，根本得不到回應，但夢想的美妙就在於，它是有可能實現的。&nbsp;
於是人們還是不斷祈求，一生之中一直在燃起希望、希望破滅、重燃希望的過程裡跌跌撞撞的前進。&nbsp;
燻香有時盡，希望永無窮。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 我微感悵然，問媽媽：「妳祈求什麼？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「力量。」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 我以為她的意思是說，祈求重傷的兒子充滿力量，活著走出醫院。&nbsp;
但是媽媽摸著小女孩的頭，卻說： 「這是我女兒，當初我兒子出車禍，你跟我說可能救不活的時候，我就想，如果……如果我兒子死了，我希望我有足夠的力量把我女兒撫養長大。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「妳放心，妳兒子很快就可以出院了。」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽聽到我這麼說，這些日子以來的擔心、害怕、守候、祈求，全部的情緒在瞬間釋放，兩行眼淚緩緩流了下來。 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 小女孩睜大眼睛，抬頭看著媽媽，右手拉著媽媽的衣角，輕輕搖擺，問說：「媽媽，妳怎麼哭了？」 &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽伸手抹了抹臉，回答：「媽媽沒有哭，只是有點難過。」&nbsp;

&nbsp; &nbsp; 「妳為什麼難過？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「因為當媽媽的有時候就是會這樣。」 &nbsp;
&nbsp; &nbsp;&nbsp;
&nbsp; &nbsp; &nbsp;不久後他出院了，偶爾在醫院碰到他，他又恢復以前壯碩結實的身材。&nbsp;

&nbsp; &nbsp; 我問：「你怎麼在這裡？」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 「好久沒來給你看，讓你看看我啊！我現在好很多。」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 這肯定是醫生最想聽到的一句話。&nbsp;

&nbsp; &nbsp; 把一個昏迷的垂死病人醫到會站著跟你說謝謝，那種感覺是很奇妙的。&nbsp;
我入行學到的第一件事：&nbsp;
任何人都可能在任何時候得到任何病、發生任何意外。&nbsp;
我們醫生被人視為金字塔頂端的人，被問「上面空氣好嗎？應該崇高偉大吧？」&nbsp;
但是，我每天都被提醒自己有多渺小，不管是病人，還是病人家屬，他們使我了解到：&nbsp;
世上的確有力量可以突破醫學的極限。&nbsp;
我們每天都經歷許多足以改變人生的瑣碎事物，沒人會知道發生什麼事，也不應該知道，因為那並不在我們的控制下。&nbsp;
或許我們不知道這些事發生的用意何在，但總有一天我們會知道，如果到了那一天我們還是不知道，那就表示我們根本不需要知道，根本不需要知道的事，為何自尋煩惱，一定要去知道？&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 這個媽媽後來到醫院跟我說，兒子要結婚了，特地來邀請我參加婚禮。我欣然前往。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 那天晚上，我坐在遠遠的角落，靜靜看著全村歡欣慶祝，慶祝一個勇敢的年輕人從鬼門關前回來。&nbsp;
「活在當下」，對他有了全新的意義。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 他跟我說過，時間太寶貴了，所以要花在你愛的人事物上面。&nbsp;
他是海軍陸戰隊退伍，身上有些特種訓練留下的疤痕，他自豪地說，疤痕是軍人的勳章。&nbsp;
因為在海軍陸戰隊被磨練過，他的意志力也很驚人；此外，他是原住民，這也讓我再一次領教：原住民的生命力真的太強了！ &nbsp;&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 我眼中看著杯觥交錯的熱鬧情景，耳邊傳來陣陣敬酒祝賀之詞，但我的心卻越來越安靜下去。&nbsp;
過去一直有人問我，相不相信奇蹟，相不相信運氣，這實在很難回答。&nbsp;
我們用的是最精密的儀器，得到最精準的數據，再加上個人二十年的經驗，傷勢會怎麼走，心裡大概都有個底；可是決定病人能不能痊癒的，有時不止儀器和醫術。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 以這個年輕人來說，他運氣好，竟然可以在發生重大意外之後，被一個剛好在路邊洗車的滅火，然後立刻送到醫院，再用最好的儀器、一流的醫療團隊、最有愛心的志工團隊、還有他個人最堅強的求生意志力，再加上最偉大的母愛，才能發生奇蹟。&nbsp;
我每天都在醫院，看到那麼多病人，一個人只要生一場病、一次意外，就可以造成絕望的人生、破碎的家庭。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp;「鄭醫師，謝謝你！」&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 媽媽親切的招呼把我從深刻的思慮中喚回來，她知道我不喝酒，特地為我準備了果汁，兒子和媳婦就站在旁邊，兒子神采飛揚，精神奕奕；媳婦嬌豔亮眼，光采照人。&nbsp;
&nbsp;&nbsp;
&nbsp; &nbsp; 兩人齊向我道謝。&nbsp;

&nbsp; &nbsp; 我滿臉笑意，大聲說「乾杯吧！」端起果汁，一飲而盡，終於知道：活著，原來是一件這麼美好的事。
