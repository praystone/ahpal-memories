05/21~06/21

雙子座【品　　名】雙子座老婆
【生產日期】雙子月(5月21-6月21)，年份最好比用戶年份小。
【主要成分】善變62%，靈敏20%，好奇心18%。
【主要功能】她是活力精靈，能為用戶的生活帶來新鮮與刺激。【適用人群】追求新鮮感與變化者最為適宜，其次是外形年輕且 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 充滿活力者。
【注意事項】1、本品噪音與動作幅度較大，用戶應在使用前先鍛 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 煉出較好的承受力才行。
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 2、用戶使用本品時，隨時都有可能遇到該品突如其 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;來的變化，請不要感到意外，而是要樂觀的適應 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;與面對。
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 3、本品常常會不按照流程運行，用戶不要過分控制 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 與扭轉，不然該品會與你之前設定的目標越離越 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 偏。
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 4、本品的工作持久性短暫，因此使用者應不斷的將 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 其安置在不同的領域上進行操作。
【禁忌】遲鈍、愚笨、落伍者，請止步。拿得起放不下者，請勿 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 觸摸。
【貯藏】長期將本品擱置戶外，偶爾安置在家中較為適宜。
【包裝】主要以富有時代感、輕巧的風格與材質包裝，偶爾換換 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 不同風格的包裝會是不錯的選擇。
【備註】本品具有唯一性，不可複製，好好珍惜。非試用品、贈 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 品，決定使用，責任自擔。
