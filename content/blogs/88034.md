06/22~07/22

巨蟹座



【品　　名】巨蟹座老婆



【生產日期】巨蟹月(6月22-7月22)，年份憑用戶愛好。



【主要成分】敏感52%，忠誠18%，脆弱15%，粘黏5%。

【主要功能】1、她是「保姆」機器人，可以全方位的照顧用戶及

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 家人。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;2、她也是保險、收藏櫃。



【適用人群】重視感情、懂得保養愛護本品的雄性優先。



【注意事項】1、本品出現故障時，應採用以退為進，靜觀其變的

&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 方式處理，等其自行修復之後，方可繼續運行。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;2、一旦決定使用本品就得承受其強大的黏性，若用

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;戶有反感舉動，該品將長時間處在排斥使用的狀

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 態。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;3、在使用的過程中，用戶稍有不愛惜，本品將會出

&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;現不服從用戶指定的情況。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;4、在使用本品時，不單要愛護該產品本身，其附加

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;產品也應一齊愛護，方可保證其有效使用期的無

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;限延長。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;5、本品過去儲存在體內的東西，用戶不可擅自讀取

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;或刪除，否則將有一段時間無法使用該品。



【禁忌】家庭觀念不強者請勿靠近；長期在外者使用權將嚴重受

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 限。



【貯藏】請用戶將本品放在和諧、寧靜、遠離危險物品的地方，

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 若偶爾能帶其四處散心，可起到充電作用。



【包裝】保守、懷舊風格的材料將其修飾，極能體現出本品的韻

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 味。



【備註】本品具有唯一性，不可複製，好好珍惜。非試用品、贈
&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 品，決定使用，責任自擔。
