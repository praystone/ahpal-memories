09/23~10/23

天秤座



【品　　名】天秤座老婆



【生產日期】天秤月(9月23-10月22)，年份憑用戶需求。



【主要成分】溫文爾雅55%，魅力度20%，親和力10%，機會主

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 義5%。



【主要功能】1、本品是心靈安慰劑，會是用戶最佳的心靈貼士

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;2、審美能力強，能美化用戶的生活。



【適用人群】熱心助人且公平公正的用戶、外觀俊美的用戶、妙

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;趣橫生的用戶，皆能很好的控制住本產品。



【注意事項】1、本品只能分擔用戶一半的事務，其若遭到用戶的

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 不公平待遇，將自動關閉所有運作程序。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 2、該品具有傳宗接代的功能，但並不善於養育下一

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 代。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 3、本品決斷力低，因此用戶要提前做好運作規劃、

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 流程，以便其按照軌跡進行運作，否則該品會處

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 於混亂狀態。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 4、本品的核心較為脆弱，因此用戶要用心呵護，真

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 心對待，其使用壽命將能長長久久。



&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 5、用戶在使用期間，不可有任何的醜陋行為出現，

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;也不可醜化本品的外觀，否則其所有部件都將逐

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 漸衰竭。



【禁忌】自私且不能尊重本品者禁用。長相抱歉，行為醜陋者禁

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 用。



【貯藏】優美且具有藝術氣息的地方可將本品長期存儲。



【包裝】具有藝術性、美麗的事物將能把本品的外形優點凸顯出

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 來。



【備註】本品具有唯一性，不可複製，好好珍惜。非試用品、贈

&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 品，決定使用，責任自擔。
