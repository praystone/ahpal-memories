人生的色彩


&nbsp;



一年三百六十天，縱有百年，不過三萬六千里路程。少時濛濛懂懂，老來百病叢生，華年若不大作為，轉眼成龍鍾，空對秋月與春風。觀人生種種，品類不同，各有天賦各有能。青年人，黑髮紅顏，體魄初成，何不乘時建功名，不負父母之期望，無虛寶貴之生命。


&nbsp;


青年有為，社會進步，國家有幸。因此上，說追求，道前程，勉勵可愛青年人，色彩斑斕說人生。


&nbsp;


無論年齡大小，無論貧富貴賤，再過一百年，現代人完全消失，一併回歸自然。大家有緣同在人間，無不追求人生的幸福美滿。但各人的思想境界和生活狀態的差異甚大，若用顏色來區分，概括來講，可以分為幾種：


&nbsp;


一生無大苦無大志無大成，忙忙碌碌，平平淡淡，隨大流，無驚無險，隨遇而安，是為白色的生活


經營有術，事業有成，靈魂空虛，浮華虛榮，冷漠於社會大眾，迷戀於享樂放縱，是為黃色的生活


理想主義，時代先鋒，獻身事業，造福大眾，燃燒生命，予人光明，轟轟烈烈，赫赫有名，是為紅色的生活。


&nbsp;


當然，有人把時乖命蹇受苦受難，激流險灘中的拚搏，在逆境中的掙扎和奮鬥稱為黑色的生活


把心情陰鬱的日子稱為灰色的生活；把熱愛大自然、寄情山水、沉醉花月的生活稱為綠色的生活


把一生專心從事一種自己感興趣的事業稱為藍色的生活。


從來有紅顏知己，今又有藍顏知己，等等說法，均有道理。


&nbsp;


人生最驚心動魄最能考驗人的是這黑色的生活，這是人所厭惡，但又不能不面對的生活。世上有多少人在慘痛的失敗、突降的厄運、沉重的打擊中，消沉了，變態了，倒下了，其情可憫，聞之痛心。有人一生鴻運當頭，有人有時厄運纏身，這是命運使然，不要窮追一個「為什麼」，否則會越想越鬱悶，越想越灰心。鎮定持之、..頑強對之、用心化之就是了。


&nbsp;


作者總結一生的經驗，得出刻骨銘心的兩句話：「，不信命運想不通，人不自強活不成。」今天黑雨今天風，明天太陽照樣紅，如果一個人遇到一點不順心的事，就想著生不如死啊，不如一死了之，那有一百條命也不夠用，有再聰明的腦袋也會變得軟弱無能，有如花似玉的姿容也是薄命。


&nbsp;


人有一時的軟弱，即使是偉人，也不例外。但人不能長久的迷惘在黑暗當中，充滿競爭的社會不相信眼淚，只相信奮鬥和智慧。人啊，你當自強。輕生親者痛，有志事竟成，頑強加智慧，瀟灑走一回。


&nbsp;


白色——偏好於安閒，藍色——熱衷於事業。這白色或藍色的生活永遠是絕大部分人所過的生活，消磨了無數人的一生：兩點一線日日走，溫馨小家度春秋，默默無聞勤勞作，平平安安隨波流。


&nbsp;


豐衣足食無奢求，兒女長成白了頭。寵物棋牌茶飯酒，優哉游哉一世休。如果我們觀察一下四周的人，我們會發現包括我們的父母兄弟姐妹親戚朋友都是在這樣地生活著。平凡的一生如大海中的一滴水，大地上的一棵草。


&nbsp;


這黃色的生活是極端利己主義的產物，是江湖梟雄的生活方式——貪權戀勢，尋求刺激，酒色財氣，笑傲江湖。這種生活由於其富麗堂皇華貴鋪張，滿足人的虛榮與野性的擴張而誘惑力特強。


&nbsp;


人生幾何，及時享樂，由此觀念出發，一些一生缺乏精神追求的人，小有發跡，便放縱自己，無不奔向這佈滿美景美酒美食美女的花花世界，竟相投入這銷魂奪魄燈紅酒綠的極樂生活。這種生活儘管為一些人所艷羨，但卻不為世人所敬仰。


&nbsp;


這紅色————輝煌成就和熱烈感情的象徵。崇拜偉人，心慕力行，斗膽敢為天下先，颯爽英姿取功名。居北斗而眾星齊拱，擎大旗而四方響應。是為時代先驅、人中龍鳳。


&nbsp;


人生兩大支柱——事業和感情。一個人一生即使沒有偉大事業和煊赫功名，但卻擁有自己喜愛的平凡事業和環繞自己的真摯友情。休閒時節，相攜踏遍青山，觀賞湖海風光，抑或歡聚一堂，歌之舞之樂之，那在他的人生畫布上也是紅藍綠色鮮明，生活中也會感到其樂無窮。


&nbsp;


從人對生活的追求來講，不外乎三種：追求舒適安寧；追求物質享受；追求功名成就。青年人，你嚮往什麼？


&nbsp;


這紅色的生活以天下為己任，以改革不良現狀推動社會進步為目的，是英雄主義的實現。它好比激浪飛舟、沙場拚搏、雷霆乍響、震撼山河。這紅色的生活使人熱血沸騰、精神振作、少壯而有為、垂老而不覺。


&nbsp;


這紅色的生活是奔騰的浪，是燃燒的火，唱的是好漢歌，奏的是交響樂。一個國家、一個民族、一個社會，如果沒有一批人捨生忘死赴湯蹈火，就沒有國家的昌盛、民族的興旺、社會的更新。人只有早死與晚死之分，鳥無不死之鳥，人無長生之人。獻身崇高的事業，


&nbsp;


立功當代，名垂不朽，即使不能安享天年，也不是人生的悲哀，而是人生最高的福分。


&nbsp;


「江山代有才人出，各領風騷數百年」。每一個時代都呼喚著自己的偉人。中國的知識分子歷來講的是「窮則獨善其身，達則兼濟天下」，「以天下為己任」，「家事、國事、天下事、事事關心」。人皆追求生活的樂趣，英雄也不例外，但英雄人物絕不會只滿足於個人的快樂。


&nbsp;


「山不在高，有仙則名，水不在深，有龍則靈。」偉大的人物不一定是最有心計最具強勢的人，但他一定是胸懷博大氣度恢弘的人。時代的先驅在社會舞台上扮演的也往往是不隨大流、特立獨行、開頂風船、衝鋒在前的角色。


&nbsp;


「大海蘊藏著它的珍珠，藍天懷抱著它的星辰」。無論世界上有多少安於恬淡和貪圖享樂的人，一個社會總要產生一批理想崇高的人，關注社會進步的人，憂國憂民的人，崇仰太陽的人——燃燒自己，照亮世界的人。這批人視閒散生活為不堪忍受，視吃喝玩樂為一生虛度，視最大痛苦為失去理想追求。這批人不會媚俗以取寵，隨波而逐流。


&nbsp;


這批人來到世上不是吃飯的，而是做事的，近代教育家陶行知先生說得好；「人生天地間，各自有稟賦，為一大事來，做一大事去。」何等豪邁，何等爽快。這樣的一生，就好像焰火騰空，焚身發光，盡現美麗，完成使命，然後消失在蒼茫的天穹。比起永恆的宇宙，人生也只是一瞬間，只要能光彩一現，就不虛人世一行。


&nbsp;


青年人，夢幻迷離，生氣勃勃，走自己的路，過自己的河，栽自己的樹，結自己的果，圓自己的夢，唱自己的歌，打出自己的江山，奔向自己的星座。或沉浸於藍，或獻身於紅，這是你人生意義的根本和寄托。


&nbsp;


對於一個志向遠大才能超凡初出茅廬的年輕人來說，陷身於白色生活是浪費生命，沉溺於黃色生活是自毀前程，畏懼黑色的生活則一事無成，那麼他只有一條路，艱苦創業，奮發圖強，開自己的天，辟自己的地，在自己的天地間自由翱翔。


&nbsp;


世界上許許多多的思想家、科學家、革命家、文學家、藝術家、行業名家、體壇精英，無不是經過幽暗行程而臻於光明之境。他們發揮超世之才能，紅紅火火過一生。事業由於他們而勃興，國家由於他們而強盛，社會由於他們而進步，世界由於他們而光明。他們的人生價值是崇高的，他們的人生形象不是「一滴水」和「一棵草」所能比擬的，他們是汪洋大海中捲起的巨瀾，是拔地而起的參天大樹，他們的人生是令人敬仰的。


&nbsp;


青年人，「高山仰止，景行行止」，懷抱遠大理想，投入終身事業，則必須耐得住孤寂生活。識高於人，則不可避免孤獨，要成為強者，則不可避免寂寞。德國哲學家說：「孤獨是所有傑出人物的命運。」世上沒有不經過苦難的成功，一個人能在荒沙大漠中獨行，能在崎嶇小路上攀登，能在艱難困苦中硬挺，才能最終獲得成功的殊榮。


&nbsp;


奇跡多是在厄運中發生的，人才多是在逆境中產生的。觀念可以改變人生，觀念可以造就人生。飛機、宇宙飛船的誕生源於人類「想上天」的癡心追求。人類的慾望帶動著社會的演變，個人的志向促進著人生的發展。高爾基說：「一個人追求的目標越高，他的能力就發展得越快，對社會就越有益。」李白詩雲；「白日與明月，晝夜尚不閒，況爾悠悠人，安得久世間。」人的一生是短暫的，事業之樹卻可以永存而長青。


&nbsp;


享樂主義畢竟渺小，英雄主義通向偉大。最後我謹以一首《新青年之歌》贈給那些遠離黃色的生活，超脫白色的生活，珍惜歲月韶光，奔赴宏偉理想的年輕朋友們。他們也許全無根基，他們尚且不為人知，他們或許出身寒素，他們或許荊棘滿途，但這都無礙他們的進程，只要有一顆「燃燒不息的心」就夠了。世界上的英雄豪傑，本來就是一撥又一撥，他們就是下一撥的奇偉人物。


&nbsp;


新青年之歌
