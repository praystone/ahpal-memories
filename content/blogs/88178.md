人性的演譯


&nbsp;


又是商業街的早晨


&nbsp;


　　店舖老闆都早早地開了門，攤販們也都各就其位了，似乎都想迎來個開門紅．


&nbsp;


　　這時，一位裝著極為入時的小姐輕盈地向商業街走來，走到ａ攤販處停下來，向旁邊瞧了瞧，於是沒有猶豫地在攤販ａ手中買了一個外表很是精緻的錢包，並順手將其背包裡的一個紅色舊錢包丟在地上，但這一瞬間歷史性的動作似乎又沒有誰窺見，當然也包括了所有的攤販．


&nbsp;


這小姐剛走出兩步，攤販ｂ突然瞧見了躺在地上的紅色錢包，心往下猛地一沉，險些要喊出什麼來，但又立即強忍鎮定，他判斷：這錢包肯定是這小姐不小心丟的．


&nbsp;


而從這位小姐的穿著與神情看，她絕對不是一般的主兒，不難推斷出這錢包裡絕對有不少的鈔票．他那急不可耐的心情迫使他在小姐走出五保步之後便發起一個」光彩」的動作－－－右腳向前大跨一步，身子向前一俯，手向前」致命」地一抓，短短幾秒鐘，他便完成了撿包的整套細節．


&nbsp;


然而，看他打開錢包之後失望的表情，可以證明出錢包裡並沒有一分錢．然後，他懷著恨意將錢包狠狠的丟到人行道中央．


&nbsp;


　　不巧，兩分鐘未過，順道走過來兩個二十出頭的年輕小伙，一高一矮，一胖一瘦，成鮮明的對比，但他們絕對是屬於那」帥呆了」的一類．高個子做了個手勢，剛要跟矮個子說什麼，矮個子」嗖」地一個彎腰撿起了紅色錢包，高個子見機忙扭轉話題：」見者有份，我算一個．


&nbsp;


&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;隨著那應變的話語和那頓時驚奇的眼神而來的卻是兩副令人啼笑皆非的面容．」他媽的，個破包！」矮個子沮喪的甩下錢包，仍然走得是那麼滑稽地昂首挺胸．


&nbsp;


&nbsp;


　　在其旁的縫紉店的老闆似乎看出了點眉目，嘻嘻的笑了兩聲，正思討這破錢包能演繹出多少不可思議的故事．


&nbsp;


前面不遠處又走來了一位拄著枴杖的老大爺，這位老大爺看上去是很有點年紀，看他走路的姿態與臉上的神色，他的」路」似乎不會太長，但正在他一瘸一拐地向前行走時，他也瞧見了那個錢包，他的眼光與錢包相遇時，眼睛神秘地瞇了一陣，顯然地可以看出他衰老的體態與強烈的金欲心理是極不相適應的


&nbsp;


他慢慢地，小心翼翼地揀起錢包，可能是怕路上行人多，不便當眾打開錢包，於是將錢包在自己身上擦了擦，正欲將錢包裝進荷包裡，突然，從旁邊理髮店裡衝出兩位窈窕小姐，」喂，老不死的東西，把我的錢包往哪裡偷？」沒等那老頭兒回過神來，兩位小姐早就奪走了錢包，跑進了理髮店，那笑聲與那慾望的撞擊，彷彿想要錢包裡的鈔票與之成正比．


&nbsp;


然而，短暫的一會兒，就從理髮店裡拋出了一個紅色錢包－－正是那編織故事的一個，」嗯，原來是個空錢包．」隨之的是一串憎恨的聲調．


&nbsp;


　　也許是上帝的安排吧！正在那錢包從空中向下落時，一輛垃圾專用車剛巧從此經過，錢包不歪不斜，落進車斗裡，隨著一起遠走了．


&nbsp;


　　至於這錢包還要經歷多少動人的場面，就只能憑靠想像，那也就會成為明天的新聞或者是昨天的故事，而今天這瞬間的輝煌，在商業街就只能畫上一個句號．
