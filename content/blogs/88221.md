若彼此誠信的維繫感情,不去傷害對方及自己.
&nbsp;
給彼此這麼大的空間,你做得到嗎...
&nbsp;
今年三十四歲的謝岱琳，是一家國際性公關公司的高級主管
&nbsp;
也是出了十幾本兩性婚姻、愛情書的專欄作家，
&nbsp;
然而，這一切成績都不如她的「新分居」婚姻故事，令人津津樂道。
&nbsp;
她的老公Jeff是個美國人，以前在
&nbsp;

ICRT工作，今開一家軟體設計公司。
&nbsp;
結婚五年多來，他們既無自己的房子，也沒有共組家庭，各自賃屋居住，
&nbsp;
各有室友，而且謝岱琳的室友還是個男生呢！
&nbsp;
「你們結婚，為什麼不住在一起？」
&nbsp;
「我愛他，所以我嫁給他，卻不適合和他共同生活。」
&nbsp;
謝岱琳說，他是個天真熱情卻邋遢自由成性的大男孩，
&nbsp;
衣服、褲子、襪子脫到哪丟到哪，滿地都是。
&nbsp;
桌子、抽屜永遠堆滿了沒用（要用又找不到）的帳單、信件、工具、瓶罐。
&nbsp;
不知道是不是有很多人有這樣的老公？
&nbsp;
也不知道人家是怎麼解決的？
&nbsp;
但對於崇尚自由自在又需要很多時間與空間思考
&nbsp;
企劃案與寫作的她來說，卻受不了每天替他收拾殘局，
&nbsp;
勉強如是，只怕會變得嘮嘮叨叨，戀人也會變成怨偶。
&nbsp;
常有人問她：「他愛妳，不會為妳改變嗎？
&nbsp;
「他已經這樣生活了三十幾年，過得很開心，
&nbsp;
為什麼要勉強改變？每個人都有自己的生活方式，
&nbsp;
我從不相信一個人的本性可以改變。」說也奇怪，
&nbsp;
從戀愛四年多到結婚，他們從來沒有要找個「家」一起住的念頭。
&nbsp;
所以，他住在最愛的陽明山，她則選擇便利的台北東區。
&nbsp;
週末假日一起度過，週一到週五見面兩、三次，
&nbsp;
一起吃飯、看電影、社交。
&nbsp;
有時他到她家，或者她到他家，正如同婚前一樣。
&nbsp;
他們相處方式很尊重彼此。
&nbsp;
有時，他跟她通完電話後會說：
&nbsp;
「如果我等一下覺得寂寞，可以再打電話給妳嗎？」
&nbsp;
「你這麼容易寂寞嗎？」
&nbsp;
「不是，而是我很容易想念妳。」
&nbsp;
她說，給他一個想念的機會，可以對自己甜言蜜語，也是一種不錯的感覺。
&nbsp;
他沒有她家的鑰匙，到她家前一定先打電話聯絡好，
&nbsp;
問她好不好？是否在忙？
&nbsp;
有一次他喝醉酒，渾身臭味直接跑到她家，
&nbsp;
她一邊替他洗澡，一邊哄他：「我已經很舒服的躺在床上看書，
&nbsp;
下次喝酒不要來這兒，直接回你的家好不好？親愛的」
&nbsp;
很多人知道他們的「新分居」故事後，又新奇又羨慕說：
&nbsp;
「如果我的婚姻關係也能如此，該有多好？」
&nbsp;
她總是說：「假使你認為這樣不錯，也適合你們，
&nbsp;

很簡單呀，你搬出去，或他搬出去，或是你們一起搬出去。」
&nbsp;
但是，接下來對方一定是一堆「可是」的話。
&nbsp;
究竟你要的是什麼樣的婚姻？
&nbsp;
何種關係才能使彼此獲得最大的快樂？
&nbsp;
謝岱琳記得Jeff的母親在她婚前說過一段令她終身難忘的話：
&nbsp;
「妳有才華，又獨立，我很喜歡也很羨慕妳。
&nbsp;
記得，妳絕對要保持這樣，即使婚後，
&nbsp;
也要永遠以自己為重心，不要把家庭或先生放在最前面，
&nbsp;
這個道理，我花了很多時間和代價才體會出來。」
&nbsp;
原來， Jeff的父親曾經外遇，離家一年多。
&nbsp;
逼得母親不得不出去找工作，變成一個亮眼的幹練女性。
&nbsp;
過了很久， Jeff的父親回來，
&nbsp;
看到原本懶得瞧一眼的老婆變得如此具吸引力，就回頭了。
&nbsp;
結婚、不結婚、同居、分居，都只是形式而已。
&nbsp;
世界上每個人都不一樣，每兩個人的關係也都不同，
&nbsp;
只要協調出最適合你們的形式，就對了。
&nbsp;
重要的是，要有成熟獨立的人格，尊重自己也尊重對方，
&nbsp;
付出的愛與得到的愛才不會是負擔，彼此的感情也才自由愉悅。
&nbsp;
