&nbsp;人生的光彩在哪裡？說起來其實很簡單。
&nbsp;
怎樣擁有人生的光彩有一個人去應聘工作時，隨手將走廊上的紙​屑撿起來，放進了垃圾桶。他的舉動恰好被路過


的面試官看到了，因​此他得到了這份工作。
&nbsp;
　原來獲得賞識很簡單，養成好習慣就可以了。
&nbsp;
有個小弟在腳踏車店當學徒，有人送來一部有故障的腳踏車，小弟除​了將車修好，還把車子擦試得乾乾淨淨。其


他學徒笑他多此一舉，後​來雇主將腳踏車領回去的第二天，小弟就被挖到那位雇主的公司上班​。
&nbsp;
　原來出人頭地很簡單，多干點就可以了。
&nbsp;
有個小孩對母親說：“媽媽你今天好漂亮。”母親回答：“為什麼.​"
&nbsp;


小孩說：“因為媽媽一天都沒有生氣。”
&nbsp;
　原來要擁有漂亮很簡單，只要不生氣就可以了。
&nbsp;
有個牧場主人，叫孩子每天在牧場上辛勤地工作，朋友對他說：“你​不需要讓孩子如此辛苦，農作物一樣會長得


很好的。”牧場主人回答​說：“我不是在培養農作物，我是在培養我的孩子。”
&nbsp;
　原來培養孩子很簡單，讓他吃點苦頭就可以了。
&nbsp;
有一家商店經常燈火通明，有人問：“你們店裡到底是用什麼牌子的​燈管？那麼耐用。”店家回答說：“我們的


燈管也常常壞，只是我們​壞了就換而已。 ”
&nbsp;
　原來保持明亮的方法很簡單，只要常常更換就可以了。
&nbsp;
住在田邊的青蛙對住在路邊的青蛙說：“你這裡太危險，搬來跟我住​吧！”路邊的青蛙說：“我已經習慣了，懶


得搬了。”幾天后，田邊​的青蛙去探望路邊的青蛙，卻發現它已被車子壓死，暴屍在馬路上。
&nbsp;
　原來掌握命運的方法很簡單，遠離懶惰就可以了。
&nbsp;
有一隻小雞破殼而出的時候，剛好有隻蝸牛經過，從此以後小雞就背​著蛋殼過了一生。
&nbsp;
　原來脫離沉重的負荷很簡單，放棄固執成見就可以了。
&nbsp;
有幾個小孩很想當天使，上帝給他們一人一個燭台，要他們每天把燭​台擦亮，結果一天兩天過去了，上帝都沒


來，於是有些小孩就不再擦​拭那燭台。有一天上帝突然造訪，只有一個燭台是乾乾淨淨明明亮亮​的，那是被大家


叫做笨小孩的燭台，因為上帝沒來，他也每天都擦拭​，結果這個笨小孩成了天使。
&nbsp;
　原來當天使很簡單，只要實實在在去做就可以了。
&nbsp;
有隻小豬，向神請求做他的門徒，神欣然答應。剛好有一頭小牛由泥​沼裡爬出來，渾身都是泥濘，神對小豬


說：“去幫他洗洗身子吧！”​小豬訝異的答道：“我是神的門徒，怎麼能去侍候那臟兮兮的小牛呢​！”神


說：“你不去侍候別人，別人怎會知道，你是我的門徒呢！
&nbsp;
　原來要得到別人尊敬很簡單，只要真心付出就可以了。
&nbsp;
有一支淘金隊伍在沙漠中行走，大家都步伐沉重，痛苦不堪，只有一​人快樂地走著，別人問：“你為何如此愜


意？”他笑著：“因為我帶​的東西最少。”
&nbsp;
　原來快樂很簡單，擁有少一點就可以了。
&nbsp;
人生的光彩在哪裡？早上醒來，光彩在臉上，充滿笑容地迎接未來。​到了中午，光彩在腰上，挺直腰桿地活在當


下。到了晚上，光彩在腳​上，腳踏實地地做好自己。
&nbsp;
　　人生箴言：
&nbsp;


原來人生也很簡單，只要能懂得“珍惜、知足、感恩”你就擁有​了生命的光彩。
