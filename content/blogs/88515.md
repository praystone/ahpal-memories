語言，意境，情感



文有三道：「語言，意境，情感」。

&nbsp;


語言，可以華麗絢美，亦可以樸素無華；可以平淡無奇，亦可以波瀾壯闊。語言是通道，是載體，引領你進入一座花園，或寧靜，或遙迢，或律動，或飄搖。

&nbsp;

&nbsp;

&nbsp;

台灣詩人鄭愁予的《錯誤》，其詩語言跌宕起伏，富有音律，堪稱一絕，「東風不來/三月的柳絮不飛/你底心如小小寂寞的城/恰若青石的街道向晚/音不響/三月的春帷不揭/你底心是小小的窗扉緊掩」。為文語言必須獨具一格，「雷聲太大/我把它擰小些/再擰小些」，「在暗澹的時日/我是攤開扉頁的書/標題已在昨夜掀過去」，「請在天涯海角面前/加一個破折號」，「那隻鳥在紙上叫了一聲/你就不見了」，「雨披頭散髮而來/門鈴再次被離去的人摁響」，不一而足，這些語言可謂獨具匠心，新穎奇特，很能抓人眼球。在語言的海洋裡，你為語言迷，為語言惑，為心底半開的花朵，引吭而歌。這樣多好！。

&nbsp;

&nbsp;


「意境者，文之母也」，「作詩之妙，全在意境融徹，出聲音之外，乃得真味。」，唐詩宋詞營造了意境的顛峰，我們恐無法企及。

&nbsp;

&nbsp;

&nbsp;

「弱水三千，只取一瓢。」，就已足夠。好的意境，必是一幅好畫，在你面前徐徐展開。無需走近，你已身臨其境。她有時是遼闊的草原，奔騰的美麗駿馬，「天蒼蒼，野茫茫，風吹草低見牛羊」；有時是江南迷人的景致，「小橋、流水、人家」；有時是沙漠的浩渺與蒼涼，「大漠孤煙直，長河落日圓」；有時是淒苦離別的江岸，「今宵酒醒何處？楊柳岸曉風殘月」。意境貴深邃高遠，如「依然是那一列城堞/將經年的灰/石印在藍天的這一邊/而藍天的那邊/遠山欲溶的雪有些泫然」，意境要清新自然，如「百米之內/無百姓人家無狗吠無燈盞/這群山連綿/只有天堂的雪/只有冷月的光」。把握好意境，為文才能靈動，「有境界則自成風格，自有名句」。

&nbsp;

&nbsp;

&nbsp;

&nbsp;


情感則是利器讓你胸口滴血，讓你的晶瑩忍不住在眼眶打轉。情感是為文的核心，無情感的文，如一朵病懨懨的花朵，看一眼就枯萎。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

不管世界如何流轉感動不會改變，「世界原本就在/一滴淚裡」。「我只想輕拍歲月的肩/讓父親回到三尺講台/再談笑風生/而我就站在二十歲的門檻邊」，「或者/我只是三月的一縷紅/在有你的省份/尋求落腳」，「那薔薇/就像所有的薔薇/只開了一個早晨」，「永遠永遠/你退入夜晚/向著暮色抹去雕像的地方」，讀了這些有血肉的詩行，我們怎會無動於衷，怎不會輕輕對世界說，「我還在這裡/沒有消失」，「對於愛/我還能愛/對於遠方/我還能淚眼婆娑」。

&nbsp;

&nbsp;

&nbsp;

&nbsp;

&nbsp;


好文無固定的邊框。語言，意境，情感，若能有機融為一體，必成妙文。

&nbsp;

&nbsp;

&nbsp;

台灣詩人痖弦的《秋歌》，我讀了多遍，每次捧讀，心底都會湧起柔軟，「落葉完成了最後的顫抖/荻花在湖沼的藍睛裡消失/七月的砧聲遠了/暖暖//雁子們也不在遼?的秋空/寫它們美麗的十四行詩了/暖暖//馬蹄留下踏殘的落花/在南國小小的山徑/歌人留下破碎的琴韻/在北方幽幽的寺院//秋天秋天什麼也沒留下/只留下一個暖暖/只留下一個暖暖/一切便都留下了」「荻花、湖沼、飛雁、、山徑……馬蹄、寺院」,詩人給讀者呈現遙遠開闊的視域,由近及遠,由遠及近,這裡面都有暖暖,秋天在詩人眼中什麼都沒留下,但有什麼關係,「只留下了一個暖暖,/一切便都留下」，多麼深沉的愛！暖暖是幸福的，詩人是哀傷的，唱著一首給暖暖的秋歌。
