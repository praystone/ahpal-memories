人一生中"最恐懼"五件事


&nbsp;


人類好像總與恐懼為伍，最早的時候我們害怕壞天氣，害怕猛獸毒蛇，現在我們害怕孤獨、不被理解。恐懼之所以會困擾我們，很多是「自卑」和「安全感」在作怪。


&nbsp;


人類總是被各種恐懼困擾&nbsp;&nbsp;


&nbsp; 恐懼1：害怕自己不受歡迎


&nbsp; 這其實是一種自卑的表現，好像一個來自農村，只有小學三年級文化的打工仔到城裡打工，他追求的首先是能夠吃飽，能夠養家餬口。一旦這個追求被滿足，他就需要被認同被尊重。那麼，如果他是一個自卑的人，就會敏感的看待一切外人的言語、表情甚至動作。他會懷疑人們鄙視他的行為和看法，於是不敢正視自己，也不會積極地面對社會，不受歡迎的恐懼便油然而生。


&nbsp; 不光是農村來的打工仔，普通的老百姓，甚至被人們羨慕的大款，也會有或多或少的自卑情緒，於是我們攀比附和、張揚怪異，在所有場合展示自己的優勢，掩蓋自己的短處。&nbsp;&nbsp;&nbsp;&nbsp;


&nbsp; 學著發現自己的長處，同時也要接受自己的短處，而不要總拿自己的短處和別人的優勢比。這樣才能夠找回信心，自然也就不用擔心自己不受歡迎了。


&nbsp;


&nbsp; 恐懼2：穿比基尼


&nbsp; 同害怕「不受歡迎」一樣，害怕穿比基尼，也是怕自己的不足被別人發現。在美麗的假日海灘上，如果一個女孩兒有一副好身材，她還害怕什麼呢？人總是希望展示自己的美好，而不幸的是，場合和自身條件總是首要被考慮的因素。




　 恐懼3：愛人去世


&nbsp; 前兩種恐懼與自信緊密相連，而「愛人去世」體現了人對死亡的恐懼。一個人一旦歷經愛人去世的打擊，便很難擺脫孤獨的困擾，焦躁不安也就迅速地侵佔了他的心理。這種「喪失」的感覺與對自己生命的珍惜交織在一起，替代了愛人在世的歸屬感，壓抑著人們脆弱的心靈。於是「愛人去世」變成了對「死亡的恐懼」。


&nbsp; 然而人死不能復生，當你為愛人的離去痛苦到撕心裂肺的時候，也還是要告訴自己「堅強、快樂地活著」，因為你的愛人希望你能夠好好地生活，你此去的人生也是他生命的延續。因此，你沒有理由放棄自己。


&nbsp;



恐懼4：當眾講話


&nbsp; 嬰兒喜歡用哭來引起大人的注意，當他們飢餓的時候，總是會哭的異常響亮，這時的嬰兒希望媽媽用最快的速度給他餵奶。但不幸的是，這種要求不見得每次都得到響應。從心理學上說，這種情況很容易在成人身上表現為以為「別人不重視我」「我自己沒用」等過低的自我評價。從而產生自卑感，覺得沒有歸屬，這些影響了人的表現慾望，也就產生了對當眾說話的恐懼。


&nbsp; 沒有人天生就可以在所有人面前口若懸河。要想在當眾講話的時候保持一份平靜、放鬆的心態，除了戰勝自己的自卑感以外，還需要不斷地練習。你可以先對著鏡子說話，假想下面有人在聽，這樣反覆練習幾次，也就不至於那麼緊張了。


&nbsp;


&nbsp; 恐懼5：一生單身


&nbsp; 每個人都希望與愛人分享自己的情感，對愛人表達自己的看法，而一生單身的人很難得到這樣的優待。如果一個人不能擁有一個愛人，那他是孤僻的；如果一個人不能付出他的愛，那他是壓抑的。這種孤僻和壓抑，都是對沒有歸屬感，沒有安全感的反應。於是，一生單身便成了讓人恐懼的事情。


&nbsp; 對單身產生恐懼的人往往性格都比較孤僻，不願意與外界交流。這類人還是應該強迫自己有意識地和周圍人溝通，比如主動打個電話找人聊天。如果你不願意與人接觸的話，養養寵物或是讓自己回歸到大自然去，都可以從中得到慰藉。
