如何改變一生的命運



改變任何人之前，改變世界之前，需要改變的是你自己。從決定開始，而決定，在行動之前。


&nbsp;


　　成功的故事比比皆是，而主角曾經是你嗎？


&nbsp;


　　或許，你也曾有和我類似的遭遇。十幾歲時，我隻身負笈美國留學，初次體驗人生，接觸到許多成功者的資訊報道，於是心中隱隱有一股想成功的慾望。


&nbsp;


　　於是，我開始嘗試去做各項工作，餐廳小弟、在電腦店打工、推銷菜刀、賣汽車，然而，成績不佳及被炒魷魚的事件一次次發生，也使我頻繁地更換工作，有一天早上，當我提起手提箱正要出門銷售時，忽然有一個聲音從心中傳出："陳安之，難道你甘心天天敲門賣刀嗎？"仍然是心中的回答："絕不！"


&nbsp;


　　當時，我馬上發誓：我一定要做個成功的人！


&nbsp;


　　從那天開始，我拚命找尋致富的方法，閱讀各類教人成功的書籍，同時積極投入直銷事業。


&nbsp;


　　八個月後，我仍然工作失敗，沒有錢，沒有朋友，一個人窩在聖地牙哥的公寓裡不斷思索。


&nbsp;


　　從十六歲開始，我連續五年嘗試的所有工作全部失敗，每當興起成功的慾望時，我失敗的頹喪模樣就不自覺的浮現在腦海，使我不知所措。


&nbsp;


　　命運是可以改變的


&nbsp;


　　直到一次偶然的機會，我去參加一個激發心靈潛能的課程，遇到了我的老師安東尼·羅賓（Anthony Robbins），我的人生從此改變。


&nbsp;


　　當時，安東尼在一千多人的研討會上講他的故事：


&nbsp;


　　他在二十二歲時窮困潦倒，住在十坪大的房子裡，洗碗只能在浴缸裡進行，後來因為接觸了一門"神經語言"的課程而改變了命運，一年後，搬到四百坪的城堡裡，擁有豪華轎車和直升飛機。


&nbsp;


　　他的兩句話重新燃起我成功的慾望，他說："這世界沒有失敗，只有暫時停止成功。過去不等於未來。"


&nbsp;


　　他可以，我也一定可以，之後，我開始陸續參加數次研討課程，一九八九年，我加入該學院的講師班，同時，不懼年齡最輕又是唯一東方面孔的挑戰，和其他七十名優秀而經驗豐富的學員競爭講師的職務。


&nbsp;


　　當時，由於我呈上的履歷表毫無回音，於是我費盡方法找到主其事的總經理面談，表達了我的工作意願，誰知那位總經理除了強調工作的困難度之外，並質疑常換工作的我是否有恆心毅力長期從事這份工作。


&nbsp;


　　他說："你和別人一樣，等我明天上午統一發佈錄取名單吧！"


&nbsp;


　　我回答："當我把履歷表交給你的時候，就表示我已經下決心要這份工作了，而且一定要，為了不必麻煩，你還是現在就錄取我吧！"


&nbsp;


　　但是，那位總經理仍然搖頭，要我等明天的答覆。


&nbsp;


　　那時我心想，我不能等到明天哪！便立刻詢問他公司裡最佳的銷售業績，並保證成為最棒的推廣講師，鍥而不捨的推廣自己。最後，他終於開口："你七月二十一號可不可以飛去賓州工作？"


&nbsp;


　　我大叫一聲："沒問題！"隨即感動得流下淚來，我知道，我的命運即將改變。


&nbsp;


　　八個月後，我成為公司最棒的銷售人員之一。


&nbsp;


　　請你下一個決定


&nbsp;


　　回到家鄉來授課也有兩年多了，這其中，我四處演說開課，努力把使我改變的學問和別人分享，我看到了許多人因此建立自信，改變生活，更使我愈加堅信要以一套有系統激發潛能的方式，來幫助更多的人和團體，並以此做為終生事業。


&nbsp;


　　在這過程裡，許多人勸我："陳安之啊，成功者畢竟是少數人！""陳安之啊，成功必須付出極大代價的！"這些我都明白。


&nbsp;


　　過去，我認為成功者實在具有強大的毅力和決心，現在卻發現，成功者微不足道，反是失敗者的毅力和決心要來得更堅強--因為他們可以忍受失敗一輩子。


&nbsp;


　　成功很難，但不成功更難！


&nbsp;


　　永遠記住：


&nbsp;


　　改變任何人之前，改變世界之前，需要改變的是你自己。從決定開始，決定，在行動之前。


&nbsp;


　　因此，在閱讀其他章節之前，請做一個決定：我一定要成為我理想中的人物，為自己活，為他人著想，盡最大能力來發展自我，對人類社會做一番貢獻。


&nbsp;


　　記住，是決心，而非環境在決定你的命運。


&nbsp;


　　行動承諾


&nbsp;


　　為了幫助您真正有效學習運用本書，請您仔細並用心的寫下您學習後的行動承諾，請務必確實執行。


&nbsp;


　　１．請下決定並清楚描繪出你最想成為的理想人物的形象。


　　２．要讓自己成為理想中的人物，你現在將會做哪些改變？


　　３．你準備從什麼時候起下決定改變並開始行動呢？


　　４．當你寫好以上承諾後，請再寫下"我一定要，馬上行動，絕不放棄！
