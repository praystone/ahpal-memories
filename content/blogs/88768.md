&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 誰是你愛情的頭號天敵？



有人說，愛情是沒有道理可循的。

但事實上，還是找得出一些蛛絲馬跡。

讓我們告訴你，到底哪個星座的女人，是你的愛情頭號天敵？



牡羊座

頭號天敵：天蠍座淑女

你的感情熱烈而直接，個性衝動又沒耐性。並希望男朋友能把「我愛你」三個字當成口頭禪，全天候24小時說給你聽。當他遭遇到感情內斂沉穩、心思細膩、氣質典雅的天蠍女時，那位若即若離的淑女可會讓「受夠」你的男友心動哦，而此時的你，在他眼中則變成了一位還沒有長大，驕縱任性的嬌驕女。



金牛座

頭號天敵：雙子座或射手座的鄰家女孩

她們沒有你的高貴、穩重。可是，天生開朗體貼的雙子、射手女，在男人眼裡可比你有情趣多了。她們很會逗人開心，容易溝通，常有天馬行空，古靈精怪的鬼主意。在她們面前，你的高貴氣質變成了驕傲自負。有著極佳異性緣的她們，用親切的笑臉，像朋友一般輕鬆舒服的相處方式，輕而易舉就征服他的心。



雙子座

頭號天敵：處女座或雙魚座小女人

當感情已成定局，以為一切盡在掌控的時候，你就不自覺地露出大女人的狐狸尾巴。儼然把自己當成女皇，男友就淪為伺候左右的奴隸。但是小女人般的處女、雙魚女生卻不然，會貼心去注意另一半的需求，而且小鳥依人的樣子讓男人心動不已。被你忽視的感情和「踐踏」的自尊在她那裡卻能受到尊重和安慰，這是你要多多學習的地方。



巨蟹座

頭號天敵：樂觀開朗射手女

巨蟹座非常容易情緒化，又很多愁善感。她非常戀家，又注重物質的表象底下，其實是因為缺乏安全感造成的。因此常常要黏著另一半，並且很容易因為對方的一舉一動，情緒大受影響。而樂觀開朗的射手女生則不然，她不會動不動就開始鑽牛角尖，也不會無緣無故情緒化。讓男人覺得很輕鬆沒有壓力。



獅子座

頭號天敵：雙魚座妹妹

唯我獨尊的你從來不願意為別人改變自己，哪怕是自己的男友。可是作為最有女人味的雙魚座卻正好相反，她們的必殺技——柔弱正好破解了你的剛強，讓你看起來十分的任性不講理。任何一位普通的男人，在宛如林黛玉的她面前，馬上變成了神。那一刻的憐香惜玉引發的大丈夫成就感，令人無法抗拒，她的眼淚能讓男人的道德防線在瞬間瓦解。



處女座

頭號天敵：牡羊座率性女孩

你最大的優點就是你最大的缺點，完美主義的你不僅對自己的要求很嚴格，對待男友也會像個老媽一樣，到處挑剔兼嘮叨，他與你促膝談心的渴望也會變得有所顧忌。而以兄弟自稱的牡羊座卻有大把機會聽他傾訴，一起喝酒，一起打球。別以為她太沒女人味所以掉以輕心，牡羊女外剛內柔千變萬化。某天造型一變，周圍的男人都會目瞪口呆。



天秤座

頭號天敵：金牛座或是獅子座職場熟女你很沒有安全感，於是恨不得時刻黏在男友身邊，片刻的分離也會讓你心緒不寧，五花八門的遙控跟蹤加指揮，常令男友既丟面子又神經緊張。在這一點上，金牛女和獅子女則與你相反，她們成熟獨立，並相信自己的掌控力。如果她們出現在男友的生活中，被長期「軟禁」的男友就如同溺水之人突然浮出水面，大吸一口清新氧氣，內心也隨之蕩漾動搖。



天蠍座

頭號天敵：巨蟹座新人女生

要強的你很容易讓男生有挫折感，會毫不留情面的指責對方，並請對方改正。但是在初出茅廬的巨蟹女生衷心讚美之下，加上稚嫩、好奇、崇拜兼幾分羞澀的飄忽眼神，男人的優越感驟然飆升。種種天真無邪，讓人宛如回到初戀年代，而若此時你已進入洗衣做飯、不修邊幅的黃臉婆階段，心中的對比將尤為強烈。



射手座

頭號天敵：水瓶座紅粉知己

大剌剌的你喜歡的男生多如陽光般熱情，他身邊總難免會有紅顏知己——比如號稱人緣最好的水瓶女。而你在戀愛前和戀愛後基本上沒什麼的改變，依舊喜歡和朋友們成天瘋癲，同時也給了男友太多的自由。水瓶女比你想像的更重視感情，更忍辱負重，甚至無怨無悔，在這方面很容易把你看似漫不經心的態度比下去。



魔羯座

頭號天敵：天秤座舊情人

你認為愛情就是兩個人心意相通，不必天天掛在嘴上，所以看起來平平淡淡。而自詡優雅派的天秤女就很容易佔上風，如果他們兩人在一起的時間又比你跟他長，對他的喜好會比你還瞭解，更知道要如何引起他的注意或哄他開心。稍不留神，一個眼神的交互，都可能引發電光火花，舊情復燃。



水瓶座

頭號天敵：射手座閨中密友

和水瓶座最投緣又互補的就是射手了。她和你情同姐妹，無話不談，開心的事情一起分享，不開心也一起承擔。她當然會知道你男友的喜好，甚至和你的男友打成一片，親密無間。別以為只是因為你的關係而一笑了之，她對於男友的喜好，多半會與你雷同呢！相處久了，難免擦槍走火。



雙魚座頭號天敵：獅子座或魔羯女強人多愁善感，優柔寡斷，三心兩意的你總是搖擺不定，讓對方無所適從。可是偏偏不湊巧，男友的頂頭上司或客戶是位獅子座女強人，那你就要格外小心咯。如果你還落後地以為女強人就是男人婆的代名詞，那就大錯特錯了。恰恰相反，對於受夠了你的多變的男友來說，獅子女的優雅利落，時尚幹練，果斷堅決就是強烈的吸引力。
