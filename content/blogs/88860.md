&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;職場女人需要的7種武器



雖然現代職場很少有性別歧視的存在，但不得不承認，大部分的老闆還是對男性員工比較重視。雖不圖混出個「有模有樣」，但好歹也要讓自己的職場生活過得順暢點吧，姐妹們，妳們說是嗎？給妳的七種武器吧！集齊全部七種武器，就能兌換「呼風喚雨女強人」勳章一枚！



武器一：美麗

不得不說「漂亮是職場的通行證」，可是傾國傾城的女人畢竟只是極少數。沒有漂亮臉蛋，沒關係！服裝、髮型、化妝品……這些都有化腐朽為神奇的能量，只要妳不懶，只要妳知道自己的美，並善於使用這些美，即便妳年過四十，也能在職場游刃有餘哦！

潛力星座：射手女、魔羯女、水瓶女



武器二：鎮定

親愛的，請搞清楚這裡是職場！雖然男人們時刻都準備充當護花使者，但是一個遇見什麼都大驚小怪的女人總會給人無膽識、不穩重的感覺，相信沒有哪個上司會願意重用這樣的職員吧！臨危不懼，處變不驚，這才是值得男人佩服、值得老闆欣賞的領導人才喲！

潛力星座：雙魚女、天秤女、巨蟹女



武器三：文靜

熱情活潑的女生固然可愛，但成天像個假小子一樣將辦公室物品弄得亂七八糟，或是像個長舌婦八卦這打聽那，誰能對妳放心啊？別說要做個名媛貴婦，至少在辦公室也得像半個淑女吧，多多體會微笑的力量吧！

潛力星座：牡羊女、射手女、雙子女



武器四：愛心

不得不否認，女人在職場中的某些方面確實不如男性，很多時候都會需要男同事的幫助。想要獲得這些幫助，那麼妳得先付出！都說女人的愛心最易讓人感動，平時對同事多些關懷，多些照顧，那麼當妳有難時，他們也會願意伸出援手！

潛力星座：獅子女、魔羯女、金牛女



武器五：規矩

老闆最反感員工什麼？就是不聽話，搞「反動」，還要將其他員工給帶「壞」！尤其對方還是個女人，妳說老闆的自尊傷不傷？當然，妳更加不能將辦公室當成風月場所，不然，不僅女同事鄙視妳，連男同事也對妳沒得尊重！放心，規規矩矩做事做人會為妳贏得更多關注的！

潛力星座：牡羊女、水瓶女、雙子女



武器六：自信

辦公室不是男人的天下，妳的能力、學識或經驗並不比任何人差，甚至更加細心負責，或是更具有創新意識！妳要做的就是完全相信自己的能力，大膽地展示自己，充滿自信地看待每件事、每個人，這樣還有誰能忽視妳的存在呢？

潛力星座：巨蟹女、處女女、雙魚女



武器七：健康

別以為妳身體不適，別人就會多關照妳。柔弱的女人確實能激起男人的保護欲，但別忘了這是職場，妳們除了是同事，也是競爭對手。當妳因身體不適經常休息時，人家可是衝鋒陷陣、奮筆疾書，妳覺得當老闆對員工進行考評時會考慮妳是病號嗎？

潛力星座：天秤女、雙魚女、天蠍女
