&nbsp;&nbsp; 縈縈我是位標準的電視大人&nbsp; 沒電視(韓劇)可看,我想我會

&nbsp; 目前正值茶葉產季 茶山上四處可見做茶人家忙於做茶 當然 我家也不例外

&nbsp;

&nbsp; 不過再怎麼說 我也是上班族&nbsp; 在茶業公司上班

&nbsp; 平常淡季中很閒&nbsp; 遇到茶葉盛產期 忙屬人囉&nbsp;

&nbsp; 三不五時跑外面出差或去百貨公司洽公&nbsp; 回來家中 偶而較晚囉

&nbsp; 還是一定會先洗好澡 然後舒服看我最愛的韓劇&nbsp;一次好幾台變換看

&nbsp; 假日是我最開心的時刻囉&nbsp; 不但能睡到飽 還可看整天想看的電視

&nbsp;

&nbsp; 不過 這兩天 我回家後要看電視時&nbsp;遙控按呀按 怎會顯示無此頻道

&nbsp; 問了媽媽之後 才知媽媽已經請有線電視人員將線拔掉

&nbsp; 而改看內建在液晶螢幕的數位電視&nbsp; 天啊! 數位電視只有那少少的15台ㄟ

&nbsp; 我就跟媽媽ㄠ說:&nbsp;媽媽沒第四台可看 總要有MOD豪華型可看吧

&nbsp; 媽媽卻冷冷的回應說:&nbsp; 我就是不想讓妳看 才氣到請人家來解除掉

&nbsp; 媽媽又說: 妳這女兒呀 我該怎跟妳說才好&nbsp; 你整天除了上班還是上班

&nbsp; 假日又幾乎窩在家裡看電視也不出門&nbsp; 除了這些 妳還會哪些?

&nbsp;

&nbsp; 我回媽媽說:&nbsp; 媽呀 妳怎就這樣小看我呀&nbsp; 我除了上班和看電視外

&nbsp; 我還會吃飯 享受下午茶 會睡覺 會上網玩&nbsp;還會幫忙招呼客戶泡茶ㄟ

&nbsp;

&nbsp; 媽媽就回應說:&nbsp; 總之 養妳這麼大了 不是要妳除了上班外

&nbsp; 其餘時間就像宅女一樣 迷住電視不放 拜託妳 多出外走走吧

&nbsp; 多去找找朋友去看電影或去遊玩都好 就是別給我窩在家裡看電視

&nbsp; 想看第四台或MOD"免供拉"(台語音)&nbsp; 先給我去好好找個對象再來跟我談條件

&nbsp;

&nbsp; 媽媽&nbsp; 那有人限制自己的女兒自由阿 好歹 我也是成年人耶

&nbsp; 媽媽回應說:免供整篇廢話(台語音)&nbsp;...... 

&nbsp;&nbsp;

&nbsp; 喔喔~~媽媽 女兒我忘記告訴妳一件事囉&nbsp;就是客廳也有電腦可用

&nbsp; 我可請人家來幫我裝線連接電視與電腦呀&nbsp; 沒第四台可看&nbsp; 還有電腦

&nbsp; 可以下載我想看的戲劇連接至液晶電視看 超大螢幕看才過癮耶&nbsp;
