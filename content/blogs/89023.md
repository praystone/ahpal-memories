真心愛了，才會胡思亂想，不代表不信任~
&nbsp;

真心愛了，才會吃醋，吃醋不代表不信任我想，
&nbsp;

談過戀愛的人一定都會有這樣的感受，
&nbsp;

看到自己的愛人和異性接觸頻繁、
&nbsp;

聊的投機或者背著自己和別人有著私下交往的時候，
&nbsp;

心裡都會有酸酸的感覺，於是開始莫名的猜測。

&nbsp;

愛你，所以才吃醋。如果沒有愛，那麼無論你做什麼我也無所謂了。


&nbsp;

我也知道，聰明的人這時候應該表現得落落大方、不顯露出半點妒意​，
&nbsp;

可是，話是這樣講，能不能做到又是另一碼事了。

&nbsp;

有誰能夠在愛情的天平上保持平穩的心態呢？
&nbsp;

愛情的關鍵是兩人之間要有起碼的信任，真心愛才會真吃醋。


&nbsp;

有感情但從不吃醋，恐怕是雙方誰都不在...意誰。
&nbsp;

如果一輩子一起生活整天相敬如賓，沒有波浪、沒有起伏、
&nbsp;

沒有感情上的溝溝坎坎磕磕碰碰，死水一潭，


&nbsp;

生活還有什麼樂趣？從這個意義上講，


&nbsp;

&nbsp;吃醋會不會也是一種愛、一種提醒、一種監督、一種約束？
&nbsp;

話說回來，有哪個人不吃醋？ ！

&nbsp;

因此，請你們好好的珍惜那位在你身邊,
&nbsp;

總是為了小事吃醋生氣的那個人吧！


&nbsp;

為了小事而經常生氣... 因為，能夠被一個人這樣深深的愛著，
&nbsp;

是一種幸福。相愛的男女朋友對對方的一舉一動，
&nbsp;

總是會胡思亂想的，很正常。情人的眼裡是容不下任何小沙子的。


&nbsp;

真正愛你的人，是無法在你和其他異性聊天打電話談笑風聲時，
&nbsp;

沒有任何感覺的。假如她不會吃醋，那麼請你不要高興，


&nbsp;

&nbsp;因為她可能不是真的愛你，不是很在乎你。

&nbsp;

為什麼男人要和其他女人頻繁聯繫？真的只是單純的好朋友嗎？


&nbsp;

別欺騙自己了，那麼多女人，為什麼就只是她？


&nbsp;

因為，你們一定是彼此喜歡，就算沒有，也有一點點，或是一點點點​……對吧？
&nbsp;

或許，你對她真的沒有愛情，但站在你的另一半的角度去想，
&nbsp;

換做是你你會不會真的一點不在乎呢？


&nbsp;

畢竟，你會和你現在的女朋友在一起，當初，
&nbsp;

&nbsp;

也是從聊得來的普通朋友開始的吧！真的，
&nbsp;

好好的去珍惜現在你身邊那位會管你，會吃你醋的人吧！


&nbsp;

不要覺得她不講道理，因為如果要講理，那就做普通朋友就好了，
&nbsp;

普通朋友就不會管你，而且，還會永遠說你好話。

&nbsp;

相愛的人，任何的吵鬧、嫉妒、猜忌、孩子氣等行為，
&nbsp;

都是合理正常的。再完美的人，一旦愛了，也一樣像個孩子，
&nbsp;

偶爾自私，偶爾奢望、、、 換個角度想想，你是幸福的。


&nbsp;

如果，有個人這樣深愛著你，千萬別不懂珍惜。 。 。 。 。
