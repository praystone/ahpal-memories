&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;做好你的人脈投資



成功不外乎兩大因素：智商和情商，即實力和人脈。雖然對於不同的星座，二者所佔的比重會有所不同，但後者的重要性比前者更甚。人脈旺盛，事半功倍；人脈受損，舉步維艱。



子曰：天地之性人為貴。人脈是人生的重要財富，不僅能給我們帶來溫暖、鼓勵、支援、快樂……而且不知道哪天就會突然轉變成我們物質財富的增減，是人生路上不可忽視的首要投資。



在星座的分類中，人際運最強的是水相星座（巨蟹座、天蠍座、雙魚座）。雖然水是感性、被動的物質，水相星座的人不夠理性，缺少行動及決策的魄力，但也因為同樣的原因，他們重視與人的心靈溝通，合群性強，可以容於任何形狀的容器之中，所以在與人互動時彼此不會有壓力，在任何場合都是倍受歡迎的人物，容易得到貴人的青睞，借此獲得權力、地位和財富的迅速提升。



相較而言，土相星座（金牛、處女、魔羯），略輸感性；風相星座（雙子、天秤、水瓶），稍遜沉穩；交際天才，火相星座（牡羊、獅子、射手），只識義氣論結交。



例如火相星座，在人際互動中給人的印象是積極主動的類型，通常結交甚廣，擁有龐大的人脈存摺，不過由於他們太有主見，常常想當老大，容易產生爭執而倏合倏離，甚至招來小人的關注。所以，火相星座的人脈不夠穩定，且魚龍混雜。



不過我常常強調，個性先天沒有善惡優劣，有一利必有一弊。我們瞭解星相命理，就是為了認知「林子大了，什麼鳥都會有」的道理，有的喜歡啃樹，有的喜歡捉蟲，沒有誰對誰錯，都是習性使然，如果它們都以自己的習性為「做鳥」的標準，則必然互不相容。人類的相生與相剋，正是緣於個性帶來的價值觀及處事模式的差異，與其逃避或者要求對方改變，不如學著包容。正所謂有容乃大，學會了包容，人脈才會旺。



只要願意包容，小人也會變成生命中的貴人，如果不願包容，貴人也會變成生命中的小人。是小人還是貴人，一念之間，一正一負，千里之別。



人脈投資就像一本存摺，須先存而後取，多存少取，才會越積越豐厚，勿輕易當成信用卡來透支，特別是為了物質財富而讓人脈受損，最終必然越欠越多。還錢易，還人情難，失去人脈，再多的物質財富也沒有意義。人生最大的悲劇，既不是「人死了，錢沒花出去」，也不是「人活著，錢沒了」，而是「錢有了，心沒了」，錢再多也買不回人心，成功得不到認同，就是最大的失敗。



水是生命之源，懷抱一顆如水般清澈、柔順的心，善待身邊的每一個人，生命就會生生不息。祝福各位天天出門遇貴人！
