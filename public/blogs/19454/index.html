父親的殺生果報<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

 

父親逝去5年多了，每每思及，那種心痛的感覺，仍難以言表。

 

父親個頭不高，卻擔起了整個家庭的重擔。早前家中有地的時候，地裏的活兒，往往都是他一個人做。在我的印象中，我只下過兩三次地。他象天下所有的慈父一樣，為了家人，他什麼苦都能吃！什麼累都能受！

 

街坊鄰居們的口中，他是出了名的好人，老實人，他無論對誰，總是笑眯眯的。誰家有什麼難處，一說到眼前，絕對毫不含糊。

 

可誰知就是這樣一個人，卻厄運不斷。先是在自己的廠子，遭遇一場大火，把臉燒傷，差點丟掉性命。後來集體在廠子的附近搞建築，污染了廠子的水井，造成巨大的損失，後跟村裏打官司，又輸了官司。因為我父親是承包人，所以幾萬元的承包費，只能自己承擔。這是88年的事。那時候的幾萬元，對於一個普通的農村家庭，可不是個小數目。

 

 

 

 

 

厄運並未止步，更大的災難，正在悄悄降臨。98年農曆3月，父親突發腦溢血，住院治療40天。總算保住性命，卻從此走路再也離不開人的攙扶。

 

2004年農曆<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />3月3日，病魔再次降臨，父親腦溢血復發 ，入院搶救。半個月後，與世長辭。享年62歲。住院期間，父親經受了難以想像的痛苦。臨終幾天，還把咽喉割開，插管往外導痰。

 

所有認識我父親的人，皆唏噓不已。大家說這麼好的一個人，怎麼會—還有人說，好人不長壽。

 

對於父親的死，我也曾困惑不已，難道真的是好人不長壽？！綜觀我父親的一生，與人為善，處處與人方便，可現實卻是如此殘酷，誰能解我心頭之惑呢？

 

直到有一天，讀《地藏經》，心頭疑雲才一掃而光。「地藏菩薩若遇殺生者，說宿殃短命報」。那我父親以前是經營什麼廠子呢？我講出來朋友們就明白了，為什麼在大家眼中的好人老實人會落此惡果了，原來我父親的廠子是一個養貂廠。養的那些貂是要殺了剝皮的。

 

我的可愛的可憐的父親啊！你知道這些年有多少鮮活的生命毀於你手嗎？你同時也無情的毀了你的一生啊！世上生意千萬宗，你為何要做這一宗！

 

我再去看看周圍的殺生者，城東10多裏有一個村子，以殺豬出名。那些殺豬的，沒一個善終，不是橫禍，就是癱瘓。就在前年，還有一個在市場上被人捅死。

 

我一個至親，同樣在2004年病故，還不到60歲。其人生前頗愛撈魚捕鳥。

 

我一個鄰居前幾年上吊自殺，他家以前殺雞烤雞，後來又養狐狸。

 

如果您的朋友親人中有從此業者，速勸其回頭，懺悔以往罪過。他既少造罪業，您亦功德無量！
