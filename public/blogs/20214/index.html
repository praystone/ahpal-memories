個人主頁CSS背景圖語法

參考範例

body{ /background-image:url(http://www.wallcoo.com/cartoon/Vector_Flower_Background_Patterns/wallpapers/1280x800/Vector_Flower_Patterns_Background_vb13.jpg); repeat; color:red;/ background-image:url(http://www.wallcoo.com/cartoon/Vector_Flower_Background_Patterns/wallpapers/1280x800/Vector_Flower_Patterns_Background_vb13.jpg); background-attachment:fixed; background-repeat; background-position: center center; color: red; } a{ color: red; font-weight: ;}

red頁面字體顏色可變更

顏色參考帖    http://ahpal.com/home/space.php?uid=7323&amp;do=blog&amp;id=19241

 

 

個人主頁CSS背景圖語法(參考龍哥帖子) http://ahpal.com/home/space.php?uid=7323&amp;do=blog&amp;id=20086 語法如下:

body {background:url(圖檔連結網址) center top transparent no-repeat;} html {background:url(圖檔連結網址) center top #fcd8b4 repeat;}

css發帖背景圖語法(參考龍哥帖子) http://ahpal.com/home/space.php?uid=7323&amp;do=blog&amp;id=19217 語法如下: <style type=text/css> <!– body{ background-image : url(背景圖網址); background-repeat : repeat; background-attachment : fixed;} –> </style>
