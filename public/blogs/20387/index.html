你媽和我今天要去辦離婚了！

一位住在台北的老先生在農曆春節前打電話給他在落杉機的兒子。 rn＂兒子，雖然美國人不過中國年，但我也真的不想在這個時候破壞你的心情，也不想麻煩你。＂ rn rn兒子：？？ rn rn＂你媽和我今天要去辦離婚了。＂ rn rn兒子大吼道；爸，你在說什麼啊！ rn rn＂四十五年來我受夠了，我們現在連看一眼都受不了對方。我不說了，你打個電話去紐約給你姐姐，我不說了，等會我和你媽就 要出去了。＂rn rn兒子立刻急的打電話給他姐姐。 rn rn他姐姐在電話那頭已然火藥庫快炸了，大聲咆哮的說：這兩個人是瘋了還是怎麼樣？離什麼鬼婚，你交給我搞定這二個老糊塗。rn rn女兒立即從紐約打電話回台北家裡，並且在電話裡對著老爸大小聲：＂你不准給我離婚，你給我聽好，明、後天我就和弟弟回來，我回來之前，你什麼都不准做。＂ rn rn女兒講完就掛了電話。 rn rn rn台北這頭，老先生掛了電話，對著廚房叫道：＂老太婆～～！都搞定了，妳寶貝女兒和兒子，明、後天就回來過年了，而且第一次沒有叫我出機票錢。＂
