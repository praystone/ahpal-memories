讓「活著」趕得上你

✍️ 影子 📅 2010-03-19

作者：影子

發文：2010-03-19

瀏覽：20 次 ｜ 回應：0 則

有一個人很害怕死亡。 rn    他心裡想著：「死亡是在前面呢？還是在後面呢？」 rn    他想到：「人總是在往前跑的時死亡，例如飛機失事、車禍喪生。 rn    所有的動物也都是在往前逃命的時候，被捕殺的。 rn    從來沒有動物是在後退時喪生，所以，死亡是從後面追趕的。」 rn    他得到一個重要的結論：「要避免被死亡追上的唯一方法，就是走得更快速、更匆 rn    忙。」於是，他每天總是行色匆忙，不論是吃飯、工作或走路，都比從前的自己快了三倍。 rn    有一天，他匆匆忙忙的趕路時，突然被一個白鬍子的老人叫住。 rn    老人問他說：「你如此匆忙，是在追趕什麼呢？」 rn    他說：「我不是講追趕，我是在逃開呀！」 rn    「逃開什麼呢？」老人問。 rn    「逃開死亡！」 rn    老人說：「你怎麼知道死亡是在後面呢？」 rn    他說：「因為所有的動物都是在往前逃命被死亡追上的。」 rn    老人說：「你錯了！死亡不是在起點時追趕，而是在終點時等候的。 rn    不論你跑快或跑慢，都會抵達終點。」 rn    「你怎麼知道？」 rn    「因為我就是死神呀！」老人說。 rn    那個人大驚失色的說：「你今晚會出現，莫非我的死期到了？」 rn    死神說：「喔！你不用害怕，你的死期還沒有到，只是你一直跑得太快，我的兄弟 rn    「活著」一直向我抱怨趕不上你，如果你不和他會合，和死亡又有什麼兩樣呢？他 rn    特別請我通知你慢一些呀！」 rn    「我要如何才能和「活著」會合呢？」 rn    死神說：「首先，你要站著不動，把心靜下來，然後你要環顧四周，用心體會、 rn    用愛感覺、用所有的力量來品味，活著就會趕上你了。」 rn    當他把心靜下來的時候，老人說：「你回頭看看，我的兄弟來了。」 rn    他一回頭，老人不見了，卻看見了從來沒有看見的、美麗的街景。 rn    幸福並不取決於財富、權力和容貌，而是取決於你和周圍人的相處。在平凡的日子 rn    裡，珍惜週遭的人事物！~
