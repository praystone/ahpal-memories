【軟體介紹】：

在截圖後的儲存界面，可以看到會隨「波」蕩漾的預覽圖! 很酷! 簡潔是因為，它沒有編輯圖片的功能。儲存界面的按鈕非常簡潔而實用。

使用方法

按下 PrintScreen 鍵之後，螢幕變暗，用右鍵畫線，畫好之後，用左鍵把你想要截圖的內容圈起來。

PrintScreen：對全螢幕進行截圖 Alt + PrintScree：對目前視窗進行截圖。 左鍵：繪製需要的儲存區域，也就是說可以截出不規則的區域。 右鍵：繪製畫線與註釋。 Ctrl + 左鍵：擷取矩形區域。 Ctrl + 右鍵：繪製矩形。 滑鼠滾輪：調整畫線的大小。 Del/BackSpace：刪除上次一條線。可以多次使用。 Esc：結束截圖。 Space：擷取整個屏。 在系統列選單還可以選取倒數計時截圖。
