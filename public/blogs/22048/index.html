02  章         初識                             他說他不是從前的他，這才是他。

我和陳恆收拾好東西後悠悠哉哉的慢步走往回學校的路，過程中我還嗑掉了從陳恆家裡A來的另一個不同口味的大麵包( 紅豆奶油口味 )，和兩份從冰箱裡拿出來，還沒有解凍冷吱吱的鬆餅( 巧克力口味 )，外加半瓶在路上的7-11裡買來的保力達。 陳恆對於我雙手空空的來到他家，肚子滿滿的回去倒也沒多說什麼，指不過在路上開口說了一句話：「 你有病阿 … ? 」，看了我一眼後又回複成那個很少說話的他，我可以感覺的到他心裡其實有非常多的點點點點。  ….  我也感到有點無言，沒想到我居然在這短短的路上吃了這麼多東西，為了我的好身材著想，我把剩下半罐的保力達鎖緊打算拿回去孝敬孝敬邱跳。 學校的校門口越來越近，我看到了一輛大搖大擺停在校門口閃亮亮的灰狼重型機車。 『邱跳也回來了。』陳恆說。 「嗯，我知道了。」 那台花枝濫綻，蝦怕到不行的機車，主人就是邱跳。機車既然出現在校門口，那也代表主人回到了學校。 操場上教官正在上學弟學妹的體育課，所以我們倆只好不走校門口，改爬圍牆進學校。 「 書生！陳恆！你們兩個傢伙剛剛三節課都死到哪去啦！班長怎麼找你們都找不到，給我去後面罰站好好反省反省！！」 剛進到教室，被我們取為綽號『阿婆』的國文老師馬上咆嘯了起來，嚇的我和陳恆立刻立正站好不敢輕舉妄動，深怕這位獅吼功了得的國文老師叫吼的太激烈，將聲音傳到校長室或者在操場的教官耳中，那可就不好玩了！！ 我看見措賽林和大仔往後看了看我們，竊笑了幾聲。 「顏譽航、林耀史，你們兩個不用笑人家。你們只比他們早來了一節課你們憑什麼笑他們，給我把頭轉回來坐好！」　我看到國文老師將它的大型麥克風轉到了最大聲，彷彿殺豬般的聲音瞬間傳開在每個好同學的耳中。 大仔和措賽林現在整個臉都是綠的 ，默默的將頭給轉回講桌的方向。 經過阿婆老師的提醒，我看看手機螢幕上顯示的11：45，才恍然明白我們這一悠哉的慢走，居然真的『慢走』了那麼久，如果不是早上先來將書包放好的話，搞不好老師會以為我和陳恆今天來學校是為了吃午餐的。 當正午十二點的鐘聲響起之後我才想起那轉學生，楊襄。差點就忘了他的存在，我環視了班上每個人發覺都是熟悉的那群，並沒有看到什麼新面孔，但我發現了有一張本來不存在的桌椅，沒有人在位子上，很顯然那就是新轉學的位子。 不過一個新轉學生到了學校不坐在位子上，會是去哪裡呢？何況現在還是吃午飯的時間。 「怪了，那轉學生呢？」 我站在陳恆身旁自言自語著。 『 ….. 』 陳恆他一個字也沒回應我。 我只好再次環視一次教室。沒有看還沒什麼關係，一看之後我整個懵了。 大仔不在教室！！　連挫賽林也不見蹤影。 挫賽林是唯一一個吃飽太閒，會成天跟著大仔的傢伙，現在連他這個最可能知道大仔行蹤的人也失蹤，讓我更是懵上加懵。 身旁的同學已經開飯也閒話家常的開始聊起天了，我還站在原地不知所云。 但懵的人只是我，並不代表我身旁的陳恆他也矇了。

「對不起憐姐，打擾一下。」   『嗯？怎麼了，小恆？』 被我們稱為憐姐的女生放下了手中的碗盤轉過頭看了看陳恆。 「憐姐知道大仔在哪裡嗎？我和書生正在找他。」 陳恆指了指還在原地發呆罰站的我說。 憐姐還沒有出聲，在旁邊陪著憐姐吃飯的四五個姊妹淘就開口了。 「他去抽菸了！」　憐姐的姊妹淘其一的慈培。 「我不知道！」　姊妹淘其二的吳小皮。 陳恆一時之間也不知道該說什麼好，明明好端端的在請問憐姐，這幾個小三八搞什麼急著答話！而且還是有回答跟沒回答一樣的廢話 … 我走到恆身邊對憐姐點了點頭，再用我楚楚可憐加上閃閃淚光的眼看著憐姐，希望她能給我個和其他小三八不一樣的，正確的回答。 「別那樣看我！ 我也不知道那小子跑哪去了，而且你那個眼神真的是 … 真的是好 …噁心。」 由於不敢直視我的雙眼，她把頭給轉了過去。 我整個都囧了現在 …

「邱跳 … 邱跳他在 …」 正當絕望的時候，我耳邊傳了一陣弱不禁風且不好意思那樣的聲音。我一看，原來是芸芸。 不得不說，芸芸算是憐姐的好友裡最有禮貌，最溫柔善良的女孩子了。 「哪裡？」陳恆脫口而出。 『他和 …他和那個新來的轉學生，去 …去你們常去抽菸的那個 …小巷子。』 她盯著我，卻是在回答陳恆。 「和新來的一起！？」　恆有點疑惑，但他臉上沒有任何表情，至少我看不出來。 『芸芸說是那就是了，我還記得邱跳看見他的時候嚇了一跳，之後還有說有笑的。』憐姐這時開口了。 「嗯，我是真的有看見他們走去小巷。」 芸芸還是看著我，讓我有點不知所錯。 『快點去吧，不是很急著找他嗎？』 說完憐姐就又跟那兩個小三八聊東聊西，不管我們了。 我連午飯都不吃了，對憐姐應聲好之後馬上趕著要去小巷找大仔，沒想到陳恆就像早就知道了一樣已經出現在教室門口，顯然就是在等我那樣。 「走吧，這次真的要見識見識這位轉學生，看他是何方神聖了。」我說。 『嗯 …』 走出教室時我回頭看了芸芸一眼，而她像是被發現什麼祕密一樣，眼睛轉來轉去做一些毫無意義的動作。

小巷位於本校的最東邊，而小巷就如它的名子一樣，是一條非常非常之狹窄的小巷 … 寬不超過一尺，但長度還可以，大概有三十公尺長，小巷裡還有一條非常貼心且輔合民情的水溝，非常之方便。可以用來：堆垃圾、丟菸頭、吐痰，甚至還可以排尿 …離題了。 右邊是教室的圍牆，圍牆上有一條和小巷長度一至的直徑十五公分大鋼管，可以讓我們坐著。而左邊就是學校的圍牆，翻過去是一片樹林。 這裡龍蛇雜處，不管誰都可以進來。但不知為何，乖乖牌學生很少人願意光顧。當然 …能來的人也包括了校長和教官。 有人會在這裡吃早餐、吃午餐，更多的是來這裡抽菸、聚會喝酒的人。 一如往常，我和陳恆兩人還沒踏進巷子，裡面就傳來了陣陣菸味和嘰嘰喳喳的說話聲音。 一腳踏入，一頭望去。 「我操！怎麼搞得這麼多人！」 不誇張！絕對不誇張！在這間學校上了整整一學期加上四分之一學期的日子裡，我第一次看到這麼多的人在這裡！ 望去，以我的明眼略掃了一下，人數也絕不會少於二十五。 十幾個學長坐在圍牆上，而橫條管上坐了十幾個，還有後面的…以我的眼力看不清楚有多少人。 陳恆沒有和我一起走往巷子的更裡面，他翻上了圍牆，跟我說聲快去吧！穩好身子之後又沉默了。 「對不起學長！」，「對不起，不小心撞到的，我找邱跳。」 短短幾公尺內我就撞到了好幾個學長，身子扭來扭去的才擠到更中間。 終於，我看見了大仔。他正和幾個學長說說笑笑的。 「大仔！終於找到你了，那轉學生呢？」 『呦！書生你終於來啦。』大仔笑了笑。 大仔指向了他身邊，將身子挪開讓我看個清楚，『你自己看吧，哈！』 我和新轉學生四目交接。

我覺到我的心，停止跳動了一秒。 我的嘴角，上揚了四十五度角。 『艾斯！』

 

 

 

眼中的人笑了。 『沒有艾斯了，也再沒有楊碩了。』 從此以後叫我，楊襄。

憶，相思。 ( 二 )
