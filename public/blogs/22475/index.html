【軟體介紹】：

使用者們都知道，絕大多數的軟體，隨著版本號的增加，除了功能的增強與介面更加華麗外，最明顯的不同就是體積的增幅，而這點在微軟的 Media Player 系列上也可以得到相當明顯的驗證。也因此，雖然 Windows Media Player 11 已經發佈了一段時日，但是許多使用者還是寧願抱著過去的 Media Player Classic 來做為主力播放器。

如果你也是 Media Player Classic （底下簡稱為 MPC）的愛用者，那麼你就絕對不能錯過 Media Player Classic - Home Cinema （底下簡稱為 MPC-HC）。由於 MPC 的開發已經停止了約兩年的時間，也因此讓它在處理某些新的影片格式時會發生錯誤，但是這卻仍無法讓許多愛用者放棄它的好（體積小巧、啟動速度快、資源佔用低），不過對於使用 64 位元處理器的使用者來說，就無法再繼續享受它的這些優點了。但是別擔心，因為它的後繼者 MPC-HC 已經問世了。

MPC-HC 是以原本的 MPC 為基礎而繼續開發的新版本，它的目的就像它的名字一樣，希望在家庭劇院中扮演播放者的角色。而 MPC-HC 除了修正許多 MPC 原有的錯誤外，最大的特色就是提供了 64 位元的版本，讓使用 64 位元處理器的使用者可以繼續享受這款小巧播放器所帶來的優點。如果你是 MPC 的愛用者，那麼 MPC-HC 絕對就是你的新最佳選擇喔。
