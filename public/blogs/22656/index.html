【軟體名稱】：Windows Process Security

【軟體分類】：系統工具

【軟體性質】：免費軟體

【檔案大小】：壓縮後 3.71 MB (壓縮前 27.7 MB)

【放置空間】：

【分享期限】：直到掛點為止

【軟體介紹】：

Windows Process Security 是免費開源的軟體，用資料庫來鑑別電腦中執行的程式是否安全。 可以線上更新資料庫，號稱可以檢驗13萬種有害的威脅。 功能略嫌簡單，但是方便使用、一目了然，提供給有興趣的人試試看。
