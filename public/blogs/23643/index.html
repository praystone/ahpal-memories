勞作是福

✍️ Anita 📅 2010-06-17

作者：Anita

發文：2010-06-17

瀏覽：93 次 ｜ 回應：7 則

   勞動是人類生存的基礎，是一個人增強體質，提高技能的基本途徑。勞動也是我們的最大福分。鄙棄勞動的人，往往會受到人們的指責，熱愛勞 動的人，多會受到人們的尊重和愛戴。    rn 有則佛教故事說，有 一個又髒又臭的老乞丐，天天站在路旁乞討。有一頓沒一頓的，日子過得窮苦不堪，但是他每天早上仍虔誠的祈禱，希望奇跡能夠降臨到自己身上。   rn 一天,當他祈禱完畢，抬頭一看，竟然有位全身發光的菩薩站在眼前。菩薩告訴乞丐，說自己能夠滿足他的三個願望。   rn 老乞丐心中大喜，毫 不遲疑地立刻許下了他的第一個願望：要變成一個有錢人。?那間，他就置身於一座豪華的大宅院中，身 邊有無數的金銀財寶，終其一生也享用不盡。   rn 老乞丐馬上又向菩薩 許下第二個願望：希望自己能年輕四十歲，果然，一陣青煙過後，老乞丐變成了二十歲的小夥子。   rn 這時，他興奮到了極 點，不假思索地說出了第三個願望：一輩子不需要工作。   rn 菩薩點了點頭，他立 刻又變回了路旁那個又老又髒的乞丐了。   rn 乞丐不解地問：「這 是為什麼？這個願望說出來之後，我為何變得一無所有呢？」   rn 一個聲音從天際傳 來，：「工作是上帝賜給你的最大的福份。想一想，如果你什麼都不做，整天無所事事，那是多麼可怕的一件事！只有投入工作，你才能變得富有，才能有生命活 力。現在你把上帝給你的最大恩賜扔掉了，當然就一無所有了！」   rn 乞丐許下了一個「不 需要勞作的願望」，使他從一個年輕富足的人，一下子又回到了老弱病殘，又髒又臭的狀態，這是他好逸惡勞所招致的果報。   rn 佛教主張人要勤勞， 歷代的高僧大德都鼓勵修行人要熱愛勞動。他們一致主張叢林要農禪並重，自食其力。百丈懷海禪師更以踐行「一日不做，一日不食」的理念，而倍受後人推崇。他 每天除了領眾修行外，必親執勞役，勤苦工作，要求自己與其他僧人過自食其力的生活，對於平常生活中的瑣碎事務，尤不肯假手他人。   rn 後來，百丈禪師漸漸 老了，但他每日仍隨眾上山擔柴、下田種地，因為農禪生活就是自耕自食的生活。弟子們不忍心讓年邁的師父做這種粗重的工作，因此懇請他不要過分的勞作，但百 丈禪師仍以堅定的口吻說：「我無德於人，人生在世，如果不親自勞動，那不是成了廢人了嗎？」   rn 弟子們阻止不了禪師 勞作的決心，只好將禪師所用的扁擔、鋤頭等工具藏起來，不讓他做工。   rn 百丈禪師無奈，只好 用不吃飯的絕食行為抗議，弟子們焦急的問道：「師父，您為何不飲不食？」   rn 百丈禪師說：「既然 沒有工作，哪里能吃飯呢？」   rn 弟子們沒有辦法，只 好將工具又還給他，讓他隨眾勞作。   rn 勞動是人類獲取物質 資料的基礎，勞動可以鍛煉身體，開發智慧，拓展人的生命活力，使人遠離空虛和無聊。工作中還蘊藏著無數的成功的機會，使人可以感受到工作的樂趣，體現自身 的價值，工作也是人生的一大福分，那種幻想不勞而獲的想法是要不得的。
