JRE可讓您的電腦執行使用Java技術與Applet的應用程式與網頁（如：網路郵局），是電腦裝機時必裝的套件，內含JAVA虛擬機器(Java virtual machine)，所以你也可以叫他作新版的JAVA虛擬機器；若不想要常常跑出自動更新訊息，可以關閉自動檢查更新功能。

鑑於 JRE 6u4 在 FF2.0.0.13 上不斷導致許多靈異現象、FF 一直當！從 JRE 5 測試到 JRE 6 update 5，最後經好友小強建議改採 5.0 (1.5.0) 版，果然這版舊架構才是王道！用這版，JRE 就不會透過 FF 瀏覽器告訴你要下載 Java Plug-In，使用 Java 技術的網頁也完全正常了！以後，這種東西有裝過就好，如果沒問題，不要再更新了！免得自找麻煩，殺掉一堆 DeBug 的時間。
