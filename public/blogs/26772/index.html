借錢放生，母癌得愈——奇跡震撼人心，人人都可實踐<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

                                           作者：龍樹初發心

扈向民師兄，山東淄博市紅衛電機廠工人，來自農村，侍親至孝，為人質樸，不善言辭。每次大放生，他都會帶領幾位元工人兄弟參加，默默無聞，從不多話，卻總是搶著幹最髒最累的活。據我的經驗，這樣的師兄往往都是修行很好的，比起我這種動輒大呼小叫，指揮這個指揮那個的所謂組織者強過太多！

扈師兄文化程度不高，以下是他自述的親身經歷，由我記錄、整理，文辭稍作修飾，事實並無出入：

我叫扈向民，今年（2010年）39歲。

我母親李本榮，於2007年5月份查出乳腺癌，後在濱州醫學院附屬醫院做了左乳房切除手術，術後病情暫時穩定下來。

2009年7月下旬，母親病情突然惡化，全身出現浮腫，經檢查癌細胞已擴散到整個胸腹部。醫生說乳腺癌一般不會擴散這麼快，病情發展到這種程度已是回天乏術，勉強治療也是白花錢，剩下的時間不多了，不如讓老人家回家休養，少受點罪，儘量別讓她生氣，多吃點好東西……

母親才65歲，一生為人善良，樂於助人，為這個家操勞了大半輩子，剛到了能享點福的年齡卻要離我們而去了……我們全家都很傷心，我更是成夜成夜的睡不著覺，一想起小時候母親撫育我的點點滴滴便心如刀割……這時候如果能拿我的命去換母親的命，我想我會毫不猶豫！

就在全家人陷入絕望的時侯，我妻子從信佛同修那裏請了一本“拔眾生苦放生會”編印的《戒殺放生》，書中有好幾個通過放生念佛治癒癌症的實例，一口氣看完這本書，我好象是溺水的人抓住了一根木頭，立即和妻子一起發心，用放生來救我母親！當時這也是沒有辦法的辦法了。

那時我雖已信佛，但對放生還是有點半信半疑，陰曆八月初一晚上念佛時，我祈求觀音菩薩點化，恍惚中感覺有人告訴我，誦《地藏經》和放一萬元的生命可以救我母親！

我父母、哥哥、弟弟都不信佛，更別說拿錢放生了。為了盡最大努力挽救母親，父親已下了任務，我哥出一萬，我和弟弟一人出五千，湊錢給母親做化療。

我是下崗工人，現在一鋼鐵廠給人打工，妻子在一家超市幹服務員，兩人月收入加起來2000元左右，因為買房子還欠債12萬元，拿5000元給母親治病已很困難，再拿出一萬元放生，更是難上加難。但看著飽受病痛折磨的母親，我想，自己就是再難，也得為她保留最後一絲生的希望！

我當時已沒處借錢，但妻子修行很好，對我也很體貼，她二話沒說，到處找親戚、朋友、同事，用了不到十天時間就借來了15000元，5000給母親化療，10000元準備放生。於此同時我開始沒日沒夜地誦《地藏經》，每天誦八遍，回向給母親的怨親債主，希望他們與母親解怨釋結，早日往生極樂，希望母親能夠戰勝病魔，身體儘快康復。

我想到附近黃河放生甲魚，有些居士怕黃河水太渾濁不適合甲魚生存，我也有點猶豫，就和放生會L居士聯繫，希望他幫我一起放生，L居士那段時間恰好去了青島，他讓我看情況辦，並說關鍵在發心！

為慎重起見，<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />2009年8月10日，我買了兩隻甲魚，和張清華、陳建宇兩位居士一起來到黃河濱州段的一座浮橋，一邊念觀音菩薩聖號，一邊用網兜套住兩隻甲魚放在黃河水裏試驗，過了一個多小時，提上甲魚來觀察，活得很好，沒什麼影響，我這才放了心。

2009年8月12日上午，我們全家還有另外幾位居士一起到本地海盛水產市場“明光水產”攤檔購買了甲魚、龜、泥鰍等物命，共計12000元。其中一隻大龜重約25斤，憨態可掬，十分可愛。放生地點還是黃河濱州段的浮橋，同修們念完放生儀軌後，來到浮橋中段，將物命放入水中。

水流很急，鱉、泥鰍都很快順水流走，唯獨那只大龜遲遲不肯離去，在水裏沉下去又浮上來，連續三次，每次浮出水面都轉回頭來看著我們，很長時間才漸漸遊走遠去……

這時，我九歲的女兒看到大龜遠去的方向，空中出現一圈紫色的光環——據她說，光環很大，顏色很濃，就像在空中出現了一個大洞，之後光環由紫色變成七彩顏色，然後慢慢消失。

放生後第二天，我妻子打電話給老家詢問母親病情，不可思議的事情發生了！——父親很高興的說，母親全身浮腫已經消退，情況很穩定，精神健旺了很多，也能吃得下飯了。

之後，母親的身體竟一天比一天好轉，一個月後，再次去醫院檢查，除了血糖偏高（我母親原來就有糖尿病），其他指標均正常，竟然恢復如常了！醫生不敢相信，我們全家更是不敢相信，然而，事實擺在面前，奇跡就這樣發生了！

現在，我母親除了有點虛弱之外，其他和常人完全一樣，每天在家裏看看孩子，做做家務，平安喜樂，安享晚年。誰也看不出來，幾個月前，她還是個被醫院判了死刑的癌症晚期病人！

借的錢可以慢慢還，只要人在，我就仍有機會陪母親嘮嘮嗑，仍有機會為老人捶捶腿，我女兒還可以在她懷裏撒撒歡，我還擁有一個完整的家！

感謝觀世音菩薩護佑！感謝《戒殺放生》這本書，感謝拔眾生苦放生會，也感謝我的妻子，沒有她的支持，這一切都不可能實現！

這次放生之後，除了母親的病好了，我身邊很多事情，也開始發生變化：

一、家庭越來越和睦：

以前因為經濟問題、生活瑣事，我經常和妻子吵架。經過這件事，我們的感情比以前任何時候都更加深厚，我現在對妻子只有感激，再不吵架了。女兒小小年紀也信佛了，經常跟著念佛、禮拜，比以前聽話了很多。家裏氣氛越來越祥和，成了一個名副其實的佛化家庭。

二、工作越來越順利：

以前，我打工的工廠領導，總是看我不順眼，我工作再賣力也沒用，常常藉故找我的麻煩。有時我都不想幹了，但現在工作不好找，只好忍耐。

現在，廠領導對我的態度越來越和善，再不隨便找碴“修理”我了，轉變之大，我自己都覺得奇怪！我妻子在單位也比以前更順，工作之餘，還接了點零活幹，經濟上也比以前寬裕了。

三、身體變好了：

因為常加夜班，我以前總感覺全身無力，沒有精神。現在多數時候都精神很足，感覺渾身是勁。以前我有嚴重的“恐高症”，一到高處就腿軟、腳發麻，心裏害怕，現在這些現象都沒有了。

這次放生後大約一個月，一天晚上，我念佛號兩小時後，心裏越來越沉靜，慢慢的，連佛號也忘了……這時，眼前漸漸現出一個大刺蝟的形象，我馬上想起了小時候的一件事：

我老家在山東濱州農村，因為孩子多，從小家裏就窮，八歲時，一家人還住土胚房，兩個明間一個里間。那年秋天的一個晚上，天已經很黑，我母親聽到裏屋有動靜，就拿著手電筒進去看，發現地上有一隻刺蝟，個頭很大，抬頭望著母親，眼光挺和善，一點不怕人，也不知怎麼進屋的。

我母親生性善良，那時也不知道什麼叫放生，因為怕別人看見害了它，就讓我找個小筐把它裝進去提到村頭野地放了。這時，我家院後一個鄰居來串門，母親就叫他陪我一起去，當時也不知他怎麼想的，他領著我到了村南頭水灣邊，刨了個坑把大刺蝟扔進去，用石頭把它砸昏，然後再蓋上土，就這樣把它活埋了！（懺悔！）那時我年齡小，也不懂他在幹嘛，只有眼睜睜看著。

這時候，眼前的刺蝟，逐漸變成了一個小孩的形象，感覺他跟我說，我母親前世救過他的命，幾十年前，他到我家，本來是去報恩的，如果不被打死，我家能發大財，可是竟被鄰居砸死活埋了，而且死得很痛苦！我母親雖然無心害他，但與此事也有關係，所以，因緣成熟，還是得了癌症，現在他可以走了。之後，那個小孩越來越小，逐漸消失不見了……

我從定中清醒過來，豁然明白，這是菩薩在點化我母親得病的因緣，同時，也是在堅定我精進修行的信心啊！不由想起那個砸死刺蝟的鄰居，那件事發生不久，他妻子就開始生病，是肺炎，病不重，卻怎麼也治不好！時好時壞拖了兩年，花光了家裏所有積蓄，最後還是不幸死去。鄰居中年喪妻，從此一蹶不振，窮困潦倒，後來去外地打工，不知所終……

因果報應，絲毫不爽。這是我的親身經歷，再次告誡所有善良的人們，千萬不要隨意殺害生靈！對你來講，也許是不經意的一件小事，日後付出的代價，卻是你難以想像也無法承受的！

四、餘話：

這次放生之後，還發生了兩件奇怪的事：

從十四歲開始，我就經常做同一個夢，夢見員警開著警車追我，心裏很害怕，有時會從夢中驚醒！那次放生後的一天晚上，夢見一個熟人用自行車載我過橋，這時，出現一個便衣員警把我叫住，對我說以後不要再犯法了，再犯法就要你的命，說完就走了。

這時我也醒了，就去上廁所，在廁所地上竟然看到一隻“濕濕蟲”，當時正是寒冬，我房間也沒有暖氣，而這種蟲子只在春夏兩季，天氣暖和時才有。

這時，我想起少年時，也就是14歲左右，我和哥哥常去農田刨地，我們刨地用的工具叫“沙耙子”，是用幾根鐵管子焊的，鐵管中空，裏面總是爬滿了“濕濕蟲”，成千上萬！因為害怕蟲子，每次我倆都把它們從鐵管裏全部倒出來，然後用腳踩死，幾年下來，殺死的小蟲不可計數，造了大量殺生惡業！

想起往事，再找那只蟲子時，它已消失不見了……

這件事之後，我再也沒夢見過警車追我，睡覺安穩了很多。我哥哥一直患鼻炎，長年治不好，從那之後，竟然也不再發作了！我想通過念佛、放生，當年殺死大量小蟲的罪業可能已經消除了！

我母親病癒後，我對放生有了極大信心！開始積極參加“拔眾生苦放生會”組織的所有活動。

2009年10月5日，陰曆九月初八，放生會組織到高青大蘆湖大放生。放生途中，我一直在念佛號，感覺很清淨。客車下高速路口時，突然看見一尊釋迦摩尼佛像在我前面盤腿坐著，笑眯眯的，很清晰……

放生後第三天，也就是陰曆九月十一早晨四點左右，我夢見家裏一個男孩娶媳婦，家裏人都忙活著給孩子操辦婚禮，但他有新房子不住，非要住在老房子裏。

夢境很清晰，醒來後我明白，通過放生，又了卻了一樁業力！——1995年，妻子曾墮過一次胎，從那之後，我經常夢見有小孩擋路，經濟也變得緊張，生活工作各方面都開始不順。那次放鱉之後，曾夢見小孩已經八歲了，長得很精神。這次，又夢見他已結婚成家，看來孩子已經放過我們，不來討債了。

每次參加放生，我都越來越深的體會到，所有的生命都是平等的，都是無比珍貴的！也越來越深的體會到“諸功德中，放生第一”這句話的含義！

當你真正領教世事的難料，當你真正面對生命的無常，當你眼睜睜看著最親近的人即將逝去卻束手無策，當你恨不得拿自己的生命去交換卻無能為力……

只有在身臨其境的那一刻，你才會明白：金錢、美色、權利、名譽……等等等等你為之營營苟苟、忙忙碌碌的一切，在生命面前都是那麼蒼白，那麼毫無意義！那時你會毫不猶豫放棄這一切來換取哪怕多一秒種的生命！只是，很多人真正明白的時候，很多事已經為時太晚……

趁您還有大把的時光，趁您還有健康的身體，趁您還能在溫暖的陽光下行走，趁您還能在新鮮的空氣中呼吸，即刻回頭，斷惡向善，戒殺放生，孝順父母……一切都還來得及！

通過以上親身經歷，我更堅定了精進修行，跳出輪回的信心！

現在，我已經吃全素，除了正常工作，業餘時間大部分都用來修行，除了參加放生，每天都會堅持念佛號五小時，或誦《地藏經》五遍，感覺雜念越來越少，心地越來越清淨，業力越來越輕，生活也越來越幸福。

印光大師說：“不殺，放生，吃素，念佛。這四點能做到的人，就可以心想事成。”在我身上，已完全得到印證！（人人可以實踐、驗證，佛菩薩、祖師大德絕無虛言！）

拔眾生苦放生會常年堅持不懈組織放生，編印流通善書，既救活了無數物命，又為無數參與同修和他們的家人消除了大量業力，再次向他們表示感謝！功德無量！（所有參與的同修，其實都已經消除了大量業力，雖然感覺可能並不明顯，但請注意觀察身邊的細節小事，就明白放生的功德有多麼大了！） （全文完）
