各家BIOS嗶聲訊息意義

✍️ 巴薩拉 📅 2011-01-11

作者：巴薩拉

發文：2011-01-11

瀏覽：65 次 ｜ 回應：7 則

BIOS在電腦開機時會針對電腦硬體做一連串的測試，如果有問題時會發出嗶嗶聲警告，可藉由嗶嗶聲的來判定電腦硬體那裡到底發生了何種故障，下列各家的BIOS嗶聲所代表的意義：

【AMI BIOS】 嗶聲數目代表意義 1記憶體Refresh有問題 2記憶體同位元檢查錯誤 3前 64K 記憶區段檢測失敗 4系統計時器失效 5處理器錯誤 6鍵盤控制器 8024 . A20 位址線錯誤 7處理器發生異常中斷 8顯示卡未裝妥或視訊記憶體存取錯誤 9ROM BIOS 檢查錯誤 10CMOS shutdown 暫存器存取錯誤 11外部快取錯誤

【PHOENIX BIOS】 嗶聲方式代表意義 2-2-3ROM BIOS 檢查碼錯誤 3-1-1記憶體充電失敗 3-1-3鍵盤控制器 8042 錯誤 3-4-1512K 位址解碼電路錯誤 3-4-3512K 主記憶體錯誤 2-1-2-3BIOS 版權遭修改 2-2-3-1處理器發生異常中斷

【AWARD BIOS】 嗶聲方式代表意義 連續的嗶叫記憶體損壞或沒插好 1長2短的叫顯示卡記憶體有問題或沒插好

【AWARD】 1短：系統啟動正常。 2短：CMOS設定錯誤。 一長一短：DRAM錯誤。 一長二短：顯示卡或螢幕連接錯誤。 一長三短：鍵盤錯誤。 一長九短：ROM錯誤。 不斷長響：DRAM未插好。 不停急響：電源有問題。 　 【AMI 】 1短：DRAM刷新錯誤。 2短：DRAM ECC檢查錯誤。 3短：DRAM檢查失敗。 5短：CPU錯誤。 6短：鍵盤錯誤。 8短：顯示卡記憶體錯誤。 9短：ROM錯誤。 一長三短：DRAM損壞。 一長八短：顯示卡或螢幕連接錯誤。 1 聲 → refresh failure 充電失敗 2 聲 → parity error 同位檢查錯誤 3 聲 → BASE 64K MEMORY FAIL 前64k記憶體錯誤 4 聲 → TIMER NOT OPERATIONAL 時脈錯誤 5 聲 → processor error cpu 燒了 6 聲 → 8042-gate a20 fail 無法轉換到保護模式 7 聲 → process exception interrupt error cpu 中斷錯誤 8 聲 → display memory error　VGA 卡上記憶體燒了 9 聲 → rom checksum erroe 唯讀記憶體檢查碼錯誤 10 聲 → cmos shutdown register error CMOS 燒了 11 聲 → CACHE MEMORY BAD CACHE MEMORY 燒了 1 長 3 短 → 顯示卡沒插好 1 直短 → 記憶體沒插好

從你打開電腦電源到作業系統載入之中，都是在執行 BIOS中的程式，其中包括檢測電腦系統中的基本配備 CPU,RAM,VGA等，若發現問題，會發出聲響以警告 使用者，但隨不同的BIOS製造商，會有不同的表示方 式，下面列出幾種常看到的版本，你可以參考看看， 下次當你聽到電腦發出"嗶"聲時，你就可以表現聽 音辨位的功力了。
