高僧傳授三件法寶，對治一切惡疾、絕症！<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

一、檢點過失，改過向善！

   多數人身患惡疾、絕症，包括倒楣、不順、意外、破財等等，究其原因，不外乎兩種情況。一是今世造了惡業受報，這些惡業一般都體現在三個方面:不孝、邪淫、殺生！這三種惡業最損人福報！二是以前生中冤親債主來報，但前提和條件是“惡緣成熟”，所謂“惡緣成熟”同樣也多體現在以上三種惡業！債主們已經跟隨了很長時間，隨時在找機會，你今生不做壞事，不造惡業，誰也拿你沒辦法！稍有觸犯，他們就會乘虛而入，新帳老賬一起算！

   如果當事人本身就福薄，福不夠折，就折你的壽！因為這兩者是可以互相轉換的（阿羅漢自己就有能力以壽命換福報）。所以才會出現這麼多絕症、意外！你把自己的福、壽提前折騰光了，結果只有一個，就是死！

   更恐怖的是，這還只是個開始！以上三種惡業都可以輕而易舉直接把你送進地獄！一點病痛就讓你死去活來，可是跟地獄罪報相比，那些都是小兒科！看看《地藏經》吧，裏面描述的地獄苦報，完全真實不虛，而且時間是以“劫”計！

您信也好，不信也好，這就是宇宙萬物的法則，誰也無法更改！

您還別問這法則是誰定的，“法爾如是”！

   不服氣？夠膽您就接著試，繼續不孝父母、公婆、岳父母，繼續婚外戀、**、嫖娼、手淫，繼續殺生、吃肉、進補。。。。看看最終等你的會是什麼結局？其實也不用等，現在就去危重房病瞧瞧那些求生不得，求死不能的病人吧，去車禍、意外現場看看那些殘肢斷臂吧。。。。

悠悠世人，億萬眾生，警醒吧！

在這起個案中，患病少年的母親就不太孝順公婆，據說還打過婆婆！

這種情況不在少數，師父曾明確開示，15歲以下的孩子患惡疾或出意外，往往都與其父母造的惡業有關！

   還有另外兩位母親也曾找過師父，她們的孩子都是腦癱！無法自理，生不如死，師父一打照面，就明白八九分，然後直接開訓，痛斥她們不孝父母、公婆的惡行。兩位母親被揭傷疤，自知理虧，一聲都不敢吭！訓完了，馬上開藥方，很簡單，就倆字：“孝順”！做得越好，孩子好的越快！就是做不到？結果就是無藥可治！自己看著辦！

   這些案例中，當事人的個性都很剛強，誰的話也聽不進去，父母管不了、公婆管不了、老公管不了。。。。但是，天地管得了！

   她們別的都不在乎，最緊張的就是自己的孩子，所以債主就從孩子身上下手，報應就在孩子身上體現！當然，這些小孩也是前世造作惡業，互相感召來的。反過頭來想，這也未必不是好事，正是通過這種因緣，很多剛強難化的眾生才有了聽聞佛法、改過向善的機會，否則就此放縱下去，後果可以想像！

列位看官，您又做的如何呢？

   向善方面，很簡單，完全不必到處朝山拜佛，燒香磕頭，等等等等。一句話概括，“好好做人！”一個中心思想“利益別人”！但說來容易，做起來很難，要落實生活的點點滴滴，方方面面。。。。

二、戒殺放生，儘量吃素！

   師父說，多數惡疾、絕症，尤其是醫院治不了的，其實都是業力病！比如癌症，有神通的人會清楚看到，你前生、今世殺過、吃過的生靈，就“潛伏”在你的患病部位！也許是蛇，也許是刺蝟，各式各樣，不一而足！

   它們很頑固，“堅守崗位”，目的只有一個：就要讓你痛苦，讓你難受！

   你曾經加於它們的一切，你也必須一一承受，一一償還！有的還要加倍！和房貸樣，時間越長，利息越重，還得越多！ 這就是“因果報應”！令人生畏，卻又絲毫不爽！

   就像你打了別人一拳，自己也會手疼一樣！您打的要是一普通人，下回碰上，他踹您一腳，也就完了。您打的要是一黑社會，回頭他就海扁你個半死！同理，被殺、被吃的動物越有靈性，嗔恨心越重，比如蛇龜，貓狗，受報就越快。

只要殺生，遲早以命償還！

   所謂的“去醫院治病”，其實就是先反復折騰你，讓你害怕，讓你受疼，讓你花錢，讓你家人擔心，受累。沒辦法，你殺吃它們的時候它們也很害怕，也很疼，它們也有眷屬、兒女。。。。您當時覺得無所謂，幹得很痛快，不就是一小貓小狗，蒼蠅蚊子嗎！現在呢？

   你認為經過醫院治療，病減輕了，好了。實際上只是通過這種方式消了一部分業力，還了一部分舊帳，但是命債仍在，因此很多人病情幾經反復，最終還是不治！

所以說：“菩薩畏因，眾生畏果”！

   可悲的是，多數人死到臨頭還是不明所以，不知道根源所在！只會歸咎於種種客觀因素，怨天尤人，從而喪失寶貴的活命良機！見過很多絕症病人，剩下沒幾天了，跟他談這些，他還會用僅有的力氣罵你是“封建迷信”，還要多多殺生進補，增加營養，增加抵抗力。。。。

殺生食肉，補養自身，焉有是理！

  家有病人，萬勿殺生，素食青菜，營養足夠，多做些花樣，有益無害！

        而放生回向，直接對治殺生惡業！如果有條件，放的越多越好，往往會立見效果，出現奇跡！曾有位老兄，患了惡疾，腹部脹氣，肚大如鼓，痛不欲生，用盡各種辦法，沒有任何效果。總算他有善根，聽人勸，讓他放生，立馬就辦。買了一車鯉魚，因為沒經驗，隨便找了一座橋，看見下面有水，就把魚都倒進去放生。

     放生後次日，一陣上吐下瀉，他肚子就很奇怪的不漲了，完全恢復正常！所以，放生是有甚深佛法密意包含其中的，以凡夫俗智，永遠難以測度！所有有情眾生，最終都難逃一死，但在此之前，任何一個生命都是能多活一秒是一秒，有人給他這個機會，誰都是歡天喜地，千恩萬謝！

不必多慮，儘管去放，放生功德，鬼神難測！

三、誦《地藏經》，消業極快！

   最好找拼音版的，病人自念更好，不能念親人代念也可，儘量誦讀出聲！因為誦得同時，並不只是你自己在聽！無數跟隨你很長時間，伺機或正在報復的冤親債主此時都會很歡喜的來聽。因為無始劫來，這種機會並不多見！

    一方面，他們聽經聞法，會智慧大開，嗔恨心減輕，對你的報復欲也隨之降低，運氣好的話，就此放過你，也未可知。另一方面，《地藏經》代表地藏菩薩，那可不是蓋得，福德無比，威力巨大！將誦經功德回向給冤親債主，他們輕則離苦得樂，業障少的，以此功德瞬間轉生善道也是常事！

   沒事時也多誦《地藏經》吧，真的是寶貝，誦得越多，受益越多！相信很多師兄對此都頗有體會！當然，積怨深的冤親債主也不會就這麼輕易放過你，很多人念佛持咒，讀誦其他佛經都很輕鬆，唯獨《地藏經》，就是很難順利讀完一遍！

   和放生一樣，你想誦經時，不是這事，就是那事。好不容易開始，中間要麼犯困打哈欠，要麼眼花流眼淚，種種種種，目的也只有一個，就是障礙你誦經！但越是這樣，越要迎難而上，熬過最難受的時段，自然會業障轉輕，智慧現前，撥雲見日，柳暗花明！

“諸惡莫作，諸善奉行，自淨其意，是諸佛教”。
