臺灣四百年人物誌之荷西時期荷蘭第01任長官馬蒂孫克(16241625) 宋克（Martinus Sonck，或譯馬蒂·孫克，？—1625年），台灣荷蘭殖民時期第一任台灣長官。1621年曾率兵攻佔班達，成為班達長官。1623年被控浪費槍枝、彈藥而被調回巴達維亞，1624年被在巴達維亞的荷蘭東印度公司總督科恩派赴大員（台灣），成為台灣荷蘭殖民時期首任台灣長官。 宋克於一鯤身設政務廳，並開始興建奧倫治城（Orange），<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1625年1月24日改稱普羅民西亞（Provintia）。宋克死後，1627年此城改名熱蘭遮城（Zeelandia），即今安平古堡。 宋克去世有二說。一為1625年9月與高級舵手佛爾西（Adviaen Verhee）溺斃於大員灣入口，後世有人懷疑宋克是被他曾攻打的新港社人挾怨報復所淹死的。。另說為1626年12月於返回荷蘭途中，溺水死於好望角。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
