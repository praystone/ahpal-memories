1625臺灣四百年人物誌之荷西時期~十八芝 十八芝是清江日昇《台灣外記》中所描述，鄭芝龍在台灣海盜時期的十八位兄弟與結義兄弟。由於名中皆有「芝」字，故稱十八芝。 書中描述，鄭芝龍自日本平戶前往台灣加入顏思齊海盜集團。不久顏思齊急病而死，眾海盜推選鄭芝龍為首領，並於天啟五年（1625年）<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十二月十八日，選十八位先鋒，以芝字排輩。除為首的鄭芝龍外，有其胞弟鄭芝虎、鄭芝豹，族弟鄭芝莞、鄭芝燕，以及異姓兄弟芝鵬、芝鶴、芝鳳、芝彪、芝麒、芝豸、芝獬、芝鵠、芝熊、芝蛟、芝蟒、芝鸞。 抵禦西荷有功 十八芝艦隊擁有海船千艘，海上華人民兵十餘萬人，在抵禦荷蘭西班牙海軍侵略東南各省，發揮保家衛國功效，應予部份肯定。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
