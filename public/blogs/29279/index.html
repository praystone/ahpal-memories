臺灣駕照在大陸真實的故事@#$%^‏‏

 

一個真實的故事，一個臺灣人到大陸發生的事，

讓我見識到臺灣人的確是〝奸肖〞第一名。

話說這個臺灣人到北京去租了一輛車開，開著開著勒，

就被一個公安給攔了下來，公安要求這個臺灣人把駕照拿出來

( 應該是想敲一筆吧！)，這個臺灣人就拿出中華民國駕照啦…厚！

這時這個公安就說啦……

公安：你這個駕照不能用！

臺：為什麼不能用？這不是駕照嗎？

公安：你這是臺灣駕照，所以不能在中國使用。

臺：(火大) 那我問你，臺灣是不是中國的一部分？

公安：是啊

臺：臺灣是不是中國的領土？

公安：是啊

臺：既然臺灣屬於中國，

那你告訴我，為什麼臺灣駕照在中國不能用？

你這樣是認為臺灣不屬於中國囉！臺灣是個主權獨立的國家囉！

因為臺灣是個獨立國所以他的駕照不能在中國使用囉？

公安：*%#&^$…..這這這…. (出現小丸子的三條線)

臺：若你不接受這駕照，也就表示你承認臺灣是個獨立國，

那就是說你是一個贊成臺灣獨立的臺獨份子囉？

我不想浪費時間在你這個臺獨份子身上，走！

和我到派出所找另一個公安出來理論。

公安：屙… ( 汗都飆出來了 ) @#$… 好啦好啦，你可以走了…
