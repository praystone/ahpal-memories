「傻子」──宇宙的鍾愛

 

 <?xml:namespace prefix = st1 />朱　嵐<朱　嵐

為我們揭示和解讀「生命密碼」的日本最著名的生物科學家村上和雄教授近來發表新著，延續他對宇宙和生命的探求和演繹。新著標題非常醒目驚人：「傻子」是宇宙的鍾愛！！ rn<?xml:namespace prefix = o /> 

社會上有太多的聰明人，擅於算計、抓緊一切機會、分清所有得失，務必躋身於精英行列，成就個人和社會的名利。 rn 

村上教授的思考卻非常不同。這些一般意義上的成功者，雖有世俗認可的聰明和才智，卻也往往因此而侷限了自己。這些人生賽程中的所謂「勝利者」一般都自視極高，有意無意間常升起傲慢之心，總以為一切的成就都來自自身的努力，往往也就無法真正打開視野，認知生命的真相，超越自己的侷限，亦無法以柔軟的心對應各種的未知。稍遇挫折，更顯得力不從心，難以應對。無論在順境或逆境，所有展露無遺的聰明和才智隱約間總有一些急促、一些淺薄、一些迷失。 rn 

而對這些人才竭盡鼓勵褒獎之事的我們，身處現代的文明社會，也同樣面臨「物質繁榮、心靈空虛」的尷尬，很多問題找不到答案，很多創傷找不到康復，很多迷失找不到帶領。日本糧食狀況就是一例，自給率不及一半，僅為 40％，但每天被人們浪費丟棄的食物竟不計其數！！如此精於算計的「聰明人群」和「聰明社會」，為何會算的僅是日常小帳，不會也不懂環環相扣的生存大計？？ rn 

不論在本土或他鄉，零零星星，你也會見到一些不急不躁、不爭不奪、平靜又充滿溫暖，普通卻又極其難得的人。他們總保持著自己的節奏、自己的思考、自己的微笑，不人云亦云，不計較得失。不但不加入名和利的爭奪，更希望實踐「付出、付出再付出」的心願，所思所言所為在現代社會和一般人群看來簡直莫名其妙，故常被歸類為匪夷所思的「傻子」！ rn 

宇宙要的究竟是我們社會激賞的「聰明人」？還是如此逆流而上、不計得失、一心利他的「傻子」？ rn 

村上教授自小就常聽祖母宣講所謂的「兩個銀行」：天上銀行和地上銀行。祖母說地上銀行也許會倒閉破產，天上銀行是絕對不可能發生這種事情的，所以你們零用錢或壓歲錢的最理想的儲存地方自然是天上銀行。彼時年幼無知的村上聽著祖母的遊說，常有不滿之心，很想提醒祖母，將錢存往天上銀行的同時是否也能眷顧村上的儲蓄罐？！不僅祖母，連母親也常常在拮据的家用中拿出財物接濟更需要的人。她們常異口同聲地對孩子持續「洗腦」：錢包中的錢若能首先用於他人，實在是極大的福氣，因為這樣就將「錢」轉為了「德」！ rn 

兒時覺得如此傻氣、匪夷所思的「利他論」，竟在不知不覺中也刻入了村上的「遺傳因子」。博士畢業後開始在大學執教，工資的 10％一直捐贈出去，日後收的演講費、版稅也幾乎全額捐助各項慈善事業。領取的大學退職金，分文不留，全部投入「心和遺傳因子研究會」的運作，以期有更多研究成果，利益更多的社會人群。近五十年的研究生涯中獲得的種種機遇成就，村上教授都不認為是偶然所致，更無一己之力所為的錯覺和傲慢，相反，時常歡喜地告訴自己：一定是天上銀行的一筆滿期存款的利息匯下來了！即便從他的研究專項的角度來看，村上教授同樣認為在我們的遺傳因子（DNA）中原本就有「利他」的刻印，若能澄清本性、沉澱自我、洞察真相，我們一定會體會到利益他人帶給我們的無以言表的喜悅和滿足。小自地鐵上的讓座，大至災難中的捨身，無不令我們愉悅充實，而這其實是每一個人的嚮往，因為利他之心與生俱來！競爭和對立在瞬息間也許會帶來成功和勝利的快感，但這不僅極其短暫，更是一種顛倒錯覺，若置身的是與天理相違的種種虛幻假象，怎麼可能體會真實又持久的幸福和快樂？ rn 

人生旅途極其迂迴曲折的蘋果電腦創始人史蒂夫˙喬布斯（Steve Jobs）曾應邀前往史丹福大學的畢業典禮，發表了感人至深的演講。他以自己人生的三個重要片段為例分享了他對生命深刻的體悟和認知。生命沿途散落著的不起眼的點點滴滴日後都將串聯成不可思議的人生線索，只要你深信不疑，只要你勇敢跟隨，只要你取捨得當，多年後的某一天，當你回首往事，你會恍然大悟，也會很慶幸你一直以來，都和你的心同行！箇中一些苦不堪言、極難忍受的失敗和挫折，竟會是一份無法想像的禮物，當你打開層層包裝，你會看到生命的魔術和宇宙的微笑，但只有當你心無旁鶩、堅守真我，這份驚喜和圓滿才能前來拜訪。17 歲後的每一天，史蒂夫都以「如果今天是我生命的最後一天，我會去做我今天計畫安排去做的事嗎？」作為一天的開始，以人生必至的終點時時刻刻提醒自己、思考自己、反省自己，隨時修正人生的軌跡，永遠記得真我的目的，不浪費極其難得又極其有限的生命。演講的最後，他引用「The Whole Earth Catalog」雜誌的停刊寄語：Stay hungry，stay foolish！！（堅持飢渴的求知而不鬆懈自滿、堅持愚直的努力而不投機迎合）這既是給當時在座的所有史丹福的優秀畢業生的贈言，也是他多年來給自己的祝福和心願。若能不因所謂的聰明才智侷限自己、定型自己，不以世俗名利為重，不忘內心真正的渴望，縱使人生旅程中要不間斷地堅守被常人視為「傻子」般的選擇，也一定能由此發現成就自己、實現人生、圓滿旅程的真正無上的智慧和勇氣。 rn 

日本的江戶時代，有一位良寬和尚，一次渡河，撐船的人惡作劇故意將船左右搖晃，使良寬和尚最終失去平衡落入水中，又對良寬和尚在水中不斷掙扎的境況竭盡嘲諷之後才把他拉上船。一般人遭此作弄，一旦上船，不是爭吵便是爭鬥。豈料良寬和尚一上船，非但隻字不提也不追究被作弄之事，反而極其真誠地向撐船的道謝，感激他施予的救命之恩！置自己的屈辱於不顧，首先想到的是原諒和化解對方的無知無禮，絕對被一般人稱為「傻子」的良寬和尚擁有的是一個何等寬廣的心量和一份宇宙本性確切無誤的展現！ rn 

村上教授的友人大越俊夫在日本神戶經營一家私塾，名為「師友塾」。這是一家非常獨特的私塾，因為來這裡的學生都是「抗拒上學者」（注：「抗拒上學者」近年已成為日本越來越嚴重的社會問題之一）。三十五年的歲月中，「師友塾」已靜靜地接納了六千名以上的學生。在這裡，聚焦點不在於學業上的長進和突破，而是力圖康復有緣前來的每一位的創傷，調整培養他們不經學校體系也能自立生活的健全身心。已很多次應邀在「師友塾」演講的村上教授，每次去，每次看到那裡學生的開朗有禮、歡笑從容，每次都有很深很深的感動和感慨，因為這裡的每一個人都曾經是「抗拒上學者」，都曾經煩躁憂鬱、痛苦不堪，有些更有自殺的衝動和嘗試。不難想像，每位學生康復離去時，都會對「師友塾」和大越俊夫表示無盡的感謝，而大越每次卻都由衷地反過來感謝學生，因為他覺得是這裡的每一個學生、每一位員工讓他實現了充實幸福的人生。雖說緣起是為了給這些「受傷的心靈」提供一些康復，而在過程中大越覺得真正得到了康復的是他自己！日復一日的日常工作中，更不可思議的是，因為他日以繼夜地思考如何能更好地幫助學生、幫助員工，根本無暇顧及的個人煩惱竟然都神奇化解。大越俊夫常情不自禁地和村上教授分享他在經年累月中一再的心得和感動：當你為他人承擔時，你的煩惱會消失；當你為他人謀利時，真正受益的一定是你；當你不斷付出時，你所得之多無法想像！ rn 

二○○六年秋天在日本廣島召開了「國際和平會議」，出席者中有三位諾貝爾和平獎得主。因擔任大會主持，村上教授有幸能近距離地聆聽這些偉大的生命的教導。無論是來自南非的主教，還是北愛爾蘭的和平運動推進者，大家要傳遞的都是更不可思議、更意味深長的提醒和帶領：原諒惡待你的人、感謝惡待你的人！！超越習以為常的報復之心，修練為對方謀利的寬容之心，還要感謝他為你帶來的修行磨練的良機。如此驚人的度量和胸襟、如此透徹的智慧和勇氣！紛爭不斷、創傷不堪的現代社會究竟要待何時才能領悟教導、痛下決心、改弦易轍呢？ rn 

身為生物科學家的村上教授，研究生涯雖已長達半個世紀，但至今每一次注視著雙重螺旋狀的DNA的美妙精玄，每一次依然會有深深的讚嘆和無比的感動。這令人嘆為觀止的「生命的結晶」，並非人類獨有，而為所有生命共享，人和大猩猩的遺傳因子的差僅為 1.2％，人和稻穀之間竟也有 40％的相同之處！若如此顯然的生命間的息息相關尚且如此難以想像和接受，那超越人智的生命藍圖又如何得以實現和展示？   地球 38 億年的旅程是我們的縱向承接，各種生命共同擁有的藍圖和密碼是我們的橫向關聯，宇宙中的點點滴滴都互依互靠，缺一不可。當我們來到這個世界，我們暫現宇宙的生命個體；當我們離開這個世界，我們又重返宇宙的生命整體；當我們再次出現，也許已展現為一縷微風、一掌塵土、一枝樹木、一葉青草，較之我們暫居的這個三度空間，我們更需要學習和記得的是宇宙的「遊戲規則」，遠離得失計較，倒轉身心側重，不以自己為優先，而以他人為權衡，帶著勇氣，帶著智慧，盡心盡力在每一天了解和謀求他人的安樂，爭取盡早接軌「傻子思路」，完成「傻子功課」，回歸「傻子一族」，再次見證宇宙的種愛和你我的本源，讓我們久違的慈悲、智慧和康復將能如期而至。
