情感是亙古不變的話題，親情的血濃於水、愛情的忠貞不渝、友情的肝膽相照歷來為人們所感動、嚮往。人們或許也一直認為，人世間的情感幾乎可以用這三類情感所囊括，但其實在這三類情感之外，還有一類情感存在，它被人稱為第四類情感。

所謂第四類情感指的是徘徊於友情和愛情之間的一種情感，具體點說，就是比友情多一些，比愛情少一點的男女之情。在此類情感之間不能算是愛情，但卻有超過普通的友情，即男女之間真正的知己。

或許有人對此類情感不屑一顧，嗤之以鼻，認為這不可能，兩性之間怎麼可能有如此純潔之友誼，但亦有人認為有這種可能，稱此類感情可謂情感中的上品，對男女雙方都是一種驕傲。其實在這第四類情感當中又有幾種情況，有的是男方有這種情感，而女方則不是;有的是女方有這種情感，而男方想進一步發展為愛情;也有雙方都是這樣的情感，都把彼此當成自己最好的異性知己。他們一般稱女方為“紅顏知己”，稱男方為“藍(男)顏知己”。
