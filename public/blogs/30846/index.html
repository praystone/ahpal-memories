假如你是透明人，你會想做些什麼事呢??

✍️ chang1118 📅 2011-03-14

作者：chang1118

發文：2011-03-14

瀏覽：29 次 ｜ 回應：2 則

如果你是透明人，可以四處自由穿梭，無人能知道你在做什麼，擁有這樣無窮的力量，你會想做些什麼事呢？

  1. 偷竊貴重物品
  2. 四處搞破壞，做一些變態的壞事
  3. 接近傾慕的人
  4. 惡作劇，開些無傷大雅的小玩笑

解析：

  1. 偷竊貴重物品 你誠實，但野心很大，想吃下不少東西，不管是權位或是利益，你都不願放過。這些企圖也在主管的眼裡，不過，只要你是個人才，老板當然也不會虧待你。你必須先創造個人最大的優勢，盡力表現，先拿到高分，才有機會與人談判。可是也不能太過自滿，若是遇到不會惜才的老板，可能會想些法子來殺殺你的銳氣。

  2. 四處搞破壞，做一些變態的壞事 你自覺能力不錯，所以絕不願受任何委屈。如果有什麼差別待遇，你馬上就會大斥冤屈。不過，你也很會看人，會先觀察主管是屬於什麼樣的角色，才決定該不該叫屈。有時候，你也知道該先閉上嘴，好好做出一些成果來，然後在適當時機，再為自己爭取到應得的利益。

  3. 接近傾慕的人 你有點貪吃，不過，只在可允許的範圍內，你才會動手動口。平常時候，你會克制自己的欲望，即使覺得自己受到不公平的待遇，你還是會隱忍下來。對於上司，還是很尊敬對方的權威。你默默期待公理出現，相信只要一直努力，總會讓人發現自己的價值與貢獻。

  4. 惡作劇，開些無傷大雅的小玩笑 你好像是隱士高人，辦公室裡的鬥爭永遠都不會摻和上一腳，因為你根本就志不在此。每當到了人事變動的時候，你總是置身事外，毫不關心，因為不喜歡太復雜的人事鬥爭，所以不會特意表現。你很怕被卷入爭權奪利的漩渦中，寧可守著自己的工作，安安分分做個小職員。要升官的話，就得看你的上司有沒有這種眼光了。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />rn
