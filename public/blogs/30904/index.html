現代寓言：疾病七面觀

飛利浦‧<?xml:namespace prefix = st1 />殷可醫師（Philip Incao, M.D）  翻譯：洪美卿 rn 

  <?xml:namespace prefix = o /> 

 很久很久以前，在一個很遙遠的國度裏，七位學習康復之道的弟子來到他們敬愛的老師父跟前參加結業考試。睿智的老師父把弟子帶到一位病人的病榻前，就在那個時候，弟子們認識已久的病人咽下了最後一口氣，離開了人間。弟子們對著他的遺體，哀悼他的逝世。這時，師父發出了問題。 『親愛的弟子們，你們都認識這位病人，我們都為他的逝世感到傷心。每一個人都將死亡，然而，為什麼死神在這個時候把他帶走？他為什麼會死亡？』 這些學生都是該國度裏絕頂聰明的人。他們各自深思著老師父提出的問題，遲疑著不敢開口。最後，一位禪定良久的弟子說話了。 1.『尊師，承蒙您的教誨，日月星辰的古老智慧也剛給了我啟示。這位朋友的天命已盡，他已經完成了這一世的業報。他自己選擇了這條道路，他也秉承著上天所賦予的一切力量走完了這條路。靈魂以及身體的受用都有其侷限，那是他無法超越的。所以，他的神識離開了身體，去到更高的世界，開始創造一個新的身體，好讓他再次回來的時候，神識和靈魂可以繼續提昇。這是他的高層意願，也是上天賦予他的聖職。』 rn 

師父緘默不語，另一位弟子發言了，語氣有些不耐煩。 2.『是啊，是啊，』她說：『我們知道這與業報和輪迴有關，然而他之所以死亡，還有一個跟他的生活經歷更有關連的原因。』大家期待著她繼續講下去。『他的靈魂已經喪失了光芒，他對生活徹底失去興趣。他自暴自棄，完全失去了生存的意志力，所以，他死亡了。』 rn 

  1. 大家沉默地思考著她的論點。另一位弟子鼓起了勇氣，躊躇地發言：『大家都知道，在我們活著的時候，神識和靈魂固然對健康有很重要的影響，然而，眼前的情況是，他的肉身再也無法支撐他的生命。在他過世之前的好幾個星期，他的脈搏已經非常虛弱，我幾乎無法感覺到任何脈動。他的氣和生命力消耗殆盡，五臟六腑無法運作，腎上腺更是耗盡了，他精疲力竭，生命力和能量都致命地衰竭了。』 rn 

  2. 有好幾個弟子開口了：『是的，我同意，我同意。』其中一位說：『但是，我們卻忽略了最重要的一個因素：他的生活方式。他是一個天才，但是他卻完全把自己的健康置之度外。他大吃大喝，抽煙和大量使用藥品。他晝夜顛倒，晚上工作和狂歡，白天卻睡覺。女人們對他趨之若鶩，他也玩世不恭。他的生活大起大落，完全沒有規律。他也從不呼吸新鮮空氣，從不運動，他的生命力會消耗殆盡是不足為奇的。』                     rn 

  3. 弟子們更踴躍地發表看法了。『是的，他是一個耐人尋味，又充滿才華的人。』一個說：『他極端而且熱情，我們肯定會很懷念他。但是，我也認為他的生活方式搞垮了他的身體。我相信他的細胞和內臟都負荷過度，以致失去了呼吸、消化和自我凈化的功能。這會造成身體機能淤塞不通，造成細胞無法排毒。我很肯定他血液中的毒素遠遠超標。這就是奪命因素：他的身體充滿毒素， 衰歇了的器官無法排除身體的毒素， 因為再也無法排毒，所以他死了， 他死於中毒。』 rn 

  4. 其他的學生都七嘴八舌地，興致勃勃地發言。師父眼睛雪亮，但是始終保持緘默。又有一把聲音說：『是的，我們可以從他的舌頭和眼睛中看出他確實是中毒了，但是，中毒之後，一般又會發生什麼事呢。。。？感染！當然是感染！』他嚷道：『我們都很清楚，就像垃圾和糞便會引來蒼蠅，我們身體中的毒素和廢物也會引來無所不在的細菌和寄生蟲。 我很肯定他是死於感染，他曾經發高燒，他的身體已經腐壞。』 rn 

  5. 所有的弟子都發言了，除了其中一位。這最後一位弟子帶著欣賞的目光看著她的同修，然後，慢慢地，認真地說：『我無法反駁你們所說的每一個理由。但是，在研究了最新的研究報告後，我發現我們似乎忽略了這位朋友最終極的死因。是的，他受到了感染，他的身體腐壞了，但是，說到底，他的免疫系統才是真正的殺手。』 rn 

其他弟子都帶著懷疑的口氣嚷道：『這怎麼可能？這是不可能的！』師父臉上露出淡淡的一抹微笑，然而，他還是不說話。 rn 

最後那位弟子繼續說：『是的，直到最近，大家仍舊認為，除非患上自我免疫系統的疾病，否則免疫系統會時時保護我們。但是，現在科學界已經發現我們的免疫系統會製造化學份子，這些化學份子會傷害我們的身體甚至讓我們喪命。這些份子稱為細胞活素，它們有很多種類：幹擾素、白細胞介素和腫瘤壞死因子等等。 有些細胞活素會造成身體發炎或者加劇發炎情況，有些細胞活素則會在發揮了清洗功能後，抑制發炎 。 當我們身體的各個機能和諧地運作時，細胞活素會讓我們的身體恰到好處地溫和發炎，以消除過多的微生物，讓身體繼續發揮排毒功能，在這個過程中，身體不會出現症狀。 然而，水能載舟，也能覆舟。如果我們的免疫系統嚴重失調，抑或累積過多毒素，抑或受到感染，就會釋放出大量的細胞活素，造成血液中的細胞活素氾濫。 這會使得我們全身突然發炎，一發不可收拾地引起發高燒、敗血症性休克、全身中毒以及主要器官的機能出現嚴重障礙，以致死亡。這就是奪走我們的朋友兼病人的兇手。』 rn 

弟子們都沈默了，他們望著彼此，沈思著那一席話。 rn 

儘管不願意打破那內蘊豐富的沈默，老師父最終還是帶著深厚的感情說話了： rn 

『親愛的弟子們，你們所說和所想的讓我深深感動，也讓我欣慰。 儘管我才疏學淺，但是，我相信你們所說的都是正確的。 你們在老朽面前，列出了一系列造成人體敗壞的因素，你們的涵蓋面既深又廣，也包括了精神和肉體層面。在這種種因素中，我們發現人的精神，靈魂和生命力都可以在任何一個環節，通過不同的方式和諧地共鳴，以創造健康；也可能互相衝突，為身體帶來疾病。 rn 

你們可以下山到世間行醫了。 我的任務已經完成，現在，是你們向病人學習的時候了。 但是，請時時謹記你們今天所學習的疾病七面觀。 世間沒有一種疾病是由單一因素造成的。健康和疾病都是由多重因素造成的，你們不可以單靠一兩個因素來下判斷。 即使你們還無法看清所有的因素，你們也必須知道疾病是由方方面面的深淺因素造成的。這樣的覺知能夠使你們帶著謙遜的心為病人帶來真正的康復。』 rn 

於是，這七位弟子都通過了他們的結業考試，他們彼此告別，也告別了恩師，走向世界，向世人分享他們的康復之道。他們對自己知道多少還沒甚麼把握，但是他們要為病人帶來康復的心念非常堅定。他們從病人身上獲益良多，也治癒了很多人，他們對康復之道的瞭解與日俱增。
