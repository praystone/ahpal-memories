1826臺灣四百年人物誌之清朝時期(臺灣進士)05~曾維楨(開彰進士) 曾維楨，號雲松，清燕霧上保白沙坑莊(花壇鄉文德村)人，祖籍福建晉江，清嘉慶23年(1818) ，由臺灣府學附生中式戊寅科第三名舉人，道光6年(1826)丙戌科經魁中式，殿試<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />二甲第六十八名成進士，朝考選翰林庶吉士，爲清代臺灣首位玉堂人物，有「開台翰林」之稱。 曾維楨考取翰林的道光6年，位於現在彰化縣內的「東螺堡睦宜庄」賊匪李通，竊取粵人黃文潤豬隻所以互相拚鬥，不料卻演變成台灣中部的閩粵大械鬥，彰化縣粵籍客家人建立的客家人專屬市集「永靖街」還被焚毀。 西元一八二六年，彰化花壇鄉白沙坑子弟曾維楨，考取開台首位「翰林院庶吉士」功名，據傳曾維楨在參加御前殿試之際，清朝宣宗皇帝看見曾維楨背後站著一位白髮老翁，之後又立即消失不見，皇帝驚訝詢問，曾維楨答覆說，他僅攜帶家鄉土地公香火以保平安。 彰化縣，花壇鄉，曾維楨宅，這棟看似平凡的一條龍紅磚厝，在1826年可是出了一位進士，而且還是開台翰林，既然是名人故居，就記錄一下，說不定哪天就不見了。曾翰林的種種傳說中，最有名的應該是讓家鄉的土地公戴烏紗帽的故事，有機會不妨去看看這座香火鼎盛的文德宮。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
