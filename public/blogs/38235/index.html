臺灣四百年人物誌之清朝時期~曹瑾

臺灣四百年人物誌之清朝時期~曹瑾 根據《鳳山縣采訪冊》＜職官、知縣＞記載：「曹瑾（字懷樸，河南懷慶府河內縣人，嘉慶丁卯解元，丁丑會試大挑一等以知縣用），道光<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十七年正月二十五日任，十八年二月奉文准補，二十一年七月一日卸（有傳）。」 曹瑾公自幼聰穎，在生長的家鄉，經年累月看到農家如何充分利用充沛水源撫育農作物。因此，他在道光十七年蒞鳳山縣，正逢台嘉鳳地區前一年亢旱百餘華里的地區，農作物歉收，盜賊四起，飢民嗷嗷待哺之慘況，在他到任之初，已有耳聞，而如何令老百姓「足食弭盜」，正考驗這位初履鳳山縣父母官的智慧。 曹瑾公於道光十七年正月蒞任，立即下鄉巡視災情，並安撫災民。推算他在三、四月間巡至下淡水溪畔時，正逢春樹綠芽滿枝的季節，潺潺而流的下淡水溪，正呈現在他眼前，回憶他的故鄉河內縣勤奮的農民，如何克服地理障礙，而導引河水灌溉田畝，安居樂業。因此，他不禁感慨的說：「是造物者之所置，而以待人經營者，奈何前人置之而不理，毋乃暴殄天物歟！」於是著手鳩工度地，開鑿埤圳，才有今天享譽全台的「曹公圳」。 「曹公圳」灌溉區域遍及大高雄地區的鳳山、林園、大寮、大樹、仁武、大社、鳥松、鼓山、左營、楠梓、三民、苓雅、前鎮、小港等十四鄉鎮市區農田之外，也是早期供應大高雄地區二百萬人口飲用水的澄清湖自來水廠取水源頭（已上移至大樹鄉攔河堰）。曹公圳完工至今一百七十年，與大高雄民生、農業、工業息息相關。曹公圳灌溉系統，一直肩負農田灌溉、涵養水源、防止地下水位下降、防止海水入浸鹽化作用、防止地層下陷等功能；同時，曹公圳也支援大高雄地區民生用水。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

曹公圳 曹公圳是清代台灣的重要水利工程，由清朝鳳山縣令曹瑾主導築圳，費時兩年，於清道光十九年（西元1839年）完工，使原本屬於看天田的鳳山平原，一躍變成允水田；並使原來盜竊橫行的縣治，一夕形成民生富裕的樂園。曹瑾的上司熊一本因此將圳渠命名為「曹公圳」，曹公也因而被史家公認為治績最優良的縣長。本水門是曹公圳原來的制水門，俗名「五孔頷」，又名「曹公圳頭」。日治時期，曹公圳重修，另設鋼筋水泥閘門，與舊水門並存，其檜木制水板尚存。光緒年間重修之曹公舊圳制水門為五座圓拱門，進水孔前端設有船形座墩。日治時期新建的水門為鋼筋混凝土造，水門形狀則改為方形。進水口前端，砌有磚材船首型護礅，其形制保存完整，惟大部分已埋入淤土中，僅露出平頂部分，目前結構仍甚完好。入淤土中，僅露出平頂部分。目前結構仍甚完好。
