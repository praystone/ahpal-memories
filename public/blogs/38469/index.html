一封寫給自己的信

✍️ shakespear 📅 2011-04-09

作者：shakespear

發文：2011-04-09

瀏覽：54 次 ｜ 回應：2 則

 

&nbsp;


一封寫給自己的信，看了有點心酸···


&nbsp;


親愛的自己，從今天起為了自己驕傲的活著吧，好好愛自己，沒有人會心疼你。 



&nbsp;


親愛的自己，不要太在意一些人太在乎一些事，順其自然以最佳心態面對，因為這世界就是這麼不公平往往在最在乎的事物面前我們最沒有價值。 



&nbsp;


親愛的自己，永遠不要為難自己，比如不吃飯、哭泣、自閉、抑鬱，這些都是傻瓜才做的事。 


&nbsp;


親愛的自己，學會聰明一點，不要老是問周圍的人一些很白癡的問題，那真的是很無聊。 



&nbsp;


親愛的自己，如果不開心了就找個角落或者在被子裏哭一下，你不需要別人同情可憐，哭過之後一樣可以開心生活。 


&nbsp;


親愛的自己，學會控制自己的情緒，誰都不欠你，所以你沒有道理跟別人隨便發脾氣，耍性子。 



&nbsp;


親愛的自己，你可以失望但不能絕望，你要始終相信，tomorrow is another day. 


&nbsp;


親愛的自己，你不要老是想依賴別人，更不能奢望別人在你需要的時候第一時間站出來，畢竟你們誰都不是誰的誰。 



&nbsp;


親愛的自己，永遠不要輕易對別人許下承諾，許下的承諾就是欠下的債！ 


&nbsp;


親愛的自己，這個世界只有回不去的而沒有什麼是過不去的。 



&nbsp;


親愛的自己，別人對你好，你要加倍對別人好，別人對你不好，你還是應該對別人好，因為那說明你還不夠好。


&nbsp;


親愛的自己，不管現實有多慘不忍睹你都要固執的相信這只是黎明前短暫的黑暗而已。 



&nbsp;


親愛的自己，不要抓住回憶不放，斷了線的風箏，只能讓它飛，放過它，便是放過自己。


&nbsp;


親愛的自己，全世界只有一個你，就算沒有人懂得欣賞，你也要好好愛自己，做最真實的自己。 



&nbsp;


親愛的自己，好好對待陪在你身邊的那些人，因為愛情可能只是暫時的但友情是一輩子的。


&nbsp;


親愛的自己，你必須找到除了愛情之外，能夠使你用雙腳堅強站在大地上的東西。 



&nbsp;


親愛的自己，記得要常常仰望天空，記住仰望天空的時候也要看看腳下。


&nbsp;


親愛的自己，相信你的直覺，不要招惹別人，也不要讓別人來招惹你。 



&nbsp;


親愛的自己，永遠不要跟別人搞曖昧，因為你玩不起！


&nbsp;


親愛的自己，不要太低調了，有時要強悍一點，被欺負的時候，一定要討回來！但是一定不要記恨，小人之見隨他們去好了，憐憫會使你高貴。 



&nbsp;


親愛的自己， 要快樂、要開朗、要堅韌、要溫暖，這和性格無關。


&nbsp;


親愛的自己，要自信甚至是自戀一點，時刻提醒自己我值得擁有最好的一切。
