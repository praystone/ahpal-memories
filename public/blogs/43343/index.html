1889臺灣四百年人物誌之清朝時期(臺灣進士)25~丘逢甲 丘逢甲（1864年12月26日－1912年2月25日），本名丘秉淵，又名倉海，字仙根，號蟄仙，是一位台灣詩人和教育家，台灣苗栗銅鑼灣客家人，祖籍嘉應鎮平（今廣東蕉嶺）。擅長詩文，著有《嶺雲海日樓詩鈔》(本書約收錄一千六百多首古今體詩)。 生平 1864年出生於福建省臺灣府淡水廳後壟堡銅鑼灣（今台灣苗栗縣銅鑼鄉竹森村，即銅鑼李家）。 1889年丘逢甲至北京考中進士，被任為工部主事。但丘逢甲無意在京做官返回台灣，到台灣台中衡文書院擔任主講，後又於台灣的台南和嘉義教育新學。1895年甲午戰爭後，1895年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />4月17日李鴻章與日本簽訂馬關條約，割讓台灣，台灣人民激憤，丘逢甲堅持反對並組織義軍反抗。 1895年5月23日，唐景崧發表「臺灣民主國獨立宣言」，宣稱「台灣同胞誓不服倭，與其事敵寧願戰死……」。而後於1895年5月25日臺灣民主國成立，唐景崧出任總統，劉永福為大將軍，丘逢甲為義勇軍統領，年號「永清」。隔日，國會議長林維源逃亡至中國大陸福建省廈門。 在5月29日乙未戰爭掀起戰端，6月4日總統唐景崧棄職逃亡福建廈門，鎮守北台灣的正規軍潰敗。其後丘逢甲見局勢不可為，攜帶家眷內渡廣東嘉應州。或有謂其挾帶巨額公款而行；但因無實據，亦有持不同意見者，迄今仍無定論。 其後雖有名將劉永福率領的黑旗軍及吳湯興、姜紹祖、徐驤等人率領的諸多民間義勇軍奮起抗日，但由於裝備及訓練均遠不如日本，終究於10月21日被日軍攻入大本營台南，臺灣民主國因而滅亡。 丘逢甲內渡後在廣東任興民中學首任校長，中華民國建國後，丘逢甲被選為廣東省代表參加孫中山組織的臨時政府。 紀念<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

1961年臺灣中部地區仕紳由丘逢甲之子丘念台及楊亮功等議在中部地區興建一所大學，為紀念丘逢甲而命名為逢甲工商學院。1961年，正式創建於臺中市北屯區，而後遷往西屯區現址，1980年改制為逢甲大學。 2006年5月，丘逢甲在廣東省蕉嶺縣文福鎮逢甲村的故居被國務院核定為全國重點文物保護單位。 歷史評價 正面評價 丘逢甲少年得志，卻棄官返台從事教育工作；已未割台時，他首倡獨立抗日；內渡大陸後則獻身推廣新式教育，為國家培養元氣。終其一生始終對國家抱有高度的期望，具有強烈的愛國情操。 丘逢甲的詩文曾獲得諸多學者高度的評價：錢仲聯曾評其《嶺雲海日樓詩鈔》曰「七律一種，開滿勁弓，吹裂鐵笛，真成義軍舊將之詩。」柳亞子謂「時流竟說黃公度，英氣終輸倉海君，戰血臺澎心未死，寒笳殘角海東雲[11]。」梁啟超則譽為「詩界革命钜子」、「天下健者」。 負面評價 1895年反割台運動期間，丘逢甲雖首先刺血上書反對割台，爾後卻提前內渡，其前後言行不一，實際表現未盡理想，使後人稍有微詞。連雅堂在《台灣通史》便作總評為「成敗論人，吾所不喜，獨惜其為吳湯興、徐驤所笑爾。」 丘氏內渡之際，有謂其挾帶巨額公款而行；但因無實據，亦有持不同意見者，迄今仍無定論。 親屬 子丘念台 因在清雍正年間，「丘」改成了普遍常見的「邱」姓，故丘逢甲後代子孫姓「丘」或「邱」。 其兄邱先甲，於臺灣割讓日本後一起返回廣東，後又遷回臺中市，開墾現在臺中市北屯區大坑一帶，現有邱先甲墓園於臺中國際高爾夫球場南面，2005年經臺中市政府列為歷史建築。 姪子邱欽洲曾任第四屆臺中市市長 姪女陳邱阿慎（邱欽洲的姐姐）曾任台中市議員，其夫陳彩龍曾任臺灣省臨時省議會第三屆議員，其子陳端堂曾任第七屆臺中市市長(其子陳文憲為亦是曾任臺中市市長張溫鷹的夫婿)。

 

丘逢甲的冥婚

丘逢甲是一位愛台抗日的志士這是大家都知道的,可是他有一段冥婚我想可能知道的人不多 所以就把這段故事po上來跟大家分享: 丘逢甲小時候曾經與台灣望族林獻堂的妹妹訂婚，丘逢甲的冥婚但不幸的是，林小姐還沒有過門就病逝了。當時瘑瘧瘉皸，熂熉熗熅丘逢甲正好要到大陸赴京趕考，便隨同父親搭船渡海前往大陸。船隻經過台灣海峽州幔廕廎廗，銗銖銪銋忽然聞風浪大作，船隻在浪中搖擺不定。丘逢甲忽然看見一個少女站在水面上靼靺鞃鞀，酲酺酹酸兩眼淚汪汪地看著他。丘逢甲大驚，趕緊告訴了父親。他的父親認為她就是林家小姐榤榨槏榽，維綼綪綱於是出艙對著大海說：“假如你死後心情不能平靜，沒有安身之地，害怕沒有後代祭祀你，那你就保佑逢甲考上進士，等到功成名就之時，馬上回台灣迎娶你為丘家的媳婦。“果然風浪平靜了下束，船隻平安地到達了廣東。丘逢甲進京趕考，果然中了進士。返回台灣以後，丘逢甲不毀前言，如約迎娶林家小姐的牌位，以冥婚方式娶她為妻。
