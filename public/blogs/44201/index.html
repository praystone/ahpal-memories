1895臺灣四百年人物誌之日治時期~乙未戰爭之~唐景崧

1895臺灣四百年人物誌之日治時期乙未戰爭之唐景崧 唐景崧（1841年－1903年），中國清朝政治人物，字維卿，廣西灌陽人。台灣末代巡撫。1895年出任台灣民主國總統。 生平 1865年（同治四年）進士。選庶起士，授吏部主事。 1882年，法國與越南發生衝突，河內、南定等地相繼失陷。唐景崧赴越南招劉永福黑旗軍，進兵河內，格斃法國將領安鄴（Francis Garnier）。次年勸劉永福內附。以功賞四品卿銜。1884年中法戰爭時率「景字軍」迎戰法軍有功，賞花翎，官昇二品。 1891年出任台灣布政使司，1894年接替邵友濂出任台灣巡撫。 1895年4月17日，李鴻章與日本簽訂馬關條約，割讓台灣，民眾激憤，上書景崧：「萬民誓不服倭，割亦死，拒亦死，寧先死於亂民之手，不願死於倭人手。」。 1895年5月23日，唐景崧發表「台灣民主國獨立宣言」，宣稱「台灣同胞誓不服倭，與其事敵寧願戰死……」。 1895年5月25日台灣民主國成立，唐景崧出任總統，丘逢甲為副總統兼台灣義勇軍統領，劉永福為大將軍，年號「永清」。隔日，國會議長林維源逃亡至中國廈門。 1895年6月2日，李經芳在台灣基隆外海日本軍艦上正式與日本海軍大將樺山資紀辦理交割事誼。6月3日日軍攻陷基隆之後，唐景崧於6月4日化妝為老婦[來源請求]，帶著官銀先逃至滬尾（現今台灣淡水）德商忌利士洋行（Douglas），後來乘德國籍輪船鴨打號（Arthur）棄職逃亡中國廈門。丘逢甲得知唐景崧逃走，亦攜帶公款<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十萬兩逃亡中國廣東嘉應州(現今中國廣東梅縣)（臺灣通史稱「景崧未戰而走，文武多逃，逢甲亦挾款以去，或言近十萬雲。」）。日後唐景崧以抗命見黜。 1903年卒於家。 唐景崧孫女唐簣女士是史學家陳寅恪妻，當時胡適的父親胡傳也是台東知縣（於8月15日離台）；1931年9月，胡適曾寫了一首詩《題唐景菘先生遺墨》給陳寅恪：「南天民主國，回首一傷神。黑虎今何在，黃龍亦已陳。幾枝無用筆，半打有心人，畢竟天難補，滔滔四十春」。 文學 在台期間，頗好文事，聘進士施士潔主講海東書院，建萬卷堂，藏書富，飭纂《台灣通志》，自為監督，未成而遭割台之役。任兵備道，修葺舊有斐亭，組「斐亭吟社」，自撰楹聯懸掛亭柱，每逢春秋佳日，與台南進士、文人於道署內射虎助興，後有《謎拾》問事，附於《斐亭詩畸》卷內，《澄懷園唱和集》是唐景崧及其僚友平日吟詠唱和之詩，為唐贊袞所輯。及任布政使駐臺北，又時邀名士吟詠於官署，詩會時曾由海上運來數十盆牡丹，遂名為「牡丹詩社」，亦多作詩鐘。光緒19年（1893）1月取歷年唱稿，分門編輯，錄佳作十卷，命名《詩畸》，為台灣詩鐘選集之濫觴，內景崧作品1301聯，律詩68首，另包括宦台及本省名士佳作，如進士施士潔、丘逢甲、汪春源、林啟東及淡水舉人黃宗鼎等56人之作品。唐景崧在台南及臺北帶動地方文風，有功於詩歌傳播。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
