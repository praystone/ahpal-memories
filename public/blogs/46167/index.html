(轉載)CSS基礎教學

前言：

CSS(Cascading Style Sheets)是一種樣式表語言。它的目的是為了對像 XHTML 及 HTML 之類的標記語言 (markup language) 提供一個顯示層。有了 CSS，我們就可以將資料層及顯示層分開：HTML 文件就只包括資料，而 CSS 則是告訴瀏覽器這些資料應該要如何顯現出來。(資料來源)

序言：

在此提供CSS的基礎語法，逐一解說，只需花你幾個小時的時間，就能讓你的個人空間看起來漂漂亮亮的，切勿抄襲別人的CSS作品。CSS語法難度的等級比程式語言還簡單，但是也不是一步就能登天，有耐心點一步一步的操作，如果這種語法一天就能全部學會並融會貫通，那大家都不會找不到工作了，所以請耐心看完，如果你想要讓你的主頁變漂亮的話。

CSS的語法結構：

選擇器 子選擇器 { 屬性1: 設定值1 ; 屬性2: 設定值2 ; …(以此類推); }

選擇器：簡單說就是你個人主頁想改的地方都有所謂的標籤語法，例如".comments_list"指的是留言版評論的列表，也就是個人主頁最下方。

子選擇器：若是在".comments_list"後面加上".quote"(引用的意思)，就變成".comments_list .quote"，所指定的就變成留言版引用樣式。子選擇器為非必要，通常用於更改更詳細的部分才需要。

屬性與設定值：例如想更改文字的顏色成紅色，想更改屬性就是文字，其設定值為紅色。

注意：CSS的語法其屬性與設定值必須被大括弧包含起來，且每個屬性與設定值設定完成都必須用分號做結束！

區塊：指整個語法宣告的結構，例如在HTML語法中把"甲"這個字變成粗體，語法是"<div><b>甲</b></div>"，這整個統稱為區塊，會自動換行。會顯示成以下這樣：

甲

這樣看來，圖片也是區塊；網頁分頁也是分成很多的區塊，就這個日誌來看，最上面有首頁、個人主頁到右邊的有積分的這個橫條，就是一個區塊；左邊的菜單也是區塊；文章的段落"<p>甲</p>“也是區塊；表格(Table)也是區塊；輸入東西的欄位如輸入記錄那邊也是區塊。

附註：如果有數個選擇器都有相同的樣式，例如我想要暱稱、記錄、留言字都是紫色的，就能一次宣告所有選擇器，選擇器間須用逗號”,“隔開。

e.g. 選擇器1, 選擇器2, 選擇器3 { 顏色: 紫色 ; } (在此只是範例，宣告須用英文。)

CSS的語法建議：

1.中文註解或是不想被執行但想保留的語法都可以用”/**/“所包含，系統偵測”/“到”/“中間的語法或字串並不會被執行。

2.CSS語法並不會受到空格所影響，當然，語法與語法間的空格是必須的。原則上，英文的句子如果在標點符號後面，要空一格；語法與大括號之間也習慣空一格。

3.如果重複宣告CSS語法，則會取後者作為結果，比方說先前設定超連結顏色為紫色，最後又不小心設定到超連結為藍色，同樣的選擇器和屬性，只是設定值不相同，最後超連結會是藍色的，特別注意這點。

4.如果本人列出的語法下面說明了預設的設定值為何，假若你喜歡伊莉預設的樣式，你將可以捨棄語法內的與預設相應的"屬性: 設定值;“這段語法。

5.伊莉的自定義風格有限制字數，所以最好在最下面加上幾行註解如”/Buffer/"，免得最下面的語法因為字數超過而消失，緩衝行數的減少告知你字數不能再增加了。

6.如果認為本人寫的看不太懂，可以參考其它人的傑作，本人由這學習的，並請記得表態、推文，讓更多人知道謝謝。

簡易CSS的語法樣式：

※這邊只列出最簡單的語法樣式，有些英文不會可以去奇摩字典查，通常很容易了解。

背景部分：

選擇器 { background: #000000; } 在這選擇器代表的區塊其背景是黑色的。

選擇器 { background: url(網址) fixed; } 在這選擇器代表的區塊其背景來自於你的相簿的某個圖片，並且圖片完全固定於瀏覽器視窗的邊框，也就是說背景圖片不會因為你拉移瀏覽器最右方的捲軸而有所改變，“fixed"也可以代換成"no-repeat”。

選擇器 { background: url(網址) fixed center; } 這裡背景不但固定，而且置中。

顏色部分：

選擇器 { color: blue; } 這代表選擇器代表的區塊其文字都是藍色的

注意：顏色的表示方法有三種：

  1. 選擇器 { color: blue; } 直接指定顏色的英文名稱，查詢顏色名稱。

2. 選擇器 { color: #0099FF; } 直接指定色碼，查詢簡易色碼表。

3. 選擇器 { color: RGB(0,100,0); } 直接指定三維陣列代入256色，第一個參數是紅色，再來是綠色，最後是藍色，唯一要注意的是：參數值是從0開始計算，0代表第一個元素，255代表第兩百五十六個元素，因為從0數到255有256個數字(索引(index))。另外，這三個參數也可以用0%~100%表示。例如：RGB(30%,20%,63%)。

盒子部分：

請參考我的個人主頁，“Margin”(邊界)指的是整個瀏覽器能顯示網頁的邊界，“Border”(邊框)指的是我個人主頁橘色虛線的部分，“Padding”(留白)指的是"邊界"與"邊框"的中間部分，最後"Content”(內容)指的是"邊框"以內的部分，也就是本個人空間(網誌)的重點。關於詳細語法將在最下面補充。這邊是舉例主體，但是任何區塊都有邊界、邊框、留白和內容，比方說留言版。

文字部分：

選擇器 { font-family: Georgia; } 

後面的設定值可以替換為"Verdana",“Arial”,“Helvetica”,“sans-serif”,“細明體”,或"標楷體"……等等，每一樣都試試看，找到你喜歡的字體吧！

附註：更多CSS的語法樣式在最下面。

伊莉的CSS選擇器(或稱元素)：

※注意：

1.這邊開始按部就班更改你的CSS語法，前面只是簡易說明，並沒有實際操作。這邊補充一下：打語法的地方在你的主頁右上角有個"設置"的選項，點了之後出現新的網頁找到"個人設置"的選項，再按了之後找到"自定義風格"，這就是編輯語法的地方。

2.以下所有範例都將依我的主頁為準，可以參考我的主頁，不過有些可能已經不一樣了，特別注意一下，另外，藍色字體都為語法或註解，如有錯誤請幫忙指正，謝謝。

3.如果遇到語法不懂，可以到最下方的"補充CSS的語法樣式"找找看，或是在Google或雅虎的搜尋器打上「“border” CSS」搜尋，假如想要搜尋"border"的CSS相關語法的話，應該可以找到你要的答案，畢竟CSS語法很多網誌都有用，雖然選擇器(或稱元素)不太相同，但是屬性和設定值幾乎是一樣的。

1.更改個人空間的主體、副版面的區塊與背景圖案(“body”&“wrap”)：

/主體與背景圖案/

body { padding: 0 0 50px; background: url(網址) fixed; color: #FF783C; }

“body"就是整個個人空間你可以看到的地方都算是。

“padding: 0 0 50px;“可以讓最下面的留白(Padding)部分(例如我的主頁最下方的橘色虛線)往上抬移50個像素，沒有這樣做的話，最下面的邊框(Border)會看不見。

“background: url(網址) fixed center;“可以讓你的背景圖案固定且置中，另外，如果要找自己相片的網址，到自己的圖片點選查看原圖，會出現新的只有圖的視窗，那個網址就是你要的。

“color: #FF783C;“讓你的整個內容(Content)的文字，也就是整篇網頁非超連結的所有文字，都改成橘色類。

顏色、網址、留白抬移多少像素請依個人喜好修改。

/副版面/

#wrap { margin-top: -10px; padding: 15px 10px; border: 2.5px dashed #FF783C; background: transparent; }

“wrap"就是個人空間(網誌)中間最重要的部分，簡單說就是從ID、暱稱、訪問人次、記錄、個人資料、個人動態到留言版這一塊版面，包括左邊的個人菜單和右邊的最近來訪，姑且稱為主體的副版面。

“margin-top: -10px;“指的是我把橘色框線所包起來的區塊(副版面)往下移動-10個像素，正確說來就是往上移動10個像素。

“padding: 15px 10px;“指的是主體的留白部分往上移動15個像素，再往左移動10個像素，有關padding的所有用法將在最下面補充。

“border: 2.5px dashed #FF783C;“指的是我個人主頁的橘色虛線，厚(寬)度2.5個像素，“dashed"是虛線，"#FF783C"是橘色，如果不要虛線就刪掉"dashed”，預設為直線，如果整個border都不要，就改成"border: none;“即可，之後有關於任何的邊框不需要，就在語法加上"border: none;"。關於線的形狀將在最下面補充。

“background: transparent;“指的是副版面的背景設定為透明的(transparent)，因為主體已經有背景了，當然你仍可以放背景或是指定顏色，請依個人喜好自行調整。

/副版面大部分的橫線/

#spaceindex_name, #space_feed li, #space_page .line_list li, #space_page .comments_list li { border: none; }

個人將它設定成不顯示，當然，如果你的背景太花，導致字看不夠清楚，橫線可以作陪襯來呈現段落文字。

/副版面的所有橫條/

#space_page #ubar h2, #space_page .feed_header, #space_page .sidebox h2.title { background: transparent; text-align: center; color: #FF5AF0; font-size: 1em ; border-style: outset; border-color: #FF5AF0; border-width: 5px; }

“background: transparent;“可以更改橫條的背景，當然可以使用圖片，只是要注意大小，或是可以藉由更改相框的大小，至於如何更改，下面講到”/頂部中間的圖案/“會詳細說明，本人將橫條背景設定為透明！“text-align: center;“可以把文字置中，預設是靠左。可改文字大小、字體、顏色，本人將顏色設定成紫色，請依個人喜好修改。“border-style: outset;“這是改邊框的，我將它設成浮凸，顏色為紫色，寬度為5個像素。有關邊框(Border)的詳細語法補充將在最下面說明。

/主頁的所有顯示時間的數字或文字/

#space_page .gray { color: #0078F0; }

更改主頁所有顯示的時間數字或文字的顏色、字體，或是說有灰色字的部分，例如"kejsu160913 去自己的 開心農場 辛勤工作了一番 5小時前"的"5小時前”，另外留言、日誌發表等等，還有相簿的簡易說明都會更改到喔。

3.更改個人空間的頂部區塊("#header”)：

/頂部橫條顏色或背景圖案/

#header { background: transparent; }

#header .headerwarp { background: transparent; }

這邊就是指從首頁、個人主頁、好友到道具、設置、退出那整個橫條，本人把它用成透明的，這樣就只能看到主體的背景，這邊仍可放背景或改背景顏色，"#header"與”#header .headerwarp"似乎是一樣的。

/頂部的圖案/

#append_parent { background: url(網址) no-repeat center; height: 100px; width: 100%; }

這邊就是指頂部橫條下方(或上方)的圖片，或是有用中國年的風格就清楚了。此區有什麼功用呢？你可以放圖片，或是放個文字圖片作公告用(就是在Word檔打個文字用鍵盤上"PrintScreen"照下來，再貼到小畫家存成JPEG檔案。)我的頂部圖案是好幾行紫色的字，背景是透明的，你可以使用影像處理軟體將背景用成透明的，再存成GIF檔，網路搜尋很容易找到這樣的教學。

注意：圖片放入的概念跟日常生活中把相片放入相框的意思是一樣的，通常相框的大小是預設的，也就是說如果你圖片的高度或長度太長會被剪掉，所以可以定義你要的相框大小。另外，相框也可以作移動，這部分用到的是"Margin”(邊界)這個屬性，將在最下面補充。相框的大小如何定義呢？“width: 1024px; height: 100px;“前者為寬度，後者為高度，“px"是像素，這類語法都是一樣的，之後將不贅述。

“height: 100px;“指的是我的相框高度是100個像素，這樣我插入的圖片高度剛好契合。

“width: 100%;“這邊提供不同的方法，此指將相框寬度設定成瀏覽器視窗寬度的100%(也就是完全相等)，但是展示的方式有點不同，圖片是由左邊插入相框的，記住這邊是調整相框，所以圖片大小並不會有影響。換句話說，如果我設定成"width: 60%;"，相框是緊貼於左側的(如果沒用移動的語法)，整個相框的寬度占瀏覽器視窗的60%，而圖片從左邊插入後，圖片的左邊40%的部分自然被截去。這有什麼用呢？有時候你想讓圖片多餘或礙眼的部分截掉，然後用"margin"的語法讓相框移動，或用"center"將其置中，找到你喜歡的位置。

就是設定以下兩個講的超連結。

#header ul.menu { background: transparent; position: absolute; left: 30px; }

(就是我啦！咬我呀！)

你可以改掉這個區塊的大小，包括寬度"width”、高度"height”。如果你想移動這個區塊，讓其靠左，要先加上"position: absolute;"，改成絕對位置，絕對位置當然需要一個基準點囉！這個區塊的基準點(也就是其父選擇器或父元素)就是整個"body”(主體)。如果想讓這個區塊靠左側，就加上"left: 30px;"，30個像素表示這個區塊靠左但離最左邊有30個像素的距離，如果0像素表示緊貼於左側。想緊靠右側就換成"right: 0px;"，不過這行語法給下一行的選擇器使用較好。

補充CSS的語法樣式：

以下的語法少有圖例，大多以例子的方式呈現，教學在先前皆有說過，尤其式顏色的部分，先前講得很清楚了，故不再說明，其它的可以自己試試看。

長度(Length):

像素"px”、拉長"ex"和大小"em”，還有一些絕對的單位，公分"cm”，公釐"mm"和英吋(inch):“in”，別問有公尺嗎，長度單位可用於字體、相框等等。

/e.g. 字體大小7em/ 選擇器 { font-size: 7em; }

超連結(Hyperlink):

“a:link"指的是超連結未被點過的樣式；

“a:hover"指的是超連結被滑鼠游標覆蓋的樣式；

“a:active"指的是超連結正在被滑鼠點擊的樣式；

“a:visited"指的是超連結被點過的樣式。

/e.g. 被點過的超連結呈現暗紅色/ 選擇器 a:visited { color: darkred; }

盒子(Box):

這邊再提醒一次：請參考我的個人主頁，“Margin”(邊界)指的是整個瀏覽器能顯示網頁的邊界，“Border”(邊框)指的是我個人主頁橘色虛線的部分，“Padding”(留白)指的是"邊界"與"邊框"的中間部分，最後"Content”(內容)指的是"邊框"以內的部分，也就是本個人空間(網誌)的重點。

邊界(Margin)與留白(Padding):

“margin-top"指上邊界；“margin-right"指右邊界；“margin-bottom"指下邊界；“margin-left"指左邊界。Margin是設定與元素之間的距離，例如我們說body(主體)的margin(邊界)，其意指body(主體)與#wrap(我主頁橘色虛線內的副版面)之間的距離。換句話說，這之間的距離也叫Padding(留白)，所以當你設定body的margin和設定body的padding結果是一樣的。

/e.g. 主頁的上邊界往上抬升100像素/ body { margin-top: 100px; }

/e.g. 其實上述也等於下邊界往下降-100像素/ body { margin-bottom: -100px; }

/e.g. 左邊界設定為自動(系統自動調整)/ body { margin-left: auto; }

/e.g. 右邊界設定為原本的120%(增加20%)/ body { margin-right: 20%; }

有一個辦法可以全部一行宣告完成：

選擇器 { margin: 上 右 下 左; }

/e.g./ body { margin: 0 0 20px 30px; }

“padding-top"指上方留白；“padding-right"指右方留白；“padding-bottom"指下方留白；“padding-left"指左方留白；一次宣告：“padding: 上 右 下 左;“意思一樣。

注意：要用margin就使用margin，最好不要混用，否則想改版面的時候，會感到紊亂。

邊框(Border):

“border-style"是指邊框的線條樣式，設定值有實線"solid”，虛線"dashed”，雙線"double”，點線"dotted”，凹線"groove”，凸線"ridge”，凹入線"inset”，浮凸線"outset”。

“border-width"是指邊框線條的寬度，設定值可以是像素"px”，或是薄"thin”、中"medium"和厚"thick”。

“border-color"是指邊框的顏色，設定值先前說的很明白了，可以回去參考。

另外可以在語法中間加上「上右下左」，“border-left-style"表示左邊邊框的線條樣式，其它寬度和顏色也可以如此宣告。本人主頁的副版面的是橘色虛線。

也可以如此宣告：“border: 寬度 樣式 顏色;"。

#wrap { border: 2.5px dashed #FF783C; }

當然，可以麻煩一點…

#wrap { border-width: 2.5px; border-style: dashed; border-color: #FF783C; }

字體(Font)：

“font-family"可以改變字體的樣式，其設定值有"Georgia”、“Verdana”、“Arial”、“Helvetica”、“sans-serif”、“細明體”、“標楷體"或"隸書”，當然一定還有不少，可以自行找。

/e.g./ 選擇器 { font-family: 標楷體; }

“font-size"可以改變字體的大小，其設定值有像素"px”，放大縮小百分比”%"，絕對長度"cm”(還有先前有獎過的"mm"和"in”)，或是直接設定大中小"large”、“medium”、“small”。

/e.g./ 選擇器 { font-size: 200%; }

“font-weight"可以改變字體的厚度，其設定值可為"bold”(即改為粗體)，或是用值表示(100~900)。

/e.g./ 選擇器 { font-weight: 350; }

“font-style"可以改變字體為斜體，其設定值可為"italic"或"oblique”。

文字(Text)：

“letter-space"可以用來設定字與字的之間的距離，其設定值為像素"px”。

/e.g./ 選擇器 { letter-spacing: 10px; }

“line-height"可以用來設定行與行之間的距離，其設定值仍為像素"px”。

/e.g./ 選擇器 { line-height: 20px; }

“text-align"可以用來對齊字串，其設定值有向左對齊"left”，向右對齊"right”，置中對齊"center”，左右分散對齊"justify”。

/e.g./ 選擇器 { text-align: center; }

“text-decoration"可以用來裝飾文字，其設定值有加底線"underline”，加頂線"overline”，加刪除線"line-through”。

/e.g./ 選擇器 { text-decoration: underline; }
