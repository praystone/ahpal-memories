統計學老師

 

 

 

一位在某大學任教的統計學老師

 

與其說他是仙人，不如說他很機車。

第一次上課時－－

 

老師：「上我的課，你們可以很輕鬆，

 

要吃早餐的可以，但要吃得營養：

 

基本上除了牛排、我不想看到有人在吃別種食物；

 

要睡覺也可以，但是一定要蓋棉被….」

 

同學：「-_-’….」     ( 哪裡??   銹逗!! )

 

老師：「我唯一比較在意的是：

 

手機一定要關機，因為我絕對不允許

 

有人打擾那些正在睡覺的同學。」

 

同學：「O_o’….」   ( 啥米??  碗跪~~ )

期中考時，大家都各自忙著作答。

 

下課鈴聲響起後，有一個學生神情慌張的

 

在考卷下塞了1000元，外加一張紙條，

 

上面寫著「10元1分」，

 

還很得意的對老師比ok~的手勢，

 

老師也對學生比了ok…  ^____ __^|||  

 

下一次上課時，老師發考卷，該生心想：

 

這次考試一定是100分的啦！

                                                                                               

沒想到老師給了他一張59分的考卷和410元。…= =|||  

 

 

微積分老師 

某天，一位同學跟微積分老師說：

 

「老師啊！我今天心情很不好耶！」

 

老師就說：「那我幫你用微積分來卜卦看看！」

 

然後要求同學寫幾個字。

 

同學寫了「麻煩」兩個字。老師看了之後，

 

笑笑的說：「你一定是被爸媽罵了！」

                                                         

 

同學說：

 

「哇！老師啊！你怎麼那麼厲害？一下就知道了！」   老師說：「你別急！我慢慢解釋給你聽－－

 

首先，我們用一次微分，

 

把『麻煩』的『麻』字的蓋子去掉，

 

不是就剩下『林』了嗎？

然後用二次微分，把『煩』這個字的『火』去掉，

 

再把剩下『頁』這個字的頭頂也去掉，

 

不是就剩下『貝』了嗎？

 從『林貝』就可知你被你爸爸罵了啊！

 

還有，剩下的『貝』，你再一次微分，

 

把下面去掉，就得到『目』，

 

那麼『林目』就說明你也有被你媽媽罵囉！」    這位同學聽了之後，

 

當場 ……. #@@$%&*!~

親愛的你/妳 今天  …  被碎碎唸了嗎? …●︿●
