桑椹蒟蒻凍

材料

1.      蒟蒻粉（海藻萃取物）3大平匙

2.      細冰糖或二砂糖（依自己的口味）

3.      溫開水（550 C.C.）

4.      桑椹果汁或吟香梅汁——-等（500 C.C. ）

作法

1.      將蒟蒻粉加入溫開水拌勻。

2.      細冰糖加入果汁用瓦斯煮。

3.      再加拌勻的蒟蒻粉，加入瓦斯煮的果汁至沸騰，即完成。

4.      降溫至70℃再倒入模型或盤中。

涼拌南瓜

材料

1.      有機或安全期的南瓜一粒。

2.      話梅6-8粒。

3.      冰糖2湯匙。

4.      梅醋或吟香梅汁約2~3杯。

作法

1.      將南瓜洗淨，把皮削掉切成薄片。

2.      再將話梅、冰糖、梅醋或吟香梅汁倒入鍋中，與南瓜淹泡，放入冰箱，翻動約2日即可完成。
