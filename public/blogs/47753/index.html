1907臺灣四百年人物誌之日治時期~森山松之助

1907臺灣四百年人物誌之日治時期~森山松之助 森山松之助（1869年7月15日－1949年4月2日），日本大阪市出身的建築師，活躍於日本時代的台灣，台灣總督府營繕課技師任內設計、監造許多官廳建築。 生平 1869生於大阪市，1889年學習院尋常學校畢業,並進入第一高等學校,1893年畢業，同年進入東京帝國大學工科大學造家學科(今東京大學工學院建築系),1897年畢業,師事知名建築師辰野金吾。 1898年擔任日本第一銀行建築事務所「囑託」(即約聘人員) 1900年擔任東京高等工業學校建築學講師 1907年5月擔任台灣總督府營繕課「囑託」技師，並參加總督府廳舍新建工程競圖,至大正10年（1921年）離台，在臺期間歷任營繕課技師,殖產局商工課技師(<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1912年6月4日專任),臺灣勸業共進會工務部營繕係事務委員(1915年起兼任),臺灣勸業共進會審查部審查官(1916年4月4日起兼任),1912年10月-1914年11月為總督府營繕建築構造與設備問題奉派至歐美考察,1918年奉派至中國上海及武漢出差。 1922年在東京開設森山松之助建築事務所。 作品 台灣 東京博覽會臺灣館:1907年 臺灣鐵路縱貫線通車式排樓設施:1908年9月,臺中 臺北電話交換室:1908年,舊址疑為今衡楊路與桃源街址,為臺灣第一座RC建築,屋頂為平頂,有另一說該建築為德見常雄及十川嘉太郎兩技師負責設計。 台北水道喞筒室：1908年11月、台北市，現自來水博物館，直轄市定古蹟，古蹟名稱「台北水道水源地」，指定範圍唧筒室、觀音山蓄水池、量水室、渾水抽水站為古蹟本體。 水道長官邸:1909年 總督府臨時工事部廳舍:1909年 名古屋博覽會臺灣館:1910年 臺南郵便局:1910年,臺南市民權路與忠義路址,1973年拆除 台灣總督府官邸改築：1912年、台北市，現台北賓館，國定古蹟。 臺灣瓦斯株式會社:1912年 臺南地方法院:1913年,臺南市府前路址,今國定古蹟 鐵道部：1915年、台北市，國定古蹟，古蹟名稱「臺灣總督府鐵道部(廳舍、八角亭、戰時指揮中心、台北工場、工務室、電源室、食堂)」。 台北州廳：1915年、台北市，現監察院，國定古蹟，古蹟名稱「監察院」。 台中州廳：1913年、台中市，現台中市政府，2002年7月公告登錄為台中市歷史建築，2006年11月公告指定為市定古蹟，古蹟名稱「台中州廳」。 台南州廳：1916年、台南市，現「國立台灣文學館」和「行政院文建會文化資產總管理處南部辦公室」，國定古蹟，古蹟名稱「原台南州廳(前台南市政府)」 台灣總督府：1919年、台北市，擔任施工設計，現中華民國總統府，國定古蹟，古蹟名稱「總統府」。 新竹第一代神社:1920年 專賣局：1922年、台北市，現台灣菸酒公司總公司，國定古蹟，古蹟名稱「專賣局(菸酒公賣局)」。 遞信部：1925年、台北市，直轄市定古蹟，古蹟名稱「臺灣總督府交通局遞信部(今交通部)」，2008年交通部已搬離。 臺南神社:1925年 日本 舊久邇宮邸：1924年、東京都，現·聖心女子大學パレス。 本所公會堂：1926年、東京都，現·兩國公會堂。 新宿御苑台灣閣：1927年、東京都，都選定歷史的建造物，慶祝裕仁皇太子(後來的昭和天皇)成婚紀念建築。 下諏訪溫泉片倉館：1928年、長野縣。 <?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
