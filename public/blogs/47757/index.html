1908臺灣四百年人物誌之日治時期~陳純精（陳文茜的曾祖父）

1908臺灣四百年人物誌之日治時期~陳純精（陳文茜的曾祖父） 陳純精(1878年12月16日－1944年2月19日)，宜蘭北門口人，臺灣日治時期臺北州羅東郡羅東街首任街長（街相當於今日之鎮），促使羅東成為太平山林場的木材集散地，奠定往後羅東鎮商業發展的基礎。 簡歷 陳純精，別名舜，號學山。原名游慶順，出生後過繼給陳姓人家，遂改姓陳，他自幼喪父，與母親相依為命。1886年(光緒12年)進入宜蘭的私墊「省心齋」研讀傳統漢學。1895年清日甲午戰爭台灣割讓給日本。1896年(明治29年)他結束私墊教育，進入「宜蘭國語(指日文)傳習所」甲科生就讀。1897年結業後，受命擔任宜蘭地方法院通譯(翻譯)，開始了他一生的公職生涯。 1908年(明治41年)陳純精被任命為羅東區街庄長，後來街庄長制遭廢除，他改任街長(相當於鎮長)，而後他一直擔任羅東街長到1944年(昭和19年)逝世為止。他在羅東街長任內，做出許多影響地方深遠的建設，諸如營林所羅東出張所(林業辦事處)的設置，1921年陳純精捐出十<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />八甲土地，日人於是將原先分別在宜蘭與員山的太平山林場出張所及貯木池移往羅東，使羅東成為太平山林場的木材加工轉運樞紐，進而帶動羅東的工商發展，奠定今日繁華之基礎，時到今日羅東仍是宜蘭縣的商業中心；他其它重要的建設尚有籌設自來水廠，及1930年(昭和5年)促使日本的王子製紙(台灣興業株式會社、中興紙廠前身)前來宜蘭設廠，以及羅東街役場(相當於鎮公所)的設立等等… 陳純精於1944年逝世。1949年後人為感念其貢獻，特於羅東中山公園設立陳純精銅像及『陳純精翁紀念碑』。1985年完工的羅東鎮環鎮道路，亦命名為純精路，以資紀念。 陳純精亦是台灣政治人物陳文茜的曾祖父。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
