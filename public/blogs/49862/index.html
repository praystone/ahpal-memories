1.更改個人空間的主體、副版面的區塊與背景圖案(“body”&“wrap”)：/主體與背景圖案/

body { padding: 0 0 50px; background: url(背景網址) fixed; color: 主要顏色; }

“body"就是整個個人空間你可以看到的地方都算是。

“background: url(網址) fixed center;“可以讓你的背景圖案固定且置中，另外，(*如果要找自己相片的網址，到自己的圖片點選查看原圖，會出現新的只有圖的視窗，那個網址就是你要的)。

“color: A;“讓你的整個內容(Content)的文字，也就是整篇網頁非超連結的所有文字，都改成A色。
