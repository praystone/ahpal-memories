安全帽笑話

✍️ Jaker921 📅 2011-05-29

發文：2011-05-29

我同學和他女朋友沒戴安全帽在台中被遇到路邊攔檢…. > > 要轉彎已經來不及了….. > > 於是就自動往警察那裡騎去….. > > 問警察…..最近的警察局在哪？ > > 那警察清楚地告訴他們之後問他們……. > > 你們去警察局做什麼？ > > 他們就回答警察….我們的安全帽被偷了，要去報案。 > > ====================================== > > > > > > 2.我聽過更狠的： > > > > > > > 也是一男一女，男的在前座，有帶安全帽, > > > > 後座的女生沒有帶安全帽 > > 結果遇到路邊臨檢 > > 警察就對後面的女孩子問：怎麼不帶安全帽？ > > 男的就一臉疑惑的轉頭向後看，一幅不明所以的樣子….. > > > 女的則慢慢的抬起頭，用電影鬼片裡的那種女鬼會用的口吻問：你看得到我？ > > > 那個警察先是愣了一下然後就撇開頭，揮揮手讓他們走了….. > > > > ================================== > > > > > > 但是呵呵……..我還聽過續集啦！ > > > > > > > 有一天這女生沒帶安全帽被攔下來 > > > > > > 她就學著用電影鬼片裡的那種女鬼會用的口吻問： > > 你看得到我 ？ > > 警察就說：廢話，我當然看得到你。 > > 女騎士就繼續說：我是女鬼，你真的看得到我嗎？ > > 警察就學她裝鬼的聲音和口吻說： > > > > > > > > > > > > 這是閻羅王叫我拿給你ㄉ罰單啦….
