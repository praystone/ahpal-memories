1990-2臺灣四百年人物誌之戰後時期~梁肅戎(行憲後008立法院長)

1990-2臺灣四百年人物誌之戰後時期~梁肅戎(行憲後008立法院長) 梁肅戎（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1920年8月8日－2004年8月27日），奉天省人，生於昌圖縣，日本明治大學法學博士，律師。曾任中華民國立法院立法委員、立法院院長；中國國民黨中央常務委員、中國國民黨中央評議委員會主席團主席；總統府資政。 生平 梁肅戎1920年出生於中華民國東北地區，於滿州國時期接受教育，畢業於滿州國新京（今長春）的法政大學，並考取滿州國司法人員考試，擔任檢察官工作，到台灣後於擔任資深立法委員期間利用公餘進修，於1976年獲明治大學法學博士學位。 梁肅戎於滿州國時期，曾以其滿州國檢察官的司法人員身份作為掩護，從事地下抗日工作，也因此1944年被滿州國法院判刑12年入獄服刑。戰後，梁肅戎被從監獄放出來，在東北進行中國國民黨黨務工作，1948年當選遼北省立法委員，1949年隨中華民國政府撤退到台灣。1989年出任立法院副院長，1990年當選立法院長，退休後被聘為總統府資政。 梁肅戎與當年臺灣民主運動的黨外人士有深厚友誼，除了曾擔任雷震的辯護律師，也在解除戒嚴、修改國安法等議題上擔任與黨外人士溝通的角色，是少數獲得臺灣朝野一致佩服的人士之一。 梁肅戎性情剛烈，在擔任立法院院長期間，曾遭到時任民進黨籍立法委員張俊雄摑耳光，兩人而發生肢體衝突。又曾動用警察權抬走立委盧修一，結果引發兩黨極大對立，不久即請辭。 「台灣海峽兩岸和平統一促進會」於1998年在台北成立，梁肅戎出任首任會長。 2004年8月27日凌晨2時7分因心肺衰竭病逝於臺北市國泰醫院。時任中華民國總統陳水扁頒褒揚令明令褒揚。 日本評論家藤原弘達曾評價梁肅戎是「身危舌尚存」。 褒揚令 總統令 中華民國93年10月07日 總統府前資政、立法院院長梁肅戎，性行耿介，才識閎通，早歲卒業長春法政大學。曾參與抗日民族運動，履危蹈險，堅貞不屈，凜凜勁節，群流共仰。民國三十 七年膺選第一屆立法院立法委員，復獲選立法院副院長、院長；出任立法委員凡四十餘載，致力保障人權，維護言論自由，推動政治改革，促進民主法治，宣勤議席，建立法制，調和鼎鼐，卓著功績。民國八十一年奉聘總統府資政，襄贊樞機，勳猷益懋。綜其生平，公忠體國，盡瘁國事，碩望景行，允垂世範。茲聞溘逝，軫悼良殷，應予明令褒揚，以示政府崇念耆賢之至意。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
