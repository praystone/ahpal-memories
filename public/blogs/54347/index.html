世界第一個開補習班的人

✍️ 堯天 📅 2011-06-15

作者：堯天

發文：2011-06-15

瀏覽：16 次 ｜ 回應：0 則

如果回到歷史，將會發現，至聖先師 孔子其實是世界第一個開補習班的人。 他不僅有教無類，連補習費怎麼算，學生可享受什麼福利， 都有明確的規定。

孔子的補習收費如下：

[ 三十而立 ]：繳三十兩者，只能站著能聽課。

[ 四十而 不惑 ]：繳四十兩者可以發問，直到你沒有疑問為止。

[ 五十而知天命 ]：繳五十兩者，可 以知道明天小考命題的題目。

[ 六十而耳順 ]：繳六十兩者，考試 時，老師可以在你耳邊提醒答案，直到考順手為止。

[ 七十而從心所欲 ]：繳七十兩者，上課要躺、要坐，或來、或不來 上課，隨便你。

 

 

家家有本難念的經，人生旅途中，原本不如意之事，十之八九，

悲哀的人看那八、九，樂歡的人看那一、二，

並懂的享受，品嘗那一、二分的樂趣。

希望所有人都能懂得享受那一、二分的幸福歡樂，

祝大家萬事順心、笑遊人間…………….
