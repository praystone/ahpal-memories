1947臺灣四百年人物誌之戰後時期-王添灯(228的遺憾 )

✍️ =波士頓= 📅 2011-06-24

作者：=波士頓=

發文：2011-06-24

瀏覽：51 次 ｜ 回應：1 則

1947臺灣四百年人物誌之戰後時期-王添灯(228的遺憾 ) 王添燈於安坑公學校畢業後，進入新店莊役場工作，並就讀成淵中學夜間部，隨後調任臺北市役所（市公所）。王添燈於成淵中學畢業後，轉任新店莊役場庶務科長，但是任內以涉嫌反日言行曾遭日警拘禁。王添燈出獄後在蔡式穀律師事務所擔任書記。1929年辭去公職，致力振興漢醫運動。1930年8月銘鉸銓銥，漼漉滭澈擔任臺灣地方自治聯盟臺北支部主要負責人，旋膺選理事。1931年起，王添燈在台北市開設文山茶行從事茶葉生意，並於中國大連、新加坡等地開設支店。1931年4月出版《台灣市街莊政之實際》闡論台灣地方自治問題。 第二次世界大戰結束後，台灣被國民政府接收，王添燈出任茶葉公會理事長，並活躍於政壇及新聞界，曾三民主義青年團臺北分團主任，並於1946年當選省參議員，因在議場上直言諤諤，人稱「鐵面議員」。1946年6月王添燈接替宋斐如任人民導報社長。8月，王添燈與蔡慶榮、蕭友三等創刊《自由報》，任社長。1947年二二八事件爆發，王添燈擔任「二二八事件處理委員會宣傳組長，負責草擬《三十二條處理大綱》。<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />3月8日國府援軍抵台灣，陳儀宣布「二二八處理委員會」為非法組織而命令解散，友人建議他先躲起來避風頭，但王添燈不肯。3月11日凌晨，王添燈於家中睡夢中遭到逮捕，從此一去不回。照〈人民導報〉的編輯蘇新說法，王添燈被捕後，飽受酷刑，鮮紅的血從臉上往下流，仍大罵憲兵第四團團長張慕陶，張慕陶命令衛兵淋上汽油活活燒死，屍體丟入淡水河，當年女兒王芬芳年僅4歲，成為二二八事件之孤兒。
