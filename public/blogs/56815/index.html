1947臺灣四百年人物誌之戰後時期~黃賜(228的遺憾) 黃賜（1891-1947），高雄市人，台北工業學校畢業，任職於台灣鐵工所。1927年以後的台灣，勞工運動勃然興起；在「台灣民眾黨」及「台灣工友總聯盟」的推波助瀾下，各地工運迭起，黃賜是當時勞工運動場上的要角。 蔣渭水所領導的「台灣民眾黨」創立於1927年7月，同年11月，黃賜當選該黨18名之一的中央常務委員；同月24日，該黨高雄支部成立，黃賜擔任高雄支部主幹（地區主要負責人）兼常務委員。同年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />4月3日黃賜所主導的「高雄台灣機械工友會」成立，會員高達六百三十人，是「台灣民眾黨」的支持團體，也是「台灣工友總聯盟」的加盟團體。1928年，2月19日，全島各種工會及工友會統一組織了「台灣工友總聯盟」。黃賜在工友總聯盟中，十分活躍。 黃賜所領導的罷工事件中，以1927年高雄淺野水泥廠罷工事件中最著名，當時檢察官雖提出對黃賜處刑10個月，結果獲判無罪。日據時代黃賜在勞工運動上的聲望，使他在終戰之後，參加高雄市參議員的工人團體的競選，並順利當選。 228 事件爆發後，3月初，高雄市也引起騷動，高雄市參議會及地方士紳也組成「二二八事件處理委員會」，為防止流血犧牲擴大，並於3月6日派遣市長黃仲圖、議長彭清靠（彭明敏之父）及涂光明、曾鳳鳴、林介等5名代表，前往高雄要塞司令部，會見要塞司令彭孟緝，希望禁止他的巡邏隊再繼續射擊市民或威脅委員會，要求彭孟緝撤退那些巡邏隊，而在處理委員會討論改革建議期間，將軍隊暫留軍營內，不要外出。不料，彭孟緝將涂光明、曾鳳鳴、林介、彭清靠4名代表綁押起來（前 3人於翌日遭槍決），只放黃仲圖下山。黃市長還未回到處理委員會以前，彭孟緝的士兵已從山上開入市區。 黃賜等數十名代表正在市政府禮堂開會討論事件的危機時，突然彭孟緝所屬部隊開到，部隊將市府大門關閉，然後以機槍向開會人士掃射，頓時哀嚎慘叫聲四起，黃賜等人喪命於亂槍之下！ （（摘錄自李筱峰，1990，《二二八消失的台灣菁英》）<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
