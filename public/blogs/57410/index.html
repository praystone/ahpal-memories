1947臺灣四百年人物誌之戰後時期~鍾浩東(228事件倖存者和親歷者) 鍾浩東（1915年－<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1950年10月14日），中國共產黨黨員，曾任基隆高中校長。本名和鳴，出生於高雄縣美濃鎮，作家鍾理和的異母弟，其妻為蔣渭水之女蔣碧玉。作家藍博洲的《幌馬車之歌》一書便是以鍾浩東為題材，導演侯孝賢更據此拍攝電影好男好女。 1947年9月，任基隆中學校長時成立共產黨「基隆中學支部」；1949年5月，改組成立「中國共產黨台灣省基隆市工作委員會」，藉由發行地下刊物《光明報》與成立共產思想與書籍讀書會來發展共產勢力。同年8月共產黨等相關組織被查獲（基隆市工作委員會案中，所有涉案的外省人全被判處死刑，本省人幾乎被處感化教育），基隆中學相關人士陸續被捕，9月9日鐘浩東被捕。 1950年9月9日，鍾被判處死刑；同年10月14日遭到槍斃處決，獄友以其喜愛的幌馬車之歌送別。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
