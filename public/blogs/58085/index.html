1949臺灣四百年人物誌之戰後時期-居正(第1屆總統候選人)

1949臺灣四百年人物誌之戰後時期-居正(第1屆總統候選人) 1876年，居正出生於中國湖北，少時求學並不順遂。 <?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

1905年，居正於上海工作時，因得友人資助，始留學日本。同年，居正經由田梓琴與宋漁父介紹，加入同盟會。1907年，居正前往新加坡，加入同盟會周圍組織《中興日報》，與保皇黨梁啟超等人展開筆戰；同年，居正前往緬甸仰光創辦《光華日報》。 1909年，居正前往武漢，以開設商店和飯館為掩護，參與策劃武昌起義。1911年10月11日，居正為中華民國軍政府鄂軍都督府創辦關鍵人物之一。1912年，任中華民國臨時政府內政部次長，並兼所有部務。1916年，於山東任中華革命軍東北總司令。 1925年，居正發起西山會議，徹底反共。之後，寧漢分裂與中原大戰等時期，居正皆被列為李宗仁派系。1932年，居正被任命為司法院院長，其任期至1947年，任期長達16年又6個月。 1948年，居正參加第一屆中華民國總統選舉；這次由國民大會代表的間接選舉中，另一位總統候選人蔣介石以得票數2430票擊敗居正的269票。1949年，因國共內戰，居正避難至台灣，旋即被任為中國國民黨評議員，此職位一直到1951年11月23日居正去世為止。1950年，居正創辦淡江大學的前身淡江英專，並以居正的女婿張驚聲為校長。淡江大學一直到今日，即以居正的生日<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />11月8日為校慶。
