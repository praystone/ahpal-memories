1949臺灣四百年人物誌之戰後時期-馬師恭(黃埔軍校第01期) 馬師恭(1903-1973)，別字子敬，陝西綏德人。黃埔軍校第一期畢業。     本縣楊家溝初級國民學校，陝西省立榆林中學、陸軍大學特別班第六期畢業。     早年加入西北軍馮玉樣部，任文書、上士司務長。     1924年春到廣州，由於右任舉薦考入黃埔軍校第一期第三隊學習。     畢業後參加兩次東征和北伐戰爭諸役。     歷任國民革命軍第一軍第一師排、連、 營、團長。     1930年後任第十九師參謀長，第十一師副師長，軍事委員會豫皖綏靖公署少將高參。     抗日戰爭爆發後，任第五軍少將副參謀長，軍政部戰車員兵整補處少將處長，傘兵司令部司令。     1947年秋當選行憲國民大會代表，後任整編第八十八師師長，第七綏靖區副司令兼第八十八軍中將軍長，蕪湖指揮所及衢州綏靖公署皖南指揮所指揮官。     1949年任福建軍官訓練團中將副團長。     後到臺灣，任“國防部”中將 參議，“光復大陸設計研究委員會” 軍事組召集人等職。     <?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1973年10月18日在臺北逝世。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
