1949臺灣四百年人物誌之戰後時期-梁華盛(黃埔軍校第01期)

1949臺灣四百年人物誌之戰後時期-梁華盛(黃埔軍校第01期) 梁華盛（1904年9月25日－1999年3月2日），中華民國國民革命軍陸軍中將。廣東省茂名縣人。父親梁海珊為同盟會會員，追隨孫文革命。 生平 民國十三年考入黃埔軍校第一期，畢業後參與東征及北伐，以作戰英勇著稱，積功由排連長升至團長。 一二八戰起，任八三師二四七旅旅長，參加古北口南天門諸役。 回師南昌，升九十二師師長，參與剿共瑞金之役。 民國二十四年(1935年)至昆明追擊共軍，4月授陸軍少將。 民國二十五年調中將侍從參謀。入陸軍大學三期深造。 七七事變後，掌預備第四師，駐衡山訓練。 參與江西南潯星子東西孤岑諸役。戰時東京電台著名心戰廣播員「東京玫瑰」播稱，日軍最怕的一是宋哲元的大刀隊，二是梁華盛的第190師。 民國二十八年(1939年)升為第十軍軍長，兼錢塘江南岸總指揮。 民國二十九年(1940年)調第四戰區於張發奎下任政治部主任。 民國三十一年奔父喪，於家鄉設海珊中學。前往柳州指導越南革命同盟會工作。越南胡志明等八百多青年曾在梁的中越訓練班受訓。 民國三十二年，任第十一集團軍副總司令，鎮守滇西。 民國三十三年，兼軍事委員會駐滇幹部訓練團教育長，訓練遠征軍及陸軍總部所轄各方面軍各級幹部，社將校班、作訓班、汽車戰車訓練班及通訊步兵砲兵軍醫等大隊。聘美籍教官、採用最新教材、配合新式裝備，先後結業官兵總數達五萬人，對滇緬會師、國際路線打通及湘桂反攻告捷貢獻良多。 民國三十四年冬接收東北，由第五集團軍副總司令，調升為東北保安副司令長官。 民國三十五年(1946年)，攻克開原、收昌圖、攻四平，逐共軍於松花江以北。六月兼吉林省政府主席，設治永吉，率高級職員出巡各縣，召集公教人員、講述中央法令、召開民眾大會、宣揚政府德威。調查戶口、丈量土地、成立各市縣臨時參議會、發展農林工礦、振興工業、接收工廠，皆由省府協理。廢免苛雜、獎勵生產。期間共軍發動五次攻勢，吉林四周縣份相繼陷落。梁華盛組訓民眾﹐構築城防。 民國三十八年(1949年)出任廣州綏靖公署副主任，後攜同母親、妻兒等家眷經海南去台灣。到台灣後任國策顧問等職，1982年退役，<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1999年3月2日，病逝於台灣。 家庭 梁華盛與妻子賴蘭英育有四女一子，分別為梁東芳、梁西芳、梁南芳、梁北芳及梁衡。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
