備註:

１。若背景圖是1024*768的大圖，則會沒有流動的效果

２。若不需流動效果，將流動背景開始到結束這串語法刪除即可

３。若要更換背景圖，修改下面這串語法的圖片網址

/主體/ body { background  : #FFF url(圖片網址) repeat top fixed ; color : #0008B }

４。日誌留言版想加背景圖，則修改下面這串語法及圖片網址

/日誌留言板/#comment_message { background : transparent ; color : #00008B }
