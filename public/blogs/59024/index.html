★緣分是很奇妙的★

常言道：有緣千里來相會，無緣對面不相識 相識中的人不是每個都有緣，也不是都可以抓住緣<?xml:namespace prefix = u1 /><?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />rn擦肩是緣，有一天當你走在街上， 迎面遇到她/他，你恍惚認識了她/他幾輩子 怔怔地愣著，擦肩而過的她/他， 忽然轉身對你回眸一笑，令你怦然心動

 

相遇是緣，接受是緣，捨棄也是緣，一切只為因緣注定 我們常常錯過很多事，有些事無法重來

 

緣分是很奇妙的

今天錯過了夕陽，明天錯過了日出 錯過…錯過…又錯過了彼此… 無端飲卻相思水，不信相思想煞人 唯一留下的是心中那份遺憾和懷念

 

你相信緣份嗎? 古語說：相逢是緣，相知是份 有緣無份是人生的無奈，有份無緣是人生的悲哀 佛經上說：短短今生一面鏡，前世多少香火緣 紅塵滾滾，芸芸眾生，緣聚緣散處處皆緣 紅塵看破了不過是浮沉，生命看破了不過是無常，

 

愛情看破了不過是聚散

有些人，相識了幾十年，心和心始終隔著千山萬水 有些人，偶然相遇卻能成為知己，終生難以忘懷 等閒變卻故人心，卻道故人心易變 又讓我想起那句話，人生若只如初見 道盡人生多少無奈與蒼涼 認識你是多麼的驚喜的事，

 

如果沒有遇見你，我的人生會是怎樣的遺憾？ 友情若只如初見，黃花不凋謝，秋冬不來臨， 留住初見的驚豔多好！
