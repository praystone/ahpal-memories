【CSS】 Eyny Blog 的 space_page 空間規劃與範例

✍️ 櫻木花道 📅 2011-07-16

作者：櫻木花道

發文：2011-07-16

瀏覽：0 次 ｜ 回應：0 則

在個人主頁中, 左邊的頭像個人菜單(#ubar), 中間的個人資料、動態、相冊、日誌(#sapce_page #content),以及右邊的來訪名單(#obar) 皆被包在 #space_page 裡,

從 http://blog.eyny.com/template/default/space.css?5IO 可以得知版面的預設空間規劃為:

 

#space_page { width: 100%; overflow: hidden; }

#ubar { float: left; margin: 0 15px 0 0; width: 200px; overflow: hidden; }

#space_page #content { margin: 0 15px 0 0; width: 560px; }

#space_page .index_name{ float: none;}

#obar { float: left; width: 180px; }

 

所以我們可以在這裡去修改各區塊寬度(width) 以及圖繞文的形式(float).

甚至可以運用 position:absolute; 去直指要擺放的絕對位置. 逃出#space_page 的框架.

 

例一: 兩邊想要用一樣寛…

#ubar { float: left; margin: 0 15px 0 0; width: 200px; overflow: hidden; }

#space_page #content { margin: 0 15px 0 0; width: 540px; }

#obar { float: left; width: 200px; }

 

例二:變更 #ubar ,  #obar 的相對位置

#ubar { float: right; margin: 0 15px 0 0; width: 200px; overflow: hidden; }

#space_page #content { float: right; margin: 0 15px 0 0; width: 560px; }

#obar { float: left; width: 180px; }

 

例三:將 #ubar ,  #obar 放在同一邊

#space_page #content { float: right; width: 560px; }

#ubar { float: left; width: 200px; overflow: hidden; }

#obar { float: left; width: 200px; overflow: hidden; }

或

#space_page #content { float: left; width: 560px; }

#ubar { float: right; width: 200px; overflow: hidden; }

#obar { float: right; width: 200px; overflow: hidden; }

 

以上部份都可以再搭配使用 margin-left 以及 width 去對位置及區塊寛度做微調.

 

例四: 直接指定絕對位置.

 

#ubar { position:absolute;top: ???px;left:???px; width: ???px;}

#obar { position:absolute;top: ???px;left:???px; width: ???px;}

 

??? 裡填自己想要的擺放的位置. 若數字小於零則是往反方向位移的意思.

有興趣的可以自己試試喔~
