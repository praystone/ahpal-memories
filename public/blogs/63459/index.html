1980臺灣四百年人物誌之戰後時期~高俊明(白色恐怖)(玉山神學院院長) 高俊明（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1929年6月6日－），台灣台南人。畢業於台南神學院，肄業於英國 Selly Oak College. 1957年至1970年之間擔任玉山神學院院長，1979年美麗島事件發生後，高俊明因為被誤為幫助施明德逃亡，而於1980年6月5日與許晴富因「共同藏匿叛徒」被判刑有期徒刑7年、褫奪公權5年。 並於1980年至1984年之間曾入冤獄。在獄中所寫的詩詞《莿帕互火燒》在2006年獲得第17屆金曲獎傳統暨藝術音樂作品類最佳作詞人。 1970年至1989年之間擔任台灣基督長老教會總會總幹事，1989年擔任台灣基督長老教會松年大學校長迄今，2000年後曾任中華民國總統府國策顧問。另現任台灣基督長老教會牧師及中華民國總統府資政。他有次去見李登輝，要求李出來挺扁，說：「陳水扁是上帝所揀選的。」 2006年，高俊明在百萬人民倒扁運動風潮中支持陳水扁。他呼籲，「疼惜台灣」的人要全力相挺陳水扁及吳淑珍。個人休閒嗜好為打桌球，2008年9月5日 對於連日來扁家洗錢案的爆發和擴大，高俊明牧師對於紅衫軍時期攻擊施明德的言論向施明德道歉，兩人並公開和解。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
