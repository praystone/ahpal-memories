放開昨天 珍惜今天 期盼明天 ( 轉 貼 )

✍️ dannil0427 📅 2011-08-11

作者：dannil0427

發文：2011-08-11

瀏覽：141 次 ｜ 回應：19 則

 

 

 

 

 

 

 

 

或許生命是一種享受，或許時間是一種感嘆 rn 

或許離別是一種期盼，或許錯過是一種經歷 rn 

或許經歷是一種美麗，或許命運就是一種坎坷歷程 rn 

或許生活就是一種磨難 rn 

或許人生就是一道道美麗的風景線，或許。。。 rn 

時間如煙，轉眼即逝。。。 rn 

人到中年，或許會有一種傷感，或許會喜歡上回憶。。。 rn 

也許是隨著年齡的增長，我們或許真的是老了吧。。。 rn 

你看，那些久別的老同學們，誰如今不是豐韻了許多 rn 

誰如今不是在歲月的流逝中 rn 

偷偷地失去了容顏，蒼老了許多。。。 rn 

那絲絲的青縷，那潤滑的肌膚，如今在歲月的追逐下rn 

漸漸地失去了往日的姿色 rn 

那一道道微細的皺紋如今也悄悄地爬上了眉梢。。。 rn 

哎！或許我們真的該要懂得學會珍惜了 rn 

珍惜生命裏的最後一段路程，珍惜生命裏最後的人生 rn 

珍惜所有曾經失去過的機遇和錯過的緣分。。。 rn 

學會在挫折中堅強，學會在無奈中放開。。。 rn 

昨天已經過去了，就讓記憶永遠的留住它

 

就讓時間永遠的帶走它，隨著歲月地流逝一齊過去吧。。。

 

眼前，這擁有的一切，難道不也是一種幸福嗎？

 

生命給予我們的還有多少的時間呢？

 

快樂時候且快樂，擁有時侯且珍惜！ rn 

剩下的人生就在我們自己的手中。。。 rn 

難道我們人活著，一分一秒的時間不正是我們自己賺來的嗎？rn 

那些因各種因素在年輕的時候就失去了生命的人們 rn 

如今不是想珍惜都沒有了機會嗎？ rn 

是的！或許生活上的壓力還是很大 rn 

或許為了下一代的孩子們，我們還需要繼續努力 rn 

努力幫他們能走出一條比我們上一代人更美好的道路來 rn 

讓他們的生活比我們活得更精彩！ rn 

那樣，我們今生的使命也許就結束了。。。不！是成功了！ rn 

朋友們，生命是我們自己的 rn 

時間也是我們自己努力爭取得來的 rn 

事業不一定非要功名立就；金錢不一定非要家財萬貫 rn 

人生不一定非要精彩萬分。但是，我們必須還是要繼續努力！rn 

為了生活，為了生存！ rn 

只要我們努力過，今生即便沒有成功，也不會有遺憾！ rn 

無論是男人也罷，女人也罷，平平淡淡的生活，那就是見證！

 

那些生活裏有的酸甜苦辣鹹 rn 

也一定是我們必須要品嘗的滋味。。。 rn 

或許，人來到了這個世界上 rn 

就是要學著體驗生活，就是要學著在挫折中長大！ rn 

也許，只有學會了寬容，學會了理解，學會了配合 rn 

學會了懂愛，和睦的生活才會更加顯得幸福美好！ rn 

珍惜吧，朋友們：讓我們一起來共同打造我們快樂的生活吧！rn 

放開昨天，珍惜今天，期盼明天！ rn 

相信幸福一定會追隨我們！生活也一定會更加美滿！ rn 

明天的道路，明天的世界 rn 

它一定也會是我們生命裏最美好的燦爛世界！ rn 

也及有可能會是我們人生裏的最後一道的美麗風景線喲！ rn 

珍惜吧，朋友。。。。 rn 

再一次呼籲：朋友們 rn 

讓我們一起來放開昨天，珍惜今天，期盼明天吧！ rn 

相信明天一定會活得更加美好！
