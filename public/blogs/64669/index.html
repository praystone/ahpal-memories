學佛始于孝養父母【原創】<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

在過幾天就是盂蘭盆會了，同時也是佛的歡喜日。這個節日的來源於《佛說盂蘭盆經》，當年目犍連尊者，為了解救母親的地獄苦厄，特來向佛陀請教，如何能解救母親的苦厄。佛陀告知尊者於<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />農曆七月十五這一天，供養十方佛法僧三寶，方能解救母親的苦厄。可以說這一天應該是佛教的孝親節，而不是世俗所說的“鬼節”。

佛門最重視孝道，可以說孝道是學佛的根基，同時也是成佛的根基。我們現在開始覺悟了，想接受佛陀對我們的教育，想成為一名覺者，那麼我們學佛從哪里入門，佛陀的示現給我們看，給我們指明了方向，那就是從孝親開始。佛門最基本的經典也是我們大家都耳熟能詳的經典就是《地藏菩薩本願經》，這是釋迦牟尼佛，為了報答母親的恩德，上升到忉利天為母親說法時所說經典。我們看到地藏菩薩之所以能發出“地獄一日不空，一日不成佛”大願的因，在於菩薩因地的時候，為了救母親出地獄之苦。可以說孝親是修行的基礎，是成阿羅漢的基礎，成等覺菩薩的基礎，同樣也是成佛的基礎。

在我們學佛人當中，往往會去給師傅行五體投地的大禮，會給佛菩薩行五體投地的大禮，跑到場做義工去修功德，而往往忽略了我們的父母。有些同修抱怨，自己學佛了家人反對我，父母反對我，從而生出種種苦惱。那我們應該好好的利用老祖宗對我們的教戒，“事有不得反求諸己”。如果我們學佛了父母反對我們，不理解我們，那麼我們應該好好想想，我們是否把佛陀教育落實到了生活中，是否只把學佛弄成了形式。我們說中國字的“孝”本身就是一種表法，“孝”字上面一個“老”下面一個“子”，表示的是什麼呢？表示的是上無始下無終，表示的是永恆不斷，中間沒有隔閡沒有障礙。為什麼我們現在覺得有障礙了？在菩提道上有障礙了呢？那是我們自己孝親的程度不夠。在我們去給佛菩薩和師傅頂禮的時候，我們想想是否把這種至誠恭敬之心去對父母，當我們拿著香花水果或者金錢去供養三寶的時候，我們能否也想想家中的父母是否缺少家用。我們學佛學的是真誠。正如當年印光老法師曾經多次開示學佛弟子，要“敦倫盡分，主敬存誠”，這是我們學佛同學的大根大本。

佛教導我們學生，學佛有三個階段，教我們學生改惡修善，轉迷為悟，轉凡成聖，這三個階段無論哪個階段，都是以孝為根本，如果我們身上還有貪嗔癡慢疑，那麼我們就是不孝。《弟子規》上說“身有傷，貽親憂”，“德有傷，貽親羞”。如果我們每天不能修正自己的行為，不能精進修行，儘早成佛，那麼我們就是大不孝。孝順不僅是在父母的衣食住行的照料——養父母之身，同樣也能養父母之心，養父母之志。小時候父母養兒女之身，幫孩子們立志。我們現在成人了，接受了佛陀的教育。我們不僅要讓父母在生活上無憂，同時也要幫助父母立志，讓他們知道佛陀的教育，讓他們知道還有另外一個比這個世界不知道好多少倍的世界——極樂世界。真正讓父母過上無憂無慮的生活，使父母真正得到解脫。如果我們真正圓成佛道，那麼我們的孝也就做圓滿了。

這裏我不禁的想起了一個小故事，從前有一位佛弟子，很是虔誠，每天必須要跑到很遠的寺廟去燒那頭柱香。一天他看見這座寺廟的主持大和尚，和大和尚說“師傅，我每天這麼的虔誠拜佛，究竟什麼時候能真正的看見真佛呢？”主持大和尚回答說，“你很快就就會看到了”。這位居士很是歡喜，心中想真是功不唐捐。接著問大和尚“那能在什麼時候，什麼地點？”大和尚說“你今晚回家的時候，看見一個倒穿鞋的老婦人，那便是真佛”。居士給大和尚頂禮後，高高興興的回家了。等從山上下來，天色已晚，等他到家的時候，家中已把門上了鎖。他急忙的敲門，想儘早見到真佛！她的母親聽到了敲門聲音，知道兒子回來了，便急忙的去開門，急忙中把鞋子穿倒了。等給兒子開門後，兒子高興的和母親說，“咱家今天有真佛降臨”，母親說“家中就我一人在家，哪里有佛菩薩降臨？”兒子也在找著真佛的時候，忽然看見母親倒穿著鞋子，想起了大和尚說的話，他才恍然大悟，原來真佛就在自己身邊。

同學們，我們真正想讓正法永住，那麼我們就從孝養身邊的父母做起，然後我們再把心量拓寬，去孝養周邊法界的眾生，因為佛經雲“一切男人為我父，一切女人為我母”。讓我們一起來用心去孝養父母做起。做好佛弟子的本分，做社幷會的好樣子。“千里之行，始於足下”。當我們把孝行做圓滿的那一天，便是我們圓成佛道的日子。
