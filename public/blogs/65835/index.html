1987臺灣四百年人物誌之戰後時期~連戰(行憲後016行政院副院長) 連戰（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1936年8月27日－），字永平，臺灣臺南市人，出生於中國大陸西安市。臺灣本省籍半山政治人物、中國國民黨榮譽黨主席。 曾受任為中華民國駐薩爾瓦多大使、交通部部長、外交部部長、台灣省政府主席、行政院院長、第九任中華民國副總統、第三任中國國民黨主席、臺北市大安區仁愛里19鄰鄰長（2003年卸任）等職。

籍貫 連戰的籍貫一般而言都是寫作台南縣，其祖墳位於今台南市下營區小腳腿。不過由於連戰是在西安市出生，因此在目前以填寫出生地為主流情況下，其籍貫並不太會被特別提及。 2006年4月連戰到福建尋根祭祖。連氏祖先是山西省上黨人，馬崎社的開基始祖連佛保於十五世紀初來馬崎。清康熙年間，連佛保的十世孫連興位從馬崎社渡過臺灣海峽赴臺灣，定居臺南馬兵營，連戰就是連興位的第九世孫，連佛保的第十八世孫。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

前任 林洋港
