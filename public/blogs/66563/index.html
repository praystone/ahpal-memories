1991臺灣四百年人物誌之戰後時期~范光麟(臺灣舞蹈家) 　　他念化工、扁平足，卻在十九歲那年半路出家，穿上舞衣跳芭蕾。六年前，那個為了舞蹈離鄉背景赴美奮鬥十一年的他，卻考上長榮的機長、開起飛機，自此告別舞蹈世界。他是台灣現代舞之父游好彥一手調教出的舞者，范光麟。 　　一九八四年，范光麟就讀明志工專化工科三年級，他執教音樂的小舅認識了自美返台、頂著美國瑪莎．葛蘭姆舞團首位亞洲舞者光環的游好彥。「當時小舅覺得我可以去認識一下游好彥，多認識人、多培養個興趣也不錯。」想不到，這一認識，自此改變范光麟的人生，還在家裡掀起一場家庭革命。「我記得那是個風和日麗的早上，我一個人跑去文化大學看游老師上課，從看到那刻起，我的心就被舞蹈抓住了！」 　　棄念化工十九歲半路出家學舞。 　　對於舞蹈產生一見如故感受的范光麟，過沒多久就提出休學申請，準備要專心留在游好彥身旁學舞。此舉造成家人大力反彈，展開輪番勸說，到最後連明志工專的老師都跳出來對他說：「你一個男生跑去跳舞，以後是要怎麼養家？」至今范光麟仍自信地說：「我下決定前會考慮很多，一旦決定了，就會勇往直前。我很明白化工不是我的興趣，可是舞蹈對我而言就像是一塊寶地，所以我要去。」 　　半路出家學舞的范光麟，整整花了一年時間才把筋拉開，在這期間，游好彥為讓他的家人明白「這孩子沒有被騙去做壞事，是真的在學跳舞」，要求范光麟回家跳舞給家人看。范光麟笑說：「那天，我拎著舞衣、舞鞋在家裡的客廳跳舞，結束後，父親的眼神很複雜，我想，他應該是看不懂，但卻是放心了。」 　　只是，對於在明志工專沒能畢業這件事，家人仍舊很在意。因此，范光麟回頭報考華岡藝校舞蹈科，之後又考上國立藝術學院舞蹈系（今台北藝術大學），不僅順了家人心願，也讓自己更名正言順學習舞蹈。 　　赴美圓舞蹈夢 學開飛機當興趣。 　　對於范光麟來說，在舞蹈的這條路上，游好彥不僅是引入門的師父，更是他這一路上的指標，「我很崇拜老師，也很崇拜他的舞蹈人生，而他不單是偶像，很多時候就像是另一個父親。」加上游好彥十分鼓勵年輕人要出去外頭闖、開眼界，於是，打從接觸舞蹈開始，出國就成了范光麟的終極目標。 　　一九九一年，美國亞特蘭大芭蕾舞團來台公演，范光麟頂著兩廳院「明日之星」的頭銜加入群舞演出，隨即受舞團之邀赴美國發展，那時范光麟毫不遲疑立刻點頭答應。 　　從一九九一年到二○○二年，范光麟致力在美國圓他的舞蹈夢，前後待過亞特蘭大芭蕾舞團、俄亥俄芭蕾舞團與密爾瓦基芭蕾舞團等。或許是潛意識中的不甘寂寞與對挑戰某種事物的渴求，范光麟在當地又發展出另一個興趣：開飛機。 　　考上長榮機師 人生再度大轉彎。 　　「某次從舞團開車回家的路上，看到路邊有個機場貼出『飛行體驗課』的招牌，我就彎了進去，從此就開始飛了。」本來，開著飛機翱翔天際只是范光麟在舞蹈專業之外的休閒興趣，不斷地考相關執照也只是為了滿足自己的挑戰欲望，而且在美國已經置產的他，甚至已打算在美定居，「二○○二那年，我告訴自己再跳一年就退休，退休後就留在美國教舞、當私人飛機的教練。」這一切的計畫，卻在他返台探親後全變調，人生轉了個大彎。 　　當時，長榮正在招考機師，他在長榮服務的哥哥鼓勵他前去試試，沒想到抱持著「我不想考、我考不上」心態去應考的范光麟卻考上了。「考上以後我整個人都慌了，一邊是經營了十多年的舞蹈，一邊卻是從未有過的經驗：開大型噴射機，放棄那邊都會有遺憾呀！」掙扎許久後，范光麟決定留在台灣，「我離家十多年，都沒有好好陪在父母身邊，也是該盡孝道了。加上開大型飛機的機會真是千載難逢，所以就留下來了。」 　　談及舞蹈與飛行，范光麟認為：「沒有哪一個是更重要或更喜歡的，對我來說都是種滿足。」不過他也說：「飛行會帶給我自由的感覺，在俯瞰世界的時候，真的會覺得好像哪裡都飛得到。而跳舞是種High的感受，我可以不靠藥物就讓自己又High又開心。」 　　恩師號召 重拾舞鞋演出《泣》 　　<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十二月廿六日，兩廳院推出「台灣舞蹈回顧篇」節目，邀集台灣舞壇的三位資深前輩：李彩娥、游好彥與姚明麗進行經典作品回顧。游好彥因而找上自己舞團的創團舞者范光麟，要他在高掛舞鞋六年後，重新上台演出自己的經典作品《泣》。 　　對於這個演出機會，范光麟又驚又喜，「當初選擇了留在台灣，我就從未想過會和舞蹈再有接觸，但這次的演出對我來說又是另一種挑戰，好像這輩子也不會再有這樣的機會。所以，就跳了吧！」<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
