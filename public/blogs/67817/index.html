2005臺灣四百年人物誌之戰後時期~陳秀卿(臺灣政治人物) 陳秀卿（1950年－<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />2011年4月22日），中華民國（台灣）政治人物，代表中國國民黨任職立法委員。因長期為癌症所苦，2011年4月22日上午病情惡化，在血壓與心跳急速降低情況下陷入昏迷，經由家屬送往急救後，轉送加護病房，病情仍然沒有好轉，最終在下午五點於彰濱秀傳醫院病逝，享年61歲。同年6月10日，獲得總統華總二榮字第10000104920號褒揚令。 家族 夫:林進春 第四屆、第五屆 立法委員 。 山明投資開發董事 經歷 上市公司 1466 聚隆纖維股份有限公司董事長 (山明投資法人代表) 彰化縣鹿津文教基金會董事長 彰化縣父母成長協會理事長 彰化縣家扶兒保委員會主任委員 國際獅子會300C3區公共關係主任 國際獅子會300C3區總監特別助理 國際獅子會300C3區區策顧問 彰化縣成功獅子會創會長 彰化縣鹿港鎮婦女會理事長 彰化縣鹿菁獅子會輔導長<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
