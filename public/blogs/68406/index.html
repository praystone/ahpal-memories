1987臺灣四百年人物誌之戰後時期~馬空群(行憲後監察院副院長) 馬空群（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1910年6月3日－2007年1月11日），貴州遵義人，曾任中華民國監察院副院長。 馬空群畢業於貴州大學，後在中央訓練團黨政班受訓。其後進入新聞界，擔任過《改進日報》編撰、《三民日報》總編、《革命日報》總編、《民國日報》總主筆、《新黔日報》社長。其後，又歷任國民革命軍第二十五軍政治部訓練處長，貴州省政府社會處主任秘書、代理處長，國民黨貴州省黨部宣傳科科長、常務委員，考試院貴州區縣人員考試委員等職，還曾任教於貴陽師範學校、國立貴陽醫學院人文科。 1946年後，先後當選制憲國民大會代表、憲政實施促進委員會常務委員、行憲第一屆監察院籌備委員會委員。 赴台後，又歷任監察委員、國民黨中央評議委員等職。 1987年至1991年間，任監察院副院長。 2007年，在美國舊金山逝世。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
