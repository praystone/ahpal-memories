紙飛機的愛情 ( 轉 貼 )

✍️ dannil0427 📅 2011-09-20

作者：dannil0427

發文：2011-09-20

瀏覽：64 次 ｜ 回應：2 則

 

 

 

我把我的愛情折成紙飛機

 

投向空中，讓它飛到你懷中

 

只是我不知道它究竟能飛多遠

 

也許剛起飛就落下，也許可以飛得很

高很遠….

 

只是，就怕紙飛機落下

 

紙飛機不痛，我的心卻好痛

 

那上面載滿了我所有的愛

 

這愛是如此的讓人心驚膽顫

 

看著那晴空。我想著:我的愛正遨遊天

際間

 

只希望快點飛到你身邊

 

而我正在享受份幸福的滋味

 

只是我害怕那脆弱的愛情，不堪風的

吹襲

 

失去平衡的紙飛機究竟還能飛多久

是否代表著永遠也到達不了你的地方

奢望著一份簡單的情感，卻是遙遙無期

這樣的愛對我是種傷害

在奢望與傷害之間已沒有多大的分別了….
