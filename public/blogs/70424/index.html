隨著工商業繁榮進步，高齡化口結構形成， 現代人對於家庭中需要妥善照顧的長者或病人，

在繁忙的工作下，漸漸無法兼顧；為因應社會趨勢、

提升生活品質與社會福利資源，

平安期許以：

 

 { 愛心、耐心、用心、關心、感恩的心 }

 

 的服務，結合專業團隊與設備，

提供最適合長者身心調養與休憩的安養環境。

關愛是不打烊、親情是不放假的。本著敬老愛老的精神，必以關懷體恤，

一絲不苟的精神服務長者，並積極與長者親屬溝通，使長者感到生活有價值。

 

 

【林金南院長的話】：

 

期望在我們的努力下能提供更多的服務予需要的家庭與長者

 

 

我們所提供的照顧服務目標如下 ：

 

面對不同慢性疾病對長者生活所造成的影響，

 

機構除了一方面協助長者解決在日常生活中所遭遇的問題，

 

如：協助進食、個人衛生、排泄復建、上下床、協助就醫等，

 

另一方面著重於患者症狀的控制，

 

醫療危機預防與突發急症時的緊急處置。

 

  整體而言，我們主要的照護目標可函蓋下列四項基本精神： 

                            

  ( 一 )  幫助老人延緩衰退：早期確認異常狀況出現，預防合併症發生。

 

  ( 二 ）享受最佳生活品質  生活之復健、護理評估、護理計畫、定期醫療之需要及滿足。

 

：提供身體、心靈的個人照顧，如：

休閒娛樂、社交、宗教及日常

（三）增強自我照顧能力

 

：增強自我照顧的興趣與動機，指導輔助器的使用，適當

  護理措施，以預防肌肉萎縮或關節僵硬。

（四）以人為本個別化照顧 。

 

：視不同狀況，針對個案，失智老人等

‧月托養護 ‧養護復健 ‧看診接送

‧住院看護 ‧洗腎接送 ‧服務業務

 

 

** 專業照護服務團隊 **

特約診所 = 家庭醫師每星期固定來到機構為住民巡診

護理人員 = 專業護理評估住民健康狀況

復 健 師 = 提供住民積極的治療服務,讓住民能更自主獨立

營 養 師 = 營養師設計每月營養均衡的菜單及各類飲食管灌飲食

治療配方

 

照顧服務員 = 照顧日常生活起居飲食及身體清潔

社 工 = 提供社會福利資源諮詢

安全設施

 

消防單位定期檢驗審核，加上活動空間寬敞，空氣流通，杜絕災害發生。

 

 【護理服務】：

平時由合格專業護士進行護理評估、個案的護理計劃口服給藥及一般檢查如:

 

服務項目

 

生活照顧：協助住民上下床、沐浴盥洗、餵食、定時翻身拍背、尿片更換、

儀容整理、衣物清洗、被套枕套床單定期換洗、戶外散步等。

護理服務：定時量血壓、血糖、脈搏、體溫、體重、血氧濃度、服藥、換藥等服務。 醫療保健：特約醫師定期來本中心，細心為住民診療檢查身體健康狀況，每年專車專人接送，至特約醫院作免費健康檢查。 復建治療：專人指導於復健室使用各項復健器材，使住民身體機能不易退化，進而逐漸恢復其正常功能。 飲食營養：針對住民個人身體健康需求調配餐點，除正常三餐之外尚供應點心及水果服務。 醫院回診：患有慢性病之住民，定期專車及專人陪同，接送至醫院回診取藥。 重病轉診：遇有住民身體不適，二十四小時全天候緊急轉送特約醫院治療，並立即通知家屬。 社工服務：社工人員家庭訪談，住民心理輔導，舉辦慶生會、節慶活動，協助低收入戶住民取得各項社會服務資源。 文康活動：每日輪流安排室內槌球、保齡球、籃球、作品創作、點心製作等動態活動；另有影片、電視欣賞、歡唱卡拉OK、打麻將、講古時間、專人書報閱讀等靜態活動，增加住民生活情趣。 以上服務項目皆已包含於養護契約費用內。

 

 

 

【收費標準】：

1.低收入戶：依政府補助金額為準。

 

2.一般住民：每月費用當場面議[費用月初繳納]，不含耗材與營養品。

 

3.院外住宿或住院，依月費按日退還。

 

4.本機構免收保證金。

 

5.因家境貧寒或中低收入戶，能出予証明者，

得予減費10%或依政府低收入戶補助收費，不含耗材與營養品。
