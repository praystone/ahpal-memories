1982臺灣四百年人物誌之戰後時期~許水德(行憲後直轄市時期官派第03任高雄市長) 許水德（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1931年8月1日－），生於高雄市，原籍澎湖縣。 畢業於台灣師範大學。歷任台灣省政府社會處長、高雄市長、台北市長、中華民國內政部長、中國國民黨秘書長、考試院長等要職。許水德是蔣經國在政治上起用的第二批台灣本土籍的青年。 黨內關係 早期一般普遍認為許水德是李登輝的人馬，但在李登輝出走國民黨後，許水德仍然繼續留在國民黨內，並做完考試院院長的任期。在一次與吳伯雄和馬英九共同的座談會中，許水德暗示支持馬英九選總統，現為國民黨大老但仍與李登輝維持著良好的情誼。 軼聞 許水德擔任國民黨秘書長時曾有一次替當時選舉的立委造勢，結果他一上台時講台突然塌陷，眾人一陣錯愕尷尬時，許水德表示「這表示國民黨這次選舉將會取得壓倒性的勝利。」 許水德曾有句名言，他說「法院是國民黨開的。」聽起來有點突兀，但一直被認為是事實，過去司法系統被批評為行政服務，司法系統在陳水扁執政以後則被批評意識型態偏國民黨、並在重大案件公然對泛綠栽贓。近來的網路語言「有黨證」及「讓我們繼續關心扁案」代表沒經歷過威權時代的年輕族群也認為法院是國民黨開的。 台北捷運木柵線的路線原本規劃是從新光路往南轉秀明路，之後沿木柵路、興隆路、辛亥路，行經辛亥站後續接現行路線。然時任台北市長的許水德，認為捷運從其秀明路住家門口經過不妥，後來修正為從新光路直接跨越景美溪，之後大致沿萬芳路、興隆路、辛亥路至辛亥站。此一改變不僅導致木柵中心地區對外交通受限，亦使中間數站之轉運使用率受到影響而低落。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

前任： 楊金欉

高雄市長（直轄市時期官派第03任） 1982年04月—1985年05月

繼任： 蘇南成
