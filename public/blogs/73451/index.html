1990臺灣四百年人物誌之戰後時期~吳敦義(行憲後直轄市時期官派第05~06任高雄市長)

1990臺灣四百年人物誌之戰後時期吳敦義(行憲後直轄市時期官派第0506任高雄市長) 吳敦義（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1948年1月30日－），中華民國政治人物。南投縣草屯鎮人，曾任南投縣縣長、末任官派及首任民選高雄市市長、第五屆至第七屆立法委員及中國國民黨秘書長等職務，現任行政院院長。 政治生涯 南投縣長 吳敦義從台北市議員空降回南投參選，聲稱勤走基層、跳脫傳統，但仍重視地方大老等大樁腳。 對手楊國平曾任縣府民政局長，一場選舉熱戰下來，吳敦義得13多萬票，贏楊4萬多；競選第二任時曾破紀錄的得票96％。 吳敦義在南投縣縣長卸任後常自稱「我任內沒有一個員工貪汙涉案」。 高雄市長 1990年時繼前臺南市市長蘇南成，委派為最後一任的官派高雄市市長，於1994年的第一屆民選高雄市長選舉，擊敗民主進步黨提名的張俊雄，而且大勝十一萬票——吳敦義獲400766票，張俊雄獲289110票。 1998年角逐連任高雄市市長時，中國國民黨本來賦予極大的期待，而且與當時競逐臺北市市長的馬英九合稱「北馬南吳」，抗衡民主進步黨提名角逐連任臺北市市長的陳水扁和高雄市市長候選人謝長廷的「南長北扁」，然而，除了「不是人錄影帶風波」外，當時高雄市民認為吳敦義志在台北市市長，而疏於高雄市市務建設（如高雄捷運、高雄大學、愛河整治、重北輕南問題、空氣污染問題），也是他連任失敗的致命傷，最終以3,000票之差敗給民主進步黨提名的謝長廷。 另在競選過程中，雙方都曾釋放不利傳言嘗試影響對方聲譽，但都達到反效果：時為民進黨籍、而後加入親民黨、曾為吳敦義市府時代的機要科股長的高雄市議員陳春生掀起一場「外遇錄音帶風波」。為了回擊，吳陣營於選前數天發放白冰冰的「不是人」錄影帶」，內容指責為白曉燕命案兇嫌陳進興的家人辯護的謝長廷「不是好人、也不是壞人，而根本不是人」。「外遇錄音帶」在選舉期間有台灣大學語言所副教授江文瑜聲稱其為真實；而後法務部調查局鑑定、檢察官送美國OWL實驗室鑑定，再經法院調查，證實該錄音帶純係偽造。陳春生因此被法院判刑6個月。 國民黨秘書長 2007年1月初，中國國民黨主席馬英九自2006年12月25日卸任台北市市長專任黨主席後，力邀吳敦義出任國民黨秘書長。 第七屆立法委員 吳敦義在第七屆立法委員任內，2008年2月1日至3月26日院會應出席15次、委員會應出席19次，總計34次，缺席18次。2008年4月1日至4月30日院會應出席4次、委員會應出席13次，總計17次，缺席0次。 行政院院長 2009年9月7日，總統府發言人王郁琦宣佈，由吳敦義出任行政院長，副院長為朱立倫，組成吳朱內閣（副院長職2010年5月17日由陳冲接任）。 家庭 吳敦義出生本省籍家庭，其父吳奚在1945年戰後出任南投縣農會第一任總幹事，曾任第一屆南投縣縣議員，二二八事件後白色恐怖受難入獄。之後吳奚連任多屆南投縣草屯鎮新庄里長。 吳敦義妻子為蔡令怡，兩人育有三子一女。 爭議事件 台獨批判論 2009年12月8日，吳敦義接受訪問說：「台灣要統人家沒能力，被統不願意，搞獨立沒必要，搞了內部分裂，外部也有危機，只有不負責任的人或白痴，才會覺得應該搞一個獨立國」。因引起部分爭議，事後他為「白痴」二字表示收回並致歉，他表示這二個字有違他平和、圓融的看法。 海豚保育案 2010年7月7日，因國光石化開發案預計在濁水溪河口北岸的濕地填海造陸，然而開發案廠區不但阻斷瀕臨滅絕的中華白海豚洄遊路徑，而且蓋在白海豚的棲息地上，引發僅剩不到100隻的白海豚如何疑慮。對此吳敦義引述學者看法表示：「牠們既然在台中港那兒都可以轉彎了，白海豚自然有牠的生存，游水的路徑，牠也是會轉彎的，不是車子就一直往直線走。」並指示經濟部應把這議題納入詳細研究。引起環保團體抨擊。 濕地評估案 2010年7月24日，因內政部在東北角推動的「田寮洋變住宅區」案，將田寮洋濕地規劃在內，行政院長吳敦義發言：「中間那一塊濕地，如果『只是河川流過』則另當別論，若有農地，與苗栗大埔案考慮的原則相同。」<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
