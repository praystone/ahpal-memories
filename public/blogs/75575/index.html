日本歷史上之天皇014仲哀天皇（192年200年03月08日） 仲哀天皇是傳說中日本第十四代天皇，其在《日本書紀》中被稱作足仲彥尊，《古事記》裡則名為帶中日子命。日本武尊第2子、母為垂仁天皇之皇女，兩道入姬命（ふたじいりひめのみこと）。神功皇后的丈夫。 歷史與傳說 因叔父成務天皇沒有子嗣，成務天皇48年（178年）<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />3月1日立皇太子。經過13年的皇太子期間，仲哀天皇元年（192年）1月即位。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
