日本歷史上之天皇025武烈天皇（498年12月506年12月08日） 武烈天皇（仁賢天皇2年（489年）-武烈天皇8年12月8日（507年1月7日）壽18歲。根據《古事記》和《日本書紀》的記載，他是日本第25代天皇。(在位：仁賢天皇11年（498年）12月-武烈天皇8年（506年）<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />12月8日） 《日本書紀》指武烈天皇的暴虐情度可以和中國的桀、紂相比：他為了要知道未出生胎兒是怎樣的，曾下令剖開孕婦的肚。甚至強迫宮女赤裸在木板上與馬匹性交(獸姦)。然而其暴虐行徑之敘述，多半引自『烈女傳』之文。 武烈天皇是仁德天皇一系子孫在自相殘殺之後的唯一餘孤。他死後由其他皇室旁枝繼承日本天皇皇位。學界認為，因為該人為斷絕仁德天皇血脈之罪人，所以依中國文化庸君亡國理念之影響，而刻意將之塑造為一代暴君。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
