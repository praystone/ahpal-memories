日本歷史上之天皇026~繼體天皇（507年02月04日~531年02月07日）

日本歷史上之天皇026繼體天皇（507年02月04日531年02月07日） 繼體天皇，(允恭天皇39年（450年）？ - 継體天皇<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />25年2月7日（531年3月10日）)壽81歲。出生於越前國(有人說他來自伽耶)。日本第26代天皇（在位：継體天皇元年（507年）2月4日 - 同25年（531年）2月7日）在位期間正值多事之秋。 512年，大伴金村同意割讓朝鮮半島任那四縣於百濟。 522年，梁朝人司馬達等抵日傳佛教。 527年至528年間磐井叛亂(由大連物部彈壓)。《日本書紀》記載繼體天皇父彥主人王為應神天皇5世孫。母為垂仁天皇7世孫，振媛（ふりひめ、布利比彌命） 他被認為是日本天皇制形成時代第一位天皇(他的年號顯示此轉變,他也是大和王權第一位天皇),之後提出辛酉年革命,把天皇制提前至公元前660年,他設置了日祠部祭拜天照大御神。 皇子 広國押武金日尊（長子，安閒天皇） 小広國押楯尊（第二子，宣化天皇） 天國押波流岐広庭尊（欽明天皇）<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

前任： 武烈天皇

繼任： 安閒天皇
