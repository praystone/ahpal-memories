日本歷史上之天皇059宇多天皇（887年12月05日897年08月04日） 宇多天皇(867年6月10日－931年9月3日)，名定省(さだみ)，日本第59代天皇(887年12月5日－897年8月4日)。 系譜 宇多天皇是光孝天皇的第七個兒子，母親是桓武天皇的兒子仲野親王之女班子女王(外祖母是漢靈帝孫女後人)。 宇多天皇曾一度臣籍降下，賜姓源氏，名為源定省；後因關白藤原基經的緣故而於仁和3年(887年)<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8月25日恢復皇族身份，並於隔日被冊封為皇太子，同日因光孝天皇駕崩而踐祚，於同年的11月17日舉行即位儀式。 簡歷 他重用了藤原時平和菅原道真而造就了寛平之治。888年(仁和4年)，他命人建造了仁和寺。他是宇多源氏（近江源氏）佐佐木氏的太祖。 家庭 父：光孝天皇 母：班子女王，仲野親王之女。 皇后：藤原溫子，太政大臣藤原基經之女。生均子內親王，後世稱東七條後。 　　　藤原胤子，內大臣藤原高藤之女。生醍醐天皇、敦慶親王、敦固親王、敦賓親王、柔子內親王。 女御：橘義子，參議橘廣相之女。生齊中親王、齋世親王、齊邦親王、君子內親王。 　　　菅原衍子，右大臣菅原道真之女。 　　　橘房子 更衣：源貞子，大納言源昇之女。生依子內親王。 　　　藤原褒子，左大臣藤原時平之女。生雅明親王、載明親王、行明親王。稱京極御息所或是富小路御息所。 　　　藤原氏，大和守藤原繼蔭之女。 　　　王氏，生孚子內親王。 　　　藤原氏，生誨子內親王、季子內親王。 皇子：醍醐天皇 　　　敦慶親王 　　　敦固親王 　　　敦賓親王 　　　齊中親王 　　　齋世親王 　　　齊邦親王 　　　雅明親王 　　　載明親王 　　　行明親王 皇女：均子內親王 　　　柔子內親王 　　　君子內親王 　　　依子內親王 　　　孚子內親王 　　　誨子內親王 　　　季子內親王 逸話 彼是愛玩於貓 諡號 宇多天皇 陵墓 山城國大內山陵宇多野（現今、日本國京都府京都市右京區鳴滝宇多野谷）<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
