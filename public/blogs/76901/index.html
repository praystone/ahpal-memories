棺材板的由來~<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

「棺材板」由於好吃，名稱又怪，故聞名全台，它的創始人是在「沙加里巴」開設「赤崁點心店」已四十幾年的許六一。「棺材板」的做法是將土司麵包切成<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />3公分厚的麵包塊，切去邊皮，放進油鍋裡炸酥，然後挖掉一層約1公分高的表皮，再挖去些麵包心，成盒子狀，注入以雞肝、雞肫、碗豆、馬鈴薯、蝦仁、花枝、奶油糊燴煮而成的作料，再把麵包蓋蓋上。四十多年前，「棺材板」原叫作「雞肝板」，麵包裡裝的是炒熟的雞肝配蕃茄醬。那時還是飯店裡年輕跑堂的許六一，在吃精了口味後，覺得蕃茄醬洋味太重，不如牛奶麵糊鮮美，所以研究改換了部份作料，但仍以雞肝為主，還是叫它「雞肝板」。
