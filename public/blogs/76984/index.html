日本歷史上之天皇069後朱雀天皇（1036年1045年） 後朱雀天皇（ごすざくてんのう、寬弘六年十一月二十五日（1009年12月14日）-寬德二年一月十八日（1045年2月7日）），日本第69代天皇，諱敦良。 他是一條天皇的第三皇子，母為藤原道長女──中宮藤原彰子。後一條天皇剛即位時，原本以敦明親王為皇太子，但敦明親王卻在寬仁元年（1017年）辭退皇太子之位，其後便以敦良親王為皇太子。寬仁五年（1021年），娶藤原道長六女，即姨母藤原嬉子為東宮妃。萬壽二年（1025年），兩人之間生下期待已久的第一王子親仁（後來的後冷泉天皇），然而嬉子卻因產後失調，兩天後便過世了。之後，他又娶道長孫女，即堂妹禎子內親王為妃，生第二王子尊仁（後來的後三條天皇）等一男二女。他的兄長後一條天皇沒有生育皇子便駕崩，此後便由他繼承皇位。 即位後，首先迎娶關白藤原賴通的養女藤原嫄子入宮，立為中宮。其後又陸續將藤原教通之女藤原生子、藤原賴宗之女藤原延子等等迎入後宮，但這些女性都沒有生下皇子。後朱雀天皇在病危之際，決心讓位給親仁親王，並以尊仁親王做下一任的皇太子。寬德二年一月十六日（<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1045年2月5日）讓位，兩天後出家，同日駕崩，享年三十七歲。 后妃・皇子女 皇后：禎子內親王（1013-1094） - 三條天皇第三皇女 第一皇女：良子內親王（1030-1077） - 伊勢齋宮、一品准三宮 第二皇女：娟子內親王（1032-1103） - 賀茂齋院、源俊房室 第二皇子：尊仁親王（後三條天皇）（1034-1073） 中宮：藤原嫄子（1016-1039） - 敦康親王女、關白藤原賴通養女 第三皇女：祐子內親王（1038-1105） - 三品准三宮 第四皇女：禖子內親王（六條齋院）（1039-1096） 尚侍（贈皇太后）：藤原嬉子（1007-1025） - 攝政藤原道長六女 第一皇子：親仁親王（後冷泉天皇）（1025-1068） 女御：藤原生子（1014-1068） - 內大臣藤原教通長女 女御：藤原延子（1016-1095） - 權大納言藤原賴宗次女、脩子內親王養女 第五皇女：正子內親王（押小路齋院）（1045-1114） 在位中的年號 長元（1028年 - 1036年） 長曆（1037年 - 1039年） 長久（1040年 - 1044年） 寬德（1044年 - 1046年） <?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
