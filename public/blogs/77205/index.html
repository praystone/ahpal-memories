日本歷史上之天皇079~六條天皇（1165年08月03日~1168年03月30日）

日本歷史上之天皇079六條天皇（1165年08月03日1168年03月30日） 六條天皇（1164年12月28日－1176年8月23日，長寬二年十一月十四日－安元二年七月十七日），日本第79代天皇（1165年8月3日－1168年3月30日，永萬元年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />六月二十五日－仁安三年二月二十九日在位）。名順仁。後禪位成為上皇。是目前為止日本歷史上最年幼的天皇和上皇。 家庭 二條天皇第二皇子，生母為下級貴族伊岐致遠的女兒（名不詳）。因生母出身不顯，二條天皇皇后、藤原氏貴族藤原育子以養母身份撫育天皇并行母后職責。 天皇早逝，無後妃兒女。 踐祚 永萬元年（1165年）二條天皇病重，於六月二十五日（8月3日）冊立尚在襁褓的順仁（六條天皇）為親王，立為太子，並於當日禪讓，七月二十七日（9月4日）舉行六條天皇踐祚儀式，翌日二條天皇駕崩。 六條天皇受禪時出生僅7個月零11日，是日本最年幼的天皇。踐祚儀式一度因天皇哭泣而中斷，由乳母（藤原公長女、藤原邦綱母，名不詳）為其哺乳並由藤原育子懷抱天皇登御座才使儀式進行下去。 政治 二條天皇在位期間，曾因親政問題與後白河上皇產生矛盾，貴族中亦產生支持後白河上皇的院政派與支持二條天皇的親政派。雖二條天皇終得以逼退後白河上皇院政影響，但卻形成與後白河上皇對立的局面。二條天皇駕崩後，後白河上皇仍健在，親政派轉而支持二條天皇繼續與親政派對抗。 六條天皇甫即位，親政派人物關白大臣藤原氏貴族領袖近衛基実（藤原育子族兄）轉而出任摂政大臣，加之藤原育子與親政派合作，總體上朝廷仍然是親政派主政局面，但因天皇年幼政局不安定導致後白河上皇政治影響開始回復。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

永萬元年十一月十六日（1165年12月25日）後白河上皇冊立其寵愛的第七子憲仁（二條天皇異母弟，即後來高倉天皇）為親王。按當時原則，嫡出皇子方可冊立為親王，後白河上皇此舉意在使庶出的憲仁擁有皇位繼承權。 永萬二年七月廿六日（1166年8月23日），親政派核心人物摂政大臣藤原氏領袖近衛基実暴病身亡，其嫡子近衛基通年幼無法襲承父職。翌日，在後白河上皇勢力的支持下，松殿基房就任新任摂政和藤原氏領袖。永萬二年十一月十一日（1166年12月5日），朝廷職位答覆變更：院政派勢力開始凌駕親政派之上。迫於形勢，近衛基実之後親政派當軸人物藤原経宗向後白河上皇表示恭順的姿態並結交院政派人物，至此親政派日趨瓦解。

禪讓 仁安三年二月廿九日（1668年3月30日），在祖父後白河上皇的主導下，六條天皇禪讓於叔父憲仁親王，被尊為六條上皇，其時年僅3歲零3個月，為日本最年幼的上皇。 駕崩 安元二年七月十七日（1176年8月23日），六條上皇駕崩，年僅11歲零8個月。死因據說是罹患痢疾。葬於京都清閑寺陵。 父親： 二條天皇 母親： 伊岐致遠女 陵墓： 清閑寺陵
