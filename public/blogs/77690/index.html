日本歷史上之天皇096~後醍醐天皇（1318年03月29日~1336年09月18日）

日本歷史上之天皇096後醍醐天皇（1318年03月29日1336年09月18日） 後醍醐天皇（正應元年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十一月初二（1288年11月26日）－延元四年/曆應二年八月十六（1339年9月19日））為日本第九十六代天皇（1318年3月29日—1336年9月18日在位），諱尊治。 生平 在德治三年（1308年）被持明院統的花園天皇立為皇太子，在文保二年（1318年）因為花園天皇讓位之故以三十一歲的壯年登基。 在足利尊氏於1332年擁立持明院統的光嚴天皇後，作為大覺寺統代表的後醍醐天皇逃至大和的吉野，從此開始了日本的南北朝時代。 在鎌倉幕府滅亡後建立建武新政。1335年，中先代之亂更是讓足利尊氏成功反叛後醍醐天皇的契機。 系譜 父親： 後宇多天皇 母親： 藤原忠子 中宮： 西園寺禧子 珣子內親王 陵墓・靈廟 塔尾陵<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
