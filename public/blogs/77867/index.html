東方美人茶的由來~

清朝嘉慶年間，柯朝氏自福建省武夷山引入烏龍茶茶種，種植於魚桀魚，在石碇山中的茶農挑到西街集順廟埕販賣的茶被茶商收購後，運至大稻埕精製，再透過洋行外銷英、美。當時石碇人採新葉末端尖葉製茶，歐洲人很喜歡茶葉，泡水後豎立水中如花朵般的模樣，將之比擬為體態玲瓏的東方女子，於是暱稱為「東方美人茶」，又稱為「香檳烏龍」。椪風茶名字的由來，據說是一位不信邪的茶農，用遭茶小綠葉蟬 ( Tea green leaf-hopper, 學名Jacobiasca formosana Paol i，一種茶樹害蟲 ) 刺吸危害的茶樹嫩芽，加以製成茶葉後，拿出去賣，卻意外的大受歡迎。當這位茶農將它銷售的情形向自己附近茶農說起時，卻被其他人說他在「椪風」 ( 吹牛 ) ，而使得該茶農的茶葉被稱為「椪風茶」。又 相傳百年前，英國商人將此茶呈現給英國女皇品嚐，女皇對其 獨特果香與蜜香的口感，以及外表炫麗斑斕、宛如絕色佳人，愛不釋手，加上因產於東方的福爾摩莎寶島台灣，故賜名為「東方美人茶」。

而我們一般聽到的「椪風茶」為台灣烏龍茶高級品之俗稱，指的也就是「東方美人茶」，為本省特產茶類，係台灣茶早期外銷的主力，聞名於歐美。 「東方美人茶」為部份發酵茶類中發酵程度最重的一種，外觀艷麗，滋味醇厚，以臺北縣石碇鄉所產最負盛名，不同於新竹北埔、峨嵋的東方美人茶，而坪林所產的東方美人茶多了股「梨子氣」，這是在坪林石碇一帶產的才有的味道，風味獨特。 「東方美人茶」在台灣依等級又分為 (1)白毫烏龍(取其高級品皆帶有白茸毛的芽尖) (2)紅仔茶(取其水色為橙紅琥珀色) (3)椪風仔(取其水色為黃橙色) (4)番莊仔(取其水色為綠色) (5)金烏龍(取其水色為褐色) 所以白毫烏龍茶是東方美人茶的極品，是東方美人茶的一種，但不能說統稱東方美人茶為白毫烏龍茶。
