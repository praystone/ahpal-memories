2006臺灣四百年人物誌之戰後時期~陳偉仁(臺灣作家) 陳偉仁，是台灣知名軟體公司友立資訊的創辦人之一，也是一名虔誠的基督徒。 早年生活 陳偉仁於逢甲大學資訊工程學系(電子計算機科學系)畢業，於1981年進入台灣電力公司服務，利用個人電腦在CP/M系統上開發「圖形線上電壓與電流監視系統」。 1983年到1985年期間在交通大學進修，完成計算機工程碩士的學位。畢業後進入資訊工業策進會服務，開發出全世界第一套在Microsoft Windows 1.0的黑白影像處理程式，並陸續與台灣的全友電腦、宏碁、東元科技，日本的Ricoh以及義大利Olivetti等公司的影像掃描器搭售，行銷到世界各地。1988年，陳偉仁獲選為中華民國資訊產業十大傑出人物之一。 創立友立資訊 1989年與另兩位夥伴陳學群及廖敏芳創立友立資訊，隔年開發全世界第一套在Microsoft Windows 2.0的全彩影像處理程式La Palette，與包括HP、全友電腦等許多世界知名的彩色影像掃描器搭售，並開始進入全世界的零售市場。後來繼續參與PhotoStyler、ImagePals及PhotoImpact等產品的研發。在影像處理的套裝軟體領域當中，他負責的產品都曾多次榮獲歐、美、日等知名媒體的肯定，對影像核心技術與產品定義有深入的研究。 生涯轉型 2001年起擔任友立資訊董事長並兼任總經理，直到2005年4月友立資訊被美國英特維數位科技收購後才退休離開友立資訊經營團隊。退休後完成台灣大學EMBA課程學業並從事志工活動，並自2006年1月起每個星期五晚上八點半在基督教佳音電台主持廣播節目「新詩部落格」。 目前為基督教台北信友堂長老，同時也是台灣世界展望會副會長。也是一名文字創作者及攝影家，涉獵於散文、童書、新詩等文體創作，並出版詩集「旅行詩篇」及開攝影展。 2006年11月28日出版他的第一本童書「胖子尋寶」。 2011年3月離開世界展望會後，目前仍繼續從事社會福利與團體組織改造工作。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
