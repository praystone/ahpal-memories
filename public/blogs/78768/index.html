外銷講究包裝

 rn 弟弟和妹妹都到了愛漂亮的年齡，對身上的衣著很講究。但是媽媽常為妹妹添購新衣，而忽略了弟弟。

為此，弟弟很不開心，說媽媽偏心。而媽媽卻有她的理由，說：「外銷的東西，要特別講究包裝。」

   

離家出走

 rn 兒子提著一個很大的提包準備離家出走，經過客廳時，

 rn 看見爸爸似乎欲言又止，於是對他就對爸爸說：

 rn 「這個家實在太沉悶了，我再也忍受不下去了！我要離開！

 rn 我要自己去過那種天天有刺激！天天花天酒地，天天有漂亮美眉的生活。 爸爸，誰都不能阻止我。」

 rn 爸爸終於開口說話了，他說：

 rn 「我才沒有，你等我一下，我馬上準備行李和你一起去。」

   

讚美

 rn 妻子在穿衣鏡前試新衣，回頭問丈夫：好看嗎？

 rn 丈夫把視線從報紙移開，瞥了她一眼，沒吭聲。

 rn 妻子生氣地說：馬克吐溫說過「一句讚美的話，可以讓我活兩個月」，

 你怎麼就不試著對我說幾句讚美的話？ 丈夫答：好吧！那你想活多久？

   

有一半嗎?

 rn 我今天去了百貨公司

 rn 看到一對夫婦…說了讓我在旁邊昏倒的話

 rn 老婆看到喜歡的戒指，拉著老公過去看

 rn 看了一下子，老公問老婆：「真的喜歡嗎?」

 rn 老婆一直點頭…. 帶著懇求的眼神

 rn 於是老公問店員：「請問，這個戒指多少錢呀?」

 rn 店員說：「打過折，八千八百八十八元~」

 rn 老公本來要付錢的，這時候他老婆竟然說：「老公..看你那麼體貼我也付一半價錢….」

 rn 聽完老公一定很開心，我跟店員的想法應該一樣

 rn 有這種老婆應該很不錯，會幫自己分擔但是沒想到………….

 rn 他老婆掏出了八十八元 ，說道:「老公我出一半了，剩下的交給你………………」

   

  特異能力

 rn 有一位探險家到美國西部探險，紮營時一位當地的印地安土著跑了過來對他說：「今天會下雨。」

 rn 探險家也沒在意繼續工作，不料到了晚上果然下起大雨。

 rn 第二天那土著又跑來了，說道下午會颳大風。探險家給了他十塊錢謝謝他，而當天下午果然也刮起風來。

 rn 如此過了一個禮拜，那土著每天跑來報告天氣，探險家也每次都給他十塊錢，

而每天的天氣也果然如土著所預言的一樣。探險家心中十分佩服土著的特異能力，簡直比氣象報告還準。

 rn 這一天，土著又跑來了，可是一句話也沒說。

 rn 探險家奇道：「你今天為什麼不預報天氣了呢？」

 rn 「因為我的收音機壞了」土著答道

   

  不要亂答腔 ~~

 rn 男人在高速公路休息站停車上洗手間

 rn 第一間有人，於是他進了第二間。

 rn 一坐上馬桶，就聽到隔壁的人說：「嗨，怎樣，一切還好吧？」

 rn 男人覺得上廁所時和人攀談怪怪的，不過為了不失禮，

 rn 還是回答了：「還過得去啦！」

 rn 然後隔壁的人又說：「你在忙什麼？」

 rn 男人覺得有點奇怪，不過還是答道：「我要去台中出差。」

 rn 這時聽到隔壁的人說： 我等一下再打給你。我旁邊有個神經病，每次我和你說話，他都搶著回答

 rn   

  超速的藉口

 rn 一位警官想使一輛超速行駛的車子停下，

 rn 但那司機卻逐漸地加快了速度，一直加到100英里/每小時。

 rn 當他意識到終究無法逃脫時，只好開到路邊停了下來。

 rn 警官過來對他說：

 rn 「上了一天的班，我也差不多要下班了，這樣吧，

如果你能為你的逃跑行為找一個好的借口，我就放過你。」

 rn 那司機想了幾秒鐘後說：

 rn 「我妻子在大約一個星期前跟一個警察跑了，

我以為你想把她送回來給我，所以我就拚命逃了。」
