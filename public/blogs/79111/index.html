以下CSS是整個日誌的結構

基本上是所有的圖片位置全都不顯示透明化了

只有藍色網址位置是整個背景圖顯示

(這是螞蟻下面css網址提供的背景圖)

<STYLE type=text/css> BODY{background-image : url(http://devoted-protect.myweb.hinet.net/CSS/0555.jpg);background- repeat:repeat;background-attachment : fixed;background-position :50% 50%;}#membernotemenu_menu li img { display: none;  }#comment_message {background: transparent;color:black;}.comments_list .quote { background: transparent;} #header { background: transparent; }#header .headerwarp { background: transparent; }
