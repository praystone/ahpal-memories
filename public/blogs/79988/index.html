116台北市文山區沿革~ 　　本區位於臺北市南郊，為通往新店、深坑、宜蘭必經要道，其地勢為一小型盆地。開拓之初，到處污泥、荊棘；乾隆年間，先民由景美沿溪入墾，至嘉慶道光之際漸成街肆，西邊設有萬盛、興福兩莊，東邊沿溪以木椿圍柵以拒山胞來襲，漸成部落，故有木柵、霧裡薛社、內湖莊之產生，沿用甚久；至同治年間隸屬淡水廳，又稱木柵莊、內湖莊、木見尾街；光緒初年置臺北府，仍屬淡水廳。 　　臺灣光復初期、隸屬臺北縣深坑鄉；民國三十九年三月一日政府為推行政令之需要，乃將深坑鄉劃分為景美鎮、木柵鄉、深坑鄉三鄉鎮；民國五十七年七月一日景美鎮、木柵鄉改隸臺北市，變更為景美、木柵兩區；民國七十九年三月十二日行政區域調整，又將景美、木柵兩區合併為文山區。 資料來源 : http://163.29.36.87/cgi-bin/SM_theme?page=43b21f69#3 杏花林 春遊行腳到木柵杏花林　　 99年花季預計<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />2月1日開始        洽詢電話：29394866  29369367 張金頂先生 台北位處盆地，山林野外隨處可看見春天的芳蹤。以茶聞名的木柵貓空， 就有一片正值花季廣達二甲的杏花林，置身其中觸目所見，青鬱蒼蔚間斑斕翻飛，仲春二月，品春茗、賞春花，正是時候。前往貓空爬山者，不乏茶道中人，殊不知山道、茶道與花道原可異途同歸，三合一盡得春遊之樂，杏花林即堪稱典型。 沿著木柵走木新路二段轉恆光街至老泉街口，已是山坡地，進入老泉街不久，就有櫻花及杏花兩側夾道，號稱北台灣最大的杏花園區….貓空杏花林，二月上旬已到了賞花季，由於今年立春時序較遲，花季也較晚登場，杏花將持續至三月中旬後，目前正是盛開期間。 此杏花林是茶農張家的私人花園，園區開放免費入園，數以千計的杏樹全由張丁頂老先生一手裁種，分為三區，每區均鋪設了石板步道，曲徑通幽，不時可見樹齡達數十年的老杏樹，枝幹蒼勁挺拔，卻不減花朵柔麗的姿態；又或碰到正在蒔花弄草的張老伯，攀談幾句，恍若回到農家的鄰里閒聊。張老先生今年已八十歲，是世代茶農，在貓空闢有四甲的茶園，因年事已高，茶園的經營已交由後代接手，他的兒子就在杏花林間開設了一間茶館。 杏花本是張老先生在茶農退休後出於雅趣而開始裁培，卻大放異彩，成為貓空廣褒的茶園中獨樹一幟的美景，在此喝茶聊天看花賞景，別有風味。想帶把杏花回去，200 元可以買到，特製的金棗膏、桂圓薑母膏、蘿蔔乾、福菜及杏花露別具風味，都是道地「土」產。「杏花林」茶館平常只在晚間開放，但花季期間從早上就開始營業。前往杏花林，可從木新路二段轉入恆光街，沿指標上山即可。 地址：老泉街45巷27號之3 文通：236、251、512、指南客運1、3路，在木柵下車，轉搭小型公車10路，在瓦厝站下車 指南宮 一．位置與沿革 位於猴山坑上海拔二百三十公尺，創建於清光緒年間，據說景尾（景美）鄉人聽說艋舺玉清齋雕刻店自雕「孚佑帝君呂洞賓」像奉祀，十分靈驗，而請求另雕一尊，迎回景尾供奉，後來信徒越來越多，所以建議蓋廟。在清光緒十七年（一八九一年）經邑紳張德明奔走，在現址蓋一小廟，清光緒三十年（一九0四年）擴充，至一九二一年向各地募款，乃大興土木，請來大木匠師陳應彬修建，陳應彬為當時台灣傳統建築界之大師，建此廟時極為用心，而指南宮也成為陳應彬後期的代表作品。後來指南宮規模逐漸發展，增建了「凌霄寶殿」（道）、「大雄寶殿」（佛）及「大成殿」（儒），並於近年修建本殿，將來可成儒、釋、道三教合一之宗教聖地。 二．神明由來及傳說 孚佑帝君呂洞賓，即民間俗稱之「呂純陽」、「純陽夫子」、「仙公」，據說祂是唐朝京兆人（西安），本姓李，為唐朝皇室之宗親；出生時，滿室異香，仙樂喧然，一真人騎鶴自空中降下；自小聰穎，十歲便會做文章，二十歲就頗有聲名，後來中了進士派任縣官，但當時天下大亂，所以棄官入山修道，恰好找到一個有兩個出入口的山洞，就以「呂」為姓（雙『口』），自身為洞中之賓客，取名「洞賓」。潛心修煉，後遇漢鍾離，二人共同修道，終成大羅神仙。 傳說：相傳「臭頭皇帝」朱元璋每次請人剔頭時，理髮師都會弄破朱元璋的「惡瘡」（臭頭），使得他痛得哇哇大叫，極為生氣，立刻叫人將理髮師「拖出去砍了」。接連許多理髮師因此而喪命，呂洞賓對此非常不忍心，就下凡化為理髮師為朱元璋剔頭，結果不但沒有弄痛朱元璋，反而把朱元璋的「臭頭」治好了。從此以後，凡間的理髮師奉呂洞賓為「保護神」。 三．參觀建議： 上指南宮，最方便的方法是搭指南客運直接上山，但是這樣會遺漏許多自然的風光，和失去活動筋骨的機會，建議從山腳下，沿著步道慢慢的走上來，這樣不但能活動筋骨，呼吸新鮮空氣，而且可以注意看些植物、鳥類或風景。從步道上山後，再到各殿去拜拜參觀，如指南宮、大雄寶殿、凌霄寶殿、大成殿等，比較各神明雕像的不同，並和同學討論或請師長解釋各神明的故事。 四．古蹟保存討論 指南宮正在修建，因為中國傳統建築內部大都用木材，木材很容易因潮溼、蟲蛀….原因而損壞，大約一甲子（六十年）就要大修，上次大修是民國十年，距離現在也七十幾年了，所以必須修建。因此，在進入指南宮的二側，可以看到磚頭、銅瓦、募款說明等，也可以見到工人正在工作的情形，但是我們也看到了粗糙的水泥建築，和老照片看到的精美建築完全不同，我們可以討論下面幾個題目： 1.水泥的堅固但粗糙，和木材的精緻但易壞，如何選擇呢？ 2.木材雕刻師傳越來越少，怎麼辦？ 3.是不是用水泥來建能夠精緻些呢？ 地址：木柵萬壽路115號 交通：搭公車２３６、２３７或282路至政大站下車，沿公路步行５０分鐘即可達或搭指南客運530至指南宮下車。 <?xml:namespace prefix = o ns =
