背景漸層

 

漸層效果~

body {background: url(放上圖片網址) repeat-x center top ; color: purple ; }

注意~  repeat-x

 

body {background: url(圖區.jpg) repeat-x center top fixed white; color : blue ;}

由上而下  由藍至白~

如果要做橫向漸層  就必須先做圖檔旋轉 則效果就是由左或右開始~ body {background: url(圖區.jpg) repeat-y left  top fixed white; color : blue ;}

body {background: url(圖區.jpg) repeat-y right  top fixed white; color : blue ;}

兩個都是縱向重複  一左一右

   /全版預設整體字體-顏色-字型-大小(其它架框項目無設定時，在此可能影響)/ BODY {color:#FFFF00;Font-Family: 新細明體;Font-Size:115%;}

 

在此貼上音樂IP&ar=1&as=1” width=“130” height=“45”> 以上音樂語法解說 : amp;ar=1  (數字1為重複播放 0為不重複) amp;as=1  (數字1為自動播放 0為手動) width=“130” (數字130為播放器寬度，數字越大越寬) height=“45” (數字45為播放器高度，數字越大越高)   如欲設為隱藏，只需將語法中130及45都改成1 即成隱藏的播放器

 

 

＊CSS＊ 在主頁設置youtube影片（新版）

 

擷取下來的程式碼 <iframe width=“560” height=“349” src=“http://www.youtube.com/embed/qPMH6y4AzGM" frameborder=“0” allowfullscreen></iframe>

先把"去掉             (p.s.注意不要刪到空格) 然後allowfullscreen也去掉 就變成 <iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0 ></iframe>

 

修改過後程式碼，再去掉<>後，分成兩段 第一段 iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0 第二段 /iframe    (p.s.注意斜線不要去掉)

依照下面標示的位置放進去 body{over:expressio\6e(((this.className=='l'))||(i=function(){s=documen\74.getElementById('位置');s.innerHTML='\3C 從這開始放第一段  \3E \3C這裡是第二段\3E' + s.innerHTML ;},i(),this.className='l'))}

註：其實 < 跟 > 即是上面css語法中的 \3C 跟 \3E

 

最後填入位置就成下面這樣！ body{over:expressio\6e(((this.className=='l'))||(i=function(){s=documen\74.getElementById('位置');s.innerHTML='\3C iframe width=560 height=349 src=http://www.youtube.com/embed/qPMH6y4AzGM frameborder=0  \3E \3C/iframe\3E' + s.innerHTML ;},i(),this.className='l'))}
