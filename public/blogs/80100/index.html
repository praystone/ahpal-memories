204基隆市安樂區沿革~      本區在清領時代亦稱基隆堡，日據初期，曾創設大武崙庄、蚵殼港庄，外加內木山庄，大竿林庄，均屬基隆廳。日據沿用清代行政區劃至民國9年10月1日地方制度改革，廢庄為大字，為地籍名字，屬基隆街。（民國<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />13年12月25日屬基隆市）。      至民國13年（西曆1924年，大正13）改庄為町，民國30年10月1日因應都市發展，蚵殼港變更為觀音町、寶町、西町、（大武崙仍為大字），民國31年各町及大字設區會，太平洋戰爭發生後合併為第10第14兩區會，先後乃將原有區會（觀音區、寶區、西區、大武崙區）改為第四區，嗣民國35年1月改稱安樂區。   並將全區劃分為21里，嗣後於民國37年、41年、54年、60年、67年、68年、73年區轄各里均經部份調整，迄民國77年3月市政府為因應本市7區未來均衡發展態勢，特將行政區域作一重大調整。本區原轄之西華、西榮、西定、西康、德和、德安、中和等七里劃歸中山區，原隸七堵區之鶯歌、七賢、四維、三民、五福、六合等6里歸併本區，87年由五福里增編長樂里、新崙里增編武崙里，91年外寮里增編興寮里、鶯歌里增編鶯安里，95年由三民里增編壯觀里。     行政區域調整後本區現轄25個里，共計636鄰，面積由180,250平方公里（約占全市總面積13.4％）略增為204,320平方公里（約占全市總面積13.58％）。本區現有人口數為85,116人（100年9月底統計），面積為全市第三位、人口數居全市之冠。 資料來源 : http://www.klal.gov.tw/know/vicissitudes.asp<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
