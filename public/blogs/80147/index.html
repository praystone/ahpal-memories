208新北市金山區沿革~ 開發簡史 　　本鄉轄屬範圍原是一大森林地帶，傳說中先有本省北部原住民「平埔番」二十多人，因補魚遭遇颱風，漂至本鄉海岸，上陸覓食，見荒蕪而離去，遂沿海尋至貢寮鄉安住，爾後數百年，經由其子孫形成三紹四社，大雞籠社，金包里社等，嗣後再經歲月，子孫日益繁殖，三紹四社漸向蘭陽地方分佈，大雞籠社漸向台北平原分佈，金包里沿北部海岸漸向淡水分佈，於是「平埔番」分佈台灣北部地方。據聞本鄉在台灣北部開發史中，早由「平埔番」開拓。「金包里」之名稱，也是照番語口音基巴里翻譯漢字而來，此即本鄉早期開拓史中之雛型。 　　到乾隆末年至道光年代，有福建「漳」、「泉」二州移民來此，慢慢開拓，人口逐漸增多，致有漢番之媾婚。 　　遠溯清康熙時，即在金包里街興起土木，雍正間已聚成街市。其後至嘉慶年間，即西元一八００年代，福建各地又相繼有人渡海前來，積極投入屯墾，並落地生根，繁衍子孫後代，將本鄉開拓史帶入中期，此亦即我大部份鄉民始祖之由來，可從各姓氏之家譜及祖先墓碑上或家中供奉歷代神祇牌位上所載之文字證之。 行政區域變遷 　　日本佔據台灣時，本地稱為金包里堡，時有土匪竄匿此地，匪魁簡大獅將本堡作為根據地。 　　金包里街係本鄉唯一市集，日據時將軍隊、憲兵、警察官等駐在此地，施行軍政。民前十七年軍政組織中，臨時行政機關設保良局，總局設在大稻埕。而設分局於士林、新莊、基隆、金包里、頂雙溪等地。民前十六年廢保良局、成立台北縣、下設基隆廳、金包里隸屬該廳，當時分為中股外三莊，設區長。民前十五年六月十四日成立台北縣直轄金包里辦務署，管轄八區，包括萬里鄉全部及石門鄉下角。同年六月二十九日改隸台北縣基隆辦務署、金包里支署管轄。民前十二年十<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />二月九日廢台北縣，改隸基隆廳金包里支廳。時本地飲用水不足，鼓勵百姓鑽井補充用水，約莫經過十年，始設下水道，供給一般民眾使用。民國四年二月廢基隆廳，改屬台北廳金包里支廳管轄。包括下萬里加投莊，設金山莊，隸屬台北州基隆郡管轄，自治機關設金山莊役場，置莊長，下分十八區，各區置區總代，警察機關設金山分室。同時下萬里加投劃歸萬里莊管轄。民國七年末，人口統計：內地人（日本人）五十四人，本島人一千七十二人，支那人（中國人）二人，計有二百三十五戶。 　　民國九年金包里改稱金山，本省光復後，照原金山莊區域改設金山鄉，隸屬台北縣。 　　昔日本鄉共轄有十七村，後將永樂、民興合併為永興村；重光、三和合併為重和村；五福、南湖合併為五湖村；故今日共轄十四村。 村里名由來 和平村：昔日稱為金裡村，因金包里地區而得名。 大同村：屬於昔日金包里莊地區，原稱金鄉村。 豐漁村：原名水尾村，因位於金包里溪與磺潭溪匯集出海口而名之，因本村係為漁村，期望漁獲豐收，而更名為豐漁村。 磺港村：此地為一港灣，因係磺溪入海口處而得村名。 美田村：早期於水田之中心建莊，所以稱為田心子，今稱美田。 五湖村：原為五福與南湖兩村分別所轄，後因行政區域調整而合併，再各取其中一字為村名。 重和村：行政區域調整，將重光、三和兩村合併稱之。 兩湖村：以葵扇湖和倒照湖兩角落組成，以該兩湖而得名。 六股村：昔名為六股莊，今名六股村。 三界村：早期鄉民於本村籌建三界公廟，名為三界壇。 清泉村：因此地有清水溪、後方有西勢溪，水清澄靜，乃稱清泉村。 西湖村：本村有一西勢湖，位於西方山腳下，村名由來。 萬壽村：取吉利之名為萬壽。 永興村：合併永樂、民興兩村，各取一字為村名。 旅遊名勝<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
