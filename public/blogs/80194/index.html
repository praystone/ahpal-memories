「大台北」烏來祕境泡湯 綠林相隨

✍️ 愛德華二世 📅 2012-01-03

作者：愛德華二世

發文：2012-01-03

瀏覽：44 次 ｜ 回應：0 則

烏來擁有天然溫泉水質，車行到新烏路後一路蓊鬱綠林相隨，空氣清新，從五星級溫泉酒店到特色旅館都任君選擇，西式蔬食、小吃、甕仔雞等變化多端，每年泡湯季節都是最佳去處。

戶外大眾池對著溪水，空氣清新，很受顧客喜愛。

   馥蘭朵烏來渡假酒店 蟬聯全球票選﹁亞洲最佳服務度假飯店﹂殊榮的春秋烏來，於今年改名為馥蘭朵烏來，為義大利文的「飛翔」之意，Logo上改為2隻展翅的蝴蝶，但以山水為背景、點綴原民文化的簡約設計不變，精緻的貼心服務依舊，但當湖畔傳來太鼓打擊樂時，碧綠南勢溪旁落地玻璃窗前，蓮花銅雕彷彿被精靈點活了生命一樣，裊娜的姿態在陽光下熠熠生輝，音樂劇場不定時展開多場大提琴、聲樂、原民音樂表演，現場激盪出空靈樂章，這是改名後新注入的藝術力量，「即淨音」、「繞空鼓」、「棋不語」等表演都頗受好評。 DATA 地址：新北市烏來區堰堤3號 電話：（02）2661-6555 公休日：無 刷卡：皆可 交通：開車走二高下新店交流道，走北新路右轉新烏路往烏來，於左側見到烏來區公所再往前行100公尺可抵。 泡湯DATA 設施：大浴場850元起／人／4hr，景觀湯屋1080元起／2人／1hr，湯屋套房1800元起／2人／1hr。 開放時間：08：00～24：00 泉質：碳酸氫鈉泉

柴燒披薩套餐（香草洋芋）360元／窯烤披薩逢假日提供，使用主婦聯盟的全麥麵粉，口味多且具特色；無菜單料理與晚餐需提前預約。

西雅圖的天空 原名天邊的家，Chloe因愛上山間生活頂下餐廳，重新粉刷打造童話氛圍，香草園、鞦韆都是最佳取景處。找來Bagel Bagel餐廳主廚掌廚，打造獨特創意西式蔬食，主菜之一岩鹽破冰船很有創意，以焢窯概念燜煮蔬菜與鮮菇，米粒飽含蔬菜汁與蔥油香，鮮味十足。 DATA 地址：新北市烏來區忠治村金堰113-1號 電話：（02）2661-6679 營業時間：11：00～20：30 公休日：一 刷卡：不可 席位：100席 交通：開車走二高下新店交流道，走北新路右轉新烏路往烏來，過日月光溫泉直行至忠治左轉上山，沿大桶山步道路標至叉路右轉前行可抵。 網址：www.facebook.com/seattle.wulai 備註：晚餐及無菜單料理需事先預約

名為泰雅之湯的主題湯屋採半開放式，湯煙緩緩繚繞，與周邊自然景致相映。

璞石麗緻溫泉會館璞石麗緻緊臨堰堤，以獨具的美感設計，營造出極簡的美學風格，加以6大主題造景，添增泡湯樂趣。講究湯質與泉源，讓遊客在泡湯除了能將烏來的好山水盡收眼底，還能洗滌煩悶心靈，打造自然中的樸實感。 DATA 地址：新北市烏來區堰堤路61號 電話：（02）2661-8000 公休日：無 刷卡：皆可 交通：搭捷運新店線在「新店站」下車，轉乘新店客運往烏來方向即可抵。 泡湯DATA 設施：大眾湯810元；五六900元／人，主題湯屋2250元；五六2500元／2人／1.5hr，主題客房湯屋3150元；五六3500元／2人／1.5hr，景致湯屋1710元；五六1900元／2人／1.5hr 開放時間：大眾湯08：00～22：00，湯屋24hr 泉質：碳酸氫鈉泉

半戶外的露天裸湯池，搭配周圍清幽的山水景色，宛如置身山中般輕幽。

箱根苑 箱根苑緊傍南勢溪，擁有270度的絕佳視野，露天風呂及湯屋設計獨具，流露出濃濃和風味，採用下崁式的浴池，增加旅客的安全措施，房裡的大片落地窗，可一覽寬闊景致，並貼心送上泡湯甜品，給旅客由內而外的全方位溫暖服務。 DATA 地址：新北市烏來區新烏路堰堤77號 電話：（02）2661-6688 公休日：無 刷卡：可（AE、大來除外） 交通：開車走二高下新店交流道，走中興路接北宜路一段，右轉新烏路循指標可抵。 泡湯DATA 設施：大眾男女裸湯500元／人，雅致湯屋800元／2人／1.5hr，景觀湯屋1200元／2人／1.5hr 開放時間：大眾湯10：00～23：00，湯屋24hr 泉質：碳酸氫鈉泉

室內家庭湯屋有別於露天湯屋，享受更私密的泡湯。

烏來名湯溫泉會館 環境清幽僻靜的烏來名湯，到這享受溫泉還能聽到壯麗的溪流聲響，熱呼呼的湯泉如瀑布般流下，清澈乾淨的泉質洗淨一身疲意，簡單大方的大眾湯維持日式溫泉裸浴風格，池底的小圓石兼具按摩效果，讓烏來名湯始終人氣居高不下。 DATA 地址：新北市烏來區啦卡路36號 電話：（02）2661-6161 公休日：無 刷卡：可（AE、大來） 交通：開車走二高下新店交流道，走中興路接北宜路，右轉新屋路直行，過烏來派出所經老街接啦卡路可抵。 泡湯DATA 設施：大眾湯600元／人，室外露天湯屋800元／人／1hr，室內家庭湯屋600元／人／1hr 開放時間：大眾湯08：00～23：00，湯屋24hr 泉質：碳酸氫鈉泉
