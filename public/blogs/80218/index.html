224新北市瑞芳區沿革~ 開發簡史 　　乾隆末年，漢人對台北盆地的開闢大抵完成，而噶瑪蘭則於嘉慶十七年開闢完成，據此推論，漢人對位於這兩個地區的平溪、瑞芳及雙溪諸丘陵地區的開闢，應為乾隆年間以後陸續進行的。 　　清嘉慶年間，有人自福建引入武夷茶於深坑種植，至咸豐年間（1860年左右），茶葉及樟腦便成為包含本區的整個北部丘陵的重要產業。而漢移民的拓墾，則逐漸形成了小村及孤屋為主的散村聚落，零星地分布在基隆河及其支流的河岸階地上。而瑞芳鎮地名之由來，係先民因當時交通不便，瑞芳為由台北、基隆往返噶瑪蘭（即現今之宜蘭）地區者必經之地，且本鎮金瓜石、九份採礦者，必先經由目前之柑坪里上山，適時柑坪里有一家商店店名「瑞芳」，為上山者中途補給、休息處所。久之，往來者眾，均不約而同或口頭相約「瑞芳」聚集同行，沿襲成名。<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

行政區域變遷 　　民前十七年（光緒廿一年），清廷與日本簽訂馬關條約，將台澎割讓日本，日人佔據後，將行政區設「瑞芳庄」、「基隆郡」、「台北州」，瑞芳庄屬基隆郡管轄。瑞芳庄之興起與金、煤礦之開採有著非常密切的關係，就業人口幾佔全庄一半，依戶政機關現有統計人口數最高時達七萬餘人，另加未設籍人口更曾高達十餘萬人。 　　民國卅四年，台灣光復，同年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />十一月二十七日政府派李建興先生為代理街長，隨即將行政區改稱「台北縣瑞芳鎮」，編訂四十二里，復因礦業沒落，人口外流，改為目前三十四里。

村里名由來 龍潭里：民國三十五年設立。昔日為龍潭渚莊地區皆以龍名之，因有一水潭，故以名之。 龍興里：民國五十九年十二月一日設立。由龍潭里劃出，因該里為新興地區，故命名龍興。 龍鎮里：民國三十五年設立。昔日為龍潭渚莊地區皆以龍名之，為鎮公所在地。 龍安里：民國三十五年設立。昔日為龍潭渚莊地區皆以龍名之，該里有一土地公廟，保佑里民平安，故以名之。 龍川里：民國三十五年設立。昔日為龍潭渚莊地區皆以龍名之，該里鄰靠基隆河，故以名之。 龍山里：民國三十五年設立。昔日為龍潭渚莊地區皆以龍名之，因靠山邊，故名之龍山。 爪峰里：民國三十五年設立。以三爪子莊得名，其地有山脈三支如人手指故名。 東和里：民國五十九年十二月一日設立。由爪峰里劃出，其地有東和煤況，故以命名。 柑坪里：民國三十五年設立。以昔日柑子瀨莊得名，地沿基隆河，有淺水成瀨，附近栽培柑樹以名。 侯硐里：民國三十五年設立。本里劉厝有一石洞聚集猴子，故命名猴洞，後改為侯硐。 弓橋里：民國三十五年設立。以芎橋莊得名，昔日莊有小橋係以九芎柴所造，故命名。 光復里：民國三十五年設立。昔為柴寮，為紀念台灣光復而命名。 碩仁里：民國三十五年設立。緣雅麗語立名，由地方士紳廖宗斯命名。 傑魚里：民國三十五年設立。該里地產鮚魚而命名，原稱鮚魚坑，因鮚字不雅，故改為傑魚。 上天里：民國三十五年設立。因尪子上天莊得名，該地有山峰，狀似人形上入雲霄，故名。 吉慶里：民國三十五年設立。緣吉祥語立名，為昔日大埔坑及大坑內二莊地區。 吉安里：民國五十九年十二月一日設立。由吉慶里劃出，因該里有吉安宮廟宇，因之命名。 頌德里：民國三十五年設立。該里因有台陽礦業紀念開礦先賢所建造之頌德碑而命名。

基山里：民國三十五年設立。該里因靠基隆山下，因而命名。 永慶里：民國三十五年設立。緣吉祥語立名。 崇文里：民國三十五年設立。緣吉祥語立名。 福住里：民國三十五年設立。寓意福地福人居意而命名。 瓜山里：民國三十五年設立。該里係金瓜石地區，里內山形似金瓜而命名。 新山里：民國三十五年設立。該里係金瓜石地區，原屬墳墓場，後發展為地區新興之里。 石山里：民國三十五年設立。該里係金瓜石地區，為一不毛之地像石頭似，故命名之。 銅山里：民國三十五年設立。該里係金瓜石地區，地產銅礦，因而命名。 瑞濱里：民國五十九年十二月一日設立。由深澳里劃出，因該里有瑞濱海水浴場及瑞濱國小而命名。 海濱里：民國三十五年設立。昔為庚子寮莊地區，因地濱大海而命名。 深澳里：民國三十五年設立。因臨海，岸曲水深，故曰深澳。 濂洞里：民國三十五年設立。該地原為水南洞，地有天然石洞，處水之南，故曰水南，後因名不雅，乃曰濂洞。 濂新里：民國五十九年十二月一日設立。由濂洞里劃出，因係新發展地區，故名濂新。 鼻頭里：民國三十五年設立。地處濱海，為一岬角突入大海，形若鼻頭以名。 南雅里：民國三十五年設立。原為南子吝莊，以其不雅，乃改為南雅。 新峰里：民國八十七年八月一日設立。以爪峰里行政區域調整劃出，取其「新」增之里名之。 資料來源 : http://www.banqiao.land.ntpc.gov.tw/web/SelfPageSetup?command=display&amp;pageID=20007&amp;page=view&amp;PX=
