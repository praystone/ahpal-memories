226新北市平溪區沿革~ 開發簡史<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

　　組成「台北炭礦株式會社」（後又改為台陽礦業株式會社），才正式開始採掘，之後平溪線鐵路的興築，更使平溪進入發展的蓬勃期，形成現今平溪村和石底村聚落、菁桐坑聚落與十分聚落。 　　平溪鐵路於民國七年（大正七年）三月中旬，鐵道部技手測量由猴硐經十分寮到菁桐坑的路線；顏雲年於同年六月創立台陽公司，也投下鉅額資金，開闢平溪線鐵路。這條鐵路，從宜蘭線鐵路三貂嶺分線起，至終點菁桐坑，長為十二．<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />九公里。興築鐵路平溪線工程不易，因為它沿著基隆河上游溪岸，需要開崖鑿洞，施工期間又遇上第一次世界大戰後日本經濟不景氣，身為殖民地的台灣，也深受影響，施工被迫停頓，民國十年（大正十年）七月始告竣工。平溪鐵路完成後，對整個山城的發展，有著莫大的影響與貢獻。由於這條鐵路的完成，平溪的對外交通才得以打開，當地居民的日常用品之輸入、煤礦礦產的輸出，都仰賴這條鐵路，直到今日這情形並未改變多少。 　　到了六０年代，隨著礦坑一個個的停採，本鄉的人口大量外移，盛極一時的礦業城市又回復到以農為生的鄉村。隨著台灣經濟穩定，人民生活富足後，開始尋求心靈的充實、放鬆，傾向走入大自然或是探尋古蹟回顧歷史。從七０年代國民旅遊興起，純樸的礦業聚落景觀，逐漸在旅遊市場上受到歡迎，九份即是一個最好的例子。本鄉已沈寂了廿、卅年，應該是重振的時候，所以全鄉積極投入觀光業。本來鐵路局想要拆除虧損累累的平溪線鐵路，然而，於鄉民極力爭取下，終可保留下來，成為觀光鐵路，並推展平溪一日遊。本鄉境內觀光據點很多，如知名的十分瀑布、野人谷及萬寶洞等等，都是休閒渡假的好去處。藉由觀光業的發展，相信本鄉第二個春天不久將來臨。 行政區域變遷 　　宣統元年（明治四二年，一九０九年），台灣地方改制為十二廳，廢基隆廳，本鄉隸台北廳水返腳支廳十份寮及石底二區。民國九年（大正九年）日本駐台總督改任文官田健治郎，重新更改台灣地方行政區域，將之區分為五州二廳四十七郡三市二六三街庄，本鄉改隸台北州七星郡平溪庄。民國十五年（昭和元年）實施五州三廳制，除增加澎湖廳外，行政區域並無很大的改變，本鄉不受影響。民國廿一年（昭和七年）改隸基隆郡，仍為平溪庄，直到光復。 台灣光復後 　　民國卅四年（昭和廿年）日本戰敗投降，十月廿五日台灣光復，行政區域仍維持原制，至同年十二月六日公佈省轄市組織規程，十一日又公佈台灣省縣政府組織規程，將台灣原有的五州三廳十一廳市，改為八縣九省轄市及二縣轄市。民國卅五年一月，各縣市政府分別成立後，縣市（縣轄市）下之行政單位為區鎮、鄉里、村，而省轄市則設區及其下之里。平溪為台北縣基隆區平溪鄉。民國卅九年八月，行政院重新劃分全台的行政區域，將全台分為十六縣五省轄市一管理局，原各區署一律裁廢，平溪直隸台北縣，其下有十三村、一百廿七鄰。民國六十七年本鄉調整行政區域，原十三村變成十二村，包含薯榔、白石、菁桐、石底、平溪、嶺腳、東勢、十分、新寮、望古、平湖與南山。而今之東勢村原分為紫來、東勢二村，於民國六十七年紫來村併入東勢村。 村里名由來 新寮村：以「新寮庄」得名。因此區地力瘠薄，開闢較遲，相傳咸豐三年（一八五三年），始有泉州人胡文濟、胡文隈等前往開闢，種植大青、蕃薯等作物。 資料來源 : http://www.ntpc.gov.tw/web/SelfPageSetup?command=display&amp;pageID=20143&amp;page=view&amp;PX=
