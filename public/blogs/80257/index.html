232新北市坪林區沿革~ 開發簡史 　　本鄉位於台北縣的東南方，因地處偏遠，山野瘠薄，相較於其它鄉鎮的開發，算是落後；最早的拓墾，約相當於中國清朝乾隆末年，可分為兩時期敘述：　 一、清乾隆嘉慶時期 　　此時期，中國大陸閩粵沿海移民大量湧入現在的台北地區，約百年時間，台北縣平地，山坡平原，河流沿岸，普遍開闢；屬北縣的石錠，雙溪、深坑、土城、三峽以及坪林多在此時期開發，本鄉內坪林村，土億村，漁光村均屬此時期開發。　 二、清道光、咸同時期 　　開闢者已轉入山地地區，栽茶煮腦，培植大菁，北勢溪南岸地區及雙溪、貢寮、三峽成福山地和坪林均在這時期開闢，本鄉內水德村，闊瀨村、石嘈村、大林村、粗窟村等也均漸漸開闢。 村里名由來 　　本鄉四圍皆山，中為平地，開闢初始，森林茂密，因平坦地形稱「坪」，又有茂盛的森林分佈，故以「坪林」通稱，有「地勢平坦的林區之意」。由於地形上林木由高山向平原傾斜，於傾斜尾端建莊，因此以「坪林尾莊」為名。民國九年，日人設莊治於此，為「坪林莊」。光復後為「坪林鄉」。 　　本鄉原有坪林、水德、大林、上德、新昇、漁光、闊瀨、石嘈、粗堀、金溪等十村，<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />民國六十七年三月二十六日上德、闊瀨、金溪等三村各合併入新昇村、漁光村、粗堀村。民國六十九年十月十日，新昇村又更名為上德村。現有坪林等共七村。 坪林村：以坪林尾莊得名。乾隆末年，有安溪人陳梓孚者，採取金石斛等藥草至此。見土地肥沃，可以耕墾；歸後，至嘉慶初年，即約同楓子林（今石碇鄉）、冷飯坑墾戶陳合興等十四人來此開闢。以白銀一兩，向秀朗山胞購來。初墾之時，山胞進擾不已，嗣後移民漸多，合力以禦，乃得闢。以地勢平坦，森林茂密，於林端建莊，乃曰坪林尾莊。 水德村：以水聳淒坑莊得名。道光初年，泉州人鍾姓開闢。當時人口繁盛，為茶及大菁之集散地。地有小瀑布，以水聲得名。 大林村：以人口稀少，地多山林故名。 上德村：緣雅麗語立名。 漁光村：本村大粗坑為昔年採製造船木料之所，故名。 闊瀨村：以闊瀨莊得名。道光時，泉人林光祿開闢，地多流水淺瀨，故名。 石嘈村：以石嘈莊得名。道光初年，安溪人陳金來等十八人開闢。溪底有石，狀若嘈，故名。 粗窟村：以粗窟莊得名。道光末，安溪人王同開闢，地有溪谷，多巨石參差，故名。 金溪村：以昔日金瓜寮莊得名。光緒時，尚為山胞居地。日人據臺，光緒二十三、四年間，我抗日義軍徐祿、陳秋菊等據此抗日，山胞始退，地乃開闢。嗣為日人焚燒，復為山胞地區。民國十一年（日本大正十一年），始編入坪林莊。 資料來源 : http://www.banqiao.land.ntpc.gov.tw/web/SelfPageSetup?command=display&amp;pageID=20122&amp;page=view&amp;PX=<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
