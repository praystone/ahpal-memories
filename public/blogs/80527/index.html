004宜蘭縣歷史沿革~ 　　宜蘭古稱"蛤仔雞"（亦有作葛雅蘭、蛤仔蘭、甲子蘭等），原為平埔族Kavalan人居住地，直到清朝才開墾成為城市。宜蘭面積2137平方公里，人口44萬。 　　宜蘭是個多山的縣，山的環抱致使蘭陽平原形如畚箕，在東北季風的吹拂下，宜蘭盡攬雨水濕氣，故人稱"竹風蘭雨"。宜蘭森林茂密，喬木叢林櫛比，蘊藏豐富。河川多發源於中 <?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />

央山脈，以蘭陽溪（古稱宜蘭濁水溪）為最大，全長<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />73公里，其下游形成扇狀三角形而且肥沃的平原，堪稱宜蘭的動力之河。 　　產業方面，農業一向是宜蘭的重要產業，主要作物為稻穀。漁業是宜蘭另一項重要產業，綿長的海岸線使得南北漁業發達，如大溪、梗枋、南方澳等沿海養殖業或近海漁業特別發達。山林、沼澤、河塘遍佈，山鳥與水鳥齊飛，宜蘭實為野生鳥類的新天堂樂園。宜蘭以山水勝景取勝，北關、太平山、翠峰湖、棲蘭、明池、松蘿湖、神秘湖、福山植物園最為代表；人文風情則有頭城牽罟、二龍村賽舟、本地歌仔戲，還有致力田園鄉土體驗的頭城、北關、香格里拉等休閒農場，以及南澳純樸的泰雅風情；而規劃設計精良的冬山河游憩區、羅東北成運動公園，更是近年臺灣公共藝術、建設的里程碑。 歷史沿革

　 1950年臺灣調整各縣市行政區域，其中：臺北縣分為臺北、宜蘭二縣。宜蘭縣管轄宜蘭、羅東、蘇澳3區及宜蘭市。計1市11鄉鎮。246941人，面積2137.4615平方千米。縣政府設于宜蘭。　宜蘭縣：轄宜蘭市、羅東、蘇澳、頭城3鎮，及礁溪、壯圍、員山、冬山、五結、三星、太平、南澳等8鄉。疆界：東為蘇澳鎮北方澳海岸，位於東經121°46′8″；西為太平鄉卑南村桃山，位於東經121°14′24″；南為南澳鄉大濁水溪口，位於北緯24°18′49″；北為頭城鎮大裏簡，位於北緯24°

59′25″；中心位置為三星鄉月眉村，位於東經121°32′34″，北緯24°39′20″。本縣南與花蓮、台中兩縣為界，東臨太平洋，西連桃園、新竹兩縣。島嶼有：龜山島位於東經121°55′50″—121°57′38″，北緯24°49′59″—24°50′56″。龜卵島位於東經121°55′37″—121°55′41″，北緯24°48′24″—24°48′32″。

　　1958年7月15日，太平鄉更名為大同鄉。1971年12月2日，將釣魚臺列嶼劃歸宜蘭縣（頭城鎮）管轄：包括釣魚臺、黃尾嶼、赤尾嶼、沖北岩、沖南岩、北小島、南小島、飛瀨小嶼共8個島嶼。總面積6.1636平方千米。

　　1976年7月1日，員山鄉的一至四鄰劃歸宜蘭市梅洲裏，原三星鄉所轄的中華村劃歸員山鄉。1979年9月1日，三星鄉天山村的王蘭巷劃歸大同鄉松羅村。 資料來源 : http://baike.baidu.com/view/103195.htm
