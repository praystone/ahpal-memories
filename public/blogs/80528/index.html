260宜蘭縣宜蘭市沿革~     宜蘭市位於蘭陽平原精華區的中央，東通壯圍鄉，西連員山鄉，南鄰蘭陽溪與五結鄉相對，北接礁溪鄉，為宜蘭縣的核心都市、交通樞紐。     宜蘭縣於清嘉慶15年（1810）收入清朝版圖，嘉慶17年，正式設廳治理，廳治即選在五圍，即今之宜蘭市。嘉慶18年，宜蘭城修築完成，城內設施在數年內一一完備，宜蘭城儼然成為蘭陽平原政治、經濟、文教的中心。光復後 ，宜蘭正式設縣，宜蘭市為縣治所在，並為縣內唯一的縣轄市，全縣級的設施，如縣政府、縣議會、文化中心、縣圖書館等，均設在本市。     在歷史背景與豐厚的文化資源條件下，宜蘭市一向被譽為宜蘭的文教特區。     宜蘭市一帶舊名「五圍」。1920年台灣地方改制，成立宜蘭街，隸屬台北州宜蘭郡，1940年實施市制，改為宜蘭市，戰後初期，改為台北縣宜蘭市，1950年改為宜蘭縣宜蘭市至今，為宜蘭縣唯一的縣轄市，宜蘭市為全宜蘭縣的政治行政文教中心都市，宜蘭縣政府原址在原新月廣場附近，緊鄰宜蘭設治紀念館，1997年以後搬遷至原日治時代神風特攻隊遺址附近。 資料來源 : http://zh.wikipedia.org/wiki/%E5%AE%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />9C%E8%98%AD%E5%B8%82<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
