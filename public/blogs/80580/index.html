263宜蘭縣壯圍鄉沿革~     壯圍鄉舊名「民壯圍」、「民壯圍堡」，嘉慶七年（1802年）時，由吳沙率眾進入開墾蘭陽平原，後為酬謝有功青壯鄉民，故稱之。     1920年，台灣總督府在此設立「壯圍庄」，劃歸台北州宜蘭郡管轄。 戰後，改街庄為鄉鎮改稱「台北縣壯圍鄉」，1950年宜蘭縣設立，改稱「宜蘭縣壯圍鄉」，沿用至今。 資料來源 : http://zh.wikipedia.org/wiki/%E5%A3%AF%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />9C%8D%E9%84%89<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
