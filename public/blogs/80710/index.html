300-3新竹市香山區沿革~     香山地名由來傳說有二：一說是鄭成功治台時，為原住民族道卡斯族竹塹社所居，無固定名稱；爾後漢人流寓至此，見大坪頂一帶，漫山遍野無名花草盛開，薰芳馥郁，故名香山。     另一說自鹿仔坑秀才林秀春派，傳云：香山往昔為竹塹番棲住地，漢人初來稱曰番山，後覺地名不雅，乃改稱香山。     香山與新竹市有幾度分合：1920年設立香山庄屬新竹郡，1941年併入新竹市，戰後並一度仍為新竹省轄市之轄區。     1950年，台灣實施地方自治，新竹市改為縣轄市、香山改為鄉。     1982年<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />7月1日新竹回復省轄市，香山再次成為市轄香山區、並於1990年11月1日正式成立香山區公所。 資料來源 : http://zh.wikipedia.org/wiki/%E9%A6%99%E5%B1%B1%E5%8D%80<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
