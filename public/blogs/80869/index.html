304新竹縣新豐鄉沿革~     新豐鄉舊稱紅毛鄉，因境內紅毛港而得其名，《新竹縣志》記載，傳說南明唐王隆武元年（1646年），荷蘭人因船破登陸紅毛港。時間距今三百五十多年。     雍正三年（1725年），粵省陸豐縣人徐立鵬到竹塹埔西北約二十里之紅毛港新莊子開墾，成為客家籍移入竹塹之始。來自金門以閩南為主的鄭氏家族，也陸續進入紅毛港開墾，後期移入新竹市區，新竹市議會議長鄭再傳的家族即為其一。     日治時代大正9年（1920年），台灣實施街庄制，設為紅毛庄，轄屬新竹州新竹郡。轄域內分為福興、青埔子、後湖、崁頂、中崙、新庄子、紅毛、員山、坑子口九個大字。戰後，更名為紅毛鄉，因其名不雅，於1956年改稱新豐鄉。     1953年5月，新竹縣文獻會委員郭輝在紅毛港發現之「磨製石庖丁」破片及史前繩紋陶器碎片，深受考古學界重視，文化遺物主要是紅色、褐色、淡褐色的夾沙陶。器型為侈口鼓腹的罐形器，口緣通常外侈低矮，少量帶有圈足，通常從頸部以下器身佈滿拍印的繩紋。石器以農業用具日常生活用具為主。 資料來源 : http://zh.wikipedia.org/wiki/%E6%96%B0%E8%B1%90%E9%84%89_(%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
