337桃園縣大園鄉沿革~ 　　大園鄉舊稱『大坵園』，位居沿海地帶，鄉民以捕魚和種植農作物為生。古詩『漁人網集許家村，小艇搓搓漲水痕，難得沙深魚又夥，捕來換取盈樽斟』『乘興登臨眼界寬，蛛屯俯瞰海漫漫，三千弱水知何處，絕鳥蓬壺訖漢官』之寫照當時繁榮實景，後因海沙淤積逐漸凋零，人口外移減少。 　　近年因中正國際機場、中正航空科學館、中國石油公司沙崙輸油站、大園工業區、竹圍漁港公設帶動本鄉繁榮與人口增加，現全鄉區域劃分為十八村四百一十七鄰(※原建華村因行政區域調整<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />民國95年2月1日併入大海村)，設籍人口正逐年增加中〈最新統計請點選網頁上方之人口統計〉，展望邁入二十一世紀亞太航空城，營造東方新明珠的目標努力。 資料來源 : http://www.taynhr.gov.tw/cht/profile/history.html<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
