352苗栗縣三灣鄉沿革~     因為中港溪有四個彎曲處，每個彎曲都有原野可以設庄開墾，後人又把「彎」改字為「灣」，也就是現在的內灣、二灣、三灣、四灣。     本鄉，因為本地恰位於中港溪中游東岸的第三個曲流河階上，故稱為『三灣』。 資料來源 : http://home.educities.edu.tw/nkhs9323005/%A5x%C6W%A6U%B<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />6m%C2%ED%A6a%A6W%A4%A7%A5%D1%A8%D3.htm<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
