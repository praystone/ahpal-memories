364苗栗縣大湖鄉沿革~     大湖在漢人入墾前，東部山區為泰雅族汶水群、大湖群聚居之地。     原住民稱本地為馬凹（Ma-Ao），其意為山楜椒而得名。此外，大南勢方面的泰雅族，又將大湖叫做巴價拉崎（Bagalagya，或譯巴喀刺他給），一說是為了紀念一位頭目；一說為周圍溪水環繞之意。     咸豐六年（一八五六年），銅鑼庄新雞隆人吳立傳，出獵觀音山附近高地受困，侄吳定新馳援，見東方低地四面環山成一盆地，平原中茅葦花齊放，微風吹遇處如湖面波狀，故命名為「大湖」而沿用迄今。 資料來源 : http://zh.wikipedia.org/wiki/%E5%A4%A7%E6%B9%96%E9%84%89_(%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
