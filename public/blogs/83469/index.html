希望大家看到有興趣的人也能自己運用

 

一、ID增加自序

這個是從人氣超高的星人(gary12378)學來的喔，分享給大家

 

語法↓

 

 

#content {over:expressio\6e(((this.className=='l'))||(i=function(){s=documen\74.getElementById('spaceindex_name');s.innerHTML= s.innerHTML +'（做事總是很勤勞\3C strike\3E又嫌麻煩\3C /strike\3E的左小）';},i(),this.className='l'))}

#spaceindex_name EM { display: none \9; }

 

 

把上面的語法複製貼上就可以了

紅色字體部份

（做事總是很勤勞\3C strike\3E又嫌麻煩\3C /strike\3E的左小）

請改成自己喜歡的敘述吧

\3C strike\3E 和 \3C /strike\3E 是刪除線，把想要加刪除線的文字包起來

前面加 \3C strike\3E，後面加\3C /strike\3E，改好就完成了。 如果不想用刪除線想用粗體的話，就改為 \3C strong\3E 和 \3C /strong\3E 包起來即可。

 

二、跑馬燈

 

語法↓

 

 

/跑馬燈/ body {over:expressio\6e(((this.className=='l'))||(i=function(){s=documen\74.getElementById('space_info');s.innerHTML='\3C embed src=http://huangyu43.myweb.hinet.net/eyny/01.swf width=560 height=25 flashvars=txt=歡迎來到我的部落格 autostart=true loop=1 \3E \3C/embed\3E \3C/object\3E' + s.innerHTML ;},i(),this.className='l'))}

 

 

http://huangyu43.myweb.hinet.net/eyny/01.swf  就是你要插入的FLASH網址。

歡迎來到我的部落格 就是你要給它跑的文字，改成自己喜歡的，要跑馬燈性質的FLASH才可以用。

width=560 height=25  跑馬燈寬560、高25要看該FLASH檔設計而定，請自己調整吧。

space_info 要插入的位置(個人資料的上面)，記得別重複到(例如有插入YOUTUBE影片的人)。
