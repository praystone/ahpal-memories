406台中市北屯區沿革~     北屯區位於臺中市東北部，西以土庫溪與西屯區相鄰，東以頭嵙山與東勢鎮、中興嶺、太平鄉毗連，南與北區、太平鄉鄰接，北與臺中縣潭子、新社二鄉相鄰。     北屯舊名「三十張犁」，位在台中盆地北部，原為拍宰海平埔族岸社總土官阿穆所有。阿穆曾協助清廷討伐叛亂有功，獲賞地多處十張犁為阿穆屬地之南方部分，當時一張犁，是指土地面積<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />五甲，在此處墾成的地計有一百五十甲，故稱為「三十張犁」，又因位於東大墩之北，民國九年，改稱「北屯」。     當時北屯四張犁的繁榮可媲美東大墩，因四張犁位於交通要道，以前要從彰化到葫蘆墩（豐原市），必須經過南屯和四張犁，所以此地便成了彰化城北門外的第一站，來往的人頻繁，自然會帶動一個地區的繁華。何況當時，天黑後，彰化城門就會關閉，旅者進不了城便會在此歇腳，住在棧喝上幾杯茶酒，準備明日一旦再趕著進城。 資料來源 : http://entry.hit.edu.tw/~xe96012/d3.htm<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
