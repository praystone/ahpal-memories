423台中市東勢區沿革~     東勢最早叫「板寮」，意思是木工做木板的工寮。台灣清朝時期稱為東勢角，因為當時漢人開發足跡（今豐原區向東經石岡區至極東邊）。     台灣日治時期1895年劃歸台灣民政支部（隔年改為臺中縣）。     1897年劃歸臺中廳葫蘆墩辦務署。     1901年改為臺中廳東勢角支廳東勢角區。     1913年12月，抗日誌士羅福星發動起義苗栗事件，賴來也在東勢響應，在革斃數名日警後也遭到日警革斃，史稱東勢角事件。     1920年台灣總督府將台灣改成五州三廳制，再改制為設臺中州東勢郡東勢庄。     1933年升格為東勢街。     1945年中華民國政府接收台灣，東勢街改制為臺中縣東勢區東勢鎮。     1950年8月廢區署，改為臺中縣東勢鎮。     2010年12月25日隨著臺中縣市合併為直轄市而改制為東勢區。 資料來源 : http://zh.wikipedia.org/wiki/%E6%9D%B1%E5%8B%A2%E5%8D%80<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
