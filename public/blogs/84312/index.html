502彰化縣芬園鄉沿革~ 這裡最早是由平埔洪雅族貓羅社所居住，清康熙初葉（約1660年）始有閩人（福建人）移入墾拓。當時此處尚屬彰化縣半線堡之一部份，芬園於清代雍正元年（1723年）彰化正式置縣時稱「貓羅社」，屬彰化縣半線堡線北社番之一部份，至乾隆二十九年以後，由彰化縣轄內諸番社中獨立分出為「貓羅堡」（貓羅堡包含今彰化縣芬園鄉、台中市霧峰區、彰化市及台中市烏日區一部分）。     1887年台灣建省，改隸台灣府台灣縣貓羅堡。     1895年日本治理台灣後，於1909年芬園境域成為台中廳直轄「芬園區」（當時非彰化支廳所轄），這是「芬園」正式成為行政區域名稱的開始。     1920年改隸屬於台中州彰化郡的「芬園庄」。     戰後1945年由台中州接管後改台中縣。     1950年10月全台行政區域調整，將台中縣之彰化、員林、北斗三區合併，成立彰化縣政府，芬園鄉隸屬彰化縣迄今。 資料來源 : http://zh.wikipedia.org/wiki/%E8%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8A%AC%E5%9C%92%E9%84%89<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
