540南投縣南投市沿革~ 南投之地名譯自平埔洪雅族南投社社名，該社社名，初見於康熙三十四年（1695年） 修之台灣府志。其社名係與同族阿里坤支族之北投社對稱之，因在北投社之南。諸羅縣志所載：「東為南投山，內社二，溪南（貓羅溪）為南投，溪北為北投（今屬草屯鎮）。」 南投街區的形成在乾隆中葉之前。自乾隆二十四年（1759年）設南投縣丞於南投街，隸屬彰化縣。日治時期歷經台灣民政支部彰化出張所、台中縣南投堡、南投廳南投堡（廳治設於此），至1920年設置南投街，劃歸台中州南投郡。 戰後初期改為台中縣南投區南投鎮；1950年又調整台灣行政區域調整，實行小縣制，南投設縣，並撤廢區署，改為南投縣南投鎮；<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />1957年7月1日台灣省政府遷至中興新村，南投市遂為省府所在地，1981年「南投鎮」升格為縣轄市，並改稱為「南投市」，是南投縣唯一的縣轄市，為南投縣之政治中心。 遺址 共計有半山遺址、軍功寮遺址、公埔遺址、小半山遺址、十八張遺址、內轆遺址。 具有三重行政機能的都市 南投市，早在清朝乾隆年間設立南投縣丞之後，即為一個具有行政機能的市鎮。 日治之後，不論設廳或是設郡時期，南投市一直為南投地區的區域行政中心。 台灣光復後，南投市不僅是鄉、鎮、市級的地方行政中心，亦為縣治所在；民國四十六年(1957)，台灣省政府選定南投鎮作為施政中心，本鎮一躍為台灣地區獨一無二、兼有地方、區域與中央三級行政中心機能的都市。 古都之說 南投市在臺灣西部是漢人較相對晚進入的地區之一，然而其行政歷史仍是南投地區四鄉鎮中之最。在《南投郡管內概況》一書中，對於南投郡及南投街的描述：「本郡向來為中部山區政治核心，人民以南投街為往來中心，呈現相當繁榮」，又提到「草屯庄昇格為草屯街，具凌駕古都南投街之勢」。反映出南投市在行政機能歷史及人文活動上的面貌。 資料來源 : http://zh.wikipedia.org/wiki/%E5%8D%97%E6%8A%95%E5%B8%82<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
