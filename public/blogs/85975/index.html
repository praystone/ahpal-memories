如果、你在乎我 …

✍️ SHAWEE 📅 2012-03-01

作者：SHAWEE

發文：2012-03-01

瀏覽：36 次 ｜ 回應：3 則

如果、你在乎我 … 可不可以讓我知道 不要總是讓我找你 那會讓我感覺 你根本就不在意我 ⋯⋯ 如果、你在乎我 … 就不要總是讓我孤單一個人 我真的很討厭寂寞

如果、你在乎我 … 記得多關心我關心我 我喜歡你問我今天做了什麼 而不是自己一個勁地告訴你 我今天怎麼了

如果、你在乎我 … 在我情緒低落 心情鬱悶的時候 要多講話逗逗我 不要一直的沉默 其實 … 只要你一句話 我就會很開心了

如果、你在乎我 … 在我生你氣的時候 絶對不可以想著我在生氣 就不理會我 這樣 … 我會很傷心 也會更生氣 其實、我只是想你哄哄我

如果、你在乎我 … 不要總是回我 呵呵、哦 這類的話語 就算你不想說話 也要多打幾個字 不要讓我感覺你是在敷衍我

如果、你在乎我 … 不要讓我在需要你的時候 卻找不到你、那樣的我很無助

如果、你在乎我 … 要記住我們在一起發生的事情 要記住我的喜好

如果、你在乎我 … 不管是好是壞的事情 我都想你可以告訴我 讓我分享你的快樂 分擔你的憂愁

如果、你在乎我 … 你會想辦法、讓我每天都開開心心的吧? 如果我在乎你、我也可以做到 …更多
