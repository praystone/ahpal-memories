545南投縣埔里鎮沿革~     埔里鎮，舊稱埔裏，取自原住民社名，位於臺灣南投縣北部，為臺灣本島地理中心，地形則屬於典型的陷落盆地地形。     埔里鎮是清代水沙連一部份，全境是由中央山脈、合歡山白姑支脈與雪山山脈大橫屏支脈包圍，境內有起伏的丘陵與埔里盆地構成，盆地南北受南烘溪、眉溪兩大河川切割，是渾然天成的遠古湖泊流失所遺留的盆地地形。 資料來源 : http://zh.wikipedia.org/wiki/%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />9F%94%E9%87%8C%E9%8E%AE<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
