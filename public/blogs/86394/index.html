555南投縣魚池鄉沿革~     魚池鄉原稱「五城堡」，日治時期原屬於南投廳埔裡社支廳管轄，1920年（大正9年）年10月1日，廢廳建州，改為台中州新高郡魚池庄，同時成立庄役場（鄉公所）。     民國<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />34年8月15日台灣光復，於翌年1月21日改為台中縣新高區魚池鄉。     民國39年10月21日全台調整行政區域，改隸南投縣，轄有魚池、東池、大林、東光、共和、新城、大雁、五城、中明、水社、日月、頭社、武登等十三村，即現有的行政區域。 資料來源 : http://zh.wikipedia.org/wiki/%E9%AD%9A%E6%B1%A0%E9%84%89_(%E5%8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
