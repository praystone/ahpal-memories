603嘉義縣梅山鄉沿革~     梅山舊稱為「梅仔坑」（台灣日治時稱『梅仔坑庄』），因為本地位於倒孔溪南岸的寬闊坑谷內，而且這一帶往昔是以梅花著稱，故有此稱。後來則改為「梅山」。另有一說為：本地位處山腳地帶，為行旅必經之地，有人在溪畔築屋，販售「米糕粥」，閩人稱粥為「糜」，乃稱本地為「糜仔坑」。     1920年，台灣地方制度改正，設立小梅庄，隸屬台南州嘉義郡，戰後改為台南縣嘉義區梅山鄉，1950年實施地方自治改隸嘉義縣。 梅山鄉日治時期行政沿革     日治初期屬臺南縣嘉義支廳，1895年9月改為臺南民政支部嘉義出張所。     1896年改為臺南縣嘉義支廳，1897年嘉義縣梅仔坑辨務署。     1898年臺南縣嘉義支廳，1901年嘉義廳梅仔坑支廳。     1907年竹頭崎支廳梅仔坑區，1920年臺南州嘉義郡小梅庄。 1946年迄今     戰後當地居民認為小梅庄名與鄰近「大」林比較，聽起來比較「小」，因而希望改名，後便改名為梅山鄉。     1946年梅東、梅南劃為梅東、梅北、梅南三村，1952年太平村分出太興村，1967年龍眼村分出碧湖村，半天村分出永興村。 資料來源 : http://zh.wikipedia.org/wiki/%E6%A2%85%E5%B1%B1%E9%84%89_(%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
