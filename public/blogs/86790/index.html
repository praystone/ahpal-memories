613嘉義縣朴子市沿革~

613嘉義縣朴子市沿革~     清乾隆12年（1747年）重修台灣府志記載為「猴樹港街」，清乾隆29年續修台灣府志則記載：「朴仔腳街，舊為猴樹港街，今更名。」清朝年間，樸仔腳地區僅有數間農舍及數株樸仔樹。樸仔樹蒼翠成蔭，樹下逐漸成為旅途者或居民所休息乘涼好地方。     清康熙21年（1682年），林馬迎請媽祖，欲至居住地布袋嘴半月庄供祀，經牛稠溪〈朴子溪〉南岸樸仔樹下休息。當地民眾聞訊聚集參拜，並奉神意指示要停住此地，故在此樹下立廟稱為樸樹宮。     清乾隆54年（1789年），樸樹宮奉令改為「配天宮」。當地便以媽祖廟為中心，逐漸發展成市鎮，當地因於樸仔樹下建廟，奉祀媽祖而發跡，於是取名「樸仔腳」。指樸仔樹下的意思，「腳」是台語「下」的意思。     1898年9月8日設立嘉義國語（日語）傳習所樸仔腳分教場，同年10月1日改為樸仔腳公學校，朴子新式教育之始。     1911年蒜頭糖廠運蔗鐵道朴子線通車。     1920年（大正9年），台灣總督府實施州廳－郡市—街庄三級地方區劃，改樸仔腳為朴子，設立朴子街隸屬台南州東石郡，為東石郡役所設治在朴子街（今朴子警分局廳舍）。     1932年六腳鄉下雙溪居民因朴子溪洪水氾濫集體遷村，在樸仔腳與雙溪口間重建家園，建成新吉庄（新結庄仔）與下寮仔。     1934年興建朴子水塔，塔高35公尺，至今仍為朴子最顯著的地標。     1936年(昭和11年)<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />9月10日東石神社鎮座。（今朴子藝術公園）     1945年，第二次世界大戰結束，行政區劃不變，改稱為台南縣東石區朴子鎮。     1950年行政區域調整，廢區署，東石區、嘉義市、嘉義區合併為嘉義縣。     1962年10月，原隸屬義竹鄉的牛挑灣、南勢竹改隸朴子鎮。     1972年9月，鎮內兩所國中協議實施男女分校，東石國中限收男生，朴子國中專收女生至今。     1985年4月7日，省立朴子醫院開業（今衛生署朴子醫院）。     1991年（民國八十年）十一月嘉義縣政府遷至朴子西界太保市祥和新村。     1992年9月10日朴子鎮改制為朴子市。     1999年3月6日蒜頭糖廠運蔗鐵道朴子線停止營運，並陸續拆除鐵軌。     2001年1月16日長庚醫院嘉義院區開業。 資料來源 : http://zh.wikipedia.org/wiki/%E6%9C%B4%E5%AD%90%E5%B8%82<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
