614嘉義縣東石鄉沿革~     西元1661年福建泉州惠安縣人柳櫻隨鄭成功來到台灣，後裔即到東石開拓。     清代以來陸續有漢人渡海入墾，編漁戶，累世以蚵田為活計。同年代孫黃生、黃聖兄弟自福建泉州晉江縣東石渡海來臺移拓樸仔腳東石寮，為東石地名由來。     日治時期東石設立辦務署，後改為嘉義廳東石港支所。1920年（大正九年）改為東石郡東石庄，屬台南州管轄。     戰後改稱東石區東石鄉，隸屬台南縣。1950年（民國卅九年）行政區域劃分改隸嘉義縣。 資料來源 : http://zh.wikipedia.org/wiki/%E6%9D%B1%E7%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />9F%B3%E9%84%89_(%E5%8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
