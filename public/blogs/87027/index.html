623嘉義縣溪口鄉沿革~     溪口鄉舊稱「雙溪口」東接大林鎮以三疊溪為界，北以華興溪與雲林縣大埤鄉為畔。該兩溪於溪口所在地約一公里處交叉合流直奔北港溪形成雙溪咽口，因而稱為「雙溪口」。     日治時期設「雙溪口區」，至1920年10月地方制度更改廢區置庄，同時將「雙溪口區」改為「溪口庄」，隸屬台南州嘉義郡。     戰後改為「溪口鄉」，同時將原有二十保併設十四村，隸屬嘉義縣至今。 資料來源 : http://zh.wikipedia.org/wiki/%E6%BA%AA%E5%<?xml:namespace prefix = st1 ns = “urn:schemas-microsoft-com:office:smarttags” />8F%A3%E9%84%89_(%E5%8F%B0%E7%81%A3)<?xml:namespace prefix = o ns = “urn:schemas-microsoft-com:office:office” />
