【放置空間】：HTTP

【分享期限】：直到掛點為止

【軟體介紹】：

Hosts封鎖清單可有效封鎖掛馬、色情、賭博、低俗廣告等多種類型的惡意網站，封鎖病毒傳播途徑，保障上網瀏覽安全。同時具有小巧靈活，不佔系統資源的特點。

使用方法： 根據相應的系統將Hosts檔案覆寫至以下路徑：

Windows XP/2003/Vista/2008/win7使用者 「C:\Windows\System32\Drivers\Etc」

Windows NT/2000使用者 「C:\Winnt\System32\Drivers\Etc」

注意： 當替換Hosts時，您的防毒軟體或hips類工具可能會出現警告及攔截提示，請務必選擇“允許”或“同意”，以保證hosts文件更新成功。
